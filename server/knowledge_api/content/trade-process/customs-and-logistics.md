# 报关与物流（Customs & Logistics）

报关（customs declaration）与物流（logistics）是外贸出口"最后一公里"，涉及货代（forwarder）、船公司/航空公司、报关行与目的国申报。本文件覆盖出口报关、订舱、海运/空运、装柜、提单及美国 AMS/ISF 申报。

## 一、出口报关

出口报关（export declaration）由报关行凭单据向海关申报，核心单据：

- **报关单**（customs declaration form）
- **合同/PI**（contract / proforma invoice）
- **发票与装箱单**（commercial invoice / packing list）
- **报关委托书**（power of attorney, POA）
- **出口收汇核销/退税**资料（如适用）

关键要素：**HS 编码（Harmonized System code）**、申报金额、数量、件数、重量（毛重/净重）、原产地。HS 编码决定税率与监管条件，需准确归类。

## 二、订舱（Booking）

- 出货前向船公司/货代**订舱（booking）**，确定船期（sailing date）、港口与舱位。
- 提交**订舱单（booking confirmation）**，确认装柜日（loading date）、截关日（cut-off）。
- 海运术语：**ETD（预计离港）**、**ETA（预计到港）**、**截港**（gate cut-off）。

## 三、海运与空运

| 方式 | 英文 | 特点 | 适用 |
|:---|:---|:---|:---|
| 海运整柜 | FCL (full container load) | 成本低，适合大批量 | 大货 |
| 海运拼箱 | LCL (less than container load) | 按立方米计费 | 小批量 |
| 空运 | air freight | 快、贵 | 急单/高价值 |
| 快递 | courier (DHL/FedEx/UPS) | 门到门、小件 | 样衣/小批 |

- 集装箱常用 **20GP / 40GP / 40HQ**，装柜要计算**体积（volume）与重量（weight）**利用率。
- 货代（forwarder）负责衔接订舱、报关与运输，是外贸物流的关键伙伴。

## 四、装柜（Loading）

- 装柜（loading/container loading）时核对：**唛头（shipping mark）**、纸箱数量、箱单、柜号（container no.）与封签号（seal no.）。
- 装柜前清点，装柜后拍照留档，监督监装（loading supervision）可委托第三方。
- 装柜日期延误会拖累船期，需与工厂、货代、船公司三方同步。

## 五、提单（Bill of Lading, B/L）

提单是海运货物的**物权凭证（document of title）**，核心点：

| 类型 | 英文 | 说明 |
|:---|:---|:---|
| 已装船提单 | on-board B/L | 货物已装船签发 |
| 收货待运提单 | received for shipment | 未装船 |
| 清洁提单 | clean B/L | 无不良批注（通关/结算常用） |
| 不清洁提单 | claused/foul B/L | 有货物瑕疵批注 |
| 电放提单 | telex release B/L | 电放，无需正本 |

- 提单信息必须与发票、箱单一致（件数、重量、货名、唛头），否则影响结汇与提货。
- 正本提单是提货凭证，**遗失风险高**，常用电放（telex release）或电放保函。

## 六、美国 AMS / ISF 申报

出口到美国的货物需在装船前完成信息安全申报：

- **AMS（Automated Manifest System，自动化舱单系统）**：船公司/货代在**装船前 24 小时**向美国海关提交舱单（manifest）。
- **ISF（Importer Security Filing，进口安全申报，10+2）**：进口商/货代在**装船前 24 小时**提交 10 项数据（如收货人、发货人、HS 编码、柜号）。

> 数据须准确、及时，否则可能产生罚金。AMS/ISF 通常由货代或报关行代为向美国 CBP 申报。

## 七、跟单要点

1. HS 编码与申报金额必须与发票一致，防止归类错误导致退关或补税。
2. 订舱提前，预留报关与装柜时间，避免误船。
3. 装柜信息、柜号、封签号、照片留档，作为运输追踪与理赔依据。
4. 提单信息核对无误后再结汇，遇不符及时申请改单。
