# 外贸团队管理与新人培训（Trade Team Management & Onboarding）

外贸团队的核心资产是"客户资源 + 跟单经验"，核心风险是"业务员离职带走客户"。管理体系要解决：**能力可复制、资源不私有化、交接不断档**。

## 一、组织架构与分工

| 角色 | 职责 | 配比 |
|:---|:---|:---|
| 业务（Sales） | 开发客户、报价、谈判、接单 | 1 |
| 跟单（Merchandiser） | 订单执行、工厂协调、验货出货 | 1:1-1:2（跟单:业务） |
| 单证（Documentation） | 报关/产地证/结汇单证 | 1:3（单证:业务） |
| QC | 验货、工厂品质监督 | 按产能配 |
| 采购（Sourcing） | 面辅料开发采购 | 按品类配 |

- **业务+跟单分离**：业务员专注开发，跟单专注执行——一人全包的模式在 3 单/人以上时必然出错。

## 二、新人培训路径（90 天）

| 阶段 | 内容 | 产出 |
|:---|:---|:---|
| 第 1-2 周 | 产品知识（面料/品类/工艺）+ 工厂实习 | 能看懂工艺单 |
| 第 3-4 周 | 流程学习（询盘→出货全流程影子学习）+ 单证实操 | 独立做单证 |
| 第 2 月 | 协助老业务员（回复邮件草拟/报价表制作）+ 展会观摩 | 掌握报价逻辑 |
| 第 3 月 | 分配小客户/小市场独立操作（导师复核） | 独立完成首单 |

- **教材**：本知识库（七域文档）作为新人必读+考核题库来源。

## 三、KPI 与激励

### 业务员 KPI 组合
| 指标 | 权重 | 说明 |
|:---|:---|:---|
| 销售额/毛利 | 50% | 按回款计（防虚假出货） |
| 新客户开发 | 20% | 首单金额/客户数 |
| 客户留存 | 15% | 老客户复购率 |
| 过程指标 | 15% | 询盘转化率/报价及时率 |

- **提成模式**：底薪 + 毛利提成（3-8% 毛利额）——按**回款**结算，坏账倒扣；
- **跟单 KPI**：出货及时率 + 验货一次通过率 + 客户投诉率。

## 四、客户资源管理（防私有化）

1. **CRM 强制录入**：所有客户联系记录/报价/订单进系统——"系统外的客户不存在"；
2. **公司邮箱制**：客户沟通只用公司邮箱（禁用个人微信/WhatsApp 谈单——可配公司账号）；
3. **双人服务制**：重要客户配"业务+跟单"双人对接——客户认公司不只认个人；
4. **离职交接**：客户清单/在手订单/未结款项书面交接+30 天陪访期；竞业协议（核心业务员，需支付补偿金才有效）。

## 五、风险控制

| 风险 | 对策 |
|:---|:---|
| 飞单（业务员私自外单） | 报价审批权限 + 工厂直发监控 + 毛利异常预警 |
| 业务员带走客户 | CRM 客户归属公司 + 双人服务 + 离职交接审计 |
| 报价错误 | 报价三级复核（业务→主管→财务成本复核） |
| 收款违规 | 收款账户唯一（公司账户），业务员不接触货款 |

## 六、知识管理

- **案例库**：客诉/索赔/纠纷案例复盘入库（每案 30 分钟复盘会）；
- **报价库**：历史报价按品类归档（新报价参照）；
- **市场情报周会**：关税/汇率/原料行情周报（15 分钟站会）；
- **本知识库即培训底座**：新人按七域顺序学习，Agent 可基于知识库答新人问。
