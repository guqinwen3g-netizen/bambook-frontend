# 样品间管理与样品全生命周期（Sample Room Management）

样品是外贸的"硬通货"：**报价千万句不如一件好样品**。样品间管理混乱（找不到样/寄错样/样品无记录）是贸易公司常见内耗。

## 一、样品类型体系

| 样品 | 用途 | 留存要求 |
|:---|:---|:---|
| 开发样（proto sample） | 款式开发验证 | 记录+拍照归档 |
| 确认样（approval/seal sample） | 客户确认的大货基准 | **双签封样**（客户+工厂各存） |
| 产前样（PP sample） | 大货前最终确认 | 生产会议基准 |
| 船样（shipping sample） | 大货出货抽样 | 客诉争议比对基准 |
| 色样（lab dip/strike off） | 颜色/印花确认 | 色卡归档 |
| 展样 | 展会/展厅陈列 | 样品间常设 |

## 二、样品编码与档案

### 编码规则（示例）
```
样品编号 = 年份-客户代码-品类-序号
2026-WMT-T-0035 = 2026 年 Walmart T 恤第 35 款
```

### 档案要素（一样品一档案）
- 款号/客户/品类/日期/版本（V1/V2/最终版）；
- 工艺单（规格表/面辅料明细/做工要求）；
- 照片（正/侧/背/细节——白底标准图）；
- 状态（开发中/已确认/已寄出/已封样）；
- 关联订单号（转大货的样品关联生产单）。

## 三、样品间物理管理

- **分区**：按品类/客户/年份分区（挂装区+叠装区+面料样卡区）；
- **标识**：吊牌（编号/款名/客户/日期/状态）——无吊牌不入架；
- **环境**：防潮/防尘/防光（白色面料泛黄）；
- **出入库登记**：借出登记（谁借/何时还——展会借样最易丢失）；
- **定期清理**：季度清理（过季/无关联订单样品淘汰——拍卖/捐赠/报废流程）。

## 四、寄样管理（客户触点）

1. **寄样流程**：客户索样 → 样品检查（熨烫/线头/吊牌）→ 拍照留底 → 快递（单号同步客户）→ 跟踪签收 → 3 天内跟进反馈；
2. **样品费**：收费原则（见 `trade-process/sample-development-and-confirmation.md`）——免费样品设上限（防薅样）；
3. **快递选择**：DHL/FedEx 主账号（协议折扣）——到付账号（ freight collect）给未付费客户；
4. **寄样清单**：箱内附样品清单（款号对照）+ 名片——细节专业感。

## 五、封样管理（法律意义）

- **双签封样**：确认样一式两件——客户签封一件存我方，工厂签封一件存生产端；
- **封样要素**：签字/日期/封样袋密封——大货争议的裁决基准；
- **船样抽取**：每票大货出货前抽 2-3 件船样（留存 1-2 年——客诉追溯）；
- **封样失效**：改版后旧封样作废标记（防混用）。

## 六、样品成本控制

- **样品成本核算**：开发样成本 = 材料+工时 3-5 倍单价（样品工是技术工）——报价时计入开发费或摊销；
- **免费样品政策**：A 级客户免费 + B 级收费下单退 + C 级收费——**样品费是客户诚意的试金石**；
- **样品失败率**：开发样→确认样转化率约 30-50%——失败样品成本是开发的正常投入。

## 七、数字化管理

- **样品系统**：样品档案数字化（照片+工艺单+状态可检索）——Agent 可调用样品库回答"我们做过哪些类似款"；
- **3D 样衣**：CLO3D 虚拟样衣减少实体打样（趋势——省 30-50% 打样成本与时间，见 `customers-market/fashion-trend-forecasting.md`）。
