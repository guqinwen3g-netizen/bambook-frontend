# 出口收款方式实操决策（Export Payment Methods Practice）

收款方式是**风险与竞争力的天平**：要安全就没竞争力，要竞争力就担风险。实操是"按客户/市场/订单"动态决策。

## 一、五种方式风险对比

| 方式 | 出口方风险 | 进口方风险 | 适用 |
|:---|:---|:---|:---|
| 预付（T/T in advance） | **最低** | 最高 | 小客/新客/定制 |
| 信用证（L/C） | 低（银行信用） | 低 | 大客/高风险国 |
| 付款交单（D/P） | 中 | 中 | 中等信任 |
| 承兑交单（D/A） | 高 | 低 | 谨慎 |
| 赊销（O/A） | **最高** | 最低 | 老客/品牌大客户 |

- 详细机制见 `trade-process/foreign-exchange-settlement.md` 与 `trade-process/letter-of-credit-review.md`。

## 二、T/T 实操（最常用）

### 结构变体
| 结构 | 风险 | 适用 |
|:---|:---|:---|
| 100% 预付 | 零风险 | 小单/新客 |
| **30% 定金 + 70% 见提单副本** | 主流平衡 | 常规订单 |
| 30% + 70% 到货后 | 偏高 | 老客 |
| 见提单副本付尾款 | 中（客户拒付风险——已生产） | 信任客户 |

### 电放风险（T/T + telex release 陷阱）
- **场景**：客户要求电放（快速提货）——**电放=放货**，尾款未收齐就电放=钱货两空；
- **铁律**：**尾款到账才电放**（见 `trade-process/new-sales-common-mistakes.md`——电放骗局是新人最贵的学费）。

## 三、信用证实操

- **优势**：银行信用（开证行承担付款——出口方风险低）；
- **成本**：银行费（开证/议付/不符点费——货值 1-3%）+ 单证工作量；
- **软条款/不符点**：见 `trade-process/letter-of-credit-review.md` 与 `trade-process/export-documents-errors.md`；
- **适用**：大单/高风险国/新客户大交易。

## 四、赊销（O/A）的现实

- **现实压力**：欧美大客户普遍要求 O/A 30-90 天（品牌采购惯例——不接就没单）；
- **风控配套**：
  1. **中信保**（出口信用保险——O/A 的安全网，见 `trade-process/foreign-exchange-settlement.md`）；
  2. **信用调查**（见 `trade-process/customer-credit-investigation.md`——授信额度）;
  3. **额度管理**：累计欠款≤授信额度；
  4. **账期纪律**：逾期停发货（付款记录恶化立即收紧）。

## 五、组合与谈判

### 按客户分级
| 客户 | 方式 |
|:---|:---|
| 新客户 | 预付 50-100% / L/C |
| 成长客户 | 30/70 T/T |
| 老客户 | 30/70 或 O/A 30 |
| 战略大客户 | O/A 60-90（+信保） |

### 谈判筹码
- **价格换付款**：O/A 加价 2-3%（资金成本转嫁——见 `trade-process/trade-negotiation-skills.md`）；
- **渐进**：首单预付→翻单 30/70→成熟 O/A（信任积累的付款演进）；
- **市场差异**：欧美惯例 O/A / 中东非洲预付或 L/C / 拉美谨慎（见各市场文档）。

## 六、风险红线

- ❌ 新客大单接受 O/A（欺诈高风险）；
- ❌ 未收尾款就电放/寄正本提单；
- ❌ 制裁/高危国家 O/A（收不回的概率大）；
- ❌ 变更收款账户不核实（邮箱诈骗——见 `trade-process/new-sales-common-mistakes.md`）。
