# 询盘与报价（Inquiry & Quotation）

外贸业务从询盘（inquiry）开始，报价（quotation）是决定订单成败的第一道关口。本文件覆盖纺织服装外贸询盘要素、报价单构成、FOB/CIF 报价口径与常见价格条款。

## 一、询盘要素

客户询盘（buyer's inquiry）通常随附款式图（tech pack / style reference）、面料要求、目标价（target price）与目标市场。业务员应核对以下要素是否齐全：

- **款式描述**：款号（style no.）、图片/图纸、工艺细节（styling）。
- **面料规格**：成分（composition）、克重（GSM）、纱支、后整理（如防水、抗皱）。
- **尺码与尺码表**：size range、合身要求（fit）。
- **数量与目标价**：MOQ（minimum order quantity）要求、预算区间。
- **包装与吊牌**：polybag、纸箱、吊牌（hangtag）、条码。
- **目标市场与合规**：出口国、检测标准（如美国 CPSIA、欧盟 REACH）。

> 要素不全时先补全再报价，避免按错误规格核算导致返工或亏损。

## 二、报价单内容

一份完整的报价单（quotation / proforma offer）至少包含：

| 栏目 | 说明 |
|:---|:---|
| 报价编号与日期 | quotation no. + date |
| 客户与联系人 | buyer、consignee |
| 款号与品名 | style no.、description |
| 面料与规格 | composition、GSM、幅宽（width） |
| 数量与单价 | unit price、currency（USD/EUR） |
| 价格条款 | FOB/CIF/FCA 等（Incoterms 2020） |
| 起运港/目的港 | port of loading / destination |
| 交期 | lead time（生产 + 运输） |
| 有效期 | validity（通常 7–30 天） |
| 付款方式 | T/T、L/C（见单证与收汇文档） |

## 三、FOB 与 CIF 报价构成

### FOB（Free On Board，装运港船上交货）
报价 = 出厂/仓库成本 + 内地运输 + 报关费 + 港杂费 + 装船费 + 利润。风险在货物越过装运港船舷时转移给买方。

### CIF（Cost, Insurance and Freight，成本加保险费加运费）
报价 = **FOB 价 + 海运费（ocean freight）+ 保险费（insurance）**。卖方负担到目的港的运费与保险，但风险仍在装运港转移。

### 常用换算（近似）
- **FOB → CIF**：`CIF = (FOB + 运费) / (1 − 投保加成 × 保险费率)`
- 投保加成通常为 110%（即 CIF×110%），保险费率按货类与航线约 0.3%–1%。

> 同货号不同数量、不同港口，单价差异可能很大，务必写清港口与币种。

## 四、价格条款与术语

| 条款 | 中文 | 风险/费用边界 |
|:---|:---|:---|
| EXW | 工厂交货 | 卖方在工厂交付，买方承担一切 |
| FCA | 货交承运人 | 交至指定地点承运人 |
| FOB | 装运港船上交货 | 越过船舷转移 |
| CFR/CPT | 成本加运费 / 运费付至 | 卖方负担运输 |
| CIF/CIP | 成本保险费运费 | 卖方负担运输+保险 |
| DDP | 完税后交货 | 卖方负担至目的国完税交货 |

## 五、MOQ 与交期

- **MOQ（minimum order quantity）**：起订量，由面料起订、缝制排产、辅料（配件、吊牌）最低量决定。通常接到 MOQ 后报阶梯价（tiered price）。
- **交期（lead time）**：面料备料 + 生产 + 验货 + 海运/空运。常规梭织成衣交期约 30–60 天，含色样/样衣确认周期。
- 报价时明确**交期节点**：色样确认日、大货面料齐套日、验货日、ETD（estimated time of departure）与 ETA（estimated time of arrival）。

## 六、报价核查要点

1. 币种与汇率锁定：USD/EUR 波动大时注明汇率有效期。
2. 核对 MOQ 与数量档位，避免低量高成本。
3. 附价格条款（Incoterms 版本），防止"FOB"理解分歧。
4. 报价留存档案，便于后续对比与跟单追溯。
