# 面料册与剪版贸易模式（Fabric Book & Cut Length: bunch 制作/零剪现货/定织转单）

面料册（bunch）贸易是高端面料的"**现货 + 期货**"混合模式：面料商按季开发花型、制作剪样册分发给定制店/品牌，客户按册选料，面料商**零剪现货快速发货（cut length）或大货定织**。这是 VBC/Reda 等意大利面料厂全球扩张的核心打法，也是中国面料贸易商服务高端定制渠道的必修课。本文件梳理模式机制与运营要点（高支面料品牌体系见 `fabric/super-worsted-suiting-brands.md`）。

## 一、模式机制

| 环节 | 内容 | 成本/周期 |
|:---|:---|:---|
| 花型开发 | 每季 30-80 个新花型（素色/条纹/格纹矩阵） | 打样费 3-6 个月前置 |
| 面料册制作 | 剪样（8×12cm 标准样片）+装订+编号+成分标 | 每册成本 $15-40，印量 500-2000 册 |
| 分发 | 定制店/裁缝/品牌免费或押金领册 | 物流+更新（年 2 次换册） |
| 零剪现货 | 1 剪（3.3m 西装料）起订，现货仓 1-2 周交付 | **备现货占用资金是核心成本** |
| 定织转单 | 客户大货（300m+）转定织，单价降 15-25% | 交期 6-10 周 |

- **商业本质**：面料册=**获客工具**，利润在零剪现货的加价率（定织价 ×1.8-2.5）与定织转单的规模利润之间平衡；
- **现货深度决策**：每个花型备多少卷（25m/卷）——**畅销花型断货=定制店转单竞品**，滞销花型=库存减值（尾货处理见 `fabric/fabric-inventory-stock-strategy.md`）；经验值：经典素色深备（50-100 卷）、季节花色浅备（10-20 卷）。

## 二、运营实务

- **花型编号体系**：成分+克重+花型+颜色四维编码（如 SB150-280-HB-021）——**编号贯穿样册/库存/订单全链**，错号=发错货的高端事故；
- **样片品质**：剪样必须取**无疵点代表性片段**（样片与大货色差/风格差=客诉源头）——样片与大货同缸或留样对照；
- **定制店关系**：定制店按册接单后才向面料商零剪——**面料商掌握"哪个花型被哪些店翻牌"的数据=补货与开发的风向标**（数据资产）；
- **剪版与损耗**：3.3m 标准剪（单排扣两件套）/4m（双排扣或大衣）——**剪裁精度 ±5cm**（多剪是利润流失，少剪毁了客户的单）；
- **代理与窜货**：区域代理制（中国总代/城市分销）——**窜货乱价是渠道大忌**（低价倾销毁掉整个价格体系），合同设区域保护+价格条款（见 `suppliers/supplier-contract-risk.md`）。

## 三、风控与增长

- **库存风险**：面料册模式=重库存模式——**季末未动销花型果断折价清**（服装厂尾单渠道/电商面料店），让库存周转率 >2 次/年；
- **汇率与账期**：进口面料（欧元采购）+本币销售——汇率套保；定制店月结 Net 30-60（信用管理见 `trade-process/customer-credit-investigation.md`）；
- **仿冒风险**：热销花型被国产厂快速仿织——**花型注册（部分国家可外观专利）+快速迭代节奏**（每季新册让仿品追不上）是现实解法；
- **增长路径**：零剪现货→为连锁定制品牌做**专属花型定织**（独家协议）→向上游染厂/织厂延伸（供应链垂直化降本）。
