# 货运保险索赔案例集（Cargo Insurance Claims Cases）

买了保险 ≠ 能赔到钱：**索赔成败在证据链与时效**。案例教你在事故发生的第一时间做对动作（保险基础见 `trade-process/cargo-insurance.md`）。

## 一、成功案例（动作正确）

### 案例 1：集装箱落海全损获赔
- **场景**：海运途中集装箱落海——船公司出"落海证明"；
- **动作**：① 立即通知保险公司 ② 取得船公司事故证明 ③ 提供提单/发票/装箱单/保单 ④ 30 天内获全损赔付；
- **要点**：**一切险+仓至仓条款**覆盖；全损案件证据简单（船公司证明是关键）。

### 案例 2：水湿货损部分获赔
- **场景**：到港发现集装箱顶部渗水，20% 服装水湿；
- **动作**：① **不开箱先拍照**（箱体渗水痕迹）② 申请保险公司检验（survey）③ 检验报告认定损失比例 ④ 按货值比例获赔；
- **要点**：发现货损**第一时间报检**（擅自开箱整理=破坏现场，保险公司可拒赔）。

### 案例 3：共同海损分摊
- **场景**：船舶起火，船东宣布共同海损（General Average）——无货损也需分摊救助费用；
- **动作**：① 保险公司出具共同海损担保函（GA guarantee）② 货主凭担保提货 ③ 分摊费用由保险公司承担；
- **要点**：**没买保险的共同海损 = 自己掏钱分摊**（不买保险的隐性巨坑）。

## 二、拒赔/争议案例（教训）

### 案例 4：延迟报案被拒赔
- **场景**：收货 3 周后发现内货受潮（隐蔽损失），向保险公司报案——**超过通知时效**（通常到货 7-15 天内），拒赔；
- **教训**：到货即开箱抽检（隐蔽损失早发现）；保险条款的通知时限牢记。

### 案例 5：包装不当拒赔
- **场景**：纸箱受潮塌箱——保险公司认定"包装不足"（insufficient packing 属除外责任），拒赔；
- **教训**：出口包装标准（五层瓦楞/防潮袋）；易受潮货加干燥剂+缠绕膜。

### 案例 6：战争险未投保
- **场景**：红海航线被袭击——只投一切险（战争险是附加险），不赔；
- **教训**：**战区航线加保战争险**（War Risk——费率临时上浮但必要）。

### 案例 7：仓至仓条款断点争议
- **场景**：货物到港入客户指定仓库后 3 天发现短少——保险公司主张保险责任在入库时终止（仓至仓到库为止），入库后短少不赔；
- **教训**：**入库即清点**（保险责任终点）；后续风险用财产险覆盖。

### 案例 8：无提单清洁批注的短少争议
- **场景**：目的港短少 3 箱——但装港提单是清洁提单（shipper's load and count），承运人与保险公司互相推诿；
- **教训**：装柜监装+封条号记录（见 `garments/garment-packaging.md` 封柜管理）——装柜照片+封条影像是关键证据。

## 三、索赔时效与流程

| 环节 | 时限 |
|:---|:---|
| 通知保险公司 | 发现货损立即（隐蔽损失 7-15 天内） |
| 申请检验 | 提货前/开箱前 |
| 提交索赔文件 | 备齐后尽快（诉讼时效 2 年） |
| 承运人索赔 | 海运 1 年（海牙规则）——先告承运人再保险代位 |

### 索赔文件清单
- 保单正本/副本
- 提单（全套）
- 商业发票/装箱单
- 检验报告（survey report）
- 货损照片/视频
- 承运人事故证明（如落海/火灾）
- 索赔函（索赔金额计算）

## 四、保险安排建议

1. **投保险别**：一切险（All Risks）为基础 + 战争险（战区）+ 罢工险（必要时）；
2. **保险金额**：CIF 货值 × 110%（加成 10% 覆盖预期利润）；
3. **免赔额**：注意免赔条款（如每次事故 $500 免赔——小额损失自己扛）；
4. **投保时机**：装船前投保（见 `trade-process/export-documents-errors.md` 案例 4——保单日晚于装船日是 L/C 不符点+保险责任瑕疵）。
