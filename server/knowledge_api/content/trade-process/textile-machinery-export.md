# 纺织机械出口实务（Textile Machinery Export: 缝纫设备/织机/染整设备出海）

纺织机械是中国纺织产业链出海的**资本货物线**：孟加拉/越南/柬埔寨/印尼的服装与面料产能扩张持续采购中国设备（缝制设备中国产量占全球 70%+）。与面辅料出口不同，机械出口是**"设备+安装+培训+备件"的长周期服务生意**。设备选型知识见 `suppliers/garment-machinery-equipment.md`——本文聚焦出口贸易链路。

## 一、产品线与目标市场

| 产品线 | 中国地位 | 目标市场 | 单笔规模 |
|:---|:---|:---|:---|
| 工业缝纫机（平车/包缝/绷缝） | 杰克/中捷/标准——**全球产量 70%+** | 孟加拉/越南/印度/非洲 | 柜级（数百台） |
| 特种设备（模板机/自动裁床/吊挂） | 成熟替代欧美日 | 东南亚新建大厂 | 项目级 |
| 针织圆机/横机 | 全球主力供应商 | 孟加拉针织集群/土耳其 | 项目级 |
| 织机（喷水/喷气/剑杆） | 喷水织机全球主导 | 印度/印尼/乌兹别克 | 项目级（百万美元） |
| 染整设备（染色机/定型机） | 性价比替代欧洲 | 南亚/东南亚印染园区 | 项目级 |
| 无纺布设备 | 完整产线输出 | 中东/非洲新建 | 整厂交钥匙 |
| 备件与耗材（针/梭/皮带） | — | 全球存量设备 | 高频小单 |

## 二、贸易链路特征

- **项目型销售**：新建工厂整线采购——**设计院/咨询公司影响选型**（印度/孟加拉咨询生态）；投标周期 3-12 个月；
- **付款结构**：**30% 定金+60% 发货前+10% 安装验收**（行业惯例）——大项目配信用证（审单见 `trade-process/letter-of-credit-review.md`）或卖方信贷（中信保承保——见 `trade-process/export-credit-insurance.md`）；
- **出口合规**：旧设备出口需**装运前检验**（部分国家强制——如印度对旧机械）、新设备 CE/目的国认证；两用物项边界（部分高端织造设备敏感——见 `trade-compliance/dual-use-export-control.md`）；
- **物流**：重大件/超尺寸——**框架箱/开顶箱+港口吊装**；设备防锈包装（真空+干燥剂——海运 30-60 天）；
- **安装调试**：**工程师签证+现场服务周期**（1-4 周）——差旅成本计入报价；远程调试（物联网模块预装）是降本趋势；
- **备件生意**：设备售出后**备件+维修是 10 年长尾收入**（毛利 40%+）——代理商备件库存协议。

## 三、渠道与服务体系

- **代理制**：目标国独家代理（当地售后能力=成交前提）——代理协议框架见 `customers-market/overseas-agents-distributors.md`；
- **直销大客户**：大型纺织集团（孟加拉 DBL/越南 TNG 类）直采+年度框架协议；
- **展会**：ITMA（四年一届全球纺机第一展）、ITMA Asia、孟加拉 DTG、越南 SaigonTex——展会运营见 `trade-process/overseas-exhibition-playbook.md`；
- **中资出海配套**：中国服装厂海外建厂（见 `suppliers/china-plus-one-capacity-strategy.md`）自带设备采购——**"跟客户出海"是最稳订单**；
- **融资配套**：买家分期需求——融资租赁公司合作（设备抵押）或中信保买方信贷。

## 四、风控要点

- **安装验收纠纷**：验收标准（产能/良品率/能耗）写入合同附件——**"达到约定产量"类模糊条款是争议源**；
- **汇率与通胀**：新兴市场货币贬值（孟加拉塔卡/越南盾）——美元计价+尾款发货前收讫（外汇管理见 `trade-process/foreign-exchange-settlement.md`）；
- **知识产权**：**仿制国际品牌的"同款"机型出口=目的国海关 IP 查扣风险**（见 `trade-compliance/ip-brand-authorization.md`）——自有品牌+专利布局；
- **售后责任边界**：易损件（针板/旋梭）不在质保——质保条款列明易损件清单；
- **制裁筛查**：部分目的地（伊朗/缅甸军工关联企业）——最终用户审查（见 `trade-compliance/sanctions-screening-compliance.md`）；
- **旧设备政策**：部分国家限制旧机械进口年限（如印度≤8 年）——接单确认目的国政策。
