# 样品开发与确认（Sample Development & Confirmation）

样品是纺织服装外贸买卖双方确认品质、颜色、版型与工艺的核心载体。任何大货（bulk production）之前，通常需经过一系列样品确认。本文件覆盖外贸跟单中的样品类型与确认流程。

## 一、样品类型总览

| 样品 | 英文 | 阶段 | 作用 |
|:---|:---|:---|:---|
| 色样 | lab dip | 开发 | 确认面料颜色色光 |
| 手刮样/布样 | strike-off / handloom | 开发 | 印花/织花布面效果 |
| 确认样 | approval sample | 开发 | 版型/工艺初步确认 |
| 样衣 | fit sample | 开发 | 确认版型与合身 |
| 产前样 | pre-production sample (PP sample) | 大货前 | 按大货工艺/面料做最终确认 |
| 船样 | shipment sample | 出货前 | 代表大货实际状态留档 |

## 二、关键样品详解

### 色样（Lab Dip）
- 面料染厂按客供颜色打板，供客户确认色光与色差。
- 关键：**光源（light source）**与**色牢度（color fastness）**。常用光源 D65（日光）、TL84（商场荧光）、A（乌丝灯）。
- 确认时要注明内销/出口国的光源习惯，避免"日光下 OK、店中偏色"。

### 布样（Strike-off / Handloom）
- **strike-off**：印花打样，确认花型、配色、套色（screen）效果。
- **handloom**：梭织小样，确认织物结构、手感、克重。

### 样衣（Fit Sample）
- 确认版型、合身度（fit）、工艺（stitching）、辅料（配件 zipper/button）。
- 附带**尺码表（size spec / measurement chart）**，逐部位核对（如胸围、肩宽、衣长、袖长）。

### 产前样（Pre-production Sample）
- 用**大货面料与工艺**制作，是放行大货前的最终确认样。
- 需客户书面/邮件确认（approval）后，工厂方可开裁。

### 船样（Shipment Sample）
- 从大货中抽取，代表实际出货状态，用于客户留档、验货对照、清关参考。

## 三、样品确认流程

1. **收到设计要求**：客户发 tech pack / 色卡 / 参考样。
2. **打样**：工厂按规格打样（打样费 sample cost 需事先谈妥）。
3. **寄样**：附样品样卡（sample card/label），注明款号、色号、日期。
4. **批样**：客户确认（approval）或提出修改意见（comments）。
5. **记录并存档**：每次改样留记录，确认意见落实到产前样。

## 四、样品开发中的常见问题

1. **色差**：lab dip 与标样（standard）色差需控制在可接受范围（如 ΔE 指标）。
2. **版型放大/缩小**：多尺码需做尺码试穿（fit on mannequin），保证各尺码版型一致。
3. **面料替代**：客户指定面料不足时，替代面料（substitution）需重新确认。
4. **样品周期**：打样周期常占交期大头，需在报价时预留。

## 五、跟单要点

1. 样品状态（待打样/待寄/已批/待改）用表格或系统跟踪，避免漏样。
2. 批样意见逐条落到生产单（production order），防止大货遗漏修改项。
3. 产前样批准单（PP approval）是开裁的**前置条件**，未批不放行。
4. 船样留存档案，作后续验货与质量追溯依据。
