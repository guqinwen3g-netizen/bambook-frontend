# 货运保险（Marine Cargo Insurance）

国际海运货损率虽低（约 0.1-0.3%），但单次事故损失可达整柜货值。正确投保与索赔能力，是外贸风控的最后一道防线。

## 一、投保责任划分（与 Incoterms 联动）

| 条款 | 投保义务方 | 风险转移点 |
|:---|:---|:---|
| FOB / FCA | 买方 | 装运港船上/货交承运人 |
| CFR / CPT | 买方 | 同上（买方需自行投保，卖方应提醒） |
| **CIF / CIP** | **卖方** | 卖方投保至目的港/目的地 |

- CIF 下卖方投保是**代办性质**——风险仍在装运港转移给买方，保险单背书后交买方索赔。
- **FOB 卖方注意**：货物上船前风险在卖方，建议投保"国内运输险"覆盖工厂→港口段。

## 二、险别选择

### 基本险（主险，可单独投保）
| 险别 | 英文 | 保障范围 |
|:---|:---|:---|
| 平安险 | FPA | 自然灾害全损 + 意外事故损失（最低保障） |
| 水渍险 | WA/WPA | 平安险 + 自然灾害造成的部分损失 |
| **一切险** | **All Risks** | 水渍险 + 外来原因所致损失（最常投） |

### 附加险（不可单独投保）
- 一般附加险：偷窃提货不着（TPND）、淡水雨淋、短量、混杂沾污、钩损、包装破裂等 11 种（一切险已含）。
- 特殊附加险：**战争险**（War Risk）、**罢工险**（Strikes Risk）——需单独加保，红海/黑海航线必加。
- 特别附加险：黄曲霉素险、拒收险、舱面险等。

> 纺织品怕湿怕污：**一切险 + 淡水雨淋确认覆盖**是标配；走敏感航线加战争险/罢工险（费率约 0.05-0.15%）。

## 三、投保要素

1. **保险金额**：CIF 货值 × **110%**（10% 为预期利润加成，L/C 通用要求）。
2. **保险单据**：保险单（Policy）或保险凭证（Certificate）；L/C 下通常要求可转让的正式保单。
3. **投保时机**：**装船前**投保——保险责任"仓至仓"（Warehouse to Warehouse, W/W），但船后投保若已出险保险公司可拒赔。
4. **币种与赔付地**：与合同币种一致；赔付地通常为目的港。
5. **费率参考**：纺织品一切险约 0.08-0.25%（航线/包装/承运船龄影响费率）。

## 四、索赔流程

货损发现后时效极关键：

1. **收货时当场查验**：外包装破损/湿痕**必须在提货单上批注**（clean receipt 签收后举证困难）。
2. **48-72 小时内报险**：通知保险公司/保单载明的目的港检验代理人（survey agent）。
3. **申请检验**：保险公司指派检验师（surveyor）现场定损，出具检验报告（survey report）。
4. **向承运人书面索赔**：**海运货损向船公司索赔时效 1 年**（海牙规则），逾期丧失对承运人追偿权，保险公司也以此为由减赔。
5. **提交索赔文件**：保单正本、提单、发票、装箱单、检验报告、货损照片、向承运人索赔函副本。
6. **赔付与代位**：保险公司赔付后取得代位求偿权（subrogation）向承运人追偿。

## 五、常见拒赔原因与预防

| 拒赔原因 | 预防 |
|:---|:---|
| 保险责任开始前出险 | 装船前投保 |
| 包装不良（inherent vice） | 出口标准包装，留存装箱照片 |
| 未及时检验定损 | 72 小时内报险 |
| 清洁提单 claims 举证失败 | 提货当场批注 |
| 投保不足额 | 按 CIF×110% 足额投保 |
| 未保战争险（敏感航线） | 红海等航线加保 |

## 六、实操要点

1. **CIF 订单**：投保后保单与提单一起交单结汇（L/C 下单据之一）。
2. **FOB 订单**：提醒客户投保——客户未投保货损后往往迁怒供应商，影响关系。
3. **装箱影像留存**：每柜拍装箱照片/视频（货物状态+铅封号），是保险索赔与客诉抗辩的双重证据。
4. **保费入账**：保险费计入 CIF 成本报价，费率变动大时单独列示。
