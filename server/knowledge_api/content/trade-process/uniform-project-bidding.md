# 团定项目投标实务（Uniform Project Bidding: 酒店/游轮/金融机构制服竞标全流程）

高端团定项目（酒店/游轮/私行）的单项目金额 $10 万-200 万，但**投标本身就是一场专业竞赛**：方案设计、样衣制作、述标表现决定 70% 胜率。产品侧见 `garments/luxury-cruise-finance-uniforms.md`，市场模式见 `customers-market/uniform-corporate-apparel-programs.md`——本文件聚焦**投标全流程的胜负手**。

## 一、投标信息获取

- **信息源**：
  - 酒店集团采购平台（万豪/希尔顿/洲际的供应商门户）——**注册预审是入场券**；
  - 游轮公司采购部（Royal Caribbean/MSC/中船邮轮）——**新船建造周期=制服采购周期**；
  - 金融机构行政采购（总行集采目录）；
  - 专业标讯平台（招标网/千里马）——**设置"制服/职业装/服装"关键词订阅**；
- **提前布局**：**新酒店签约管理公司时=制服设计启动时**——开业前 12-18 个月介入设计端，早于招标 6 个月。

## 二、标书分析与策略

- **资格预审**：注册资本/同类业绩/验厂报告/检测资质——**业绩不足时联合投标（与设计公司/面料商组成联合体）**；
- **评分结构拆解**：
  - 设计方案（25-35%）：**酒店制服的胜负手**——与酒店 VI/空间设计/岗位动线的融合度；
  - 样衣品质（20-30%）：面料/工艺/版型；
  - 价格（20-30%）；
  - 服务方案（10-15%）：量体/配送/补单/售后；
- **策略选择**：
  - 设计驱动型酒店（精品/奢华品牌）→ 重设计投入（请独立设计师合作）；
  - 成本驱动型（经济型连锁）→ 标准化方案+价格竞争；
  - **弃标判断**：垫资 >合同额 30%、账期 >6 个月、业绩门槛明显为内定者量身定做——**三类标果断弃**。

## 三、方案设计与样衣（决胜环节）

- **设计提案**：
  - 岗位矩阵：前厅/客房/餐饮/工程/安保——**每岗位的"形象+功能"双重定义**；
  - 色系方案：延续酒店 VI 色系——**潘通色号对接设计院的 VI 手册**；
  - 功能细节：客房部口袋容量/餐饮部防污处理/门童的仪式感——**场景化细节是述标亮点**；
- **投标样衣**：
  - 工艺等级：投标样衣按**最高工艺标准制作**（全麻衬/手工细节）——中标后按预算分级；
  - 面料实样：禁用替代料做样衣——**评委触摸面料的瞬间定生死**；
  - 系列呈现：男装+女装+配饰的完整 look——**单件样衣 vs 系列提案的视觉差距是碾压级的**。

## 四、述标与商务谈判

- **述标结构**（15-20 分钟）：
  1. 对酒店品牌的理解（3 分钟——展示功课）；
  2. 设计理念与方案（8 分钟——样衣真人展示优于 PPT）；
  3. 品质保障体系（3 分钟——验厂/检测/验货流程）；
  4. 服务承诺（2 分钟——量体/补单/售后响应时效）；
- **评委构成**：行政总采+房务总监+餐饮总监+总经理——**部门总监关注实用性，总经理关注形象，采购关注价格，分众准备答案**；
- **澄清与二次报价**：**澄清环节是暗线翻盘机会**——对手的技术瑕疵可在澄清中被评委关注。

## 五、中标后管理

- **合同要点**：
  - 分期付款：签约 30%+量体完成 30%+交付 30%+质保金 10%（12 个月）——**质保金条款争取缩短至 6 个月**；
  - 补单价格锁定：3-5 年补单按中标价 ±5%——**面料涨价联动条款必须写入**；
  - 尺码调换率：约定 5% 内免费调换——**超出的责任划分（量体数据准确性归责）**；
- **履约关键**：量体组织（多城市门店巡量）/分批交付（按开业倒计时倒排）——**开业日是不可协商的死线**；
- **续约铺垫**：**首单履约数据（准时率/调换率/投诉率）是续约与集团内推荐的资产**。

## 六、风控红线

- **围标串标**：刑事风险——**同集团多品牌投标也要避免共用 IP/账户**；
- **履约保证金**：合同额 5-10% 的保函占用——**计入资金成本再报价**；
- **业主资金链**：中小酒管公司的付款风险——**开业前的制服款拖欠是行业痼疾，预付比例是底线**。
