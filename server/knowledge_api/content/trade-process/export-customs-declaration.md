# 出口报关实务（Export Customs Declaration）

报关是货物出境的法定程序。外贸公司自营出口需懂报关逻辑（即使委托货代/报关行），否则查验/归类/退税任一环节卡壳都会造成连锁损失。

## 一、基本流程

```
订舱 → 装货（SO 提箱）→ 申报（报关单）→ 海关审核 → 查验（如布控）
→ 放行 → 装船 → 结关 → 退税联/结汇联
```

- **申报时点**：货物运抵监管区后、装船前（"运抵报告"触发申报）；
- **无纸化**：全国通关一体化 + 单一窗口申报，电子放行（放行信息直达码头）。

## 二、报关单填制要点

| 栏目 | 要点 |
|:---|:---|
| 境内发货人 | 与退税主体一致（出口退税的"四流一致"核查） |
| 生产销售单位 | 自产/委托加工的工厂（退税核查上游） |
| 贸易方式 | 一般贸易（0110）/ 进料加工（0615）/ 跨境电商（9610/9710/9810）——**方式决定退税与监管** |
| 征免性质 | 一般征税 / 进料加工 |
| 成交方式 | FOB/CIF 等——退税按 FOB 价计算，CIF 需拆运费保费 |
| 商品编码 | HS 10 位码（归类见 `trade-compliance/hs-classification-practice.md`） |
| 申报要素 | 品名/成分/工艺/品牌等按税则要求逐项填报（服装：织造方法/种类/成分含量/品牌） |
| 单价总价 | 与发票一致——**低价报关 = 骗税嫌疑 + 客户清关低价风险**（见红线） |

## 三、查验应对

- **布控来源**：风险分析（企业信用/商品风险/随机）；
- **查验类型**：机检（H986 扫描）/ 人工查验（开箱核对品名数量规格）；
- **应对**：随货文件一致（品名/数量/唛头与单证 100% 对应）；敏感商品（品牌货）带授权文件（见 `trade-compliance/ip-brand-authorization.md` 海关备案核查）；
- **查验异常**：归类争议/价格质疑——提供合同发票付款记录申辩，必要时申请归类预裁定。

## 四、跨境电商报关方式速查

| 代码 | 模式 | 适用 |
|:---|:---|:---|
| 9610 | B2C 直邮出口 | 小包直发（清单核放汇总申报） |
| 9710 | B2B 直接出口 | 阿里国际站类 B2B 线上成交 |
| 9810 | B2B 海外仓 | 前置仓模式（离境即退税，见 `trade-process/cross-border-ecommerce-logistics.md`） |
| 0110 | 一般贸易 | 传统外贸 |
| 1210 | 保税电商 | 进口为主（出口场景少） |

## 五、退税联与数据一致性

- 报关单**退税联**是出口退税的凭证之一（2026 新规下退税申报与报关数据自动比对）；
- **四流一致**：合同流（外商订单）、货物流（报关单）、发票流（工厂增值税票）、资金流（收汇）——品名/金额/主体交叉印证，不一致是退税函调与稽查高发点；
- 报关金额与收汇金额差异（佣金/折扣）需留存协议备查。

## 六、常见违规红线

1. **低价/高价报关**：低价报关压税（进口国关税损失+进口商低报风险）；高报骗退税——两者均涉走私嫌疑；
2. **品名不符**：服装报"纺织品"模糊申报——查验改单影响退税；
3. **贸易方式错用**：9610 订单按 0110 报（退税路径错误）；
4. **买单出口**：无进出口权企业购买他人单证出口——2026 退税新规下"买单"企业的退税彻底封堵（见 `trade-process/export-tax-rebate.md` 五条红线）。
