# 国际贸易争议解决与仲裁（Trade Dispute Resolution & Arbitration）

跨境诉讼执行难：仲裁裁决凭《纽约公约》可在 170+ 国执行——合同争议条款是"签字前最便宜的风控"。

## 一、争议解决方式对比

| 方式 | 优势 | 局限 |
|:---|:---|:---|
| 友好协商 | 零成本保关系 | 无强制力（恶意买家无效） |
| 调解（商事调解中心） | 灵活保密 | 调解协议执行依赖自愿 |
| 仲裁 | 纽约公约全球可执行/一裁终局/保密 | 费用较高（数万起） |
| 外国法院诉讼 | — | 判决跨境执行极难（美国判决在华执行几乎不可能） |

**结论：外贸合同首选仲裁条款——避免"赢了官司拿不到钱"。**

## 二、仲裁机构选择

- **CIETAC（贸仲委）**：中国卖家主场（北京/上海/深圳——中英文程序）;
- **HKIAC（香港国际仲裁中心）**：双方接受度最高（中立地+英美法系——推荐折中方案）;
- **SIAC（新加坡）**：东南亚业务首选;
- **ICC（巴黎）**：欧美大客户偏好（费用最高）;
- **买家所在国仲裁**：尽量避免（客场+成本高）。

## 三、仲裁条款要点（合同必备）

- **四要素**：仲裁机构+仲裁地+适用规则+语言（缺一不可——缺漏条款可能无效）;
- **推荐表述**："凡因本合同引起的争议，提交 HKIAC 按其仲裁规则在香港仲裁，仲裁语言为英文，裁决是终局的";
- **适用法律（governing law）**：与仲裁条款配套（推荐香港法/英国法/CISG——明确排除或适用 CISG 国际货物销售合同公约）;
- **缺席仲裁**：买家不应诉不影响程序（缺席裁决同样可执行——解决恶意拖延）。

## 四、执行路径

- **纽约公约**：170+ 缔约国（美欧日韩全在——裁决可申请当地法院承认执行）;
- **执行对象**：买家资产所在地法院申请（银行账户/存货/应收账款）;
- **资产调查**：裁决前先查资产（空壳公司赢了也白搭——中信保资信报告见 `trade-process/export-credit-insurance.md`）;
- **保全措施**：仲裁中可申请财产保全（冻结账户——香港/新加坡程序成熟）。

## 五、证据准备（日常留痕决定胜负）

- **合同链**：PO+PI+合同（签章版——传真件/邮件确认效力）;
- **履约链**：提单+报关单+验货报告（SGS 第三方报告效力高——见 `trade-process/pre-shipment-inspection-sop.md`）;
- **沟通链**：邮件/WhatsApp 记录（确认质量标准的往来——勿删）;
- **质量争议**：买家收货后检验期限（合同约定 30 天——逾期视为接受条款）。

## 六、常见争议类型与预防

| 争议 | 预防 |
|:---|:---|
| 质量不符 | 船样确认+第三方验货+AQL 标准入合同 |
| 交期延误 | 交期条款+违约金上限+不可抗力界定 |
| 短装/错货 | 装柜照片+监装记录 |
| 拒付/拖欠 | 付款节点设计+信保（见 `trade-process/export-payment-methods-practice.md`） |
| 设计侵权反诉 | IP 归属条款（见 `trade-compliance/ip-brand-authorization.md`） |

## 七、成本与周期预期

- **仲裁费**：标的 10 万美元案件约 1-3 万美元（HKIAC 标准——含仲裁员费用）;
- **律师费**：可风险代理（按回款比例——跨境律师所）;
- **周期**：6-18 个月（简易程序 6 个月内）;
- **小额争议**：5 万美元以下建议协商/调解优先（仲裁性价比低）或信用保险覆盖。
