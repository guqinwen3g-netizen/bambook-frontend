# 贸易融资工具（Trade Finance Instruments）

外贸垫资周期长（生产 30-60 天 + 海运 30-45 天 + 账期 30-90 天），贸易融资把"应收账款"变成"现金流"。用对工具可以在不稀释股权的前提下放大接单能力。

## 一、出货前融资

| 工具 | 说明 | 适用 |
|:---|:---|:---|
| **打包贷款（Packing Loan）** | 凭信用证向银行申请生产采购资金（通常 L/C 金额 60-80%） | L/C 订单 |
| 订单融资 | 凭 T/T 订单+历史交易记录融资 | 稳定老客户的 T/T 订单 |
| 红条款信用证 | L/C 内嵌预支条款（预支部分货款备料） | 需客户配合开立 |

## 二、出货后融资

| 工具 | 说明 | 适用 |
|:---|:---|:---|
| **出口押汇（Bill Purchase）** | 交单后银行垫付货款（L/C/D/P 项下），银行向开证行/客户收款 | L/C/D/P 订单 |
| **福费廷（Forfaiting）** | 银行**无追索权**买断中长期承兑汇票/延期 L/C 债权 | 远期 L/C（90-360 天） |
| **出口信保融资** | 凭中信保保单向银行申请融资（保单质押/赔款转让） | OA 账期订单 |
| 出口保理（Factoring） | 保理商受让应收账款+提供坏账担保+催收 | OA 订单（欧美买家） |
| 商业发票贴现 | 发票质押融资 | 临时周转 |

## 三、核心工具详解

### 出口押汇
- 利率：美元押汇约 SOFR+2-4%（或人民币 LPR 挂钩）；
- 期限：即期 L/C 押汇 15-30 天、远期按票据期限；
- 注意：L/C 项下有不符点时押汇银行有权追索——**单单一致是前提**（见 `trade-process/letter-of-credit-review.md`）。

### 福费廷（无追索权卖点）
- 银行买断远期债权，出口商**即刻收款且不承担买家违约风险**（无追索权）；
- 成本：贴现率高于押汇（风险溢价）——实质是"贴现 + 保险"二合一；
- 适用：大额设备/大单远期 L/C（纺织服装较少用，但大项目单可用）。

### 信保融资
- 结构：投保中信保短期险 → 保单赔款权益转让给银行 → 银行按应收账款 70-90% 放款；
- 价值：**OA 订单也能融资**——账期客户的应收账款提前变现；
- 组合价值：中信保额度批复本身即买家信用背书（见 `trade-process/foreign-exchange-settlement.md`）。

### 国际保理
- 双保理模式：中国出口保理商 + 进口国保理商（FCI 网络）；
- 保理商承担买家信用风险（核准额度内 100% 坏账担保）；
- 费用：保理费（发票额 0.5-2%）+ 融资利息；适合中小额高频 OA 订单。

## 四、供应链金融新形态

- **确权融资**：核心企业（大品牌/大进口商）确认应付账款后，其供应商凭确权凭证向银行融资——若客户是大型零售集团可争取纳入其供应链金融计划。
- **跨境电商平台贷**：亚马逊/Shein 供应商基于平台交易数据的信用贷。
- **出口退（免）税融资**：部分银行凭退税记录提供退税款质押融资（退税到账前周转）。

## 五、融资成本与风控

1. **算综合成本**：利率 + 手续费 + 汇率锁定成本；与订单毛利率比对（融资成本应 < 毛利 1/3）。
2. **匹配期限**：融资期限与回款期限匹配，避免短贷长用。
3. **单一押品依赖风险**：L/C 押汇依赖单证质量；OA 融资依赖买家信用——工具组合分散。
4. **汇率联动**：融资币种与收款币种一致（美元融资还美元），避免双重汇率敞口（见 `trade-process/foreign-exchange-settlement.md`）。
