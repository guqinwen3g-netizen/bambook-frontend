# ATA 单证册与暂时进出口（ATA Carnet: 展会样品/专业设备免税暂准进口）

ATA 单证册是"**货物护照**"：展会样品/商业样品/专业设备在 80+ 成员方之间**暂准进口免关税、免进口证、免当地担保**——外贸参展与高价值样品寄送的专用工具。展会执行细节见 `trade-process/overseas-exhibition-playbook.md`，本文聚焦单证册机制与操作纪律。

## 一、机制与适用

| 要素 | 内容 |
|:---|:---|
| 出证机构 | 中国贸促会 CCPIT（各地方分会） |
| 担保 | 押金或银行保函（按货值比例——退回核销后退还） |
| 有效期 | **1 年**（不可延期——超期补税+罚款） |
| 适用货物 | 展览品、商业样品、专业设备（摄影/测试/演出器材）、体育赛事器材 |
| 不适用 | **销售货物、消耗品、加工/维修用料**（销售需补办正式进口） |

- **核心价值**：免逐国临时进口担保（现金押金/当地保函）+通关快速（专用通道）+多国巡回（一册多国——欧洲巡演/多国展会）；
- **纪律红线**：单证册项下货物**必须复运出境**（"暂时"是法律定义——留购需向海关申请转正式进口补税）。

## 二、操作流程

1. **申请**：清单（品名/数量/价值/序列号——与实物严格一致）+贸促会审核出证；
2. **出境**：中国海关签注（出口联）——货物与清单核对；
3. **境外入境**：目的国海关签注（进口联）——**每进出一国一次签注**（联次管理）；
4. **复运出境**：目的国签注（复出口联）——期限（通常 6-12 个月内，各国自定）；
5. **复运进境**：中国海关签注（复进口联）；
6. **核销**：单证册退回贸促会——全套签注齐全后**退担保**。

## 三、高频场景与替代方案

| 场景 | 方案选择 |
|:---|:---|
| 海外展会样品（服装/面料样册） | ATA（高价值样册/成衣样）或**快递低值样品**（样布小件走 DHL 按 sample 申报——低值免税额度内更便捷） |
| 客户看样寄送（需退回） | ATA 或暂时进出口报关（保证金模式） |
| 专业设备出国（拍摄/检测） | ATA 标准场景 |
| 非 ATA 国家（部分中东/非洲/拉美） | **暂时进出口报关**（出口时报"暂时进出境货物"+保证金——复进口核销退保） |
| 销售为目的的寄样 | 正式出口（不可走 ATA——伪报是走私风险） |

## 四、风控要点

- **清单一致性**：件数/序列号与实物不符=海关质疑（开箱查验纪律）；
- **签注完整性**：缺任一联次签注=**核销失败→担保没收+追税**——参展后逐项核对（撤展混乱期高发）；
- **超期**：境外停留超期限（展会延期/行程变更）——提前向海关申请延期（境内出证方协调）；
- **灭失/损坏**：展会失窃——报警记录+海关备案（仍可能补税——保险覆盖见 `trade-process/cargo-insurance.md`）；
- **美国特殊**：美国接受 ATA 但**纺织品样品有额外申报**（CBP 对纺织样品审查——成分标签随货）。
