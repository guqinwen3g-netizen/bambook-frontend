# 外贸谈判与函电实务（Trade Negotiation & Correspondence）

纺织服装外贸谈判的胜负手不在话术，而在**报价结构透明、让步有据、响应速度**。函电（邮件/WhatsApp）是谈判主战场，书面记录即合同证据。

## 一、报价与议价

### 报价策略
- **首次报价留 5-8% 谈判空间**（中东/南亚客户还价幅度大，预留 10-15%）。
- **阶梯报价**：数量挂钩（1k/3k/5k 单价递减），引导客户放大订单。
- **分项透明**：大客户提供成本拆解（面料/工费/印绣分项），用专业度换信任——"这个价格已经是基于 3000 件的最优工费"。

### 还价应对
| 客户话术 | 应对 |
|:---|:---|
| "Your price is too high" | 问清对标（与谁比/什么规格），差异化说明（面料支数/工艺/认证） |
| 目标价低于成本 | 给替代方案（降克重/换面料/减工艺）而非直接降价 |
| "Other supplier offers lower" | 要求同等规格对比；强调质量/交期/合规确定性 |
| 最后通牒式压价 | 用交期/付款条件换价格（前 T/T 50% 可让 2%） |

### 让步纪律
- 每次让步**必须换到东西**（量、付款、交期、翻单承诺）——单边让步只会引来下一轮压价。
- 让步幅度递减（3% → 1.5% → 0.5%），传递"已近底线"信号。
- 底价（walk-away price）谈判前由成本核算+管理层定死（见 `garments/garment-costing-pricing.md`）。

## 二、关键条款谈判

### 付款方式（风险 vs 订单的平衡）
- 坚持顺序：前 T/T 30-50% → 即期 L/C → D/P → OA（账期）——新客户不碰 OA。
- 妥协话术："首单 L/C at sight，合作三单后我们内部评审账期额度。"
- 中信保额度查询是账期谈判的底气（先查买家信用再谈条件）。

### 交期
- 报价交期 = 生产周期 + 缓冲（5-7 天）；快时尚客户压交期时，用分批出货（partial shipment）方案满足上架节奏。
- 延期预警：预判延期立即主动告知+新 ETA+补救方案，瞒报是最差选择。

### 质量与索赔条款
- 验货标准（AQL 值）、索赔时限（到港后 30/45 天）、争议解决（仲裁地）写进 PI。
- 客户自设苛刻条款（如"任何瑕疵全额退款"）必须逐条谈判修改，模糊的严格即风险。

## 三、函电规范

### 邮件结构
```
主题：具体+可检索（如 "PO#12345 T-shirt order - bulk fabric color approval needed"）
开头：一句话点题（要客户做什么/要什么信息）
正文：编号列项（1. 2. 3.），一事一段
结尾：明确 action + 时限（"Please confirm by Friday so we can hold the dyeing slot"）
```

### 写作原则
- **短句**：英语非母语的双方沟通，一句一事；避免从句套从句。
- **数字书面化**：价格/数量/日期永远写进邮件正文（WhatsApp 口头确认后补邮件 recap）。
- **确认闭环**：重要事项用 "Please confirm" 收尾，未确认不执行。
- **语气**：直接但礼貌（"Unfortunately we cannot..." 优于绕弯）；催款/催确认用 "gentle reminder" 模板。

### WhatsApp/即时通讯
- 日常沟通主渠道（尤其中东/南美/东南亚客户）；**关键决定回到邮件书面确认**。
- 响应速度即竞争力：工作时区内 1 小时响应；非工作时区设置自动回复。

## 四、谈判场景案例

1. **新客户首单压价**：用"首单体验价（trial order price）+ 翻单阶梯"框架——首单微利，绑定翻单量后回归正常毛利。
2. **原材料涨价**：发正式涨价函附成本证据（棉纱指数/面料厂涨价单），给旧价锁单窗口期（2 周）。
3. **客户拖延确认**：说明供应链连锁反应（"面料缸位只能保留到 X 日"），用第三方约束代替催促。
4. **索赔谈判**：证据先行（验货报告/照片/封存样品），方案分级（补货/折扣/信用额度），见 `trade-process/claims-handling.md`。

## 五、跨文化要点

| 市场 | 谈判风格 |
|:---|:---|
| 美国 | 直接、数据驱动、合同导向 |
| 欧洲（德/北欧） | 严谨守时、重细节与认证，还价少但要求高 |
| 日本 | 决策慢（层层上报）、一旦合作极稳定；细节确认邮件要极精确 |
| 中东 | 大幅还价是礼节，关系优先，WhatsApp 高频 |
| 拉美 | 热情但付款拖延常见，坚持发货前付清 |
