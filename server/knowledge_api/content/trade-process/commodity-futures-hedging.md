# 纺织原料套期保值实务（Futures Hedging: 棉花/PTA 期货/基差/套保纪律）

纺织原料（棉/涤纶/锦纶）年波动 20-40% 是常态——**接长单不锁价=裸奔赌博**。套期保值的本质不是赚钱，是**把不可控的价格风险换成可控的小额基差风险**，锁定加工利润。基础行情框架见 `fabric/cotton-yarn-import-trade.md` 与 `fabric/fabric-inventory-stock-strategy.md`，本文件展开套保操作机制与纪律。

## 二、套保场景与方向

- **买入套保（防涨）**：接了 6 个月后交货的出口订单，当前棉价低——买入期货锁定原料成本；到时现货买棉+期货平仓（期货盈利对冲现货涨价）；
- **卖出套保（防跌）**：坯布厂备了大量原料库存/产成品库存——棉价下跌库存贬值，卖出期货对冲；
- **虚拟库存**：资金紧张的工厂用期货多头替代部分实物备库（保证金只占合约值 10% 左右）——**但交割月前必须移仓或平仓**（纺织厂一般不做实物交割）；
- **点价贸易（basis trading）**：与供应商按"期货价+基差"定价——先锁基差（质量/物流/加工费的相对固定部分），**点价时机留给自己选择**——大棉商/纱厂普遍接受此模式。

## 三、基差风险（套保不完美的真相）

- **基差 = 现货价 - 期货价**：套保锁定的是期货价，但交割的是现货——基差变动是残余风险（通常远小于价格波动）；
- **品种错配**：用棉花期货套保棉纱成本——纱-棉价差（加工利润）也在波动；用 PTA 套保涤纶面料——中间还有短纤加工与织造利润环节；**错配越远流水越粗**，需按成本结构计算"套保比率"（如面料成本的棉花含量占比）；
- **时间错配**：期货合约月份 vs 用棉时点——移仓换月有价差成本（contango/backwardation 结构）。

## 四、操作纪律（血泪经验）

1. **套保比例**：≤实际敞口的 80%（留出生产损耗与订单变化余量；超额=投机）；
2. **方向纪律**：套保方向永远与现货敞口相反——**禁止"看行情"加仓变投机**（套保部门赌行情破产的纺织厂案例每年都有）；
3. **保证金管理**：预留 2-3 倍初始保证金应对浮亏追缴（margin call——被强平在黎明前是最惨的死法）；
4. **审批与分权**：套保方案（品种/方向/数量/期限）书面审批；**下单与记账分人**（内控——见 `suppliers/garment-factory-cash-flow.md` 资金纪律）；
5. **记账口径**：期货盈亏与现货成本**合并核算**（评估套保效果看合并结果，期货端单独浮亏不是"亏损"——这是老板最容易误解的地方）；
6. **期权替代方案**：怕保证金风险的用**买入看跌/看涨期权**（权利金固定损失上限）——成本略高但睡得着。

## 五、决策框架（什么时候值得套）

- **不套的情况**：订单周期 <1 个月（现货随行就市）、敞口金额小（套保管理成本>风险敞口）、价格波动处于历史低位区（向下空间有限）；
- **建议套的情况**：长周期大单（3 个月+）+原料占成本比高+利润薄（经不起 10% 原料波动）；
- **替代工具**：与供应商签**锁价长协**（付定金锁价——见 `fabric/cotton-yarn-import-trade.md`"定金锁纱"）、订单报价加**价格联动条款**（把风险转移给客户——大买家未必接受）、缩短报价有效期（7-15 天）。
