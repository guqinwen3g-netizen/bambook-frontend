# 客诉与索赔处理（Claims & Complaint Handling）

客诉（customer complaint）与索赔（claim）是外贸业务的常态环节而非偶发事故。处理质量纠纷的能力直接影响利润与客户留存——处理得当可将危机转化为信任，处理失当则损失订单、客户乃至商誉。

## 一、客诉类型与成因

| 类型 | 典型情形 | 责任归属参考 |
|:---|:---|:---|
| **质量索赔** | 疵点超标、色差、缩水不合格、色牢度差、尺寸偏差 | 供方（面料/成衣厂）为主 |
| **数量索赔** | 短装（shortage）、溢短装超约定 | 供方/物流 |
| **交期索赔** | 延迟交货致空运费或取消订单 | 供方为主，需看不可抗力条款 |
| **包装/标识索赔** | 标签错误、包装破损、混码混色 | 供方 |
| **合规索赔** | 测试不合格（甲醛/铅/偶氮）、标签不合规被召回 | 供方，最严重 |
| **运输货损** | 湿损、破损、丢失 | 船公司/保险公司（CIF 下卖方协助索赔） |

## 二、处理流程（六步法）

### 第 1 步：接收与响应（24-48 小时）
- 第一时间回复确认收到（acknowledge），表达重视，避免客户情绪升级。
- **不在首轮回复中认责或推责**，只承诺调查时间表。
- 要求客户提供：照片/视频、不良数量与比例、批次号（PO/style/lot）、影响程度。

### 第 2 步：核实与取证
- 比对**合同质量标准**与**确认样（golden sample）**：客户主张是否超出约定公差。
- 核查我方出货前检验报告（PSI report）与留样（retained sample）。
- 必要时要求客户寄回不良品实物，或委托**双方认可的第三方机构**（SGS/BV/Intertek）在目的地检验。
- 关键判断：不良是否属实？比例多少？是否系统性问题（整批）还是个别？

### 第 3 步：内部定责与损失测算
- 定性：我方责任 / 客户责任（如储存不当、洗涤不当）/ 共同责任 / 第三方责任。
- 测算直接损失：货值、返工费、补货运费、客户降价损失、空运费。
- 同步启动**对上游的追偿**：面料问题向面料厂索赔，成衣问题向工厂索赔（参见供应商协议质量条款）。

### 第 4 步：提出解决方案
按严重程度递进的方案矩阵：

| 严重度 | 方案 | 成本参考 |
|:---|:---|:---|
| 轻微（不影响销售） | 下一订单折让（credit note）或小额赔偿 | 货值 2-5% |
| 中度（部分可售） | 不良品补货 / 按不良比例退款 | 按实际比例 |
| 重度（不可售） | 全批退换货 / 补发合格品 + 承担运费 | 货值 + 双向运费 |
| 紧急（影响上架季） | 空运补货，运费责任按定责分担 | 高额，优先谈判 |
| 系统性质量事故 | 委托当地整修（sorting/rework）+ 费用承担 | 整修费 + 管理费 |

### 第 5 步：协商与书面确认
- 方案达成一致后**必须书面确认**（邮件或 settlement agreement）：金额、方式、时限、双方责任终结条款（full and final settlement）。
- 折让执行方式：出具 credit note 冲抵后续货款，或直接 T/T 退款。
- 付款抵扣注意：客户**单方面扣款**（deduction）是外贸痛点，合同中应约定"索赔须经双方确认后方可抵扣"。

### 第 6 步：复盘与纠正预防（CAPA）
- 输出 8D 或纠正预防措施报告：根因（root cause）→ 纠正（correction）→ 预防（prevention）。
- 更新检验标准、产前会议（PPM）要点、供应商考核记录。
- 重大客诉纳入管理层评审，必要时调整供应商等级（见 `suppliers/supplier-classification-evaluation.md`）。

## 三、证据链管理

**完整的证据链是谈判地位的根基**：

1. **产前**：确认样（双方签字）、样卡、测试报告、合同质量标准条款。
2. **产中**：中期检验报告（DUPRO）、验货照片。
3. **出货**：PSI 报告、装箱照片/视频、铅封号、提单。
4. **售后**：客诉往来邮件、不良照片、第三方检验报告、留样对比记录。

> 教训：无 golden sample 对比，色差纠纷必输；无出货装箱影像，短装纠纷说不清。证据留存期建议 ≥ 2 年。

## 四、谈判与沟通要点

- **及时**：响应速度本身就是诚意，拖延使小索赔变大纠纷。
- **对事不对人**：用数据（不良率%、AQL 标准、测试值）替代情绪化表述。
- **算账给客户听**：退货重运成本往往高于折让，引导客户选择双赢方案（如当地折价销售 + 我方补贴差价）。
- **守住底线**：超出合同公差范围的索赔有理有据拒绝；对习惯性索赔客户（claim-oriented buyer）在后续订单中提高预付款比例或停止合作。
- **维护关系**：认责爽快 + 整改到位的供应商，客户粘性反而上升——日本客户尤其看重态度与改进。

## 五、预防体系（事前重于事后）

1. **合同条款**：明确质量标准、检验方法、验收期（claim period，如到货后 30 天内）、索赔上限、争议解决（仲裁条款，推荐 CIETAC 或 HKICA）。
2. **样品确认制**：大货生产以双方签字的确认样为准，杜绝"大概""差不多"。
3. **验货前置**：PSI 不合格不放行；大客户订单考虑 DUPRO 中期验货。
4. **出口信用保险**：中信保（Sinosure）覆盖买方拒收、拖欠风险，费率约 0.5-1%。
5. **产品责任险**：欧美订单建议投保，覆盖召回（recall）与人身伤害索赔。
6. **供应商管理**：客诉数据计入供应商记分卡，连续两批同类问题启动淘汰程序。

## 六、升级路径

协商破裂时的升级顺序：
1. 高层介入（executive escalation）
2. 第三方检验裁定（合同有约定时）
3. 行业协会/商会调解
4. **仲裁**（arbitration，推荐，裁决跨境可执行——《纽约公约》）
5. 诉讼（litigation，成本高周期长，最后手段）
