# 亚马逊服装类目运营实务（Amazon Apparel Operations）

服装是亚马逊"**退货率最高的类目**"（15-30%）：尺码、变体结构、视觉素材决定生死——与传统 B2B 外贸是完全不同的运营逻辑。

## 一、服装类目特殊性

| 维度 | 特征 |
|:---|:---|
| 退货率 | 15-30%（全类目最高——尺码不合适占 60%+） |
| 变体结构 | 每个颜色×尺码一个 SKU（50 SKU/款常态——库存深度管理难） |
| 季节性 | 换季清库存压力（过季滞销仓储费吞噬利润） |
| 视觉驱动 | 主图+模特图决定点击率（白底主图+场景副图） |

## 二、listing 基建

- **变体（variation）**：父体+子体（颜色/尺码双变体——合并 review 共享排名）;
- **尺码表（size chart）**：实测平铺尺寸表（inch/cm 双单位——退货率第一杀手）;
- **标题公式**：品牌+核心词+特性+场景（字符 200 内）;
- **A+ 页面**：品牌备案后图文详情（提升转化 3-5%）;
- **关键词**：核心词（dress/shirt）+长尾（summer casual dress for women）——后台 Search Terms 250 字节填满。

## 三、FBA 物流与库存

- **FBA 必选**：服装自发货无流量（Prime 标+Buy Box 门槛）;
- **头程**：海运整箱/拼箱到美国 ONT8/CLT2 等仓（见 `trade-process/sea-freight-practice.md`）;
- **仓储费**：旺季（10-12 月）仓储费 3 倍——季节款控制入仓节奏;
- **长期仓储费**：库存 365 天+ 高额惩罚（过季款清仓决策点）;
- **移除/弃置**：滞销款移除费 vs 清货站外 Deal（保本线测算）。

## 四、退货管理（利润黑洞）

- **退货成本**：退货处理费+不可售损耗（服装试穿后 20-30% 不可再售——吊牌拆除/污渍）;
- **降低退货**：
  - 尺码表精准（实测数据+模特试穿报告——"模特 175cm 穿 M"）;
  - 面料实拍（色差投诉——自然光拍摄）;
  - QA 版块预埋尺码问题（"偏大一码"提示）;
- **退货数据**：Voice of Customer 看退货原因分布（每月复盘——尺码问题改款）。

## 五、评价体系

- **VP review**：服装 review 提及尺码（"runs small"关键词监控）;
- **Vine 计划**：新品冷启动（官方测评——每款 30 个）;
- **差评处理**：尺码差评跟进（改进尺码表/详情页置顶说明）;
- **rating 门槛**：4.0 以下转化腰斩（服装类目均值 4.2-4.4）。

## 六、广告与排名

- **SP 广告**：自动+手动（核心词精准+长尾词组）;
- **ACOS 基准**：服装类目 25-35%（新品期 50%+ 正常）;
- **排名机制**：BSR 由销量驱动（秒杀/7 天促销冲排名）;
- **Coupon**：服装转化率对折扣敏感（10-20% coupon 标配）。

## 七、合规红线

- **纺织标签**：FTC 纤维成分+原产国+洗护（见 `trade-compliance/textile-labeling-regulations.md`）;
- **儿童服装**：CPC 证书（抽查下架——见 `trade-compliance/cpsc-children-safety.md`）;
- **知识产权**：图案版权/品牌词侵权（跟卖投诉——服装印花图案侵权高发，见 `trade-compliance/ip-brand-authorization.md`）;
- **类目审核**：服装部分子类目需审批（内衣/儿童）。

## 八、与传统外贸的协同

- **柔性供应链**：小单测款（200-500 件）→ 数据好追单（快反工厂是核心竞争力——见 `customers-market/fast-fashion-shein-model.md`）;
- **工厂转型**：B2B 代工→B2C 品牌（运营团队+资金占用模式完全不同——库存风险自担）;
- **多平台**：亚马逊跑通后复制沃尔玛/独立站（分散平台风险）。
