# 谷歌广告 B2B 获客（Google Ads for B2B Lead Generation）

谷歌搜索广告是外贸 B2B **主动获客**的付费通道：客户搜 "custom hoodie manufacturer" 时你出现——与 SEO（见 `customers-market/independent-site-seo.md`）互补（SEO 慢、Ads 快）。核心挑战：**B2B 关键词贵且杂，烧钱换垃圾询盘是新手常态**。

## 一、账户与广告系列结构

```
账户 → 广告系列（按产品线/市场分）→ 广告组（按关键词意图分）→ 关键词+广告+落地页
```

- **系列划分**：按产品品类（hoodie/jacket/activewear——见 `garments/` 各品类词根）+ 品牌词防御系列；
- **广告组窄化**：单组 5-15 个紧密相关词（质量得分=点击率×相关性×落地页体验）。

## 二、关键词策略（B2B 核心）

| 词类型 | 示例 | 意图 | 出价 |
|:---|:---|:---|:---|
| 制造商词 | clothing manufacturer china | 找工厂（B2B 真金） | 高 |
| 定制词 | custom t-shirt bulk / private label activewear | 定制采购 | 高 |
| 批发词 | wholesale blank hoodies | 小 B/分销（见 `trade-process/b2b-wholesale-platforms.md`） | 中 |
| 品类+规格词 | 300gsm french terry supplier | 专业买家 | 中 |
| **否定词**（关键！） | free/jobs/retail/near me/how to/单件 | 排除 C 端与求职者 | — |

- **否定词表是第一周必做**（不做=50% 预算被 C 端点击烧掉）；
- **匹配类型**：词组/完全匹配起步（广泛匹配+智能出价是烧钱模式）；
- **地区**：分国家出价（美/欧出价高；印度/巴基斯坦点击多但转化差——限预算或排除）。

## 三、广告与落地页

- **RSA 自适应广告**：15 个标题+4 条描述（突出 MOQ/认证/交期/验厂——B2B 决策要素：如 "BSCI Audited Factory""MOQ 100pcs""15-Day Sampling"）；
- **落地页**：与词组一一对应（搜 hoodie 到 hoodie 页——不要都导首页）；落地页要素：工厂实拍/认证标志/产能数据/询盘表单（3 字段以内——名字/邮箱/需求）+ WhatsApp 浮窗；
- **转化追踪**：表单提交+邮箱点击+WhatsApp 点击全埋点（不追踪=盲人开车）。

## 四、预算与出价

| 阶段 | 日预算 | 目标 |
|:---|:---|:---|
| 测试期（1-2 月） | $30-50 | 跑出有效词（CTR >3%，询盘成本基准建立） |
| 优化期 | $50-100 | 关停高成本低转化词；质量得分 ≥6 |
| 放量期 | $100-300 | 有效词拓匹配/拓地区 |

- **询盘成本基准**：服装 B2B $30-80/询盘（品类热度差异）；**询盘质量分层**（垃圾询盘 60-70% 正常——业务过滤后有效询盘成本 $100-300）；
- **智能出价**：数据积累后（月 30+ 转化）切 tCPA（目标转化成本）。

## 五、常见坑

| 坑 | 后果 | 对策 |
|:---|:---|:---|
| 不做否定词 | 预算被 C 端烧光 | 首周建否定词表+每周搜索词报告 |
| 落地页导首页 | 转化率腰斩 | 品类落地页一一对应 |
| 只看点击不看询盘 | 虚假繁荣 | 转化追踪先行 |
| 垃圾询盘当失败 | 误判关停 | 按有效询盘成本评估（行业常态） |
| 投中文界面词 | 引来同行/供应商 | 排除中国 IP（除非找代理） |
| 全年一个价 | 展会季浪费 | 广交会/旺季前加价抢量（见 `trade-process/annual-sourcing-calendar.md`） |

## 六、与渠道组合

- **SEO+Ads 协同**：Ads 数据反哺 SEO（高转化词做内容——见 `customers-market/independent-site-seo.md`）；
- **再营销（RLSA）**：访问过未询盘访客搜索再触达（B2B 决策周期长——30 天窗口）；
- **配合海关数据**：广告落地页 A/B 测试+海关数据精准开发（见 `customers-market/customs-data-customer-development.md`）双通道。
