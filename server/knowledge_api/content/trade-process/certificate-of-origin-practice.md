# 原产地证书办理实务（Certificate of Origin Practice）

原产地证书（C/O）是货物的"国籍证明"：优惠产地证直接决定客户能否享受 FTA 关税减免（差一个证书，客户可能多付 10-30% 关税）。

## 一、证书类型

| 类型 | 用途 | 签发机构 |
|:---|:---|:---|
| 一般原产地证（CO） | 证明中国原产（无关税优惠，清关/结汇用） | 贸促会 CCPIT / 海关 |
| 普惠制 Form A | 发达国家 GSP 优惠（注意：**多数国家已对华毕业**——欧盟/日本/加拿大均已取消对华 GSP；现仅极少数国家适用） | 海关 |
| 中国-东盟 Form E | 东盟十国零关税 | 海关 |
| RCEP 原产地证 | RCEP 成员国（见 `trade-compliance/rcep-fta-utilization.md`） | 海关/贸促会 |
| 中澳/中韩/中秘/中智等 FTA 证书 | 各自 FTA 优惠 | 海关 |
| 加工装配证书/转口证明书 | 特殊贸易方式 | 贸促会 |

## 二、申领实操流程

### 企业备案（一次性）
1. 海关"互联网+海关"或单一窗口完成**原产地企业备案**；
2. 备案产品清单（HS 编码+原材料构成）；生产型企业需做产品预审（核实原产资格）。

### 逐票申领
1. 登录**中国国际贸易单一窗口**或贸促会原产地证系统（ECO 电子原产地证）；
2. 填制证书：出口商/收货人信息、运输细节、唛头、货描（与发票箱单一致）、HS 编码、原产地标准（WP/PE/CTC 等）；
3. 海关/贸促会审核（通常当日或次日）；
4. 签发：**自助打印**（A4 纸+企业印章，海关已全面推行）或现场领证。

### 关键时限
- **出运前或出运时**申请为正常件；出运后申请为**后发证书**（issued retrospectively）——Form E 允许出运后 3 日内（东盟部分国家更宽），RCEP 允许 1 年内补发。
- 证书有效期：通常自签发 1 年内有效（进口国海关要求运输与证书日期逻辑一致）。

## 三、填制要点与退证风险

| 常见错误 | 后果 |
|:---|:---|
| 货描与提单/发票不一致 | 进口国海关退证查询，优惠作废 |
| HS 编码用中国税号而非进口国税号 | 归类不符退证（证书用**进口方 HS**） |
| 唛头漏填/错填 | 与货物不符被拒 |
| 原产地标准填错（WP vs PSR） | 资格判定错误，退证查询 |
| 第三方发票信息缺失 | 三角贸易需勾选 third-party invoicing 并填发票方 |

- **退证查询（verification）**应对：进口国海关发查询函后，及时通过签发机构回复原产地真实性证明（生产记录/采购发票）——超期未复视为无效。

## 四、各类 FTA 证书的选择策略

- 同一目的国可能有多重优惠路径：如泰国可用 Form E 或 RCEP 证书——**比较两边税率与原产地规则宽严**后选择（RCEP 可累积区域价值，Form E 规则不同）。
- 澳大利亚/新西兰/韩国：中澳 FTA（ChAFTA）、RCEP 双通道并存，逐税号比较。
- 经香港/新加坡转口：必须申请**未再加工证明**（中转确认书），否则优惠失效。

## 五、与订单流程的协同

1. **报价阶段**：确认客户是否需要优惠产地证（影响原产地判定准备）；
2. **生产阶段**：保留原材料采购与生产记录（原产地追溯备查，海关可事后 3 年核查）；
3. **出运阶段**：证书信息在制单时与 B/L、发票交叉核对；
4. **寄单**：正本证书随单证包快递客户（或电放后补寄）——RCEP 部分成员国接受电子证书/自助打印件直接清关。

## 六、合规红线

- **虚假申领原产地证 = 骗取关税优惠**，海关可处货值 30%-2 倍罚款，信用降级；进口国海关追溯补税由客户承担后将向我方索赔。
- 含有进口成分的产品申请前必须核实 **PSR（产品特定原产地规则）** 达标（增值率/税则改变），不确定时先申请**预裁定**或咨询签证机构。
