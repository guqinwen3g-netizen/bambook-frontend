# 采购代理与买手办公室协作（Sourcing Agent & Buying Office）

采购代理（Sourcing Agent/Buying Office）代表海外买家在中国执行采购：寻厂、议价、跟单、验货、出运。与贸易公司（见 `trade-process/trading-company-operations.md`）的本质差异：**agent 不持货权、不吃差价，赚买家佣金（通常 3-8%）**。工厂大量欧美中小品牌订单经 agent 触达，必须掌握其协作规则。

## 一、Agent 类型谱系

| 类型 | 代表 | 特征 | 合作要点 |
|:---|:---|:---|:---|
| 大型采购行 | 利丰、Target/Walmart 自有买办 | 体系化、订单大、压价狠、合规要求全 | 过验厂是前提（见 `suppliers/factory-audit-guide.md`） |
| 中型代理公司 | 香港/深圳/上海 50-200 人 | 服务多个中小品牌，跟单验货全包 | 主流合作对象 |
| 个人 SOHO agent | 前外贸人单干 | 灵活、佣金低（1-3%）、风控弱 | 核实其终端买家真实性 |
| 品牌驻厂 QC/跟单 | 品牌直雇华人 | 只验货不采购 | 配合但保持商务直连品牌 |

## 二、Agent 价值链服务

- **开发期**：寻厂（sourcing）→初筛→安排打样→陪同验厂；
- **执行期**：代下 PO→驻厂跟单→中期/尾期验货（DUPRO/FRI）→单证审核→订舱协调；
- **增值项**：产品整合（多厂拼柜）、设计打样支持、质量仲裁、付款托管（部分 agent 代付货款）；
- **费用模式**：买家付佣金为主流；少数 agent 向工厂收"上架费/年费"——**警惕纯向工厂收费却无实单的伪 agent**（见 `trade-process/trade-fraud-prevention.md`）。

## 三、工厂协作规则

- **报价透明**：给 agent 的报价=给终端买家的报价（agent 佣金由买家端加）——报两份价被拆穿即失去整个 agent 网络信任；
- **信息对等**：交期/品质问题第一时间同步 agent（他们是第一道防线），隐瞒=被拉黑名单并在买家圈传播；
- **验货配合**：agent 验货标准通常比 AQL 抽检严（他们的佣金与质量挂钩）——中期验货（DUPRO）发现的问题整改成本最低，主动邀请中期验；
- **佣金处理**：若约定"买家价含佣"，合同与发票如实体现（退税按 FOB 实价，见 `trade-process/export-tax-rebate.md`）——不做阴阳合同；
- **直连边界**：通过 agent 认识的终端买家，**12-24 个月保护期内不绕开 agent 直接交易**——行业信用污点终身跟随。

## 四、防跳单与防飞单

- **防 agent 跳单**（agent 带你的样品找别厂生产）：
  - 核心工艺/花型申请版权或外观专利（见 `trade-compliance/ip-brand-authorization.md`）；
  - 首单后签三方协议或让买家直接确认工厂为指定供应商；
  - 关键物料（定制面料/模具）掌握在自己渠道；
- **防自己人飞单**：业务经理私下接 agent 单转小厂——ERP 订单留痕+报价权限管理（见 `suppliers/garment-erp-digitalization.md`）；
- **agent 选厂逻辑**：品质稳定>价格最低——持续三单无索赔的工厂议价权自然提升。

## 五、与 Agent 谈判要点

| 议题 | 工厂立场 |
|:---|:---|
| 验货标准 | 要求书面化（AQL 等级+缺陷清单），拒绝口头"客户不满意" |
| 付款链路 | 明确买家→agent→工厂资金流与时点，拒绝无限期"买家还没付" |
| 佣金披露 | 要求 agent 明示佣金率（大 agent 可接受），评估终端价格竞争力 |
| 独家区域 | 给 agent 的区域/客户独家必须有年度订单量对赌 |
| 索赔上限 | 约定按货值比例上限+返工优先（见 `trade-process/claims-handling.md`） |
