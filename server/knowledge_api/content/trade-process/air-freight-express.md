# 空运与国际快递（Air Freight & Express）

海运是纺织服装大货主力，但**样品、补货、快反、急单**离不开空运与快递。空运成本约为海运 10-15 倍，用对场景才能控住物流成本。

## 一、国际快递（Express Courier）

### 四大快递
| 快递 | 优势线路 | 特点 |
|:---|:---|:---|
| DHL | 欧洲/中东/全球 | 时效最稳，清关能力强，价格最高 |
| FedEx | 美国 | 美线优势，IP（优先）/IE（经济）分级 |
| UPS | 美国 | 美线重货优势 |
| TNT/Aramex/顺丰国际 | 区域线路 | 中东 Aramex、东南亚顺丰性价比高 |

### 计费规则
- **计费重量 = MAX(实重, 体积重)**；体积重 = 长×宽×高(cm) ÷ 5000（快递）或 ÷ 6000（空运）。
- 服装泡货（轻泡货）通常按体积重计费——**压缩包装直接省钱**。
- 燃油附加费（fuel surcharge）按月浮动（15-25%），偏远附加费（remote area）另计。

### 代理折扣
- 官方原价高，**货代折扣账号**可拿到 3-5 折；样品寄送量大可自开协议账号。
- 快件报关：价值 < 5000 元人民币可走快件简易报关（无退税）；要退税须正式报关。

## 二、空运（Air Freight）

- **适用**：100kg+ 急单、补货、高价值小批量（真丝/羊绒）。
- **运价结构**：空运费（按计费重量，分 45/100/300/500/1000kg 阶梯）+ 燃油 + 安检 + 地面杂费。
- **时效**：中国→美西 3-5 天、美东/欧洲 4-7 天（含两端地面）。
- **包板/包机**：大促季（圣诞补货）舱位紧张，提前 2 周锁舱。
- 机场选择：PVG（上海）/CAN（广州）/SZX（深圳）主力；内陆城市中转增加 1-2 天。

## 三、典型场景决策

| 场景 | 推荐方案 | 理由 |
|:---|:---|:---|
| 寄样（1-5kg） | 快递（客户到付账号或免费寄样） | 3-5 天门到门 |
| 确认样+船样 | 快递 | 时效优先 |
| 急单补货（<300kg） | 快递 IE/空运 | 按性价比比选 |
| 大货空运（>300kg） | 空运 | 阶梯价 + 清关代理 |
| 电商补仓 | 空运 + 海外仓 | 见 `trade-process/cross-border-ecommerce-logistics.md` |

## 四、样品寄送管理

1. **到付 vs 预付**：新客户索要样品用客户 DHL/FedEx 到付账号（防"骗样"）；意向明确客户可免费寄样换信任。
2. **样品发票**：形式发票注明 "Sample, no commercial value, value for customs only"——申报 $5-20 合理低值，避免目的国关税争议（但**不可零值申报**，海关会核定补税）。
3. **追踪与跟进**：寄出后给客户 tracking number + 预计到达日，签收后 24 小时内跟进反馈。
4. **留存**：寄样清单（款式/数量/日期/单号）归档，翻单时核对"样品→大货"一致性。

## 五、成本与时效优化

1. **轻重搭配**：泡货服装与重货（辅料/五金）混装平衡体积重。
2. **集货拼单**：多家工厂样品集中一票寄出，摊薄首重成本。
3. **时效承诺留缓冲**：给客户时效 = 快递时效 + 1-2 天清关缓冲；旺季（黑五前/圣诞前）+ 3-5 天。
4. **保险**：高价值样品（羊绒衫/真丝礼服）投保运输险，保费约 0.3%。
5. **危险品排查**：含电池（发热服/LED 装饰服装）须按危险品申报（UN3481），否则退运罚款。
