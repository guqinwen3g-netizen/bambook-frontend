# 客户信用调查与背景核实（Customer Credit Investigation）

外贸坏账的 80% 可以在接单前通过信用调查避免。**新客户不问信用就赊销 = 赌博**。本文给出分层调查工具箱。

## 一、免费自查（5 分钟初筛）

| 渠道 | 查什么 |
|:---|:---|
| 公司官网域名邮箱 | @company.com vs @gmail.com（免费邮箱风险+1） |
| Google Maps 街景 | 注册地址是写字楼还是居民区/空壳 |
| 公司注册查询 | 美国（各州 Secretary of State）/英国（Companies House）/欧盟（当地商业登记）——查注册年限/状态 |
| LinkedIn | 公司规模/员工数/联系人职位真实性 |
| 网站域名年龄 | whois 查询——注册 3 个月的"大公司"可疑 |
| 展会名录交叉 | 是否在行业展会参展/观展名录 |

## 二、付费资信报告

| 工具 | 说明 | 费用 |
|:---|:---|:---|
| **中信保资信报告** | 中国出口信用保险公司海外买家库（投保客户免费/优惠） | 数百-数千元 |
| **邓白氏（D&B）** | 全球最大商业数据库（D-U-N-S 编号）——付款指数 PAYDEX | $100-300/份 |
| **CreditSafe/Coface** | 欧洲买家资信强 | €100-300/份 |
| **本地商账公司** | 目的国催收/资信机构 | 按国别 |

- **看哪些指标**：付款记录（是否逾期惯犯）、财务健康（流动性/负债率）、涉诉记录、**信用额度建议**（直接给出授信上限）。

## 三、中信保的深度用法

1. **限额申请**：出运前向中信保申请买家信用限额——**批复额度就是官方风控意见**（批复 $0 = 红旗）；
2. **买家黑名单**：中信保理赔记录库（拒付/拖欠买家记录）；
3. **国别风险报告**：免费订阅（政局/汇率/行业风险）；
4. **组合策略**：限额内 OA/DA 敢做 + 限额外坚持 T/T 定金。

## 四、高风险信号（红旗清单）

| 信号 | 风险解读 |
|:---|:---|
| 免费邮箱+无网站 | 皮包公司画像 |
| 首单就要求 OA/DP 远期 | 骗子经典开场 |
| 注册 <1 年 + 大单 | 快骗快消失模式 |
| 收货国 ≠ 注册国 | 三方贸易套货（尤其收货地在西非/中东转运港） |
| 催促免定金赶交期 | 利用"大单诱惑"心理 |
| 要求货发指定货代（不知名） | 无单放货风险（货代与买家串通） |
| 公司名称与知名公司近似 | 蹭名公司（"Apple Trading Inc"≠ Apple） |

## 五、分级授信决策

| 客户等级 | 资信依据 | 付款条件上限 |
|:---|:---|:---|
| A（低风险） | 上市公司/知名企业/资信报告优 | OA 60 天（中信保覆盖内） |
| B（中低） | 注册 5 年+/付款记录良好 | OA 30 天或 D/P |
| C（中） | 信息有限但无红旗 | T/T 30% 定金 + 见提单副本付尾款 |
| D（高/未知） | 有红旗/查无信息 | T/T 50% 定金 + 发货前付清（甚至 100% 预付） |

## 六、老客户的动态监控

- **信用不是一次性的**：老客户也会破产（经济下行期零售商破产潮）——年度复查+大额订单前复查；
- **预警信号**：付款开始拖延（从 30 天拖到 60 天）、订单异常放大（清库存前兆）、频繁换对接人；
- **行业情报**：客户所在国零售/行业新闻监控（破产重组新闻早知道）。
