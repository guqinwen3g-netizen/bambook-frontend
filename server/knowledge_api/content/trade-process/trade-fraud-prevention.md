# 外贸欺诈防范指南（Trade Fraud Prevention）

外贸诈骗年产值数十亿美元：**邮箱劫持改账号是第一大高发手法**——一封"我们换银行账户了"的邮件可以让一笔货款永久消失。

## 一、六大高发骗局

| 骗局 | 手法 | 损失点 |
|:---|:---|:---|
| 邮箱劫持（BEC） | 黑客入侵买卖双方邮箱→篡改收款账户 | 货款打入骗子账户（最难追回） |
| 假水单 | PS 付款凭证催发货/催放提单 | 货放钱未到账 |
| 假客户大单 | 新客急单大额→要求赊销/或收货后消失 | 货财两空 |
| 信用证软条款 | 不符点拒付+银行费勒索（见 `trade-process/letter-of-credit-review.md`） | 货款拒付 |
| 假检验/假认证 | 要求向指定"机构"付费检测/注册 | 服务费被骗 |
| 尼日利亚预付费 | 遗产/合同预付款诱惑（419 诈骗） | 前期费用 |

## 二、邮箱劫持（BEC）深度拆解

- **入侵途径**：钓鱼邮件（假登录页盗密码）/弱密码爆破/公共 WiFi;
- **潜伏观察**：黑客阅读往来邮件数周（掌握订单/金额/语气——模仿签名和措辞）;
- **动手时机**：收款前夕（注册相似域名 xxx-co.com 替 xxx.com——或直接用被控邮箱发）;
- **改号话术**："我司审计要求换账户"/"原账户升级"（新账户多在第三国）;
- **防范铁律**：
  - **收款账户变更必须双通道确认**（邮件+电话/WhatsApp 视频——且打给通讯录旧号码，不用邮件里的新号码）;
  - 合同中写明"账户变更需签署正式变更函+视频确认";
  - 企业邮箱开二次验证（2FA）+定期改密码;
  - 域名相似度自查（定期搜自己公司名的相似域名注册）。

## 三、假水单识别

- **水单≠到账**：汇款回执可伪造（SWIFT MT103 也有假——可P图或套用真实报文格式）;
- **核实**：以银行实际入账为准（**未入账不放单、不放提单**——电放指令尤其）;
- **异常信号**：水单金额与货款不符（多付要求退款=洗钱手法）/付款人与买家不一致（第三方代付风险）;
- **到账时间**：TT 一般 1-3 个工作日（"已付一周未到账"+催放货=高危）。

## 四、新客户防骗尽调

- **免费核查**：官网域名年龄（whois——注册 3 个月的"百年老店"=假）/邮箱后缀（gmail 自称大公司采购=可疑）;
- **付费核查**：中信保资信报告（见 `trade-process/customer-credit-investigation.md`）;
- **行为信号**：不谈价格就下单/数量远超其市场容量/催交期催到不合理（骗子只关心"快发货"）;
- **小额试单**：新客户首单收定金+尾款发货前清（绝不赊销首单）。

## 五、收货端诈骗（货到目的港）

- **无单放货勾结**：货代与买家串通（指定货代风险——FOB 下买家指定货代可能无单放货，对策：要求货代出具保函/或用自己货代）;
- **弃货敲诈**：货到港后买家压价（"不提货就拍卖"——高滞港费胁迫降价，对策：合同弃货条款+转卖预案，见 `trade-process/claims-handling.md`）;
- **假国企/假 NGO**：冒充实体采购（核查注册信息+官方渠道回拨电话）。

## 六、遭遇诈骗后的应急

- **黄金 48 小时**：立即联系汇出行发**止付/召回（SWIFT recall）**（未解付可截回）;
- **收款行所在地报警**+本国公安经侦报案（跨境追回率与时间强相关）;
- **FBI IC3**：涉美账户报 ic3.gov（美国账户冻结快速通道）;
- **证据保全**：全部邮件头（含 IP）/聊天记录/水单（司法鉴定用）;
- **通知客户**：防止连环骗（骗子可能双向诈骗——告知真实客户账户未变）。

## 七、制度防线（公司级）

- **财务制度**：变更收款信息双人复核+电话回拨（写入财务 SOP）;
- **邮箱安全**：企业邮箱强制 2FA/离职立即销号/定期安全培训;
- **权限分离**：业务谈单不碰账户变更（财务独立确认）;
- **意识培训**：每季反诈案例通报（新员工第一课）。
