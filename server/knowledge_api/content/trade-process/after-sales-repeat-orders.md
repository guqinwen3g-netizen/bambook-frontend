# 售后服务与翻单管理（After-Sales & Repeat Orders）

外贸的利润在**翻单**：开发新客成本是维护老客 5-10 倍。售后不是成本中心，是翻单的入口。

## 一、售后响应体系

### 到货跟进（黄金 7 天）
- **到货确认**：货到 3 天内跟进（"Did the goods arrive in good condition?"）；
- **反馈收集**：销售反馈（款式/尺码/质量的 market feedback）——为翻单改进积累数据；
- **问题响应**：客户报问题 **24 小时内响应**（即使还在调查——响应速度=态度）。

### 质量客诉处理
- 见 `trade-process/claims-handling.md` 六步流程——核心是**快+诚+方案**。

## 二、翻单（repeat order）机制

### 翻单信号识别
| 信号 | 含义 |
|:---|:---|
| 客户报销售好 | 翻单临近（主动跟进） |
| 问库存/交期 | 在算翻单时间 |
| 要新款目录 | 在规划下季 |
| 询同类款价格 | 比价中（抢翻单的关键时刻） |

### 翻单效率优势（利润所在）
- **翻单 = 纯利提升**：开发/打样/磨合成本已摊销——翻单毛利高 20-30%；
- **交期更快**：工艺单/版型/供应链现成——翻单交期可压缩 30%；
- **质量风险低**：大货已验证——品质确定性高。

### 翻单跟单要点
- **面料锁定**：翻单面料（同缸/同批——缸差控制，见 `fabric/fabric-procurement-quality-agreement.md`）；
- **价格微调**：原料波动时的翻单调价（有理有据——成本变动凭证）；
- **版型稳定**：翻单不改版（除非客户要求——版型变更需重新确认样）。

## 三、客户关系维护

### 定期触点
- **节日问候**：圣诞/新年/客户国节日（greeting 不推销——人情账户）；
- **新品推送**：季度新品目录/面料开发成果（"we developed a new fabric that fits your line"）；
- **展会邀约**：展会前邀客户见面（见 `trade-process/overseas-exhibition-playbook.md`）；
- **市场情报**：主动分享（"棉花涨价趋势——建议提前备单"——增值顾问角色）。

### 客户分级维护
| 级别 | 维护 |
|:---|:---|
| A（战略客户） | 高层互访/年度框架/新品优先 |
| B（成长客户） | 季度跟进/展会见面 |
| C（机会客户） | 目录推送/节日问候 |

## 四、翻单率提升动作

1. **首单完美**：首单质量/交期零事故（翻单的前提——首单即口碑）；
2. **主动复盘**：交货后主动问反馈（"how did the styles sell?"——收集数据+表达关心）；
3. **改进闭环**：首单问题在翻单中解决（"we fixed the collar issue you mentioned"——客户感到被重视）；
4. **翻单便利**：一键翻单机制（确认交期+价格即可——降低翻单决策成本）；
5. **季度提案**：主动带新款/新面料提案（从"接单"到"供货顾问"）。

## 五、流失预警

| 流失信号 | 应对 |
|:---|:---|
| 翻单周期拉长 | 主动问（是否销售不佳/库存压力） |
| 比价频繁 | 审视竞争力（价格/品质/服务哪项掉队） |
| 沟通变少 | 上门拜访/高层介入 |
| 投诉后沉默 | 客诉处理不到位（补救动作） |
