# 客户拜访与验厂接待（Customer Visit & Factory Tour）

客户验厂是订单转化的临门一脚——**看厂 2 小时的印象分，决定百万订单归属**。接待不是礼仪问题，是信任构建工程。

## 一、接待前准备清单

### 资料
- 公司介绍 PPT（产能/客户/认证一页纸）；样品间上新（客户品类相关样品挂前排）；
- 审核资料包：营业执照/认证证书/验厂报告/检测能力清单；
- 访客卡/劳保（如需进车间）/拍照规则说明（部分区域禁拍）。

### 现场
- 车间 5S 整理（但**不做假**——为接待停产打扫反而露馅，正常生产状态最好）；
- 动线规划：展厅 → 裁剪 → 缝制 → 后整 → 实验室 → 会议室（亮点前置）；
- 关键岗位预演：QC 演示检测、车间主任能答产能问题。

### 人员
- 接待小组：业务对接人 + 厂长/生产负责人 + 翻译（如需要）；
- 提前了解客户：公司背景/采购品类/上次沟通记录——**记住客户上次提的细节，胜过豪华接待**。

## 二、参观讲解要点

| 站点 | 讲解重点 |
|:---|:---|
| 展厅 | 相关品类样品+"这个工艺我们给 [某市场] 客户做过"（去标识化） |
| 裁剪 | 自动裁床/拉布精度 |
| 缝制 | 单件流/在制品控制/设备品牌 |
| 实验室 | 现场演示摩擦牢度测试（眼见为实） |
| 检针 | 日本单客户必看检针机操作 |
| 成品仓 | 出货看板/周转效率 |

- **客户问尖锐问题**（如"最大月产能"）：如实回答+给验证方式（"这是近三个月出货记录"）——吹牛的工厂客户见得多。

## 三、会议环节

- 议程：双方介绍（15 分钟）→ 需求对接（30 分钟）→ 合作模式讨论（30 分钟）→ 行动项确认（15 分钟）；
- **报价策略**：看厂后报价可上浮 3-5%（信任溢价），当场不报底价；
- 样品需求当场记录：品类/数量/时限——24 小时内确认样单。

## 四、餐饮与礼仪

- 欧美客户：简餐/咖啡即可（重效率）；日韩客户：正式宴请（重关系）；
- 禁忌：不劝酒（欧美客户反感）；宗教饮食（清真/素食提前确认）；
- 接送安排：机场/酒店接送（客户旅程疲劳度影响看厂心情）。

## 五、拜访客户（反向场景）

- **展会拜访**：提前预约（展期客户时间以 15 分钟计）——带目录+样品卡+iPad 视频；
- **总部拜访**：带针对性开发方案（客户当季品类延伸建议）——展示"懂他的生意"比展示工厂更有效；
- 伴手礼：中国元素小礼品（茶叶/丝绸方巾）——避免贵重（合规红线，欧美客户礼品上限 $25-50）。

## 六、接待后跟进

- 24 小时内感谢邮件+会议纪要+行动项清单（样品/报价/资料的时间表）；
- 客户提出的整改项（如车间发现的问题）——整改完成后拍照反馈，**变失分点为信任加分**；
- 两周内无反馈主动跟进（看厂后犹豫期，竞品也在接触）。

## 七、常见失分点

| 失分点 | 后果 |
|:---|:---|
| 车间为接待停产打扫 | 客户看出"演戏"，信任崩塌 |
| 产能数据前后不一（业务员说 10 万件，厂长说 6 万） | 真实性存疑 |
| 实验室设备蒙尘（买了不用） | 品质体系形式化 |
| 关键岗位无人能答问题 | 管理空心化 |
| 临时抱佛脚的认证证书（证书地址与工厂不符） | 合规风险 |
