# 信用证审单与风险防范（L/C Document Review）

信用证（Letter of Credit, L/C）是银行信用担保的付款方式，理论上"单证相符即付款"，但实操中不符点（discrepancy）与软条款陷阱是收汇风险的主要来源。审单能力是外贸单证与业务员的必备技能。

## 一、信用证基础

- **定义**：开证行（issuing bank）应买方申请开立的有条件付款承诺——受益人（卖方）提交符合条款的单据，银行即付款。
- **国际惯例**：**UCP600**（跟单信用证统一惯例，2007 版）+ ISBP 821（国际标准银行实务）。
- **基本原则**：
  - **独立抽象性**：信用证独立于买卖合同，银行只审单据不看货。
  - **单证严格相符**：单证一致（docs vs L/C）、单单一致（docs vs docs），拼写、标点、数字差异都可能成不符点。
- **类型**：即期（at sight）/ 远期（usance 30/60/90 天）；可撤销/不可撤销（irrevocable，UCP600 下全部为不可撤销）；保兑（confirmed）/ 不保兑。

## 二、收证后审核要点（审证）

收到信用证草本或正本后 **48 小时内**完成审核，发现问题立即要求改证（amendment）：

1. **当事人信息**：受益人名称地址与公章/报关信息完全一致（一个字母都不能错）。
2. **金额与币种**：与合同一致，溢短装条款（tolerance，如 ±5%）是否匹配。
3. **效期与交单期**：expiry date（效期）、latest shipment date（最迟装运日）、presentation period（交单期，默认装运后 21 天内且不超效期）。
4. **装运条款**：起运港/目的港、分批（partial shipment）、转运（transshipment）是否允许——与订舱可行性核对。
5. **单据要求**：逐项核对能否提供（产地证 FORM A/CO、检验证书、船公司证明等）。
6. **软条款排查**：见下节。
7. **费用条款**：银行费用承担（开证费通常买方，议付/通知费卖方）；不符点费（USD 50-100/次）。

## 三、软条款识别（Soft Clause / Trap Clause）

软条款指付款主动权实际掌握在买方手中的条款，收到必须要求删除或修改：

| 软条款 | 风险 | 处理 |
|:---|:---|:---|
| 要求提交**买方签署的收货证明/验货报告** | 买方不签则无法交单 | 改为第三方检验机构（SGS/BV）证书 |
| 开证行收到**买方确认**后才付款 | 银行信用变商业信用 | 删除，恢复银行第一性付款责任 |
| 检验证书由**买方指定人签发**且签字须与开证行留存一致 | 签字无法核实 | 改为独立第三方 |
| 1/3 正本提单**直寄买方** | 货权失控（可凭正本提货） | 全套正本经银行 |
| 装船后须将**船名、航次通知开证行确认**后生效 | L/C 迟迟不生效 | 拒绝或改证 |

> 原则：**凡是"付款/生效依赖买方行为"的条款，一律要求改证**。改证费用由提出方承担（通常买方），宁可延误不冒收汇风险。

## 四、制单与审单（交单前自查）

### 常见单据清单
- 商业发票（Commercial Invoice）
- 装箱单（Packing List）
- 海运提单（Bill of Lading, B/L）：注意 consignee 通常 "To Order of Issuing Bank"、清洁提单（clean on board）
- 产地证（Certificate of Origin / FORM A / RCEP 证书）
- 保险单（CIF 条款下，Insurance Policy，投保金额 = CIF × 110%）
- 检验证书、熏蒸证书等（按 L/C 要求）

### 高频不符点
1. **拼写/数据不一致**：发票与箱单数量不符、唛头（shipping marks）拼写差异。
2. **过装运期**（late shipment）或**过效期**（late presentation / expired L/C）。
3. **提单问题**：未注明 "On Board" 日期、不清洁批注（dirty B/L）、背书缺失。
4. **发票未按 L/C 措辞**：品名描述必须与 L/C 完全一致（可用简称但总描述要对应）。
5. **保险单日期晚于提单日**、币别错误、背书漏签。

### 不符点处理
- **改单**：交单期内退回修改重交（最优）。
- **担保议付**：向银行出具担保（LOI），如遭拒付承担退款+利息。
- **电提（cable negotiation）**：请议付行向开证行电询不符点是否可接受，买方接受则付款。
- **付款赎单 / 托收处理**：降级为 D/P 托收，银行不再担保——议价地位被动。

## 五、风险防范清单

1. **新客户 L/C 先审开证行资信**：高风险地区小银行开立的 L/C，要求世界一流银行保兑（confirm）。
2. **装运前收妥正本 L/C 并完成审证**：没收到可执行的 L/C 不备大货。
3. **交单期预留余量**：最迟装运日 ≠ 建议装运日，预留 7-10 天缓冲防甩柜延误。
4. **全套单据交叉核对**：制单后由第二人复核（checker），外贸企业标配双人审单制。
5. **留存全套副本**：发票、箱单、提单副本归档，议付后跟踪收汇入账。

## 六、与其他付款方式对比

| 方式 | 风险（卖方视角） | 适用 |
|:---|:---|:---|
| 前 T/T 全款 | 最低 | 小单、样品单 |
| T/T 定金 + 尾款见提单副本 | 低 | 常规老客户 |
| **L/C 即期** | 中低（银行信用，但不符点风险） | 新客户、大单 |
| L/C 远期 | 中（占用资金 + 汇率） | 有议价能力时争取即期 |
| D/P / D/A | 中高 / 高 | 谨慎，D/A 不建议 |
| OA 赊销 | 高 | 仅长期稳定大客户 + 中信保 |
