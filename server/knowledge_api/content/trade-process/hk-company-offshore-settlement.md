# 香港公司与离岸结算实务（Hong Kong Company & Offshore Settlement）

香港公司是外贸企业常见的**收付汇与海外签约主体**：外汇自由、税制简单、国际认可度高。但**合规前提是真实贸易背景**——离岸账户不是避税工具，CRS 信息交换下账户透明化，合规运营是唯一可持续路径。

## 一、适用场景与价值

| 场景 | 价值 |
|:---|:---|
| 收取海外货款（多币种） | 无外汇管制/结售汇额度限制（对比内地个人 5 万美元额度） |
| 转口贸易签约主体 | 香港公司签约+内地工厂出货（三角贸易结构） |
| 海外参展/平台入驻 | 国际主体认可度高（展会注册/Stripe 等平台要求） |
| 品牌出海载体 | 持有海外商标/独立站主体（见 `customers-market/dtc-brand-clients.md`） |
| 海外投资跳板 | 东南亚设厂持股平台（见 `suppliers/china-plus-one-capacity-strategy.md`） |

## 二、注册与维护

- **注册**：1 名股东+1 名董事（无国籍限制）+ 香港注册地址+法定秘书（秘书公司代办——全套 ¥3000-6000，3-5 工作日）；
- **年度维护**（逾期罚款累积）：
  - **周年申报（NAR1）**：成立周年日起 42 天内；
  - **商业登记证续期**：年度换领；
  - **审计报税**：**每年强制审计**（香港执业会计师）+ 利得税申报（无论是否运营）；
- **利得税**：两级制（首 200 万港元利润 8.25%，其后 16.5%）；**离岸收入豁免**需申请（offshore claim——须证明利润非源自香港，举证要求高：合同/谈判/货物流均不在港）。

## 三、银行账户（开户是最难环节）

- **开户行选择**：汇丰/中银香港/渣打（传统大行门槛高）+ 虚拟银行（ZA Bank/Airstar——门槛低但功能限制）+ 持牌支付机构账户（Airwallex/万里汇等——非银行户但满足收付）；
- **开户材料**：业务证明（合同/发票/提单——**真实贸易背景是审批核心**）/内地关联公司资料/董事履历/预计流水说明；
- **面签**：董事赴港面签（部分银行支持视频见证）；
- **维护红线**：
  - 避免与**受制裁国家**资金往来（伊朗/朝鲜等——见 `trade-compliance/sanctions-screening-compliance.md`）；
  - 快进快出/代收代付触发风控（账户冻结高发——保留贸易单证 7 年备查）；
  - 长期不动户被关停（保持最低活跃度）。

## 四、合规要点（CRS 时代）

- **CRS 信息交换**：香港金融机构向税务机关报送账户持有人税务居民信息（内地居民控制的香港公司账户信息交换回内地——**透明度常态，无隐匿空间**）；
- **内地税务居民义务**：居民企业/个人控制的香港公司利润——受控外国企业（CFC）规则下无合理经营需要的利润留存可能被视同分配征税；
- **转让定价**：内地工厂与香港公司关联交易须符合独立交易原则（香港公司留利率需有功能支撑——报关价格逻辑见 `trade-compliance/customs-valuation-audit.md`）；
- **出口退税衔接**：香港公司签约+内地工厂出口模式——退税主体为内地出口企业（单证流/资金流匹配，见 `trade-process/export-tax-rebate.md`）。

## 五、资金回流路径

| 路径 | 说明 |
|:---|:---|
| 利润汇回 | 香港公司分红回内地母公司（缴 5% 预提税——税收协定优惠税率） |
| 支付货款 | 香港付内地工厂（正常贸易付款——内地公司收汇结汇，见 `trade-process/foreign-exchange-settlement.md`） |
| 服务费/佣金 | 需真实服务+代扣代缴（虚列服务费是稽查红线） |
| 个人股东分红 | 20% 个税（无豁免——"公转私"直接打款是雷区） |

## 六、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 零申报长期不报审计 | 罚款+董事检控 | 每年审计报税（无运营也须申报） |
| 账户代收代付 | 冻结/关户 | 只收付自有贸易款项 |
| 离岸豁免空口申请 | 驳回+补税罚息 | 留存完整非港经营证据链 |
| 秘书公司失联 | 年审逾期+公司除名 | 选持牌秘书（TCSP 牌照）+设日历提醒 |
| 香港账户收内地平台货款混用 | 税务定性混乱 | 账户专款专用（内外账分离） |
