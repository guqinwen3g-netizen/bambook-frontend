# 二手服装出口贸易实务（Used Clothing Export Trade）

中国二手服装出口是纺织外贸的特殊细分：国内回收→分拣分级→压缩打包→出口非洲/东南亚/中东。2023 年起中国已成全球前三大二手衣出口国。与新衣出口的关系：**既冲击低端新衣市场，也是部分工厂尾货的消化渠道**（见 `suppliers/garment-stock-lot-disposal.md`）。

## 一、产业链结构

1. **回收端**：小区回收箱/上门回收/慈善捐赠渠道（民政部门备案）——货源集中在一二线城市；
2. **分拣厂**（核心环节，产业带：广东佛山/东莞、山东枣庄、河北保定）：
   - 粗分：夏装/冬装/童装/鞋包/床品；
   - 精分：按品类+成色分级（T恤/衬衫/牛仔裤/连衣裙各成包）；
   - **分拣标准决定卖价**——非洲客户按"包"买，包内品类纯度>90% 才有溢价；
3. **打包**：液压机压缩成 40-100kg 方包（透明膜+编织布），40 尺柜装约 28-29 吨；
4. **出口报关**：HS 6309.00（旧衣物），按公斤申报；
5. **目的港分销**：进口商拆包→批发给集市摊主（非洲 mitumba 模式）。

## 二、等级与报价逻辑

| 等级 | 标准 | 价格带（FOB，参考） |
|:---|:---|:---|
| A级（精品） | 近新、无瑕疵、品牌款可选 | $1.5-2.5/kg |
| B级（普货） | 轻微穿着痕迹 | $0.8-1.5/kg |
| C级（统货） | 未精分混合包 | $0.4-0.8/kg |
| 擦机布/纤维级 | 破损不可穿 | $0.1-0.3/kg（按废料） |

- **夏装价值>冬装**（非洲气候）；童装、女士牛仔裤、运动鞋为硬通货；
- 报价随非洲汇率与运费波动大——乌干达/肯尼亚先令贬值期客户压价凶猛。

## 三、主要目的国与政策风险

| 市场 | 状态 | 要点 |
|:---|:---|:---|
| 肯尼亚 | 最大市场 | mitumba 合法且庞大；关税按件/按公斤浮动政策频出 |
| 乌干达 | 增长快 | 关税 35% 或 $1.5/kg 取高（2023 后多次调整） |
| 尼日利亚 | 明令禁止 | 海关列旧衣为"绝对禁运"——灰色渠道风险极高，勿碰 |
| 坦桑尼亚 | 允许+高税 | EAC 共同对外关税按公斤计 |
| 卢旺达 | 禁止 | 2018 起禁令（曾引发对美 AGOA 争端） |
| 中东（转口） | 分拣再出口 | 迪拜中转至中亚/中东非 |

- **政策反复是常态**：东非共同体（EAC）曾决议全面禁旧衣（保护本地纺织业），各国执行松紧不一——出货前必须确认当月清关政策（见 `customers-market/africa-market.md`）；
- 部分国家要求**熏蒸/卫生证书**（旧衣属"可能携带病菌"监管类目）。

## 四、实操要点

- **出口资质**：普通外贸公司可报 HS 6309；部分口岸要求固体废物属性鉴别——旧衣不是固废（可再穿用），但**破损污秽品混入可能被认定固废**（2021 全面禁废后口岸严查）；
- **品质红线**：无霉烂、无医用/殡仪来源衣物、无警用/军用制服（目的国忌讳）；内衣袜子多数国家禁入或只能作纤维级；
- **合同与收款**：行业惯例 **前 TT 全款或 30% 订金+见提单副本尾款**——非洲二手衣客户信用风险高，不做 OA（见 `trade-process/export-payment-methods-practice.md`）；
- **重量纠纷**：压缩包含水率影响重量——合同注明"装柜前过磅照片+视频"；
- **与新衣尾货联动**：工厂全新剪标尾货可入二手贸易渠道（比 A 级旧衣价高），但需剪标彻底（见 `suppliers/garment-stock-lot-disposal.md` 的 IP 规则，见 `trade-compliance/ip-brand-authorization.md`）。

## 五、趋势研判

- **供给端规范化**：国内《废旧纺织品循环利用实施意见》推动正规回收体系，源头货源向持牌企业集中；
- **需求端分化**：非洲中产扩大→精品包（A级）需求升；本地纺织保护政策→低价统货承压；
- **循环政策影响**：欧盟纺织废弃物政策（见 `trade-compliance/textile-waste-circularity-policy.md`）可能改变全球旧衣流向（欧洲旧衣转内销处理），长期利好中国分拣产能。
