# 服装视觉素材与产品摄影（Apparel Visual Content & Product Photography）

视觉素材是 B2B 与 B2C 转化的共同杠杆：B2B 场景（画册/网站/展会物料）决定买家是否约谈，B2C 场景（亚马逊/独立站）直接决定点击率与转化率（见 `trade-process/amazon-marketplace-operations.md`、`customers-market/independent-site-seo.md`）。低成本高质量出图能力=外贸公司隐性竞争力。

## 一、B2B 视觉素材清单

| 素材 | 规格 | 用途 |
|:---|:---|:---|
| 平铺/挂拍白底图 | 2000×2000px+，300dpi 备选 | 报价单/邮件附件/画册 |
| 细节特写 | 面料纹理/车线/辅料/logo 工艺 | 品质证明（比文字可信） |
| 工艺过程图/视频 | 验货/裁剪/充绒等实拍 | 社媒内容（见 `trade-process/linkedin-social-selling-b2b.md`） |
| 工厂与设备 | 车间全景/验针机/实验室 | 验厂前置信任建立 |
| 型录（lookbook） | PDF ≤10MB，按系列分页 | 展会与展会后跟进 |

- **命名规范**：`款式号-颜色-视角.jpg`（如 `BK2401-navy-front.jpg`）——客户存档友好=转介绍率高；
- **版权底线**：自拍或签肖像权协议（模特图）；禁扒竞品图（DMCA 投诉会封独立站）。

## 二、白底图拍摄标准（电商硬指标）

- **亚马逊主图**：纯白底 RGB 255/255/255、产品占画面 85%、无水印无道具——违规主图直接下架；
- **拍摄方案**：
  - 平铺图（flat lay）：俯拍架+硫酸纸柔光——T恤/童装高效方案；
  - 幽灵模特（ghost mannequin）：人台拍摄+后期合成领口内侧——立体感的行业标准做法；
  - 挂拍：适合外套/连衣裙（注意肩部塑形）；
- **布光**：两灯（主光+补光）+柔光箱即可覆盖 80% 场景；阴影过重=廉价感；
- **熨烫整形**：拍摄前整烫是最大变量（见 `suppliers/finishing-ironing-packing-room.md` 整烫标准）——皱巴巴的样品图浪费所有后期。

## 三、成本与外包决策

| 方案 | 成本 | 适用 |
|:---|:---|:---|
| 自建摄影角（2-3 万设备） | 边际成本≈人工 | 月出图 >200 款的贸易公司 |
| 外包摄影棚 | 30-80 元/款（白底） | 中小批量 |
| 电商精修（含模特） | 150-400 元/款 | 品牌单 |
| **AI/3D 出图** | 3D 建模 200-500/款，复用免费 | 颜色/花型多的款——**换色零成本** |

- **3D 样衣（CLO3D/Style3D）**：打样前出虚拟效果图给客户确认——省 50% 实体样费与 2 周快递时间（与 `trade-process/sample-development-and-confirmation.md` 流程衔接）；颜色/印花方案用 3D 轮换展示；
- **AI 生图定位**：场景氛围图（lifestyle 图）可 AI 辅助，**产品主图必须实物拍摄**——AI 图冒充实物在 B2B 是信任自杀。

## 四、B2C 图片矩阵（以亚马逊为例）

1. 主图（白底）→2. 卖点图（功能标注）→3. 尺寸图（尺码表可视化，降低退货率）→4. 场景图（模特穿搭）→5. 细节图×2→6. 包装图；
- **A+ 页面**：品牌备案后开放（见 `trade-process/overseas-trademark-registration.md`）——对比图表提升转化 5-10%；
- **视频**：30 秒主图视频（展示面料弹性/上身效果）——转化率提升显著；
- **移动端优先**：80% 流量来自手机——卖点图文字 ≥20pt 才清晰。

## 五、素材资产管理

- **归档结构**：`客户/季度/款式/原图+修图+详情页` 三级目录——复用与审计；
- **版本控制**：改款后的旧图立即下线（图货不符=差评与索赔源头）；
- **给客户的素材包**：白底图+细节图+尺寸表打包发采购商——帮客户上架=帮自己抢单（小 B 客户尤其吃这套，见 `trade-process/b2b-wholesale-platforms.md`）。
