# 海关查验与扣货应对（查验流程/布控原因/费用/扣货救济/知识产权备案）

海关查验是出口物流中最不可控的时效黑洞：正常申报放行 1-2 天，命中查验则 3-15 天起，费用与船期损失动辄数千元。申报流程见 `trade-process/export-customs-declaration.md`——本文聚焦**查验触发后的应对链路**：布控逻辑、费用结构、扣货救济与知识产权海关保护备案。

## 一、查验类型与布控逻辑

| 查验方式 | 内容 | 时效影响 | 费用量级 |
|:---|:---|:---|:---|
| 机检（H986 扫描） | 集装箱过 X 光比对申报品名 | +1-2 天 | 低（扫描费数百） |
| 人工查验（抽查） | 开箱抽检 10-30% 货物 | +3-5 天 | 吊柜+掏箱+服务费 1-3k |
| 彻底查验（彻查） | 全箱卸货逐件清点 | +7-15 天 | 3-8k+，易甩柜 |
| 目的港查验 | CBP MET/exam、欧盟海关抽检 | +5-30 天 | 海外仓租+滞箱高 |

- **布控三来源**：风险参数布控（HS 敏感品+申报要素异常，系统自动命中）、随机抽查（口岸查验率通常 1-5%）、**专项布控**（专项行动期——如侵权专项治理、低报价格整治期查验率飙升）；
- **高发触发点**：HS 归类模糊（纺织品类目税率倒挂易触发）、申报价值明显偏低、品名笼统（"garments" 无细分）、**品牌词**（吊牌/洗标带 logo 未申报授权）、产地证与申报不符。

## 二、查验流程与费用控制

- **国内流程**：查验通知→预约查验计划（港区排队）→吊柜至查验区→海关开箱→核对品名/数量/品牌→无异常放行（异常转**缉私/法规科**）；
- **费用明细**：吊柜费+掏箱费+理货费+查验服务费（代理收取）+滞箱费（船公司免箱期外）+堆存费——**主动预算**：买单报关的低价单查验一次可能吃掉全部利润；
- **时效补救**：开查验单当日催代理约计划；遇甩柜立即改配最近航次并通知客户（滞港责任条款见 `trade-process/trade-contract-terms.md`）；
- **查验陪同**：工厂/外贸公司可派人到场——**开箱前准备样品、成分标、授权书**，现场解释能力直接影响放行速度。

## 三、扣货场景与救济路径

- **常见扣货原因**：知识产权侵权（无授权品牌标识）、申报不实（品名/数量/价值）、敏感物项（两用物项无证——见 `trade-compliance/dual-use-export-control.md`）、骗取退税嫌疑（价格虚高）；
- **救济阶梯**：① 补充说明/担保放行（轻微瑕疵）→② 行政处罚认罚（罚款+货物放行）→③ **行政复议**（60 日内向上级海关）→④ 行政诉讼（6 个月内）→⑤ 退运/放弃（损失止损——退运流程见 `trade-process/export-return-repair-customs.md`）；
- **时效红线**：扣货后 3 个月内海关应作处理决定；滞港超期货物可被**变卖抵缴**——收到扣货通知 48 小时内必须启动应对；
- **证据链**：合同/发票/付款水单/品牌授权书/检测报告——平时归档备查（单证管理见 `trade-process/export-documents-errors.md`）。

## 四、知识产权海关保护备案

- **备案价值**：品牌方在海关总署备案商标后，海关**主动查扣**疑似侵权货物（无需逐案举报）——服装代工企业接单前反向核查客户商标是否被第三方备案（代工贴牌侵权连带责任）；
- **备案流程**：知识产权海关保护备案系统在线申请→缴纳备案费（800 元/件）→有效期 10 年（随商标权）；
- **代工自保**：接单索要**品牌授权书+商标注册证**，授权链条（品牌方→进口商→工厂）完整留档——吊牌洗标上的每一个 logo 都是查验触发点（见 `trade-compliance/ip-brand-authorization.md`）；
- **目的港镜像**：美国 CBP e-Recordation、欧盟 AFA（Action for Application）——出口品牌货提前在目的国备案，防止被抢注者反咬（抢注应对见 `trade-process/overseas-trademark-registration.md`）。
