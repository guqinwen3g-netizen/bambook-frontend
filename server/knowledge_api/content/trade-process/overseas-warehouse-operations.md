# 海外仓运营实务（Overseas Warehouse Operations）

海外仓是跨境电商的"**本地化履约基座**"：时效 2-5 天对标本土电商——但库存前置的风险与成本结构决定它只适合动销稳定的品类。

## 一、海外仓 vs 直邮

| 维度 | 海外仓 | 跨境直邮 |
|:---|:---|:---|
| 时效 | 2-5 天（本土发货） | 7-15 天（专线） |
| 单件物流成本 | 尾程 $3-6（量大摊薄头程） | $5-15（单票全链路） |
| 库存风险 | 高（滞销资金占用+仓储费） | 低（卖一单发一单） |
| 适用 | 标品/动销稳/大件重货 | 长尾/测款/轻小件 |
| 退换货 | 本地处理（可二次销售） | 基本放弃（退回成本>货值） |

## 二、成本结构拆解

- **头程**：海运整柜摊薄（见 `trade-process/sea-freight-practice.md`——服装每 CBM 摊到单件 $0.1-0.3）;
- **入库费**：卸柜+清点+上架（$0.2-0.5/件）;
- **仓储费**：按 CBM/月或托盘/月（旺季加价——美西仓约 $0.5-1/CBM/天档级）;
- **出库处理费（pick & pack）**：$1-3/单（含包材——多件订单阶梯）;
- **尾程派送**：USPS/UPS/FedEx 折扣账号（仓配一体仓有协议价——轻小件 USPS Ground Advantage $4 内）;
- **增值费**：贴标/换标/质检/拍照（退货处理核心场景）。

## 三、核心增值服务

- **FBA 中转/补货**：第三方仓作为 FBA 前置仓（规避 FBA 库容限制+旺季仓储费——快进快出补 FBA）;
- **退货换标（relabeling）**：亚马逊移除订单到第三方仓→检查换标→重新入 FBA（服装退货 20-30% 的挽救通道——见 `trade-process/amazon-marketplace-operations.md`）;
- **一件代发（dropship fulfillment）**：多平台订单统一履约（亚马逊 MCF/独立站/TikTok Shop 本土店）;
- **质检翻新**：退货分级（A 品重上架/B 品折价/C 品报废——服装质检熨烫重包）。

## 四、选仓要点

- **位置**：美西（CA/TX——头程近+华人仓密集）/美东（NJ/GA——人口密集配送时效）/欧洲（德国/波兰/英国）;
- **华人仓 vs 本土仓**：华人仓沟通顺+灵活（灰色操作风险——跑水账号封店连坐）/本土仓合规（ShipBob 等上市仓）;
- **系统对接**：API 对接店铺（自动推单——万邑通/谷仓/4PX 等头部系统成熟）;
- **资质尽调**：经营年限/仓库实地视频/同行口碑（跑路仓高发——预存款控制额度）;
- **尾程账号**：确认是正规折扣账号（"跑水单"——低价 USPS 账号欺诈，连坐封店+货物扣押）。

## 五、库存管理纪律

- **首批试水**：动销未验证产品小批量入仓（100-500 件——卖动再补）;
- **库龄监控**：90 天+ 库龄预警（清仓促销/移除——仓储费滚雪球）;
- **补货模型**：海运头程 30-40 天+安全库存（断货损失 vs 滞销风险平衡——服装季节款宁缺毋滥）;
- **盘点**：季度对账（仓库库存差异率>2% 警惕——索赔条款写入合同）。

## 六、2026 格局与趋势

- **平台仓配竞争**：Temu 半托管/SHEIN 美国本土履约（第三方仓承接平台半托管订单成新增长点）;
- **TikTok Shop**：本土发货强制（美区——第三方仓一件代发主流方案）;
- **关税驱动**：小额包裹免税取消（美国 800 美元 de minimis 2025 年起取消——直邮成本上升倒逼海外仓备货模式）;
- **自动化**：头部仓机器人分拣（中小仓人工为主——选择看订单量级）。
