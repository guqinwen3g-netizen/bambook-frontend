# 西装出口验货 SOP（Suit Inspection SOP: 高端正装出货前检验标准与流程）

西装验货是"**服装验货中最严苛的品类**"：300+ 道工序意味着 300+ 个潜在缺陷点，日本客户 0.5cm 公差级要求重新定义了"合格"。泛验货见 `trade-process/pre-shipment-inspection-sop.md`，泛缺陷见 `garments/garment-defects-inspection.md`，AQL 抽样见 `trade-process/aql-sampling-standards-deep-dive.md`——本文件聚焦**高端西装/正装的专项验货标准**。

## 一、验货流程（西装专项）

1. **抽样**：AQL 2.5（major）/4.0（minor）——**日本订单升级至 AQL 1.5**；
2. **尺寸测量**：每款抽 5-13 件全尺寸测量（西装 18-22 个测量点）；
3. **外观检验**：自然光/D65 灯箱下逐件检验；
4. **工艺检验**：拆解检查（衬结构/里布/缝份）；
5. **试穿检验**：真人模特试穿（合体度/活动量）；
6. **包装检验**：挂装/折叠方式/箱唛/配比。

## 二、尺寸公差表（西装专项）

| 测量点 | 欧美标准 | 日本标准 | 测量要点 |
|:---|:---|:---|:---|
| 胸围（chest） | ±1.0cm | ±0.5cm | 腋下 2.5cm 平量×2 |
| 腰围（waist） | ±1.0cm | ±0.5cm | 最细处平量×2 |
| 衣长（back length） | ±1.0cm | ±0.7cm | 后中领下至下摆 |
| 肩宽（shoulder） | ±0.6cm | ±0.5cm | 肩点到肩点 |
| 袖长（sleeve） | ±0.7cm | ±0.5cm | 肩点至袖口 |
| 领围（collar） | ±0.5cm | ±0.4cm | 领座下口 |
| 袖口（cuff opening） | ±0.4cm | ±0.3cm | 平量 |
| 驳头宽（lapel） | ±0.3cm | ±0.2cm | 最宽处 |

- **对称性公差**：左右袖长差 <0.4cm；左右驳头对称 <0.2cm——**对称性是西装验货的第一观感**。

## 三、外观缺陷分类（西装专项）

### 致命缺陷（Critical，直接拒收）
- 衬布起泡/脱胶（粘合衬前胸）；
- 驳头翻卷不对称/翻卷线扭曲；
- 左右明显色差（同一件前后片）；
- 面料疵点在主视区（前胸/领面/袖面）；
- 金属异物（断针——检针机全检前提）。

### 主要缺陷（Major）
- 对格对条错位 >2mm（口袋/门襟/后衩）；
- 绱袖吃势不均（袖山起包/打扭）；
- 里布起吊（里布短于面料导致下摆内卷）；
- 扣眼锁线不良/扣位偏移；
- 领子压痕/领座外露；
- 裤线偏移（前裤线不在中位）；
- 拱针/珠边断线/针距不均。

### 次要缺陷（Minor）
- 线头未清（>3mm）；
- 里布色差（里布与面布非要求同色的轻微色差）；
- 非主视区轻微污渍（可擦除）；
- 熨烫极光（呢面压光——可蒸汽修复）。

## 四、工艺拆解检验

- **衬结构验证**：剪开小样（或利用预留样）——**验证半麻衬/全麻衬与订单约定一致（欺诈高发区）**；
- **里布品质**：宾霸里布的验证（燃烧法/溶解法鉴别铜氨丝）；
- **手工含量核查**：手工纳驳头/手工锁眼的抽样验证——**"声称手工 vs 实际机制"的贸易纠纷预防**；
- **辅料核对**：扣子品牌（果实扣/贝母扣）/拉链品牌（YKK/riri）——**按订单 BOM 逐项核对**。

## 五、试穿检验（西装专项）

- **静态**：肩线平顺/驳头贴合/后领贴颈/衣长比例；
- **动态**：抬臂 45° 袖窿不卡/前抱不露背缝/蹲坐裤裆不撕裂；
- **模特选择**：按目标市场体型（欧美模特 L 码/日本模特 M 码）；
- **拍照存档**：试穿照片附验货报告——**争议时的关键证据**。

## 六、包装与配比检验

- **挂装（GOH）**：衣架承重（西装需宽肩衣架）/防尘袋密封/箱内挂杆承重；
- **折叠包装**：折叠衬纸（防压痕）/折叠位置（后中折 vs 对折）；
- **配比（assortment）**：尺码/颜色配比与装箱单一致——**配比错误是服装验货第一高频问题**；
- **备用扣**：每套西装配备用扣（2 粒前扣+1 粒袖扣）——**缺备用扣计 minor 缺陷**。

## 七、验货报告与争议处理

- **报告要素**：缺陷照片（带标尺）/尺寸实测表/抽样比例/缺陷统计/结论（accept/reject/rework）；
- **争议高发点**：
  - 色差判定（D65 灯箱 vs 自然光——**合同必须约定判定光源**）；
  - 对格精度（"视觉可接受"是模糊表述——**必须数字化：错位 >2mm 为 defect**）；
- **rework 管理**：缺陷品返工后的二次验货——**返工批次必须 100% 复检**。
