# 加工贸易手册与保税实务（Processing Trade & Bonded Manual Management）

加工贸易的本质：**保税进口料件→加工→复出口，暂缓缴纳进口关税与增值税**。手册是海关监管账本——核销不平（进口料件 ≠ 出口耗用 + 合理损耗）就要补税 + 罚款。

## 一、模式对比与选择

| 模式 | 监管代码 | 料件权属 | 收汇方式 | 适用 |
|:---|:---|:---|:---|:---|
| 进料加工 | 0615 | 我方买断（付汇进口） | 成品全额收汇 | 自主采购进口面料加工出口（主流） |
| 来料加工 | 0214 | 外商所有（不付汇） | 只收工缴费 | 客户供料代工（品牌控料场景） |
| 一般贸易 | 0110 | 无保税监管 | 全额收汇+退税 | 国产面料为主（默认路径） |

**决策框架**（见 `trade-process/export-tax-rebate.md` 退税对比）：

- **选加工贸易**：进口料件关税+增值税高（如意大利羊毛面料关税 10-12%）、复出口比例 ≥ 80%、单一大客户长期订单；
- **选一般贸易**：国产面料为主、内外销比例灵活、不想受手册监管束缚——出口退税已覆盖大部分税负；
- **混合模式**：同一工厂可并行两种贸易方式（**保税料与国产料物理隔离**是红线）。

## 二、手册生命周期

1. **备案**：商务部门生产能力证明→海关备案手册（电子化——金关二期）→保证金台账（AEO 高级认证企业可免实转——见 `trade-compliance/customs-aeo-certification.md`）；
2. **料件进口**：按手册额度保税进口（报关单注明手册号）；
3. **生产加工**：单耗管理（下文）——海关默认监管周期 1 年（可延期）；
4. **成品出口**：手册项下逐票核扣；
5. **核销结案**：进口总量 = 出口耗用 + 损耗 + 余料/边角料处置，平衡后结案退保证金。

## 三、单耗管理（核销核心）

- **单耗 = 净耗 + 工艺损耗**：净耗=单位成品实际用料（按尺码加权——服装必须分尺码算加权单耗）；损耗=裁剪碎布/布头布尾/印花次片；
- **服装行业损耗率参考**：梭织 8-15%（排料紧密度决定——见 `suppliers/cutting-room-management.md`）、针织 10-18%、皮革 15-25%（伤残剔除——见 `garments/leather-fur-garment-production.md`）；
- **申报口径**：备案单耗可略高于实际（留余量），核销按实际——**高报低耗=余料凭空出现，擅自处理即走私风险**；
- **BOM 留档**：排料图/裁剪报表/称重记录是核销举证材料（海关可下厂核查）。

## 四、余料/边角料/残次品处置

| 形态 | 处置路径 | 税负 |
|:---|:---|:---|
| 剩余料件（余料） | 结转新手册 / 内销补税 / 退运出境 | 内销=关税+增值税+缓税利息 |
| 边角料（碎布） | 内销补税（按废料估价）/ 有偿转让 / 销毁（海关监销） | 按审价计税 |
| 残次品 | 内销补税 / 退运 / 销毁 | 同上 |
| 副产品 | 申报后内销 | 同上 |

- **红线**：保税料件/成品**未补税擅自内销 = 走私**（刑事风险，不是罚款了事）；
- **缓税利息**：内销补税时加收（按日万分之五——手册时间越长利息越高）。

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 串料（保税料做内销单） | 走私认定 | 仓库物理隔离+ERP 分账套（见 `suppliers/material-warehouse-management.md`） |
| 单耗申报不实 | 核销倒挂补税+稽查 | 按实际排料数据建 BOM |
| 手册逾期未核销 | 锁手册+保证金没收 | 到期前 30 天启动核销（设日历提醒） |
| 余料"送"给辅料商 | 擅自处置违法 | 一切出账必有海关手续 |
| 外发加工未备案 | 违规 | 外发加工提前向海关备案（跨关区需双方海关确认——见 `suppliers/subcontracting-outsourcing-management.md`） |

## 六、实操要点

- **联网监管**：金关二期 EDI 传输——账册数据与 ERP 对账每月一次（差异早暴露）；
- **延期**：手册期满前申请延期（最长再延 1 年，一般不超过 2 次）；
- **稽查应对**：海关 3 年内可稽查——单证（报关单/领料单/排料图/出入库）保存至核销后 3 年；
- **小单快反不适用**：手册按订单备案的节奏不适应快反（备案周期长）——快反单走一般贸易+退税更灵活。
