# 验货（Inspection & Quality Control）

验货（inspection）是出货前把好质量关的关键环节，也是纺织服装外贸"一手交钱、一手交货"之间的质量守门。本文件覆盖中期验货、终期验货、AQL 抽样标准与第三方验货机构。

## 一、验货类型

| 类型 | 英文 | 时机 | 作用 |
|:---|:---|:---|:---|
| 中期验货 | mid-line inspection | 缝制/生产中段 | 提前发现工艺问题，及时整改 |
| 终期验货 | final inspection | 包装后、出货前 | 出货质量最终确认 |
| 出货数量核对 | quantity/shortage check | 装箱前 | 核对数量与尺码分配 |
| 装柜监装 | loading supervision | 装柜时 | 监督装柜与箱单一致 |

## 二、中期验货（Mid-line）

- 多在缝制阶段进行，检查线迹、针距、尺寸、色差、工艺是否按产前样执行。
- 目的：在问题未扩散前整改（corrective action），避免大货整体返工。
- 常见检查项：**尺码（size）**、**缝线牢度（seam strength）**、**对称性（symmetry）**、**工艺细节（styling detail）**。

## 三、终期验货（Final Inspection）

- 在包装完成后抽取一定数量样衣，按标准逐项检验。
- 分**外观检查（appearance）**与**尺寸/功能检查**。
- 需要**出货数量与尺码浪（size breakdown）核对**，防止短装或多装。

## 四、AQL 抽样标准

AQL（Acceptance Quality Limit，可接受质量水平）是验货抽样的行业标准，通常参考 **ISO 2859-1**（即 ANSI/ASQ Z1.4）。

- 术语：**批量（lot/batch）**、**样本量（sample size）**、**Ac（acceptance number，接收数）**、**Re（rejection number，拒收数）**。
- 常用 AQL 等级：服装常采用 **AQL 2.5 / 4.0**（一般检验水平 II）。
- 判定：抽检到的**缺陷数（defects）≤ Ac 判合格（pass）**，≥ Re 判不合格（fail）。
- 缺陷分级：
  - **严重缺陷（critical）**：影响安全/功能（如金属异物、尺码错误）。
  - **主要缺陷（major）**：明显影响外观/使用（如色差、破洞、缝线断开）。
  - **次要缺陷（minor）**：轻微不影响使用（如线头、轻微污渍）。

> AQL 抽样表由验货机构或客户指定，跟单需在验货前确认采用哪个等级与水平。

## 五、第三方验货机构

常见国际第三方（third-party inspection）机构：

| 机构 | 缩写 | 说明 |
|:---|:---|:---|
| SGS | Société Générale de Surveillance | 全球知名检验认证 |
| BV | Bureau Veritas | 法国必维，验货/认证 |
| Intertek | ITS / Intertek | 英国天祥，验货/测试 |
| TÜV | TÜV Rheinland 等 | 德国认证/检验 |

流程：下单验货 → 验货员现场抽检 → 出具**验货报告（inspection report）** → 判 pass/fail → 出具整改清单（if fail）。

## 六、验货常见问题与处理

1. **验货不过**：根据报告逐项返工（rework），整改后申请复验（re-inspection）。
2. **色差/尺寸超差**：与客户确认可接受范围，避免整批报废。
3. **数量不符**：核对箱单（packing list）与实装，短装需补装或协商。
4. **验货报告归档**：作为出货、结算、保险理赔的依据。

## 七、跟单要点

1. 验货前确认：验货标准（AQL、检验水平）、验货机构、验货日期与地点。
2. 提前自检（pre-inspection）：在第三方验货前工厂先自检，降低不合格风险。
3. 验货报告留存，作为质量追溯与客诉处理依据。
4. 与交期联动：验货不合格推延出货，需同步调整船期与客户沟通。
