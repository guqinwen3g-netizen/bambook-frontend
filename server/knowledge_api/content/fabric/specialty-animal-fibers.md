# 特种动物纤维贸易（马海毛/羊驼毛/牦牛绒/兔毛/骆马绒：小众高值原料）

特种动物纤维是毛纺体系的"轻奢原料层"：产量小（全球马海毛年产仅万吨级 vs 羊毛 120 万吨）、产地集中、价格波动大，**拼的是产地资源与分梳工艺**。羊毛羊绒基础见 `fabric/wool-cashmere-fabrics.md`——本文聚焦**小马种纤维的产地、品级与贸易要点**。

## 一、纤维谱系与产地格局

| 纤维 | 主产地 | 细度 | 特征 | 价格带（洗净毛/kg） |
|:---|:---|:---|:---|:---|
| 马海毛（mohair） | 南非（55%）/美国德州/土耳其 | 幼羔 24-27μm/成羊 30-40μm | 光泽强、挺括——西装衬里/娃娃假发/花式纱 | $15-40 |
| 羊驼毛（alpaca） | 秘鲁（80%）/玻利维亚 | 贝贝 18-22μm/成驼 26-32μm | 中空保暖、无脂低敏、22 天然色 | $20-60（贝贝 $80+） |
| 骆马绒（vicuña） | 秘鲁/安第斯保护区 | 12-14μm | **全球最贵纤维**（$400-1000+/kg）——CITES 附录管制 | $400+ |
| 牦牛绒（yak down） | 中国（青藏高原 90%） | 16-20μm | 保暖超羊毛、天然棕灰黑三色 | $30-80 |
| 兔毛（安哥拉） | 中国（90%）/法国 | 11-14μm | 轻软蓬松——掉毛是死穴 | $20-50 |
| 骆驼绒（camel） | 中国西北/蒙古 | 16-24μm | 天然驼色、保暖裤填充大宗 | $15-40 |

- **中国角色**：牦牛绒/兔毛/驼绒的**绝对产地**（原料出口 vs 制成纱线出口的结构升级是产业议题）；马海毛/羊驼依赖进口原料（南非/秘鲁直采+国内分梳）；
- **品级核心=细度+长度**：羊驼按细度分 Royal（<19μm）/Baby（20-22）/Superfine（23-26）/成驼——**细度每降 1μm 价差 20-30%**；马海毛 Kid 与 Adult 价差 2 倍+。

## 二、加工与品控要点

- **分梳工艺**：牦牛绒/驼绒是"粗毛+绒"混合原毛——**分梳去粗**（粗毛含量 <1% 是绒品级关键）——分梳得率仅 30-45%（成本大头）；洗毛碳化（去草杂——草刺含量是手感命门）；
- **染色限制**：羊驼/牦牛天然色是卖点（无染色环保叙事）——但深色底（牦牛绒棕黑）**只能染深色**（浅亮色系不可达——产品企划限制）；白色羊驼毛最稀缺（可染色款溢价）；
- **掉毛与起球**：兔毛纤维表面光滑抱合差——**掉毛投诉**（纯兔毛必须混纺——粘胶/尼龙 20-30% 固毛）；羊驼毛起球优于羊绒但仍需抗起球整理；
- **混纺主流**：纯特种纤维制品少——**与羊毛/尼龙混纺**控成本+补性能（马海毛 30%+羊毛 70% 是花式纱经典配比——`fabric/fancy-yarns.md`）。

## 三、贸易与合规要点

- **CITES 红线**：骆马绒（vicuña）受 CITES 附录 II 管制——**进出口需双证**（秘鲁出口证+目的国进口证），无证的"骆马绒"=走私或假冒（市场假货率极高——真 vicuña 围巾零售价 $1500+，$100 级必是 alpaca 冒充——见 `trade-compliance/cites-compliance.md`）；
- **纤维名称标识**：FTC/EU 纤维名称法规（`trade-compliance/textile-fiber-names-regulation.md`）——"alpaca"/"mohair"/"cashmere"标注必须含量达标；**"pashmina"乱象**（化纤仿冒克什米尔羊绒）已被多国执法；
- **动物福利**：安哥拉兔毛的活拔毛争议（PETA 曝光后 H&M/Zara 停购——**RWS 类认证扩展到兔毛 RAS**）；马海毛 2020 年南非虐待风波——品牌要求 **RMS（Responsible Mohair Standard）** 认证（认证体系见 `trade-compliance/textile-certifications.md`）；
- **价格波动**：小品种纤维**拍卖定价**（南非马海毛拍卖/秘鲁羊驼拍卖）——季节性与气候敏感（干旱减产暴涨），锁量锁价框架协议是风控核心。

## 四、应用与市场

- **马海毛**：高端西装胸衬（黑炭衬——`fabric/linings-interlinings.md`）、花式纱（拉毛纱——毛衣仙气感）、手编毛线（零售绞纱——欧美手编市场）、娃娃假发（BJD 高端线）；
- **羊驼**：秘鲁原产地制品（围巾/斗篷——旅游纪念品渠道）vs 高端针织（意大利品牌纱线）；**"baby alpaca"标注泛滥**（实为成年细毛——FTC 执法案例）；
- **牦牛绒**：国产高端替代叙事（"藏地软黄金"）——SHOKAY/ Norlha 品牌模式；混纺针织衫+填充被；
- **兔毛**：贝雷帽/毛衣混纺（法国 angora 传统线）；**出口以兔毛纱/兔毛条为主**；
- **市场渠道**：纱线展（意大利 Pitti Filati/上海 Spinexpo）、手编零售（欧美 yarn shop——小绞精包装）。
