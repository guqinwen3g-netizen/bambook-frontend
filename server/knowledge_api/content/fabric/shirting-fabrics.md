# 衬衫面料专题（Shirting Fabrics）

衬衫面料（shirting）是梭织面料中精细化程度最高的分支：高支高密、色织提花、免烫整理。商务衬衫面料的支数与免烫等级是价格分水岭。

## 一、主流品种

| 品种 | 英文 | 特征 | 定位 |
|:---|:---|:---|:---|
| 府绸 | poplin / broadcloth | 平纹高密，光滑细腻 | 商务正装主力 |
| 牛津纺 | oxford | 双经单纬 basket 组织，颗粒感 | 商务休闲（OCBD 经典） |
| 青年布 | chambray | 色经白纬平纹，仿牛仔浅色 | 休闲 |
| 斜纹 | twill | 2/1、2/2 斜纹，柔软垂感 | 商务（比府绸抗皱） |
| 人字纹 | herringbone | 鱼骨纹 | 中高端商务 |
| 米通/小提花 | dobby | 几何小提花 | 差异化商务 |
| 大提花 | jacquard | 花型复杂 | 礼服/时尚 |
| 泡泡纱 | seersucker | 凹凸褶皱免熨 | 夏季/度假 |
| 法兰绒 | flannel | 磨毛棉，暖 | 秋冬休闲 |

## 二、规格体系

- **支数**：80S/2、100S/2、120S/2、140S/2（双股）——支数越高面料越细滑。**100S/2 是商务主流，140S/2+ 属奢侈级**。
- **密度**：如 144×76、160×90（根/英寸）；高支必须配高密（"高支高密"）。
- **成分**：100% 棉（长绒棉最佳）/ CVC 60/40 / T/C 65/35 / 棉麻 / 棉莫代尔。
- **幅宽**：57/58"（145cm）为主。

## 三、色织（Yarn-Dyed）——衬衫面料灵魂

- 色织 = 先染纱后织布：条子（stripe）、格仔（check/plaid）、青年布。
- **对条对格**是成衣端成本点：裁片对格增加单耗 10-20%（见 `garments/garment-costing-pricing.md`）。
- 色织面料产区：江苏南通/山东鲁泰（全球最大色织布基地）、广东溢达。
- **纬斜公差**：色织格仔布纬斜 >2% 即无法对格——验布重点（见 `fabric/fabric-defects-glossary.md`）。

## 四、后整理

| 整理 | 说明 |
|:---|:---|
| **免烫（non-iron / wrinkle-free）** | 树脂整理（DP 4.0+ 级为高级免烫）；注意甲醛释放量控制（国标 ≤75mg/kg，贴肤衬衫 ≤75） |
| 液氨整理（liquid ammonia） | 改善手感与强力，高档棉料标志 |
| 丝光（mercerization） | 增加光泽与上色率 |
| 柔软整理 | 硅油类柔软剂 |
| 抗菌/易去污 | 功能型商务衬衫卖点 |

- **免烫分级**：DP/DP-4 级（洗后平整度 4 级）为真免烫；DP 3.5 级为半免烫——报价与宣称须对应实测。

## 五、质量检验要点

1. **甲醛**：免烫树脂整理面料必检（尤其贴肤类）。
2. **纬斜/弧形纬斜**：格仔色织布 ≤2%。
3. **色牢度**：领口摩擦（白衬衫领子沾色投诉高发）。
4. **起毛起球**：高支细纱面料反而易起球，注意检测。
5. **缝制缩率**：免烫面料热缩影响成衣尺寸，产前测试。

## 六、采购与报价

- **报价三要素**：支数（100S/2）+ 成分（100% 长绒棉）+ 整理（DP 免烫/液氨）。
- 价格参考带（2026）：CVC 普通府绸 12-16 元/m；全棉 100S/2 色织 25-40 元/m；140S/2 液氨免烫 45-60 元/m。
- **起订量**：色织 1000-1500m/色/花型；现货白坯+染色可降低 MOQ（但色织质感无法替代）。
- **品牌背书**：鲁泰（Luthai）、溢达（Esquel）面料是高端衬衫客户指定常客；进口料 Thomas Mason、Albini、Monti 为奢侈线。
