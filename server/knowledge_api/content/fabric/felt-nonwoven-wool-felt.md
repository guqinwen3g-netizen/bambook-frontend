# 毛毡专题（Felt: 羊毛湿毡/针刺毡/工业毡/工艺毡）

毛毡是人类最早的片状织物（不织不编，靠纤维缠结成毡），今天分两条技术路线：**羊毛湿毡**（缩绒原理，高端）与**针刺毡**（机械缠结，大宗）。应用从欧美手工 DIY 工艺毡到德国工业密封毡、乐器毡、抛光毡轮——**低价泡货与精密工业品并存**。本文件梳理工艺路线、产品谱系与外贸要点。

## 一、两条工艺路线

| 路线 | 原理 | 原料 | 产品定位 |
|:---|:---|:---|:---|
| 羊毛湿毡（wool felt） | 羊毛鳞片遇湿热+碱+机械力缩绒缠结 | 羊毛（细度决定档次） | 高端：鞋材/帽坯/乐器/密封 |
| 针刺毡（needle-punched felt） | 刺针往复机械缠结纤维网 | 涤纶/丙纶/腈纶/混毛 | 大宗：工艺毡/土工/过滤/填充 |

- **羊毛毡档次看细度**：66s（粗）→ 70s 以上（细，美利奴级）——细度决定毡面细腻度与缩绒速度；原料逻辑见 `fabric/wool-cashmere-fabrics.md`；
- **密度是核心指标**：羊毛毡按密度分档（0.14 软毡-0.70+ g/cm³ 硬毡）——**钢琴弦槌毡/抛光毡轮要求高密度均匀性**，密度公差±0.02 是工业客户验收红线；
- **针刺毡看克重与厚度**（100-3000g/m²）——工艺毡主流 1-5mm（200-600g），产业带：河北南宫（毛毡之乡）/浙江。

## 二、产品谱系与市场

| 品类 | 规格要点 | 市场 |
|:---|:---|:---|
| 工艺毡（craft felt） | 1-3mm 彩色化纤毡，A4/卷装 | 欧美手工 DIY/幼教（圣诞手工季放量，见 `garments/christmas-holiday-textiles.md` 季节逻辑） |
| 羊毛毡拖鞋/鞋材 | 5-8mm 湿毡一体成型 | 北欧/德语区家居鞋 |
| 工业密封毡/吸油毡 | 密度+含油率指标 | 机械配套（德系标准 DIN 61200） |
| 抛光毡轮 | 高密度硬毡+平整度 | 珠宝/玻璃/金属抛光耗材 |
| 乐器毡 | 钢琴弦槌/弱音毡 | 乐器厂配套（认证周期长） |
| 毡制收纳/包袋 | 3-5mm 针刺毡车缝 | 家居收纳/电脑包（见 `garments/laundry-storage-organizers.md` 渠道） |
| 种植袋 | 300g 针刺毡透气 | 园艺（见 `garments/grow-bags-garden-planters.md`） |

## 三、外贸接单要点

- **泡货属性**：工艺毡蓬松低值——40HQ 装载量与海运费占比是报价核心（压缩包装/抽真空可降运费 30%+，但羊毛毡压缩后回弹受损，需与客户确认）；
- **色牢度与环保**：工艺毡直接接触儿童手工——欧标 EN71-3（可迁移元素）+ 偶氮染料检测是欧美订单门槛（见 `trade-compliance/testing-lab-selection.md`）；
- **羊毛毡特殊检测**：含毛量（FZ/T 25001）、毡化均匀性（无未毡化死毛）、pH 值；
- **工业毡认证**：密封/抛光类需按客户图纸+试样——**先免费小样→装机测试→小批→年框**，转化周期 6-12 个月但粘性极高；
- **气味投诉**：羊毛毡脱脂不净会带羊膻味（欧美客诉高发点）——要求供应商强化碳化/洗毛工艺并随批嗅检。
