# 研磨抛光纺织品基材（Abrasive & Polishing Textiles: 砂布基布/布轮/百洁布）

研磨抛光纺织品是涂附磨具的**骨架基材**：砂布/砂带的布基、抛光布轮的棉布、百洁布的尼龙无纺网。金属加工/木工/不锈钢厨具抛光消耗巨量磨具——**基材占磨具成本 20-40% 且决定其强度与柔韧性**。剑麻抛光布在麻纤维文档有提及（见 `fabric/hemp-bast-fibers-deep-dive.md`），本文系统梳理全族。

## 一、产品矩阵

| 品类 | 材质/结构 | 功能定位 | 下游 |
|:---|:---|:---|:---|
| 砂布基布（abrasive backing） | 全棉斜纹/涤棉混纺（X/J 重量分级） | 植砂基体——**X 重布（粗磨）/J 轻布（柔韧曲面磨）** | 涂附磨具厂 |
| 砂带基布 | 高强度涤纶/锦纶 | 接头抗拉+尺寸稳定 | 砂带转换厂 |
| 抛光布轮（buff） | 全棉绒布/府绸/剑麻布 | 层叠/折皱布轮——镜面抛光 | 五金/厨具/乐器抛光 |
| 百洁布基网（scouring pad web） | 尼龙/涤纶无纺网+磨料喷涂 | 去锈去垢 | 3M 类品牌/商超清洁 |
| 麻轮布（sisal buff） | 剑麻粗布 | 粗抛去划痕 | 不锈钢制品厂 |
| 千叶轮基布 | 涤棉/混纺 | 砂布页片基体 | 金属打磨 |

## 二、材料与工艺要点

- **重量分级体系**：涂附磨具行业惯例——**J（轻量柔）/X（重量挺）/Y（超重砂带）**；克重与断裂强力对应表随货；
- **基布处理**：**烧毛（表面光洁防砂粒嵌毛）+定型（尺寸稳定）+浸渍（酚醛树脂增强耐水耐油）**——处理工艺是磨具寿命分水岭；
- **强力指标**：经向断裂强力（砂带≥3000N/5cm 级）+**接头强度**（砂带接头断裂=甩带事故）；
- **布轮布**：**绒布起绒密度**决定抛光膏保持量；府绸细布用于精抛（镜面）；布轮偏心车缝（螺旋纹散热）；
- **剑麻布**：硬质粗纤维切削力强——粗抛专用；剑麻纤维特性见 `fabric/hemp-bast-fibers-deep-dive.md`；
- **百洁布网**：尼龙 66 单丝成网+**磨料（碳化硅/氧化铝）树脂喷涂**——磨料目数分级（粗 60-80/细 240-400）。

## 三、市场与商业要点

- **需求结构**：涂附磨具厂（3M/圣戈班/三菱+中国磨具集群——**河南郑州/湖北通城**）B2B 复购；布轮成品直供五金抛光厂；
- **出口链条**：基布出口→东南亚/印度磨具厂；成品布轮/百洁布出口→欧美 MRO 渠道；
- **替代与升级**：纸基（砂纸）vs 布基——**布基耐水耐油可洗重复使用**，湿磨/重负荷不可替代；无纺布磨具（不织布砂带）蚕食部分份额；
- **价格联动**：棉纱成本占比高——棉价波动传导（套保见 `trade-process/commodity-futures-hedging.md`）；
- **认证**：磨具厂认证体系（FEPA 标准/欧盟 EN 13743 安全）——基材随成品认证。

## 四、风控要点

- **强力虚标**：砂带基布强力不足=使用中断裂飞出伤人——**批次留样+拉力测试记录**（产品责任见 `trade-compliance/product-liability-recall.md`）；
- **树脂浸渍一致性**：浸渍不均=磨具局部脆化掉砂——在线克重监测；
- **棉纺纱质量**：纱疵/棉结影响植砂均匀——原棉配棉管理（纺纱逻辑见 `fabric/cotton-yarn-import-trade.md`）；
- **环保**：酚醛树脂游离酚/甲醛——车间接触与成品残留（化学合规见 `trade-compliance/chemical-environmental-compliance.md`）；
- **账期**：磨具厂账期 60-120 天——大客户授信管理（见 `trade-process/export-payment-methods-practice.md`）。
