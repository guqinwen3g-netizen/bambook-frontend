# 集装袋与吨袋生产（FIBC/Bulk Bags: PP 编织大包装出口实务）

集装袋（FIBC=jumbo bag/big bag/吨袋/太空袋）是"**PP 扁丝编织+吊带承重**"的产业用纺织大品类：单袋装载 500-2000kg，服务化工/矿产/食品/粮食散装物流，全球年需求量数十亿条。与篷盖布同属 PP/PE 编织产业用布（见 `fabric/tarpaulin-coated-industrial-fabrics.md`），但产品形态是**缝制袋体+吊装结构**，安全逻辑接近吊装带（见 `fabric/ropes-cords-lifting-slings.md`）。

## 一、结构与类型

| 部位 | 规格 | 要点 |
|:---|:---|:---|
| 袋身 | PP 扁丝圆织筒布/片布（140-220gsm）+涂膜可选 | 方型/圆型——拉筋（baffle）防鼓肚成方柱好堆码 |
| 吊带 | PP 高强织带（环吊/跨角吊/单提） | 承重核心——缝制回车结构定强力 |
| 进料口 | 裙口（skirt）/料嘴（spout）/全开口 | 配灌装设备对接 |
| 卸料口 | 料嘴+系绳/星型瓣口/全开口 | 卸料速度控制 |
| 内衬袋 | PE 薄膜内衬（防漏粉/防潮） | 食品级 PE（FDA 接触材料） |

**防静电等级分类（化工刚需知识）**：
| 类型 | 特性 | 应用 |
|:---|:---|:---|
| A 型 | 普通 PP——无静电防护 | 不燃物料（砂石/粮食） |
| B 型 | 防击穿布（击穿电压<6kV） | 干燥易燃粉尘（但无可燃气环境） |
| C 型 | 导电丝+**必须接地** | 易燃粉尘/溶剂蒸气环境（接地管理是客户责任） |
| D 型 | 静电耗散纤维（Crohmiq 类）——无需接地 | 易燃环境但免接地（高端溢价） |

- **安全系数**：**5:1=单次使用（出口主流）/6:1=可重复使用**——顶吊试验（额定载荷×系数保压）是出厂必检；
- **危险品认证**：UN 13H 系列（编织袋 UN 编码——装危险品需型式试验+性能证书）；食品级需 BRC/洁净车间（异物管控）。

## 二、生产工艺链

- **拉丝**：PP 粒子熔融挤出→膜片切割→**拉伸成扁丝**（拉伸倍数定强度——旦尼尔/强度指标）；混配 UV 母粒（户外堆放抗老化——UV 处理 200-1600 小时等级报价差异点）；
- **圆织**：六梭/八梭圆织机织筒布（织造背景见 `fabric/greige-fabric-weaving-mills.md`）——克重/密度（13×13-15×15 根/英寸）；
- **涂膜**：PE/PP 淋膜（防潮——20-30gsm 涂层）；印刷（柔性版 1-4 色——客户 logo/警示语/UN 标记）；
- **缝制**：吊带打枣回车（承重结构——断针管理见 `suppliers/needle-control-metal-management.md`）+袋身包缝；**缝线用高强涤纶/PP 线**（见 `suppliers/sewing-thread-needles.md`）；
- **检验**：顶吊试验/跌落试验（0.8-1.2m）/撕裂传递/UV 老化/堆码试验——**批次抽检报告随大货**（客户 IQC 依据）。

## 三、市场与出口要点

- **需求方**：水泥/化肥/塑料粒子（化工三巨头——中东/东南亚基建拉动）、食品（糖/盐/淀粉/咖啡豆——食品级内衬+洁净）、矿产（矿粉/萤石——耐磨加厚）、农业（种子/饲料）；
- **出口市场**：中东/非洲/南美（基建+农业——见 `customers-market/middle-east-market.md`、`customers-market/africa-market.md`）+欧洲（化工高标准——D 型袋需求）；
- **装柜**：空袋压缩打包（捆装/托盘）——**40HQ 装 4000-8000 条**（克重决定装载量——泡货逻辑见 `garments/reusable-shopping-bags-production.md` 同类）；
- **报价要素**：袋型尺寸/克重/吊带结构/内衬/印刷色数/UV 等级——**按条报价**（原料 PP 粒价格联动——期货套保见 `trade-process/commodity-futures-hedging.md`）；
- **认证与验厂**：UN 认证/食品级 BRC/ISO 21898（FIBC 国际标准）——客户验厂看拉丝-圆织-缝制一体产能+实验室（顶吊试验机）；
- **风险**：吊带断裂事故=重大责任（码头吊装伤人——产品责任见 `trade-compliance/product-liability-recall.md`）；海运受潮霉变（PE 内衬+集装箱干燥剂——见 `suppliers/warehouse-moisture-mold-prevention.md` 防潮逻辑）。
