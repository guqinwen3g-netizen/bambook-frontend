# 船帆面料与制帆（Sailcloth: Dacron 编织帆布/层压竞赛帆）

船帆面料是"**拉伸模量+保形性**"定胜负的海洋功能材料：帆形保持=航速——巡航帆求耐用（Dacron 编织），竞赛帆求轻量高模量（膜层压+高强纤维）。与船罩/遮阳帆同属海洋纺织（见 `garments/marine-yacht-textiles.md`），本文聚焦帆体材料与制帆工艺。

## 一、材料分层

| 材料 | 结构 | 应用 |
|:---|:---|:---|
| Dacron 编织帆布 | 聚酯平纹+树脂定型（fill-oriented 纬向加强） | 巡航帆主力——耐用 8-10 年 |
| 尼龙帆布 | 轻量 ripstop | 球帆（spinnaker——顺风轻量彩色） |
| 层压板 laminate | Mylar 膜+纤维网格（芳纶/碳纤/Dyneema） | 竞赛帆——轻量+零拉伸（寿命短 2-4 季） |
| 3DL 一体成型 | 纤维路径直接铺丝成膜 | 顶级竞赛（美洲杯级别） |
| 再生帆布 | 回收旧帆再造 | 环保叙事小件（帆布袋——Sea Bags 模式） |

- **关键指标**：**拉伸模量（保形——受力不鼓包变形）**、克重（oz/yard² 分级——风速匹配）、抗 UV、耐霉（湿热舱内存放）、撕破（缝线孔应力集中）；
- **帆索配套**：缭绳/升帆索（Dyneema 芯——见 `fabric/ropes-cords-lifting-slings.md`）。

## 二、制帆工艺

- **裁剪设计**：**radial 放射剪裁**（受力路径沿纤维方向——三角片从帆角放射排布）vs 横向剪裁（cross-cut——经济巡航）；CAD 排料（膜层压板按帆型定制幅宽）；
- **缝制**：**多行锯齿缝（zigzag）**——帆布接缝受力+可微弹缓冲；粗针大线（涤纶/PTFE 缝纫线——PTFE 线耐 UV 顶级但成本高，见 `suppliers/sewing-thread-needles.md`）；
- **附件**：帆角环（铜/不锈钢——液压铆接）、帆骨袋（batten pocket）、加强贴（层压补片——帆角应力区）、视窗（mono film 透明窗）、保护袋（UV cover——前帆卷帆器遮阳条）；
- **品控**：帆形检台平铺测量（设计吃水度 draft 核对）+试航。

## 三、市场与商业要点

- **需求结构**：新船 OEM 配套（帆船厂——法/德/意/美+中国代工船体增长）+**存量帆更换**（巡航帆 8-10 年/竞赛帆 2-4 季——稳定复购）+帆维修（撕裂缝补——帆装店 loft 模式）；
- **竞争格局**：帆装品牌（North Sails/Quantum/Doyle——设计与工艺软件壁垒）；**中国机会=Dacron 编织帆布材料供应+巡航帆代工**（竞赛层压板仍欧美主导）；
- **客户形态**：帆装店（loft——量体裁衣式定制——帆船型号数据库）/船厂/帆船学校/租赁船队（ charter 公司——耐用优先）；
- **区域**：地中海/加勒比/东南亚游艇季（见 `garments/marine-yacht-textiles.md` 区域逻辑）；中国帆船运动起量（青岛/厦门/深圳——国内俱乐部赛事）；
- **环保叙事**：再生帆（回收旧帆再造袋/配件——欧美消费者愿付溢价）——帆船文化圈层营销。

## 四、风控要点

- **质量责任**：帆失效（暴风撕裂）=航行安全事件——材料批次追溯+使用手册（风速等级标注）；
- **交期**：帆船季节性强（北半球春季备航——倒排冬季生产）；
- **海运**：帆折叠箱装（膜层压板**不可死折**——卷装运输）；
- **付款**：定制单 50% 定金惯例（帆船用品定制行业惯例）。
