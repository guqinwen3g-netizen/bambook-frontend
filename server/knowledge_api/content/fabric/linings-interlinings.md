# 里布与衬布专题（Linings & Interlinings）

里布（lining）与衬布（interlining）是"看不见的结构材料"：消费者看不到，但**衬布决定西装的骨、里布决定外套的滑**。辅料成本小但出问题整件报废。

## 一、里布（Lining）

### 品类
| 里布 | 特性 | 应用 |
|:---|:---|:---|
| 涤塔夫（polyester taffeta） | 190T/210T 常用；性价比 | 常规外套/棉服里布 |
| 美丽绸（twill lining） | 斜纹、滑爽、耐用 | 中高端西装/大衣 |
| 色丁（satin lining） | 光泽、华丽 | 礼服/高档女装 |
| 粘胶里布（viscose/acetate） | 吸湿透气、高级质感、易皱缩水 | 高档西装（宾霸 Bemberg 铜氨丝是顶级） |
| 网眼里布（mesh） | 透气 | 运动服/冲锋衣 |
| 摇粒绒/羊羔绒 | 保暖 | 冬装内里 |

### 质量要点
- **滑爽度**：里布核心功能（穿脱顺滑）——摩擦系数是关键指标；
- **抗静电**：化纤里布需抗静电处理（冬季贴腿尴尬）；
- **色牢度**：浅色面料配深色里布的沾色风险（耐汗/耐摩擦）；
- **尺寸稳定性**：里布缩水率需与面料匹配（里布缩水导致下摆起吊——常见低级质量事故）。

## 二、衬布（Interlining）

### 品类与用途
| 衬布 | 特性 | 应用 |
|:---|:---|:---|
| 有纺粘合衬 | 梭织基布+热熔胶点 | 西装胸衬/领衬/袖窿 |
| 无纺粘合衬 | 无纺基布、性价比高 | 衬衫领/袖口、裤腰 |
| 针织衬 | 弹性、随形 | 针织服装/弹力面料 |
| 黑炭衬（hair canvas） | 马尾/羊毛混织、高档 | 全毛衬西装（见 `garments/suits-tailoring-production.md`） |
| 领底呢（collar felt） | 绒面挺括 | 大衣/西装领底 |
| 垫肩（shoulder pad） | 棉/海绵/针刺棉 | 西装/大衣肩部造型 |

### 粘合衬工艺参数（质量事故高发区）
- **粘合三要素**：温度（130-160°C）+ 压力 + 时间（10-18 秒）——按衬布规格书设定压烫机参数；
- **剥离强度**：≥ 8N/5cm（水洗/干洗后保持）——起泡脱胶是粘合衬第一事故；
- **渗胶（strike-through）**：薄面料用细胶点衬（防胶点渗到正面）；
- **水洗/干洗兼容性**：干洗服装必须用耐干洗衬（PES 胶）——水洗衬用于水洗服装（PA 胶）。

## 三、选型决策表

| 服装部位 | 推荐衬布 |
|:---|:---|
| 衬衫领 | 无纺衬（硬挺度按领型） |
| 西装胸衬 | 有纺衬+黑炭衬（半毛/全毛衬工艺） |
| 裤腰 | 专用腰衬（防滑带） |
| 大衣前片 | 有纺粘合衬+胸绒 |
| 针织服装 | 针织衬（随形不板结） |
| 袖口/袋口 | 无纺衬（局部加固） |

## 四、采购与成本

- **品牌**：德国骏马（Kufner）/意大利衬布为高端；国产（佛山衬布集群）性价比主力；
- **成本占比**：衬布里布合计占成衣成本 3-8%（西装类 8-12%）——**小钱省不得**（衬布省 1 元，整件档次掉一级）；
- **配套性**：衬布克重/厚度与面料匹配（薄面料配薄衬）——供应商提供配套方案。

## 五、常见质量事故

| 事故 | 原因 |
|:---|:---|
| 洗后起泡 | 剥离强度不足/胶不耐洗 |
| 正面渗胶点 | 胶点过粗/压烫温度过高 |
| 下摆起吊 | 里布缩水率大于面料 |
| 领子软塌 | 领衬硬度不足/压烫不到位 |
| 静电贴腿 | 里布无抗静电处理 |
