# 纹理休闲面料专题（Textured Casual Fabrics）

纹理面料靠"**表面立体感**"取胜：灯芯绒的绒条、雪尼尔的绒感、泡泡纱的凹凸。这类面料季节性强（秋冬纹理是常青品类）。

## 一、灯芯绒（Corduroy）

### 工艺与规格
- **结构**：纬二重组织割绒形成绒条（wales）；
- **条数规格**：**条/英寸（wales per inch）**——细条（16-21 条）/中条（11-14）/粗条（4-8）；
- **成分**：棉为主 / 棉氨弹力 / 涤棉；
- **克重**：200-350gsm（裤装中条，衬衫细条）。

### 品质要点
- **绒条均匀**：割绒不齐（绒条高低）是主要疵点；
- **掉绒**：洗涤后绒条脱落（底布密度与割绒牢度）；
- **倒绒色差**：绒条倒向导致色差（裁剪需统一顺毛方向——倒顺毛排版）。

## 二、雪尼尔（Chenille）

- **结构**：雪尼尔纱（绒毛夹在芯纱间）织造——绒感厚实如"毛毛虫"；
- **应用**：毛衣/开衫（雪尼尔毛衫）、家纺（沙发面料/窗帘）；
- **品质**：掉毛（绒毛牢度——雪尼尔痛点）、钩丝；
- **搭配**：雪尼尔+金银丝（节日毛衫）。

## 三、泡泡纱（Seersucker）

- **结构**：双经轴织造（张力差异形成凹凸条纹/格子）——**免熨烫的夏凉面料**（凹凸结构减少贴肤面积）；
- **应用**：夏季衬衫/西装（美国南部绅士标配）、童装、床品；
- **成分**：棉/涤棉；色织条格经典（蓝白条是标志款）；
- **品质**：泡型均匀度（泡不起伏=工艺失败）、洗后泡型保持。

## 四、其他纹理面料

| 面料 | 特征 | 应用 |
|:---|:---|:---|
| 天鹅绒（velvet） | 割绒光泽华丽 | 礼服/西装领/家纺 |
| 平绒（velveteen） | 棉质短绒 | 童装/西装 |
| 提花布（jacquard） | 大提花立体花型 | 女装/家纺 |
| 皱布（crinkle） | 压皱/盐缩工艺 | 夏装 |
| 华夫格（waffle） | 蜂窝凹凸 | 浴袍/床品/打底衫 |
| 菠萝格/玉米粒 | 针织提花纹理 | 卫衣/休闲装 |

## 五、纹理面料的裁剪缝制注意

1. **倒顺毛**：灯芯绒/天鹅绒必须统一方向排版（顺毛光泽一致）——**单片裁剪或单向排料**；
2. **对条对格**：泡泡纱条格/灯芯绒绒条在口袋/门襟对位；
3. **压烫**：绒面面料不可重压（倒绒留印——蒸汽吊烫）；
4. **缝纫**：绒类厚度用较大针距+适当压脚压力。

## 六、检验要点

| 项目 | 说明 |
|:---|:---|
| 绒条/纹理均匀 | 目测+样照对照 |
| 掉绒掉毛 | 摩擦/洗涤测试 |
| 倒绒色差 | 排版方向核验 |
| 纬斜 | 纹理面料纬斜更明显（条格歪斜） |
| 色牢度 | 深色绒类湿摩擦 |

## 七、市场与采购

- **产业带**：灯芯绒（江苏常州/浙江）、雪尼尔（浙江杭州/绍兴）、泡泡纱（江苏南通色织集群）；
- **季节**：纹理面料秋冬单 5-7 月下单——提前备坯布；
- **趋势**：复古回潮（灯芯绒/天鹅绒 2020s 复兴——Y2K 风格带动）。
