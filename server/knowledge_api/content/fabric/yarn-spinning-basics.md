# 纱线与纺纱基础（Yarn & Spinning Basics）

纱线（yarn）是纤维与面料之间的关键环节：同成分面料，纱线支数/纺法不同，价格与品质差数倍。看懂纱线规格是面料采购的基本功。

## 一、纱支（Yarn Count）体系

### 定重制（数值越大越细）
| 单位 | 定义 | 应用 |
|:---|:---|:---|
| **英制支数（Ne/S）** | 1 磅纱长 840 码的倍数 | 棉纺通用（如 32S、40S） |
| **公制支数（Nm）** | 1 克纱长多少米 | 毛纺/麻纺（如 2/48Nm） |
| **号数（Tex）** | 1000 米纱重多少克（**数值越大越粗**） | 国标体系 |

### 定长制（数值越大越粗）
- **旦尼尔（Denier, D）**：9000 米纱重克数——化纤长丝用（如 75D、150D、300D）。
- 换算参考：Ne 与 Denier 换算 D ≈ 5315 ÷ Ne。

### 股线表示
- 32S/2 = 32 支双股；2/60Nm = 60 公支双股。
- **股线 vs 单纱**：股线强力高、条干匀、毛羽少——高档面料用股线（如 100S/2 衬衫料）。

## 二、纺纱工艺

| 工艺 | 特点 | 品质/成本 |
|:---|:---|:---|
| **环锭纺（ring spun）** | 传统主流，纱线结构紧密 | 品质基准 |
| **精梳（combed）** | 环锭纺+精梳去短绒 | 高支纱必备，价高 15-25% |
| **气流纺（OE, open-end）** | 高速低成本，纱线蓬松毛感 | 牛仔/低端针织，价低 10-20% |
| **赛络纺（siro spun）** | 双粗纱喂入仿股线效果 | 毛羽少，毛纺常用 |
| **紧密纺（compact）** | 环锭纺升级版，毛羽最少 | 高支高档 |
| **涡流纺（vortex）** | 高速、抗起球好 | 针织纱增长快 |

- **品质直觉**：同支数下 紧密纺/精梳 > 环锭纺 > 气流纺；OE 纱针织布手感粗犷但易起球。

## 三、棉纺规格速查

| 支数 | 定位 | 典型用途 |
|:---|:---|:---|
| 16S-21S | 粗支 | 牛仔、帆布、卫衣 |
| 26S-32S | 中支 | T 恤、针织常规 |
| 40S-60S | 中高支 | 高档 T 恤、衬衫、床品 |
| 80S-120S | 高支 | 商务衬衫、高支床品 |
| 140S+ | 超高支 | 奢侈衬衫 |

## 四、化纤长丝规格

- **DTY（低弹丝）**：针织/纬编主力（如 75D/72F——72F 指 72 根单丝，F 数高手感软）。
- **FDY（全拉伸丝）**：光滑长丝，里布/塔夫绸。
- **POY**：预取向丝（半成品，加弹厂加工 DTY）。
- **ATY（空气变形丝）**：仿棉感长丝。
- **单丝纤度（dpf）**：≤1D 为细旦（超细纤维/microfiber 手感丝滑）。

## 五、混纺与特种纱

- **混纺比**：T/C 65/35、CVC 60/40（棉为主）、T/R 65/35——混纺比写进合同，检测按溶解法/显微镜法（见 `trade-compliance/testing-standards.md`）。
- **色纺纱（melange/heather）**：纤维染色后纺纱（麻灰效果），比匹染贵但色牢度好、风格独特。
- **花式纱**：竹节纱（slub）、圈圈纱（boucle）、大肚纱——时尚面料设计元素。
- **包芯纱（core-spun）**：氨纶芯+棉/涤外包——弹力面料的纱线形式（如棉包氨 40S+40D）。

## 六、纱线质量指标

| 指标 | 说明 |
|:---|:---|
| 条干 CV% | 粗细均匀度（越低越好，乌斯特 Uster 统计公报对标） |
| 强力（cN/tex） | 断裂强度 |
| 毛羽 H 值 | 影响起球与织造效率 |
| 棉结/杂质 | 每克粒数 |
| 捻度（twist） | 捻系数影响手感与强力 |

- 采购索样：纱线乌斯特条干报告 + 强力报告；高档面料指定"乌斯特 25% 水平"（优于全球 75% 产能）。

## 七、采购要点

1. **报价三要素**：成分 + 支数 + 纺法（如"精梳紧密纺 40S"）。
2. **纱价跟踪**：棉纱期货（郑商所 CF）+ 32S 现货指数——棉价波动传导纱价约 2-4 周滞后。
3. **起订量**：常规品种 1 吨起；定纺品种（特殊支数/混纺比）5-10 吨起。
4. **交期**：常规 7-15 天；定纺 20-30 天。
