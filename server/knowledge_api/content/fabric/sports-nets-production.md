# 运动网具生产（Sports Nets: 球门网/网球网/高尔夫练习网/场地围网）

运动网具是"**结网工艺+耐冲击配方**"的体育器材配套品类：从标准赛事网（尺寸/网目规则化）到家庭后院练习网（亚马逊大热）。结网技术与渔网同源（见 `fabric/fishing-nets-aquaculture-nets.md`），差异在**冲击载荷与赛事规格**。

## 一、产品矩阵

| 产品 | 材料 | 规格要点 |
|:---|:---|:---|
| 足球门网 | PE 有结网（线径 3-5mm，网目 10-12cm） | FIFA 球门尺寸配套；六角网目（外观） |
| 网球网 | PE/PP 编织带+网体（网目 4cm） | 标准 12.8×1.07m——顶带白帆布+钢丝绳 |
| 排球/羽毛球网 | 尼龙/PE | 标准尺寸——边带+标志杆 |
| 高尔夫练习网 | 高强 PE/涤纶（线径 2-3mm 加密） | **击球冲击吸收**——网架配套（家庭后院爆款） |
| 棒球/垒球挡网 | PE 有结（加重型） | 击球笼/投手网 |
| 篮球网 | 涤纶/尼龙编织（链网高端） | 标准 12 扣 |
| 场地围网/分隔网 | PE 无结网（大网目） | 球场围护（定制高度长度） |
| 多功能训练网 | 组合式（反弹网/目标网） | 家庭训练市场 |

## 二、材料与工艺

- **有结 vs 无结**：有结网（knotted——强力高/经济）vs 无结网（knotless——轻量/外观好/应力分布均匀）——高尔夫/棒球冲击场景用有结加粗；
- **编织工艺**：经编网（raschel——无结网主流）/有结网机（结型：单结/双结——死结防滑脱）；
- **定型**：热定型（网目尺寸稳定）+拉伸定型（线径圆整）；
- **抗 UV**：户外网具**UV 母粒 2-3%**（3-5 年户外寿命——粉化脆断是失效模式）；
- **配件**：顶带（帆布/PVC 包边带）、钢丝绳（镀锌/包塑——两端索具压制）、边带织带（见 `fabric/webbing-narrow-fabrics.md`）、穿绳；
- **检验**：网目尺寸公差、断裂强力（单线/结点）、外观（脱结/断丝）。

## 三、市场与商业要点

- **赛事/机构**：FIFA/FIVB 等赛事规格网（标准尺寸文件化）+学校体育器材集采（开学季脉冲——国内教育装备招标）；
- **家庭训练**：**亚马逊高尔夫练习网/足球反弹网**——套装逻辑（网+架+目标靶+收纳包）；差评热点：网面被击穿（线径虚标）、架管弯曲、安装说明不清；
- **场地工程**：球场围网随场地建设（与人造草坪打包投标——见 `fabric/artificial-turf-production.md` 场地系统）；
- **区域**：欧美家庭体育（后院文化）+东南亚/中东足球基建+拉美足球全民化；
- **季节**：北半球春季（3-5 月）上架旺季——倒排 12-2 月出货；
- **延伸**：宠物围栏网/儿童安全网（阳台防护——建筑安全网交叉）、农用防鸟网（见 `fabric/technical-agro-geo-textiles.md`）。

## 四、风控要点

- **安全责任**：练习网被击穿=高速球体伤人风险——**线径/强力实标+警示说明**（"非专业拦截用途"边界声明）；儿童产品防缠绕风险（网目尺寸安全——见 `trade-compliance/cpsc-children-safety.md` 逻辑）；
- **虚标重灾区**：线径/克重虚标是类目顽疾——实标+检测报告显示=差异化竞争力；
- **装柜**：网具抛货（体积大重量轻）——压缩打包+与网架分箱（套装匹配唛头）；
- **知识产权**：训练网结构专利（反弹角度机构）——亚马逊专利投诉高发品类（自查见 `trade-process/overseas-trademark-registration.md` 关联检索）。
