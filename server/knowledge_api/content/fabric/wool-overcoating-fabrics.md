# 大衣呢面料专题（Overcoating: 麦尔登/双面呢/羊绒呢/羊驼/后整理风格）

大衣呢（overcoating）是粗纺毛纺的重头赛道：克重 380-600g/m² 的厚重呢料，靠**原料等级（羊绒含量）与后整理风格（顺毛/水波纹/立绒）**拉开十倍价差。成衣制造见 `garments/wool-coat-production.md`，羊毛原料见 `fabric/wool-cashmere-fabrics.md`——本文件聚焦**面料开发、风格体系与贸易要点**（服务 Max Mara 风格大衣/高端正装客户）。

## 一、经典品种谱系

| 品种 | 特征 | 风格定位 |
|:---|:---|:---|
| 麦尔登（melton） | 重缩绒短顺毛、呢面丰满挺括 | 经典切斯特菲尔德大衣/军装风 |
| 双面呢（double-faced） | 双层织合可剖缝、两面同色或异色 | **无里布手缝大衣的唯一选料**——高端分水岭 |
| 羊绒呢（cashmere overcoating） | 羊绒 10-100% 梯度、轻暖柔 | 奢侈大衣（Max Mara 101801 即羊绒羊毛混纺） |
| 阿尔巴卡（alpaca blend） | 羊驼毛长纤维、光泽毛流感 | 廓形大衣——**掉毛是客诉命门** |
| 水波纹（moiré/水波呢） | 压波纹后整理、光线下波纹流动 | 女式礼服大衣 |
| 人字呢/千鸟格（houndstooth） | 色织格纹 | 英伦复古——格纹对格工艺消耗大 |
| 法兰绒（flannel） | 轻缩绒柔糯 | 薄大衣/裙裤两用 |

## 二、开发要点（原料×整理的组合游戏）

- **羊绒含量梯度定价**：10%（可标羊绒混纺）→30%（手感质变点）→100%（奢侈级）——**含量检测（纤维镜检/近红外）是验收必备**（虚标 5% 即退货级纠纷）；
- **双面呢织法**：双层接结组织——**接结强度与剖缝便利性反向相关**（接太牢剖缝断纱，接太弱穿着开层）——打样时剖缝测试先行；
- **顺毛 vs 立绒**：顺毛（绒面向一侧倒伏，光泽好）vs 立绒（绒面挺立，保暖好）——同坯布不同整理路线，**开发期就要锁定风格**；
- **克重与季节**：北方市场 480-600g、南方/春秋 320-420g——**轻薄化是近年趋势**（室内暖气+叠穿文化）；
- **色织格纹的纱线备料**：千鸟格/窗格需色纱备纺——**色纱 MOQ 推高开发成本**，格纹大衣报价含纱线损耗溢价。

## 三、贸易与品控要点

- **产区格局**：江苏（阳光/海澜系供应链）/浙江（桐乡/绍兴）/山东（如意）——高端双面呢手工配套集中在江浙（手缝女工资源，见 `garments/wool-coat-production.md`）；
- **呢面疵点检验**：缺纱/呢粒/草刺（粗纺原料带草杂）/水印——**深色呢面检验用侧光**（四分制见 `fabric/fabric-inspection-4point.md`）；
- **脱毛测试**：羊驼/兔毛混纺必做（干摩擦+胶带粘附）——**阿尔巴卡大衣掉毛毁掉品牌的案例年年有**；
- **缩率控制**：蒸呢预缩后复测经纬缩率 ≤3%——**大衣裁片长，缩率超标导致下摆波浪**；
- **起订与交期**：素色呢 300m/色起织、色织 500m+——交期 45-60 天（含备纱）；**大衣季节刚性（9-11 月零售）倒排面料 7 月前到厂**（采购日历见 `trade-process/annual-sourcing-calendar.md`）；
- **库存料机会**：意大利/国产尾货大衣呢（每季 10-20% 尾量）——**尾货淘料是中小品牌大衣线的成本武器**（尾货逻辑见 `fabric/fabric-inventory-stock-strategy.md`）。
