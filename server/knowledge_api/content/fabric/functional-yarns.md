# 功能性纱线专题（Functional Yarns）

功能性纱线是面料差异化的源头：功能在纺纱阶段植入（原纱功能）比后整理助剂更耐久——"永久抗菌""原纱防晒"的卖点都来自纱线层。

## 一、功能植入两大路径

| 路径 | 原理 | 耐久性 | 成本 |
|:---|:---|:---|:---|
| 原纱改性 | 纺丝液添加功能母粒（涤/锦熔纺）或纤维改性 | 永久（洗 50 次+ 保持） | 高（MOQ 1-3 吨） |
| 后整理 | 面料浸轧功能助剂 | 30-50 次洗涤衰减 | 低（小批量灵活） |

**卖点话术对应**："永久 XX"必须原纱路线（后整理宣称永久=虚假宣传风险）。

## 二、主流功能纱线

### 1. 抗菌纱
- **银系**：纳米银/银离子（抗菌率 99%——广谱抗菌主流）;
- **锌系/铜系**：氧化锌/铜离子（成本低于银——铜氨纤维有铜绿风险）;
- **壳聚糖**：天然抗菌（蟹壳提取——营销概念好，耐洗性一般）;
- **标准**：GB/T 20944 / AATCC 100 / ISO 20743（抗菌率≥99% 宣称抗菌——AAA 级抗菌洗 50 次后仍≥80%）;
- **应用**：内衣/袜子/运动服（消臭概念——日本市场标配）。

### 2. 凉感纱
- **玉石/云母粉**：矿物微粒导热（接触凉感 Q-max≥0.15 可宣称）;
- **木糖醇整理**：吸湿放热反应反向（后整理路线）;
- **应用**：夏季 T 恤/防晒衣（见 `garments/sun-protection-clothing.md`）/床品。

### 3. 发热纱
- **吸湿发热**：纤维吸湿放热（日本东丽 Softwarm/优衣库 HEATTECH 原理——腈纶+粘胶混纺）;
- **远红外**：陶瓷微粒辐射（促进微循环概念——检测发射率≥0.8）;
- **应用**：保暖内衣（冬季"自发热"卖点——升温 2-4℃ 实测）。

### 4. 其他功能纱
- **导电纱**：不锈钢纤维/碳纤维混纺（防静电工装/触摸屏手套——见 `garments/workwear-uniform-production.md`）;
- **阻燃纱**：本质阻燃纤维（芳纶/阻燃腈纶/阻燃粘胶——消防服/防护服，后整理阻燃洗后衰减）;
- **防紫外纱**：TiO₂ 母粒（UPF 原纱——见防晒衣）;
- **吸湿排汗纱**：十字截面涤纶（Coolmax 类——沟槽芯吸）。

## 三、花式纱线（时尚维度）

- **圈圈纱/大肚纱/竹节纱**：肌理感（针织毛衣花型——见 `garments/knitwear-sweater-production.md`）;
- **马海毛/羊驼毛风格**：长毛羽纱（花式纱机仿制——成本远低于真毛）;
- **段染纱**：一段纱多色（织出渐变效果——无需印花）;
- **包芯纱**：氨纶包芯（弹力——见 `fabric/nylon-spandex-stretch-fabrics.md`）/金属丝包芯（闪光）。

## 四、采购与验证

- **品牌纱**：东丽/晓星/英威达功能纱有授权吊牌（纱厂→面料厂→成衣厂吊牌链传递——合同写吊牌配额）;
- **检测报告**：功能性必索第三方报告（且是**成衣面料**送检——纱线报告≠面料性能）;
- **洗后复测**：功能持久性验证（客户标准洗 20/50 次后功能保持率）;
- **起订量**：原纱功能 MOQ 高（1-3 吨纱≈3-8 千米布——小单用后整理替代）。

## 五、宣称合规

- **功能宣称需检测背书**（见 `trade-compliance/testing-standards.md`）;
- **"抗菌"≠"医疗"**：不得宣称治疗功效（广告法红线）;
- **成分标注**：功能纤维含量如实标注（见 `trade-compliance/textile-fiber-names-regulation.md`）。
