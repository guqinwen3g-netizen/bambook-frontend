# 梭织面料专题（Woven Fabrics）

梭织（woven）面料由经纱（warp）与纬纱（weft）垂直交织而成，结构稳定、挺括有形、不易变形，是衬衫、西装、裤装、外套、牛仔等品类的载体。外贸中"woven garment"与"knit garment"是两大基本订单类别。

## 一、三大基本组织

| 组织 | 英文 | 结构特征 | 典型面料 |
|:---|:---|:---|:---|
| 平纹 | plain weave | 经纬一上一下，最紧密 | 府绸、牛津纺、雪纺 |
| 斜纹 | twill weave | 连续斜向纹路（2/1、3/1） | 斜纹布、卡其、牛仔 |
| 缎纹 | satin weave | 浮线长、光泽柔滑 | 色丁/贡缎 |

## 二、常见梭织面料品种

### 衬衫类
- **府绸（poplin）**：高支高密平纹，细腻挺括，正装衬衫首选。常见 40S×40S/133×72。
- **牛津纺（oxford）**：平纹变化组织，颗粒感、休闲衬衫/校服。分精梳/普梳、纯色/色织（yarn-dyed）。
- **青年布（chambray）**：色经白纬平纹，类牛仔外观但更轻薄。

### 裤装/外套类
- **斜纹布（twill）**：2/1 或 3/1 斜纹，耐磨挺括，工装裤/休闲裤。
- **卡其（khaki/drill）**：粗斜纹棉布，工装与制服。
- **哔叽/华达呢（serge/gabardine）**：精梳斜纹，西装裤、风衣。
- **桃皮绒（peach skin）**：磨毛处理表面桃绒感，夹克/沙滩裤。

### 女装类
- **雪纺（chiffon）**：轻薄透明平纹（涤纶仿真丝为主），连衣裙/丝巾。
- **色丁（satin）**：缎纹光泽面，晚装/睡衣/里料。
- **乔其纱（georgette）**：强捻绉效应，垂坠飘逸。
- **双绉（crepe de chine）**：真丝或仿真丝绉类。

### 牛仔（denim）
- 靛蓝染色经纱 + 本白纬纱的 3/1 斜纹。
- 规格按盎司（oz/yd²）：6-8oz 薄款（衬衫）、10-12oz 常规裤装、13oz+ 重磅。
- 工艺：水洗（stone wash/enzyme wash）、猫须（whisker）、做旧（vintage）。

### 里料/功能类
- **涤塔夫（polyester taffeta）**：平纹里料/防绒布。
- **春亚纺（pongee）**：轻薄里料/羽绒服面里通用。
- **尼丝纺（nylon taffeta）**：锦纶平纹，羽绒服/风衣面料。
- **塔斯隆（taslan）**：锦纶/涤纶空变丝，耐磨户外感。

## 三、关键规格参数

| 参数 | 说明 | 示例 |
|:---|:---|:---|
| 纱支密度 | 经纱×纬纱 / 经密×纬密 | 40S×40S 133×72 |
| 克重 | GSM 或 oz/yd²（牛仔） | 府绸 110-130 GSM |
| 幅宽 | 梭织常规 57/58"（145cm） | 43/44"、57/58" |
| 组织 | 平纹/斜纹/缎纹及变化 | 2/1 斜纹 |
| 成分 | 棉/T/C/CVC/全涤/人棉 | 65% Polyester 35% Cotton |

## 四、梭织面料特性要点

- **脱边（fraying）**：裁剪边缘纱线脱落，需锁边/包缝。
- **纬斜（skew/bowing）**：纬纱歪斜，格仔/条子布尤其敏感，客户常要求 ≤ 3%。
- **缩率**：经向缩率通常大于纬向；未经预缩（sanforized）的棉布可达 5-8%，下单需注明防缩要求。
- **色织（yarn-dyed） vs 染色（piece-dyed）**：色织先染纱后织布（格仔/条子），价格高、交期长；匹染后染布身，快而便宜。
- **印花白底/半漂**：印花用布需退浆精练到位，否则上色不匀。

## 五、采购与报价要点

1. **报全规格**：成分 + 纱支密度 + 组织 + 克重 + 幅宽 + 工艺（如"T/C 65/35 45×45 133×72 57/58\" 漂白"）。
2. **密度实测**：客户验布用密度镜（pick glass）数纱，虚报密度是常见纠纷点。
3. **坯布溯源**：梭织产业链长（纺纱→织造→染整），确认供应商是织造厂还是贸易商。
4. **起订量**：染色布 500-1000m/色；色织布 2000-3000m 起；印花加版费（圆网约 300-500 元/套色）。
5. **盛泽/柯桥分工**：坯布看盛泽，成品色布看柯桥（详见 `suppliers/fabric-market-sourcing.md`）。
