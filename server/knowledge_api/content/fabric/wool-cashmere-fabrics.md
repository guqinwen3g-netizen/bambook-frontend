# 羊毛与羊绒面料专题（Wool & Cashmere Fabrics）

羊毛（wool）与羊绒（cashmere）是高档服装的核心动物纤维面料，单价高、订单金额大、质量争议多。掌握支数、克重、成分检测是接单基本功。

## 一、原料分级

### 羊毛
- **美利奴（merino）**：最优质羊毛，按细度分级——超细 ≤17.5μm、细 17.6-19.5μm、中 19.6-22.5μm。细度每降 1μm 价格显著跳升。
- **支数（super number）**：Super 100s / 120s / 150s / 180s——数值越高纤维越细、面料越柔、价格越贵。Super 120s 以上属高档西装料。
- 产地：澳大利亚（最大美利奴产地）、新西兰、南非、中国（新疆/内蒙）。

### 羊绒
- 来自山羊（cashmere goat）底层绒毛，细度 14-16μm，产量极低（每只山羊年产绒约 150-250g）。
- 中国内蒙古占全球羊绒产量约 70%，鄂尔多斯为产业中心。
- **分级**：按细度与长度——一级绒 ≥ 15μm/34mm+；原绒（raw）→ 无毛绒（dehaired）→ 羊绒纱。
- 警惕掺假：绵羊毛/丝光羊毛冒充羊绒，需显微镜或 DNA 检测鉴别。

## 二、精纺 vs 粗纺

| 维度 | 精纺（worsted） | 粗纺（woollen） |
|:---|:---|:---|
| 工艺 | 精梳去短绒，纱线光洁 | 不经精梳，绒面丰满 |
| 外观 | 平滑挺括、纹路清晰 | 绒面、松软、保暖 |
| 典型面料 | 哔叽、华达呢、凡立丁 | 麦尔登、法兰绒、粗花呢 |
| 用途 | 西装、正装裤 | 大衣、休闲外套 |
| 克重 | 200-320 g/m | 350-600 g/m |

### 常见品种
- **哔叽（serge）**：2/2 斜纹精纺，西装主力。
- **华达呢（gabardine）**：陡斜纹紧密，风衣/裤装。
- **凡立丁（valitin/平纹精纺）**：轻薄夏季西装。
- **麦尔登（melton）**：粗纺缩绒，厚实大衣料。
- **法兰绒（flannel）**：轻绒面，衬衫/休闲西装。
- **粗花呢（tweed）**：花式纱粗纺，英伦风格。
- **双面呢（double-face）**：两层织合可剖缝，高档大衣（手工剖缝工时高）。

## 三、针织羊毛

- **羊毛衫（knitwear）**：横机针织，支数如 2/26Nm、2/48Nm（Nm 数值越大纱越细）。
- 工艺：全成形（fully-fashioned，高档）vs 裁片缝合（cut & sew）。
- 羊绒衫常见 12G/14G/16G 针型，G 数越高越轻薄细腻。

## 四、关键质量指标

1. **成分检测**：羊毛含量（Woolmark 认证背书）；羊绒国标 GB 18267 要求羊绒 ≥ 95% 方可标纯羊绒。
2. **起球**：羊毛天然起球，精纺优于粗纺；抗起球整理可提升 1-1.5 级。
3. **缩绒性（felting）**：羊毛遇水热+摩擦毡缩——机可洗（machine washable）需丝光/树脂防缩处理（superwash）。
4. **虫蛀（moth）**：仓储需防蛀处理（防蛀剂需符合 REACH）。
5. **色牢度**：深色呢绒摩擦牢度是痛点，订单注明等级要求。

## 五、采购与报价要点

- **报价三要素**：成分（如 100% merino / 70W30P 混纺）+ 支数/细度 + 克重。
- **混纺降本**：羊毛/涤（W/P）、羊毛/羊绒混（降低成本但维持手感）。
- **起订量**：精纺呢绒 1000-1500m/色；羊绒衫 300-500 件/色。
- **交期**：羊毛面料 45-75 天（原料采购周期长），比棉化纤长一倍，订单计划前置。
- **检测**：纤维含量送第三方（显微镜法/溶解法），高档订单附 Woolmark 或 Cashmere and Camel Hair Manufacturers Institute 标识授权。
