# 功能性面料与测试标准（Functional Fabrics & Testing）

功能性面料（functional fabric）是在基础服用性能之外，通过纤维改性、组织结构或后整理赋予特殊功能的面料，广泛用于运动、户外、防护与家纺品类。外贸沟通中客户常以功能点询盘，须明确**功能宣称—测试标准—判定阈值**三者对应关系，避免虚假宣传风险。

## 一、防护类功能

### 防水（Waterproof / Water Repellent）
- **防泼水/沾水（water repellency）**：表面抗润湿。GB/T 4745、AATCC 22、ISO 4920，喷淋评级 0-5 级，5 级最优。
- **抗静水压（hydrostatic pressure）**：抗渗水。GB/T 4744、AATCC 127、ISO 811，单位 mmH₂O，数值越高防水越强。冲锋衣常要求 ≥10,000 mmH₂O。
- **防水透湿复合（waterproof & moisture permeable）**：GB/T 40910-2021 为防水透湿评价标准；涂层/贴膜（coating/lamination，如 PU、TPU、ePTFE）实现。

### 防紫外线（UV Protection / UPF）
- 标准：GB/T 18830、AATCC 183、AS/NZS 4399、EN 13758。
- 判定：**UPF＞40 且 UVA 透过率＜5%** 方可标注"防紫外线产品"；UPF 50+ 为高等级。
- 应用：防晒服（sun protection clothing）、遮阳面料。

### 阻燃（Flame Retardant / FR）
- 垂直燃烧：GB/T 5455、ISO 15025、EN ISO 11612（防护服），测续燃时间、阴燃时间、损毁长度。
- 极限氧指数（LOI）：GB/T 5456，LOI＞27% 为难燃。
- 美国儿童睡衣强制阻燃：16 CFR 1615/1616（CPSC）。
- 应用：防护服、工装、窗帘、儿童睡衣。

### 抗静电（Anti-static）
- 标准：GB/T 12703 系列、EN 1149、AATCC 76，测表面电阻率/电荷密度。
- 判定：电荷密度＜7μC/m²、表面电阻 10⁶-10¹¹Ω 为抗静电。
- 应用：电子厂无尘服、防爆区工装。

## 二、舒适体感类功能

### 吸湿速干（Moisture Wicking / Quick Dry）
- 标准：GB/T 21655.1（单项法）、GB/T 21655.2（动态法）。
- 核心指标：滴水扩散时间、芯吸高度、蒸发速率；**洗前洗后均须达标**方可宣称。
- 应用：运动 T 恤、速干衣、瑜伽服。

### 接触凉感（Cool Touch / Q-max）
- 标准：FZ/T 73067-2020，热板法测最大热流密度 qmax。
- 判定：**qmax≥0.15 J/(cm²·s)** 有凉感，越高越凉。
- 应用：夏凉被、凉感内衣、冰丝面料。

### 透气与透湿（Air Permeability / MVTR）
- 透气率：GB/T 5453、ASTM D737，单位 mm/s 或 CFM（防风要求 CFM≤1）。
- 透湿量（MVTR）：GB/T 12704、JIS L 1099、ASTM E96，单位 g/m²·24h。
- RET 值（ISO 11092）：蒸发阻力，RET<6 为高透湿（户外高端）。

### 保暖（Thermal Insulation）
- 标准：ISO 11092、JIS L 1096，测热阻（克罗值 clo）与保暖率。
- 远红外发热（far-infrared）：宣称须对应温升值测试报告。
- 应用：冬装、羽绒服、睡袋。

## 三、卫生类功能

### 抗菌（Antibacterial / Anti-microbial）
- 标准：GB/T 20944.3（振荡法）、FZ/T 73023（针织抗菌内衣）、ISO 20743、AATCC 100。
- 菌种：金黄色葡萄球菌、大肠杆菌、白色念珠菌。
- 判定：抑菌率≥90%（优等）、≥80%（一等）；宣称"高效抗菌"通常＞99%。
- 注意：欧美对生物杀菌剂宣称有法规限制（欧盟 BPR、美国 EPA/FIFRA），抗菌宣称须谨慎。

### 防螨与防霉（Anti-mite / Anti-mold）
- 防螨：GB/T 24253，测驱避率/死亡率，用于家纺床品。
- 防霉：ISO 846、GB/T 24346，长霉等级 0-3 级。

### 消臭（Deodorant）
- 标准：GB/T 33610 系列，测对氨气、醋酸、异戊酸的去除率。

## 四、耐用易护理类功能

### 抗起球（Anti-pilling）
- 标准：GB/T 4802.1、ISO 12945、ASTM D4970，圆轨迹/马丁代尔法，1-5 级，≥4 级为优。

### 防污易去污（Stain Release / Soil Release）
- 拒油：GB/T 19977、AATCC 118，油滴评级 0-8 级。
- 易去污：FZ/T 01118、AATCC 130。

### 三防整理（Triple-proof Finish）
- 拒水+拒油+防污（water/oil/stain repellent），常用氟系（C6/C8）或无氟（fluorine-free）整理剂。
- **合规警示**：C8 含 PFOA/PFOS 已被多国禁用（欧盟 POPs 法规、美国多州 PFAS 禁令），出口订单普遍要求 **C6 或无氟三防**，并索取 PFAS 检测报告。

## 五、功能宣称沟通要点

| 客户宣称 | 必问问题 | 对应证据 |
|:---|:---|:---|
| waterproof | 防泼水还是静水压？要求多少 mmH₂O？ | GB/T 4744 / AATCC 127 报告 |
| breathable | 透湿量多少？RET 要求？ | GB/T 12704 / ISO 11092 |
| quick dry | 洗后几次仍达标？ | GB/T 21655.1 洗前/洗后数据 |
| UPF 50+ | 是否要求第三方报告？ | GB/T 18830 / AS/NZS 4399 |
| antibacterial | 哪个市场？宣称用词限制？ | ISO 20743 + 目的国法规评估 |
| flame retardant | 用途（睡衣/工装/家纺）？ | 对应强制标准报告 |

> **报价提示**：功能整理通常增加面料成本 5%-20%（视工艺），且多数功能有耐洗次数（如 20 次/50 次水洗后仍达标）要求，订单确认时须写明耐洗次数与测试标准，作为验货依据。
