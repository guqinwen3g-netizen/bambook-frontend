# 面料开发流程（Fabric Development Process）

面料开发是从"趋势概念"到"大货面料"的完整链路，周期 2-6 个月。开发能力是从"卖现货"升级为"做方案"的核心竞争力——**差异化面料 = 议价权**。

## 一、开发全流程

```
趋势输入 → 概念设计（成分/组织/克重）→ 纱线/胚布开发 → 手织样（handloom）
→ 染色打样（lab dip）→ 大样（meter sample）→ 成衣样验证 → 封样 → 大货
```

| 阶段 | 产出 | 周期 |
|:---|:---|:---|
| 手织样（handloom） | 巴掌大组织样（看纹理/配色） | 3-7 天 |
| 缸样（lab dip） | 颜色小样确认 | 5-10 天（返修 2-3 轮常见） |
| 大样（strike off / meter sample） | 1-5 米（看成衣效果） | 2-3 周 |
| 船样确认 | 大货首批比对 | 出货前 |

## 二、开发方向决策

### 1. 趋势驱动
- 输入源：PV 展/米兰 Unica/Intertextile 面辅料展、WGSN 趋势报告（见 `customers-market/fashion-trend-forecasting.md`）；
- 提前量：面料开发领先成衣季 **12-18 个月**（2027 春夏面料 2025 秋启动）。

### 2. 客户驱动
- 品牌来样（counter development）：分析成分/组织→逆向打样→报价；
- 联合开发：与品牌设计师共创新面料——签排他协议保护（花型/配方）。

### 3. 功能驱动
- 需求倒推：如"UPF50+ 凉感衬衫面料"→ 选纤维（凉感锦纶）→ 组织（高密平纹）→ 后整（抗 UV 整理）→ 检测验证。

## 三、关键技术决策

| 决策 | 考量 |
|:---|:---|
| 成分方案 | 成本 vs 性能 vs 可持续性（再生/有机加分） |
| 组织规格 | 纱支×密度×克重三联动（改一个全变） |
| 染色方案 | 色纺（色牢度好/起订量大）vs 匹染（灵活） |
| 后整理 | 功能整理的成本与耐洗次数权衡 |
| 起订量 | 定织面料 MOQ 通常 3000-5000m/色——开发前先确认客户量级 |

## 四、开发成本与风险控制

- **开发成本**：手织样 500-2000 元/款；大样 2000-5000 元/款（织厂开机费）；全季开发 10-20 款需 5-10 万预算；
- **开发失败率**：行业惯例 30-50% 开发款最终无单——**开发预算 = 获客成本**，需向客户收取开发费或约定下单返还；
- **知识产权**：自主开发花型/组织留创作记录；客户来样开发注意原样 IP 归属。

## 五、开发协作管理

- **打样进度表**：每款面料跟踪表（阶段/负责人/期限/状态）；
- **客户确认节点**：手织样 → 色样 → 大样三级确认，每级书面签样（邮件确认留痕）；
- **打样提速**：与织厂/染厂建"快样通道"（插单打样 3 天出）——快反竞争的基础设施；
- **开发库管理**：历史开发样分类存档（可复用的组织/配方避免重复开发）。

## 六、与大货的衔接

- **封样（sealed sample）**：大样确认后封样三份（双方+检测机构）——大货品质基准；
- **技术文件转移**：开发参数（纱支/密度/工艺单）移交生产环节（见 `fabric/fabric-procurement-quality-agreement.md` 规格条款化）；
- **首缸大货验证**：首缸面料全项检测+成衣试制——确认与封样一致再放量。
