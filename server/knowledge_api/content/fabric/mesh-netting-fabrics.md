# 网布与网眼面料专题（Mesh & Netting Fabrics）

网布（mesh）是"结构透气"的功能面料：从运动鞋面到背包背垫到反光背心，**透气、轻量、可视性**是其核心价值。

## 一、品类矩阵

| 品类 | 工艺 | 特征 | 应用 |
|:---|:---|:---|:---|
| 经编网布（tricot mesh） | 经编机 | 轻、透、弹性小 | 运动服内衬/里布 |
| 三明治网布（spacer fabric） | 双针床经编（两面+中间连接丝） | 3-10mm 厚度、缓冲透气 | 鞋面/背包背垫/座椅/文胸模杯 |
| 珠地网眼（pique） | 针织纬编 | 凹凸网眼 | POLO 衫（见 `fabric/knitted-fabrics.md`） |
| 蚊帐网/六角网 | 经编 | 细密 | 帐篷/防护 |
| 弹力网布（power mesh/net） | 锦氨经编 | 高弹贴身 | 内衣/塑身衣/舞蹈服 |
| 荧光网布 | 高强涤纶+荧光染 | 高可视 | 反光背心（见 `garments/workwear-uniform-production.md`） |

## 二、三明治网布深度（最高技术含量）

- **结构**：上下两网面 + 中间单丝支撑层——厚度 3-10mm 可调；
- **功能**：透气（空气流通层）+ 缓冲（单丝回弹）+ 透湿——鞋面/背包/汽车座椅的"会呼吸的海绵"；
- **参数**：克重（200-800gsm）、厚度、单丝密度（决定支撑性）；
- **应用**：运动鞋面（轻量透气）、背包背垫（减压透气）、文胸模杯（三明治替代海绵——不易黄变）、办公椅（人体工学椅全网布趋势）。

## 三、关键规格参数

| 参数 | 说明 |
|:---|:---|
| 网眼密度（目数/孔径） | 透气性与遮蔽性的权衡 |
| 克重 | 轻量（<100gsm）到厚重（500+gsm 三明治） |
| 成分 | 涤纶（耐用）/锦纶（柔软耐磨）/锦氨（弹力网） |
| 幅宽 | 常规 1.5-1.8m |
| 弹性 | 经向/纬向伸长率（弹力网布四向弹） |

## 四、应用场景与采购

| 场景 | 选型 |
|:---|:---|
| 运动服内衬 | 经编网布（轻量透气导湿） |
| 鞋面 | 三明治网布（+热熔膜贴合支撑） |
| 背包背垫/肩带 | 厚三明治（缓冲） |
| 内衣/塑身 | 锦氨弹力网（贴身透气） |
| 反光背心 | 荧光网布+反光条 |
| 婴童床围 | 细密网布（防夹+透气） |

- **产业带**：福建长乐（经编网布集群——与蕾丝同源的经编产业）、浙江绍兴/海宁。

## 五、质量检验要点

1. **网眼均匀度**：稀密路（knitting defect——局部网眼大小不一）；
2. **克重/厚度**：三明治厚度公差 ±0.3mm；
3. **弹性回复**（弹力网）：拉伸回复率（塑身应用核心）；
4. **色牢度**：荧光色网布的日晒牢度（反光背心 ANSI 色牢度要求）；
5. **勾丝**：网布易勾丝（snagging test）——鞋面/背包耐磨场景必测。

## 六、趋势

- **一体织鞋面**（flyknit 式）：网布与鞋面一体成型（减少裁剪缝制）；
- **可持续**：再生涤纶网布（鞋服品牌可持续线）；
- **功能复合**：抗菌网布（内衣/婴童）、凉感网布（夏季产品）；
- **汽车内饰**：网布座椅（替代皮革——透气温控）——车规级网布是高门槛订单。
