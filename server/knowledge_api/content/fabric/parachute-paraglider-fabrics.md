# 降落伞与滑翔伞面料装备（Parachute Fabrics: 尼龙 66 伞布/零透气涂层）

降落伞/滑翔伞面料是"**轻量高强+透气率精确控制**"的航空纺织品：主伞布要求近零透气（保形升力），材料失效=生命安全——属纺织品中可靠性等级最高的分支之一。与航空座椅纺织（见 `garments/airline-aviation-textiles.md`）同属航空体系，本文聚焦伞体材料与运动装备。

## 一、材料体系

| 部件 | 材料 | 要点 |
|:---|:---|:---|
| 主伞布 | 尼龙 66 高强力 30-70D ripstop 格子布 | 撕破止裂（格子结构）+克重 38-45gsm |
| 零透气处理 | 硅油/PU 涂层（calendering 压光+涂层） | **透气率近零（Frazier <1 CFM）**——升力保持 |
| 滑翔伞翼面 | 尼龙/聚酯 ripstop+双面涂层 | 上翼面承压——涂层均匀度定翼型保持 |
| 伞绳 | 尼龙编织绳（降落伞）/Dyneema 芯+涤纶护套（滑翔伞） | 见 `fabric/ropes-cords-lifting-slings.md` 高强纤维 |
| 加强带 | 尼龙/涤纶织带（伞肋/提带） | 见 `fabric/webbing-narrow-fabrics.md` |

## 二、核心指标

- **透气率**：Frazier 法 CFM 值——主伞近零、后备伞/运动伞特定微量（透气率决定开伞冲击与下降速度）——**批次透气率 CV 值是验收焦点**；
- **撕破强力**：ripstop 格子止裂逻辑（单点破损不扩展）——舌形撕破/梯形撕破测试；
- **抗 UV 老化**：滑翔伞暴晒场景——**寿命 300-500 飞行小时**（UV 降解是强制报废主因——抗 UV 配方+存储避光说明）；
- **克重/厚度**：轻量（收纳体积——登山徒步滑翔伞 hike&fly 轻量线 30D 以下）；
- **耐水解**：海滩牵引伞/救援伞湿热环境。

## 三、产品与认证

| 产品 | 认证/标准 | 市场 |
|:---|:---|:---|
| 滑翔伞（paraglider） | **EN 926/LTF 分级**（A/B/C/D 安全等级） | 欧洲运动主流（阿尔卑斯——法/德/瑞士/奥地利） |
| 动力伞（paramotor） | 同滑翔伞体系 | 全球发烧友 |
| 跳伞（skydiving） | FAA TSO C23（美国） | 军贸+运动双轨 |
| 牵引伞（parasail） | 海岸旅游安全规范 | 海滩旅游（东南亚/地中海/加勒比） |
| 阻力伞（speed chute） | 体育训练用品 | 田径/足球训练（亚马逊小件） |
| 无人机回收伞 | 新兴（无人机配送/航测） | 增长曲线品类 |

- **出口管制注意**：军用降落伞/军规伞布在多国出口管制边缘——体育用途自由但**接单先做品类判定**（见 `trade-compliance/dual-use-export-control.md` 同类逻辑）；
- **责任风险**：救生装备产品责任重大——**质量追溯批次管理+产品责任险**（见 `trade-compliance/product-liability-recall.md`）。

## 四、工艺与商业要点

- **织造**：细旦高密 ripstop（喷气织机——格子组织）——断经/稀密路是致命疵点（见 `fabric/fabric-defects-glossary.md`）；
- **涂层**：硅油轧光——**涂层量克重仅增 2-4gsm 但定透气率**（工艺窗口窄）；颜色（运动消费——鲜艳色牢度）；
- **缝制**：伞衣拼接（搭缝+锯齿缝——接缝透气与强力平衡）；伞绳连接套结——**缝制区应力集中设计**；
- **市场结构**：欧洲品牌主导（滑翔伞 Advance/Ozone/BGD——中国代工部分型号）+军贸体系+消费训练小件（阻力伞/儿童降落伞玩具——中国主场）；
- **新兴**：无人机回收伞（物流无人机强制降落伞监管趋势——美欧无人机法规驱动）+电动垂直起降飞行器（eVTOL 整机降落伞——前沿）。
