# 可持续与再生面料（Sustainable & Recycled Fabrics）

欧美品牌商普遍将可持续材料（sustainable materials）纳入采购硬性要求。供应商须理解再生纤维、有机纤维、环保再生纤维素的来源、认证与宣称边界，避免**漂绿（greenwashing）**风险——欧盟《绿色声明指令》（Green Claims Directive）对无依据环保宣称可处罚。

## 一、再生纤维（Recycled Fiber）

### 再生涤纶（Recycled Polyester / rPET）
- 来源：回收 PET 瓶（bottle flakes）→ 切片 → 纺丝。
- 特点：性能接近原生涤纶，减碳约 30%-50%（视工艺），价格略高于原生。
- 形态：再生 DTY/FDY、再生短纤（recycled staple fiber）。
- **认证**：GRS（含量≥20%）或 RCS（含量≥5%），订单须索取**交易证书（Transaction Certificate, TC）**逐批追溯。
- 注意：再生涤纶色光/强力批差略大于原生，深色与功能性订单需提前确认可染性与指标。

### 再生锦纶（Recycled Nylon）
- 来源：渔网、地毯、工业废料（如 ECONYL® 再生尼龙）。
- 应用：泳装、瑜伽服、运动面料，常与氨纶交织。
- 认证：GRS / RCS，品牌常指定 ECONYL 等原料商标。

### 再生棉（Recycled Cotton）
- 来源：裁剪废料/旧衣开松（mechanical recycling），纤维变短，通常与原生棉或涤纶混纺。
- 限制：再生棉比例过高影响强力与起球，梭织衬衫料中一般不超过 30%-50%。

## 二、有机纤维（Organic Fiber）

### 有机棉（Organic Cotton）
- 定义：种植过程禁用化学农药、化肥与转基因种子，需 3 年以上转换期。
- 认证：**GOTS**（最终产品有机纤维≥70%标"made with organic"，≥95%标"organic"）；**OCS**（含量声明，≥5% 即可，只管含量追溯不管加工环保）。
- 注意：有机棉产量低、价格高（较常规棉溢价约 20%-50%），交期长，订单须预留认证审核与 TC 申请时间。

### 其他有机/可持续天然纤维
- 有机亚麻（organic linen）、有机麻（hemp，汉麻，需确认目的国法规）、可持续羊毛（RWS 认证）、责任羽绒（RDS 认证）。

## 三、环保再生纤维素纤维

### 莱赛尔（Lyocell / TENCEL™ 天丝）
- 兰精（Lenzing）专利工艺：木浆 + NMMO 溶剂闭环回收（回收率＞99%），可生物降解。
- 特点：吸湿优于棉、强力高、悬垂好，用于衬衫、连衣裙、家纺。
- 命名规范："TENCEL™"为兰精注册商标，非兰精货源只能标 **Lyocell/莱赛尔**，冒用商标有法律风险。

### 莫代尔与环保粘胶
- 莫代尔（Modal）：高湿模量，柔软亲肤，Lenzing Modal 为知名品牌。
- 环保粘胶：兰精 ECOVERO™（EU Ecolabel 认证，排放较常规粘胶低 50%）；常规粘胶（viscose）因二硫化碳排放与林源问题，欧美品牌多要求改用认证环保粘胶并溯源林源（FSC/PEFC）。

### 其他新型纤维
- 聚乳酸纤维（PLA，玉米基，可堆肥降解）、生物基锦纶/涤纶（bio-based，如 Sorona® 生物基 PTT）、醋酸纤维（Naia™）。
- 菠萝叶纤维（Piñatex®）、菌丝体材料（mylo）等植物基皮革替代品，主要用于鞋包。

## 四、回收方式与宣称边界

| 回收方式 | 英文 | 说明 | 宣称限制 |
|:---|:---|:---|:---|
| 机械回收 | mechanical recycling | 开松再造纤维，棉/毛为主 | 可标 recycled |
| 化学回收 | chemical recycling | 解聚再聚合，rPET/锦纶 | 可标 recycled |
| 消费前回收 | pre-consumer | 裁剪废料、工业边角 | 须注明 pre-consumer |
| 消费后回收 | post-consumer | 旧瓶、旧衣 | 品牌最看重，溢价最高 |
| 生物基 | bio-based | 原料部分来自生物质 | 不等于可降解 |
| 可降解 | biodegradable | 特定条件下分解 | 须对应测试标准（如 ISO 14855 工业堆肥） |

## 五、订单实操要点

1. **先确认认证要求再报价**：GRS/OCS/BCI 等不同认证对应不同原料采购渠道与成本，报价单注明认证名称与含量比例。
2. **TC 交易证书逐批申请**：GRS 订单每批出货须由认证机构开具 TC，周期约 5-10 个工作日，纳入交期计划。
3. **宣称证据链**：吊牌/网页宣称（claim）须与认证范围证书（Scope Certificate, SC）+ TC 一致，成分标中再生比例写法遵循 FTC/EU 纤维标签法规。
4. **供应链一致性**：再生面料的纺纱—织造—印染各环节都须持证，任一环缺失即断链，整单无法挂 GRS 吊牌。
5. **检测叠加**：再生/有机面料仍须通过常规物性与化学检测（见 testing-standards 文档），认证不替代检测。
