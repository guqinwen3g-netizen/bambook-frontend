# 无纺布与非织造材料专题（Nonwoven Fabrics）

无纺布跳过纺纱织造直接成网固结：纺粘/水刺/熔喷三大工艺对应医疗防护、卫生材料、衬布三大市场——疫后回归常态但医用刚需稳定。

## 一、三大主流工艺

| 工艺 | 原理 | 特性 | 应用 |
|:---|:---|:---|:---|
| 纺粘（spunbond） | 熔融喷丝直接铺网热轧 | 强力好/成本低 | 购物袋/防护服面料/农业覆盖 |
| 熔喷（meltblown） | 热风拉伸超细纤维 | 过滤性好（纤维 1-5μm） | 口罩过滤层/吸油材料 |
| 水刺（spunlace） | 高压水针缠结 | 柔软似布/无化学粘合 | 湿巾/面膜基布/医用纱布 |
| 针刺（needlepunch） | 刺针机械缠结 | 厚实 | 土工布/汽车内饰/过滤毡 |
| 热风/热轧 | 热熔纤维粘合 | 蓬松 | 卫生巾面层/填充棉 |

## 二、医疗防护应用（出口主力）

- **医用防护服**：纺粘+透气膜复合（SMS/SMMS 结构——阻菌透气平衡）;
- **口罩**：三层结构（纺粘外层+熔喷过滤层+纺粘内层——熔喷布是核心，过滤效率 BFE/PFE≥95/99）;
- **隔离衣/手术衣**：SMS 无纺布（抗酒精/抗血液渗透——YY/T 标准）;
- **出口认证**：美国 FDA 注册+510(k)（医用）/欧盟 CE（PPE 指令+MDR——见 `trade-compliance/market-access.md`）; 
- **检测**：合成血液穿透/过滤效率/抗静电/断裂强力。

## 三、卫生材料（最大宗市场）

- **婴儿纸尿裤**：面层（热风无纺布柔软）/导流层/底膜（纺粘复合透气膜）;
- **女性卫生用品**：超薄面层技术（3D 打孔——日本/意大利设备主导）;
- **成人失禁用品**：老龄化驱动增长（欧美日市场稳定增量）;
- **湿巾**：水刺无纺布（可冲散湿巾需木浆复合——环保趋势）。

## 四、服装相关应用

- **服装衬布**：无纺衬（粘合衬——见 `fabric/linings-interlinings.md`）;
- **填充棉**：喷胶棉/仿羽绒棉（热风棉——被服填充，见 `garments/home-textiles.md`）;
- **购物袋**：纺粘无纺布袋（限塑令替代品——价格低竞争红海）;
- **防尘罩/包装袋**：服装包装辅料。

## 五、产业格局

- **中国产能**：全球最大（仙桃"中国非织造布之都"——医疗防护集群）;
- **设备**：德国莱芬豪舍/意大利 STP（高端线）/国产恒天重工（性价比）;
- **疫后格局**：2020-2021 产能暴增发泡沫破裂——行业回归医用/卫生刚需常态，低端熔喷产能出清;
- **原料**：PP 粒料（熔指差异——纺粘 35/熔喷 1500）。

## 六、订单要点

- **医用资质**：出口医疗用途需注册证（FDA/CE——周期长，提前布局）;
- **克重规格**：gsm（克/平米）——防护服 40-65gsm/口罩熔喷 25gsm;
- **检测报告**：每批次随货（医用客户必索）;
- **价格波动**：PP 原料联动（报价有效期短——锁油联动条款）。

## 七、趋势方向

- **可降解**：PLA 聚乳酸无纺布（环保法规驱动——欧盟一次性塑料指令）;
- **可冲散**：木浆水刺（湿巾环保化——欧美下水道标准）;
- **SMS 高端化**：高抗+透气医疗面料（进口替代空间）。
