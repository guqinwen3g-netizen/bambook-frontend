# 土工合成材料深度（土工格栅/土工膜/膨润土毯/排水板：工程材料贸易）

土工合成材料（geosynthetics）是纺织技术与土木工程的交叉大宗：公路铁路加筋、垃圾填埋场防渗、水库堤坝、矿山堆浸场——**一带一路基建与非洲矿业是外贸主引擎**。土工布（针刺/编织）与农用网见 `fabric/technical-agro-geo-textiles.md`——本文聚焦**格栅/膜/毯/板四大结构材料**。产品按工程图纸采购，**拼检测数据与工程案例背书**。

## 一、产品矩阵

| 产品 | 材料工艺 | 用途 | 关键指标 | 价格带（FOB/㎡） |
|:---|:---|:---|:---|:---|
| 塑料土工格栅（单/双向） | PP/HDPE 挤出板材冲孔拉伸 | 路基/边坡加筋 | 拉伸强度 15-50kN/m、节点剥离 | $0.4-1.2 |
| 经编土工格栅 | 涤纶/玻纤经编+PVC 涂层 | 沥青路面加筋（防反射裂缝） | 断裂强度、蠕变 | $0.8-2.5 |
| 钢塑格栅 | 钢丝+PE 包覆焊接 | 高填方/挡墙 | 焊点剥离力 ≥500N | $1.5-3 |
| 土工膜（HDPE 光面/糙面） | HDPE 吹塑/压延 0.5-3mm | 填埋场/尾矿库防渗 | 断裂伸长 700%+、抗穿刺、糙面摩擦角 | $0.8-2.5 |
| 膨润土防水毯（GCL） | 钠基膨润土+针刺土工布复合 | 人工湖/地下工程防渗 | 膨润土含量 ≥4.8kg/㎡、渗透系数 | $1.5-3.5 |
| 排水板（蓄排水板） | HDPE 凸点压型+土工布滤膜 | 地下车库顶板/屋顶绿化 | 抗压强度、通水量 | $0.5-1.5 |

- **与土工布的关系**：土工布负责隔离/反滤/排水（透水），土工膜负责防渗（不透水）——**复合土工膜（两布一膜）**是渠道防渗标准结构，由厂家复合好出厂；
- **经编格栅是纺织技术主场**：高强涤纶工业丝经编成格+涂层——与产业用织造体系同源（`fabric/greige-fabric-weaving-mills.md` 工业丝逻辑）。

## 二、材料与检测要点

- **原料红线**：HDPE 土工膜**禁用回料**（回料膜 2-3 年脆化渗漏——填埋场污染事故=天价索赔）；炭黑含量 2-3%（抗 UV 分散度——炭黑母粒分散不均是薄弱点）；树脂密度 ≥0.94g/cm³（GRI-GM13 标准）；
- **检测体系**：出厂检（厚度/拉伸/撕裂/穿刺）+第三方型检（**GRI/ASTM/GB 三套并行**——出口按 ASTM D 系列，国内工程按 GB/T 17639/17643）；蠕变测试（长期荷载强度折减——50 年设计寿命外推）；
- **焊接配套**：土工膜施工靠双轨热楔焊机——**出口膜+焊机+焊工培训打包**（施工质量占防渗系统成败 70%，材料厂延伸到施工指导是溢价点）；
- **GCL 命门**：膨润土锁土（针刺密度——运输颠簸漏土=拒收）；钠基 vs 钙基（钠基膨胀倍数 25+ 是防渗核心，钙基改性冒充钠基是行业造假高发）。

## 三、市场与交付模式

- **项目渠道**：EPC 总包集采（中交/中铁海外项目带量出口）、矿业公司直采（非洲/南美铜金矿堆浸场——单项目 50-200 万㎡）、填埋场/市政投标（资质+案例门槛）；
- **认证与标准**：GRI-GM13（国际土工膜事实标准）、CE（欧盟 CPR 建材法规）、国内水利/交通部委检测报告——**投标需提供 5 年以上工程案例**（新厂破局靠 EPC 跟随出海）；
- **交付特征**：大卷径卷材（膜卷直径 1.5m+/重 1-2 吨——集装箱装载率低，40HQ 装 2.5-3 万㎡）；**工期驱动**（旱季施工窗口——延迟交付违约金重）；
- **价格联动**：HDPE 树脂占成本 60-70%——报价有效期短（树脂价格波动条款——套保逻辑见 `trade-process/commodity-futures-hedging.md`）。

## 四、风控要点

- **质量责任链**：防渗工程渗漏=环境污染事故——合同明确**材料责任 vs 施工责任边界**（焊缝检测归施工方，膜材缺陷归厂家）；质量保险（产品责任险——`trade-compliance/product-liability-recall.md` 工业品逻辑）；
- **检测造假红线**：工程材料送检样品特制（"送检样 vs 大货样"两套是行业潜规则——**一旦被业主飞行检查发现=工程禁入+刑事责任**）；
- **目的国标准差异**：中东（SASO——CoC 见 `trade-compliance/pre-shipment-coc-psi.md`）、非洲（矿业主自检+SGS 监装）、欧洲（CE+CPR DoP 声明）；
- **安装指导风险**：派焊工出国指导——签证/劳工合规（见 `trade-compliance/sanctions-screening-compliance.md` 敏感国别排查）。
