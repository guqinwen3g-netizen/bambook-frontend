# 产业用纺织品：农用与土工（Technical Textiles: Agro & Geo Textiles）

产业用纺织品（technical textiles）是纺织业第三极（服装/家纺/产业用），中国产量全球第一。农用网与土工布是其中外贸大宗：中东非洲农业基建、东南亚种植园、一带一路工程拉动需求。产品远离时尚，**拼的是原料配方（抗 UV）、设备产能与工程资质**。

## 一、农用纺织品谱系

| 产品 | 工艺 | 关键指标 | 主要市场 |
|:---|:---|:---|:---|
| 遮阳网（shade net） | HDPE 圆丝经编 | 遮阳率 30-95%、UV 稳定 3-5 年 | 中东/非洲/南美种植 |
| 防虫网（insect net） | HDPE/PP 平织 20-50 目 | 目数精度、透光率 ≥85% | 东南亚/以色列设施农业 |
| 防雹网/防鸟网 | 高强 PE 单丝 | 断裂强力、网孔均匀 | 果园（智利/南非） |
| 农用无纺布（覆盖布） | PP 纺粘 17-30g | 透光/保温/可降解需求 | 欧美早春覆盖 |
| 滴灌带基布/栽培袋 | PP 编织布 | 抗 UV+抗老化 | 滴灌配套 |
| 牧草打包网 | HDPE 经编 | 拉伸强度 | 澳新/北美畜牧 |

- **核心命门=抗 UV 配方**：户外使用寿命（3 年/5 年/8 年档）由抗老化母粒决定——**虚标年限是最大质量纠纷**（中东强光环境 1 年就粉化的劣质网毁掉客户整个种植季）；合同注明"UV 保留强力 ≥70%（X 年）"+ 提供 QUV 加速老化测试报告；
- **克重与遮阳率**：遮阳网按遮阳率分档（35%/50%/75%/90%）——用编织密度控制，客户拿照度计验收。

## 二、土工布（Geotextile）

| 产品 | 工艺 | 用途 | 关键指标 |
|:---|:---|:---|:---|
| 短纤针刺土工布 | PP/涤纶短纤针刺 | 公路反滤/隔离 | CBR 顶破强力、等效孔径 O90 |
| 长丝纺粘土工布 | 涤纶长丝 | 高铁/机场高标准 | 断裂强力 kN/m 级 |
| 编织土工布 | PP 扁丝 | 软基加筋 | 经纬向强力 |
| 土工格栅/格室 | PP/HDPE 拉伸 | 路基加筋 | 节点剥离力 |

- **工程资质门槛**：土工布卖给**工程项目**而非贸易商——投标需第三方检测（GRI/ISO 土工合成材料标准）、型检报告、部分国家要求本地认证（沙特 SASO/印尼 SNI，见 `trade-compliance/pre-shipment-coc-psi.md`）；
- **订单特征**：项目制（一个标段几十万平米）、交期死（误工索赔）、账期长（工程回款 6-12 个月）——现金流评估见 `suppliers/garment-factory-cash-flow.md` 逻辑；
- **出口单证**：工程物资常需使馆认证/商会证明（见 `trade-process/document-legalization-apostille.md`）。

## 三、生产与供应链要点

- **设备**：经编机（卡尔迈耶为主）、圆织机、针刺线——单线投资数百万到数千万，属重资产业态；
- **原料**：HDPE/PP 拉丝级树脂——价格随油价波动，大客户合同用"原料指数联动条款"；
- **拉丝车间**：扁丝/圆丝自拉丝（控制强力）vs 外购丝——一体化厂品质稳定；
- **检测能力**：拉伸机/UV 老化箱/顶破仪自检是接单门槛（见 `trade-compliance/testing-lab-selection.md` 外送补充）。

## 四、外贸接单要点

- **买家画像**：农业资材分销商、灌溉工程商、基建承包商、政府项目总包（世行/亚行贷款项目采购有专门规则）；
- **报价要素**：克重/目数/宽度（2-12m 超宽机是竞争力）/卷长/抗 UV 年限——**宽幅与定长卷装是差异化**；
- **装柜优化**：网布打卷+编织袋包装——40HQ 装载量与卷径直接决定海运费占比（泡货逻辑同 `garments/reusable-shopping-bags-production.md`）；
- **付款**：项目单 30% TT 定金+见提单副本尾款为主流；政府项目 LC（审单见 `trade-process/letter-of-credit-review.md`）；
- **售后**：工程质量问题（如边坡滑移归因土工布）索赔巨大——产品责任险+合同责任上限条款（见 `suppliers/supplier-contract-risk.md`）。
