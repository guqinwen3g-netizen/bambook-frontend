# 色织面料专题（Yarn-Dyed Fabrics）

色织（yarn-dyed）是"先染纱、后织造"的工艺：色彩层次与色牢度优于匹染，是衬衫/西装/休闲裤的中高端面料路线。江苏南通/武进是全球色织布中心。

## 一、色织 vs 匹染

| 维度 | 色织（yarn-dyed） | 匹染（piece-dyed） |
|:---|:---|:---|
| 工艺 | 纱线先染色再织造 | 织成白坯再染色 |
| 花型 | 条子/格子/提花（色彩交织） | 纯色为主 |
| 色牢度 | **优**（纱线染透） | 一般 |
| 色彩层次 | 丰富（双面异色/渐变色织） | 单一 |
| 起订量 | 高（3000-5000m，需先染纱） | 低（可小缸染） |
| 交期 | 长（染纱+织造 45-60 天） | 短 |
| 价格 | 高 20-50% | 低 |

## 二、经典品种

| 品种 | 特征 | 用途 |
|:---|:---|:---|
| 色织牛津纺 | 双色经纱+白色纬纱的颗粒感 | 牛津纺衬衫（OCBD） |
| 青年布（chambray） | 色经白纬平纹 | 休闲衬衫/童装 |
| 条子布（stripe） | 色织竖条 | 商务衬衫 |
| 格子布（check/plaid） | 色织格型（塔特索尔格/窗格/维希格） | 衬衫/裙装 |
| 色织府绸 | 高密平纹色织 | 高端衬衫 |
| 色织提花 | 大提花机色织 | 高端女装/家纺 |

## 三、生产工艺链

```
纱线染色（筒子纱染色）→ 整经（按色序排经）→ 浆纱 → 织造（喷气/剑杆）
→ 后整理（退浆/丝光/液氨/定型）
```

- **筒子纱染色**：色织核心工序——纱线染色的均匀度决定布面质量（层差/内外差是色织特有疵点）；
- **整经色序**：条格花型靠整经时色纱排列实现——排错一根经纱整匹报废；
- **液氨整理**：高端色织衬衫面料的免烫+手感处理（见 `fabric/shirting-fabrics.md`）。

## 四、质量检验特有疵点

| 疵点 | 成因 |
|:---|:---|
| 色档（color bar） | 纱线染色批次差/换纱不接 |
| 错花（pattern error） | 整经色序错误 |
| 雨丝条 | 筒子纱内外层色差 |
| 条干不匀 | 色纱纺纱质量 |
| 纬斜 | 色织格型纬斜特别明显（格型歪斜一眼可见——公差严于素色布） |

## 五、采购与开发要点

1. **起订量**：色织 MOQ 3000-5000m/色（染纱+整经的批量要求）——小单用现货色织布；
2. **交期**：45-60 天（比匹染多 2-3 周）——订单排期前置；
3. **现货色织**：南通/广州中大有色织现货市场（流行格型滚动更新）——快反订单走现货；
4. **定制格型**：品牌专属格型开发（注册花型版权——BURBERRY 格纹式的品牌资产）；
5. **双面色织**：双面异色/异格（大衣面料——一衣两面穿卖点）。

## 六、产业带与供应商

- **南通**：色织衬衫面料集群（联发/帝人合作体系）；
- **武进**：色织牛仔/厚色织布；
- **佛山**：色织针织（色织条格汗布——POLO 衫面料）；
- **评估要点**：筒子染厂配套（自有染厂 vs 外发染纱——质量稳定性差异大）。
