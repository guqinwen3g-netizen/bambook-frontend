# 拉丝布与充气运动产品（Drop Stitch: SUP 桨板/充气体操垫/浮台）

拉丝布（drop stitch/空间布）是"**双层基布+数万根连接丝**"的高压充气结构材料：充气后连接丝绷紧形成刚性平板（气压 15-25PSI），让 SUP 桨板/充气体操垫替代硬板与海绵垫。威海/宁波是全球 SUP 产能集群。与气模（见 `garments/inflatable-advertising-products.md`）同属充气品类但**气压高 10 倍、材料体系完全不同**。

## 一、材料结构与原理

| 层位 | 材料 | 功能 |
|:---|:---|:---|
| 上下面层 | 机织涤纶基布+PVC 贴合（单层/双层加强） | 气密+耐磨+UV 防护 |
| 连接丝 | 涤纶单丝/复丝（数万根/m²） | **充气后垂直绷紧——决定厚度与刚性** |
| 边条 | PVC 加强条（热风焊接包边） | 缝合上下层+防漏气 |

- **拉丝高度**：5cm（体操垫）/10-15cm（SUP）/20-30cm（浮台/船底）——厚度均匀度±2mm 是质量线；
- **气压**：SUP 15-20PSI（低压大容积——双腔高压泵配套）；体操垫 5-10PSI；
- **TPU 升级线**：TPU 涂层替代 PVC（轻量+耐水解+环保概念——高端差异化，焊接逻辑见 `garments/dry-bags-waterproof-pouches.md`）。

## 二、工艺链要害

- **基布织造**：双轴向经编/机织同步植入连接丝——**拉丝密度均匀度**（局部稀密=充气后鼓包变形）是织机核心技术；
- **PVC 贴合**：面层贴合牢度（剥离强度——泡水脱层=报废）；二次加强（竞速板双层）；
- **焊接成型**：**热风焊接边条**（气密生命线——虚焊=慢漏气差评首因）；高周波用于局部附件；
- **气密检验**：**全检打气保压 24h（压降<5%）**——抽检制在这品类不成立（单条漏气=整批信誉）；
- **附件**：D 环（牵引/座椅固定）、尾鳍座（US fin box 标准）、把手、防滑 EVA 垫（钻石纹/鳄鱼纹贴合）——附件胶水粘合牢度（泡水环境）。

## 三、产品矩阵与市场

| 产品 | 规格 | 市场 |
|:---|:---|:---|
| SUP 桨板 | 10'6"/11' 全能款为主（宽 32-34"） | 欧美水上运动爆发（亚马逊/迪卡侬/Costco 季节性堆头） |
| 竞速/旅行 SUP | 12'6"/14' 尖头+双层加强 | 进阶玩家（高客单 $500+） |
| 充气体操垫 air track | 3-10m×1-2m | 体操馆/啦啦队/家庭（替代海绵垫——回弹可调） |
| 充气浮台/钓鱼平台 | 2-4m 方形 | 路亚/水上瑜伽（欧美湖钓文化） |
| 充气船底/RIB 底 | 定制 | 橡皮艇升级件 |
| 充气帐篷梁柱 | 管状拉丝结构 | 露营装备（替代玻纤杆） |

- **渠道**：亚马逊（夏季类目——**5-8 月旺季倒排 1-3 月出货**）+大型商超季节单（Costco/ALDI——2 月下单）+品牌 OEM（iRocker/Red Paddle 类）；
- **套装逻辑**：板+桨（铝合金/碳纤）+泵+尾鳍+修补包+背包——**套装完整性是 listing 竞争力**；
- **售后痛点**：慢漏气（边条焊接）、尾鳍座断裂、EVA 垫开胶、泵故障——**修补包标配+备件供应**是品牌合作门槛。

## 四、合规与风控

- **安全**：非救生设备声明（除非做 PFD 认证款——见 `garments/life-jackets-buoyancy-aids.md` 边界）；载重标称（虚标=事故责任）；
- **化学**：PVC 邻苯/PAHs（Prop 65——见 `trade-compliance/california-prop65.md`）；欧盟 REACH；
- **海运**：**高温柜内变形风险**（夏季海运 60℃+——PVC 软化+内压升高爆边）——放气状态+加固包装；单箱重（套装 12-15kg——尾程派送费敏感）；
- **知识产权**：板型/印花设计抄袭泛滥——原创花型注册+亚马逊品牌备案（见 `trade-process/overseas-trademark-registration.md`）。
