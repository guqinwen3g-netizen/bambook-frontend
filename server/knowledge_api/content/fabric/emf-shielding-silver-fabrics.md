# 防辐射与电磁屏蔽面料（EMF Shielding: 银纤维/金属化织物/屏蔽效能）

电磁屏蔽面料通过**金属导电网络反射/吸收电磁波**：银纤维（镀银锦纶）、金属化织物（镀铜镍）、不锈钢纤维混纺、导电涂层布四大路线。应用横跨**国内孕妇防辐射服（特色消费品）、军用/工业屏蔽（帐篷/屏蔽室）、电子防护（屏蔽袋/RFID 防盗布）**。核心指标是**屏蔽效能（dB 值）+耐洗涤衰减**——与抗菌银纤维（见 `fabric/antimicrobial-insect-repellent-finishes.md`）共用材料但功能宣称与测试体系完全不同。

## 一、技术路线对照

| 路线 | 结构 | 屏蔽效能 | 特点 |
|:---|:---|:---|:---|
| 银纤维 | 锦纶/涤纶长丝化学镀银→纯纺或混纺 | 30-60dB | 亲肤可织针织物、**孕妇装主力**、银氧化发黑 |
| 金属化织物 | 织物化学镀铜+镀镍复合层 | 60-80dB | 屏蔽效能高、手感硬、工业用 |
| 不锈钢纤维 | 316L 微丝（6-8μm）与棉/涤混纺（10-30%） | 20-40dB | 耐洗耐折、工装/军装 |
| 导电涂层/梭织金属网 | 涂层导电浆料/金属丝网夹层 | 40-90dB | 屏蔽室/帐篷工程用 |

## 二、屏蔽效能与测试

- **dB 值换算**：30dB=衰减 99.9%、50dB=99.999%、70dB=99.99999%——listing 宣称"99.99% 屏蔽"对应需 40dB 实测支撑；
- **频段**：民用关注 30MHz-10GHz（手机/WiFi/基站）；**不同频段效能差异大**——宣称需给频段-效能曲线而非单点值；
- **测试标准**：GB/T 30142（平面材料屏蔽效能——法兰同轴法）、ASTM D4935、GB/T 25471（电磁屏蔽涂料/织物）；军用 GJB 系列（屏蔽帐篷 60dB+）；
- **防辐射服行标**：GB/T 22583《防辐射针织品》——国内孕妇装产品标准（屏蔽效能分级）；
- **测试机构**：第三方报告（CNAS——国内电商质检联动见 `trade-compliance/china-domestic-standards.md`）。

## 三、耐久性与服用性能（品类命门）

- **银氧化**：银纤维硫化发黑（汗液/空气）——**外观劣变但屏蔽保持**；防氧化整理+深色染色遮盖（藏青/黑色主流色系）；
- **洗涤衰减**：镀层摩擦脱落——标准要求洗 20-30 次效能衰减<10%（**洗涤标识必须中性洗涤剂+禁搓揉+阴干**）；不锈钢纤维路线耐洗最优；
- **手感与亲肤**：金属化织物硬挺（不适合贴身）；银纤维针织可做内衣级（含量 15-50%——含量越高屏蔽越强但成本陡增：银纤维纱价格是普通锦纶 10-20 倍）；
- **透气矛盾**：屏蔽需要致密导电网络 vs 孕妇装需要透气——**蕾丝拼接+局部屏蔽设计**（腹部重点防护区高含量）。

## 四、应用场景与市场

- **国内孕妇防辐射服**：中国特色品类（市场规模曾达数十亿——"智商税"争议后理性回落，现稳定细分市场；十月妈咪/婧麒/添香主导）——营销红线：**不得宣称"防电离辐射"**（X 光/CT 是电离辐射，面料无效——虚假宣传处罚点）；只能讲"日常电磁波防护"；
- **军用/政务**：屏蔽帐篷/保密会议室衬布（金属化织物 60-80dB——需军工资质供应商）；
- **电子工业**：屏蔽袋（防静电+屏蔽复合——见 `garments/medical-healthcare-textiles.md` 的洁净逻辑）、设备遮盖布；
- **RFID 防盗**：钱包/卡包屏蔽内衬布（镀镍铜布——13.56MHz 频段针对性屏蔽，见 `garments/rfid-smart-labels-retail.md` 的射频逻辑）；
- **出口注意**：欧美孕妇装市场无防辐射消费习惯（文化差异——FDA 无相关品类）；出口主打工业/军用屏蔽材料赛道（功能性面料出口报价见 `fabric/functional-fabrics.md`）。

## 五、采购与质控要点

- **银纤维真伪**：火烧法（纯银镀层烧后留银白灰）、电阻法（方块电阻<1Ω）、光谱检测——市场有镀锡铜丝冒充银纤维（屏蔽类似但氧化后失效+致敏风险）；
- **含量验证**：混纺纱金属纤维含量（溶解法测试——见 `trade-compliance/testing-standards.md` 的成分测试）；
- **批次一致性**：镀银工艺批次色差（银层厚度影响色相）+效能波动——到厂按批抽测方块电阻快速筛查；
- **供应商结构**：银纤维纱线厂（山东/浙江集中）→面料织造→功能宣称背书（专利+检测报告全套是品牌合作门槛）。
