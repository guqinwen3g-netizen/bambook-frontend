# 精纺毛料疵点与高端索赔实务（Worsted Defects & Claims: 面料贸易纠纷处理）

精纺毛料单价高（€20-300/m），一匹疵布的损失可能超过整单利润——**高端面料贸易的索赔专业度直接决定利润保全**。泛疵点见 `fabric/fabric-defects-glossary.md`，泛索赔见 `trade-process/claims-handling.md`，四分制检验见 `fabric/fabric-inspection-4point.md`——本文件聚焦**精纺毛料的疵点特征与高端供应链索赔规则**。

## 一、精纺毛料特征疵点

| 疵点 | 成因 | 特征 | 索赔难度 |
|:---|:---|:---|:---|
| 缸差（shade variation） | 染色批次差异 | 同色号不同缸的色差 | ★★★（需 D65 灯箱证据） |
| 呢面档（barre/织档） | 织机张力波动 | 横向条纹状密度差异 | ★★★★（意厂常称"织造特性"） |
| 吊经/吊纬（tight end） | 单纱张力异常 | 局部纱线过紧发亮 | ★★ |
| 呢面磨光（shine） | 后整理压光过度 | 局部镜面反光 | ★★★（高支面料敏感） |
| 结子/粗细节（slub） | 纺纱不匀 | 纱线粗细突变 | ★★（花呢类可辩称风格） |
| 油污渍（oil stain） | 织造/运输污染 | 点状污斑 | ★（明确责任） |
| 虫蛀（moth hole） | 仓储虫害 | 小孔洞 | ★★★★（仓储责任划分难） |
| 水印（water mark） | 受潮后干燥痕 | 波浪状色变 | ★★（运输险覆盖） |

- **高支面料的放大效应**：Super 130s+ 面料纱线极细——**同样疵点在高支面料上更显眼，修复更不可能**；
- **深色面料的色差敏感度**：藏青/黑色的缸差比浅灰更难判别——**深色系索赔需要分光仪数据支撑**。

## 二、检验标准与证据链

### 到货检验（黄金 72 小时）
1. **外观全检**：验布机 40-60m/分钟（毛料需低速）+ 透光检验台；
2. **色差判定**：
   - 标准：D65 灯箱 45° 角观察——**眼评+分光仪 ΔE 双重判定**；
   - 允收线：同缸 ΔE<0.8；缸间 ΔE<1.2（高端订单 <1.0）；
3. **四分制计分**：100 码内 ≤28 分允收（高端客户 ≤20 分）；
4. **克重/幅宽**：每卷实测——**克重偏差 >5% 可整批索赔**；
5. **缩率复测**：蒸缩/水洗缩率——**裁前预缩工序的依据数据**。

### 证据链构建（索赔成败关键）
- **到货即拍**：集装箱开箱视频（封条号→整柜状态）；
- **疵点照片**：带标尺+布边码单同框——**证明疵点位置与卷号对应**；
- **留样封存**：疵布样 1m×全幅 + 双方签封——**复检基准**；
- **时效**：意大利 mill 通行索赔窗口为**到货后 15-30 天**——逾期丧失索赔权。

## 三、索赔规则与谈判

### 行业通行规则
- **"开剪即认收"铁律**：面料一经开剪（cut），视为接受品质——**索赔必须在裁剪前提出**；
- **损耗补偿模式**：
  - 补布（replacement）：补发等量面料——mill 首选；
  - 折让（allowance）：疵点米数 1:1 至 1:1.5 折让——买家争取；
  - 退货（return）：整批退回——仅严重系统性缺陷成立；
- **意厂惯用抗辩**："织造特性""风格特征""天然纤维不可避免"——**应对：合同附件明确允收标准（附疵点图例）**。

### 谈判策略
1. **首战即终战**：首次索赔的处理定调长期合作——**证据充分时全额主张，不轻易接受五折**；
2. **关系平衡**：VBC/Reda 等大厂的年采购额是谈判筹码——**"本年度采购 5 万米"的陈述比律师函有效**；
3. **升级路径**：业务员→销售经理→出口部总监——**每级升级前备好完整证据包**；
4. **仲裁兜底**：合同仲裁条款（米兰商会/中国国际商会）——**面料仲裁案例少，威慑意义大于实战**。

## 四、损失控制实务

- **疵点利用**：主视区疵点裁剪时规避——**排料避疵的利用率抢救（通常可挽回 60-80%）**；
- **改单消化**：疵布改做裤装/马甲（小裁片品类）——**与工厂协商改单方案**；
- **保险衔接**：运输险（受潮/破损）+ 存货险（虫蛀）——**保险与供应商索赔的顺位设计**；
- **预防优先**：
  - 首次合作 mill 首单 100% 到检；
  - 稳定供应商抽检 30%；
  - **"免验厂"资格 = 历史索赔率 <2%**。
