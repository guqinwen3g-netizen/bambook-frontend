# 天鹅绒与人造毛皮专题（Velvet & Faux Fur Fabrics）

天鹅绒（velvet）与人造毛皮（faux fur）是"**触感奢华**"的面料：视觉与触觉的高级感，但生产工艺与品控都有专门门道。

## 一、天鹅绒（Velvet）

### 品类
| 品类 | 工艺 | 应用 |
|:---|:---|:---|
| 真丝天鹅绒 | 真丝割绒 | 顶级礼服（光泽无可替代） |
| 粘胶天鹅绒 | 粘胶绒面 | 中高端礼服/西装领 |
| 涤纶天鹅绒 | 涤纶割绒 | 大众礼服/家纺 |
| 弹力天鹅绒 | 氨纶底布 | 贴身礼服/舞蹈服 |
| 压花天鹅绒 | 压花/烂花（burn-out） | 设计款 |
| 韩国绒 | 涤纶超细纤维 | 女装/家纺（性价比） |

### 品质要点
- **绒高/密度**：绒越密越挺括（稀疏绒面露底）；
- **倒顺毛**：天鹅绒倒绒色差显著——**单向排版铁律**；
- **压痕**：折叠压痕难恢复（卷装运输——不可折叠）；
- **掉绒**：绒牢度（摩擦掉绒测试）。

## 二、人造毛皮（Faux Fur）

### 品类
| 品类 | 特征 |
|:---|:---|
| 长毛绒（long pile） | 毛高 20-60mm（仿狐狸/貉子） |
| 短毛绒 | 毛高 5-15mm（仿貂） |
| 提花毛皮 | 多色提花（豹纹/斑马纹） |
| 卷毛（curly） | 仿羊羔卷毛 |
| 渐变色毛皮 | 毛尖染色（仿天然毛尖） |

### 工艺
- **经编/纬编毛皮**：针织底布+毛条（腈纶/涤纶毛条）；
- **毛尖处理**：褪色/染色（仿天然毛皮的双色效果）；
- **复合**：毛皮+麂皮绒复合（皮毛一体——外套面料）。

### 品质要点
- **掉毛**：毛条牢度（手拔测试——掉毛是退货首因）；
- **毛面均匀**：露底/稀密不均；
- **手感**：仿真度（滑爽 vs 涩——原料与后整理）；
- **阻燃**：儿童毛皮服装阻燃要求（见 `garments/childrenswear-production.md`）。

## 三、应用与订单

- **天鹅绒**：礼服（秋冬礼服季）/西装领/旗袍/家纺（窗帘/沙发）；
- **人造毛皮**：外套（毛领/毛外套）/家居（毛毯/拖鞋）/玩具（毛绒玩具面料）；
- **季节**：秋冬单 5-8 月生产峰值；
- **伦理趋势**：**真皮草禁令**（加州/欧盟多国禁真皮草——人造毛皮需求增长，见 `trade-compliance/esg-csrd-sustainability.md`）。

## 四、裁剪缝制注意

1. **倒顺毛**：天鹅绒/毛皮单向排版（毛向一致）；
2. **毛边处理**：毛皮裁剪后毛边修剪（剪毛——缝线处毛压入缝内）；
3. **缝纫**：毛皮用毛皮专用压脚（滚轮压脚——防毛卷入）；
4. **里布**：毛皮外套必加里布（遮盖毛皮底布）。

## 五、检验要点

| 项目 | 说明 |
|:---|:---|
| 掉毛/掉绒 | 摩擦/手拔测试 |
| 毛面/绒面均匀 | 目测露底/稀密 |
| 倒绒色差 | 排版方向核验 |
| 色牢度 | 深色绒类湿摩擦 |
| 复合牢度 | 皮毛一体复合剥离强度 |

## 六、产业带

- **天鹅绒**：江苏/浙江（韩国绒集群）；
- **人造毛皮**：江苏常熟（毛绒集群——玩具+服装毛皮）、浙江慈溪。
