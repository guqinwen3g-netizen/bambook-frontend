# 声学与乐器纺织品（Acoustic Textiles: 音箱透声布/吸音板布/钢琴呢毡）

声学纺织品是"**声学参数驱动**"的特种面料族：音箱透声布（声学透明）、影院/录音棚吸音板包布（吸声系数）、钢琴呢毡（榔头毡/止音毡）。与舞台幕布的声学应用（见 `garments/stage-theatre-drapes.md`）和地毯吸声（见 `garments/machine-made-carpets.md`）不同，本族是**精密声学部件级**纺织品——织物的声学性能以数据（透声损耗 dB/吸声系数 NRC）交付。

## 一、产品矩阵

| 品类 | 材质 | 核心指标 | 应用 |
|:---|:---|:---|:---|
| 音箱透声布（grille cloth） | 涤纶/尼龙弹力网眼、特种提花 | **透声损耗<0.5dB**、防尘、外观纹理 | 音箱/Hifi/家庭影院/舞台音响 |
| 吸音板包布（acoustic panel fabric） | 涤纶平纹/麂皮绒 | 透气率（Rayl 值）、阻燃 | 影院/会议室吸音板 |
| 钢琴击弦机呢毡（hammer felt） | 100% 羊毛高密度毡 | **密度 0.4-0.6g/cm³、硬度分级** | 钢琴榔头/止音器 |
| 乐器箱包内衬绒 | 天鹅绒/短毛绒 | 防刮、低掉毛 | 提琴/管乐箱（包体见 `garments/specialty-cases-instrument-bags.md`） |
| 录音棚扩散体包布 | 三维纹理织物 | 声学扩散+装饰 | 录音棚/演播室 |
| 汽车声学毡（NVH） | 再生棉毡/PET 针刺毡 | 吸隔音量、克重/厚度 | 车门/地毯下隔音层 |

## 二、技术要点

- **透声布声学逻辑**：**开孔率+丝线直径+组织**决定透声性——粗线密织=高频衰减（"闷"）；拉伸覆框后张力变化影响声学参数——**同一布料张紧度不同透声不同**，覆框工艺指导随货；
- **外观与声学平衡**：提花/双色纹理（装饰性）vs 声学透明——高端品牌音箱布（B&O 类）**纹理即设计语言**；
- **吸音板布**：布料本身吸声有限——**作用是保护玻璃棉芯+透声入芯**；透气率过低=高频吸声失效；
- **钢琴毡**：羊毛毡密度分级（榔头毡经蒸汽压制定型+硬化处理）——**密度均匀性±5% 是音色一致性前提**；德国 Filzfabrik Wurzen 类为标杆；
- **阻燃**：影院/公共场所吸音板布需阻燃（NFPA 701/EN 13501——见 `fabric/flame-retardant-fabrics-deep-dive.md`）；
- **检测**：混响室法吸声系数（ISO 354）、阻抗管（ISO 10534）——**第三方声学报告是投标门槛**。

## 三、市场与商业要点

- **客户形态**：音箱厂（Hifi/专业音响——OEM 配套）、声学工程商（影院/剧院/KTV 装修）、钢琴厂（榔头毡 B2B 极少供应商）、汽车 Tier1（NVH 毡大宗）；
- **替换市场**：复古音箱翻新（vintage grille cloth 复刻——小众高溢价）、琴行维修毡；
- **电商增量**：DIY 家庭影院风潮——吸音板 DIY 套件（布料+框架+棉芯）亚马逊有售；
- **竞争格局**：音箱布美国 Acoustic Mac/欧洲厂商主导高端；**中国窗口在消费电子音箱配套（智能音箱放量）与影院工程出口**；
- **延伸**：吸音画（art acoustic panel——装饰画+吸音）、宠物隔音房毡。

## 四、风控要点

- **声学参数承诺**："NRC 0.8"类宣称需报告支撑——**系统吸声=芯材+布+空腔共同作用，单卖布料不承诺系统指标**（合同限定布料透气率范围）；
- **色差批次**：影院工程单批次用量大——**缸差管理**（见 `fabric/color-management-pantone-measurement.md`）；
- **毡类防虫**：羊毛毡储运防蛀（防虫剂残留 vs 乐器接触安全平衡）——仓储见 `suppliers/warehouse-moisture-mold-prevention.md`；
- **定制账期**：工程单按进度回款——验收节点写清（合同框架见 `trade-process/trade-contract-terms.md`）；
- **样品即标准**：声学/外观双封样——大货与封样偏差是工程纠纷源。
