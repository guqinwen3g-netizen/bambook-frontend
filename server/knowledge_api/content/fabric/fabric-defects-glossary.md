# 面料疵点中英文术语对照（Fabric Defects Glossary）

验布报告与外商沟通的硬通货。四分制检验（见 `fabric/fabric-inspection-4point.md`）的判分记录、客诉描述都依赖统一术语。

## 一、织造疵点（Weaving Defects）

| 中文 | 英文 | 说明 |
|:---|:---|:---|
| 断经 | broken end / missing end | 经纱断裂未接，布面缺一根经线 |
| 断纬 | broken pick / missing pick | 纬纱断裂，横向缺线 |
| 稀纬 | thin filling / loose pick | 纬纱密度不足，横向稀疏道 |
| 密路 | tight pick / thick pick | 纬纱过密，横向紧道 |
| 双纬 | double pick | 两根纬纱同入一梭口 |
| 纬缩 | filling loop / snarl | 纬纱扭结成小圈浮于布面 |
| 跳花 | float / skipped stitch | 经纬纱未按组织交织，浮长异常 |
| 星跳 | star defect | 多根跳花集中呈星状 |
| 百脚 | reed mark / warp streak | 筘齿痕，经向条状痕 |
| 边撑疵 | temple mark | 边撑刺辊造成的针眼/破洞 |
| 松边/紧边 | loose/tight selvedge | 布边松弛或过紧 |
| 烂边 | torn selvedge | 布边破损 |
| 破洞 | hole | 孔洞（致命疵点） |
| 油污 | oil stain / grease spot | 机油污染（可洗除性影响判级） |

## 二、纱线疵点（Yarn Defects）

| 中文 | 英文 | 说明 |
|:---|:---|:---|
| 粗节 | thick place / slub | 局部纱线过粗 |
| 细节 | thin place | 局部纱线过细 |
| 棉结 | nep | 纤维纠缠成的小白点 |
| 毛丝 | fuzz / hairiness | 长丝纱毛羽过多 |
| 条干不匀 | unevenness / yarn irregularity | 纱线粗细不均导致布面条影 |
| 异纤 | foreign fiber | 混入异色/异种纤维（如丙纶丝混入棉） |
| 纱结 | knot | 接头过大或脱结 |

## 三、染色印花疵点（Dyeing & Printing Defects）

| 中文 | 英文 | 说明 |
|:---|:---|:---|
| 色差 | color difference / off shade | 与确认样色差（ΔE 超标） |
| 缸差 | lot-to-lot variation / dye lot difference | 不同染缸批次色差 |
| 色花 | uneven dyeing / shade bar | 染色不匀呈云斑 |
| 色点 | color speck | 未化开的染料颗粒点 |
| 横档 | barre / dye bar | 横向条档（针织常见致命疵点） |
| 前后色差 | end-to-end shading | 一匹布头尾色差 |
| 左右色差 | side-to-side shading / selvedge shading | 布边与中黑色差 |
| 沾色 | staining / color transfer | 印花/染色沾污 |
| 漏印 | misprint / printing skip | 印花漏浆图案残缺 |
| 对花不准 | out of register | 多套色印花错位 |
| 渗色 | bleeding | 颜色洇出图案边界 |
| 极光 | glazing / sheen mark | 轧光过度布面发亮 |

## 四、后整理与外观疵点

| 中文 | 英文 | 说明 |
|:---|:---|:---|
| 纬斜 | skew / bias / bow | 纬纱歪斜（格仔布致命——裁片对不上格） |
| 弧形纬斜 | bow | 纬纱呈弧状弯曲 |
| 折痕 | crease mark | 定型前褶皱压死成永久痕 |
| 卷边 | curling / edge curl | 针织布边卷曲 |
| 起球 | pilling | 表面毛球（分级 1-5） |
| 钩丝 | snag | 纱线被勾出形成线圈 |
| 磨毛不匀 | uneven sanding | 磨毛/拉绒效果不均 |
| 缩水率超标 | excessive shrinkage | 洗后尺寸变化超限 |
| 门幅不足 | narrow width / short width | 实际幅宽窄于标称 |

## 五、针织专有疵点

- **横条（barre）**：纱线批次/张力差异造成的横向条纹——针织面料第一大客诉。
- **针路（needle line）**：织针损伤造成的纵向细线。
- **花针（needle cut / press-off）**：断针导致的纵向破口。
- **漏针（drop stitch / ladder）**：脱圈形成纵向梯状脱散。
- **油针（oil line）**：织针油污造成的油渍纵条。

## 六、验货报告常用句式

- "3 yards broken end at 45" from right selvedge" —— 距右边 45 英寸处 3 码断经。
- "Rejection: excessive bow 4.5% over tolerance 2%" —— 纬斜 4.5% 超公差 2%，判退。
- "Shade continuity within tolerance ΔE 0.8" —— 缸差在 ΔE 0.8 内，可接受。
