# 纺织染料与助剂贸易（Dyestuffs & Auxiliaries: 活性/分散染料/环保合规/价格周期）

染化料是印染成本的第二大项（占 15-25%，仅次于坯布），也是**品质与环保合规的源头**：色牢度差多源于染料选型，废水 COD/重金属源于染化料。中国是最大染料生产国（分散染料占全球 70%——浙江龙盛/闰土/吉华三寡头）。采购与跟单必须理解染料基础逻辑。染整工艺见 `fabric/dyeing-printing-finishing.md`。

## 一、染料分类与选型（按纤维匹配）

| 染料 | 适用纤维 | 特点 |
|:---|:---|:---|
| 活性染料（reactive） | 棉/麻/粘胶 | 共价键结合——色牢度好、色谱全，棉织物主力 |
| 分散染料（disperse） | 涤纶/醋酸 | 高温高压/热熔染色——涤纶唯一选择；**低温型/高温型按色深度选** |
| 酸性染料（acid） | 羊毛/真丝/锦纶 | 鲜艳度高——丝毛染色 |
| 还原染料（vat） | 棉 | 牢度顶级（士林染料）——军品/工装高要求 |
| 硫化染料 | 棉 | 低成本深色（牛仔经纱靛蓝为特例——见 `fabric/denim-fabric-deep-dive.md`） |
| 阳离子染料 | 腈纶 | 腈纶专用（鲜艳） |

- **选型三要素**：纤维匹配+色牢度要求（出口单摩擦/水洗/光照等级倒推染料档次）+成本（高档进口染料价格是国产 2-5 倍）；
- **拼色配伍**：三原色拼色需配伍性（上染速率一致——否则缸差）；**客户确认样到大货的染料批号管理**是色差控制源头（见 `fabric/color-management-pantone-measurement.md`）。

## 二、助剂体系

- **前处理**：退浆酶、精练剂、双氧水稳定剂——**前处理不净=染色百病之源**（染斑/色花多归因于此而非染料）；
- **染色**：匀染剂、促染剂（元明粉/纯碱——活性固色）、消泡剂、螯合分散剂（水质硬度管理）；
- **后整理**：固色剂（提高水洗牢度——注意**含醛固色剂的甲醛风险**）、柔软剂（硅油——影响吸水性，见 `garments/towels-bath-textiles.md`）、防水剂（C6/C0 无氟转型——见 `trade-compliance/pfas-restriction-fluorine-free.md`）；
- **特殊功能**：抗紫外线、抗菌、阻燃整理剂——功能宣称需配套检测（见 `fabric/functional-fabrics.md`）。

## 三、合规红线（欧美订单）

- **禁用偶氮染料**：裂解出 24 种致癌芳香胺——欧盟 REACH 附录 17（<30mg/kg），OEKO-TEX 同限；**非洲蜡染布/印度手工印染是通报高发区**；
- **重金属**：染料中铅/镉/汞/六价铬杂质——生态染料（如 DyStar/亨斯迈体系）有完整合规声明；
- **APEO/NPEO**：洗涤剂类助剂（壬基酚聚氧乙烯醚——环境激素）欧盟禁用——出口订单助剂清单审查；
- **ZDHC 协议**：品牌（Inditex/H&M/Nike）要求染厂执行 **ZDHC MRSL（生产限用物质清单）**——染料助剂供应商需提供 ZDHC Gateway 认证等级（Level 1-3），这是**品牌订单的染料采购前提**（见 `trade-compliance/chemical-environmental-compliance.md`）；
- **蓝标 Bluesign**：bluesign approved 染料体系（见 `trade-compliance/textile-certifications.md`）。

## 四、价格周期与采购

- **寡头定价**：分散染料三寡头（龙盛/闰土/吉华）协同提价史明显——**环保督察停产是涨价导火索**（2017-2018 分散黑 ECT 300% 从 3 万涨到 8 万+/吨案例）；中间体（间苯二胺/H 酸）供应事故同理；
- **采购策略**：染厂常规备 1-2 个月库存+价格低点囤货（资金占用 vs 涨价风险权衡）；**长单报价的染料价格联动条款**（订单周期 3 个月+ 约定染料涨价分担机制——见 `fabric/fabric-procurement-quality-agreement.md`）；
- **质量检验**：力份（强度）与色光（shade）批次检验——每批染料打小样对色；供应商固定（频繁换染料供应商=色差失控）；
- **替代叙事**：数码印花墨水是增量市场（涂料墨水免水洗——见 `fabric/digital-printing-technology.md`）、超临界 CO₂ 无水染色（产业化初期——关注即可）。
