# 提花面料（Jacquard Fabrics: 大提花、小提花与纹板设计）

提花 = **织造时成形的花型**（区别于印花后加工）：小提花（dobby）做几何点纹，大提花（jacquard）每根经纱独立控制做复杂图案。纹板/CAD 设计与上机成本是技术与经济核心。

## 一、分类体系

| 类型 | 设备 | 花型能力 | 应用 |
|:---|:---|:---|:---|
| 小提花（dobby） | 多臂织机（16-32 页综） | 几何/点纹/米通格 | 衬衫面料（见 `fabric/shirting-fabrics.md`）/里布 |
| 大提花（jacquard） | 电子提花机（1344-10000+ 纹针） | 花卉/人物/复杂图案 | 女装/家纺/领带/装饰布 |
| 色织提花 | 色纱+提花 | 色彩交织立体花型 | 高端女装/家纺（见 `fabric/yarn-dyed-fabrics.md`） |
| 针织提花 | 提花圆机/电脑横机 | 针织花型 | 毛衣（见 `garments/knitwear-sweater-production.md`）/运动面料 |
| 剪花/烂花 | 提花+后整理 | 镂空/浮雕效果 | 女装时尚面料（见 `fabric/womens-fashion-fabrics.md`） |

## 二、设备与纹针

- **电子提花机**：史陶比尔（Staubli）/博纳斯（Bonas）——纹针数决定花型精细度（2688 针入门/5376-10000+ 针精细）；
- **速度**：喷气提花机 600-900 转/分（比平纹慢 20-30%——产能折价计入成本）；
- **上机成本**：换花型需重新装造（纹板/通丝穿经——1-3 天），**小单不划算**（起订量通常 500-1000m/花型）。

## 三、设计与制版流程

1. **花稿**：客户提供图案/实样（或采购花型——提花 CAD 素材库）；
2. **CAD 纹板设计**：意匠图（组织点展开）→ 电子纹板文件（EP/JC5 格式）；
3. **试织打样**：手织样/机织样确认（周期 3-7 天——见 `fabric/fabric-development-process.md`）；
4. **大货**：确认样封样后上机。

- **设计关键**：组织搭配（平纹/斜纹/缎纹区块形成明暗对比——缎纹浮长决定光泽与花型清晰度）；
- **纱线配合**：提花对纱线强力/条干要求高（断经=错花疵点——见 `fabric/yarn-spinning-basics.md`）；经纱上浆率上调。

## 四、成本构成

| 项目 | 说明 |
|:---|:---|
| 织费加价 | 比平纹高 30-80%（速度折价+提花机折旧） |
| 上机费 | 换花型一次 ¥2000-8000（纹针越多越贵——摊入米数） |
| 纹板设计费 | 新花型 ¥500-3000/个（买断/授权） |
| 纱线损耗 | 提花断头率高（损耗 +2-3%） |

## 五、品质检验要点

| 疵点 | 成因 | 判定 |
|:---|:---|:---|
| 错花/断花 | 纹针故障/断经 | 主花位不允许（见 `fabric/fabric-defects-glossary.md`） |
| 勾丝 | 缎纹浮线过长（>5mm 高危） | 模拟穿着勾丝测试 |
| 纬缩/百脚 | 提花开口不清 | 四分制扣分（见 `fabric/fabric-inspection-4point.md`） |
| 花型错位 | 对版偏差 | 与确认样比对（花回尺寸公差 ±2%） |

- **应用场景检验**：女装提花注意**透光度**（薄提花做裙需里布）与**缩水差异**（提花区块缩率不匀——洗后起拱）。

## 六、采购策略

- **产区**：浙江（柯桥/海宁许村家纺提花）/江苏（盛泽）/广东（西樵）；领带提花集中嵊州；
- **现货 vs 定制**：柯桥提花现货丰富（小单快反走现货——见 `suppliers/fabric-market-sourcing.md`）；定制花型注意**花型版权**（原创花稿登记——见 `trade-compliance/ip-brand-authorization.md`）；
- **起订量谈判**：拼单（与其他客户共用花型）降 MOQ。
