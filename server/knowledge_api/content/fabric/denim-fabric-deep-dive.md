# 牛仔面料深度专题（Denim Fabric Deep Dive）

牛仔布（denim）是"有生命的面料"：靛蓝染色只染纱线表面（环染），穿着摩擦褪色形成独一无二的色落（fading）。面料品质决定成衣上限（成衣洗水工艺见 `garments/denim-jeans-production.md`）。

## 一、核心工艺：浆染联合

```
棉纱 → 球经/片染（浆染联合机：靛蓝多次浸染氧化）→ 织造 → 后整理（退浆/丝光/预缩/烧毛）
```

- **环染（ring dyeing）**：靛蓝只渗透纱线表层（芯白）——摩擦后露白形成色落，这是牛仔的灵魂；
- **染色次数**：6-12 次浸染（次数越多色越深——深蓝 vs 浅蓝）；
- **硫化染/套色**：黑牛仔/彩色牛仔用硫化染料套染。

## 二、品类矩阵

| 品类 | 特征 |
|:---|:---|
| 赤耳丹宁（selvedge denim） | 老式梭织机窄幅（~80cm）带布边——红边/彩边；高端原牛标志（日本冈山赤耳最负盛名） |
| 原色牛仔（raw denim） | 未经洗水（养牛文化——穿着者自己养出色落） |
| 弹力牛仔 | 纬向加氨纶（1-3%）——女式紧身牛仔裤主力 |
| 针织牛仔 | 针织结构仿牛仔外观（更舒适——legging 化） |
| 提花牛仔 | 大提花牛仔（品牌 logo/花型） |
| 轻磅牛仔 | 6-8oz（衬衫/裙装） |

## 三、规格参数

| 参数 | 说明 |
|:---|:---|
| 盎司重（oz/yd²） | 轻磅 6-8 / 中磅 10-12 / 重磅 13-16+（原牛玩家追重磅） |
| 纱支 | 经纱 6-16S（粗纱是牛仔风格）、纬纱可不同支 |
| 密度 | 3/1 右斜纹为主（也有左斜/人字） |
| 成分 | 100% 棉经典 / 棉氨弹力 / 棉涤（快干） / 棉麻 |
| 颜色 | 靛蓝（indigo）/ 硫化黑 / 蓝黑套色 |

## 四、品质检验要点

| 项目 | 说明 |
|:---|:---|
| 色差 | 牛仔缸差（indigo lot variation）显著——同缸裁剪纪律 |
| 纬斜（skew） | 斜纹布纬斜导致扭腿（成衣裤腿扭转）——拉斜整理控制 |
| 缩水 | 牛仔缩率大（经向 3-5%）——预缩（sanforized）处理；未预缩（unsanforized/缩到合身的玩家玩法） |
| 布面疵点 | 竹节（slub——风格竹节 vs 疵点竹节需区分）/断经/色条 |
| 色牢度 | 靛蓝湿摩擦牢度天然低（沾色是特性非缺陷——但需告知客户标准） |

## 五、产业带与品牌

- **中国**：广东新塘（全球最大牛仔集群）、中山大涌、江苏常州；
- **日本**：冈山儿岛（赤耳丹宁圣地——桃太郎/Japan Blue）；
- **土耳其**：ISKO/ORTA（高端弹力牛仔面料全球领导者）；
- **意大利**：Candiani（高端可持续牛仔）。

## 六、采购与开发

- **起订量**：浆染线 MOQ 5000-10000m（球经染色的批量要求）；现货牛仔布市场（新塘）可小批量；
- **开发方向**：功能性（吸湿排汗牛仔/凉感牛仔）+ 可持续（再生棉/天丝牛仔/节水染整——见 `fabric/sustainable-fabrics.md`）；
- **价格**：普通牛仔 ¥18-30/m；赤耳/高端弹力 ¥40-80/m；
- **验厂关注**：牛仔洗水厂环保（污水排放——见 `garments/denim-jeans-production.md` EIM 评分）。

## 七、趋势

- **可持续染整**：泡沫染色/激光做旧/臭氧洗（节水 90%）；
- **再生纤维**：再生棉牛仔（GRS）+ 回收牛仔闭环（旧衣回收再纺）；
- **无弹力回归**：原牛复兴（100% 棉重磅——复古文化）；
- **针织牛仔增长**：舒适化趋势（居家办公延续）。
