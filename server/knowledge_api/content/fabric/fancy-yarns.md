# 花式纱线专题（Fancy Yarns）

花式纱线（fancy yarn / novelty yarn）是通过**特殊捻线结构或喂入方式**形成不规则外观效果的纱线——是毛衣、粗花呢、小香风面料的"颜值担当"，也是纱线端差异化溢价的主要来源。

## 一、主要品种与结构

| 品种 | 结构特征 | 典型应用 |
|:---|:---|:---|
| 圈圈纱（bouclé） | 饰纱超喂形成环圈 | 小香风粗花呢、毛衣、外套 |
| 竹节纱（slub yarn） | 粗细周期性变化 | 竹节棉 T 恤、牛仔、麻感面料 |
| 大肚纱（big belly） | 局部粗节（比竹节更夸张） | 手工感毛衣、围巾 |
| 结子纱/疙瘩纱（nep/knop yarn） | 饰纱缠绕成结 | 针织、装饰面料 |
| 羽毛纱（feather/eyelash yarn） | 纤维两端外露如睫毛 | 毛衣、家居毯（曾爆款后回落） |
| 雪尼尔（chenille） | 短绒夹于两股芯纱间 | 沙发面料、毛衣（绒感丰满） |
| 包芯纱（core-spun） | 芯（氨纶/涤纶）+外包棉/毛 | 弹力纱、包覆纱（技术型） |
| 段染纱（space dyed） | 纱线分段染色 | 彩虹毛衣、段染面料 |
| 点子纱（nep yarn/彩点） | 混入异色纤维点 | 彩点卫衣面料、呢料 |
| 波纹纱（spiral/corkscrew） | 两纱粗细差螺旋缠绕 | 针织肌理 |

## 二、生产关键

- **设备**：花式捻线机（空心锭子/环锭改造）——核心参数是**饰纱超喂比**（决定圈圈大小密度）；
- **三纱结构**：芯纱（core）+饰纱（effect）+固纱（binder）——圈圈纱经典三纱组合，固纱锁住圈圈防脱落；
- **打样周期**：花式纱打样 3-7 天（比常规纱长——参数调试靠经验）；
- **起订量**：常规花式纱 MOQ 300-500kg/色，特殊定制 1 吨起。

## 三、应用与时尚周期

- **小香风（tweed/粗花呢）**：圈圈纱+结子纱+金银丝混织——香奈儿风格常青树，2020 年后国内电商爆款带动产能扩张；
- **毛衣**：羽毛纱/雪尼尔/段染是毛衫差异化首选（横机针织吃纱线颜值）；
- **卫衣/休闲**：彩点纱（nep）卫裤面料近年流行"花纱灰"效果；
- **时尚周期**：花式纱**流行性极强**——今年爆款明年库存（羽毛纱 2018 爆、2021 衰），下单忌赌库存。

## 四、品质控制要点

- **圈圈牢固度**：固纱张力不足→洗后圈圈脱落（重大客诉）——做水洗测试验证；
- **条干均匀度**：竹节/大肚的"不规则"也要**规律地不规则**（周期稳定，避免意外粗细节）；
- **色差**：段染纱对色难（每段颜色都要对）——大货前确认段染循环样本；
- **强力**：花式纱强力普遍低于常规纱（结构所致）——织造效率下降，报价含损耗。

## 五、采购与成本

- **价格**：花式纱比常规纱贵 30%-200%（看结构复杂度——圈圈纱加工费占大头）；
- **供应商类型**：专业花式纱厂（江浙多）vs 常规纱厂兼营——复杂结构找专业厂；
- **库存纱风险**：花式纱库存纱（跳楼价）要查清存放年限——涤纶丝老化、圈圈弹性衰减；
- **开发配合**：提供目标效果参考样（照片/实物）比口头描述有效——"圈圈大一点"无标准。

## 六、产业带

- **江苏**：张家港/江阴（花式捻线集群——圈圈纱/结子纱主产地）；
- **浙江**：桐乡/海宁（毛衫配套花式纱）、绍兴（雪尼尔）；
- **广东**：东莞大朗（毛织纱线集散地——现货花式纱超市）；
- **山东**：花式纱设备制造（纺机配套）。
