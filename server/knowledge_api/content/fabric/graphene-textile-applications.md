# 石墨烯纺织应用专题（Graphene Textiles: 改性纤维/发热膜/宣称乱象/检测辨别）

石墨烯纺织是"**真实技术 + 过度营销**"并存的典型赛道：石墨烯改性纤维确有导热/抗菌实证，但市面大量"石墨烯内裤治宫寒"式宣称使品类声誉受损。对供应商而言，机会在**发热膜电热产品**（有真实性能优势）与**理性改性纤维**（运动/户外导热场景），风险在功效宣称的法律红线。本文件梳理技术路线、检测辨别与合规边界。

## 一、三条技术路线

| 路线 | 工艺 | 真实功能 | 代表应用 |
|:---|:---|:---|:---|
| 石墨烯改性纤维 | 氧化石墨烯共混粘胶/涤纶纺丝 | 导热（接触凉感）/一定抗菌/抗静电 | 运动内衣/袜子/床品 |
| 石墨烯涂层整理 | 涂层/印花到面料 | 远红外发射（争议最大） | 护具/保暖概念款 |
| 石墨烯发热膜 | 石墨烯导电油墨印制成膜 | **通电发热——性能真实且优秀**（面状均匀发热/低压 5V 可用） | 加热服饰/暖手宝/理疗垫 |

- **发热膜是最实的应用**：对比碳纤维发热丝——石墨烯膜面状发热均匀无热点、可水洗折叠（膜封装工艺决定耐洗次数）——但**供电系统（充电宝/电池）合规见 `trade-compliance/eu-battery-regulation-textiles.md` 与 `trade-compliance/lithium-battery-shipping-compliance.md`**；
- **"自发热"是伪概念**：石墨烯不产热——所谓自发热是吸湿放热（任何亲水纤维都有）或远红外反射体温，升温幅度 1-3°C 量级，宣称"升温 8°C"必有猫腻；
- **改性纤维的真实含量**：共混添加量 0.5-3% 即有效——**含量高低不是核心，分散均匀性才是**（团聚则功能打折还堵喷丝板）。

## 二、检测与辨别

- **石墨烯定性**：拉曼光谱看 D/G/2D 特征峰——2D 峰形态判层数（单层/少层/多层）；**市面"石墨烯"多为多层石墨烯微片甚至炭黑/石墨粉冒充**；
- **含量测定**：热重分析（TGA）+ 元素分析——宣称"含石墨烯"但添加量 ppm 级的属概念添加；
- **功能实证**：导热系数（热流法）/抗菌率（GB/T 20944）/远红外发射率（GB/T 30127，≥0.88 才可标远红外）——**无报告不宣称**；
- **送检注意**：部分检测机构对"石墨烯"字样出证谨慎——先与实验室确认检测方法学再送样（机构选择见 `trade-compliance/testing-lab-selection.md`）。

## 三、宣称合规红线

- **医疗功效绝对禁区**："改善微循环/缓解关节炎/治疗宫寒"——纺织品宣称医疗功效违反广告法/FTC 规定，跨境电商因此被封店的案例密集（宣称边界同 `fabric/protein-regenerated-fibers.md`）；
- **"量子/能量/频谱"组合词**：石墨烯+量子=伪科学叠加——欧美平台（亚马逊）对 pseudoscience 宣称有下架政策；
- **可宣称区间**："石墨烯改性纤维""导热性能经 XX 检测""抗菌率 99%（附报告）"——**功能宣称=检测报告一句话对应**；
- **吊牌标注**：成分标仍需标载体纤维（"聚酯纤维（含石墨烯）"——见 `trade-compliance/textile-fiber-names-regulation.md`）。

## 四、接单与供应链要点

- **原料格局**：石墨烯粉体（常州/青岛系）→ 母粒/改性纤维（化纤厂定制）——**母粒供应商的技术支持能力决定开发效率**；
- **发热膜产品链**：膜厂→封装（PET/TPU 热压）→线束与温控器→成衣整合（见 `garments/heated-vests-electric.md` 整机逻辑）——**膜厂提供封装与电路匹配方案的能力比膜本身更稀缺**；
- **报价陷阱**：石墨烯改性纤维溢价 30-80%——客户拿"普通涤纶价"询盘石墨烯款时需教育成本结构；
- **差异化机会**：运动恢复场景（导热均温）、婴童恒温概念（配合相变材料，见 `fabric/pcm-phase-change-textiles.md`——一储一导可组合叙事）。
