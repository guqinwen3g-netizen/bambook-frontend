# 面料纤维与原料（Fiber & Raw Material）

面料是纺织服装外贸的核心物料。理解纤维（fiber）是选料、报价、质检与沟通的起点。本文件覆盖天然纤维与化学纤维两大类的关键知识与中英文术语。

## 一、纤维分类总览

纤维按来源分为**天然纤维（natural fiber）**与**化学纤维（man-made/chemical fiber）**。

```
纤维 fiber
├── 天然纤维 natural fiber
│   ├── 植物纤维 plant fiber：棉 cotton、麻 linen/ramie
│   ├── 动物纤维 animal fiber：羊毛 wool、羊绒 cashmere、真丝 silk
│   └── 矿物纤维 mineral fiber：玻璃纤维玻璃棉（少用于服装）
└── 化学纤维 chemical/man-made fiber
    ├── 再生纤维 regenerated fiber：粘胶 viscose/rayon、莱赛尔 lyocell/Tencel、莫代尔 modal、醋酸 acetate
    └── 合成纤维 synthetic fiber：涤纶 polyester/PET、锦纶 nylon/polyamide、腈纶 acrylic、氨纶 spandex/elastane、丙纶 polypropylene
```

## 二、常用天然纤维

### 棉（Cotton）
- 最常用的植物纤维，吸湿透气、亲肤。
- 关键规格：支数（Ne）、克重（GSM）。
- 常见纱支：20S、32S、40S、60S、80S（S 越高越细）。
- 术语：长绒棉 long-staple cotton、精梳棉 combed cotton、普梳棉 carded cotton、水洗棉 washed cotton。

### 麻（Linen / Ramie）
- 亚麻 linen（造价高、凉爽）、苎麻 ramie（中国为主，粗犷干爽）。
- 特点：易皱，但透气清爽，夏季面料常用。

### 羊毛与羊绒（Wool & Cashmere）
- 羊毛羊毛 wool：多用美利奴 merino，规格看支数与细度（mic）。支数如 2/48Nm、2/60Nm。
- 羊绒 cashmere：更细更软更贵，来自山羊绒（中国内蒙古为重要产地）。
- 术语：梭织/针织羊毛、羊毛混纺 wool blend。

### 真丝（Silk）
- 桑蚕丝 mulberry silk：高档，光泽好。
- 规格：姆米 momme（如 16mm、19mm、22mm 真丝）。
- 术语：绉缎 crepe/satin、双绉 crepe de chine、电力纺 habotai/pongee。

## 三、常用化学纤维

### 涤纶（Polyester / PET）
- 最常用的合成纤维，国外常用缩写成 **polyester**，学名 **polyethylene terephthalate (PET)**。
- 特点：挺括、耐磨、易干、不易皱，但透气性/吸湿性较弱。
- 规格：涤纶长丝 filament、短纤 staple；DTY / FDY / POY 为纱线形态。
- **同义词**：涤纶、聚酯纤维、polyester、PET、poly。
- 后处理：吸湿排汗 moisture-wicking、抗起球 anti-pilling。

### 锦纶（Nylon / Polyamide）
- 国外常用 **nylon**，学名 **polyamide (PA)**。
- 特点：耐磨、弹性好、强度高，常用于户外、运动、羽绒服面料。
- 规格：尼龙塔丝隆 nylon taffeta、尼龙牛津 nylon oxford。

### 氨纶（Spandex / Elastane / Lycra）
- 弹性纤维，国外常用 **spandex**（美）/ **elastane**（欧），**Lycra** 为品牌名。
- 通常以混纺占比出现，如"棉 95% + 氨纶 5%"、95/5 或 92/8。
- 术语：高弹 high stretch、四向弹力 4-way stretch。

### 粘胶与再生纤维（Viscose / Rayon / Lyocell）
- 粘胶 viscose（北美称 rayon），吸湿柔软、悬垂性好，易缩水。
- 莱赛尔 lyocell（品牌 Tencel），更环保、强度更高、更挺。
- 莫代尔 modal：柔软舒适，常用于内衣/家居服。

## 四、成分与混纺术语

外贸标识按中文国标或英文习惯：

- **中**：棉 65% 涤纶 35%　**英**：65% Cotton 35% Polyester
- 混纺常见组合：棉涤 CVC(T/C)、棉氨、涤氨、羊毛棉、真丝棉。
- **缩写**：
  - CVC = chief value cotton（棉为主）
  - TC / T/C = polyester/cotton（涤棉）
  - 成衣成分标签（label）需符合目的国要求（如美国 FTC 要求英文成分表述）。

## 五、采购与沟通要点

1. **成分必须精确**：报价与生产单上的成分比例要准确，避免海关/客户不符。
2. **注明纱支与克重**：同成分不同支数/克重价格差异大。
3. **术语统一**：与外商沟通用其熟悉的缩写（polyester/nylon/spandex），避免中文歧义。
4. **索样核实**：首次合作供应商务必索样并做成分检测（成分证书 certificate of composition）。
