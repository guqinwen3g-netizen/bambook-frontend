# 魔术贴与粘扣带专题（Hook & Loop: 射出钩/起毛布/剥离强度/背胶冲型）

魔术贴（hook & loop）源于 1948 年瑞士工程师仿牛蒡刺果结构的发明，Velcro 品牌专利到期后中国产能承接全球大宗需求。产品看似简单（钩面+毛面），但**钩型设计、材料配比与强度指标**构成真实门槛——医疗固定带与军工装具的寿命要求是服装应用的数十倍。本文件梳理结构分类、性能指标与采购要点。

## 一、结构与技术路线

| 类型 | 钩面工艺 | 特性 | 应用 |
|:---|:---|:---|:---|
| 编织钩（标准型） | 尼龙单丝编织成钩 | 成本低、开合寿命 5,000-10,000 次 | 服装/鞋帽/箱包 |
| 射出钩（注塑型） | PA/PP 注塑成型钩 | 钩型硬挺、剥离强度高 | 军工/户外/医疗 |
| 蘑菇头（Dual Lock 类） | 蘑菇头互锁（非钩毛） | 强度最高、可反复定位 | 3M 专利壁垒区/工业装配 |
| 不抓毛（软毛面） | 细旦起毛布 | 不伤接触面料 | 婴儿用品/高档服装 |
| 背胶型 | 涂压敏胶（丙烯酸/橡胶基） | 免车缝 | 家居/汽车内饰临时固定 |

- **毛面同样重要**：起毛布的圈绒密度与回弹性决定开合寿命——低价毛面几百次后绒毛倒伏失效，**寿命投诉 80% 出在毛面而非钩面**；
- **材料选择**：尼龙（强度高/贵）vs 涤纶（耐 UV 好/户外用）vs PP（不耐温/最低价）——**户外装备禁用 PP**（70°C 软化变形）；
- **混纺比例**：钩面尼龙 66 含量决定强力——掺涤降本是行业潜规则，验收靠燃烧法+红外光谱（FTIR）抽检。

## 二、性能指标与测试

- **剥离强度（peel strength）**：FZ/T 64038 / ASTM D5170——垂直撕离力（N/cm），服装级 ≥1.0、装备级 ≥2.5；
- **剪切强度（shear strength）**：平行滑移力——承重应用（背包外挂/医疗固定）的核心指标；
- **开合寿命**：标准测试循环 5,000 次后强度保留 ≥50%——**写入验收条款**（"X 次开合后剥离强度 ≥Y"）；
- **色牢度与耐洗**：服装应用需耐水洗色牢度 4 级+（见 `fabric/functional-fabrics.md` 测试体系）；
- **特种要求**：阻燃（军标/航空）、低噪音（军装静音款——撕开声 <65dB）、抗 UV（户外装备 500h QUV）。

## 三、采购与应用要点

- **规格语言**：宽度（10/16/20/25/30/38/50/100/110mm 标准档）×颜色（潘通对色）×钩毛配对——**报价按米，背胶按平米**；
- **车缝 vs 背胶**：服装/装备必须车缝（背胶水洗即失效）；背胶款仅适干燥静态场景——电商详情页混淆两者是差评来源；
- **冲型加工**：圆角冲切防勾纱、定制形状（鞋舌贴/袖口袢）——模具费计入首单；
- **搭配禁忌**：魔术贴接触针织/丝绸面料会勾丝——设计阶段用不抓毛款或加保护盖布（结构逻辑见 `garments/accessories-and-trims.md`）；
- **洗涤指引**：粘扣闭合后再洗涤（防勾坏其他衣物）——写入洗标（合规见 `trade-compliance/textile-labeling-regulations.md`）。

## 四、产业格局与外贸

- **产业带**：广东（佛山/中山）+浙江（义乌/温州）——Velcro/3M 高端、国产大厂（百宏/三信类）中端、义乌小厂低价；
- **专利雷区**：蘑菇头互锁结构 3M Dual Lock 仍有有效专利——**出口美国慎做蘑菇头仿品**（337 调查风险）；
- **买家画像**：服装厂辅料采购（走供应商目录，见 `suppliers/garment-accessories-trims.md`）、医疗器械厂（固定带按图纸定制）、军警装备商（需检测报告随批）。
