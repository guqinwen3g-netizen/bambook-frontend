# 渔网与养殖网箱（Fishing Nets: 尼龙单丝网/PE 编织网/深水网箱）

渔用网具是**产业用纺织的耐久之赛道**：捕捞网具（拖网/围网/刺网）、养殖网箱（近海网箱+深水抗风浪网箱）、防护网（防鸟/防鲨）。核心材料=**尼龙单丝、PE/涤纶编织网线**——网目尺寸与结节强力规格化。生意特征：**渔业资源周期性+养殖扩张驱动**（深远海养殖是国家战略——大型网箱单笔订单可达百万级）。

## 一、产品体系

| 产品 | 材料 | 结构 | 应用 |
|:---|:---|:---|:---|
| 刺网/流刺网 | 尼龙单丝 0.20-0.35mm | 单层/三层（trammel） | 近海捕捞 |
| 拖网 | PE 编织线/涤纶 | 网身+网囊分片缝合 | 渔船拖捕 |
| 围网 | 尼龙复丝/PE | 大网目+括纲 | 围捕中上层鱼群 |
| 养殖网箱（近海） | PE 编织网衣 | 框架浮筒+网衣 | 海水鱼养殖 |
| 深水抗风浪网箱 | **UHMWPE（迪尼玛）/高强 PE 网衣** | 周长 40-120m 大型网箱 | 深远海养殖 |
| 防鸟网/防鲨网 | PE 单丝/尼龙 | 大网目 | 养殖防护/浴场 |

## 二、生产要害

- **网线材料**：尼龙单丝（**透明度高——刺网隐蔽性**；直径均匀度±0.01mm——影响网目整齐）；PE 编织线（8/16 股编织——**耐磨优于单丝**）；UHMWPE 高强线（深水网箱——强度是钢丝 15 倍重量比，见 `fabric/ropes-cords-lifting-slings.md` 的高强纤维体系）；
- **织网**：**有结网**（织网机打结——结节强力损失 15-30%）vs **无结网**（经编/插捻——强力保持率高+10-20% 溢价）；网目尺寸公差±3%（**渔政合规——最小网目尺寸法规**）；
- **定型**：拉伸定型（热处理——**网目尺寸稳定性**；未定型网衣水中收缩变形）；染色（**海蓝/黑色——伪装与抗 UV**；染色牢度海水浸泡）；
- **抗 UV/防附着**：户外海水环境（**抗 UV 剂添加**——3-5 年寿命）；防生物附着涂层（铜系/无铜环保防污漆——养殖网箱换网周期关键）；
- **网箱系统**：网衣+框架（HDPE 浮筒）+锚泊+**沉子/浮子配重计算**（流体力学——网衣在水流冲击下的变形与容积保持率）；大型网箱由**网衣厂+工程公司联合交付**（设计-制造-安装总包趋势）。

## 三、合规与法规

- **渔政网目法规**：**最小网目尺寸**（国内农业农村部按海区/捕捞方式规定——幼鱼保护）；**禁用网具**（绝户网/电鱼网具——生产销售违法）；出口目的国渔业法规（EU 共同渔业政策网具标准）；
- **远洋捕捞配套**：IUU 捕捞合规链（**网具出口给被列黑名单船队的风险**——客户背景核查，见 `trade-compliance/sanctions-screening-compliance.md`）；
- **环保趋势**：**幽灵渔具**（遗失网具持续捕捞——联合国 FAO 关注）→**可降解渔网**（生物基材料——试验阶段）+网具标识追溯（欧美提案中）；
- **养殖网箱**：海洋牧场环评（网箱密度许可）；网衣**防逃逸**（养殖鱼逃逸生态责任——挪威三文鱼逃逸法规参照）；
- **质量检测**：网线断裂强力/结节强力/网目尺寸（GB/T 18673 渔用聚乙烯网线等国标系列）。

## 四、市场与贸易

- **国内**：近海捕捞**总量控制**（双控政策——存量更新需求）；**深远海养殖扩张**（国家级海洋牧场示范区——大型深水网箱 2025-2030 高景气）；休闲渔业（垂钓网具小件）；
- **出口**：东南亚（菲律宾/印尼/越南养殖扩张）；非洲（**渔业援助项目**——中国援非渔船网具打包）；南美（秘鲁/智利渔业大国）；中东欧（淡水养殖）；
- **渠道**：渔需物资经销商（港口渔需店——**账期生意**）；养殖企业直供（网箱年度换网合同——**绑定式复购**）；政府渔业采购（增殖放流/执法网具）；
- **价格与账期**：网衣按公斤计价（PE 粒料联动——见 `trade-process/commodity-futures-hedging.md`）；**渔业季节账期**（开渔前备货赊销——年底回款——坏账风险管理）；
- **产业带**：山东（威海/烟台——渔网集群+深水网箱工程）、浙江（舟山渔场配套）、江苏（淡水网具）、福建（养殖网衣）；
- **延伸**：**防鲨网**（海滨浴场——夏季安装年度维护）、**运动网**（球网——高尔夫练习网/足球场围网——跨界同工艺）。
