# 工业过滤纺织品（Filter Fabrics: 袋式除尘/液体过滤/滤布选型）

工业过滤是纺织材料的高附加值应用：袋式除尘器滤袋（水泥/钢铁/电厂烟气治理）、液体过滤布（压滤机/离心机）、空气过滤（HVAC/洁净室）。环保政策驱动（中国超低排放改造+欧美工业排放标准）——滤袋是**耗材属性**（1-3 年更换），复购稳定。产业带：辽宁抚顺/江苏盐城阜宁（滤料集群）。

## 一、气固分离（袋式除尘）滤料体系

| 材质 | 耐温 | 特性 | 应用 |
|:---|:---|:---|:---|
| 涤纶针刺毡（PET） | ≤130°C | 通用经济 | 常温粉尘（木工/粮食/一般工业） |
| 亚克力（homopolymer acrylic） | ≤125°C | 耐水解优于涤纶 | 潮湿烟气 |
| PPS（聚苯硫醚） | ≤160-190°C | 耐酸耐温——电厂燃煤锅炉标配 | 火电/垃圾焚烧（需控制氧含量） |
| 芳纶（Nomex 间位芳纶） | ≤200-220°C | 耐高温 | 沥青搅拌/水泥窑 |
| P84（聚酰亚胺） | ≤260°C | 高温+不规则截面过滤效率高 | 水泥窑尾/垃圾焚烧 |
| PTFE（聚四氟乙烯） | ≤260°C 长期 | 耐腐耐温天花板+**PTFE 覆膜**（表面过滤） | 高腐蚀高要求场景 |
| 玻纤（覆膜） | ≤260-280°C | 高温经济型但脆 | 水泥/钢铁 |

- **覆膜技术**：ePTFE 微孔膜热压复合在毡面——**表面过滤**（粉尘不渗入基布）=排放浓度<10mg/m³（超低排放标准）+清灰容易；覆膜牢度（剥离强力）是质量分水岭；
- **针刺毡结构**：基布（scrim）+纤维网针刺缠结——基布断裂强力决定滤袋抗拉（脉冲清灰数万次冲击）；
- **后处理**：烧毛压光（表面平滑易清灰）、拒水防油整理（潮湿粉尘防糊袋）、抗静电（混入导电纤维——易燃粉尘防爆，见 `fabric/functional-yarns.md`）。

## 二、滤袋缝制与检验

- **缝制**：三针六线/热熔焊接（PTFE 线缝纫——普通涤纶线在高温工况先老化断线）；袋口弹性涨圈（与花板孔密封配合——泄漏=排放超标）；袋底加固；
- **尺寸配合**：滤袋与笼骨（cage）间隙设计——过紧磨损/过松拍打疲劳；
- **出厂检验**：逐条外观+抽检强力/透气度/克重；**透气度（permeability）**是过滤阻力核心指标（压差=风机能耗）；
- **失效分析**：破袋位置归因（磨损/烧袋/水解/结露糊袋）——帮助客户优化工况是增值服务（提高复购粘性）。

## 三、液固分离（压滤机滤布）

- **织法**：单丝（monofilament——卸饼容易，压滤机主流）/复丝/单复丝混合；平纹/斜纹/缎纹（缎纹表面最滑——卸饼性最好）；
- **定型与砑光**：热定型尺寸稳定+砑光表面平整（滤饼含水率均匀）；
- **应用**：选矿（尾矿脱水）、化工、市政污泥、食品（糖厂/淀粉——食品级 FDA/EU 10/2011 合规）；
- **选型参数**：过滤精度（截留粒径 μm）、透水率、断裂强力、耐酸碱（按料浆 pH 选 PP/PET/PA）。

## 四、贸易与市场

- **B2B 项目制**：滤袋随除尘器工程配套（设计院规格书——按烟气温度/成分/粉尘性质选型），或直接供终端工厂更换市场；
- **出口逻辑**：跟着中国环保工程出海（一带一路水泥/电厂 EPC）+ 终端工厂直采（东南亚/中东水泥厂滤袋更换市场）；**规格非标准化**——按除尘器型号定制（直径 120-160mm×长度 6-10m）；
- **认证**：ISO 9001 基础；电力/水泥大客户入网审核（业绩门槛——"已供 300 条以上运行 1 年无事故"类）；部分市场需本地代理（售后响应——破袋紧急补货 48 小时）；
- **价格与账期**：PPS/PTFE 滤袋单价数百元——项目单金额大但**账期长**（工程业主资金链传导——水泥行业 6-12 个月账期常见，风控见 `trade-process/customer-credit-investigation.md`）；
- **耗材复购模型**：首单（工程配套）→ 更换市场（1-3 年周期）——**建立客户装机档案**（工况+换袋周期）是复购营销核心。
