# 玻璃纤维织物与防火毯（Glass Fiber Fabrics: 防火毯/电焊毯/挡烟垂壁）

玻璃纤维织物是"**无机不燃+耐温分级**"的工业防护材料：从家用厨房灭火毯到造船厂电焊毯到建筑挡烟垂壁，核心价值是**550-1260℃ 耐温区间**（有机阻燃面料的上限替代——对比见 `fabric/flame-retardant-fabrics-deep-dive.md`）。出口主市场=欧美消防渠道+工业 MRO+新能源防火新场景。

## 一、材料分级与产品线

| 材料 | 耐温 | 应用 |
|:---|:---|:---|
| E-glass 玻纤布（平纹/缎纹/膨体） | 550℃ | 灭火毯/电焊毯/保温套基布 |
| 高硅氧布（SiO₂≥96%） | 1000℃+ | 航天/冶金溅射防护 |
| 陶瓷纤维布（含钢丝增强） | 1260℃ | 工业窑炉/防火门芯 |
| 硅胶涂层玻纤布 | 260-550℃（柔性） | 挡烟垂壁/可拆卸保温套/软连接 |
| 铝箔复合玻纤布 | 辐射热反射 | 消防服外层面料/高温管道 |

- **成品线**：灭火毯（fire blanket 1×1m/1.2×1.2m/1.2×1.8m——家用厨房+车载）、电焊毯（welding blanket 1×2m 级——造船/石化动火作业）、挡烟垂壁（smoke curtain——商场/车库固定或电动卷帘式）、可拆卸保温套（阀门/管道节能+防烫）、防火背包/文件袋（新兴小件）。

## 二、标准与认证

| 标准 | 适用范围 |
|:---|:---|
| EN 1869 | 欧洲灭火毯（家用/商用厨房——CE 依据） |
| BS 7944 | 英国重型工业灭火毯 |
| EN 13501 / EN 12101 | 挡烟垂壁防火分级（建筑工程强制） |
| EN ISO 11611 关联 | 电焊防护场景（配套焊接防护服见 `garments/fr-workwear-flame-resistant.md`） |
| ASTM F1989 | 美国烹饪灭火毯 |
| NFPA 701 | 美国纺织品阻燃（公共场所垂壁——见 `trade-compliance/textile-flammability-regulations.md`） |

- **认证逻辑**：灭火毯是**消防器材**（部分国家要求消防产品认证/列名）——出口前确认目的国监管定性（普通商品 vs 消防设备）；挡烟垂壁属建材（欧盟 CPR 建筑产品法规）。

## 三、生产工艺要害

- **织造**：玻纤脆性大——**剑杆/喷气织机低速+无捻粗纱/膨体纱**（膨体处理提升覆盖性与手感）；断纱/毛羽管控（毛羽=皮肤刺痒源）；
- **涂层**：硅胶刮涂/浸渍（柔性+防纤维飞散）——PTFE 涂层（耐腐蚀）/蛭石涂层（耐温提升）/丙烯酸（低成本）；
- **缝制**：**玻纤缝纫线/钢丝增强线**（普通涤线遇火即熔失效）——包边折叠结构（边缘纤维外露=刺痒投诉）；灭火毯拉带（快抽设计——1 秒展开）；
- **后整理与防护**：裁剪/缝制工序**纤维粉尘管控**（工人皮肤刺痒+呼吸防护——见 `suppliers/factory-occupational-health.md`）；
- **包装**：灭火毯 PVC 硬盒/软袋装（挂墙快取结构）——说明书多语种+使用图示。

## 四、市场与商业要点

- **家用消防**：欧美厨房灭火毯（超市/亚马逊——捆绑灭火器销售）；**德国/北欧家用渗透率高**（安全文化）；中东/拉美工程渠道起量；
- **工业 MRO**：造船（中韩船厂集群——电焊毯消耗品定期更换）+石化检维修+焊接分包商——复购型耗材；
- **建筑配套**：挡烟垂壁随消防工程招标（资质+型式检验报告）；
- **新能源增量**：锂电池包防火罩/充电防火毯（EV 车库场景——欧美新品类）+储能柜防火隔层；
- **价格与竞争**：低端灭火毯中国产能充足（$2-4/条出厂——薄利跑量）；**差异化=硅胶涂层柔性布+认证齐全+定制尺寸**；
- **合规注意**：玻纤被 IARC 列为可能的致癌物（特定形态——产品需 SDS 说明+"非吸入形态"封装声明；欧盟 CLP 分类关注）。
