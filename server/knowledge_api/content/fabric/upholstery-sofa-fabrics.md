# 沙发与家具面料（Upholstery Fabrics: 耐磨/科技布/猫抓布）

家具面料是家纺中**克重最高、耐磨要求最苛刻**的分支：沙发布、椅套布、床头软包布。与服装面料逻辑差异大——按"坐压摩擦 5-10 年"设计寿命。产业带：浙江海宁/余杭（装饰布）、广东佛山（家具产业集群配套）。出口链条=面料→海外家具厂/沙发厂，或成品沙发套→零售渠道。

## 一、主流品类与结构

| 品类 | 结构 | 特点 | 价格带（元/米） |
|:---|:---|:---|:---|
| 雪尼尔沙发布 | 雪尼尔纱线梭织 | 绒感厚实、垂感好 | 25-60 |
| 科技布（leathaire） | 涤纶基布+PU 涂层/烫膜 | 仿皮外观+布的价格、耐污易擦 | 15-40 |
| 猫抓布 | 高密涤纶短纤+特殊组织 | 防猫抓（表面光滑猫爪难勾丝）、耐抓测试 | 20-50 |
| 亚麻/仿麻布 | 麻/涤麻混纺 | 北欧风、透气但易皱 | 20-55 |
| 绒布（荷兰绒/意大利绒） | 涤纶割绒 | 轻奢风、倒顺毛明显 | 18-45 |
| 真皮 vs 仿皮 | — | 仿皮（PU/PVC 革）见 `fabric/leather-synthetic-leather.md` | — |

## 二、核心性能指标（与服装面料的本质差异）

- **耐磨马丁代尔（Martindale, ISO 12947）**：家用沙发 ≥15,000-25,000 转；商用（酒店/办公）≥40,000-80,000 转；重度商用（机场/影院）≥100,000 转——**报价单必须标明转数等级**，这是家具厂选料的第一筛选条件；
- **抗起球**：≥3-4 级（ISO 12945）——沙发高频摩擦部位（座面/扶手）起球是主要客诉；
- **色牢度**：摩擦牢度干磨 4 级/湿磨 3-4 级（牛仔裤蹭色到浅色沙发是典型场景）；光照牢度 ≥5 级（靠窗沙发日晒褪色）；
- **耐水解（涂层类命门）**：科技布/PU 革在湿热环境水解粉化——**耐水解年限（3 年/5 年/8 年等级）按热带市场必须验证**（东南亚/南美订单关键项）；
- **阻燃**：英国家具阻燃法规 BS 5852（全球最严——家具+面料组合测试）、美国 TB117-2013、商用 NFPA 701/BS 7176——出口英国市场必查（见 `trade-compliance/textile-flammability-regulations.md`）。

## 三、生产与贸易要点

- **门幅**：140-150cm（家具排料逻辑——大幅宽减少拼缝），部分 280cm 宽幅；
- **最小起订量**：家具面料按"沙发套数"核算——1 套三人位沙发用布 12-18 米，订单常以"柜"为单位（40HQ 约 8,000-10,000 米）；
- **色差与缸差**：同一沙发各部位（座/靠/扶手）必须用同缸布——家具厂收货按缸号分批管理（见 `suppliers/dyeing-mill-cooperation-management.md`）；
- **复合底布**：多数沙发布背面复合无纺布/针织底（增加厚度手感+防滑）——复合剥离强度测试；
- **倒顺毛管理**：绒布/雪尼尔裁剪必须同一方向排料（同灯芯绒逻辑，见 `fabric/corduroy-fabrics.md`）——面料标注绒毛方向箭头；
- **打卷包装**：纸管打卷+塑料袋——绒布类不可折叠压痕（永久折痕客诉）。

## 四、市场与渠道

- **B2B 主线**：海外家具厂（越南/马来西亚家具产业带大量采购中国面料）、沙发套成品出口（可拆洗沙发套是亚马逊品类——按沙发型号定制尺寸）；
- **工程单**：酒店/办公/影院家具配套（阻燃+高耐磨门槛，订单大但认证周期长）；
- **国内市场**：顾家/芝华仕等成品家具品牌的面料供应链——账期长（90-120 天）但量大稳定；
- **电商变量**：可拆洗沙发套（sofa cover）亚马逊品类——弹力全包款，尺寸体系（1/2/3/4 人位）+防滑设计，图案花色驱动复购；
- **趋势**：猫抓布（宠物经济延伸）、防水防污三防布（有孩家庭）、再生涤纶布（GRS 叙事，见 `fabric/sustainable-fabrics.md`）。
