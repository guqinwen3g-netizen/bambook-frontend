# 人造草坪生产（Artificial Turf: 草丝/底布/背胶与 FIFA 认证）

人造草坪是"**PE/PP 草丝+机织底布+背胶锁固**"的地面材料：运动草（足球/橄榄球/曲棍球——认证体系）与景观草（庭院/商业）双轨。中国产能全球占比领先（青岛/无锡/乐陵集群），出口欧美+中东基建双线。与土工材料同属地面覆盖产业用纺织（见 `fabric/technical-agro-geo-textiles.md`）。

## 一、结构分层

| 层位 | 材料 | 功能 |
|:---|:---|:---|
| 草丝 | PE 单丝（直丝）+PP 曲丝混织——分特 6600-13000 dtex | 直立回弹（运动性能）+曲丝托砂 |
| 底布 | PP 编织布+网格复合（单层/双层） | 草丝簇绒基体（见 `fabric/greige-fabric-weaving-mills.md` 织造逻辑） |
| 背胶 | SBR 乳胶/PU 发泡 | **锁草丝——拔出力≥30N 验收线** |
| 填充（运动草） | 石英砂+橡胶颗粒（SBR/EPDM/TPE） | 缓冲+草丝直立支撑 |
| 减震垫（可选） | XPE 发泡垫层 | 高端运动场地 |

- **草丝形态**：直丝（足球）、曲加直混织（景观——仿真）、网丝（fibrillated——曲棍球/网球）、C 型/U 型/W 型截面（直立性与耐磨）；
- **规格**：草高 10-60mm（景观 20-40/足球 40-60）、行距（3/8" 或 3/4"）、密度（针数/㎡）。

## 二、认证与标准

| 体系 | 适用 |
|:---|:---|
| **FIFA Quality / Quality Pro** | 足球场（实验室检测+场地现场检测双阶段——球滚动/垂直回弹/冲击吸收/皮肤摩擦） |
| World Rugby / FIH（曲棍球） | 对应运动场地认证 |
| EN 15330 | 欧洲人造草场地标准 |
| 阻燃/抗 UV | 工程招标强制（户外 5-8 年质保——UV 老化测试见 `trade-compliance/testing-standards.md`） |
| REACH/PFAS | 草丝加工助剂与填充颗粒化学合规（见 `trade-compliance/pfas-restriction-fluorine-free.md`） |

- **认证逻辑**：FIFA 认证按**场地**发证（材料+施工+填充系统）——材料厂做实验室预检（Lisport 磨损模拟）提升中标率。

## 三、生产工艺链

- **草丝挤出**：PE/PP 粒子熔融挤出+拉伸定型（加筋定型——截面形状模具）+加捻合股（直曲丝混）；
- **簇绒**：簇绒机（tufting——针距行距精度——漏针/断丝是在线检测项）；
- **背胶**：SBR 乳胶刮涂发泡烘干——**胶量均匀+渗透锁固**（背胶剥离=场地事故）；PU 背胶高端（耐候回收性优）；
- **后道**：打孔排水（运动草）、切边、卷装（4m/2m 幅——纸芯卷装防压痕）。

## 四、市场与风控

- **运动草**：政府基建（学校/社区球场——招标制：资质+检测报告+业绩）+职业俱乐部（FIFA 认证场地）；中东/非洲体育基建（世界杯/非洲杯带动——高温耐候定制）；
- **景观草**：欧美庭院 DIY（Costco/建材超市——卷装零售）+商业绿化（屋顶/围挡）+宠物草（抗菌排水——宠物友好叙事）+高尔夫球场（果岭专用短草）；
- **政策风险**：**欧盟橡胶颗粒微塑料禁令**（2031 禁售 SBR 填充颗粒——有机填充：软木/橄榄核/椰纤替代方案是接单卖点——见 `trade-compliance/microfiber-shedding-regulation.md` 微塑料政策背景）；PFAS 草丝助剂受限（无氟草丝切换）；
- **关税**：美国 301 关税覆盖人造草（3918 塑料铺地类——见 `trade-compliance/us-tariff-2026.md` 税率叠加结构）；
- **原料联动**：PE/PP 树脂占成本 50%+（期货套保见 `trade-process/commodity-futures-hedging.md`）；
- **售后**：场地质保 5-8 年（UV 粉化/背胶老化是索赔主因——留样+批次检测记录）。
