# 高可视与反光面料（Hi-Vis & Reflective Fabrics: EN ISO 20471 体系）

高可视服装（hi-vis）= 荧光底色面料 + 反光带组合，服务交巡警/环卫/建筑/物流等强制着装场景。属 PPE 法规强制品类（合规体系见 `trade-compliance/ppe-protective-clothing-compliance.md`），本篇聚焦**材料技术与生产要点**。反光带供应链高度集中（3M/艾利/道明/夜光明），是订单成本与认证的核心。

## 一、双组分结构

| 组分 | 技术要求 | 关键指标 |
|:---|:---|:---|
| 荧光底色面料 | 荧光黄/橙红/红三色，涤纶或涤棉 120-300g/㎡ | **色度坐标+亮度因子 β≥0.7**（EN ISO 20471 附录色域） |
| 反光带 | 玻璃微珠（经济型）/微棱镜（高亮型） | 逆反射系数 RA：新态 ≥330 cd/(lx·㎡)（二级带） |

- **荧光面料要害=日晒褪色**：荧光染料光牢度差（3-4 级），标准要求**氙灯老化测试后色度仍在色域内**——选大品牌的"高日晒荧光面料"（承诺 50 次洗涤+光照后达标）；
- **反光带分级**：EN ISO 20471 单性能级（1/2 级带）；**洗后性能是分水岭**——工业洗涤 50 次（ISO 15797）后 RA ≥100 才能标"工业洗适用"。

## 二、成衣等级（EN ISO 20471）

| 等级 | 荧光面料最小面积 | 反光带最小面积 | 场景 |
|:---|:---|:---|:---|
| Class 3 | 0.80 ㎡ | 0.20 ㎡ | 高速道路作业（最高级） |
| Class 2 | 0.50 ㎡ | 0.13 ㎡ | 常规道路/物流 |
| Class 1 | 0.14 ㎡ | 0.10 ㎡ | 低风险环境 |

- **面积计算含拼接损耗**：背心/夹克/连体服结构不同——打版时用 CAD 核算"可视面积"（口袋/接缝遮挡要扣除）；
- **反光带布局规范**：躯干环带+肩部过带（背带式）——间距/宽度有最小要求；**改动布局=重新送检**；
- **美国 ANSI/ISEA 107**：分类逻辑不同（Type O/P/R + Class 1/2/3），出美国订单按 ANSI 设计，别拿 EN 版直接改。

## 三、生产工艺要点

- **反光带车缝**：专用压脚+低张力——微珠面带脆性，针距 3.5-4mm（过密断珠）；热贴带（heat transfer）需热压机 160-180℃ 控温；
- **拼接与断带**：反光带接头搭接 2cm 车双道；**省道/褶皱穿越反光带=认证失效风险**；
- **色迁移**：荧光面料与深色里料接触摩擦移染——里料选同色系或做升华牢度测试；
- **洗涤标签**：按反光带耐洗等级标注（家用洗 25 次/工业洗 50 次）——虚标洗涤次数是召回重灾区（见 `trade-compliance/product-liability-recall.md`）；
- **全检增项**：逐件检查反光带气泡/缺珠/划伤+荧光面污渍（浅色荧光布极显脏——包装防尘，见 `garments/garment-packaging.md`）。

## 四、认证与送检

- **CE 认证路径**：EN ISO 20471 测试（公告机构如 SGS/TÜV/SATRA）→ EU 型式检验（Module B）+ 年度监督（Module C2/D）——测试周期 4-6 周，费用 1-3 万/款；
- **测试样品**：成衣 3-5 件+面料/反光带各 2 米原样——**材料供应商变更必须重新送样**（常见违规点：换便宜反光带不交底）；
- **DOC 与技术文件**：制造商声明（Declaration of Conformity）+测试报告+洗唛图样存档 10 年；
- **英国 UKCA/澳新 AS/NZS 4602/中国 GB 20653**：多市场订单按最严版设计。

## 五、接单与报价要点

- **反光带成本占比 15-30%**（Class 3 连体服反光带用量 4-6 米）——报价单列反光带品牌与等级（3M 8910 vs 国产二级带价差 3 倍）；
- **客户类型**：政府采购/央企集采（中铁/中石油工装）+ 欧洲劳保分销（见 `garments/workwear-uniform-production.md`）——**标单常要求"送检报告在有效期内"**，过期报告直接废标；
- **交期陷阱**：认证测试排期不可控——新款式首单留 8-10 周认证缓冲；
- **组合订单机会**：hi-vis 上衣+工装裤+雨衣套装报价（雨衣需 EN 343 防雨认证）——捆绑提高单值。
