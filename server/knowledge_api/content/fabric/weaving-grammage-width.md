# 织造、克重与幅宽（Weaving, Knitting, Grammage, Width）

面料结构决定了其性能、成本与用途。本文件覆盖**组织方式、克重、幅宽、纱支**四个外贸报价与跟单高频维度。

## 一、组织方式：梭织 vs 针织

面料按织造方式分为**梭织（woven）**与**针织（knitted）**两大类。

### 梭织（Woven）
- 经纬纱交织（warp 经纱 × weft 纬纱），结构稳定、挺括、不易变形。
- 常用组织：平纹 plain、斜纹 twill、缎纹 satin。
- 常见品类：府绸 poplin、斜纹布 twill、帆布 canvas、牛津布 oxford、牛仔布 denim、塔丝隆 taffeta。
- 用途：衬衫、外套、裤装、风衣。

### 针织（Knitted）
- 纱线成圈相套，弹性好、透气、贴身。
- 常用组织：平纹单面 jersey、罗纹 rib（1×1/2×2）、双面 interlock、卫衣抓毛 fleece。
- 常见品类：汗布 jersey、罗马布 pique、毛圈 terry、卫衣布 french terry/fleece。
- 用途：T 恤、卫衣、运动服、内衣。

### 沟通要点
- "梭织/机织"与"woven"同义；"针织/纬编"与"knitted"对应。**"机织"与"梭织"是同一概念**。
- 起订量（MOQ）与交期通常不同：针织圆机效率高、梭织按经轴/织机安排。

## 二、克重（Grammage / GSM）

克重是面料单位面积重量，外贸以 **GSM（grams per square meter，克/平方米）** 或 **oz/yd²（盎司/平方码，多用于牛仔）** 表示。

### 常见区间
- 薄型 knit T 恤：140–180 GSM
- 常规汗布：150–200 GSM
- 卫衣抓毛：280–360 GSM
- 牛仔：8 oz–14.5 oz/yd²（约 270–490 GSM）
- 风衣/夹克梭织：80–150 GSM

### 沟通要点
- **同义词**：克重、GSM、gram per square meter、重量。
- 克重直接影响成本与手感，报价必须锁定 GSM 与允许公差（常见 ±3%~±5%）。
- 针织克重受纱支与组织结构影响；同克重手感可因纱支不同而差异大。

## 三、幅宽（Width）

幅宽是布面可用的横向宽度，影响排料利用率与成本。

### 常见幅宽
- 针织：通常 150–190 cm（如汗布 150/160/185cm）。
- 梭织：通常 140–150 cm（如 57/58" inch，即 144.8–147.3 cm）。
- 牛仔：58/60" inch 常见。

### 沟通要点
- 幅宽单位可能为 **cm** 或 **inch（"）**，务必换算：1 inch = 2.54 cm。
- 幅宽影响单件用量（consumption）：幅宽越宽，通常单耗越低。
- 报价时注明幅宽与克重，避免下单后偏差。

## 四、纱支（Yarn Count）

纱支表示纱线粗细，影响手感与价格。

- 棉纱常用 **英制支数 Ne**（S）：数值越大越细，如 40S、60S、80S。
- 毛纱/丝常用 **公制支数 Nm**：如 2/48Nm、2/60Nm。
- 化纤长丝常用 **旦尼尔 Denier（D）**：数值越大越粗，如 70D、150D。
- 沟通：明确纱支体系（Ne/Nm/D），避免误解。

## 五、单耗（Consumption）与报价

1. 确认**克重 GSM + 幅宽 width + 纱支**三要素。
2. 单耗（单件面料用量）按版型与幅宽计算，常见单位：米/件（m/garment）或公斤/打。
3. 报价需含缩水率、损耗率与备布（通常 3%~8%）。
4. 与供应商确认**色牢度、缩水率、起球等级**等物性，避免成衣后不合格。
