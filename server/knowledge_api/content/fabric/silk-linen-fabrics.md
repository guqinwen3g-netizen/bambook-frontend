# 真丝与麻面料专题（Silk & Linen Fabrics）

真丝（silk）与麻（linen/ramie）是两大高档天然纤维：真丝主打光泽垂坠（女装/睡衣/围巾），麻主打干爽透气（夏装/休闲）。两者都易皱、价格敏感、质量争议点多。

## 一、真丝（Silk）

### 原料与规格
- **桑蚕丝（mulberry silk）**：家蚕，品质最优，占市场 90%+。
- **柞蚕丝（tussah silk）**：野蚕，色偏黄褐、粗犷，价格低。
- **计量单位**：**姆米（momme, mm）**——1 姆米 = 4.3056 g/㎡；常见 12/16/19/22/25/30mm。
  - 12-16mm：衬衫、围巾、里料
  - 19-22mm：睡衣、枕套（19mm 是电商枕套主流）
  - 25-30mm：重磅真丝、高档睡衣
- **丝级（grade）**：6A > 5A > 4A...，6A 为最高级长丝。

### 常见品种
| 品种 | 英文 | 特征 | 用途 |
|:---|:---|:---|:---|
| 素绉缎 | silk charmeuse/satin | 正面缎光背面哑 | 睡衣、衬衫 |
| 双绉 | crepe de chine | 细绉纹、垂坠 | 连衣裙、衬衫 |
| 电力纺 | habotai/pongee | 轻薄平纹 | 里料、围巾印花底布 |
| 乔其 | georgette | 强捻透明感 | 礼服、丝巾 |
| 欧根纱 | organza | 硬挺透明 | 礼服、装饰 |
| 斜纹绸 | silk twill | 斜纹肌理 | 丝巾（爱马仕风格）、衬衫 |

### 质量与争议点
- **缩水**：真丝缩率 3-8%，需预缩或成衣水洗工艺。
- **色牢度**：真丝染色水洗/汗渍牢度偏弱，深色系订单注明等级。
- **泛黄**：白色真丝久置/光照泛黄，仓储避光、抗氧化包装。
- **检测**：纤维含量（燃烧法/溶解法鉴别真丝 vs 仿真丝涤纶）、姆米实测（客户常用电子克重仪复核）。

## 二、麻（Linen & Ramie）

### 亚麻（Linen，欧洲为主）
- 产地：法国/比利时/荷兰亚麻（欧洲雨露麻最优）、中国（黑龙江/新疆）。
- 规格：常见 14s/17s/21s 纯亚麻，或麻棉/麻粘混纺。
- **21 支 vs 14 支**：支数越高越细腻；14s 粗犷休闲，21s 衬衫级。

### 苎麻（Ramie，中国为主）
- 中国特产（湖南/四川），纤维长、强度高、更挺括但刺痒感强。
- 常与其他纤维混纺改善手感。

### 特性与争议点
- **易皱**：麻的天性，客户需接受"自然褶皱"风格；抗皱整理会影响透气性。
- **麻结（slubs）**：竹节状麻结是麻面料的自然特征而非疵点——**验货标准需事先与客户书面确认麻结接受度**，这是麻类订单第一大争议点。
- **刺痒感**：纯麻贴肤刺痒，内衣/T 恤多用麻棉混纺。
- **缩水**：麻缩率 4-10%，必须预缩处理。

### 常见品种
- 纯亚麻布（100% linen）：衬衫、裤装、桌布。
- 麻棉（linen/cotton 55/45）：休闲衬衫主力。
- 麻粘（linen/viscose）：垂感改善，女装。
- 色织麻（yarn-dyed linen）：条子/格仔，价格高于染色麻。

## 三、报价与采购要点

1. **真丝报价看姆米与丝级**：同品种 19mm 与 22mm 价差 15-20%；报全"品种+姆米+丝级+门幅"。
2. **真丝按米计价、麻按米或公斤**：注意客户询价单位。
3. **起订量**：真丝染色 300-500m/色；麻布 500-1000m/色。
4. **交期**：真丝 30-45 天（缫丝-织造-精炼-染色链长）；麻 30-50 天。
5. **产地背书**：杭州/苏州真丝集群；法国麻原料+中国织造是主流模式（可标 "European Flax™ 认证"）。
6. **仿真丝警示**：涤纶仿真丝（imitation silk）外观近似但价格差 5-8 倍，成分检测把关。
