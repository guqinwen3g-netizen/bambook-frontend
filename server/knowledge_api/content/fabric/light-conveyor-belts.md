# 轻型输送带（Light Conveyor Belts: PVC/PU 食品级/物流分拣带）

轻型输送带是"**涤纶织物骨架+PVC/PU 涂层复合**"的机电配套耗材：食品加工/物流分拣/机场行李/跑步机四大场景，核心商业逻辑=**设备配套+磨耗更换复购**。与篷盖布同属 PVC 涂层织物家族（见 `fabric/tarpaulin-coated-industrial-fabrics.md`），但精度与接头工艺要求更高。

## 一、结构与产品矩阵

| 层位 | 材料 | 功能 |
|:---|:---|:---|
| 骨架层 | 涤纶织物 1-4 层（经向高强低缩） | 抗拉定伸长（拉力核心） |
| 面层 | PVC（通用）/PU（食品级）/硅胶（耐高温）/毛毡（防划伤） | 接触物料——表面特性定场景 |
| 底面 | 织物（低摩擦）/涂层（耐磨） | 与托辊/床板接触 |

| 场景 | 带型 | 要点 |
|:---|:---|:---|
| 食品加工（烘焙/屠宰/果蔬） | PU 白色/蓝色带 | **FDA+EU 10/2011 食品接触合规**——耐油耐水解；蓝色带=异物目视识别 |
| 物流分拣/输送 | PVC 草花纹/钻石纹 | 爬坡防滑；**防静电型**（电子件物流） |
| 机场行李 | PVC 黑色耐磨 | 阻燃+高耐磨（24h 连续运行） |
| 跑步机 | PVC 预润滑带 | 低摩擦系数+静音（家用机售后件） |
| 提升/挡板输送 | PVC+挡板（cleat）+裙边（sidewall） | 高频焊接附件——焊接牢度是要害 |
| 农业收获 | 耐候 PVC/橡胶带 | UV+泥水环境 |

## 二、规格与指标

- **厚度/宽度**：1-6mm 厚、4m 内幅宽（热压机规格限制）；卷长 100-200m；
- **接头工艺**（交付关键）：**齿接（finger joint）热熔**——接头强度 80%+本体/平整度（跑偏主因）；现场接头服务（硫化机+技工——售后绑定）；
- **导条/定位**：V 型导条防跑偏（底面焊接）——导条尺寸与设备槽匹配；
- **物理指标**：拉伸强度（经向 N/mm）、1% 定伸长（预张紧设计依据）、剥离强度（层间）、摩擦系数（工作面/底面分别）；
- **特殊性能**：耐温（PVC -10~+80℃/PU -30~+90℃/硅胶 200℃+）、耐油、耐切割（屠宰线）、抗菌（食品）。

## 三、生产与品控

- **压延/涂覆**：PVC 糊树脂涂覆凝胶化（多遍涂覆达厚度）——涂层均匀度+无气泡（气泡=运行脱层）；
- **织物预处理**：骨架布浸渍打底（粘合——层间剥离是批量事故首因）；
- **花纹压印**：表面花纹辊压（钻石纹/直条纹——防滑功能面）；
- **检验**：厚度公差（±0.1mm 级）、整卷外观（杂质/色差）、接头试样拉力；食品级批次留样（迁移测试报告随货——见 `trade-compliance/testing-standards.md`）；
- **裁切包装**：定尺分切+卷装（纸芯+缠绕膜——防潮防压痕）。

## 四、市场与商业要点

- **需求结构**：设备厂 OEM 配套（输送机整机厂）+终端工厂 MRO 更换（**带是磨耗件——1-3 年更换周期=稳定复购**）；
- **客户形态**：欧美工业分销商（皮带仓库模式——现货裁剪+现场接头服务）、国内食品/物流设备集群；
- **出口注意**：卷装重货（海运 20GP 为主——重泡比接近 1:1）；目的港吊装（单卷 1-3 吨——木箱/托盘加固）；
- **竞争格局**：高端（瑞士 Habasit/荷兰 Ammeraal——品牌+服务体系）；中国厂（上海/无锡集群）性价比替代——**服务短板是主要差距**（海外接头服务能力=溢价关键）；
- **延伸**：同步带/三角带（传动带——橡胶基+帘线骨架）、片基带（高速平带）、网带（金属/塑料模块——烘干线）。
