# 广告喷绘材料（Flex Banner: 灯箱布/网格布/车贴/刀刮布）

广告喷绘材料是"**涤纶基布+PVC 涂层/贴合**"的户外广告刚性耗材：灯箱布/网格布/车贴三大类，按克重与透光性分层，全球广告业年消耗以亿平米计。与篷盖布同源（PVC 涂层织物——见 `fabric/tarpaulin-coated-industrial-fabrics.md`），差异在**表面适印性与光学指标**。成品端见 `garments/flags-banners-production.md`。

## 一、产品矩阵

| 产品 | 结构 | 特征 | 应用 |
|:---|:---|:---|:---|
| 外打光灯箱布 frontlit | 500D/1000D 基布+PVC 贴合/涂层（440-610gsm） | 高遮盖——外投光照明 | 户外大牌/围挡 |
| 内打光灯箱布 backlit | 高透白 PVC（透光率 25-35%） | **透光均匀无排骨纹** | 灯箱招牌/机场广告 |
| 网格布 mesh | 网格基布+涂层（透风率 30-50%） | 透风抗撕裂 | 高楼围挡/体育场馆 |
| 刀刮布 knife-coated | 刀刮涂层（浆料直涂） | 高强度+平整——高端画面 | 5m 宽幅无缝画面 |
| 双喷布 | 双面涂层 | 双面喷绘 | 吊旗/道旗 |
| 车贴/单孔透 | PVC 膜+导气槽胶（单透 50% 孔率） | 可移除胶/透视 | 巴士车身/玻璃幕墙 |
| 弱溶剂油画布/相纸 | 棉/化纤布+吸墨层 | 户内写真 | 展厅/影楼 |

## 二、核心指标

- **基布**：高强低缩涤纶（500D/1000D——抗撕裂骨架）；基布密度定画面平整度；
- **克重/厚度**：440/510/610gsm 分级报价——克重=挺度与抗风载；
- **吸墨适配**：溶剂/弱溶剂/UV/Latex 墨水——**表面张力与吸墨层配方**（发花/渗化是投诉点）；
- **光学**：白度（≥85——画面底色）、遮盖力（外打布）、透光均匀性（内打布——排骨纹=基布稀密不匀）；
- **耐候**：抗 UV（户外 1-3 年——UV 母粒+面层配方）、耐温（-30~+70℃）、防霉（热带地区）；
- **阻燃**：公共场所强制——**德标 B1/NFPA 701/法标 M1**（展会搭建与室内广告刚需——见 `trade-compliance/textile-flammability-regulations.md`）；
- **剥离强度**：面层与基布粘合（分层=画面报废）。

## 三、生产与品控

- **贴合工艺**：基布+PVC 膜热压贴合（lamination——三层结构）vs **刀刮直涂**（浆料刮涂凝胶——剥离更强、表面更平）——刀刮线投资大但高端市场必需；
- **表面处理**：亚光/亮光面（眩光管控）；吸墨层涂布（弱溶剂适配）；
- **宽幅**：3.2m/5m（5m 无缝=高端画面免拼接——超宽幅产线是壁垒）；
- **检验**：克重/厚度公差、表面晶点/杂质（黑点=喷绘废品）、整卷接头数（客户要求≤2 个/卷）；
- **包装**：纸芯卷装+牛皮纸/编织袋（防潮防压痕——压痕=画面死褶报废）。

## 四、市场与商业要点

- **渠道**：广告耗材分销商（欧美/中东/非洲——**卷材批发+当地分切**模式）；展会搭建（德美展会——阻燃报告随货）；车贴（4S/广告公司）；
- **价格竞争**：中东/非洲市场低价敏感（$0.3-0.5/㎡ 跑量）；欧美重认证与稳定性；
- **环保趋势**：**PVC-free 需求上升**（欧洲零售品牌可持续承诺——PP/TPU 替代基材+可回收概念——见 `trade-compliance/us-textile-epr-recycling-law.md` 政策背景）；Latex/UV 墨水适配面是研发方向；
- **装柜**：卷装 3.2m——40HQ 卧装（重货——单卷 200-400kg）；注意柜内固定（滚动风险）；
- **回款风险**：广告耗材分销链条坏账率高——信保+信用调查（见 `trade-process/customer-credit-investigation.md`）。
