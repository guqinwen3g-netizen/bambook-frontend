# 汉麻与韧皮纤维深度（Hemp & Bast Fibers: 汉麻/亚麻/苎麻/黄麻）

韧皮纤维（bast fibers）取植物茎秆韧皮部：亚麻/汉麻/苎麻/黄麻/剑麻。共同特性=**高强低伸、吸湿放湿快、天然抑菌、粗犷风格**；共同短板=刺痒感（纯麻）、易皱、纺纱难度大。麻类是可持续叙事最强的天然纤维（低水耗/低农药/碳汇）。亚麻基础见 `fabric/silk-linen-fabrics.md`，本文件补全麻类全族与汉麻专题。

## 一、麻族对照

| 纤维 | 主产地 | 特性 | 应用 |
|:---|:---|:---|:---|
| 亚麻（linen/flax） | 法国/比利时/荷兰（西欧雨露麻最优）、中国（哈尔滨） | 细腻度麻族第一——可纺高支做服装 | 衬衫/西装/家纺（见 `fabric/silk-linen-fabrics.md`） |
| 汉麻（hemp/工业大麻） | 中国（云南/黑龙江——**许可证种植**）、加拿大、法国 | 强度最高+抑菌最强，纤维粗硬 | 混纺服装/牛仔/家纺/绳索 |
| 苎麻（ramie） | 中国（湖南/江西——产量占全球 90%+） | 丝光感强（"中国草"），挺括 | 夏布/服装/刺绣底布 |
| 黄麻（jute） | 孟加拉/印度 | 粗硬低成本 | 麻袋/地毯底布/环保袋（见 `garments/reusable-shopping-bags-production.md`） |
| 剑麻（sisal） | 巴西/东非 | 硬质纤维 | 绳缆/抛光布/猫抓板 |

## 二、汉麻专题（监管是最大变量）

- **与毒品大麻的区别**：工业大麻 THC（四氢大麻酚）<0.3%（中国/欧盟标准）——无致瘾性；但中国种植/加工**全程许可制**（公安部门监管），供应链文件需留痕；
- **各国监管**：美国 2018 Farm Bill 合法化（THC<0.3%）；欧盟 2023 起 THC 上限放宽至 0.3%；日本/韩国/中东**零 THC 要求**——出口订单先查目的国法规；产品宣传禁用大麻叶图案（多平台广告拒登）；
- **纺纱工艺**：汉麻单纤维短且粗——**必须脱胶（生物酶/化学）+ 与棉/天丝混纺**（纯汉麻 21S 以下为主）；精梳长麻纺是高端路线；
- **性能卖点**：抑菌（天然酚类物质——抑菌率检测报告支撑宣称）、抗 UV（UPF 天然高）、吸湿快干（比棉高 30%）、越洗越软；
- **市场叙事**：可持续（种植低投入+碳汇）+功能（抑菌袜/床品）——Patagonia/prAna 等品牌汉麻系列；价格=棉的 2-3 倍（产能小+脱胶成本）。

## 三、共性工艺与质量控制

- **脱胶是关键工序**：微生物/酶脱胶（环保但周期长）vs 化学脱胶（快但废水负荷）——脱胶不净=纤维粗硬刺痒；过度=强力损失；
- **刺痒感管理**：纯麻贴身衣物的刺痒来自硬挺纤维端——对策：混纺（棉/天丝/粘胶）、生物酶柔软整理、液氨处理；**婴幼儿贴身品类慎用纯麻**；
- **褶皱叙事**：麻的褶皱是风格不是缺陷（"富贵皱"）——但需客户教育（洗后免烫整理影响麻的天然手感）；
- **色牢度**：麻纤维结晶区高、上染率低——深色面料摩擦牢度预警（靛蓝麻牛仔掉色同牛仔逻辑）；
- **支数与价格**：麻纱支数普遍低（10-36Nm）——高支纯麻（60Nm+）是技术壁垒（法国亚麻长麻纺）。

## 四、贸易与市场

- **原料贸易**：法国亚麻原料中国采购（沤麻后纤维条）——汇率与欧洲天气影响供给；汉麻原料国内配额逻辑；
- **认证**：European Flax（欧洲亚麻认证——原料追溯）、GOTS 有机麻、OCS；**汉麻特别注意"有机"宣称与许可文件链**；
- **关税**：麻纤维/麻纱 HS 53 章——部分市场（印度）对黄麻制品有保护性关税；美国对华麻制品关税叠加见 `trade-compliance/us-tariff-2026.md`；
- **应用场景增量**：汉麻牛仔（Levi's Wellthread 系列——减水叙事）、麻混纺床品（散热助眠叙事）、麻塑复合材料（汽车内饰——宝马 i3 门板）；
- **风险点**：苎麻产能萎缩（劳动密集——湖南产区老龄化），价格波动大；亚麻欧洲歉收年（2023 减产 30%）传导全球价格。
