# 羽绒原料贸易与检测（Down & Feather: 绒子含量/蓬松度/水洗加工/掺假鉴别）

羽绒是**动物性原料大宗商品**：价格随禽类养殖周期波动（鸭绒年产量与肉鸭屠宰量联动），品质靠专业检测定价。中国占全球羽绒原料供应 70%+（安徽六安/广西贵港/浙江萧山为集散地）。成品应用见 `garments/down-jackets-production.md`，本文件聚焦原料端的贸易、加工与检测。

## 一、原料规格体系

| 指标 | 定义 | 贸易意义 |
|:---|:---|:---|
| 绒子含量（down content） | 绒子占填充物比例（新国标口径：绒丝羽丝不计入） | **定价第一指标**——90% 白鸭绒 vs 50% 价差 3-4 倍 |
| 蓬松度（fill power） | 1 盎司绒占据立方英寸数 | 保暖效率——鹅绒 700-900FP / 鸭绒 450-700FP |
| 清洁度 | 水洗后滤液透明度（mm） | ≥450mm 合格——异味/过敏源指标 |
| 耗氧量 | 有机物残留（mg/100g） | ≤10 合格——微生物繁殖风险 |
| 残脂率 | 脂肪含量 | 0.4-1.2% 正常——过低说明过度脱脂（蓬松度受损） |
| 水分含量 | 含水率 | ≤13%——高水分=短斤缺两+霉变风险 |

- **规格命名惯例**：如 "90/10 白鸭绒 650FP" = 90% 绒子/10% 毛片，白鸭来源，蓬松度 650；
- **鹅绒 vs 鸭绒**：鹅绒朵大蓬松高、异味轻（鸭是杂食脂肪味重）——同指标鹅绒溢价 30-50%；
- **白绒 vs 灰绒**：保暖无差异——白绒溢价纯因浅色面料不透色。

## 二、加工链条（毛片→水洗绒）

```
原料收购（屠宰场毛片）→ 预分（粗筛）→ 水洗（多道洗涤+脱脂）→ 烘干（120°C 杀菌）
→ 冷却 → 分选（风力分绒——绒子/毛片按比重分离）→ 拼配（按目标绒子含量混配）→ 打包
```

- **水洗是品质核心**：洗涤剂配方+水洗次数决定清洁度与异味——水洗不足=异味客诉（"鸭子味"）；过度水洗=残脂率过低、绒朵脆化；
- **分选精度**：风力分绒机多仓分离——高绒子含量（90%+）依赖设备精度与多道循环；
- **拼配陷阱**：低标充高标（80% 绒掺作 90% 卖）、掺绒丝/羽丝（旧国标口径注水——新国标 GB/T 14272-2021 已堵）、**掺胶水绒/粉尘绒**（粉碎毛片粘胶增重——显微镜+燃烧法鉴别）、掺化纤棉（手感偏滑、燃烧鉴别）；
- **防掺假实操**：大单采购约定**到货自检权**（取样送第三方）+ 合同标注新国标口径 + 违约按价差倍数赔偿。

## 三、检测体系

- **权威实验室**：**IDFL（国际羽绒羽毛检测实验室，瑞士/美国）**是行业金标准——欧美品牌只认 IDFL 报告；国内：中国羽绒工业协会检测中心、ITS/SGS 羽绒专项；
- **检测项目**：成分分析（绒子/毛片/绒丝/羽丝/杂质显微镜分拣称重）、蓬松度（蒸汽还原法）、清洁度、耗氧量、微生物（沙门氏菌等——出口欧盟动物源产品检疫要求）、种类鉴定（鸭/鹅鉴别——显微镜下绒核形态，**鸭绒充鹅绒是高价差掺假点**）；
- **报告管理**：每批绒"随货报告"+ 买方到贷复检——报告编号与批号对应（防"一报告多用"）；
- **抽样方法**：大包压缩绒四角+中心五点取样（压缩包装上下层品质可能不同——顶层好绒底层差绒是经典手法）。

## 四、贸易与合规

- **价格机制**：羽绒原料报价按"规格+产地+季节"——每年 12 月-次年 3 月（屠宰旺季）价低备货窗口；锁价条款（订单周期>3 个月必须约定绒价联动或锁价，见 `garments/down-jackets-production.md`）；
- **RDS 认证（Responsible Down Standard）**：禁活拔/禁填喂——欧美品牌强制；供应链**全链条认证**（养殖场→水洗厂→制品厂，产销监管链 transaction certificate 每批转移），见 `trade-compliance/textile-certifications.md`；
- **动物源检疫**：出口欧盟需动物健康证书（非疫区证明）+ 注册加工企业名单（欧盟 TRACES 系统）；美国 USDA/APHIS 对未消毒羽毛有进口限制——**水洗消毒工艺记录是清关凭证**；
- **人道风险叙事**：活拔绒视频是 PETA 类组织攻击点——无 RDS 的羽绒制品在欧美有品牌下架风险；
- **关税与归类**：水洗消毒羽绒 HS 0505.10（原料）vs 9404.90（填充制品）——见 `trade-compliance/hs-classification-practice.md`；美国 301 关税叠加情况见 `trade-compliance/us-tariff-2026.md`。
