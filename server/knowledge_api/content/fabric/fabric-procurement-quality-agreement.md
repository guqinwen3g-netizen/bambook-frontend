# 面料采购合同与质量协议（Fabric Procurement Quality Agreement）

面料占成衣成本一半以上，面料质量事故会穿透到成衣端放大损失。质量协议（Quality Agreement）是采购合同的技术附件——**把"客户标准"转化为"对供应商的可执行条款"**。

## 一、技术规格条款

协议必须锁定以下参数（避免"按样品"的模糊表述）：

| 参数 | 示例 | 公差 |
|:---|:---|:---|
| 成分 | 100% 精梳棉 | 按国标允差 ±3%（纯纺标"100%"） |
| 纱支/密度 | 40S×40S/133×72 | 密度 ±3% |
| 克重 | 145 gsm | ±5% |
| 幅宽 | 57/58" 有效 | 不得低于标称 |
| 颜色 | 潘通 19-4052 TCX，D65 光源 | ΔE ≤ 1.0，同缸 4-5 级 |
| 色牢度 | 耐洗 AATCC 61 / 耐摩擦 AATCC 8 | ≥ 4 级（干）/3 级（湿） |
| 缩水率 | AATCC 135 水洗 3 次 | 经向 ≤3% 纬向 ≤3% |
| 起球 | ISO 12945 | ≥ 3.5 级 |
| 环保 | OEKO-TEX 100 / REACH SVHC | 符合性声明+抽检 |

## 二、验收条款

1. **验收方法**：四分制验布（见 `fabric/fabric-inspection-4point.md`），抽样比例（如 10% 匹数、不足 10 匹全验）；
2. **合格判定**：每 100 平方码 ≤ 28 分（或按客户标准约定数值）；超标退货或折价（折价率阶梯约定）；
3. **疵点免责上限**：供应商对"可开裁疵点"补偿——每匹 ≤X 个疵点允许换片，超出按损耗补偿；
4. **异议期**：到货 7-15 天内提出（隐蔽瑕疵如缩水率/色牢度延长至成衣水洗后）。

## 三、关键商务条款

### 数量与短码
- **按实际米数结算**（验米机复核）；短码超 1% 部分双倍赔偿；
- 整单数量公差 ±3%（约定补/退机制）。

### 缸差管理
- 同订单**同缸生产**要求条款；分缸时供应商必须标注缸号并分开包装；
- 缸差超 4 级（灰卡）的缸次由供应商承担换货或成衣配片损失。

### 交期与违约
- 交期 = 面料送达指定仓库日；晚交期违约金 0.5%/天（上限 5%）；
- 因面料晚交导致成衣空运的，**空运费差额由面料供应商承担**（穿透条款）。

### 质量追溯与赔偿上限
- 面料问题导致成衣被拒/索赔的，供应商承担面料款 + 加工费损失（**赔偿上限 = 面料货值的 2-3 倍**——行业惯例，需在协议中明确，否则法院只支持面料款）；
- 隐蔽质量问题（洗后褪色/起球）追溯期延长至成衣销售后 90 天。

## 四、环保与合规条款

- 供应商保证符合目的国化学品法规（REACH/GB 18401），提供 OEKO-TEX 或检测报告；
- **涉棉订单的非新疆棉承诺条款**（输美订单，见 `trade-compliance/uflpa-forced-labor.md`）——含原料产地声明与赔偿责任；
- 再生/有机面料需提供 GRS/OCS 范围证书 + 每单 TC 交易证书（见 `trade-compliance/textile-certifications.md`）。

## 五、过程管控工具

| 工具 | 时点 |
|:---|:---|
| 缸样（lab dip）确认 | 染色前 |
| 产前样（PP 样布）确认 | 大货投产前 |
| 船样（shipping sample） | 大货发货前——与确认样比对 |
| 第三方抽检 | 高价值/新客户订单（SGS/ITS 验布） |
| 留样 | 每缸 1m，双方各存 12 个月 |

## 六、争议解决

- 检验机构约定：争议时以 **ITS/SGS 等双方认可的第三方检测**为准（检测费由败诉方承担）；
- 仲裁条款：贸仲 CIETAC 或供应商所在地仲裁——跨地域采购避免在供应商主场诉讼。
