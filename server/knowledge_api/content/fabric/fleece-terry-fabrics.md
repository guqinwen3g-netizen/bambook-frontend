# 摇粒绒与保暖绒类面料专题（Fleece & Thermal Pile Fabrics）

绒类面料是秋冬保暖品类的主力：**摇粒绒（polar fleece）是全球销量最大的保暖面料**（Patagonia 发明，优衣库普及）。绒类看似简单，品质差异藏在工艺细节里。

## 一、品类矩阵

| 品类 | 工艺 | 特征 | 应用 |
|:---|:---|:---|:---|
| 摇粒绒（polar fleece） | 针织+拉毛+摇粒（滚筒起粒） | 轻量保暖、快干 | 抓绒衣/外套/毯子 |
| 单面绒/双面绒 | 单/双面拉毛 | 双面绒更保暖 | 卫衣/家居服 |
| 珊瑚绒（coral fleece） | 超细纤维+高拉毛 | 柔软如珊瑚、贴身 | 家居服/毯/童装 |
| 羊羔绒（sherpa） | 高卷曲绒面仿羊羔 | 蓬松、视觉暖感 | 外套内里/卫衣帽里 |
| 法兰绒（flannel） | 梭织+磨毛 | 棉质温润 | 衬衫/床品/睡衣 |
| 天鹅绒/金丝绒（velvet） | 割绒 | 光泽华丽 | 礼服/家纺 |
| 摇粒绒复合 | 摇粒绒+TPU 膜/针织布 | 防风升级 | 软壳外套 |

## 二、摇粒绒品质分级（核心知识）

| 等级 | 克重 | 特征 |
|:---|:---|:---|
| 轻量（micro fleece） | 100-200gsm | 内层打底/春秋 |
| 中量（midweight） | 200-300gsm | 主力（Polartec 100/200 级） |
| 重量（heavyweight） | 300-400gsm | 严寒/外套 |

### 品质关键指标
1. **起球（pilling）**：摇粒绒第一痛点——**抗起球等级（3-4 级为优）**；原料（大化 vs 再生）与染整定型决定；
2. **克重虚标**：报 300gsm 实测 280——绒类克重虚标是行业顽疾（验货抽测）；
3. **掉毛（shedding）**：低质摇粒绒掉毛（穿一次一身毛）——摇粒工艺与拉毛牢固度；
4. **手感**：柔软度（硅油柔软整理——过量硅油影响牢度）。

## 三、原料与成本

- **涤纶 DTY/FDY**：摇粒绒主原料（大化切片 vs 再生 PET——再生绒 GRS 认证趋势，Patagonia/优衣库均已切换再生绒）；
- **价格**：普通摇粒绒 ¥12-25/kg；Polartec 品牌绒（专利授权）¥60-120/kg——品牌绒的性能与故事溢价；
- **克重计算**：单件抓绒衣用料 0.4-0.6kg——原料价格波动直接影响成本。

## 四、生产与缝制要点

- **裁剪**：绒面方向性（顺毛/逆毛色差）——排版统一方向；
- **缝制**：绒类弹性+厚度——链式线迹/四线包缝；压脚压力调整；
- **掉毛控制**：成衣洗水（去除浮毛）——出口童装尤其重要；
- **复合工艺**：摇粒绒+防风膜复合（软壳——见 `fabric/functional-coating-lamination.md`）。

## 五、订单与市场

- **产业带**：绍兴柯桥（绒类集群）、常熟（家纺绒）；
- **旺季**：绒类 6-9 月生产峰值（秋冬订单）——提前锁产能；
- **品牌单**：优衣库/迪卡侬/Patagonia 绒类供应链（品质标杆订单）；
- **可持续**：再生摇粒绒（rPET）+ 微纤维脱落问题（洗护脱落微塑料——欧盟关注，过滤洗衣袋方案）。

## 六、检验要点

| 项目 | 标准 |
|:---|:---|
| 克重 | 实测 vs 标称 ±5% |
| 起球 | ISO 12945 ≥3 级（品牌单 4 级） |
| 掉毛 | 胶带粘附测试/抖落测试 |
| 色牢度 | 耐洗/耐摩擦（深色绒掉色高发） |
| 尺寸稳定 | 水洗缩率（绒类易缩——定型工艺） |
