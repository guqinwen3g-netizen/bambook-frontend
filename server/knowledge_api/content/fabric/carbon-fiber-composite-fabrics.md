# 碳纤维织物与复合材料基材（Carbon Fiber Fabrics & Prepreg: 高性能增强材料）

碳纤维织物是纺织织造技术与高性能材料的交叉品类：平纹/斜纹/缎纹碳布、单向布、多轴向经编布是复合材料（自行车架、无人机、汽车件、球拍）的增强骨架。与玻纤防火布同属高性能纤维织物（见 `fabric/glass-fiber-fabrics-fire-blankets.md`），但**技术等级、单价、出口管制敏感度全面更高**。纺纱级导电碳纤维应用见 `fabric/functional-yarns.md`——本文聚焦结构增强用碳布。

## 一、原料与分级

| 分级 | 丝束 | 特征 | 应用 |
|:---|:---|:---|:---|
| T300/T700S 级 | 3K/6K/12K | 标准模量——**民用主力** | 自行车、球拍、渔具 |
| T800/T1000 | 12K/24K | 中高强——航空次级结构 | 无人机、汽车 |
| M40J/M55J 高模量 | 6K/12K | 高模量——卫星/精密 | 航天（管制敏感） |
| 大丝束（48K+） | 48K/50K | 低成本工业级 | 风电叶片、建筑补强 |

- **原丝格局**：东丽（Toray）/东邦/三菱三家主导高端；国产（中复神鹰/光威/恒神）T700 级成熟、T800 级放量——**国产碳布成本优势显著**；
- **K 数与价格**：3K 平纹布（外观件经典纹路）溢价最高；12K 以上走工业量；
- **混编布**：碳/芳纶混编（抗冲击）、碳/玻混编（降本）、碳/有色玻纤（装饰色纹——外观件）。

## 二、织物形态与工艺

| 形态 | 结构 | 用途 |
|:---|:---|:---|
| 平纹碳布（plain weave） | 1/1 交织——稳定不易散边 | 外观件、薄壳 |
| 斜纹碳布（twill 2/2） | 纹路立体、服帖性好 | 曲面件、改装车外观 |
| 缎纹（satin 5H/8H） | 浮长长、 drapability 最佳 | 深曲面、球拍 |
| 单向布（UD） | 经向 90%+ 承载 | 承力主结构 |
| 多轴向经编（NCF） | 0/90/±45 铺层缝合 | 风电叶片、船舶 |
| 提花/3D 编织 | 异形/立体预成型 | 刹车盘预制体、异形件 |

- **织造要点**：碳纤维**脆性大、起毛静电**——剑杆/片梭织机低速+张力精密控制；毛丝/断丝是外观件致命伤；
- **上浆剂匹配**：碳丝上浆剂（环氧兼容型为主）决定与树脂浸润性——**买布需问清树脂体系**；
- **预浸料（prepreg）**：碳布+环氧树脂预浸——**冷链储运（-18℃）+ 保质期 6-12 个月**（热固树脂缓慢固化）——高附加值深加工方向；
- **幅宽与克重**：1K/3K 外观布 100-200gsm；工业 12K 布 400-600gsm——克重公差 ±5% 行业惯例。

## 三、出口管制与合规（高敏感）

- **两用物项管制**：高性能碳纤维及织物属**瓦森纳安排 1C010 项**——中国出口需**两用物项许可证**（商务部）；T700 级以上/航空级敏感（管制框架见 `trade-compliance/dual-use-export-control.md`）；
- **最终用户审查**：伊朗/朝鲜/俄罗斯等目的地禁运——**最终用户声明（EUC）+ 制裁筛查**（见 `trade-compliance/sanctions-screening-compliance.md`）；
- **美国再出口**：含美原产丝织成的布受 EAR 管辖——转售第三国注意再出口规则；
- **合规红线**：**低报品名（"普通化纤布"）出口碳布=走私/违规出口双重违法**——HS 6815.12/6815.13 如实申报；
- **民用级豁免边界**：部分低规格民用碳布可申请通用许可——具体以最新《两用物项出口管制清单》为准。

## 四、市场与商业要点

- **需求结构**：自行车/电动车架（最大民用量）、无人机机架、汽车改装外观件、体育器材（球拍/钓竿/桨板桨——SUP 配套见 `fabric/drop-stitch-inflatable-materials.md`）、建筑补强布（结构加固）、3C 外壳；
- **客户形态**：复材制品厂（热压罐/模压工艺）、改装件作坊（小批量高频）、科研院所（试验小单）；
- **竞争**：中国碳布价格优势+稳定供货——替代台系/日系中低端份额；**外观件纹路一致性是复购关键**；
- **假冒风险**：**碳纹印花布（仿碳纹涤纶布）冒充真碳布**是电商乱相——真碳布燃烧残留/电阻测试可鉴别；反过来仿碳纹布也是独立品类（装饰用途），报价时必须区分；
- **付款与账期**：高货值小体积——空运为主（空运实务见 `trade-process/air-freight-express.md`）；工业客户账期 30-60 天；
- **延伸**：碳纤维短切/碳毡（高温炉保温）、活性碳纤维（吸附材料——与过滤布交叉 `fabric/industrial-filter-fabrics.md`）。
