# 棉面料深度专题（Cotton Fabrics Deep Dive）

棉是全球第一大天然纤维：**棉花品质 → 棉纱 → 棉布**的品质链从源头决定。理解棉花分级与纺纱工艺，才能在采购时说清"为什么这块棉布贵"。

## 一、棉花分级（纤维品质源头）

| 指标 | 说明 |
|:---|:---|
| 长度（staple length） | 短绒 <25mm / 中绒 25-32 / **长绒 33mm+**（长绒棉=高端） |
| 细度（micronaire） | 马克隆值 3.5-4.9 正常（过粗过细都差） |
| 强力 | 纤维断裂强力 |
| 含杂 | 杂质/短绒率 |
| 颜色 | 白棉/淡点污棉（颜色级） |

### 长绒棉（高端棉）
- **埃及棉（Giza）**：Giza 45/86/96（顶级）；
- **匹马棉（Pima）**：美国/秘鲁（Supima 是美国匹马棉协会认证商标）；
- **新疆长绒棉**：中国顶级（阿克苏——**UFLPA 合规注意**，见 `trade-compliance/uflpa-forced-labor.md`）；
- **用途**：80 支以上高支纱（高端衬衫/床品——见 `fabric/shirting-fabrics.md`）。

## 二、棉纱工艺（精梳 vs 普梳）

| 工艺 | 说明 | 品质 |
|:---|:---|:---|
| **精梳（combed）** | 梳理去除短纤维（短绒率<10%）——纱线均匀光滑 | 高端（高支纱必须精梳） |
| **普梳（carded）** | 仅粗梳——短绒多、毛羽多 | 中低端（粗厚面料） |
| 半精梳 | 介于两者之间 | 性价比 |

- **支数**：棉纱支数（Ne/S——32S/40S/60S/80S/100S+，越高越细越贵——见 `fabric/yarn-spinning-basics.md`）。

## 三、棉面料的品质层级

```
棉花（长绒/细绒）→ 纺纱（精梳/普梳 + 支数）→ 织造（密度/组织）→ 染整（丝光/液氨）
```

### 后整理提升
- **丝光（mercerization）**：烧碱处理——光泽+强力+染色鲜艳（高端棉标志）；
- **液氨（liquid ammonia）**：抗皱+手感（免烫前处理）；
- **烧毛**：表面绒毛烧除（布面光洁）；
- **预缩**：防成衣缩水（见 `fabric/woven-fabrics.md`）。

## 四、棉布主要品类

| 品类 | 特征 |
|:---|:---|
| 府绸（poplin） | 高密平纹（衬衫——见 `fabric/shirting-fabrics.md`） |
| 斜纹（twill） | 卡其/华达呢（裤装） |
| 牛津纺 | 双经单纬（休闲衬衫） |
| 帆布（canvas） | 厚重平纹（工装/鞋包） |
| 灯芯绒 | 见 `fabric/casual-textured-fabrics.md` |
| 牛仔 | 见 `fabric/denim-fabric-deep-dive.md` |
| 针织棉 | 汗布/卫衣布（见 `fabric/knitted-fabrics.md`） |
| 双层纱（double gauze） | 婴童/家居（柔软透气——母婴爆款面料） |

## 五、采购与品质鉴别

### 手感目测（经验法）
- **高支精梳**：细腻光滑/光泽柔和/毛羽少；
- **普梳低支**：粗糙/毛羽多/光泽暗；
- **丝光棉**：丝般光泽（与普通棉明显区别）。

### 检测验证
- **成分**：100% 棉验证（掺涤的"纯棉"——燃烧法初判+检测）；
- **支数密度**：密度镜+纱支测定（虚标支数常见）；
- **克重**：实称（超喂虚标——见 `suppliers/fabric-mill-evaluation.md`）。

## 六、有机棉与可追溯

- **有机棉**：GOTS/OCS 认证（见 `trade-compliance/textile-certifications.md`）——品牌可持续单；
- **BCI**：良好棉花（见 `fabric/sustainable-fabrics.md`）；
- **追溯**：棉源地证明（UFLPA 合规——见 `trade-compliance/uflpa-forced-labor.md` 溯源举证包）。
