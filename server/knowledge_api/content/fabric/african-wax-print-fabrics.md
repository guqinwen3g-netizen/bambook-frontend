# 非洲蜡染印花布（African Wax Print Fabrics: 对非出口主力品类）

蜡染布（Wax Print / Ankara / Dutch Wax）是中国对非面料出口第一大品类：全棉印花布，双面同色渗透，图案浓烈、色彩饱和。西非（尼日利亚/加纳/科特迪瓦）为核心消费市场，婚礼/节日/日常服饰刚需。中国产"仿蜡染"（machine-made imitation）以 1/3 价格占据主流市场，冲击了荷兰 Vlisco 等真蜡染（true wax）高端线。

## 一、产品分级

| 级别 | 工艺 | 价格带 | 市场定位 |
|:---|:---|:---|:---|
| 真蜡染（True Wax） | 蜡防染+龟裂效应（Vlisco 等少数厂） | $8-15/码 | 高端、身份象征 |
| 超级仿蜡（Super Wax） | 双面渗透印花+上蜡感整理 | $2.5-4/码 | 中端主流 |
| 普通仿蜡（Java Print） | 单面印花双面渗透处理 | $1.2-2.5/码 | 走量主力 |
| 涤纶仿蜡 | 涤布分散印花 | $0.6-1.2/码 | 低端/二手衣替代 |

- **规格惯例**：6 码/件（cut piece）——非洲按"件"零售（一件做一套衣服）；幅宽 46-48 英寸；
- **品质核心=渗透度**：正反面色差越小越接近真蜡染（客户验货对折看反面）；
- **手感整理**：上浆+蜡感涂层（越"脆挺"越像高端货）——水洗后掉蜡变软的低端货会被投诉。

## 二、生产要点

- **坯布**：全棉 40×40/96×96 或 24×24 平纹——坯布质量决定渗透效果（见 `fabric/woven-fabrics.md`）；
- **印花工艺**：圆网印花为主（滚筒机双面印刷的高端线在国内少数厂）——颜色 6-12 套色，**多套色对花精度**是技术壁垒（见 `fabric/dyeing-printing-finishing.md`）；
- **颜色体系**：非洲市场偏好高饱和撞色（橙/绿/紫/金）——配色师必须研究西非流行色（每年拉各斯/阿克拉时装周发布）；
- **图案知识产权**：**自行设计花型**——抄袭 Vlisco/当地设计师花型会在目的国遭遇扣押与诉讼（见 `trade-compliance/ip-brand-authorization.md`）；国内花型设计工作室（绍兴/广州）可按系列买断；
- **金银粉印花**：节日款加金粉——金粉牢度（干磨 3 级）是常见质量纠纷点。

## 三、对非贸易实操

- **客户结构**：西非进口大户（拉各斯 Balogun 市场、阿克拉 Makola 市场）+ 中国人在非批发商——**客户多为现金交易传统，首次合作坚持前 TT 或信用证**（见 `trade-process/export-payment-methods-practice.md`）；
- **出运节奏**：旱季（11-4 月）为销售旺季，8-9 月为发货高峰——舱位紧张提前订（见 `trade-process/sea-freight-practice.md`）；
- **清关文件**：西非多国要求 SONCAP（尼日利亚）/PVoC 等装运前认证（见 `trade-compliance/pre-shipment-coc-psi.md`）；**尼日利亚外汇管制**——客户付汇周期长是常态；
- **拼柜惯例**：多花色小批量（每花型 2-5 件×数十花型）——单证需列明每件花号明细（海关查验核对，见 `trade-process/export-customs-declaration.md`）；
- **汇率与回款**：奈拉/塞地剧烈波动——合同美元计价+收款优先路径（部分客户经迪拜转汇，警惕三方付汇合规，见 `trade-compliance/sanctions-screening-compliance.md`）。

## 四、市场趋势

- **本地产能崛起**：尼日利亚/加纳政策扶持本土印染厂（进口布关税上调压力）——长期看低端仿蜡出口承压；
- **消费升级**：中产转向超级仿蜡与真蜡染——国内厂升级双面渗透工艺有窗口期；
- **电商渗透**：Jumia 等平台销售面料——小 B 直采增长（见 `customers-market/africa-market.md`）；
- **二手衣冲击**：二手服装（见 `trade-process/used-clothing-export-trade.md`）挤压低端新布市场，但蜡染布因文化属性（节日必须新布）抗冲击强。
