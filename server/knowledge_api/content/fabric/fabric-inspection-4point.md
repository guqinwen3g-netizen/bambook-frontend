# 面料四分制检验与常见疵点（4-Point Fabric Inspection & Defects）

面料约占成衣成本 60%-70%，疵点面料流入裁剪将造成裁片报废与交期延误。外贸面料验货普遍采用**四分制（4-Point System）**（ASTM D5430），对疵点按长度记罚分，客观判定每卷面料是否合格。

## 一、四分制评分规则

### 罚分标准

| 疵点长度（英寸） | 疵点长度（毫米） | 罚分 |
|:---|:---|:---|
| ≤3" | ≤75mm | 1 分 |
| ＞3"-6" | 75-150mm | 2 分 |
| ＞6"-9" | 150-230mm | 3 分 |
| ＞9" | ＞230mm | 4 分 |

### 强制 4 分情形
- **破洞（hole）**：不论大小，2 根及以上纱线断裂即评 4 分/码。
- **连续性疵点**：横档（barre/barriness）、边中色差（side-center-side shading）、窄幅/幅宽不一、整幅折痕、染色不均等，每码评 4 分。
- 每直线码（linear yard）最高罚 4 分，不累加。

### 不计分情形
- 布边 1 英寸以内的疵点。
- 表面不可见疵点；轻微疵点（minor defect）不记录，只记主要疵点（major defect）。

## 二、计算公式与合格标准

**每 100 平方码罚分（points per 100 square yards, PPHSY）**：

```
PPHSY = (总罚分 × 36 × 100) / (受检码数 × 有效幅宽(英寸))
```

### 常用合格线（以 100 平方码计）

| 等级 | 罚分上限 | 典型客户 |
|:---|:---|:---|
| 高端/严苛 | 15-25 分 | 高端品牌、正装料 |
| 常规 | **40 分** | 多数外贸默认线 |
| 宽松 | 60 分 | 低端订单 |

- 单卷超过限值判为**二等品（seconds）**；整批平均分超限则整批不合格。
- 合格线须在**订单/品质协议中预先约定**，客户无约定时按 40 分执行。

## 三、抽样要求

- 常规抽检比例：**10%-20%** 卷数（按客户要求，高要求客户全检 100%）。
- 抽样规则：随机抽取；每种颜色至少抽 1-2 卷；多缸染色的须覆盖每个缸号（dye lot）。
- 大货须 100% 完成、≥80% 完成包装后验布员到场抽检；抽检卷确定后不得更换。
- 检验环境：验布机（inspection machine）、标准光源（D65）、匀速送布。

## 四、常见疵点分类与术语

### 织造疵点（Weaving Defects）
| 疵点 | 英文 | 说明 |
|:---|:---|:---|
| 断经/缺经 | broken end / end out | 经纱断裂或缺失 |
| 断纬/缺纬 | broken pick / missing pick | 纬纱断裂或缺失 |
| 双经/双纬 | double end / double pick | 并列两根纱织造 |
| 稀纬/薄段 | thin place / thin bar | 纬密不足 |
| 粗纬 | coarse pick | 纬纱过粗 |
| 纬缩 | weft loop / kinky weft | 纬纱打扭起圈 |
| 横档 | barre / weft bar | 横向条痕（连续性，4分/码） |
| 织洞 | hole | 纱线断裂成洞（4分） |

### 针织疵点（Knitting Defects）
- 漏针（dropped stitch）、抽丝（laddering/run）、花针（needle line）、断纱（broken yarn）、横条（barré，纱线批次张力差异）。

### 纱线疵点（Yarn Defects）
- 粗节（slub）、细节（thin place）、结头（knot）、异纤（foreign fiber，如棉中丙纶丝）、条干不匀（unevenness）。

### 染整疵点（Dyeing & Finishing Defects）
- 色差（shading/color variation）：缸差（lot to lot）、边中差、头尾差。
- 色斑/染料渍（dye spot/color stain）、油渍（oil stain）、锈渍（rust stain）。
- 折痕（crease mark）、预缩痕、白印（chafe mark）。
- 纬斜/纬弧（skew/bow）：染色布与印花布有不同限值（如 60" 幅宽染色布纬斜≤1.5"），超限整卷不合格。
- 手感异常：极光（glazing/摩擦发亮）、板结。

## 五、与验货流程衔接

1. **到厂检验（坯布/成品面料到货）**：四分制验布 → 出具验布报告（fabric inspection report），附疵点分布记录。
2. **超标处理**：二等卷退供应商或协商扣款/补数；整批超标拒收（rejection）并索赔。
3. **裁剪避让**：轻微超标卷可由裁剪车间**避裁（defect marking & cut around）**消化，记录用料损耗率变化。
4. **证据留存**：疵点拍照+尺量记录+卷号/缸号，作为对供应商索赔依据。
5. **关联检测**：四分制管外观疵点；克重、幅宽、密度、色牢度等仍按 testing-standards 文档另行检测（克重/幅宽允差通常 ±5%）。

> **报价与合同提示**：面料订单建议写明"按 ASTM D5430 四分制检验，100 平方码不超过 XX 分"及抽样比例，避免到料纠纷无据可依。
