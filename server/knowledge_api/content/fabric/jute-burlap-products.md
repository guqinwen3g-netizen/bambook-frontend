# 黄麻与硬质纤维制品（Jute & Hard Fibers: 麻袋/黄麻购物袋/剑麻/蕉麻）

黄麻（jute）是全球产量仅次于棉的天然纤维，**孟加拉+印度占全球 95% 产能**——这是少数中国不占主导的纺织原料赛道。硬质纤维（黄麻/剑麻/蕉麻）主打包装、地毯底布与环保袋，欧盟限塑令（SUP 指令）使黄麻购物袋成为棉花袋之外的环保替代主力。本文件梳理产地格局、产品谱系与外贸要点（纺织级麻纤维见 `fabric/hemp-bast-fibers-deep-dive.md`）。

## 一、原料格局与分级

- **产地垄断**：孟加拉（品质最优，白麻/红麻）+印度（西孟加拉邦）——中国基本不产，**黄麻是纯进口原料**（关税/汇率/孟加拉政局是三重变量）；
- **分级体系**：孟加拉按 TD1-TD8（色泽/强力/含杂）分级——TD3-TD4 是出口主流档；**雨季（6-9 月）沤麻品质波动大**，合同注明等级+拒收条款；
- **报价锚点**：孟加拉黄麻局（BJA）出口最低限价（MEP）政策——价格随政策与产量波动，长约用公式定价；
- **剑麻（sisal）**：坦桑尼亚/巴西/肯尼亚——硬度最高，猫抓板/抛光轮/地毯；**蕉麻（abaca）**：菲律宾——绳索/茶包纸/特种纸。

## 二、产品谱系

| 产品 | 规格要点 | 市场 |
|:---|:---|:---|
| 麻袋（gunny bag） | 粮食/咖啡豆/可可豆包装（50-100kg） | 西非/拉美农产品国——**年均损耗品，重复订单稳** |
| 黄麻购物袋 | 覆膜（PE 淋膜防水）+印刷+织带提手 | 欧美商超/品牌赠品（替代塑料袋叙事） |
| 黄麻地毯底布 | 机织底布（簇绒地毯基布） | 地毯厂配套（见 `garments/machine-made-carpets.md`） |
| 麻布/装饰麻布 | 粗纺布（桌旗/园艺/婚庆装饰） | 欧美 rustic 风格渠道 |
| 土工麻网 | 可降解护坡网 | 生态工程（降解是卖点——与 `fabric/technical-agro-geo-textiles.md` PP 网互补） |

## 三、外贸接单要点

- **黄麻袋 vs PP 编织袋**：黄麻胜在环保叙事+咖啡/可可行业传统（豆袋需透气性——PP 不透气存豆发霉）；PP 胜在价格——**竞标时先确认客户行业惯例**；
- **覆膜质量命门**：PE 淋膜附着力差→印刷掉色/脱层——验货做揉搓测试+胶带剥离；
- **印刷局限**：黄麻表面粗糙——**只适粗线条 logo 丝印**（1-3 色），精细图文建议织标或棉布袋替代（见 `garments/reusable-shopping-bags-production.md` 材质对比）；
- **气味与含杂**：沤麻不净带泥腥味+麻屑多——欧美商超订单要求脱臭处理与洁净度抽检；
- **食品接触**：咖啡豆/可可袋需无矿物油（批次含油率检测——黄麻软化用 BATCHING OIL 可能含芳烃，欧盟对食品接触麻袋有 PAHs 限量，检测见 `trade-compliance/testing-lab-selection.md`）；
- **验厂特殊性**：孟加拉/印度黄麻厂社会责任审核（童工/最低工资）是欧美买家必查——中国贸易商转口需保留产地证与验厂报告链（合规链同 `trade-compliance/uflpa-forced-labor.md` 追溯逻辑）。
