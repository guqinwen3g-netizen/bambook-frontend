# 蕾丝与花边面料专题（Lace & Embroidery Fabrics）

蕾丝（lace）是女装与内衣的"情绪面料"：工艺复杂、单价高、品质差异极大（法国顶级蕾丝与国产普通蕾丝价差 10 倍+）。选型与品控需要专门知识。

## 一、蕾丝分类

| 品类 | 工艺 | 特征 | 价位 |
|:---|:---|:---|:---|
| 列韦斯蕾丝（Leavers lace） | 法国加莱古董织机 | 最顶级（细腻/立体感） | ¥500-2000+/m |
| 车骨蕾丝（corded/guipure） | 粗线勾勒花型轮廓 | 立体厚重、婚纱主用 | ¥30-150/m |
| 水溶蕾丝（chemical lace） | 刺绣后溶解底布 | 镂空立体 | ¥20-80/m |
| 睫毛蕾丝（chantilly/eyelash） | 边缘睫毛状细须 | 轻柔、内衣/裙摆边 | ¥15-60/m |
| 拉舍尔蕾丝（raschel） | 经编机织 | 性价比、弹性好 | ¥8-30/m |
| 刺绣花边（embroidery lace） | 网布上机绣 | 可大货化、花型自由 | ¥10-50/m |

## 二、产业带与品牌

- **法国**：加莱（Calais）列韦斯蕾丝（Solstiss/Desseilles）——奢侈品牌指定；
- **中国**：福建长乐（花边产业集群，全球 60% 经编蕾丝产能）、广东汕头（内衣花边）、浙江绍兴；
- **价格逻辑**：列韦斯古董机全球存量固定（不可复制）——顶级蕾丝是"稀缺资产"。

## 三、绣花面料分类（Embroidery）

| 类型 | 工艺 | 应用 |
|:---|:---|:---|
| 平绣 | 平针刺绣（多色） | 时装/民族风/童装 |
| 珠片绣（sequin） | 亮片+珠管 | 礼服/舞台装/派对 |
| 盘带绣/绳绣 | 丝带/绳线盘绕 | 中式礼服/高定 |
| 立体绣/贴布绣 | 垫高/贴布组合 | 童装/卫衣 logo |
| 雕孔绣（eyelet） | 打孔+锁边 | 棉麻夏装（法式镂空） |

- **计价**：绣花按针数计价（万针单价×针数）；制版（digitizing）1-3 天；
- **风险点**：珠片绣洗后脱落/变色是客诉高发；底布与绣线收缩率差异→洗后起皱（预缩+材质匹配）；
- **国潮带动**：中式盘金绣/打籽绣元素需求上升（见 `garments/new-chinese-style-clothing.md`）。

## 四、采购关键参数

1. **幅宽**：蕾丝幅宽多为 1.4-1.5m（花边为条状按码计）；
2. **花回（pattern repeat）**：循环长度决定裁剪排料（对花裁剪用料率差 15-30%）；
3. **成分**：锦纶+棉+粘胶混纺常见；弹力蕾丝含氨纶；
4. **克重/密度**：薄透 vs 厚重的用途区分（内衣轻薄 vs 婚纱厚重）。

## 五、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 花型完整性 | 断线/缺花/错花（机绣跳针） |
| 对花一致性 | 匹与匹花型位置一致性（对花裁剪前提） |
| 染色均匀 | 蕾丝染色易花（锦纶/棉双组分染色工艺复杂——两相色差是常见疵点） |
| 强力 | 蕾丝轻薄易勾丝（勾丝测试） |
| 色牢度 | 内衣蕾丝耐汗/耐洗 |
| 幅宽稳定 | 蕾丝定型不稳定幅宽波动大（影响排料） |

## 六、裁剪与缝制要点

- **对花裁剪（pattern matching）**：婚纱/礼服必须对花——用料率增加 20-30%（报价必须计入）；
- **排花师**：蕾丝排花是技术工种（花型沿人体曲线走位——见 `garments/evening-wedding-dress.md`）；
- **缝制**：细针（9-11 号）+ 密针距防勾丝；法式包缝（french seam）处理蕾丝边缘；
- **拼接**：蕾丝与素色面料拼接的过渡工艺（贴布绣过渡/缎带包边）。

## 七、应用场景与成本

- **婚纱**：车骨蕾丝全身款用料 8-15m——蕾丝成本占婚纱面料成本 50-70%；
- **内衣**：睫毛蕾丝边缘装饰（见 `garments/underwear-lingerie-production.md`）；
- **女装**：蕾丝拼接/假两件（衬衫+蕾丝下摆）——低成本提升设计感；
- **成本优化**：主体用拉舍尔蕾丝+关键部位（领口/胸前）用车骨蕾丝——视觉焦点用好料。

## 八、现货与定制

- **现货 vs 定制**：现货花型快但同质化（电商撞款）；定制花型独家但 MOQ 高（蕾丝定制 3000 码+/开机费——摊薄成本）；
- **花型版权**：原创花型登记版权（国内外观专利）——仿花是行业痼疾，合同注明独家使用；
- **进口蕾丝**：法国 Solstiss（高定级）进口周期 4-6 周+单价 10 倍于国产；
- **可持续**：再生涤纶蕾丝/环保染整绣花线（品牌 ESG 询盘增加——见 `trade-compliance/textile-certifications.md`）。
