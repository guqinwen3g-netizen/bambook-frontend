# 鞋材面料与飞织鞋面（Shoe Materials & Flyknit Uppers）

运动鞋鞋面已从"裁片缝合"演进到"一体织造成型"（Nike Flyknit 2012 年开创）。鞋材是面料企业的横向延伸赛道：福建晋江/莆田、广东东莞、浙江温州为鞋材-鞋厂集群。核心品类：飞织鞋面、贾卡提花网布、三明治网布、超纤革。

## 一、鞋面材料谱系

| 材料 | 工艺 | 特征 | 应用 |
|:---|:---|:---|:---|
| 飞织鞋面（一体织） | 电脑横机 3D 成形 | 无裁片、轻量化、贴合脚型 | 中高端跑鞋/休闲鞋 |
| 贾卡提花网布 | 经编贾卡机 | 单层提花透气孔，性价比高 | 大众运动鞋主力 |
| 三明治网布 | 经编双面+间隔丝 | 缓震支撑、透气 | 鞋面/鞋垫/背包肩带（见 `fabric/mesh-netting-fabrics.md`） |
| 超纤革 | 无纺基材+PU 含浸 | 仿真皮、耐磨 | 鞋头/后跟补强 |
| 梭织/针织布 | 常规织造 | 帆布鞋面等 | 硫化鞋/板鞋 |

## 二、飞织鞋面生产要点

- **设备**：电脑横机（斯托尔/岛精/国产慈星）——14G/16G 为主流针型；一台机日产 8-15 双鞋面；
- **纱线组合**：涤纶低弹丝（主体）+热熔丝（加热定型锁结构）+氨纶（弹性区）+TPU 纱（耐磨区）——**分区喂纱编程是核心技术**（花型程序由版师按鞋楦数据开发）；
- **热熔定型**：织片下机后热压（130-160℃）使热熔丝熔化固结——温度/压力/时间三参数决定鞋面挺度；
- **后整理**：防水涂层/贴膜（防泼水款）、数码印花（见 `fabric/digital-printing-technology.md`）；
- **配套工序**：鞋面交鞋厂后高频焊接/热压 TPU 膜（装饰与补强）+车缝后跟+套楦成型——飞织厂通常只做到"鞋面半成品"。

## 三、品质指标

| 指标 | 测试 | 基准 |
|:---|:---|:---|
| 耐磨 | Martindale / 国标耐磨仪 | ≥25600 次（鞋面重点区域） |
| 耐折 | 常温/低温曲折 | 4-6 万次无裂纹（配合鞋底测试） |
| 剥离强度 | 贴合类材料 | ≥2.5kg/cm |
| 色牢度 | 摩擦/汗渍/水洗 | 同纺织通标（见 `trade-compliance/testing-standards.md`） |
| 黄变 | 耐黄变测试（UV/酚黄） | 白色浅色鞋材必测（4 级以上） |
| 尺寸稳定性 | 热收缩 | 热压后收缩率控制 |

- **飞织特殊项**：鞋面分左右脚、分码——**织错脚/错码是头号生产事故**（肉眼难辨），下机必须扫码配对+量楦抽检。

## 四、商业与接单要点

- **产业链位置**：鞋材厂→鞋面厂→鞋厂（成型）→品牌——中国鞋出口集中于代工（晋江系/莆田系），面料企业切入点是**给鞋面厂供差异化纱线/给品牌供新材料方案**；
- **开发周期**：新款鞋开发 3-6 个月（含试穿测试）——鞋材确认远早于量产，**材料卡（material card）入品牌库是关键门槛**；
- **认证**：品牌化学品 RSL 清单（Nike/adidas 的 RSL 严于法规）——见 `trade-compliance/chemical-environmental-compliance.md`；再生材料 GRS（鞋用再生涤需求大，见 `fabric/sustainable-fabrics.md`）；
- **起订与交期**：飞织鞋面 MOQ 3000-5000 双/色；旺季（Q2-Q3）横机产能紧张，锁产能需预付款；
- **报价逻辑**：按"双"报价——纱线成本+织造工费+后整理，热熔丝/功能性纱占比可达材料成本 40%。

## 五、趋势

- **可回收单一材质**：全涤鞋面（无 TPU 混纺）适配品牌闭环回收承诺（见 `trade-compliance/textile-waste-circularity-policy.md`）；
- **无水染色纱线**：鞋材色纱引入 dope-dyed（原液着色）降本+环保卖点；
- **4D 编织/袜套化**：鞋舌鞋身一体织减少组装工序；
- **对服装面料企业的启示**：横机/经编产能与鞋材互通——针织面料厂（见 `fabric/knitted-fabrics.md`）可评估贾卡机/横机产线延伸。
