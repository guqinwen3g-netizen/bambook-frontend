# 涤纶与化纤面料深度（Polyester & Synthetic Fabrics Deep Dive）

涤纶（polyester）是**全球第一大纤维**（占纤维总量 50%+）：便宜、耐用、功能可塑——快时尚与功能服的基础。理解化纤规格体系是面料采购的基本功。

## 一、涤纶规格体系

### 长丝（filament）规格
| 术语 | 含义 |
|:---|:---|
| D（旦尼尔） | 纤维粗细（75D/150D/300D——数字越大越粗） |
| F（根数） | 一束丝的根数（75D/72F——72 根细丝；F 数高手感软） |
| DTY | 拉伸变形丝（低弹丝——有蓬松感，针织/面料主力） |
| FDY | 全拉伸丝（有光/半光——里布/仿真丝） |
| POY | 预取向丝（半成品——DTY 原料） |
| ATY | 空气变形丝（仿棉感） |

### 短纤（staple）
- 涤纶短纤（仿棉/仿毛——与棉/毛混纺）。

## 二、涤纶面料主要品类

| 品类 | 特征 | 应用 |
|:---|:---|:---|
| 涤塔夫（taffeta） | 平纹细薄 | 里布/羽绒服面 |
| 春亚纺（pongee） | 稍厚平纹 | 里布/休闲服 |
| 桃皮绒（peach skin） | 磨毛表面 | 沙滩裤/休闲 |
| 色丁（satin） | 缎面光泽 | 礼服/里布/睡衣 |
| 雪纺（chiffon） | 轻薄飘逸 | 女装裙 |
| 牛津布（oxford） | 粗斜纹 | 箱包/帐篷/工装 |
| 涤纶针织 | DTY 针织（运动服——见 `fabric/knitted-fabrics.md`） | 运动/休闲 |
| 摇粒绒 | 见 `fabric/fleece-terry-fabrics.md` | 保暖 |
| 四面弹 | 涤氨弹力 | 运动/户外 |

## 三、涤纶的功能化（核心竞争力）

涤纶可通过改性/后整理实现功能（见 `fabric/functional-fabrics.md`）：
- **吸湿排汗（wicking）**：异形截面丝（coolmax 类——运动服）；
- **抗紫外线**：抗 UV 整理/添加；
- **抗菌**：银离子/抗菌母粒；
- **阻燃**：阻燃涤纶（工装/家纺）；
- **凉感**：玉石粉/凉感丝；
- **发热**：远红外/吸湿发热。

## 四、其他主要化纤

| 纤维 | 特性 | 应用 |
|:---|:---|:---|
| 锦纶（nylon） | 耐磨+弹性（比涤纶软） | 袜/泳装/户外（见 `fabric/swimwear-production.md`） |
| 腈纶（acrylic） | 仿毛（膨松保暖） | 毛衣/毛毯 |
| 氨纶（spandex） | 弹性（混纺 2-20%） | 弹力面料 |
| 粘胶（viscose） | 再生纤维素（吸湿柔软） | 女装垂感面料 |
| 莱赛尔（lyocell） | 环保再生（天丝） | 高端女装/床品 |
| 醋酸（acetate） | 真丝感 | 里布/礼服 |

## 五、涤纶 vs 棉（选型逻辑）

| 维度 | 涤纶 | 棉 |
|:---|:---|:---|
| 价格 | 低（约棉 1/2-1/3） | 高 |
| 吸湿 | 差（闷） | 好 |
| 耐用 | 强（耐磨抗皱） | 中 |
| 手感 | 滑（改良可仿棉） | 天然亲肤 |
| 易打理 | 快干免烫 | 皱缩 |
| 环保 | 石油基（再生涤改善） | 天然但耗水 |

- **混纺逻辑**：棉涤/CVC 平衡（棉的舒适+涤的耐用经济）。

## 六、再生涤纶（可持续主线）

- **再生涤纶（rPET）**：回收 PET 瓶纺丝（GRS 认证——见 `trade-compliance/textile-certifications.md`）；
- **品质**：再生涤纶与原生涤纶性能接近（主流品牌大量采用——Nike/Adidas 再生承诺）；
- **溢价**：再生涤纶溢价 10-20%（品牌可持续买单）。

## 七、采购要点

- **规格标注**：D/F 数+成分+克重+幅宽（规格不全=价格不可比）；
- **品牌原料**：仪征化纤/三房巷（原生）/ 再生看 GRS 证书；
- **产业带**：江苏盛泽（化纤面料全球最大集群）、浙江绍兴/萧山。
