# 薄纱织物深度解析（Sheer Fabrics: 欧根纱/巴厘纱/乔其纱/玻璃纱）

薄纱是"**低克重高透明**"的梭织面料家族：以细旦高捻/高密平纹实现透光与支撑的平衡，横跨窗纱、婚纱结构层、民族服饰披肩、舞台装饰四大应用带。技术要害在**捻度设计、硬挺整理与勾丝控制**——同名义品种下品质价差可达 3 倍。

## 一、品种矩阵与识别

| 品种 | 原料 | 结构特征 | 手感/外观 | 主应用 |
|:---|:---|:---|:---|:---|
| 欧根纱 organza | 涤纶长丝/真丝 | 平纹、高密、低捻 | **硬挺爽脆**、透明有骨感 | 婚纱蓬层、礼盒、刺绣底布 |
| 巴厘纱/玻璃纱 voile | 棉/涤棉/人棉 | 平纹、**强捻纱**、稀薄 | 柔软滑爽、半透明 | 窗纱、夏季衬衫、头巾 |
| 乔其纱 georgette | 真丝/涤纶 | 平纹、**S/Z 强捻交替** | 绉效应、垂坠飘逸 | 礼服、纱丽、丝巾 |
| 雪纺 chiffon | 涤纶/真丝 | 平纹强捻、比乔其更薄 | 轻盈飘逸、微绉 | 礼服外层、围巾 |
| 泡泡纱 seersucker（邻近） | 棉 | 双经轴张力差起绉 | 立体绉纹 | 夏装、童装 |
| 网纱 tulle（邻近） | 锦纶/涤纶 | 六角网眼（经编） | 硬挺蓬感 | 婚纱蓬裙、芭蕾 tutu |

- **欧根纱的"骨感"来源**：涤纶欧根纱=**轧光+硬挺整理（树脂/浆料）**；真丝欧根纱（生丝缎）=**丝胶未脱尽**的天然挺度——两者价差 5-10 倍，燃烧/溶解法鉴别；
- **巴厘纱 vs 玻璃纱**：中文语境常混用——巴厘纱偏服装级（细旦柔软），玻璃纱偏家纺/装饰（挺括透亮）；
- **雪纺与乔其的界限**：行业惯例以克重划——<75gsm 归雪纺，>75gsm 归乔其（非严格标准，报价需附规格书）；
- **网纱 tulle 属经编网眼**——与网布家族共享逻辑（见 `fabric/mesh-netting-fabrics.md`），本文不展开。

## 二、生产与整理要点

- **织造**：细旦高密平纹对织机状态敏感——**稀密路、断经、百脚是三大织疵**；强捻纱蒸纱定捻是巴厘纱品质前提；
- **印染**：涤纶薄纱分散染料**高温染色易折痕**——卷染/经轴染色优于绳状；浅色窗纱需**荧光增白**统一白度；
- **硬挺整理**：欧根纱树脂整理克重增加 5-15%——**整理量决定挺度与价格的正比关系**，洗后失挺是廉价品通病（婚纱一次性场景可接受）；
- **真丝类**：真丝乔其/雪纺砂洗做柔——真丝供应链见 `fabric/silk-linen-fabrics.md`；
- **检验**：薄纱**透光检验**（灯光台）能检出常规验布机漏掉的稀密疵——四分制应用见 `fabric/fabric-inspection-4point.md`。

## 三、应用带与商业要点

- **窗纱**：巴厘纱/玻璃纱做 sheers——阻燃要求（酒店 NFPA 701）与打褶倍数体系见 `garments/curtains-window-treatments.md`；**宽幅（280-300cm）窗纱**是溢价规格；
- **婚纱礼服**：欧根纱蓬层+雪纺外层——礼服结构应用见 `garments/evening-wedding-dress.md`、裙装蓬层见 `garments/dresses-skirts-production.md`；
- **民族服饰**：印度纱丽 dupatta 披肩大量用乔其/雪纺（数码印花——见 `garments/indian-saree-lehenga.md`）；中东头巾用高捻巴厘纱（透气+遮盖平衡——中东市场见 `customers-market/middle-east-market.md`）；
- **刺绣底布**：欧根纱作为**镂空绣/贴布绣底布**——水溶后保留绣花的特种工艺底布另议；
- **季节性**：窗纱随地产装修周期；礼服薄纱随婚庆季；头巾斋月前脉冲。

## 四、风控要点

- **勾丝与缝滑**：细旦长丝织物**勾丝（snag）与缝口滑脱（seam slippage）**是成衣投诉热点——服装用薄纱需做缝滑测试（ASTM D434）并限定针号（7-9 号细针+圆头针）；
- **纬斜**：稀薄平纹染整易纬斜——裁剪前按四分制验布必查（见 `fabric/fabric-inspection-4point.md`）；
- **透光度纠纷**："半透/微透"无量化标准——**封样双签+透光对比照片**留档；
- **荧光剂迁移**：白色窗纱荧光增白剂接触浅色家具可能迁移泛黄——酒店项目需耐光色牢度数据；
- **价格陷阱**：同名义"欧根纱"从 30D 到 75D、从有光到半光——**报价必须附旦数/密度/克重三要素**。
