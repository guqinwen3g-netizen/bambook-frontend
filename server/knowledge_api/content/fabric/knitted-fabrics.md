# 针织面料专题（Knitted Fabrics）

针织（knit）与梭织（woven）是面料两大织造体系。针织面料以线圈相互串套成布，具有弹性好、柔软透气、不易皱的特点，广泛用于 T 恤、卫衣、运动服、内衣、家居服等品类。外贸中"knit garment"订单占比极高，是我司核心业务之一。

## 一、针织 vs 梭织

| 维度 | 针织 knit | 梭织 woven |
|:---|:---|:---|
| 结构 | 线圈串套（loop） | 经纬纱交织（warp & weft） |
| 弹性 | 天然弹性好（尤其纬编） | 弹性小（靠氨纶补充） |
| 手感 | 柔软贴身 | 挺括有型 |
| 脱散性 | 会脱散（run/ladder） | 不脱散，会毛边 |
| 典型品类 | T恤、卫衣、内衣、运动服 | 衬衫、西装、牛仔裤、外套 |
| 克重表达 | GSM（克/平方米） | GSM 或 盎司/平方码 |

## 二、常见针织面料种类

### 1. 汗布（Single Jersey / 单面汗布）
- 最基础的纬编单面布，正面线圈柱、反面浮线弧，两面外观不同。
- 常用克重：140-220 GSM；纱支 20S-40S 棉或棉涤。
- 用途：T 恤、打底衫、家居服。
- 特性：易卷边（curling），裁剪前需松布。

### 2. 罗纹（Rib / 罗纹布）
- 正反线圈纵行交替配置（1×1、2×2 罗纹），横向弹性极大。
- 用途：领口、袖口、下摆（ribbing），也可做紧身衣。
- 关键参数：与主身布配色需对色（body/rib matching）。

### 3. 毛圈布（French Terry / 鱼鳞布）
- 一面平纹、一面毛圈（loop），毛圈未割断。
- 常用克重：220-320 GSM；可做抓毛（brushed/fleece）成卫衣绒。
- 用途：卫衣、运动套装、童装。

### 4. 卫衣绒（Fleece / 抓毛绒布）
- 毛圈布经抓毛（brushing）处理，绒面保暖。
- 分单面绒、双面绒（polar fleece 摇粒绒为全涤双面绒）。
- 用途：卫衣、外套内胆、家居服。

### 5. 珠地布（Piqué / 网眼珠地）
- 表面呈蜂窝状网眼，透气挺括。
- 常用克重：180-240 GSM；棉或棉涤。
- 用途：Polo 衫、高尔夫服、工服。

### 6. 双面布（Interlock / 棉毛布）
- 双面相同外观，结构紧密、不易卷边、手感厚实。
- 用途：高档 T 恤、婴儿服、内衣。

### 7. 提花/电脑提花针织（Jacquard Knit）
- 大圆机电子提花，可做图案与镂空效果，用于时尚女装。

### 8. 功能性针织
- 吸湿速干（coolmax 类）、抗菌、凉感针织布，运动订单增长快。
- 详见 `fabric/functional-fabrics.md`。

## 三、关键规格参数

| 参数 | 说明 | 示例 |
|:---|:---|:---|
| 克重 GSM | 克/平方米，决定厚薄 | T恤 160-200，卫衣 280-350 |
| 纱支 | 英支 Ne，越高越细 | 26S、32S、40S |
| 成分 | 棉/涤/粘胶/氨纶比例 | 95% Cotton 5% Spandex |
| 针数 Gauge | 圆机每英寸针数，影响细腻度 | 24G、28G、32G |
| 幅宽 | 实用幅宽（cuttable width） | 185cm / 72" |
| 缩水率 | 纬向/直向水洗后变化 | 直 -5% 纬 -5% 以内常见要求 |

## 四、针织面料特性与工艺要点

- **卷边（curling）**：单面汗布边缘卷曲，影响裁剪与缝制，需留缝份或做防卷处理。
- **脱散（laddering）**：剪口受力后线圈脱散，锁边（overlock）是必备工艺。
- **扭斜（spirality/torque）**：单面布洗后衣身扭曲，用低捻纱或定型控制，客户常要求 ≤ 5%。
- **缩水大**：针织结构松弛，预缩（compacting/compact 机）是棉针织布常规后整理。
- **弹性回复**：含氨纶（spandex/elastane）品种关注拉伸回复率与疲劳测试。

## 五、采购与报价要点

1. **报全规格**：成分 + 克重 + 纱支 + 幅宽 + 工艺（如"32S 精梳棉汗布 180GSM 185cm 丝光"）。
2. **克重公差**：通常 ±5%；客户验布用克重仪（GSM cutter）实测。
3. **大货与确认样对色**：针织布缸差（lot-to-lot shade）明显，每缸对色。
4. **用量核算**：针织按公斤计价（fabric by weight），排料核算单耗（kg/pc），克重浮动直接影响成本。
5. **起订量**：染色针织布 MOQ 通常 300-500kg/色；小单考虑现货布市场（广州中大、绍兴柯桥）。

## 六、常见疵点

- **横条（barre）**：纱线或喂纱张力不匀造成横向色条。
- **针路（needle line）**：纵向条纹，织针损伤所致。
- **油针（oil stain）**：圆机润滑油污染。
- **稀路、漏针、破洞**：织造断纱。
