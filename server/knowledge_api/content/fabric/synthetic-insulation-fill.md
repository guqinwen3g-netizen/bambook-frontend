# 仿羽绒与保暖填充材料（Synthetic Insulation: 喷胶棉/PrimaLoft/Thinsulate/Sorona）

保暖填充分两大体系：**天然羽绒**（见 `fabric/down-feather-raw-materials.md`）与**化学纤维填充**（仿羽绒/保暖棉）。化纤填充的核心优势：**成本仅羽绒 1/3-1/5、湿态保暖不崩、耐水洗、vegan 无动物成分**——快时尚棉服/睡袋/手套的绝对主力。材料话语权在**纤维配方与成棉工艺**，服装厂按克重采购。

## 一、产品谱系与性能阶梯

| 品类 | 结构 | 保暖水平 | 应用 |
|:---|:---|:---|:---|
| 喷胶棉 | 涤纶短纤+喷胶粘合定形 | 基础（CLO≈0.8-1.5/100g） | 低价棉服/靠垫 |
| 仿丝棉/软棉 | 细旦纤维+硅油滑爽处理 | 基础+手感升级 | 中端棉服/家纺 |
| 珍珠棉/球棉 | 纤维成球状（类羽绒朵） | 中（蓬松度提升） | 仿羽绒服/枕芯 |
| 杜邦 Sorona | PTT 生物基纤维（37% 玉米来源） | 中高+可持续叙事 | 品牌棉服 |
| 3M Thinsulate（新雪丽） | 超细纤维薄型高保暖 | 高（同厚度保暖 1.5 倍羽绒宣称） | 手套/鞋靴/薄款防寒服 |
| PrimaLoft | 超细拒水纤维（仿羽绒结构） | 高（Bio/Gold 系列对标 550-750 蓬羽绒） | 户外品牌（Patagonia 等） |
| Climashield | 连续长丝铺网（不钻绒不结块） | 高+耐压缩 | 军规睡袋/极寒装备 |

## 二、关键技术指标

- **克罗值（CLO）**：保暖量纲（1 CLO≈静坐办公环境舒适）——报价与客供技术协议的核心参数；同克重下：羽绒（550 蓬）>PrimaLoft Gold>Thinsulate>普通仿丝棉；
- **克重体系**：40-400g/m²（春秋款 60-100/冬款 120-200/极寒 250+）——服装厂按裁片面积算用量；
- **蓬松度与压缩**：化纤棉压缩率优于羽绒（真空收纳回弹）但**初始蓬松度天花板低**（PrimaLoft 最高对标 750 蓬——羽绒可达 900+）；
- **湿态性能**：化纤核心卖点——吸湿率<1%（羽绒湿后保暖归零）——**雨雪场景/可水洗**宣称锚点；
- **耐洗性**：喷胶棉水洗 10 次后结板（胶老化）；高端仿羽绒水洗 30 次+（品牌保用承诺按此测试）；
- **防钻绒**：连续长丝结构（Climashield）不钻绒——短纤类仍需防绒胆布（见 `garments/down-jackets-production.md` 的钻绒管控）。

## 三、采购与成本要点

- **计价方式**：按公斤/按码（成卷棉片）——克重×幅宽换算；**克重偏差±5%**（电子秤抽检——克重不足=保暖虚标）；
- **品牌填充授权**：Thinsulate/PrimaLoft/Sorona 需**品牌授权+吊牌**（3M/杜邦品牌授权体系——吊牌采购绑定用量核查，不可私自加标）；
- **再生填充**：GRS 认证再生涤纶填充（rPET 瓶片纺丝——见 `fabric/sustainable-fabrics.md`）——欧盟市场叙事刚需（溢价 10-20%）；
- **起订量与交期**：常规喷胶棉/仿丝棉现货（南通/常熟产业带）；品牌功能棉订货 2-4 周；
- **掺假雷区**："羽绒棉"营销词汇混淆（化纤棉冒充羽绒——GB/T 14272 羽绒服装标准**禁止羽绒棉标称羽绒**，见 `trade-compliance/china-domestic-standards.md` 的纤维含量标注）。

## 四、应用匹配与趋势

- **快时尚棉服**：仿丝棉 120-180g/m²+绗缝（优衣库式轻型棉服逻辑——压缩袋收纳卖点）；
- **户外中间层**：PrimaLoft/Climashield 类（湿冷环境中间层——替代抓绒的高端叙事）；
- **睡袋**：中空棉（四孔/七孔）多层结构——温标虚标重灾区（见 `garments/camping-gear-tents-sleeping-bags.md`）；
- **手套鞋靴**：Thinsulate 薄型优势（40-100g 不影响灵活性——见 `garments/gloves-production.md`）；
- **家纺**：仿丝绵被芯（可水洗被——酒店渠道刚需，见 `garments/comforters-pillows-bedding.md`）；
- **趋势**：生物基（Sorona）+再生（GRS rPET）+可降解填充（PLA 纤维棉——堆肥条件争议中）三线并进；PFAS 禁令下拒水处理转无氟体系（见 `trade-compliance/pfas-restriction-fluorine-free.md`）。
