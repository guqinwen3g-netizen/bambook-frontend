# 高端面料手感评价体系（Fabric Handle Evaluation: 主观触觉/客观仪器/KES-F/FAST 系统）

手感是高端面料的"**灵魂**"，也是最难量化的品质指标。Super 150s 与 Super 120s 的价格差异可达 30%+，但普通消费者难以分辨——**专业的手感评价体系是高端面料贸易的核心能力**。深度品控见 `fabric/premium-worsted-qc-testing.md`，精纺品牌见 `fabric/super-worsted-suiting-brands.md`——本文件聚焦**手感评价的主观体系与客观仪器检测**。

## 一、手感评价的主观体系

### 评价维度

| 维度 | 英文 | 描述 | 高端面料特征 |
|:---|:---|:---|:---|
| 柔软度 | Softness | 触摸时的软硬感 | 柔软但有骨感 |
| 丰满度 | Fullness | 握持时的充实感 | 丰满而不臃肿 |
| 滑糯度 | Smoothness | 摩擦时的滑爽感 | 滑糯如丝 |
| 活络度 | Liveliness | 弯曲时的弹性感 | 活络有回弹 |
| 悬垂感 | Drape | 悬挂时的下垂感 | 自然流畅 |
| 干爽度 | Dryness | 接触时的干爽感 | 干爽不粘腻 |

### 评价方法

- **盲评法**：遮盖面料标号，专业评手独立评价——**避免品牌/价格的心理暗示**；
- **对比法**：与标准样品对比评价——**"比标准样品更柔软/更丰满"**；
- **评分法**：1-10 分制，多人评分取平均——**"主观评价的客观化处理"**。

### 评价团队

- **专业评手**：5 年以上面料经验——**"手感是经验的积累"**；
- **评价环境**：恒温恒湿（20℃/65%RH）——**环境对手感有显著影响**；
- **评价时间**：上午 9-11 点——**"手部触觉最敏感的时间段"**。

## 二、KES-F 风格仪系统

KES-F（Kawabata Evaluation System for Fabrics）是日本京都大学川端季雄教授开发的**面料风格客观评价体系**。

### 四大测试模块

| 模块 | 测试项目 | 单位 | 手感关联 |
|:---|:---|:---|:---|
| KES-FB1 | 拉伸性能 | gf·cm/cm² | 弹性/活络度 |
| KES-FB2 | 弯曲性能 | gf·cm²/cm | 柔软度/硬挺度 |
| KES-FB3 | 压缩性能 | gf·cm/cm² | 丰满度/蓬松度 |
| KES-FB4 | 表面性能 | - | 滑糯度/粗糙度 |

### 关键指标解读

| 指标 | 符号 | 高端精纺标准 | 手感意义 |
|:---|:---|:---|:---|
| 弯曲刚度 | B | 0.05-0.12 gf·cm²/cm | 越低越柔软 |
| 弯曲滞后矩 | 2HB | 0.02-0.06 gf·cm/cm | 越低越活络 |
| 剪切刚度 | G | 0.8-1.5 gf/cm·degree | 影响悬垂性 |
| 压缩功 | WC | 0.15-0.30 gf·cm/cm² | 越高越丰满 |
| 表面摩擦系数 | MIU | 0.15-0.25 | 越低越滑糯 |
| 表面粗糙度 | SMD | 2-5 μm | 越低越细腻 |

### 风格向量

KES-F 将 16 个物理指标综合为**风格向量**：

- **硬挺度（Stiffness）**：与 B 值正相关；
- **光滑度（Smoothness）**：与 MIU/SMD 负相关；
- **丰满度（Fullness）**：与 WC 正相关；
- **柔软度（Softness）**：与 B/2HB 负相关。

> **应用**：通过 KES-F 数据，可以**客观比较不同供应商的面料风格**，或**验证标称支数与实际手感的一致性**。

## 三、FAST 快速评价系统

FAST（Fabric Assurance by Simple Testing）是澳大利亚 CSIRO 开发的**简化版面料风格评价系统**。

### 三大测试模块

| 模块 | 测试项目 | 手感关联 |
|:---|:---|:---|
| FAST-1 | 松弛/湿膨胀 | 尺寸稳定性 |
| FAST-2 | 弯曲/剪切 | 柔软度/活络度 |
| FAST-3 | 压缩/表面 | 丰满度/滑糯度 |

### 关键指标

| 指标 | 高端精纺标准 | 手感意义 |
|:---|:---|:---|
| 弯曲长度 | 25-35mm | 影响柔软度 |
| 剪切刚度 | 30-50 N/m | 影响悬垂性 |
| 压缩厚度 | 0.8-1.2mm | 影响丰满度 |
| 表面摩擦 | 0.15-0.25 | 影响滑糯度 |

### 与 KES-F 的对比

| 维度 | KES-F | FAST |
|:---|:---|:---|
| 测试精度 | 高 | 中 |
| 测试时间 | 2-3 小时 | 30-60 分钟 |
| 设备成本 | ¥500,000+ | ¥200,000+ |
| 适用场景 | 实验室/研发 | 工厂/贸易 |
| 数据维度 | 16 项 | 8 项 |

> **选择建议**：贸易公司日常品控推荐 FAST，品牌研发推荐 KES-F——**"FAST 是性价比之选"**。

## 四、手感评价的应用场景

### 1. 供应商评估

- **新供应商准入**：KES-F/FAST 检测+主观盲评——**"数据+经验"双重验证**；
- **定期质量监控**：每季度抽检——**"持续监控手感稳定性"**；
- **供应商对比**：不同供应商同类面料的客观对比——**"数据是最好的谈判筹码"**。

### 2. 产品开发

- **风格定位**：根据目标客群确定手感方向——**"商务客户偏好硬挺，时尚客户偏好柔软"**；
- **配方优化**：通过手感数据调整后整理工艺——**"柔软剂用量与手感的关系"**；
- **竞品分析**：拆解竞品面料的手感特征——**"Kiton 的面料为什么这么好？"**

### 3. 客户沟通

- **技术资料**：提供 KES-F/FAST 检测报告——**"数据是最好的销售工具"**；
- **样品确认**：客户盲评确认——**"让客户的手做决定"**；
- **品质承诺**：明确手感标准与验收方法——**"敢承诺才能赢得信任"**。

### 4. 质量争议

- **争议仲裁**：以封样+检测数据为依据——**"主观争议的客观化解决"**；
- **责任判定**：手感变化的原因分析（原料/工艺/后整理）——**"数据帮助定位问题"**；
- **赔偿标准**：手感偏差的量化赔偿——**"合同中的技术附件"**。

## 五、手感评价的局限与应对

### 局限性

- **主观性**：不同评手的评价差异——**"手感是主观的，没有绝对标准"**；
- **环境敏感性**：温湿度对手感的影响——**"同一批面料不同时间评价可能不同"**；
- **仪器局限**：KES-F/FAST 无法完全模拟人体触觉——**"仪器数据是参考，不是标准"**。

### 应对策略

- **标准化**：统一评价环境/方法/团队——**"减少主观差异"**；
- **多维度**：主观+客观+客户反馈——**"三角验证"**；
- **持续校准**：定期与标准样品对比——**"保持评价的稳定性"**。

## 六、贸易公司的手感评价能力建设

### 设备投入

| 设备 | 预算 | 优先级 |
|:---|:---|:---|
| 恒温恒湿箱 | ¥50,000-100,000 | 必需 |
| FAST 系统 | ¥200,000-300,000 | 推荐 |
| KES-F 系统 | ¥500,000-800,000 | 可选 |
| 标准样品库 | ¥20,000-50,000 | 必需 |

### 团队建设

- **专业评手**：3-5 人，5 年以上经验——**"手感是经验的积累"**；
- **定期培训**：每季度与标准样品对比——**"保持评价的敏锐度"**；
- **外部交流**：参加行业评价比对——**"与同行校准评价标准"**。

### 流程建设

- **评价流程**：盲评+对比+评分——**标准化流程**；
- **记录系统**：电子档案+纸质档案——**"数据是贸易公司的核心资产"**；
- **客户反馈**：定期收集客户手感反馈——**"客户的手是最终标准"**。
