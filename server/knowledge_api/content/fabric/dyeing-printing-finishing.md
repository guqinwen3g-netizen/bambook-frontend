# 面料染色、印花与后整理（Dyeing, Printing & Finishing）

染色、印花与后整理决定面料的色彩、手感与功能，也是外贸客诉高发环节。本文件覆盖常见工艺、术语与质检要点。

## 一、染色（Dyeing）

### 常见方式
- **成品质染色（piece dyeing）**：白坯布染成色布，颜色灵活、适用小单。
- **纱染（yarn dyeing）**：先染纱再织（色织），如色织布、牛仔、格纹。
- **散纤维染色（stock dyeing）**：纤维阶段染色，多用于混纺/精纺。
- **吊染/浸染（dip dyeing）**：渐变效果。

### 关键物性
- **色牢度（color fastness）**：耐水洗、耐摩擦、耐光照、耐汗渍。外贸订单通常要求 4 级（5 级最高）。
  - 耐水洗色牢度 washing、耐摩擦色牢度 rubbing（干/湿 dry/wet）、耐光色牢度 light。
- **同色性**：大货与确认样颜色一致（用灯箱 D65 光源对色）。

### 沟通要点
- 颜色用 **Pantone** 号或客户色卡对色，不用口头"偏深/偏蓝"。
- 确认**对色光源**（D65 日光 / TL84 商店光 / CWF 冷白光）。
- 深色与荧光色成本更高、牢度更难保证。

## 二、印花（Printing）

### 常见方式
- **数码印花（digital printing）**：图像精度高、无花位限制、适合小单/多花色。
- **平网印花（flat-bed screen printing）**：平整、精度较高，适合大花位。
- **圆网印花（rotary screen printing）**：产能高、适合批量化。
- **转移印花（transfer printing）**：多用于化纤。
- **活性印花（reactive printing）**：棉类，色牢度好、手感佳。
- **拔印（discharge）**：深底浅花。

### 沟通要点
- 明确**花位循环（repeat）**、套色数（number of screens/colors）。
- 确认**印花牢度**（水洗、摩擦）与环保染料要求（如是否禁用 AZO 偶氮染料）。
- 数码与平网/圆网成本结构不同，报价需按工艺区分。

## 三、后整理（Finishing）

### 常见整理
- **磨毛（brushed）**：柔软起绒，如抓毛、磨毛布。
- **压光/轧光（calendering）**：光泽平滑。
- **水洗（washing）**：软hand、缩水稳定，如普洗、酵素洗、石洗（牛仔）。
- **防水（water-repellent）**：如 DWR（durable water repellent）。
- **阻燃（flame retardant）**、**抗菌（anti-bacterial）**、**防紫外线（UV protection）**。
- **抗起球（anti-pilling）**：改善起球等级。
- **定型（setting）**：稳定尺寸与门幅。

### 沟通要点
- 后整理可能改变克重、缩水率与手感，需在大货前确认**洗后尺寸与撕破强力**。
- 功能整理有**环保/法规要求**（如防水剂 PFOS/PFOA 受限），详见合规文档。

## 四、常见外观/疵点（Fabric Defects）

外贸验布需识别常见疵点：
- 色条（shade bar）、色差（shade variation）、横档（bowing/skewing）。
- 断纱（broken yarn）、油污（oil stain）、破洞（hole）、粗节（slub）。
- 印花露白/套色不准（misregistration）、缩率不均。
