# 复合与涂层功能面料深度（Coating & Lamination Fabrics）

复合（lamination）与涂层（coating）是户外/功能性服装的核心面料技术：**防水透湿**（waterproof & breathable）矛盾统一靠膜技术实现。这是冲锋衣/滑雪服/防护服的面料基础。

## 一、技术原理

### 防水透湿膜
- **微孔膜**：孔径 0.1-10μm（水滴 100μm 进不来，水蒸气 0.0004μm 出得去）——PTFE（GORE-TEX）/PU 微孔膜；
- **亲水膜（无孔）**：PU 亲水涂层——靠化学基团"搬运"水蒸气分子（透气量低于微孔膜但防风好）；
- **指标**：耐水压（waterproof, mmH₂O）+ 透湿量（breathability, g/m²/24h）。

| 等级 | 耐水压 | 透湿 | 场景 |
|:---|:---|:---|:---|
| 防泼水（DWR） | <1,000mm | — | 小雨（仅表面处理，会失效） |
| 防雨级 | 3,000-5,000mm | 3,000-5,000 | 日常雨衣/轻户外 |
| 专业户外 | 10,000-20,000mm | 10,000-20,000 | 冲锋衣/滑雪服 |
| 极限（GORE-TEX Pro） | 28,000mm+ | 25,000+ | 登山/极地 |

## 二、复合结构

| 结构 | 说明 | 应用 |
|:---|:---|:---|
| **2 层（2L）** | 面料+膜（内里需加衬） | 性价比冲锋衣 |
| **2.5 层** | 面料+膜+薄印刷保护层 | 超轻便携雨衣 |
| **3 层（3L）** | 面料+膜+内衬网布一体 | 专业冲锋衣（耐用） |
| **三合一** | 外壳+可拆内胆（抓绒/羽绒） | 大众户外 |

- **贴合工艺**：热熔胶（PUR）点状复合（保住透气通道）vs 满幅复合（牢度高但透气差）；
- **剥离强度**：膜与面料的粘合牢度（≥ 8N/5cm 行业基准）——水洗后起泡发皱是剥离不足。

## 三、涂层工艺

| 涂层 | 特性 | 应用 |
|:---|:---|:---|
| PA（聚丙烯酸酯） | 性价比，手感可调 | 普通防雨/涂层里布 |
| PU（聚氨酯） | 柔软耐水解 | 中高防水 |
| PVC | 硬挺、全防水 | 雨衣/篷布（不透气） |
| 硅胶 | 耐高低温、防滑 | 特种防护 |
| 银胶/黑胶 | 遮光 | 帐篷/遮阳伞 |

- **转移涂层/离型纸工艺**：仿皮革质感（PU 革）——皮夹克/皮裙面料。

## 四、配套工艺与检测

- **压胶条（seam sealing）**：车缝针孔是漏水通道——接缝压胶条（热风压胶机）是防水成衣的必要工序（见 `garments/outerwear-jackets-production.md`）；
- **DWR 防泼水处理**：面料表面拒水整理（洗 5-10 次衰减，需修复剂）——**DWR ≠ 防水**（客户常见误解，报价时讲清）；
- **检测标准**：耐水压 AATCC 127/ISO 811；透湿 ASTM E96/JIS L1099（B-1 法）；剥离强度 ASTM D2724。

## 五、采购与报价要点

- **膜的品牌溢价**：GORE-TEX 需授权加工（Gore 认证工厂）；eVent/Tepor（东丽）/Dermizax 次之；国产膜（PTFE 国产线成熟）性价比方案；
- **报价结构**：基布 + 膜 + 复合加工费（复合费 8-20 元/米按层数）；
- **起订量**：复合面料 MOQ 1000-3000m（复合厂开机量）；
- **环保趋势**：PTFE 膜的 PFAS 问题（欧盟 PFAS 禁令波及——GORE-TEX 已推 ePE 无氟膜替代，见 `trade-compliance/chemical-environmental-compliance.md`）。

## 六、常见质量问题

| 问题 | 原因 |
|:---|:---|
| 水洗后起泡 | 剥离强度不足/胶耐水洗差 |
| 透湿虚标 | 检测方法差异（倒杯法 vs 正杯法数值差数倍——报告需注明方法） |
| 压胶条脱胶 | 压胶温度/压力参数不当 |
| 面料发硬（多次洗后） | DWR 失效+涂层水解 |
