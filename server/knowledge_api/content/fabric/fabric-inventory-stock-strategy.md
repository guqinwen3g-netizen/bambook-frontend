# 面料库存与备料策略（Fabric Inventory & Stock Strategy）

面料库存是双刃剑：备料支撑快反与交期确定性，但呆滞库存吞噬利润（服装面料过季贬值 30-70%）。核心是**分层备料 + 周转纪律 + 呆滞处置机制**。

## 一、备料决策框架

| 备料类型 | 适用 | 风险 |
|:---|:---|:---|
| **订单备料**（按单采购） | 常规订单 | 零库存风险，交期受面料周期制约 |
| **滚动备料**（畅销基础料安全库存） | 常年翻单品种（黑白涤塔夫/常规汗布） | 低——基础料不过时 |
| **趋势备料**（季节性流行料） | 提前锁定流行色/新品 | 高——流行判断失误即呆滞 |
| **客户锁定备料**（客户承诺包销） | 大客户年度协议 | 中——需书面承诺（口头承诺无保障） |

## 二、安全库存计算

- **基础公式**：安全库存 = 日均用量 × 采购周期 × 波动系数（1.2-1.5）；
- 例：某汗布日用 200m，采购周期 15 天，波动系数 1.3 → 安全库存 3900m；
- **快反模式**：Shein 类供应商备 3-7 天用量的现货池（见 `customers-market/fast-fashion-shein-model.md`）。

## 三、库存管理纪律

1. **账实一致**：面料仓按"缸号+匹号"管理（缸差追溯需要）；每月盘点；
2. **先进先出（FIFO）**：同品种面料按批次先进先出——存放超 6 个月的面料需重新检验（泛黄/脆化）；
3. **储存条件**：恒温避光（浅色面料泛黄）；针织布松卷存放（长期紧卷产生卷边记忆）；
4. **库存周转 KPI**：面料库存周转天数 ≤ 45-60 天为健康线；超 90 天启动呆滞预警。

## 四、呆滞面料处置

| 渠道 | 折价 |
|:---|:---|
| 内部消化（改款利用/样衣/促销品） | 全价 |
| 老客户转销（通知面料商友） | 7-9 折 |
| 面料市场现货商回购 | 4-7 折 |
| 尾货平台（库布/批布网） | 3-5 折 |
| 废品处理 | 残值 |

- **预防优于处置**：趋势备料设上限（≤ 面料月用量 20%）；订单取消的面料损失向客户追偿（合同条款）。

## 五、与供应商的库存协同

- **供应商寄售（VMI）**：战略面料商在厂设寄售仓——用多少结算多少，库存压力转移给供应商（份额承诺交换）；
- **联合备料**：与面料商共担趋势备料风险（各 50%）——绑定开发深度；
- **现货锁价**：行情低点锁价锁量（付 10-20% 定金），3 个月内分批提货。

## 六、面料行情分析

- **棉价**：郑棉期货 + Cotlook A 指数；新棉上市季（10-11 月）通常价格低点；
- **化纤**：PTA/MEG 期货传导涤纶价格（原油联动）；锦纶看己内酰胺；
- **采购节奏**：行情下行期推迟采购+压库存；上行期提前锁价——但**不赌行情**（贸易公司不是炒家，锁定利润为主）。

## 七、数字化管理

- 面料库存表：品名/缸号/颜色/数量/库龄/锁定状态（订单占用 vs 可用）——每日更新；
- 库龄看板：30/60/90 天分层预警；
- 与排产系统联动：下单自动检查面料库存可用量（避免重复采购）。
