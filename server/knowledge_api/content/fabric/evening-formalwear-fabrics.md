# 礼服面料专题（Evening & Formalwear Fabrics: 丝绒/提花/Barathea/缎面/罗缎）

礼服面料是正装体系的"**塔尖品类**"：tuxedo（无尾礼服）、晨礼服（morning coat）、燕尾服（tailcoat）的面料逻辑与日常西装截然不同——**光泽控制、纹理深度、仪式感重量**是核心。服务高端定制店与品牌正装线，必须掌握礼服面料的品类边界与选配规则。日常精纺面料见 `fabric/super-worsted-suiting-brands.md`，西装工艺见 `garments/suits-tailoring-production.md`。

## 一、礼服面料品类谱系

| 品类 | 特征 | 礼服应用 |
|:---|:---|:---|
| **Barathea（巴拉西娅）** | 细粒纹/卵石纹、哑光微光、悬垂挺括 | **Tuxedo 首选**——缎面驳领+Barathea 裤装是经典组合 |
| **丝绒（velvet）** | 割绒表面、光泽流动、色彩饱和 | 吸烟装（smoking jacket）/节日礼服——酒红/墨绿/藏青 |
| **提花（jacquard）** | 织入花纹（佩斯利/几何/花卉） | 婚礼礼服/宴会西装——低调提花优于印花 |
| **缎面（satin）** | 高光泽、平滑、反光强 | 驳领贴面/腰封/领结——**大面积使用易显廉价** |
| **罗缎（grosgrain）** | 横向凸纹、哑光、挺括 | 礼服裤侧缝/腰带——比缎面更克制 |
| **马海毛混纺（mohair blend）** | 光泽感+抗皱、挺括度极高 | 夏季礼服/热带正式场合——"亮而不闪" |
| **骑兵斜纹（cavalry twill）** | 粗斜纹、厚重、耐磨 | 日间礼服/骑马装——晨礼服裤装传统选料 |

- **配色铁律**：午夜蓝（midnight blue）是 tuxedo 的"隐形标准"——比黑色更黑（灯光下泛深蓝），黑色仅在日间礼服与极正式场合使用；
- **纹理逻辑**：礼服面料的纹理是"远看素色、近看细节"——Barathea 的卵石纹、提花的暗纹都在社交距离（1.5m）外不可见。

## 二、Tuxedo 面料体系（核心中的核心）

- **经典组合**：
  - 上衣：Barathea（午夜蓝/黑）或丝绒（彩色）
  - 驳领：缎面（grosgrain 罗缎为低调选项）
  - 裤侧缝：缎面条纹（braid）
  - 腰封：缎面或罗缎
- **季节变体**：
  - 夏季：高捻羊毛（fresco 类——见 `fabric/summer-suiting-fabrics.md`）+ 缎面细节，或马海毛混纺（mohair 30-50%）——**抗皱+微光是夏季礼服的刚需**；
  - 冬季：双面丝绒（double-faced velvet）/羊绒混纺 Barathea——保暖与仪式感平衡；
- **现代变体**：
  - "午夜蓝丝绒"：红地毯常客——**丝绒礼服是"可穿的艺术品"**；
  - "白色 dinner jacket"：热带/游艇晚宴——亚麻或棉质为主，非正装羊毛。

## 三、采购与品控要点

- **供应商格局**：意大利（VBC/Reda 礼服线）/英国（Scabal 礼服系列）/法国（Dormeuil Gala 系列）——**礼服面料占意英品牌册的 10-15% 但溢价最高**；
- **起订量**：礼服面料定织 MOQ 通常 100m（比常规面料 300m 低）——**礼服订单小、批次多是常态**；
- **检测重点**：
  - 光泽度一致性（缎面/丝绒的批次色差是退货高发区）；
  - 绒毛倒伏方向（丝绒必须同向裁剪——见 `fabric/velvet-faux-fur-fabrics.md` 绒毛方向管理）；
  - 干洗牢度（礼服 100% 干洗——见 `trade-compliance/chemical-environmental-compliance.md` 干洗溶剂标准）；
- **库存策略**：礼服面料周转慢（年 1-2 次）——**深备经典色（午夜蓝/黑/酒红），浅备季节色**（圣诞红/翠绿）。

## 四、搭配与禁忌

| 场合 | 面料组合 | 禁忌 |
|:---|:---|:---|
| 黑领结（black tie） | Barathea + 缎面驳领 + 罗缎裤侧条 | 全身缎面（"服务员感"） |
| 白领结（white tie） | 黑色燕尾服（绒面或 Barathea）+ 白背心 | 任何彩色面料 |
| 婚礼（新郎） | 提花/丝绒/浅色羊毛 | 与伴郎同款不同料（档次混乱） |
| 红地毯 | 丝绒/马海毛/午夜蓝 | 反光过强的合成缎面 |
