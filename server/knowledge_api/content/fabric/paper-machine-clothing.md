# 造纸网毯与纸机织物（Paper Machine Clothing: 成形网/压榨毛毯/干网）

造纸网毯（PMC）是造纸机的"**消耗性心脏部件**"：成形网、压榨毛毯、干网三大件随纸机 24 小时高速运转持续磨损，1-6 个月强制更换——**全球纸机存量=永续复购市场**。技术壁垒在织造精度与针刺工艺，单价高（毛毯每条数千至数万美元）、客户粘性极强。与工业过滤布同属"织造+针刺"工业纺织品族（见 `fabric/industrial-filter-fabrics.md`），但工况与标准体系独立。

## 一、三大产品线

| 产品 | 功能 | 材质/结构 | 寿命 | 单价带 |
|:---|:---|:---|:---|:---|
| 成形网（forming fabric） | 纸浆成形脱水——纸页成型面 | 聚酯单丝多层编织（双层/三层 SSB） | 1-3 个月 | 中高 |
| 压榨毛毯（press felt） | 压榨脱水+传递纸页 | 锦纶底网+羊毛/化纤针刺植绒（BOM） | 1-2 个月 | **最高** |
| 干网/干毯（dryer screen） | 烘缸部传递+透气 | 聚酯/锦纶螺旋环/平织+抗污染涂层 | 3-6 个月 | 中 |

- **成形网技术核心**：三层 SSB（sheet support binding）结构——**成形面细密（纸页质量）+底层粗耐磨（寿命）**；织口精度（经纬密度均匀性）决定纸页匀度；
- **毛毯技术核心**：针刺密度+绒层均匀性——**毯面印痕（felt mark）是纸病源头**；含毛量（羊毛/锦纶比例）影响脱水与寿命；
- **螺旋干网**：螺旋环穿丝连接——**环径一致性与接头平整度**是关键指标。

## 二、生产与品控要点

- **织造设备**：重型剑杆/片梭织机（幅宽可达 10 米+——**幅宽壁垒**：超宽织机投资巨大）；单丝原料（聚酯/锦纶单丝）自配拉丝或外购；
- **针刺**：毛毯针刺机（同针刺无纺布原理但精度要求高——见 `fabric/nonwoven-fabrics.md` 的针刺工艺）；
- **热定型**：网毯尺寸稳定性（运行中伸长率<1%）——定型张力+温度曲线锁定；
- **接头**：成形网无端织造（无缝）或插接——**接头处厚度突变=纸机运行隐患**，插接工艺是秘技；
- **检验**：透气度（CFM）、经纬密度、厚度均匀性、**动态模拟测试**（小型试验机跑合）。

## 三、市场与商业要点

- **需求结构**：**造纸厂 MRO 复购**（文化纸/包装纸/生活用纸/特种纸机）——单台纸机年耗网毯数十至上百万元；
- **客户粘性**：纸机调试换毯成本高（停机损失以小时万元计）——**供应商一旦验证通过极难替换**；新供应商切入靠"免费试用+驻厂服务"；
- **竞争格局**：国际三强（Albany/Valmet/Heimbach）占高端；中国厂商（四川环龙/江苏金呢等）中端放量——**出口主攻东南亚/中东/拉美新建纸机配套与替换**；
- **服务属性**：配毯工程师现场跟机（开机曲线调整）——**技术营销>价格营销**；
- **纸种适配**：生活用纸（软质毛毯护纸面）vs 包装纸（耐磨优先）vs 特种纸（定制）——选型表是销售工具。

## 四、风控要点

- **质量事故放大**：网毯断头/起皱=整批纸报废+停机索赔——**产品责任险必配**（见 `trade-compliance/product-liability-recall.md`）；
- **账期**：造纸厂账期 90-180 天常见——现金流压力（见 `suppliers/garment-factory-cash-flow.md` 同理逻辑）；
- **试用风险**：免费试用毯上机失败可能索赔停机损失——**试用协议限定责任范围**；
- **原料联动**：聚酯单丝价格随 PTA 波动（套保逻辑见 `trade-process/commodity-futures-hedging.md`）；
- **技术泄密**：配方/织造参数是核心机密——员工跳槽带走工艺是行业痛点（保密协议+竞业限制）。
