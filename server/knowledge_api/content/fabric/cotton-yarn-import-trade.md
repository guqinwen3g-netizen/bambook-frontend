# 棉花与进口棉纱贸易实务（Cotton & Imported Yarn Trading）

棉价是纺织产业链成本锚点。中国纺织业原料端三条路：国产棉（配额内收储体系）、进口棉（配额+关税）、进口棉纱（零关税通道，越南/印度/巴基斯坦纱为主）。面料厂与服装厂理解原料贸易逻辑，才能预判成本波动与报价窗口。

## 一、棉花贸易基础

- **定价基准**：ICE 美棉期货（美分/磅）+ Cotlook A 指数（远东到岸现货）+ 国内郑棉期货（元/吨）——三者价差驱动贸易流向；
- **进口配额**：关税配额 89.4 万吨/年（关税 1%）；配额外滑准税（价格越高税率越低，机制保护国内棉农）——**无配额企业外棉到岸成本显著高**；
- **加工贸易通道**：进料加工手册项下进口外棉免配额免关税（成品必须复出口）——见 `trade-process/processing-trade-bonded-manual.md`；
- **保税棉**：保税区仓储现货（青岛/张家港/上海）——"看货提单"模式，适合小批量急用；
- **质量指标**：马克隆值（3.5-4.9 主流）、长度（1-1/8" 为主）、强力、含杂——美棉/澳棉（机采一致性高）、巴西棉（性价比）、西非棉、印度棉（S-6）。

## 二、进口棉纱通道

- **零关税**：棉纱进口无关税配额限制（增值税 13%）——进口纱是中小织厂规避棉花配额的主流选择；
- **来源格局**：
  - 越南纱（C32/40 为主）：RCEP 零关税+交期 2 周，品质稳定；
  - 印度纱：量大价优，批次一致性差（夏季限电停产风险）；
  - 巴基斯坦纱：粗支纱成本最低；
  - 乌兹别克/中亚纱：新兴来源，中欧班列运输（见 `trade-process/china-europe-rail-freight.md`）；
- **贸易术语惯例**：CNF/CIF 中国主港+即期信用证或 DP——印巴纱商惯用"装船后传真提单副本催尾款"模式；
- **验货重点**：支数偏差（±2%）、条干 CV、棉结杂质、回潮率（8.5% 标准——**回潮超标=花纱价买水**）——到货抽验见 `suppliers/incoming-material-inspection.md`。

## 三、UFLPA 与溯源红线

- **涉棉出口订单铁律**：美国订单全链路（棉纱→坯布→面料→成衣）必须有**非疆棉证明**——采购合同写明原产地+留存发票/运输单据链（见 `trade-compliance/uflpa-forced-labor.md`、`trade-compliance/supply-chain-traceability-mapping.md`）；
- **混纺风险**：国产纱与进口纱混用=整批溯源失效——涉美订单专用纱线分区管理；
- **同位素检测**：海关抽检成本约 $2000/样——被扣货的举证成本远高于预防成本。

## 四、价格联动与报价策略

- **面料报价有效期**：棉价波动期（年度波动 20-30% 常态）报价单注明"价格有效期 7-15 天"或"按订单日棉价联动"（见 `fabric/fabric-procurement-quality-agreement.md`）；
- **锁价工具**：大厂用期货套保（郑棉/ICE）；小厂用"定金锁纱"（纱厂付 20-30% 定金锁价锁量）；
- **行情跟踪**：郑棉主力合约、Cotlook A、印度 S-6 现货、越南纱 FOB——每周记录四个数据即可判断趋势；
- **季节规律**：北半球新棉上市（10-12 月）价格承压；春季纺织旺季（3-5 月）价格偏强——接单报价参考 `trade-process/annual-sourcing-calendar.md`。

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 印度纱夏季断供 | 交期违约 | 备选越南纱供应商双轨 |
| 回潮率超标 | 隐性亏重 3-5% | 合同注明公定回潮结算 |
| 配额外采购外棉 | 成本失控 | 无配额走棉纱或加工贸易通道 |
| 混批纱染色差 | 布面横档 | 同批纱同缸染（见 `suppliers/dyeing-mill-cooperation-management.md`） |
| 期货投机代替套保 | 经营风险 | 套保比例 ≤ 实际用量 80% |
