# 香云纱（莨绸）面料（Gambiered Canton Silk: 非遗染整工艺）

香云纱是**唯一以植物染料+河泥媒染的真丝面料**（国家级非遗，广东顺德特产）：薯莨染液 + 塘泥反应 + 日晒脆化的"三蒸九煮十八晒"工艺不可复制——**黑色龟裂纹/两面异色**是识别标志。新中式高端化的旗帜面料。

## 一、工艺与品类

| 品类 | 底胚 | 特征 |
|:---|:---|:---|
| 莨纱（香云纱正统） | 桑蚕丝纱罗组织（提花纱罗） | 黑面棕底/龟裂纹/挺括沙沙响 |
| 莨绸 | 平纹/斜纹真丝底胚 | 同工艺，无纱罗孔眼 |
| 电力纺莨绸 | 电力纺底胚 | 现代量产型 |

- **工艺流程**：绸胚→薯莨液浸染（数十次反复）→**过乌**（顺德特定含铁矿河泥涂抹——铁离子与单宁反应变黑）→日晒→摊雾（夜间露水润泽脆化）→成品；
- **产地锁定**：顺德伦教（河泥成分+气候=工艺不可外迁——地理标志产品）；
- **产量**：手工操作+天气依赖（雨季停产）——年产有限=价格坚挺。

## 二、真伪与品质鉴别

| 鉴别点 | 真香云纱 | 仿品 |
|:---|:---|:---|
| 外观 | 黑面油光+棕底/龟裂纹理自然 | 涂层黑色/无两面异色 |
| 手感 | 挺括爽滑、抖动沙沙声 | 软塌或僵硬（树脂涂层） |
| 洗水 | 越洗越亮（包浆感） | 掉色/涂层脱落 |
| 成分 | 100% 桑蚕丝 | 化纤底胚+染色冒充 |

- **价格基准**：真品 ¥300-800+/米（姆米数与工艺批次）；仿品 ¥50-150（市场 80% 是仿品——采购索证：地理标志+检测报告）。

## 三、应用与订单要点

- **应用**：新中式上衣/旗袍/连衣裙/围巾（见 `garments/new-chinese-style-clothing.md`）——高端客群（40+ 女性/文化消费）；
- **裁剪缝制**：
  - 挺括面料**不可高温熨烫**（低温垫布）；针孔留痕明显——样衣先试针距；
  - 单层裁床（纱罗组织滑移——见 `suppliers/cutting-room-management.md`）；
- **洗护**：真丝洗护标准（干洗/冷水手洗——吊牌注明）；
- **储存**：避光防潮（真丝泛黄）；

## 四、采购与供应链

- **渠道**：顺德伦教厂家直采（晒莨场实地验厂）/非遗工坊合作；
- **起订量**：手工生产批量小（数百米级——提前 30-60 天订货，雨季顺延）；
- **叙事价值**：非遗+地理标志=品牌故事（出口高端线/文化 IP 联名——见 `customers-market/dtc-brand-clients.md`）；
- **出口合规**：真丝成分标识（fiber content——见 `trade-compliance/textile-fiber-names-regulation.md`）；非遗宣称需真实产地支撑（见 `trade-compliance/green-claims-anti-greenwashing.md` 宣称证据链）。

## 五、相关面料对比

| 面料 | 关系 |
|:---|:---|
| 宋锦/云锦/蜀锦 | 三大名锦（织锦提花——工艺不同：锦是织出来，莨是染出来） |
| 柞蚕丝 | 北方野蚕丝（粗犷——见 `fabric/silk-linen-fabrics.md`） |
| 电力纺/双绉 | 常规真丝（莨绸底胚原料） |
