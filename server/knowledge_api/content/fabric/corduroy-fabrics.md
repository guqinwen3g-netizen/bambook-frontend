# 灯芯绒面料（Corduroy Fabrics: 条绒规格与生产要点）

灯芯绒是**秋冬复古风经典面料**（裤装/外套/童装/帽子）：核心参数是**条数（wales/英寸）**，工艺难点在**割绒与刷绒**——绒条饱满度与掉毛率是品质分水岭。

## 一、规格体系

| 条数（wales/inch） | 类型 | 应用 |
|:---|:---|:---|
| 4-8 条 | 粗条（wide wale） | 外套/沙发/复古裤装 |
| 11-14 条 | 中条 | 裤装/夹克（主流） |
| 16-21 条 | 细条（pinwale/needlecord） | 衬衫/童装/女装 |
| 无条（平绒 velveteen） | 仿平绒 | 女装/装饰 |

- **成分**：全棉（主流——手感与绒感最佳）/棉弹（97/3 棉氨——裤装舒适）/涤棉（低价）/涤纶（玩具/家纺）；
- **克重**：200-350gsm（外套 280+；衬衫 180-220）。

## 二、生产工艺关键点

```
织造（纬二重组织）→ 割绒（割纬起绒）→ 刷绒/梳绒 → 染色/印花 → 后整理（柔软/预缩）
```

1. **割绒**：割绒机沿浮长线剖开——**割偏=绒条歪斜**（不可修复疵点）；
2. **刷绒**：绒条竖起均匀度（刷绒次数与张力）；
3. **染色**：还原/活性染料（深色绒面色光难控——缸差管理见 `suppliers/dyeing-mill-cooperation-management.md`）；
4. **后整理**：柔软+轻度刷毛定型；**预缩必做**（纬向缩水大）。

## 三、品质检验要点

| 检验点 | 标准/痛点 |
|:---|:---|
| 绒条饱满度 | 绒高均匀、无露底（底布外露=降级） |
| 掉毛率 | 摩擦掉毛（浮毛不净——成品抖落测试） |
| 倒顺毛 | **裁剪必须同一方向**（倒顺绒色差——排料方向性耗料增加 5-8%，见 `suppliers/cutting-room-management.md`） |
| 压痕恢复 | 绒面受压留痕（包装折叠/运输压痕——挂装或卷装出货） |
| 耐磨性 | 绒条磨损（裤装臀部/膝部——马丁代尔 ≥20,000 次，见 `trade-compliance/testing-standards.md`） |

## 四、采购与应用

- **产区**：江苏（常州/南通——灯芯绒传统产区）/浙江；全棉细条高端线集中常州；
- **起订量**：染色 500-1000m/色；现货丰富（柯桥/广州市场——快反走现货，见 `suppliers/fabric-market-sourcing.md`）；
- **应用**：复古裤装（秋冬主力）/工装夹克/童装背带/帽子（见 `garments/fashion-accessories-hats-scarves.md`）/沙发家纺；
- **时尚周期**：复古回潮（2024-2026 年 70s 复古风持续——灯芯绒需求上行）；

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 排料不分倒顺向 | 成衣色差报废 | 排料图标注绒向+裁床执行检查 |
| 折叠压痕 | 客诉退货 | 卷装/挂装运输（外贸 GOH——见 `garments/garment-packaging.md`） |
| 深色湿摩擦 | 掉色投诉 | 湿摩擦牢度 3 级+（深色加做皂洗固色） |
| 弹力款氨纶外露 | 绒条缝隙露白丝 | 氨纶包覆纱规格+染色工艺匹配 |
| 水洗款掉绒 | 水洗后绒秃 | 水洗工艺试片先行（酵素洗参数） |
