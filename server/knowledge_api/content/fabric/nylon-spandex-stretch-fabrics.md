# 锦纶氨纶弹力面料专题（Nylon & Spandex Stretch Fabrics）

弹力面料是**运动/泳装/内衣的物理基础**：锦纶提供耐磨与手感，氨纶提供弹性。"锦氨"组合是高端弹力面料的黄金搭档。

## 一、锦纶（Nylon / Polyamide）

### 特性
| 特性 | 说明 |
|:---|:---|
| 耐磨 | **纤维中最耐磨**（比涤纶强 10 倍） |
| 弹性 | 回弹性好（优于涤纶） |
| 手感 | 柔软滑爽（比涤纶高级） |
| 强度 | 高强度 |
| 吸湿 | 优于涤纶（4% vs 0.4%） |
| 缺点 | 耐热差/耐光差（日晒变黄）/价格高 |

### 锦纶面料品类
| 品类 | 应用 |
|:---|:---|
| 尼龙塔丝隆（taslan） | 户外冲锋衣/羽绒服 |
| 尼龙牛津 | 箱包/户外 |
| 锦纶针织 | 泳装/运动（锦氨——见 `fabric/swimwear-production.md`） |
| 锦纶长丝 | 袜/内衣 |
| 尼丝纺 | 轻薄羽绒面 |

## 二、氨纶（Spandex / Elastane / Lycra）

- **弹性纤维**：拉伸 5-8 倍回弹（混纺 2-20% 提供弹性）；
- **品牌**：**Lycra（莱卡）**= 英威达氨纶品牌（品质标杆——莱卡吊牌是卖点）；
- **规格**：20D/40D/70D（氨纶粗细——含量与弹力匹配）；
- **耐氯氨纶**：泳装专用（普通氨纶怕氯——泳池环境降解，见 `fabric/swimwear-production.md`）。

## 三、弹力面料结构

### 弹力方向
| 类型 | 说明 |
|:---|:---|
| 单向弹（2-way） | 仅纬向/经向弹力 |
| **四面弹（4-way stretch）** | 经纬双向弹（运动/瑜伽——全方位活动） |

### 锦氨针织（高端弹力主力）
- **锦纶+氨纶**（85/15 或 80/20）：泳装/瑜伽服/内衣——手感软糯+耐磨+弹性；
- **涤氨**：性价比弹力（运动服——耐磨略逊于锦氨但便宜）；
- **锦氨 vs 涤氨**：锦氨高端（手感/耐磨）/ 涤氨大众（价格）。

## 四、应用领域

| 应用 | 面料 |
|:---|:---|
| 泳装 | 锦氨（耐氯氨纶）——见 `fabric/swimwear-production.md` |
| 瑜伽/运动 | 锦氨/涤氨四面弹——见 `garments/activewear-production.md` |
| 内衣 | 锦氨（贴身弹性）——见 `garments/underwear-lingerie-production.md` |
| 户外弹力 | 锦纶弹力（软壳——活动量） |
| 牛仔弹力 | 棉氨牛仔（纬弹——见 `fabric/denim-fabric-deep-dive.md`） |
| 袜 | 锦纶+氨纶（见 `garments/socks-hosiery-production.md`） |

## 五、品质检验要点

| 项目 | 说明 |
|:---|:---|
| 弹性回复 | 拉伸回复率（弹性疲劳——洗后弹性保持） |
| 氨纶含量 | 实测含量（虚标氨纶——弹力不足） |
| 耐热 | 氨纶怕高温（定型温度限制——超温氨纶熔断失弹） |
| 耐氯 | 泳装耐氯测试（泳池环境） |
| 卷边 | 弹力针织卷边性（裁剪缝制难度） |

## 六、生产注意

1. **定型温度**：氨纶面料定型 ≤185°C（高温熔氨纶——弹性报废）；
2. **裁剪**：弹力面料松式裁剪（张力导致裁片回缩）；
3. **缝纫**：弹力线迹（绷缝/四线——线迹要跟着弹）；
4. **储存**：氨纶面料避光避热（氨纶老化——库存弹力面料时效）。

## 七、产业带

- **锦纶**：福建（长乐/晋江——锦纶产业集群）；
- **氨纶**：华峰/晓星（Hyosung——韩国氨纶巨头）/泰和；
- **弹力面料**：福建晋江（运动弹力面料）、广东（泳装锦氨）。
