# 夏季正装面料（Summer Suiting: Fresco/高捻羊毛/泡泡纱/亚麻/棉质体系）

夏季正装面料解决一个悖论：**在 30°C+ 保持正式感**。高捻羊毛的开放织法、泡泡纱的立体结构、亚麻的天然透气性构成三大技术路线。服务热带市场（中东/东南亚/南欧）与夏季婚礼季，夏季面料是高端供应商的差异化战场。冬季大衣呢见 `fabric/wool-overcoating-fabrics.md`，常规精纺见 `fabric/super-worsted-suiting-brands.md`。

## 一、技术路线对比

| 路线 | 原理 | 代表面料 | 正式度 | 适用场景 |
|:---|:---|:---|:---|:---|
| **高捻羊毛（high-twist）** | 纱线强捻→开放织法→空气流通 | Fresco（Harrisons 注册商标）/Crispaire（Dormeuil） | ★★★★★ | 商务正装/日间婚礼 |
| **泡泡纱（seersucker）** | 经纱张力差异→立体条纹/格纹 | 棉质泡泡纱/羊毛泡泡纱 | ★★★☆☆ | 美式南部/游艇/夏季婚礼 |
| **亚麻（linen）** | 亚麻纤维中空结构→天然透气 | 纯亚麻/亚麻羊毛混纺/亚麻丝混纺 | ★★★☆☆ | 度假/创意行业/非严格正装 |
| **棉质（cotton）** | 高支棉+特殊后整理 | 高支府绸/棉麻混纺 | ★★☆☆☆ | 休闲正装/夏季制服 |
| **马海毛（mohair）** | 马海毛纤维光泽+抗皱 | 马海毛 20-40% 混纺 | ★★★★☆ | 热带正式场合/夏季礼服 |

## 二、Fresco 与高捻羊毛（夏季正装之王）

- **技术本质**：纱线捻度比常规高 30-50%（强捻），织成开放组织（open weave）——**空气流通但外观密实**，抗皱性来自纱线自身张力而非树脂整理；
- **手感悖论**：初摸粗糙（"像砂纸"是新手误判），上身挺括——**高捻羊毛的"骨感"是夏季西装不贴身的根源**；
- **品牌体系**：
  - Harrisons of Edinburgh：Fresco 商标持有者——**"Fresco"一词被其注册，别家只能称"high-twist"**；
  - Dormeuil：Crispaire 系列；
  - VBC：Perennial 高捻线；
- **配色策略**：浅灰/米白/浅蓝——**深色高捻显热**，浅色反射阳光且视觉降温；
- **克重**：240-260g/m（比常规 280g 轻 15%）——**过轻（<220g）失去挺括度，过重失去透气意义**。

## 三、泡泡纱与亚麻（风格化路线）

### 泡泡纱（seersucker）
- **结构**：双经轴织造——地经张力正常、纹经张力松弛→布面自然起泡；
- **洗护优势**：起泡结构**免熨烫**（皱了也看不出来）——旅行西装首选；
- **风格边界**：蓝白条纹是经典，但**在保守商务场合仍被视为"休闲"**——金融/法律行业慎用；
- **升级路线**：羊毛泡泡纱（提升正式度）、深色泡泡纱（藏青/炭灰降低休闲感）。

### 亚麻（linen）
- **混纺策略**：
  - 亚麻 50% + 羊毛 50%：保留亚麻透气+羊毛抗皱——**夏季婚礼"不出错"选项**；
  - 亚麻 + 丝：光泽提升——晚宴/度假场景；
  - 高支亚麻（60s+）：细腻度接近棉——**高端亚麻西装面料价格 > 普通羊毛**；
- **客诉管理**：亚麻必皱——**销售话术"亚麻的皱是生活方式"**，并提供熨烫指南；
- **产区**：比利时/法国亚麻（欧洲亚麻协会认证）> 中国亚麻（纤维长度与均匀度差距）。

## 四、贸易与品控要点

- **季节刚性**：夏季面料 3-5 月下单、6-8 月交付——**错过窗口=库存一年**（见 `trade-process/annual-sourcing-calendar.md`）；
- **检测要点**：
  - 透气性（ASTM D737）——高捻面料必须提供实测数据；
  - 抗皱性（AATCC 128）——免烫声明需测试报告支撑；
  - 缩水率（亚麻预缩处理是必备——见 `fabric/fabric-pre-treatment.md`）；
- **库存风险**：夏季面料过季即贬值 50%——**浅备畅销色、快反翻单模式**（见 `fabric/fabric-inventory-stock-strategy.md`）；
- **价格带**：高捻羊毛 €25-45/m、亚麻混纺 €15-30/m、泡泡纱 €12-20/m——**夏季面料毛利率低于冬季 10-15%**（季节性竞争）。
