# 帆布与牛津布专题（Canvas & Oxford Fabrics）

帆布与牛津布是"**耐用型厚织物**"双雄：帆布偏天然（棉/麻）走箱包鞋材，牛津布偏化纤（涤/锦）走户外装备——两者撑起了箱包、帐篷、工装三大产业。

## 一、帆布（canvas）

- **定义**：平纹/斜纹粗厚棉织物（经纬多股线并合——"帆布"源于帆船用布）;
- **规格**：以盎司计重（oz/yd²——8oz 薄/12oz 中/16oz+ 厚）或号数（6/8/10/12 号——号小布厚）;
- **材质**：纯棉（主流）/涤棉（挺括低价）/麻帆布（复古）;
- **应用**：帆布袋（ tote bag——环保袋爆款）/帆布鞋（匡威/万斯经典）/工装/围裙/画框布/帐篷（传统棉帆布——透气但重）;
- **后整理**：染色/洗水（复古做旧）/涂层（PVC 贴合防雨——卡车篷布）/蜡感（油蜡帆布——英伦工装）。

## 二、牛津布（oxford）

- **定义**：平纹变化组织（纬重平/方平——双色效果源于色经白纬传统）;
- **两大分支**：
  - **衬衣牛津纺（oxford shirting）**：棉质薄型（经典扣领衬衫面料——见 `fabric/shirting-fabrics.md`）;
  - **箱包牛津布**：涤纶/锦纶长丝粗旦（210D/420D/600D/1680D——D 数越大越厚）;
- **箱包牛津布规格**：
  - **210D/420D**：里布/轻包（背包内衬）;
  - **600D**：双肩包主力（性价比之王——PVC/PU 涂层防水）;
  - **1680D 双股**：高端商务包（弹道尼龙手感——耐磨）;
- **涂层**：PU（软/环保方向）/PVC（硬挺/低价）/TPU（高端耐寒）——涂层次数决定防水与手感（一次 PU 轻防泼/三次 PU 耐水压 2000mm+）。

## 三、品质指标

- **耐磨**：马丁代尔（箱包面料 10,000 转+——见 `trade-compliance/testing-standards.md`）;
- **撕裂强力**：箱包关键（提手受力——抗撕裂磅数）;
- **色牢度**：摩擦牢度（深色帆布掉色投诉高发）;
- **防水**：静水压（帐篷 1500-3000mm/防雨罩 3000mm+）;
- **克重偏差**：±5%（帆布厚度影响用纱量成本）。

## 四、应用场景速查

| 应用 | 推荐面料 |
|:---|:---|
| 环保袋/帆布包 | 12-16oz 纯棉帆布（染色/印logo） |
| 帆布鞋 | 10-12oz 帆布+硫化工艺 |
| 双肩包主体 | 600D×600D PU 两次涂层 |
| 商务电脑包 | 1680D 双股 PU |
| 帐篷外帐 | 210T 涤塔夫涂银/牛津布 PU3000 |
| 工装外套 | 10-12oz 涤棉帆布（耐磨耐洗） |

## 五、采购要点

- **产地集群**：河北白沟（箱包牛津布——白沟箱包产业带配套）/浙江绍兴（全品类）/山东（棉帆布）;
- **现货为主**：牛津布花色现货充足（广州中大/白沟市场——起订量低适合快反）;
- **涂层定制**：防水等级/手感可定制（打样确认静水压）;
- **涤锦鉴别**：锦纶（尼龙）手感软+耐磨优于涤纶（价格高 30%——燃烧/手感鉴别）。

## 六、趋势方向

- **再生涤纶牛津布**：rPET 回收瓶片（GRS 认证——环保包袋营销，见 `trade-compliance/textile-certifications.md`）;
- **可提拉（Cordura）**：英威达品牌尼龙（高端战术包——授权吊牌）;
- **蜡感帆布复兴**：heritage 工装风潮（Filson 风格——油蜡夹克回潮）;
- **环保涂层**：水性 PU 替代溶剂型（DMF 残留合规——见 `trade-compliance/chemical-environmental-compliance.md`）。
