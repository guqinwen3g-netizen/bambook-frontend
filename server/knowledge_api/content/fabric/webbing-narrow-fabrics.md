# 织带与窄幅织物（Webbing & Narrow Fabrics: 提花带/松紧带/安全带）

织带是服装/箱包/装备的"骨架辅料"：提花 logo 带（品牌外露件）、松紧带（内衣裤腰）、背包带、汽车安全带。单价小但**用量大+品质事故影响大**（一根断带毁一件成衣）。产业带：浙江义乌/江苏南通/福建石狮。本篇覆盖采购与品质验收，配合辅料管理（见 `suppliers/fabric-accessories-supplier-management.md`）。

## 一、产品谱系

| 品类 | 工艺 | 材质 | 应用 |
|:---|:---|:---|:---|
| 平纹/斜纹织带 | 有梭/无梭织带机 | 涤纶/尼龙/PP/棉 | 背包带/挂带 |
| 提花织带 | 电脑提花织带机 | 涤纶为主 | 品牌 logo 带（外露件） |
| 松紧带 | 针织/编织（氨纶芯） | 涤纶包乳胶丝/氨纶 | 裤腰/袖口/口罩耳带 |
| 安全带 | 高强尼龙斜纹 | 尼龙 66 | 汽车/高空作业（强制认证品） |
| 魔术贴（粘扣带） | 钩面+毛面织机 | 尼龙 | 服装/鞋/医疗 |
| 包边带/滚边条 | 斜裁针织/梭织 | 涤纶/棉 | 内包边 |
| 反光织带 | 织带+反光膜复合 | 涤纶基 | 工装/宠物（见 `fabric/hi-vis-reflective-fabrics.md`） |

## 二、品质验收指标

- **断裂强力**：按用途定（背包带 ≥300kg、裤腰松紧不考核强力但考核**伸长率与回复率**——拉伸 50% 回复 ≥90%）；
- **色牢度**：摩擦/水洗/汗渍 4 级（织带与面料直接接触，移色投诉高发）；
- **尺寸稳定**：水洗缩率 ≤3%（松紧带预缩处理）；
- **厚度/克重一致性**：卷内与卷间差（影响车缝张力调校）；
- **魔术贴**：剥离强度+剪切强度+开合寿命（5000 次后保持 ≥70%）——钩面刮手检验（婴童用品用细钩/蘑菇头）；
- **有害物质**：镍释放（金属配件）、APEO（柔软剂残留）——婴童与皮肤接触类必测（见 `trade-compliance/chemical-environmental-compliance.md`）。

## 三、采购与报价要点

- **报价维度**：宽度（mm）+材质+克重/厚度+颜色+提花复杂度（换纱色数）——按"米"或"码"计价；
- **起订量**：现货常规色黑白无 MOQ；定染 3000-5000 米/色；提花带开机费（版费 200-500 元）+MOQ 5000 米；
- **交期**：常规 3-7 天；提花新开发 10-15 天（打样确认 logo 细节）；
- **定染色差**：织带染色缸差管理同面料逻辑（见 `fabric/color-management-pantone-measurement.md`）——**与面料同批配色时织带送染厂对色**；
- **品牌提花带**：logo 版权文件存档（授权书，见 `trade-compliance/ip-brand-authorization.md`）；提花稿留底防翻单重画。

## 四、安全带的特殊性（强制认证）

- **汽车安全带**：ECE R16/FMVSS 209——属安全部件，织带断裂强力 ≥26700N，耐磨/耐光/耐温测试全套——**非认证厂家不碰**；
- **高空作业安全带**：EN 361/ANSI Z359——PPE Ⅲ类（最高风险级，见 `trade-compliance/ppe-protective-clothing-compliance.md`）；
- **警示**：普通织带厂接"安全带外观订单"风险——客户拿去装安全产品，织带断裂=连带责任。**合同注明用途限制**（见 `suppliers/supplier-contract-risk.md`）。

## 五、应用侧配合要点

- **车缝匹配**：织带厚度变化→缝纫机压脚压力与针距调整（厚带跳针是常见次品）；
- **热切 vs 冷切**：织带末端热切封边（防散）——热切温度控制（过高发硬发黄）；
- **印刷织带**：丝印 logo 在织带上（升华/胶浆）——印刷牢度（弯曲摩擦测试）；
- **存放**：松紧带避光避热（乳胶丝老化——库存超 1 年抽检弹性，见 `fabric/fabric-inventory-stock-strategy.md`）。
