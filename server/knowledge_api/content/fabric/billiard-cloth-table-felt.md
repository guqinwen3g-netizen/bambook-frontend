# 台球呢与台面毡（Billiard Cloth: 精纺毛呢/斯诺克/美式落袋/扑克桌毡）

台球呢是"**精纺羊毛高密+绒毛方向性**"的专业台面织物：球速、走球精度、旋转响应全由呢面决定——斯诺克世锦赛指定英国 Strachan 6811、美式 Simonnis 为行业标杆，中国替代产能崛起。属精纺毛纺高端分支（羊毛基础见 `fabric/wool-cashmere-fabrics.md`）。

## 一、产品与材料

| 产品 | 材料 | 特征 |
|:---|:---|:---|
| 斯诺克/英式台呢 | 精纺羊毛 100%（高支高密——24-32oz） | 绒毛短匀——慢速精准（赛事绿） |
| 美式落袋台呢 | 羊毛+尼龙混纺（耐磨增强） | 球速快——蓝/酒红/灰流行色 |
| 中式黑八台呢 | 羊毛/混纺（耐高频使用） | 球房消耗品（6-12 月更换） |
| 扑克桌毡 speed cloth | 涤纶防水起绒 | 防水泼溅+滑牌顺畅 |
| 桥牌/麻将桌垫 | 呢绒/植绒 | 家用小件 |

- **幅宽壁垒**：斯诺克 12 英尺台——**呢面幅宽 1.98m 无拼接**（超宽幅精纺织机是设备壁垒）；美式 9 英尺台窄幅可拼（库边条单独裁）；
- **绒毛方向**：**顺毛/逆毛——走球方向性**（斯诺克从底库向顶库顺毛——铺呢方向错误=赛事事故）。

## 二、工艺链

- **纺纱**：精纺毛条（高支——条干均匀度定呢面）；尼龙混纺（美式耐磨）；
- **织造**：高密平纹/斜纹（密度定球速稳定性）——织疵零容忍（呢面档子=走球偏线，见 `fabric/fabric-defects-glossary.md`）；
- **染整**：缩绒（呢面起绒）+**剪毛（绒毛长度均匀——球速一致性关键）**+染色（赛事绿——色牢度耐光/耐摩擦——球粉 chalk 污染场景）；
- **检验**：呢面绒毛均匀度（目测+手感）、克重/幅宽、摩擦系数（走球速度实测）、抗静电。

## 三、市场与商业要点

- **球房渠道**：中式黑八球房国内爆发（俱乐部连锁扩张——**台呢 6-12 月高频更换=稳定复购耗材**）；换呢服务（换呢工团队——材料+施工打包）；
- **赛事体系**：世锦赛/职业赛指定呢（Strachan 垄断高端——**赛事认证是品牌背书天花板**）；国内赛事（乔氏/星牌球桌配套呢）；
- **家用市场**：亚马逊台球桌套装（7-8 英尺家用台——呢+配件配套）；扑克桌毡（家庭游戏室）；
- **出口**：东南亚球房扩张（越南/菲律宾黑八热）+中东（斯诺克流行——沙特大师赛）；
- **价格带**：斯诺克赛事呢 ¥800-1500/米（进口标杆）vs 中国替代 ¥200-500/米——球房经济性选择。

## 四、风控要点

- **绒毛方向标示**：卷装方向标（铺呢施工依据——错误方向整台报废）；
- **色差**：同球房多台球桌**同批次呢**（分批采购色差——球房形象投诉）；
- **仓储**：防潮防蛀（羊毛呢——仓储见 `suppliers/warehouse-moisture-mold-prevention.md`；防虫蛀剂合规）；
- **虚标**：克重/羊毛含量虚标是低价竞争顽疾——检测报告显示=中高端客户敲门砖。
