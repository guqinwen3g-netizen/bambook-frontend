# 女装时装薄面料专题（Women's Fashion Fabrics: Chiffon, Satin, Crepe）

女装薄面料是连衣裙/衬衫的"**垂感与光泽语言**"：雪纺透、缎面亮、双绉哑——选错面料直接毁掉设计稿的落地效果。

## 一、四大主力品类对比

| 面料 | 组织/工艺 | 手感光泽 | 典型用途 |
|:---|:---|:---|:---|
| 雪纺（chiffon） | 强捻经纬+平纹 | 轻薄微透/哑光/飘逸 | 连衣裙外层/罩衫/头巾 |
| 乔其（georgette） | 更强捻度+平纹 | 比雪纺略厚/颗粒感/更垂 | 连衣裙/礼服外层面料 |
| 缎面（satin） | 缎纹组织（浮长线） | 高光泽/滑爽/垂重 | 礼服/睡裙/衬衫（见 `garments/evening-wedding-dress.md`） |
| 双绉（crepe） | 强捻双向绉效应 | 哑光/微皱肌理/弹性垂感 | 衬衫/连衣裙（通勤主力） |
| 顺纡绉 | 单向强捻 | 竖向绉纹/轻薄 | 度假风连衣裙 |

## 二、材质路线

- **真丝**：高端（素绉缎/双绉/乔其——见 `fabric/silk-linen-fabrics.md`）;
- **涤纶仿真丝**：量产主力（75D/100D 雪纺珠/缎面雪纺——价格仅为真丝 1/5）;
- **醋酸**：高端平替（见 `fabric/acetate-fabrics.md`——光泽接近真丝且易打理）;
- **粘胶（人棉）**：垂感好价低（湿强低易变形——水洗款慎选，见 `fabric/regenerated-cellulose-fabrics.md`）;
- **弹力缎/弹力雪纺**：+5-8% 氨纶（修身裙/衬衫——注意氨纶对印花的限制）。

## 三、品质关键点

- **捻度均匀性**：雪纺/乔其绉效应靠强捻（捻度不匀=布面横档）;
- **勾丝（snagging）**：缎面浮长线易勾丝（箱包/指甲——试穿退货高发，针织包边款注意）;
- **纰裂（seam slippage）**：薄面料纱线滑移（缝口开裂——高密度规格+锁边工艺，出口欧美必测）;
- **透度与里料**：雪纺必配里布（弹力雪纺里布/50D 平板里——见 `fabric/linings-interlinings.md`）;
- **缩水**：人棉薄料缩水 5-8%（预缩/水洗工艺前置）。

## 四、印花与染色

- **数码印花主场**：薄料花型更新快（数码印花小单快反——见 `fabric/digital-printing-technology.md`）;
- **涤纶分散印花**：热转移（雪纺印花主流——色牢度好）;
- **真丝活性印花**：高端（手感无损）;
- **素色染色**：缸差控制（薄料透色明显——同一订单面料同缸号）。

## 五、工艺适配（成衣厂注意）

- **裁剪**：薄滑料移位（铺布层数限 30-50 层+压布）;
- **缝纫**：细针（7-9#）+细针距（13-15 针/3cm——防抽丝针洞）;
- **锁边**：来去缝/卷边（薄料毛边外露是低端标志——法式缝提升档次）;
- **熨烫**：低温（涤纶极光/真丝烫黄——垫布熨）。

## 六、采购要点

- **现货市场**：绍兴柯桥（雪纺/缎面现货花色最齐——50D/75D/100D 常规备货）;
- **起订量**：现货 1 卷起（约 100-150 米）/定织 3000 米+;
- **价格带**：涤纶雪纺 5-8 元/米/醋酸缎 25-40 元/米/真丝双绉 90-150 元/米（2026 行情参考）;
- **检测**：纰裂/勾丝/色牢度三件套（出口订单——见 `trade-compliance/testing-standards.md`）。

## 七、趋势方向

- **哑光醋酸缎**：低调光泽替代亮缎（极简风）;
- **褶皱肌理**：压褶/树皮皱（免烫卖点）;
- **再生涤纶雪纺**：rPET（环保营销——见 `fabric/sustainable-fabrics.md`）;
- **重磅真丝**：22/25 momme 重磅双绉（奢侈通勤风——真丝回潮）。
