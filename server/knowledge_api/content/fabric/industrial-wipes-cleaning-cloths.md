# 工业擦拭布与清洁巾（Industrial Wipes: 无尘布/超细纤维/木浆复合）

擦拭布是"**无纺布+超细纤维双技术路线**"的功能品类：从家用抹布到半导体洁净室无尘布，价格跨两个数量级。产业带：江苏/浙江（超细纤维针织）、广东/山东（水刺无纺布）、湖北仙桃（无纺布集群）。出口主线=工业 MRO 渠道+商超自有品牌清洁巾+洁净室耗材。

## 一、产品分层体系

| 层级 | 产品 | 材料/工艺 | 价格逻辑 |
|:---|:---|:---|:---|
| 家用清洁巾 | 超细纤维毛巾/魔布 | 80/20 或 70/30 涤锦复合超细纤维针织 | 按克重+数量（12 片装 $10-15） |
| 商用擦拭 | 餐饮抹布/洗车巾/玻璃巾 | 超细纤维经编/纬编、华夫格（waffle）组织 | B2B 按箱集采 |
| 工业擦拭布 | 重油污擦拭（替代棉纱头） | 木浆+PP 水刺复合（木浆丙）、熔喷 PP 吸油棉 | 按吸油率/掉屑率分级 |
| 无尘布（cleanroom wiper） | 半导体/光电/医药洁净室 | 超细纤维针织/梭织+**激光封边+超纯水清洗+无尘包装** | 按洁净等级（Class 10/100/1000）定价 |

## 二、超细纤维技术核心

- **纤维细度**：涤锦复合橘瓣型/海岛型开纤后单丝 0.1-0.5 dtex（头发的 1/100）——**比表面积大=吸附力+刮污力的来源**；
- **开纤工艺**：碱减量/机械开纤——开纤率决定手感与吸水性（开纤不足=发滑不吸水）；
- **锦纶比例**：锦纶（尼龙）提供吸水性，涤纶提供结构——70/30 比 80/20 吸水好但成本高；
- **组织设计**：毛圈（抛光）/华夫格（玻璃无痕）/平织（通用）/珍珠纹（去角质洁面巾）；
- **掉屑控制**：针织结构锁边质量——洁净室级必须激光/超声波封边（热切边掉纤）。

## 三、工业与洁净室级要害

- **木浆水刺复合（木浆丙）**：木浆吸水+PP 强力——DRC（双层）/木浆+熔喷+木浆三明治结构；定量 40-100gsm；**湿态强力**是工业擦拭核心指标（湿擦不烂）；
- **吸油棉**：熔喷 PP（亲油疏水）——只吸油不吸水（水面溢油应急物资）；
- **无尘布全流程**：织造（洁净车间）→ 超纯水多次清洗（去除油剂/离子）→ 洁净室分切封装——**发尘量（粒子计数）、非挥发性残留（NVR）、离子含量（IC 检测）**三大指标按 IEST-RP-CC004 标准；
- **客户认证**：半导体厂（台积电/三星体系）供应商认证周期 1-2 年——但一旦进入即长期绑定（耗材复购）。

## 四、市场与贸易要点

- **家用线**：亚马逊清洁巾类目——卖点=吸水倍数（宣称"7 倍自重吸水"需测试支撑）、不掉毛、快干抑菌；差评热点=洗后发硬、掉色、吸水性名不副实；
- **商用线**：洗车连锁/餐饮集团集采——定制 logo 印花/绣花，尺寸克重按用途分级；
- **工业 MRO**：美国 Grainger/Fastenal 类渠道——箱装擦拭布（按磅计价）+ 抽式盒装；进入渠道需 EDI 对接与仓配能力（见 `trade-process/overseas-warehouse-operations.md`）；
- **合规**：家用线化学安全（OEKO-TEX）；宣称"抗菌"需测试（AATCC 100）；**环保叙事谨慎**——超细纤维是微塑料脱落来源（洗涤脱落，见 `trade-compliance/microfiber-shedding-regulation.md`），法国等市场对该品类有立法关注；
- **一次性湿巾边界**：含液湿巾（消毒液/酒精）属卫生用品监管（美国 EPA/FDA 按用途分流）——纺织厂供基布即可，灌装环节需资质工厂。
