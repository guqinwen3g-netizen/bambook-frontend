# 跨境电商税务合规专题（Cross-Border E-commerce Tax）

跨境电商税务已从"灰色地带"进入"平台代扣+数据直连"时代：欧美平台销售税/VAT 由平台强制代扣——卖家合规重点是注册义务判断与申报准确性。

## 一、美国销售税（Sales Tax）

- **无联邦增值税**：州级销售税（45 州征收——税率 4-10%，州+县+市叠加）;
- **经济关联（economic nexus）**：2018 Wayfair 案后——某州年销售额超 $100,000 即触发该州注册申报义务（多数州取消 200 笔交易门槛）;
- **平台代扣（Marketplace Facilitator Laws）**：亚马逊/沃尔玛等平台**全州强制代扣代缴**（第三方卖家销售由平台收税——卖家无需逐州注册平台订单）;
- **卖家残留义务**：独立站（Shopify 自建站）销售需自行注册申报（超过 nexus 州）+部分州仍要求平台卖家注册备案;
- **库存关联**：FBA 库存存放该州即构成实体关联（历史遗留——部分州追缴独立站卖家）。

## 二、欧盟 VAT

- **税率**：19-27%（德 19%/法 20%/意 22%/匈 27% 最高）;
- **2021 电商 VAT 改革**：
  - **€150 以下进口包裹**：IOSS 一站式申报（平台代扣——亚马逊/速卖通注册 IOSS 代收 VAT）;
  - **平台视为供应商（deemed supplier）**：非欧卖家经平台销售——平台代扣 VAT（几乎所有场景覆盖）;
  - **取消 €22 免税**：所有进口包裹征 VAT;
- **OSS（Union One-Stop Shop）**：欧盟境内远程销售一站式申报（B2C 泛欧销售——单一申报覆盖 27 国）;
- **本地仓储义务**：FBA 泛欧计划（库存存德国/波兰仓）触发当地 VAT 注册（库存所在国注册不可免——平台代扣仍要注册）;
- **远程销售阈值**：全欧统一 €10,000（超阈值按目的国税率）。

## 三、英国 VAT

- **脱欧后独立**：标准税率 20%;
- **£135 规则**：低于 £135 商品销售时平台代扣 VAT（进口环节免——高于 £135 传统进口清关缴）;
- **平台代扣**：亚马逊英国站全覆盖;
- **注册义务**：英国仓储（FBA UK）即触发注册。

## 四、其他市场

- **中东**：沙特/阿联酋 VAT 15%/5%（跨境电商注册门槛——本地仓储触发）;
- **东南亚**：各国陆续开征（新加坡 GST 9%/印尼 11%/泰国 7%——平台代扣模式为主）;
- **拉美**：巴西复杂税制（见 `customers-market/brazil-market.md`）/墨西哥 16%（平台代扣）;
- **澳新**：GST 10%/15%（$1000 低值包裹平台代收）。

## 五、卖家合规清单

- **平台销售**：确认平台代扣范围（大部分场景已覆盖——留存代扣凭证）;
- **独立站销售**：自行判断注册义务（美国各州 nexus/欧盟 OSS）——Shopify 卖家合规重灾区;
- **本地仓储**：FBA 海外仓=注册义务（泛欧计划多国注册）;
- **申报准确性**：销售额与平台数据交叉验证（欧盟税局与平台数据直连——少报必被查）;
- **服务商**：跨境税务代理（VAT 注册+申报年费数千人民币/国——欧洲多国打包方案）。

## 六、违规后果

- **欧盟**：追缴+罚款+滞纳金（税局可要求平台冻结店铺——德国 VAT 证书缺失强制关店先例）;
- **美国**：州税局追缴（独立站卖家主要风险——平台代扣后风险大降）;
- **英国**：HMRC 要求平台对未注册卖家担责（平台严格审查 VAT 号）。

## 七、与传统 B2B 的关系

- **B2B 出口**：出口退税（见 `trade-process/export-tax-rebate.md`）+目的国关税（买家承担 DDP 除外）;
- **B2C 直邮**：9610/9710/9810 监管代码（中国出口申报——9810 海外仓模式退税适用）;
- **架构选择**：香港/美国公司主体运营（收款+税务筹划——专业顾问介入）。
