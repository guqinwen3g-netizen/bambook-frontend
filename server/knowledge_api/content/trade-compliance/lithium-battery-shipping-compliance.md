# 含锂电池产品运输合规（UN38.3/MSDS/空运海运规则/带电渠道）

带电纺织品（加热服、空调服、电热毯、智能穿戴）出口的第一道门槛不是产品认证而是**运输合规**：锂电池属第 9 类危险品，无 UN38.3+鉴定书的货物航空公司拒载、船公司拒收、快递渠道扣货。产品端认证（CE/FCC/UL）见各品类专文（`garments/heated-vests-electric.md`、`garments/smart-wearable-clothing.md`）——本文聚焦**运输链路的合规文件与渠道选择**。

## 一、适用规则与分类编码

| 情形 | UN 编号 | 空运包装指令 | 典型产品 |
|:---|:---|:---|:---|
| 单独运输锂电池（锂离子） | UN3480 | PI965（**客机禁运**） | 备用充电宝/电芯 |
| 与设备同箱（未安装） | UN3481 | PI966 | 加热服+散装电池 |
| 安装在设备中 | UN3481 | PI967 | 智能穿戴（内置电池） |
| 锂金属电池（纽扣等） | UN3090/3091 | PI968-970 | 传感器/遥控器 |

- **核心差异**：PI965 纯电池**仅限货机**且需 1.2m 跌落+9 类标签全危险品流程；PI967 内置电池走"例外数量"可简化——**产品设计优先内置电池方案**（运输成本差 3-5 倍）；
- **容量红线**：电芯 ≤20Wh/电池组 ≤100Wh 走简化流程（绝大多数穿戴产品在此区间）；超 100Wh 按全危险品申报（加热毯大功率电池组常踩线）。

## 二、三大必备文件

- **UN38.3 测试报告**：8 项测试（高度模拟/热冲击/振动/冲击/外短路/挤压/过充/强制放电）——**每款电池**单独测试，周期 2-3 周，费用 3-6k/款；换电芯供应商=报告作废重测；
- **MSDS（化学品安全说明书）**：16 项标准格式，电芯厂提供——注意版本年度更新（部分船公司只收当年版）；
- **运输条件鉴定书**：空运需**航空运输条件鉴别报告**（民航局认可机构出具，如上海化工院/迪捷姆），海运对应海运鉴定——**每票货随附**，报告有效期通常 1 年；
- **配套文件**：1.2m 跌落测试报告（PI966/967 包装件）、危包证（全危险品流程时）、电池规格书（标注 Wh 计算：额定容量 Ah × 标称电压 V）。

## 三、运输渠道实操

- **空运**：大陆机场对带电货物审查最严（需航司备案+逐票鉴定书）——行业惯例**香港起飞**（HK 作为自由港对 PI967 友好），深圳-香港卡车接驳是带电产品标准路径；
- **海运**：IMDG Code 下锂电池可按 SP188 豁免条款（≤100Wh 简化包装标记）——集装箱内电池**单独绝缘包装**（电极防短路——见 `garments/cooling-workwear-fan-jackets.md` 实操）；
- **跨境小包**：带电专线（云途/燕文带电渠道）承接内置电池产品，纯电池渠道少且贵——**申报必须如实标注"含电"**（瞒报被安检查获=整票退回+渠道拉黑）；
- **平台仓**：亚马逊 FBA 带电产品需提交**电池豁免表（Battery Exemption Sheet）**+UN38.3——危险品审核（Hazmat Review）周期 1-2 周，listing 提前规划；海外仓中转同理需 MSDS 备案。

## 四、风控要点

- **瞒报是死线**：电池瞒报被查获——机场安检扣货+发货人进黑名单+可能追究刑责（危险品谎报）；2024 年起各大航司带电瞒报**罚款 $10k+/票**；
- **文件一致性**：鉴定书上的电池型号、瓦时数与实物丝印**必须一致**（换电池供应商不换文件=查验扣货——见 `trade-process/customs-inspection-detention-response.md`）；
- **旺季前置**：年底空运旺季带电仓位紧张+鉴定机构排队——9 月前完成年度测试与文件更新；
- **目的国叠加**：日本 PSE（电池属电安法管制）、韩国 KC、运输合规≠产品准入——两套体系分别办理（产品认证矩阵见 `trade-compliance/testing-standards.md`）。
