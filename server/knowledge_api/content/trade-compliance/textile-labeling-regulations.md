# 全球纺织标签法规对照（Global Textile Labeling Regulations）

标签不合规是海关扣货与下架的高频原因——且是**最低成本可规避的风险**（设计阶段一次做对）。各国要求差异大，出口多市场需"标签矩阵"管理。

## 一、核心市场标签要求对照

| 要素 | 美国（FTC） | 欧盟 | 日本 | 中国 |
|:---|:---|:---|:---|:---|
| 纤维成分 | ✅ 强制（英文，重量降序） | ✅ 强制（1007/2011，目的国语言） | ✅ 强制（日文） | ✅ GB/T 29862 |
| 洗护符号 | 可用 ASTM 符号或文字 | ISO 3758 符号 | JIS L 0001（自有体系） | GB/T 8685 |
| 原产国 | ✅ 强制（永久缝附） | 非强制（但误导性标注违法） | 强制 | 强制 |
| 进口商信息 | 不要求 | 非强制（GPSR 要求责任人） | 要求 | 要求经销商 |
| 尺寸标 | 惯例 | 惯例 | 惯例 | 强制（号型） |

## 二、美国 FTC 规则要点

- **纤维成分**：通用名（generic name）+ 重量百分比降序；<5% 纤维可标"other fiber(s)"（功能性纤维除外须标明）；
- **商标使用**：商标不能替代纤维通用名（"Lycra® spandex" 格式——品牌+通用名）；
- **原产国**：领标/明显位置永久标注 "Made in China"；双语产品美加市场英法双语（加拿大要求）；
- **洗护**：2014 起 FTC 认可 ISO 3758 符号（美标 ASTM 也可用）；必须可耐久（经多次洗涤仍可读）；
- **RN 号**：美国企业可用 RN（Registered Identification Number）替代公司全名——中国出口商标进口商 RN 或全称。

## 三、欧盟标签（1007/2011）

- **纤维成分**：目的国官方语言（法国法语、德国德语...多市场需多语言标签）；
- **动物来源材料**：真皮/毛皮必须标注 "Contains non-textile parts of animal origin"；
- **特殊纤维名**：欧盟有官方纤维名录（如 "elastane" 而非 "spandex"）——美欧术语差异需转换；
- **原产国**：欧盟层面非强制，但法国/意大利等国有本国要求；误导性原产国标注违反反不正当竞争法。

## 四、日本标签

- **家庭用品品质表示法**：成分（日文）+ 洗护（JIS L 0001 符号——**与 ISO 有差异**：如干燥方式符号不同）+ 原产国 + 尺寸；
- 日文假名/汉字标注；进口商名称地址电话。

## 五、多市场标签策略

1. **标签矩阵表**：按目的国列出必需要素，设计阶段确认；
2. **主标+吊牌分工**：耐久性信息（成分/原产国）上主标；营销信息上吊牌；
3. **多语言标签**：欧线多国销售用 4-6 语言组合标（英法德意西荷）；
4. **洗护符号版本**：确认目的国符号体系（ISO vs JIS vs ASTM）——印错体系等于不合规；
5. **缝附位置**：成分/原产国标缝于明显位置（美国：领口；裤装：腰头内侧）；
6. **电子标签趋势**：欧盟 DPP（数字产品护照）推进中——未来 QR 码承载标签信息（见 `trade-compliance/esg-csrd-sustainability.md`）。

## 六、常见违规与后果

| 违规 | 后果 |
|:---|:---|
| 成分虚标（"100% cotton" 实为 T/C） | FTC 罚款+召回；职业打假（美国 class action 高发） |
| 原产国标错/遮盖 | 海关扣货+罚款（美国原产国标注违规可罚每票 $10,000+） |
| 语言不符（法国市场英文标签） | 下架+DGCCRF 处罚 |
| 洗护符号错体系 | 整改+客户索赔 |
| "有机/竹纤维"宣称无据 | 误导宣传处罚（澳 ACCC/美 FTC 均有处罚案例） |
