# 海关估价与审价应对（Customs Valuation & Audit）

海关估价决定关税基数：WTO《估价协定》以成交价格为基础——但关联交易、佣金、返利等调整项是审价争议高发区，低报漏报则面临补税罚款甚至刑事风险。

## 一、估价方法层级（WTO 协定顺序适用）

1. **成交价格法**：实付应付价格+调整项（首选——90%+ 案件适用）;
2. **相同货物成交价格**;
3. **类似货物成交价格**;
4. **倒扣价格法**（进口国转售价倒推）;
5. **计算价格法**（成本+利润构成）;
6. **合理方法**（兜底——禁止使用最低限价/武断价格）。

## 二、成交价格的调整项（计入 vs 不计入）

**计入完税价格（加项）：**
- 买方负担的佣金和经纪费（**购货佣金除外**——进口商自己的采购代理佣金不计）;
- 容器费和包装费;
- 协助费用（assists）：买方免费/减价提供的材料、模具、设计（服装业高发——客供面料/商标/纸样要分摊计入）;
- 特许权使用费（royalty）：与进口货物有关且构成销售条件（品牌授权费——出口方代垫商标费的审价争议点）;
- 转售收益分成（买方后续转售付给卖方的部分）。

**不计入（减项/排除项）：**
- 进口后运输费/保险费（CIF 国别差异——美国 FAS 计价不含国际运费）;
- 进口后安装/维修费（单独列明）;
- 进口国关税和国内税。

## 三、关联交易审价（转移定价交叉火力）

- **关联关系≠否定成交价格**：海关需证明关系影响价格（测试价格/销售环境审查）;
- **同时面临两线**：海关（低报关税角度——希望价格高）vs 税务局（转移定价角度——利润转移希望价格低）——两套逻辑可能矛盾，需同期资料自洽;
- **应对**：转移定价报告与报关价格一致性检查（年度对照表）。

## 四、低报风险（红线）

- **形式**：低报发票价/两套发票/品名瞒报（高税率品名报低税率——纺织 35% 报成辅料 10%）;
- **后果**：
  - 中国出口端：报关价格不实（海关行政处罚——影响信用等级）;
  - 进口国端：补税+罚款（美国 632 条款罚款可达货值数倍——刑事走私追责）;
  - 巴西/印度/土耳其等审价严格国：扣货+估价调增+黑名单（查验率 100%）;
- **买家要求低报**：坚决拒绝书面化（邮件留证——责任连带，改用合规筹划：合理利用 FOB 拆分/首次销售规则）。

## 五、合规筹划空间（合法节税）

- **首次销售规则（first sale rule）**：美国允许——多级贸易链条中，以工厂→中间商的首次销售价报关（非中间商→美国买家的最终价），节省关税基数（服装业经典筹划：香港贸易公司链条）;
- **费用拆分**：国际运费/保费单列（美国 FAS 口径——不计入完税价格）;
- **购货佣金架构**：进口商自设采购代理（佣金合规排除——协议与实际资金流一致）;
- **FTA 原产地**：估价不变但税率归零（见 `trade-compliance/tariff-rules-of-origin.md`）。

## 六、审价稽查应对

- **稽查形式**：单票审价（查验时质疑）/专项稽查（追溯 3-5 年）;
- **资料备存**：价格单证链（合同/发票/付汇凭证/价格构成说明——5 年保存期）;
- **磋商权利**：海关估价质疑→申辩→复议→诉讼（层级救济）;
- **预裁定**：美国 CBP ruling/中国海关预归类预审价（事先确定性——大额长期交易推荐申请）。
