# 俄罗斯与欧亚联盟 EAC 认证（EAC Certification for Textiles: TR CU 017）

输俄罗斯/白俄罗斯/哈萨克斯坦等欧亚经济联盟（EAEU）的服装家纺，**EAC 符合性标志是清关与销售前提**——无 EAC 证书/DOC 货物到港无法放行。核心是技术法规 TR CU 017/2011《轻工业品安全》。

## 一、法规框架

- **EAEU 五国**：俄罗斯、白俄罗斯、哈萨克斯坦、亚美尼亚、吉尔吉斯斯坦（一证五国通用）；
- **TR CU 017/2011 轻工业品安全**：覆盖服装/家纺/面料/皮革制品；
- **EAC 标志**：符合性标志（贴吊牌/包装——无标商品禁止销售，电商同样要求）。

## 二、认证形式（按接触皮肤程度分级）

| 形式 | 适用 | 要点 |
|:---|:---|:---|
| EAC 合格证书（CoC） | 内衣/童装/袜类等**直接接触皮肤**（第一层） | 认证机构发证+测试报告+部分需工厂审核；有效期最长 5 年 |
| EAC 符合性声明（DoC） | 外衣/家纺（第二、三层） | 申请人自我声明+证据（测试报告）注册备案——成本低于 CoC |
| 豁免函（ rejection letter ） | 不在管制目录的品类 | 清关辅助文件 |

- **童装**：3 岁以下童装要求最严（CoC 强制+国家注册证 SGR 部分品类——见 `garments/childrenswear-production.md` 童装安全逻辑）；
- **申请主体**：**必须是 EAEU 境内法人**（进口商/授权代表——中国工厂不能持证，需俄进口商或授权代表公司申请）。

## 三、办理流程与文件

1. **定级**：HS 编码+用途→确定 TR CU 017 层级（第一层/第二层）与形式（CoC/DoC）；
2. **测试**：俄认可实验室（GOST 体系——成分/色牢度/甲醛/pH/偶氮，指标与国标逻辑相近但标准号不同）；
   - 已有 GB/ISO 报告可作参考，但发证机构通常要求俄本土/联盟认可实验室报告；
3. **申请**：经进口商/授权代表提交（技术文件：说明书/成分标/合同/发票）；
4. **发证**：CoC 1-4 周（含测试）；DoC 3-7 天（有报告前提下）；
5. **贴标**：EAC 标志（≥5mm）+ 俄文标签（成分/洗护/原产国/进口商信息——见 `trade-compliance/textile-labeling-regulations.md` 俄标签要点）。

## 四、费用与周期参考

| 项目 | 参考 |
|:---|:---|
| CoC（含测试） | ¥1.5-4 万/系列，3-4 周 |
| DoC | ¥3000-8000，1 周 |
| 授权代表服务 | 年费制（无俄进口商时租用——注意持证人风险） |
| 工厂审核（部分 CoC） | 视机构 |

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 货到港无 EAC | 退运/销毁 | 接单确认客户清关能力（客户持证 or 代办） |
| 证书型号覆盖不全 | 部分款式被扣 | 证书附件列全款式/成分 |
| 授权代表"持证人"风险 | 证书被代表公司绑架 | 合同约定证书使用权/自建俄主体 |
| 俄文标签不合规 | 市场抽检罚款 | 标签俄文强制（成分/进口商/生产日期） |
| 灰关清关 | 罚没+刑事风险 | 坚持白关（俄罗斯市场灰关历史包袱——见 `customers-market/russia-central-asia-market.md`） |

## 六、市场联动

- **制裁环境**：欧美品牌退出后中国服装份额扩大（平行进口并存——注意品牌授权风险，见 `trade-compliance/ip-brand-authorization.md` 与 `trade-compliance/sanctions-screening-compliance.md`）；
- **渠道**：Wildberries/Ozon 电商崛起（平台要求 EAC 文件上传——见 `customers-market/russia-central-asia-market.md`）；
- **支付**：受制裁银行结算受限（VTB/人民币结算通道——见 `trade-process/foreign-exchange-settlement.md`）。
