# 付款方式（Payment Terms）与收汇风险管理

付款方式是外贸合同的核心条款之一，直接决定出口企业的**收汇风险**与资金占用。纺织服装外贸常见的付款方式包括电汇（T/T）、信用证（L/C）、付款交单（D/P）、承兑交单（D/A）与赊销（O/A）。选择何种方式需综合客户信用、货值、市场惯例与风险承受能力。

## 一、主要付款方式总览

| 方式 | 英文 | 资金与风险 | 适用场景 |
|:---|:---|:---|:---|
| 电汇 | **T/T**（Telegraphic Transfer） | 买方银行电汇，风险取决于预付比例 | 最常用，新老客户均可 |
| 信用证 | **L/C**（Letter of Credit） | 银行信用，单证相符才付款 | 大额、新客户、中东/非洲部分市场 |
| 付款交单 | **D/P**（Documents against Payment） | 买方付款取得单据 | 商业信用较强的市场 |
| 承兑交单 | **D/A**（Documents against Acceptance） | 买方承兑后取单，到期付款 | 老客户赊销 |
| 赊销 | **O/A**（Open Account） | 买方收货后约定账期付款 | 高信任长期客户 |

## 二、T/T 电汇详解

- **前 T/T（T/T in advance）**：买方先付定金（常 30% 预付 + 70% 见提单副本/发货前付清），出口商风险低。
- **后 T/T（T/T after shipment）**：先发货后收款，买方凭提单副本付款，风险较高，需评估客户信用。
- 常见组合：**30% 预付 + 70% 发货前付清**，或 **30% 预付 + 70% 见提单副本**。
- 优点是灵活、手续费低；缺点是**依赖商业信用**，无银行担保。

## 三、L/C 信用证

- **即期信用证（at sight L/C）**：单证相符即付款，出口商收款快。
- **远期信用证（usance L/C）**：承兑后到期付款，常见 30/60/90 天。
- 关键概念：开证行（issuing bank）、通知行（advising bank）、**单证相符（documents comply）**、软条款（soft clause）。
- 对纺织出口商：务必审证，避免"软条款"（如下船后复检、货到港检验）导致无法收汇。
- 优点：银行信用、安全性高；缺点：手续费高、制单严格、开证行资信需核实。

## 四、D/P 与 D/A 托收

- **D/P 付款交单**：进口商付款后取得提货单据，属**商业信用+一定程度保障**。
- **D/A 承兑交单**：进口商承兑汇票即取单，到期再付款，风险更高（已放货）。
- 托收（collection）不经银行信用担保，若买方拒付/拒赎，出口商需自行处理货物，务必投保**出口信用保险**。

## 五、O/A 赊销

- 先发货、后按账期（net 30/60/90 天）收款。
- 仅适合信用优良、多次合作的长期客户，建议配合**出口信用保险（export credit insurance）**与**应收账款融资（factoring）**。

## 六、收汇风险防范要点

1. **新客户**：优先 T/T 预付或 L/C，不做 O/A。
2. **大额订单**：用 L/C 或"预付+发货前付清"。
3. **高风险国别**（政局不稳、外汇管制）：提升预付比例或要求 T/T+保险。
4. **投保出口信用保险**：覆盖买方商业风险与政治风险（如中国信保）。
5. **审单审证**：L/C 必审，软条款一律拒绝；制单做到"单单一致、单证一致"。
6. **保留提单控制权**：未收齐货款前谨慎放单（尤其 D/A）。
