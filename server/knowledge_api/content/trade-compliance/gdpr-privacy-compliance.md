# GDPR 与电商数据合规（GDPR & Privacy Compliance）

做欧洲 B2C（独立站/平台）必然处理欧盟用户数据：GDPR 罚款上限全球营收 4%——独立站卖家是中小卖家合规重灾区。

## 一、适用范围（触发即管辖）

- **地域原则**：向欧盟境内个人提供商品/服务（哪怕公司在中国——独立站发欧洲即适用）;
- **个人数据**：姓名/地址/邮箱/电话/IP/Cookie ID/购买记录（电商全链路数据都算）;
- **B2B 例外**：纯 B2B 公司信息不适用（但联系人个人邮箱仍属个人数据）。

## 二、核心义务清单（独立站落地）

| 义务 | 落地动作 |
|:---|:---|
| 隐私政策（Privacy Policy） | 网站公示（收集什么/用途/保存多久/第三方共享——模板需定制） |
| Cookie 同意 | 横幅弹窗（**同意前不得加载追踪 Cookie**——默认拒绝，欧盟罚款高发点） |
| 用户权利响应 | 访问/更正/删除/导出（30 天内响应——邮箱受理通道） |
| 数据最小化 | 结账只收必要信息（注册非强制——游客结账） |
| 安全措施 | HTTPS/支付 PCI（不存信用卡全号——走 Stripe/PayPal 托管） |
| 数据出境 | 欧盟数据传中国服务器需 SCC 标准合同条款（Shopify/云服务商多已内置） |

## 三、营销合规（罚款高发区）

- **邮件营销**：必须事先明确同意（opt-in——不得预勾选/不得买名单群发）;
- **退订**：每封营销邮件一键退订（退订后立即停止）;
- **再营销像素**：Meta/Google Pixel 属追踪（Cookie 横幅未同意前不加载——德国/法国监管重点）;
- **Klaviyo/Mailchimp**：工具合规≠用法合规（导入老客户名单需证明来源同意）。

## 四、平台与独立站的差异

- **亚马逊等平台**：平台是数据控制者（卖家只见脱敏数据——卖家合规负担小，但**不得导出买家数据做站外营销**——违反平台政策+GDPR 双重风险）;
- **独立站**：卖家自己是数据控制者（全责——Shopify 提供工具但责任在卖家）;
- **TikTok Shop/Temu**：半托管数据同样受限。

## 五、执法与罚款现实

- **罚款量级**：大公司天价（Meta 12 亿欧元）/小企业现实处罚多为数千-数万欧元+整改令;
- **执法触发**：用户投诉/数据泄露报告/监管抽查（Cookie 横幅不合规是低成本执法对象——扫描即取证）;
- **数据泄露**：72 小时内报监管机构（泄露应对预案必备）;
- **各国差异**：德国/法国/西班牙执法最积极。

## 六、其他市场隐私法

- **英国 UK GDPR**：脱欧后沿用（基本同 GDPR）;
- **美国**：无联邦统一法（加州 CCPA/CPRA——消费者删除/拒绝出售权，独立站"Do Not Sell My Info"链接）;
- **巴西 LGPD**、**加拿大 PIPEDA**：框架类似（合规一次到位可复用）;
- **中国 PIPL**：回国数据（跨境双向注意）。

## 七、低成本合规路径（中小卖家）

- **SaaS 工具**：Cookiebot/Iubenda 横幅（月费 $10-30——自动扫描+同意管理）;
- **模板定制**：隐私政策生成器+律师审一次（一次性 €500-1500）;
- **数据清单**：列出收集点（结账/订阅/客服/像素）逐项对齐;
- **DPO 代表**：非欧盟公司需指定欧盟代表（服务商 €100-300/年——第 27 条要求）;
- **留证**：同意记录/处理活动记录（RoPA——被查时举证）。
