# 墨西哥 NOM 认证与拉美合规（NOM-004 纺织标签/NOM 认证流程/拉美认证地图）

墨西哥是中国纺织品的**高壁垒高溢价**市场：NOM（Norma Oficial Mexicana）强制标准体系+西班牙语标签+本土持证代理人三重门槛把低价散货挡在门外。市场侧见 `customers-market/mexico-market.md`、`customers-market/latin-america-market.md`——本文聚焦**NOM 合规操作与拉美认证地图**。

## 一、NOM 体系与纺织品相关标准

| 标准 | 范围 | 核心要求 |
|:---|:---|:---|
| **NOM-004-SE-2021** | 纺织品/服装标签（**强制**） | 西语标签：纤维成分（%）、原产国、洗涤符号（GINETEX/ASTM）、**进口商名称与 RFC 税号**、尺码 |
| NOM-015-SCFI | 玩具安全 | 机械物理+化学（纺织类毛绒玩具适用） |
| NOM-020-SE | 皮革/鞋类标签 | 材质标识+原产国 |
| NOM-050-SCFI | 一般商品标签通则 | 西语标签基本框架 |
| NOM-024-SCFI | 电子电器包装信息 | 带电纺织品叠加（加热服——`trade-compliance/lithium-battery-shipping-compliance.md`） |

- **NOM-004 命门**：标签必须在**入境前**缝制/贴附完成（到港后整改=海关扣货+代理整改费天价）；成分允差 ±5%（与 FTC 逻辑不同——美国 ±3%，见 `trade-compliance/textile-labeling-regulations.md`）；
- **进口商责任**：NOM 合规的法律责任主体是**墨西哥进口商**（RFC 税号上标签）——中国出口商配合提供准确成分/原产国信息，但**标签由谁制作**（出口方缝制 vs 进口商贴）必须在合同明确。

## 二、NOM 认证流程（适用产品）

- **是否需要认证**：服装/家纺一般**只需 NOM-004 标签合规**（无产品认证）；安全相关类（儿童睡衣阻燃参考项、防护服、带电产品）触发**NOM 认证**（产品测试+证书）；
- **认证路径**：认可实验室测试（墨西哥本土 NYCE/ANCE 或 ILAC 互认实验室）→认证机构（Organismo de Certificación）发证→NOM 标志使用；周期 4-8 周；
- **持证人要求**：NOM 证书**必须墨西哥本土公司持有**（进口商或本地代表）——一证绑定一进口商（换进口商=重新办证，渠道掌控力在进口商手中）；
- **海关查验**：墨西哥海关对纺织标签查验率高（低价纺织品是反倾销敏感区——见 `trade-compliance/antidumping-countervailing.md` 墨西哥对华纺织关税史）；**标签不符=扣货整改或退运**（应对见 `trade-process/customs-inspection-detention-response.md`）。

## 三、拉美认证地图

| 国家 | 纺织相关合规 | 要点 |
|:---|:---|:---|
| 巴西 | INMETRO（部分品类）+葡语标签 | 成分/原产国/进口商 CNPJ；童装安全 ABNT NBR 标准 |
| 阿根廷 | IRAM+西语标签 | 进口许可（LAPI——非自动许可历史包袱）；外汇管制回款风险 |
| 智利 | INN+西语标签 | 标签相对宽松；自贸协定零关税（原产地证——`trade-compliance/tariff-rules-of-origin.md`） |
| 哥伦比亚 | RETIE（电气）+西语标签 | 纺织标签按 Andean 共同框架 |
| 秘鲁 | DIGESA（卫生类）+西语标签 | 中秘 FTA 利用率高 |
| 中美洲 | 各国标签法 | 美国市场跳板（CAFTA-DR 规则——`trade-compliance/transshipment-anti-circumvention.md` 边界） |

- **拉美共性**：西/葡语标签+进口商信息+成分真实——**海关估价严查低报**（纺织品类历史高关税养成的稽查惯性，见 `trade-compliance/customs-valuation-audit.md`）；
- **自贸红利**：智利/秘鲁/哥斯达黎加 FTA 零关税——**原产地证（FORM F/FORM R）办理是报价竞争力**（`trade-process/certificate-of-origin-practice.md`）。

## 四、实操风控

- **标签制作流程**：客户提供西语成分表→制版（洗标印刷——`suppliers/print-embroidery-mill-management.md` 外协）→缝制（**墨西哥单单独生产线隔离**，防混标）→出货前拍照留证；
- **翻译准确性**：纤维名称官方西语（algodón 棉/poliéster 涤/elastano 氨纶——**机器翻译成分名是低级错误高发点**，用 NOM-004 附录标准术语）；
- **渠道谈判**：NOM 证书在进口商手中——**多进口商策略**（每个进口商分别办证）防渠道绑架；独家协议绑定证书归属条款；
- **电商平台**：美客多（Mercado Libre）本土仓发货同样适用 NOM 标签——**跨境小包（CBT）抽查率上升**，平台要求合规文件备案。
