# 反倾销与反补贴应对（Antidumping & Countervailing Duties）

反倾销（AD）/反补贴（CVD）是**"合法关税壁垒"**：一旦立案，税率可达 50-200%（=市场关闭）。纺织服装是 AD/CVD 的传统重灾区。

## 一、基本概念

| 措施 | 针对 | 后果 |
|:---|:---|:---|
| 反倾销（AD） | 低于正常价值出口（倾销） | 反倾销税 |
| 反补贴（CVD） | 政府补贴（低价来源） | 反补贴税 |
| 保障措施 | 进口激增（不论公平与否） | 临时关税/配额 |

- **叠加**：AD+CVD 可叠加（+ MFN + 301——综合税率层层加码，见 `trade-compliance/us-tariff-2026.md`）。

## 二、纺织服装的 AD/CVD 历史

| 案例 | 说明 |
|:---|:---|
| 美国对华 | 聚酯短纤/棉制床单/聚酯薄膜等多项 AD——纺织是重灾区 |
| 欧盟对华 | 聚酯长丝/涤纶短纤 AD 历史 |
| 土耳其/印度 | 对多国纺织 AD（新兴市场的贸易救济活跃） |
| 现状 | 成衣主体未被全面 AD（但面料/化纤制品多项在列——出口前查目标国措施） |

## 三、应对流程（企业被列名时）

### 应诉决策
- **应诉**：争取个别税率（< 全国统一税率——应诉企业获较低税率）；
- **不应诉**：接受最高"全国统一税率"（=放弃市场）；
- **成本**：应诉律师费 $10-50 万（但保住市场值得）。

### 应诉要点
1. **数据准备**：成本/销售/出口数据（核查问卷——数据完整性决定税率）；
2. **实地核查**：调查机关实地核查（账目/生产记录）；
3. **单独税率**：证明独立于政府（获得单独税率而非全国税率）；
4. **日落复审**：AD 措施 5 年期满复审（争取撤销）。

## 四、规避风险（合规经营）

- **价格纪律**：不低报出口价格（低价=倾销证据）；
- **财务规范**：补贴/优惠的会计处理（CVD 核查）；
- **市场多元化**：单一市场依赖的 AD 风险（市场分散）；
- **出口监测**：目标国进口数据（出口激增=AD 预警）。

## 五、转口的反规避（红线）

- **借第三国转口规避 AD** = 反规避调查（见 `trade-compliance/transshipment-anti-circumvention.md`——CBP 赴厂核查）；
- **实质性转变**：简单加工不改变原产国（缝标不算）；
- **风险**：反规避认定=补税+罚款+刑事责任（见 `trade-compliance/dual-use-export-control.md` 类似罚则）。

## 六、出口前核查（操作）

| 步骤 | 说明 |
|:---|:---|
| 查目标国 AD/CVD | 产品+原产国是否在列（美国 ITA/欧盟委员会数据库） |
| 查 HS 编码 | AD/CVD 按 HS+产品描述（同 HS 不同描述可能不同待遇） |
| 评估税率 | 在列产品的税率（个别税率 vs 全国税率） |
| 调整策略 | 在列产品：换市场/换产品线/应诉 |
