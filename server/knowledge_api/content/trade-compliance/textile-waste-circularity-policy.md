# 纺织废弃物与循环经济政策（Textile Waste & Circularity Policy）

欧盟正在把"纺织品"从消费品变为**循环经济监管对象**：生产者要管到产品的"死后"。这是继 ESG 立法（见 `trade-compliance/esg-csrd-sustainability.md`）后的又一层合规。

## 一、欧盟废弃物框架指令修订（Waste Framework Directive）

- **纺织品单独收集义务**（2025 年 1 月生效）：成员国必须建立废旧纺织品单独收集系统——回收量爆发的前奏；
- **纺织 EPR 提案**：将纺织品纳入生产者责任延伸（与包装 EPR 平行——见 `trade-compliance/packaging-epr-regulations.md`）——品牌/进口商为废弃纺织品付费；
- **禁止销毁未售出商品**：Ecodesign 法规（ESPR）禁止销毁未售出服装/鞋类（大型企业 2026 起——中小微豁免）+ 销毁信息披露义务。

## 二、对出口企业的影响

| 环节 | 影响 |
|:---|:---|
| 设计 | 可回收设计（mono-material 单一材质——混纺难回收的结构性挑战） |
| 生产 | 废料管理（裁剪废料回收——供应商 ESG 审核点） |
| 销售 | 客户（品牌）承担 EPR 费用→**成本向上游传导**（压价或要求供应商分担） |
| 库存 | 销毁禁令——未售出库存需出口/捐赠/回收处理（不能再烧） |

## 三、二手服装出口（灰色转规范）

- **全球二手服装贸易**：中国二手服装出口非洲/东南亚（肯尼亚/加纳是主要市场——见 `customers-market/africa-market.md`）；
- **政策分化**：东非共同体曾提议禁止二手服装进口（保护本土产业）vs 非洲二手市场民生依赖；
- **质量分级**：二手服装出口按等级（A 级近新/B 级/C 级）——分拣产业（广州/青岛分拣中心）。

## 四、纺织回收技术与产业化

| 回收路径 | 现状 |
|:---|:---|
| 机械回收 | 开松再纺（再生棉/再生毛——降级循环，品质递减） |
| 化学回收（涤纶） | 解聚再聚合（再生涤纶——技术成熟但成本高） |
| 化学回收（棉） | 棉浆粕→再生纤维素（Infinited Fiber/兰精 Refibra——莱赛尔路径） |
| 混纺分离 | 棉涤分离是技术难点（水解/溶剂法——中试阶段） |

- **再生认证**：GRS/RCS（见 `trade-compliance/textile-certifications.md`）——再生含量宣称的凭证。

## 五、设计端应对（循环设计）

1. **单一材质**：100% 棉/100% 涤（可回收性——混纺是回收天敌）；
2. **可拆解设计**：拉链/扣件易拆（辅料的材质统一）；
3. **耐用性**：耐久设计（穿更久=最环保——北欧耐用叙事）；
4. **标签**：材质+回收指引（DPP 数字护照将承载，见 `trade-compliance/esg-csrd-sustainability.md`）。

## 六、趋势与机会

- **再生纤维需求**：品牌再生含量承诺（2025/2030 目标）→ 再生纤维采购确定性增长（再生涤纶/再生棉溢价）；
- **回收基础设施**：欧洲纺织品分拣/回收产能投资潮（中国回收设备/技术出口机会）；
- **转售（resale）**：品牌二手渠道（Patagonia Worn Wear 模式）；
- **中国政策**：废旧纺织品循环利用实施意见（国内回收体系+再生纤维产业——政策红利）。
