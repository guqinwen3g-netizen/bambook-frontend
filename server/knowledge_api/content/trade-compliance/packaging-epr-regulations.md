# 全球包装法规与 EPR（Packaging & EPR Regulations）

服装出口的**包装本身也是合规对象**：塑料袋/纸箱/吊牌都有法规约束。EPR（生产者责任延伸，Extended Producer Responsibility）正在全球铺开——品牌商/进口商需要为包装废弃物付费注册，合规成本沿供应链传导到供应商。

## 一、欧盟 PPWR（包装与包装废弃物法规）

- **Regulation (EU) 2025/40**，2025-02 生效，**2026-08-12 起主要条款实施**（取代旧指令 94/62/EC）；
- 核心要求：
  - **可回收性**：2030 起所有包装需达可回收等级（70%+）；
  - **再生料比例**：2030 塑料包装含再生料 10-35%（按类别）；
  - **最小化**：包装空隙率 ≤50%（电商袋/箱）；
  - **标签**：包装材质标识（回收分类标志）强制化；
  - **EPR 注册**：在每一销售成员国注册包装生产者责任（或指定授权代表）。
- **对服装出口的影响**：胶袋（PE 袋）、纸箱、衣架全部纳入——客户会要求供应商提供**包装材质数据**（重量/材质/再生料含量）用于其 EPR 申报。

## 二、各国 EPR 与塑料法规速查

| 市场 | 法规 | 要点 |
|:---|:---|:---|
| 法国 | AGEC + Triman 标签 | 包装须印 **Triman 回收标志 + Info-tri 分类指引**（法语）；未标可罚 |
| 德国 | VerpackG | LUCID 注册（进口商）；不合规禁售 |
| 英国 | Plastic Packaging Tax | 再生料 <30% 的塑料包装征税（约 £217/吨）——**供应商提供再生料证明可帮客户避税** |
| 西班牙 | 塑料税（2023） | 不可再生塑料 €0.45/kg |
| 美国 | 州级 EPR（加州 SB 54 等） | 加州 2032 起包装 100% 可回收/堆肥；多州跟进 |
| 日本 | 容器包装回收法 | 进口商承担回收费用 |
| 澳洲 | APCO 标签 | ARL 回收标签体系 |

## 三、塑料袋安全警示（强制性最强）

- **窒息警告语**：开口 ≥ 7 英寸（约 18cm）的塑料袋必须印窒息警告（美国多州/欧盟事实标准）：
  `WARNING: To avoid danger of suffocation, keep this bag away from babies and children. Do not use in cribs, beds, carriages or playpens. This bag is not a toy.`
- 打孔（vent holes）要求：部分州要求袋身透气孔；
- 童装包装尤其严格（见 `garments/childrenswear-production.md`）。

## 四、包装材质合规要点

| 材质 | 合规点 |
|:---|:---|
| PE/PP 胶袋 | 窒息警告+回收标志（♻ LDPE 4）；再生料证明（GRS 塑料袋） |
| 纸箱 | FSC 认证（欧美客户普遍要求）；ISTA 运输测试（电商直发） |
| 衣架 | 可回收材质声明；部分品牌禁 PVC 衣架 |
| 吊牌 | FSC 纸张；去 PVC 覆膜（不可回收） |
| 防潮剂 | 硅胶干燥剂（DMF 富马酸二甲酯禁用于防潮剂——欧盟已禁） |

## 五、供应商行动清单

1. **包装数据台账**：每款包装的材质/单重/数量记录——客户 EPR 申报随时要数据；
2. **警告语模板库**：按市场预置多语言窒息警告（英法德西意）；
3. **再生料胶袋采购**：向胶袋供应商索取 GRS/再生料含量证明（应对英国塑料税）；
4. **减量化**：与客户协商去胶袋/合袋方案（折叠包装+纸质腰封替代）——降本+合规双赢；
5. **合同条款**：包装合规责任与数据提供义务写入供应协议。
