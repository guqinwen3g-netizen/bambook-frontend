# PFAS 限制与无氟防水转型（PFAS Ban & Fluorine-Free DWR Transition）

PFAS（全氟/多氟化合物）是防水防油整理的传统核心，因**环境持久性（"永久化学品"）正被全球快速立法禁止**。防水功能面料正经历 C8→C6→C0（无氟）的技术换代——这是功能面料订单的未来准入证。

## 一、法规地图（动态收紧）

| 法域 | 状态 | 要点 |
|:---|:---|:---|
| 法国 | **2026 年起禁售**含 PFAS 纺织服装（防护服豁免） | 最激进（见 `customers-market/eu-market.md`） |
| 美国加州 AB 1817 | 2025 年起纺织禁令生效 | 服装/家纺全覆盖（见 `trade-compliance/california-prop65.md` 加州联动） |
| 美国纽约 | 2025-2028 分阶段 | 服装禁令先行 |
| 欧盟 | REACH 限制提案（ECHA 通用限制）+ POPs 已禁 PFOA/PFOS | 通用限制立法流程中（2026-2027 落地预期） |
| 丹麦/荷兰等 | 国家层面先行限制 | 食品接触+纺织延伸 |
| 日本/中国 | GB 标准管控 PFOA（纺织品强制性国标限量） | 出口内销双适用 |

- **动态跟踪**：以 ECHA/各州立法最新文本为准（立法节奏极快——每季复核）。

## 二、技术转型：C8 → C6 → C0

| 代际 | 成分 | 性能 | 合规状态 |
|:---|:---|:---|:---|
| C8 | 长链全氟 | 防水防油最优 | **全球禁用**（PFOA/PFOS POPs 公约） |
| C6 | 短链氟化 | 防水防油良好 | 过渡期方案——**正被新禁令覆盖**（短链同属 PFAS 大家族） |
| C0（无氟） | 硅/石蜡/聚氨酯/树枝状聚合物 | 防水可达，**防油弱**是短板 | 合规方向 |

- **无氟短板**：防油性（防污等级降 1-2 级）+耐洗性——户外品牌高端线仍用 C6（豁免争议中）；日常服装 C0 已够用；
- **成本**：无氟助剂单价略高，但无合规溢价损失——品牌已普遍要求 C0。

## 三、供应链应对

1. **库存排查**：现有防水面料库存确认助剂体系（C6/C0——向助剂供应商/染厂索要 SDS 与声明，见 `suppliers/dyeing-mill-cooperation-management.md`）；
2. **检测**：总氟（TF）筛查（ Combustion Ion Chromatography——指示性）+ 靶向 PFAS 定量（LC-MS/MS）；**OEKO-TEX ECO PASSPORT / ZDHC MRSL** 合规助剂清单（见 `trade-compliance/textile-certifications.md`）；
3. **客户声明**：品牌 PFAS-free 承诺文件（签署 RSL/禁限用物质保证——见 `trade-compliance/chemical-environmental-compliance.md`）；
4. **面料开发**：无氟防水 + 膜技术（防水靠膜不靠助剂——见 `fabric/functional-coating-lamination.md`）；
5. **宣称管理**："PFC-free / PFAS-free"宣称需检测支撑（见 `trade-compliance/green-claims-anti-greenwashing.md` 证据链）。

## 四、常见误区

| 误区 | 事实 |
|:---|:---|
| "C6 安全" | 短链同属 PFAS——新禁令按家族管控，C6 不是终点 |
| "防水必须含氟" | 无氟防水可满足日常防泼水（防油场景另议） |
| "检测报告一次永逸" | 助剂批次波动——定期抽检+供应商声明双轨 |
| "只有面料要管" | 成衣防水整理（ garment wash 后整）同样受控 |

## 五、商机视角

- **转型窗口**：品牌集中更换供应链（无氟能力=接单资格——2026 起法国/加州硬门槛）；
- **卖点升级**：PFAS-free + 再生面料 + DPP 数据（组合合规叙事——见 `trade-compliance/eu-espr-dpp.md`）；
- **风险订单**：接含氟防水订单前确认目的州/国（美国订单按州排查——加州/纽约订单默认 C0）。
