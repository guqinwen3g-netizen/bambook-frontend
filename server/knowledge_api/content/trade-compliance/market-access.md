# 目的国市场准入（Market Access）

纺织服装进入不同目的国，除关税外还需满足各自的**标签、安全、化学品与进口申报**要求。美国与欧盟是最主要的成品出口市场，本文件聚焦两地准入要点，兼顾加州特殊法规。

## 一、美国市场准入（美国）

### 标签要求（FTC 主导）
- **纤维成分标签（fiber content label）**：按 FTC《纺织纤维产品标识法》，须用英文列出各纤维通用名及比例，如 "100% Cotton"。
- **保养标签（care label）**：洗涤/熨烫/干洗说明，常用符号（ASTM 体系）。
- **原产国标签（country of origin）**：永久性缝入的 "Made in China" 等。
- **进口商信息**：美国进口商/经销商名称地址或 RN 号（Registered Identification Number）。

### 安全合规（CPSC）
- **童装**：12 岁以下儿童服装须符合 CPSIA，提供 **CPC 证书**与第三方检测（铅、邻苯二甲酸盐、小部件、绳索等）。
- 成人服装一般关注阻燃、绳带安全等有限要求。

### 加州 Proposition 65
- 加州《安全饮用水与有毒物质强制法》，要求含超限致癌物/生殖毒物的产品**加贴警告标签**。
- 涉及纺织常见项：铅、镉、甲醛、某些染料，需关注加州 65 清单与限值。

## 二、欧盟市场准入（欧盟）

- **CE 标志**：纺织服装一般不强制 CE（CE 主要针对机械、电子、个人防护设备 PPE 等），但**防护服（PPE）**需 CE。
- **标签要求**：成分（欧盟 1007/2011 条例）、维护符号（ISO 3758）、原产地、尺寸。
- **化学品合规**：REACH、OEKO-TEX、纺织品有害物质限制（欧盟拟强化）。
- **可持续立法**：ESPR 生态设计、DPP 数字产品护照、再生含量要求，未来趋势需关注。

## 三、进口商要求（Importer Requirements）

品牌/零售商（importer）对接单的合规要求通常包括：

1. **指定检测项目与标准**：AATCC/ISO/EN 方法及限值。
2. **合规证书**：成分、原产地、安全、化学品报告。
3. **社会责任与环保审计**：交期外的 BSCI、WRAP、SA8000 等工厂审核。
4. **可追溯性**：供应链信息披露、再生材料证书（GRS/OCS/RCS）。
5. **样品与大货一致性**：产前样、船样、出货前检验。

## 四、其他市场要点

- **东南亚/南亚（越南、印尼、孟加拉等）**：多要求原产地证、成分标签，部分市场关税优惠需自贸协定原产地证。
- **中东/北非**：部分市场要求清真/宗教合规、严格成分与安全标签。
- **日本**：家用品品质表示法，洗涤标志、成分、原产地、材质（可燃性）要求细致。

## 五、准入合规实操

1. **接单核对准入清单**：明确目的国标签、安全、化学品、证书要求，写入合同。
2. **建立模板与档案**：成分/保养/原产国标签模板化，避免重复返工。
3. **第三方合规报告前置**：关键市场提前送检，避免到港退运。
4. **关注法规动态**：美欧环保与关税政策变化快，需持续跟踪。
