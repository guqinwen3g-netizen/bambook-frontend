# 微纤维脱落与微塑料法规（Microfiber Shedding & Microplastics Regulation）

合成纤维（涤纶/锦纶/腈纶）洗涤时脱落的**微纤维是海洋微塑料的主要来源之一**——欧盟与法国已率先立法，品牌开始要求供应商提供脱落测试数据。这是继 PFAS 之后可持续合规的下一个热点。

## 一、法规与政策动态

| 法域 | 状态 | 要点 |
|:---|:---|:---|
| 法国 | **2025 年起新售洗衣机须配微纤维过滤器**（AGEC 法延伸） | 全球首个硬性设备立法（见 `customers-market/eu-market.md` 法国动向） |
| 欧盟 | ECHA 微塑料限制（有意添加的微塑料已禁——纺织品洗涤脱落属"无意释放"，立法研究中） | ESPR/DPP 框架下产品环境数据披露（见 `trade-compliance/eu-espr-dpp.md`） |
| 英国/美国加州 | 议案阶段 | 洗衣机滤网跟进提案 |
| 行业自愿 | The Microfibre Consortium（TMC——品牌/实验室联盟） | 测试方法与减量路线图 |

- **节奏判断**：短期（2026-2027）以**品牌自愿要求**为主（测试数据披露）；中期立法将扩展到产品端（低脱落面料标准）。

## 二、测试方法

| 方法 | 说明 |
|:---|:---|
| AATCC TM212 | 美标——家庭洗涤加速模拟，收集脱落纤维称重/计数 |
| ISO 105-X19（制定中/部分发布） | 国际协调方法 |
| TMC 方法 | 行业联盟版（与 AATCC 互认趋势） |

- **测试对象**：面料（非成衣）——5 次洗涤循环，报告 mg/kg 脱落量；
- **典型数据**：摇粒绒/抓绒脱落最高（长纤绒毛），高密平纹涤纶最低（见 `fabric/fleece-terry-fabrics.md` 摇粒绒注意点）。

## 三、影响因素与减量路径

**面料端**：
- 长丝 > 短纤（短纤纱脱落量数倍于长丝）；
- 高捻度/高密组织脱落低；
- 磨毛/起绒工艺增加脱落（保暖内衣/抓绒——见 `garments/thermal-underwear-production.md`）；
- 再生涤纶（rPET）脱落量与原生相当（再生不减微纤维——宣称注意）。

**染整端**：
- 柔软剂/硅油整理减少摩擦脱落；
- 烧毛/剪毛工艺去除表面浮毛。

**消费端**（品牌叙事素材）：
- 洗衣袋（Guppyfriend）/滤网/低温快洗——品牌随售教育内容。

## 四、对供应商的实务要求

1. **测试能力**：品牌订单开始要求 AATCC TM212 数据（户外品牌先行——Patagonia 等，见 `garments/outdoor-functional-wear-production.md`）；
2. **数据留存**：分面料建立脱落数据库（接单报价时直接调用——差异化竞争力）；
3. **宣称合规**："低微纤维"宣称需测试支撑（证据链逻辑见 `trade-compliance/green-claims-anti-greenwashing.md`）；
4. **面料开发**：与面料厂联合开发低脱落品种（长丝+高密+整理优化——见 `fabric/fabric-development-process.md`）。
