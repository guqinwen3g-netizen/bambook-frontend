# 知识产权与品牌授权（IP & Brand Authorization）

纺织服装外贸的 IP 风险是双向的：**客户图案/品牌被侵权**（我方担责）与**承接假冒订单**（法律红线）。OEM 贴牌模式下，授权链条核验是接单前置条件。

## 一、接单前的 IP 审查

### 品牌授权核验（承接品牌订单）
| 客户类型 | 核验动作 |
|:---|:---|
| 品牌方直客 | 营业执照+商标注册证（目的国注册），核对签约主体一致性 |
| 品牌代理商/被授权商 | **品牌方出具的授权书（LOA）**——载明被授权方、品类、地区、期限 |
| 贸易商转手单 | 追溯完整授权链（品牌→总代→贸易商→我方），链条断裂即拒单 |

- 授权书要素：商标注册号、授权品类（如"针织 T 恤"）、授权区域（如"仅限北美销售"）、有效期、品牌方签章。
- **超授权生产即侵权**：授权 10,000 件做 12,000 件，多出的 2,000 件属假冒。

### 高风险信号（涉嫌假冒订单）
- 国际大牌（Nike/Disney/LV 等）+ 无法提供授权书；
- 价格明显低于正品供应链逻辑；
- 要求"无标生产、商标后寄"或发往第三国换标；
- 样品为正品，要求"照原样一模一样做"。

> **生产假冒商品（counterfeit）在中国与目的国均为刑事犯罪**，不因"客户提供的商标"免责——代工厂同责。此类订单一律拒绝。

## 二、图案与花型的版权风险

- **印花图案**：客户提供的花型/卡通/IP 形象（迪士尼/三丽鸥/球队 logo）需授权证明；设计师原创图案确认不侵犯第三方版权。
- **字体**：英文字体（如迪士尼体、球队字体）同样受保护。
- **格纹/迷彩**：部分经典格纹（Burberry 格子）有商标保护；迷彩通常无风险。
- 接单动作：图案授权文件归档；无法提供时在合同中加"客户保证图案不侵权，由此产生的责任由客户承担"条款（**但该条款不能对抗刑事责任**，仅分担民事赔偿）。

## 三、我方 IP 保护

### 自主设计与花型
- 自主开发面料花型/款式，进行**版权登记**（中国版权保护中心，花型登记费低、周期快）。
- 参展/寄样前：重要设计申请外观设计专利（6-12 个月）或版权先行。
- 给客户寄新开发样时附保密条款（NDA），防止设计被转手给其他工厂。

### 自有品牌出口
- **商标国际注册**：马德里体系（一次申请指定多国）或单一国注册；主营市场（美/欧/日/中东）必须提前注册——**目的国被抢注后，正品也会被海关查扣**。
- 美国 USPTO、欧盟 EUIPO 注册周期 8-14 个月，提前布局。

## 四、海关知识产权保护

- **中国海关备案**：商标在海关总署备案后，出口环节海关主动查扣疑似侵权货物（既是保护也是风险——我方承接的贴牌订单若商标已备案，需向海关提供授权链文件才能放行）。
- **美国 CBP 备案（e-Recordation）**：品牌方在美备案后，CBP 口岸查扣侵权品。
- 实操：承接美国品牌订单前，自查该商标是否在 CBP 备案名录，确认授权文件可覆盖清关核查。

## 五、合同 IP 条款要点

1. **知识产权归属**：客户提供的商标/图案归客户；我方开发的花型/版型归属明确（默认归我方，除非客户支付开发费买断）。
2. **侵权担保与赔偿**：双方各自担保提供内容不侵权。
3. **超额生产禁止**：明确按订单数量生产，多余产品销毁/去标，不得流入市场。
4. **模具/版费归属**：客户付费的绣花版/印花网版/模具，所有权与保管责任写明。

## 六、纠纷应对

- 收到品牌方律师函（cease & desist）：立即停止出货，核查授权链，法务介入评估——回应时限通常 10-15 个工作日。
- 货物被海关以侵权查扣：限期（中国海关 3 个工作日）内提交授权证明或书面说明；逾期进入调查程序。
- 证据留存：授权书、往来邮件、付款记录全档保存，证明"善意代工"可降低责任层级。
