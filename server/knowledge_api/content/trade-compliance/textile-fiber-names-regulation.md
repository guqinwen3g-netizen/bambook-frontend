# 纤维名称与成分标注法规深度（Fiber Names & Content Labeling Rules）

成分标注是纺织标签的技术核心：**用错纤维名称或虚标含量 = 违法**（各国均有处罚案例）。欧盟 1007/2011 与美国 FTC 规则是两大基准体系，术语差异需精确转换。

## 一、纤维通用名体系（generic names）

| 中文 | 美国 FTC | 欧盟 1007/2011 | ISO |
|:---|:---|:---|:---|
| 棉 | cotton | cotton | cotton |
| 涤纶 | polyester | polyester | polyester |
| 锦纶 | nylon | polyamide（或 nylon） | polyamide |
| 氨纶 | spandex | **elastane** | elastane |
| 腈纶 | acrylic | acrylic | acrylic |
| 粘胶 | rayon | **viscose** | viscose |
| 莱赛尔 | lyocell | lyocell | lyocell |
| 醋酯 | acetate | acetate | acetate |
| 羊毛 | wool | wool | wool |
| 腈纶改性 | modacrylic | modacrylic | modacrylic |

- **美欧术语差异**（高频错误点）：spandex（美）= elastane（欧）；rayon（美）= viscose（欧）；nylon（美）= polyamide（欧）——同一产品双市场需两套标签术语；
- **商标≠纤维名**：Lycra®/Tencel®/Modal® 是品牌——法规要求用通用名（可写 "Tencel™ lyocell"，不能只写 Tencel）。

## 二、含量标注规则

### 美国 FTC
- **重量百分比降序**；含量 <5% 的纤维标 "other fiber(s)"（功能性纤维如氨纶必须标明不论比例）；
- **允差**：±3%（单一纤维标 100% 则不允许任何含量偏差——"100% cotton" 必须真的是 100%）；
- **装饰部分豁免**：装饰性花边/刺绣可注明 "exclusive of decoration"（不计装饰部分）。

### 欧盟 1007/2011
- **允差更复杂**：加工损耗允许 2-5%（视纤维组合）；混纺标注四舍五入规则；
- **动物纤维**：羊毛可含少量其他动物毛（粗纺习惯），但羊绒（cashmere）标注必须真实——**羊绒虚标是欧盟执法重点**；
- **皮草/真皮**：必须标 "Contains non-textile parts of animal origin"。

### 中国 GB/T 29862
- 纤维含量允差按具体产品标准（如 FZ/T 系列）；纯纺产品允差 0（"100%"=100%）。

## 三、特殊纤维宣称的合规

| 宣称 | 要求 |
|:---|:---|
| 有机棉（organic cotton） | GOTS/OCS 认证支撑（见 `trade-compliance/textile-certifications.md`）——无认证标"有机"=误导宣传 |
| 再生涤纶（recycled polyester） | GRS/RCS 认证+TC 交易证书 |
| 竹纤维（bamboo） | **美国 FTC 严打**：竹浆粘胶必须标 "rayon made from bamboo"（不能标 bamboo——化学加工后已非竹纤维），违者罚款（多起 $10 万+ 案例） |
| 羊绒（cashmere） | 细度 ≤19μm（国标 GB 18267）；虚标是中美欧共同执法点 |
| 真丝（silk） | 100% silk 必须全真丝；绢丝/柞蚕丝需区分标注 |
| 凉感/发热/抗菌纤维 | 功能性宣称需检测数据支撑（见 `fabric/functional-fabrics.md`） |

## 四、检测与验证

- **成分检测方法**：ISO 1833 系列（化学溶解法）/AATCC 20A（显微镜+溶解）——混纺比例以检测报告为准；
- **双组分/三组分**：棉涤氨三组分检测误差大于单组分——标注留缓冲（如 "60% cotton 37% polyester 3% elastane" 而非精确到 0.5%）；
- **抽检制度**：大货面料定期送检（成分证书随订单归档）——客户审计/海关查验的举证材料。

## 五、违规后果与案例

| 违规 | 后果 |
|:---|:---|
| "100% cotton" 实为 CVC | FTC 民事罚款（$46,517/件/天上限）+ 召回 |
| 竹纤维标 "bamboo" | FTC 系列处罚（Bed Bath & Beyond $50 万案） |
| 羊绒虚标（羊毛充羊绒） | 欧盟 RAPEX 通报+下架+罚款 |
| 氨纶标 spandex 入欧 | 标签不合规（应为 elastane）整改 |
| 有机宣称无认证 | 误导宣传处罚+职业打假诉讼（美国 class action） |

## 六、实操清单

1. **标签术语对照表**：按目的国生成标签（美/欧/日三版本常备）；
2. **检测报告对应**：每款面料成分检测报告与标签含量一致——改配方必改标签；
3. **宣称审查**：有机/再生/功能性宣称必须有证书或检测支撑；
4. **供应链传导**：要求面料供应商提供准确成分信息（合同条款约束）——成分虚标很多是上游传导。
