# HS 归类实务（HS Classification Practice）

归类决定税率、监管条件、退税率三重结果。纺织服装集中在 **61 章（针织）与 62 章（梭织）**，归类错误的代价是补税 + 罚款 + 退税损失 + 客户清关连锁损失。

## 一、归类总规则（GIR 六条）

1. **规则一**：按品目条文与类注章注（优先于一切）；
2. **规则二**：未制成品/拆散件按制成品归类；
3. **规则三**：混合物/组合货品——具体列名 > 基本特征 > 从后归类；
4. **规则四**：最相类似；
5. **规则五**：容器包装随货归类；
6. **规则六**：子目比较逐级适用。

## 二、服装归类的判断顺序

```
针织 or 梭织？（61 vs 62 章分界）
→ 男装 or 女装？（"男式"与"女式"分列税目）
→ 品种（衬衫/西服/裤/T恤...）
→ 材质（棉/毛/化纤/丝...按重量最大成分）
→ 具体税号（8-10 位）
```

### 关键分界规则
- **针织 vs 梭织**：针织物（含钩编）服装全部归 61 章——即使是"衬衫"款式，针织衬衫归 6105/6106 而非 6205/6206；
- **男女装判别**：门襟方向（男左女右）、纽扣方向；不明确的按"女式"归（税则注释惯例）；
- **套装**：西服套装/便服套装成套报验归一个税号（注意"套装"定义：同面料同款式零售成套）；
- **材质权重**：多种纤维按**重量最大**成分归（棉 51% + 涤 49% → 棉制）；相等时从后归类。

## 三、常见归类争议点

| 商品 | 争议 |
|:---|:---|
| T 恤 vs 针织衬衫 | 6109（T恤/汗衫背心）vs 6105（针织衬衫）——有无领/门襟是关键 |
| 连帽卫衣 | 6110（针织套头）——不是夹克（6101）除非全开襟 |
| 羽绒服 | 6201/6202（梭织面料）——按面料而非填充物归类 |
| 瑜伽裤 | 6104（针织裤）——紧身裤不是"运动服"税号单列（61/62 章运动服需符合章注定义） |
| 连衣裙 vs 上衣+裙套装 | 单件连衣裙 6204.4x；两件套按套装或分别归类 |
| 婴儿服装 | 6111/6209 专章（身高 ≤86cm）——比童装税率高或低需注意 |
| 功能性服装 | 救生衣/防弹衣等非普通服装归其他章（63 章或 90 章） |

## 四、税率与监管查询

- **查询路径**：中国税则（海关总署税则查询）查出口退税率与监管条件；目的国税率用进口国税则（美国 HTS hts.usitc.gov、欧盟 TARIC、日本海关税则表）；
- **服装出口退税率**：多数 13%（2026 新规下按"视同自产"口径管理，见 `trade-process/export-tax-rebate.md`）；
- **监管条件**：服装出口一般无许可证；**两用物项**（防弹衣等特种）除外；
- 美国 HTS 注意 9903 章节的 301 关税附加码（见 `trade-compliance/us-tariff-2026.md`）。

## 五、风险管理工具

1. **预归类/预裁定**：商品复杂或金额大时向海关申请**预裁定**（Ruling）——归类意见具有约束力，规避事后争议；
2. **归类一致性管理**：同一商品长期出口，归类决定书归档，防止不同口岸/不同报关行归错；
3. **中美归类差异**：同一商品中国 8 位码与美国 10 位码可能归类逻辑不同（如套装拆分规则）——给客户报价关税时以**进口国归类**为准；
4. **归类争议应对**：海关质疑时提交产品说明/成分检测/工艺说明，必要时通过归类预裁定或复议解决。
