# 供应链追溯与强迫劳动映射（Supply Chain Traceability & Forced Labor Mapping）

从"知道供应商"到"**知道供应商的供应商的供应商**"：强迫劳动立法（美 UFLPA/欧 FLR）要求全链溯源到原料。

## 一、立法要求（见各专项文档）

| 法规 | 追溯要求 |
|:---|:---|
| 美国 UFLPA | 棉花溯源到棉田（可反驳推定——见 `trade-compliance/uflpa-forced-labor.md`） |
| 欧盟 FLR | 全链风险评估（见 `trade-compliance/esg-csrd-sustainability.md`） |
| 德国 LkSG | 供应链尽职调查（见 `trade-compliance/eu-national-supply-chain-laws.md`） |
| 英国/加/澳现代奴隶法 | 供应链声明 |

## 二、供应链映射（mapping）

### 层级
```
Tier 0：品牌/零售商（客户）
Tier 1：成衣厂（直接供应商）
Tier 2：面料厂/染厂
Tier 3：纱厂
Tier 4：原料（棉田/牧场/化纤原料）
```

- **现实难点**：多数企业只知 Tier 1——Tier 2-4 是"盲区"（强迫劳动风险恰在上游原料端）。

### 映射方法
1. **供应商申报**：要求 Tier 1 申报其供应商（逐级——问卷+合同义务）；
2. **交易凭证**：发票/提单（供应链交易链的证据）；
3. **产地标识**：原料产地证明（棉花产地证/羊毛产地）；
4. **第三方数据**：供应链数据库（如 Oritain 同位素溯源/TextileGenesis 区块链）。

## 三、棉花溯源（UFLPA 核心）

- **棉田级溯源**：棉花从棉田→轧花→纱厂→布厂→成衣的批次链；
- **技术**：
  - **同位素检测（isotope testing）**：Oritain——棉花"指纹"鉴定产地（科学证据）；
  - **区块链**：TextileGenesis——链上记录流转；
  - **文件链**：轧花厂/纱厂/布厂的交易与加工凭证；
- **新疆棉回避**：非新疆棉证明（美棉/澳棉/印度棉——供应链置换，见 `trade-compliance/uflpa-forced-labor.md`）。

## 四、举证包（被扣货时）

| 文件 | 说明 |
|:---|:---|
| 供应链图 | 全链供应商清单（Tier 1-4） |
| 交易凭证 | 各级发票/提单/付款记录 |
| 原料产地证 | 棉花/原料产地证明 |
| 加工记录 | 纱厂/布厂加工批次记录 |
| 同位素报告 | Oritain 等产地鉴定 |
| 尽职调查文件 | 供应商审核/风险评估记录 |

- **时效**：CBP 扣货后 30 天内举证（材料平时备好——临时凑来不及）。

## 五、供应链风险评估

| 风险点 | 评估 |
|:---|:---|
| 原料产地 | 新疆棉/朝鲜劳工等高风险源 |
| 供应商透明度 | 拒绝披露上游=红旗 |
| 中介层级 | 层级越多越难追溯（贸易商层级） |
| 地区风险 | 强迫劳动高发地区（联合国/美国劳工部名单） |

## 六、体系建设

1. **政策**：强迫劳动零容忍政策（供应商行为准则——见 `suppliers/factory-audit-guide.md`）；
2. **合同条款**：供应商追溯义务（合同强制披露上游）；
3. **数据系统**：供应链追溯系统（批次级记录——数字化）；
4. **审核**：社会责任审核（见 `suppliers/factory-audit-guide.md` BSCI/SMETA——含强迫劳动模块）；
5. **技术投入**：同位素/区块链（高价值订单的溯源背书）。
