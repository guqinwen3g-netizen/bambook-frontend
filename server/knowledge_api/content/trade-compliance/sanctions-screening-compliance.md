# 制裁筛查与出口合规（Sanctions Screening & Compliance）

制裁违规代价是"**罚款 + 断美元通道 + 刑事责任**"级：服装非敏感商品但支付、物流、客户身份环节均可能踩雷——筛查是接单前置动作。

## 一、主要制裁体系

| 体系 | 核心名单 | 特点 |
|:---|:---|:---|
| 美国 OFAC | SDN（特别指定国民）/SSI 行业制裁 | 域外效力最强（美元结算即入管辖） |
| 欧盟 | 综合制裁清单 | 成员国强制实施 |
| 联合国 | 安理会制裁清单 | 各国立法转化 |
| 英国 OFSI | UK 制裁名单 | 脱欧后独立体系 |

## 二、核心规则

- **SDN 名单**：冻结资产+禁止一切交易（美国人/美元/美国商品三管辖触发点）；
- **50% 规则**：被制裁人合计持股 ≥50% 的实体自动视同制裁（查股权结构——隐性关联是高发雷区）;
- **行业制裁（SSI）**：非全面禁止但限制特定交易（融资/服务）；
- **二级制裁**：非美国主体与受制裁对象重大交易亦可被制裁（切断美元通道威胁——伊朗/俄罗斯领域最活跃）。

## 三、服装外贸高风险场景

- **俄罗斯市场**：服装本身不在禁运清单（非奢侈品限 €300 以上/件）——但**支付环节**高危（主要银行被剔 SWIFT——VTB 等次级结算、人民币/卢布结算通道）;
- **第三国中转**：土耳其/阿联酋/中亚转口俄罗斯（物流路径暴露风险——收货人与最终用户不一致）;
- **朝鲜/伊朗/古巴/叙利亚/克里米亚地区**：全面制裁——直接拒单;
- **军民两用**：迷彩服/战术装备出口敏感地区（见 `trade-compliance/dual-use-export-control.md`）。

## 四、筛查实务

### 1. 筛查对象（全链条）
- 客户公司及**最终受益人**（50% 规则——要股权结构）;
- 收货人/通知方（提单三方）;
- 结算银行（开证行/付款行自身被制裁=货款冻结）;
- 船公司/船舶（OFAC 制裁船舶名单——订舱前查）;
- 目的港（受制裁港口）。

### 2. 工具
- **免费**：OFAC Sanctions List Search（官网）/欧盟 consolidated list/英国 OFSI list——模糊匹配功能;
- **商业系统**：Descartes/Refinitiv World-Check（货代银行级——中小企可用货代筛查服务）;
- **筛查时点**：新客户建档必查+出货前复查（名单动态更新）+留存筛查记录（举证）。

## 五、违规后果与案例

- **民事罚款**：OFAC 罚款可达交易额数倍（历史案例数十万-数亿美元）;
- **美元通道**：银行合规审查终止合作（外贸企业致命）;
- **刑事**：故意规避（structuring/伪造文件）可追刑责;
- **连坐**：货代/报关行连带调查（供应链信誉）。

## 六、风险决策框架

- **红灯（拒单）**：SDN 命中/朝鲜伊朗古巴叙利亚/收货人拒绝披露;
- **黄灯（强化尽调）**：俄罗斯/白俄罗斯/第三国中转/股权复杂——筛查+合同制裁条款+支付路径合规确认;
- **绿灯（常规）**：主流市场正常客户（仍保留筛查记录）;
- **合同条款**：制裁合规陈述与保证+情势变更解约权（见 `trade-process/trade-contract-terms.md`）。

## 七、与 UFLPA 的协同

- 制裁（国家安全）与强迫劳动禁令（人权——见 `trade-compliance/uflpa-forced-labor.md`）是两条独立合规线——但尽调流程可合并（供应商/物流/股权一张表）;
- 供应链追溯要求叠加（见 `trade-compliance/supply-chain-traceability-mapping.md`）。
