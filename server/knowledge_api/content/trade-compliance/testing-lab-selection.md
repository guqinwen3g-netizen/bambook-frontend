# 检测机构选择与合作（Testing Lab Selection）

检测报告是**合规的通行证与争议的裁决书**：选对实验室（资质被客户/海关认可）比检测本身更重要。

## 一、主要检测机构

| 机构 | 总部 | 特点 |
|:---|:---|:---|
| SGS | 瑞士 | 全球最大（网络最广——多数客户默认认可） |
| Intertek（天祥） | 英国 | 纺织检测强（英美品牌常用） |
| BV（必维） | 法国 | 欧系品牌偏好 |
| TÜV（南德/莱茵） | 德国 | 德系/技术产品 |
| UL | 美国 | 安全认证（儿童产品） |
| 中纺标（CTTC） | 中国 | 国标检测权威（内销+出口 GB 标准） |
| 华测（CTI） | 中国 | 国产第三方（性价比） |

## 二、选择标准

### 1. 资质认可（第一位）
- **客户指定**：品牌指定实验室（"test at SGS only"——客户要求是硬约束）；
- **目的国认可**：如美国 CPSC 认可实验室（CPC 证书必须 CPSC-accepted lab——见 `trade-compliance/cpsc-children-safety.md`）；
- **CNAS/CMA**：中国资质（报告法律效力）。

### 2. 标准覆盖
- **标准版本**：实验室能否按指定标准版本测试（AATCC 61-2020 vs 旧版——版本影响结果）；
- **项目覆盖**：化学（REACH/偶氮）+物理（色牢度/强力）+功能（防水/抗菌）——一站式 vs 分包。

### 3. 周期与成本
- **周期**：常规 5-7 工作日（加急 2-3 天+50-100% 加急费）；
- **成本**：单项几十到几百美元（全套 REACH+物理测试 $500-2000/款）；
- **框架协议**：年签框架协议（折扣+优先排期——大客户策略）。

## 三、检测流程

```
送样（足够样品量）→ 报价确认 → 测试 → 报告（电子版+纸质）→ 报告审核 → 交单
```

### 送样要点
- **样品量**：按测试项目备足（化学测试破坏性——多备）；
- **代表性**：大货样（非确认样——测试大货实际状态）；
- **信息完整**：测试申请表（成分/款号/标准/项目——填错=测错）。

## 四、报告解读与应对

### 报告要素
- **结果**：Pass/Fail + 实测值（对照限值）；
- **方法**：测试标准+版本（核对是否客户指定）;
- **有效期**：报告一般 1 年有效（客户要求内）；
- **报告真伪**：官网验证编号（伪造报告=欺诈）。

### 不合格应对
1. **复核**：申请复测（样品不均/操作误差——实验室也可能错）；
2. **整改**：面料/工艺调整（甲醛超标→换树脂/水洗——见 `trade-compliance/chemical-environmental-compliance.md`）；
3. **重测**：整改后重测；
4. **争议**：两家实验室结果冲突（第三家仲裁/客户认可的为准）。

## 五、检测策略（成本控制）

| 策略 | 说明 |
|:---|:---|
| 大货前检测 | 投产前测（避免大货不合格——止损最早） |
| 风险聚焦 | 高风险项目必测（童装铅/邻苯——见 `trade-compliance/cpsc-children-safety.md`），低风险抽检 |
| 面料厂报告 | 利用面料厂既有报告（同面料不重复测——但需客户认可） |
| 年度框架 | 固定实验室年签（成本+效率） |
| 内部预检 | 有条件的企业建内部实验室（初筛——正式报告仍第三方） |

## 六、常见误区

- ❌ 用小厂便宜报告交品牌客户（客户不认可=废纸）；
- ❌ 拿旧报告交新订单（面料批次变了——报告对应批次）；
- ❌ 测错标准版本（客户要 AATCC 61-2020 给了 2012——结果不可比）；
- ❌ 只测主料漏辅料（拉链镍/纽扣铅——辅料也要测）。
