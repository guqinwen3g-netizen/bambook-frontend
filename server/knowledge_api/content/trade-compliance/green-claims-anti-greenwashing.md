# 绿色声明与反漂绿合规（Green Claims & Anti-Greenwashing Enforcement）

"可持续/环保/再生"宣称已从营销加分项变为**法律高风险区**——欧盟绿色声明指令+各国执法案例密集落地（H&M/Decathlon 被罚和解），纺织业是执法第一目标行业。宣称必须有证据链支撑。

## 一、法规框架

| 法域 | 法规 | 核心要求 |
|:---|:---|:---|
| 欧盟 | 《赋能消费者指令》（Empowering Consumers Directive，2024 生效） | 禁泛化环保词（"eco-friendly"/"绿色"无证据即违法）；禁基于碳抵消的"碳中和产品"宣称 |
| 欧盟 | 《绿色声明指令》（Green Claims Directive，立法中） | 环保宣称须**事前验证+生命周期证据**（PEF 方法）；自检声明（self-declared）标签禁止 |
| 美国 | FTC Green Guides（修订中） | "可持续/可降解"等术语使用边界；州法（加州）更严 |
| 英国 | CMA Green Claims Code | 时尚业专项执法（ASOS/Boohoo 被查——"Responsible edit"系列改名） |
| 法国 | AGEC 法+气候法 | "碳中和"广告须披露抵消细节；纺织品环境标签强制化推进 |
| 荷兰/挪威 | 消费者局执法 | H&M "Conscious" 系列案和解（捐 50 万欧元+整改） |

## 二、高危宣称用语（红黑名单）

| 高危（需强证据或禁用） | 相对安全（有凭证即可） |
|:---|:---|
| 环保/eco-friendly/绿色（泛化词——欧盟禁用） | "含 50% GRS 认证再生涤纶"（具体+证书） |
| 可持续系列（sustainable collection） | "本款面料获 OEKO-TEX Standard 100 认证" |
| 碳中和产品（欧盟 2026 起禁抵消型宣称） | "本产品碳足迹 X kg CO2e（PEF 方法核算）" |
| 可降解（须明确条件/时间——填埋环境不降解即误导） | "工业堆肥条件下 180 天降解（EN 13432）" |
| 天然/纯素（边界模糊——需全成分支撑） | "植物染（具体染料名称+工艺说明）" |

## 三、证据链要求

- **再生成分宣称**：GRS/RCS 交易证书（TC——批次级凭证，见 `trade-compliance/textile-certifications.md`）；无 TC 的"再生"宣称=漂绿；
- **有机宣称**：GOTS/OCS 证书+TC；"有机棉"须注明认证比例（"含 70% 有机棉"）；
- **低碳/碳足迹**：ISO 14067/PEF 核算报告（第三方核证更稳——见 `trade-compliance/esg-csrd-sustainability.md`）；
- **可回收宣称**：产品实际可拆可分拣（混纺面料宣称"可回收"多数站不住——涤棉混纺当前无法规模化回收）；
- **追溯数据**：DPP 落地后宣称与护照数据联动（见 `trade-compliance/eu-espr-dpp.md`——宣称必须与 DPP 数据一致）。

## 四、执法案例与后果

- **H&M/Decathlon（荷兰 2022）**："Conscious"/"Ecodesign" 系列宣称依据不明——和解：捐款+营销整改；
- **Boohoo/ASOS（英国 CMA 2022-2024）**："Responsible" 系列筛选标准不透明——签署承诺书（宣称须有明确标准+证据公示）；
- **后果梯度**：整改承诺→行政罚款（欧盟上限全球营业额 4%）→集体诉讼（美国加州）→品牌信任崩塌（社交媒体放大）。

## 五、对供应商的传导

- **客户索证激增**：品牌要求供应商提供"宣称支撑包"（证书/TC/测试报告/供应链声明）——见 `trade-compliance/supply-chain-traceability-mapping.md`；
- **合同条款转移风险**：品牌合同新增"宣称合规保证+赔偿条款"（供应商证据不实→赔偿品牌全部损失）；
- **工厂端动作**：
  1. 建立证书/TC 台账（每批次可查）；
  2. 对客户提供的营销文案**不背书超出证据的部分**（客户写"100% sustainable"，实际只能证"含 50% 再生"——书面留痕建议修正）；
  3. 自有品牌/白牌出海同理自查（见 `fabric/sustainable-fabrics.md` 宣称边界）。

## 六、合规宣称写作公式

**安全宣称 = 具体指标 + 认证/方法 + 边界说明**

- ❌ "环保面料" → ✅ "面料含 60% GRS 认证再生涤纶（证书号 XXX，2026 年有效）"
- ❌ "低碳生产" → ✅ "本厂 2025 年单位产值碳排放较 2020 年下降 30%（ISO 14064 核证）"
- ❌ "零污染染厂" → ✅ "染整环节符合 ZDHC 废水指南 v2.1（检测报告可查）"
