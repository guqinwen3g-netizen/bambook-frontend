# 纺织品认证体系（Textile Certifications）

欧美订单普遍要求产品与工厂持有第三方认证。认证分四大类：**化学品安全、可持续材料追溯、社会责任、动物福利**。理解各认证的覆盖范围与含金量，是接单评估成本与周期的前提。

## 一、化学品安全认证

### OEKO-TEX® STANDARD 100
- 全球最通用的纺织品有害物质检测认证，检测 1000+ 种有害物质（甲醛、重金属、致敏染料、PFAS 等）。
- **四个产品等级（Product Class）**：
  | 等级 | 适用 | 严格度 | 典型产品 |
  |:---|:---|:---|:---|
  | Class 1 | 婴幼儿（0-3 岁） | 最严 | 婴儿服、尿布、床品 |
  | Class 2 | 直接接触皮肤 | 高 | 内衣、T 恤、衬衫 |
  | Class 3 | 不直接接触皮肤 | 中 | 外套、大衣 |
  | Class 4 | 家纺装饰 | 标准 | 窗帘、桌布 |
- 有效期 1 年，每年续证；每个色号/材质单独送检。
- 延伸认证：MADE IN GREEN（可溯源标签）、STeP（工厂可持续生产认证）。

### 其他化学品管控
- 欧盟 REACH 法规（SVHC 高关注物质清单）为**法定义务**非自愿认证，见 chemical-environmental-compliance 文档。
- ZDHC（有害化学品零排放）MRSL：品牌商对染厂化学品清单的要求。

## 二、可持续材料追溯认证

### GRS（Global Recycled Standard，全球回收标准）
- 用途：**再生材料**产品（再生涤纶/锦纶/棉/羊毛）。
- 门槛：最终产品再生含量 **≥20%**（挂 GRS 吊牌）；≥50% 可标特定比例声明。
- 覆盖：含量追溯 + 化学品管理 + 环境与社会责任，审核较严。
- 关键单证：**范围证书（SC, Scope Certificate）** + 每批**交易证书（TC, Transaction Certificate）**。

### RCS（Recycled Claim Standard，回收声明标准）
- 轻量版：只验证再生含量（**≥5%** 即可），不审化学品/社会责任。
- 适用：再生比例低或客户无社会责任审核要求的订单。

### GOTS（Global Organic Textile Standard，全球有机纺织品标准）
- 用途：**有机纤维**纺织品（有机棉/麻/毛为主）。
- 门槛：标"organic"须 **≥95%** 有机纤维；标"made with organic"须 **≥70%**；其余合成/再生纤维≤10%（运动品类可放宽至 25%）；禁用转基因纤维。
- 覆盖：含量追溯 + 加工环保（染化料白名单、废水处理）+ 社会责任，**三者一体**，是有机纺织品最权威认证。
- 单证：SC + TC，每批出货申请 TC。

### OCS（Organic Content Standard，有机含量标准）
- 轻量版：只验证有机含量（≥5%），不限纺织品、不审加工环保。
- 适用：有机混纺比例低、或客户只要含量声明的订单。

### BCI（Better Cotton Initiative，良好棉花发展协会）
- 棉花种植层面的可持续改进体系（节水、减药、土壤健康、体面劳动），**非产品认证**，通过质量平衡（mass balance）核算。
- 品牌（H&M、Zara 等）大量采购 BCI 棉；棉纺企业注册成为 BCI 会员后可按 BCCU 额度流通。

### Bluesign®（蓝标）
- 从**源头管控化学品**的体系认证：染料助剂、染厂工艺、排放、工人安全全链条。
- 户外品牌（Patagonia、The North Face 等）普遍要求面料厂有 Bluesign system partner 资质。

## 三、社会责任验厂（Social Compliance Audit）

| 认证/标准 | 全称 | 说明 |
|:---|:---|:---|
| BSCI | Business Social Compliance Initiative | 欧洲品牌主流，amfori 体系，A/B/C/D/E 评级，通常要求 C 级以上 |
| Sedex/SMETA | Sedex Members Ethical Trade Audit | 英系品牌常用，2-Pillar/4-Pillar |
| WRAP | Worldwide Responsible Accredited Production | 美系服装品牌常用，证书制（白金/金/银） |
| SA8000 | Social Accountability 8000 | 社会责任管理体系认证，证书含金量高 |
| SLCP | Social & Labor Convergence Program | 融合评估框架，一份报告多品牌共享，渐成趋势 |
| Disney FAMA / Walmart / Costco 验厂 | 品牌自建标准 | 大客户自有审核体系，下单前须通过 |

> **接单提示**：新客户首次合作前确认验厂要求（哪套标准、什么级别、有效期），验厂未过不能开工；报告在有效期内可复用给同体系品牌。

## 四、动物福利认证

- **RDS**（Responsible Down Standard，责任羽绒标准）：羽绒制品（羽绒服/睡袋），禁止活拔羽绒，须全链追溯。
- **RWS**（Responsible Wool Standard，责任羊毛标准）：羊毛制品，禁止割皮防蝇法（mulesing），关注草场管理。

## 五、认证选型速查

| 客户要求 | 应持认证 | 备注 |
|:---|:---|:---|
| 产品安全无害 | OEKO-TEX Standard 100 | 按产品等级送检 |
| 再生涤纶面料 | GRS（含量≥20%）/ RCS（≥5%） | 每批申请 TC |
| 有机棉成衣 | GOTS（成衣厂+面料厂都须持证） | 标签写法区分 70%/95% |
| BCI 棉 | 纺纱厂 BCI 会员 + BCCU 额度 | 非吊牌认证 |
| 户外面料 | Bluesign + OEKO-TEX | 品牌常双重要求 |
| 羽绒制品 | RDS | 羽绒源头追溯 |
| 欧洲品牌下单 | BSCI C 级以上或 Sedex | 验厂报告有效期内 |

## 六、成本与周期提示

- OEKO-TEX：按色号/材质计费，周期约 2-4 周，有效期 1 年。
- GRS/GOTS：首次认证审核周期 1-3 个月，此后每年监督审核；TC 每批 5-10 个工作日。
- 验厂：BSCI/Sedex 审核费 + 整改成本，报告有效期 1-2 年（视评级）。
- 认证费用须计入该客户订单成本；小订单客户若要求全套认证，评估投入产出。
