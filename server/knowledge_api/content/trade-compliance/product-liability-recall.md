# 产品责任与召回管理（Product Liability & Recall Management）

欧美产品责任是"**严格责任**"：无过错也可能担责——一次召回的直接成本可达数十万美元，产品责任险与召回预案是出口商的生存配置。

## 一、责任体系

| 体系 | 要点 |
|:---|:---|
| 美国 | 严格产品责任（缺陷产品致害即赔——设计缺陷/制造缺陷/警示缺陷三类） |
| 欧盟 | 产品责任指令（2024 年新修订——扩展至软件/数字产品，举证便利化） |
| 责任链 | 制造商→进口商→分销商全链担责（中国工厂被美国消费者直接起诉虽少，但进口商被诉后必然向供应商追偿） |

## 二、召回触发场景（服装高发）

- **儿童产品**：绳带（勒颈）/小部件（窒息）——CPSC 召回榜常客（见 `trade-compliance/cpsc-children-safety.md`）;
- **阻燃不合规**：睡袍/儿童睡衣（见 `trade-compliance/textile-flammability-regulations.md`）;
- **化学品超标**：铅（拉链/涂层）/邻苯（印花胶浆）/甲醛;
- **抽绳腰绳**：欧盟 EN 14682 不符（进口商主动下架）。

## 三、召回流程（美国 CPSC 模式）

1. **报告义务**：获知缺陷后 **24 小时内**向 CPSC 报告（Section 15(b)——隐瞒不报是加重处罚情节，罚金可达数千万美元）;
2. **召回方案**：与 CPSC 协商（退款/修理/更换——Fast Track 快速召回程序减免部分处罚）;
3. **公告执行**：官网/社媒/零售端公告（召回执行率有考核——联系消费者率）;
4. **进度报告**：月度报告召回进展;
5. **产品处置**：召回品销毁/整改（防止二次流入市场）。

## 四、召回成本构成

- **直接成本**：退款/销毁/物流/公告（平均每起召回 $10-100 万——童装大规模召回更高）;
- **间接成本**：品牌损害/平台下架（亚马逊同步冻结 ASIN）;
- **处罚**：CPSC 民事罚款（未及时报告的历史案例 $100-1500 万）;
- **诉讼**：人身伤害诉讼（和解金/律师费）。

## 五、产品责任险（Product Liability Insurance）

- **保额**：美国客户普遍要求 $100-500 万/次（百货渠道 $500 万+，见 `customers-market/department-store-channel.md`）;
- **保费**：约营收 0.1-0.5%（儿童产品/高风险品类上浮）;
- **承保范围**：人身伤害/财产损失（**注意：召回费用通常需单独附加召回险**）;
- **投保要点**：保险公司安全问卷（质量体系/检测记录影响费率——投保前整理证据链）;
- **出口信用险互补**：信用险保货款，责任险保安全责任（不同风险，见 `trade-process/export-credit-insurance.md`）。

## 六、预防体系（远胜于补救）

- **设计阶段**：安全设计评审（儿童款绳带/小部件红线检查表——见 `garments/childrenswear-production.md`）;
- **检测前置**：CPC 全项测试（不合格不出货——侥幸心理是召回之源）;
- **追溯体系**：批次管理（SKU+生产日期码——出问题时精准召回而非全系列）;
- **供应商协议**：责任分担条款（工厂→贸易公司→进口商逐级追偿合同化）;
- **客户通知**：发现潜在问题主动通知客户（主动召回 vs 被动查处——处罚力度天差地别）。

## 七、危机应对预案

- **召回小组**：法务/品质/客服/公关角色预演;
- **沟通模板**：消费者公告/零售商通知/监管报告模板库;
- **证据保全**：生产记录/检测报告封存（诉讼举证）;
- **舆情监测**：社媒投诉关键词监控（早期信号——一个 viral 投诉视频可能触发监管注意）。
