# UFLPA 与美国强迫劳动合规（UFLPA & Forced Labor Compliance）

《维吾尔强迫劳动预防法》（UFLPA，2022-06-21 生效）是美国对纺织服装进口影响最深远的单边法规：**"可反驳推定"机制将举证责任完全倒置给进口商**。棉纺供应链是全法执法的"高优先级行业"。

## 一、核心机制：可反驳推定（Rebuttable Presumption）

- **推定原则**：凡全部或部分在新疆地区开采/生产/制造的商品，**推定为强迫劳动产品，禁止入境**；与 UFLPA 实体清单企业相关的产品同样推定禁止。
- **举证责任倒置**：进口商必须用"清晰且令人信服的证据"（clear and convincing evidence）证明供应链无涉疆要素——这是美国海关法中最高的举证标准。
- **范围穿透**：不限于新疆直接出口——第三国加工（越南/孟加拉成衣）只要原料含新疆棉，同样被禁。

## 二、实体清单（Entity List）

- UFLPA 实体清单由跨部门工作组（FLETF）持续扩充，覆盖：新疆棉企、纺纱厂、以及使用其原料的下游企业。
- 清单企业及其子公司的产品推定禁止入境；**与清单企业有供货关系本身即触发推定**。
- 实务动作：接单/采购前对照最新实体清单筛查供应商与客户指定原料商（清单动态更新，CBP 官网可查）。

## 三、执法流程

| 环节 | 说明 |
|:---|:---|
| 扣留（Detention） | CBP 口岸扣留嫌疑货物，30 天内提交反驳证据 |
| 举证 | 提交全供应链溯源文件（见下） |
| 释放/排除 | 证据充分则放行；否则排除（exclusion）甚至没收（seizure） |
| WRO | 暂扣令（Withhold Release Order）——针对特定企业/地区的持续扣留令 |

- 服装被扣后仅约 **30-40%** 能成功举证放行——多数因溯源文件不完整被排除。

## 四、溯源文件体系（通关举证包）

CBP 期望的"清晰且令人信服"证据链：

```
棉农/轧花厂发票 → 籽棉采购记录 → 纺纱厂（纱线批次号+采购发票）
→ 织布厂（坯布流转单）→ 染整厂（加工单）→ 成衣厂（生产记录）
→ 出口商（装箱单/提单）→ 进口商
```

每一环要求：
1. **交易文件**：采购合同、发票、付款凭证；
2. **运输文件**：各环节运输单据（证明物理流转）；
3. **生产记录**：投料记录（纱线批次对应坯布批次对应成衣批次）；
4. **企业信息**：每环节供应商营业执照/产能证明。

### 技术工具
- **同位素检测（isotope testing）**：通过棉花同位素指纹鉴定产地——CBP 与品牌均采用的抽检手段，"单据链 + 检测"双验证。
- **区块链溯源平台**：TextileGenesis 等被品牌用于纤维级追溯。

## 五、企业应对策略

### 风险隔离
- **棉源白名单**：输美棉制品优先使用美棉（Supima）、澳棉、巴西棉、西非棉——要求供应商提供产地证书（certificate of origin at fiber level）。
- **BCI/USCTP 追溯体系**：参与可信棉花追溯项目（注意：BCI 曾暂停新疆良好棉花认证，BCI 证书本身不等于"非新疆"证明）。

### 供应商管理
- 采购合同加入**"非新疆棉保证条款"** + 违约赔偿责任；
- 对纺纱/织布供应商做原料来源审计（上游轧花厂名单）；
- 高风险订单出货前做同位素抽检预验证。

### 被扣应对
- 30 天举证期内快速集结文件包（平时就应建立"一单一档"）；
- 聘请熟悉 CBP 程序的报关行/律师；
- 无法举证时选择**再出口（re-export）**止损，避免没收记录影响后续进口信用。

## 六、欧盟 FLR 联动

- 欧盟《禁止强迫劳动条例》（EU 2024/3015）2027-12-14 起适用，无规模门槛、覆盖所有产品（见 `trade-compliance/esg-csrd-sustainability.md`）。
- **一套溯源档案，美欧双用**：现在建立的棉源溯源体系是未来欧盟市场的准入门票。
