# 纺织品阻燃法规专题（Textile Flammability Regulations）

阻燃是欧美服装的"**隐性强制门槛**"：一般服装需过 16 CFR 1610 基础可燃性，儿童睡衣另有 1615/1616 严格标准——不合规面临召回与 CPSC 处罚。

## 一、美国法规体系（CPSC 执法）

| 法规 | 适用 | 核心要求 |
|:---|:---|:---|
| 16 CFR 1610 | 一般服装纺织品 | 基础可燃性分级（Class 1 正常可燃才可销售——Class 3 快速剧烈燃烧禁售） |
| 16 CFR 1615/1616 | 儿童睡衣（0-6X/7-14 码） | 垂直燃烧炭化长度≤17.8cm（严格——宽松睡衣需阻燃处理或紧身豁免） |
| 16 CFR 1630/1631 | 地毯 | （家纺相关） |
| 16 CFR 1632/1633 | 床垫/床褥 | 明火+香烟阴燃（家纺出口硬门槛） |

## 二、1610 基础可燃性要点

- **测试**：45° 斜面燃烧（1 秒火焰接触——测火焰蔓延时间）;
- **分级**：Class 1（蔓延≥3.5s 普通/≥7s 起绒面——可销售）/Class 2（中等——起绒面 4-7s 警示）/Class 3（<3.5s——**禁售**）;
- **高危面料**：薄型起绒/长毛絮面/薄纱（ rayon/棉起绒面燃烧快——抽查高发）;
- **豁免**：帽子/手套/鞋/里布（非直接接触层）。

## 三、儿童睡衣 1615/1616（严格）

- **测试**：垂直燃烧（3 秒火焰——炭长≤17.8cm，5 样本平均）;
- **"紧身豁免"**：紧身睡衣（按法规尺寸表——胸腰围贴身）可豁免阻燃测试（靠不兜空气降低风险——设计规避路径：袖口/裤口收口）;
- **宽松款**：必须阻燃（本质阻燃纤维 or 阻燃整理——且**耐洗 50 次**后仍达标）;
- **标识**：黄色吊牌（阻燃处理款标注护理——紧身款标注"须贴身穿着"）;
- **抽检执法**：CPSC 市场抽检+亚马逊 CPC 审核（见 `trade-compliance/cpsc-children-safety.md`）。

## 四、欧盟/英国

- **欧盟**：一般服装无统一阻燃强制（但 GPSR 一般安全原则兜底——见 `trade-compliance/eu-gpsr-deep-dive.md`）;
- **英国**：睡衣安全条例（Nightwear Safety Regulations——儿童睡衣 BS 5722 阻燃）;
- **EN 标准**：EN 14878（儿童睡衣燃烧性能——协调标准）;
- **窗帘/家纺**：各国公共场所阻燃要求（德国 B1/法国 M1——酒店工程单必备）。

## 五、阻燃技术路线

- **本质阻燃纤维**：芳纶/阻燃腈氯纶/阻燃粘胶（永久——高价，工装/防护服）;
- **阻燃整理**：棉用 Proban/Pyrovest（磷系——耐洗 50 次，工装主流）;
- **儿童睡衣现实方案**：紧身设计豁免（90%+ 品牌选择——阻燃整理化学品争议，家长抵触）;
- **混纺陷阱**：涤棉混纺"骨架效应"（棉燃涤熔滴——比纯品更危险，测试必做）。

## 六、合规实操

- **测试时机**：大货面料送检（每缸留样——燃烧性能受克重/起绒批次影响）;
- **实验室**：CPSC 认可实验室（见 `trade-compliance/testing-lab-selection.md`）;
- **证书链**：儿童睡衣 CPC 证书含阻燃项（测试报告+CPC 存档 5 年）;
- **召回案例**：CPSC 官网可查（薄纱睡袍/浴袍召回高发——进口商承担召回成本）。
