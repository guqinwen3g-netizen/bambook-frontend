# RCEP 与自贸协定优惠利用（RCEP & FTA Utilization）

区域全面经济伙伴关系协定（RCEP）2022 年生效，覆盖东盟十国 + 中日韩澳新，是全球最大自贸区。纺织服装是 RCEP 关税减让的重点受益品类，**累积规则**对重构供应链意义深远。

## 一、RCEP 核心价值

### 关税减让
- 区域内 90% 以上货物最终零关税，分阶段降税（10-20 年过渡期）。
- **中日首次建立自贸关系**：日本对华纺织服装关税从约 8-11% 逐步下调，多数品类在 10-16 年内降至零——这是出口日本订单的实质性利好。
- 中韩、中国-东盟已有 FTA，RCEP 在其基础上进一步降税。

### 原产地累积规则（Cumulation）
- **核心机制**：缔约国之间原材料价值可以**累积计算**区域价值成分（RVC）。
- 例：中国面料 → 越南成衣 → 出口日本，中国面料价值可计入越南的区域价值成分，使成衣更易达到原产资格。
- 对纺织供应链的意义：在 RCEP 区域内采购面辅料不影响最终产品的优惠资格，方便"中国面料 + 东南亚缝制"模式。

## 二、原产资格判定

常见判定标准（按产品特定规则 PSR，因 HS 编码而异）：
1. **税则归类改变（CTC）**：加工后 HS 编码发生改变（如面料 52-60 章 → 服装 61-62 章天然满足）。
2. **区域价值成分（RVC）**：通常要求 ≥ 40%（可累积计算）。
3. **加工工序标准**：如"裁剪 + 缝制"（cut and sew）规则。

> 纺织服装多数适用"章改变"或 RVC 40%，中国产面料在中国缝制成衣基本天然符合。

## 三、优惠凭证与申请

| 凭证 | 签发方 | 适用 |
|:---|:---|:---|
| RCEP 原产地证 | 海关或贸促会（CCPIT） | 常规出口 |
| 原产地声明 | 经核准出口商自行出具 | 高级认证企业 |
| 背对背原产地证 | 中转国签发 | 经第三方转运分拨 |

- **申请渠道**：中国国际贸易单一窗口（singlewindow.cn）或贸促会原产地证系统，线上申请当日可出证。
- **申请时机**：货物出运前后均可（出运后 1 年内可补发），但建议出运前办好随货同行。

## 四、税率查询与对比

- **官方查询**：中国自由贸易区服务网（fta.mofcom.gov.cn）按 HS 编码查各协定税率。
- **动态对比**：同一产品在 RCEP / 中国-东盟 FTA / 亚太贸易协定下税率可能不同，**选最优协定申报**。
- 例：棉制针织 T 恤（HS 6109.10）出口日本——MFN 约 10.9%，RCEP 逐年递减。

## 五、其他主要 FTA 速查

| 协定 | 伙伴 | 纺织要点 |
|:---|:---|:---|
| 中国-东盟 FTA | 东盟十国 | 大部分纺织服装已零关税 |
| 中韩 FTA | 韩国 | 服装分阶段降税，部分敏感品类例外 |
| 中澳 FTA | 澳大利亚 | 纺织品已基本零关税 |
| 中国-智利/秘鲁/新西兰/瑞士等 | 多国 | 查询单一窗口 |
| CPTPP | 未加入 | 越南/墨西哥享其优惠，是中国订单分流原因之一 |

## 六、实操策略

1. **报价时算优惠**：对日/韩/东盟报价将 RCEP 降税空间纳入竞争力测算。
2. **主动提供证书**：客户清关凭 RCEP 证书享优惠，主动办证是服务加分项（办证成本仅数十元/份）。
3. **供应链规划**：评估"中国面料 + 东南亚成衣"模式下累积规则的关税优化空间，对冲美国 301 关税（RCEP 优惠不适用美国）。
4. **留存原产地证据**：原材料采购发票、生产记录保存 3 年以上，海关核查时需举证。
5. **注意直接运输规则**：经非缔约国转运需未再加工证明（如经香港中转的"中转确认书"）。
