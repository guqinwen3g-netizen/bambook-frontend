# 欧洲各国供应链立法（EU National Supply Chain Laws）

CSDDD 统一化之前，欧盟多国已先行立法（德国 LkSG、法国警戒义务法等）。2026 年 Omnibus I 后格局重构：**各国法向 CSDDD 对齐收窄，但通过品牌合同条款的"间接传导"对中国供应商的实质要求不会消失**。

## 一、各国立法现状（2026）

| 国家 | 法律 | 门槛（现行） | 2026 动态 |
|:---|:---|:---|:---|
| 德国 | **LkSG**（2023 生效） | 1000+ 员工 | 2026-07-02 改革方案：最早 2026 秋收窄至 **5000+ 员工 + 15 亿€**；报告义务已取消；将以新"国际企业责任法"1:1 转化 CSDDD（死线 2028-07-26） |
| 法国 | **警戒义务法**（2017，全球首部） | 5000+ 员工（法国总部）/10000+（全球） | 多起纺织业诉讼进行中（快时尚品牌被 NGO 起诉）；全 harmonization 领域将向 CSDDD 对齐 |
| 挪威 | 透明度法（2022） | 大中型企业 | 消费者可要求企业提供供应链信息 |
| 荷兰 | 童工尽职调查法 + CSDDD 转化准备 | - | 待 CSDDD 转化 |
| 英国 | 现代奴隶法案 2015（非欧盟但相关） | 营收 3600 万镑+ | 年度声明义务；修订讨论中 |

### 关键理解：全 harmonization（Full Harmonization）
- Omnibus I 后，CSDDD 对**风险分析、预防/纠正措施、投诉程序、监督、报告**实施"全 harmonization"——成员国在这些领域**不得制定更严规定**。
- 意味着德国 LkSG 等各国法将逐步"瘦身"到 CSDDD 统一标准，合规碎片化风险降低。

## 二、对中国供应商的传导路径

### 直接适用（极少数）
- 中国企业在德国有 1000+ 员工分支才直接适用 LkSG——纯出口商不适用。

### 间接传导（主要路径）
```
欧盟大客户（在法适用范围内）
→ 合同条款要求供应商遵守《供应商行为准则》
→ 审核（BSCI/SMETA/品牌自有标准）
→ 纠正措施计划（CAP）
→ 严重违规：暂停/终止合作
```

- **预防义务前移**：LkSG/CSDDD 要求大客户对"有实据风险线索"（substantiated knowledge）的间接供应商也要行动——品牌会把球踢给一级供应商（贸易公司），要求管理自己的下级工厂。
- **投诉机制**：任何人/NGO 可向 BAFA（德国联邦经济出口管制局）投诉——历史上纺织业是高投诉行业。

## 三、纺织业的高风险点

| 风险领域 | 触发场景 |
|:---|:---|
| 强迫劳动 | 涉疆棉（UFLPA 联动）、监狱劳工 |
| 童工 | 家庭作坊环节、暑期工 |
| 工时工资 | 旺季超时加班、社保欠缴 |
| 职业安全 | 消防、化学品（印染厂） |
| 环境 | 印染废水排放 |

## 四、供应商应对

1. **维护审核有效性**：BSCI/SMETA 证书保持有效，CAP 及时关闭（见 `suppliers/factory-audit-guide.md`）。
2. **下级供应商管理**：面辅料厂/外发厂纳入合规告知（签署行为准则附录）——大客户会要求提供供应链图谱。
3. **投诉应对预案**：收到客户转来的 NGO/BAFA 质询时，48 小时内响应、提供事实材料、避免对抗性回复。
4. **利用减负空间**：Omnibus 后大客户不能强制要求 <1000 员工供应商提供超 VSME 标准的数据（"受保护企业"条款）——对过度数据索取可理性沟通。

## 五、与 CSDDD/FLR 的关系

- **CSDDD**：2029-07-26 起适用（5000+ 员工/15 亿€），各国法逐步对齐（见 `trade-compliance/esg-csrd-sustainability.md`）。
- **FLR**：产品禁令无门槛、独立运行——**LkSG 减负不等于强迫劳动风险降低**（见 `trade-compliance/uflpa-forced-labor.md`）。
- 三层架构：CSDDD（超大型企业过程义务）+ 各国法（过渡）+ FLR（产品禁令兜底）。
