# 加州 65 号提案合规（California Proposition 65）

Prop 65 是"**警告义务**"而非禁令：含 900+ 清单物质超安全港水平就必须加警告标签——服装/鞋包是 bounty hunter（赏金律师）诉讼重灾区。

## 一、基本机制

- **全称**：1986 年安全饮用水与有毒物质强制执行法（Safe Drinking Water and Toxic Enforcement Act）;
- **清单**：900+ 种化学物质（铅/镉/邻苯二甲酸酯/甲醛/BPA——OEHHA 每年更新）;
- **义务**：暴露于清单物质超过**安全港水平（safe harbor level）**时，必须提供"清晰合理的警告";
- **适用范围**：在加州销售的所有产品（线上卖到加州也算——亚马逊卖家同样适用）;
- **执法方式**：政府执法+**私人执法（bounty hunter）**——律师/NGO 可代位起诉并分得罚款 25%（产业化诉讼）。

## 二、服装鞋包高危物质

| 物质 | 常见来源 | 安全港水平参考 |
|:---|:---|:---|
| 铅（lead） | 拉链/金属配件/印花油墨/PVC 涂层 | 0.5μg/天（暴露量极低——金属配件必测） |
| 邻苯二甲酸酯（DEHP/DBP/BBP 等） | PVC 革/胶浆印花/软胶章 | 各物质限值不同 |
| 镉（cadmium） | 金属扣/电镀件/颜料 | 金属饰品高危 |
| 甲醛 | 免烫整理/粘合剂 | 纺织品常规项 |
| BPA | 热敏纸吊牌/某些涂层 | 吊牌小票纸 |
| 全氟化合物（PFAS 类） | 防泼水整理 | 2023 起陆续列入（户外服注意） |

## 三、警告标签形式

- **标准格式**：黄色三角警告符号+"WARNING: This product can expose you to chemicals including [物质名], which is known to the State of California to cause cancer/birth defects..."（长短两种格式——短格式 2024 修订后需含至少一个物质名）;
- **载体**：产品标签/包装/货架标签/网页（**电商需在网页展示**——下单前可见）;
- **语言**：销售地语言（英文+必要时的西班牙语）。

## 四、两条合规路线

1. **测试豁免路线**：检测证明暴露量低于安全港水平（无需警告——一劳永逸但测试成本高，且配方变动需重测）;
2. **警告标签路线**：不测试直接加警告（成本低——但警告标签影响转化，且亚马逊部分类目不愿收）;
**实务**：核心款测试+长尾款标签（或者全链控制高危物质源头：无铅拉链/环保油墨——见 `trade-compliance/chemical-environmental-compliance.md`）。

## 五、诉讼与和解现实

- **60 天通知**：私人执法先发违规通知（60 天内政府不介入则私人可起诉）;
- **和解金额**：服装配件类和解常见 $10,000-100,000/案（+律师费——小卖家也难幸免）;
- **和解协议**：通常要求整改（配方/标签）+罚金+原告律师费;
- **高危品类史案**：仿皮手袋（铅）/PVC 雨衣（邻苯）/金属腰带扣（铅镉）/印花童装（铅）。

## 六、电商卖家特别义务

- **网页警告**：产品页需展示警告（结账前可见——仅包装贴标不够）;
- **亚马逊合规**：类目审核可能要求 Prop 65 声明（违规 listing 下架）;
- **FBA 库存**：入加州仓即视为在加州销售（全美销售统一加标最省事——其他州不反对）。

## 七、应对策略

- **供应链管控**：拉链/扣具/印花厂索 Prop 65 检测报告（合格供方名录）;
- **定期抽测**：高危部件年测（供应商换料是失控点——合同写入违规赔偿条款）;
- **收到 60 天通知**：立即找专业律师（抗辩空间存在但成本高——多数和解）;
- **保险**：产品责任险附加合规诉讼条款（见 `trade-compliance/product-liability-recall.md`）。
