# 抗菌防蚊处理纺织品法规（EU BPR / US EPA FIFRA: 杀生剂处理制品合规）

"抗菌""防蚊""防螨""抗病毒"是纺织功能整理的常见卖点，但在欧美法规下它们是**杀生剂宣称（biocidal claims）**——受专门法规管辖，而非普通纺织品合规。宣称越界=下架/召回/罚款。产品技术侧见 `fabric/antimicrobial-insect-repellent-finishes.md`，本文聚焦法规边界。

## 一、欧盟 BPR（杀生剂产品法规 528/2012）

- **处理制品（treated article）规则**：含杀生剂成分的纺织品（抗菌袜/防蚊服/防螨床品）——**所用活性成分必须已在欧盟批准清单**（对应产品类型 PT 2/7/9/18 等），且供应商需能提供合规声明；
- **标签要求**：处理制品须标注**处理声明（"含杀生剂"）+活性成分名称+警示语**（如致敏提示）——即使终端是服装也适用；
- **宣称管制**："抗菌/抗病毒/抗 COVID"等宣称必须有功效证据+与批准用途一致——**"抗新冠病毒"类宣称在疫情后被重点执法**（大批listing下架案例）；
- **执法趋势**：成员国市场监管（德国/法国抽查电商）+边境核查——进口商负主体责任（品牌/进口商连带）；
- **氯菊酯防蚊服**：氯菊酯（permethrin）在欧盟 PT 18（杀虫剂）项下——处理制品需确认批准状态与使用条件。

## 二、美国 EPA FIFRA（联邦杀虫剂法）

- **豁免路径（treated article exemption）**：纺织品杀生剂处理**只能宣称"保护产品本身"**——"抗菌防臭（anti-odor）""防霉保护面料"属豁免范围；
- **人体健康宣称=农药注册**："防蚊驱蜱防虫咬（保护穿着者）"→**该处理必须按农药在 EPA 注册**（如 Insect Shield 模式——注册号标注）——未注册的人体防护宣称=违法销售；
- **州注册**：加州等州额外注册要求；
- **亚马逊执行**：美国站对 antimicrobial/pesticide 宣称 listing 强制要求 EPA 注册号或豁免声明——**文案措辞（"protects the fabric" vs "protects you"）定生死**。

## 三、其他市场

- **韩国 K-BPR**：杀生剂物质/产品批准制（对标 EU）；
- **日本**：防蚊/抗菌加工属"杀虫剤/防臭加工"边界——SEK 标志（纤维评价技术协议会——自愿性品质认证，电商信任标）；
- **中国**：消毒产品（卫消字号——抑菌织物）与农药（驱蚊）边界——内销宣称管理；
- **海湾/东南亚**：SASO/TISI 等进口核查中功能宣称文件要求渐严。

## 四、实操合规清单

| 动作 | 要点 |
|:---|:---|
| 活性成分追溯 | 向整理剂供应商索取**成分名称+欧盟批准状态/EPA 注册状态**（Sanitized/银离子/氯菊酯——批次技术文件） |
| 宣称文案审查 | 分市场措辞库（美站"protects the garment from odor-causing bacteria"合规句式） |
| 标签缝制 | 欧盟处理制品标签+美国豁免声明——成分标外挂功能标 |
| 检测留档 | 抗菌率（AATCC 100/ISO 20743）/驱避率测试报告——宣称证据链（见 `trade-compliance/testing-standards.md`） |
| 平台申报 | 亚马逊 pesticide 类目问卷预判——避免 listing 冻结 |
| 反漂绿 | 功能宣称与环保宣称区分（见 `trade-compliance/green-claims-anti-greenwashing.md`） |
