# 纺织检测标准（Testing Standards）

纺织服装出口须满足目的国标准，检测结果用于验货、报关与客户验收。常见标准体系包括国际的 **ISO**、美国的 **AATCC**、欧盟的 **EN** 与中国的 **GB**。理解各体系的测试方法与限值，是保证交单合格、避免退赔的关键。

## 一、主要标准体系

| 体系 | 组织/地区 | 典型用途 |
|:---|:---|:---|
| **ISO** | 国际标准化组织 | 国际通用，多数市场认可 |
| **AATCC** | 美国纺织化学师与印染师协会 | 美国市场常用 |
| **ASTM** | 美国材料与试验协会 | 美国物理性能测试 |
| **EN** | 欧洲标准 | 欧盟市场准入参考 |
| **GB** / **FZ** | 中国国标/纺织行业标准 | 内销与部分外贸基础 |

> 同一指标不同标准方法/限值不同，务必以**客户指定标准**为准，避免用错方法导致误判。

## 二、常用物理性能测试

- **缩水率（dimensional stability / shrinkage）**：水洗/干洗后尺寸变化，常用 AATCC 135、ISO 6330。
- **色牢度（colorfastness）**：耐水洗、耐摩擦、耐汗渍、耐光照、耐唾液等。
  - 摩擦牢度 AATCC 8/116，水洗牢度 AATCC 61、ISO 105-C06。
- **起球（pilling）**：织物表面起球程度，AATCC 135 配套、ASTM D4970、ISO 12945。
- **强力（strength）**：拉伸强力和撕破强力，ASTM D5034/D2261、ISO 13934。
- **耐磨（abrasion）**：马丁代尔（Martindale）耐磨测试，ISO 12947。
- **色差（color difference）**：染色一致性，常用灰度卡（gray scale）评级 1-5 级。

## 三、成分与含量检测

- **纤维成分（fiber content）**：鉴别纤维种类与比例，如棉/涤/氨混纺，ISO 1833、AATCC 20A。
- **甲醛含量（formaldehyde）**：游离甲醛限量，OECD/GB 18401。
- **pH 值**：纺织品水萃取液酸碱度，GB 18401 要求 4.0-9.0。
- **偶氮染料（azo dyes）**：禁用偶氮染料致敏/致癌，见环保合规文档。
- **重金属**：铅、镉、镍等迁移限量（尤其童装/配饰）。

## 四、标识与标签要求

- **成分标签（fiber content label）**：美国 FTC 要求英文表述成分比例。
- **保养标签（care label）**：洗护符号说明（ASTM/ISO care symbols）。
- **原产国标签（country of origin）**：美国强制要求永久性"Made in China"等标记。
- **耐久性**：美国要求标签在服装使用期内可读（耐久性标签）。

## 五、检测机构与流程

- **国际第三方机构**：SGS、Intertek（天祥）、BV（必维）、TÜV、ITS。
- **国内机构**：中纺标（CTA）、中国纤维检验局、各省质检院。
- **流程**：样品确认 → 测试项目报价 → 出报告 → 报告审核 → 交单/留档。
- **注意事项**：报告有效期、是否需目的国认可（accredited lab）、测试标准版本需与合同一致。

## 六、验货（Inspection）配合

- **出货前检验（pre-shipment inspection, PSI）**：按 AQL（可接受质量水平）抽样，常见 AQL 2.5/4.0。
- 常见第三方验货：SGS/Intertek 的 AQL 抽样、色差/尺寸/功能/外观抽检。
- 检测报告与验货报告共同构成**交单结汇**的凭据，务必留存。

## 七、实操提示

1. **接单即确认标准**：报价时明确测试项、标准与方法、限值，写入合同。
2. **大货前打样送检**：投产前送样检测，避免大货不合格。
3. **保留检测报告**：客户索赔或海关查验时作为合规依据。
