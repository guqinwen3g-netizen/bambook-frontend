# 欧盟电池法规与带电纺织品合规（EU 2023/1542: 可拆卸要求/标签/尽职调查）

欧盟《电池与废电池法规》(EU) 2023/1542 于 2023 年 8 月生效，取代 2006 电池指令——**从指令升级为法规（直接适用 27 国）**。对带电纺织品（加热服/智能穿戴/发光服），**2027 年 2 月 18 日起便携式电池必须"用户可拆卸"**——这一条直接改写产品设计。运输侧（UN38.3/空运海运）见 `trade-compliance/lithium-battery-shipping-compliance.md`——本文聚焦**产品设计与市场准入侧**。

## 一、法规核心时间线（纺织相关条款）

| 生效时间 | 要求 | 对带电纺织品影响 |
|:---|:---|:---|
| 2024-02-18 起 | CE 标志+符合性声明（DoC）+**电池护照预备** | 出口文件包升级 |
| 2024-08-18 起 | 有害物质限值（汞/镉/铅）+标签（打叉垃圾桶） | 常规已合规项复核 |
| 2025-08-18 起 | **生产者责任延伸 EPR**（各国注册+回收缴费） | 卖家/进口商注册义务（同包装法逻辑——`trade-compliance/packaging-epr-regulations.md`） |
| 2026-08-18 起 | 可拆卸**法规细则+豁免清单**明确 | 设计定型最后窗口 |
| **2027-02-18** | **便携式电池必须可由最终用户拆卸更换** | **加热服/穿戴产品设计红线** |
| 2027 年起 | 电池碳足迹声明（>2kWh——纺织品基本不涉及） | — |

- **可拆卸条款核心**：用户可用**普通工具**（螺丝刀/撬片）自行拆卸更换电池——**胶封/超声波焊接死封的电池仓 2027 年起禁售**；豁免情形：医疗器械/防水防尘等级必需（IP67+ 且拆卸破坏防水）——**加热服防水诉求可援引豁免但需逐案论证**；
- **专业拆卸过渡期**：2027 前设计为"专业人员可拆卸"（售后拆换）已不足够——**最终用户可拆卸**是终局标准。

## 二、带电纺织品设计合规策略

- **电池仓重构**：磁吸/卡扣/旋钮电池仓（加热马甲电池口袋+插拔接口已是主流——天然合规）——**风险产品=内置缝合电池的智能穿戴**（加热鞋垫/加热手套一体款——必须改为模块化）；
- **连接器标准化**：USB-C 供电（DC 接口逐步淘汰——与欧盟通用充电器指令 2022/2380 协同）；**电池规格通用化**（5V/7.4V 标准移动电源兼容——用户自备电池模式规避大部分义务）；
- **"无电池销售"模式**：加热服不配电池（用户自购充电宝）——**产品落出电池法规范畴**（但页面必须明确电池规格要求——差评管理）；
- **标签与文档**：电池打叉垃圾桶标志+容量标识+DoC（声明符合 2023/1542 附件 I）；说明书多语种拆卸指南（拆卸说明 2027 年起强制）。

## 三、EPR 注册与回收义务

- **生产者定义**：在成员国**首次投放电池/含电池产品**的主体——中国卖家直邮欧盟（DDP/平台代扣模式）=卖家或平台承担；进口商模式=进口商承担；
- **各国注册**：德国（Stiftung EAR 电池注册——与 WEEE 并行）、法国（Screlec/Corepile 回收组织）、意大利（Registro Pile）——**每国分别注册+按销量缴费**（€0.01-0.1/节量级）；
- **平台执法**：亚马逊欧洲站 2025 年起**强制提交电池 EPR 注册号**（同包装法/WEEE 的合规门槛化）——无注册号下架；速卖通/Temu 同步跟进；
- **与既有法规叠加**：WEEE（电子电气回收——智能穿戴主机）、包装法（彩盒）、电池法（电芯）——**一件带电纺织品三重 EPR 注册**（合规成本 €2000-5000/国/年量级——选国聚焦策略）。

## 四、风控与行动清单

- **设计冻结检查**：2026 年前完成在售带电产品电池可拆卸性盘点——不可拆卸款**2026 年内完成改版或清库退出欧盟**；
- **供应链文件**：电芯供应商提供 2023/1542 符合性文件（汞镉铅检测+碳足迹声明预备）；**回收材料比例声明**（2031 年起钴/锂/镍回收比例——提前锁定合规电芯厂）；
- **责任链划分**：合同中明确 EPR 注册责任（卖方注册还是买方注册——平台模式下平台代注册费用转嫁条款）；
- **罚则认知**：各成员国处罚（德国最高 €10 万+禁售）；海关扣货（电池文件不全——`trade-process/customs-inspection-detention-response.md`）；
- **全球外溢**：英国 UK 电池法规跟随评估、美国州法（加州 AB 系列电池回收提案）——**欧盟先行→全球跟随的历史规律**（同 GDPR/包装法路径）。
