# 两用物项与敏感品类出口管制（Dual-Use & Sensitive Items Export Control）

纺织外贸中的"特殊品类"——军服、防弹衣、战术装备、军规面料——涉及**出口管制与军品出口许可**。误碰红线不仅是罚款，可能涉及刑事责任。

## 一、什么算敏感品类

| 品类 | 管制属性 |
|:---|:---|
| 防弹衣/防弹插板 | **两用物项**（民用安保+军用）——出口需许可证 |
| 军用迷彩服/军服 | 现役军服样式出口敏感（部分国家禁止） |
| 战术背心/战术装备 | 视目的国与最终用户（军警订单敏感） |
| 阻燃/防割军规面料 | 高性能纤维（芳纶/超高分子量聚乙烯）制品 |
| 防化服/核生化防护 | 明确两用物项 |
| 夜视/红外隐身面料 | 军品技术 |

## 二、中国出口管制框架

- **《出口管制法》**（2020 施行）：两用物项/军品/核心技术管制；
- **两用物项出口管制清单**：军贸七类+两用清单——防弹材料及制品在列；
- **军品出口专营**：军品出口须通过军贸公司专营资质（普通外贸公司不能做军品）；
- **最终用户/最终用途审查**：出口需申报最终用户——**转售军方=违规**。

## 三、业务场景风险判定

| 场景 | 风险等级 |
|:---|:---|
| 民用保安公司防弹背心 | 中——需两用物项许可证 |
| 国外警用装备订单 | 高——最终用户审查严格 |
| 战乱/制裁国家军警订单 | **极高——禁止**（联合国制裁名单国家） |
| 普通迷彩图案民用服装（狩猎服/户外） | 低——民用迷彩不构成军品（但避免现役军服完全复刻） |
| 战术风民用服饰（tactical fashion） | 低——外观风格不涉管制 |

## 四、合规操作流程

1. **品类判定**：接单先判定是否涉管制（技术参数对照两用清单——防弹等级 NIJ IIIA 以上基本必管）；
2. **许可申请**：两用物项许可证（省级商务主管部门——最终用户证明+合同+技术说明）；
3. **最终用户声明**：客户出具 EUC（End User Certificate）——承诺不转售军方/受制裁实体；
4. **目的国审查**：受制裁国家/地区一律不接（名单动态更新——商务部/外交部公告）；
5. **报关申报**：HS 编码+许可证号如实申报（瞒报=走私）。

## 五、违规后果

- **行政处罚**：罚款+没收+吊销外贸经营权；
- **刑事责任**：走私罪/非法经营罪（军品）；
- **国际风险**：目的国制裁连带（美国 BIS 实体清单——涉军转售可能被列入，全球业务瘫痪）。

## 六、民用边缘品类的把握

- **迷彩民用服装**：可以做（民用狩猎/户外/潮流迷彩是市场品类）——但不做现役军服 1:1 复刻+不接军警最终用户；
- **防弹元素民用化**：防割手套（工业）可以做；防弹等级产品需许可；
- **谨慎原则**：拿不准的先咨询商务部门/专业律师——**一单违规毁掉整个公司**。
