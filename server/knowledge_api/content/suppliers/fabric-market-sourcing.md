# 面料市场采购指南（Fabric Market Sourcing）

中国面料现货市场是全球最大的纺织品集散地。小批量、快反订单离不开市场找布；即使定向开发，市场也是比价、找灵感、验证供应商报价的基准线。

## 一、三大核心市场

### 绍兴柯桥（中国轻纺城）
- **地位**：全球最大纺织品集散中心，年成交额数千亿级。
- **结构**：按品类分区——东区（针织/女装面料）、北市场（窗帘/家纺）、联合市场（时装面料）、坯布市场（白坯）。
- **优势品类**：化纤时装面料、针织布、印花布；绍兴本地印染产能全国第一。
- **特点**：档口+工厂结合，现货充足，可剪样（cutting sample）、可寄样卡。

### 广州中大（中大国际轻纺城）
- **地位**：华南最大面辅料市场，服务珠三角服装产业带。
- **优势品类**：针织面料（T恤/卫衣布）、牛仔、雪纺、蕾丝花边、辅料配件一站式。
- **特点**：快时尚反应极快，十三行/沙河服装市场联动，当日剪版次日到货；辅料配套（拉链/纽扣/织带）最齐全。

### 苏州盛泽（东方丝绸市场）
- **地位**：丝绸与化纤梭织面料重镇，背靠盛泽/吴江织造集群。
- **优势品类**：仿真丝、涤塔夫、春亚纺、尼丝纺等里料/防绒布；梭织坯布价格风向标。
- **特点**：以坯布和半制品为主，适合对接织造厂一手货源。

### 其他专业市场
- **佛山张槎**：针织面料集群（大圆机密度全国最高）。
- **石狮/晋江**：运动休闲面料、功能性面料。
- **东莞虎门**：服装面辅料配套市场。

## 二、现货 vs 订单（订货）

| 维度 | 现货（stock） | 订单（make-to-order） |
|:---|:---|:---|
| 起订量 | 一条布（约 100-150m）起 | 染色 300-500kg/色，印花另加版费 |
| 交期 | 即取或 1-3 天 | 15-30 天 |
| 单价 | 高 10-30% | 低 |
| 颜色 | 固定色卡 | 可按潘通号定制 |
| 风险 | 断货不补、缸差明显 | 大货与确认样差异风险 |
| 适用 | 打样、小单、快反补单 | 大货、品牌订单 |

## 三、找布与采购实操

1. **剪样对色**：先剪 A4 样（sample cutting）回公司比对，市场灯光与 D65 灯箱下颜色可能不同。
2. **问清成分与规格**：档口口头报的克重/成分要实测复核（GSM 仪、燃烧法初判纤维）。
3. **要布版卡（hanger/sample card）**：注明档口号、货号、克重、幅宽、单价，便于翻单追溯。
4. **确认现货存量**：翻单前电话确认库存，热销布种可能一周断货。
5. **验布再付款**：现货提货当场验布（抽 10% 验外观/幅宽/克重），拉走后发现疵点难退换。
6. **档口 vs 厂家**：档口多为经销商，量大可让档口引荐背后厂家直接合作，省中间差价。

## 四、质量控制红线

- **缸差（lot shade variation）**：不同缸次色差常见，同一订单务必同一缸号。
- **短码（short length）**：市场布短码率 2-5% 是潜规则，开单写明足码验收。
- **二手布/库存布**：低价布注意存放年限与强力衰减。
- **检测**：现货布无检测报告，出口订单需自行送检（成分/色牢度/甲醛）。

## 五、线上渠道补充

- **1688/搜布/百布/链尚网**：先线上比价找供应商，再线下验样；搜布类 App 拍照找布（图像识别匹配档口——粗筛可用精判靠人）。
- **微信找布群**：发布找布信息（带样衣/图片/规格），市场中介免费找版，成交抽佣。
- **档口直播**：柯桥档口直播卖料常态化（远程看布+寄样）。
- 线上仅为线索来源，**成交前必须实物验样**。

## 六、档口关系经营

- **固定档口池**：针织/梭织/功能料各 1-2 家常合作档口——熟客有新品优先通知+赊账额度；
- **市场情报**：档口是活数据库（哪个料走得好=一手动销情报）——关系处好信息免费；
- **市场迁移跟踪**：中大旧改向清远/佛山疏解——档口搬迁关系不断链（联系方式+新址建档）；
- **快反打法**：首单现货测款→爆单锁定档口库存+同步订货补量（"现货+订货"双轨——见 `suppliers/production-capacity-scheduling.md`）。
