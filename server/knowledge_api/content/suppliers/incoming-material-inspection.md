# 面辅料入库检验 SOP（Incoming Material Inspection SOP）

入库检验（IQC, Incoming Quality Control）是质量第一道关：**面料问题在裁剪前发现 = 损失面料钱；成衣后才发现 = 损失整件+交期+客诉**。

## 一、检验流程总览

```
到货 → 核对（PO/送货单/标签）→ 抽样 → 检验（数量+外观+规格+性能）
→ 判定（合格入库/让步接收/退货）→ 记录 → 反馈供应商
```

## 二、面料检验（最重的入库检验）

### 数量检验
- **码长抽验**：验布机复码（抽 10-20%）——短码是面料采购高频争议（约定码长公差 ±0.5-1%）；
- **重量**：针织布按重计价——抽验克重换算总量。

### 外观检验（验布机）
- **四分制**（见 `fabric/fabric-inspection-4point.md`）：验布机全检或抽检（10% 起步，问题批全检）；
- **幅宽**：有效幅宽测量（可裁幅宽——含针孔边需扣除）；
- **色差**：匹间色差（缸差）——边中色差、头尾色差验布灯下目测+灰卡；
- **疵点密度**：超标准 → 退货或扣款。

### 规格检验
| 项目 | 方法 |
|:---|:---|
| 克重 | 圆盘取样器+克重仪（每缸抽 3 点） |
| 成分 | 送检（每新供应商首批必检） |
| 密度/纱支 | 密度镜/纱支对照 |
| 幅宽 | 有效幅宽（≥ 合同值） |

### 性能检验（按需）
- 缩水率（剪样水洗实测——决定纸样加放）；
- 色牢度（干/湿摩擦现场快测）；
- 功能性（防水/抗 UV 送第三方）。

### 预缩与松布
- **松布（relaxing）**：针织布/弹力布入库后松布 24h（释放卷装张力——裁前必做，否则裁片回缩尺寸偏小）。

## 三、辅料检验

| 辅料 | 检验要点 |
|:---|:---|
| 拉链 | 型号/长度/色号（对确认样）、拉合顺畅、齿合牢固（抽 5-10% 试拉） |
| 纽扣 | 尺寸/颜色/牢固（四眼扣缝线拉力）、扣眼配套 |
| 织带/橡筋 | 宽度/克重/弹性回复 |
| 商标/洗标 | 内容核对（文字错误是低级高发事故——逐字核对） |
| 衬布 | 型号/幅宽/胶点（压烫测试） |
| 缝纫线 | 色号/强力/规格（402/403） |
| 包装材料 | 胶袋厚度/警告语、纸箱克重/尺寸 |

## 四、判定与处置

| 判定 | 条件 | 处置 |
|:---|:---|:---|
| 合格 | 全项达标 | 入库（按缸号/批次分区存放——FIFO 见 `fabric/fabric-inventory-stock-strategy.md`） |
| 让步接收 | 轻微偏差可生产消化（如轻微缸差分色用） | 记录+扣款+供应商签认 |
| 挑选使用 | 疵点率超但可选片用 | 全检挑选+工时成本转嫁供应商 |
| 退货 | 严重不合格 | 退换货+索赔+供应商绩效记录 |

## 五、记录与追溯

- **检验报告**：每批 IQC 报告（供应商/批号/数量/结果/判定/检验员）——质量追溯起点；
- **样品留存**：每批留样（A4 大小面料样+辅料样）——大货争议的比对基准；
- **缸号管理**：面料入库按缸号分区（裁剪按缸配套——防缸差混用）；
- **供应商记分**：IQC 结果计入供应商评分卡（见 `suppliers/supplier-quality-management.md`）。

## 六、常见入库事故

| 事故 | 预防 |
|:---|:---|
| 短码 | 验布机复码抽检+合同短码赔偿条款 |
| 缸差超标 | 验布灯比对+分缸存放 |
| 辅料色号错 | 对确认样（双签样制度） |
| 洗标文字错 | 逐字核对（版本管理） |
| 克重虚标 | 克重仪每缸抽测 |
