# 服装厂安全与消防管理（Factory Safety & Fire Management）

服装厂是"**人员密集 + 可燃物密集**"双重高危场景：面料粉尘、纸箱堆垛、几百人同时作业——消防是验厂红线，更是生命底线。

## 一、火灾风险源

| 风险源 | 场景 |
|:---|:---|
| 电气线路 | 私拉乱接/电箱堆物/老化线路（制衣厂火灾第一元凶） |
| 可燃物堆垛 | 面料/纸箱/成品仓库（燃烧速度快——堆距/灯距不合规） |
| 熨烫设备 | 蒸汽发生器/电熨斗高温（下班后未断电） |
| 粉尘 | 起绒/磨毛车间布尘（高浓度粉尘爆燃风险） |
| 违章动火 | 机修电焊（无动火审批+无看护） |

## 二、消防设施配置（合规清单）

- **灭火器**：每 75-100㎡ 一组（ABC 干粉——月检卡）;
- **消火栓**：不被遮挡（前面堆货是验厂最常见不符合项）;
- **应急灯/疏散指示**：断电可用（月度测试）;
- **烟感/喷淋**：按建筑消防验收配置（丙类厂房标准）;
- **疏散通道**：宽度≥1.4 米+双向出口（**安全出口上锁=验厂致命项+违法**——逃生门锁必须外开无障碍）;
- **警铃**：全厂可闻（分区测试）。

## 三、消防管理动作

- **疏散演练**：半年一次（记录+照片——验厂必查：访谈员工"上次演练什么时候"）;
- **义务消防队**：每班次有受训人员（灭火器实操）;
- **用电管理**：下班总闸断电（设备点检表——谁最后走谁签字）;
- **动火审批**：电焊/切割审批单+灭火看护+30 分钟留守;
- **仓库管理**：堆垛距灯 0.5 米/距墙 0.3 米（灯距不符烤燃纸箱是真实火灾案例）;
- **宿舍联动**：三合一场所（生产+仓储+住宿同楼）是**绝对红线**（消防法明令禁止——发现即整改）。

## 四、生产安全（工伤防控）

- **缝纫机针**：断针防护（护针器——手指伤残高发工序，见 `suppliers/sewing-thread-needles.md`）;
- **裁床/电剪**：钢丝手套（裁床工必配——电剪割伤是重伤高发）;
- **整烫**：蒸汽烫伤防护（防烫手套/排气）;
- **特种设备**：锅炉/蒸汽发生器年检（操作证）;
- **化学品**：去渍枪药水/胶水（MSDS+通风+劳保——见 `trade-compliance/chemical-environmental-compliance.md` 工厂端）;
- **工伤处理**：工伤认定+保险（社保/雇主责任险——见 `suppliers/garment-factory-setup.md`）。

## 五、验厂安全模块

- **BSCI/SEDEX 安全权重**：消防通道/出口/演练记录是 Major 不符合项（见 `suppliers/factory-audit-guide.md`）;
- **WRAP/品牌验厂**：灭火器检查卡/疏散图/应急灯测试记录（记录缺失=现场再好也扣分）;
- **访谈应对**：员工必知（逃生路线/集合点/报警方式——培训记录+抽查回答一致）。

## 六、管理制度框架

- **责任制**：厂长第一责任人（安全生产法——签字背书）;
- **日巡检**：安全员每日巡查表（通道/电箱/堆垛——照片打卡）;
- **月排查**：综合安全检查（隐患整改闭环：发现→整改→复查）;
- **培训**：入职三级安全教育（厂/车间/班组——记录存档）;
- **保险**：财产险+雇主责任险（火灾+工伤双覆盖）。

## 七、事故教训（行业案例类型）

- **疏散通道锁闭**：火灾伤亡扩大主因（孟加拉/巴基斯坦服装厂大火教训——欧美品牌因此强化验厂）;
- **阁楼违规住人**：三合一火灾;
- **纸箱仓库自燃**：南方梅雨季受潮发酵（堆垛通风+先进先出）;
- **电熨斗下班未关**：夜间阴燃（断电制度）。
