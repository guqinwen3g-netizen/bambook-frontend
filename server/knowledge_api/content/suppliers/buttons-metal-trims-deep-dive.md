# 纽扣与金属辅料深度（Buttons & Metal Trims: 四合扣/工字扣/气眼/拉力与化学测试）

小辅料大风险：四合扣脱落=童装窒息风险召回、镍超标=欧盟通报、气眼锈斑=整批退货。辅料总览见 `suppliers/garment-accessories-trims.md`、拉链专篇见 `suppliers/zipper-fasteners-deep-dive.md`，本文件覆盖纽扣与金属小件的选型、测试与采购。

## 一、品类与结构

| 品类 | 结构 | 应用 |
|:---|:---|:---|
| 树脂扣（尿素/密胺/聚酯） | 四眼/两眼/暗扣 | 衬衫/童装主流（激光 logo 定制） |
| 天然扣 | 贝壳（塔螺/马蹄螺）、牛角、果实（象牙果）、木 | 高端衬衫/西装（每粒纹理唯一——瑕疵率管理） |
| 金属四合扣（snap） | 面扣+母扣+公扣+底扣四件 | 夹克/牛仔/箱包——按 405/486/655 等型号区分规格 |
| 工字扣（jeans button） | 面扣+工字钉（敲击固定） | 牛仔裤门襟（17mm/20mm 常规） |
| 撞钉（rivet） | 面钉+底钉 | 牛仔袋口加固（见 `garments/denim-jeans-production.md`） |
| 气眼（eyelet/grommet） | 两件冲压 | 帽檐透气孔/卫衣帽绳/窗帘（见 `garments/curtains-window-treatments.md`） |
| 五爪扣（prong snap） | 爪面+底件 | 婴儿爬服（薄料不撕裂） |
| 调节扣/插扣 | POM 塑料 | 背包/帽类（见 `garments/bags-luggage-production.md`） |

## 二、测试体系（安全与耐久）

- **拉力测试（童装生死线）**：纽扣/四合扣抗拉——美国 16 CFR 1500 小部件+ASTM F963 逻辑，行业标准 **15-17 磅（67-75N）保持 10 秒不脱落**；婴童装建议 90N+；**每批大货抽测**（拉力计——工厂 QC 标配设备），见 `trade-compliance/cpsc-children-safety.md`；
- **镍释放**：金属件皮肤接触——欧盟 REACH 附录 17（≤0.5μg/cm²/week 长期接触/0.2μg 穿刺饰品）——电镀工艺（无镍电镀/封孔处理）解决；
- **盐雾测试**：金属件防锈——中性盐雾 24-48h 无锈斑（海运高湿+汗液场景）；铜件钝化/电镀层厚度管理；
- **耐洗/耐干洗**：树脂扣耐四氯乙烯（干洗溶剂——劣质扣溶解碎裂）、贝壳扣耐冲击（干洗店滚筒事故——高端衬衫附备用扣是行业惯例）；
- **咬力（童装附加）**：婴儿啃咬模拟——扣面碎裂测试；
- **锐边锐点**：冲压毛刺（8 岁以下服装管控）。

## 三、采购与生产配合

- **打钉设备匹配**：四合扣/工字扣/气眼需专用模具打钉机——**采购时按扣型配模具**（供应商提供或自备）；手工钉（脚踩机）vs 气动/伺服打钉机（大货效率+压力一致性——压力不足脱落/过大开裂）；
- **面料适配**：薄料用细齿五爪（防撕裂）；厚料（牛仔/帆布）用长脚钉；弹力面料加垫片（防拉脱）；
- **色差与配套**：树脂扣配色（潘通色号对色——与面料同缸概念）；金属件电镀色（青古铜/枪色/珍珠镍）批次色差管理；
- **起订量与定制**：激光 logo 树脂扣 1000 粒起；开模金属扣（品牌 logo 立体扣）3000-10000 粒+模具费；交期 10-20 天（定制色 30 天）；
- **品牌风险**：扣面 logo 按品牌授权书生产（同拉链 YKK 纪律，见 `trade-compliance/ip-brand-authorization.md`）；**备用扣包**（衬衫 2 粒/西装 1 大 1 小）计入物料清单。

## 四、失效案例库（客诉归因）

| 失效 | 根因 | 预防 |
|:---|:---|:---|
| 四合扣脱落 | 打钉压力不足/面料太薄无垫片 | 首件拉力测试+垫片 |
| 工字扣转动 | 钉脚太短/面料厚度过界 | 按面料厚度选钉脚长度 |
| 气眼锈斑 | 铁质气眼+电镀薄 | 铜/不锈钢气眼+盐雾测试 |
| 树脂扣洗后开裂 | 尿素扣耐温不足（烘干高温） | 密胺/聚酯扣替代 |
| 贝壳扣碎裂 | 干洗冲击/扣厚不均 | 出厂检验扣厚+备用扣 |
| 金属扣皮肤过敏 | 镍释放超标 | 无镍电镀+检测报告 |
