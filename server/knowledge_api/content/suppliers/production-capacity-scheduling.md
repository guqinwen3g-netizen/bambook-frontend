# 产能管理与排产协同（Capacity Planning & Production Scheduling）

交期延误是外贸订单第二大客诉（仅次于质量）。贸易公司的排产管理不是替工厂排产，而是**掌握供应商产能水位、锁定产线档期、预警瓶颈**。

## 一、供应商产能档案

### 核心数据（每家合作工厂须建档）
| 数据 | 说明 |
|:---|:---|
| 产线数/人数 | 缝制产线条数 × 单线人数 |
| 标准日产能 | 按品类：T 恤/衬衫/牛仔裤分别人天产能（SMV 法换算） |
| 瓶颈工序 | 印花/洗水/套口等外发或专用设备环节 |
| 当前负荷 | 在手订单排产水位（%） |
| 旺季窗口 | 该厂主要客户的集中下单期 |

- **SMV 产能换算**：日产能(件) = 工人数 × 日工时 × 60 ÷ SMV × 效率(60-75%)。例：30 人线 × 8h × 60 ÷ 10 分钟 SMV × 65% ≈ 936 件/天。

## 二、排产协同流程

### 1. 接单前产能确认
- 询盘阶段即向工厂核**产线档期**（非只问价格）："X 月 X 日前需要 5000 件 T 恤，你的产线排得进吗？"
- 旺季（4-6 月秋单、9-11 月春单/年货）产能锁定要付**档期定金**或框架协议。

### 2. 订单排产表（Master Schedule）
```
订单号 | 款号 | 数量 | 面料到厂日 | 裁剪日 | 上线日 | 下线日 | 验货日 | 出货日
```
- 每个节点设**预警提前量**：面料到厂晚 3 天 → 立即评估是否压缩后道或分批。

### 3. 周度跟进机制
- 每周与工厂更新排产表（周一 production meeting）；
- 关键订单（大客户/短交期）驻厂跟单；
- 延误预警升级：预警（晚 3 天）→ 警报（晚 7 天，启动补救方案）→ 红色（晚 14 天，分批空运/转厂评估）。

## 三、瓶颈工序管理

| 瓶颈 | 对策 |
|:---|:---|
| 印花/绣花外发 | 提前锁外发厂档期；产前样阶段即测试外发厂产能 |
| 洗水（牛仔） | 洗水厂排单独立于成衣厂确认 |
| 套口（毛衫） | 熟练套口工是稀缺资源——旺季提前 60 天锁定 |
| 检针/检品 | 日本单全检产能单独核算 |
| 面辅料到位 | 拉链/织唛定制周期 15-25 天，是隐形瓶颈——下单首日采购 |

## 四、多厂协同与转厂预案

- **同款分厂**：大单拆分 2-3 厂并行（统一封样与工艺单），交期风险对冲。
- **转厂预案**：主力厂红色预警时，备选厂 7 天内能切换（纸样/工艺单/封样资料随时可移交状态）。
- **外发管理**：外发工序纳入合同（质量责任不因外发转移），外发厂同样需验厂（见 `suppliers/supplier-contract-risk.md` 禁止转包条款）。

## 五、产能与报价的联动

- **填谷订单**：工厂淡季（1-3 月）接单可获 5-10% 工费折让——向客户争取淡季交期订单。
- **加急溢价**：插单加急费 10-15% 是合理成本，向客户 transparent 传导（加急费买确定性）。
- **产能共享信息**：与战略工厂共享**滚动 3 个月订单预测（forecast）**，换取产能优先权。

## 六、数字化工具

- 简单可行：共享排产看板（在线表格按订单行更新，工厂每日填报进度%）。
- 进阶：MES/ERP 对接工厂报工数据；按工序节点扫码报工。
- 关键不是工具而是**更新纪律**——排产表不更新等于没有。
