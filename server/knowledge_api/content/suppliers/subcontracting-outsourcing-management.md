# 外发与分包管理（Subcontracting & Outsourcing Management）

印花、绣花、洗水、特殊工艺普遍外发（outsourcing）。外发失控是品质事故与审厂违规的双重高发区——**外发不是责任的转移，而是责任的延伸**。

## 一、常见外发场景

| 工序 | 外发原因 | 风险点 |
|:---|:---|:---|
| 印花 | 专业设备（圆网/数码机） | 色差、对花、牢度 |
| 绣花 | 绣花机投资大 | 断线、针迹密度、对位 |
| 洗水（牛仔） | 洗水厂环保资质 | 手感偏差、磨破、色落 |
| 特种工艺 | 压胶/复合/涂层设备 | 剥离强度 |
| 缝制（外发厂） | 旺季产能不足 | 品质体系不一致 |
| 检品/检针 | 日本单全检 | 漏检 |

## 二、外发厂准入

- **与主厂同等审核**：外发厂纳入验厂范围（客户审厂时通常要求申报外发厂）——**未申报外发 = 审厂重大不符项**（BSCI/Sedex 明令禁止未经授权分包）；
- 环保资质：洗水厂排污许可证（红线）；印花厂环评；
- 设备能力核实：绣花机头数/印花线产能与订单匹配。

## 三、外发合同要点

1. **技术标准**：工艺参数书面化（印花：潘通号+对色灯箱标准；绣花：针迹密度+线色 DMC/ Madeira 色号）；
2. **产前确认样**：外发工序必须做**产前样封样**（PP sample）——大货以此为准；
3. **损耗责任**：外发加工损耗率上限（如裁片印花损耗 ≤3%），超耗赔偿；
4. **交期联动**：外发厂交期与主厂排产表联动（外发是排产瓶颈高发点——见 `suppliers/production-capacity-scheduling.md`）；
5. **质量责任穿透**：外发品质问题导致成衣索赔的，外发厂承担（质量协议条款，见 `fabric/fabric-procurement-quality-agreement.md` 逻辑）。

## 四、过程管控

### 流转管理
```
主厂裁片 → 外发厂（点数签收）→ 加工 → 回厂（点数+质检）→ 主厂缝制
```
- **数量闭环**：发出数 = 收回合格数 + 损耗数 + 退回数——每批对账（裁片丢失是外发纠纷高发）；
- **首件确认**：外发大货开机先做首件送主厂确认（避免整批错误）；
- **驻厂巡检**：大额外发订单派员驻外发厂巡检。

### 验收标准
- 印花：对色（D65 灯箱）、对花（对位公差）、牢度抽检（摩擦/水洗）；
- 绣花：针迹密度抽检、断线率、绣面平整度；
- 洗水：手感对确认样、尺寸变化、磨白效果一致性。

## 五、客户合规要求

- **品牌申报义务**：多数品牌要求订单合同列出所有外发厂清单（含地址）——擅自增加外发厂 = 违约；
- **社会责任穿透**：品牌审核延伸至外发厂（工时/工资/消防）——外发厂劳工问题品牌会追责主单供应商；
- **UFLPA 穿透**：外发环节同样需纳入溯源链（见 `trade-compliance/uflpa-forced-labor.md`）。

## 六、成本管理

- 外发加工费询价 3 家比价（印花按色/按面积、绣花按针数计价——核价公式透明化）；
- 绣花计价：针数 × 单价/千针（核实针数——版带针数报告）；
- 旺季外发涨价（绣花/洗水旺季 +20-30%）——成本预算留弹性。

## 七、风险场景与对策

| 场景 | 对策 |
|:---|:---|
| 外发厂品质批量事故 | 首件确认 + 分批外发（不一次全发） |
| 外发厂扣留裁片（纠纷时） | 裁片所有权条款 + 分批流转控制敞口 |
| 客户发现未申报外发 | 事前书面申报获批；审厂资料一致 |
| 外发厂转包再外发 | 合同禁止二次转包 + 不定期现场核查 |
