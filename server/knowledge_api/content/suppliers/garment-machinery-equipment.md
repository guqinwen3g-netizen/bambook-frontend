# 服装设备与机台配置（Garment Machinery & Equipment）

设备是**工艺能力的物理边界**：什么设备决定能做什么工艺。验厂看设备=看工艺天花板。

## 一、缝制主机

| 机型 | 功能 | 应用 |
|:---|:---|:---|
| 平缝机（single needle lockstitch） | 基础缝合 | 万能主力（占 60-70%） |
| 包缝机（overlock/拷边） | 缝份包边 | 常规（3/4/5 线） |
| 绷缝机（coverstitch） | 针织下摆/袖口 | 针织必备（T 恤/卫衣） |
| 双针机 | 双明线 | 衬衫/牛仔 |
| 链式机 | 链式线迹 | 牛仔/厚料 |

### 品牌梯队
- **进口**：重机（JUKI）/兄弟（Brother）/飞马（Pegasus——包缝绷缝标杆）——精度/耐用/速度；
- **国产**：杰克（Jack）/标准/中捷——性价比（近年品质大幅提升）；
- **电脑车**：自动剪线/自动抬压脚（效率+品质一致——现代厂标配）。

## 二、特种机（工艺分水岭）

| 特种机 | 工艺 | 品类 |
|:---|:---|:---|
| 锁眼机 | 扣眼 | 衬衫/西装 |
| 钉扣机 | 钉扣 | 通用 |
| 套结机 | 加固套结 | 袋口/裤袢 |
| 撬边机（暗缝） | 裤脚暗缝 | 西裤 |
| 四针六线（flatlock） | 无骨拼接 | 运动/内衣（见 `garments/activewear-production.md`） |
| 冚车（coverlock） | 针织绷缝 | 针织 |
| 模板机 | 自动模板缝纫 | 口袋/绗线（去技术化） |
| 花样机 | 电脑花样 | 装饰线迹 |

- **特种机=品类门槛**：做西装要撬边机/做运动要四针六线——没设备接不了对应品类。

## 三、裁剪设备

- **裁刀**：直刀/圆刀（手工裁剪——见 `suppliers/cutting-room-management.md`）；
- **自动裁床**：Gerber/Lectra/力克——精度±1mm（高端厂标志）；
- **拉布机**：自动拉布（针织松式拉布）；
- **验布机**：见 `suppliers/incoming-material-inspection.md`。

## 四、后道设备

- **烫台**：蒸汽烫台（见 `suppliers/finishing-ironing-packing-room.md`）；
- **验针机**：见 `garments/childrenswear-production.md`；
- **包装设备**：封箱/打包。

## 五、自动化与智能化趋势

| 技术 | 现状 |
|:---|:---|
| 模板机 | 普及（去技术化——新工做技术活） |
| 自动裁床 | 中高端厂标配 |
| 吊挂系统 | 精益单件流（见 `suppliers/garment-factory-lean-production.md`） |
| 缝纫机器人 | 试点（软性面料缝纫自动化仍是行业难题—— Sewbo 等方案未大规模商用） |
| AGV 物流 | 裁片/成品自动搬运（大厂） |

- **现实**：服装自动化程度仍低于其他制造（面料软性=自动化难——人工密集在可预见期仍是主流）。
