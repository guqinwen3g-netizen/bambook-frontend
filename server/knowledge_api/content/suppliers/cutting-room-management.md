# 裁剪车间管理（Cutting Room Management）

裁剪是**成衣质量的第一关**：裁错了后面全错（裁剪不可逆——裁片废=面料废）。裁剪车间的管理水平直接决定面料利用率与成衣品质。

## 一、裁剪流程

```
验布 → 松布（24h）→ 排料（marking）→ 拉布（spreading）→ 裁剪（cutting）→ 验片 → 编号 → 扎包
```

## 二、关键环节控制

### 1. 验布（入裁剪前）
- 见 `suppliers/incoming-material-inspection.md`——四分制验布（面料问题在裁剪前发现=止损最早时点）。

### 2. 松布（relaxing）
- **针织面料松布 24 小时**（卷装张力释放——否则裁片回缩尺寸不准）；
- 松布区（面料静置——温湿度稳定）。

### 3. 排料（marking）
- **排料图（marker）**：CAD 排料（利用率最大化——排料师经验=面料成本）；
- **利用率**：85-95%（排版水平直接省料/废料）；
- **对条对格**：格条面料排料预留对位（见 `fabric/yarn-dyed-fabrics.md`）；
- **倒顺毛**：绒类/有方向面料单向排版（见 `fabric/velvet-faux-fur-fabrics.md`）。

### 4. 拉布（spreading）
- **层数**：梭织 50-150 层/针织 30-80 层（厚度与裁刀能力）；
- **张力**：拉布张力均匀（针织松式拉布机——张力导致裁片变形）；
- **对齐**：布边对齐（边不齐=裁片大小边）。

### 5. 裁剪
- **设备**：直刀/圆刀/带刀/自动裁床（Gerber/Lectra——自动裁床精度±1mm）；
- **精度**：裁片与样板误差 ±2mm（自动裁床 vs 手工裁剪差距）；
- **刀口**：裁刀锋利（钝刀裁片边缘毛糙/粘连）。

### 6. 验片与编号
- **验片**：裁片抽检（尺寸/疵点——面料疵点在裁剪后仍可挑片）；
- **编号**：裁片编号（缸号+床次+层数——**色差追溯**：同一件衣服用同层裁片，防"一件衣服两个色"）。

## 三、裁剪质量事故

| 事故 | 原因 | 后果 |
|:---|:---|:---|
| 裁片尺寸偏差 | 样板错/拉布张力/裁刀走位 | 成衣尺寸不准 |
| 同件色差 | 不同缸/不同层裁片混用 | 衣服前片后片两个色（致命） |
| 对格错位 | 排料/拉布对位失败 | 格条不对（明显疵点） |
| 倒顺毛错 | 排版方向错 | 绒面倒绒色差 |
| 裁片漏裁/多裁 | 排料图错/计数错 | 配套不齐 |

## 四、面料利用率（成本核心）

- **利用率 = 排料水平**：85% vs 95% = 10% 面料成本差（大订单=巨额）；
- **省料方法**：CAD 优化排料 / 大小码混排 / 合理定宽幅宽；
- **裁损率**：正常 2-3%（见 `fabric/fabric-inventory-stock-strategy.md` 补料公式）；
- **碎布利用**：裁剩余料（小裁片——口袋/童装/拼布——或碎布出售）。

## 五、裁剪车间管理要点

| 项目 | 说明 |
|:---|:---|
| 样板管理 | 样板（pattern）版本控制（改版样板标记——旧版作废） |
| 裁床单 | 裁剪通知单（款号/尺码配比/层数/面料缸号——作业指令） |
| 缸号管理 | 同缸裁剪（不同缸分开——色差隔离） |
| 首件裁片 | 首批裁片核对样板（产前验证） |
| 裁片存储 | 裁片扎包防护（防潮防污——裁片是半成品资产） |

## 六、验厂视角

- **松布区**有无（针织厂松布 24h 是品质意识）；
- **CAD/自动裁床**（硬件水平——但手工裁剪管理好的厂也可靠）;
- **裁片编号系统**（色差追溯能力）；
- **样板房管理**（版型知识产权+版本控制）。
