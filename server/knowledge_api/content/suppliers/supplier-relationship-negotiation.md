# 供应商商务谈判与关系管理（Supplier Negotiation & Relationship）

与供应商的关系不是零和博弈——**压价到供应商无利可图，最终会用品質和交期偿还**。目标是"总成本最优 + 风险共担 + 长期绑定"。

## 一、议价策略

### 询价结构设计
- **3 家比价**为基线（避免单一报价的信息劣势）；
- **分解报价**：要求供应商报"材料 + 加工 + 利润"结构（懂成本结构才能谈到点上）；
- **量价阶梯**：500/1000/5000 件阶梯报价——明确量大从优的兑现路径。

### 谈判筹码排序
| 筹码 | 说明 |
|:---|:---|
| 订单份额 | "给你 60% 份额"比"降价 5%"更有吸引力 |
| 账期 | 月结 30 天换 2-3% 价格优惠（供应商现金流价值） |
| 长期协议 | 年度框架协议锁价（供应商换取排产确定性） |
| 联合开发 | 共同开发新品类（绑定技术壁垒） |
| 预付款 | 行情波动期预付锁价（双方风险对冲） |

### 谈判禁区
- **不压到成本线以下**：供应商亏损接单→偷工减料（克重缩水/偷换原料）；
- **不只用价格谈判**：交期/起订量/质量条款都是谈判变量；
- **不留模糊**：口头承诺进不了合同等于零（见 `suppliers/supplier-contract-risk.md`）。

## 二、账期与资金流管理

- **账期阶梯**：新供应商款到发货 → 3 单后月结 30 天 → 战略供应商月结 60 天（用信用换价格）；
- **按时付款是信誉资产**：付款信誉好的采购方在旺季获得优先排产权——**拖款省的资金成本，旺季加倍还**；
- **对账机制**：每月对账日固化（单据齐全 5 个工作日内付款）。

## 三、供应商分级与份额管理

| 等级 | 份额 | 关系策略 |
|:---|:---|:---|
| 战略（A） | 40-50% | 年度协议+联合开发+高层互访+VMI 寄售 |
| 主力（B） | 30-40% | 常规订单+季度复盘 |
| 备份（C） | 10-20% | 保持活跃的"鲶鱼"——防止 A/B 懈怠 |

- **双供应商纪律**：关键面辅料永远保持 2 家以上合格供应商（环保关停/质量事故的对冲——见 `suppliers/fabric-accessories-supplier-management.md`）。

## 四、联合降本（可持续的降本方式）

1. **VA/VE（价值工程）**：与供应商一起分析"这个工艺能不能简化"（如合并工序/优化排料）——降本不降质；
2. **集中下单**：多客户订单拼单采购（达到供应商的经济批量）；
3. **淡季锁产**：淡季下单锁定低价产能（供应商填产线，你得折扣）；
4. **规格标准化**：减少面料规格数（SKU 收敛）换取单规格量增。

## 五、冲突与危机处理

- **质量事故**：先止损（隔离库存）再定责（第三方检测）后谈赔（按质量协议）——**先解决问题再分钱**；
- **交期延误**：预警机制（晚 3 天黄灯/7 天红灯）+ 补救优先（空运分担谈判）；
- **供应商倒闭风险**：关注信号（拖欠工资/设备查封/负责人失联）——预付敞口控制 + 模具/原料资产隔离；
- **关系修复**：重大冲突后高层互访重启——供应商关系是资产，不轻易清零。

## 六、供应商大会与生态

- 年度供应商大会：发布年度采购计划/质量白皮书/优秀供应商颁奖——**被认可感是免费的绑定剂**；
- 信息共享：行情/趋势信息共享给战略供应商（帮其规划产能）；
- 早期介入（ESI）：新品开发期邀请供应商参与（源头可制造性设计）。
