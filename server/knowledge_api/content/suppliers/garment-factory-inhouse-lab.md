# 服装厂自建检测实验室（In-house Lab: 设备配置/校准/客户认可）

自建实验室是服装厂从"加工车间"升级为"**品质供应商**"的分水岭：品牌验厂（技术审核）把实验室配置作为硬性评分项；出货自检能力=减少第三方送检成本+缩短交期。但不是买设备就行——**校准体系+检测记录+人员资质**才是客户认可的核心（买了不用的蒙尘实验室是验厂扣分项，见 `trade-process/customer-visit-factory-tour.md`）。

## 一、设备配置分级

| 级别 | 设备 | 投资 | 覆盖场景 |
|:---|:---|:---|:---|
| 基础级 | D65 灯箱+电子天平+钢尺+缩水率洗涤机+摩擦色牢度仪 | ¥5-10 万 | 尺寸/克重/对色/缩水/摩擦 |
| 标准级 | +起球仪（马丁代尔）+撕破/拉力机+耐洗色牢度机+pH 计+汗渍架 | ¥20-40 万 | 常规物理测试全覆盖 |
| 进阶级 | +静水压仪+透湿仪+喷淋仪+紫外老化箱+甲醛速测 | ¥60 万+ | 功能面料自测 |

- **优先项**：**对色灯箱（D65/TL84/UV 三光源）+缩水率测试+摩擦色牢度**——覆盖 80% 日常客诉项（见 `fabric/color-management-pantone-measurement.md` 的对色流程）；
- **功能服工厂**：静水压+透湿仪是接单户外/滑雪单的验厂门槛（见 `garments/ski-wear-production.md`）。

## 二、管理体系（比设备更重要）

- **校准**：计量器具年度校准（第三方计量所——拉力机/天平/温度计必须校准证书在期）；**验厂必查校准标签与证书对应**；
- **标准作业**：每项检测 SOP（取样位置/测试条件/判定基准——照抄 AATCC/ISO 方法原文，见 `trade-compliance/testing-standards.md`）；
- **记录**：检测原始记录（批次/日期/操作人/结果——保存 3 年+，与出货批次追溯对应）；
- **人员**：检测员培训记录（内部培训+外部机构培训证书——SGS/ITS 有实验室人员培训课程）；
- **环境**：恒温恒湿间（21°C/65%RH——物理测试标准要求环境，无环境控制的拉力/起球数据无效）。

## 三、客户认可与外部联动

- **品牌实验室认可（lab accreditation）**：部分品牌（M&S/迪卡侬模式）对供应商实验室做**认可审核**——通过后自测报告直接采信（免第三方送检——每款省 ¥2000-5000+5-7 天）；
- **比对测试**：定期与第三方实验室（SGS/ITS/TÜV——选择见 `trade-compliance/testing-lab-selection.md`）做**同一样品比对**——数据偏差在允差内是认可依据；
- **CNAS/ISO 17025**：实验室国家认可（自愿——进阶级：出口企业做 CNAS 背书报告公信力，周期 12-18 个月）；
- **红线项目不外化**：偶氮/重金属/邻苯等化学项目**必须第三方**（自建化学实验室投入与风险不匹配——化学送检，物理自测是合理分工）。

## 四、成本与接单联动

- **标准级回报**：第三方送检费 ¥300-800/项——月均 50 款测试需求时，自测 1-2 年回本；加急件响应（当天出数）是抢单优势；
- **验厂评分**：技术审核实验室项通常占 10-15 分——**无实验室直接失去高分档**（见 `suppliers/factory-on-site-audit-sop.md`）；
- **报价支撑**：测试数据随报价单（功能面料静水压/透湿实测）——专业度差异化；
- **常见失败**：设备买了没人会用（招聘兼职能手）/无校准（数据无效力）/无记录（审核拿不出证据）——**先定制度再买设备**。
