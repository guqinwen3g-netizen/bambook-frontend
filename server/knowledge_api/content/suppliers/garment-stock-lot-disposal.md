# 成衣尾货与库存处理（Garment Stock Lot Disposal & Liquidation）

成衣库存来源三类：**客户取消单/拒收货、溢短装余量、内销滞销**。处理原则 = **快速变现优先于高价变现**（库存贬值速度每月 5-10%），同时守住品牌保护与客户协议红线。

## 一、库存来源与定性

| 来源 | 特征 | 处置约束 |
|:---|:---|:---|
| 客户取消单 | 已投产/已完货（客人违约） | **合同条款优先**（品牌保护/区域限制——见 `trade-process/trade-contract-terms.md`） |
| 验货拒收 | 质量争议尾货 | 修復后转售/降级处理 |
| 溢短装余量 | 大货多裁（1-3%） | 正常商业库存（自有处置权） |
| 内销滞销 | 电商退货/过季 | 自主处理（见 `customers-market/domestic-ecommerce-livestream.md`） |

- **法律定性**：带客户商标的货=客户知识产权——**未经授权转售正品尾货属侵权**（哪怕客户违约在先，商标权仍受保护；合同应预先约定取消单处置权）。

## 二、处理渠道（按回收率排序）

| 渠道 | 回收率（对成本） | 说明 |
|:---|:---|:---|
| 客户协议转售（原客户同意） | 60-90% | 最优（off-price 渠道——见 `customers-market/us-offprice-discount-channel.md`） |
| 其他品牌客户/贴牌转售 | 40-70% | 换标/改款后卖（需原客户书面豁免） |
| 库存商打包（stock lot buyer） | 20-40% | 现金快（广州/义乌库存商；美国 overstock 进口商） |
| 内销特卖/直播清货 | 30-60% | 剪标后自销（见 `customers-market/domestic-ecommerce-livestream.md`） |
| 出口库存市场（非洲/中东） | 20-35% | 按公斤/按件打包（拉各斯/迪拜库存市场） |
| 捐赠/销毁 | 0 | 最后选项（税务处理+品牌保护） |

## 三、品牌保护操作

- **剪标/去标**：主唛/洗唛/吊牌三处全去（剪角不规范=品牌方追责+库存商压价）；
- **换标**：转售贴自有标/无标（注意**保留成分洗唛**——内销法定义务，见 `trade-compliance/textile-labeling-regulations.md`）；
- **区域隔离**：协议限定销售区域（欧洲尾货不得回流美国正价市场——库存商合同注明流向条款）；
- **时间隔离**：过季 2 季以上再放行（保护客户当季销售）。

## 四、定价与谈判

- **库存估值逻辑**：可售率（次品剔除）× 款式时效性 × 尺码完整度（断码折价 30-50%）；
- **谈判筹码**：多款打包（好款搭差款——库存商惯例）；现金一次性 > 分期；
- **快速决策**：库存持有成本（仓储+资金占用+贬值）月均 8-12%——**3 个月内必须出清决策**（捂货是亏损最大化路径）。

## 五、预防机制（治本）

1. **合同前置**：取消单赔偿条款（已投产成本+合理利润）+ 尾货处置权约定（见 `trade-process/trade-contract-terms.md`）；
2. **溢短装控制**：合同允许 shortfall 比例内少裁（多裁=自担库存）；
3. **取消单早识别**：客户经营异常信号（账期拖延/验货刁难升级——见 `trade-process/customer-credit-investigation.md`）；投产前定金到位是底线（见 `suppliers/order-review-acceptance.md`）；
4. **保险**：取消单属商业风险（信用保险部分覆盖——见 `trade-process/export-credit-insurance.md`）。

## 六、财务与税务

- **计提**：库存跌价准备（财务制度——库龄 6 个月+开始计提）；
- **处置收入**：正常开票纳税（无票低价处理=税务风险）；
- **核销**：销毁处置留存影像/清单（资产损失税前扣除证据链）。
