# 供应商成本分析与审计（Supplier Cost Analysis & Audit）

"应成本模型"（should-cost modeling）是采购从"讨价还价"升级为"成本对话"的核心工具：**知道一件 T 恤该值多少钱，谈判就从情绪战变成数据战**。

## 一、应成本模型（Should-Cost Model）

### 成衣成本拆解公式
```
FOB 成本 = 面料成本 + 辅料成本 + 加工费（CMT）+ 包装 + 管理分摊 + 利润
```

| 成本项 | 占比（针织 T 恤示例） | 核算方法 |
|:---|:---|:---|
| 面料 | 45-55% | 单件用量（kg）× 面料单价——用量=（衣长+袖长）× 胸围 × 克重 × 损耗系数 |
| 辅料 | 5-10% | 拉链/扣/线/标逐项累加 |
| 加工费 CMT | 20-30% | SMV × 分钟工价（见 `suppliers/production-capacity-scheduling.md`） |
| 后整/包装 | 3-5% | 整烫+检品+包装材料 |
| 管理+利润 | 8-15% | 工厂管理费率与利润率 |

### 实战示例（男士基础 T 恤）
- 面料：180gsm 精梳棉汗布，单件用量 0.22kg（含 3% 损耗）× ¥45/kg = **¥9.9**
- 辅料：螺纹领+洗标+尺码标+线 = **¥0.8**
- CMT：SMV 8 分钟 × ¥0.9/分钟 = **¥7.2**
- 后整包装：**¥1.2**
- 管理利润 12%：**¥2.3**
- **应成本 ≈ ¥21.4 ≈ $2.95**——供应商报 $3.5 则有谈判空间；报 $2.5 则需警惕偷工减料。

## 二、Open Book 成本公开（战略供应商）

- **模式**：战略供应商公开成本结构，双方按"成本 + 约定利润率"定价——成本下降双方分享收益；
- **前提**：长期份额承诺 + 信任关系（供应商担心成本数据被滥用压价）；
- **适用**：年采购额 $100 万+ 的核心品类供应商。

## 三、成本审计要点

### 面料成本核实
- 面料单价 vs 市场行情（棉纱价格公开可查——见 `fabric/fabric-inventory-stock-strategy.md` 行情跟踪）；
- **用量核算**：排版图（marker plan）验证单件用量——供应商多报 3-5% 用量是常见灰色空间。

### 工费核实
- SMV 实测：秒表测时（GSD 标准）vs 供应商申报 SMV；
- 分钟工价 =（车工月工资 × 1.4 福利系数）÷（月工时 × 60 × 效率）——可独立复算。

### 辅料核实
- 拉链/扣件按采购发票核价（YKK 有公开价格带——虚报辅料价格容易查证）。

## 四、降本机会识别

| 方向 | 方法 |
|:---|:---|
| 面料用量 | 排版优化（门幅利用率从 85% → 90%+） |
| 工艺简化 | 减少不必要工序（双针改单针、合并车缝） |
| 规格收敛 | 面料规格数减少（库存与采购规模效应） |
| 包装优化 | 精简包装（去胶袋/合袋——同时满足 EPR 趋势） |
| 淡季生产 | 反季锁产能折扣（工厂填产线） |

## 五、成本谈判话术框架

1. **数据开场**："我们按 40S 精梳棉 ¥45/kg、SMV 8 分钟测算，应成本在 $2.9 左右——您的报价 $3.4，能帮我们看下差异在哪？"
2. **对事不对人**：差异点逐项核对（面料单价？用量？工价？）——**用对方的合理性打败对方的价格**；
3. **给台阶**：差异找到后给供应商保留合理利润（"这部分我们认可，但那部分再商量"）——赶尽杀绝的谈判没有下次。

## 六、风险警示

- **低于应成本的报价是危险信号**：偷工减料（克重不足/换便宜原料）或现金流危机（抢单续命——跑路前兆）；
- **成本透明是双向的**：要求供应商 open book 的同时，采购方也需分享需求预测（信息换价格）；
- **不滥用成本模型**：小单/急单的成本结构天然偏高——模型是谈判工具不是压榨工具。
