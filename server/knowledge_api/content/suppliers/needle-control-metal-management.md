# 断针验针与金属异物管控（Needle Control & Metal Detection Management）

断针/金属异物是服装出口"**致命缺陷**"之首——残留针尖可致消费者重伤，日本订单与童装强制 100% 过验针机，欧美客户验厂必查断针记录。一根断针=整批翻箱+客户信任崩塌。

## 一、风险场景与法规要求

| 场景 | 要求 |
|:---|:---|
| 日本订单 | 100% 检针强制（行业惯例法律化——检测记录留存 1 年+，见 `customers-market/jp-market.md`） |
| 婴童装 | 全球客户默认强制（致命缺陷——见 `garments/childrenswear-production.md`） |
| 欧美品牌 | 验厂查断针 SOP+记录（WRAP/BSCI 加分项，见 `suppliers/factory-audit-guide.md`） |
| 内衣/床品 | 贴肤品类高敏（客户投诉高发） |

- **法律责任**：美国 CPSC 可强制召回（金属异物=物理危害）；日本制品责任法（PL 法）索赔；中国《产品质量法》同样适用。

## 二、断针管控 SOP（缝纫现场）

1. **领用登记**：机针以旧换新（断针必须**碎片全数交回**才能领新针——数量对不上不发放）；
2. **断针即时处置**：
   - 停机→找齐碎片（用吸铁石+目视）；
   - 碎片拼接核对完整→贴《断针回收记录表》（日期/机台/员工/针型号）；
   - **找不到碎片**：当班半成品隔离（用验针机逐件排查）→仍未找到报主管扩大排查（前后 2 小时产量）；
3. **针具定置**：机针存放上锁（针盒专人管理——员工不得自带针）；
4. **手缝针管理**：手工用针当日领还登记（尾部穿绳防丢）；
5. **其他金属源**：剪刀/锥子定置；车间禁戴饰品（验厂项）；打枣机/钉扣机模具检查（金属屑）。

## 三、验针机（检针机）管理

- **灵敏度标准**：常规 Fe Φ1.0mm 测试卡（童装/日本单 Φ0.8mm）——灵敏度档位按客户要求设定；
- **校准频次**：**每班 3 次**（开班/中途/收班——9 点测试法：传送带左中右×高中低）；
- **测试卡管理**：标准测试卡（Fe/SUS 两种——不锈钢扣件区用 SUS 卡）专人保管；
- **报警处置**：报警产品→隔离区→逐段排查（手持探测器定位）→找到异物记录；找不到→拆解检查→仍无则**报废处理**（不得放行）；
- **干扰控制**：验针区无金属架/无电机干扰（传送带周边 1m 净空）；员工过机前清空口袋（钥匙/手机）。

## 四、流程位置

- **后整末端**：整烫后→验针→**立即装箱**（验针后到装箱不再经手无防护环节——见 `suppliers/finishing-ironing-packing-room.md`）；
- **二次验针**：高风险品类（婴童/日本单）装箱前抽检复验；
- **记录留存**：验针记录表（日期/机台/班次/数量/报警处置）保存 1-3 年（客户追溯）。

## 五、常见失效原因（验厂扣分点）

| 失效点 | 表现 | 对策 |
|:---|:---|:---|
| 校准流于形式 | 测试卡过期/只做 1 点 | 9 点法+记录签字 |
| 报警品放行 | "找不到就算了" | 报废制度+主管审批 |
| 断针记录造假 | 补抄记录 | 碎片实物袋存档 |
| 验针后污染 | 验完放金属货架 | 验针区物理隔离 |
| 手持探测器无校准 | 灵敏度漂移 | 纳入设备点检表 |

## 六、成本与设备

- **传送带式验针机**：国产 1.5-4 万元（安立/东莞产主流），进口（日本 Hashima/安立）8-15 万——日产稳定性标杆；
- **手持探测器**：数百元级（辅助定位用）；
- **运行成本**：电费可忽略；核心是**人力执行成本**（专职验针员+记录）；
- **ROI 逻辑**：一次断针客诉翻箱费（第三方全检 2-5 元/件×万件）+客户降级损失 >> 设备投入。

## 七、数字化延伸

- **验针数据联网**：新型验针机计数联网（产量与验针数比对——漏检可追溯）；
- **X 光检针**：鞋类/厚料产品用 X 光机（断针+金属+玻璃/石块全检——成本 10 万+，鞋厂标配）；
- **金属辅料管理**：拉链/纽扣本身含金属——**先验针后上辅料？不可行**；正确做法：选低磁辅料（无镍拉链）+验针机灵敏度按辅料调试（含辅料成衣能过机为准）。
