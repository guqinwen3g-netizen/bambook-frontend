# 面料与成衣仓储防霉防潮管理（Warehouse Moisture & Mold Prevention）

霉变是纺织服装**索赔最高发的隐性杀手**：梅雨季节面料上霉、海运集装箱雨成衣受潮——一单霉变索赔可吞掉全年利润。防霉管理=**环境控制+包装防护+库存周转**三体系（包装段防潮见 `garments/garment-packaging.md`，本文聚焦仓储全链路）。

## 一、霉变机理与风险点

- **霉菌条件**：湿度 75%RH+温度 25-35°C+有机物（浆料/汗渍/淀粉）=霉菌爆发；棉麻粘胶（天然纤维）>化纤（涤纶抗霉但**浆料/油剂可霉**）；
- **高危时点**：江南梅雨（6-7 月）/华南回南天（2-4 月）/海运高湿航线（东南亚-美西——集装箱内昼夜温差"集装箱雨"）；
- **高危物料**：全棉色织布（浆料残留）/牛仔（淀粉浆——见 `fabric/denim-fabric-deep-dive.md`）/真丝/羊毛（蛋白质纤维）/皮革（六价铬之外霉变是皮料头号仓储问题，见 `fabric/leather-synthetic-leather.md`）；
- **验货红线**：霉斑（mildew spots）=AQL 致命缺陷——**整批拒收+熏蒸费用由供方承担**（合同条款见 `trade-process/trade-contract-terms.md`）。

## 二、仓储环境控制

- **湿度目标**：仓库 55-65%RH（除湿机/空调除湿模式——梅雨季 24h 运行）；温湿度计分布（每 500 ㎡ 一个——**日记录台账**=验厂与索赔举证）；
- **地坪防潮**：托盘/货架离地 ≥15cm（水泥地坪返潮——一楼仓库重点）；墙面离地 30cm 检查（墙角霉斑预警）；
- **通风**：对流风扇/排风定时（封闭仓库闷湿是霉菌温床）；
- **梅雨季专项**：入梅前全面检查（屋顶渗漏/窗缝/下水）；新入库面料**摊开晾放 24h 再上架**（运输途中吸湿）；
- **成品仓**：成品装箱后码垛留风道；纸箱湿度检测（纸箱含水率 ≤12%——湿箱=箱内霉菌培养基）。

## 三、包装与运输防护

- **内包**：防潮袋（PE 袋+干燥剂——硅胶/蒙脱石用量按体积：1m³ 约 500g 起）；防霉片（防霉贴片/防霉纸——芥末精油/缓释型，注意**防霉剂合规**：DMF 富马酸二甲酯禁用——欧盟 2009/251/EC 召回史，见 `trade-compliance/product-liability-recall.md`）；
- **装箱**：集装箱干燥剂挂条（40HQ 挂 8-12 条——氯化钙型吸湿量自重 3 倍）；箱门侧挂条+顶部铺放；
- **装柜检查**：集装箱木地板湿度（>20% 拒装——验箱流程）；雨天装柜管控（月台雨棚/快速关箱）；
- **海运条款**：提单湿度免责条款陷阱（承运人"said to contain"——保险承保霉变需特约，见 `trade-process/cargo-insurance.md`）。

## 四、库存周转与处置

- **FIFO**：面料先进先出（库存超 90 天面料湿度抽检——见 `fabric/fabric-inventory-stock-strategy.md`）；
- **隔离区**：受潮/疑似霉料**立即隔离**（霉菌孢子扩散——一疋霉布毁一仓）；
- **受潮处置**：轻度受潮→通风晾干+湿度复测；霉斑料→专业除霉（成本与价值权衡——多数报次处理）；**处置记录**（质量追溯）；
- **索赔举证链**：温湿度台账+干燥剂用量记录+装柜照片（封条号同框）——客户/保险索赔时的自证材料（见 `trade-process/claims-handling.md`）。

## 五、管理体系

- **责任划分**：仓管每日湿度记录/品质周抽检/梅雨季主管日巡；
- **验厂关注**：品牌审核看仓库湿度记录+托盘离地+通风（形式化记录=审核员现场测湿度核对）；
- **成本**：除湿机电费（梅雨 3 个月约 ¥1-3 万/千㎡）vs 一单霉变索赔（$5,000-50,000）——**防霉投入是最划算的保险**。
