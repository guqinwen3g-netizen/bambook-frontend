# 服装厂筹建与投资指南（Garment Factory Setup & Investment）

服装建厂是"**轻资产重运营**"生意：设备投入可控（一条针织线 30-50 万），真正门槛在招工、管理与订单——规划失误高发在产能与订单不匹配。

## 一、投资决策框架

| 规模 | 工位 | 月产能（衬衫） | 设备投资 | 适用 |
|:---|:---|:---|:---|:---|
| 微型 | 20-30 | 1.5-2.5 万件 | 30-50 万 | 加工点/快反工作室 |
| 小型 | 50-80 | 4-7 万件 | 80-150 万 | 起步厂/专单品类 |
| 中型 | 150-300 | 12-25 万件 | 300-600 万 | 品牌代工门槛 |
| 大型 | 500+ | 50 万件+ | 1500 万+ | 集团化/垂直整合 |

## 二、选址要素

- **劳动力**：县城乡镇（女工资源——工资低于城市 30% 但稳定性高）;
- **产业集群**：面辅料配套半径（绍兴面料/广州辅料——离集群近采购快，见 `suppliers/fabric-market-sourcing.md`）;
- **物流**：外贸厂近港口/机场（宁波/深圳/广州周边）;
- **政策**：地方招商优惠（内地县市政府补贴/厂房租金减免——中部承接转移）;
- **海外建厂**：东南亚（越南/柬埔寨/孟加拉——关税+人工成本，见 `customers-market/vietnam-market.md` 等）。

## 三、产线规划

- **品类定产线**：针织（平车+包缝为主）/梭织（平车+专机多）/牛仔（专用设备链——见 `suppliers/garment-machinery-equipment.md`）;
- **线体配置**：一条流水线 25-35 工位（含机动工——SAM 平衡设计，见 `suppliers/garment-ie-engineering.md`）;
- **配套部门**：裁剪房（裁床+拉布机）/后整（整烫+包装）/版房（见 `suppliers/pattern-sample-room-management.md`）/品控;
- **吊挂系统**：中大型厂标配（效率+数据——投入每工位约 2000-4000 元）。

## 四、设备投资清单（小型梭织厂参考）

- **平缝机**：30-50 台（重机/兄弟二手 vs 国产杰克/标准——国产新机性价比主流）;
- **包缝/绷缝**：按品类配比（针织厂包缝占比高）;
- **专机**：锁眼/钉扣/套结/撬边（外发或二手起步）;
- **裁剪**：裁床+电剪+拉布机;
- **整烫**：烫台+蒸汽锅炉（或蒸汽发生器）;
- **原则**：主力设备新购国产+专机二手+低频工序外发（控制初期投入）。

## 五、招工与管理

- **招工难是常态**：熟练车工稀缺（长三角/珠三角——内地建厂工资低但技能弱，培训周期 3-6 个月）;
- **薪酬**：计件为主（SAM 工价透明——见 `suppliers/garment-ie-engineering.md`）+保底+全勤;
- **管理班子**：厂长（生产）+IE（效率）+品控（质量）铁三角（小厂一人多职）;
- **产能爬坡**：新厂前 3 个月效率仅 40-60%（招工+磨合——订单承诺留 buffer）。

## 六、订单来源与现金流

- **起步订单**：外贸公司加工单/二手单（利润薄但求稳定——积累口碑）;
- **升级路径**：加工（CMT）→ 包工包料（FOB）→ ODM 设计（毛利阶梯：8%→15%→25%）;
- **现金流模型**：面料垫资+45-60 天回款（流动资金 = 月产值×2 倍安全线）;
- **客户集中风险**：单一客户占比<40%（砍单即死——客户结构多元化）。

## 七、合规要求

- **营业执照+环保**：服装厂环评要求低（无染整——缝纫噪声/固废管理）;
- **消防**：厂房消防验收（人员密集场所——疏散/喷淋）;
- **社保**：用工合规（验厂硬指标——见 `suppliers/factory-audit-guide.md`）;
- **出口资质**：自营出口需进出口权+电子口岸（或经外贸公司代理）。

## 八、失败案例教训

- **先建厂后找单**：设备闲置烧钱（先有订单意向再投资）;
- **品类贪全**：针织梭织通吃（设备分散+技术不精——单品类做深）;
- **低估招工**：招不满产线（选址先看劳动力池）;
- **账期失控**：客户欠款拖垮（新厂现金流脆弱——前 T/T 比例坚持）。
