# 供应商协作与跟单要点（Supplier Collaboration）

供应商协作覆盖从下单、交期、质量对接到对账付款与关系维护的全过程。规范协作可减少扯皮、保障履约。

## 一、下单与合同

- **下单前**：确认品质规格、交期、MOQ、价格与付款方式，双方书面确认（采购订单 purchase order）。
- **合同要素**：品名规格、数量、单价、交期、质量标准、违约责任、知识产权与保密条款。
- **留档**：采购订单、确认回执、来往邮件统一归档，作为对账与索赔依据。

## 二、交期管理

- **交期沟通**：下单时明确交期（lead time）与里程碑（面料入库、缝制、验货、出运）。
- **进度跟踪**：按节点跟进生产进度，提前预警拖延风险；滞期需提前与外部客户协调。
- **产能预约**：旺季提前锁定产能与坯布/辅料库存，避免断料停工。
- **延期处理**：明确延期责任与赔偿约定，必要时分级上报、调整排产或转单。

## 三、质量对接

- **质量标准前置**：下单时明确验收标准（AQL 抽检、理化指标、签样（golden sample））。
- **过程管控**：关键节点验货（产中检、产终检），发现问题及时整改，避免大货成灾。
- **三方验货**：按客户要求安排第三方验货（如 SGS、BV、Intertek），出具验货报告。
- **客诉联动**：供应商质量异常导致的客户索赔，按责任划分追责并沉淀改进。

## 四、对账与付款

- **对账**：按月/按单核对数量、单价、退换、补料，形成对账单（statement）。
- **付款方式**：按约定执行预付款（deposit）、发货款、尾款；常用 T/T、L/C。
- **凭证管理**：合同、入库单、发票、付款回执一一对应，避免账实不符。
- **账期与授信**：根据合作历史与信用，设置合理账期与额度，控制资金风险。

## 五、关系维护

- **稳定合作**：优质供应商长期锁定，返单优先，共同优化成本与交期。
- **信息共享**：共享生产计划与客户需求变化，帮助供应商提前备料排产。
- **定期复盘**：每季度/半年复盘质量、交期、价格，明确改进项。
- **激励与淘汰**：表现优异者给更多订单与支持；长期不达标者及时调整，保持供应商池健康。
