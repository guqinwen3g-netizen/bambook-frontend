# 面料厂评估与开发（Fabric Mill Evaluation & Development）

面料是成衣质量的 60%：**选错面料厂 = 后面所有环节都在救火**。面料厂评估比成衣厂更技术化（织染工艺专业门槛高）。

## 一、面料厂类型

| 类型 | 特征 | 适用 |
|:---|:---|:---|
| 织染一体厂 | 纺纱/织造/染整全链 | 大订单品质稳定（鲁泰/申洲模式） |
| 织造厂 | 只织不染（外发染整） | 梭织/针织坯布 |
| 染整厂 | 只染不织（接坯布加工） | 染色/印花/后整理 |
| 贸易商/档口 | 现货面料（见 `suppliers/fabric-market-sourcing.md`） | 小单快反 |

## 二、评估维度（技术审核清单）

### 1. 设备与产能
- **织造**：织机类型（喷气/剑杆/大圆机——决定能做什么布）+ 台数（产能）；
- **染整**：染缸类型（溢流/气流——节水环保等级）+ 定型机（门幅/温度均匀性）+ 预缩机；
- **印花**：圆网/平网/数码（见 `fabric/digital-printing-technology.md`）；
- **检验**：验布机/实验室（色牢度仪/强力机——有无实验室是分水岭）。

### 2. 质量体系
- 实验室检测能力（GB/AATCC/ISO——能否按客户标准自检）；
- 认证（ISO9001 + OEKO-TEX/GRS/GOTS——见 `trade-compliance/textile-certifications.md`）；
- 追溯系统（缸号管理——问题面料能否追溯到缸次）。

### 3. 环保合规（硬性红线）
- **排污许可证**（印染是重污染——无证厂随时关停）；
- 污水处理（在线监测/中水回用）；
- ZDHC（有害化学品零排放——品牌验厂要求）；
- **环保关停风险**：园区集中化管理（入园企业更稳——见 `suppliers/fabric-accessories-supplier-management.md` 双备份）。

### 4. 技术与开发能力
- 打样速度（lab dip 3-5 天/手织样 7-10 天）；
- 花型开发（印花厂设计能力）；
- 功能性整理（防水/抗菌——技术储备）。

## 三、现场审核动线

```
原料仓 → 织造车间 → 染整车间（染缸/定型机）→ 印花车间 → 检验包装 → 实验室 → 污水站
```

### 看什么（红旗项）
| 观察点 | 健康信号 | 红旗 |
|:---|:---|:---|
| 织造车间 | 织机开机率高、挡车工巡台 | 大面积停机（订单不足） |
| 染缸区 | 缸号标识清晰、配料自动化 | 人工凭经验配色（色差风险） |
| 定型机 | 温度/车速自动记录 | 超喂不当（克重虚标源头） |
| 检验区 | 验布机全检+疵点标记 | 验布走过场 |
| 实验室 | 检测设备+使用记录 | 实验室形同虚设 |
| 污水站 | 正常运行+在线监测 | 污水站停运（偷排——随时被关停） |

## 四、面料厂开发流程

1. **寻源**：展会（Intertextile）/市场/同行推荐/线上（见 `suppliers/fabric-market-sourcing.md`）；
2. **初评**：资质+设备+认证问卷；
3. **打样验证**：lab dip/手感样——**小样质量=上限，大货稳定=下限**；
4. **现场审核**：技术+环保+社会责任（见 `suppliers/factory-on-site-audit-sop.md`）；
5. **小批量试单**：1-2 缸小单验证大货稳定性；
6. **准入**：合格供应商名录（AVL）+ 质量协议（见 `fabric/fabric-procurement-quality-agreement.md`）。

## 五、评估评分卡（示例权重）

| 维度 | 权重 |
|:---|:---|
| 品质（实验室+大货稳定） | 35% |
| 环保合规 | 20% |
| 技术/开发能力 | 15% |
| 交期/产能 | 15% |
| 价格 | 10% |
| 社会责任 | 5% |

- **环保一票否决**：排污无证/污水偷排——品质再好也禁用（随时关停毁交期）。
