# 供应商合同与风险管控（Supplier Contract & Risk Management）

贸易公司的供应链风险最终都落在合同与证据上。口头约定在纠纷时归零，**合同条款 + 过程留痕**是仅有的保护。

## 一、采购合同必备条款

### 1. 技术条款
- 产品规格：品名/成分/克重/工艺/颜色（潘通号）/尺码表——以附件 tech pack 与确认样为准。
- **封样约定**："品质以双方签封之确认样为准，封样一式三份各执"——色差/手感争议的裁决基准。
- 验收标准：AQL 值、疵点分级标准、测试项目与标准编号（如色牢度 AATCC 61 ≥ 4 级）。

### 2. 商务条款
- 价格与含税：明确含税（13% 专票）与否、税率变动处理。
- 付款：定金 20-30% + 验货合格后尾款；**新供应商首单后付款比例提高**。
- 交期：明确"交货日 = 货物送达指定仓库日"（非出厂日）；晚交期违约金 0.5-1%/天，上限 5-10%。
- 数量公差：±3-5%（服装惯例）；面料按实际米数结算条款。

### 3. 质量违约条款
- 验货不合格：返工+重验费由供应商承担；无法返工按折价/取消处理。
- **大货与封样不符**：买方有权取消订单并索赔定金+面料损失。
- 客诉连带：因产品质量导致的客户索赔（含空运费、折扣损失）由供应商承担——**质量责任溯及到港后 30-90 天**。

### 4. 知识产权与合规
- 客户商标/图案保密义务；超额生产禁止（多余产品销毁/去标）。
- 合规保证：非新疆棉承诺（输美订单）、环保合规（REACH/OEKO-TEX）、社会责任（不得转包给未审厂单位）。
- **禁止转包条款**：未经书面同意不得转包/分包——质量失控与审厂失效的第一大漏洞。

## 二、履约风险管控

### 供应商信用分层
| 层级 | 合作方式 |
|:---|:---|
| 新供应商 | 小单试产 + 30% 定金 + 验货后付尾款 + 质保金 5-10% |
| 成熟供应商 | 常规定金 + 月结/票后 15-30 天 |
| 战略供应商 | 年度框架协议 + 滚动预测 + 联合开发 |

### 过程留痕（证据链）
- 订单确认书（PO）双方盖章回传；
- 关键变更（交期/工艺/数量）**书面确认**（邮件/微信记录截图归档）；
- 验货报告、封样照片、往来函电按订单归档——客诉诉讼时就是胜负手。

### 飞单防控
- 贸易商核心资产是客户与订单——工厂绕过我方直接联系客户即"飞单"。
- 防控：合同竞业/保密条款（禁止直接接触终端客户）；唛头/吊牌信息管理（商标资料分阶段提供）；客户层面证明贸易公司的增值（质检/跟单/垫资）。

## 三、纠纷处理路径

1. **协商优先**：质量/交期纠纷先以补货/折扣/延期方案协商（成本最低）。
2. **验货报告固化证据**：第三方验货报告（SGS/ITS）是仲裁/诉讼的关键证据——重大订单验货务必第三方。
3. **仲裁条款**：约定仲裁（贸仲 CIETAC）优于法院诉讼（效率高、保密）。
4. **定金罚则**：《民法典》定金不得超过主合同标的 20%——超付部分不具定金效力，预付款比例设计注意。

## 四、特殊风险场景

| 场景 | 应对 |
|:---|:---|
| 面料涨价工厂要求加价 | 合同价格锁定期条款；超期未交货承担涨价自担 |
| 工厂挪用面料（把我的面料做别家货） | 面料直发工厂时签收货单+余料退回约定+不定期盘点 |
| 供应商停业跑路 | 定金比例控制 + 供应商经营状态动态监控（企查查预警） |
| 一货多卖（现货面料抢货） | 现货付款锁货+当日提货，合同明确所有权转移时点 |
