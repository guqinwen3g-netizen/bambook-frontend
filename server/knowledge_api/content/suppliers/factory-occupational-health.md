# 服装厂职业健康管理（Occupational Health: 粉尘/噪声/化学品防护）

职业健康是 BSCI/SMETA 验厂的**核心模块**（与消防安全并列）+国内职业病防治法的强制要求。服装厂职业危害集中在**裁断粉尘、粘合化学品、设备噪声、熨烫高温**四大点位——管理缺失=职业病索赔+验厂失分双重风险。消防安全见 `suppliers/factory-safety-fire-management.md`，本文聚焦健康危害防控。

## 一、危害点位与防护对照

| 点位 | 危害 | 防护 |
|:---|:---|:---|
| 裁剪/裁断 | 纤维粉尘（棉尘——棉尘肺） | 局部排风+防尘口罩（KN90+）+湿式作业 |
| 粘合/复合 | 热熔胶/溶剂挥发（VOC） | 排风罩+活性炭口罩+机器密闭 |
| 缝制 | 噪声（平车 75-85dB 累积）/视力疲劳 | 设备减震+工间操+照明（500-750 lux） |
| 熨烫 | 高温中暑/蒸汽烫伤 | 岗位通风+防烫手套+夏季降温（盐汽水/轮岗） |
| 充绒 | 羽绒粉尘（过敏原） | 密闭充绒间+负压+KN95 |
| 验针/金属 | 断针刺伤 | 见 `suppliers/needle-control-metal-management.md` |

- **牛仔喷砂**（高危专项）：**干喷砂=矽肺致命**（土耳其喷砂工人矽肺死亡事件致全球品牌禁令）——服装厂接单牛仔水洗必须确认**无干喷砂工艺**（激光/手擦替代，见 `suppliers/washing-factory-management.md`）；
- **化学品清单**：粘合剂/清洗剂/去渍剂 MSDS 收集（去渍枪溶剂——三氯乙烯类高危溶剂淘汰）+专柜储存+标签（见 `trade-compliance/chemical-environmental-compliance.md`）。

## 二、法定管理动作（国内法+验厂双重要求）

- **职业病危害因素检测**：年度第三方检测（粉尘/噪声/VOC 浓度——报告留档）；职业病危害项目申报（安监系统）；
- **职业健康体检**：接害岗位**岗前/在岗/离岗三检**（粉尘岗位胸片——体检报告归档，离岗体检是离职纠纷防火墙）；
- **劳保用品（PPE）**：按岗位发放（口罩/耳塞/手套——**发放签收台账**）；佩戴稽核（车间巡查——不佩戴=验厂现场扣分）；
- **警示标识**：危害告知卡（岗位张贴——粉尘/噪声/高温图标）+MSDS 现场可查；
- **档案**：一人一档（接害史+体检+PPE 记录——保存期法定）。

## 三、验厂健康模块高频失分点

| 失分点 | 整改 |
|:---|:---|
| 口罩发放无签收/过期口罩 | 台账+定期更换（活性炭口罩 8h 寿命） |
| 粘合车间无排风 | 加装排风罩+风速检测 |
| 体检缺失（离岗未检） | 三检 SOP+离职流程卡点 |
| MSDS 缺失/无中文 | 供应商索取+翻译张贴 |
| 高温车间无饮水点 | 饮水+盐汽水+休息区 |
| 女工保护（孕期调岗） | 孕产期岗位调整制度（BSCI 关注） |

## 四、成本与风险账

- **投入**：排风改造 ¥2-5 万/车间+PPE 年支出 ¥200-500/人+体检 ¥150-300/人次——全套年成本约占人工 1-2%；
- **风险对照**：职业病赔偿（尘肺病一次性赔付 30 万起+工伤待遇）；验厂健康模块失分=订单暂停（见 `suppliers/factory-audit-guide.md`）；
- **保险联动**：雇主责任险（职业病承保范围核对——见 `suppliers/garment-factory-hr-labor-management.md` 的用工风险）；
- **正向价值**：健康车间=招工卖点（粉尘/异味车间招工难——环境改善降低流失率，见 `suppliers/garment-factory-hr-labor-management.md`）。
