# 染厂协作与缸差管理（Dyeing & Printing Mill Cooperation Management）

染整是面料品质波动最大的环节——**缸差、色花、手感**三大顽疾都发生在这里。成衣厂/贸易公司与染厂的协作质量，直接决定大货颜色稳定性（染厂审核评估见 `suppliers/fabric-mill-evaluation.md`，本文聚焦协作跟单实操）。

## 一、打色与对色流程

1. **色样标准**：客户提供潘通号/原样→染厂打 lab dip（小样品 3 选 1）；
2. **光源箱对色**：D65 主光源+TL84/U30 副光源（**同色异谱必查**——商场灯光下变色的退货杀手）；
3. **确认样签封**：双方签字的色样（一式三份——客户/染厂/跟单各存）；
4. **放样（bulk lot）**：大货前先染一匹放样确认（色光/手感/缩率——放样 OK 才开大货）；
5. **首缸封样**：大货第一缸取样对封样——作为后续缸次基准。

## 二、缸差（lot shade variation）控制

- **成因**：染料批次/水质/温度曲线/浴比波动——**绝对同色不存在，只有可接受的缸差**；
- **分级标准**：灰卡 4 级以上为合格（4-5 级优；3-4 级需客户确认——见 `trade-compliance/testing-standards.md`）;
- **实操规则**：
  - 同一订单**同缸号裁片配套**（裁剪按缸号分包——成衣不允许左右片跨缸）；
  - 加单/补数优先同缸复染（新缸必对色）；
  - 缸差超标的布**降级做深色/次品处理**（不可混入）；
- **责任界定**：来料检验时发现缸差超标→48 小时内提报染厂（逾期默认接受——见 `suppliers/incoming-material-inspection.md`）。

## 三、加色/回修（shade correction）

- **加色逻辑**：染浅了可以加深（回修一次 20-30% 成本）；染深了基本报废（剥色伤布——强力/手感损失）；
- **决策**：加色前取小样试加（加色后色牢度下降半级常见——客户确认）；
- **次数红线**：回修不超过 1 次（多次回修布面发花/强力损失 15%+——直接报废更划算）。

## 四、印花厂协作要点

- **花型确认**：数码印花打样（见 `fabric/digital-printing-technology.md`）→对色对花位→大货网版/文件锁定；
- **对花对格**：裁片对花需求提前告知（印花厂控制花位循环偏差）；
- **色牢度**：涂料印花摩擦牢度弱（深色湿摩 2-3 级——接单时与客户书面确认接受标准）；
- **手感**：印花后上柔定型（涂料印花发硬是痼疾——活性印花手感好但贵 30%）。

## 五、交期与产能协作

- **排产节奏**：染厂旺季（4-6 月/9-11 月）排队 7-15 天——大单提前锁缸位（见 `trade-process/annual-sourcing-calendar.md`）;
- **环保限产**：秋冬采暖季北方限产+汛期排污管控（突发限产通知——备选染厂双轨）；
- **最小缸量**：溢流缸 200-500kg/缸——不足缸按缸计费（小单染色成本高 30%+，报价必算）；
- **急单插队**：染厂关系户特权（年合作量决定话语权——固定染厂年框优于散单比价）。

## 六、品质争议处理

| 争议 | 判定依据 | 处理 |
|:---|:---|:---|
| 缸差超标 | 灰卡评级+封样比对 | 超标部分换货/折价（行业标准折价 10-30%） |
| 色花/条痕 | 验布记录（四分制——见 `fabric/fabric-inspection-4point.md`） | 疵布退换 |
| 牢度不合格 | 第三方检测报告 | 返修回染/索赔（合同注明牢度指标） |
| 缩率超标 | 洗测报告 | 定型返修/降级 |
| 手感不符 | 封样对比（主观——前置约定风格样） | 回整/折价 |

- **证据链**：留布版+验布报告+检测数据（扯皮时只认物证——口头无效）；
- **合同条款**：染整加工合同明确色号标准/缸差级数/牢度指标/缩率范围/赔偿公式（见 `fabric/fabric-procurement-quality-agreement.md`）。

## 七、协作关系经营

- **技术人员直通**：跟单与染厂**打色师傅直接对接**（绕开业务层级——色差沟通零损耗）；
- **年度框议**：年量换优先级+价格（旺季保缸位——比单次砍价有价值）;
- **数据沉淀**：每缸记录（染料配方号/温度/批次）入档——翻单复染一致性靠档案。
