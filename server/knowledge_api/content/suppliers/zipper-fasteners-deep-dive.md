# 拉链深度解析（Zippers: 型号体系/强力测试/品牌梯队/失效模式）

拉链是服装辅料中**技术密度最高、客诉占比最大**的单品：一条裤子拉链爆开=整件退货。辅料总览见 `suppliers/garment-accessories-trims.md`，本文件展开拉链选型、测试与采购深度。

## 一、类型与型号体系

| 类型 | 结构 | 适用 | 价格（#5 码装参考） |
|:---|:---|:---|:---|
| 尼龙拉链（coil） | 聚酯螺旋链牙缝合在布带上 | 服装主流（裤子/裙子/外套）、箱包 | ¥1-3/米 |
| 树脂拉链（vislon/塑钢） | 注塑链牙咬合 | 外套/童装/户外（轻+耐低温） | ¥1.5-4/米 |
| 金属拉链 | 铜/铝/锌合金链牙（Y 牙/方牙） | 牛仔/皮衣/高端外套 | ¥3-10/米 |
| 防水拉链 | 尼龙链+TPU/PU 覆膜（反装） | 冲锋衣/潜水服/防水袋 | ¥5-15/米 |
| 隐形拉链 | 尼龙链反装+细牙 | 女装裙/礼服 | ¥1-2/条 |

- **型号 = 链牙合拢后宽度（mm）**：#3（4.0mm）/#5（5.5-6mm）/#8（8mm）/#10——**号数越大强力越高**；裤子门襟常用 #3/#4.5，外套 #5/#8，箱包 #8/#10，帐篷 #10+；
- **长度与结构**：闭尾（close-end 裤子）/开尾（open-end 外套——插销方块结构）/双开尾（双拉头羽绒服）/上下拉（睡袋）；开尾结构的**插销抗扭强度**是外套拉链失效首因。

## 二、强力与性能测试（QB/T 2171-2173 / BS 3084）

| 测试项 | 定义 | 常规指标（#5 尼龙） |
|:---|:---|:---|
| 平拉强力 | 链牙横向抗拉 | ≥340N |
| 拉合轻滑度 | 拉动阻力 | ≤3N（顺滑度） |
| 单牙移位强力 | 单牙抗错位 | ≥25N |
| 上止/下止强力 | 止口抗拉脱 | ≥60N/90N |
| 拉头抗扭 | 拉片扭矩 | ≥0.2N·m |
| 往复拉动 | 寿命次数 | ≥1000-5000 次无故障 |
| 耐水洗/干洗 | 收缩与变色 | 按服装洗涤方式匹配 |

- **水洗协同**：拉链布带与面料**收缩率差异=洗后门襟起拱**（拉链波浪）——采购时确认布带预缩处理；金属拉链水洗氧化变色（古铜效果例外——做旧工艺）；
- **色牢度**：深色拉链布带沾色到浅色面料（摩擦/汗液）——色牢度 4 级起步。

## 三、品牌梯队与采购

- **第一梯队**：YKK（全球标杆——价格是国产 2-3 倍，品牌客户指定率最高）；**YKK 授权纪律**：吊牌/拉头 logo 必须正品采购——仿 YKK 是品牌验厂红线（见 `trade-compliance/ip-brand-authorization.md`）；
- **国产头部**：SBS 浔兴（上市，性价比首选）、SAB 伟星、3F 福兴、YQQ——中端品牌主力供应链；
- **采购模式**：码装（整卷裁切——箱包厂）vs 条装（按长度成品——服装厂）；**起订量**：常规色现货，特殊色染色 500 打/色起；特殊拉头开模费；
- **交期**：常规 7-15 天；YKK 定制色 30-45 天——**拉链是辅料交期瓶颈**，大货面料到厂前必须先确认拉链；
- **验针兼容**：金属拉链头含铁——服装过验针机需调整灵敏度/分段过机（见 `suppliers/needle-control-metal-management.md`）。

## 四、失效模式与客诉归因

| 失效 | 根因 | 预防 |
|:---|:---|:---|
| 爆开（链牙分离） | 平拉强力不足/缝制针距过稀/穿着应力 | 选型升级号数；缝合双针线 |
| 拉头脱落 | 上止失效 | 上止强力测试+加厚上止 |
| 插销断裂（外套） | 低温脆化/扭力 | 树脂改尼龙加强插销 |
| 布带撕裂 | 布带纱线密度低 | 高密度布带选型 |
| 牙缝夹布 | 内衬卷入 | 拉链护布设计+缝制导向 |
| 金属牙氧化 | 铜牙汗液/水洗腐蚀 | 镀层加厚/钝化；出汗场景选铝牙 |

- **镍释放**：金属拉头/四合扣镍释放量（欧盟 REACH 附录 17——0.5μg/cm²/week 皮肤接触限值）——见 `trade-compliance/chemical-environmental-compliance.md`；
- **童装安全**：拉头小部件拉力测试（防吞咽）+ 锐边检查（见 `trade-compliance/cpsc-children-safety.md`）。
