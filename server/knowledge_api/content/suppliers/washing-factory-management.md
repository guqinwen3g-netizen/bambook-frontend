# 洗水厂管理与牛仔洗水工艺（Garment Washing Factory Management）

洗水（garment washing）是牛仔/休闲服的"**二次设计**"——同一条裤子洗出不同效果价差数倍。洗水厂是典型高污染环节（水耗/化学品/污水），也是品牌 ESG 审计重点。

## 一、主要洗水工艺

| 工艺 | 效果 | 要点 |
|:---|:---|:---|
| 普洗（rinse wash） | 退浆柔软、轻微落色 | 基础工艺——固色剂控制落色度 |
| 酵素洗（enzyme wash） | 均匀做旧、手感软 | 纤维素酶吃毛羽——时间/温度控制色光 |
| 石磨洗（stone wash） | 强做旧、雪花感 | 浮石摩擦——石渣损伤面料/设备（现多用胶球替代） |
| 雪花洗（acid wash） | 斑驳雪花纹 | 高锰酸钾浸石——化学品管控严 |
| 猫须（whisker） | 大腿放射状折痕 | 手工擦/模具喷马骝——3D 定型树脂固定 |
| 手擦（hand sand） | 局部磨白 | 人工砂纸——工人硅尘防护（职业病风险） |
| 马骝（PP spray） | 局部褪色 | 高锰酸钾喷淋+中和——重金属残留管控 |
| 破洞（destroy/ripped） | 磨破/割破 | 激光+手工——牢度测试（破口继续撕裂） |
| 扎染/吊染 | 渐变艺术效果 | 时尚款——重现性差（每件唯一） |

## 二、环保洗水技术（品牌必查）

- **激光（laser）**：替代手擦/猫须——零化学品零水耗（电脑雕刻纹理，效率 10 倍）；
- **臭氧（ozone）**：替代漂白——空气源氧化褪色（省水 60%+）；
- **纳米气泡/e-flow**：雾化处理替代浸洗（Jeanologia E-flow——省水 90%）；
- **EIM 评分**：Jeanologia 的洗水环境影响评分系统——Levi's/H&M 要求供应商洗水 EIM 达标（green score）；
- **禁喷砂（sandblasting）**：喷砂致矽肺病——全球品牌 2010 年起全面禁止（致命职业病，接单须确认工厂无喷砂线）。

## 三、洗水厂选择与审计

- **环保资质**：排污许可证+污水处理设施（自建或园区集中处理）——COD/pH/色度在线监测；
- **水源与回用**：中水回用率（先进厂 50%+）——水耗是洗水第一成本（一柜牛仔裤洗水耗水 50-100 吨）;
- **品牌审计**：WRAP/BSCI/amfori+品牌专属 ESG 审核（Inditex 的 GTW 环境审核最严——见 `suppliers/factory-audit-guide.md`）；
- **化学品管控**：ZDHC MRSL 清单（禁 APEO/高毒溶剂——见 `trade-compliance/chemical-environmental-compliance.md`）；
- **产能匹配**：洗水厂辐射半径（牛仔产业带内配套——外发洗水物流+沟通成本高）。

## 四、跟单与品质要点

- **洗前样（wash standard）**：确认洗水效果标样（对色光源箱下比对——洗后色光每缸有缸差）；
- **缸差控制**：同单分批洗→缸差风险（要求同单同机/同配方+首缸封样）；
- **缩率（shrinkage）**：洗水后尺寸缩——纸样预放缩率（洗前量/洗后量双记录，国标 ±3% 内）;
- **色牢度**：洗后摩擦牢度（干摩/湿摩）——深蓝牛仔湿摩 2-3 级常见（接单时与客户确认接受度）；
- **手感与强力**：重洗水伤面料（强力下降 10-20%）——洗后撕裂/顶破测试；
- **五金防护**：洗前包扣/包拉链（防磨花氧化）——洗后检查五金变色。

## 五、成本结构

- **洗水报价**：按工艺叠加计价（普洗 2-4 元/件 → 酵素+猫须+马骝 8-15 元/件——手工工序占比高）；
- **水洗 vs 免洗**：raw denim（原牛不洗）零洗水费但面料要求高——赤耳原牛是另一品类逻辑；
- **淡旺季**：洗水厂旺季（6-9 月）排队——大单洗水产能需与成衣同步锁定。

## 六、产业带

- **广东**：新塘（牛仔之都——洗水厂集群，环保整治后入园集中）、均安、中山大涌（牛仔+洗水一体）；
- **江西**：于都（承接广东转移——新园区环保配套）；
- **山东**：潍坊/淄博（北方牛仔洗水）；
- **环保趋势**：广东 2017 年后洗水厂"退城入园"——园区统一污水处理，小散乱关停。
