# 供应商分类与评估（Supplier Classification & Evaluation）

供应商是外贸履约的产能与质量基础。分类管理、量化评估与严格准入，能降低交期与质量风险。

## 一、供应商分类

- **面料厂（Fabric Supplier）**：棉/涤/真丝等坯布与色布供应商，关注织造、克重、幅宽与起订量。
- **辅料厂（Trims Supplier）**：纽扣、拉链、标签、织带、包装等，关注规格一致性、交期与环保（如 REACH）。
- **成衣厂（Garment Factory）**：缝制与整装，关注工艺、产能、品质控制（AQL）与验厂合规。
- **印染厂（Dyeing/Printing Plant）**：染色印花与后整理，关注色牢度、色差、环保（废水、REACH 受限物质）。
- **其他**：检测机构、物流货代等服务型供应商，纳入合格名录管理。

## 二、评估维度

- **质量（Quality）**：理化指标（色牢度、缩水、起毛球）、外观一致性与历史客诉率。
- **价格（Price）**：单价、MOQ、批量折扣、付款账期，与市场行情比对。
- **交期（Delivery）**：正常交期（lead time）、准时交货率、加急能力与异常响应。
- **产能（Capacity）**：月产能力、旺季承接能力、设备与自动化水平。
- **合规（Compliance）**：验厂（社会责任 ISO/BSCI/sedex）、环保资质、受限物质检测能力。
- **服务（Service）**：配合度、沟通响应、样品与打版能力、问题解决的主动性。

## 三、评分与准入流程

- **评分表**：按上述维度加权打分（如质量 30%、交期 25%、价格 20%、合规 15%、服务 10%）。
- **准入流程**：
  1. 资料收集：营业执照、资质证书、样品、报价；
  2. 现场或远程考察：产能、设备、质量管理体系；
  3. 样品检测与试单（trial order）；
  4. 综合评分，达标纳入合格供应商名录（approved vendor list, AVL）；
  5. 签订质量协议与保密协议。
- **分级**：按评估结果分 A/B/C 级，A 级优先派单，C 级警戒或淘汰。

## 四、动态管理

- **定期复评**：每年或每半年复评一次，结合交期准时率、客诉率更新等级。
- **异常处理**：出现重大质量/交期事故，触发降级、暂停或淘汰。
- **风险分散**：核心品类保持 2-3 家备选（dual source），避免单一依赖。
