# 版房与样衣房管理（Pattern Room & Sample Room Management）

版房（pattern room）是**服装厂的技术核心**：版型决定款式成败。版师是"稀缺技术资源"——版房管理是工厂竞争力。

## 一、版房职能

```
设计图/客供款 → 打版（纸样）→ 样衣（首样）→ 版型修正 → 放码（grading）→ 生产纸样 → 工艺单
```

## 二、打版（pattern making）

### 方式
| 方式 | 说明 |
|:---|:---|
| 平面裁剪 | 公式/比例法制版（基础款——快速） |
| 立体裁剪（draping） | 人台立裁（礼服/复杂款——见 `garments/evening-wedding-dress.md`） |
| 拷贝（copy） | 样衣拆解拷贝（来样复制——外贸常见） |
| CAD 打版 | 电脑打版（富怡/格柏——现代主流） |

### 版师能力
- **版型理解**：人体结构+松量（版型是"人体工程学"）；
- **品类专长**：西装版师 ≠ 针织版师（品类版型差异大——见各品类文档）；
- **经验积累**：版型库（成熟版型=快速翻版）。

## 三、放码（grading）

- **放码规则**：见 `garments/pattern-grading-sizing.md`——跳码档差（S/M/L 各部位档差）；
- **CAD 放码**：电脑放码（精度+效率）；
- **放码质量**：跳码后版型保持（不放变形——大码版型走样是放码水平问题）。

## 四、样衣制作

- **样衣工**：技术最好的缝纫工（样衣=工艺标杆——样衣工工资高于产线）；
- **首样（proto）**：款式验证（版型/工艺——客户反馈修正）；
- **确认样（approval）**：客户确认（封样——大货基准，见 `trade-process/sample-room-management.md`）;
- **产前样（PP sample）**：大货前（材料/工艺最终确认）。

## 五、版型库与知识产权

### 版型库（工厂资产）
- **成熟版型归档**：T 恤/POLO/卫衣基础版型库（翻单快速调用）；
- **客户版型**：客户专属版型（版型保密——客户资产）；
- **版型数据化**：CAD 版型库（数字化管理——版师流动不丢版型）。

### 知识产权
- **客户版型保密**：客供款版型不外流（见 `trade-compliance/ip-brand-authorization.md`）；
- **版型版本控制**：改版记录（V1/V2——生产用最新版）。

## 六、版房与生产衔接

- **生产纸样**：版房出生产纸样（裁剪用——含缝份/对位记号）；
- **工艺单**：版房+工艺员出工艺单（tech pack——见 `garments/garment-technology-process.md`）;
- **产前会**：版师参与产前会（工艺难点交底——见 `suppliers/production-capacity-scheduling.md`）；
- **生产支持**：产线版型问题版师支持（版型问题的现场解决）。

## 七、验厂视角

| 看什么 | 解读 |
|:---|:---|
| CAD 打版 | 技术装备（电脑打版=精度+效率） |
| 版型库 | 技术积累（成熟版型=快速翻单） |
| 版师配置 | 品类覆盖（有无对应品类版师） |
| 样衣质量 | 样衣=工艺上限（样衣差大货更差） |
| 版房管理 | 纸样归档/版本控制 |
