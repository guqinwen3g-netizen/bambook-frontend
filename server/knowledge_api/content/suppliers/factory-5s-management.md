# 服装厂 5S 现场管理（Factory 5S Management）

5S 是精益生产的"**地基工程**"：整理/整顿/清扫/清洁/素养——验厂第一印象、效率损耗、品质事故都与现场状态直接相关。

## 一、5S 定义与服装厂落地

| S | 定义 | 服装厂场景 |
|:---|:---|:---|
| 整理（Seiri） | 要与不要分开，不要的清除 | 裁床区无闲置纸样堆积/机台无报废半成品/通道无杂物 |
| 整顿（Seiton） | 要的物品定位定量 | 辅料定置盒+标签/裁片车有位/工具挂板形迹管理 |
| 清扫（Seiso） | 扫除+点检异常 | 机台每日擦拭（发现漏油=设备预警）/地面无布毛 |
| 清洁（Seiketsu） | 前 3S 制度化 | 区域责任牌/点检表/红黄绿目视看板 |
| 素养（Shitsuke） | 习惯养成 | 早会/巡检/稽核——最难也最根本的 S |

## 二、服装厂高发痛点对照

- **裁片管理**：裁片车乱堆放（混款混号=错片事故——裁片车+标签+定置线）;
- **线头/布毛**：飞扬污染成品（白色款沾污——工位吸风集尘+日清扫）;
- **辅料混乱**：扣子/拉链混盒（错用辅料批量事故——分格盒+色标）;
- **针管理**：断针找不回（5S+断针回收表联动——见 `suppliers/sewing-thread-needles.md`）;
- **消防通道**：纸箱堆通道（验厂硬伤+安全隐患——黄线标识+日巡）。

## 三、目视化管理（visual management）

- **区域线**：通道黄色/合格品绿色/不良品红色（地贴/划线——一眼可辨）;
- **形迹管理**：工具挂板轮廓（剪刀/锥子缺失即见）;
- **看板**：产线进度看板（目标 vs 实际——小时级更新，见 `suppliers/garment-factory-lean-production.md`）;
- **标识**：机台状态牌（运行/维修/待料——减少询问成本）;
- **标准照片**：工位 5S 标准照张贴（对照执行）。

## 四、推进方法（避免"一阵风"）

- **样板区先行**：一条产线做 3 个月样板（做出对比效果再全厂推——说服力来自眼见）;
- **红牌作战**：不要品贴红牌限期处理（周度集中行动）;
- **定点摄影**：同位置改善前后对比照（看板公示——成就感驱动）;
- **稽核积分**：周度 5S 检查评分排名（与班组绩效挂钩——末位辅导非罚款）;
- **层别审核**：班组长日查/厂长周查/月度互查（分层保持压力）。

## 五、与验厂/客户的关系

- **验厂首因效应**：审核员进厂 10 分钟定印象（现场乱=管理体系问号——见 `suppliers/factory-audit-guide.md`）;
- **客户参观**：现场是最硬的名片（整洁产线=报价谈判加分——客户相信眼见）;
- **安全合规模块**：消防/通道/化学品定置（5S 是 BSCI/WRAP 安全项基础）。

## 六、效益量化

- **效率**：找物时间归零（工具/辅料定置——工位有效工时+5-10%）;
- **品质**：错用辅料/混款事故下降（目视防错）;
- **设备**：清扫点检=早期故障发现（机修成本下降）;
- **安全**：通道畅通+地面无油（工伤下降——保险费/赔偿连带效益）;
- **士气**：环境改善离职率下降（招工难时代的留人杠杆，见 `suppliers/worker-training-skill-matrix.md`）。

## 七、常见失败模式

- **运动式**：大搞三天后回潮（没有稽核制度支撑）;
- **形式化**：只搞卫生不搞定置（清扫≠整顿）;
- **基层抵触**：没有激励只考核（把 5S 做成福利——改善后员工自己受益）;
- **老板不带头**：管理层办公室最乱（上行下效——素养从管理层做起）。
