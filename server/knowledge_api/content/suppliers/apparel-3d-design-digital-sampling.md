# 3D 服装设计与数字样衣（CLO3D/Style3D: 减样衣成本/加速确认/数字资产）

3D 数字样衣用虚拟仿真替代部分实体样衣：版型/配色/印花位置/上身效果在软件中确认——**开发周期从 4-6 周压到 1-2 周，样衣费省 50-70%**。Zara/Shein 快反体系与头部品牌已规模化应用；外贸工厂的落地场景=**远程客户看样（视频 3D 旋转）+ 减少国际快递轮次 + 大货前版型预确认**。样品管理见 `trade-process/sample-room-management.md`。

## 一、软件格局

| 软件 | 背景 | 特点 |
|:---|:---|:---|
| CLO3D | 韩国 | 行业事实标准——设计师生态+渲染效果最强 |
| Style3D | 中国（凌迪） | 国产替代——供应链协同（面料数字化库）+价格优势 |
| Browzwear | 以色列 | 与版型 CAD（VStitcher）+生产数据流强 |
| Optitex | 以色列/被 EFI 收购 | 2D-3D 一体（打版师友好） |

- **输入**：版型 DXF/AAMA 文件（ET/富怡/度卡 CAD 导出）+ 面料物理参数（克重/厚度/弯曲刚度/拉伸率——**面料物理测试是仿真真实度的命门**）；
- **输出**：3D 样衣视频/图片（客户确认）、虚拟试衣（不同体型 avatar——尺码放码预览，见 `garments/pattern-grading-sizing.md`）、电商素材（3D 渲染图替代部分实拍，见 `trade-process/apparel-product-photography-visual.md`）。

## 二、工厂落地场景

1. **开发轮次压缩**：客户改配色/印花/细节——3D 即时呈现，实体样只做最终确认样（1 轮替代 3 轮）；
2. **远程看样**：3D 文件/视频发客户（屏幕共享旋转查看）——省国际快递（$50-100/次）与 5-7 天时间；
3. **版型预审**：虚拟缝合发现版型问题（起绺/不服帖）在打样前——版师+3D 师协同岗位出现；
4. **报价辅助**：3D 拆解工艺点（客户改设计即时评估工费变化——见 `garments/garment-costing-pricing.md`）；
5. **展销**：3D 数字展厅/虚拟时装秀——展会前发客户预选款，提高展会面谈效率（见 `trade-process/overseas-exhibition-playbook.md`）。

## 三、实施路径与成本

- **团队配置**：3D 设计师（懂版型+软件——薪资比平面设计师高 30-50%）或培训版师转型；起步 1-2 人试点；
- **面料数字化**：面料扫描仪（测物理参数）或送面料数字化服务商——**建立自己的 3D 面料库**是长期资产（大货面料参数实测入库）；
- **成本**：软件 license（CLO 约 $50-100/月/账号；Style3D 企业版按规模）+硬件（高配显卡工作站）+面料数字化（自扫设备 10 万+ 或外包 ¥30-80/款）；
- **与 AI 协同**：AI 生成设计稿→3D 打样呈现→客户确认——开发流再加速（见 `trade-process/ai-tools-foreign-trade.md`）；
- **局限诚实**：手感/悬垂微妙差异/面料光泽仍无法 100% 替代实体——**大货确认样实体件不可省**（3D 是过滤器不是终点）。

## 四、客户沟通要点

- **提案话术**：给客户算"样衣费+快递费+时间"三笔账——首单客户用 3D 降低其决策成本是获客差异化；
- **文件交付**：3D 源文件（.zprj）归属——合同明确（工厂数字资产，客户买服务不买源文件，除非约定）；
- **色差边界**：3D 渲染色≠实物色——标注"以实物为准"+实物色卡并行（见 `fabric/color-management-pantone-measurement.md`）。
