# 服装厂员工培训与多能工体系（Worker Training & Skill Matrix）

服装厂用工的本质矛盾：**熟练工越来越难招，订单却越来越小单快反**——多能工矩阵是解方（一人会 3 道工序，产线柔性翻倍）。

## 一、技能培训分级

| 等级 | 能力 | 培养周期 |
|:---|:---|:---|
| L1 新手工 | 单一简单工序（直线车缝） | 1-2 周 |
| L2 熟练工 | 独立保质完成本工序 | 1-3 个月 |
| L3 多能工 | 3+ 工序（跨机种） | 6-12 个月 |
| L4 全能工/样衣工 | 整件制作（见 `suppliers/pattern-sample-room-management.md`） | 2 年+ |
| L5 班组长 | 技术指导+产线管理 | 内部提拔 |

## 二、培训道场（training dojo）

- **独立培训区**：与产线隔离（10-20 工位——新员工先道场后上线）;
- **教具**：纸样练习（车直线/曲线/转角——不耗面料）→废布→实料;
- **标准课程**：7 天上手计划（D1-2 设备安全+直线/D3-4 曲线拼接/D5-7 工序实操）;
- **考核上岗**：技能鉴定（速度+质量双达标——未达标不接触大货）;
- **内训师**：L4/L5 担任（带教津贴——老带新绑定奖励）。

## 三、多能工技能矩阵（skill matrix）

- **矩阵表**：行=员工、列=工序、格=技能等级（0 不会/1 学习中/2 独立/3 可带教）;
- **覆盖率目标**：每工序至少 3 人会（含机动——请假/离职不断线）;
- **挂钩激励**：技能津贴（每多认证 1 工序 +50-100 元/月——比普涨工资精准）;
- **轮岗机制**：月度轮岗（保持多能——久不做生疏，也防职业疲劳）;
- **快反价值**：换款时产线重排灵活（IE 排车不受人手限制——见 `suppliers/garment-ie-engineering.md`）。

## 四、招聘与留任

- **招工渠道**：内地劳务对接（县职校合作——定向培养）/老员工返厂（返厂奖）;
- **95 后/00 后管理**：环境（空调车间/宿舍 WiFi）>单纯加薪（离职主因调研：辛苦单调+管理粗暴）;
- **留任杠杆**：计件透明（工资 APP 可查——纠纷是离职第一推手）+技能成长通道+工龄奖;
- **淡旺季**：旺季临时工（学生工/共享员工）+淡季保底轮休（放长假流失率 60%+）。

## 五、班组建设

- **班组长是基石**：技术+管理双能（从 L4 提拔——管理能力培训外训）;
- **日会制度**：产量/质量/问题 5 分钟站会;
- **改善提案**：一线提案奖励（月评——小改善大奖赏，精益文化见 `suppliers/garment-factory-lean-production.md`）;
- **技能比武**：季度比赛（速度+质量——荣誉感+发现高手）。

## 六、与验厂/客户的关系

- **验厂培训记录**：BSCI/WRAP 查培训档案（入职/消防/化学品——见 `suppliers/factory-audit-guide.md`）;
- **客户审厂看点**：培训道场是加分项（快反承诺的可信证据）;
- **社会责任**：未成年工保护（16-18 岁工种/工时限制——童工红线零容忍）。

## 七、成本账

- **培训成本**：新员工 7 天产能损失+带教（约 500-1000 元/人）;
- **回报**：合格工人月产值 8000-15000 元（培训是最划算投资——招工难环境下留存>招聘）;
- **流失成本**：熟练工流失=3 个月产能+品质波动（招聘+培训+爬坡综合 5000 元/人）。
