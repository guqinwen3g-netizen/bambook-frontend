# 服装 ERP 与数字化管理（Garment ERP & Digitalization）

服装厂数字化的价值排序：**工单进度透明 > 计件工资自动化 > 面辅料库存准确 > 数据分析**——多数工厂失败在跳过基础数据直接上系统。

## 一、系统分层

| 层级 | 系统 | 功能 |
|:---|:---|:---|
| 决策层 | BI 报表 | 订单毛利/交期达成/工厂效率看板 |
| 管理层 | ERP（企业资源计划） | 订单/BOM/采购/库存/财务/成本 |
| 执行层 | MES（制造执行系统） | 工单派工/进度采集/品质记录/计件 |
| 设备层 | 吊挂系统/裁床/模板机 | 硬件数据回传（吊挂自带工位采集） |

## 二、服装 ERP 核心模块

- **订单管理**：客户 PO→工厂工单（款号/颜色/尺码矩阵——服装特有的 SKU 结构）;
- **BOM 与用量**：面料单耗+辅料清单（与 IE 的 SAM 联动算工费——见 `suppliers/garment-ie-engineering.md`）;
- **采购与库存**：面辅料入库/领用/退料（**齐套检查**——到料不齐不开工，见 `suppliers/incoming-material-inspection.md`）;
- **生产进度**：裁剪→缝制→后整→包装各段日报（交期预警——见 `trade-process/order-delivery-kpi.md`）;
- **财务成本**：工单成本归集（面料+工费+制造费用——单款毛利分析）。

## 三、MES 与数据采集

- **采集方式**：
  - **RFID/条码工票**：捆扎流（每扎一票——扫码报工）;
  - **吊挂系统**：单件流自动采集（衣架芯片——实时工位数据，见 `suppliers/garment-factory-lean-production.md`）;
  - **平板报工**：工位触屏（适合大单长工序）;
- **计件工资**：报工数据自动算工资（纠纷减少——工人 APP 查明细是信任建设）;
- **品质数据**：中查/尾查不良录入（按工序归因——前道改善）。

## 四、实施失败的高发原因

- **基础数据缺失**：款号/SAM/物料编码没建好就上系统（垃圾进垃圾出——先标准化再数字化）;
- **管理层不坚持**：报工漏报不追责（数据失真后全厂不信系统——回到纸质）;
- **贪大求全**：一次上全模块（建议路径：工单进度→计件工资→库存→财务，逐模块站稳）;
- **忽视一线**：界面复杂工人抵触（扫码报工必须 3 步内完成）。

## 五、选型参考

- **规模匹配**：100 人以下轻量 SaaS（按年付费）/300 人+ 可考虑行业版（富怡/秒优/智布互联等垂直方案）;
- **关键考察**：服装行业适配度（款色码矩阵/SAM 计件/面辅料齐套是通用 ERP 短板）;
- **集成**：与吊挂/裁床数据对接能力（开放 API）;
- **外贸扩展**：英文界面/多币种/报关数据导出（外贸厂刚需）。

## 六、数字化的外贸价值

- **验厂加分**：品牌验厂看实时数据能力（进度透明=交付可信——见 `suppliers/factory-audit-guide.md`）;
- **快反基础**：进度实时可见才敢接小单快反（黑箱工厂不敢承诺 7 天翻单）;
- **客户协同**：大客户要求开放进度端口（ERP 对接客户系统——粘性壁垒）;
- **报价提速**：BOM+SAM 数据库支撑 24 小时报价（快反核心竞争力）。

## 七、落地路线图

- **第一步（标准化）**：款号编码规则/SAM 库/物料编码——3 个月基础工程;
- **第二步（进度+计件）**：报工采集上线（见效最快——工资纠纷立减）;
- **第三步（库存采购）**：面辅料账实一致（齐套管理）;
- **第四步（数据分析）**：效率/毛利/交期看板（管理驾驶舱）。
