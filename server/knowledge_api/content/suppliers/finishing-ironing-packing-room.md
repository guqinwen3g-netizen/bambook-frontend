# 后整理与包装车间管理（Finishing, Ironing & Packing Room）

后道（finishing）是"**出厂前最后一道工序**"：整烫定型、线头清理、验针、包装——这里出的错直接到客户手里。

## 一、后道流程

```
缝制半成品 → 初检 → 剪线头 → 整烫 → 终检 → 验针 → 包装 → 装箱 → 出货
```

## 二、关键环节

### 1. 剪线头（thread trimming）
- **线头**：缝制残留线头（客户最直观的"廉价感"——线头多=品质差的第一印象）;
- **管理**：专人剪线/剪线机——线头率纳入后道考核。

### 2. 整烫（pressing/ironing）
- **作用**：定型（成衣"型"来自整烫——三分缝七分烫）；
- **设备**：蒸汽烫台/定型机（西装整烫是工艺——见 `garments/suits-tailoring-production.md`）；
- **风险**：**烫黄/烫焦/极光**（浅色面料高温——温度控制+垫布）；
- **倒顺毛面料**：蒸汽吊烫（不可重压——见 `fabric/velvet-faux-fur-fabrics.md`）。

### 3. 终检（final inspection）
- **全检 vs 抽检**：高端/童装全检；常规按 AQL（见 `suppliers/supplier-quality-management.md`）；
- **检验项目**：尺寸/外观/缝制/辅料/色差/污迹——对照确认样。

### 4. 验针（needle detection）
- **验针机**：过机检测断针/金属残留（童装强制——见 `garments/childrenswear-production.md`）；
- **管理**：验针记录+验针机灵敏度每日校准（标准测试卡）。

### 5. 包装（packing）
- 见 `garments/garment-packaging.md`——折叠/胶袋/唛头/装箱。

## 三、后道质量事故

| 事故 | 后果 |
|:---|:---|
| 线头残留多 | 客户观感差/退货 |
| 烫黄烫焦 | 直接报废（不可修复） |
| 极光（shine mark） | 深色面料烫痕——品质投诉 |
| 漏验针 | 断针流出（安全事故/召回） |
| 包装错 | 尺码混装/唛头错（清关/销售问题） |
| 装箱错 | 数量短装（短装索赔） |

## 四、后道管理要点

| 项目 | 说明 |
|:---|:---|
| 温度管理 | 烫台温度按面料设定（面料温度表——浅色低温） |
| 线头标准 | 线头长度<3mm（目视标准——样照） |
| 验针纪律 | 童装 100% 过机+记录（客户验厂查记录） |
| 包装核对 | 装箱前核对（款号/尺码/数量/唛头——四人眼原则） |
| 成品仓 | 成品防护（防潮防尘——出货前状态） |

## 五、效率与人员

- **后道人效**：整烫/包装计件（效率管理）；
- **后道瓶颈**：旺季后道积压（前道快后道慢——后道产能规划）；
- **临时工**：旺季临时包装工（培训+质量风险——新人贴错标）。

## 六、验厂视角

- **验针区**（验针机+记录+校准卡——童装客户必查）；
- **整烫区**（温度管理/烫黄痕迹）；
- **包装区**（装箱核对流程）；
- **成品仓**（防潮/防虫——成品保护）。
