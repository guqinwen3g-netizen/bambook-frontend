# 反恐验厂与供应链安全（C-TPAT/GSV/SCAN: 美国订单准入）

反恐验厂（security audit）是美国订单的**第三道验厂门槛**（社会责任+质量+安全三件套）：911 后美国海关建立 C-TPAT 自愿认证体系，进口商将安全要求传导给供应商。Walmart/Target/Disney 等美国大客户**反恐验厂不过=不得出货**（装柜封锁/铅封管理是核心）。与社会责任验厂（见 `suppliers/factory-audit-guide.md`）并行，本文聚焦安全专项。

## 一、三大体系对照

| 体系 | 发起方 | 特点 |
|:---|:---|:---|
| C-TPAT | 美国海关 CBP | 官方自愿认证（进口商持证——供应商配合满足最低安全标准 MSC） |
| GSV | Intertek | 第三方审核商业化（Walmart 历史体系） |
| SCAN | 零售商联盟 | 统一报告多客户共享（Target/Costco 等——**一次审核多方认可**，趋势主流） |

- **审核频率**：年度；**分数制**（SCAN 76 分合格线逻辑——关键项零容忍）；
- **与其他验厂关系**：社会责任（BSCI/SMETA）+质量（QMS）+反恐（SCAN）=美国大 B 三证；部分客户打包一次审完。

## 二、审核核心模块（实体安全+程序安全）

- **实体安全**：
  - 围墙/大门管控（访客登记+车辆检查——进出记录）；
  - **成品仓/装柜区隔离**（授权人员进出名单+监控覆盖——重点区域）；
  - 监控（CCTV 30-90 天存储——关键区域无死角：大门/装卸区/成品仓）；
  - 照明（周界夜间照明）；钥匙管理（发放台账）。
- **程序安全**：
  - **集装箱检查七点法**（装柜前检查：前壁/左侧/右侧/地板/顶部/内外门/底盘——检查记录表签字）；
  - **铅封管理**：ISO 17712 高保铅封（封条台账——领取/使用/剩余核对；装柜后封条号记录与提单一致）；
  - 装柜监督（授权监装员——装柜过程拍照留档）；
  - **人员安全**：员工背景调查（入职审查——身份证核验/无犯罪记录范围）；离职管控（证件收回/权限注销）；
  - 访客/供应商管控（陪同制度）；
  - 邮件/包裹安检（收发室检查程序）。
- **IT 安全**：系统账号权限/密码策略（订单数据防篡改——SCAN 新版强化）；
- **运输安全**：货代/车队管控（运输途中封条完整性——封条异常开箱报告程序）。

## 三、常见失分点与整改

| 失分点 | 整改 |
|:---|:---|
| 监控存储不足 30 天 | 扩容硬盘/NVR 设置核对 |
| 铅封无台账/抽屉混放 | 专柜上锁+领用登记 |
| 装柜区人员随意进出 | 门禁/授权名单上墙 |
| 围墙缺口/攀爬点 | 物理封堵+巡逻记录 |
| 员工背景调查缺失 | 入职 SOP 增加审查项 |
| 集装箱七点检查无记录 | 装柜前检查表强制执行 |

- **零容忍项**：**封条失控/装柜区失控/监控失效**——任一关键项不合格=整体不通过（无分数补救）；
- **整改周期**：初审→CAP（整改计划）30-90 天→复审；复审不过=客户暂停新订单。

## 四、成本与接单联动

- **投入**：监控扩容/门禁/铅封柜——¥2-10 万级（一次性）；审核费 $800-1500/次（客户指定机构）；
- **接单联动**：美国商超/品牌（Walmart RS+SCAN 组合——见 `customers-market/big-box-retail-channel.md`）**报价单注明"SCAN audited"=信任加分**；
- **维护**：月自查（保安巡逻记录/监控抽查/封条盘点——内审表）；保安培训（外包保安公司资质审核）；
- **误区**：只做文件不做执行（审核员调监控录像核对记录真实性——造假=黑名单）；
- **联动文档**：装柜防潮与封条实务（见 `garments/garment-packaging.md`）；海运封条与提单（见 `trade-process/sea-freight-practice.md`）。
