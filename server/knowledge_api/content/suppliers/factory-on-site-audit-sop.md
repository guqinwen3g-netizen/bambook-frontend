# 成衣厂现场审核 SOP（Factory On-site Audit SOP）

本文是采购方**自主审核**成衣厂的操作手册（区别于第三方认证审核——认证体系见 `suppliers/factory-audit-guide.md`）。目的：签约前核实工厂真实能力，识别风险。

## 一、审核前准备

- **资料预审**：营业执照、环评（有洗水/印花工序的）、既往验厂报告、主要客户清单（验证——可要求提供合作证明）；
- **审核清单**：按本文表格打印打分表；
- **同行人员**：QC + 跟单主管（技术+管理双视角）；
- **不通知审核（unannounced）**：常规合作前审核可预约；**复查或疑虑审核建议突击**（预约审核看到的都是准备好的）。

## 二、现场审核路线（按动线）

```
原料仓 → 裁剪车间 → 缝制车间 → 后整（整烫/包装）→ 成品仓
→ 品控室/实验室 → 宿舍/食堂（社会责任）→ 消防/安全
```

### 1. 原料仓
- 面料堆放（垫板离地、防潮）、缸号管理（追溯）；
- 辅料仓：拉链/扣件分类；检针机旁断针记录本（童装有针管理）。

### 2. 裁剪车间
- 裁床数量与类型（自动裁床 vs 手工电剪）；
- 拉布机/铺布松量控制（弹力面料）；
- 裁片捆扎标识（扎号票——色差管理）。

### 3. 缝制车间（核心）
- **设备清单**：平车/包缝/绷缝/套结/锁眼钉扣机数量与品牌（Juki/Brother vs 杂牌——设备档次反映投入意愿）；
- **产线布局**：单件流（吊挂系统=现代化）vs 捆包流；
- **在制品（WIP）量**：堆积如山=排产混乱；
- **车位密度与照明**（500 lux 以上）；
- **现场品质**：随机抽 3 件半成品看线迹/缝位——线头控制反映管理水平。

### 4. 后整车间
- 整烫设备（蒸汽锅炉/烫台）；包装区整洁度；
- 检针机（日本单必备）与检针记录。

### 5. 品控室
- 检测设备：摩擦色牢度仪/拉力机/起球仪/灯箱（D65 光源）；
- **检测记录**：随机调阅最近 3 批的巡检/终检报告——有没有、是不是后补的；
- QC 人数比例（QC:车位 ≥ 1:15 为佳）。

### 6. 产能核实
- **车位数 × 开工率**核实理论产能（见 `suppliers/production-capacity-scheduling.md` SMV 法）；
- 电费单/考勤记录侧面验证开工率（申报产能 vs 实际）。

### 7. 社会责任与安全
- 消防通道/灭火器/应急灯（堵塞=重大隐患）；
- 宿舍食堂（如提供）；考勤工资记录抽查（工时真实性）；
- 特种设备操作证（锅炉/电梯）。

## 三、评分表（示例权重）

| 维度 | 权重 | 关键项 |
|:---|:---|:---|
| 品质体系 | 30% | 检测设备/记录/QC 配置/现场品质 |
| 产能与设备 | 25% | 设备档次/产线布局/产能真实性 |
| 管理与交付 | 20% | WIP 控制/排产看板/交期记录 |
| 社会责任 | 15% | 消防/工时/宿舍食堂 |
| 商务条件 | 10% | 价格/账期/配合度 |

- **≥80 分**：优先合作；**60-80 分**：整改后小单试用；**<60 分**：淘汰。

## 四、红旗项（一票否决或重大扣分）

1. 消防通道锁闭/严重堵塞；
2. 无证锅炉/特种设备；
3. 明显使用童工；
4. 检测记录造假（批量后补笔迹）；
5. 环保工序（洗水/印花）无环评；
6. 实际为"皮包"厂（无设备纯外发——见 `suppliers/subcontracting-outsourcing-management.md`）。

## 五、审核后行动

- 24 小时内出审核报告（照片+评分+整改项）；
- 整改项限期（30 天）+ 复查安排；
- 纳入 AVL 名录并分级（见 `suppliers/fabric-accessories-supplier-management.md`）。
