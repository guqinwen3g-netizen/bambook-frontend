# 印染环保治理与合规（Dyeing Wastewater: 污水处理/中水回用/排污许可/园区化）

印染是纺织链**环保风险最集中**的环节：高耗水（每吨布 80-150 吨水）、高污染（COD/色度/盐分/锑）、高能耗。环保政策直接决定染厂产能（关停/限产=供应链断点）——采购方必须理解染厂环保资质与风险。化学品合规见 `trade-compliance/chemical-environmental-compliance.md`，染厂协作见 `suppliers/dyeing-mill-cooperation-management.md`。

## 一、污染物谱与治理技术

| 污染源 | 成分 | 治理工艺 |
|:---|:---|:---|
| 退浆/煮练废水 | 高 COD（PVA/淀粉浆料）、强碱 | 厌氧+好氧生化（主体工艺） |
| 染色废水 | 色度、残余染料、盐分（元明粉） | 脱色（混凝/高级氧化）+生化；**盐分是回用瓶颈**（反渗透膜法） |
| 印花废水 | 糊料、尿素 | 同上 |
| 锑（涤纶催化剂残留） | 重金属 | 专门去除（限值 0.1mg/L 级别——江浙地标严） |
| 定型机废气 | 油烟/颗粒物/VOCs | 静电除油+余热回收 |
| 污泥 | 染料残渣 | 危废鉴别（部分属危废——处置成本高） |

- **中水回用率**：先进染厂回用 40-60%（膜处理）——回用水质影响染色重现性（工艺匹配）；
- **定形机余热回收**：节能即省钱（蒸汽成本占染费 20-30%）。

## 二、合规框架（中国）

- **排污许可证**：印染属重点管理——许可证载明排放口/浓度/总量；**无证或超许可排放=停产/刑责**；
- **入园入区**：新上印染产能强制进园区（集中供热/污水厂）——**园外存量染厂是搬迁关停高风险对象**（供应商评估要点，见 `suppliers/fabric-mill-evaluation.md`）；
- **清洁生产审核**：重点企业强制——单位产品取水量/综合能耗对标基准值；
- **排污权交易**：浙江等地试点——新增产能需购买排污指标（推高进入门槛，存量指标成资产）；
- **环保督察常态**：中央环保督察+错峰生产——**旺季限产是交期风险**（跟单需知，见 `suppliers/production-capacity-scheduling.md`）。

## 三、品牌端要求（出口订单传导）

- **ZDHC 网关**：品牌要求染厂上传废水测试报告（ZDHC Wastewater Guidelines——常规参数+MRSL 物质）至 ZDHC Gateway 平台——**detox 承诺品牌（Inditex/H&M/Nike 等 100+）强制**；
- **Higg FEM**：环境模块年审（用水/能耗/废水/废气/化学品管理打分）——品牌供应商记分卡（见 `customers-market/brand-retailer-supplier-systems.md`）；
- **Bluesign/OEKO-TEX STeP**：体系认证（见 `trade-compliance/textile-certifications.md`）；
- **数据透明度趋势**：品牌 ESG 报告要求供应链环境数据（见 `trade-compliance/esg-csrd-sustainability.md`）——染厂数据能力（在线监测/台账）成为接单竞争力。

## 四、供应链风险管理（采购视角）

1. **染厂环保尽调**：排污许可证查验（全国排污许可平台公开可查）+园区属性+近三年环保处罚记录（信用中国/地方环保局公示）+ZDHC/Higg 状态；
2. **双染厂策略**：主力+备份染厂（环保停产时的切换能力——同一颜色两厂对色管理，见 `fabric/color-management-pantone-measurement.md`）；
3. **交期缓冲**：环保督察季（通常秋冬季+重大活动保障期）预留 1-2 周缓冲；
4. **成本传导**：环保成本上升是染费长期上涨动因——大单锁价考虑环保加码风险（见 `fabric/dyestuffs-auxiliaries-trade.md`）；
5. **绿色溢价机会**：有 ZDHC Level 3/Bluesign 体系的染厂稀缺——**环保资质本身就是订单入口**（品牌可持续系列指定）。
