# 面辅料仓库管理（Material Warehouse Management）

面辅料占服装成本 60%+：仓库管不好就是"**利润漏勺**"——账实不符、错发漏发、面料霉变、呆料积压都是钱。

## 一、仓库分区

| 区域 | 功能 |
|:---|:---|
| 待检区 | 到货暂存（IQC 检验前隔离——防止未检面料上线，见 `suppliers/incoming-material-inspection.md`） |
| 合格品区 | 面料架（卷装立式/平铺）+辅料货架（分格盒） |
| 不良品区 | 红色标识隔离（退供应商/降级处理——不入账混放是账实不符之源） |
| 裁配区/发料区 | 按工单配套待发（齐套区） |
| 成品区 | 与面料物理分隔 |
| 呆料区 | 超 6 个月未动料（单独管理——定期处理评审） |

## 二、入库管理

- **验收流程**：送货单→点数/量米（抽验比例：面料每批抽 10% 验米数——短码是行业潜规则）→IQC→入账;
- **面料短码防控**：供应商短码 2-5% 常态（验布机复码——合同短码赔付条款）;
- **标识**：物料卡（款号/缸号/数量/入库日期——缸号管理是色差追溯关键）;
- **上架**：按品类+款号定位（库位编码——找料时间归零）。

## 三、存储养护

- **面料存放**：卷装立放/架放（堆高压皱——真丝/针织忌重压）;
- **防潮**：湿度 50-70%（南方梅雨季除湿机——棉麻霉变高发，垫板离地 20cm）;
- **防虫**：毛料/真丝防虫（樟木/防虫剂注意气味残留——高端面料定期通风）;
- **防火**：仓库是消防重点（灯距/堆距——见 `suppliers/factory-safety-fire-management.md`）;
- **光照**：避免阳光直射（变色——窗帘/苫布）。

## 四、发料管理（成本闸门）

- **按单发料**：裁剪计划单→仓库配套（齐套检查——缺料不投产）;
- **先进先出（FIFO）**：缸号批次先入库先发（防呆料+防色差：同单面料用同缸）;
- **超耗管控**：定额发料（单耗×数量+损耗率——超领审批单，IE 核定单耗，见 `suppliers/garment-ie-engineering.md`）;
- **退料**：剩余面料当日退库（车间滞留=丢失/账外——月底盘亏的隐形来源）;
- **辅料包**：小辅料按单分包（扣子/主标按 100 件/包——车间零配发错误）。

## 五、盘点与账实

- **周期盘点**：A 类高值料（真丝/羊绒）月盘/B 类季盘/C 类辅料抽盘（不等年终大盘）;
- **账实差异率**：目标 <1%（差异必查——偷盗/短码/发料错误归因）;
- **ERP 账**：实时出入库（见 `suppliers/garment-erp-digitalization.md`——手工台账延迟是差异温床）;
- **呆料处理**：季度评审（转售面料市场/改做其他款/折价处理——见 `fabric/fabric-inventory-stock-strategy.md`）。

## 六、数据指标

- **库存周转**：面料库存 30-45 天健康（超过=资金占用+呆料风险）;
- **齐套率**：到货齐套及时率（影响开工——采购协同指标）;
- **短码追回率**：供应商短码赔付执行;
- **发料准确率**：错发漏发次数（目标 0——错发面料=批量事故）。

## 七、常见漏洞与对策

| 漏洞 | 对策 |
|:---|:---|
| 面料短码 | 复码机抽验+合同赔付条款 |
| 缸差混用 | 缸号标识+裁剪单指定缸号 |
| 账外余料 | 退料制度+车间余料日清 |
| 呆料遗忘 | ERP 库龄报表+季度评审 |
| 内盗 | 高值料专柜+双人收发+监控 |
