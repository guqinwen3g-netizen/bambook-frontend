# 服装厂精益生产基础（Lean Production in Garment Factory）

精益（lean）在服装厂的核心是**单件流（one-piece flow）+ 产线平衡**：消除在制品堆积、缩短生产周期、快速暴露问题。理解精益才能评估供应商的真实产能与交期承诺。

## 一、服装生产的七大浪费

| 浪费 | 服装厂表现 |
|:---|:---|
| 等待 | 车等料（裁片供应不上）/人等衣（瓶颈工序前堆积） |
| 搬运 | 裁片包往返搬运（裁床→车缝→后整动线乱） |
| 库存 | 在制品（WIP）堆积如山——藏住所有问题 |
| 过量生产 | 前一工序拼命做（后工序消化不了） |
| 返工 | 质量问题后道返修（线头/跳针返工区） |
| 动作 | 车工取放裁片动作浪费（裁片摆放不合理） |
| 工序冗余 | 不必要的整烫/检验重复 |

## 二、单件流 vs 捆包流

| 模式 | 说明 |
|:---|:---|
| 捆包流（bundle system） | 裁片打捆（20-30 件/捆）工序间传递——传统模式；WIP 高、周期 3-5 天、问题滞后暴露 |
| **单件流（OPS）** | 一件一件流——裁片从裁床到成品不落地；周期缩短至 2-4 小时、问题即时暴露、品质责任到人 |
| **吊挂系统（hanger system）** | 单件流的自动化载体——衣片挂吊架自动传输（JIT 物流） |

- **单件流前提**：工序平衡（节拍一致）+ 质量稳定（不能边做边修）+ 多能工（一人多工序）。

## 三、产线平衡（Line Balancing）

### 基本概念
- **节拍（takt time）** = 可用工时 ÷ 目标产量——日产 1000 件/8h = 28.8 秒/件；
- **瓶颈（bottleneck）**：最慢工序决定整条线产能（见 `suppliers/production-capacity-scheduling.md`）；
- **平衡率** = 各工序工时和 ÷（瓶颈工时 × 工位数）——目标 85%+。

### 平衡方法
1. **工序拆分/合并**：长工序拆分（如"上领"拆为"上领面+修领+压领线"）；
2. **增援瓶颈**：瓶颈工序加人/加机；
3. **多能工调配**：IE 实时观察——堆积处即瓶颈，立即支援；
4. **编排表（operation bulletin）**：每款上线前做工序编排（SMV 分配工位）。

## 四、IE 工程师（Industrial Engineer）职能

- **GSD/SMV 测定**：标准工时数据库（款式工时核算）；
- **产线编排**：新款上线的工位设计与人员配置；
- **效率监控**：学习曲线（新款式效率爬坡——第 1 天 40% → 第 5 天 80%+）；
- **改善提案**：模板/夹具改良（口袋模板/拉筒——把技术活变傻瓜活）。

## 五、快速换款（SMED 在服装的应用）

- **换款时间**：老款清线→新款上线的转换（传统 2-4 小时——目标 30 分钟内）；
- **方法**：产前准备充分（裁片/辅料/设备/工艺单齐套才上线）；小批量流（首件确认后立即全线）；
- **小单快反的工厂能力**：换款速度决定小单成本（见 `customers-market/fast-fashion-shein-model.md`）。

## 六、可视化管理

- **生产看板**：线头电子屏（目标产量/实际产量/效率——实时差距可视）；
- **小时产量**：按小时追踪（不是按天——问题当班解决）；
- **品质看板**：不良类型帕累托图（80% 问题集中 2-3 类）。

## 七、验厂视角（买家看什么）

| 精益信号 | 解读 |
|:---|:---|
| WIP 堆积少 | 产线平衡好——交期可信 |
| 吊挂系统 | 硬件投入（管理意识） |
| 看板实时数据 | 管理颗粒度 |
| 多能工比例 | 柔性（应对请假/波动） |
| 车间地面标线 | 5S 基础（通道/物料区/半成品区） |

- **精益不是设备是管理**：同样设备的两家厂效率可差 30%——验厂看 WIP 和看板比看设备更准（见 `suppliers/factory-on-site-audit-sop.md`）。
