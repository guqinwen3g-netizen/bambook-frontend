# 缝纫线与机针专题（Sewing Thread & Needles）

缝纫线与机针是"**最小的辅料，最大的质量杠杆**"：一根线一根针的选错，整批货跳针/断线/针洞。

## 一、缝纫线

### 品类
| 线 | 特性 | 应用 |
|:---|:---|:---|
| 涤纶短纤线（SP线） | 性价比主力 | 常规服装 |
| 涤纶长丝线 | 强度高、毛羽少 | 高端衬衫/西装 |
| 包芯线（core-spun） | 涤纶芯+棉包覆（强度+耐热） | 高速缝制/牛仔 |
| 锦纶线 | 弹性好 | 针织/弹力面料 |
| 棉线 | 天然、耐热（熨烫） | 高端棉服/绣花底线 |
| 绣花线 | 人造丝/涤纶（光泽） | 绣花（见 `garments/printing-embroidery.md`） |
| 防水线/阻燃线 | 功能线 | 户外/工装 |

### 规格（tex / ticket number）
- **常用号数**：402（40 英支 2 股——T 恤/衬衫主力）/ 202（粗——牛仔/厚料）/ 603（细——真丝/雪纺）；
- **tex 制**：tex 24 ≈ 402——规格换算见供应商资料；
- **颜色**：对色（潘通色卡/布样对色——线色与面料匹配）。

### 品质要点
- **强力**：断裂强度（不断线——高速机缝制考验）；
- **毛羽**：毛羽少（堵针孔/起球）；
- **润滑**：硅油润滑处理（缝制顺畅）；
- **色牢度**：线的色牢度（深色线掉色染面料）。

## 二、机针

### 规格体系
- **号数（Nm）**：针粗细（9/11/14/16/18——数字越大越粗）；雪纺 9-11 号 / 常规 14 号 / 牛仔 16-18 号；
- **针尖形状**：

| 针尖 | 适用 |
|:---|:---|
| 尖针（sharp/R point） | 梭织面料（穿透经纬纱） |
| 圆头针（ball point/SES） | **针织面料必用**——推开纱线不戳断（防针洞/抽丝） |
| 特细圆头（light ball） | 细针织/弹力 |
| 皮革针（leather/LR point） | 皮革/涂层 |

### 常见缝制问题与针的关系

| 问题 | 原因 |
|:---|:---|
| 跳针 | 针弯/针号不对/针与旋梭配合 |
| 断线 | 针孔毛糙/线张力过紧/针过热 |
| 针洞（针织） | 用了尖针（应圆头）/针号过大 |
| 抽丝 | 针尖毛刺/针钝 |
| 缝皱 | 针过粗/送布牙压力不当 |

### 换针纪律
- **定期换针**：机针 4-8 小时更换（针尖磨损是渐进的——等断线才换已出批量问题）；
- **断针管理**：断针必须找齐碎片（见 `garments/childrenswear-production.md` 检针——断针残留是安全事故）。

## 三、针距（stitch density）

| 品类 | 针距（针/cm） |
|:---|:---|
| 常规梭织 | 4-5 针/cm |
| 高档衬衫 | 6-7 针/cm（细密是高端感） |
| 针织 | 3-4 针/cm（防断纱） |
| 牛仔明线 | 3-4 针/cm（粗线大针距风格） |
| 锁眼/套结 | 密针距 |

- **针距影响**：过密（面料起皱/强度下降）/过稀（缝线不牢）——按面料与工艺单设定。

## 四、品牌与采购

- **缝纫线**：高士（Coats——全球第一）/A&E/金泰/敦煌——品牌线品质稳定（断头率低=省工时）；
- **机针**：德国蓝狮（Groz-Beckert）/日本风琴（Organ）/国产飞虎——进口针精度高（针织面料建议进口针）；
- **成本**：线是辅料小项（一件 T 恤线成本 ¥0.1-0.3）——**省线钱省出质量事故最不划算**。
