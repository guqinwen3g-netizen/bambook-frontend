# 服装辅料专题（Garment Accessories & Trims）

辅料（trims/accessories）单件价值虽小，却是验货客诉与交期延误的高发区。一条错版织带、一批色差纽扣都可能导致整批返工。辅料管理核心：**确认样先行、供应商锁定、产前全数备齐**。

## 一、拉链（Zipper）

### 材质分类
| 类型 | 特点 | 用途 |
|:---|:---|:---|
| 尼龙拉链（nylon/coil） | 轻、软、便宜 | 裤装、裙、箱包 |
| 树脂拉链（vislon/delrin） | 齿粒感、耐用 | 外套、运动服、童装 |
| 金属拉链（metal） | 铜/铝/白铜，质感 | 牛仔、皮衣、高档外套 |
| 隐形拉链（invisible） | 齿藏布后 | 连衣裙、裙装侧缝 |

### 规格与品牌
- 号数：#3、#5、#8、#10（齿宽 mm），服装常用 #3/#5。
- **YKK**（日本）：全球第一品牌，客户指定率最高，价格比国产高 30-50%。
- **SBS（浔兴）/SAB（伟星）/YCC**：国产主流，性价比替代。
- 关键动作：**拉头（slider）与布带（tape）对色**——按布色卡或潘通号定染布带；客户指定品牌时合同写明"YKK genuine"。

## 二、纽扣（Button）

- **材质**：树脂（polyester，最常用）、贝壳（shell，高档衬衫）、金属（jeans button 工字扣）、尿素（urea，耐高温熨烫）、木头/椰子（自然风）。
- **规格**：以 ligne（L）计，18L=11mm 直径；衬衫常用 18L-24L。
- **固定方式**：四眼/两眼手缝扣、包布扣（covered）、按扣（snap/press stud，四合扣）、风纪扣（hook & bar）。
- **风险点**：重金属（镍释放，欧盟 REACH）、童装小部件拉力（90N 测试）、游离甲醛。

## 三、织带与绳类（Webbing & Cord）

- **织带**：平纹/斜纹/提花织带，棉/涤/尼龙/PP 材质；用于腰带、包边、装饰。
- **罗纹带（grosgrain）**：横纹带，腰头衬、装饰。
- **松紧带（elastic）**：编织/针织/丝光松紧，注意缩水率与疲劳测试。
- **帽绳/裤绳（drawcord）**：童装受限（美标 ASTM F1816，见 `trade-compliance/cpsc-children-safety.md`）。
- **印字/提花 logo 带**：定制周期 15-25 天，MOQ 通常 3000-5000 米。

## 四、衬布（Interlining）

- **粘合衬（fusible）**：无纺/有纺/针织衬，按克重（20-75g）与胶点（PA/PES）选型。
- 用途：领口、袖口、门襟、腰头定型。
- **风险**：剥离强度不足（起泡）、渗胶（strike through）、耐洗性——产前做粘合测试（熨温/压力/时间三要素）。

## 五、商标与吊牌（Labels）

| 类型 | 说明 | MOQ/周期 |
|:---|:---|:---|
| 织唛（woven label） | 主唛/尺码唛，高密度织标质感好 | 3000 枚起，10-15 天 |
| 印唛（printed label） | 洗水唛/成分唛，缎带/尼龙/棉带 | 1000 枚起，7-10 天 |
| 吊牌（hangtag） | 铜版纸/特种纸 + 穿绳 | 1000 套起 |
| 皮标（leather patch） | 真皮/PU，牛仔后腰标配 | 500 枚起 |
| 热转印标（heat transfer label） | 无感标签，内衣/运动服替代织唛 | 1000 枚起 |

- 洗水唛内容：成分 + 洗护符号 + 原产国 + 客户注册号（如美国 RN）。
- **欧盟多语言、日本 JIS 符号**必须按目的国要求制版（见各市场文档）。

## 六、缝纫线（Sewing Thread）

- **涤纶线（polyester）**：通用主力，40/2、40/3 支。
- **包芯线（core-spun）**：涤包棉/涤包涤，高速缝纫不断线，牛仔/厚料用。
- **高士（Coats）/A&E/柳青**：品牌线色牢度与强力稳定；对色按线色卡。
- 线色匹配原则：配色缝线（matching）或对色效果线（contrast stitching，需客户确认）。

## 七、辅料采购管理

1. **确认样制度**：所有辅料产前寄样客户确认（trims card 辅料卡签样），大货照样验收。
2. **交期倒排**：定制类辅料（织唛 15 天、拉链定染 20 天）交期长于面料备料，下单首日即采购。
3. **备损率**：辅料按订单量 102-103% 采购（缝制损耗），贵价辅料（YKK 拉链）按实需+1%。
4. **环保合规**：欧盟订单辅料也要过 REACH/OEKO-TEX——纽扣镍释放、织带偶氮、PVC 胶章邻苯。
5. **供应商池**：广州中大/义乌辅料市场现货 + 定制厂家双轨（见 `suppliers/fabric-market-sourcing.md`）。

## 八、来料检验与配伍测试

- **IQC 抽检**：辅料到货按 AQL 4.0 抽检（见 `trade-process/pre-shipment-inspection-sop.md`）：拉链拉合/纽扣色差/织唛文字——**文字错误是灾难**（出货前逐字核对）；
- **配伍测试**：辅料与面料水洗互染（浅色面料+深色拉链）；金属辅料盐水防锈测试（泳装/户外单）；
- **合规文件**：镍释放报告（金属件欧盟 REACH）/邻苯报告（PVC 胶章）/OEKO-TEX（婴幼单要求）。

## 九、成本与产业带

- **成本占比**：基础款辅料占 5-8%；功能款（冲锋衣防水拉链+多扣件）可达 15%+；
- **报价要点**：客户是否指定 YKK 差价大单显著——报价前问清拉链品牌要求；
- **账期**：辅料厂月结 30 天常态（优于面料现款——现金流友好）；
- **产业带**：温州桥头（纽扣）/义乌（拉链织带）/绍兴南通（衬布）/东莞广州（织唛印唛）/深圳（RFID 吊牌）/张家港（缝纫线）。
