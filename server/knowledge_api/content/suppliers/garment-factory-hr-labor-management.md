# 服装厂用工与计件薪酬管理（Garment Factory HR & Piece-rate Management）

服装厂第一经营变量已从订单变为**人**：熟手车工平均年龄 40+、90 后不进厂、春节后返厂率决定全年产能。用工管理能力=接单能力（培训体系见 `suppliers/worker-training-skill-matrix.md`，本文聚焦招留用与薪酬机制）。

## 一、用工现状与结构

- **断层危机**：车工主力 35-50 岁（90 后占比 <15%）——未来 10 年供给持续收缩；
- **区域流动**：内地县城建厂吸引"陪读妈妈"（离家近+灵活——沿海向内地转移的动因之一）;
- **季节性波动**：春节后 2-4 周是返岗博弈期（员工比价观望——开工红包/保底工资是标配）；
- **用工形态**：正式工+临时工（旺季补充）+外发点（家庭作坊卫星点）。

## 二、计件工资体系设计

| 要素 | 设计要点 |
|:---|:---|
| 工序单价 | IE 测时（标准工时×时薪基准——见 `suppliers/garment-ie-engineering.md`） |
| 保底工资 | 淡季保底（当地最低工资 1.2-1.5 倍——保人不保量） |
| 质量挂钩 | 返修不计件/质量系数 0.9-1.1（产量质量双维） |
| 全勤/工龄奖 | 全勤 200-300 元/月+工龄逐年累加（留熟手） |
| 透明化 | 当日产量当日公示（计件透明=信任基础——ERP 自动计件见 `suppliers/garment-erp-digitalization.md`） |

- **定价陷阱**：新款单价争议是怠工导火索——新款上线 3 天内定价（试产测时，承诺"定价追溯不亏待"）。

## 三、招工渠道与成本

- **老带新**：介绍费 500-1500 元/人（干满 3 月兑现——成本最低质量最好）；
- **县域网点**：内地劳务合作点（驻点招工+包车进厂）；
- **技校合作**：服装中专定向班（实习+就业——年轻血液唯一来源）；
- **线上**：抖音/快手招工直播（工厂实拍——真实感是转化关键）；
- **成本**：普工获客成本 800-2000 元/人（熟手更高——流失一个熟手=损失 5000 元隐性成本）。

## 四、留人机制（比招人重要）

- **返厂率管理**：年前登记+开工红包（初八报到 800-1500 元）+老员工返厂奖；
- **伙食住宿**：夫妻房/伙食补贴（生活体验直接决定流失率——食宿改善 1 元 > 工资涨 1.5 元效果）；
- **工资准时**：**每月固定日发薪是底线**（拖一天=谣言四起——现金流再紧优先保工资）；
- **情感联结**：班组长关怀谈话/生日会/子女暑托（小投入高粘性）；
- **晋升通道**：车工→多能工→组检→班组长（可见的上升通道——见 `suppliers/worker-training-skill-matrix.md`）。

## 五、淡旺季用工策略

- **淡季保底+轮休**：保底工资+集中轮休（保住骨干——放走就回不来）；
- **多能工柔性**：小单季跨线调配（技能矩阵价值兑现）；
- **外发缓冲**：旺季峰值外发卫星工厂（见 `suppliers/subcontracting-outsourcing-management.md`）；
- **自动化对冲**：模板机/自动裁床减少对熟手依赖（见 `suppliers/garment-machinery-equipment.md`——新手上手周期缩短 50%）。

## 六、劳动合规红线

- **社保**：全员社保是验厂硬项（见 `suppliers/factory-audit-guide.md`——按实际工资基数是趋势）；
- **工时**：月加班 ≤36 小时法定上限（验厂考勤工资双账核查——两套账时代已结束）；
- **未成年工**：16-18 岁禁用缝纫夜班（未成年工登记+体检）；
- **临时工**：劳务派遣比例 ≤10%（超比例违法）；
- **争议高发**：计件单价单方下调/离职扣款——仲裁败诉率高的坑（单价调整须公示+员工签字）。

## 七、数据指标

| 指标 | 健康值 |
|:---|:---|
| 月流失率 | <5%（行业平均 8-12%） |
| 春节返厂率 | >85%（开工红包兑现） |
| 熟手占比（1 年+） | >60% |
| 多能工覆盖率 | 每工序 ≥3 人 |
| 人均产值 | 逐年提升 5-10%（IE 改善+设备） |
