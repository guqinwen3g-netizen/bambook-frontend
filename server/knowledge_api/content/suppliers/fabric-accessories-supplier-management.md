# 面辅料供应商开发与管理（Fabric & Trims Supplier Management）

面辅料占服装成本 50-70%，供应商质量决定大货质量上限。面辅料供应商管理的核心是：**分类分级 + 合格名录（AVL）+ 质量协议 + 动态考核**。

## 一、供应商分类

| 类别 | 举例 | 管理重点 |
|:---|:---|:---|
| 纱线厂 | 棉纺厂/化纤厂 | 支数稳定性、批次一致性 |
| 织布厂 | 梭织/针织圆机厂 | 织疵率、幅宽克重稳定性 |
| 印染厂 | 染色/印花厂 | 色牢度、环保资质（排污许可） |
| 后整理厂 | 涂层/复合/定型厂 | 功能指标、剥离强度 |
| 辅料厂 | 拉链/纽扣/织带/衬布 | 品牌授权（YKK 等）、环保检测 |
| 贸易商 | 现货面料商 | 现货真实性、短码率 |

- **产业链穿透**：面料贸易商背后是织布厂+印染厂——质量事故追责需穿透到实际生产方。

## 二、开发评估流程

### 1. 初筛
- 资质：营业执照、环保许可（印染厂红线）、检测报告能力；
- 产能与设备：织机型号/数量、染缸容量、定型机门幅；
- 现有客户：是否服务知名品牌（侧面验证）。

### 2. 打样验证
- 开发样（development sample）：看开发响应速度与理解力；
- **连续 3 批大货样检测**：成分/克重/色牢度/缩水率——一批好不算好，批批好才是体系能力。

### 3. 现场审核
- 重点：**实验室配置**（有无耐洗色牢度仪/摩擦仪/起球仪）、**品控流程**（验布工序）、**环保设施**（印染厂污水处理）；
- 评分制（同工厂审核，见 `suppliers/factory-audit-guide.md`），70 分以上入合格名录。

### 4. 小单试用
- 首单 500-1000m 小单试用，全项检测+跟单记录后决定是否升级。

## 三、合格供应商名录（AVL）与分级

| 等级 | 标准 | 策略 |
|:---|:---|:---|
| A（战略） | 质量稳定+配合开发+交期准 | 优先份额、联合开发、账期优惠 |
| B（主力） | 质量达标，配合度一般 | 常规订单 |
| C（观察） | 偶发问题 | 限小单、限期整改 |
| D（淘汰） | 重大质量事故/诚信问题 | 移出名录 |

- 每季度考核：质量（批合格率）40% + 交期 30% + 价格竞争力 20% + 服务响应 10%。

## 四、质量协议与追溯

- **质量协议**随采购合同签署（条款详见 `fabric/fabric-procurement-quality-agreement.md`）；
- **批次追溯**：要求供应商每缸/每匹提供缸号（lot no.）+ 出厂检验报告——大货问题可精准追责到缸；
- **留样制度**：每批面料留样 1m（双方各存），争议时对样检测。

## 五、价格与账期管理

- **价格联动**：原料（棉/涤/锦）价格波动超 ±5% 时启动调价谈判（双向）；
- **账期**：成熟供应商月结 30-60 天；新供应商款到发货或 30% 定金；
- **淡旺季策略**：淡季锁定低价备料（面料行情 3-4 月/9-10 月低点）。

## 六、风险防控

1. **环保关停风险**：印染厂是环保督查重点（江浙鲁印染集群整治常态化）——双供应商备份，避免独家印染厂被关停导致断供；
2. **短码/缺斤**：现货面料短码率 3-5% 是行业潜规则——收货验米数，合同约定"按实际米数结算"；
3. **缸差管理**：同一订单面料要求同缸生产；无法同缸时分缸裁剪（见 `garments/factory-collaboration-follow-up.md`）；
4. **知识产权**：独家开发面料签排他协议（花型/配方保密）。
