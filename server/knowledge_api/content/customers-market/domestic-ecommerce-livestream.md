# 国内电商与直播供应链（Domestic E-commerce & Livestream Supply Chain）

内销为辅的定位下，电商/直播是消化产能与库存的现实渠道：**抖音直播要"快反+深度库存"，拼多多要"极致成本"，淘系要"品质稳定"**——三渠道三套供应链逻辑，且**退货率 30-60% 是定价必须先算清的账**。

## 一、渠道格局与供款逻辑

| 渠道 | 供款模式 | 核心要求 | 账期/结算 |
|:---|:---|:---|:---|
| 抖音直播（达人/店播） | 供货给主播/MCN（或自播） | 快反 7-15 天翻单、深度库存（爆单万件级） | 达人佣金 20-30%+平台扣点 |
| 拼多多（含 Temu 国内逻辑） | 商家入驻自营/供货 | 极致低价（比价系统）+仅退款生态 | 平台结算周期短、罚款多 |
| 淘系/天猫 | 商家入驻 | 品质与内容（详情/短视频）、搜索运营 | 相对规范 |
| 视频号/快手 | 达人分销 | 中老年/下沉客群款型 | 同抖音逻辑 |

- **自营 vs 供货**：工厂普遍缺运营基因——**供货给成熟玩家**（主播/档口/电商卖家）比自建店铺现实；自播需 3-6 个月冷启动投入。

## 二、直播供应链要点

1. **选款**：直播款=视觉冲击+价格锚点（"专柜价 899 直播间 99"叙事——成本必须压在 ¥35 内）；
2. **快反**：测款（100-300 件）→ 爆单翻单（48h 决策，面辅料现货是前提——见 `suppliers/fabric-market-sourcing.md` 现货面料）；
3. **库存风险共担**：主播压价+压库存（"备 5000 件卖不完退回"条款——**合同必须明确退货上限与次品责任**）；
4. **品控底线**：直播退货主因=色差/尺码/质量（退货率连衣裙类目可达 50%+）——差评估计翻单无望。

## 三、退货率经济学（内销定价核心）

- **定价公式**：直播售价 = （成本 + 佣金 + 平台扣点 + 物流 + **退货损耗**）× 利润率——退货率 50% 意味着实际售出率折半，退件熨烫/翻新/二次销售成本 ¥3-8/件；
- **退件处理**：翻新再售（主路径）/剪标特卖/库存商打包（见 `suppliers/garment-stock-lot-disposal.md`）；
- **仅退款**：拼多多生态规则——白嫖损耗计入成本（0.5-2% 货值）。

## 四、与外贸订单的协同与冲突

| 维度 | 外贸单 | 内销电商单 |
|:---|:---|:---|
| 单款量 | 大单期货 | 小单快反 |
| 毛利 | 薄（5-15%） | 高（30-50% 供货价）但退货侵蚀 |
| 账期 | T/T 30-90 天（信用证保障） | 平台/主播账期+坏账风险 |
| 品质标准 | AQL/客检 | 平台抽检+差评驱动 |
| 产能配合 | 计划性强 | 脉冲式（爆单插队——**与外贸交期冲突是常态**） |

- **排产隔离**：内销快反单走专门小组/小线（见 `suppliers/production-capacity-scheduling.md`）——避免冲击外贸大货交期（OTIF 罚款，见 `customers-market/big-box-retail-channel.md`）；
- **面辅料**：内销用现货面料（市场面料——注意现货面料成分虚标风险，抽检成分）；
- **合规**：国内执行 GB 18401（纺织品基本安全）+GB 31701（童装）+纤维含量标识 GB/T 29862——吊牌合规（见 `trade-compliance/textile-labeling-regulations.md`）；职业打假高发（成分虚标/三无——退一赔三）。

## 五、切入路径

1. **清库存**：尾货直播清货（保本即赢——见 `suppliers/garment-stock-lot-disposal.md`）；
2. **供货试水**：与 2-3 个腰部达人/MCN 合作供货（单场 500-2000 件测款）；
3. **稳定款返单**：基础款（T 恤/卫衣/打底）供电商卖家常年返单（类外贸补单逻辑）；
4. **谨慎自播**：除非有运营合伙人——自播是零售生意不是制造生意。
