# 孟加拉与斯里兰卡市场（Bangladesh & Sri Lanka Market）

孟加拉是**全球第二（或第三）大成衣出口国**——比越南更"纯粹"的服装代工国（纺织是经济命脉）。斯里兰卡以**内衣/高端代工**著称。

## 一、孟加拉（Bangladesh）

### 产业地位
| 维度 | 数据/特征 |
|:---|:---|
| 成衣出口 | $450 亿+（占出口总额 80%+——纺织是国本） |
| 客户 | H&M/Zara/Primark/Walmart（快时尚+大众超市主力代工） |
| 成本 | **全球最低之一**（月薪 $100-150——成本优势核心） |
| 产能 | 4000+ 成衣厂（达卡/吉大港集群） |

### 与中国的关系
- **竞争**：基础款大订单（T 恤/衬衫/牛仔——孟加拉是中国最直接的低价竞争者）；
- **面料依赖**：孟加拉面料自给率 30-40%——**中国是孟加拉第一大面料供应国**（针织/牛仔面料大量进口中国）；
- **中资布局**：中资成衣厂孟加拉基地（成本+EBA 免税出口欧盟）。

### 风险与合规
- **劳工安全**：Rana Plaza 倒塌（2013——1134 人死亡）→ Accord/Alliance 品牌安全协议——孟加拉工厂的消防/建筑安全审核全球最严；
- **劳工动荡**：最低工资抗议（2023 大幅加薪后成本上升）；
- **基础设施**：港口拥堵（吉大港）+ 电力不稳；
- **LDC 毕业**：2026 年从最不发达国家毕业——EBA（欧盟免税）3 年过渡期后可能失去→**关税优势窗口期**。

## 二、斯里兰卡（Sri Lanka）

- **定位**：**高端内衣/功能服**（Victoria's Secret 主产地——MAS Holdings/Brandix 是全球顶级内衣代工）；
- **品质口碑**："无血汗工厂"营销（伦理制造——品牌溢价合作）；
- **规模小**：成衣出口 $50 亿+（精品路线）；
- **危机**：2022 国家破产危机——经济恢复中（货币贬值下的成本窗口）。

## 三、南亚采购策略

| 策略 | 说明 |
|:---|:---|
| 面料出口 | 孟加拉/斯里兰卡面料进口需求（中国面料商的南亚市场） |
| 转单竞争 | 客户拿孟加拉报价压中国——中国以"快反+面料差异化+品质"应对 |
| 多基地布局 | 中国高端 + 孟加拉基础款 + 越南中端的多点采购（品牌方策略） |
| 内衣学习 | 斯里兰卡内衣工艺（MAS 模式——高端内衣代工标杆，见 `garments/underwear-lingerie-production.md`） |

## 四、市场端（次要）

- **孟加拉**：1.7 亿人口但消费力低（人均 GDP $2600）——本土市场有限；
- **斯里兰卡**：2200 万人口——旅游带动的消费（危机后恢复期）；
- **机会**：中国面料/辅料出口 > 成衣出口（南亚是中国产业链的"上游市场"）。
