# DTC 品牌客户合作专题（DTC Brand Clients）

DTC（Direct to Consumer）品牌是服装供应链的"**新势力买家**"：订单小但增长快、对快反要求高、付款习惯好——是工厂从代工走向共创的优质客户层。

## 一、DTC 品牌画像

| 特征 | 说明 |
|:---|:---|
| 渠道 | 独立站为主（Shopify）+社媒营销（Instagram/TikTok） |
| 规模 | 年销 $100 万-$5000 万（腰部主力） |
| 订单 | 首单 100-500 件/款（测款）→ 爆款翻单 1000-5000 件 |
| 品类聚焦 | 单一品类深耕（瑜伽服/大码/环保基本款——Allbirds/SKIMS 范式） |
| 团队 | 精简（创始团队+营销——无传统采购部门） |

## 二、与传统品牌客户差异

- **决策快**：创始人直接拍板（无层层审批——打样到下单 2 周）;
- **付款好**：信用卡/PayPal 预付 30-50% 常态（现金流优于传统外贸——OA 少见）;
- **数据驱动**：测款→数据→翻单（首单小是模式而非实力——翻单速度是关键指标）;
- **品质期望高**：客单价高（$50-200——对应品质要求高于同等量传统单）;
- **包装定制**：品牌体验完整（吊牌/包装盒/感谢卡——配套能力加分）。

## 三、合作模式要点

- **MOQ 灵活性**：首单小单是行业惯例（工厂设"品牌孵化线"——100 件起订+单价上浮 20-30%）;
- **快反能力**：翻单 7-15 天是核心竞争力（面料备现货/产线预留——见 `customers-market/fast-fashion-shein-model.md`）;
- **开发协同**：DTC 团队常无技术背景（需要工厂提供版型/工艺支持——ODM 能力溢价）;
- **保密协议**：爆款保护（NDA+同款不供竞对——DTC 对供应链保密敏感）;
- **账期与增长**：随规模增长可能要求账期（用信保控制——见 `trade-process/export-credit-insurance.md`）。

## 四、获客渠道

- **LinkedIn 开发**：搜"founder + apparel brand"（创始人直连——开发信模板见 `trade-process/business-email-english-templates.md`）;
- **展会**：美国 Magic/英国 Pure——设 DTC 专区;
- **服务商生态**：Shopify 建站服务商/跨境营销机构转介绍;
- **独立站逆向开发**：SimilarWeb 筛流量增长中的品牌站（$100-500 万档最甜——太大有固定供应链，太小会死）;
- **社媒监听**：TikTok 爆款品牌（爆单缺供应链=切入时机）。

## 五、风险与筛选

- **死亡率**：DTC 品牌 3 年死亡率 50%+（营销成本上升——筛选标准：复购率>30%/有盈利的）;
- **订单波动**：爆款依赖（单款爆单后产能挤占——合同产能预留条款）;
- **需求外溢**：成长后要求 ODM/独家面料（服务能力匹配度评估）;
- **收款**：首单必预付（新品牌无信用记录——PayPal 争议期注意发货凭证留存）。

## 六、战略价值

- **利润结构**：DTC 订单毛利 20-35%（vs 传统代工 10-15%）;
- **能力升级**：快反/小单/包装定制能力沉淀（服务 SHEIN/Temu 半托管同源能力）;
- **客户组合**：3-5 个成长型 DTC 客户=订单基本盘（分散+高粘）;
- **品牌共创**：深度绑定可谈合资/股权（工厂入股品牌案例增多）。
