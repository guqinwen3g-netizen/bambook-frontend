# 马来西亚与新加坡市场（Malaysia & Singapore Market）

马新是东南亚"**高收入 + 贸易枢纽**"组合：新加坡是区域贸易/金融中心，马来西亚是穆斯林服饰与中产消费的现实市场。

## 一、新加坡（Singapore）

### 角色（枢纽大于市场）
| 维度 | 说明 |
|:---|:---|
| 贸易枢纽 | 东南亚采购中心（区域品牌总部/买手办） |
| 金融 | 贸易融资/结算（新加坡银行体系） |
| 消费 | 570 万人口但**人均 GDP $8 万+**（高端消费） |
| 转口 | 区域转口港（中转角色） |

### 市场特征
- **高端消费**：国际品牌主导（滨海湾购物带）；
- **电商**：Shopee 总部（新加坡）——区域电商中枢；
- **多元族群**：华人 74%/马来 13%/印度 9%（多元尺码/族群需求）；
- **机会**：区域采购决策地（接触东南亚买家的桥头堡）。

## 二、马来西亚（Malaysia）

### 市场
| 维度 | 说明 |
|:---|:---|
| 人口 | 3400 万（中产规模） |
| 收入 | 人均 GDP $1.2 万（东南亚第三） |
| 族群 | 马来 70%（**穆斯林**）/华人 23%/印度 7% |
| 电商 | Shopee/Lazada/TikTok Shop 高增长 |

### 穆斯林服饰（核心特色）
- **穆斯林市场**：马来穆斯林占多数——**端庄服饰（modest wear）**需求：头巾（hijab/tudung）、长袍（baju kurung/jubah）、穆斯林泳装（burkini——见 `garments/swimwear-production.md`）；
- **halal 联想**：穆斯林市场对"端庄/保守"设计的偏好（长袖/宽松/不透）；
- **节日**：开斋节（Hari Raya——穆斯林服饰消费峰值，见 `customers-market/middle-east-market.md` 斋月节奏）。

### 采购特征
- 华人买家主导批发（吉隆坡 GM Klang 批发中心）；
- 价格敏感（中端为主）；
- 付款：T/T 常规（信用较好）。

## 三、合规与准入

| 项目 | 说明 |
|:---|:---|
| SIRIM 认证 | 马来西亚标准（部分纺织品） |
| 标签 | 马来语/英语（成分标签） |
| 关税 | 东盟内部低关税；中国对马出口（中国-东盟 FTA/RCEP——多数零关税） |
| 穆斯林敏感 | 避免猪皮材质/不当图案（宗教敏感） |

## 四、进入策略

1. **穆斯林服饰线**：马来西亚是穆斯林服饰的"试金石市场"（比中东近/沟通易——验证产品后进中东）；
2. **电商优先**：Shopee/Lazada 马来西亚站（低门槛进入）；
3. **新加坡枢纽**：借新加坡接触区域采购（东南亚品牌/买手集中）；
4. **RCEP 利用**：中国对马新出口零关税/低关税（见 `trade-compliance/rcep-fta-utilization.md`）。
