# 南美南锥体市场指南（Southern Cone: Argentina, Chile, Peru）

南锥体三国（阿根廷/智利/秘鲁）是拉美"**高波动但有特色机会**"的市场：智利开放稳定、阿根廷封闭波动、秘鲁有羊驼特色原料。

## 一、三国概览

| 国家 | 人口 | 特征 |
|:---|:---|:---|
| 智利 | 1960 万 | **拉美最开放**（FTA 网络最广——中智 FTA 2006 拉美首个）；零售发达（Falabella/Cencosud 集团） |
| 阿根廷 | 4600 万 | 高关税封闭+外汇管制（进口许可制）；经济周期剧烈波动（米莱改革期的变数） |
| 秘鲁 | 3400 万 | 羊驼（alpaca）原料+有机棉（pima 棉）产地；矿业经济带动消费 |

## 二、智利（机会最稳）

- **中智 FTA**：纺织品零关税/低关税——价格竞争力直接兑现；
- **零售集团**：Falabella（拉美最大百货+电商）/Cencosud/Ripley——集中采购（进集团供应商体系=覆盖全拉美）；
- **消费**：中产成熟+电商渗透高（Mercado Libre/Falabella.com）；
- **付款**：智利买家信用拉美最好（银行体系健全——D/P 安全）。

## 三、阿根廷（高墙内的机会）

- **进口壁垒**：进口许可（SIRA/SIMI 制度——审批慢）+ 高关税（成衣 35%）+ 外汇管制（付款汇出难）；
- **外汇风险**：比索长期贬值+官方/黑市双汇率——**收款是最大风险**（客户拿不到外汇付不出）；
- **付款建议**：预付款/中信保（阿根廷买家违约率拉美最高）；
- **机会**：本土纺织业保护下的"替代进口"需求——经济开放周期时的窗口机会。

## 四、秘鲁（原料+市场）

- **羊驼（alpaca）**：秘鲁是全球 80% 羊驼毛产地（见 `fabric/fibers-and-materials.md`）——羊驼制品（毛衣/围巾）的**反向采购机会**（秘鲁产羊驼制品进口中国）；
- **Pima 棉**：秘鲁皮马棉（长绒棉——高端衬衫原料）；
- **市场**：中端消费（利马都市区）+ 矿业带动；
- **FTA**：中秘 FTA（2010）——关税优惠。

## 五、共性实操

| 项目 | 说明 |
|:---|:---|
| 语言 | 西班牙语（智利/阿根廷）+ 秘鲁西语 |
| 物流 | 海运 35-45 天（圣安东尼奥/布宜诺斯艾利斯/卡亚俄） |
| 反倾销 | 阿根廷对华纺织品反倾销史——出口前查措施 |
| 付款 | 智利稳/秘鲁中/阿根廷高危——**中信保国别限额** |
| 电商 | Mercado Libre 覆盖三国（跨境店 vs 本土店） |

## 六、市场策略

1. **智利为锚**：智利 FTA+稳定——南美南锥体的"测试市场"；
2. **阿根廷谨慎**：只做预付款/中信保覆盖的订单（外汇风险不可控）；
3. **秘鲁双线**：服装出口（FTA）+ 羊驼/pima 棉进口（特色原料供应链）；
4. **渠道**：Mercado Libre 本土店（智利/秘鲁）+ 零售集团采购（Falabella 体系）。
