# 客户画像与采购习惯（Customer Profile & Buying Behavior）

不同类型的客户在采购权责、下单习惯、付款与验厂要求上差异明显。识别客户类型有助于精准报价、安排跟单与维护关系。

## 一、主要客户类型与差异

### 品牌客户（Brand）
- **特征**：拥有自有品牌，对品质、合规、交期要求最严；常指定面料与辅料（指定 supplier）。
- **采购**：下单量大、周期长，重视验厂（audit）与第三方检测；返单稳定。
- **对接**：需完整报价（含 FOB/CIF）、样品确认、产前样（pre-production sample）与大货样（shipment sample）。

### 零售商（Retailer）
- **特征**：终端销售渠道，直接采购或通过采购办公室（buying office）采购。
- **采购**：对时尚度与性价比敏感，下单节奏快，常要求小批量多款（multi-style）。
- **对接**：重视交期与补单响应速度，质量以消费者投诉为导向。

### 进口商（Importer）
- **特征**：本国有进口资质与渠道，代品牌或自有品牌采购。
- **采购**：起订量（MOQ）灵活，对价格与合规（海关准入）敏感。
- **对接**：需提供完整单证（invoice、packing list、certificate of origin）。

### 贸易商（Trader / Trading Company）
- **特征**：无自有生产，赚取差价，转手给终端客户。
- **采购**：以价格为导向，常询价多家；对交期与价格敲定后有较高弃单风险。
- **对接**：需核对其最终客户要求，避免信息失真。

### 电商渠道（E-commerce）
- **特征**：跨境电商平台（Amazon、Shopee、TikTok Shop 等）卖家，或 DTC（direct-to-consumer）品牌。
- **采购**：小批量、快返、多 SKU，重视现货与快速翻单；对物流与包装有特殊要求。
- **对接**：报价需含包装与标签（如 ASIN 条码、合规标签），交期要求短。

## 二、采购周期与下单习惯

- **常规节奏**：欧美大客户每年 2 个主季（春/秋），秋冬面料提前 6-10 个月打样下单。
- **返单**：大货下单后 3-6 个月返单，需提前锁定产能与面料库存。
- **下单前置**：一般先询价 → 样品确认 → 产前样 → 大货生产 → 验货 → 出运。
- **签约要点**：明确 MOQ、交期（lead time）、付款方式（T/T、L/C、D/P）、违约责任与索赔条款。

## 三、验厂要求（Audit）

- **常见类型**：社会责任验厂（sedex/SMETA、BSCI）、质量体系验厂、反恐（C-TPAT / GSV）。
- **准备**：提前检查员工工时、社保、消防、化学品存储、安全设施与文件台账。
- **对接**：验厂结果影响客户准入与订单量，需设专人跟进整改项（CAP）。

## 四、客户画像记录要点

- 记录客户类型、目标市场、采购量级、价格敏感度、验厂状态、主要联系人。
- 维护客户偏好：指定面料、常规款、包装习惯、语言与沟通渠道。
- 结合历史订单分析毛利与付款及时性，划分重点/一般/风险客户。
