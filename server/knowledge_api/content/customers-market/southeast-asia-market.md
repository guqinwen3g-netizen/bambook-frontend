# 东南亚消费市场指南（Southeast Asia Consumer Market）

东南亚 6.8 亿人口、年龄中位数 29 岁、电商渗透率快速提升——是"中国供应链 + 本地消费"模式的增长极。注意：**这里既是消费市场（卖货），也是制造基地（产能转移目的地），双重身份需区分**。

## 一、主要市场画像

| 国家 | 人口 | 特征 |
|:---|:---|:---|
| 印尼 | 2.8 亿 | 东南亚最大；87% 穆斯林——**穆斯林服饰（modest fashion）全球第一大市场** |
| 菲律宾 | 1.1 亿 | 英语普及、美式消费文化、社媒电商（TikTok Shop 强势） |
| 越南 | 1 亿 | 制造基地+消费升级双轨；本土品牌（如 IVY Moda）崛起 |
| 泰国 | 7000 万 | 旅游业联动、曼谷时尚圈 |
| 马来西亚 | 3400 万 | 穆斯林+华人双市场；人均 GDP 高 |
| 新加坡 | 600 万 | 区域总部+高端市场，规则最规范 |

## 二、电商渠道（主战场）

- **Shopee**（腾讯系）：全域第一；**Lazada**（阿里系）；**TikTok Shop**（印尼曾禁后复出、泰国/越南/菲律宾增长最快）；
- **模式**：跨境直邮（中国仓发货）→ 本土仓（海外仓备货）升级路径；平台大促节奏（9.9/10.10/11.11/12.12 生日大促）；
- **价格带**：主流客单价 $5-25——极致性价比竞争（中国白牌 vs 本土工厂）。

## 三、准入与关税

- **RCEP 红利**：东盟十国全部在 RCEP 内——中国服装凭 RCEP 证书享低税率或零关税（见 `trade-compliance/rcep-fta-utilization.md`）；
- **中国-东盟 FTA（ACFTA）**：Form E 证书，多数纺织品已零关税（见 `trade-process/certificate-of-origin-practice.md`）；
- **进口合规**：印尼 SNI 认证（部分纺织品）、泰国 TISI、菲律宾 BPS——电商小包裹走简易清关，B2B 大货需正式认证；
- **印尼配额制**：纺织品进口有配额与许可管理（保护本土产业）。

## 四、品类与文化

- **穆斯林服饰**（印尼/马来）：头巾（hijab）、长袍（abaya/gamis）、保守泳装（burkini）——斋月前 2 个月是销售峰值（开斋节新衣传统）；
- **气候**：全年热季——薄款棉麻/凉感面料主力；无冬装市场；
- **尺码**：偏小码（东南亚体型）；宗教因素——透明/紧身款在穆斯林市场禁忌；
- **色彩**：印尼/马来偏好高饱和度色彩与印花（蜡染 batik 文化影响）。

## 五、供应链协同模式

- **中国面料 + 东南亚成衣**：越南/柬埔寨/印尼成衣厂用中国面料比例 60-80%——面料出口东南亚是 B2B 主线（纱线/面料出口越南关税与物流优势）；
- **中国成品 + 东南亚电商**：直邮/本土仓模式——极致供应链效率竞争；
- **品牌出海**：SHEIN/UR/森马等中国品牌东南亚开店；中小品牌借 TikTok Shop 切入。

## 六、付款与物流

- **电商回款**：平台结算（Shopee/Lazada 卖家钱包，支持人民币提现）；
- **B2B 付款**：T/T 为主；印尼/菲律宾买家信用中等，建议中信保；
- **物流**：海运 7-12 天（华南→雅加达/胡志明/马尼拉）；电商小包专线成熟（3-7 天）。

## 七、实操要点

1. **区分 B2B 与 B2C 逻辑**：面料卖给本地工厂（B2B 大单）vs 成衣卖给消费者（电商小单）——两条业务线资源配置完全不同；
2. **本土化优先级**：穆斯林市场——产品开发（保守款）+ 模特图（头巾模特）+ 斋月营销日历；
3. **本土仓升级**：月销稳定 5000 件以上 SKU 转本土仓（时效 3 天 vs 直邮 10 天，转化率差 2 倍+）；
4. **越南特殊**：制造与消费双强——面料出口越南竞争与机会并存（本地纺织业也在升级）。
