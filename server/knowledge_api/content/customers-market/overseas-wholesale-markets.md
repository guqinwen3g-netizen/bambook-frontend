# 海外批发市场渠道（Wholesale Districts: Prato/Laleli/Deira/约翰内斯堡）

海外实体批发市场是纺织外贸的"隐形大动脉"：全球 60%+ 的纺织品仍经批发市场中转（中东/非洲/拉美/东欧的零售底层供给）。与 B2B 平台（`trade-process/b2b-wholesale-platforms.md`）、代理商体系（`customers-market/overseas-agents-distributors.md`）互补——批发市场的特征是**现货、现金、快进快出、价格屠夫**。

## 一、全球主要批发市场地图

| 市场 | 位置 | 辐射 | 特征 |
|:---|:---|:---|:---|
| Deira/德拉 | 迪拜（Naif/Al Ras） | 中东+东非+中亚转口 | 现货现提/转口贸易（伊朗敏感——`trade-compliance/sanctions-screening-compliance.md`） |
| Laleli | 伊斯坦布尔 | 俄罗斯/中亚/巴尔干 | 俄语区采购枢纽（"行李箱贸易"历史——灰色清关遗产） |
| Prato | 意大利佛罗伦萨 | 南欧快时尚 | 华人纺织城（面料+成衣快反——欧洲版柯桥） |
| 约翰内斯堡 | 南非（JHB CBD/Dragon City） | 南部非洲 | 中国商城模式（现货批发+雇佣本地销售） |
| 拉各斯/内罗毕 | 尼日利亚/肯尼亚 | 西非/东非 | 二手衣冲击下的新衣批发（价格战残酷） |
| 圣保罗 Brás | 巴西 | 南美 | 本地华商+韩商竞争（巴西关税壁垒高） |
| 莫斯科柳布利诺 | 俄罗斯 | 俄语区 | 制裁后平行进口枢纽（合规排查——`trade-compliance/sanctions-screening-compliance.md`） |

- **层级结构**：中国工厂→进口批发商（一手柜货）→市场档口（二手分销）→内地零售店/小贩——**环节每多一层加价 30-50%**；直接供货档口（跳过大批发商）是利润策略但需本地团队。

## 二、市场运作模式

- **现货交易**：档口看样→现款现货（现金/即时转账）——**无账期是最大优点**（vs 商超 60-90 天）；试单量小（10-50 件/款）但翻单快（3-7 天）；
- **柜货模式**：整柜到港直接入市场仓库分拨——**集装箱店**（中亚/非洲特色的"一柜一店"）；拼柜散货（货代集拼——运费成本敏感）；
- **档口运营**：租金+本地雇员工资+仓租——**夫妻店模式**（华商家庭经营是主流）；本地销售员（语言+客源——非洲市场靠本地"marketer"拉客）；
- **季节性**：换季压货风险自担（无退货——**滞销款就地清仓**（3-5 折给清货商））；斋月/圣诞/开学季节奏（区域日历见 `trade-process/annual-sourcing-calendar.md`）。

## 三、选品与定价逻辑

- **品类特征**：中低价位走量款（T 恤/牛仔裤/头巾/校服/家居服）——**批发市场不做高价款**（高端客户不在此渠道）；尺码/花型本地化（中东大码/非洲鲜艳花型——`fabric/african-wax-print-fabrics.md`）；
- **价格屠夫逻辑**：档口比价半径 50 米——**同质款价差 $0.1 即丢单**；成本倒推定价（市场零售价反推 FOB——`garments/garment-costing-pricing.md`）；
- **爆款跟风**：市场爆款生命周期 2-4 周——**抄款速度是核心竞争力**（跟款交期 7-10 天——快反能力见 `suppliers/garment-factory-small-order-flexible.md`）；
- **仿牌雷区**：批发市场是仿牌重灾区——**知识产权风险**（海关查扣+品牌方市场打假——`trade-compliance/ip-brand-authorization.md`；俄罗斯/中东部分市场默认仿牌生态=随时被整肃）。

## 四、进入策略与风控

- **进入路径**：① 供货给现有进口批发商（最低门槛——利润最薄）→② 与档口合作寄售（consignment——卖完结算，风险共担）→③ 自设档口（本地公司+签证+仓储——重资产）；
- **本地合伙人**：非洲/中东市场**没有本地合伙人寸步难行**（清关/税务/治安/收款）——合伙协议+股权控制（51% 陷阱——当地名义股东风险）；
- **收款风控**：现金市场假钞（美元假币——验钞机+银行存验）；本地货币贬值（尼日利亚奈拉/埃及镑——**定价随行就市+快速换汇出境**——外汇管制见 `trade-process/foreign-exchange-settlement.md`）；
- **灰色清关诱惑**：部分市场历史形成的灰关渠道（俄罗斯/中亚）——**法律风险与货物安全风险并存**（整柜没收无追索）；正规清关成本纳入报价（清关代理见 `trade-process/freight-forwarder-broker-management.md`）；
- **安全与治安**：部分市场治安风险（JHB/拉各斯）——现金管理与人员安全预案。
