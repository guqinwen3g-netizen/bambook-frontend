# 柬埔寨与缅甸市场（Cambodia & Myanmar Market）

柬埔寨/缅甸是**低成本代工链的最末端**：比孟加拉更便宜但更不稳定。对中资成衣厂而言是产能转移目的地，对贸易商是价格竞争的参照。

## 一、柬埔寨（Cambodia）

### 产业地位
| 维度 | 说明 |
|:---|:---|
| 成衣出口 | $80-100 亿（占出口 40%+——支柱产业） |
| 成本 | 月薪 $200 左右（2024 加薪后——仍低于越南） |
| 客户 | H&M/Gap/Adidas（大众品牌基础款） |
| 中资 | **中资厂占柬埔寨成衣厂 60%+**（中国产能转移首选地之一） |

### 优势与风险
- **优势**：EBA（欧盟免税——除武器外一切商品）+ 成本 + 中资管理输出成熟；
- **风险**：EBA 部分撤销（2020 欧盟因人权撤销部分产品免税——政治风险现实化）/ 工会罢工频繁 / 基础设施弱（电价比越南高）；
- **配套**：面料辅料 90% 进口（中国供应——柬埔寨是"纯缝制"基地）。

## 二、缅甸（Myanmar）

- **成本最低**：月薪曾低至 $100——全球成本洼地；
- **政变冲击**：2021 政变后——ESG 风险（品牌撤单/暂停）、EU/美国制裁、物流受阻；
- **现状**：部分品牌回归（低价诱惑）vs 伦理审查——**高风险高波动市场**；
- **中资**：中资厂缅甸基地（政变后部分撤回/观望）。

## 三、与中国的关系（竞争+协同）

| 关系 | 说明 |
|:---|:---|
| 竞争 | 超低成本基础款（柬埔寨/缅甸抢最低端订单） |
| 协同 | **中国面料辅料供应**（柬缅无上游——中国是其"粮仓"） |
| 转移 | 中资厂"中国+柬缅"双基地（规避关税+成本） |

## 四、市场端（有限）

- **柬埔寨**：1700 万人口/消费力低——本土市场小；
- **缅甸**：5500 万人口但政治动荡——市场开发高风险；
- **机会**：面料辅料出口 > 成衣出口（柬缅是中国产业链下游客户）。

## 五、风险提示

| 风险 | 说明 |
|:---|:---|
| 政治/ESG | 缅甸政变/柬埔寨人权——品牌伦理审查撤单风险 |
| EBA 变动 | 欧盟贸易优惠的政治条件（随时可能调整） |
| 基础设施 | 电力/物流/港口弱（交期不确定性） |
| 劳工 | 罢工/加薪压力（成本优势在缩小） |

## 六、策略建议

1. **面料辅料出口**：柬埔寨/缅甸是面料出口的现实市场（中资厂柬缅基地的中国供应链）；
2. **产能布局**：评估"中国+1"时的选项（成本 vs 政治风险权衡）；
3. **竞争参照**：客户拿柬缅报价压价——以"品质+交期+面料"差异化应对；
4. **谨慎评估缅甸**：政治风险下的订单安全（收款/物流/ESG）。
