# 快时尚与小单快反模式（Fast Fashion & Quick Response）

以 Shein 为代表的"小单快反"模式重构了服装供应链：从"预测式大货"转向"测试式快反"。对供应商而言，这既是订单结构的变化，也是能力模型的重写。

## 一、模式对比

| 维度 | 传统外贸 | 快时尚（Zara 式） | 超快时尚（Shein 式） |
|:---|:---|:---|:---|
| 开发→上架 | 6-9 个月 | 3-6 周 | 7-15 天 |
| 首单量 | 3000-10000 件 | 500-2000 件 | **100-300 件** |
| 翻单周期 | 季度 | 2-4 周 | 3-7 天 |
| 淘汰率 | 低（预测制） | 中 | 高（测款制，爆款率 5-20%） |
| 面料 | 定向开发 | 半现货 | **现货面料为主** |

## 二、小单快反的供应链要求

### 1. 现货面料池
- 爆款翻单 3-7 天交付，**等不起 30 天的面料定做**——必须备现货面料（黑白灰基础色 + 当季流行色）。
- 与面料商共建"快反面料仓"：畅销品种滚动备货 3000-5000m。

### 2. 柔性产线
- 小单（100-300 件）上流水线不经济——**单件流/小组制（cell production）**：3-5 人小组完成整件，换款快。
- 快速换款能力：日换款 2-3 次（vs 传统产线 3-7 天一换）。

### 3. 快速打版
- 24-48 小时出纸样+样衣；3D 设计（CLO3D）跳过实物打样环节。
- 版房与产线同厂协同，改版即时响应。

### 4. 数字化接单
- Shein 供应商系统（SCM）：款式图片/工艺单/交期线上化，系统派单、扫码报工、动态评分。
- 评分维度：**准时交付率、次品率、翻单速度**——决定派单量。

## 三、商业逻辑与账期

- **测款逻辑**：首单 100-300 件上架测试，数据（点击率/加购率/转化率）决定翻单量——供应商接到的是"概率订单"。
- **翻单集中**：爆款翻单可达 5000-50000 件，但时间窗口短（7-15 天）。
- **账期**：Shein 类平台月结 30-90 天（视供应商评级）；自营快反客户可谈现款。
- **毛利结构**：单件工费低于传统订单 10-20%，靠翻单总量与产线效率补利润。

## 四、供应商切入策略

1. **能力自评**：是否具备现货面料渠道 + 小组产线 + 48 小时打版？缺一项即无法入场。
2. **从品类切入**：连衣裙/T 恤/泳装是快反最大品类；复杂工艺（西装/羽绒服）不适合快反。
3. **多客户分散**：Shein/Temu/TikTok Shop + 独立站卖家组合，避免单一平台依赖（平台政策突变风险——如 Temu 美国站 2026 年转向本土仓模式）。
4. **利润模型测算**：小单工费损耗（换款频繁）vs 翻单规模收益，先跑 3 个月数据再扩产。
5. **合规底线**：快反不等于免检——Shein 对供应商有 SRS（社会责任）审核与产品测试要求（见 `suppliers/factory-audit-guide.md`）。

## 五、风险与争议

- **低价内卷**：极致压价模式供应商利润空间持续收窄。
- **环保审查**：快时尚是欧盟 ESG 监管重点对象（纺织品 EPR、销毁禁令——见 `trade-compliance/esg-csrd-sustainability.md`）。
- **关税政策**：De Minimis 取消后 Shein/Temu 转向半托管+本土仓（见 `trade-process/cross-border-ecommerce-logistics.md`），供应商需配套海外仓履约能力。
- **知识产权**：快时尚侵权诉讼高发，自主开发款注意图案授权（见 `trade-compliance/ip-brand-authorization.md`）。

## 六、传统工厂的转型路径

```
阶段1：接快反单做产能补充（学习节奏）
阶段2：独立快反小组产线（3-5 组，日产 500-1000 件）
阶段3：面料仓 + 版房 + 产线全链路快反（7 天交付）
阶段4：自营品牌/店铺（从供应到零售）
```
