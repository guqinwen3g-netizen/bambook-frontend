# 港台市场指南（Hong Kong & Taiwan Market）

港台是"**中国纺织外贸的历史枢纽与现代伙伴**"：香港是老牌贸易转口港与买办中心，台湾是功能性面料与品牌代工的隐形冠军。

## 一、香港（Hong Kong）

### 角色演变
| 阶段 | 角色 |
|:---|:---|
| 1980-2000 | 中国纺织出口主转口港（配额时代——香港配额+珠三角加工） |
| 2000-2010 | 贸易公司/买办中心（利丰 Li & Fung 模式的全球供应链） |
| 2010 至今 | 金融/物流/设计服务中心——实体贸易减少但高端服务仍在 |

### 现实价值
- **贸易公司**：香港贸易商（利丰/晶苑国际）仍掌握欧美品牌采购网络——通过香港贸易公司接单仍是通道；
- **展会**：香港时装节（Fashion InStyle）——亚洲重要展会；
- **金融**：香港账户收汇/信用证（国际贸易金融便利性）；
- **物流**：香港机场（高价值/紧急货物枢纽）。

### 合规注意
- 香港原产地证（转口证——香港不签发一般原产地证 CO，只签转口证/加工证）；
- "Made in Hong Kong" 标签（香港制造需实质加工——简单缝标不算）。

## 二、台湾（Taiwan）

### 产业地位（隐形冠军）
| 领域 | 地位 |
|:---|:---|
| 功能性面料 | **全球顶级**——台塑/远东新/儒鸿（Eclat：Lululemon 核心面料商）/聚阳 |
| 针织代工 | 儒鸿/聚阳/年兴（牛仔）——品牌高端代工 |
| 户外功能 | 台华（福华）——GORE-TEX 合作/尼龙功能性面料 |

### 与大陆的关系
- **台湾面料+大陆成衣**：台资面料厂（远东新越南/大陆基地）——功能性面料的技术标杆；
- **台资成衣厂**：大陆/越南/柬埔寨布局（儒鸿越南基地）——管理与技术输出；
- **竞争+学习**：台湾功能性面料是大陆面料厂的对标（技术差距在缩小）。

### 贸易实务
- **两岸贸易**：ECFA（海峡两岸经济合作框架协议）——纺织品关税优惠；
- **付款**：台商信用良好（制造业文化）；
- **语言**：繁体中文+台语术语差异（"纱"称"支数"等术语基本一致）。

## 三、港台采购商特征

| 特征 | 说明 |
|:---|:---|
| 专业度高 | 几代纺织世家（面料/工艺精通——报价忽悠不了） |
| 网络深 | 欧美品牌关系网（几十年的客户积累） |
| 品质导向 | 愿为好品质付溢价（但要求极严） |
| 小单灵活 | 香港贸易商善于组小单（多客户拼柜模式） |

## 四、合作策略

1. **接单通道**：香港贸易公司（欧美品牌间接订单——利润薄但量稳）；
2. **技术对标**：台湾功能性面料（研发方向参考）；
3. **展会**：香港时装节+台北纺织展（TITAS）——接触港台买家网络；
4. **金融物流**：香港账户/物流枢纽的便利性利用。
