# 墨西哥市场深度指南（Mexico Market Deep Dive）

墨西哥是"**美国后院的世界工厂 + 1.3 亿人口消费市场**"：USMCA（美墨加协定）框架下的近岸外包（nearshoring）明星，中美贸易变局中的关键枢纽。

## 一、战略地位：Nearshoring 核心

- **USMCA 原产地规则**：纺织服装"从纱开始"（yarn-forward）——纱线+面料+裁剪均在北美完成才能免关税入美；
- **近岸红利**：美国品牌供应链多元化（China+1）下，墨西哥成衣交期 2-3 周（vs 中国海运 6-8 周+关税）；
- **中国企业的双重机会**：① 对墨出口面料（墨西哥面料自给不足）② 在墨设厂/合作（借 USMCA 入美）。

## 二、墨西哥纺织业格局

- **产业集群**：普埃布拉（Puebla 传统纺织城）、墨西哥州、哈利斯科；
- **强项**：牛仔（全球知名——Kaltex 集团）、针织、家纺；
- **短板**：化纤/功能面料依赖进口（中国供应）、棉纺原料依赖美棉；
- **成本**：工资约为中国 80-90%（已无成本优势——竞争力在交期与关税）。

## 三、消费市场

- **人口**：1.3 亿（拉美第二）；中产扩大+电商高增长（Mercado Libre 墨西哥站是拉美最大电商市场之一）；
- **零售**：Liverpool/Palacio de Hierro（百货）、Walmart de México（最大零售商）、Shein/Temu（跨境包裹曾爆发式增长）；
- **2024-2026 包裹税政**：墨西哥对无 FTA 国家（中国）包裹征 33.5% 关税（2025 年 8 月，见 `customers-market/emerging-markets.md`）——跨境小包模式受冲击，本土化仓储/公司运营成趋势。

## 四、合规要点

| 项目 | 说明 |
|:---|:---|
| 标签 | NOM-004-SE-2021 纺织标签标准（西班牙语：成分/原产国/洗涤/进口商） |
| 进口关税 | 成衣 25-35%（无 FTA 国家）；面料 10-15% |
| 认证 | 部分品类 NOM 强制认证 |
| 语言 | 西班牙语（英语商务可用但合同/标签需西语） |

## 五、实操策略

### 对墨出口面料（现实主线）
- **品类**：化纤/功能面料、针织面料、牛仔面辅料（墨牛仔产业的面辅料进口）；
- **客户**：墨西哥成衣厂（为美国品牌代工——面料进口需求持续）；
- **付款**：中等信用——L/C 或中信保覆盖。

### 借墨入美（战略级）
- **合规红线**：USMCA yarn-forward 规则严格（简单缝制不构成原产）；CBP 对墨转口查核趋严（见 `trade-compliance/transshipment-anti-circumvention.md`）；
- **可行模式**：在墨投资针织/染整产能（纱线可从美进口——美墨纱线互流）；
- **风险**：USMCA 2026 年联合审查（续约谈判不确定性——关税政策可能调整）。

### 消费品牌出海
- 电商本土化（Mercado Libre 本土店）、KOL 营销（墨西哥社媒活跃）、价格带适配（中端为主）。

## 六、风险提示

1. **政策波动**：包裹税政频繁调整（保护本土纺织业）；
2. **治安与物流**：公路货运安全风险（保险+车队管理）；
3. **汇率**：比索波动（近年相对坚挺但历史波动大）；
4. **USMCA 审查**：2026 联合审查期的政策不确定性——在墨重大投资需评估情景。
