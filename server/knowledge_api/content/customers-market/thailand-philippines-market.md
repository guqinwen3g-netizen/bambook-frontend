# 泰国与菲律宾市场（Thailand & Philippines Market）

泰菲是东南亚"**中产消费市场**"：泰国成熟稳定、菲律宾年轻高增长——都是中国服装出口的现实电商市场。

## 一、泰国（Thailand）

### 市场
| 维度 | 说明 |
|:---|:---|
| 人口 | 7000 万 |
| 收入 | 人均 GDP $7000+（东南亚中上） |
| 消费 | 中产成熟+旅游零售（曼谷购物） |
| 电商 | Shopee/Lazada/TikTok Shop 泰国（高渗透） |

### 特征
- **时尚消费**：泰国消费者时尚敏感（曼谷是东南亚时尚节点——韩系/日系影响）；
- **本土产业**：泰国有纺织基础（成衣代工历史——但成本已高于越柬）；
- **旅游零售**：曼谷/普吉旅游购物（纪念品/度假服）；
- **合规**：TISI 标准（泰国工业标准）。

### 机会
- 快时尚电商（Shein/Temu 泰国——中国跨境电商已深入）；
- 度假/海滩服饰（旅游场景）；
- 穆斯林服饰（泰南穆斯林——见 `customers-market/malaysia-singapore-market.md`）。

## 二、菲律宾（Philippines）

### 市场
| 维度 | 说明 |
|:---|:---|
| 人口 | 1.15 亿（东南亚第二） |
| 年龄 | **中位年龄 25 岁**（极年轻——消费潜力） |
| 英语 | 官方语言之一（英语市场——沟通成本低） |
| 电商 | 高增长（Shopee 菲律宾第一大——社媒购物盛行） |

### 特征
- **年轻+社媒**：TikTok/Facebook 购物（社交电商渗透率全球领先）；
- **价格敏感**：低客单价走量（大众市场）；
- **尺码**：美式尺码（菲律宾受美国影响深——英语+美式）；
- **物流挑战**：群岛地理（7000+岛屿——末端物流成本）。

### 机会
- 大众快时尚（年轻+价格敏感——中国跨境电商主战场）；
- 英语市场（Listing/客服英语——运营便利）；
- 宗教（天主教——圣诞消费旺季长）。

## 三、共性（东南亚电商逻辑）

| 项目 | 说明 |
|:---|:---|
| 平台 | Shopee/Lazada/TikTok Shop 三强 |
| 支付 | COD 占比下降但仍在（电子钱包 GCash/TrueMoney 增长） |
| 物流 | 跨境直邮 vs 本土仓（时效竞争） |
| 关税 | RCEP/中国-东盟 FTA（多数零关税——见 `trade-compliance/rcep-fta-utilization.md`） |
| 季节 | 常年夏季（夏装全年——无冬季SKU） |

## 四、进入策略

1. **电商先行**：Shopee/Lazada 开店（低门槛——本土店 vs 跨境店）；
2. **TikTok Shop**：社交电商（直播/短视频——年轻市场首选）；
3. **本土化**：尺码/款式本土化（泰国时尚 vs 菲律宾美式）；
4. **夏装专营**：常年夏季（夏装/泳装/防晒——无季节错配风险）。
