# 新兴电商平台运营：TikTok Shop 与 Temu（Emerging Platforms）

亚马逊之外的"**第二增长曲线**"：TikTok 靠内容兴趣电商、Temu 靠全托管低价——两者都在重塑服装跨境的供应链要求。

## 一、TikTok Shop（兴趣电商）

| 模式 | 特征 |
|:---|:---|
| 全闭环本土店 | 美国/英国/东南亚本土发货（中国公司可开跨境店） |
| 内容带货 | 短视频+直播（达人分佣 15-25%——货找人的逻辑） |
| 货架商城 | 商城搜索流量增长（货架+内容双轮） |

**服装运营要点**：
- **爆款逻辑**：视频爆→订单爆（单款日销从 0 到数千——供应链爆单压力，48 小时发货率考核）;
- **达人建联**：海量寄样（样品成本=营销费——达人履约率仅 20-30%，批量寄样筛效率）;
- **直播**：美区直播占比低于东南亚（英语主播成本高——短视频为主）;
- **本土履约**：美国站要求本土发货（第三方海外仓一件代发——见 `trade-process/overseas-warehouse-operations.md`）;
- **类目门槛**：服装开白（品牌备案+质检报告——仿牌高压线，封店率高）。

## 二、Temu（托管电商）

| 模式 | 特征 |
|:---|:---|
| 全托管 | 供货价模式（平台定价/运营/物流——卖家只负责生产发货到国内仓） |
| 半托管（2024 起） | 卖家负责海外仓履约（定价权仍在平台——大件/服装补充） |

**服装供应商要点**：
- **核价机制**：供货价被压到极致（对标 1688——毛利 10-15% 常态，适合走量基础款）;
- **JIT 模式**：先销售后发货到仓（24-48 小时到仓考核——快反产线才能接，见 `customers-market/fast-fashion-shein-model.md`）;
- **质量罚款**：质检不合格/缺货罚款（罚款条款细——接单前核算罚款风险敞口）;
- **卖家定位**：工厂型卖家优势（贸易公司无价格优势——适合清产能非树品牌）。

## 三、平台策略对比与组合

| 维度 | 亚马逊 | TikTok Shop | Temu |
|:---|:---|:---|:---|
| 毛利 | 20-40% | 25-45% | 10-15% |
| 运营复杂度 | 高（广告+listing） | 中（内容能力） | 低（纯供货） |
| 品牌沉淀 | 可积累 | 中（人设绑定） | 无 |
| 适合 | 品牌长线 | 爆款打法 | 清产能/现金流 |

**组合策略**：Temu 清基础产能+TikTok 测爆款+亚马逊沉淀品牌（三线并行分散风险）。

## 四、供应链新要求

- **小单快反标配**：新平台首单都小（200-500 件——工厂快反线是入场券）;
- **48 小时履约**：现货/准现货模式（面料备库成关键——见 `fabric/fabric-inventory-stock-strategy.md`）;
- **质检前移**：平台罚款倒逼（出厂全检比例提升）;
- **数据对接**：ERP 对接平台（自动推单——手工导单在爆单时崩溃）。

## 五、风险提示

- **政策风险**：TikTok 美国法案（剥离或禁令悬而未决——不把鸡蛋放一个篮子）;
- **平台规则变动**：Temu 罚款规则频繁调整（利润模型按季度重算）;
- **价格内卷**：全托管模式下比价透明（无差异化能力的供应商被挤出）;
- **知识产权**：平台对仿牌零容忍（见 `trade-compliance/ip-brand-authorization.md`）。
