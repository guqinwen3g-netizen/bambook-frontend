# 越南市场指南（Vietnam Market）

越南是"**最大的竞争对手 + 最大的面料客户**"：全球第二大成衣出口国（Nike/Adidas 最大代工基地），但面料自给率仅 40%——**中国是越南第一大面料供应国**。

## 一、竞争格局

| 维度 | 越南 | 中国 |
|:---|:---|:---|
| 成衣出口 | 全球第二（$400 亿+） | 全球第一（$1500 亿+） |
| 成本 | 工资约中国 60-70% | 高但效率补 |
| 关税 | CPTPP/EVFTA/RCEP 多重 FTA（欧美关税优势） | 美国 301 关税负担 |
| 面料 | **自给率 40%（短板）** | 全产业链 |
| 交期 | 面料依赖进口拖长交期 | 快反能力强 |
| 大客户 | Nike/Adidas/Uniqlo 主代工 | 同客户的高端/快反线 |

- **竞合关系**：越南赢"大批量基础款+关税敏感单"；中国赢"快反/复杂工艺/面料差异化单"——**中国的最优策略之一是"面料卡位"**。

## 二、面料出口越南（现实主线业务）

- **规模**：中国对越面料出口 $100 亿+/年（越南纺织业"瓶颈在上游"）；
- **品类**：针织面料、功能性面料、化纤面料、牛仔布、里布辅料——越南织染产能不足；
- **客户**：越南成衣厂（台资/韩资/越资——为欧美日品牌代工，指定采购中国面料）；
- **渠道**：胡志明面料展（VTG/SaigonTex）、面料进口商（胡志明新平市场）、中资面料厂驻越办事处。

## 三、中资布局越南

- **纺纱**：天虹/百隆东方（越南纱厂——规避美棉关税+成本）；
- **织染**：盛虹/申洲（越南织染一体化——申洲国际越南基地是全球针织代工标杆）；
- **成衣**：中资成衣厂越南基地（交欧美订单避 301 关税）；
- **风险提示**：越南电力短缺（北部夏季限电——2023 教训）、环保审批趋严（染整牌照稀缺）、工资年涨幅 8-10%。

## 四、合规要点

| 项目 | 说明 |
|:---|:---|
| 原产地 | 越南出口欧美需满足 FTA 原产地规则（面料来源影响资格——中国面料+越南缝制的"从纱"判定按各 FTA 条款） |
| 关税 | 中国面料入越关税（RCEP/中国-东盟 FTA 框架下多数零关税/低关税） |
| 转口风险 | 借越南转口美国规避关税 = CBP 重点打击（见 `trade-compliance/transshipment-anti-circumvention.md`） |
| 反倾销 | 越南对美出口的木质橱柜/轮胎等被反倾销——纺织目前安全但需关注 |

## 五、消费市场（次要机会）

- 1 亿人口+年轻结构（中位年龄 32 岁）——电商高增长（Shopee/TikTok Shop 越南）；
- 本土品牌弱（国际品牌主导）——中国服装品牌出海机会（UR/波司登模式）；
- 消费力有限（人均 GDP $4000+）——中低价位为主。

## 六、实操建议

1. **面料出口商**：把越南当成"第二个内销市场"（地理近/文化通/量大）——驻越销售+现货仓模式；
2. **成衣出口商**：评估"中国高端+越南基础"的双基地策略；
3. **品牌方**：越南制造标签在美国消费者认知中无劣势（Nike 背书效应）；
4. **关注政策**：越南电价/环保/工资政策变动影响产能成本。
