# 拉美市场深度指南（Latin America Market）

拉美 6.6 亿人口、中产扩容、电商增速全球前列（美客多 Mercado Libre 生态）。对中国服装出口，拉美是"高关税 + 高物流成本 + 高价格承受力"的三高市场——门槛过滤了竞争者，进去后利润可观。

## 一、主要市场格局

| 国家 | 人口 | 特征 |
|:---|:---|:---|
| 巴西 | 2.1 亿 | 拉美最大；本土纺织业受保护，进口关税高（II 35% + IPI + ICMS 叠加综合税负可达 60-90%） |
| 墨西哥 | 1.3 亿 | USMCA 成员，本土成衣业强；对中国面料需求大（服装加工出口美国） |
| 智利 | 2000 万 | 最开放（与中国 FTA，多数商品零关税），但人口小 |
| 哥伦比亚 | 5200 万 | 麦德林纺织集群，进口面料+本土加工 |
| 秘鲁 | 3400 万 | 与中国 FTA；本土棉（Pima 皮马棉产地） |
| 阿根廷 | 4600 万 | 外汇管制严格，付款风险最高 |

## 二、准入与关税

### 巴西（最难）
- **综合税负**：II（进口税，服装 35%）+ IPI（工业产品税 0-25%）+ PIS/COFINS（9.25%）+ ICMS（州流转税 17-25%）——层层税基包含前序税种，综合税负可达 CIF 价的 60-90%。
- **进口许可**：部分纺织品需提前申请进口许可。
- **Remessa Conforme**：跨境电商 50 美元以下包裹合规计划（20% 进口税 + 17% ICMS）。

### 墨西哥
- 服装进口关税 20-25%；2024-2026 年多次对中国纺织品加征临时关税（保护本土产业）。
- **IMMEX 保税加工**：面料进口墨加工再出口美国可免墨方关税——"中国面料 + 墨西哥成衣 + 美国市场"路径（注意美国原产地规则：墨产成衣需满足 yarn-forward）。

### FTA 红利
- **智利/秘鲁/哥斯达黎加**：与中国有自贸协定，纺织品逐步零关税——提供 CO（Form F/中秘证书）享惠。
- 厄瓜多尔 2024 年起生效中厄 FTA。

## 三、采购与商务特征

- **语言**：西班牙语为主（巴西葡萄牙语）——报价单/洗唛/吊牌需西语（巴西要求葡语标签）。
- **尺码**：接近欧码偏小；拉美体型版型需调整（臀围比例）。
- **风格**：色彩鲜艳、印花大胆；宗教节日（亡灵节/狂欢节）特色品类。
- **订单节奏**：季节与北半球相反（巴西 12 月夏季）——反季订单可平衡产线淡季。
- **MOQ 灵活**：拉美进口商首单普遍小（试单 500-2000 件），翻单稳定。

## 四、付款与风控（核心风险区）

| 风险 | 对策 |
|:---|:---|
| 外汇管制（阿根廷） | 仅接受 100% 前 T/T；阿根廷单不接账期 |
| 本币贬值 | 美元计价；雷亚尔/比索波动期缩短报价有效期 |
| 进口商弃货 | 高关税国家弃货成本低→客户弃货时转卖难（关税已缴）——收 30-50% 定金覆盖风险 |
| 银行信用 | L/C 仅接受一流银行（巴西 Itaú/Bradesco、墨 Banamex）；本地小银行 L/C 视同 D/P 风险 |
| 中信保 | 拉美买家额度审批较严，提前查额度再谈账期 |

## 五、物流

- 海运：中国→桑托斯（巴西）35-45 天、→曼萨尼约（墨西哥）18-25 天（太平洋航线）。
- 清关：巴西清关慢（7-15 天常见），文件瑕疵罚款高——发票箱单必须与实际货物 100% 一致（巴西海关以严著称）。
- 电商物流：美客多/亚马逊巴西站本土仓模式增长（见 `trade-process/cross-border-ecommerce-logistics.md`）。

## 六、实操要点

1. **首单结构**：高关税市场首单小批量试单，验证客户清关能力与付款信用。
2. **认证**：巴西部分品类需 INMETRO 认证；墨西哥 NOM 标签认证。
3. **标签**：巴西葡语标签（成分+原产国+进口商 CNPJ）；墨西哥西语 NOM-004 标签。
4. **反季营销**：利用南北半球反季——6-8 月推春夏款给巴西/阿根廷客户。
5. **展会**：巴西 São Paulo 纺织展、墨西哥 Intermoda 服装展是主要获客渠道。
