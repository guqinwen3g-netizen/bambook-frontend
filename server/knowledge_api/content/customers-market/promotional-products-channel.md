# 美国促销品渠道（Promotional Products: ASI/PPAI 体系）

美国促销品行业规模 $250 亿+：**企业定制 logo 的服装/帽/包**，经 ASI/PPAI 分销商体系流转。订单逻辑 = **大走量 + 急交期 + 极低价格 + 印绣花配套**——与品牌订单完全不同的生意。

## 一、行业结构

```
中国工厂 → 美国空白衫批发商（supplier）→ 分销商（distributor，2-4 万家小 B）→ 终端企业客户
```

- **ASI / PPAI**：行业两大协会（会员编号=准入门票）；展会（ASI Show/PPAI Expo——见 `trade-process/overseas-exhibition-playbook.md`）；
- **空白衫批发巨头（中国工厂的直接客户）**：
  | 批发商 | 特点 |
  |:---|:---|
  | SanMar | 最大（Nike/Adidas 授权+自有品牌 Port & Company/Gildan 分销） |
  | Alphabroder | 全品类（含运动/工装） |
  | S&S Activewear | 快反配送见长 |
  | Gildan 自有渠道 | 垂直一体化（自产+分销——价格标杆） |
- **分销商**：服务终端企业（活动衫/员工服/礼品/赛事周边——单小但频次高）。

## 二、主力品类与订单特点

| 品类 | 规格 | 价格带（空白件） |
|:---|:---|:---|
| 文化衫 T 恤 | 180-220gsm 全棉/涤棉 | $1.5-3.5 |
| Polo | 珠地棉 | $4-8 |
| 卫衣/帽衫 | 抓绒（见 `garments/hoodies-sweatshirts-production.md`） | $6-12 |
| 帽子 | 棒球帽（见 `garments/fashion-accessories-hats-scarves.md`） | $2-5 |
| 托特包/围裙 | 帆布（见 `fabric/canvas-oxford-fabrics.md`） | $1-4 |

- **印绣花配套**：logo 1-4 色丝印为主（量大用机印——见 `garments/printing-embroidery.md`）；左胸刺绣（polo/帽）；
- **交期**：报价 24-48h 响应； blanks 现货模式（美国仓备空白衫——下单即印）+ 定制单 2-4 周；
- **合规**：CPSIA（童装促销品——见 `trade-compliance/cpsc-children-safety.md`）、Prop 65（见 `trade-compliance/california-prop65.md`）、产品责任险。

## 三、中国工厂进入路径

| 路径 | 门槛 | 优劣 |
|:---|:---|:---|
| 成为批发巨头供应商 | 验厂（社会责任）+EDI+年产能承诺 | 量大稳定/价格硬（Gildan 垂直成本标杆压顶） |
| 服务中型分销商 | ASI 会员+美国仓/代发能力 | 灵活/利润略高，需本地服务 |
| 跨境电商定制（Etsy/亚马逊定制） | 小单快反+印花能力 | 零售毛利高但单散 |

- **竞争格局**：空白衫面临**海地/洪都拉斯/尼加拉瓜（加勒比盆地免税）+ 墨西哥（USMCA）+ 孟加拉**夹击——中国优势在面料一体化与印绣花复杂工艺、混纺/功能性差异化；
- **关税变量**：de minimis 取消后直邮定制模式成本重构（见 `trade-process/cross-border-ecommerce-logistics.md`）。

## 四、报价与风控

- **报价结构**：空白件 FOB + 印绣花加工费（按色数/针数）+ 包装（独立胶袋+尺码贴）；
- **印绣花确认**：logo 矢量稿（AI/EPS）+ 潘通号对色（见 `suppliers/subcontracting-outsourcing-management.md` 外发印花标准）；
- **风险**：
  - 图案侵权（分销商提供的 logo 需授权证明——见 `trade-compliance/ip-brand-authorization.md`）；
  - 旺季爆单交期（4-6 月毕业季/选举年活动衫脉冲）；
  - 库存：客户取消单=无品牌空白衫可转售（比品牌单风险低）。
