# 美国折扣零售渠道专题（US Off-Price Retail Channel）

Off-price 折扣渠道（TJX/Ross/Burlington）是"**品牌尾货与库存的最大出口**"：年销超千亿美元，也是服装厂处理库存和接补单的重要渠道。

## 一、渠道格局

| 零售商 | 规模/特征 |
|:---|:---|
| TJX（TJ Maxx/Marshalls/HomeGoods） | 全球最大折扣零售商（年收 500 亿美元+——门店 4900+） |
| Ross Stores | 美国第二（年收 200 亿美元+——低价定位） |
| Burlington | 第三（转型全价+折扣混合） |
| Nordstrom Rack/Saks OFF 5TH | 百货旗下折扣线（中高端尾货） |
| 线上折扣 | Rue La La/Gilt（闪购模式） |

## 二、运作模式（与正价零售根本不同）

- **买手 opportunistic buying**：不订期货——扫货模式（品牌取消单/过季库存/减产订单）;
- **折扣深度**：正价的 40-60%（吊牌价对比是核心营销——"compare at $XX"）;
- **快速周转**：门店每周上新（寻宝式购物——库存周转 8-10 次/年 vs 百货 4 次）;
- **不退货条款**：与品牌方交易多为一锤子买卖（no return——品牌清库存意愿高）;
- **无线上主导**：TJX 线上占比极低（门店寻宝体验——抗电商冲击的零售模式）。

## 三、货源结构（服装厂机会点）

- **品牌取消单（cancelled orders）**：品牌砍单后工厂转售（需品牌授权放货——法律红线）;
- **过季库存**：品牌季末清仓（整批买断）;
- **减产/溢装**：订单溢短装多产部分（合同允许范围内的超产）;
- **专门生产**：TJX 体量已大到直接下单生产专供款（packaway 模式——买好存仓明年卖）;
- **尾货中介**：jobber/库存买手（中美之间的库存贸易中间商）。

## 四、进入方式与注意

- **品牌授权**：带品牌标的尾货必须品牌书面放行（否则商标侵权——美国海关扣货风险，见 `trade-compliance/ip-brand-authorization.md`）;
- **剪标要求**：部分品牌要求去标/剪标后放行（保护正价渠道）;
- **价格核算**：尾货价通常为成本 30-50%（回笼现金优先——库存持有成本见 `fabric/fabric-inventory-stock-strategy.md`）;
- **供应商资质**：TJX 等对供应商有合规要求（验厂/社会责任——大厂直接对接，小厂走中介）;
- **订单特征**：整批现货+快速决策（窗口期短——报价 24-48 小时有效）。

## 五、对服装厂的战略价值

- **库存变现**：取消单/溢装货快速回笼（比国内直播清货价高）;
- **产能填谷**：淡季接折扣渠道专供单（packaway 计划性订单）;
- **客户转型跳板**：部分厂从尾货供应升级为 TJX 直采供应商（稳定量大——价格硬但账期可靠）;
- **风险**：尾货渠道依赖=利润薄+无品牌沉淀（现金流业务非主业）。

## 六、市场背景（2026）

- **消费降级利好**：通胀环境下 off-price 增速持续跑赢百货（中产消费下移）;
- **品牌库存周期**：疫后库存过剩→出清→常态化（2024-2026 供需恢复平衡——尾货供给减少价格回升）;
- **关税影响**：301 关税推高新品成本（折扣渠道相对优势——见 `trade-compliance/us-tariff-2026.md`）。
