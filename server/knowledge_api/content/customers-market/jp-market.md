# 日本市场（Japan Market）

日本市场以极致的品质要求、精细化管理与长期稳定的合作关系著称。单价高、订单稳，但准入门槛与质量容错率全球最低。

## 一、市场概况

- **规模**：日本服装市场约 7.8 万亿日元，进口渗透率超 98%，中国占其服装进口约 55%。
- **客户类型**：
  - **商社（trading company）**：伊藤忠、丸红、住友等，连接品牌与工厂，订单规范、付款准时。
  - **品牌/零售商**：优衣库（Fast Retailing）、无印良品、岛村（Shimamura）等，自有供应链管理体系。
  - **中小品牌**：小批量、多批次，注重设计细节与面料品质感。
- **合作特征**：一旦通过验厂与首单验证，合作关系极稳定，可长达十年以上；但试错机会通常只有一次。

## 二、品质文化：全数检品与检针

### 全数检品（100% inspection）
- 日本市场**不接受抽样合格即放行**的欧美惯例，高端订单普遍要求**全数检品**（每件成衣逐一检查）。
- 检品在日本国内检品中心或中国第三方检品公司（如 QIMA 日本专线、日本检品株式会社）执行。
- 疵点判定远严于 AQL：轻微抽纱、线头、污渍均可被判不良。
- 不良品处理方式：修整（repair）、降等（B grade）或退回，费用由供方承担。

### 检针（needle detection）
- 出口日本的服装**必须 100% 过检针机**（conveyor needle detector），检测断针与金属异物。
- 检针记录需存档备查；童装、婴儿装要求最严。
- 断针管理：工厂需建立断针回收与登记制度（broken needle log），机针以旧换新。

### AQL 标准
- 日本客户常用 **AQL 2.5**（major）甚至 1.5，minor 疵点容忍度也远低于欧美。
- 验货不通过通常**没有第二次验货机会**，直接取消订单或巨额索赔。

## 三、标签与法规

### 家庭用品品质表示法（强制）
- 成衣必须有**日文标签**：纤维成分（日文或国际符号）、洗涤表示（JIS L0001 洗涤符号）、原产国、经销商信息。
- 洗涤符号采用日本 JIS 体系（与国际 ISO 符号有差异，如水温标注方式不同），需专门制版。
- 标签缝制位置、方式也有惯例（主唛后领、洗唛左侧缝）。

### 其他法规
- **有害物质管控**：日本《含有害物质家庭用品规制法》管控甲醛（婴幼儿 ≤ 16 ppm）、偶氮染料等。
- **包装要求**：独立胶袋 + 防潮纸常见；吊牌印刷精美度直接影响终端评价。

## 四、尺码与版型

- **尺码体系**：JP 尺码（S/M/L/LL/3L，或数字 7-15 女装），整体比欧美偏小 1-2 码。
- **版型偏好**：合体、细节精致；对缝线平整度、对条对格、左右对称性要求极高。
- **尺寸公差**：通常 ±1cm 以内（欧美 ±1.5-2cm），量尺寸方法需按客户仕样书（spec sheet）执行。

## 五、商务习惯

- **订单特征**：单款量小（500-3,000 件常见）、批次多、交期紧凑（45-60 天）。
- **付款方式**：商社订单信誉极好，T/T 30 天或出货后付款常见；坏账率全球最低。
- **沟通风格**：谨慎、重细节、决策慢但执行严格；邮件需逐项回复，不能遗漏问题。
- **样品文化**：样品必须与大货零差异；产前样（pre-production sample）确认流程严格，未经确认不得开裁。
- **索赔文化**：问题发生时客户会提供详尽的不良报告（照片 + 数据），索赔金额精确但通常合理；及时认责 + 改进方案比辩解更能维护关系。

## 六、实操要点

1. **产能匹配再接单**：全数检品意味着返工成本极高，品质不稳定时不要碰日本订单。
2. **检针设备必备**：接日本单工厂必须有检针机与断针管理制度，验厂必查。
3. **仕样书逐条核对**：日文仕样书（规格书）是生产圣经，翻译后由懂日文的跟单逐项确认。
4. **预留检品时间**：出货计划包含检品周期（通常 3-7 天），避免船期延误。
5. **重视包装细节**：折衣方式、胶袋贴纸位置、箱唛格式都有明确要求，按指示书执行。
