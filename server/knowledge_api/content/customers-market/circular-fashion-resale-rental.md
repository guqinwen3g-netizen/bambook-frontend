# 循环时尚商业模式（Resale/Rental/Repair: 二手平台/租赁/品牌回收）

循环时尚（circular fashion）从环保概念变成真实商业：全球二手服装市场 $2000 亿级（增速快于新品）、欧美 Z 世代 40%+ 买过二手服装。对纺织服装企业的意义：理解品牌客户的循环战略（影响新品订单结构）+ 抓住新增量（翻新加工/再制造/回收纤维）。政策法规面见 `trade-compliance/textile-waste-circularity-policy.md`，旧衣出口贸易见 `trade-process/used-clothing-export-trade.md`。

## 一、商业模式图谱

| 模式 | 代表 | 盈利逻辑 | 纺织企业触点 |
|:---|:---|:---|:---|
| 二手平台（C2C 寄售） | ThredUp/Poshmark/Vinted（欧）/闲鱼 | 佣金 20-30%+鉴定服务 | 无直接（抢新品份额） |
| 奢侈品二手（鉴定制） | Vestiaire Collective/The RealReal | 高佣金+鉴定壁垒 | 无直接 |
| 品牌自营二手（trade-in） | Patagonia Worn Wear/lululemon Like New/Levi's SecondHand | 用户粘性+ESG 叙事+全生命周期利润 | **翻新整理加工外包机会** |
| 租赁（rental） | Rent the Runway/衣二三（已倒闭） | 订阅制 | 高周转损耗品供应+清洗维护 |
| 修补服务（repair） | 品牌终身保修（Patagonia/始祖鸟） | 品牌溢价支撑 | 修补工单外包 |
| 回收再制造 | Renewcell（破产）/Circ/再生涤纶 | 纤维到纤维闭环 | 再生纱线采购（见 `fabric/sustainable-fabrics.md`） |

## 二、品牌循环战略对供应商的影响

- **耐用性叙事**："少买买好"（buy less buy better）——品牌把耐用测试（30 次水洗质保）变成卖点，**供应商的耐久品质数据成为接单筹码**；
- **可维修设计**：可替换拉链/补丁结构设计——打样阶段参与度提高；
- **单一材质**：便于回收的 100% 涤/100% 棉设计（放弃混纺）——面料开发方向变化；
- **回收计划**：品牌门店回收旧衣（H&M/IKEA 类）——分选后的去向：二手出口（见 `trade-process/used-clothing-export-trade.md`）、降级回收（擦机布/保温棉，见 `fabric/industrial-wipes-cleaning-cloths.md`）、纤维再生；
- **DPP 数据**：循环的前提是产品数据留存（成分/拆解指南）——欧盟 DPP 强制后供应商需提供结构化数据（见 `trade-compliance/eu-espr-dpp.md`）。

## 三、新生意机会评估

- **翻新整理加工**：品牌二手业务的实物处理（清洗/消毒/修补/整烫/拍照上架）——劳动密集型，**中国工厂可服务东南亚/国内品牌**，欧美品牌多用本地社会企业（运费+碳足迹叙事）；
- **租赁供应链**：工装/酒店布草租赁已成熟（见 `garments/hotel-linen-b2b.md`）；时装租赁在中国未跑通（卫生信任+快递成本），但**礼服/婚纱/童装租赁**细分仍有机会（见 `garments/evening-wedding-dress.md`）；
- **认证与标准**：二手商品卫生标准（消毒工艺）、再生成分认证（GRS/RCS——见 `trade-compliance/textile-certifications.md`）是准入门槛；
- **风险叙事**：循环模式被品牌用于营销，实际占比多数 <5%——**供应商不必为此调整主线产能**，关注但不押注；反漂绿监管见 `trade-compliance/green-claims-anti-greenwashing.md`。

## 四、数据与观察指标

- 二手价格锚点：热门单品二手价/新品价比值（高保值品牌=品质叙事真实——反推其供应链标准）；
- 平台 SKU 结构：快时尚单品在二手平台流转快（Shein 同款在 Vinted 量大）——反映真实消费需求；
- 政策节点：法国纺织品 EPR 返还金、欧盟纺织品回收令时间表（见 `trade-compliance/packaging-epr-regulations.md`、`trade-compliance/textile-waste-circularity-policy.md`）。
