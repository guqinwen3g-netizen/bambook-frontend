# 印度市场指南（India Market）

印度 14 亿人口、全球第二大纺织服装生产国——对中国企业是**"竞争对手 + 潜力市场 + 原料产地"三重角色**。市场进入门槛高（关税+认证+本土保护），但增量诱人。

## 一、三重角色认知

| 角色 | 含义 |
|:---|:---|
| 竞争对手 | 印度棉纺/成衣与中国争夺欧美订单（棉制品优势+英语+民主供应链叙事） |
| 潜力市场 | 中产 3-4 亿人扩容，服装消费年增 8-10%——但中国成品进入受高关税限制 |
| 原料产地 | 印度棉（Shankar-6）、纱线（32S/40S 棉纱价格常低于中国）——中国面料厂采购印度棉纱套利 |

## 二、市场准入（高门槛）

### 关税
- 服装进口基本关税（BCD）20% + 社会福利附加税（SWS 10% of BCD）+ IGST 5%——**综合税负约 28-30%**；
- 中印无 FTA（印度退出 RCEP 谈判——核心顾虑即中国纺织品冲击）。

### 认证
- **BIS 认证**：部分纺织品（涤纶长丝/棉纱等原料类）纳入 BIS 强制认证（QCO 质量控制令）——中国原料输印需 BIS 注册；
- 成衣零售标签：纤维成分+原产国+进口商信息（英文）。

### 非关税壁垒
- 海关估价严格（低报价格风险高）；原产地核查趋严（经第三国转口至印度的中国货被重点关照）；
- 2020 年后对华贸易政策整体收紧（APP 禁令/投资审查 Press Note 3）。

## 三、本土纺织业格局

- **产业链完整**：棉花（全球第二大产棉国）→ 纺纱（全球第二）→ 织造 → 成衣；集群：蒂鲁普尔（Tirupur 针织之都）、卢迪亚纳（毛衫）、苏拉特（化纤）。
- **PLI 计划**：印度政府生产激励计划扶持 MMF（化纤）与技术纺织品——印度正补化纤短板。
- **对中国依赖**：面料（尤其化纤面料/功能性面料）、辅料、纺织机械——**中国面料出口印度是现实机会**（印度面料自给率化纤类不足）。

## 四、市场进入路径

1. **面料/纱线 B2B 出口**：印度成衣厂采购中国功能性面料/差异化面料（本土不足的品类）——主要现实路径；
2. **品牌授权/合资**：与印度本土集团（Reliance/Aditya Birla Fashion）合作进入零售；
3. **跨境电商**：SHEIN 模式曾被禁（2020 年 APP 禁令），2023 后借道亚马逊印度站回归——政策风险高；
4. **设备与技术输出**：纺机/印染设备出口（印度产能扩张期）。

## 五、竞争情报（作为对手）

- **印度优势**：棉花原料、棉纺成本、英语沟通、欧美"中国+1"受益、美印关系红利；
- **印度短板**：化纤产业链不全、交期稳定性（电力/物流基建）、劳工法规僵化（100 人以上解雇需政府批准——2020 劳工法改革推进中）；
- **中国应对**：差异化（功能面料/快反能力/化纤优势品类）+ 锁定印度做不了的高端订单。

## 六、风险提示

- **政策突变**：对华贸易政策随边境局势波动——合同加不可抗力与政策变化条款；
- **付款**：印度进口商信用分化大，L/C 只认一流银行（SBI/HDFC/ICICI）；卢比汇率长期贬值趋势；
- **合规灰色地带**：印度海关自由裁量大——靠谱的清关代理是必需品。
