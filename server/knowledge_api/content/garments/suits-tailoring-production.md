# 西装与正装品类生产专题（Suits & Tailoring Production）

西装是服装制造的"**技术天花板**"——一件全麻衬西装 300+ 道工序，衬布结构/归拔工艺/手工含量决定档次。中国承接全球中高端西装代工（意大利品牌亦有中国产线），同时国内定制西装市场持续增长。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 商务西装（suit） | 两件套/三件套——正装核心 |
| 单西/布雷泽（blazer） | 不成套上衣——商务休闲 |
| 礼服（tuxedo/晨礼服） | 婚礼/宴会——缎面戗驳领 |
| 西裤/马甲 | 套装组件 |
| 正装衬衫/大衣 | 配套品类 |

## 二、衬布结构（档次分水岭）

| 结构 | 工艺 | 成本/档次 |
|:---|:---|:---|
| 粘合衬（fused） | 胸衬热熔粘合 | 流水线量产——中低端（前胸易起泡是痼疾） |
| 半麻衬（half canvas） | 胸部毛衬+下摆粘合 | 中高端主流——性价比最优 |
| 全麻衬（full canvas） | 整片毛衬手工纳衬 | 高端定制——前胸随体型"活"（越穿越合身） |

- **毛衬（canvas）**：马尾衬/黑炭衬（马尾毛+棉/毛混织）——回弹性是灵魂；
- **鉴别方法**：捏前胸——全麻衬有"蓬松空气感"层，粘合衬是死板一层。

## 三、核心工艺

- **归拔（easing/stretching）**：熨斗归拢拔开塑形（胸凸/腰吸/背拢）——西装立体感的根源，机器无法替代师傅手感；
- **纳驳头**：手工纳驳头衬（驳头翻卷自然——机器纳的翻不出"活"卷）；
- **真袖衩/真开衩**：高端标识（袖衩真开真扣 vs 装饰假衩）；
- **拱针/珠边（pick stitching）**：领边门襟手工拱针——装饰+档次标识；
- **米兰眼（Milanese buttonhole）**：手工锁驳头花眼——顶级定制标识；
- **工序量**：粘合衬西装 ~150 道工序，全麻衬 300+（工费差 3-5 倍）。

## 四、面料（精纺毛料为主）

- **精纺羊毛（worsted）**：Super 100s-150s（纱支越高越细滑也越娇——Super 130s 以上日常穿易磨亮）；
- **面料品牌梯队**：Scabal/Dormeuil/Loro Piana（顶级）→ VBC/Reda（高端意大利）→ 国产南山/阳光（中端性价比）；
- **成分创新**：毛涤混纺（抗皱耐用——商务日常）、毛+弹（2% 氨纶舒适度）、羊毛+亚麻/丝（夏季）；
- **里料**：宾霸（cupro 铜氨丝——透气抗静电首选）vs 涤纶里布（低端）。

## 五、版型体系

- **英版（British）**：收腰/厚垫肩/双开衩（结构化——萨维尔街传统）；
- **意版（Italian）**：轻垫肩/薄衬/贴体（南意那不勒斯软结构——"穿了像没穿"）;
- **美版（American sack）**：直筒无省/单开衩（常春藤传统——宽松）；
- **亚洲版**：改短衣长/收袖窿（日韩版型适配亚洲体型）；
- **下单要点**：版型确认用试穿模特+量体数据——"修身"无标准，必须给尺寸表（见 `garments/pattern-grading-sizing.md`）。

## 六、订单与市场

- **出口 OEM**：欧美中端品牌西装（粘合/半麻衬）——中国大连/江浙产能为主；
- **定制市场**：国内 MTM（made-to-measure）定制爆发（婚礼/商务——报喜鸟/蓝豹模式）；
- **团单职业装**：银行/航空/地产制服（招投标模式——关系型市场）；
- **女装西装**：女式 power suit 增长（版型借男装工艺——女西装胸省处理是技术点）；
- **趋势**：商务休闲化（无衬/轻结构 "unstructured jacket"）+ 弹力通勤西装（针织西装——传统西装厂转型方向）。

## 七、产业带

- **辽宁**：大连（西装出口集群——日韩欧美订单）；
- **浙江**：宁波（雅戈尔/杉杉发源地——红帮裁缝传承）、温州；
- **江苏**：苏州/无锡（高端定制工坊）；
- **广东**：广州/深圳（女式西装/时尚西装）。
