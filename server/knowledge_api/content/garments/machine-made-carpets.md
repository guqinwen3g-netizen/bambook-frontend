# 机织地毯与商用地毯（Machine-made Carpets: 阿克明斯特/威尔顿/簇绒/方块毯）

地毯是家纺中**货值最高、工程属性最强**的品类：酒店走廊/宴会厅/会议室满铺毯、办公方块毯、家用块毯。产业带：山东（威海/德州——山花/海马为龙头）、江苏溧阳、河北（家用地垫集群）。出口=中东（祈祷毯+家用毯刚需）+欧美商用工程+家用地毯电商。与地垫门垫（见 `garments/door-mats-floor-coverings.md`）相邻但工艺与渠道完全不同。

## 一、工艺体系（决定价格带）

| 工艺 | 结构 | 特点 | 应用 |
|:---|:---|:---|:---|
| 手工打结（hand-knotted） | 经纬线逐结 | 波斯毯/藏毯——收藏品级（按结数 KPSI 定价） | 高端家用/礼品 |
| 阿克明斯特（Axminster） | 机织提花——每根绒头独立配色 | 图案精细+绒高密——**五星级酒店标配** | 酒店大堂/宴会厅 |
| 威尔顿（Wilton） | 机织——绒头连续 | 单色/少色几何纹、性价比高 | 酒店客房/走廊 |
| 簇绒（tufted） | 针剌植绒+背胶底布 | 产量最大、成本低 | 商用满铺/家用块毯 |
| 方块毯（carpet tile） | 50×50cm 模块化 | 办公主流——局部更换 | 写字楼/机场 |
| 印花毯 | 簇绒白坯+数码印花 | 图案无限——定制地毯（logo 毯/儿童毯） | 电商定制单 |

- **纱线材料**：羊毛（高端——天然阻燃+回弹，阿克明斯特主材）、尼龙 6/66（商用耐磨首选——原液着色抗污）、PP 丙纶（经济型——色牢度好但回弹差）、涤纶（家用印花毯）；
- **底背**：黄麻（天然——高端）/PP 编织布+乳胶（簇绒）/PVC 或 PU 底（方块毯——尺寸稳定性核心）。

## 二、核心性能指标

- **绒重（pile weight）/绒高/密度**：克重（oz/yd² 或 g/m²）是定价第一参数——酒店宴会厅 40oz+；
- **耐磨**：Vettermann 滚筒测试/商用等级（Class 31 轻度商用—Class 33 重度商用）；方块毯按 EN 1307 分级；
- **阻燃**：美国 DOC FF-1/FF-2（药丸测试）民用底线；**商用强制 NFPA 253（辐射板测试——临界辐射通量 Class I/II）**；酒店工程还要烟密度；英国 BS 4790；
- **抗静电**：≤3.5kV（人体行走电压——办公环境防设备干扰）——导电纤维混纺；
- **色牢度**：光照（走廊阳光区）+摩擦+**洗发水残留泛黄**（酒店清洁化学品）；
- **声学**：地毯吸音是酒店/办公设计参数（撞击声隔声 ΔLw 值）。

## 三、工程订单逻辑

- **酒店工程**：设计院图纸（分区域花型配色——宴会厅大提花定制设计）→打样（阿克明斯特小机样）→封样→大货；**图案对花拼接**损耗 8-15% 计入报价；铺装指导（接缝方向/张力）；
- **办公方块毯**：模数化（50×50/25×100cm）——**同色号批次一致性**是验收命门（不同批次铺装色差即翻车）；预留 5% 备品（局部更换）；
- **周期**：酒店工程从设计确认到铺装 4-8 个月——与装修总包进度绑定（延迟罚款条款）；地毯常在装修末期进场——**订单交付节点刚性**；
- **出口中东**：祈祷毯（礼拜毯—— arch 拱门图案指向麦加）是文化刚需品；家用大块毯（客厅满铺）——沙特/阿联酋高端别墅市场阿克明斯特有需求（见 `customers-market/middle-east-market.md`）。

## 四、家用与电商

- **家用块毯**：亚马逊/Rugs USA 类——可机洗地毯（Ruggable 模式：毯面+防滑垫分离式）是近五年最大品类创新——**薄毯面数码印花+可洗**是差异化方向；
- **图案驱动**：波斯风/几何/侘寂风季节轮换——数码印花小单快反（见 `fabric/digital-printing-technology.md`）；
- **物流**：地毯是泡货（卷装 2-4m）——海外仓前置（见 `trade-process/overseas-warehouse-operations.md`）；可折叠底背技术解决大规格物流痛点；
- **客诉**：异味（乳胶/背胶 VOC）、掉毛（羊毛毯初期浮毛——标注说明）、卷边、色差。
