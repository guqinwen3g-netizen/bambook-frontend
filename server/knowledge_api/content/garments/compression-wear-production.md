# 压缩服与压力袜生产（Compression Wear: 运动压缩与医用压力）

压缩服饰两条线：**运动压缩**（2XU/Skins 模式——提升表现与恢复，营销驱动）与**医用压力**（静脉曲张袜/术后压力衣——医疗器械监管）。共同技术内核是**梯度压力**（远端高压近端低压），但合规路径完全不同。产业带：浙江诸暨/海宁（袜机集群）、广东。

## 一、两条产品线的本质差异

| 维度 | 运动压缩 | 医用压力 |
|:---|:---|:---|
| 压力值 | 15-25 mmHg（无强制标准） | 分级 Ⅰ级 18-21/Ⅱ级 23-32/Ⅲ级 34-46 mmHg（强制标准） |
| 监管 | 普通消费品 | **医疗器械**（欧盟 MDR Ⅰ类/美国 FDA Ⅰ类、国内二类） |
| 宣称 | "提升表现/加速恢复"（不可医疗宣称） | 适应症宣称（静脉曲张/淋巴水肿） |
| 渠道 | 运动零售/电商 | 药房/医院/医保渠道 |
| 测试 | 企业自定压力曲线 | RAL-GZ 387/ENV 12718/CEN 标准压力测试 |

- **红线**：运动压缩产品**不得宣称治疗功效**（"治疗静脉曲张"= 按医疗器械无证处罚，见 `trade-compliance/product-liability-recall.md`）；
- **医用线门槛**：欧盟 MDR Ⅰ类自我声明+技术文件；国内二类需注册证——医用订单溢价 3-5 倍但资质先行（合规框架参考 `trade-compliance/ppe-protective-clothing-compliance.md` 的认证逻辑）。

## 二、材料与织造

- **纱线组合**：锦纶/涤纶 + 氨纶（莱卡含量 15-30%——**压力来自氨纶弹性回复**）；医用压力袜用包覆纱（氨纶外包锦纶，压力更稳定）；
- **织造设备**：无缝圆机（圣东尼 SM8/SM4 系列，袜机改型）——**一次成型无侧缝**（有缝压缩服用平车+四针六线拼缝，见 `garments/sewing-and-workmanship.md`）；
- **梯度压力实现**：分区密度编程（小腿袜：踝部最密向上递减）——版师按目标压力曲线调机，每档压力留样测压存档；
- **压力测试**：HATRA 法/Hosy 测试仪（袜口/踝/小腿多点测压）——**每缸抽测压力值**（氨纶批次差异导致压力漂移是最大质量风险）。

## 三、生产与品质要点

- **尺码决定压力**：同一双袜子穿在不同腿围上压力不同——**尺码表按"踝围+小腿围"双维度**（医用线强制）；尺码错=压力错=无效或伤害；
- **罗口设计**：防滑硅胶点/加宽罗口——医用袜罗口压力必须低于袜身（防止血带效应）；
- **耐洗保持**：氨纶疲劳——宣称"洗涤 30 次压力保持 ≥80%"需测试支撑（氯漂禁止标注）；
- **穿着辅助**：医用高压袜配穿袜器/丝滑内衬——配件齐套率影响差评率；
- **验货增项**：压力抽测+拉伸回复+尺码实测（对照尺码表公差 ±0.5cm）——见 `trade-process/pre-shipment-inspection-sop.md`。

## 四、市场与接单

- **运动线客户**：运动品牌配件线、马拉松/骑行社群品牌、亚马逊自有品牌——看卖点故事（"恢复科技"）与测评口碑；与骑行服/跑步装备联动（见 `garments/cycling-wear-production.md`）；
- **医用线客户**：欧美药房渠道（SIGVARIS/Medi 代工）、医院集采、术后康复机构——**订单稳定但准入周期长**（送样→临床评价→试单 6-12 个月）；
- **孕妇压力袜**：细分市场（孕期静脉曲张预防）——配合孕妇装线（见 `garments/plus-size-maternity-wear.md`）；
- **报价要点**：无缝机台产量低（一双 8-15 分钟）——报价按机时核算；氨纶用品牌（莱卡/晓星）与杂牌价差大，合同注明品牌。
