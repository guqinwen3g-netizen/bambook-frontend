# 服饰配件生产专题（Fashion Accessories: Hats, Scarves, Gloves, Belts）

服饰配件（fashion accessories）是"小品类大生意"：单价低但连带率高（随服装订单配套采购），且配饰品牌订单是进入品牌供应链的低门槛切入点。

## 一、帽子（Hats & Caps）

### 品类与工艺
| 品类 | 工艺要点 | 产业带 |
|:---|:---|:---|
| 棒球帽（baseball cap） | 六片/五片结构、帽眉（visor）插板、绣花/印花 logo、调节扣（魔术贴/铜扣/塑胶排扣） | 江苏扬州/山东青岛 |
| 针织帽（beanie） | 圆机/横机针织、翻边罗纹、提花 | 浙江 |
| 渔夫帽（bucket hat） | 梭织面料、帽檐定型 | 扬州 |
| 草帽 | 草编工艺（拉菲草/纸草）、定型 | 浙江温岭 |

### 关键参数
- **头围尺码**：57/58/59cm（均码带调节扣为主）；童帽 52-54cm；
- **帽眉定型**：PE 插板（平眉/弯眉——弯眉需热定型）；
- **内衬**：汗带（sweatband）吸湿棉/网布；
- **绣花**：帽片平绣 + 立体绣（puff embroidery）——帽绣对花居中精度要求高。

## 二、围巾（Scarves）

| 材质 | 工艺 | 市场 |
|:---|:---|:---|
| 羊绒/羊毛围巾 | 梭织/针织、起绒 | 高端（欧美冬礼季） |
| 真丝围巾 | 印花（台版/数码）、手工卷边（hand-rolled hem 是高端标志） | 中高端 |
| 涤纶仿真丝 | 数码印花、机器卷边 | 大众/促销礼品 |
| 棉麻围巾 | 色织/印花 | 春夏 |
| 针织围巾 | 横机/圆机、提花 | 冬装配套 |

- **尺寸规格**：方巾（90×90 / 140×140cm）、长巾（180×70 / 200×90cm）；
- **卷边工艺**：手工卷边（法式设计感）vs 机卷边 vs 流苏（fringe）；
- **节日礼品季**：圣诞季（8-9 月下单）是围巾出口峰值——礼盒包装配套。

## 三、手套（Gloves）

| 品类 | 要点 |
|:---|:---|
| 针织手套 | 圆机/横机；触屏纱线（导电纱）是功能升级点 |
| 皮手套 | 羊皮/猪皮裁剪缝制；里衬（羊绒/摇粒绒） |
| 滑雪手套 | 防水透气膜+保温棉（3M Thinsulate）——户外工艺 |
| 防晒手套 | UPF50+ 面料（骑行/驾驶场景） |

- **尺码**：S/M/L/XL（掌围+中指长度）；
- **触屏兼容**：电商 listing 必备卖点（拇指/食指导电纱）。

## 四、腰带（Belts）

- **材质**：真皮（头层/二层）、PU 革、织带（帆布腰带）、编织腰带；
- **扣头**：锌合金压铸（pin buckle/板扣/自动扣）——扣头电镀质量（盐雾测试 48h）；
- **尺码**：按腰围长度（欧码 85-115cm）——带身打孔 5 孔间距 2.5cm 惯例；
- **合规**：皮革材质标注（欧盟真皮标注规则——"genuine leather" 泛指标的合规性注意）；镍释放（扣件，见 `trade-compliance/chemical-environmental-compliance.md`）。

## 五、订单与渠道特征

- **配套采购**：服装品牌的配饰连带单（"服装+帽子+围巾"套装方案）——配饰是订单增值抓手；
- **促销礼品市场**：广告帽/围巾（企业定制 logo）——B2B 礼品渠道大走量；
- **季节波段**：冬配饰（针织帽/围巾/手套）8-9 月出货峰值；夏配饰（棒球帽/草帽）2-3 月；
- **MOQ 友好**：帽/围巾 500-1000 件起——新供应商切入品牌的低门槛品类。

## 六、质量检验要点

| 品类 | 关键检验 |
|:---|:---|
| 帽 | 帽型对称、绣花花位、汗带缝合、调节扣拉力 |
| 围巾 | 尺寸公差、卷边质量、印花对花、色牢度 |
| 手套 | 左右对称、指长公差、触屏功能、缝线牢固 |
| 腰带 | 带身厚度均匀、扣头电镀/盐雾、打孔光滑 |
