# 成衣成本核算与报价（Garment Costing & Pricing）

精准的 costing 是外贸盈利的底盘——报价高 5% 丢单，低 5% 亏损。成本核算必须逐项拆解、留痕可复核。

## 一、FOB 成本结构拆解

```
FOB 单价 = 面料成本 + 辅料成本 + 印绣加工 + 工费(CMT) + 包装 + 厂内费用 + 利润
         + 国内运输/商检/报关 + 银行/平台费用
```

典型占比（针织 T 恤示例）：

| 项目 | 占比 | 说明 |
|:---|:---|:---|
| 面料 | 45-55% | 最大变量 |
| 工费（CMT） | 20-30% | 裁剪+缝制+后整 |
| 辅料 | 5-10% | 唛头/线/扣/拉链 |
| 印绣 | 0-10% | 按工艺另计 |
| 包装 | 2-5% | 胶袋/纸箱/人工 |
| 费用+利润 | 8-15% | 管理费、退税收益调节、利润 |

## 二、面料成本核算（核心变量）

### 单耗计算
- **针织（按重量）**：单件耗料(kg) = 单件成品克重 ÷ (1 - 裁剪损耗率 5-8%)；或直接按排料图（marker）测算：单耗 = 幅宽内排料面积 × GSM × (1 + 损耗 3-5%)。
- **梭织（按长度）**：单耗(米) = 排料长度 ÷ 利用率（85-92%）；缩水率要计入（预缩布按实测调整）。
- **对条对格（matching）**：格仔/条子布单耗增加 10-20%。

### 面料价格确认
- 锁定单价时点（棉价波动期报价注明"面料价格随行就市"条款）。
- 含税 vs 不含税：退税订单必须含 13% 增值税专票价核算（退税收益回冲成本）。

## 三、工费（CMT）核算

- **秒时成本法（SMV-based）**：单件工费 = 标准工时（SMV）× 工价/分钟 ÷ 效率。
  - 例：T 恤 SMV 8 分钟，工价 0.5 元/分钟（含效率折扣），工费 ≈ 5-6 元。
- **市场行情参考**（2026 内地工厂）：针织 T 恤 4-8 元、卫衣 10-15 元、衬衫 12-20 元、牛仔裤 15-25 元、西装 80-150 元。
- 工费随订单量、交期、品质要求浮动：小单 +20-30%，加急 +15%，全检品订单 +10-15%。

## 四、印绣与特殊加工

- 印花：版费 ÷ 数量 + 单件印花费（按色数）；绣花：版费 + 按针数计价（见 `garments/printing-embroidery.md`）。
- 洗水（牛仔/成衣染色）：按件 2-8 元，复杂工艺（猫须/破洞）另计。
- 检针/检品费：日本订单全检 0.5-1.5 元/件。

## 五、报价输出规范

### 报价单要素
- 款式图/款号、面料规格（成分/克重/纱支）、尺码范围、数量阶梯（1k/3k/5k 阶梯价）
- FOB 港口、交期、付款方式、报价有效期（通常 15-30 天）
- **不含项声明**：如"不含测试费/验货费/特殊包装"

### 数量阶梯逻辑
- 量越大单耗面料议价空间越大、工费分摊越低；阶梯差通常 3-8%。

### 试算示例（针织 T 恤，3000 件）
```
面料：180GSM 精梳棉 26元/kg × 0.24kg/件     = 6.24
辅料：唛头+线+胶袋                          = 0.55
工费：CMT                                  = 5.50
印花：2 色丝印                              = 1.20
包装运输                                    = 0.60
厂内费用+利润 12%                           = 1.69
小计                                       = 15.78 元
退税回冲（采购进项 13% 部分调节）            ≈ -0.60
FOB 报价 ≈ 15.2 元 ≈ $2.12（汇率 7.16）
```

## 六、报价风险控制

1. **留复核痕迹**：每单 costing 表存档，业务员/成本会计双人复核。
2. **汇率条款**：报价注明基准汇率与有效期（见 `trade-process/foreign-exchange-settlement.md`）。
3. **面料涨价条款**：大货锁价前棉价大幅波动时，合同加"面料价格联动"条款。
4. **样品与试产验证**：新款首单先做 counter sample 复核单耗——纸样估算误差可达 5-10%。
5. **毛利率底线**：常规订单毛利率 ≥ 10%；新客户开发单可降至 5-8%，亏损接单只在策略性填产能时由管理层审批。
