# 演出服与 Cosplay 服装专题（Costume & Cosplay Production）

演出服/Cosplay 是"高溢价长尾品类"：节日驱动（万圣节/嘉年华）、IP 文化驱动（动漫/影视角色）、工艺混合（服装+道具+假发）。中国是万圣节服装全球最大供应地。

## 一、市场结构

| 细分 | 特征 |
|:---|:---|
| 万圣节服装 | 美国万圣节 $40 亿+ 服装市场（9-10 月零售峰值）——狂欢节（巴西/德国科隆）次之 |
| Cosplay 服装 | 动漫展（Comic-Con/CP 展）驱动；还原度是生命线 |
| 舞台演出服 | 剧院/舞蹈团/巡演（小批量高工艺） |
| 主题派对服 | 单身派对/化装舞会（平价走量） |
| 吉祥物服装 | 企业吉祥物/赛事吉祥物（定制重工艺） |

- **渠道**：Spirit Halloween（美国万圣节连锁巨头）、亚马逊、Party City、独立站；
- **节奏**：万圣节订单 3-4 月下单、7-8 月出货（9 月零售上架）——**错过船期=整季报废**。

## 二、工艺特征（区别于常规服装）

1. **非常规材料**：EVA 泡棉（盔甲造型）、PU 革、亮片布、羽毛、LED 灯带（发光服装）；
2. **造型工艺**：立体造型（填充/骨架/热定型）——cosplay 盔甲用 EVA 热塑成型；
3. **印花**：全身定位印花（连体衣肌肉纹/骨骼纹——数码印花主力应用，见 `fabric/digital-printing-technology.md`）；
4. **配件集成**：服装+面具+假发+道具套装（套装 SKU 管理）；
5. **尺码宽松逻辑**：演出服追求造型不追求合身（oversize 设计为主）。

## 三、合规红线（高发风险区）

| 风险 | 说明 |
|:---|:---|
| **IP 侵权** | 迪士尼/漫威/任天堂角色cos——**无授权生产是重灾区**（美国海关 CBP 专项查扣万圣节季侵权服装）——必须核实授权（见 `trade-compliance/ip-brand-authorization.md`） |
| 阻燃 | 美国儿童演出服阻燃要求（16 CFR 1615/1616 类似童装睡衣——万圣节服装阻燃事故史） |
| 小部件 | 儿童演出服亮片/珠子脱落（吞咽风险——见 `garments/childrenswear-production.md`） |
| 面具安全 | 视野/透气（窒息风险警示标签） |

## 四、生产管理要点

- **季节单集中爆发**：万圣节单 2-4 月询价、4-5 月下单、7-8 月出货——产能集中预定；
- **返单率低**：节日款一年一季（设计年年换）——**不做库存**（明年不过时的是少数经典款）；
- **样品即大单**：演出服客户看图下单——样品照片决定订单（打样投入是获客成本）；
- **套装管理**：一套多组件（上衣+裤+帽+道具）——齐套检验是出货前提。

## 五、利润与风险结构

- **利润**：万圣节服装毛利 50-100%（节日刚需+时效溢价）；cosplay 高还原款更高；
- **风险**：季节死线（船期延误=全损）+ IP 侵权（查扣+诉讼）+ 库存风险（过季一文不值）；
- **对冲**：经典款（女巫/吸血鬼/超级英雄通款）可跨年销售；IP 款严格授权才碰。

## 六、产业带

- **广东澄海/东莞**：万圣节服装集群（玩具产业带延伸）；
- **浙江义乌**：派对服饰小商品；
- **山东/河南**：演出服加工（戏服产业基础）。
