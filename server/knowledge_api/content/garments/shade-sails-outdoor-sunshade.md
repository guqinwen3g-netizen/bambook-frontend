# 遮阳帆与户外遮阳成品（Shade Sails: HDPE 针织帆/张拉结构/五金安装）

遮阳帆是"面料+结构力学"的庭院成品：HDPE 针织遮阳布按三角/四角/矩形裁剪，通过边角 D 环与拉绳张拉成预应力曲面。澳大利亚是全球标杆市场（人均庭院+强日照），欧美 DIY 渠道（亚马逊/Home Depot）持续放量。材料端（HDPE 圆丝遮阳网/抗 UV 配方）见 `fabric/technical-agro-geo-textiles.md`、船用遮阳同源见 `garments/marine-yacht-textiles.md`——本文聚焦**成品帆的结构、五金与渠道**。

## 一、产品矩阵

| 款型 | 材料 | 特征 | 价格带（零售） |
|:---|:---|:---|:---|
| 三角帆 3.6m | HDPE 针织 160-185gsm | 入门走量款（3 件装组合） | $25-40 |
| 矩形帆 3×4m | HDPE 185-220gsm | 庭院/车位主力款 | $35-60 |
| 防水帆（涂层款） | HDPE+PE 淋膜/涤纶牛津涂银 | 遮阳+挡雨双功能（**不透气闷热**短板） | $40-80 |
| 卷帘式遮阳（shade screen） | HDPE+铝合金卷轴 | 阳台/窗用下拉式 | $30-70 |
| 定制尺寸帆 | 按图纸裁剪 | 商用（餐厅外摆/泳池/学校） | $80-300 |

- **遮阳率分档**：70%/85%/95%（密织度）——**深色帆遮阳率虚标重灾区**（黑色天然高遮光但 UV 透过率≠遮阳率，紫外线阻隔需 UV 稳定剂配方）；
- **UVR 阻隔宣称**：澳洲 ARPANSA 测试（UPF 15-50+ 分级——防晒宣称逻辑见 `garments/sun-protection-clothing.md`）。

## 二、结构与工艺要害

- **预应力原理**：平张的帆会兜风兜水撕裂——**必须张拉成马鞍形双曲率曲面**（四角高低交错）——随附安装指南（两对角高点+两低点，倾角 30° 排水）是差评防控核心（安装不当积水撕裂是第一大售后）；
- **边角结构**：织带包边（50mm PP/涤纶织带双层——`fabric/webbing-narrow-fabrics.md`）+**不锈钢 D 环**（304/316——三角受力件，焊接成型 vs 冲压）；边角加强三角布+多道车缝（应力集中区）；
- **裁片曲率**：大帆裁片带内凹弧线（catenary curve——张拉后边缘平直）——**曲率计算是版型技术**（CAD 展开）；
- **风载设计**：帆面透风率（针织网眼透风 10-20% 降低风载）vs 防水款不透风（**大风区禁用大面积防水帆**——风掀翻案例）；五金锚点（墙体膨胀螺栓/立柱）承重计算——配套安装五金包（turnbuckle 花篮螺栓+S 钩+pad eye）是连带销售利润点。

## 三、合规与责任

- **抗 UV 承诺**：户外寿命 3/5/8 年档（QUV 加速老化报告——同遮阳网逻辑 `fabric/technical-agro-geo-textiles.md`）——**虚标寿命是最大纠纷源**；
- **化学合规**：HDPE 母粒重金属（Prop 65——`trade-compliance/california-prop65.md`）；REACH SVHC（出口欧盟）；
- **产品责任**：坠落/掀翻伤人——**警示标签**（"大风天收起/定期检查五金/非永久结构"）；安装指南免责声明（`trade-compliance/product-liability-recall.md`）；
- **阻燃**：商用场所（餐厅/学校）部分州要求 NFPA 701 阻燃报告（`trade-compliance/textile-flammability-regulations.md`）——阻燃母粒添加影响 UV 寿命（配方平衡）。

## 四、市场与运营

- **渠道**：亚马逊（shade sail 类目——中国卖家主导，价格战激烈）、家居建材连锁（Home Depot/Bunnings 澳——`customers-market/big-box-retail-channel.md`）、园林工程商（定制商用单）；
- **季节节奏**：北半球 3-7 月峰值（春季备货）+澳洲 9-2 月（反季平衡产能——**南北半球双市场日历**是品类天然优势）；
- **差评热点**：积水撕裂（安装问题——指南前置）、D 环拉脱（五金质量）、尺寸不足（张拉后实际投影小于标称——**标注"边长为张拉前尺寸"**）、色差（同庭院多片不同批次）；
- **差异化方向**：**套装化**（帆+五金包+安装工具）、防水+遮阳双功能、定制尺寸服务（CAD 制图+按图生产）、彩色条纹设计款（庭院美学趋势）；
- **B2B 延伸**：幼儿园/学校操场（澳洲 sun-safe 政策强制遮阳——政府集采）、停车场车棚（商用大跨）、游泳池遮阳（氯环境材料选型）。
