# 成衣品类与工艺（Garment Types & Construction）

成衣（garment/ready-to-wear）品类繁多，外贸谈判与跟单必须先对齐品类与工艺术语。本文件按织法来源与品类梳理常用英文术语，并区分针织与梭织两大工艺路径。

## 一、按织法分两大工艺体系

成衣制造的两大源头是**针织（knit）**与**梭织（woven）**，工艺与弹力、用途完全不同：

| 特性 | 针织 knit | 梭织 woven |
|:---|:---|:---|
| 形成方式 | 线圈交织 loops | 经纬纱上下交错 warp & weft |
| 弹性 | 天然有弹性 stretch | 基本无弹性/低弹 |
| 常见面料 | 汗布 single jersey、毛圈、罗纹 | 平纹 poplin、斜纹 twill、缎纹 satin |
| 常见成衣 | T 恤、卫衣、内衣、套头衫 | 衬衫、西装、裤装、外套、牛仔 |
| 洗护 | 易变形、多需平铺晾干 | 相对挺括、可挂晾水洗 |

> 沟通要点：报价前必须确认"针织还是梭织"，运输重量、用量（consumption）、洗水缩率完全不同。

## 二、针织成衣品类（Knitwear）

### 套头衫与毛衣（Sweater / Pullover）
- 术语：毛衣 sweater、套头衫 pullover、开衫 cardigan、圆领 crew neck、V 领 V-neck。
- 工艺：横机编织 flat knitting（提花 jacquard、嵌花 intarsia、绞花 cable）。
- 常见毛衫用纱：羊毛、羊绒、棉纱、腈纶 acrylic。

### 上装（Knit Tops）
- T 恤 T-shirt、polo 衫 polo shirt、卫衣 hoodie/sweatshirt、背心 tank top、打底衫 layering tee。
- 廓形术语：修身 slim fit、宽松 loose fit、oversized。

### 下装与套装
- 针织裤 jogger pants、针织裙 knit skirt、运动套装配色 color block。

### 内衣与家居（Intimates & Loungewear）
- 内衣 underwear、文胸 bra、内裤 panty/brief、睡衣 sleepwear、家居服 loungewear。
- 注意：内衣多用高弹力面料（含氨纶 spandex），贴合度贴合 fit 要求高。

## 三、梭织成衣品类（Woven Apparel）

### 衬衫（Shirt / Blouse）
- 男式衬衫 dress shirt、女士衬衫 blouse、休闲衬衫 casual shirt。
- 关键部件：领子 collar、门襟 placket、袖克夫 cuff、前胸口袋 chest pocket。
- 常见领型：尖领 point collar、纽扣领 button-down collar、立领 stand collar。

### 外套（Outerwear）
- 西装 jacket/suit、夹克 jacket、风衣 trench coat、大衣 coat、羽绒服 down jacket。
- 羽绒服关键参数：含绒量（down content，如 90/10）、绒朵比、面料防绒（down-proof）。

### 裤装（Bottoms）
- 西裤 trousers、休闲裤 casual pants、短裤 shorts、工装裤 cargo pants。
- 裤腰术语：腰头 waistband、门襟 fly、插袋 slash pocket、裤脚 hem。

### 牛仔（Denim/Pants）
- 单宁 denim、牛仔裤 jeans、直筒 straight、修身 slim、喇叭 bootcut/flare。
- 洗水工艺：石磨 stone wash、酵素洗 enzyme wash、猫须 whisker、做旧 distressed。

### 裙装（Dresses & Skirts）
- 连衣裙 dress、半身裙 skirt、A 字裙 A-line、百褶裙 pleated skirt、裹身裙 wrap dress。

## 四、常见工艺与术语对照

| 工艺 | English | 说明 |
|:---|:---|:---|
| 车缝线迹 | stitch | 明线 topstitch、暗线 concealed stitch |
| 锁边/包缝 | overlock/merrow | 防止散边，针织多用 |
| 领口车口 | neckline binding | 领口滚边 |
| 拼接 | panel | 多片组合 |
| 荷叶边 | ruffle/flounce | 装饰褶边 |
| 对条对格 | matching stripes/plaids | 梭织衬衫常见要求 |
| 洗水 | washing | 预缩 pre-shrink、酵素酶洗 |
| 绣花 | embroidery | 见辅料文档 |
| 压花/压胶 | heat-seal/taping | 户外防水服常用 |

## 五、沟通与跟单要点

1. **先分体系**：针织/梭织决定工艺、洗水、用量与报价。
2. **明确廓形与合体度**：修身/宽松影响版型与用量。
3. **对条对格**：梭织格纹/条纹需在款式图上标注对条要求，影响排料 utilization。
4. **洗水品类单独确认**：牛仔、针织洗水后尺寸变化大，需按洗后尺寸（washed size）制作规格单。
5. **术语统一**：用英文与外商对齐品类，避免中文歧义（"夹克"可指 jacket 或 windbreaker）。
