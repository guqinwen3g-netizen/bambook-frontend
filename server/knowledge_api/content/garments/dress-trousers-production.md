# 正装裤装体系（Dress Trousers: 西裤工艺/版型/搭配/裤脚处理）

西裤是"**被低估的工艺载体**"：裤线（crease）的锋利度、裤脚（hem）的处理、腰头的结构，处处体现工艺水准。泛裤装生产见 `garments/pants-trousers-production.md`——本文件聚焦**正装场景的西裤体系**。

## 一、版型体系

| 版型 | 特征 | 体型适配 |
|:---|:---|:---|
| **直筒（straight）** | 大腿到裤脚等宽 | 通用/保守 |
| **修身（slim）** | 大腿收窄、裤脚小 | 瘦高/时尚 |
| **锥形（tapered）** | 大腿宽松、裤脚收窄 | 大腿粗/小腿细 |
| **阔腿（wide leg）** | 整体宽松 | 复古/高个子 |
| **高腰（high-rise）** | 腰头在肚脐以上 | 复古/腿长优化 |

- **裤长标准**：
  - 全褶（full break）：裤脚轻触鞋面——**保守商务**；
  - 半褶（half break）：裤脚微触鞋面——**现代标准**；
  - 无褶（no break）：裤脚在脚踝上方——**时尚/年轻**；
  - 负褶（negative break）：露袜——**时尚冒险，保守行业禁忌**；
- **裤线（crease）**：**永久裤线（permanent crease）是高端西裤标识**——需高温定型+树脂处理。

## 二、工艺要点

- **腰头结构**：
  - 常规腰头（waistband）：标准——**内有防滑带（gripper tape）是高端细节**；
  - 背带扣（brace buttons）：腰头内侧纽扣——**配背带使用（见 `garments/luxury-accessories-system.md`）**；
  - 调节袢（side adjusters）：替代皮带——**"无皮带"是高端定制趋势**；
- **口袋**：
  - 斜插袋（slant pocket）：通用——**袋口滚边（piping）是工艺标识**；
  - 表袋（watch pocket）：右前袋内小袋——**复古细节**；
  - 后袋：单唇/双唇——**双唇后袋（double-welt）更正式**；
- **裤脚处理**：
  - 翻边（cuff/turn-up）：**翻边 4-5cm 是经典**——增加重量改善垂感；
  - 无翻边（plain hem）：简洁——**现代修身款主流**；
  - 马蹄形（horse-shoe）：后长前短——**罕见，复古风格**。

## 三、面料与季节

- **面料**：与西装上衣同料（套装）或对比料（单西+灰裤）——**" separates" 策略增加搭配灵活性**；
- **季节**：
  - 夏季：高捻羊毛/亚麻混纺（见 `fabric/summer-suiting-fabrics.md`）；
  - 冬季：法兰绒/骑兵斜纹——**克重 280-320g/m**；
- **颜色**：藏青/炭灰/黑色为基石——**浅灰/米色为季节款**。

## 四、搭配规则

- **皮带**：必须配皮带（除非有调节袢/背带）——**皮带颜色与皮鞋一致**；
- **袜子**：裤长决定袜长——**无褶裤必须配长袜（不露肤）**；
- **鞋**：牛津/德比/孟克——**运动鞋+西裤是时尚实验，非正装**。

## 五、生产与品控

- **排料**：裤片方向性——**顺毛面料必须同向排料**；
- **对格**：前后片侧缝对格——**误差 >2mm 为次品**；
- **裤线定型**：高温定型机（160-180°C）+ 树脂——**水洗 10 次后裤线保持 >80%**；
- **尺寸**：腰围/臀围/大腿围/裤脚围/外长/内长——**六维尺寸表是日本市场基本要求**。
