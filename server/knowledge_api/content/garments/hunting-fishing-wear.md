# 狩猎与钓鱼服装生产（Hunting & Fishing Wear: 美国细分户外）

狩猎/钓鱼是美国**高客单价、高忠诚度**的细分户外品类（合计 $100 亿+市场）：技术门槛在**迷彩图案授权、气味控制、法规色要求**——与泛户外服装逻辑不同（泛户外见 `garments/outdoor-functional-wear-production.md`）。

## 一、品类与场景

| 品类 | 场景需求 | 代表品牌 |
|:---|:---|:---|
| 狩猎服（big game） | 静音面料/气味控制/迷彩 | Sitka/Kryptek/Under Armour Hunt |
|  upland/水禽狩猎 | 耐磨/防水/活动量 | Browning/Carhartt |
| 钓鱼服 | 防晒 UPF50+/快干/防蚊 | Columbia PFG/AFTCO/Simms |
| 涉水裤（wader） | 防水透湿（氯丁橡胶/贴膜） | Simms/Frogg Toggs |

## 二、迷彩图案授权（准入门槛）

- **授权体系**：Realtree / Mossy Oak / Kryptek 等图案公司持有迷彩版权——**印花需购买授权**（年费+按码 royalty，验厂审核印花厂资质）；
- **违规红线**：无授权印花=侵权（美国海关查扣——见 `trade-compliance/ip-brand-authorization.md`）；
- **面料供应**：授权印花厂出迷彩坯布（采购指定印花厂面料=合规路径）。

## 三、技术与合规要点

| 要点 | 说明 |
|:---|:---|
| 气味控制（scent control） | 活性炭/银离子整理（鹿类嗅觉灵敏——宣称需测试支撑） |
| 静音面料 | 刷毛/起绒表面（摩擦噪音测试——猎装核心指标） |
| Blaze orange 法规色 | **多数州强制猎人穿荧光橙**（可见面积各州法规——色号/面积合规是设计前提） |
| 防水透湿 | 涉水裤 10K/10K+（压胶条工艺） |
| UPF 防晒 | 钓鱼服 UPF 50+（见 `garments/sun-protection-clothing.md`） |
| 防蚊 | 氯菊酯整理（EPA 注册——见 `fabric/functional-fabrics.md` 防蚊节） |

## 四、渠道与订单

- **渠道**：Bass Pro Shops/Cabela's（合并后最大户外连锁）/Academy/Sportsman's Warehouse——专业户外渠道（区别于大卖场，见 `customers-market/big-box-retail-channel.md`）；
- **订货周期**：春季展（SHOT Show 1 月——行业主展）下单，7-9 月交货（狩猎季 10 月+）；
- **订单特点**：尺码偏大（美国壮硕体型——版型放大，见 `garments/sizing-and-fit.md`）；套装组合销售（上衣+裤+帽）；
- **客群粘性**：猎人对品牌忠诚度高（口碑社区驱动——质量事故=永久拉黑）。

## 五、生产注意

- **迷彩对版**：印花对格对花（裁片定位——见 `suppliers/cutting-room-management.md`）；
- **防水压胶**：涉水裤压胶条 100% 检验（漏水=退货——见 `fabric/functional-coating-lamination.md`）；
- **法规色牢度**：blaze orange 日晒/水洗牢度（法规色失效=安全事故责任）；
- **检针**：童装狩猎服（青少年猎手市场）同标准（见 `suppliers/needle-control-metal-management.md`）。

## 六、商机评估

- **优势**：竞争少于泛户外（技术门槛+授权门槛）、客单价高（套装 $200-500）、复购稳定（损耗品）；
- **门槛**：迷彩授权年费、SHOT Show 参展成本、美国户外渠道验厂；
- **切入**：钓鱼服（防晒快干——技术门槛低于狩猎）→ 积累渠道 → 狩猎线。
