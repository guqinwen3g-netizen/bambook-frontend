# 智能服装与可穿戴技术生产（Smart & Wearable Tech Clothing）

智能服装=纺织+电子跨界产品：加热服、制冷风扇服、LED 发光服、生理监测服等。美国冬季加热服（ORORO、Milwaukee 模式）与夏季空调服（日本/中东工装）是两个已验证的规模化市场。生产门槛在**电子供应链整合与合规认证**，不在缝纫。

## 一、主要品类与技术路线

| 品类 | 核心技术 | 电源 | 主要市场 |
|:---|:---|:---|:---|
| 加热服（马甲/夹克/手套/袜） | 碳纤维/金属丝发热片（5V/7.4V/12V） | 充电宝/专用锂电池 | 美国、北欧、加拿大 |
| 空调/风扇服 | 腰部微型风扇×2 循环送风 | 5V 移动电源 | 日本、中东工装、国内工地 |
| LED 发光服 | 柔性 LED 灯带+控制器 | 纽扣电池/锂电池 | 演出、夜跑、节日 |
| 生理监测服 | 导电织物电极+传感器模块 | 微型锂电 | 运动队、医疗康复 |
| 制冷服（半导体制冷片） | Peltier 片+散热系统 | 大容量锂电 | 尚属小众高端 |

## 二、关键物料与供应链

- **发热片**：碳纤维发热膜（柔软可水洗主流）/金属发热丝（成本低但硬、断丝风险）——采购看电阻均匀性与耐弯折次数（≥5000 次）；
- **电池**：必须 **UN38.3 认证+MSDS**（空运强制，见 `trade-process/air-freight-express.md`）；18650 电芯选品牌厂（杂牌=起火风险+产品责任，见 `trade-compliance/product-liability-recall.md`）；
- **控制器**：温控档位（3 档为主流）+过热保护（60℃ 断电）+短路保护——方案商集中在深圳；
- **导电连接**：导电缝纫线（银纤维/不锈钢混纺）vs 柔性排线（FPC）——量产多用"发热片+隐藏式排线+USB/DC 接口"，导电纱线车缝尚不成熟；
- **跨界协作**：服装厂+电子方案商+电池厂三方——合同必须明确**电子部分质保责任归属**（客诉大头是电池与控制器，不是缝纫）。

## 三、生产要点

- **可拆卸设计**：电子模块（电池/控制器）必须可拆——洗涤标签标注"取出电池后可机洗"（一体不可拆=一次性产品，差评重灾区）；
- **发热片固定**：绗缝/包边固定防移位（移位=局部过热烫伤投诉）；位置避开脊柱/肾脏区（安全惯例）；
- **走线防护**：排线穿织带通道，过骨位加护套——断线是头号工艺不良；
- **防水**：发热片与接插件 IPX4 起步（防汗/小雨）；宣传"防水"需对应 IP 等级测试报告；
- **全检通电**：每件成品通电测试 3 档位+温升（红外测温枪抽查表面 35-55℃ 区间）——电子件不良率远高于纯服装，全检不可省（见 `suppliers/garment-factory-qc-system.md`）。

## 四、合规认证（接单前置确认）

| 认证 | 适用 | 要点 |
|:---|:---|:---|
| UN38.3+MSDS | 含锂电池（全球运输） | 电池厂提供，每型号一份 |
| FCC（Part 15） | 美国（控制器属数字设备） | 带蓝牙/App 控制必做 |
| CE-RED | 欧盟（带无线功能） | 无无线功能走 CE-EMC+LVD |
| RoHS/REACH | 欧盟 | 电子部分 RoHS，纺织部分 REACH（见 `trade-compliance/chemical-environmental-compliance.md`） |
| UL/ETL（充电器） | 美国 | 配充电头时需 |
| WEEE | 欧盟 | 电子产品回收注册（卖家责任） |

- **产品责任险**：带电产品烫伤/起火风险显著高于普通服装——美国市场务必投保并核查保额（见 `trade-compliance/product-liability-recall.md`）；
- **宣传合规**：不可宣称医疗功效（"治疗关节炎"=FDA 监管红线）。

## 五、接单评估要点

- **MOQ 结构**：电子物料（控制器/电池）起订量常高于面料——综合 MOQ 由电子件决定；
- **报价拆项**：电子 BOM 与服装 BOM 分开列——汇率/芯片涨价时便于调价；
- **交期**：电子件采购周期 4-8 周（含认证确认），比服装面辅料长——排产倒排以电子件到料为关键路径（见 `suppliers/production-capacity-scheduling.md`）；
- **售后**：预留 2-3% 备品（电池/控制器）随货发——跨境退换电子件物流极贵（含电池空运受限）。
