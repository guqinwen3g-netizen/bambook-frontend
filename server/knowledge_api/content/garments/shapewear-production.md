# 塑身衣生产（Shapewear Production: 压力分级与无缝工艺）

塑身衣是内衣中**技术与溢价双高**的品类（SKIMS 估值 $40 亿+带动的赛道）：核心是**压力工程学**——分区加压设计 + 高弹面料 + 无缝工艺，版型差 2cm 就是"有效"与"穿不上"的区别。

## 一、品类矩阵

| 品类 | 压力等级 | 场景 |
|:---|:---|:---|
| 高腰塑身裤 | 中-高压 | 收腹提臀（主力走量款） |
| 连体塑身衣（bodysuit） | 中压 | 全身塑形（DTC 爆款） |
| 塑身上衣/腰封 | 高压 | 产后修复/收腰 |
| 塑身裙/吊带 | 轻-中压 | 内搭隐形 |
| 大腿/手臂局部 | 中压 | 吸脂术后医用（跨界） |

- **压力分级**：轻压（日常 <20mmHg）/中压（塑形 20-30）/高压（医用 30-40+——术后衣属医疗器械边界，出口宣称需谨慎，见 `trade-compliance/ppe-protective-clothing-compliance.md` 宣称合规逻辑）。

## 二、面料与工艺

### 面料
- **锦氨高弹**：锦纶 70-80% + 氨纶 20-30%（氨纶含量=压力基础，见 `fabric/nylon-spandex-stretch-fabrics.md`）；
- **弹力网布（power mesh）**：局部加压区（见 `fabric/mesh-netting-fabrics.md`——拉伸回复率核心）；
- **克重**：180-280gsm（高压款 280+）；四面弹双向拉伸；
- **功能叠加**：凉感/抗菌（夏季塑身裤——见 `fabric/functional-fabrics.md`）。

### 工艺路线
| 工艺 | 特点 | 应用 |
|:---|:---|:---|
| 无缝圆机（圣东尼 Santoni） | 一体成形无侧缝——舒适隐形 | 中高端主力（设备 30-80 万/台） |
| 车缝（四针六线/绷缝） | 拼片加压结构精准 | 高压/复合结构款 |
| 点胶/贴合 | 无痕边缘（防滑胶条） | 腿口/腰口防滑 |

- **无缝 vs 车缝**：无缝舒适但压力上限低；高压款仍需车缝拼片（裁片分区加压）；
- **关键尺寸**：压力靠**负松量**（成品比围度小 15-30%）——版型师按面料弹伸率反算（弹伸率测试先行）。

## 三、版型与测试

- **分区加压设计**：腹部双层/臀部提托线/大腿渐变——纸样标注压力区（见 `suppliers/pattern-sample-room-management.md`）;
- **试穿测试**：真人试穿 4 小时（压痕/卷边/勒痕/闷痒——差评四大源）；
- **洗涤耐久**：氨纶老化（50 次水洗后压力衰减 ≤15%——洗标注明冷水手洗）；
- **尺码体系**：XS-3XL 全码（大码塑身需求大——见 `garments/plus-size-maternity-wear.md`）；**尺码偏小退货率最高的类目**——尺码表建议给"介于两码选大码"。

## 四、品质检验

| 检验点 | 标准 |
|:---|:---|
| 拉伸回复 | 定伸长反复拉伸 5 次回复率 ≥90% |
| 接缝强力 | 高压区绷缝强力（穿着崩裂是致命差评） |
| 防滑胶条 | 贴合牢度+皮肤刺激（硅胶过敏客诉） |
| 色牢度 | 汗渍/摩擦（深色塑身衣——见 `trade-compliance/testing-standards.md`） |
| 外观 | 无抽丝/横条（氨纶断丝露白） |

## 五、市场与客户

- **品牌梯队**：SKIMS/Spanx（高端 DTC）→ Shapermint/Honeylove（中端）→ 亚马逊白牌（走量）；
- **渠道**：DTC 独立站为主力（见 `customers-market/dtc-brand-clients.md`）+ 亚马逊塑身衣类目（竞争红海但量大）+ 百货内衣区；
- **客群扩展**：产后修复（maternity shapewear）/大码/男士塑身（小众增长）；
- **合规提示**：避免医疗宣称（"治疗静脉曲张/术后修复"= FDA 医疗器械边界）；宣称限于"塑形/平滑线条"。

## 六、成本与报价

- **无缝款**：圆机织胚+染色+定型——加工费高于普通内衣 50%+（设备摊销）；
- **车缝款**：IE 工时见长（见 `suppliers/garment-ie-engineering.md`），四针六线设备必需；
- **报价要点**：氨纶含量/克重/压力结构单列（氨纶价格波动大——报价有效期缩短）。
