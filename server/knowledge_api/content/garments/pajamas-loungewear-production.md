# 睡衣与家居服品类专题（Pajamas & Loungewear Production）

睡衣家居服（sleepwear/loungewear）是**"后疫情红利"品类**：居家办公让家居服从"睡觉穿"升级为"全天穿"——舒适度与颜值并重。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 睡衣套装（pajama set） | 上衣+长裤（棉/莫代尔——经典款） |
| 睡裙（nightdress） | 女式（真丝/缎面——性感线） |
| 睡袍（robe） | 浴袍/晨袍（毛巾布/华夫格/真丝） |
| 家居服（loungewear） | 可外穿的居家套装（卫衣款/针织套装——"可出门的睡衣"） |
| 睡裤（sleep pants） | 法兰绒/棉（冬季格子睡裤是常青款） |
| 儿童睡衣 | **阻燃法规严格**（见 `garments/childrenswear-production.md`） |

## 二、面料配套

| 面料 | 应用 |
|:---|:---|
| 纯棉针织 | 基础睡衣（透气亲肤） |
| 莫代尔/竹纤维 | 高端睡衣（柔软垂坠——"第二层肌肤"） |
| 真丝/缎面 | 性感睡裙（奢华线） |
| 法兰绒 | 冬季睡裤/睡袍（保暖） |
| 毛巾布 | 浴袍（吸水——见 `fabric/fleece-terry-fabrics.md`） |
| 华夫格 | 浴袍/家居服（见 `fabric/casual-textured-fabrics.md`） |
| 摇粒绒 | 冬季家居服 |

## 三、舒适优先的工艺

- **无感标签**：印花标签替代织标（颈部无刺痒——睡衣第一体验）；
- **平缝/四针六线**：减少缝份摩擦（贴身舒适）；
- **松紧腰**：睡裤松紧腰（无束缚——橡筋舒适度）；
- **宽松版型**：睡衣松量大于外衣（睡眠活动量）。

## 四、安全合规（儿童睡衣红线）

- **美国儿童睡衣阻燃**：16 CFR 1615/1616——**紧身款豁免（snug-fit）vs 宽松款必须阻燃**（阻燃处理或阻燃面料）；
- **阻燃处理**：阻燃剂（化学处理——有争议）vs 阻燃纤维（本质阻燃）vs **紧身设计豁免**（主流方案—— snug-fit 标签）；
- **欧盟**：睡衣阻燃（EN 14878 儿童睡衣燃烧性能）；
- **警示标签**：宽松非阻燃款警示"keep away from fire"。

## 五、订单特征

- **节日属性**：圣诞睡衣套装（家庭装 matching family pajamas——欧美圣诞爆款，Q4 大单）；
- **家居服升级**：loungewear 化（可外穿——单价高于传统睡衣）；
- **礼品市场**：真丝睡袍（婚庆/礼品——礼盒包装）；
- **翻单稳定**：基础睡衣套装常年翻单。

## 六、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 阻燃 | 儿童睡衣阻燃证书/紧身豁免标签 |
| 标签 | 无感标签（印花标签牢度） |
| 缝制 | 贴身缝份舒适（无硬边） |
| 色牢度 | 睡衣洗涤频繁（耐洗牢度） |
| 尺寸 | 睡衣宽松版型尺寸 |

## 七、产业带

- **广东**：汕头（家居服集群——"中国家居服之都"）；
- **浙江**：杭州（真丝睡衣）、义乌；
- **江苏**：南通（家纺延伸——浴袍/家居服）。
