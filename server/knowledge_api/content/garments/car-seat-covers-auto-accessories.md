# 汽车座套与车用纺织品（Car Seat Covers & Auto Textile Accessories）

汽车后市场纺织品是稳定外贸品类：座套、车罩、方向盘套、头枕腰靠、后备箱垫、宠物车载垫。需求驱动=美国/澳洲保有老旧车+皮卡文化。渠道以亚马逊/eBay Motors/汽配连锁（AutoZone/O'Reilly）为主。生产是"缝纫+复合海绵+版型数据"的组合。

## 一、产品线与材料

| 产品 | 面料 | 结构要点 |
|:---|:---|:---|
| 通用座套 | 涤纶针织+海绵复合/PU 皮 | 松紧带+挂钩固定，通用版型 |
| 专车专用座套 | 三明治网布/皮革 | **按车型版型数据开版**——侧气囊开口 |
| 车罩（car cover） | 190T 涤塔夫涂银/无纺布复合 | 防水透气平衡+防风绑带 |
| 宠物车载垫 | 600D 牛津+防水涂层 | 吊床结构+安全带开口 |
| 方向盘套 | PU/硅胶/毛绒 | 内圈防滑颗粒 |
| 后备箱垫 | TPE/XPE+毯面 | 高边防水 |

- **复合工艺**：面料+3-5mm 海绵+网底三层火焰复合/胶点复合——复合剥离强度 ≥1.5N/cm（脱层是最大质量投诉）；
- **版型数据库**：专车专用核心资产=车型版型库（美系皮卡 F150/Silverado 版型需求量最大）——扫描仪+手工复版积累，数据壁垒>设备壁垒。

## 二、安全红线（侧气囊）

- **侧气囊开口（airbag compatible）**：座椅侧气囊位置的缝线必须用**专用爆破线**（断裂强力精确控制 30-50N）——普通缝线会阻碍气囊弹出=**致命+天价诉讼**；
- 验证：供应商提供气囊爆破测试报告；产品线逢"气囊位"必用认证缝线并留检测记录；
- **宣称纪律**：无测试报告不写 "airbag compatible"——美国集体诉讼盯这个宣称（见 `trade-compliance/product-liability-recall.md`）；
- 阻燃：FMVSS 302（车用材料阻燃）——出口美国车用纺织品强制，水平燃烧速率 ≤100mm/min。

## 三、生产要点

- **打版**：通用款按"座椅平均尺寸+弹性包容"设计（适配率宣称 90% 需实测清单）；专车款按 3D 扫描+试穿修正 2-3 轮；
- **车缝**：双针装饰线+受力位打枣；皮革类用同步车（同箱包厚料逻辑，见 `garments/bags-luggage-production.md`）；
- **车罩特殊项**：面料透气与防水的矛盾——高端款用透气膜复合；镜面/天线开口位置按车型；内层磨毛处理防划伤车漆（差评敏感点）；
- **配件**：挂钩（塑料 POM 不断裂）、松紧带（耐老化——车厢高温 70℃ 环境）、卡扣；
- **包装**：座套装 PVC 钢丝包（展示性）——压缩体积控制海运费。

## 四、市场与接单

- **美国是主战场**：皮卡/SUV 座套、宠物车载垫（美国家庭带狗出行常态）为亚马逊长青类目；
- **季节节奏**：车罩按北半球冬季备货（雪季防护）——7-8 月下单 9-10 月到仓（见 `trade-process/annual-sourcing-calendar.md`）；
- **客户类型**：汽配连锁自有品牌（大单验厂）、亚马逊品牌（快反小单多色）、4S 店赠品渠道；
- **报价要点**：海绵/皮革价格波动单列；专车专用款按车型收版费（$100-300/车型）；
- **侵权警示**：车标 logo（福特/雪佛兰标）绣在座套上=商标侵权——只有授权单可做（见 `trade-compliance/ip-brand-authorization.md`）。
