# 纱笼与围裹裙（Sarong/Lungi/Kanga: 东南亚南亚东非文化面料）

纱笼是"**一块围裹布=文化刚需**"的跨洲品类：印尼/马来 sarong（祈祷+日常）、缅甸笼基（longyi）、南亚 lungi、东非 kanga（格言印花社交货币）、太平洋 lavalava——同构产品不同文化叙事。与非洲蜡染布（见 `fabric/african-wax-print-fabrics.md`）同属"文化绑定面料"，定长定宽的**按条销售**逻辑。

## 一、区域形态对照

| 区域 | 名称 | 形态 | 特征 |
|:---|:---|:---|:---|
| 印尼/马来 | Sarong | 筒裙（缝合圆筒）或整幅 | **蜡染 batik/格纹**——祈祷五时+日常；男穿为主 |
| 缅甸 | 笼基 Longyi | 圆筒裙 | 男女同穿——男格纹（paso）女花型（htamein） |
| 孟加拉/印度 | Lungi | 围裹（不缝合） | 棉格纹——居家劳作 |
| 中东（也门/阿曼） | Futah/Izaar | 围裹 | 白/格纹——海湾日常 |
| 东非 | **Kanga/Khanga** | 成对方块布（1.1×1.5m×2） | **斯瓦希里格言印花**（jina——社交表达）——女裹身/头巾 |
| 东非海岸 | Kikoy | 织边条纹布 | 肯尼亚海滩文化 |
| 太平洋 | Lavalava | 围裹 | 萨摩亚/斐济——正装场合适用 |

## 二、材料与工艺

- **基材**：棉（高端——透气）、人棉（粘胶——垂感印花鲜艳，见 `fabric/regenerated-cellulose-fabrics.md`）、涤纶（低价跑量）；规格 1.1×2m 级整幅或缝合圆筒；
- **印花**：蜡染（batik——印尼文化标识+机器仿蜡染跑量）、活性印花（人棉发色好）、拔染/圆网（深底花）；
- **织边**：两侧织边（selvedge——不散边是品质点）+两端流苏/锁边；
- **kanga 特殊性**：**成对销售（2 块一组）+格言区（jina 文字带）**——斯瓦希里语文案是文化适配核心（错译=事故）；
- **色牢度**：热带高频洗涤+暴晒——皂洗/日晒牢度是口碑命门（见 `fabric/cotton-fabrics-deep-dive.md` 染色管控）。

## 三、市场与渠道

- **东南亚**：印尼（2.7 亿人——sarong 是男装刚需）+马来西亚+文莱；**斋月前备货脉冲**（祈祷场景放量——见 `garments/modest-muslim-wear.md` 季节逻辑）；缅甸笼基民生必需；
- **南亚**：孟加拉 lungi（国民服饰级用量——低价棉格跑量，见 `customers-market/bangladesh-sri-lanka-market.md`）；
- **中东**：也门/阿曼/沙特 futah（见 `customers-market/middle-east-market.md`）；
- **东非**：坦桑尼亚/肯尼亚 kanga——**婚庆/社交赠礼场景**（成对购买）——中国产 kanga 与本地品牌（Khangas of Tanzania）竞争；
- **旅游/度假线**：巴厘岛/泰国沙滩纱笼（欧美游客——亚马逊 beach sarong 类目——人棉印花+流苏）；
- **渠道**：本地批发市场（雅加达 Tanah Abang 类）+非洲分销（迪拜中转——见 `customers-market/africa-market.md` 贸易路径）+电商。

## 四、风控要点

- **文化适配**：花型/文字本地化（kanga 格言需母语者校对——文化误用=市场事故）；宗教图案禁区（清真寺/经文图案慎用——见 `garments/modest-muslim-wear.md` 禁忌逻辑）；
- **规格习惯**：尺寸/缝合方式按区域（印尼圆筒 vs 孟加拉整幅——发错形态=滞销）；
- **价格敏感度**：民生品类价格弹性大（$1-3/条出货价）——跑量+柜量逻辑（抛货按条捆装）；
- **回款**：非洲/南亚分销链——信保+信用调查（见 `trade-process/customer-credit-investigation.md`）。
