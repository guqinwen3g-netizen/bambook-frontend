# 劳保安全鞋生产（Safety Footwear: 防砸/防刺穿/绝缘/EN ISO 20345）

安全鞋是 PPE 鞋类：建筑/制造/物流/能源行业的强制防护装备。中国是全球最大安全鞋生产国（温州/晋江/高密产业带）。订单=海外劳保用品品牌商 OEM+工业集团集采+电商（亚马逊工装鞋品类）。**认证是准入门票**——欧盟 CE（EN ISO 20345）、美国 ASTM F2413。

## 一、防护功能与等级体系

| 防护功能 | 标识 | 技术要求 |
|:---|:---|:---|
| 防砸（toe cap） | SB/S1-S5 基础 | 钢头/复合头/铝头承受 200J 冲击+15kN 静压 |
| 防刺穿（midsole） | P | 钢/凯夫拉中底——1100N 穿刺力 |
| 防静电 | A | 电阻 10⁵-10⁸ Ω（电子厂/石化） |
| 绝缘 | EH（美）/电绝缘（国标） | 18kV（美标 EH）耐电压 |
| 防滑 | SRA/SRB/SRC | 瓷砖+甘油/钢板+洗涤剂摩擦系数 |
| 防水 | WR/WRU | 鞋面透水/整鞋防水（雨靴逻辑见 `garments/umbrella-rain-gear-production.md` 相邻） |
| 耐热/耐寒 | HRO/CI | 大底耐 300°C 接触热/-17°C 保暖 |
| 耐油 | FO | 大底耐油溶胀 |

- **等级组合**：SB（基础防砸）→S1（+防静电+后跟吸能+封闭后跟）→S1P（+防刺）→S3（S1P+防水鞋面+大底齿纹）→S4/S5（全橡塑一体成型——食品厂/化工）；
- **钢头 vs 复合头**：复合头（玻纤/碳纤/塑料）轻+不导磁（机场安检场景叙事）+不导热（冷库）；钢头成本低+超薄壁设计成熟。

## 二、生产与测试要点

- **结构工艺**：注塑（PU 底直接注射——主流）/冷粘（运动鞋工艺——轻便时尚化趋势）/固特异沿条（高端工装——Red Wing 类）；
- **鞋面材料**：头层牛皮（压花/绒面）、超纤（见 `fabric/leather-synthetic-leather.md`）、飞织（时尚安全鞋趋势——飞织鞋面技术见 `fabric/shoe-materials-flyknit-uppers.md`）；
- **大底**：PU 双密度（中底缓震+大底耐磨）/橡胶（耐热耐油场景）——**水解是 PU 底命门**（库存 2 年+湿热环境底降解开裂——订单约定储存条件与保质期）；
- **型式试验**：认证机构（欧盟公告机构——SATRA/TÜV/Intertek）全项测试；**批量抽检**（每 5000 双抽样防砸/防刺复测）；
- **尺码体系**：欧码为主体——出口美国换算+宽楦（EE/EEE 宽版需求——欧美脚型，见 `garments/pattern-grading-sizing.md` 鞋楦逻辑相邻）。

## 三、认证与合规

- **欧盟**：PPE 法规 (EU) 2016/425——安全鞋属**二类 PPE**（Module B 型式试验+Module C2 年度抽检）；CE 标志+公告机构号；技术文件（TCF）留存 10 年；EU 符合性声明（DoC）随货；
- **美国**：ASTM F2413（OSHA 引用）——测试报告即可（无强制认证机构），但大买家要求第三方（Intertek/SGS）报告；
- **澳洲/新西兰**：AS 2210.3；**加拿大**：CSA Z195（绿三角标识）；
- **PPE 延伸**：与安全服（`trade-compliance/ppe-protective-clothing-compliance.md`）、安全手套（`garments/gloves-production.md`）构成劳保全套供应链——**组合供应**是渠道竞争力。

## 四、市场与贸易

- **品牌商 OEM**：Honeywell/Uvex/UVEX/Delta Plus 类劳保品牌代工——认证主体是品牌（工厂配合测试）；审厂（BSCI/Sedex——见 `suppliers/factory-audit-guide.md`）；
- **工业集采**：石油（阿美/壳牌供应商名录）、建筑集团、物流（亚马逊仓库安全鞋要求）——投标+年框；
- **电商线**：时尚化安全鞋（运动鞋外观+防砸——年轻蓝领接受度高）亚马逊品类增长快；差评热点=重（轻量化复合头解决）、闷脚（透气飞织）、开胶（冷粘工艺质量控制）；
- **价格与利润**：出厂价 $6-15（注塑基础款）至 $25+（复合头时尚款）——品牌零售 $40-150，**渠道毛利厚**；
- **趋势**：时尚化（safety sneaker）、轻量化（复合头+飞织减重 30%）、ESG（回收材料鞋面叙事——见 `fabric/sustainable-fabrics.md`）。
