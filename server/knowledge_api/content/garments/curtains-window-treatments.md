# 窗帘与窗饰生产深度（Curtains & Window Treatments: 遮光/阻燃/定制尺寸）

窗帘是家纺中**工程属性最强**的品类：酒店/办公/医院工程单（阻燃强制）+ 零售定制（按窗型尺寸）双轨运行。产业带：绍兴柯桥（窗帘布全球最大集散地）、海宁（工程布）。基础品类见 `garments/home-textiles.md`，本文件展开遮光技术、工程合规与定制订单逻辑。

## 一、遮光技术路线（按遮光率分级）

| 路线 | 结构 | 遮光率 | 特点 |
|:---|:---|:---|:---|
| 三层梭织遮光布 | 黑丝夹层（表布+黑纱+底布） | 70-90% | 可水洗、手感软、主流零售款 |
| 涂层遮光布 | 基布+丙烯酸发泡涂层（2-3 层） | 95-100% | 全遮光，涂层老化开裂是寿命短板 |
| 植绒遮光布 | 基布+植绒面 | 80-95% | 绒面质感，植绒牢度是关键 |
| 半遮光/柔纱 | 高密薄布 | 40-70% | 透光不透视场景 |
| 窗纱（sheer） | 特丽纶/玻璃纱 | 10-30% | 装饰+柔光，阻燃工程单常配 |

- **遮光率检测**：分光光度计实测（宣称"全遮光"需 ≥99%——儿童房/夜班人群卖点）；
- **涂层路线雷区**：低价涂层布甲醛/异味（丙烯酸涂层助剂残留）+ 耐候粉化（阳光面 2-3 年开裂）——出口订单要求 OEKO-TEX + 耐光老化测试。

## 二、尺寸体系与加工工艺

- **打褶倍数**：布幅宽度 ÷ 轨道宽度 = 1.5-2.5 倍（褶皱饱满度的来源——低价单偷减褶倍数是行业潜规则，合同必须写明）；
- **头部工艺**：四爪钩打褶（pinch pleat）/韩式褶（S 钩）/穿孔（grommet 气眼）/穿杆（rod pocket）/背袢（back tab）——**不同头部工艺用布量差异 10-20%**，报价前确认；
- **气眼安装**：金属/塑料气眼冲压——冲压牢度（反复拉动不脱落）+ 防锈（镀层厚度，海运高湿环境）；
- **定高 vs 定宽**：**定宽布**（1.4-1.5m 幅宽，高度无限）拼接逻辑 vs **定高布**（2.8-3.2m 幅宽即层高，宽度无限）——别墅挑高窗必须定高布，报价先问窗型；
- **拼接对花**：印花/提花布多幅拼接必须对花（pattern match）——对花损耗 15-30% 计入用料；
- **铅线/配重**：下摆铅绳增垂感——窗纱必备；儿童安全注意（铅含量——改用环保配重珠链）。

## 三、工程单合规（阻燃是硬门槛）

| 市场 | 标准 | 适用 |
|:---|:---|:---|
| 美国 | NFPA 701（小火焰垂直燃烧） | 酒店/剧院/公共场所强制 |
| 英国/欧洲 | BS 5867-2 Type B/C、EN 13773 | 工程招标强制 |
| 德国 | DIN 4102 B1 | 公共场所 |
| 法国 | NF P 92-507 M1 | 公共场所 |
| 日本 | 消防法防炎标签（防炎マーク） | 酒店/医院 |

- **阻燃路线**：阻燃涤纶长丝（磷系共聚——**永久阻燃耐水洗**，工程单首选）vs 后整理阻燃（成本低，洗后衰减——合同必须约定洗后阻燃保持次数）；
- **工程单流程**：投标→送样检测（第三方阻燃报告）→封样→大货抽检——报告与批次对应是验收命门（见 `trade-compliance/testing-lab-selection.md`）；
- **医疗/养老场景**：抗菌+阻燃双重要求，隔帘（cubicle curtain）网格布顶段设计（喷淋系统联动）。

## 四、订单与市场逻辑

- **零售电商**：亚马逊窗帘按"片"销售（1 片/2 片装），标准尺寸（52×63"/52×84"/52×95"）+颜色矩阵——**遮光率+克重是 listing 核心参数**，差评热点=色差（屏幕 vs 实物）、遮光不足、长度不符；
- **工程单**：酒店翻新周期 5-7 年——连锁酒店集团（万豪/希尔顿体系）集采，见 `garments/hotel-linen-b2b.md`；工期倒排（酒店开业节点刚性），违约金条款重；
- **定制窗帘**：海外本地定制店（measure & install 模式）——中国工厂角色=成品加工（按订单尺寸单片生产）——**柔性裁床+条码管理系统**是承接能力关键（见 `suppliers/garment-erp-digitalization.md`）；
- **智能窗帘面料**：电动轨道配套面料（静音滑轮带、超平垂感布）——智能家居增长带动。
