# 被芯与枕芯生产（Comforters & Pillows: 填充/立衬/防钻绒）

被芯枕芯是家纺四件套之外的**填充类独立品类**：羽绒被、蚕丝被、化纤被（羽丝绒/大豆纤维）、枕芯（羽绒/记忆棉/乳胶/化纤）。美国零售（Costco/HomeGoods）年采购量稳定，酒店渠道随布草打包（见 `garments/hotel-linen-b2b.md`）。核心壁垒=**填充物真实性+防钻绒工艺**——填充虚标是行业水深区。

## 一、填充物体系（成本与宣称的灵魂）

| 填充 | 关键指标 | 定位 |
|:---|:---|:---|
| 白鹅绒/鸭绒 | 绒子含量 90/95%+蓬松度 700+FP | 高端（见 `fabric/down-feather-raw-materials.md`） |
| 蚕丝 | 桑蚕长丝/双宫丝 | 高端恒温叙事 |
| 羽丝绒/超细纤维 | 0.9D-3D 细旦 | 走量主力（down alternative） |
| 大豆/玉米纤维 | 植物基叙事 | 环保概念款 |
| 记忆棉/乳胶（枕） | 密度 40-60D | 功能枕 |

- **羽绒真实性**：绒子含量虚标（绒丝+羽丝充绒子）是重灾区——IDFL 检测报告随批（见 `fabric/down-feather-raw-materials.md` 的检测与 RDS 认证）；
- **化纤虚标**："羽丝绒"克重虚标（标 700g 实 500g）——**称重全检**（±3%）；
- **蚕丝掺假**：柞蚕丝冒桑蚕丝/短丝冒长丝——燃烧法+84 溶解+显微镜（见 `fabric/silk-linen-fabrics.md`）。

## 二、生产工艺要点

- **立衬工艺（baffle box）**：羽绒被**立体盒式立衬**（立高 2-3cm——绒朵舒展空间）vs 切穿绗缝（冷点跑绒——低端）；立衬条缝制精度=防跑绒关键；
- **防钻绒面料**：高支高密防绒布（233TC+ 防绒棉布/防绒涤）——**摩擦防钻绒测试**（滚箱法评级）；面料透气与防绒平衡（过密影响排湿）；
- **绗缝**：化纤被绗缝花型（电脑绗缝机——花型版权自有）；绗距均匀+无跳针；
- **枕芯结构**：立体边（gusset——侧睡支撑）/滚绳包边；双层枕（外羽绒内羽片——支撑+柔软复合）；
- **充绒均匀度**：充绒机按格定量（每格克重误差 ±5%——验货剪角抽查）；
- **清洁度**：羽绒清洁度/耗氧量检测（异味——差评首因 smell）；化纤棉低 VOC 散味。

## 三、合规要点

- **美国法律标签（law label）**：**填充物注册**（宾州/俄亥俄/加州等 30+ 州——统一注册号 URN 制度；新工厂出口前完成注册，周期 4-6 周）；
- **成分标注**："Down"标注需绒子含量 ≥75%（FTC 规则——"down alternative"表述规范，见 `trade-compliance/textile-labeling-regulations.md`）；
- **阻燃**：加州 TB117 不适用被芯（床上用品豁免逻辑——但床垫关联产品注意边界）；
- **过敏宣称**："hypoallergenic"宣称需支撑（down alternative 的卖点——宣称纪律见 `trade-compliance/green-claims-anti-greenwashing.md`）；
- **卫生**：回收填充物禁令（法律标签强制新料——再生填充仅限特定品类标注）。

## 四、渠道与运营

- **零售**：Costco/HomeGoods/TJ Maxx（性价比大包装）+亚马逊（压缩卷包——回弹测试同 `garments/pet-beds-mats-production.md` 逻辑）；
- **酒店**：随布草招标（枕芯被芯按房间数×3 配比——见 `garments/hotel-linen-b2b.md`）；
- **差评关键词**：flat（塌陷——羽丝绒结团）/feathers poking（钻绒）/smell（异味）/not warm（蓬松虚标）；
- **季节**：Q3-Q4 冬季被芯峰值；枕芯全年平销（换枕健康营销）。

## 五、报价与接单

- **成本结构**：填充物占 50-70%（羽绒价格联动——原料行情见 `fabric/down-feather-raw-materials.md`）+防绒布+人工；
- **报价纪律**：填充克重+绒子含量+蓬松度三参数锁价（防验收纠纷）；
- **MOQ**：被芯 500-1000 条；枕芯 2000+（枕芯机台效率）；
- **验厂**：填充车间飞绒管控（除尘设备）+验针（见 `suppliers/needle-control-metal-management.md`）。
