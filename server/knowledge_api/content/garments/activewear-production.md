# 运动服生产专题（Activewear Production）

运动服（activewear/sportswear）是增长最快的服装品类（瑜伽、健身、户外驱动），技术核心是功能性面料 + 专业缝制工艺。单价与毛利高于基础款，是外贸订单升级方向。

## 一、功能性面料

| 功能 | 面料方案 | 测试标准 |
|:---|:---|:---|
| 吸湿排汗 | 涤纶异形截面（Coolmax 类）、单向导湿 | AATCC 195 / GB/T 21655 |
| 四面弹 | 涤/锦 + 15-25% 氨纶，4-way stretch | 拉伸回复测试 |
| 抗菌防臭 | 银离子/锌离子整理 | AATCC 100 |
| 防紫外线 | 高密度/抗 UV 整理，UPF 50+ | AATCC 183 |
| 速干 | 低吸水纤维 + 快干整理 | 干燥速率测试 |
| 压缩 | 高氨纶比例梯度压力 | 压力值测试 |

- **瑜伽服面料**：锦纶（nylon）+ 氨纶为主流（裸感 buttery soft），250-320GSM 高克重不透；涤氨次之。
- **跑步/训练**：轻量涤纶网眼（mesh）、提花面料。
- **户外**：软壳（softshell 三合一贴合）、硬壳冲锋衣（防水透湿膜 PTFE/PU，静水压 10000mm+）。

## 二、专业缝制工艺

### 四针六线（Flatlock，4-needle 6-thread）
- 运动服标志性工艺：接缝平服无凸棱，贴肤不磨。
- 专机（Yamato/Pegasus 冚车），工费比普通拷克高 30-50%。
- 验货看：线迹均匀、无跳针、接缝拉伸不断线。

### 其他工艺
- **无缝（seamless）**：圣东尼（Santoni）圆机一体成形，运动内衣/紧身裤；开版费高、MOQ 大（500-1000 件/色）。
- **贴合/压胶（bonding/taping）**：无痕口袋、压胶拉链、冲锋衣全压胶（seam taping 防水关键）。
- **激光切割（laser cut）**：无痕裁边、透气孔。
- **反光印花（reflective print）**：夜跑安全，3M 反光材料检测标准。

## 三、品控要点

1. **拉伸回复测试**：瑜伽裤反复拉伸后膝部/臀部不变形（growth & recovery）；氨纶含量与织法决定。
2. **抗起球**：运动摩擦高发起球，马丁代尔测试 ≥ 4 级。
3. **色牢度叠加**：深色面料 + 大量汗液 + 摩擦——耐汗渍/摩擦牢度按运动场景加严。
4. **接缝强力**：平缝拉伸测试（seam slippage + burst strength）。
5. **透湿/透气**：按客户指定标准送检（透湿率 g/m²/24h）。
6. **洗后性能**：功能整理（吸湿排汗/抗菌）**洗 20-30 次后性能保持率**是品牌关注点，订单注明测试洗涤次数。

## 四、认证与合规

- **OEKO-TEX Standard 100**：贴肤运动服基本门槛（见 `trade-compliance/textile-certifications.md`）。
- **Bluesign**：户外品牌（Patagonia 等）强制。
- **GRS**：再生涤纶（rPET）瑜伽服是品牌主推卖点，订单需 TC 交易证书链。
- 化学品：运动服整理剂（吸湿排汗剂/抗菌剂）需符合 ZDHC MRSL。

## 五、报价与生产要点

- **面料占比高**：功能性面料 25-50 元/kg，占成本 50-60%。
- **工费**：四针六线工艺使 CMT 比普通针织高 30-60%（瑜伽裤 CMT 12-20 元）。
- **起订量**：功能面料定织 500-1000kg；无缝款 MOQ 高。
- **打样周期**：功能面料+工艺验证，开发样周期 3-4 周（比基础款长一倍）。
- **产业集群**：福建石狮/晋江（运动面料+成衣）、浙江义乌（无缝）、广东东莞。

## 六、趋势与机会

- **瑜伽/普拉提赛道**持续增长，高腰裸感裤是常青爆品。
- **可持续**：rPET + 生物基氨纶（如 Lycra EcoMade）成为品牌 brief 标配。
- **户外运动融合**：gorpcore 风格模糊运动与日常边界，软壳/机能裤需求上升。
