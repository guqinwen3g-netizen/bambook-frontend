# 化妆包与首饰收纳包生产（Cosmetic & Jewelry Bags: 美妆出行收纳）

化妆包是"**美妆经济溢出+促销赠品渠道**"双轮品类：美妆品牌赠品（GWP——购满即赠化妆包是行业标配促销）+旅行收纳零售。洗漱包/航空赠品包已被旅行配件文档覆盖（见 `garments/travel-accessories-production.md`）——本文聚焦**美妆零售与礼赠渠道**的化妆包、刷具包、首饰收纳卷。生产逻辑与箱包相通（见 `garments/bags-luggage-production.md`），但**小件精细化+颜值驱动**是差异。

## 一、产品矩阵

| 品类 | 材质 | 结构特征 | 渠道 |
|:---|:---|:---|:---|
| 圆筒/方型化妆包 | PU 革/尼龙/TPU 透明 | 大开口+内袋分隔 | 零售/赠品 |
| 贝壳/饺子化妆包 | 缎面/灯芯绒+定型 | 半圆硬挺造型 | 礼品 |
| 刷具包（brush roll/case） | PU+松紧插位 | 刷头保护盖+卷式 | 美妆工具配套 |
| 分层化妆箱（train case） | 铝框+PU/ABS | 多托盘展开——专业化妆师 | 专业渠道 |
| 透明 TPU 化妆包 | TPU 膜 | 机场安检合规（夸脱袋） | 旅行零售 |
| 首饰收纳卷（jewelry roll） | 天鹅绒/缎面 | 项链挂扣+戒指条+耳钉板 | 旅行/礼品 |
| 首饰盒（travel case） | PU+绒布内衬 | 分隔小格+镜子 | 礼品季主力 |
| 抽绳平铺化妆包（lay-flat） | 涤纶牛津 | 摊开成垫——找物便利卖点 | 电商创新款 |

## 二、材料与工艺要点

- **PU 革品质**：干法 PU（耐磨刮）vs 湿法（柔软）——**白色/浅色 PU 耐黄变**是痛点（抗 UV 助剂）；人造革基材见 `fabric/leather-synthetic-leather.md`；
- **透明 TPU**：**抗黄变等级**（TPU 黄变是品类第一差评——选脂肪族 TPU）、低温不脆裂；车缝 TPU 用细针+硅油线防针孔撕裂；
- **内衬**：浅色缎面/塔夫绸（找物可视性）+**防污涂层**（化妆品渗漏）——里布逻辑见 `fabric/linings-interlinings.md`；
- **拉链**：化妆包拉链手感=品质第一触感——**YKK/SBS 尼龙拉链+定制拉片**（logo 拉片是品牌单标配；拉链技术见 `suppliers/zipper-fasteners-deep-dive.md`）；
- **首饰收纳细节**：项链防缠绕挂扣+松紧、戒指槽绒布包裹、**耳钉板孔位精度**——小件工艺公差 ±1mm；
- **定型工艺**：贝壳包/箱型用**海绵+衬板复合**——热压定型 vs 车缝定型。

## 三、渠道与商业要点

- **品牌赠品单（GWP）**：美妆品牌（雅诗兰黛/兰蔻类）季度促销赠品——**设计由品牌方出稿、工厂代工**；起订量大（10 万+）、交期紧、单价低（$0.8-2）；验厂要求（Sedex/BSCI——见 `suppliers/factory-audit-guide.md`）；
- **零售电商**：亚马逊 makeup organizer 类目——颜值驱动（大理石纹/棋盘格/莫兰迪色迭代快）；
- **礼盒渠道**：圣诞/母亲节首饰盒+化妆包套装——Q3 下单 Q4 交付；
- **订阅盒（subscription box）**：美妆订阅盒品牌采购——款式月月新、单款量小（快反模式）；
- **专业渠道**：化妆师 train case（ durability 导向）、美容院工具包（美容院渠道见 `garments/salon-spa-textiles.md`）；
- **白牌窗口**：**功能创新**（LED 镜化妆包、悬挂式旅行化妆包、防水健身洗漱包）避开纯颜值红海。

## 四、风控要点

- **化妆品渗漏污染**：内衬防污+可擦拭是基本要求——详情页宣称"wipeable"需实测；
- **TPU 环保宣称**："PVC-free"是卖点但需材质证明——化学合规见 `trade-compliance/chemical-environmental-compliance.md`；
- **赠品单合规**：美妆品牌验厂+**成品需过品牌国合规**（欧盟 REACH/美 Prop 65——见 `trade-compliance/california-prop65.md`）；
- **知识产权**：大理石纹/豹纹等通用图案安全，**品牌纹样（LV 老花类）仿制=侵权雷区**（见 `trade-compliance/ip-brand-authorization.md`）；
- **尺寸虚标**：容量（升）与实物不符是退货点——标注实测容量+参照物照片；
- **交期刚性**：赠品单与促销 campaign 绑定——延期=全单取消+索赔（交期管理见 `suppliers/production-capacity-scheduling.md`）。
