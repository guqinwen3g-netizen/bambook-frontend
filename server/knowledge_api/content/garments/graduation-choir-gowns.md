# 学位服与仪式长袍生产（Graduation Gowns & Choir Robes: 仪式服装）

仪式长袍是**稳定细分**的工装近亲品类：学位服（学士/硕士/博士袍+学位帽）、唱诗班长袍（choir robe）、牧师服（clergy robe）、法官袍、毕业纪念披肩（stole/sash）。美国市场=学校集采（Herff Jones/Jostens 模式）+教会经销商——**年需求可预测**（每年 5-6 月毕业季）。生产门槛低，**颜色/规格标准体系**是接单关键。

## 一、产品线与规格体系

| 产品 | 面料 | 规格要点 |
|:---|:---|:---|
| 学士/硕士袍 | 涤纶平布/哑光府绸 | 黑为主色；硕士袍长袖口开衩 |
| 博士袍 | 涤纶/混纺绒面饰条 | 天鹅绒前襟条+袖三条杠（学科色） |
| 学位帽（mortarboard） | 同袍面料+硬衬方板 | 流苏（tassel——年份 charm） |
| 披肩（stole/sash） | 色丁 | 荣誉披肩（GPA 色/社团刺绣） |
| 唱诗班袍 | 涤纶/色丁 | 教会色系（白/红/紫——教派传统） |
| 牧师服 | 涤棉/羊毛混纺 | 黑色主调+领口袢（ preaching tabs） |

- **美国学位服规范（ACE 学术服饰法典）**：学士袍尖袖/硕士袍长弧袖/博士袍喇叭袖+天鹅绒条——**版型按 ACE 规范**（错版=整批退货）；
- **学科色体系**：博士袍丝绒条颜色=学科代码（哲学深蓝/教育浅蓝/工程橙/医学绿——30+ 学科色卡）；学校定制色（校色镶边）；
- **流苏色**：学科色/学校色——年份牌（2026/2027 金属牌）年度更新。

## 二、生产工艺要点

- **面料**：哑光涤纶（matte finish——拍照不反光，毕业照刚需）；一次性租赁款用无纺布（成本极低——见 `fabric/nonwoven-fabrics.md`）；
- **打褶**：前襟育克打褶（yoke——定型规整度是验货点）；
- **丝绒贴合**：博士袍丝绒条（压绒布——绒向一致）；缝合平整不卷边；
- **学位帽**：方板内衬 EVA/纸板（挺度）+头围调节（松紧/魔术贴——头围 52-62cm 分码）；
- **披肩绣花**：学校徽/希腊字母（兄弟会姐妹会——刺绣见 `garments/printing-embroidery.md`）；金色金属丝绣线（metallic——断线率高，绣花机降速）；
- **包装**：挂装+防尘袋（礼服级包装——见 `garments/garment-packaging.md`）；学校集采按人名分装（名单分拣工序）。

## 三、渠道与季节

- **学校集采**：Herff Jones/Jostens/Balfour 三大巨头垄断美国毕业用品（戒指+年鉴+学位服打包）——代工门槛=年度框架+验厂；中小学校的直销空档（经销商+亚马逊）；
- **教会渠道**：教会用品经销商（唱诗班袍按堂区订单——20-60 件小单）；非洲市场（尼日利亚/肯尼亚教会袍——大量涤纶色丁袍出口，见 `customers-market/africa-market.md`）；
- **租赁模式**：学校租赁池（回收清洗次年再用——耐用性+可洗性是采购指标）；
- **季节铁律**：**美国毕业季 5-6 月→Q4 下单 Q1 出货**；非洲教会年底（圣诞季）；
- **配套销售**：学位帽+袍+流苏+披肩套装；荣誉绳（honor cord——绳结编织）/毕业熊/相框（礼品连带）。

## 四、合规与报价

- **常规化学**：偶氮/甲醛（贴肤少——标准宽松）；儿童毕业服（幼儿园毕业典礼——CPSIA 适用）；
- **阻燃**：舞台场景部分州查（与 `garments/stage-theatre-drapes.md` 场景关联）；
- **报价**：涤纶袍 $3-8（走量）/博士袍 $15-30（丝绒+工艺）/套装 $10-15；MOQ 500 件/色；
- **利润点**：博士袍/定制刺绣披肩（溢价区）>基础学士袍（价格战）；租赁池年度替换单（稳定返单）。
