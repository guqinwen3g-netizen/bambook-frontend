# 空调服与降温工装生产（Cooling Workwear: 风扇服/蒸发冷却/相变背心）

降温工装是夏季高温作业刚需：**风扇服（腰部风机循环送风）、蒸发冷却背心、相变（PCM）冰袋背心、水冷循环服**四条技术路线。主力市场=**日本（成熟品类，渗透工地/物流/农业）、中东户外工装、国内建筑/电力/外卖骑手**。生产门槛在**风道结构设计与电池合规**，缝制本身简单。智能服装总述见 `garments/smart-wearable-clothing.md`，本文聚焦降温工装的品类深度。

## 一、四条技术路线对照

| 路线 | 原理 | 降温能力 | 续航/持续 | 价格带（零售） |
|:---|:---|:---|:---|:---|
| 风扇服（空調服） | 腰部双风扇抽风→体表蒸发散热 | 体感降 3-6℃（依赖出汗蒸发） | 5V 充电宝 8-12h | $40-120 |
| 蒸发冷却背心 | PVA/高吸水纤维浸水后缓释蒸发 | 体感降 5-8℃（干热气候有效，高湿失效） | 浸水 1 次持续 4-8h | $15-40 |
| 相变 PCM 背心 | 冰格/相变材料包（15-28℃ 熔点）插袋 | 局部强降温 | 2-4h（冷冻/冷藏再生） | $30-80 |
| 冰袋/水冷循环 | 冰袋贴袋/微型泵循环冷水 | 强降温 | 2-3h | $25-150 |

- **风扇服局限性**：环境温度>37℃ 或高湿环境效果锐减（吹热风）——日本市场已教育成熟，中东需搭配 PCM 组合销售；
- **蒸发冷却**：中东干热气候首选（PVA 面料吸水膨胀后缓释——**高湿地区差评高发**，listing 必须讲气候适用性）。

## 二、风扇服生产要害

- **面料**：涤塔夫/尼龙塔夫绸（**防钻风**——透气率过高风短路、过低鼓不起来；主流透气率 5-15mm/s）——与防晒服面料逻辑相反（见 `garments/sun-protection-clothing.md`）；**保气性=核心指标**（领口/袖口/下摆橡筋收拢形成空气循环腔）；
- **风扇口结构**：腰部两侧 9-10cm 开孔+**防护网+卡扣座**（风扇快拆——洗涤拆机）；开孔锁边+织带加固（风机振动工况下撕裂是主要失效）；
- **风扇选型**：5V 无刷电机（寿命 5000h+）——转速 3500-5500rpm 可调档；**振动噪声<50dB**（工地对讲干扰投诉点）；线束内置通道（走线管车缝在侧缝）；
- **版型**：宽松蝙蝠袖（空气腔容积）+**长袖款主流**（防晒+鼓风充盈）；反光条配置按工装惯例（见 `fabric/hi-vis-reflective-fabrics.md`）；
- **电池袋**：侧腰内袋+USB 线穿孔——电池不随服销售（空运合规简化，listing 标注"充电宝自备"或套装配认证电池）。

## 三、电池与电器合规

- **锂电池运输**：UN38.3 测试报告+MSDS+航空运输鉴定书（空运强制——见 `trade-compliance/pre-shipment-coc-psi.md` 的运输文件链）；电池**单独包装绝缘**（电极防短路）；
- **日本市场**：充电宝类电池落 **PSE 圆形标志**（电安法）——无 PSE 电池套装禁止在日销售；
- **欧盟 CE**：风扇组件按 LVD+EMC（电压<75V 仍建议做 EMC——电机干扰）；美国 FCC（电机类无意辐射体）；
- **洗涤说明**：拆风扇后整衣可水洗（listing/吊牌明示）——风机本身 IPX2 防汗滴即可（工地场景不做潜水宣称）；
- **发热安全**：电机连续工作温升（劣质电机烫腰投诉）——选用带过温保护方案商。

## 四、市场与渠道

- **日本**：成熟教育市场（小松/空調服® 等品牌主导）——尺码偏小、藏青/军绿色调、细节要求高（检针+全数检品，见 `suppliers/needle-control-metal-management.md`）；
- **国内**：建筑/电力/外卖骑手工装集采（京东工业/震坤行 B2B 渠道）——低价走量（¥80-150 出厂），电池套装是利润点；
- **中东/东南亚**：出口潜力市场（石油工地/基建中资企业外派劳保采购）——高温高湿场景推"风扇+PCM"组合款；
- **季节节奏**：北半球 4-5 月下单 6-7 月交付（生产倒排 60 天）；南半球补单季 10-11 月；
- **差评高发点**：风力虚标（listing 风速夸大）、电池续航虚标、风扇异响、洗后风道变形——详情页实测视频是转化关键。
