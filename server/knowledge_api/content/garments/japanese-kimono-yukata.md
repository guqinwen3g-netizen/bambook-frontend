# 日本和服与传统服饰出口（Kimono/Yukata: 浴衣/甚平/作务衣）

日本传统服饰是"**文化刚需+季节强脉冲**"的特色品类：浴衣（yukata）绑定夏日祭/花火大会，甚平/作务衣绑定温泉旅馆与餐饮工装，正装和服是高门槛高端线。日本市场进口传统服饰 90%+ 中国制（江浙沪集群）。市场背景见 `customers-market/jp-market.md`，本文聚焦产品与工艺。

## 一、产品矩阵

| 品类 | 材料 | 场景 | 特征 |
|:---|:---|:---|:---|
| 浴衣 Yukata | 棉平纹/棉麻/绉布（ちりめん） | 夏日祭/花火大会/温泉旅馆 | 7-8 月旺季——倒排 3-5 月交货 |
| 甚平 Jinbei | 棉/棉麻（上衣+短裤两件套） | 家居/祭典/儿童 | 宽松系绳结构 |
| 作务衣 Samue | 棉/涤棉斜纹 | 寺院/寿司店/温泉旅馆工作服 | B2B 集采+袖口收口 |
| 正装和服 Kimono | 化纤/正绢（访问着/振袖/留袖） | 成人式/婚礼/茶事 | 高门槛（正绢+手描友禅为日本本土高端） |
| 羽织 Haori/道行 | 化纤/羊毛 | 外搭 | 羽织纽（编织纽）配套 |
| 带 Obi | 窄幅提花织带（博多织/西阵织风格） | 和服固定+装饰 | 半幅带/名古屋带/袋带分级 |

- **尺寸体系**：反物（tanmono 38cm 传统幅）逻辑——成衣按**身丈/袖丈/裄（ゆき）**标注，与西洋尺码完全不同；成人/儿童分档；
- **和裁特征**：**直线剪裁**（整幅面料不浪费——缝份直线条）+袖袋（袂）+身八口——版师需懂和裁结构，不能套用西式打版（见 `garments/pattern-grading-sizing.md` 西式对照）。

## 二、工艺与品质要点

- **染印工艺**：注染（传统型染——两面透色）/プリント（平网/数码——见 `fabric/digital-printing-technology.md`）；花型=桜/朝顔/金魚/矢絣传统柄+现代柄；
- **缝制**：单衣（ひとえ）无里衬结构——**缝份包缝/来去缝**（薄料散边管控）；带枕/带板等配件缝制精度；
- **整理**：棉浴衣**防缩+抗皱**（见 `suppliers/washing-factory-management.md`）——日本客户对縮み（缩水）投诉零容忍；
- **检针**：日本订单检针全数必过（童装尤其——见 `suppliers/needle-control-metal-management.md`）；
- **品质表示**：日本家庭用品品质表示法——**纤维表示+洗涤表示+原产国**三件套（見 `trade-compliance/textile-labeling-regulations.md` 日本章节逻辑）。

## 三、市场与渠道

- **季节节奏**：花火大会/夏祭（7-8 月）——**2-3 月下单、5 月交货**；成人式（1 月——振袖高端租赁）；温泉旅馆（全年稳定——浴衣+作务衣+帯集采复购）；
- **渠道**：日本邮购/乐天/亚马逊日本（浴衣セット——浴衣+带+下駄三件套是电商标品）、温泉旅馆 B2B、海外日料店（作务衣/寿司服——欧美日餐扩张带动）、和服租赁店（京都/浅草——观光客振袖体验）；
- **出口形态**：面料反物出口（日本缝）+成衣出口（中国缝）双轨——**成衣化率提升是中国厂价值升级路径**；
- **竞品**：日本本土高端（正绢/西阵织——文化保护）不与中国竞争价格带；化纤印花浴衣=中国主场。

## 四、风险与谈判要点

- **品质预期**：日本客户**全检文化**（线头/汚れ/折ジワ 零缺陷预期——出货全检+检针+后整理见 `suppliers/finishing-ironing-packing-room.md`）；
- **交期刚性**：花火大会不等人——**延迟=整单取消**（季节品逻辑同 `garments/christmas-holiday-textiles.md`）；
- **知识产权**：传统柄可自由使用；**动漫联名/キャラクター柄必须授权**（见 `trade-compliance/ip-brand-authorization.md`）；
- **付款**：日本商社信用好但验货严（第三方检品公司出货前全检）。
