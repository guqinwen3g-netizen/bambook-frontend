# 内衣与家居服生产专题（Underwear & Loungewear Production）

内衣（underwear/lingerie）与家居服（loungewear/sleepwear）是高频复购、强复购粘性的品类，对**亲肤面料、版型合身度、缝制精细度**要求最高。贴肤品类的安全与舒适是复购根本。

## 一、面料选择

| 面料 | 特点 | 用途 |
|:---|:---|:---|
| 精梳棉（combed cotton） | 亲肤透气，基础主力 | 内裤、背心 |
| 莫代尔（modal） | 柔软悬垂、吸湿优于棉 50% | 中高端内裤/家居服 |
| 莱赛尔（lyocell/Tencel） | 丝滑环保 | 高端线 |
| 竹纤维（bamboo） | 抗菌卖点（注意 FTC 对"bamboo"宣称的规范——须标 rayon made from bamboo） | 袜类/内裤 |
| 棉氨（95/5、92/8） | 弹性贴身 | 弹力内裤 |
| 蕾丝/网布（lace/mesh） | 装饰 | 文胸/女内裤 |
| 法兰绒/珊瑚绒/摇粒绒 | 保暖 | 冬季家居服 |

- **克重参考**：内裤 160-180GSM、背心 180-200GSM、家居服 200-280GSM。
- **裆部**：双层设计，里裆 100% 棉（卫生要求）。

## 二、文胸（Bra）——技术门槛最高

- 部件多达 20-30 个（罩杯/钢圈/肩带/背扣/胶骨/衬垫），供应链涉及模杯厂/五金厂/花边厂。
- **模杯（molded cup）**：热压定型，杯型（1/2、3/4、全杯）与厚度需与客户 tech pack 一致。
- **钢圈（underwire）**：镍释放需符合 REACH；机场安检提示不是质量问题。
- **尺码体系**：下胸围+罩杯（70A/75B/80C 亚洲；32A/34B 英美）——外贸按客户市场体系。
- 公差极严：罩杯对称性 ±3mm，背扣间距 ±2mm。

## 三、缝制工艺

- **四针六线（flatlock）**：贴肤无磨缝，中高端标配。
- **冚车绷缝（coverstitch）**：下摆/袖口，正面双针反面链式，拉伸不断线。
- **包边（binding）**：领口/袖窿弹性包边带。
- **无缝（seamless）**：圣东尼圆机一体成形，无侧缝内裤/运动内衣；详见 `garments/activewear-production.md`。
- **腰头橡筋**：外露 logo 织带或内置包覆橡筋，拉伸回复测试（洗 20 次后松弛度）。

## 四、安全与合规

1. **OEKO-TEX Standard 100 附录 6（婴儿级）或附录 4**：贴肤品类品牌基本要求。
2. **甲醛/pH**：婴幼儿内衣 A 类（甲醛 ≤20mg/kg，pH 4.0-7.5）。
3. **色牢度**：耐汗渍/耐唾液（婴幼儿）/湿摩擦——内裤深色系湿磨是难点。
4. **美国睡衣阻燃**：成人睡衣适用 16 CFR 1610；儿童睡衣见童装文档。
5. **纤维宣称**：竹纤维/莫代尔/Tencel 宣称需符合 FTC 纤维命名规则。

## 五、版型与合身度

- **合身度（fit）是内衣生命线**：同一尺码不同品牌版型差异大，外贸按客户 spec + 试穿模特（fit model）确认。
- **试穿评审（fit session）**：产前样需客户试穿批准（真人试穿，非人台）。
- 跳码：内衣跳码量小（内裤腰臀围跳 4-5cm），版型放大不改变受力结构。

## 六、报价与生产要点

- **CMT**：内裤 2-4 元、背心 4-6 元、家居服套装 10-18 元、文胸 15-30 元（部件多、工序繁）。
- **MOQ**：内裤 3000-5000 件/色（面料缸量驱动）；文胸 1000-2000 件/款。
- **产业带**：广东汕头（潮南/潮阳内衣集群，全球最大文胸基地）、佛山盐步、义乌（无缝）、中山小榄（内裤）。
- **验货重点**：对称性、线头（贴肤零线头）、橡筋拉伸、洗后变形。

## 七、市场趋势

- **无尺码（one-size/adaptive）**：高弹面料+无钢圈，Shein/内外（NEIWAI）带动的趋势。
- **无钢圈舒适化**：bralette 品类增长，工艺门槛低于传统文胸，适合切入。
- **可持续**：有机棉 + GRS 再生蕾丝，欧美品牌环保线需求。
- **男士内衣升级**：莫代尔/冰丝平角裤是跨境爆款。
