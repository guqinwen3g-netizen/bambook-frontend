# 运动护具生产（Sports Protective Gear: 护膝/护腰/肌效贴/支撑等级）

运动护具是"**弹性纺织+医用叙事**"的高毛利品类：护膝/护腰/护肘/护踝/护腕+肌效贴（kinesiology tape）。横跨运动消费（亚马逊大热）与医疗康复（FDA 一类器械边界）双赛道。与压缩服（见 `garments/compression-wear-production.md`）共享弹力工艺，与医用纺织（见 `garments/medical-healthcare-textiles.md`）共享合规边界。

## 一、产品线与材料结构

| 产品 | 材料 | 结构要点 | 价格带（零售） |
|:---|:---|:---|:---|
| 基础护膝 | 氯丁橡胶（neoprene 3-5mm）+尼龙布复合 | 开孔（髌骨稳定）/闭口、魔术贴调节 | $10-30 |
| 针织护膝 | 尼龙氨纶无缝针织+硅胶防滑条 | 四面弹+**硅胶防滑圈（移位是差评首因）** | $15-40 |
| 支撑护膝（铰链款） | 针织+双侧金属/塑料铰链+髌骨垫圈 | 术后/韧带损伤级支撑 | $30-80 |
| 护腰 | 氯丁橡胶/弹力织带+支撑条（钢/PP） | 宽度 20-30cm+双重加压带 | $15-50 |
| 护踝 | 弹力针织/绑带式+八字缠绕 | 防崴脚（篮球刚需） | $10-35 |
| 肌效贴 | 棉/人造丝弹力布+医用压敏胶（波纹涂胶） | 预切/卷装——**胶水质量=致敏与粘性命门** | $8-25/卷 |

## 二、生产工艺要害

- **氯丁橡胶复合**：SBR/CR 发泡片贴合尼龙布——贴合牢度（反复弯折不脱层）+边缘包缝（锁边开裂是主要失效）；**气味控制**（低质 SBR 橡胶味重——差评高频词）；
- **无缝针织**：圣东尼（Santoni）圆机——一体成型无接缝压迫；**硅胶防滑条印刷**（波浪/点状——洗 30 次不脱落）；
- **支撑条装配**：弹簧条/钢板插袋结构——缝制牢固+防穿出（金属条刺出=安全事故）；铰链款铆接精度；
- **尺码体系**：护具按围度（膝围/腰围/踝围）分 4-6 码——**尺码表必须给测量方法图示**（尺码不符退货率 30%+）；左右脚/手专用款标注；
- **肌效贴涂胶**：医用丙烯酸压敏胶波纹涂布（胶量 30-50g/m²）——粘性（出汗不脱落）与低致敏的平衡；剥离离型纸印刷刻度。

## 三、合规边界（宣称定生死）

- **普通运动护具**：无医疗宣称（"support/comfort/protection"）=普通消费品，CPSC 一般安全+化学（邻苯/偶氮/甲醛——皮肤长时间接触按 OEKO-TEX 一类逻辑）；
- **医疗宣称红线**："治疗/矫正/术后康复/缓解关节炎疼痛"→**美国 FDA 一类医疗器械**（注册+列名+QSR）、欧盟 MDR 一类（见 `garments/incontinence-care-products.md` 同类定性逻辑、`trade-compliance/ppe-protective-clothing-compliance.md` 边界）；亚马逊要求 FDA 注册号才允许医疗宣称 listing；
- **肌效贴**：FDA 按一类器械管理（Elastic therapeutic tape）——510(k) 豁免但需注册列名；
- **止痛成分禁区**：不可添加薄荷醇/辣椒素等宣称镇痛（药品监管）；
- **Prop 65**：氯丁橡胶/胶水溶剂残留（甲苯）+邻苯——见 `trade-compliance/california-prop65.md`。

## 四、市场与渠道

- **运动线**：亚马逊（护膝/护腰是常青爆款——篮球/跑步/健身场景）+运动品牌 OEM；**差异化=硅胶防滑+透气打孔+尺码精准**（同质化红海中的细节战）；
- **银发/康复线**：老龄化驱动（护膝护腰复购）——药房渠道（CVS/Walgreens 类）+医疗保险编码（美国 HCPCS L-code 报销产品——合规门槛高但溢价稳）；
- **职业防护线**：护腰（物流搬运——亚马逊仓库工人标配叙事）+护膝（装修/园艺跪姿——gel 填充款），与工装渠道协同（见 `garments/workwear-uniform-production.md`）；
- **电竞/办公新兴**：护腕（鼠标手）/ posture corrector（体态矫正带——营销驱动品类，宣称需谨慎）；
- **差评热点**：移位下滑（防滑设计）、闷热（透气）、魔术贴失效（射出钩+起毛布配对寿命）、尺码偏小、皮肤刺痒（乳胶过敏——**latex-free 标注是美系基本要求**）。
