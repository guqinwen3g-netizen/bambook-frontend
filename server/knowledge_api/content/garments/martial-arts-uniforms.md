# 武术道服生产（Martial Arts Uniforms: 跆拳道/柔道/空手道/BJJ）

武术道服是"**重磅面料+耐撕扯车缝+协会认证**"的专业制服品类：道馆集采绑定学员入口，赛事认证款有准入壁垒。与搏击装备（拳套/护具——见 `garments/combat-sports-equipment.md`）同属格斗赛道但产品逻辑不同：道服是**服装**，核心在面料克重与缝线强力。

## 一、产品线与面料规格

| 品类 | 面料 | 克重 | 特征 |
|:---|:---|:---|:---|
| 跆拳道 Dobok | 涤棉（T/C 65/35）蜂窝布/条纹布 | 7-9 oz | V 领套头/系带，白色为主（黑领段位款） |
| 柔道 Gi | 全棉单织/双织（single/double weave） | 350-750gsm | 蓝/白两色——**双织重磅耐抓扯** |
| 空手道 Gi | 全棉/涤棉帆布（duck canvas） | 8-14 oz | 轻薄利落（击打发声脆响是卖点） |
| 巴西柔术 BJJ Gi | 珍珠织（pearl weave）上衣+防撕布（ripstop）裤 | 350-550gsm | IBJJF 比赛检查袖长/衣长/厚度 |
| 功夫服 | 缎面/仿真丝+盘扣 | — | 表演向（低价跑量） |

- **腰带体系**：白黄绿蓝棕黑段位带（4-5cm 宽涤棉斜纹——道服连带销售）；绣段位条（bar）是定制服务；
- **缩水管理**：全棉 gi **预缩不到位=差评重灾区**（洗后缩 5-10%——袖长/衣长报废）——预缩工艺+洗后尺寸公差表必须在规格书锁定；
- **面料采购**：重磅棉织类见 `fabric/woven-fabrics.md` 与 `fabric/canvas-oxford-fabrics.md` 帆布规格。

## 二、工艺要害（耐撕扯=生命线）

- **领口结构**：柔道/BJJ 领口**多层布+EVA 芯填充**（防抓扯变形——领子被抓握承受全部体重）——5-6 层车合+密针距；
- **补强点位**：腋下/裆底/膝部**三角贴布补强（gusset）**+回针/套结加固——开线投诉 90% 来自这些点位；
- **裤腰**：抽绳+松紧双系统（抽绳防滑脱——道馆训练强度下纯松紧会移位）；
- **刺绣**：道馆 logo/姓名绣（见 `garments/embroidered-patches-woven-labels.md`）——集采单必配；绣花在重磅布上需垫衬纸防起皱；
- **检验**：缝线滑移测试+面料撕破强力（见 `fabric/fabric-inspection-4point.md` 四分制外观+强力送检）。

## 三、认证与标准（比赛准入）

- **跆拳道**：WT（World Taekwondo）认证比赛服——面料/版型/标识备案制；
- **柔道**：IJF 认证（蓝白双色+尺寸窗口——袖长/衣长/领宽有公差表）——认证供应商名录制；
- **BJJ**：IBJJF 规则（袖长距腕≤4cm、面料厚度上限、禁止金属件）——赛前 gi 检查不过=退赛；
- **安全合规**：儿童道服按童装化学+物理安全（见 `trade-compliance/cpsc-children-safety.md`——抽绳长度例外：运动服腰部抽绳有功能豁免但需标注）；欧洲按一般纺织品+REACH。

## 四、市场与渠道

- **道馆集采**：全球跆拳道/柔道馆 B2B——**学员入门包（道服+腰带+护具）年复购**（学员流失补充+升段换带）——获客靠道馆教练社群+展会（MAIA/SuperShow）；
- **品牌 OEM**：Adidas/Venum/Fuji/Hayabusa 代工——审厂+验货标准（见 `suppliers/factory-audit-guide.md`）；
- **电商零售**：亚马逊道服类目——差异化=缩水率承诺+免费绣名+套装（道服+白腰带）；
- **差评热点**：缩水超标、领口洗后塌软、裤裆开线、白色泛黄（荧光剂迁移）、尺码偏小——**尺码表必须给洗后尺寸**；
- **季节性**：开学季（9 月）+新年（1 月健身潮）双脉冲。
