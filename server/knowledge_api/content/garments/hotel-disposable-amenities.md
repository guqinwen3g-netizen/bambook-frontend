# 酒店一次性纺织品生产（Hotel Disposable Amenities: 拖鞋/浴帽/洗护袋）

酒店一次性纺织品是"**低值高频+集采压价**"的耗品赛道：拖鞋、浴帽、洗护袋、擦鞋布随客房周转持续消耗，扬州杭集镇形成全球酒店耗品产业集群。品类技术门槛低，**竞争在成本控制、酒店供应链准入与环保合规升级**。与酒店制服（形象类——见 `garments/aviation-hospitality-uniforms.md`）/酒店布草（巾类床品——见 `garments/hotel-linen-b2b.md`）同属酒店采购体系但供应商分组不同（OS&E 杂品类）。

## 一、产品矩阵与规格

| 品类 | 主流材料 | 关键规格 | 单价带（元/件） |
|:---|:---|:---|:---|
| 无纺布拖鞋 | PP 纺粘 50-80gsm+EVA/防滑点塑底 | 28-29cm 通用码，底厚 3-5mm | 0.4-1.2 |
| 毛巾布拖鞋 | 全棉/涤棉毛巾布+EVA 底 | 底厚 5-7mm，包边/贴条 | 1.5-4 |
| 华夫格/珊瑚绒拖鞋 | 华夫格棉/法兰绒+加厚底 | 中高端酒店 | 3-8 |
| 浴帽 | PE 膜+松紧/无纺布 | 直径 28-32cm | 0.1-0.3 |
| 洗护袋（laundry bag） | 无纺布抽绳/PE 膜 | 45×55cm 等 | 0.3-1 |
| 擦鞋布/鞋拔 | 无纺布/绒布 | — | 0.1-0.5 |
| 卫生袋（sanitary bag） | PE 膜印刷 | — | 0.05-0.15 |

- **拖鞋鞋底分级**：EVA 发泡（轻软）>TPR（耐磨防滑）>点塑无纺布（经济）——**湿滑地面投诉多因经济款点塑底失效**；
- **工艺路线**：无纺布拖鞋**超声波压合**为主（无线头、速度快），毛巾布款车缝+包边；
- **印刷**：酒店 LOGO 烫印/丝印——连锁酒店 VI 色管理（同制服定染逻辑）。

## 二、采购体系与准入

- **采购结构**：连锁酒店集团**中央集采**（锦江/华住/万豪供应链目录）>区域经销商>单体酒店直采——进集采目录=量稳价低；
- **耗品打包招标**：酒店常将牙具/梳洗/拖鞋/纸品**整包招标**——纺织件常与洗漱用品供应商联合投标；
- **验货要点**：拖鞋抽样测底厚/克重/拉力（鞋面与鞋底粘合剥离）、异味、LOGO 印刷牢度；
- **交付节奏**：酒店耗品**安全库存低+补货高频**（月滚动订单）——供应商本地仓能力重要；
- **出口市场**：中东（酒店建设潮）、东南亚（旅游业）、日韩（民宿）——出口注意**目的国一次性塑料限制**。

## 三、环保合规升级（确定性趋势）

- **欧盟 SUP 指令**：一次性塑料制品受限——PE 浴帽/塑料底拖鞋承压，**转向无纺布/可降解材料**（PLA/玉米淀粉基）；
- **中国限塑**：上海等地酒店**不主动提供一次性用品**政策扩散——耗品从"标配"转"按需索取"，量减价升；
- **绿色叙事陷阱**：可降解宣称需认证支撑（DIN CERTCO/BPI）——虚标漂绿风险见 `trade-compliance/green-claims-anti-greenwashing.md`；
- **升级方向**：可水洗重复使用拖鞋（高端酒店）、竹木牙刷（跨界）、纸质包装替代塑封。

## 四、风控要点

- **卫生安全红线**：一次性用品**不可回收翻新**——回收棉/回收无纺布做拖鞋=重大舆情与法律责任；
- **异味控制**：EVA 底回收料异味（氨味/酸味）是差评第一源——原生料或低味配方；
- **防滑责任**：浴室滑倒引发客诉赔偿——高端酒店要求湿态防滑测试数据；
- **毛利极薄**：单件毛利常以分计——**原料价格波动（PP 粒料——套保逻辑见 `trade-process/commodity-futures-hedging.md`）与账期（酒店账期 60-90 天）**挤压现金流（现金流管理见 `suppliers/garment-factory-cash-flow.md`）；
- **无纺布基材**：纺粘/水刺无纺布规格选择见 `fabric/nonwoven-fabrics.md`；美容无纺布邻近品类见 `garments/beauty-disposable-nonwovens.md`。
