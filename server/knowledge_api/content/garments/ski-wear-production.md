# 滑雪服生产（Ski Wear: 防水透湿/雪裙/RECCO/压胶）

滑雪服是户外功能服的**技术天花板**：防水 10K-20Kmm、透湿 10K+g/m²/24h、全压胶、雪裙/RECCO 等专项结构，一件高端滑雪服工艺难度≈3 件冲锋衣。市场：欧洲（阿尔卑斯）、北美、日本（品质最挑剔）、中国（崇礼/新疆——冬奥后增长最快）。产业门槛=压胶设备+技术版师+品牌验厂（见 `garments/outdoor-functional-wear-production.md` 的户外总述，本文聚焦滑雪专项）。

## 一、面料与防水透湿体系

| 层级 | 结构 | 防水/透湿 | 定位 |
|:---|:---|:---|:---|
| 2L | 面布+膜，里布独立 | 10K/10K | 入门-中端（需里布） |
| 2.5L | 面布+膜+印花保护层 | 10K/10K | 轻量 shell |
| 3L | 面布+膜+经编保护布 | 20K/20K | 高端专业线 |

- **膜技术**：PU 膜（中端）/ePTFE 膜（Gore-Tex 模式高端）——复合工艺见 `fabric/functional-coating-lamination.md`；
- **DWR 表防**：C0 无氟 DWR 是欧美强制趋势（PFAS 禁令——见 `trade-compliance/pfas-restriction-fluorine-free.md`），耐洗 20 次后喷淋≥80 分；
- **填充保暖**（insulated 款）：PrimaLoft（P 棉）/3M Thinsulate（新雪丽）为标杆，克罗值（CLO）对标——仿品填充检测克重+克罗值（见 `fabric/down-feather-raw-materials.md` 的羽绒替代逻辑）；高端线 shell（无填充）+base layer 分层（见 `garments/thermal-underwear-production.md`）。

## 二、滑雪专项结构（与冲锋衣的差异点）

- **雪裙（powder skirt）**：弹力防滑硅胶条+按扣——防摔倒灌雪；可拆卸设计加分；
- **RECCO 反射片**：雪崩救援定位片（袖/腿内置——欧洲雪场标配，日本高端线必配）；国内替代品注意谐振频率一致性；
- **雪卡袋（ski pass pocket）**：左袖透明/RFID 友好小袋——刷卡不取卡；
- **腋下透气拉链（pit zip）**：长拉链双向——大运动量散热；
- **防风雪袖口（wrist gaiter）**：弹力内袖+拇指扣；裤脚防雪裙+防磨贴片（ski edge 切割——考杜拉/牛津补强）；
- **护目镜袋+擦镜布**：胸袋内衬超细纤维布挂袢；
- **帽兜**：头盔兼容（helmet-compatible）三维调节——不遮视野是安全项。

## 三、生产工艺要点

- **压胶（seam taping）**：全压胶（fully taped）高端 vs 关键部位压胶（critically taped）中端——压胶条宽度 20/22mm，**洗后不起翘**是验货点（胶温/压力/速度三参数，首件剥离强力测试）；
- **防水拉链**：YKK AquaGuard（PU 贴膜）/AquaSeal（ePTFE 密合）——主链用 Vislon 树脂防水（金属低温脆化+冻手）；
- **激光切割+无缝**：高端线口袋/透气孔激光切+热压贴合——裁片精度±0.5mm；
- **低温工艺验证**：压胶条/涂层 -30°C 弯折无脆裂（冷箱测试）；
- **成衣测试**：静水压（ISO 811）、透湿（JIS L1099 B1/RET）、接缝滑移、低温弯折、喷淋（AATCC 22）。

## 四、市场与接单

- **品牌梯队**：Descente/Phenix/Bogner（高端代工门槛——验厂+技术文件）、Spyder/Helly Hansen（中端主力）、白牌（韩国/国内电商——性价比）；
- **验厂门槛**：压胶车间恒温恒湿+压胶机数量=产能上限；品牌派驻厂 QC 常态；
- **合规**：滑雪服属消费品（非 PPE），但**儿童滑雪服**绳带安全（EN 14682——帽绳抽绳规则，见 `garments/childrenswear-production.md`）；RECCO 宣称需授权贴标；
- **季节**：Q1 接单→Q3 出货（北半球 10 月零售）——反季排产与羽绒服共线（见 `garments/down-jackets-production.md` 的排产冲突管理）；
- **报价**：3L 面料+全压胶+YKK 防水链——面料占成本 50%+；加工费是普通棉服 3-5 倍；MOQ 300-500 件/色（小单多款是常态）。
