# 箱包生产与出口（Bags & Luggage: Backpacks, Handbags, Suitcases）

箱包是纺织外贸重要延伸品类：背包/手袋（软包，缝纫逻辑近服装）+拉杆箱/旅行箱（硬箱，注塑+装配逻辑）。产业带：河北白沟（中低端）、广州花都狮岭（女包）、浙江平湖/温州（拉杆箱）、福建泉州（运动背包）。订单常来自服装客户连带采购（品牌配饰线）。

## 一、品类与工艺路线

| 品类 | 主体工艺 | 关键物料 | 设备差异 |
|:---|:---|:---|:---|
| 背包/运动包 | 裁片缝纫+织带车合 | 600D/900D 牛津布、YKK 拉链、插扣 | 高头车/同步车（厚料） |
| 女式手袋 | 折边/油边/铲皮+车缝 | PU/真皮、五金（锁扣/链条） | 油边机/铲皮机 |
| 电脑包 | 内衬 EVA 定型+缝纫 | 潜水料/尼龙+EVA | 热压定型机 |
| 拉杆箱（硬箱） | ABS/PC 吸塑+铝框+装配 | PC/ABS 板材、万向轮、拉杆 | 吸塑机/装配线 |
| 软壳旅行箱 | 面料车缝+内框+轮组 | 1680D 尼龙、铝框 | 混合工艺 |

- **与服装厂的能力衔接**：软包车缝工序可复用服装设备，但**厚料车（同步车）、高车、柱车**必须新配——评估见 `suppliers/garment-machinery-equipment.md`；
- **五金供应链**：拉链（YKK/SBS/SAB 价差 3-5 倍）、插扣（ITW/多耐福）、锁具——五金占成本 20-35%，且是客诉高发区（见 `suppliers/fabric-accessories-supplier-management.md`）。

## 二、品质核心指标

| 测试项 | 常用标准 | 基准 |
|:---|:---|:---|
| 拉链耐用 | QB/T 2171 / BS 3084 | 往复 5000 次无故障 |
| 负重振荡（背包） | QB/T 1333 | 加载 14-20kg 振荡 400-1000 次无破损 |
| 拉杆往复 | QB/T 2155 | 3000 次无卡滞断裂 |
| 轮子行走 | QB/T 2155 | 12-32km 负重行走无异常 |
| 跌落 | 企业标准 | 装载跌落 1m×3 次 |
| 色牢度/耐摩 | ISO 105 系列 | 同纺织通标（见 `trade-compliance/testing-standards.md`） |

- **防水**：背包防泼水（DWR 涂层）与防水包（TPU 贴合+气密拉链）是两个价位——宣传防水等级需测试支撑；
- **针距与受力**：受力部位（提手/肩带连接）回针加固+打枣（bar tack）3-5 道——承重开线是退货首因。

## 三、报价与打样要点

- **打样周期长**：手袋出格（纸格）+五金开模——首样 10-15 天，修改 2-3 轮常态；五金模具费单列（$50-300/款）；
- **报价拆项**：面料+五金+人工+损耗分开列——五金涨价快（锌合金随金属行情），便于年中调价；
- **MOQ**：软包 300-500pcs/色；硬箱开模成本高，MOQ 通常 500-1000 套；
- **成本锚点**：背包工费约占总价 25-30%——比服装（15-20%）高，报价时人工别按服装逻辑压（见 `garments/garment-costing-pricing.md`）。

## 四、出口合规与认证

- **化学**：PU/PVC 革的邻苯二甲酸酯（美国 Prop 65 重点，见 `trade-compliance/california-prop65.md`）、REACH SVHC（欧盟）——人造革必须过 6P/7P 邻苯测试（见 `fabric/leather-synthetic-leather.md`）；
- **儿童背包**：美国 CPSIA（铅/邻苯+小部件）、欧盟 EN 71 逻辑——见 `trade-compliance/cpsc-children-safety.md`；
- **真皮材质**：CITES（鳄鱼/蛇皮等，见 `trade-compliance/cites-compliance.md`）、EUDR（牛皮溯源，见 `trade-compliance/eudr-leather-deforestation.md`）；
- **HS 归类**：4202 章按材质细分（革面/塑料面/纺织面税率差异大，美国纺织面箱包关税显著低于革面）——归类策略见 `trade-compliance/hs-classification-practice.md`；
- **品牌授权**：贴牌 IP 授权链条（迪士尼/漫威等）必须留授权书副本（见 `trade-compliance/ip-brand-authorization.md`）。

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 五金电镀掉色 | 差评退货 | 盐雾测试 24-48h 报告 |
| 提手打枣强度不足 | 断带索赔 | 产前做破坏性负重测试 |
| 里布缩水皱包 | 外观次品 | 里布预缩处理 |
| 拉杆晃动间隙大 | 品质投诉 | 装配公差 ≤1.5mm 全检 |
| 胶水中毒（氯丁胶） | 验厂/工人健康 | 水性胶替代+车间通风（见 `suppliers/factory-safety-fire-management.md`） |
