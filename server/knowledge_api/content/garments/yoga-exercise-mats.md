# 瑜伽垫与健身垫生产（Yoga & Exercise Mats: TPE/NBR/麂皮绒复合面）

瑜伽垫是纺织复合技术与发泡材料的交叉品类：纯发泡垫属橡塑制品，但**麂皮绒面/毛巾面/软木布面复合垫**由纺织复合厂主导生产（热复合/胶合工艺——见 `fabric/functional-coating-lamination.md`）。家用健身（普拉提/HIIT）后疫情时代进入稳定期，差异化在**面料触感与印花颜值**。与促销垫（`garments/promo-mats-mouse-pads.md`）、野餐垫（`garments/picnic-beach-mats-production.md`）共享发泡复合产线。

## 一、产品矩阵

| 款型 | 材料 | 厚度 | 价格带（零售） |
|:---|:---|:---|:---|
| TPE 单色/双色垫 | TPE 发泡（闭孔） | 6-8mm | $15-35（**主流款**） |
| NBR 厚垫 | 丁腈发泡 | 10-15mm | $12-25（健身/普拉提缓冲） |
| PVC 垫 | PVC 发泡 | 4-8mm | $8-20（低价量大——邻苯雷区） |
| 麂皮绒复合垫 | 麂皮绒布面+天然橡胶底 | 1.5-5mm | $30-60（**汗湿防滑**叙事） |
| 软木复合垫 | 软木布面+TPE/橡胶底 | 4-6mm | $35-70（环保高端） |
| PU 橡胶垫 | PU 革面+天然橡胶 | 4-5mm | $50-100（Lululemon 对标） |

- **麂皮绒款是纺织厂主战场**：超细纤维麂皮绒（见 `fabric/leather-synthetic-leather.md`）+热升华印花（颜值款——`fabric/digital-printing-technology.md`）+天然橡胶底复合——**越汗越防滑**（微湿摩擦力上升）是核心卖点；
- **配件连带**：瑜伽砖（EVA/软木）、伸展带（织带+D 环——`fabric/webbing-narrow-fabrics.md`）、背带/收纳包、铺巾（yoga towel——超细纤维+硅胶点防滑，与毛巾工艺协同 `garments/towels-bath-textiles.md`）。

## 二、工艺要害

- **复合牢度**：布面与发泡底热压复合——剥离强度 ≥2N/cm（反复卷折不分层）；边缘**热切/包边**防起毛（卷边收纳高频摩擦）；
- **防滑双面性**：布面湿态防滑+底面干态抓地（橡胶底纹路设计——人字纹/波浪纹）；
- **印花对位**：整幅热升华印花（体位线印刷是功能款——**体位线对称精度 ±3mm**，印花对格逻辑同裁片印花 `suppliers/print-embroidery-mill-management.md`）；
- **气味管控**：TPE/橡胶发泡气味——**通风熟化 72h+** 出厂（开箱异味是差评第一来源）；低质回收料垫气味+掉渣双杀；
- **厚度公差**：±0.5mm（发泡倍率稳定性——NBR 厚垫公差控制更难）。

## 三、合规红线

- **化学合规**：PVC 款邻苯二甲酸酯（CPSIA/Prop 65——`trade-compliance/california-prop65.md`）；发泡剂偶氮二甲酰胺（ADCA——欧盟 REACH 关注项）；甲酰胺（formamide——EVA/TPE 发泡残留，法国/比利时限值 200mg/kg 参照地垫标准）；
- **乳胶过敏**：天然橡胶底款标注 latex warning（与暴汗服氯丁橡胶逻辑同——`garments/sauna-sweat-suits.md`）；
- **宣称边界**："环保/可降解"需区分——TPE 可回收但不可降解，天然橡胶可降解（反漂绿——`trade-compliance/green-claims-anti-greenwashing.md`）；
- **防滑宣称**："non-slip"属性能宣称——湿态防滑测试报告支撑（避免摔倒伤害诉讼——`trade-compliance/product-liability-recall.md`）。

## 四、市场与运营

- **渠道**：亚马逊（yoga mat 大类红海——白牌窗口在**细分场景**：旅行折叠款/超宽 72cm/亲子双人垫）+独立站（瑜伽垂类内容营销）+健身房/瑜伽馆团购（定制 logo 单色垫）；
- **差异化方向**：**场景细分**（孕妇瑜伽加厚/男健身超宽/旅行 1.5mm 折叠）、材质叙事（软木/橡胶环保线）、IP 联名（花型授权——授权链见 `trade-compliance/ip-brand-authorization.md`）；
- **差评热点**：异味（化学）、掉渣开裂（低质发泡）、卷边翘曲（平整度）、尺寸缩水、印花掉色；
- **季节节奏**：新年健身季（1 月峰值）+春季户外瑜伽（3-5 月）；B2B 健身房换新周期 1-2 年；
- **延伸品类**：普拉提核心床垫（reformer mat——器械配套）、跳绳垫（降噪缓冲——公寓场景）、儿童舞蹈垫（与舞蹈服协同 `garments/dancewear-leotards-production.md`）。
