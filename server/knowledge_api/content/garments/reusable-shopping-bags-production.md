# 环保购物袋生产（Reusable Shopping Bags: 无纺布/帆布/RPET）

全球限塑令推动环保购物袋成为大宗促销品品类：无纺布袋（超市主力）、帆布袋（品牌周边）、RPET 再生袋（环保叙事）、保温袋（生鲜电商）。工艺简单（裁片+印刷+车缝），核心竞争力在**印刷质量与材料合规**。产业带：浙江温州/苍南（无纺布袋全球最大集群）、广东、河北白沟。

## 一、四大产品线

| 线 | 材料 | 克重惯例 | 订单特征 |
|:---|:---|:---|:---|
| 无纺布袋 | PP 纺粘无纺布（见 `fabric/nonwoven-fabrics.md`） | 70-100g/㎡ | 超市/展会，单色丝印，几十万只起 |
| 帆布袋 | 8-16oz 全棉帆布（见 `fabric/canvas-oxford-fabrics.md`） | 12oz 为主力 | 品牌周边/书店文创，数码印/丝印 |
| RPET 袋 | 再生涤纶（可乐瓶回收，GRS 认证） | 190T/210D | 欧美环保客户，需 GRS 交易证 |
| 保温袋 | 外层无纺布/PVC+EPE 珍珠棉+铝膜 | 三层复合 | 生鲜/外卖，车缝+魔术贴 |

## 二、生产工艺要点

- **无纺布袋三大工艺**：
  - 车缝袋（缝纫线合缝）——承重好（8-12kg）；
  - 超声波热合袋（无线缝合）——速度快成本低，承重弱（5-8kg），提手处必须加车线或打枣补强；
  - 覆膜袋（OPP 彩膜覆无纺布）——全彩印刷主力方案；
- **印刷方式选择**：丝印（1-3 色大字 logo，版费低单价低）/覆膜彩印（照片级）/热转印（小批量全彩）/数码印（打样与小单）；
- **帆布袋要害**：帆布预缩（不预缩洗后缩 5-8% 变形）、提手 45° 斜纹包边（防散边）、底部"风琴位"结构（立体袋 vs 平袋价差 30%）；
- **打枣与受力**：提手与袋身连接打 X 形枣——承重测试（装 10kg 提拉 100 次）是欧美客验货标配。

## 三、合规要点（限塑令相关）

- **各国限塑法规催生订单**：欧盟 SUP 指令、美国各州限塑、澳大利亚——客户采购环保袋本身为合规，材料宣称必须真实：
  - **"可降解无纺布"是伪概念**——PP 无纺布不可降解（氧化降解剂在欧盟已被禁）；宣称 biodegradable 面临漂绿诉讼（见 `trade-compliance/green-claims-anti-greenwashing.md`）；
  - **RPET 宣称需 GRS/RCS 认证链**（见 `fabric/sustainable-fabrics.md`）——交易证（TC）每批开具；
- **化学合规**：印刷油墨邻苯/重金属（美国 Prop 65 对购物袋手柄 PVC 材料特别关注，见 `trade-compliance/california-prop65.md`）；欧盟 REACH SVHC；
- **棉帆布**：BCI 棉或有机棉（GOTS）加分项——有机宣称需认证（见 `trade-compliance/textile-certifications.md`）。

## 四、报价与接单要点

- **报价四要素**：材料克重+尺寸+印刷色数+数量——无纺布袋行业透明度极高（客户可秒比价），利润空间在**印刷质量稳定性与交期**；
- **版费结构**：丝印版 50-150 元/色；覆膜彩印铜版 800-1500 元/色（8 色机）——**改版费提前约定**（客户改稿频繁）；
- **起订量**：无纺布袋 3000-5000 只（丝印）/覆膜袋 10000 只起（制版成本）；帆布袋 500-1000 只；
- **交期**：无纺布袋 7-15 天（高度自动化）；帆布袋 15-25 天（缝纫工序多）；
- **海运泡货**：购物袋蓬松——40HQ 装无纺布袋约 25-30 万只（压缩打包），运费占比可达货值 15-20%，报价算清楚（见 `trade-process/sea-freight-practice.md`）。

## 五、客户与渠道

- **促销品分销商**：ASI/SAGE 体系（美国）——订单杂、单款量小、要求快反；
- **超市自有品牌**：沃尔玛/乐购购物袋——验厂+大单+年框（见 `customers-market/big-box-retail-channel.md`）；
- **品牌周边**：书店/博物馆/潮牌帆布包——设计主导、小单高毛利；
- **展会赠品**：广交会/海外展赠品袋（见 `trade-process/canton-fair-domestic-exhibitions.md`）——交期敏感。
