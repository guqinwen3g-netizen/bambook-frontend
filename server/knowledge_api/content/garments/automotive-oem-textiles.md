# 汽车 OEM 纺织品配套（IATF 16949/座椅面料/顶棚/安全带/气囊布）

汽车是全球最大的单一纺织消费市场之一（单车用纺织 20-25kg）：座椅面套、顶棚、地毯、安全带、气囊、门板——**每辆车的纺织品都是 5-8 年定点周期的订单**。与售后座套（`garments/car-seat-covers-auto-accessories.md`）、儿童座椅纺织（`garments/child-car-seat-textiles.md`）完全不同——OEM 配套玩的是**体系认证+定点制+零缺陷**。

## 一、产品矩阵与供应链层级

| 部件 | 材料 | 技术要求 | 配套层级 |
|:---|:---|:---|:---|
| 座椅面套（seat cover） | 纬编/经编涤纶+海绵复合+无纺底（三合一火焰复合） | 耐磨 50,000 次+马丁代尔、耐光 5 级、**雾化值低** | Tier 2（面套厂）→Tier 1（座椅总成：李尔/安道拓） |
| 顶棚（headliner） | 针织布+PU 泡沫+玻纤/麻板热压 | 尺寸稳定、吸音、低 VOC | Tier 2 |
| 地毯（carpet） | PA6/PET 簇绒/针刺+PE 背涂 | 耐磨、阻燃 FMVSS 302 | Tier 2 |
| 安全带织带 | 高强涤纶/尼龙 66 织带 | **断裂强力 ≥26kN**、耐光、耐磨 | 专业织带厂（见 `fabric/webbing-narrow-fabrics.md`） |
| 安全气囊布（airbag） | 尼龙 66 长丝 420D/840D 平纹+硅涂层（OPW 一次成形） | 透气量精准（充气展开动力学）、耐高温 | 高度垄断（Toray/Hyosung/海利得等） |
| 门板/立柱包覆 | 针织/PVC 革复合 | 耐刮、低 VOC | Tier 2 |

- **定点制逻辑**：车型开发期（SOP 前 2-3 年）招标定点——**一旦定点随车型生命周期供货 5-8 年**；新供应商破局靠新车型项目竞标；
- **价值链**：面料厂（经编/纬编布）→复合厂（火焰/胶点复合——见 `suppliers/lamination-coating-factory-management.md`）→裁剪缝纫厂（面套）→Tier 1 总成厂——纺织企业占据前三环。

## 二、体系认证门槛（入场券）

- **IATF 16949**：汽车行业质量管理体系（在 ISO 9001 上叠加）——**五大工具**（APQP 先期策划/PPAP 生产件批准/FMEA 失效分析/SPC 统计过程/MSA 测量系统）是日常语言；认证周期 12-18 个月+咨询投入 30-80 万；
- **PPAP 送样**：18 项文件包（尺寸报告/材料报告/过程流程图/控制计划/PSW 保证书）——**客户签 PSW 才可量产**；任何变更（材料/工艺/产地）需重新提交（变更管理是 OEM 纪律核心）；
- **零缺陷文化**：PPM（百万件不良数）考核——面套 PPM 目标 <50；**8D 报告**响应（24h 围堵/7 天报告）；
- **材料认可**：主机厂材料标准（大众 VW50180/丰田 TSL/通用 GMW）——**每款材料单独送检认可**（周期 3-6 个月）；ELV/REACH 有害物质（铅镉汞六价铬——`trade-compliance/chemical-environmental-compliance.md`）；VOC 与气味（VDA 278 热脱附/VDA 270 气味等级 ≤3.5）。

## 三、生产与质量要点

- **面套缝纫**：双针链式+装饰明线（针距一致性是外观 A 级面要求）；**安全气囊爆破区**（座椅侧气囊缝线按设计断裂强力缝制——多一针少一针都是安全事故——与座套售后市场同理见 `garments/car-seat-covers-auto-accessories.md`）；
- **追溯体系**：每卷面料/每件面套条码追溯（批次管理——质量问题 2 小时内定位到机台班次）；**15 年追溯期**（汽车法定责任期）；
- **色差管理**：同车同色件（座椅+门板+立柱）跨材料配色——主机厂色板+测色仪 ΔE CMC ≤0.8（色彩体系见 `fabric/color-management-pantone-measurement.md`）；
- **模具与裁片**：面套裁片按座椅 3D 数据（裁片展开——CAD 自动裁床）；复合面料裁边防分层。

## 四、商业特征与风控

- **账期与年降**：OEM 账期 90-120 天+**年降条款**（年降 3-5%——靠工艺优化消化，否则利润逐年归零）；模具/开发费分摊（NRE 一次性费用谈判）；
- **产能刚性**：主机厂周计划拉动（JIT 排序供货——线边仓 2-4 小时库存）；**断供罚款**（停线损失按分钟计——天价）——安全库存+双产地备份；
- **新能源增量**：电动车内饰升级（环保材料叙事——再生涤纶/生物基面料定点增加）；隐藏式出风口/氛围灯透光面料等新工艺点；
- **风控红线**：召回连带（气囊/安全带类安全件——产品责任险保额 $500 万起——`trade-compliance/product-liability-recall.md`）；知识产权（面料花型主机厂买断）；**二轨供应商策略**（主机厂强制双源——二轨份额 30% 是常态进入路径）。
