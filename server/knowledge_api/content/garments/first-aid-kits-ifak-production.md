# 急救包与 IFAK 组套贸易（First Aid Kits: 家用/车载/战术/工业 OSHA 合规）

急救包是"**纺织品包体 + 医疗内容物**"的组套贸易品类：包体缝纫是服装厂能力圈，内容物（敷料/绷带/止血带）属医药渠道，组装厂赚的是**合规配置 + 批次追溯 + 渠道资质**的钱。欧美工业安全法规（OSHA/ANSI）与车载法规（DIN）创造刚性需求，IFAK 战术急救包则随军警与户外生存市场放量。本文件梳理产品谱系、法规配置与组套厂风控要点。

## 一、产品谱系与法规配置

| 品类 | 核心标准 | 内容物特征 | 主要渠道 |
|:---|:---|:---|:---|
| 工业/办公急救包 | 美 ANSI/ISEA Z308.1（Class A/B） | 按标准清单配置（敷料/胶带/烧伤巾等 10-20 项） | 安全用品分销商（Grainger 类） |
| 车载急救包 | 欧 DIN 13164 / 各国交规 | 部分国家强制随车（德/奥/匈等） | 汽配连锁/4S 店赠品 |
| 家用/旅行急救包 | FDA 一类器械（自声明） | 配置灵活，电商爆款逻辑 | 亚马逊/商超/药店 |
| IFAK 战术急救包 | 军规+民用无强制标准 | 止血带（CAT 类）/胸腔封闭贴/ Israeli 绷带 | 军警采购/户外生存渠道 |
| 户外/运动急救包 | 轻量化+防水 | 按场景（徒步/骑行/水上）配置 | 户外品牌 OEM |
| 宠物急救包 | 无强制 | 宠物敷料/伊丽莎白圈等 | 宠物渠道（见 `garments/pet-harnesses-leashes-production.md` 渠道逻辑） |

- **ANSI/ISEA Z308.1-2021 是美国工业包命门**：Class A（常见风险）/Class B（高风险场所）两档，内容物**种类+数量+性能**全部列明——接单必须拿到最新版标准清单逐项核对，缺项即不合规；
- **内容物法规分层**：敷料/绷带多为 FDA 一类医疗器械（工厂需注册+列名），止血带/胸封属二类——**组套厂通常不做内容物生产，只做采购+组装**，但需留存供应商注册号与批次号备查；
- **宣称红线**：包装与详情页不得做治疗宣称（"cure/treat"），只能"first aid/emergency care"——FDA 对夸大宣称的警告信是电商卖家常见死因（见 `trade-compliance/product-liability-recall.md`）。

## 二、组套生产与供应链

- **包体**：600D/1680D 牛津+硬衬（见 `garments/tool-bags-organizers.md` 工艺）/EVA 硬壳（车载）/MOLLE 织带系统（IFAK，见 `garments/tactical-gear-production.md`）；
- **内容物采购**：国内敷料产业带（湖北仙桃/河南长垣无纺布制品集群）+ 进口品牌止血带（北美市场认 CAT/SOF-T 品牌，仿品法律风险极高）；
- **效期管理是组套厂核心能力**：敷料效期通常 3-5 年——**先进先出（FIFO）+ 批次混装禁止 + 效期贴标**，客户验厂必查效期台账；
- **批次追溯**：整包序列号 ↔ 内容物批次映射表——召回时按表反向定位（ISO 13485 思路，见 `trade-compliance/product-liability-recall.md`）；
- **组装环境**：无强制洁净车间要求（非无菌敷料），但需防尘+虫害管控，验厂逻辑同 `suppliers/factory-audit-guide.md`。

## 三、外贸接单要点

- **买家画像**：安全用品分销商（大单长账期）、电商品牌（小单快反）、汽车厂赠品（年框）、军警招标（资质门槛）；
- **报价拆解**：包体成本+内容物成本（附供应商清单）+组装费+检测费——**内容物价格波动（如纱布涨价）需在合同设调价条款**；
- **检测**：整包无需医疗器械检测，但内容物供应商的 FDA 注册/CE 证书需随单提供；织物部分按常规纺织品检测（见 `trade-compliance/testing-lab-selection.md`）；
- **装柜**：含液体（碘伏/生理盐水）的套件注意空运限制与海运渗漏——液体内容物独立密封袋+外箱警示；
- **付款**：分销渠道 30% 定金+尾款见提单副本；军警招标 LC（审单见 `trade-process/letter-of-credit-review.md`）。
