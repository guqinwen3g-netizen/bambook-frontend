# 新中式服装品类专题（New Chinese Style Clothing）

新中式是"**传统文化元素×现代剪裁**"的国潮品类：盘扣/立领/斜襟的日常化改良——内销爆款赛道，同时是海外华人市场与文化输出的特色品类。

## 一、品类谱系

| 品类 | 特征 |
|:---|:---|
| 新中式上衣 | 立领/斜襟/盘扣+现代版型（衬衫/外套改良——日常可穿） |
| 马面裙 | 明代裙制复兴（围合式百褶——2023 起现象级爆款） |
| 改良旗袍 | 日常化剪裁（开衩降低/面料弹力化——通勤场景） |
| 汉服 | 考据复原路线（形制严格——圈层文化驱动） |
| 新中式男装 | 立领衬衫/对襟褂（婚礼/茶服场景） |
| 儿童新中式 | 年服/抓周服（春节强周期） |

## 二、核心设计元素

- **盘扣**：手工盘扣（一字扣/蝴蝶扣/花扣——手工价值感，低端用机打扣替代）;
- **立领/交领**：领型是辨识度核心（右衽交领——汉服形制基本）;
- **斜襟/对襟**：门襟结构（琵琶襟/如意襟变化）;
- **纹样**：传统织锦/刺绣（云纹/缠枝莲/山水——织金妆花缎高端）;
- **色彩**：传统色系（天青/月白/绛红/黛蓝——低饱和雅致路线为主流）。

## 三、面料选择

- **织锦缎/宋锦**：高端（宋锦非遗——苏州产地，礼服用）;
- **香云纱**：非遗面料（薯莨染整真丝——黑色龟裂纹，广东顺德）;
- **真丝/醋酸**：垂感衬衫裙（见 `fabric/silk-linen-fabrics.md` / `fabric/acetate-fabrics.md`）;
- **棉麻**：日常款（禅意茶服——见 `fabric/silk-linen-fabrics.md`）;
- **提花面料**：机织提花替代手工织锦（量产性价比——柯桥提花集群）。

## 四、工艺要点

- **盘扣制作**：手工盘扣工时高（熟练工 15-30 分钟/对——报价单列）;
- **镶滚嵌牙**：传统镶边工艺（滚边/嵌线——精做标志）;
- **对花裁剪**：织锦纹样对花（排料损耗大——用料系数上调 10-15%）;
- **版型改良**：平裁 vs 立裁（传统平裁宽松 vs 现代立裁合体——新中式多为融合路线，见 `suppliers/pattern-sample-room-management.md`）。

## 五、市场与客群

- **内销主线**：文化自信+国潮（2023 马面裙出圈——曹县汉服产业带年产值数十亿）;
- **客群**：25-40 岁女性（日常通勤新中式）+Z 世代（汉服圈层）+婚服（秀禾/龙凤褂）;
- **价格带**：快时尚 200-500（机工量产）/中端 500-2000（设计品牌）/高定 5000+（手工非遗）;
- **海外**：华人节庆市场（春节/中秋——东南亚华人圈）+文化猎奇（欧美 niche——改良款更适销）。

## 六、春节强周期（内销节奏）

- **年服旺季**：腊月销售爆发（11-12 月生产高峰——儿童拜年服/全家福新中式）;
- **倒排**：9-10 月备料下单（春节早迟浮动——农历年份差异，备料风险自担）;
- **元宵/端午/中秋**：次节点（汉服出行活动带量）。

## 七、生产注意

- **小单多款**：设计师品牌模式（100-300 件/款——快反产线适配）;
- **工艺混合**：机绣+手工（纯手工成本不可量产——定位决定工艺配比）;
- **知识产权**：传统纹样公有领域可自由使用（但他人设计稿受保护——原创登记，见 `trade-compliance/ip-brand-authorization.md`）;
- **形制争议**：汉服圈层对形制考据严格（"山正之争"——形制错误遭社群抵制）。
