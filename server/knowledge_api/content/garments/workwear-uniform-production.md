# 工装与职业装生产专题（Workwear & Uniform Production）

工装（workwear）是功能导向的 B2B 品类：订单以企业/机构集采为主，复购稳定、价格敏感度低于时尚品，但**强制标准认证是准入门槛**。阻燃/防静电/高可视三大功能线是核心赛道。

## 一、品类结构

| 品类 | 场景 | 核心要求 |
|:---|:---|:---|
| 普通工装 | 工厂/物流/物业 | 耐磨（涤棉厚纱卡）、多口袋、易洗 |
| 阻燃服（FR） | 石化/电力/焊接 | 阻燃标准认证（不续燃/不熔滴） |
| 防静电服 | 电子/无尘车间 | 表面电阻 10⁵-10¹¹Ω |
| 高可视服（hi-vis） | 道路/机场/建筑 | 荧光色+反光带 |
| 医护服 | 医院/护理 | 抗菌、耐氯漂 |
| 厨师服/餐饮 | 餐饮 | 防污易洗、双排扣传统 |
| 商务职业装 | 银行/航空/酒店 | 版型+面料档次（西装工艺） |

## 二、强制标准（准入红线）

### 高可视（出口最大工装品类）
| 市场 | 标准 | 要点 |
|:---|:---|:---|
| 欧盟 | **EN ISO 20471** | 荧光底色（黄/橙/红）+ 反光带面积按等级 1-3 级（3 级最高） |
| 美国 | **ANSI/ISEA 107** | Class 1/2/3；Type O/R/P |
| 澳洲 | AS/NZS 4602.1 | 昼/夜/昼夜分类 |

- **反光带**：3M Scotchlite、国产反光晶格——需水洗测试（反光亮度保持率）；缝制必须**先荧光布后反光带**的顺序控制。
- 认证模式：面料认证 + 成衣设计认证（反光带位置/宽度有强制几何要求）——成衣厂需送样至公告机构（如 Satra/Intertek）做型式试验。

### 阻燃（FR）
- **本质阻燃**（芳纶 Nomex/芳砜纶）vs **后整理阻燃**（棉+Proban/Pyrovatex 阻燃剂）——后者为主流性价比方案，耐洗次数是关键指标（50 次洗后仍达标）。
- 标准：EN ISO 11612（焊接与热防护）、NFPA 2112（美石化）、EN 1149（防静电配套）。

### 防静电
- EN 1149-5 / GB 12014：导电丝（碳纤维/不锈钢纤维）网格织入面料（0.5-1cm 间距）；缝制要求导电丝连通（缝线导电）。
- 无尘室（cleanroom）：不脱落纤维（长丝面料）+ 防尘密封工艺。

## 三、生产要点

1. **面料**：涤棉 65/35 厚纱卡（245-300g）是主力；全棉厚帆布（重工）；功能性面料需锁合格供应商（阻燃整理厂资质）。
2. **工艺**：双针/三针链式线迹加固（工装受力部位）；套结（bar-tack）加强口袋/门襟受力点；金属扣件（四合扣/工字扣）防锈处理。
3. **绣花/印刷 logo**：企业集采单 100% 带 logo——绣花与印花工序排产要前置（见 `garments/printing-embroidery.md`）。
4. **尺码**：团体订单尺码分布（size curve）按客户员工数据定制；提供量体/试穿服务是加分项。

## 四、商业模式与订单特征

- **投标制**：大企业/政府工装招标（资质+样品评审+价格）——资质门槛：ISO9001、特种劳动防护用品生产许可（中国 LA 标志）、欧标/美标认证。
- **补单复购**：工装消耗品属性——新员工补充/年度换装，复购周期 1-2 年，客户粘性高。
- **小批量多批次**：团体单 500-5000 件为主，但 SKU 多（男女款 × 尺码 × 岗位变体）。
- **利润率**：功能工装毛利 25-40%（认证壁垒溢价），远高于时尚品类。

## 五、市场与客户

- **欧洲**：Engelbert Strauss、Fristads 等品牌；石油巨头供应商名录准入（壳牌/道达尔供应链认证）。
- **美国**：Cintas/Aramark 租赁工装模式（租赁公司集采）；NFPA 体系。
- **中东**：油气行业工装（阻燃+浅色反射热）大单品。
- **国内**：特种劳动防护用品 LA 认证目录（防静电/阻燃/酸碱防护服）。
