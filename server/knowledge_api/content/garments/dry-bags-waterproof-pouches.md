# 防水包与干燥袋生产（Dry Bags: 高周波焊接/卷口密封/TPU 涂层布）

防水包是"**涂层布+焊接工艺**"的功能袋类：干燥袋（dry bag）、防水背包、手机防水袋、防水腰包。核心逻辑与缝纫相反——**针孔=漏水**，接缝必须**高周波/热压焊接**。工艺设备门槛（高周波机+模具）筛掉纯缝纫厂，是包袋品类中的差异化赛道。常规包袋见 `garments/bags-luggage-production.md`，本文聚焦防水密封体系。

## 一、产品线与防水结构

| 产品 | 材料 | 密封方式 | 防水等级宣称 |
|:---|:---|:---|:---|
| 卷口干燥袋（5-40L） | 500D PVC 夹网布/210T 尼龙 TPU | 卷口 3 圈+插扣 | IPX6（防泼水/短暂浸水） |
| 防水背包（20-35L） | 840D/500D TPU 复合布 | 卷口或气密拉链 | IPX6-7 |
| 手机防水袋 | 透明 TPU 膜 | 双轨自封条+卷折 | IPX8（标称 30m 水深） |
| 防水腰包/斜挎包 | TPU 复合尼龙 | 气密拉链 | IPX7 |
| 全气密防水包（潜水级） | 840D TPU 双面涂层 | 气密拉链（TIZIP） | IPX8 |

- **卷口密封原理**：袋口内折 3 圈以上+两侧插扣锁紧——物理迷宫密封；**卷口处织带/补强片焊接**（不可车缝）；
- **气密拉链**：TIZIP/气密拉链（潜水服同技术，见 `garments/wetsuit-diving-suits-production.md`）——拉链成本 ¥80-200/条，是干式防水包最大成本项。

## 二、材料与工艺要害

- **涂层布选择**：PVC 夹网布（500D/1000D——硬挺耐磨，低价款）；TPU 复合布（环保无塑化剂+耐低温柔软——中高端主流）；尼龙 TPU 涂层（轻量化款 210T/420D）——**TPU 膜厚 0.15-0.35mm**（太薄焊接牢度差，太厚手感硬）；
- **高周波焊接**：模具（铜模——按袋型开模 ¥3-8k/套）+功率时间参数（TPU 与 PVC 焊接温度窗口不同）；**焊缝宽度 8-12mm**（窄焊强度不足）；焊后**剥离强度测试**（焊缝先坏布料再坏=合格；焊缝整齐剥离=虚焊）；
- **电压穿刺管控**：面料折角处焊接**应力集中开裂**（圆角模具设计）；焊口冷却定型后搬运（热态拉伸变形）；
- **防水测试**：**全检充气保压测试**（充气封口——30 秒压降超标即漏）+抽检浸水（1m 水深 30min 内部纸巾法）；手机袋**每只做负压/浸水检**（客诉赔付逻辑倒逼全检）；
- **透明 TPU 视窗**：手机袋触屏透明膜（0.2-0.3mm TPU——触屏灵敏度+**耐黄变配方**（紫外线黄变差评））。

## 三、合规要点

- **防水等级宣称**：IPX 等级引用需实测支撑（IEC 60529 逻辑——"IPX8 30 米"宣称必须有对应测试报告）；亚马逊对"waterproof"宣称审查趋严——建议表述"floatable / submersible to X m tested"；
- **化学**：PVC 款邻苯+铅（Prop 65——见 `trade-compliance/california-prop65.md`）；TPU 路线天然规避塑化剂（**marketing 卖点：PVC-free**）；
- **手机袋责任边界**：listing 必须"使用前纸巾测试+不承保手机进水损失"免责条款（美国集体诉讼先例）；
- **欧盟**：无专门认证——普通消费品 GPSR（见 `trade-compliance/eu-gpsr-deep-dive.md`）；
- **商标专利**：卷口插扣结构有外观专利雷区（SealLine/Earth Pak 设计——开模前 FTO 检索，见 `trade-compliance/ip-brand-authorization.md`）。

## 四、市场与运营

- **场景矩阵**：皮划艇/漂流（美国夏季）/溯溪（日本）/沙滩（全球）/摩托骑行（防水尾包）/钓鱼（路亚防水包）；
- **套装逻辑**：5L+10L+20L 三件套（亚马逊 $25-40 主力 listing）——透明手机袋作赠品拉评分；
- **季节节奏**：3-4 月到仓（5-8 月旺季）；南半球（澳洲）10 月错峰；
- **差评三高发**：卷口没卷好进水（**详情页必须教学图示**）、焊缝开裂（虚焊——全检保压规避）、异味（PVC 溶剂味——TPU 升级+散味）；
- **品牌对标**：SealLine/YETI/Earth Pak——差异化在**配色颜值+透明视窗+背带系统**（单肩/双肩可换）；
- **产业带**：浙江义乌/宁波（PVC 夹网布产地——篷布产业带延伸）、广东（TPU 复合+高周波工艺集中）。
