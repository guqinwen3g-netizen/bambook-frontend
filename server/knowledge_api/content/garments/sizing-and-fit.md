# 版型与尺码（Sizing & Fit）

成衣外贸中，**版型（fit）**与**尺码体系（sizing）**直接影响合体度、返工与客诉。本文件覆盖主流尺码体系、试身环节与**GM 尺寸单（garment measurement spec）**的拟定与测量术语。

## 一、主流尺码体系

外贸出运前必须确认目标市场的尺码体系，同一体型在欧/美/亚码下数字不同：

| 体系 | 适用市场 | 说明 |
|:---|:---|:---|
| 欧码 EU | 欧洲 | 以胸围/身高为基准，如 46/48/50 |
| 美码 US | 北美 | 男装 S/M/L/XL；女装 0-20 数字码 |
| 英码 UK | 英国 | 与欧码相近但数字不同 |
| 亚码 | 中/日/韩 | 整体偏小，需按目标市场调整版型 |
| 国际通用 | 全球 | S/M/L/XL/XXL（字母码） |

> 关键风险：**同一 S/M/L 在不同市场对应的实际尺寸不同**（即"欧码 S"明显大于"亚码 S"）。跟单时必须明确规定是对应哪套尺码表（size chart/grade rule）。

## 二、试身环节（Fit）

试身是确认版型的核心节点，常见阶段：

- **试身样 fit sample**：验证版型与合体度，一般用常规面料或近似面料。
- **规格样 measurement/p-b sample**：确认尺寸与规格。
- **修正样 revised sample**：根据试身意见修改后的版本。
- **确认样 approved sample/PP sample**：产前确认样，作为大货依据。
- **TOP 样 TOP (top of production) sample**：大货首件样，代表大货质量。

### 常见试身意见（fit comments）
- 偏紧/偏松：too tight / too loose
- 肩宽需加大：shoulder width needs to be increased
- 衣长需缩短：length to be shortened
- 领口漏光：neckline gaping
- 袖口过大：cuff too wide

## 三、GM 尺寸单（Garment Measurement Spec）

GM 单是**测量部位 + 各码尺寸**的规格表，是打版、生产、验货三方共同依据。起草要点：

1. **测量部位必须标准**：用行业通用测量点，避免"从缝到缝"歧义。
2. **给出公差 tolerance**：不同部位公差不同（如衣长 ±1cm、胸围 ±1.5cm）。
3. **注明测量状态**：平铺（laid flat）还是拉伸（stretched）；洗前（pre-wash）还是洗后（post-wash）。
4. **标明单位**：厘米（cm）还是英寸（inch），全单统一。
5. **列出全部尺码**：S/M/L/XL 一列一个码，避免漏码。

### 典型 GM 单结构示例

| 测量部位 Measurement Point | 公差 Tol. | S | M | L | XL |
|:---|:---:|:---:|:---:|:---:|:---:|
| 衣长 garment length | ±1.0 | 66 | 68 | 70 | 72 |
| 胸围 1/2 chest | ±1.5 | 50 | 53 | 56 | 59 |
| 肩宽 shoulder width | ±1.0 | 43 | 45 | 47 | 49 |
| 袖长 sleeve length | ±1.0 | 60 | 62 | 64 | 66 |
| 领宽 neck width | ±0.5 | 18 | 18 | 19 | 19 |

> 注：通常胸围/臀围/腰围标注为**半围（1/2）**，全围为 2 倍。GM 单必须写明是半围还是全围。

## 四、测量部位术语对照

| 中文 | English | 说明 |
|:---|:---|:---|
| 衣长 | garment length/body length | 侧颈点或肩点量至下摆 |
| 胸围 | chest/bust | 一般取袖窿下最宽处 |
| 腰围 | waist | 腰线处 |
| 臀围 | hip | 臀最宽处 |
| 肩宽 | shoulder width | 左右肩缝之间 |
| 袖长 | sleeve length | 肩点至袖口 |
| 领宽/领高 | neck width/height | 领口相关 |
| 下摆 | bottom hem | 下摆宽度 |
| 裤长 | inseam/outseam | 内缝/外缝 |
| 前裆/后裆 | front/back rise | 裆部到腰头 |
| 袖窿 | armhole | 袖圈周长 |
| 袖肥 | bicep | 上臂处袖宽 |

## 五、尺码链与放码（Grade）

- **放码 grade**：基准码（base size，通常中码 M）向大小码按级差（grade rule）扩展。
- **级差 grade increments**：如胸围每码 ±4cm、衣长每码 ±2cm。
- **尺码链 size range/grade**：确定出哪些码、级差多少。
- 放码错误是常见质量事故，需在大货前核对**单码量产样（size set sample）**。

## 六、沟通与跟单要点

1. **尺码表必须锁定**：与客户确认对应哪套尺码体系，锁定 size chart。
2. **GM 单三方对齐**：打版、工厂生产、质量控制（QC）用同一张 GM 单。
3. **区分洗前/洗后**：针织与牛仔洗水后缩率大，须明确测量基准。
4. **公差留合理**：公差过严增加返工，过松易被抽检判不合格。
5. **保留试身记录**：fit comments 存档，作为后续批次与客诉依据。
