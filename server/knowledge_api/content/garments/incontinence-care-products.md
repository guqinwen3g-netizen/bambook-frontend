# 失禁护理用品生产（Incontinence Products: 成人纸尿裤/护理垫）

失禁护理是老龄化驱动的确定性增长市场（欧美日 65+ 人口 20%+，全球失禁用品市场 $180 亿+）。纺织厂切入点分两条线：**一次性产品**（成人纸尿裤/护理垫——无纺布主导，卫生用品厂逻辑）与**可洗重复使用产品**（可洗尿裤/隔尿垫/护理垫——纺织工艺主导，水洗 100 次+）。本文件聚焦纺织厂可承接的可洗线与一次性线的纺织配套。

## 一、产品线结构

| 产品 | 结构 | 核心指标 | 渠道 |
|:---|:---|:---|:---|
| 可洗失禁内裤 | 外层弹力布+裆部吸收层+防漏隔层（TPU） | 吸水量（轻 50ml/中 150ml/重 300ml+）、洗 100 次性能保持 | 亚马逊/药房/养老机构 |
| 可洗隔尿垫（bed pad） | 面布（刷毛涤纶/棉）+吸收芯+防水层+防滑底 | 吸水量 1-2L、四角固定带可选 | 养老院/医院/居家护理 |
| 一次性成人纸尿裤 | 无纺布面层+SAP 吸收芯+PE 底膜 | 吸水量/回渗量/侧漏 | 商超/药房/医保渠道 |
| 一次性护理垫 | 无纺布+绒毛浆/SAP+PE 底膜 | 尺寸规格（60×90 主流） | 医院/养老机构集采 |
| 可洗宠物尿垫 | 同隔尿垫逻辑 | 耐抓+吸水 | 宠物渠道（见 `garments/pet-beds-mats-production.md`） |

## 二、可洗产品工艺要害

- **吸收层结构**：多层毛圈/超细纤维+涤纶导流层——**吸收速度（秒级）+ 回渗量（按压返湿）**是核心体验指标；竹炭纤维抗菌叙事是常见卖点（宣称需有测试支撑，见 `trade-compliance/green-claims-anti-greenwashing.md`）；
- **防水层**：TPU 复合膜（透气型优于纯 PE——闷热感是差评热点）；**复合牢度**洗 50 次不起泡不分层（见 `fabric/functional-coating-lamination.md`）；
- **洗后性能**：吸水量洗后衰减曲线——规格书承诺"洗 100 次吸水保持率≥80%"需实测数据支撑；柔顺剂会堵塞吸收纤维（洗护标签必须标注"禁用柔顺剂"）；
- **贴身剪裁**：失禁内裤按普通内裤版型+防漏腿围橡筋——橡筋压力平衡（过紧勒痕/过松侧漏），参照内衣工艺（见 `garments/underwear-lingerie-production.md`）；
- **异味控制**：抗菌整理（银离子/锌基——见 `fabric/antimicrobial-insect-repellent-finishes.md`）+ 速干面料组合减少氨味滞留。

## 三、一次性产品的纺织配套机会

- **无纺布供应**：面层 SMS/SMMS 纺粘无纺布、导流层热风棉（见 `fabric/nonwoven-fabrics.md`）——卫生级（洁净车间/微生物限度）；
- **弹性腰围/腿围**：氨纶丝+无纺布复合弹性材料；
- **魔术贴/前腰贴**：pp 前胶贴+拉毛布组合——开合 5 次粘力保持；
- **门槛提示**：一次性产品整机生产线投资大（数千万级），纺织厂更现实的角色是**材料供应商或 ODM 配套**。

## 四、合规要点

- **产品定性**：轻度失禁可洗内裤多按普通纺织品销售；**宣称"医用/治疗"即触发医疗器械监管**——美国 FDA 一类器械（成人纸尿裤列 Class I，需注册+GMP）、欧盟 MDR Class I（自我声明+技术文件）；保守做法=不碰医疗宣称（"护理/舒适"话术）；
- **皮肤接触安全**：OEKO-TEX Standard 100 一类（接近婴童级）管控——尿液环境加速化学物质迁移，甲醛/偶氮/邻苯/重金属全项测试；
- **微生物**：一次性产品需初始污染菌/抑菌率检测；可洗产品抗菌宣称需 AATCC 100 或 ISO 20743 测试报告；
- **养老/医保渠道**：美国 Medicaid 报销渠道产品需符合 HCPCS 编码要求；德国医保（Pflegeversicherung）集采有独立认证体系——走 B2B 机构渠道需提前研究准入；
- **标签**：吸水量分级标注（避免绝对化宣称）、洗护说明（可洗产品）、处置标识（一次性产品环保标识，部分州要求），包装 EPR 见 `trade-compliance/packaging-epr-regulations.md`。

## 五、市场与渠道

- **核心市场**：日本（老龄化最深+品质要求最高，见 `customers-market/jp-market.md`）、美国（亚马逊品类增长快）、德国/北欧（医保报销驱动）、澳洲；
- **渠道分层**：养老机构集采（价格敏感+账期长）vs 居家零售（品牌溢价+复购）；亚马逊美国站该品类头部品牌月销万件级——新品牌可打"可洗环保省钱"叙事切入（与一次性巨头差异化）；
- **客诉热点**：侧漏（版型/橡筋）、洗后起球（面布选型）、异味（抗菌失效）、尺码偏小（欧美体型裆部加深）、过敏（材料致敏——无荧光剂是基本要求）；
- **银发经济协同**：与医疗纺织（见 `garments/medical-healthcare-textiles.md`）共享医院/养老渠道资源。
