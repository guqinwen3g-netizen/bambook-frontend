# 正装马甲与背心（Waistcoat & Vest: 晨礼服背心/西装马甲/搭配体系）

马甲是"**正装的三件套之魂**"：晨礼服（morning coat）必须配浅色马甲，三件套西装的马甲是"可脱的正式"。泛马甲见 `garments/types-and-construction.md`——本文件聚焦**正装场景的马甲体系**。

## 一、品类体系

| 品类 | 特征 | 场合 |
|:---|:---|:---|
| **晨礼服马甲（morning waistcoat）** | 浅色（灰/米/浅黄）、单排/双排、无翻领 | 婚礼/皇家赛马会 |
| **三件套西装马甲** | 与西装同料、单排扣、V 领 | 商务/正式场合 |
| **礼服马甲（evening waistcoat）** | 黑色/午夜蓝、低领、U 型/V 型 | 白领结/黑领结 |
| **针织马甲（knitted vest）** | 羊毛/羊绒、无结构 | 商务休闲/学院风 |
| **狩猎马甲（shooting vest）** | 麂皮/粗花呢、多口袋 | 乡村/户外活动 |

## 二、晨礼服马甲（最高规格）

- **颜色**：浅灰（dove grey）/米色（buff）/浅黄（primrose）——**黑色是错误（与礼服混淆）**；
- **面料**：羊毛/丝毛混纺——**亚麻是夏季选项**；
- **款式**：
  - 单排扣：6-7 粒扣、尖角下摆；
  - 双排扣：4-6 粒扣、戗驳领——**更传统**；
- **搭配**：晨礼服+条纹裤+马甲——**英国皇家赛马会（Royal Ascot）的硬性着装要求**。

## 三、三件套西装马甲

- **结构**：
  - 前身与西装同料——**后身用里布（减厚+透气）**；
  - 腰带（back strap）：调节松紧——**金属扣是高端标识**；
  - 领型：V 领（标准）/U 领（礼服）——**领深决定领带可见度**；
- **扣子**：5-6 粒——**最下一粒不扣（爱德华七世传统）**；
- **口袋**：双唇袋（welt pocket）——**实用+装饰**。

## 四、工艺要点

- **衬布**：前身有纺衬——**保持挺括但不僵硬**；
- **归拔**：胸省/腰省——**马甲比西装更贴身，归拔更精细**；
- **里布**：宾霸（cupro）——**抗静电+滑爽**（见 `fabric/linings-interlinings.md`）；
- **扣子**：与西装同扣——**三件套扣子是"套装完整性"的检验点**。

## 五、搭配规则

- **衬衫**：马甲覆盖衬衫下摆——**衬衫必须扎进裤子**；
- **领带**：马甲内必须配领带或领结——**"空马甲"是时尚禁忌**；
- **外套**：穿马甲时外套必须敞开——**扣上外套=隐藏马甲=失去意义**；
- **季节**：马甲增加保暖——**冬季三件套、夏季两件套**。

## 六、市场趋势

- **复兴**：三件套回归（2020s 复古风）——**"Peaky Blinders"效应**；
- **单穿**：马甲单穿（无外套）——**创意行业/夏季婚礼**；
- **女式马甲**：女式西装马甲——**"马甲+衬衫"是女式正装新组合**；
- **定制店机会**：马甲是"入门定制"产品——**单价低、工艺展示效果好**。
