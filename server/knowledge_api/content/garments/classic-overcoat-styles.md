# 经典正装大衣款型（Classic Overcoat Styles: Chesterfield/Polo Coat/Peacoat/Duffle/Covert）

正装大衣是"**男装史上百年不变的款型体系**"：Chesterfield 的丝绒领、Polo coat 的驼色双排扣、Peacoat 的海军血统，每一款都有明确的历史坐标与穿着规则。毛呢大衣生产工艺见 `garments/wool-coat-production.md`，大衣面料见 `fabric/wool-overcoating-fabrics.md`——本文件聚焦**经典款型的辨识、规格与市场定位**。

## 一、五大经典款型

### Chesterfield（切斯特菲尔德大衣）
- **血统**：1840s 英国切斯特菲尔德伯爵六世发明——**"第一件现代正装大衣"**；
- **规格**：
  - 单排暗门襟（fly front）/双排均可；
  - **丝绒领（velvet collar）是灵魂标识**——黑色大衣配黑丝绒领；
  - 直身剪裁、及膝长度、无腰带；
- **定位**：**商务大衣的正解**——套在西装外的最正式大衣；
- **搭配**：西装+领带场景专用——休闲搭配反而失格。

### Polo Coat（马球大衣）
- **血统**：1920s 英国马球运动员场下保暖大衣——经美国 Brooks Brothers 推广；
- **规格**：
  - **驼色（camel hair 或驼色羊毛）是标准色**；
  - 双排 6 扣/8 扣、戗驳领；
  - 半腰带（half belt）后中+大贴袋（patch pocket with flap）；
  - 及膝或膝下长度；
- **定位**：**美式学院风（preppy）的巅峰单品**——商务休闲场景；
- **现代演变**：羊绒版 Polo coat 是奢侈品牌的冬季旗舰款。

### Peacoat（海军呢大衣）
- **血统**：18 世纪欧洲海军制服（pea = 荷兰语 pijjeker 粗呢外套）；
- **规格**：
  - 藏青色麦尔登呢（melton）；
  - 双排 6-8 粒大扣（锚纹扣）、大翻领（可竖立防风）；
  - 及臀短款、斜插暖手袋；
- **定位**：**唯一被男装界接受的"军装大衣"**——半正式到休闲；
- **搭配**：短款不适合套长西装——**单西或毛衣+Peacoat 是正确场景**。

### Duffle Coat（渔夫大衣/牛角扣大衣）
- **血统**：比利时 Duffel 镇粗呢→英国皇家海军（蒙哥马利元帅带货，故又称"蒙蒂大衣"）；
- **规格**：
  - **牛角扣+麻绳袢（toggle closure）是标识**；
  - 连帽、贴袋、及膝长度；
  - 粗纺呢（传统 Duffel 呢厚重含绒）；
- **定位**：**休闲大衣**——学院风/工装风，正装场景不适用。

### Covert Coat（隐蔽大衣）
- **血统**：19 世纪英国骑马狩猎大衣；
- **规格**：
  - 隐蔽斜纹呢（covert cloth——防水致密）；
  - 单排暗门襟、天鹅绒领、下摆与袖口**四道装饰明线（四至五行缝线）是标识**；
  - 及膝偏短；
- **定位**：**英式乡村正装大衣**——城市穿略显"戏服感"。

## 三、生产与开发要点

- **丝绒领工艺**：Chesterfield 的丝绒领需单独裁剪（绒向一致）——**丝绒与呢料的缩水率差异必须预缩匹配**；
- **双排扣排料**：Polo coat/Peacoat 双排款耗料 +15%（搭门量）——**报价损耗必须计入**；
- **扣具采购**：锚纹扣/牛角扣——**天然牛角扣（ horn toggle）vs 树脂仿牛角的成本差 5-8 倍**；
- **版型差异**：大衣需容纳西装——**胸围加放量 14-18cm（vs 西装 10-12cm）**；
- **羊绒升级路径**：经典款型的羊绒/驼绒版本——**奢侈品牌冬季的"款型复刻"策略（Loro Piana/Max Mara 的核心产品线）**。

## 四、市场与销售

- **品牌客户**：经典款型是欧美品牌的"常青 SKU"——**Ralph Lauren（Polo coat）/Burberry（Chesterfield）每季复刻**；
- **定制店**：大衣是定制店的冬季利润款——**羊绒大衣定制客单价可达西装 2 倍**；
- **女装机会**：男款大衣的女版（Max Mara 101801 即男款 Polo coat 血统）——**"女版男款"是大衣开发的成熟路径**；
- **知识产权**：**款型本身无版权（百年以上历史），但品牌复刻的版型细节受保护**——开发时可做款型，不可抄版型。
