# 应急救灾与机构集采纺织品（Relief Textiles: UNHCR 毯/救灾帐篷/政府采购）

应急救灾纺织品是"**机构集采逻辑**"的特殊市场：联合国机构（UNHCR/UNICEF/WFP）、红十字国际委员会（ICRC）、各国政府应急储备、NGO 采购。救灾毯/帐篷/睡袋/防水布是四大主力。订单特征=巨量（单次百万条级）+低价+严格规格书+政治因素敏感。与民用产品逻辑完全不同，本文件梳理准入与投标要点。

## 一、主力产品规格（以 UNHCR 规格书为例）

| 产品 | 核心规格 | 技术要点 |
|:---|:---|:---|
| 救灾毯（relief blanket） | 150×200cm、克重按温区（300-600gsm）、腈纶/涤纶/羊毛混纺 | **保温率（TOG 值）+ 耐洗 20 次尺寸稳定**；高保暖型 TOG≥2.5 |
| 救灾帐篷（family tent） | 双层结构、阻燃面料、雪裙/地钉全套 | UNHCR 标准帐篷有**精确到缝线规格的招标书**——防水静水压/阻燃/UV 老化全项检测 |
| 防水布（tarpaulin） | 4×5m / 4×6m、PE 编织布淋膜、UV 稳定 | 克重 160-200gsm、抗撕裂强力、边扣间距规格化 |
| 睡袋 | 按温标分级（同民品逻辑，见 `garments/camping-gear-tents-sleeping-bags.md`） | 压缩体积+全检温标 |
| 蚊帐（LLIN 长效药浸蚊帐） | WHO 预认证清单产品 | 氯菊酯药浸持效 3 年/20 次洗——**WHO PQ 认证是准入前提** |

## 二、机构采购准入路径

- **联合国采购门户**：UNGM（United Nations Global Marketplace，www.ungm.org）——注册供应商库是第一步（公司资质/财务/产能/质量体系建设文件）；UNHCR/UNICEF 各有补充注册要求；
- **ICRC/IFRC**：红十字会体系独立供应商名录——重视商业道德审查（反贿赂条款签署）；
- **政府应急储备**：美国 FEMA、欧盟 rescEU、中国应急管理部——国内供应商可通过承储企业分包切入；
- **WHO 预认证（PQ）**：医药相关纺织品（蚊帐/医用物资）——认证周期 1-2 年但形成**寡头准入壁垒**；
- **审核与验厂**：机构委托 SGS/BV/TÜV 做供应商审核（质量体系+社会责任+反恐安全 C-TPAT 类，见 `suppliers/factory-audit-guide.md`）。

## 三、投标与履约要点

- **招标形态**：LTAs（长期协议，1-3 年框架+分批 call-off）+ 单次紧急招标（灾后 72 小时响应要求——**现货库存或极速产能**是中标关键）；
- **规格书纪律**：机构招标书精确到"每厘米针数/布边宽度/包装唛头"——**偏离即废标**；打样确认（pre-production sample 送指定实验室）；
- **价格竞争**：全球比价（土耳其/印度/巴基斯坦/中国同台）——中国优势在交期与一致性，土耳其近欧洲有物流优势（叙利亚/乌克兰方向响应快）；
- **付款与风险**：联合国机构付款条件优（见单付款，无坏账风险）但**利润率被压至极低**（5-10%）——靠规模与供应链效率盈利；政府单注意付款周期与预算年度节点；
- **合规红线**：制裁地区运输（叙利亚/朝鲜等方向需 OFAC/联合国制裁筛查，见 `trade-compliance/sanctions-screening-compliance.md`）、强迫劳动审查（机构采购对供应链人权尽调严格，见 `trade-compliance/uflpa-forced-labor.md`）；
- **政治敏感性**：救灾物资目的地冲突地区——出口许可/最终用途申报需审慎（见 `trade-compliance/dual-use-export-control.md` 边界判断）。

## 四、产能与质量管理

- **巨量订单产能**：百万条毯订单=2-3 个月交期——多厂协同（见 `suppliers/subcontracting-outsourcing-management.md`）但机构要求**报备分包且分包厂同等审核**；
- **全检 vs 抽检**：机构通常派员或委托第三方装运前检验（PSI，见 `trade-process/pre-shipment-coc-psi.md`）——部分合同要求到货国复验权；
- **留样与追溯**：每批留样 3 年（质量投诉复验基准）；
- **库存滚动**：政府储备单常有"轮换"机制（储备期 3-5 年换新——临期品回收处理渠道）。

## 五、市场机会评估

- **优点**：订单巨大、付款安全、长期协议稳定、品牌背书（"联合国供应商"资质对其他 B2B 客户有说服力）；
- **缺点**：利润极薄、投标成本高（样品+检测+差旅）、合规成本重、紧急订单打乱正常排产；
- **建议路径**：先做机构供应链的**二级供应商**（给中标企业供面料/半成品）熟悉规格体系，再直接投标。
