# 牛仔品类生产专题（Denim & Jeans Production）

牛仔（denim）是技术壁垒最高的成衣服装品类之一：面料重缩率控制，成衣靠洗水（washing）定型风格。洗水工艺的报价与确认是牛仔订单的核心。

## 一、牛仔面料

- **结构**：靛蓝（indigo）染色经纱 + 本白纬纱，3/1 右斜纹为主。
- **克重（oz/yd²）**：6-8oz 衬衫料、10-12oz 常规裤装、13-16oz 重磅、16oz+ 赤耳丹宁。
- **赤耳丹宁（selvedge denim）**：老式梭织机窄幅布边（红边），高端复古市场，价格是普通牛仔 2-4 倍。
- **弹力牛仔**：棉 + 2-3% 氨纶，女裤主流；注意**回弹性与缩水控制**。
- **产地集群**：广东新塘（中国牛仔之都）、江苏常州、山东；进口高端料——日本冈山、土耳其、意大利。

## 二、洗水工艺（核心增值环节）

### 基础洗
| 工艺 | 英文 | 效果 |
|:---|:---|:---|
| 普洗/退浆 | rinse wash/desize | 去浆软化，原色保留 |
| 酵素洗 | enzyme wash | 生物抛光去毛羽，手感柔和 |
| 石洗 | stone wash | 浮石摩擦褪色，自然做旧 |
| 漂洗 | bleach wash | 强褪色（控制氯残留） |
| 雪花洗 | snow/acid wash | 高对比斑驳效果 |

### 做旧工艺（手工含量高）
- **猫须（whiskers）**：裤裆/大腿处横向磨白纹路——树脂定型+手擦或激光（laser）。
- **手擦（hand sanding/scraping）**：砂纸/浮石手工打磨局部褪色。
- **马骝（monkey wash / potassium permanganate spray）**：高锰酸钾喷褪色——**化学品管控重点（高锰酸钾残留）**。
- **破洞（destroy/ripped）**：手工割破+磨边。
- **3D 定型（wrinkle/crinkle）**：树脂+烘箱定型永久褶皱。
- **激光（laser fading）**：环保替代手擦/马骝的趋势工艺，无化学品、可复制性强。

### 环保红线
- 传统洗水高耗水（单件 30-70L）+ 化学品排放，欧美品牌要求洗水厂具备：
  - 污水处理与 ZDHC（有害化学品零排放）合规
  - **EIM 评分**（Environmental Impact Measuring，Jeanologia 体系）——品牌常要求报告单件 EIM 分数
- 喷砂（sandblasting）工艺因矽肺病风险**已被行业禁止**，发现供应商使用立即终止合作。

## 三、生产流程

```
面料检验（缩率测试）→ 排版裁剪 → 缝制（埋夹/链式线迹）→ 半成品检验
→ 洗水（按确认洗版）→ 烘干 → 整烫定型 → 钉扣/皮牌 → 终检 → 包装
```

### 缝制要点
- **链式线迹（chain stitch）**：裤腰/侧缝，弹性与强度。
- **埋夹缝（felled seam/lap seam）**：侧缝/育克，牛仔标志性双明线。
- **专机**：打枣（bartack，袋口加固）、裤袢机、凤眼（扣眼）、撞钉（rivet）机。
- 五金：工字扣（jeans button）、撞钉、拉链（YKK 牛仔专用）——**镍释放需符合 REACH**。

## 四、质量控制要点

1. **缩率管理**：牛仔布缩率大（经向可达 8-12%），裁剪前实测面料缩率反推纸样加放；洗后尺寸必须落在 spec 公差内。
2. **洗水版确认**：洗水效果以**客户签认的洗版（approved wash standard）为准**，大货逐缸比对——色差缸差是第一大客诉。
3. **色牢度**：靛蓝牛仔摩擦牢度天生弱（干磨 3 级/湿磨 2 级常见），订单须注明接受标准，白底绣花/白色拼接款防沾色。
4. **pH 与化学品残留**：漂洗/马骝后中和清洗，pH 4.0-9.0；高锰酸钾残留检测。
5. **强力风险**：重度做旧（大破洞+重磨）撕破强力可能不合格，产前做破坏性测试。

## 五、报价要点

- 牛仔报价 = 面料（oz/成分/是否赤耳）+ 工费（专机多，CMT 15-25 元）+ **洗水费（2-8 元/件，复杂工艺另计）** + 五金皮牌。
- 洗水按工艺清单逐项报价（酶洗+猫须+手擦+破洞累加）。
- 环保合规成本（污水处理/EIM）渐成报价组成部分。
