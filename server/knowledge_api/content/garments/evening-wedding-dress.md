# 婚纱礼服与晚装生产专题（Wedding & Evening Dress Production）

婚纱礼服（bridal & evening wear）是服装工艺的"皇冠"：重工珠绣、立体裁剪、小单快返与高级定制并存。中国（苏州虎丘/广州）是全球最大婚纱生产基地，亚马逊/独立站跨境婚纱是成熟赛道。

## 一、市场格局

- **产能**：苏州虎丘婚纱城（全球 70%+ 婚纱产能集散地）、广州（外贸晚装）、潮州（晚礼服珠绣之都）；
- **渠道**：跨境独立站（JJ's House 模式——中国婚纱 DTC 标杆）、亚马逊、线下 bridal shop 批发（欧美婚纱店进货价 $200-600，零售 $800-3000）；
- **价格带**：跨境线上 $100-500 主流；线下批发高端线 $500-1500。

## 二、面料与辅料

| 材料 | 用途 |
|:---|:---|
| 缎（satin） | 婚纱主面料（厚缎/薄缎/弹力缎） |
| 欧根纱（organza） | 蓬蓬裙结构层 |
| 雪纺（chiffon） | 晚装飘逸层/伴娘服主力 |
| 蕾丝（lace） | 车骨蕾丝/水溶蕾丝/睫毛蕾丝——法国 Solstiss 为顶级 |
| 网纱（tulle） | 裙撑/头纱 |
| 珠绣辅料 | 亮片/钉珠/烫钻/羽毛 |

## 三、核心工艺（区别于常规成衣）

1. **立体裁剪（draping）**：人台上直接塑形——礼服版型技术核心；
2. **鱼骨胸衣（boning/corset）**：塑型结构（胶骨/钢骨）+ 绑带/拉链闭合；
3. **珠绣工艺**：手工钉珠（hand beading）——潮州珠绣工按件计价，一件重工婚纱钉珠工费可达数百元；
4. **蕾丝排花**：蕾丝花型对位裁剪（对花工艺——单件用料可达 8-15 米，排花师傅经验决定用料率）；
5. **裙撑结构**：硬网撑（crinoline）/鱼骨撑——A 字/蓬蓬裙型控制；
6. **拖尾工艺**：拖尾长度（court/chapel/cathedral train）分级制作。

## 四、生产模式

- **现货模式**：虎丘档口现货（批发客看样拿货）；
- **订单模式**：按图/按样生产（跨境订单主流——客户提供图片，工厂复刻）；
- **量身定制（made-to-measure）**：按客户三围数据单件生产——独立站高客单价模式；
- **改版服务**：标准款+客户微调（换领口/加袖子）——半定制。

## 五、质量与交付要点

- **尺寸精度**：礼服贴身——胸围/腰围公差 ±0.5-1cm（严于常规成衣）；
- **配色一致性**：象牙白（ivory）/本白（white）/香槟（champagne）——白色系色差敏感（同一婚纱不同批次面料拼用是灾难）；
- **交付期**：跨境定制单 30-45 天（含试穿调整）；**婚礼日期是硬死线**（延误=全额退款+差评）；
- **包装**：挂装+防尘袋+加固箱（婚纱不可压皱——见 `garments/garment-packaging.md` GOH 条款）。

## 六、跨境运营要点

- **尺码表本地化**：US/UK/EU 尺码对照+测量指引视频（尺码不合是婚纱退货首因）；
- **图片依赖**：白底图+真人模特图+细节视频——**看图买婚纱，图片质量=转化率**；
- **评价管理**：婚礼场景情绪浓度高——差评杀伤力极大（一条"婚礼前没到"差评毁掉一季）；
- **伴娘服连带**：一单多件（4-8 件同色）——批量折扣策略；
- **退货政策**：定制款不支持退货（合同明示）；标准款接受退货（翻新二次销售）。

## 七、成本与利润

- **成本结构**：面料 30-40%（蕾丝是大头）+ 珠绣工费 20-30% + 车缝 20% + 后整包装 10%；
- **利润**：跨境 DTC 毛利 60-70%（vs 常规服装 40-50%）——高工艺壁垒带来高溢价；
- **产业带工费**：潮州珠绣/苏州整件——产业带分工协作是成本优势来源。
