# 皮革与皮草服装生产（Leather & Fur Garment Production）

皮革服装 ≠ 面料服装：**针孔不可愈合（不可拆线返工）、每张皮伤残不同（利用率决定成本）、同色同件必须配对**。版型与产线管理逻辑完全不同。

## 一、原料体系

| 原料 | 特点 | 服装用途 |
|:---|:---|:---|
| 绵羊皮 | 柔软轻薄（0.5-0.8mm） | 皮衣主力（女装/夹克） |
| 山羊皮 | 韧性好/纹路自然 | 中高端皮衣 |
| 牛皮 | 厚挺（0.9-1.3mm） | 机车服/男装 |
| 猪皮 | 性价比高/毛孔粗 | 低端/里衬 |
| 水貂/狐狸/兔毛 | 皮草 | 大衣/领条/配饰 |
| PU/环保革 | 非真皮（见 `fabric/leather-synthetic-leather.md`） | 快时尚/素食主义客群 |

- **计量**：真皮按**平方英尺**计价（一张羊皮 5-9 尺，牛皮 20-30 尺）；
- **等级**：按伤残面积分级（A 级 ≥90% 可用/B 级 80-90%——报价差 20-40%）。

## 二、采购与验皮

- **集散地**：海宁（皮革城——成衣+原料）、辛集、佟二堡；进口皮（西班牙/土耳其绵羊皮高端）；
- **验皮要点**：
  - **伤残识别**：虻眼/疤痕/鞭花/松面（腹部松面避开前身片）；
  - **利用率测算**：A 级皮服装利用率 85-95%（伤残剔除+形状不规则——**单耗 = 样板面积 ÷ 利用率**）；
  - **色差配对**：同批皮张颜色分级（染色皮缸差——逻辑同面料缸差，见 `suppliers/dyeing-mill-cooperation-management.md`）；
  - **理化指标**：六价铬（欧盟 REACH ≤3mg/kg——鞣制工艺决定，见 `trade-compliance/chemical-environmental-compliance.md`）、撕裂强力、涂层粘着；
- **合规红线**：珍稀动物皮革需 CITES 证书（鳄鱼/蟒蛇——见 `trade-compliance/cites-compliance.md`）；真皮标识法规（欧盟/美国要求"Genuine Leather"标注规范）。

## 三、生产工艺特殊性

### 1. 裁剪
- **单层裁床**：皮张形状不规则+伤残避让——无法多层铺料（刀模冲裁或手工划裁）；
- **排皮师**：核心岗位（排皮水平差 5% 利用率=单件成本差 10%+）；
- **部位分配**：背臀部（紧实）→前身/袖；腹颈部（松）→兜盖/小件。

### 2. 缝制
- **针孔不愈合**：**不可拆线返工**（拆后留针孔=次品）——一次做对是唯一策略（首件必检）；
- **设备**：同步车（送布牙+滚轮防打滑）、双针；针距放大（3.5-4mm——过密撕裂）；
- **免胶水粉线**：划粉/银笔标记（不可水洗面料记号难除——用可擦银笔）。

### 3. 后整
- **免高温熨烫**：皮革 60-80℃ 低温整形（高温涂层起泡）——专用熨台/人像机；
- **清洁**：成品污渍用皮革专用清洗剂（水洗=报废）；
- **保养卡**：随货附保养说明（不可水洗/专业皮革干洗——客户投诉预防）。

## 四、皮草工艺要点

- ** sourcing**：拍卖行体系（哥本哈根皮草 2023 年关闭后格局调整——世家皮草 Saga Furs/北美 NAFA）+ 国内养殖场直采；
- **刀路工艺**：整皮（高档）/ 拼皮（经济——碎皮拼整）/ 编织（兔毛编织外套）；
- **硝染外发**：毛皮硝染是重污染专业工序（外发硝染厂——交期 15-30 天，缸差管理同面料）；
- **品质痛点**：掉毛（针毛拉力测试）、掉色（光照/摩擦）、异味（硝染不净——VOC 残留）。

## 五、成本核算

- **单件皮耗**（女式短夹克示例）：样板 22 尺 ÷ 利用率 88% ≈ 25 尺（3-4 张羊皮）；
- **损耗率**：15-25%（远高于梭织面料 8-15%——成本敏感度翻倍）；
- **报价公式**：皮料成本 + 里布 + 辅料（拉链必须 YKK 级——**不可拆换，配件坏=整件报废**）+ 工费（工价是普通服装 2-3 倍）——见 `garments/garment-costing-pricing.md`。

## 六、质量检验

| 检验点 | 标准 |
|:---|:---|
| 同件色差 | 前身/袖/背配对无明显色差（自然光 4 级） |
| 伤残外露 | 主部位无伤残（次要部位≤2 处小疵） |
| 针迹 | 无拆线痕迹/针距均匀/无跳针 |
| 涂层 | 无起泡/无裂浆（弯折测试） |
| 气味 | 无刺鼻异味（硝染/涂层溶剂残留） |

- **验货逻辑**：全检为主（单价高+不可返修——见 `trade-process/pre-shipment-inspection-sop.md`）。

## 七、淡旺季与渠道

- **季节性强**：9-12 月出货高峰（冬装）——产能前置（见 `trade-process/annual-sourcing-calendar.md`）；
- **渠道**：海宁皮革城档口（内销现货）/品牌订单（贴牌）/出口（俄罗斯/东欧寒区——见 `customers-market/russia-central-asia-market.md`、`customers-market/eastern-europe-market.md`）；
- **库存风险**：皮料保值性强（可存 2-3 年）但成衣过季贬值快（款式敏感）。
