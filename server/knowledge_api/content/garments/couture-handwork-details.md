# 高级定制手工工艺（Couture Handwork: 米兰眼/手工锁眼/纳驳头/珠边/手工钉扣）

高级定制的"**手工含量**"是价格十倍差的核心：米兰眼（Milanese buttonhole）需 40 分钟手工锁制，机器 40 秒完成但美感天差地别。这些工艺是萨维尔街 Bespoke 的"隐形签名"，也是高端 MTM 工厂的差异化壁垒。西装整体工艺见 `garments/suits-tailoring-production.md`，定制店渠道见 `customers-market/mtm-bespoke-tailor-channel.md`。

## 一、手工锁眼体系

| 工艺 | 工时 | 特征 | 应用 |
|:---|:---|:---|:---|
| **米兰眼（Milanese）** | 30-45 分钟/个 | 圆头、手工绕线芯、缎面光泽 | 驳头花眼——顶级西装标识 |
| **手工平头锁眼** | 15-20 分钟/个 | 平头、手工锁边 | 袖口真衩——高端 MTM 标配 |
| **机器锁眼** | 30-40 秒/个 | 均匀但死板 | 量产成衣 |
| **激光切割+手工锁边** | 5 分钟/个 | 精确切口+手工完成 | 高端量产折中方案 |

- **米兰眼核心**： gimp 线芯（粗棉线外包丝线）——**手工绕芯的蓬松感是机器无法复制的立体度**；
- **鉴别方法**：放大镜下——米兰眼有"螺旋纹理"，机器锁眼是"平行线迹"；
- **工时成本**：萨维尔街米兰眼 £15-25/个，中国工厂 ¥30-50/个——**手工锁眼是"按个计价"的独立工序**。

## 二、纳驳头（Pad Stitching Lapel）

- **工艺**：手工在驳头衬上纳"人字"线迹——**使驳头自然翻卷（roll）而非死板折痕**；
- **对比**：
  - 机器纳驳头：直线线迹——翻卷僵硬；
  - 粘合衬驳头：无纳线——完全无翻卷；
  - 手工纳驳头：人字线迹密度 8-10 针/cm——**"活"的驳头会随穿着者体型微调**；
- **时间成本**：一件西装驳头纳衬 2-3 小时——**全麻衬西装的手工价值集中在此**。

## 三、珠边/拱针（Pick Stitching）

- **定义**：沿边缘手工拱出细密针迹——装饰+加固双重功能；
- **位置**：驳领边缘/门襟/口袋盖/后开衩——**"见边即拱"是意大利高定传统**；
- **线迹**：真丝线与面料同色——**远看隐形、近看细腻**；
- **工时**：一件西装全身珠边 1.5-2 小时。

## 四、手工钉扣（Hand-Sewn Buttons）

- **绕脚（shank）**：线在扣底绕出"柱脚"——**扣合后面料不拉扯**（厚面料必须）；
- **绕脚高度**：面料厚度+2mm——公式化但需经验调整；
- **交叉钉法**：线迹在扣面呈 X——**比平行钉法牢固 3 倍**；
- **米兰扣眼+手工钉扣**：一套西装的"手工套装"——**两者缺一，档次立降**。

## 五、其他关键手工

- **手工归拔（hand basting）**：定型前粗缝固定——机器归拔的"预演"；
- **手工缲边（hand felling）**：里布边缘手工缲缝——**机器缲边是"锁链线迹"，手工是"隐形点迹"**；
- **手工垫肩（hand-set shoulder pad）**：垫肩位置微调——**左右肩差 0.5cm 的体型修正**；
- **手工开衩（hand-finished vent）**：后衩/袖衩的边角处理——**"干净到反面"是检验标准**。
