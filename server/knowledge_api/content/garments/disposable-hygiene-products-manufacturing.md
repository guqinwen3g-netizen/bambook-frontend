# 一次性卫生用品生产（Disposable Hygiene: 纸尿裤/卫生巾/经期裤/护理垫）

一次性卫生用品（纸尿裤/卫生巾/护理垫）是"**设备资本密集 + 材料配方驱动**"的快速消费品：一条纸尿裤高速机投资千万级、分钟产出 400-800 片，拼的是**开机率与材料成本控制**。国内格局（恒安/百亚/豪悦代工三巨头）已定，外贸机会在**非洲/东南亚/中东中低端贴牌**与经期裤等新品类出海。本文件梳理产品结构、材料供应链与外贸接单要点（成人失禁品类见 `garments/incontinence-care-products.md`，本文聚焦婴妇卫材制造工艺）。

## 一、产品结构与材料清单

| 层级 | 材料 | 功能 | 成本占比 |
|:---|:---|:---|:---|
| 面层 | 热风/纺粘无纺布（柔软导流） | 亲肤+快速渗透 | 10-15% |
| 导流层 | ADL 无纺布 | 扩散均匀 | 5% |
| 吸收芯 | 绒毛浆+SAP 高分子（或全芯体） | 吸收锁水——**SAP 牌号决定反渗** | 30-40% |
| 底膜 | PE 流延膜/透气膜 | 防漏+透气 | 10% |
| 弹性件 | 氨纶丝/橡筋+立体护围 | 防侧漏 | 10% |
| 结构胶 | 热熔胶（汉高/富乐牌号） | 层间复合 | 8-10% |

- **全芯体 vs 木浆芯体**：全芯体（SAP+无尘纸复合）轻薄不断层，是经期裤/高端纸尿裤主流；木浆芯体成本低但厚——非洲市场仍以木浆芯体为主（价格敏感）；
- **SAP 是性能命门**：住友/三大雅/巴斯夫牌号保水值与加压吸收量差异大——合同锁定 SAP 品牌型号，换料必须重测（来料检验见 `suppliers/incoming-material-inspection.md`）。

## 二、生产与品控

- **设备**：纸尿裤机/卫生巾机（安庆恒昌/晋江系国产机 vs 意大利法麦凯尼考）——高速机 600 片/分钟 vs 低速机 200 片/分钟，**开机率决定盈亏**（换料换码停机是最大损耗）；
- **关键检测**：吸收速度/回渗量/滑渗量/渗漏量（GB/T 28004 纸尿裤、GB/T 8939 卫生巾、GB/T 28004.2 成人）、pH、可迁移荧光增白剂——出厂自检+型检送外（见 `trade-compliance/testing-lab-selection.md`）；
- **卫生红线**：GB 15979 微生物指标（细菌菌落/大肠菌群/致病性化脓菌不得检出）——车间洁净、人流物流分离、虫控是验厂重点；
- **缺陷高发**：SAP 分布不均（结块）、热熔胶断胶（脱层）、弹性腰围拉伸比不均——在线视觉检测+金属探测（断针逻辑同 `suppliers/needle-control-metal-management.md` 思路）是标配。

## 三、外贸接单要点

- **市场分层**：非洲（尼日利亚/加纳，低价木浆芯，整柜走量）/东南亚（中端全芯体）/中东（大码纸尿裤+经期裤新品类）/拉美（认证门槛见 `trade-compliance/mexico-nom-latam-certification.md`）；
- **认证**：CE（MDD 一类）/FDA 一类列名（510k 豁免）/部分国家装运前认证（见 `trade-compliance/pre-shipment-coc-psi.md`）；
- **泡货属性**：纸尿裤体积大货值低——**40HQ 装载量是报价核心变量**（压缩包装可提装载 20%+，但回弹影响卖相需客户确认）；
- **贴牌逻辑**：海外本地品牌提供设计稿，工厂 ODM 配方+生产——**打样确认吸收芯体克重配比（SAP 含量直接定价）**；
- **经期裤出海窗口**：国内成熟品类（苏菲/高洁丝教育市场）在东南亚/中东属新品类——复制国内打法（夜用防漏场景）有先发红利；
- **原料套保**：SAP/无纺布随油价波动——年框订单建议原料指数联动条款（逻辑同 `fabric/technical-agro-geo-textiles.md` 树脂条款）。
