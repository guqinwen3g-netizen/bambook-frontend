# 辅料与标签（Accessories & Trims）

成衣由**面料（fabric）**与**辅料（accessories/trims）**构成。辅料种类多、标准杂，是外贸跟单中最易出错、最易造成客诉的环节。本文件覆盖主要辅料品类、术语与采购要点。

## 一、辅料分类总览

辅料（trims/accessories）包括：拉链、纽扣、缝纫线、各类标签、吊牌、衬布、绣花、松紧带、织唛、魔术贴等。本品类文档聚焦服装闭合、标识与装饰类辅料。

## 二、闭合类辅料（Fasteners）

### 拉链（Zipper）
- 部件：拉头 slider/slider pull、拉链齿 teeth、拉链布带 tape、上下止 top/bottom stop。
- 型号：3#、5#、8#（号码越大齿越粗）；常用尼龙 zipper、金属 metal zipper、树脂 plastic/coil zipper。
- 拉头类型：尼龙拉头、金属拉头、隐形拉链 invisible zipper（用于裙装/礼服）。
- 常见故障：拉头卡顿、牙齿咬合不齐、拉链色差。

### 纽扣（Button）
- 材质：树脂 resin、贝壳 shell、金属 metal、木质、塑料；还可分**四孔/两孔（4-hole/2-hole）**、蘑菇扣（stud button）。
- 术语：五爪扣/摁扣 snap button、工字扣 rivet、磁扣 magnetic button。
- 关键：**水洗/干洗牢度**，金属纽扣需防锈（防锈防腐 anti-corrosion）。

### 其他闭合件
- 魔术贴 Velcro/hook & loop、钩扣 hook & eye、松紧带 elastic/waistband、D 环 D-ring、调节扣 cord stopper。

## 三、标识类辅料（Labels & Tags）

标识直接关系**合规与可追溯**，是验货重点：

| 辅料 | English | 说明 |
|:---|:---|:---|
| 主标/品牌标 | main label/brand label | 缝在领口或腰内 |
| 洗标 | care label | 含成分、洗涤、产地、厂商 |
| 成分标 | fiber content label | 成分比例，需符合目的地法规 |
| 尺码标 | size label | 尺码 |
| 产地标 | country of origin | 出运国 |
| 织唛 | woven label | 织入布内，耐用 |
| 印刷标 | printed label | 直接印在面料上 |
| 吊牌 | hang tag/price tag | 挂在成衣上，含品牌、条码 |
| 洗水唛/护理标 | care instruction label | 洗涤符号 |

> 合规要点：美国 FTC 要求成分与产地英文标识；欧盟要求 CE/洗涤符号符合 EN 体系。标识内容必须与检测报告一致。

## 四、其他关键辅料

### 缝纫线（Thread）
- 常用涤纶线 polyester thread、尼龙线 nylon thread、棉线 cotton thread（较少）。
- 规格与色号：车缝线需与面料对色（color matching），弹性面料需用弹力线/高弹线。
- 牢度：色牢度（colorfastness）、强力（tensile strength）需达标。

### 衬布（Interlining/Fusing）
- 分有纺衬 woven interlining、无纺衬 non-woven interlining；用于领口、门襟、腰头定型。
- 关键：**热熔衬（fusing）**的粘合牢度与耐水洗、耐干洗性。

### 绣花与装饰（Embroidery & Embellishment）
- 绣花 embroidery、机绣 machine embroidery、手工绣 hand embroidery。
- 车花/烫钻：烫钻 rhinestone/stud、亮片 sequin、珠片 beading。
- 绣花风险：跳针、脱线、色差、缩水后变形，需做牢度测试。

### 其他
- 织带/缎带 ribbon、花边 lace、肩垫 shoulder pad、里布 lining、防滑条、绳带 drawstring。

## 五、采购与跟单要点

1. **色系统一**：辅料色卡（trim card）需与面料色卡对色，出货时附色卡确认。
2. **牢度测试**：拉链、纽扣、绣花需做色牢度、强力、水洗/干洗测试。
3. **标识合规**：与客户确认目的地法规，标识内容与检测报告一致。
4. **品牌授权**：品牌标、吊牌涉及品牌授权，不得擅自替换。
5. **备料齐套**：辅料数量需按大货数量加成（一般加 3%-5% 损耗料），避免断料影响交期。
6. **留样存档**：辅料样品（approved trims sample）存档，作为大货验收对照。
