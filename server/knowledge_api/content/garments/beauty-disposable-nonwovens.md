# 美容护理无纺布制品（Beauty Nonwovens: 洗脸巾/化妆棉/面膜布/压缩毛巾）

美容一次性无纺布是**国内新消费爆款品类**（全棉时代洗脸巾单品年销数十亿——验证"棉柔巾替代毛巾"的消费升级叙事），出口面向日韩/东南亚。材料平台=**水刺无纺布**（见 `fabric/nonwoven-fabrics.md` 的工艺体系），本文聚焦消费级制品逻辑——与工业擦拭（见 `fabric/industrial-wipes-cleaning-cloths.md`）同平台不同赛道。

## 二、生产要害

- **水刺布选型**：**全棉水刺（亲肤天花板——棉花直接成布无化纤）vs 粘胶/涤纶混合（成本 1/2-1/3）**——"100% 棉"宣称需纤维成分检测支撑（粘胶冒充全棉是打假高发——GB/T 29862 纤维标识，见 `trade-compliance/china-domestic-standards.md`）；
- **克重与厚度**：洗脸巾 40-80gsm（**克重即手感**——低于 40gsm 单薄差评）；珍珠纹/网纹压花（**纹理增加摩擦清洁力+视觉厚度**）；
- **干湿两用**：湿水不破（**湿强力**——粘胶湿强差，全棉/含涤骨架优）；掉絮率（**擦拭起絮=差评首因**——水刺压力与纤维长度控制）；
- **折叠与包装**：抽取式折叠（N 折/V 折设备——**连抽不断张**是分切折叠精度）；盒装/袋装/便携装三形态；
- **面膜布**：**384 蚕丝布**（铜氨丝超薄——服帖性标杆）；天丝（莱赛尔——吸液率）；备长炭（黑膜——吸附叙事）；**裁切脸型**（眼部/鼻位刀模精度——面膜厂供基布或成品片）；
- **压缩工艺**：高温高压压缩（压缩毛巾——**遇水 3 秒展开**复原性测试）；独立糖果包装（卫生+便携）。

## 三、合规要点

- **国内**：一次性使用卫生用品 **GB 15979**（微生物指标——细菌菌落总数/真菌/致病菌——生产环境 30 万级洁净车间）；**消毒产品生产企业卫生许可证**（湿巾类——干巾按卫生纸品管理）；
- **宣称红线**：**"纯棉"需成分检测**；"食品级/可入口"等暗示宣称违规；"抗菌/抑菌"需消字号备案（普通棉柔巾不可宣称）；**婴儿适用宣称需 A 类检测**（GB 31701 逻辑，见 `trade-compliance/china-domestic-standards.md`）；
- **出口**：欧盟化妆品接触边界（面膜布随面膜液归类——**基布本身按纺织品**，预浸液面膜按化妆品 CPNP 备案）；美国 FDA（化妆棉按一类器械边界——无治疗宣称即可）；
- **环保叙事**：**全棉可降解 vs 粘胶（溶解浆来源——FSC 森林认证加分）**；欧盟一次性塑料指令（含塑湿巾标识义务——见 `trade-compliance/textile-waste-circularity-policy.md`）。

## 四、市场与渠道

- **国内**：**全棉时代/ babycare/德佑品牌格局**——白牌机会在**极致性价比+细分场景**（母婴棉柔巾/男士洁面/卸妆专用）；抖音渠道打法（9.9 元引流款——克重 40gsm 成本线）；
- **出口**：日韩（美妆配套——化妆棉品质要求高）；东南亚（穆斯林洁面场景）；欧美（环保可降解叙事——bamboo 洗脸巾）；旅行压缩毛巾（酒店/航空配套——见 `garments/airline-aviation-textiles.md` 的一次性用品逻辑）；
- **B2B**：美容院线（美容巾/床单——见 `garments/salon-spa-textiles.md`）；面膜厂基布供应（广州/上海面膜代工集群——基布占面膜成本 5-10%）；酒店一次性浴巾（民宿/洗浴渠道）；
- **差评三高发**：掉絮（纤维长度/水刺压力）、太薄（克重虚标——**标注克重是诚信卖点**）、连抽（折叠精度）；
- **产业带**：湖北（全棉水刺——稳健医疗链）、浙江（粘胶水刺）、广东（面膜布/压缩制品）；**原料联动**：粘胶短纤价格（溶解浆——见 `fabric/regenerated-cellulose-fabrics.md`）。
