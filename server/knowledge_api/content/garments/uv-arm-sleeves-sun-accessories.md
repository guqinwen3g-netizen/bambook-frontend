# 冰袖与防晒配件生产（UV Accessories: 防晒袖套/面罩/防晒帽）

防晒配件是**防晒服品类的轻量延伸**：冰袖（袖套）、防晒面罩/脸基尼、防晒帽、防晒手套。逻辑=**UPF 面料+小件高频复购**——单件 $5-15 低客单价但复购与组合销售驱动。国内是防晒第一大市场（夏季全民防晒文化），出口主赛道为**户外作业/运动场景**（骑行/钓鱼/高尔夫）。防晒服主体见 `garments/sun-protection-clothing.md`，本文聚焦配件小件。

## 一、产品矩阵

| 产品 | 面料 | 结构要点 | 价格带（零售） |
|:---|:---|:---|:---|
| 冰袖（防晒袖套） | 锦纶+氨纶凉感针织（UPF50+） | 无缝圆筒/平缝+防滑硅胶条 | $5-15/双 |
| 防晒面罩/脸基尼 | 锦纶凉感/涤纶网眼 | 口鼻透气孔+耳挂/头套式 | $8-20 |
| 防晒帽（大檐/空顶） | 涤纶/尼龙+UPF 涂层 | 帽檐 12cm+/防风绳/透气网 | $10-30 |
| 防晒手套 | 凉感针织+掌心防滑 | 露指/全指+触屏指尖 | $8-18 |
| 脖套/面巾 | 无缝圆筒针织 | 见 `garments/seamless-bandanas-headwear.md` | $5-12 |

## 二、材料与工艺要害

- **凉感面料**：**锦纶 6 凉感纱（玉石粉/云母粉添加——接触凉感系数 q-max≥0.15 宣称依据）**；导热系数+吸湿排汗双指标——凉感宣称需检测报告（GB/T 35263 接触凉感）；
- **UPF 防晒**：UPF50+（UVA 透过率<5%——AATCC 183/GB/T 18830 测试）；**深色>浅色、密织>稀疏**（面料选型即防晒力）；湿态防晒衰减是虚标雷区；
- **无缝针织**：冰袖圣东尼无缝圆机（一体成型无侧缝——与魔术头巾同设备，见 `garments/seamless-bandanas-headwear.md`）；**罗口防滑**（硅胶条印刷/氨纶加密——下滑是头号差评）；
- **尺寸弹性**：均码弹力覆盖臂围 22-38cm——**大臂围人群卷边**（加宽罗口款差异化）；
- **面罩细节**：鼻部开口（透气防闷痘）、护颈后片加长、**头发出口**（马尾辫开口——女性用户洞察点）。

## 三、合规与宣称

- **UPF 宣称**：美国 FTC 对防晒宣称监管（"UPF 50+"需 AATCC 183 报告——无报告宣称=虚假广告案例高发）；国内 GB/T 18830（UPF>40 且 UVA<5% 才能标"防紫外线产品"）；
- **凉感宣称**："冰感"为营销词（物理凉感整理 vs 心理暗示边界——检测 q-max 值背书）；
- **普通消费品定性**：防晒配件非 PPE（除非宣称焊接/工业紫外防护——PPE 边界见 `trade-compliance/ppe-protective-clothing-compliance.md`）；
- **皮肤接触化学**：偶氮/甲醛（GB 18401 B 类——见 `trade-compliance/china-domestic-standards.md`）；硅胶条致敏（皮肤斑贴测试背书是加分项）；
- **商标**："冰袖"为通用名；"Coolibar/Sunday Afternoons"等品牌版型专利检索。

## 四、市场与运营

- **国内市场**：夏季（5-8 月）电商爆发——抖音/拼多多白牌价格战（¥5-15/双）；**品牌溢价路径：检测背书+设计颜值（蕉下模式——防晒全品类化）**；
- **出口市场**：东南亚（全年需求+骑行文化）、中东（头巾兼容款）、美国（户外作业/钓鱼/高尔夫场景——亚马逊 "arm sleeves" 类目）；**欧美无全民防晒文化——按运动场景卖不按防晒焦虑卖**；
- **组合销售**：冰袖+面罩+帽子三件套（$20-35）；骑行套装（冰袖+腿套）；钓鱼套装（+手套）；
- **季节与复购**：4 月备货 5-8 月旺季；**复购逻辑**（丢失/洗坏/多色收集——年均 2-3 双）；B2B 定制（赛事/球队 Logo 印花——热升华，见 `fabric/digital-printing-technology.md`）；
- **差评三高发**：下滑（罗口松）、起球（低质涤纶——锦纶混纺升级）、凉感无感（虚标——详情页放检测报告截图）。
