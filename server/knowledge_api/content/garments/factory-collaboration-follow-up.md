# 成衣工厂合作与跟单要点（Factory Collaboration & Follow-up）

成衣外贸的落地依赖**成衣工厂（garment factory）**。本文件梳理从样品到出运的跟单流程、样品类型与验货要点，帮助控制品质、交期与成本。

## 一、样品类型与用途

跟单中最易混淆的是各类样品，须明确其用途与确认节点：

| 样品 | English | 用途 |
|:---|:---|:---|
| 开发样 | development sample | 确认款式可行性 |
| 试身样 | fit sample | 验证版型与合体度 |
| 规格样 | measurement/p-size sample | 确认尺寸规格 |
| 修正样 | revised sample | 修改后的版本 |
| 确认样 | approved sample | 作为生产依据 |
| 尺码链样 | size set sample | 确认各码放码正确 |
| 产前样/PP样 | pre-production (PP) sample | 大货前首件，代表大货 |
| 大货首件样 | TOP sample | 大货中抽出的首件 |
| 船样/出货样 | shipment sample | 随货/提前寄客户确认 |

> 沟通要点：每个节点都要**书面确认（approve）**，避免口头确认导致后续返工与扯皮。

## 二、产前样（PP Sample）与大货

- **产前样（pre-production sample）**：在正式投产前用同款面料/辅料制作的首件，用于封样（seal sample）与投产依据。
- 产前样通过后进入**大货（bulk production）**。
- 大货阶段关键管控：
  - 面料/辅料批次与色卡一致（对色）。
  - 规格按 GM 单执行，抽检尺寸。
  - 工艺按工艺单执行，抽查针距、车缝质量。
  - 包装（packing）与外箱（master carton）按装箱单执行。

## 三、验货要点（QC / Inspection）

验货是控制大货质量的关键动作，重点：

### 验货前准备
- 备齐 GM 单、工艺单、色卡、确认样（approved sample）、装箱单。
- 明确验货抽样标准（AQL，如 AQL 2.5/4.0）。

### 验货检查维度
1. **外观**：色差、污渍、抽纱、印花瑕疵。
2. **尺寸**：按 GM 单抽查关键部位，对照公差。
3. **工艺**：车缝、针距、线头、加固、对条对格。
4. **辅料**：拉链、纽扣、标签、吊牌齐全且正确。
5. **标识**：洗标、成分标、产地标合规。
6. **包装**：叠装/挂装、吊牌、外箱唛头、数量。

### 验货结论
- **合格 pass**：出运。
- **有条件合格 conditional pass**：现场修补后可出运。
- **不合格 fail**：返工或重做，需二次验货（re-inspection）。

## 四、交期与成本管控

- **交期（delivery/lead time）**：明确下单→出运的周期，关键节点（裁床、缝制、整理、包装）设里程碑跟进。
- **排产（production planning/scheduling）**：与工厂确认产能与排单，避免插单影响交期。
- **成本**：工厂报价（FOB/EXW）含面料、辅料、工费、管理费；跟单需核对**用量（consumption）**与实际用料，防止虚报。
- **损耗（wastage/add-on）**：面料与辅料按比例加损耗料，超出需与工厂确认责任方。

## 五、合作与沟通要点

1. **合同锁定**：单价、交期、质量标准、付款方式（如 T/T、L/C）写进订单合同。
2. **书面留痕**：所有样品确认、工艺变更、交期调整均书面确认存档。
3. **供应商分级**：按质量、交期、配合度对工厂分级，优先长期稳定合作。
4. **风险预案**：关键工厂备选，避免单一工厂断供风险。
5. **质量追溯**：每批大货留样存档，一旦客诉可追溯批次与责任环节。
