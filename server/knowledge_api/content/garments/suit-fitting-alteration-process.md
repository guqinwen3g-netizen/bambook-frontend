# 西装试身与版型修正（Suit Fitting & Alteration: 毛壳试穿/问题诊断/纸样修正）

试身是定制西装的"**诊断-开方**"环节：客户身上的每一道斜绺都对应一个纸样修正动作。售后修改见 `trade-process/premium-after-sales-service.md`，版型体系见 `garments/suit-fit-pattern-systems.md`，定制店运营见 `customers-market/custom-tailor-shop-operations.md`——本文件聚焦**试身问题诊断与纸样修正技术**。

## 一、试身流程

| 阶段 | 目的 | 工艺状态 |
|:---|:---|:---|
| 毛壳试身（baste fitting） | 版型大调 | 粗缝毛壳（无衬/白坯衬）——可拆可改 |
| 光样试身（forward fitting） | 细节微调 | 有衬有领——接近成品 |
| 成品试穿（final fitting） | 确认交付 | 成衣——仅允许微调（裤长/腰省） |

- **MTM vs Bespoke 差异**：MTM 通常 1 次试身（光样）——**Bespoke 的 2-3 次试身是价格差异的核心成本**；
- **试身环境**：自然光+三面镜+硬地面——**地毯会改变裤长判断**；
- **记录**：360° 照片+修正标记（划粉/珠针）+数据记录——**修正量是版型库迭代的核心资产**。

## 二、常见问题诊断表（上衣）

| 症状 | 根因 | 纸样修正 |
|:---|:---|:---|
| 后领离颈（collar gap） | 后领窝过深/肩斜不匹配 | 后领窝提高 0.3-0.5cm |
| 领下横褶 | 驼背体型/后背过长 | 后背片短缩+后领降低 |
| 前胸斜绺（指向腋下） | 胸量不足/袖窿过深 | 前胸加量+袖窿上抬 |
| 腰部横褶 | 收腰不足/肚位突出 | 中腰收省+肚省放开 |
| 驳头起空（lapel gap） | 胸衬塑形不足/驳头止口紧 | 纳衬归拔+止口松量 |
| 袖山起包 | 吃势过多/袖山高过高 | 袖山降低+吃势减少 |
| 袖子前甩/后甩 | 袖山绱袖对位偏移 | 袖山旋转调整 |
| 后背中间竖褶 | 背宽不足/后中省量过大 | 背宽加量+省量回调 |
| 下摆后翘 | 臀围放量不足/后片短 | 后片加长+臀围加量 |

## 三、常见问题诊断表（裤装）

| 症状 | 根因 | 修正 |
|:---|:---|:---|
| 裆部猫须纹 | 前裆紧/龙门窄 | 前浪加深+龙门加宽 |
| 后裆下坠横纹 | 后裆过长 | 后浪短缩 |
| 膝部起包 | 膝围松量过大 | 膝围收量 |
| 裤脚前长后短 | 站立骨盆前倾 | 裤脚斜度调整 |
| 腰部下滑 | 臀腰差过大/后翘不足 | 后上裆加长+腰省加深 |

## 四、特殊体型修正

- **溜肩（sloping shoulder）**：垫肩加厚塌肩侧+肩斜角度加大——**双溜肩需前后肩线同步调整**；
- **冲肩（square shoulder）**：相反方向——垫肩减薄+肩斜放平；
- **驼背（stooped back）**：后背加长+后领降低+前身缩短——**驼背体型的前身横褶是标志性症状**；
- **挺胸（erect posture）**：前胸加长+驳头外移；
- **大肚（prominent stomach）**：前片肚省+门襟外撇（搭门移位）——**"遮肚"剪裁是定制店的核心技能**；
- **高低肩**：左右肩分别调整——**垫肩左右差异化是 Bespoke 级服务**；
- **长短腿**：裤长左右差——**记录差值入档，后续订单直接应用**。

## 五、修正数据管理

- **修正量阈值**：单次修正 >2cm 时警惕——**版型基准可能选错（应换基准版型而非硬改）**；
- **数据沉淀**：客户修正记录→个人版型库——**二次订单直接应用修正后版型（复购体验质变）**；
- **MTM 工厂对接**：修正数据的结构化传输（调整项+方向+量）——**模糊描述（"收一点"）是定制返工第一源头**；
- **版师协作**：量体师诊断→版师开方——**两者必须同看试身照片/视频（远程协作标准流程）**。

## 六、交付标准

- **静态合格线**：无明显斜绺/领贴颈/驳头伏贴/下摆水平；
- **动态合格线**：抬臂 45° 无牵扯/前抱背不紧绷/蹲坐裆部无撕裂风险；
- **客户教育**：**"西装不是运动服"——合理活动量预期管理**是交付话术的一部分。
