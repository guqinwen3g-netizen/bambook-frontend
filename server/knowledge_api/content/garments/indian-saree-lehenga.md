# 印度纱丽与南亚民族服饰（Saree/Lehenga/Salwar Kameez 出口实务）

南亚民族服饰是"**14 亿人口刚需 + 婚庆高客单**"的文化绑定品类：纱丽（saree）是一块 5.5-9 码的披裹面料+上衣衬裙组合，楞哈（lehenga）是婚庆三件套，旁遮比（salwar kameez）是日常三件套。对中国供应商的机会在**面料出口+半成品绣片+成衣代工**三层。市场背景见 `customers-market/india-market.md`，本文聚焦产品侧。

## 一、核心产品矩阵

| 品类 | 结构 | 价格带（零售） | 场景 |
|:---|:---|:---|:---|
| 纱丽 Saree | 5.5-9 码面料（含 pallu 垂坠端+ border 织边）+ blouse 上衣+petticoat 衬裙 | $15（机印涤纶）-$3000+（Kanjivaram 真丝） | 日常/节庆/婚庆 |
| 楞哈 Lehenga | choli 短上衣+大摆裙+dupatta 披纱三件套 | $80-$1500+ | 婚庆/派对（客单最高） |
| 旁遮比 Salwar Kameez | 长衫+灯笼裤/直筒裤+dupatta 三件套 | $15-150 | 日常主力（北印/巴铁） |
| Kurti | 中长上衣（单件配牛仔裤/leggings） | $8-40 | 年轻日常（快时尚化） |

- **纱丽面料流派**：Kanjivaram/Banarasi 真丝（婚庆硬通货——zari 金线织花）、乔其纱/雪纺印花（日常跑量）、缎面/丝绒（冬季婚庆）、棉纱丽（南印日常）；
- **工艺分层**：数码印花（见 `fabric/digital-printing-technology.md`）→机绣亮片→手工 zardozi 金线绣/mirror work 镜片绣（印度古吉拉特/拉贾斯坦手工集群）——**手工绣片是中国厂难替代的溢价层**，中国机会在印花面料与机绣半成品；
- **尺码逻辑**：纱丽面料均码（披裹式），上衣/楞哈分码且**版型偏小修身**（choli 露脐贴身剪裁）。

## 二、供应链与工艺要点

- **中国切入点**：绍兴/广州雪纺乔其纱印花纱丽面料（按 5.5/6 码定长裁片出口）+亮片绣花半成品面料；印度本土 completes 缝制（人工成本低，成衣全缝制出口印度无优势）；
- **织边工艺**：纱丽必须带**连续织边（border）与 pallu 端部花位**——印花文件需按 5.5 米定位花（循环花+端部定位花复合），制版逻辑不同于常规面料；
- **刺绣配套**：亮片（sequin）耐洗牢度+金线（zari）金属丝氧化变色管控（见 `fabric/lace-and-embroidery-fabrics.md` 花边绣品通用逻辑）；
- **色牢度**：纱丽与上衣/衬裙**撞色串色风险**（深色 pallu+浅色 blouse 同洗）——皂洗牢度 4 级底线；夏季汗渍+防晒剂污染（耐汗/耐光）；
- **包装**：单条折叠入袋+腰封卡（婚庆款礼盒）；面料按条卷装防折痕。

## 三、市场节奏与渠道

- **婚庆双旺季**：10-12 月（排灯节后婚季）+4-5 月——**备货倒排：海运 6-8 月发秋冬婚季**；排灯节（Diwali）/九夜节（Navratri）/开斋节（穆斯林人口 2 亿——与 `garments/modest-muslim-wear.md` 交叉）为脉冲节点；
- **渠道**：印度本土电商（Myntra/Amazon India/Flipkart——外资卖家入驻受限，走本地分销）、海外印裔 diaspora（美国/英国/阿联酋/毛里求斯/斐济——Utsav Fashion 类垂直站+亚马逊）、批发（孟买/Surat 纺织品市场——Surat 是全球最大纱丽印染集群）；
- **竞品格局**：印度本土产业链完整（Surat 印花+加尔各答刺绣），中国优势仅在**差异化面料（仿真丝/新型印花）与价格带下探**——纯跑量市场已红海；
- **合规**：出口印度=高关税（纺织品基本关税 20%+GST）+BIS 部分品类认证；做 diaspora 市场（美/英/澳）按一般纺织品合规（纤维成分标见 `trade-compliance/textile-labeling-regulations.md`）。

## 四、风险与谈判要点

- **付款**：印度买家惯用 DA/LC 远期——**信用调查必做**（见 `trade-process/customer-credit-investigation.md`），Sinosure 额度先行；
- **知识产权**：花型版权意识弱——**原创花型被翻版是常态**，爆款走快反逻辑而非版权保护逻辑；
- **色差容忍度低**：婚庆同批次色差=整单拒收——对色光源 D65+TL84 双光源（见 `suppliers/dyeing-mill-cooperation-management.md`）；
- **报价单位**：纱丽按条（piece）报价而非按米——**换算门幅克重时核对定长**（5.5m/6m/9m）。
