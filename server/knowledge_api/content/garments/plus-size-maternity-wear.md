# 大码装与孕妇装生产专题（Plus-Size & Maternity Wear）

大码（plus-size）与孕妇装（maternity）是"被主流忽视的蓝海"：欧美大码人口占比 35%+，但供给长期不足——**版型技术是壁垒，情感共鸣是溢价**。

## 一、大码装（Plus-Size）

### 市场
- 美国女装 14 码+人群占 67%——大码女装市场 $300 亿+；品牌（Torrid/Lane Bryant）+ 零售商大码线（Target/H&M+）+ DTC 品牌（Universal Standard）。
- 尺码体系：美国 14W-32W（W=Women's 大码）/1X-6X。

### 版型技术（核心壁垒）
- **不是简单放大**：大码体型脂肪分布变化（腹围/上臂/大腿增量大于胸围）——**等比放码（grading）到大码失效**，需大码专用基础版型；
- **关键调整**：腹围松量加大、前片加长（腹部撑起）、上臂围加大、后背加宽、裆深调整；
- **人台**：大码人台（18W/20W）试身——用小号人台放大码推版是行业常见病；
- **面料**：弹力面料友好（包容体型波动）；垂感面料显瘦（粘胶/莫代尔）；避免高反光缎面（视觉膨胀）。

### 生产要点
- **用料增加**：大码单件用料 +30-60%——成本与报价重算（不能按均码成本加成）；
- **缝制**：受力部位加固（大码服装接缝受力大——裆部/腋下套结）；
- **细节设计**：宽肩带（文胸承重）、防磨裆（大腿摩擦——裤装内衬贴片）、加长拉链（穿脱便利）。

## 二、孕妇装（Maternity）

### 市场
- 全球孕妇装 $200 亿+；渠道：Motherhood（美）、Seraphine（英）、电商大单品（亚马逊孕妇裤/哺乳文胸类目）。
- **双阶段设计**：孕期（maternity）+ 产后哺乳（nursing）——一件两穿是产品溢价点。

### 版型技术
| 部位 | 设计 |
|:---|:---|
| 腹部 | 托腹面板（belly panel——高弹针织托腹带）/褶皱放量（side ruching 侧褶随孕周展开） |
| 胸部 | 哺乳开口（nursing access：交叉领/侧开扣/上掀式） |
| 腰围 | 可调节（松紧带+纽扣调节带） |
| 裤装 | 托腹裤（over-bump）vs 低腰托腹（under-bump）双版型 |

### 面料
- **高弹亲肤**：棉氨/莫代尔氨（四向弹力+回弹——孕晚期腹部极限拉伸）；
- **抗菌安全**：贴身层 A 类标准（孕妇敏感）；
- **哺乳文胸**：无钢圈+高承托（记忆棉杯）——见 `garments/underwear-lingerie-production.md`。

## 三、共性生产管理

1. **试身模型**：大码/孕妇真人试身（fit model）稀缺——建立专用试身资源池（比普通 fit model 费用高 50-100%）；
2. **尺码标**：避免羞辱性标注（"XXL"→ 部分品牌改 "1X/2X" 或 "Curve" 系列——细节体现尊重）；
3. **退货率**：特殊体型合身难度高——尺码表+真人试穿报告（"Model wears 18W, height 5'7\""）降退货；
4. **营销合规**：大码营销避免"减肥暗示"（body positivity 文化）——广告用词敏感。

## 四、订单特征

- **MOQ 友好**：品类竞争不充分——500-1000 件/款可谈；
- **复购稳定**：孕期短但哺乳用品连带（孕期内复购不同孕周尺码）；
- **客户群**：专业大码品牌/孕妇装品牌 + 综合品牌延伸线（传统品牌加大码线是行业趋势）；
- **利润**：溢价 15-30%（版型壁垒+情感价值+供给不足）。
