# 女式正装生产（Women's Tailoring: Power Suit/女式西装/大衣/职场正装）

女式正装是"**增长最快的正装细分**"：女性高管/专业人士对"权力套装"（power suit）的需求持续上升，但女式西装的工艺复杂度（胸省处理/腰臀差/版型多样性）远超男装。男装西装见 `garments/suits-tailoring-production.md`，大衣见 `garments/wool-coat-production.md`——本文件聚焦**女式正装的差异化工艺与市场需求**。

## 一、女式西装品类

| 品类 | 特征 | 场景 |
|:---|:---|:---|
| 单排扣西装 | 简洁、通用、一粒扣/两粒扣 | 日常商务/面试 |
| 双排扣西装 | 权威、复古、四粒/六粒扣 | 高管/演讲/谈判 |
| 吸烟装（Le Smoking） | 缎面驳领、修身、YSL 经典 | 晚宴/时尚活动 |
|  oversized 西装 | 宽肩、直身、中性风 | 创意行业/时尚圈 |
| 裙式西装（skirt suit） | 西装+铅笔裙/A字裙 | 保守行业/正式场合 |
| 裤式西装（pantsuit） | 西装+西裤/阔腿裤 | 现代商务/政治场合 |

- **胸省处理**：女式西装的核心技术——**公主线（princess seam）vs 腋下省（bust dart）**：
  - 公主线：从肩到摆的纵向分割线——**更贴合大胸型，但工艺复杂**；
  - 腋下省：简洁但大胸型易显紧绷——**定制店需按体型选择**；
- **腰臀差**：女性腰臀差 20-30cm（男性 10-15cm）——**女式西装后中缝必须开衩或加省**；
- **肩部**：女式垫肩比男式薄 30-50%——**"权力垫肩"是 1980s 复古风，现代主流是"自然肩"**。

## 二、面料与色彩

- **面料**：与男装共享精纺羊毛（Super 100-130s）——**但女式更重纹理变化**（人字纹/千鸟格/细条纹接受度高于男装）；
- **色彩**：突破男装黑灰蓝——**酒红/墨绿/燕麦色/雾霾蓝是女式正装增长点**；
- **创新**：弹力羊毛（2% 氨纶）——**女性对舒适度的要求高于男性**（见 `fabric/performance-wool-fabrics.md`）。

## 三、生产要点

- **版型难度**：女式西装版型库需覆盖 A/B/C/D 杯——**同一尺码不同胸型需不同版型**；
- **里布**：女式西装里布颜色可浅于面料（米色/香槟色）——**男装里布必须深色**；
- **扣子**：女式西装扣子可装饰性（珍珠扣/金属扣）——**男装扣子必须功能性**；
- **裙裤组合**：女式正装下单常为"西装+西裤+铅笔裙"三件套——**排料需考虑三件套的色差控制**。

## 四、市场与客户

- **品牌客户**：Theory/Reiss/Club Monaco 女式正装线——**"7 天衣橱"概念（周一至周日不同搭配）**；
- **定制市场**：女性高管定制增长 25%/年——**但女性定制店极少，是蓝海**；
- **团定市场**：律所/咨询/金融女合伙人制服——**裙装/裤装双选项是硬性要求**；
- **尺码痛点**：女装尺码标准混乱（美码/欧码/亚码）——**定制是解决尺码焦虑的终极方案**。
