# 厨房纺织品生产（Kitchen Textiles: 围裙/烤箱手套/茶巾）

厨房纺织是家纺中的"小件高频"品类：围裙（apron）、烤箱手套（oven mitt）、隔热垫（pot holder）、茶巾（tea towel）、厨房擦手巾套装。美国商超（Walmart/Target）厨房巾套装年采购量巨大，促销品渠道（印 logo 围裙）是另一稳定盘。生产门槛低但**套装化组货+耐洗耐污整理+食品邻近合规**是接单分水岭。

## 一、产品线与材料

| 产品 | 面料 | 功能层 | 渠道特征 |
|:---|:---|:---|:---|
| 围裙（bib/waist） | 涤棉 65/35 斜纹/帆布（见 `fabric/canvas-oxford-fabrics.md`） | 防泼水/三防整理 | 促销品印字+餐饮工服 |
| 烤箱手套 | 表布棉/涤棉印花 | 厚棉针棉/芳纶毡/镀铝膜复合 | 与隔热垫成套销售 |
| 隔热垫（pot holder） | 同手套 | 同手套（方形 7-8 英寸） | 套装挂卡 |
| 茶巾（tea towel） | 全棉平布/华夫格/亚麻混纺 | 无（吸水优先） | 印花/绣花礼品线 |
| 厨房擦手巾 | 棉毛巾布/超细纤维 | 挂袢设计 | 商超 3-6 条装 |

- **烤箱手套隔热结构**：表布+绗缝棉层（200-400g 针棉）+厚毛圈/芳纶毡内衬——高端线用**芳纶 1313 毡**（耐 300°C+，成本翻 3 倍）或硅胶+棉复合；
- **茶巾核心指标**：吸水率+不掉毛（全棉精梳/华夫格组织——与 `garments/towels-bath-textiles.md` 同源逻辑）；亚麻茶巾是欧洲高端线（吸湿快干+越洗越软）。

## 二、生产工艺要点

- **绗缝**：烤箱手套/隔热垫绗缝格子（1-1.5 英寸方格——固定棉层防洗涤结团）；绗缝距边距一致是验货点；
- **硅胶印花防滑**：手套掌心硅胶点/条纹（耐温 230°C 级——普通硅胶高温发粘）；
- **包边 vs 滚边**：围裙滚边（bias tape）斜裁 45°——转角不起扭；茶巾密拷边或折边车缝；
- **挂袢**：烤箱手套/隔热垫挂袢（织带或本布——承重与耐洗牢度，见 `fabric/webbing-narrow-fabrics.md`）；
- **印花**：促销围裙丝印（色牢度要求低→成本优先）；商超茶巾热转印/活性数码（见 `garments/printing-embroidery.md`）。

## 三、合规要点

- **隔热性能宣称纪律**："heat resistant to 200°C/400°F"宣称需实测支撑（无统一强制标准，但虚假宣传是亚马逊下架/索赔高发区——表述用"up to"并附测试报告）；
- **食品邻近**：厨房纺织不属食品接触材料（非 FDA/LFGB 范围），但**偶氮/甲醛/邻苯**常规管控（见 `trade-compliance/california-prop65.md`）；印花围裙给儿童烘焙线→按婴童化学品标准收紧；
- **阻燃宣称**：普通厨房纺织**不得宣称阻燃/防火**（"flame resistant"是 FR 整理术语，滥用=误导）；烤箱手套用"heat resistant"而非"fireproof"；
- **阻燃特例**：欧洲部分客户要求茶巾 EN 1102（窗帘阻燃逻辑不适用）——接单时确认测试条款写进合同（见 `trade-process/trade-contract-terms.md`）。

## 四、渠道与运营

- **商超套装**：美国厨房巾 3-5 件套（手套+垫+茶巾+擦手巾）挂卡装——**组货能力**（不同面料/印花配套+统一挂卡条码）比单品报价更重要；
- **促销品渠道**：印 logo 围裙/烤箱手套（银行/食品品牌赠品——见 `customers-market/promotional-products-channel.md`）——帆布围裙 $1-4 区间，交期敏感；
- **亚马逊**：茶巾/围裙差评关键词——shrinks（缩水）/thin（太薄）/color fades（褪色）→ 反向管控缩水率（预缩 ≤3%）与克重不虚标；
- **B2B 餐饮线**：餐饮围裙/工服走制服经销商（与 `garments/chef-uniforms-production.md` 渠道协同）。

## 五、接单报价

- **报价拆项**：面料（克重）+功能层（针棉/芳纶）+印花+人工——烤箱手套功能层占成本 40%+，芳纶报价单列；
- **MOQ**：印花围裙现货面料 1000-3000 条；定织茶巾 5000+；
- **旺季**：Q3-Q4（圣诞烘焙季+促销品年末预算消化）——排产见 `trade-process/annual-sourcing-calendar.md`。
