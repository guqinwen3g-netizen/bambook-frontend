# 裤装品类生产专题（Pants & Trousers Production）

裤装是"**下半身版型科学**"：裆部结构（crotch）是裤装舒适与外观的核心，腰头工艺是品质焦点。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 西裤（dress trousers） | 精纺羊毛/仿毛、腰袢/裤线（见 `garments/suits-tailoring-production.md`） |
| 休闲裤（chinos） | 棉质斜纹（卡其裤——卡其布是品类母面料） |
| 牛仔裤 | 见 `garments/denim-jeans-production.md` |
| 运动裤 | 针织（卫衣布/罗马布）、松紧腰（见 `garments/activewear-production.md`） |
| 工装裤（cargo） | 多袋/耐磨斜纹 |
| 女式裤装 | 阔腿裤/烟管裤/legging（版型多样） |
| 短裤 | 夏季品类 |

## 二、裤装版型核心：裆部结构

- **裆深（rise）**：前裆/后裆长度——高腰（high-rise）/中腰/低腰版型区分；
- **裆部合体**：卡裆（裆深不足）/吊裆（裆深过大）——版型第一投诉点；
- **后裆弧度**：后浪（back rise curve）决定臀部包裹（女裤尤其关键）；
- **横裆/大腿围**：大腿围放量（蹲下不紧绷）。

### 关键规格（POM）
腰围（waist）/臀围（hip）/前裆/后裆/大腿围（thigh）/膝围/脚口（leg opening）/外长（outseam）/内长（inseam）——裤装 POM 是成衣中最多的（见 `garments/pattern-grading-sizing.md`）。

## 三、核心工艺

### 腰头（waistband）——品质焦点
| 工艺 | 说明 |
|:---|:---|
| 西裤腰头 | 腰衬+腰里（防滑腰里带——衬衫防滑出） |
| 松紧腰 | 松紧带穿入/车缝（运动裤） |
| 抽绳腰 | 绳孔（鸡眼）+抽绳 |
| 女裤净腰 | 贴边净腰（无腰袢的简洁） |

### 关键工序
- **门襟拉链**：拉链平服不起拱（J 型弧线工艺——男装门襟第一技术点）；
- **后袋**：西裤双开线袋（welt pocket）/牛仔裤贴袋；
- **侧缝**：裤线（crease——西裤烫迹线挺直）；
- **脚口**：卷边/毛边（牛仔裤）/罗纹收口（运动裤）。

## 四、常见质量问题

| 问题 | 原因 |
|:---|:---|
| 门襟起拱 | 拉链预缩不足/弧线工艺差 |
| 扭腿 | 面料纬斜（斜纹布——排版拉斜控制） |
| 卡裆 | 裆深不足（版型） |
| 腰头波浪 | 腰衬与面料缩率不匹配 |
| 袋口豁开 | 袋口加固（套结）缺失 |

## 五、订单与生产

- **西裤**：精纺面料+归拔工艺（见 `garments/suits-tailoring-production.md`）——高端裤装；
- **休闲裤**：棉斜纹（卡其/弹力斜纹）——常年翻单基础款；
- **女式阔腿裤**：垂感面料（粘胶/天丝）——版型飘逸度靠面料；
- **产业带**：广东（牛仔/休闲）、浙江（女裤——杭州/株洲女裤集群）、山东（西裤）。

## 六、检验要点

- **尺寸**：腰围/臀围/内长公差（腰围 ±1cm）；
- **对称**：左右裤腿对称（长短腿——裁剪排料问题）；
- **拉链**：拉合顺畅、自锁（不下滑）；
- **裤线**：西裤烫迹线挺直（不偏不弯）。
