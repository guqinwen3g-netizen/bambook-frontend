# 户外功能服生产专题（Outdoor Functional Wear Production）

户外功能服是"**面料科技 + 工艺壁垒**"双高品类：防水透湿膜、接缝压胶是核心门槛——普通服装厂无法直接转产。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 冲锋衣/硬壳（hardshell） | 防水透湿外壳（暴雨级防护）——登山/徒步核心单品 |
| 软壳（softshell） | 防风+微防泼水+弹力（透气优先——动态保暖） |
| 滑雪服 | 防水+保暖+雪裙/雪卡袋（专项设计） |
| 抓绒衣（fleece） | 中间保暖层（Polartec——见 `fabric/fleece-terry-fabrics.md`） |
| 羽绒服 | 保暖层（见 `fabric/fibers-and-materials.md` 羽绒填充） |
| 速干衣裤 | 吸湿排汗（登山裤弹力+防泼水） |

## 二、核心科技：防水透湿

### 1. 防水透湿膜
- **ePTFE 膜**：Gore-Tex（膨体聚四氟乙烯——微孔比水滴小 2 万倍、比水分子大 700 倍）——行业标杆（授权制）；
- **PU/TPU 膜**：东丽 Dermizax/国产膜（性价比路线——透湿略低）；
- **贴合结构**：3L（面料+膜+里布三层贴合——专业级）/2.5L（面料+膜+印花保护层——轻量）/2L（面料+膜+独立里布——休闲）。

### 2. 关键指标
- **耐水压（mmH₂O）**：5,000（防小雨）/10,000（中雨）/20,000+（暴雨级——专业冲锋衣）；
- **透湿量（MVTR g/m²/24h）**：5,000（入门）/10,000（主流）/20,000+（高强度运动）；
- **测试标准**：JIS L1092 / AATCC 127（耐水压）、JIS L1099（透湿——见 `trade-compliance/testing-standards.md`）。

## 三、工艺壁垒

### 1. 接缝压胶（seam taping）
- **原理**：车缝针孔漏水——接缝处热压防水胶条密封；
- **全压胶 vs 半压胶**：全压胶（所有接缝——专业级）/半压胶（主要接缝——入门款）；
- **工艺参数**：压胶机温度/压力/速度（胶条与面料匹配——剥离强度测试）；
- **胶条**：三层胶条（3L）/两层胶条——宽窄规格（13mm/20mm）。

### 2. 配件专项
- **防水拉链**：YKK AquaGuard（齿面覆膜防水——主拉链/口袋拉链）；
- **DWR 防泼水**：面料表面耐久防泼水涂层（水珠滚落——洗后衰减需补喷）；
- **无缝工艺**：激光切割+热压贴合口袋（减少车缝针孔）。

### 3. 帽兜与调节系统
- **三维帽兜**：头盔兼容（登山款）+多向调节（单手抽绳）；
- **防风裙/袖口**：雪裙（滑雪服）/魔术贴袖口+拇指扣。

## 四、品质检测

- **耐水压测试**：成品抽检（接缝处是薄弱点）；
- **雨淋测试**：整衣喷淋（模拟暴雨——内部干燥判定）;
- **透湿测试**：穿着闷热感的决定指标；
- **压胶剥离强度**：洗后胶条不脱落（洗 5 次后复测）。

## 五、订单与品牌格局

- **品牌梯队**：始祖鸟/北面/巴塔哥尼亚（高端——Gore 授权+东南亚产）/哥伦比亚/迪卡侬（大众——中国主产）；
- **Gore 授权制**：Gore-Tex 产品必须戈尔认证工厂生产（验厂+设备+培训——门槛即护城河）;
- **国产替代**：国产膜+自主品牌（凯乐石/探路者——性价比户外崛起）。

## 六、产业带

- **福建**：泉州/厦门（户外运动集群——迪卡侬供应链）;
- **浙江**：三门（"中国冲锋衣之乡"——电商白牌集中）;
- **江苏**：常熟/张家港（功能性面料+成衣一体）。

## 七、风险提示

- **侵权风险**：Gore-Tex 商标（未授权禁用"GORE"字样——吊牌合规）;
- **夸大宣传**：耐水压虚标（电商投诉高发——实测报告备查）；
- **交期**：压胶工艺效率低（比普通外套慢 50%+——报价工时系数）。
