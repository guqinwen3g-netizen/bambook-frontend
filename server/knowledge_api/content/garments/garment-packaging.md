# 服装包装与装箱（Garment Packing & Packaging）

包装（packing）是成衣订单的最后一道工序，也是客诉高发区（混码、短装、湿损多源于此）。包装指示（packing instruction）必须在产前会确认并写入订单资料。

## 一、包装层级

```
单件包装 → 内包装（中包）→ 外箱（carton）→ 托盘/集装箱
polybag      inner box        export carton    pallet/container
```

### 1. 单件包装
- **胶袋（polybag）**：PE/PP 材质，常见厚度 0.03-0.06mm。
  - **强制要求**：开口周长 ≥ 一定尺寸（通常对应 7 英寸以上开口）需打**透气孔**并印**窒息警告语**（"WARNING: To avoid danger of suffocation, keep this bag away from babies and children..."）——美欧强制。
  - 环保趋势：再生 PE（GRS 认证）、可降解袋（欧盟客户要求渐多）。
- **防潮纸/拷贝纸（tissue paper）**：白色/浅色衣物防污，正装衬衫标配。
- **衬板/卡纸（collar board/butterfly）**：衬衫领口定型（collar stand + butterfly + pins 或 clips）。

### 2. 折叠与定型
- **平包装（flat pack）**：折叠入袋，T 恤/衬衫/裤装常规。
- **挂装（hanging garment / GOH）**：西装、大衣、连衣裙用衣架+挂衣箱（GOH container）运输，免熨烫但运费高 30-50%。
- **衣架**：客户常指定衣架供应商（如 VICS 标准衣架——美国零售协会标准）。

### 3. 中包与装箱
- 常见装箱规格：12/24/36 件一胶袋中包，或直接入外箱。
- **混码装箱（assorted pack）** vs **单码装箱（solid pack）**：零售客户多要求按门店配比混装（ratio pack，如 S:M:L = 1:2:1）。
- **单箱毛重**：通常 ≤ 15-20kg（欧美人工搬运法规）；单箱尺寸匹配托盘与集装箱模数。

## 二、唛头（Shipping Marks）

外箱印刷/标签信息，按客户指示书执行：

```
主唛（front mark）:           侧唛（side mark）:
客户 logo / 名称              品名 / 款号 (style no.)
PO 号                         颜色 / 尺码 (color/size)
目的港 (destination)          数量 (qty)
箱号 (C/NO.: 1-UP)            毛净重 (G.W./N.W.)
                              尺寸 (meas.)
```

- **箱号格式**：C/NO.: 1-100 表示共 100 箱之第 1 箱，连号不得跳号。
- 亚马逊 FBA 客户需贴 FBA 箱唛标签（FNSKU + shipment label），规则极严格。

## 三、条码与吊牌

- **吊牌（hangtag）**：品牌、价格、成分、条码（UPC/EAN-13）；北美零售必须 UPC，欧洲 EAN。
- **价格标签**：RSP（retail selling price）按客户格式，贴错价格属重大客诉。
- **RFID**：大型零售商（Zara/Walmart/Decathlon）渐成标配，单件级追踪。

## 四、装箱质量控制

1. **配比核对**：装箱前按装箱单（packing list）核对每箱色码数量，混码错误是 AQL 验货致命项。
2. **抽箱复秤**：抽 5-10% 外箱复秤毛重，推算总件数防短装。
3. **箱质要求**：出口纸箱五层瓦楞（double wall），跌落测试；客户常指定纸箱供应商或边压强度（ECT）。
4. **防潮措施**：箱内放干燥剂（desiccant，硅胶/蒙脱石），冬季南方装柜走北欧/北美航线的"集装箱雨"（container rain）防护；必要用集装箱干燥剂挂条。
5. **装箱照片**：每柜拍装箱过程与铅封（seal）照片，客诉/保险索赔证据。

## 五、特殊包装要求

- **免熨包装（crease-free）**：裤装夹板定型、衬衫全衬包装。
- **真空压缩（vacuum pack）**：羽绒服/棉服压缩体积省运费（40HQ 可多装 30-50%），到港后回弹。
- **金属探测**：装箱前整件过检针机（日本订单强制），装箱后抽查。
- **托盘化（palletized）**：美国大客户常要求托盘运输，托盘需 ISPM-15 熏蒸标识（木质）或用免熏蒸胶合板/塑料托盘。

## 六、成本与报价

- 包装成本占 FOB 价 2-5%：胶袋 + 纸箱 + 辅料 + 人工。
- 挂装成本显著高于平装（运费 +30-50%），报价需区分报价基准。
- 客户包装变更（如临时改混码）会产生翻箱费，需及时报价确认。
