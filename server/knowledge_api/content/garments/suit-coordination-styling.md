# 西装整体搭配体系（Suit Coordination & Styling: 衬衫/领带/鞋履/四季搭配方案）

搭配是定制店与高端零售的"**连带销售引擎**"：一套西装客户的真实需求是"明天见客户穿什么"的完整答案。衬衫见 `garments/dress-shirt-production.md`，配饰见 `garments/luxury-accessories-system.md`，鞋履见 `garments/dress-shoes-footwear.md`，领带见 `garments/neckties-mens-accessories.md`——本文件聚焦**整体搭配的规则体系与销售应用**。

## 一、搭配三大铁律

1. **正式度对齐**：西装/衬衫/鞋履的正式度必须同档——**礼服西装配牛津，单西配德比/乐福，错位即违和**；
2. **三色原则**：全身主色 ≤3 种（西装/衬衫/领带各占其一）——**口袋巾/袜子是点缀色而非主色**；
3. **质感同档**：Super 120s 西装配涤纶衬衫=档次塌方——**搭配的短板决定整体观感**。

## 二、核心单品搭配矩阵

### 衬衫 × 西装
| 西装 | 衬衫首选 | 衬衫次选 | 禁忌 |
|:---|:---|:---|:---|
| 藏青西装 | 白色 | 浅蓝 | 深色衬衫（舞台感） |
| 炭灰西装 | 白色/浅蓝 | 淡粉 | 灰色（顺色沉闷） |
| 中灰西装 | 白色 | 浅蓝/细条纹 | — |
| 粗花呢单西 | 牛津纺/浅蓝 | 格纹（图案撞图案需谨慎） | 正式法式衬衫 |
| 塔士多 | 翼领/风琴褶礼服衬衫 | — | 一切彩色 |

- **领型匹配**：宽驳头西装配温莎领——**窄驳头配窄领，比例协调是原则**；
- **法式袖口**：袖扣配宽驳头双排扣——**细节正式度对齐**。

### 领带 × 衬衫 × 西装
- **图案层级**：三件中只允许两件有图案——**西装格纹+衬衫条纹+领带领带素色=正确；三者皆花=灾难**；
- **宽度匹配**：领带宽度 ≈ 驳头宽度（8cm 驳头配 7.5-8cm 领带）；
- **材质季节**：真丝领带四季通用；针织领带/羊毛领带秋冬；亚麻领带夏季专属；
- **结型**：温莎结（宽领）/半温莎（标准）/四手结（窄领休闲）——**结的大小与领型开口匹配**。

### 鞋履 × 袜
- 搭配矩阵见 `garments/dress-shoes-footwear.md`——**皮带与皮鞋同色系**；
- **袜**：深色西裤配深色长袜；**白袜=运动场景，正装绝对禁忌**。

## 三、四季搭配方案（定制店的销售剧本）

### 春季（3-5 月）
- 中灰/浅灰精纺西装+白衬衫+真丝领带；
- 单西：浅蓝格纹+米色裤——**春季婚礼季的搭配推荐主场**。

### 夏季（6-8 月）
- Fresco/亚麻西装（浅灰/米色）+纯棉/亚麻衬衫——**不系领带可接受（商务休闲场景）**；
- 无里/半里结构+乐福鞋——**夏季的"减配美学"**。

### 秋季（9-11 月）
- 法兰绒/人字纹西装+浅蓝衬衫+羊毛领带；
- 叠穿起步：马甲加入三件套——**秋季是马甲销售的黄金窗口**。

### 冬季（12-2 月）
- 深色系西装+Chesterfield/羊绒大衣；
- 围巾/皮手套的配饰连带——**大衣+围巾组合销售的客单提升 40-60%**。

## 四、场景搭配方案（销售话术脚本）

| 场景 | 方案 | 关键话术 |
|:---|:---|:---|
| 面试 | 藏青两粒扣+白衬衫+保守领带 | "让面试官记住你而非衣服" |
| 商务谈判 | 炭灰三件套+温莎领 | "三件套的气场是谈判筹码" |
| 婚礼新郎 | 塔士多/藏青三件套 | "婚礼后仍是你的战袍" |
| 晚宴/颁奖 | 塔士多+腰封 | "黑领结规则 200 年未变" |
| 日常办公 | 中灰西装+浅蓝衬衫 | "一周五天的胶囊衣橱" |
| 商务休闲周五 | 单西+深色牛仔/卡其裤 | "放松但不随便" |

## 五、连带销售运营

- **"全案销售"流程**：西装确认后自然延伸——**"配什么衬衫"的提问时机在试身环节**；
- **搭配手册**：为每位客户生成"个人搭配卡"（已购单品的 5-8 种组合）——**售后增值服务+复购引导**；
- **连带率 KPI**：高端定制店连带率目标 ≥1.8（每单平均 1.8 件附加品）；
- **胶囊衣橱概念销售**：3 套西装+6 件衬衫+3 条领带的"30 天不重样"方案——**客单价 3-5 倍的打包逻辑**。
