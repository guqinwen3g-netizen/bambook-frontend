# 印花与绣花工艺（Printing & Embroidery）

印花（printing）与绣花（embroidery）是成衣图案装饰的两大工艺，直接影响单价、起订量、交期与耐洗性能。选错工艺或报价漏项是常见亏损点。

## 一、印花工艺

### 1. 丝网印花（Screen Printing）
- 成衣裁片印花最主流工艺，一色一网版。
- **水浆（water-based）**：手感软、透气，适合浅色布；深色布遮盖力差。
- **胶浆（plastisol）**：遮盖力强、色彩鲜艳、略有胶感，深色布常用。
- **特殊浆料**：发泡（puff）、拔染（discharge）、夜光、反光、植绒转印。
- **成本结构**：版费（每色一版，约 50-150 元/版）+ 印花费（按色数×件数）。多色图案小批量成本高。

### 2. 数码直喷（DTG, Direct-to-Garment）
- 类似打印机直喷成衣，无需制版，彩色照片级图案。
- 适合小批量、多色、渐变图案；深色布需白墨打底（成本高、手感略硬）。
- 单价高于丝印，但无版费；起订量 1 件起。

### 3. 热转印（Heat Transfer）
- 图案先印在转印纸/膜上，再热压到衣服。
- **烫画（transfer print）**：小批量定制、球衣号码。
- **热升华（sublimation）**：仅适用涤纶，图案渗入纤维、无手感、不褪色，运动服满版印首选。
- 缺点：烫画耐洗性一般，多次水洗可能开裂。

### 4. 匹布印花（Fabric Printing）
- 面料阶段印花再裁剪：圆网（rotary，大批量）、平网（flat screen，精细花型）、数码印花（digital，小批量多花型）。
- 裁片印花 vs 匹布印花：定位花（placement print）必须裁片印；循环花（allover/repeat print）匹布印更高效。

## 二、绣花工艺

### 1. 平绣（Flat Embroidery）
- 最基础绣法，logo/文字常用。按针数计价（stitch count，如 5000 针）。
- 需先做**绣花版（digitizing/打版）**：把图案转成针迹文件（DST/EMB），版费一次性。

### 2. 贴布绣（Appliqué）
- 剪形布料贴缝 + 包边绣，省针数、立体感强，字母/大块图案常用。

### 3. 特种绣
- **毛巾绣（chenille）**：绒面立体，校服字母章。
- **珠片绣（sequin）**：女装/舞台装，注意珠片牢度与扎肤问题。
- **立体绣（3D puff）**：帽类 logo 常用，海绵垫底凸起效果。
- **水溶绣/镂空绣**：蕾丝效果，女装。

### 4. 章仔/织唛替代
- **绣花章（embroidered patch）**：独立绣好再车缝/热熔胶烫上，可库存通用。
- **织唛章（woven patch/label）**：织出来的图案，细密小字比绣花更清晰。

## 三、工艺选型决策

| 需求 | 推荐工艺 |
|:---|:---|
| 大货 T 恤 logo（1-3 色） | 丝网印（胶浆/水浆） |
| 彩色照片图案小批量 | DTG 数码直喷 |
| 全涤运动服满版图案 | 热升华 |
| 帽子/Polo 衫 logo | 平绣/立体绣 |
| 大块字母图案 | 贴布绣 |
| 高耐洗要求（工装） | 绣花 > 丝印 > 烫画 |

## 四、报价与生产要点

1. **印花按色数计价**：图案分色（color separation）决定版数，接稿时先要矢量图（AI/PDF）。
2. **绣花按针数计价**：面积不是唯一因素，密度与换色次数影响针数；先打版报价。
3. **打样确认**：印花确认手感/牢度/对位；绣花确认线色（按绣线色卡如 Madeira 色号）、针迹密度。
4. **耐洗测试**：印花做水洗牢度（AATCC 61）与摩擦牢度；绣花做洗后外观（皱缩/脱线）。
5. **位置公差**：裁片印花定位公差通常 ±1cm，大货前确认定位图（placement guide）。
6. **深色布工艺**：深布印浅色需打底（underbase），费用增加；绣花深布注意底衬（backing）颜色。

## 五、常见质量问题

- 印花：开裂（cracking）、掉色、手感硬、对位不准、渗色（bleeding）。
- 绣花：断线、跳针、皱布（puckering，底衬不足）、线色差、绣后洗水变形。
- 预防：产前样（PP sample）必须含完整印花/绣花工艺，客户签样后大货照做。
