# 潜水料制品（Neoprene Products: 杯套 Koozie/午餐包/电脑内胆/材料贴合）

潜水料（氯丁橡胶发泡片贴合针织布）制品是"**材料特性变现**"的典型：保温/缓冲/防水/可印刷四大特性，孵化出杯套（koozie——美国促销品之王）、午餐包、电脑内胆包等耐用品类。与潜水服成衣（见 `garments/wetsuit-diving-suits-production.md`）同属材料族，但制品逻辑是**裁片+贴合+印刷**的轻工艺。本文件梳理材料分层、产品谱系与促销品渠道对接。

## 一、材料基础

| 层级 | 说明 | 价差 |
|:---|:---|:---|
| 胶种 | SBR（丁苯，最低价/占 80%）→ SCR（混合）→ CR（纯氯丁，高性能） | SBR:CR ≈ 1:2.5 |
| 厚度 | 1mm（杯套）/2-3mm（包袋）/5mm+（护具） | 按 mm 计价 |
| 贴面 | T 布（涤纶，印花白度好）/N 布（尼龙，手感好）/莱卡（高弹）/OK 布（粘扣） | N 布贵 15% |

- **发泡倍率决定手感与成本**：高发泡轻软便宜（杯套用）、低发泡密实挺括（包袋用）——**克重/密度写入采购规格**；
- **气味命门**：SBR 硫化体系残留气味（橡胶味）——**欧美食品接触类（午餐包/杯套）要求低气味+邻苯/PAHs 检测**（检测见 `trade-compliance/testing-lab-selection.md`）；
- **复合牢度**：贴合脱层（泡水/暴晒后起泡）是头号客诉——剥离强度 ≥2.5N/cm 写入验收。

## 二、产品谱系与工艺

| 产品 | 结构要点 | 渠道 |
|:---|:---|:---|
| 杯套（koozie） | 单片对折缝合/胶粘底 | **美国促销品 ASI 渠道之王**（啤酒/汽水品牌赠品年框） |
| 午餐包 | 3-5mm 保温层+拉链+提手 | 亚马逊/商超 |
| 电脑内胆包 | 2-3mm 缓冲+防泼水拉链 | 3C 配件渠道 |
| 运动护具 | OK 布贴面+魔术贴绑带 | 见 `garments/sports-protective-gear-production.md` |
| 红酒瓶套/保温袋 | 单层/双层 | 酒类促销 |

- **工艺链**：裁断（刀模）→**盲缝（blind stitch，针不透胶层防水）或平车**→印刷（丝印 1-4 色/热转印全彩）→质检——工序少于成衣，小厂 5-10 人可开线；
- **印刷是增值主战场**：热转印全彩 logo 比丝印溢价 30%——**潜水料表面受热 180°C 会变形，转印温度窗口 150-160°C 是工艺秘密**；
- **包边 vs 毛边**：杯套毛边款（省钱）vs 包边款（卖相好）——报价差 15%，促销品渠道常选毛边。

## 三、外贸接单要点

- **ASI/PPAI 促销品渠道**：美国促销品分销商（渠道逻辑见 `customers-market/promotional-products-channel.md`）——**年框+快速翻单**（品牌活动死交期），杯套 MOQ 500-1000 只、单价 0.3-0.8 美元；
- **报价结构**：料（按片计价：厚度×幅宽）+工+印——**料占 60%+，胶价随原油波动**（年框设调价条款）；
- **旺季波段**：美国夏季（啤酒季）+圣诞赠品季——3-5 月是接单高峰；
- **合规**：加州 65 提案（邻苯）+ 部分州 PFAS 限制（防泼水整理，见 `trade-compliance/pfas-restriction-fluorine-free.md`）；
- **差异化**：可降解/再生 CR（回收潜水服再造——Patagonia 案例）、迷彩/大理石纹印花基材现货化（缩短交期）；
- **物流**：泡货——杯套可压缩打包（橡胶回弹好不怕压），包袋类按体积重报价（逻辑见 `garments/reusable-shopping-bags-production.md`）。
