# 绣章织唛与装饰标（Embroidered Patches, Woven Labels & Badges）

绣章与织唛是品牌识别的"最小单元"：军警臂章、俱乐部绣章、服装领标、logo 布贴。跨境电商（Etsy/亚马逊）与潮牌催生了小单快反市场；军警/企业制服配件则是稳定批量单。产业带：广东东莞/浙江温州/福建石狮。

## 一、产品谱系

| 品类 | 工艺 | 特征 | 应用 |
|:---|:---|:---|:---|
| 绣章（embroidery patch） | 电脑绣花+锁边 | 立体感强、色彩丰富 | 帽徽/臂章/夹克装饰 |
| 织唛章（woven patch） | 织唛机织成 | 细节精细（小字清晰）、薄 | 队徽/精细 logo |
| 印刷章 | 热升华/丝印+激光切 | 渐变照片级 | 复杂图案 |
| PVC 胶章 | 模具滴胶 | 防水立体 | 户外装备/战术（见 `garments/tactical-gear-production.md`） |
| 皮标 | 真皮/PU 压印 | 质感 | 牛仔裤腰牌 |
| 织唛领标 | 织唛机 | 耐洗、薄软 | 服装领标/侧标 |

- **背胶方式**：车缝（最牢）/热熔胶（熨斗热压，熨烫牢度是投诉点）/魔术贴（可换——战术与队服场景）/自粘（临时）；
- **锁边**：merrow 锁边（粗线包边——经典绣章外观）vs 激光热切（无毛边、异形自由）vs 手切边（复古）。

## 二、绣章生产工艺

1. **制版（打带）**：客户图稿→绣花制版软件（Wilcom）生成针迹文件——**制版质量决定成品档次**（针向设计影响光泽与立体度）；版费 50-200 元/款；
2. **绣制**：田岛/百灵达绣花机——色数 9-15 色；底线/面线张力控制密度；
3. **后整**：剪线头（线头残留是低端标志）→背胶（热熔胶膜复合）→锁边/激光切→验针（断针残留，见 `suppliers/needle-control-metal-management.md`）；
4. **检验**：对稿核色（绣线色号对潘通，见 `fabric/color-management-pantone-measurement.md`）+密度检查（露底=次品）+尺寸公差 ±1mm。

- **金属线/夜光线/反光纱**：特殊线绣制参数调整（金属线断线率高——机速降 30%）。

## 三、织唛工艺要点

- **织唛机类型**：烧边机（热切边——常规）/钩边机（织入边——柔软高端）/木梭机（复古质感）；
- **密度分级**：缎面（高密度——细腻）/平面（常规）；**50D 经纱以上才织得清 5mm 以下小字**；
- **折法**：对折（领标）/三角折/挂耳折/激光切断——折法影响车缝方式；
- **色数限制**：织唛最多 8-12 色（每色一纬）——复杂渐变稿改印刷章；
- **耐洗**：织唛色牢度 4 级+（领标伴随成衣全生命周期，见 `garments/accessories-and-trims.md`）。

## 四、接单与市场

- **跨境电商小单**：Etsy 定制（社团/婚礼/宠物章）——50-100 个起订，毛利 50%+，拼快反（3-5 天交样）；
- **军警/公务**：臂章/肩章——注意**仿制执法徽章法律风险**（只做授权单位订单，留存授权文件）；
- **运动队/俱乐部**：赛季性团购——配合球衣订单（见 `garments/activewear-production.md`）；
- **品牌服装**：领标/织唛随服装单配套——服装厂通常外发专业织唛厂（供应商管理见 `suppliers/fabric-accessories-supplier-management.md`）；
- **报价要素**：尺寸+针数（绣章按千针计价）+色数+背胶+数量——**针数报价**：先估算针数（制版软件可预测）。

## 五、合规与 IP

- **图案授权**：球队/动漫/品牌 logo 章是侵权重灾区——Etsy 下架+海关查扣风险；只接有授权文件的（见 `trade-compliance/ip-brand-authorization.md`）；
- **国旗章**：部分国家法规限制国旗商业使用（同旗帜逻辑，见 `garments/flags-banners-production.md`）；
- **化学品**：热熔胶（EVA 系）与绣线 OEKO-TEX 认证——婴童服装配件必查（见 `trade-compliance/chemical-environmental-compliance.md`）。
