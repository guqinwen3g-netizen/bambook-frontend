# 布尿裤与可洗尿布系统（Cloth Diapers: 口袋尿裤/竹炭内衬/可调节按扣）

可洗布尿裤是欧美环保育儿的稳定细分：一次性纸尿裤年花费 $800-1000 vs 布尿裤全套 $300-500 用 2-3 年+二胎复用，环保叙事（每年每娃减少 1 吨填埋垃圾）+省钱逻辑双驱动。与失禁护理（成人向，见 `garments/incontinence-care-products.md`）共享吸收结构逻辑，与婴儿小件（`garments/baby-care-accessories.md`）共享客群。中国（南昌/宁波产业带）占亚马逊布尿裤供应 90%+。

## 一、产品矩阵

| 款型 | 结构 | 特征 | 价格带（零售） |
|:---|:---|:---|:---|
| 口袋尿裤（pocket diaper） | PUL 防水外层+摇粒绒/麂皮绒内层+口袋塞吸收芯 | **主流款**——吸收芯可拆调节 | $5-9/条（6 条装 $30-40） |
| 一体式（AIO） | 吸收芯缝合一体 | 最接近纸尿裤体验（老人/托儿所友好） | $10-18 |
| AI2（两片式） | 外罩+按扣式吸收芯 | 外罩复用 2-3 次——性价比款 | $8-14 |
| 预折尿布（prefold）+罩 | 棉纱预折片+防水罩 | 传统经济款（发展中国家用量大） | $2-5 |
| 训练裤（training pants） | 内裤式+少量吸收层 | 如厕训练过渡期（2-4 岁） | $8-15 |

- **调节系统**：3×3 按扣（snap）调节 S/M/L 三档（3-15kg 一码走天下=核心卖点）——按扣牢度（90N 拉力——童装安全逻辑见 `garments/childrenswear-production.md`）与树脂扣耐洗性是质量分水岭；魔术贴款（hook & loop）方便但洗后粘毛衰减；
- **吸收芯（insert）**：超细纤维（快吸但不贴肤）/竹炭（竹炭涤纶——抗菌除臭叙事）/竹棉/大麻棉（高吸收+天然溢价）——**分层组合销售**（日间 3 层/夜间 5 层加厚）。

## 二、材料与工艺要害

- **PUL 防水布**：涤纶针织布+TPU 热复合（透气防水）——**复合牢度**（洗 50 次不分层）是生命线；TPU vs PEVA（低价但耐温差）；复合工艺见 `fabric/functional-coating-lamination.md`；
- **内层贴肤面**：摇粒绒（suede cloth 导流快干）/竹炭绒——**keep-dry 触感**是复购关键；缝线走向避免渗漏通道（防水侧翼 gusset 双包边）；
- **腿口/腰口橡筋**：氨纶橡筋包边——过紧红痕/过松侧漏的版型平衡；橡筋耐氯洗（热水消毒洗涤场景）；
- **印花**：PUL 数码印花（花型是母婴类目视觉竞争力——见 `fabric/digital-printing-technology.md`）；浅色花型防渗色（吸收芯染料迁移）。

## 三、合规红线

- **美国**：CPSIA 追踪标签+小部件（按扣拉力）+铅/邻苯（见 `trade-compliance/cpsc-children-safety.md`）；**皮肤长时间接触类纺织品按一类标准管控**（OEKO-TEX 一类——见 `trade-compliance/textile-certifications.md`）；
- **宣称边界**：可宣"可洗复用/减少浪费"——**禁宣"治疗尿布疹/抗菌率 99%"**（抗菌宣称触发 EPA/FDA 边界——见 `trade-compliance/biocidal-treated-articles-bpr.md`）；
- **环保宣称**："环保/可降解"需限定说明（TPU 层不可降解——反漂绿见 `trade-compliance/green-claims-anti-greenwashing.md`）；
- **欧盟**：REACH SVHC（印花油墨/按扣镍释放——五金逻辑见 `suppliers/buttons-metal-trims-deep-dive.md`）。

## 四、市场与运营

- **渠道**：亚马逊（cloth diaper 类目中国品牌主导——ALVABABY/Mama Koala 模式）+独立站（环保母婴垂类——`customers-market/independent-site-seo.md`）+婴儿展会（Kind+Jugend）；
- **套装策略**：6 条装+2 吸收芯基础套装引流，**配件利润在后端**：加厚夜用芯/尿布喷枪（diaper sprayer）/湿袋（wet bag——与防水包工艺协同 `garments/dry-bags-waterproof-pouches.md`）/洗衣片；
- **差评热点**：渗漏（版型/吸收不足）、异味残留（洗涤指南缺失——**附详细洗涤卡**：预洗/主洗/禁柔顺剂）、按扣断、PUL 分层；
- **新兴市场**：东南亚/拉美中产环保育儿渗透（价格是欧美 60%——经济款预折+罩组合）；非洲 NGO 女童卫生项目（可洗卫生巾协同——`garments/emergency-relief-textiles.md` 集采逻辑）。
