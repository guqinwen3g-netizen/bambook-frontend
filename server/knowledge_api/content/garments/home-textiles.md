# 家纺品类专题（Home Textiles）

家纺（home textiles）与服装共享面料与缝制供应链，但规格体系、质量关注点、客户渠道均不同。床品/毛巾/窗帘是三大主力品类，面料企业可横向拓展的第二曲线。

## 一、品类与规格

### 床品（Bedding）
| 项目 | 内容 |
|:---|:---|
| 品类 | 四件套（被套+床单+枕套×2）、被芯、枕芯、床笠（fitted sheet） |
| 面料 | 全棉（40S/60S/80S/100S 高支贡缎）、天丝、水洗棉、磨毛 |
| 密度 | 200T/300T/400T/600T（thread count，每平方英寸经纬纱总数） |
| 工艺 | 印花（活性/涂料）、绣花、提花（jacquard）、色织 |
| 尺寸 | 美标 Twin/Full/Queen/King；欧标/澳标各异——按客户市场尺寸表 |

- **支数与密度营销陷阱**：标注"1000T"多为多股纱虚标，专业买家看单股真实密度。
- 缝制：被套开口（纽扣/拉链/信封式）、床单卷边、枕套飞边（flange）。

### 毛巾（Towel）
- 指标：克重（GSM，400-600 常规、700+ 加厚）、毛圈高度、吸水性、脱毛率。
- 产地：河北高阳、山东孚日（全球最大毛巾企业）。
- 断档（dobby border）/缎档/提花/绣花工艺。

### 窗帘（Curtain）
- 功能：遮光（blackout 三层梭织/涂层）、半遮光、窗纱（sheer/voile）。
- 尺寸按窗型定制：打褶倍数（1.5-2.5 倍褶）、挂钩/穿孔（grommet）/穿杆（rod pocket）。
- 阻燃窗帘（FR）：酒店工程单强制（美 NFPA 701 / 欧 EN 13773）。

## 二、质量标准与测试

| 项目 | 说明 |
|:---|:---|
| 色牢度 | 床品耐洗/耐摩擦（贴肤+高频洗涤场景） |
| 缩水率 | 床品洗后尺寸偏差 ≤ ±3-5%（影响套被合身度） |
| 起球 | 磨毛/水洗棉品类重点 |
| 甲醛/pH | OEKO-TEX 100 是欧美家纺准入标配 |
| 阻燃 | 窗帘/酒店床品工程单 |
| 填充物 | 被芯/枕芯：羽丝绒/蚕丝/羽绒——同羽绒服检测逻辑 |

## 三、市场与渠道

- **美国**：零售巨头渠道（Walmart/Target/Costco）+ 电商（亚马逊床品类目竞争激烈）；FTC 纤维标签 + 护理标签要求。
- **欧洲**：宜家（IKEA）式大客户长单模式；环保认证要求高（GOTS 有机棉床品溢价）。
- **日本**：西川等品牌的精细品质要求（全数检品）。
- **工程单（hospitality）**：酒店布草（hotel linen）——白色贡缎 60S/80S，耐工业洗涤测试，订单量大且稳定。

## 四、报价与生产要点

- **计价方式**：床品按套件（含面料用量测算：Queen 四件套约 7-8 米 × 幅宽 2.4m）；宽幅面料（2.4-3m）是家纺专用（与服装 1.45m 幅宽产线不同）。
- **印染**：宽幅活性印花是核心工艺，绍兴/南通家纺印染集群。
- **产业带**：江苏南通（叠石桥家纺城，全球最大家纺集散）、山东潍坊（孚日）、浙江绍兴。
- **MOQ**：印花床品 500-1000 套/花型；工程布草 1000 套起。
- **交期**：45-60 天（宽幅面料定制周期长）。

## 五、与服装业务的协同

- **供应链共享**：棉/涤面料、印染厂、缝制设备通用——服装厂可接床品缝制裁剪工序。
- **客户交叉**：服装品牌商扩家居线（如 Zara Home 模式），现有客户关系可延伸家纺品类。
- **注意差异**：宽幅面料产线、套件包装（PVC 袋+彩卡+提手）、尺寸体系完全不同——接单前确认设备适配性。
