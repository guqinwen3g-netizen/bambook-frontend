# 保暖内衣与自发热服装生产（Thermal Underwear Production）

保暖内衣是**冬季刚需大盘品类**（内销秋衣秋裤 + 日本 Heattech 式自发热 + 欧美 base layer）：技术卖点在**发热纤维 + 磨毛/起绒结构**，合规红线在**"自发热"宣称的检测支撑**。

## 一、品类与技术路线

| 路线 | 原理 | 代表 |
|:---|:---|:---|
| 吸湿发热纤维 | 纤维吸湿放热（丙烯酸/粘胶改性） | 日本 Heattech（东丽纤维） |
| 磨毛/抓毛 | 表面绒毛锁空气层 | 德绒（Dralon 腈纶）类面料 |
| 加绒复合 | 里层摇粒绒/不倒绒加厚 | 加厚保暖裤（东北市场） |
| 羊毛/羊绒混纺 | 天然保暖 | 中高端（见 `fabric/wool-cashmere-fabrics.md`） |
| 远红外/咖啡碳等 | 功能母粒添加 | 概念款（宣称需检测支撑） |

## 二、面料要点

- **德绒（Dralon）**：细旦腈纶双 T 型截面——蓬松保暖+磨毛手感（注意 Dralon 是拜耳注册商标，用"德绒类"表述）；
- **发热粘胶/腈纶**：吸湿发热值检测（升温 2-4℃ 实测——见 `fabric/functional-yarns.md`）；
- **成分搭配**：腈纶/粘胶 + 棉 + 氨纶（3-8% 弹力——贴身不勒）；涤纶款起静电痛点（抗静电整理）；
- **克重**：常规 180-220gsm / 加绒 280-380gsm。

## 三、生产工艺

- **磨毛/抓毛**：碳素磨毛（细腻）vs 钢丝起毛（绒量大——掉毛风险，洗后掉毛客诉高发）；
- **缝制**：四针六线拼缝（贴肤无骨感——见 `garments/sewing-and-workmanship.md`）；罗纹领口/袖口（防风收口）；
- **版型**：贴身负松量（-6 至 -10cm）但区别于塑身衣（无压力诉求——见 `garments/shapewear-production.md`）；
- **检验**：掉毛率/起球（磨毛面料起球 3-4 级瓶颈——订单注明等级）。

## 四、检测与宣称合规

| 宣称 | 支撑检测 | 标准 |
|:---|:---|:---|
| 保温 | 保温率（克罗值 clo） | GB/T 11048 |
| 吸湿发热 | 最高升温值/平均值 | GB/T 29866（吸湿发热针织内衣） |
| 抗菌 | 抑菌率 | GB/T 20944 / FZ/T 73023 |
| 远红外 | 发射率/温升 | GB/T 30127 |

- **红线**：无检测报告不做功能宣称（平台抽检+职业打假高发区——逻辑见 `trade-compliance/green-claims-anti-greenwashing.md` 宣称证据链）；
- **日本市场**：品质表示法（保温率/纤维名——见 `customers-market/jp-market.md`）。

## 五、市场与订单

- **内销**：9-12 月销售峰值（双 11/双 12——生产前置 6-8 月，见 `trade-process/annual-sourcing-calendar.md`）；渠道：电商+商超+直播；
- **日本**：便利店/优衣库体系（品质严苛——缝线/尺寸公差 0.5cm 级）；
- **欧美**：base layer（滑雪/户外内层——美利奴羊毛混纺高端线，见 `garments/outdoor-functional-wear-production.md`）；
- **订单特点**：SKU 多（男女×颜色×厚度）、单款量大、季节性强（压一季库存风险——见 `fabric/fabric-inventory-stock-strategy.md` 反面教材）。

## 六、成本与风险

- **面料占 55-65%**（发热纤维溢价 20-40%——与纱厂锁价）；
- **风险**：季节误判（暖冬=库存灾难）；功能宣称处罚（无检测报告的"自发热"标题）；起球/掉毛差评（磨毛工艺取舍——绒感与耐久平衡）。
