# 种植袋与园艺布艺容器生产（Grow Bags & Fabric Planters: 无纺布种植容器）

种植袋是"**家庭园艺风潮+电商轻小件**"催生的品类：无纺布/毛毡材质替代塑料花盆，透气控根（air pruning）是核心卖点。疫情后欧美家庭园艺留存率高，土豆袋、番茄袋、垂直墙挂袋成为亚马逊常青款。缝制逻辑与无纺布购物袋相通（见 `garments/reusable-shopping-bags-production.md`），但**户外耐候与荷载要求是增量门槛**。

## 一、产品矩阵

| 品类 | 材质 | 规格 | 特征 |
|:---|:---|:---|:---|
| 标准种植袋 | 无纺布 260-300gsm / 毛毡 300-400gsm | 1-400 加仑（**1/3/5/7/10/15 gal 走量**） | 双提手、黑色为主 |
| 土豆/根茎种植袋 | 无纺布+PE 覆膜内衬 | 7-10 gal+**翻盖观察窗** | 侧开收获口是卖点 |
| 草莓悬挂袋 | 无纺布筒+多侧孔 | 8-10 孔吊挂 | 悬挂链条承重 |
| 垂直墙挂袋 | 毛毡多袋连体 | 4/7/9/36 袋口袋墙 | 阳台绿化/香草墙 |
| 抬高种植床（fabric raised bed） | 厚毛毡+框架/无框 | 矩形分区格 | 庭院菜园 |
| 蘑菇种植袋 | PP 耐高温无纺布 | **耐 121℃ 高温灭菌** | 菌菇种植 B2B |
| 树木移栽袋（root control bag） | 高强度无纺布 | 大规格 45-400 gal | 苗圃 B2B——**控根防盘根** |

- **控根原理**：透气壁使根系接触空气自然修剪（air pruning）防盘根——对比塑料盆的核心营销点；
- **克重与寿命**：260gsm 无纺布户外寿命 1-2 季；**加厚毛毡 3-5 季**——克重虚标（报 300 实 230）是品类痛点；
- **颜色**：黑色主流（吸热促根）、绿色/驼色装饰款；**浅色夏季降温**差异化。

## 二、材料与工艺要点

- **无纺布选型**：PP 纺粘为主——**抗 UV 母粒添加量决定户外寿命**（不加抗 UV 一季脆化）；无纺布基材见 `fabric/nonwoven-fabrics.md`；
- **毛毡（针刺）**：涤纶针刺毡 300-400gsm——保水性好于纺粘布（毛毡袋浇水量可减少）；再生涤纶毡注意**异味与重金属**（土壤接触=间接食品链，菜用袋需关注）；
- **缝制**：双针链式线迹+包边——**提手与袋身连接是承力点**（湿土 10 gal≈12-15kg）打枣加固；缝线用涤纶高强线（棉线沤烂）；
- **排水**：无纺布本体渗水——**底角加排水孔**（暴雨积水烂根）是加分设计；
- **翻盖窗工艺**：土豆袋观察窗=魔术贴+盖片——魔术贴户外老化（尼龙件 UV 脆化）是售后点；
- **蘑菇袋特殊**：PP 材质需耐高压灭菌温度——普通纺粘布 121℃ 收缩变形，需**耐温级 PP**。

## 三、市场与商业要点

- **季节脉冲**：北半球 2-5 月种植季下单（Q4-Q1 备货）；南半球（澳新）8-10 月——**跨年双窗口**；
- **渠道**：亚马逊花园类目（grow bags 关键词年搜索量稳定）、园艺中心（Home Depot 类）、苗圃 B2B（移栽袋）；
- **竞争格局**：VIVOSUN/Gardzen 等中国出海品牌占据亚马逊头部——**白牌窗口在组合装（5 件装多规格）与差异化（加厚毛毡/彩色）**；
- **B2B 增量**：苗圃控根袋替代塑料盆（环保叙事+移栽成活率）、垂直绿化工程（植物墙布袋模块）、**菌菇种植袋**（食用菌产业大宗复购）；
- **装柜**：软质可压缩——压缩打包提升装柜量（同搬家毯逻辑见 `garments/moving-blankets-furniture-pads.md`）；
- **农纺交叉**：大宗农业覆盖布/防草布见 `fabric/technical-agro-geo-textiles.md`——种植袋是其消费端延伸。

## 四、风控要点

- **抗 UV 虚标**：承诺"3 年寿命"需 UV 老化测试数据（QUV 500h 保留率）——虚标=批量差评；
- **克重/尺寸缩水**：加仑容量按土量实测——"10 gal 装不满 8 gal"是典型投诉；
- **提手断裂**：满载提吊测试（2 倍荷载 30 秒）写入 QC 流程；
- **重金属与异味**：种植食用作物款注意再生料风险——**原生 PP 声明**；
- **季节库存风险**：过季积压=资金占用——Q2 末果断清货（清货渠道见 `suppliers/garment-stock-lot-disposal.md`）；
- **专利雷区**：特定翻盖结构/悬挂系统有美外观专利——设计差异化绕开。
