# 防割手套生产（Cut-Resistant Gloves: HPPE/ANSI等级/浸胶）

防割手套是劳保手套中**技术含量与单价最高**的分支：屠宰分割、玻璃加工、钣金冲压、厨房生蚝刀（oyster shucking）场景刚需。核心材料 HPPE（超高分子量聚乙烯，Dyneema/Spectra 模式）纱线价格是涤纶 10 倍——**等级真实性**是这个行业的水深区。生产=针织内胆（手套机）+浸胶（与劳保浸胶线共线，见 `garments/gloves-production.md` 总述）。

## 一、防割等级体系（报价的前提）

| 体系 | 等级 | 测试方法 | 场景 |
|:---|:---|:---|:---|
| ANSI/ISEA 105（美） | A1-A9（200g-6000g+） | ASTM F2992 TDM 直刀 | 美国客户报价单必标 |
| EN 388:2016（欧） | 旧 ABCDE/新 TDM 值（N） | ISO 13997 | 欧盟 CE 必测 |
| 旧版 Coupe 测试 | 1-5 级 | 圆刀往复 | HPPE 材料虚高——**新版 TDM 为准** |

- **等级-场景对照**：A2-A3 装配/物流；A4-A5 玻璃/钣金/屠宰；A6+ 金属冲压/刀片作业；
- **宣称纪律**：防割（cut）≠防刺（puncture——EN 388 单独一项）≠防砍；**"防割"宣称=PPE II 类**（CE 公告机构型式检验，见 `trade-compliance/ppe-protective-clothing-compliance.md`）——无证书宣称防割出口欧盟=清关召回风险；
- **水深预警**：玻纤/钢丝混纺可低成本冲高 Coupe 等级但 TDM 现形——接单按客户指定测试方法报价，杜绝"等级达标"模糊承诺。

## 二、材料与内胆结构

- **HPPE 纱线**：13G/15G/18G 针织内胆——15G 主流（防护与灵活性平衡）；18G 精细作业（电子厂）；纱线品牌（Dyneema 授权 vs 国产 UHMWPE）价差 40%+——高端品牌指定 Dyneema 吊牌；
- **混纺增强**：HPPE+玻纤芯（性价比冲 A4-A5）/HPPE+钢丝（A6+）——**玻纤刺痒**是穿戴投诉点（包覆工艺）；钢丝内胆不可过家用洗衣机（B2B 场景无碍）；
- **芳纶线**：耐高温+防割双需求（焊接辅助——见 `garments/fr-workwear-flame-resistant.md` 材料体系）；
- **氨纶/尼龙包覆**：弹性贴合——指掌灵敏度是回购关键（工人不愿戴=安全失效）。

## 三、浸胶工艺（与劳保线共线）

| 胶种 | 特性 | 场景 |
|:---|:---|:---|
| PU 掌浸 | 薄/灵敏/干抓力 | 装配/电子（A2-A3） |
| 丁腈光面 | 耐油/耐磨 | 机修/油污（A4+） |
| 丁腈磨砂/发泡 | 湿抓力/透气 | 屠宰/水产（防滑湿抓） |
| 乳胶起皱 | 干湿抓力 | 建筑/搬运 |

- **浸胶线要点**：内胆套模→浸胶→匀胶→硫化——胶面针孔/气泡是验货缺陷（浸胶总述见 `garments/gloves-production.md`）；
- **屠宰线专项**：抗油脂丁腈+长筒款（前臂防护）；厨房生蚝手套多为人字型不锈钢网环（chainmail——另一类产线）。

## 四、认证与渠道

- **CE 认证**：EN 388:2016+EN 420（通用安全）——公告机构 Module B+C2/Module D；周期 2-3 个月，费用按型号；
- **美国**：ANSI/ISEA 105 测试报告（第三方实验室——Intertek/SGS/TÜV）即可进入工业渠道；OSHA 场景雇主采购要看报告；
- **渠道**：劳保用品经销商（Grainger/Fastenal 模式——年度框架）、安防集成商、亚马逊工业类目（B2B+DIY 双客群）、屠宰/食品厂直接集采（关注食品级——胶种符合 FDA 21 CFR 177 间接接触）；
- **验货重点**：等级测试报告批次对应+克重/尺寸公差+胶面外观；抽测 TDM 复测（客户第三方复检是常态）。

## 五、报价与接单

- **成本结构**：HPPE 纱线占 50-65%（等级越高占比越大）+浸胶 15%+人工——纱线价格联动报价有效期 30 天；
- **MOQ**：针织机台经济量 3000-5000 双/款；定色内胆 10000+；
- **利润点**：品牌吊牌授权款（Dyneema/Ansell 代工体系）>白牌冲量；复购稳定（劳保耗材按月补货）。
