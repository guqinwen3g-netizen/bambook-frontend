# 搏击装备生产（Combat Sports: 拳击手套/沙袋/护具/缠手带）

搏击装备是"**发泡防护+皮革/PU 车缝**"组合工艺的功能性体育用品：拳击/泰拳/MMA/跆拳道手套、沙袋、护具（护头/护齿/护胫/护裆）、手靶脚靶、缠手带、格斗短裤。市场以**北美家用健身+健身房渠道**为主力（Everlast、Title、Venum、RDX 主导），电商复购靠耗材（缠手带/内衬）。生产门槛在**发泡内胆配方与版型防护性**，不在缝纫难度。与运动护具（见 `garments/sports-protective-gear-production.md` 的支撑护具赛道）工艺逻辑不同——搏击装备核心是**冲击吸收**。

## 二、生产工艺要害

- **拳套内胆发泡**：一次模压成型（多层密度渐变——表层软吸震/底层硬支撑）是防护性核心；**手工塞棉款已淘汰**（塌陷位移）；内胆与外皮的**贴合零位移**（打沙袋 1 万次内胆移位=报废）；
- **拳套车缝**：手掌内侧透气网布拼接+**内缝工艺**（缝线不外露防磨手）——车缝工人需真皮缝制经验（针距/吃势，见 `fabric/leather-synthetic-leather.md` 的皮料车缝特性）；拇指连接位加固（撕裂高发点）；
- **沙袋填充**：碎布/碎皮填充的**均匀度与紧实度**（打感硬伤手/软泄力都差评）——上层 EPE 发泡筒缓冲+下层高密度填充；吊挂织带**四点受力+内衬加强板**（承重 40-60kg 摆动工况）；
- **护具模压**：EVA 冷热压成型（护胫曲面贴合小腿）——模具投入 2-5 万/款；魔术贴刺毛面**朝外设计**（防刮伤对手）；
- **格斗短裤**：缎面光泽+高开衩（踢腿无束缚）——腰头宽幅橡筋+抽绳双保险。

## 三、合规要点

- **无专门强制认证**：搏击装备属普通体育用品（非 PPE——护齿在美国按 FDA 一类器械边界，宣称"dental protection"需谨慎）；
- **欧洲 EN 13277**：武术护具系列标准（护头/护胫/拳套缓冲性能测试）——欧洲客户常要求，属自愿性但商超准入参考；
- **化学合规**：PU/PVC 革 DMF 残留+邻苯（Prop 65，见 `trade-compliance/california-prop65.md`）；真皮**六价铬**（EN ISO 17075≤3mg/kg，见 `trade-compliance/lwg-leather-certification.md` 的皮料合规链）；填充碎布禁用回收黑心棉（偶氮/异味）；
- **儿童款**：CPSIA 追踪标签+小部件（见 `trade-compliance/cpsc-children-safety.md`）——儿童拳套是亚马逊高投诉品类（内胆硬度过高伤手）；
- **品牌授权**：赛事联名/UFC 元素 IP 红线（见 `trade-compliance/ip-brand-authorization.md`）。

## 四、市场与渠道

- **北美家用健身**：疫情后家用沙袋/拳套套装（手套+缠手带+沙袋组合 listing）常态化——套装毛利高于单品 20-30%；
- **健身房/拳馆 B2B**：Logo 定制（丝印/热压）+耐用性优先（馆用损耗率=家用 5 倍）——馆用款面料升级到 1.2mm 加厚 PU；
- **电商差评高发点**：异味（发泡/PU 溶剂味——出货前散味 48h）、车线崩裂（拇指位）、尺码偏小（拳套按 oz 标注——8/12/14/16oz 对应训练/实战场景必须在 listing 讲清）；
- **季节性**：1 月（新年健身决议）+黑五双高峰，备货提前 60 天；
- **产业带**：河北沧州/山东潍坊（沙袋+护具）、福建泉州（拳套）——报价含发泡内胆自产能力的工厂优先（外购内胆品质失控）。
