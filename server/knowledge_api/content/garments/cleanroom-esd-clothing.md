# 无尘服与防静电服生产（Cleanroom & ESD Garments: 电子/医药洁净工装）

无尘服/防静电服是"**涤纶长丝+导电丝织入+无尘工艺**"的工业工装品类：服务半导体/面板/医药/食品洁净室，核心指标是**低发尘+静电泄放**，与民用防静电（加油站/化工——GB 12014 国标）分属两个市场。复购逻辑=定期更换+无尘清洗服务绑定。属工装大类（见 `garments/workwear-uniform-production.md`）但工艺体系独立。

## 一、材料与产品矩阵

| 产品 | 材料 | 特征 |
|:---|:---|:---|
| 连体无尘服（coverall） | 100% 涤纶长丝（低发尘）+导电碳纤维条纹/网格（5mm/2.5mm 间距） | 斜拉链+立领+松紧袖口——半导体主款 |
| 分体服/大褂 | 同上 | 电子组装/食品车间（穿脱便捷） |
| 无尘鞋（靴） | 导电绸面+PU/PVC 防静电底 | 高筒靴（百级车间）/四孔鞋 |
| 无尘帽/口罩/手套 | 导电绸/涤纶网+乳胶/丁腈 | 全套配套销售 |
| 民用防静电服 | 涤棉+导电丝（条纹 0.5cm） | 加油站/化工/加油站工装（GB 12014） |

- **导电丝规格**：碳纤维复合型导电丝——**条纹（stripe）成本低/网格（grid 2.5mm）泄放更均匀**（高端洁净室指定网格）；
- **关键指标**：表面电阻 10⁶-10⁹Ω、摩擦起电电压<100V（高端<50V）、发尘量（Helmke drum 滚筒测试）；功能纱线背景见 `fabric/functional-yarns.md`；
- **辅料管控**：**不产尘辅料**——魔术贴/按扣替代纽扣，涤纶线缝制（棉线产尘禁用），无口袋/内口袋设计（藏尘死角）。

## 二、洁净等级与标准

| 等级 | ISO 14644 | 传统等级 | 应用 |
|:---|:---|:---|:---|
| 百级 | ISO Class 5 | Class 100 | 半导体光刻/芯片封装——连体+高筒靴全封闭 |
| 千级-万级 | ISO 6-7 | Class 1k-10k | 面板/精密电子——连体或分体 |
| 十万级 | ISO 8 | Class 100k | 医药/食品/组装——大褂即可 |

- **ESD 体系标准**：IEC 61340-5-1 / ANSI ESD S20.20（静电防护体系——工厂认证而非单件认证）；EN 1149（欧洲防静电服测试）；
- **民用国标**：GB 12014（防静电服——带电电荷量<0.6μC/件）——加油站/危化品工装强制；
- **测试**：表面电阻（电极法）、点对点电阻、摩擦电压、发尘量、耐洗 50/100 次后电阻保持率——**洗后性能衰减是验收焦点**（导电丝断裂/涂层脱落）。

## 三、生产工艺要害

- **无毛边工艺**：**包缝+绷缝全包覆**（散边=发尘源）——裁片激光切割封边（热切防散纱）；
- **缝制环境**：洁净车间裁剪缝制（尘埃管控——与普通服装厂隔离）+**成品无尘清洗**（超纯水 18MΩ 清洗+烘干+真空包装——清洗是交付前必要工序）；
- **无尘清洗后市场**：客户复购绑定**清洗租赁模式**（衣服归厂方——按次清洗收费+寿命管理 50-100 次报废）——这是比卖衣服更稳的现金流模式；
- **验针与异物**：电子厂客户对金属异物零容忍——验针管理见 `suppliers/needle-control-metal-management.md`。

## 四、市场与商业要点

- **需求方**：半导体厂（台积电/三星/中芯国际供应链——指定认证供应商制）、面板厂（京东方/华星）、医药（GMP 车间）、食品（洁净包装间）、锂电池厂（新兴增量——干燥房）；
- **客户验厂**：洁净车间+清洗设备+检测仪器（电阻仪/发尘测试）+批次追溯——门槛高于普通工装（见 `suppliers/factory-on-site-audit-sop.md`）；
- **出口**：东南亚电子厂（越南/马来半导体转移——中国+1 产能协同见 `suppliers/china-plus-one-capacity-strategy.md`）+中东医药；
- **价格逻辑**：连体服出厂 ¥40-120（民用防静电 ¥30-60）——**清洗租赁绑定后 LTV 是售价 3-5 倍**；
- **交付注意**：真空包装+批次检测报告随货（电阻实测值——客户 IQC 全检）；储存防潮（导电性能受湿度影响）。
