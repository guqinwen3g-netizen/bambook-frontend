# 露营装备生产（帐篷与睡袋：Camping Gear: Tents & Sleeping Bags）

露营装备是纺织外贸延伸品类：帐篷、睡袋、天幕、防潮垫等。与服装共用面料供应链（涤塔夫/牛津布/涂层工艺，见 `fabric/canvas-oxford-fabrics.md`、`fabric/functional-coating-lamination.md`），但工艺标准（防水/阻燃/温标）与服装差异大。欧美露营市场 2020 后持续高位，中国产业带集中于浙江（衢州/宁波）、江苏、广东。

## 一、帐篷核心规格

| 部件 | 常用物料 | 关键指标 |
|:---|:---|:---|
| 外帐 | 210T 涤塔夫 PU 涂层 / 20D 硅油尼龙（高端） | **静水压 PU2000-3000mm**（中雨级）、PU5000+（暴雨级） |
| 内帐 | 透气涤纶+网纱（B3/B4 防蚊） | 透气防凝露 |
| 地布 | 150D/210D 牛津布 PU | 静水压 ≥3000mm、耐磨 |
| 帐杆 | 玻纤杆（入门）/7001 铝合金（中高端） | 杆径 7.9/8.5/9.5mm |
| 黑胶遮光 | 外帐内面涂黑胶层 | 遮光率>90%（夏季卖点，涂层增重 15-20%） |

- **硅油尼龙（silnylon）**：轻量高端线，硅涂层布面滑——**缝纫后针孔无法自封闭，必须压胶条**；
- **阻燃**：美国市场帐篷需过 **CPAI-84** 阻燃测试（明火 12 秒自熄）——涂层配方与测试报告接单前确认（非强制法规但零售商普遍要求）。

## 二、帐篷生产工艺要点

- **裁剪**：大裁片（外帐单片可达 10 米）——铺布台长度与裁刀行程受限，多层铺布≤30 层（PU 面滑易偏刀）；
- **防水关键工艺=压胶条（seam taping）**：所有车缝线迹压 PU 胶条封针孔——压胶温度 350-450℃、速度 5-8m/min，**温度不足脱胶、过高烫坏涂层**；每批做淋水抽测；
- **淋水测试**：成品帐喷淋 30 分钟无渗漏（抽检比例按客户要求，高端单 100% 淋检）；
- **抗风测试**：样品级风洞/实场测试（标称抗风 6-8 级为常见区间）；
- **配件管控**：地钉/风绳/拉头（SBS/YKK）——配件缺失是客诉大头，包装全检称重。

## 三、睡袋规格与温标

- **填充**：化纤棉（中空棉/仿羽绒棉，入门）vs 羽绒（鸭绒 600FP→鹅绒 800FP+，高端——羽绒采购与充绒见 `garments/down-jackets-production.md`）；
- **温标体系**：**EN 13537 / ISO 23537**（欧洲强制标注逻辑）：
  - Comfort（舒适温度）/ Limit（极限温度）/ Extreme（生存温度，不作卖点宣传）；
  - 温标必须有实验室测试报告支撑（人体热阻模型测试），虚标=召回风险（见 `trade-compliance/product-liability-recall.md`）；
- **结构**：木乃伊式（保暖效率高）/信封式（可拼接双人）；立衬结构（盒式绗缝）防冷点——高端羽绒睡袋必用；
- **面料**：20D-40D 尼龙格子布（防钻绒+防泼水处理）；里料亲肤春亚纺。

## 四、品质检验与测试

| 测试 | 标准 | 要点 |
|:---|:---|:---|
| 静水压 | ISO 811 / AATCC 127 | 每缸布料必测（涂层均匀性波动大） |
| 阻燃 | CPAI-84（美） | 每批留样 |
| 温标 | ISO 23537 | 型式测试（非逐批） |
| 抗撕裂 | ISO 13937 | 轻薄面料重点 |
| 拉链耐用 | BS 3084 | 帐篷门襟拉头 5000 次 |
| 充绒量/含绒量 | IDFB / GB/T 14272 逻辑 | 见羽绒文档 |

- **验货参照**：AQL 之外加功能项（淋水/充气检漏/杆件插拔）——见 `trade-process/pre-shipment-inspection-sop.md`。

## 五、接单与市场要点

- **市场分层**：美国（REI/沃尔玛体系，大容量自驾帐为主）、欧洲（迪卡侬供应链体量大价优，见 `customers-market/brand-retailer-supplier-systems.md`）、日韩（精致露营：轻量化+颜值溢价）；
- **季节性**：北半球春季下单（3-5 月）、夏季销售——生产排期与羽绒服互补（见 `trade-process/annual-sourcing-calendar.md`）；
- **报价结构**：面料占成本 40-50%（涂层布价随 PU 配方波动）——锁价条款与面料采购联动（见 `fabric/fabric-procurement-quality-agreement.md`）；
- **坑**：① 静水压虚标（涂层减薄）——客户到港复测索赔；② 压胶条脱胶（储存高温环境）——做老化测试；③ 配件混批（地钉规格错装）——包装 SOP 拍照留证。
