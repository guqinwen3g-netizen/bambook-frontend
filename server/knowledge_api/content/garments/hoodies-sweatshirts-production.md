# 卫衣品类生产专题（Hoodies & Sweatshirts Production）

卫衣（hoodie/sweatshirt）是**秋冬第一大单品**：街头文化加持下从运动装变成全民基础款，也是潮牌/定制市场的核心载体。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 连帽卫衣（hoodie） | 帽子+帽绳+袋鼠袋——标志款 |
| 圆领卫衣（crewneck） | 无帽简洁款 |
| 开衫卫衣（zip-up） | 全拉链（穿脱便利） |
| oversize 卫衣 | 落肩宽松（街头风） |
| 高领/半拉链 | 变体设计 |

## 二、面料配套（卫衣布）

- **卫衣布/毛圈布（French terry）**：底面毛圈（春款——见 `fabric/fleece-terry-fabrics.md`）；
- **抓绒卫衣布（fleece）**：毛圈抓毛（冬款——底绒保暖）；
- **克重**：280-350gsm（常规）/ 350-450gsm（重磅潮牌——挺括廓形）；
- **成分**：棉/棉涤（CVC）/ 棉氨（弹力款）；
- **品质点**：起球（卫衣布痛点——抗起球处理）+ 掉毛（抓绒）。

## 三、核心工艺

### 帽子（品质焦点）
- **双层帽**：帽里+帽面（双层布——挺括有型 vs 单层软塌）；
- **帽绳**：织带/棉绳+金属/塑料绳头（aglet）；
- **鸡眼（eyelet）**：帽绳孔金属鸡眼（加固）；
- **品质点**：帽型（戴上立挺不塌）、帽绳对称、鸡眼牢固。

### 袋鼠袋（kangaroo pocket）
- 连帽卫衣标志——袋口加固（套结防撕裂）、袋型对称。

### 罗纹
- 袖口/下摆罗纹（2x2 罗纹——收口弹性）；
- 罗纹与衣身配比（起波浪=配比不当）。

## 四、印花/绣花

- **卫衣是印花最大载体之一**：胸前大印花/后背满印（街头文化）；
- **工艺**：丝印胶浆/热固油墨（厚板印花立体效果）/绣花（胸标）/烫画；
- **洗后效果**：做旧印花（vintage 风——见 `garments/printing-embroidery.md`）。

## 五、订单特征

- **秋冬主力**：卫衣是秋冬订单核心（6-9 月生产峰值）；
- **潮牌载体**：潮牌 oversize 卫衣（高克重+大印花——溢价品类）；
- **定制市场**：团体卫衣（班服/团建——定制印字）；
- **翻单稳定**：基础款卫衣常年翻单。

## 六、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 帽子 | 双层帽型立挺、帽绳/鸡眼 |
| 起球 | 卫衣布抗起球（马丁代尔评级） |
| 掉毛 | 抓绒掉毛（摩擦测试） |
| 尺寸 | 胸围/衣长（oversize 版型尺寸宽松但公差仍要） |
| 印花 | 洗后牢度（不开裂不掉色） |
| 罗纹 | 袖口/下摆罗纹弹性回复 |

## 七、产业带

- **广东**：佛山/中山针织（卫衣布+成衣）；
- **浙江**：宁波/绍兴；
- **山东**：即墨针织集群；
- **快反**：卫衣是 Shein 模式核心品类（见 `customers-market/fast-fashion-shein-model.md`）。
