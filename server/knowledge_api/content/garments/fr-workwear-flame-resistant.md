# 阻燃防护服与本质阻燃工装（FR Workwear: NFPA 2112/EN 11612/电弧防护）

阻燃（FR）工装是油气、电力、化工、焊接行业的**保命装备**：普通工装遇火熔融粘连皮肤（涤纶致命）或持续燃烧，FR 服自熄+隔热争取逃生秒数。通用工装见 `garments/workwear-uniform-production.md`、PPE 合规框架见 `trade-compliance/ppe-protective-clothing-compliance.md`，本文件聚焦 FR 技术路线与高等级市场。

## 一、FR 技术路线（成本与性能权衡）

| 路线 | 代表材料 | 特性 | 价格 |
|:---|:---|:---|:---|
| 后整理阻燃棉 | 全棉+Pyrovatex/Proban 阻燃整理 | 手感好成本低；**洗 50-100 次阻燃衰减**（需寿命标注） | 基准 |
| 本质阻燃（inherent） | 间位芳纶（Nomex）、对位芳纶混纺、FR 粘胶 | **阻燃性永不失效**（分子结构自带）——高端市场主流 | 3-8 倍 |
| 阻燃腈纶混纺（modacrylic blend） | 腈氯纶+棉/粘胶 | 性价比中间路线——欧美工装常用 | 1.5-2 倍 |
| 羊毛天然阻燃 | 美利奴羊毛 | 天然自熄+舒适 | 高端 |

- **混纺禁区**：FR 面料混入普通涤纶/尼龙=熔滴风险——**FR 服的缝线/魔术贴/反光带/罗纹也必须 FR 级**（整衣认证逻辑）；
- **洗后性能**：后整理棉按 ISO 6330 洗 50/75/100 次后复测垂直燃烧——**产品标注最大洗涤次数**是强制义务。

## 二、标准体系（按危害类型）

| 标准 | 危害 | 内容 |
|:---|:---|:---|
| NFPA 2112（美） | 闪火（flash fire——油气行业） | 垂直燃烧+热防护 TPP+假人燃烧测试（烧伤面积 ≤50%） |
| NFPA 70E / ASTM F1506 | 电弧（arc flash——电力行业） | **ATPV/EBT 值（cal/cm²）分级**：CAT 1-4（4-40+ cal） |
| EN ISO 11612（欧） | 热与火焰 | A1/A2（燃烧）+B（对流热）+C（辐射热）+D（铝熔滴）+E（铁熔滴）等级代码 |
| EN 1149 | 静电 | 防静电（油气环境配套） |
| EN 61482 | 电弧（欧） | 同 NFPA 70E 逻辑 |
| EN ISO 11611 | 焊接 | 焊接飞溅 |
| NFPA 1971/EN 469 | 消防战斗服 | 多层结构（外壳+防水透气层+隔热层+里布） |

- **整衣认证**：面料证书不够——**成衣需整衣测试与认证**（结构件兼容性）；UL/SEI 认证标志（美）、CE+公告机构（欧）；
- **行业准入**：石油公司供应商名录（阿美/壳牌/BP 指定认证与测试实验室）；电力公司 NFPA 70E 合规采购。

## 三、生产要点

- **FR 辅料全套**：芳纶缝线（Nomex 线——普通涤纶线先熔断）、FR 魔术贴、FR 反光带（见 `fabric/hi-vis-reflective-fabrics.md` 复合需求）、金属拉链（不熔滴——塑料拉链禁用）、罗纹袖口 FR 处理；
- **工艺纪律**：缝制不允许普通线替代（一根非 FR 线=整衣认证失效）；水洗工艺控制（后整理棉的阻燃剂保留率——洗后抽样送检）；
- **高可视复合**：FR+Hi-Vis 双认证（EN 20471+EN 11612）是油气工装常态——材料复合测试；
- **尺码与合规标签**：FR 等级/洗涤次数上限/危害类型永久标识——**错误标注=重大责任风险**（见 `trade-compliance/product-liability-recall.md`）。

## 四、市场与订单

- **市场**：美国（NFPA 体系——页岩油气+电力基建驱动）、中东（油气国家——阿美标准全球最严之一）、澳洲矿业、欧洲化工；
- **渠道**：劳保分销商（同安全鞋渠道逻辑，见 `garments/safety-footwear-production.md`）、工业服务商集采、品牌 OEM（Bulwark/Carhartt FR/Ariat FR 代工）；
- **订单特征**：认证壁垒高（首单测试成本 $10-30 万）→ **但复购粘性强**（客户不愿承担换供应商的再认证成本）——典型"高门槛长坡道"品类；
- **趋势**：轻量化 FR（7oz→5.5oz 面料——舒适性与合规平衡）、弹力 FR（活动性）、女装版型 FR（女性进入工业岗位）、租赁洗涤模式（FR 服租赁+专业洗涤维护——耐洗次数管理外包）。
