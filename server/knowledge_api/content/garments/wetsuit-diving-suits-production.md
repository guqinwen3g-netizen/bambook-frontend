# 潜水服生产（Wetsuits: 氯丁橡胶/盲缝/干式防水）

潜水服是**材料+胶合工艺**驱动的技术品类：氯丁橡胶发泡片（neoprene）贴合弹力布后裁剪胶合，非传统车缝逻辑。市场=潜水/冲浪/铁人三项（开放水域游泳）三大场景，欧美+澳新为核心。产业带：广东东莞/深圳（发泡贴合一体化）、台湾（高端 Yamamoto 海绵加工）。设备与版师体系与服装厂完全不同——**切入即重资产专项产线**。

## 一、材料体系

| 层级 | 材料 | 特性 |
|:---|:---|:---|
| 核心海绵 | 氯丁橡胶发泡（CR）2-7mm | 保温靠闭孔气泡——厚度=水温对应 |
| 高端海绵 | Yamamoto #38/#39（石灰石基） | 柔软度/回弹标杆——竞赛级 |
| 内衬 | 尼龙/涤纶弹力布贴合 | 贴肤+穿脱顺滑 |
| 外表 | 超弹布（4-way）/光皮（smooth skin——防风防水溅） | 耐磨 vs 减阻取舍 |
| 保暖涂层 | 钛层/石墨烯印花内里 | 高端保温叙事 |

- **厚度-水温对照**：2mm 短袖（25°C+）/3.2mm 全衣（20-25°C）/4.3mm（15-20°C）/5.4mm+头套（10-15°C）——详情页必须给水温对照表；
- **贴合**：海绵+布料胶水复合（贴合厂专工——胶水是核心机密：水性胶环保趋势，溶剂胶初粘强但 VOC 管控）；
- **环保**：石灰石基氯丁橡胶（非石油基——品牌 ESG 叙事）；**Yulex 天然橡胶**（Patagonia 模式——FSC 认证天然胶替代，高端环保线）。

## 二、核心工艺（与车缝完全不同的逻辑）

- **盲缝（blind stitch）**：针不穿透海绵（只穿布层+半穿海绵）+胶合——**不漏水**是灵魂；穿透车缝=漏水报废；
- **胶合流程**：裁片边缘刷胶（两遍——头胶渗透+二胶粘合）→对贴压实→盲缝加固；
- **缝份结构**：平接（flatlock——透气款非防水）/胶合盲缝（GBS——防水主力）/液封（taped seal——缝份内侧贴胶条，高端全密封）；
- **拉链**：后背拉链（back zip——穿脱易）/胸前拉链（chest zip——活动性好，高端）/无拉链（zip free——竞赛铁三）；拉链用塑料防水链+挡水片（见 `suppliers/zipper-fasteners-deep-dive.md`）；
- **关键补强**：膝部耐磨片（supratex）/袖口脚踝密封条（液态硅胶印刷——防灌水）；
- **裁片排版**：海绵片厚——裁床用振动刀/刀模（激光切会碳化边缘——禁用）；排版利用率决定成本（海绵宽幅窄——利用率 70% 是目标）。

## 三、品类分化

| 品类 | 结构差异 | 测试 |
|:---|:---|:---|
| 潜水温衣 | 全身密封+头套位 | 保温实测 |
| 冲浪服 | 肩部活动量+耐磨 | 撕扯/耐盐 |
| 铁三服 | 超弹+浮力分布（Yamamoto SCS 减阻涂层） | 游速测试（品牌实验室） |
| 干式潜水服（drysuit） | 复合布+防水拉链+充气阀——**不贴身、内穿保暖层** | 整衣气密测试（充气检漏） |

- **干衣是技术顶点**：防水拉链（气密级）+乳胶领口袖口+充气/排气阀——整衣气密全检（与 `garments/inflatable-advertising-products.md` 的闭气逻辑同源）；
- **测试项**：拉伸回复/撕裂强力/耐海水老化/耐臭氧（橡胶天敌——储存要求写入说明）、保温 Clo 值。

## 四、合规与市场

- **CE 认证**：欧盟把潜水服归入 PPE II 类（防冷 EN 14225——潜水服专项标准）；冲浪服属运动消费品（无强制）；
- **化学**：橡胶加工助剂（亚硝胺——橡胶硫化副产物管控）、PAHs（炭黑——REACH 附件 17，见 `trade-compliance/chemical-environmental-compliance.md`）；
- **市场**：美国（潜水/冲浪双大市场）、澳洲（全年冲浪）、欧洲（铁三增长）；品牌梯队：O'Neill/Rip Curl/Billabong（冲浪）、Scubapro/Mares（潜水）、Zone3/2XU（铁三）；
- **季节**：北半球 Q4 下单→Q1 出货（4-5 月水上运动季启动）；
- **报价**：海绵材料占 50%+（Yamamoto 海绵是 CR 国产 2-3 倍）；胶合人工占比高（熟练胶工是产能瓶颈——培养周期 6 个月+）；MOQ 300-500 件/款。
