# 缝制与工艺术语（Sewing & Workmanship）

缝制（sewing/workmanship）是把裁片组装成成衣的关键工序，也是验货中**工艺质量（workmanship/quality of workmanship）**评估的核心。本文件覆盖常用缝型、线迹、针距、设备与质量检查要点。

## 一、针距与密度（Stitch Density / Stitches per Inch）

- 针距（stitch density）即单位长度内线迹数，常用**每英寸针数（stitches per inch, SPI）**表示。
- 不同面料/部位对针距要求不同：针织多取 3-4 针/cm，梭织衬衫锁边常在 3-4 针/cm、明线 4-5 针/cm。
- **针距过密**：易挂线、面料损伤；**针距过疏**：牢度不足、易散线。
- 外包单/工艺单上须写明针距要求，避免"看着密就行"。

## 二、常用缝型（Stitch Types）

按国际标准（ISO 4915）缝型有线迹编号，外贸常用如下：

| 缝型 | English | 编号/说明 |
|:---|:---|:---|
| 平缝/单针线迹 | lockstitch (single needle) | ISO 301，最常用，明线/暗线 |
| 双针线迹 | double needle stitch | 两行平行明线 |
| 包缝/锁边 | overlock（merrow） | ISO 504/512，针织散边处理 |
| 覆盖缝 | coverstitch | ISO 602/605，针织下摆/领口，有弹性 |
| 链式线迹 | chainstitch | 有弹性，牛仔常用 |
| 绷缝 | interlock/flatlock | 拼接处平整 |
| 打枣/加固 | bar tack | 受力点加固，如口袋角、拉链头 |

> 弹性面料（含氨纶）需用**包缝/覆盖缝**等弹性线迹，普通平缝会断裂、起皱。

## 三、常见工序（Production Steps）

成衣缝制工序因品类而异，一般流程：

1. **裁片核查**：清点裁片、对条对格、核对经纬向。
2. **标记（marking）**：在裁片上划定位线（省道 dart、口袋位）。
3. **缝合（sewing/assembly）**：按工序顺序组合（如先合侧缝、再上领）。
4. **绷缝/锁边（overlock）**：处理边缘散边。
5. **部件安装**：上拉链、钉纽扣、钉揿扣。
6. **绣花/装饰**：绣花、烫钻、印花后道。
7. **熨烫（pressing/ironing）**：定型、压折。
8. **整理（finishing）**：剪线头、检查、包装。

## 四、车缝质量检查要点

验货时重点查看（结合 GM 单与工艺单）：

- **对称性**：左右肩、两侧衣片对称，拼接处齐平。
- **线迹平伏**：无线迹起伏、跳针（skip stitch）、断线（broken thread）。
- **起皱/抽褶**：领口、袖窿、下摆不得起皱（puckering）。
- **明线均匀**：明线宽度一致、线距均匀。
- **对条对格**：梭织格纹在肩缝、侧缝处对条。
- **线头处理**：内外面无线头（loose threads）。
- **加固到位**：受力处打枣（bar tack）到位。
- **尺寸复核**：按 GM 单抽查关键部位尺寸。

## 五、常见工艺缺陷与处理

| 缺陷 | English | 常见处理 |
|:---|:---|:---|
| 跳针 | skip stitch | 重车补缝 |
| 断线 | broken thread | 返工缝合 |
| 起皱 | puckering | 熨烫/调整张力 |
| 偏针/歪缝 | crooked seam | 返修 |
| 线头未剪 | loose threads | 剪线头 |
| 明线不均 | uneven topstitch | 返工 |
| 对条不对格 | mis-matched pattern | 严重需返工 |

## 六、沟通与跟单要点

1. **工艺单要量化**：针距、明线宽度、加固位置都要有明确数值。
2. **签订标准样**：工艺复杂款式，先做**工艺样/车缝样（seam/construction sample）**确认。
3. **瓶颈工序关注**：绣花、上拉链、拷边等瓶颈工序决定产能与交期。
4. **区分返工等级**：小瑕疵可现场修补（repair），结构性问题需返工（rework）甚至重做。
5. **留工艺记录**：工序表、针距标准存档，作为质量追溯依据。
