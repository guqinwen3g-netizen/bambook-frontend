# 老年与无障碍适配服装生产（Adaptive Clothing: 护理服/磁性扣/坐姿剪裁）

适配服装为**失能/半失能人群**（老人、轮椅使用者、术后康复、认知症）重新设计穿脱系统：后开口护理服、磁性扣/魔术贴替代纽扣、侧开拉链裤、坐姿剪裁。驱动市场是**美国/日本/欧洲老龄化**（日本介护体系最成熟，美国亚马逊 adaptive 类目高速增长——Tommy Hilfiger Adaptive 等品牌入场教育市场）。本质是"**普通服装+人因工程改版**"——工艺不变，版型与开合逻辑重构。

## 一、产品线与设计要点

| 产品 | 适配设计 | 场景 |
|:---|:---|:---|
| 后开口护理服（open-back） | 背部全开+肩部按扣/魔术贴（护理者协助穿脱） | 卧床/半失能老人 |
| 磁性扣衬衫 | 磁扣内嵌（外观与普通衬衫一致） | 手部关节炎/帕金森 |
| 侧开拉链裤 | 两侧全开拉链（坐姿穿脱） | 轮椅使用者 |
| 坐姿剪裁裤 | 前片短+后片长+高腰（坐姿不露腰） | 轮椅全天坐姿 |
| 魔术贴鞋/防滑袜 | 宽幅魔术贴+防滑胶点 | 居家防跌倒 |
| 防抓手套/连体衣 | 认知症防拔管设计 | 认知症护理 |
| 造口/导管适配款 | 隐形开口+管路固定袢 | 术后/造口人士 |

## 二、生产要害

- **版型核心**：**坐姿数据**（轮椅裤前裆提升+后裆加深+膝部预弯——站立审美让位坐姿功能）；后开口服肩部叠门量（盖住背部开口不露肤——尊严设计）；
- **开合件选型**：磁扣（**薄型树脂包覆磁钢**——洗涤 50 次不退磁；心脏起搏器警示标注争议——FDA 建议间距标注）；魔术贴选**细钩柔软型**（防刮皮肤+静音）；按扣选大号尼龙四合扣（肌无力可操作力度<15N）；
- **面料**：针织棉/莫代尔为主（柔软亲肤）+**耐氯漂**（养老机构工业洗涤 75℃+含氯——面料/缝线/印花全链耐氯，见 `garments/kitchen-textiles-production.md` 同类洗涤逻辑）+防污整理（进食污渍高频）；
- **安全细节**：**无内缝标签**（印制洗标——卧床者皮肤压迫敏感）；平缝/四线拷克埋夹（骨缝压迫褥疮风险）；反光条（夜间起夜）；
- **防误吞**：认知症款小配件全禁（纽扣/珠片——拉力测试+设计规避）。

## 三、合规边界

- **普通消费品定性**：不宣称医疗功能（"护理方便"≠"治疗"）——避免 FDA/MDR 边界（见 `garments/sports-protective-gear-production.md` 的宣称红线逻辑）；
- **磁扣安全**：磁钢脱落=吞咽风险（儿童产品逻辑迁移——拉力测试）；起搏器人群警示标签（"contains magnets"）；
- **阻燃**：美国养老机构部分州要求睡袍类阻燃（16 CFR 1610 一般阻燃基准——见 `trade-compliance/textile-flammability-regulations.md`）；
- **日本介护市场**：介护用品目录（福祉用具）体系——非医保品类走零售（无印良品/贝亲式渠道）；
- **标识**：易穿脱设计图示（护理者看图操作）+多语言。

## 四、市场与渠道

- **美国**：亚马逊 adaptive 类目+养老机构 B2B（Silvert's/Buck & Buck 模式——目录邮购转电商）；**礼品场景**（子女为父母购买——listing 情感化文案）；
- **日本**：介护保险外自购品（高设计接受度——本土品牌主导，中国工厂 ODM 机会）；
- **欧洲**：英国/德国养老体系采购（NHS 供应链逻辑——集采投标）；
- **定价**：比普通服装溢价 30-60%（改版+小批量）——**尺码宽松体系**（适老版型不按常规修身逻辑）；
- **差评高发点**：磁扣吸力弱/洗涤退磁、魔术贴刮皮肤、后开口走光、裤腰松紧压迫（腹带感）——**真实轮椅用户试穿测试**是开发必经环节；
- **退货率优势**：适配服装退货率（~8%）显著低于常规服装电商（30%+）——刚需+尺码宽容。
