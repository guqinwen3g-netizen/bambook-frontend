# 礼服成衣生产专题（Evening Wear Production: Tuxedo/燕尾服/晨礼服制作工艺）

礼服是"**规则最严苛的服装**"：黑领结（black tie）与白领结（white tie）的着装规范 200 年未变，每一处细节（缎面戗驳领/侧缝缎条/礼服扣）都有定式。礼服面料见 `fabric/evening-formalwear-fabrics.md`，礼服马甲见 `garments/waistcoat-vest-production.md`——本文件聚焦**礼服成衣的生产工艺与订单实务**。

## 一、礼服层级体系

| 层级 | 着装代码 | 组成 | 场合 |
|:---|:---|:---|:---|
| 白领结（White Tie） | 最高礼服规格 | 燕尾服+白马甲+白领结 | 国宴/诺奖晚宴/皇家活动 |
| 黑领结（Black Tie） | 标准晚礼服 | Tuxedo+黑领结+腰封/马甲 | 晚宴/婚礼/颁奖礼 |
| 晨礼服（Morning Dress） | 日间最高规格 | 晨礼服+条纹裤+浅色马甲 | 日间婚礼/皇家赛马会 |
| 董事套装（Stroller） | 半正式日间礼服 | 黑色短外套+条纹裤 | 日间半正式活动 |

## 二、Tuxedo（塔士多礼服）规格

- **美版 vs 英版 vs 欧陆版**：
  - 美版：青果领（shawl lapel）单排一粒扣——1920s 美国化改良；
  - 英版：戗驳领（peak lapel）双排扣——更接近正装血统；
  - 欧陆版：修身+短衣长——现代时尚改良；
- **不可谈判的细节**：
  - **缎面驳领**：领面覆缎（silk grosgrain 罗缎或 satin 缎面）——与衣身羊毛形成光泽对比；
  - **侧缝缎条**：裤侧缝单条缎带（braid/stripe）——礼服裤的标识；
  - **礼服扣**：缎面包扣（covered button）——门襟/袖口专用；
  - **腰封（cummerbund）**：褶皱朝上（传统是装戏票）——或礼服马甲替代；
  - **衬衫**：翼领（wing collar）或翻领+胸前风琴褶（pleated bib）+法式袖；
  - **鞋**：黑色漆皮牛津/歌剧鞋（opera pump）。

## 三、燕尾服（Tailcoat）与晨礼服工艺

- **燕尾服结构**：
  - 前短后长燕尾——前身裁至腰线，后身两片长尾；
  - 不扣合设计——门襟仅为装饰（钩扣固定）；
  - 高腰剪裁——马甲必须低领 U 型露出衬衫胸褶；
- **晨礼服结构**：
  - 单排一粒扣+斜裁后摆——前襟从腰线斜向后裁开；
  - 灰色/黑色——日间礼服的标准色；
  - 配条纹裤（cashmere stripe 羊绒条纹裤）——**上下不同料是晨礼服的规则**；
- **工艺难点**：
  - 燕尾的后摆垂坠——**斜纱裁剪+里料配重，摆动时保持形态**；
  - 缎面拼接——缎与羊毛的缩率差异（预缩处理必须分别完成）；
  - 白色马甲的洁净度管控——**白面料车间的无尘管理**。

## 四、生产与订单实务

- **需求特征**：
  - 婚礼季（5-6 月/9-10 月）+颁奖季（1-3 月）——**礼服订单的季节脉冲**；
  - 租赁市场：美国 tuxedo rental 占礼服消费 60%+——**租赁款与零售款的工艺差异（耐穿性>精细度）**；
  - 团体订单：婚礼伴郎团（4-8 件同料同批）——**色差管理是硬指标**；
- **版型要点**：
  - 礼服的合身度要求高于商务西装——**肩部/腰线必须精准（礼服不容许"宽松舒适"）**；
  - 青果领的翻卷线——**缎面翻卷的弧度是工艺分水岭**；
- **成本结构**：
  - 缎面辅料（真丝罗缎 €30-80/m）+包扣+腰封——**辅料成本占比达 15-20%（高于商务西装 8%）**；
  - 手工含量：缎面手扦/驳领手纳——**高端礼服手工工时 8-15 小时**。

## 五、质检红线

| 检验点 | 标准 |
|:---|:---|
| 缎面品质 | 无抽丝/无反光不均（对光检验） |
| 缎与呢拼接 | 无起皱/无拉扯（缩率匹配） |
| 包扣 | 缎面包裹无褶皱/扣位精准 |
| 裤侧缎条 | 平直无扭曲/宽度一致（通常 2cm） |
| 色差 | 同团订单 ΔE<0.5（婚礼团单硬指标） |
| 洁净度 | 白色部件无污渍/无黄变 |
