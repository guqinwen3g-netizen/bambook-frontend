# 野餐垫与沙滩垫生产（Picnic & Beach Mats: 复合结构/防沙网布/季节性单）

野餐垫/沙滩垫是"**面料复合+包边收纳**"的低门槛高周转品类：欧美春夏季节性刚需（4-7 月），商超季节促销单（Walmart/Lidl/Aldi）与亚马逊双线走量。生产门槛不在缝纫而在**复合工艺与防水底层材料**，溢价靠**图案设计+折叠收纳结构**。露营睡垫（充气/自充气）见 `garments/camping-gear-tents-sleeping-bags.md`，本文聚焦日用野餐/沙滩场景。

## 一、产品结构与材料

| 层位 | 材料方案 | 功能 |
|:---|:---|:---|
| 面层 | 印花涤纶（210D 牛津/春亚纺）/摇粒绒/腈纶格子布 | 亲肤+图案颜值 |
| 中间层 | EPE 珍珠棉 2-4mm（可选） | 缓冲隔凉 |
| 底层 | PEVA 膜/铝膜/210D 牛津涂银 | **防水隔潮核心** |

- **经典三层款**：摇粒绒面+EPE+PEVA 底（亚马逊 $20-35 主力款）；
- **超薄便携款**：单层 210T 涤纶+PU 涂层（折叠成口袋大小——$10-15 走量款）；
- **沙滩垫差异款**：**双层防沙网布**（沙粒从网眼漏下不反渗——专利技术点，普通网布仿款易侵权）；
- **高端款**：帆布面+绗缝棉+防水牛津底（$40-60，颜值驱动）。

## 二、生产工艺要害

- **超声波复合**：三层材料无线缝合（**无针孔=防水完整**——针车绗缝款针孔渗水差评）——超声波花辊模具（格子/菱形纹）1-3 万/套；
- **包边**：涤纶斜纹包边条宽度 3-4cm——四角圆弧处理（直角包边起翘）；包边车缝**断线跳针是抽检高频不合格**；
- **收纳结构**：折叠+魔术贴捆带+提手（**提手与包边一体车缝**——提手撕裂是首要差评）；附收纳袋款（束口袋/拉链袋）；
- **配件**：地钉（防风——沙滩款 4 角配 ABS 地钉+插袋）、四角口袋装沙压角（替代地钉方案）、充气枕一体款；
- **印刷**：面层热升华/数码印花（见 `fabric/digital-printing-technology.md`）——格纹经典款（红白格/蓝白格）常年霸榜，差异化靠原创图案授权。

## 三、合规要点

- **化学**：PEVA/PVC 膜**邻苯二甲酸盐**（Prop 65+欧盟 REACH——见 `trade-compliance/california-prop65.md`）；印刷油墨偶氮/甲醛（GB 18401 B 类——皮肤接触品类，见 `trade-compliance/china-domestic-standards.md`）；
- **儿童场景关联**：野餐垫常被用作婴儿爬行垫——如宣称 baby play mat 则触发 CPSIA/EN71 全项（**非儿童宣称要在 listing 规避暗示**）；
- **阻燃**：部分商超要求帐篷/垫类阻燃声明（加州 TB-117 逻辑延伸——涤纶本身体系一般可通过小尺度燃烧）；
- **尺寸标注**：展开尺寸与收纳尺寸双标（"fits 4-6 people"宣称需尺寸支撑——广告法边界）；
- **防水宣称**："waterproof"需底层静水压实测支撑（≥1000mm 才敢标）——否则用 "water-resistant backing"。

## 四、市场与渠道节奏

- **季节倒排**：欧美旺季 5-8 月→商超单 11-12 月下单 3-4 月交付；亚马逊备货 3 月到仓；
- **商超季节单特征**：单款 5-20 万件+价格极低（$3-6 FOB）+**交期死线**（错过货架期全单取消——见 `suppliers/order-review-acceptance.md` 的接单评审）；
- **亚马逊运营要点**：主图场景化（家庭野餐摆拍）+**尺寸对比图**（躺人示意）；差评三高发=太薄（EPE 克重虚标）、异味（PEVA 膜溶剂味——出货前散味）、收纳带断裂；
- **组合销售**：野餐篮套装（垫+篮+餐具——客单价翻倍）、沙滩组合（垫+遮阳伞+沙锚）；
- **南半球错峰**：澳洲 9-11 月补单——平衡产线淡季（见 `suppliers/garment-factory-hr-labor-management.md` 的淡旺季用工）。
