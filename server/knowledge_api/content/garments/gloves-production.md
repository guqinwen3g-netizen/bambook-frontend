# 手套生产与出口（Gloves: Sports, Work, Fashion & Winter Gloves）

手套是"小商品大订单"品类：SKU 小、单价低、起订量大、交期紧。产业带：山东高密/青岛（劳保浸胶）、江苏无锡/常州（运动滑雪）、浙江义乌（针织魔术手套）、河北辛集（皮手套）。四大产品线工艺差异极大，接单前先分清产线归属。

## 一、四大产品线

| 线 | 工艺 | 主产地 | 订单特征 |
|:---|:---|:---|:---|
| 针织手套（魔术手套/触屏） | 圆机编织+触屏纱指尖 | 义乌/嵊州 | 走量极大、单价 $0.3-1.5 |
| 缝制手套（滑雪/摩托/高尔夫） | 裁片车缝+防水袋+填充 | 无锡/常州/东莞 | 技术门槛高、单价 $3-15 |
| 浸胶劳保手套（丁腈/乳胶/PVC） | 针织内胆+浸胶线 | 山东高密 | 订单以"打"计、客户为工业品渠道 |
| 皮手套（时装/驾驶） | 皮革裁剪车缝 | 河北辛集/广东 | 材质溢价、冬季季节性 |

## 二、关键工艺要点

- **触屏纱**：指尖部位织入导电纱（银纤维/碳纤维混纺）——导电性能测试（屏幕响应率）逐批抽检；导电纱成本是普通纱 8-10 倍，掺假重灾区（见 `suppliers/incoming-material-inspection.md`）；
- **滑雪手套三层结构**：外层（防泼水尼龙）+防水袋（TPU/PU 膜内套——独立缝制后套入，**防水袋车缝后必须充气检漏**）+保暖填充（3M Thinsulate 新雪丽为行业标杆，仿品测试克重与克罗值）；
- **浸胶线**：起皱/磨砂/光面胶面、掌浸/半浸/全浸——胶料固含量与硫化温度决定耐磨与异味；劳保线核心是**耐磨等级**（EN 388）；
- **皮手套**：皮革利用率是成本命门（伤残避裁）——见 `garments/leather-fur-garment-production.md` 的皮革排料逻辑。

## 三、合规认证

- **劳保手套属 PPE**：欧盟 PPE Regulation (EU) 2016/425——EN 388（机械风险）/EN 407（热）/EN 511（防寒），CE 认证+公告机构测试；美国 ANSI/ISEA 105——详见 `trade-compliance/ppe-protective-clothing-compliance.md`；
- **滑雪/运动手套**：非 PPE（属消费品），但客户常要求防水透湿测试（静水压/RET）；
- **化学**：浸胶手套的促进剂（秋兰姆/噻唑类）致敏问题——欧盟 REACH 与皮肤科测试；乳胶蛋白过敏标注；
- **真皮**：CITES/EUDR 规则同皮革类（见 `trade-compliance/eudr-leather-deforestation.md`）。

## 四、报价与生产要点

- **报价单位**：行业惯例按"打"（12 双）报价——与客户确认打/双换算避免单证差错；
- **尺码体系**：欧码 6-12（掌围英寸）——同码不同手型（亚洲手偏短宽），欧美单放码表以买方为准（见 `garments/pattern-grading-sizing.md` 放码逻辑）；
- **配对检验**：左右手色差/尺寸差全检配对——针织手套色差投诉率最高；
- **季节性**：冬季手套 4-6 月下单、8-9 月交——与服装旺季重叠，产能冲突提前锁定（见 `suppliers/production-capacity-scheduling.md`）；
- **单耗损耗**：针织线废纱率 3-5%、浸胶线胶料损耗 8-12%——报价损耗率按工艺线区别计入。

## 五、客户与市场结构

- **劳保线**：工业品分销商（Würth/Grainger 模式）、建材超市（Home Depot 自有品牌）——价格敏感、订单巨大、验厂看产能与一致性；
- **运动线**：滑雪品牌（Hestra/Level 模式）、摩托装备（Dainese 模式）——技术文件要求高（防水/保暖测试报告），小单多款；
- **时装线**：百货渠道配饰区——真皮+羊绒里组合溢价（见 `customers-market/department-store-channel.md`）；
- **促销礼品线**：印 logo 针织手套——见 `customers-market/promotional-products-channel.md`。
