# 无缝针织生产专题（Seamless Knitting: 圣东尼圆机/一体织/程序制版/义乌产业带）

无缝针织用专用圆机一次织出筒形衣坯，省去大部分裁剪车缝——**贴身衣物无侧缝**的舒适体验使其成为内衣/塑身/运动服的高端工艺路线。品类应用见 `garments/underwear-lingerie-production.md`、`garments/shapewear-production.md`、`garments/compression-wear-production.md`，本文件聚焦**生产工艺与设备投资视角**：机器选型、纱线要求、程序制版与接单经济性。

## 一、设备与工艺原理

| 要素 | 要点 |
|:---|:---|
| 主机 | 意大利 Santoni（圣东尼，市占与保值率高）/国产（慈星、日发类）无缝内衣机 |
| 针筒口径×针数 | 12"/13"/14"/15"/16" 筒径 × E24-E32 针密——**筒径决定可织尺码，针密决定细腻度** |
| 成衣方式 | 全成型（whole garment，织出即成衣）/筒坯裁剪款（织筒状坯布→少量裁剪缝合） |
| 提花能力 | 电子选针单面提花——网眼/条纹/局部压力分区一织成型 |

- **一台机器一个口径**：做文胸与做 leggings 需要不同筒径——**设备组合决定可接品类**（新厂常配 13"+15" 两台起步）；
- **产量现实**：单件织造 3-8 分钟——单机日产仅 150-400 件，**设备折旧是成本大头**（圣东尼二手机 20-40 万/台）；
- **工序链**：织造→染色（匹染/成衣染）→烘干定型→少量缝合（裆部/肩带）→检验——**染色是外包给染厂的关键协作**（缸差管理见 `suppliers/dyeing-mill-cooperation-management.md` 逻辑）。

## 二、纱线与开发门槛

- **纱线要求高弹均匀**：锦纶 6/66 高弹丝+氨纶包覆纱（2040/2070 规格）——**纱线断头率直接决定开机效率**（断纱=废片），低端纱上无缝机必亏；
- **程序制版是核心人才**：无缝花型用专用软件（Santoni Photon/国产系统）编程序——**程序师薪资高于普通针织工艺师 50%+**，义乌/汕头产业带抢手；
- **打样周期**：新程序上机调试 2-3 天起——**打样费（500-2000 元/款）必须收**，否则被白嫖程序；
- **局部压力分区**：塑身/运动款靠组织密度差异实现压力梯度（非橡筋）——这是无缝对传统车缝款的**结构性优势**（无勒痕）。

## 三、接单经济性

- **MOQ 逻辑**：换程序+调机成本高——单色单款 <500 件不经济；**客户结构以小单为主的工厂慎投无缝**（小单快反逻辑见 `suppliers/garment-factory-small-order-flexible.md`，无缝路线与之天然冲突）；
- **报价构成**：织造费（按分钟计）+纱线成本（占比 40-55%）+染色+后整理——**氨纶含量每升 5% 纱线成本涨一档**；
- **品质命门**：漏针/横条（纱线张力不均）/尺码偏差（定型温度漂移）——验货重点看横档与拉伸回复（AQL 逻辑见 `garments/garment-defects-inspection.md`）；
- **尺寸体系**：无缝靠纱线弹性覆盖尺码——通常只做 S/M、L/XL 两至三档（"无尺码"概念由此来），**大码市场（2XL+）需大筒径机器**。

## 四、产业带与外贸

- **产业带**：义乌（无缝内衣之都，全球 70%+ 产能）/汕头谷饶/佛山盐步——义乌强项在中东非洲走量单，汕头强在品牌单；
- **外贸场景**：中东（高弹家居服）、欧美（无缝瑜伽/骑行内衣，见 `garments/activewear-production.md` 品类）、俄罗斯（保暖无缝内衣）；
- **升级方向**：无缝+功能纱线（抗菌/凉感，见 `fabric/functional-yarns.md`）组合溢价、无缝鞋面（与 `fabric/shoe-materials-flyknit-uppers.md` 飞织技术互通）。
