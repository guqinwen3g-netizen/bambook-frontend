# 摩托骑行服生产（Motorcycle Gear: CE护具/抗撕扯/皮革）

摩托骑行服是**PPE 属性最强的服装品类之一**：摔车滑行时面料与护具共同决定骑士生死——欧盟 2018 年起将摩托骑行服整体纳入 PPE II 类（EN 17092 系列标准）。市场=欧美摩托文化成熟市场（Dainese/Alpinestars/REV'IT! 品牌梯队），客单价 $200-800。技术门槛=**抗撕扯面料+CE 护具结构+认证体系**，非普通服装厂可切入。

## 一、标准与认证（准入前提）

- **EN 17092 系列**（欧盟 PPE）：
  - EN 17092-2 AAA 级（竞赛/高速——抗磨最高）、AA 级（公路骑行主流）、A 级（城市通勤）；
  - -3 夏季网眼款 / -4 拉力款（adventure） / -5 防水款（附加透湿）；
  - 测试：抗磨损（Darmstadt 滚筒滑行模拟）/接缝撕破/冲击（护具位）/尺寸稳定；
- **护具 CE**：EN 1621-1（四肢护具）/1621-2（背板）/1621-3（胸板）——Level 1/Level 2 冲击吸收分级；护具通常外购（D3O/SAS-TEC 模式）+服装预留护具袋；
- **美国**：无联邦强制（DOT 只管头盔）——但品牌自测 EN 标准作卖点；加州 Prop 65（皮革六价铬——见 `trade-compliance/california-prop65.md`）；
- **认证纪律**：**无 CE 证书宣称"protective motorcycle clothing"出口欧盟=清关扣货**；认证主体可以是品牌（工厂配合——见 `trade-compliance/ppe-protective-clothing-compliance.md` 的责任划分）。

## 二、材料体系

| 部位 | 材料 | 指标 |
|:---|:---|:---|
| 主体（纺织款） | 考杜拉 500D-1000D/高密尼龙 | 抗磨 AAA 需复合 |
| 主体（皮革款） | 牛皮 1.2-1.4mm（摔车滑行王者） | 抗撕 100N+（见 `garments/leather-fur-garment-production.md`） |
| 高风险区补强 | 牛皮复合/凯夫拉混纺/SuperFabric | 肩肘臀膝 |
| 弹力区 | 凯夫拉+氨纶/皮质弹力褶 | 腋下裆部活动量 |
| 内衬 | 网眼（透气）/防水膜（ touring 款——见 `fabric/functional-coating-lamination.md`） | 可拆卸保暖内胆 |

- **抗磨真相**：单层纺织面料难过 AA——主流方案=**面料+凯夫拉衬里复合**（凯夫拉含量 60%+ 的 aramid lining 是 AAA 关键）；
- **皮革六价铬**：欧盟 REACH 限 3mg/kg——铬鞣皮批次检测（见 `trade-compliance/chemical-environmental-compliance.md`）。

## 三、生产工艺要点

- **护具袋结构**：护具**必须贴合不移位**（摔车时护具在冲击点才有用）——护具袋尺寸按护具型号精配+弹力固定；可调节护具袋（多档魔术贴）是高端线；
- **接缝**：主接缝**双针/三针链式+高强尼龙线/凯夫拉线**（N66 邦迪——见 `suppliers/sewing-thread-needles.md`）；EN 17092 接缝撕破测试——普通涤线直接不合格；
- **立体版型**：骑行姿势前倾版型（pre-curved 袖/膝）——站立试穿合体≠骑行合体（样衣用骑行姿态人台/真人骑姿试穿）；
- **通风系统**：胸背拉链通风口（网眼内衬）——夏季款卖点；
- **反光**：夜间可视（反光膜/反光印花——见 `fabric/hi-vis-reflective-fabrics.md`）；
- **连接系统**：骑行裤-夹克拉链连接（防摔车上窜露腰——8 英寸连接拉链是标准配置）；
- **测试全检**：每件护具在位检查+主接缝抽测撕破。

## 四、市场与接单

- **品牌梯队**：Dainese/Alpinestars（意大利竞赛）/REV'IT!/Klim（荷兰/美国 touring）/Icon（美国街文化）——代工准入=技术文件+CE 配合+小单多款；
- **白牌机会**：亚马逊摩托配件卖家（CE 证书共享模式——买现成证书款的贴牌）；亚洲摩托通勤市场（东南亚——见 `customers-market/southeast-asia-market.md`）；
- **报价**：面料（凯夫拉衬里是成本重头）+护具（外购 $10-30/套）+人工（皮革/厚料设备工价高）——加工费是普通夹克 3 倍+；
- **MOQ**：品牌款 300-500 件；皮款 100-200 件（皮革张幅利用率）；
- **手套/靴协同**：摩托手套（见 `garments/gloves-production.md`）与骑行靴常打包投标。
