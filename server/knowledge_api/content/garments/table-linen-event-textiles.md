# 桌布与宴会纺织品（Table Linen & Event Textiles: 酒店/婚礼/餐饮）

宴会纺织品=桌布/餐巾/椅套/桌旗/背景纱幔，三大订单来源：酒店餐饮（见 `garments/hotel-linen-b2b.md` 的工业洗逻辑）、婚礼宴会租赁公司（欧美 wedding rental 产业）、派对用品电商。核心指标是**耐污易洗+垂感+尺寸规格齐全**。

## 一、产品体系

| 产品 | 主流面料 | 规格惯例 | 要点 |
|:---|:---|:---|:---|
| 桌布（round/rectangle） | 全涤平纹/缎面/提花 | 90"×132"、120" 圆等标准尺寸系列 | 垂感与免烫 |
| 餐巾 | 全涤/涤棉/亚麻 | 20"×20" 标准 | 折花成型性 |
| 椅套 | 弹力氨纶布/缎面 | 通用椅型+弹力带 | 弹性包容不同椅 |
| 桌旗/桌裙 | 色丁/欧根纱 | 12"×108" 等 | 色彩搭配体系 |
| 背景纱幔（backdrop） | 雪纺/冰丝 | 10ft×10ft 模块 | 透光层次 |

- **全涤为主流**：宴会布草要耐工业洗+免烫——全棉桌布只在高端餐厅（亚麻同理，见 `fabric/silk-linen-fabrics.md`）；
- **尺寸体系**：欧美宴会桌标准尺寸（6ft/8ft 长桌、60"/72" 圆桌）决定桌布规格——**做"桌布下垂长度"对照表**是详情页必备。

## 二、生产与品质要点

- **锁边工艺**：桌布四边卷边（rolled hem）或密拷——边部起皱/波浪是最大外观投诉（针织弹力布用三针五线）；
- **耐污整理**：Teflon/纳米三防整理（防水防油防污——红酒咖啡一擦即净是核心卖点）——**洗后三防保持率**分级报价（10 次/30 次洗后有效）；PFAS 无氟化趋势注意（见 `trade-compliance/pfas-restriction-fluorine-free.md`）；
- **颜色体系**：宴会单按色卡选色（婚礼季流行色—— blush pink/sage green 等）——同场多件套**色差控制严格**（桌布+椅套+餐巾同色系配套，见 `fabric/color-management-pantone-measurement.md`）；
- **抗皱**：全涤表观考核免烫性——包装折痕（真空压缩后挂烫恢复性）测试；
- **椅套弹力**：氨纶含量 10-15%——拉伸回复率（5000 次拉伸后松弛度）抽检。

## 三、订单渠道

- **宴会租赁公司**（美国 party rental 产业）：补货单稳定——按损耗率年度采购；要求**尺寸/颜色长期一致**（库存混用）；
- **婚礼策划供应链**：季节性高峰（5-10 月婚礼季）——交期敏感（婚期不可延）；
- **餐饮连锁**：耐洗次数与单价平衡（同酒店布草经济学）；
- **电商零售**：亚马逊婚礼类目（bride 搜索词）、派对用品——套装（桌布+椅套+餐巾）销售；
- **教堂/会场**：大额低频定制（绣徽标）。

## 四、报价与物流

- **报价按尺寸阶梯**：同款不同尺寸价差按比例——**面积计价法**（单价/平方英尺基准）便于客户核价；
- **套件折扣**：桌布+餐巾组合价（1+12 模式）——提客单价；
- **物流**：涤纶布草压缩包装——40HQ 可装 8-10 万件餐巾级产品；注意防潮（海运高湿——面料含湿霉变，见 `trade-process/sea-freight-practice.md`）；
- **备货模式**：租赁公司客户接受"年度框架+分批交货"——工厂端面料备坯定染（见 `fabric/fabric-inventory-stock-strategy.md`）。

## 五、常见坑

| 坑 | 后果 | 预防 |
|:---|:---|:---|
| 卷边波浪 | 铺设不平整退货 | 卷边拉筒+针距密度 SOP |
| 色差（套装内） | 婚礼现场投诉 | 同缸染+分缸管理 |
| 尺寸缩水 | 盖不住桌脚 | 预缩+洗后尺寸标注 |
| 三防失效快 | 差评 | 洗后保持率如实分级 |
| 污渍残留（退货翻新单） | 租赁公司纠纷 | 出厂污点全检灯检台 |
