# 羊绒大衣生产深化（Cashmere Coat Production: 纯羊绒分级/水波纹工艺/奢侈大衣）

羊绒大衣是"**大衣品类的价格天花板**"：一件 Max Mara 纯羊绒大衣零售 €3,000-8,000，而原料成本差异可达 10 倍——**原料分级认知是羊绒贸易的核心**。泛毛呢大衣见 `garments/wool-coat-production.md`，大衣呢面料见 `fabric/wool-overcoating-fabrics.md`，原料基础见 `fabric/wool-cashmere-fabrics.md`——本文件聚焦**纯羊绒大衣的深度实务**。

## 一、羊绒原料分级（价格差异的根源）

| 等级 | 细度 | 长度 | 原料价（kg） | 应用 |
|:---|:---|:---|:---|:---|
| 小山羊绒（baby cashmere） | 13-14.5μm | 30-34mm | $300-500 | Loro Piana 顶级线 |
| 头道羊绒（first grade） | 14-15.5μm | 34-38mm | $150-250 | 奢侈品牌主力 |
| 常规羊绒 | 15.5-16.5μm | 28-34mm | $100-150 | 中高端 |
| 粗羊绒/短绒 | >16.5μm | <28mm | $60-100 | 混纺/入门款 |

- **产地**：中国内蒙古（全球 70% 产量——阿拉善白山羊绒最优）/蒙古国/伊朗/阿富汗；
- **采集**：梳绒（spring combing）——**羊绒是春天自然脱落的山羊底层绒毛，剪毛 vs 梳绒的品质差异**；
- **检测**：细度（激光扫描仪）/长度/含粗率——**含粗毛率 >0.5% 的批次刺痒感明显**。

## 二、纯羊绒 vs 混纺的商业逻辑

- **100% 羊绒**：顶级款——**柔软巅峰但耐磨性差（肘部/袋口易磨损）**；
- **羊绒+羊毛（10/90, 20/80, 30/70）**：主流高端——**羊毛骨架提升耐用性，羊绒提供手感**；
- **羊绒+真丝**：光泽与垂感升级——**女式大衣常用**；
- **营销话术红线**："羊绒大衣"标签需成分 ≥30%（中国国标）——**欧盟/美国按实际含量标注，虚标是法律风险**。

## 三、水波纹与高端后整理

- **水波纹（wave finish/ondulato）**：
  - 工艺：刺果起绒后湿态定型出波纹——**意大利水波纹机+蒸汽定型的设备门槛**；
  - 视觉：波光流动的呢面效果——**Max Mara 101801 的标志性风格**；
  - 品质检验：波纹均匀度/洗后保形性——**劣质水波纹水洗后变平**；
- **轻缩绒（milled finish）**：表面微绒——**"婴儿肌触感"的来源**；
- **双面羊绒**：两层羊绒呢剖缝手缝（双面呢工艺的羊绒版）——**工时 20-30 小时/件，是双面羊毛的 1.5 倍**（羊绒更娇贵，剖缝容错率低）。

## 四、生产工艺要点

- **裁剪**：羊绒呢面的方向性（顺毛裁剪）——**所有裁片同向排料，耗料 +8-12%**；
- **缝制**：
  - 针距加密（3cm 14-16 针）——**防羊绒面料劈裂**；
  - 缝份包光——羊绒掉毛特性要求缝份全封闭；
  - 低温熨烫（垫布+蒸汽）——**羊绒呢面压光是毁灭性工艺事故**；
- **辅料**：真丝/宾霸里布（化纤里布配羊绒=档次错位）——**里布成本占比允许到 8-10%**。

## 五、成本与定价结构

- **面料成本**：纯羊绒呢 ¥600-1,500/m（14-15μm 级）——**一件大衣用料 2.5-3m，面料成本 ¥1,800-4,500**；
- **加工费**：双面手缝款 ¥400-800/件；
- **出厂价**：纯羊绒大衣 ¥2,500-6,000——**零售倍率 4-8 倍（奢侈品牌 8-12 倍）**；
- **订单特征**：奢侈品牌 500-2,000 件/款的纯羊绒订单——**中国是主要承接地（鄂尔多斯产业链+大连/江浙精品厂）**。

## 六、贸易品控红线

| 检验点 | 标准 |
|:---|:---|
| 成分 | 第三方检测（SGS/ITS 纤维含量）——**羊绒含量虚标是行业第一欺诈** |
| 细度 | 与订单等级一致（μm 实测） |
| 掉毛率 | 摩擦测试——羊绒大衣掉毛客诉红线 |
| 起球 | 4 级+（马丁代尔法） |
| 手感 | 软糯不刺痒——含粗率的主观+客观双判 |
| 水波纹 | 波纹均匀+干洗 3 次后保形 |
