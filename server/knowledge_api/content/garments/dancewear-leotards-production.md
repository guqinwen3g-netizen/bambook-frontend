# 舞蹈服与体操服生产（Dancewear & Leotards: 弹力贴身/舞台线）

舞蹈服是**小单多款+高弹工艺**的细分品类：芭蕾练功服（leotard）、体操服、拉丁/爵士舞服、舞蹈裙（tutu）、舞蹈袜裤。美国舞蹈用品市场由培训学区（每年 recital 汇报演出季）驱动——**校服式集采**（舞蹈学校统一订款）。生产=泳装工艺的近亲（高弹贴身，见 `garments/swimwear-production.md`），差异在无抗氯要求+舞台装饰性。

## 一、产品线与面料

| 产品 | 面料 | 结构要点 |
|:---|:---|:---|
| 芭蕾练功服（leotard） | 棉氨/锦氨（20-25% 氨纶） | 全衬前片/芭蕾领/包臀 |
| 体操比赛服 | 锦氨+烫钻/镭射印花 | 长袖竞赛款（FIG 规则覆盖度） |
| 拉丁舞服 | 弹力天鹅绒/流苏/网纱拼接 | 动感摆裙/露背 |
| Tutu 裙 | 硬网纱（6-8 层）+弹力腰 | 撑度=网纱硬度层数 |
| 舞蹈袜裤（tights） | 尼龙氨纶 | 包脚/踩脚/转换口 |

- **弹力基准**：四向拉伸（4-way stretch）+**回复率 95%+**（贴身不松垮——锦氨见 `fabric/nylon-spandex-stretch-fabrics.md`）；
- **前片全衬**：练功服前片加衬（防凸点——专业线标配，衬布同色系）；
- **舞台面料**：弹力天鹅绒（光泽+垂感，见 `fabric/velvet-faux-fur-fabrics.md`）、亮片布、镭射弹力布——**亮片掉粉掉片**是差评高发（缝制前震荡测试）。

## 二、生产工艺要点

- **绷缝/四针六线**：高弹拼缝（线迹随拉伸不断线——见 `garments/sewing-and-workmanship.md` 的弹力线迹）；领口袖窿橡筋包边（宽窄一致是验货点）；
- **烫钻/装饰**：热固烫钻（洗涤 20 次不脱落——高温熨烫牢度测试）；体操服钻饰按 FIG 规则位置；
- **Tutu 网纱**：硬网裁圆片锁边（不散边）——层数与撑度对应表随单；
- **裆部**：按扣裆（幼儿款换尿布逻辑）/三角包臀（竞赛款防滑上移——**包臀橡筋松紧**决定动作走光风险）；
- **尺码**：舞蹈服**负松量**（贴身——尺码表给胸围/臀围/裆长 girth 三围，girth 是舞蹈服特有维度）；儿童成长尺码买大一码的退货沟通。

## 三、合规与市场

- **童装合规**：儿童舞蹈服属 CPSIA 范围（铅/邻苯/小部件——亮片烫钻属小部件拉力测试，见 `trade-compliance/cpsc-children-safety.md`）；亮片边缘划伤是投诉点；
- **阻燃**：舞台演出服在剧院场景部分州查阻燃（与 `garments/stage-theatre-drapes.md` 场景同源——演出合同条款确认）；
- **渠道**：舞蹈用品批发商（Revolution/Weissman 模式——recital 季目录集采）、舞蹈学校定制（logo 绣花+指定款）、亚马逊（练功服走量）；
- **季节铁律**：美国 recital 季 5-6 月——**前一年 Q4 下单 Q1 交付**（演出服误季=报废，见 `trade-process/annual-sourcing-calendar.md`）；
- **款式纪律**：按客户授权款生产（Weissman 等目录款有版权——仿款接单查 IP，见 `trade-compliance/ip-brand-authorization.md`）。

## 四、报价与接单

- **报价拆项**：锦氨面料+装饰（烫钻按面积计价/流苏按码）+人工（高弹工艺工价上浮 30%）；
- **MOQ**：练功服现货面料 300-500 件；竞赛服定制 100 件/款（小单多款常态）；
- **利润点**：竞赛服/团体定制（溢价高+复购——每年新 recital 主题）；练功服是引流基础款（价格战区）。
