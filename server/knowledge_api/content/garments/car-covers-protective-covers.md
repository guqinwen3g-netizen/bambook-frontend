# 车衣与防护罩生产（Protective Covers: 车衣/烧烤罩/家具罩/机器罩）

防护罩是"**涂层布裁剪+包边车缝**"的标品化品类：车衣、摩托罩、烧烤罩（BBQ cover）、户外家具罩、空调罩、机器设备罩。逻辑统一——**按设备尺寸做合身的防水防尘套**。生产门槛低，竞争力在**尺寸数据库+面料等级矩阵+亚马逊运营**。与户外庭院纺织（见 `garments/outdoor-patio-textiles.md`）共享面料体系，本文聚焦"罩"的成品逻辑。

## 二、生产要害

- **面料核心指标**：**静水压（≥1000mm 防水宣称）+抗 UV（户外寿命 2-3 年——420D 以下面料 1 年粉化）+耐低温（-20℃ 不脆裂——北方市场）**；涂银层脱落（低价铝膜复合 6 个月脱银差评高发）；
- **尺寸数据库**：车衣按车型尺码分 8-12 档（S 轿车到 XXL SUV——**尺码对照表是 listing 转化核心**）；家具罩按椅子/沙发/桌子标准尺寸系列化（美标 patio 尺寸体系）；
- **结构细节**：车衣**镜袋立体剪裁**（后视镜凸出位——版型贴合度分水岭）；门拉链（驾驶位取物）；**防风带**（车底穿带+卡扣——大风刮走是头号差评）；家具罩**通风口**（密闭冷凝水发霉——透气窗+网布）；
- **车缝工艺**：双针埋夹（防水压胶条升级款——缝线针孔渗水投诉）；包边条 4cm 双折；底摆**松紧带穿绳+调节扣**；
- **配件**：收纳袋（同面料束口袋标配）、防风带、锁扣绳。

## 三、合规与宣称

- **防水宣称**："100% waterproof"需静水压+接缝压胶双支撑——否则"water-resistant"（亚马逊宣称审查趋严）；
- **抗 UV 宣称**："UV protection UPF50+"按 AATCC 183 测试（与防晒服同体系——见 `garments/sun-protection-clothing.md`）；
- **化学**：PVC/PEVA 邻苯+铅（Prop 65——见 `trade-compliance/california-prop65.md`）；涂银层**铝粉迁移**（浅色车漆染色投诉——内里加绒层规避）；
- **阻燃**：烧烤罩**远离明火警示**（牛津布不阻燃——警示标签必备）；壁炉罩需阻燃面料特规；
- **专利雷区**：经典车衣折叠收纳结构、烧烤罩通风口设计有外观专利（开款前 FTO——见 `trade-compliance/ip-brand-authorization.md`）。

## 四、市场与运营

- **亚马逊标品逻辑**：关键词大词垄断（car cover/bbq cover——头部 listing 万评壁垒）——**差异化切口：尺寸精准营销（"fits 2020-2026 Honda CRV"车型专属款）+场景图（暴雪/暴晒/落叶）**；
- **季节节奏**：车衣双高峰（春季防花粉+冬季防雪——9 月/3 月备货）；烧烤罩春季（4-5 月烧烤季前置）；家具罩秋季（入冬收纳 9-10 月）；
- **B2B 渠道**：4S 店赠品（车衣印刷 Logo）、家具品牌配套罩（patio 家具套装绑定销售）、设备厂 OEM（发电机原厂罩）；
- **差评三高发**：尺寸不准（尺码表混乱——**必须给测量方法图示**）、面料粉化（低价 190T 一年报废——420D+ 宣称耐用）、防风失效（无风带设计）；
- **产业带**：河北（车衣集群——清河/南宫）、浙江（牛津布+车缝一体）、广东（高端复合面料款）。
