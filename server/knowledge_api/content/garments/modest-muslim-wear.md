# 穆斯林服饰品类专题（Modest & Muslim Fashion）

穆斯林服饰是"**全球 19 亿人口 + 斋月强周期**"的特色品类：abaya 长袍从中东刚需演变为时尚单品——modest fashion 已进主流时装周。

## 一、核心品类

| 品类 | 特征 |
|:---|:---|
| Abaya（长袍） | 海湾国家女性外袍（黑色经典款→时尚化彩色/刺绣/拼接） |
| Hijab（头巾） | 日常头巾（雪纺/棉/针织——花色快时尚化） |
| Jilbab/Khimar | 全身罩袍（更保守——东南亚市场主流） |
| 礼拜服（prayer garment） | 礼拜专用（白色/浅色——telekung 东南亚两件套） |
| 男士 Thobe/Jubba | 男士长袍（白/浅色——海湾正装） |
| 穆斯林泳装（burkini） | 全覆盖泳装（法国曾争议——市场稳定增长） |

## 二、市场分布与差异

- **海湾六国（沙特/阿联酋）**：客单价最高（abaya 高端化——刺绣/钉珠/品牌款，见 `customers-market/middle-east-market.md`）;
- **东南亚（印尼/马来）**：全球穆斯林人口第一大区——jilbab+头巾花色时尚（韩系影响，见 `customers-market/southeast-asia-market.md`）;
- **土耳其**：本土设计强（modest fashion 输出国——竞争+合作）;
- **欧美穆斯林**：二线市场（英法国穆斯林社群——burkini 需求）。

## 三、斋月周期（年度节奏锚点）

- **斋月旺季**：斋月前 1-2 个月下单高峰（开斋节新衣传统——相当于西方圣诞季）;
- **斋月时间**：每年提前约 11 天（伊斯兰历——2026 年斋月约 2/18-3/19，开斋节 3 月中下旬）;
- **生产倒排**：开斋节前到货——前推物流 1 个月+生产 1-2 个月（下单窗口节前 3-4 个月）;
- **斋月后淡季**：排产避让（中东夏季+斋月后双重淡）。

## 四、产品要点

- **面料**：垂感+不透光（覆盖性要求——雪纺/nida 韩国面料/缎面）;黑色 abaya 讲究黑度纯正（深黑染色工艺）;
- **功能**：透气（海湾高温 50℃——闷是最大痛点）/防皱（礼拜折叠携带）;
- **版型**：宽松（不得显身形——保守款 A 字/直筒）;
- **细节**：钉珠/刺绣/蕾丝拼接（时尚款溢价点——见 `fabric/lace-and-embroidery-fabrics.md`）;
- **尺码**：中东体型+覆盖长度（衣长 140cm+ 常态——用料多报价注意）。

## 五、文化与合规红线

- **图案禁忌**：不得有人物/动物图案（保守市场——几何/花卉安全）;
- **十字架等符号**：严禁（宗教敏感——印绣花稿必审）;
- **透明度**：面料透光=退货（透测试纳入验货）;
- **营销**：模特图需符合当地审美（海湾电商模特戴头巾/无面部特写）;
- **认证**：无特殊强制认证，但 SABER（沙特）/ECAS（阿联酋）清关认证适用（见 `trade-compliance/market-access.md`）。

## 六、订单与渠道

- **B2B**：迪拜是中东服装集散中心（批发市场+展会——中国供应商对接窗口）;
- **跨境电商**：SHEIN/速卖通中东站（斋月大促——物流用中东专线）;
- **本土电商**：Noon/亚马逊中东站（沙特占比最高）;
- **产业带**：广州（穆斯林服饰集群——阿拉伯商人聚集地）/义乌（头巾小商品）。
