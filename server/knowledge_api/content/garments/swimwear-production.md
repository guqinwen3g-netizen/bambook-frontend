# 泳装生产专题（Swimwear Production）

泳装（swimwear）是高弹性小品类：面料四面弹力、工艺贴身、单价低但返单快（欧美夏季快消品）。版型与弹性控制是质量核心。

## 一、面料

| 要素 | 说明 |
|:---|:---|
| 成分 | **锦纶 80-82% + 氨纶 18-20%**（主流）；涤氨（印花牢度好、耐氯强） |
| 克重 | 180-220 gsm；竞赛款压缩面料 250+ |
| 弹性 | 四向弹力（4-way stretch），伸长率纵向 80-120% |
| 耐氯（chlorine resistant） | 泳池场景必备——普通氨纶遇氯脆化，耐氯氨纶（Xtra Life Lycra）寿命 5-10 倍 |
| 抗 UV | UPF 50+（户外/儿童泳装强制趋势） |
| 里布 | 泳装专用弹力里布（前片/裆部） |

## 二、工艺要点

1. **裁剪**：弹力面料铺布松量控制（张力导致裁片变形）；激光裁剪/刀模。
2. **缝制**：
   - 四针六线拼缝（同运动服）；
   - **绷缝（coverstitch）**下摆/脚口——拉伸不断线；
   - **橡筋（elastic）**：腿口/腰口橡筋张力均匀（泳装专用耐氯橡筋），橡筋回缩率按版型计算（通常负量 10-15% 收身）。
3. **罩杯/插片**：文胸式泳衣的模杯与插袋工艺（同内衣，见 `garments/underwear-lingerie-production.md`）。
4. **配件**：调节扣/背扣需耐盐水腐蚀（塑胶/涂层金属）。

## 三、印花

- **数码印花**主导（小批量多花型快返——见 `fabric/digital-printing-technology.md`）；涤氨面料用分散直喷，锦氨用酸性/活性印花。
- **定位印花（placement print）**：裁片印花后缝制，对位精度要求高。
- 色牢度特殊项：**耐海水/耐氯水/耐防晒霜**色牢度测试（AATCC 162/106）。

## 四、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 拉伸回复率 | 拉伸后回复 ≥ 90%（松垮是泳装第一质量杀手） |
| 耐氯测试 | 50 次泳池水浸泡后强力保持率 |
| 色牢度 | 耐氯水/耐海水/耐汗/耐光（户外曝晒场景） |
| 尺寸 | 按拉伸状态测量（湿态尺寸变化） |
| 透湿/速干 | 上岸速干体验 |
| 金属件盐雾 | 48h 盐雾测试（海滨场景） |

## 五、市场特征

- **季节节奏**：欧美夏季品——下单窗口 10-12 月（次年 4-6 月上市）；澳洲反季（6-8 月下单）。
- **渠道**：快时尚泳装线（Zara/H&M 泳装）、专业品牌（Speedo/arena 竞赛线）、跨境电商大单品（亚马逊泳装类目红海）。
- **版型文化**：欧美比基尼 vs 中东保守款（burkini 全覆盖泳装——清真市场增长品类）vs 亚洲连体保守款。
- **儿童泳装**：UPF 50+ 强制趋势 + 鲜艳高可视色（安全）。

## 六、报价与产业带

- **成本结构**：面料占 40-50%（耐氯氨纶面料 40-70 元/kg）；小件但工序精细，CMT 12-25 元。
- **产业带**：辽宁兴城（中国泳装之都，全球 25% 产能）、福建晋江、浙江义乌。
- **MOQ**：500-1000 件/色（数码印花可降至 300）。
