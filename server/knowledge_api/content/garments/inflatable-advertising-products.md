# 充气广告产品生产（Inflatables: 气模/充气拱门/充气帐篷/风机选型）

充气产品是"**涂层布+风机系统**"的结构性品类：开业拱门、充气卡通（品牌吉祥物）、充气帐篷（活动/广告）、充气电影屏、充气城堡（游乐——安全标准独立且严格）。广告渠道与促销品协同（见 `customers-market/promotional-products-channel.md`）、旗帜横幅相邻（见 `garments/flags-banners-production.md`）。产业带：广州/东莞、河北白洋淀。

## 一、产品体系与材料

| 产品 | 材料 | 工艺 | 价格带（出厂） |
|:---|:---|:---|:---|
| 充气拱门/立柱 | 210D-420D 牛津布 PU 涂层 | 连续送风（常开风机） | ¥300-1500 |
| 充气卡通/吉祥物 | 420D 牛津/喷绘布 | 数码印花或贴布绣造型 | ¥800-8000（按尺寸复杂度） |
| 充气帐篷（event tent） | 420D-840D + TPU 气柱 | **闭气式（TPU 内胆充气管——充满可断风机）** | ¥2000-20000 |
| 充气电影屏 | 投影专用涂层布 | 框架气柱+幕面 | ¥3000-15000 |
| 充气城堡/滑梯 | **0.45-0.55mm PVC 夹网布** | 高频焊接 | 游乐设备——EN 14960/ASTM F2374 强制 |

- **连续送风 vs 闭气式**：广告小件多连续送风（风机常开——断电即瘪）；帐篷/大型结构用 TPU 闭气气柱（一体成型充气管——保压 3-7 天）；
- **PVC 夹网布**：游乐级——抗撕裂+耐磨+阻燃（B1/NFPA 701）。

## 二、生产要害

- **造型打版**：3D 造型转平面裁片（放样软件——气模变形量经验系数：充气后尺寸缩 8-15%，打版预放量）；
- **缝制 vs 焊接**：牛津布车缝（针孔微漏——连续送风补偿）；PVC/TPU 高频焊接（气密）；
- **印花**：数码直喷（见 `fabric/digital-printing-technology.md`）——喷绘布注意**色彩 UV 耐候**（户外广告褪色——颜料墨水/UV 墨水选型）；
- **风机匹配**：功率按产品体积/泄漏率选型（瓦数不足=疲软塌腰）；**风机认证**（CE/UL——电路安全出口强制）+ 防雨型（户外）；
- **锚固系统**：沙袋/D 环/风绳配重——**大风安全事故是行业最大风险**（充气城堡被风吹起伤亡事故多国通报——锚固数量与拉力强制的 ASTM 标准）；

## 三、合规与安全

- **游乐设备线**（充气城堡/滑梯）：欧盟 EN 14960+CE（公告机构）、美国 ASTM F2374——**承压件年检+操作员培训要求**；出口该线需产品责任险高保额（见 `trade-compliance/product-liability-recall.md`）；
- **广告气模线**：普通产品（非承压载人不属游乐设备）——阻燃（活动场地消防要求 NFPA 701/B1）、风机电气安全（CE-LVD/UL）、Prop 65（PVC 邻苯——见 `trade-compliance/california-prop65.md`）；
- **LED 内照明**：夜间广告效果——低压 12V LED 系统安全性；
- **知识产权**：**卡通形象侵权是重灾区**（迪士尼/宝可梦造型订单——必须查授权，见 `trade-compliance/ip-brand-authorization.md`）；企业吉祥物定制需客户提供商标/著作权证明。

## 四、市场与订单

- **渠道**：广告物料公司/活动策划公司（B2B 复购）、展会搭建商、电商（亚马逊充气庭院装饰——万圣节/圣诞节品类爆发）、租赁公司（活动设备租赁——耐用性采购）；
- **季节脉冲**：美国万圣节充气装饰（9-10 月零售峰值——6 月前出货）、圣诞（11 月）；国内开业/店庆常年需求；
- **定制流程**：客户提供 AI/CDR 矢量图→效果图确认→打样（小单可跳过）→大货 10-15 天；
- **物流**：充气产品压缩后体积小（物流友好）——但风机配件单独包装（易损）；
- **客诉热点**：漏气（焊缝/面料针孔——出厂 24h 充气保压测试）、印花色差、风机烧毁（电压不匹配——美规 110V 风机备货区分）、锚固配件缺失。
