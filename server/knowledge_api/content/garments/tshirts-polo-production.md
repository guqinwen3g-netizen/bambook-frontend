# T恤与POLO衫品类专题（T-Shirt & Polo Production）

T恤/POLO 是**全球第一大单品**（量大、翻单稳、工艺标准化）——外贸的"现金牛品类"，也是新人练手的起点。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 圆领 T 恤 | 最基础（文化衫/打底衫/印花载体） |
| V 领 T 恤 | 领型变体 |
| POLO 衫 | 翻领+门襟——商务休闲主力（珠地网眼面料是标志） |
| 长袖 T 恤 | 春秋款 |
| 重磅 T 恤 | 220gsm+（街头潮牌风——面料厚实挺括） |
| 口袋 T 恤 | 贴袋设计 |
| 亨利领 | 无领门襟（介于 T 恤与 POLO） |

## 二、面料配套

- **汗布**（单面平纹）：T 恤主力（180-220gsm——见 `fabric/knitted-fabrics.md`）；
- **珠地网眼**：POLO 衫标志面料（透气网眼结构）；
- **棉氨**：贴身款（弹力）；
- **重磅**：220-300gsm（潮牌——oversize 挺括）；
- **成分**：100% 棉 / 棉涤（CVC/TC——性价比）/ 棉氨 / 功能性（速干）。

## 三、核心工艺

### 领口（第一品质焦点）
- **罗纹领**：领口罗纹（1x1 罗纹——领围弹性服帖）；
- **本布领**：同面料滚边（成本款）；
- **领口加固**：后领压条（neck tape——防变形+遮缝份）；
- **品质点**：领口不起浪（罗纹与衣身配比——拉得过紧起波浪/过松荷叶边）。

### POLO 衫门襟
- **门襟（placket）**：2-3 扣门襟——门襟衬（挺括）；
- **领子**：扁机领（knitted collar——横机织的领片）vs 裁剪领（面料裁剪）——扁机领是 POLO 品质标志。

### 缝制
- **绷缝**（cover stitch）：下摆/袖口绷缝（针织标准——弹性线迹）；
- **肩缝**：平缝+加固带（shoulder tape——防拉伸变形）。

## 四、印花/绣花（文化衫的灵魂）

- **丝印**：胶浆/水浆（大面积图案——见 `garments/printing-embroidery.md`）；
- **热转印**：文化衫小批量（DIY/定制）；
- **绣花**：POLO 衫左胸 logo（商务 POLO 的标志位置）；
- **位置**：左胸/后背/全幅——印花位置对版型排版影响。

## 五、订单特征

- **量大利薄**：T 恤是"跑量"品类（单价低 $1-3——利润靠量与效率）；
- **翻单稳定**：品牌基础款常年翻单（白 T 是万年款）；
- **促销单**：活动文化衫（量大交期急——广告衫市场）;
- **定制市场**：POD（print on demand——一件起印的跨境定制，见 `fabric/digital-printing-technology.md`）。

## 六、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 领口 | 罗纹平整无波浪、领围尺寸 |
| 尺寸 | 胸围/衣长公差（±1.5cm） |
| 色差 | 同批缸差（针织面料缸差敏感） |
| 印花 | 位置/对色/牢度（洗后不开裂） |
| 缝制 | 绷缝线迹均匀、无跳针 |
| 缩水 | 针织棉缩水（未预缩面料成衣洗后缩） |

## 七、成本与产业带

- **成本结构**：T 恤面料占 50%+（见 `suppliers/supplier-cost-analysis.md` T 恤试算 $2.95）；
- **产业带**：广东佛山/中山（针织集群）、浙江（宁波/绍兴）、山东（即墨针织）；
- **快反**：T 恤是快反核心品类（Shein 模式——见 `customers-market/fast-fashion-shein-model.md`）。
