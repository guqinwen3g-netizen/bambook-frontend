# 舞台幕布与剧院纺织品（Stage Drapes: 阻燃丝绒/大幕工程/演出场馆）

舞台幕布是"**阻燃+声学+机械系统**"交叉的工程纺织品：大剧院大幕/边幕/檐幕/纱幕/天幕，会议中心、学校礼堂、影院同款逻辑。订单=场馆新建/翻新工程（设计院规格书）+巡演布景定制。客户=剧场工程商、舞美公司、文化设施集采。市场窄但客单高、竞争者少。

## 一、幕布体系与材料

| 幕位 | 功能 | 材料 | 工艺要点 |
|:---|:---|:---|:---|
| 大幕（front curtain） | 舞台门面，升降/对开 | 阻燃丝绒（棉绒/涤绒——金丝绒/天鹅绒，见 `fabric/velvet-faux-fur-fabrics.md`） | 三倍打褶（饱满感）+配重底边 |
| 边幕/檐幕（legs/borders） | 遮挡侧台/顶部设备 | 阻燃绒布/帆布 | 黑色为主、吸光 |
| 纱幕（scrim） | 透景/投影介质 | 玻纤纱/涤纶纱网 | 透编织法——前投实后投虚的光学特性 |
| 天幕（cyclorama） | 背景投影面 | 无缝宽幅棉/涤帆布（可 12m+ 整幅） | 接缝平整度（投影穿帮） |
| 星空幕 | 装饰效果 | 黑绒布+LED 灯珠编织 | 电路集成+DMX 控制 |
| 投影幕 | 影音功能 | PVC 涂层光学布 | 增益/视角参数（与幕布不同产品族） |

## 二、阻燃是法律红线

- **标准**：美国 NFPA 701（Method 2 大幅面）、德国 DIN 4102 B1、法国 M1、英国 BS 5867-2、中国 GB 8624 B1——**演出场所消防验收强制**；
- **阻燃路线**：阻燃涤纶丝（永久阻燃——水洗不失效，工程首选）vs 棉/绒后整理阻燃（手感好但**吸湿返潮会降低阻燃性**——每年需阻燃复检/补喷，运维合同要点）；
- **证书**：每批幕布随货阻燃检测报告+消防产品身份标识——场馆验收/年检必查；
- **交叉参考**：`trade-compliance/textile-flammability-regulations.md` 与窗帘工程逻辑（`garments/curtains-window-treatments.md`）同源。

## 三、工程与安装要点

- **打褶倍数**：大幕 2.5-3 倍褶（视觉饱满度）——用布量按此核算报价；
- **尺寸**：按台口尺寸定制（大剧院台口 16-18m 宽×10-12m 高——单幅用布数百米）；**宽幅面料**（3m+ 门幅）减少竖缝；
- **悬挂系统配合**：幕布顶部袢带/吊带间距与吊杆（fly bar）匹配；配重底杆槽（铅条/铁管——垂坠感）；
- **声学功能**：绒布吸声系数是剧院声学设计的一部分（混响控制）——设计院会指定面密度/绒高；
- **机械接口**：电动对开幕轨道同步、升降幕平衡——幕布厂与舞台机械厂接口配合（总包模式下由舞台工程商集成）。

## 四、订单与市场逻辑

- **客户结构**：舞台工程总包商（大剧院项目投标）、舞美制作公司（巡演布景——周期紧+单件定制）、学校/企业礼堂（翻新集采）、影院（银幕框遮幅幕）；
- **巡演市场**：音乐剧/演唱会布景幕布（喷绘+拼接——大幅面数码印，见 `fabric/digital-printing-technology.md`）——巡演损耗带来持续更换；
- **出口**：中东/东南亚文化设施建设（剧院/会议中心）+邮轮剧场（IMO 阻燃标准）；
- **报价要点**：按延米/平方米+阻燃等级+打褶倍数+五金配件分别列项；安装服务分包（本地高空作业资质）；
- **运维长尾**：阻燃补喷、清洗（大幕干洗专业公司）、更换——工程客户生命周期管理（见 `suppliers/supplier-relationship-negotiation.md`）。
