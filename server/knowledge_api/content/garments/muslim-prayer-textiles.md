# 穆斯林宗教纺织品贸易（Prayer Textiles: 礼拜毯/戒衣/礼拜服/礼拜帽）

穆斯林宗教纺织品是"**信仰刚需+节庆脉冲**"的稳定品类：每日五次礼拜+斋月/朝觐年度峰值，覆盖全球 19 亿穆斯林人口。消费级礼拜毯（记忆棉加厚/便携旅行款）与机织地毯渠道的清真寺满铺毯（见 `garments/machine-made-carpets.md`）是**不同产品线**；礼拜服饰与日常穆斯林服饰（见 `garments/modest-muslim-wear.md`）亦分属不同场景。本文聚焦**宗教仪式专用**纺织品。

## 二、图案与文化合规（生死线）

- **拱门（mihrab）图案**：礼拜毯经典设计——**朝向指向功能严肃**，图案变形/印偏=宗教不敬投诉；
- **禁忌元素**：**严禁人物形象、动物形象（保守市场）、十字架等异教符号**——几何纹/植物纹/书法纹（阿拉伯书法须由懂行者审核——错字=重大事故）为安全区；
- **戒衣规范**：男式 ihram=**两片无缝合白布**（缝合款不合法）——超细纤维速干款是改良创新但需**无染色纯白**；
- **颜色**：礼拜毯绿色/酒红/藏青主流（绿色=伊斯兰传统色）；**黄色在部分海湾市场忌讳**；
- **儿童产品去偶像化**：卡通图案限几何/植物/星空——人物眼睛图案在保守派客群敏感。

## 三、市场节奏与渠道

- **斋月脉冲**：斋月前 1-2 个月（伊斯兰历每年提前约 11 天）是全品类峰值——**备货按伊斯兰历倒排**；开斋节礼赠（礼拜毯+赞珠+礼盒套装）；
- **朝觐周期**：朝觐季（伊斯兰历 12 月）前戒衣需求集中——沙特本地经销商集采+全球旅行社礼包（ihram+腰带+拖鞋包）；
- **日常复购**：礼拜毯为消耗品（家用 1-2 年更换）、清真寺捐赠毯（批量采购）；
- **渠道**：中东本地 souq 批发、欧美穆斯林电商（亚马逊 Islamic prayer rug 类目）、土耳其布尔萨产业带（机织毯竞争对手）、印尼本土 telekung 集群（爪哇绣花边款）；
- **东南亚细分**：印尼/马来市场（见 `customers-market/malaysia-singapore-market.md` 与 `customers-market/southeast-asia-market.md`）——telekung 是**女性礼赠首选**（开斋节礼盒）。

## 四、生产与风控要点

- **礼拜毯品质点**：绒面密度（脚踏感）、防滑底（礼拜动作滑动=差评）、包边牢度、**图案对中**（拱门偏斜是硬伤）；
- **记忆棉款**：海绵密度 25-40D——低密塌陷差评；绒面与海绵复合（复合工艺见 `suppliers/lamination-coating-factory-management.md`）；
- **ihram 品质**：全棉毛巾布**吸水+无荧光剂**（纯白但禁用荧光增白——宗教纯净性诉求）、掉毛率控制；
- **钩编礼拜帽**：手钩（印度/孟加拉产）vs 机钩（中国）——手钩溢价但交期不稳；
- **认证**：非常规宗教认证——但**沙特 SASO/SABER 清关**适用（装运前认证见 `trade-compliance/pre-shipment-coc-psi.md`）；
- **知识产权**：清真寺建筑图案/书法字体版权——**通用几何纹安全，名家书法须授权**（见 `trade-compliance/ip-brand-authorization.md`）；
- **付款**：中东/南亚客商习惯见 `customers-market/middle-east-market.md`——小单前 TT、大单 DP 混合。
