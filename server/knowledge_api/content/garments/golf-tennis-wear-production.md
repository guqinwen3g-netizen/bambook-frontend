# 高尔夫与网球服品类生产专题（Golf & Tennis Wear Production）

高尔夫/网球服是运动服装中的"**贵族细分**"——客单价高（高尔夫 polo 零售 $80-150）、功能与体面双重要求（上场是运动服、会所是社交服），且受"老钱风（old money aesthetic）"流行红利带动持续增长。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 高尔夫 polo 衫 | 核心单品——翻领/门襟/合体剪裁（挥杆活动量） |
| 高尔夫裤/短裤 | 弹力斜纹/西裤外观（球场着装规范——禁牛仔禁圆领） |
| 网球裙（skort） | 裙裤一体（内衬短裤+口袋装球）——女子核心单品 |
| 网球 polo/连衣裙 | 温网全白传统（all-white dress code） |
| 套头衫/马甲 | 防风 layering（球场早晚温差） |
| 雨衣/防风衣 | 高尔夫全天候装备 |

## 二、面料要求

- **珠地棉（piqué）**：polo 经典面料——透气凹凸肌理（棉珠地/涤棉/全涤功能珠地）；
- **功能性针织**：吸湿排汗（wicking）+ 四面弹（4-way stretch 挥杆不束缚）——涤氨/锦氨；
- **UV 防护**：UPF 40-50+（户外运动 4 小时暴晒——见 `fabric/functional-fabrics.md`）；
- **凉感/抗菌**：夏季卖点（凉感尼龙、银离子/薄荷整理）；
- **高尔夫裤**：弹力斜纹（棉氨/t400）——"看起来像西裤、穿起来像运动裤"。

## 三、版型与工艺要点

- **挥杆活动量**：高尔夫 polo 后中长/侧开衩（弯腰推杆不上缩）、肩部活动褶；
- **网球裙内衬**：一体短裤+球袋（球袋开口朝内下——装球不掉）；
- **门襟品质**：polo 门襟是"脸面"——门襟衬/纽洞/钉扣平整度决定档次感；
- **无感车缝**：贴身款平锁缝（flatlock）防磨（挥杆重复摩擦）；
- **Logo 工艺**：硅胶章/高频压胶/绣花——运动品牌 logo 是溢价核心，绣花样确认针数密度。

## 四、订单与市场特征

- **品牌梯队**：
  - 专业高尔夫：FootJoy/Callaway/Travis Mathew/Peter Millar（美国乡村俱乐部渠道）；
  - 运动大牌线：Nike Golf/adidas Golf/lululemon（高尔夫线 2023+ 发力）；
  - 时尚轻奢：Ralph Lauren/Lacoste/G/Fore（颜值驱动）；
  - 新兴 DTC：Bad Birdie/Fore All（社交媒体驱动——起订量小但增长快）；
- **球场/俱乐部定制**：pro shop 定制（绣 logo）——美国 1.6 万个高尔夫球场，小批量高毛利；
- **企业/赛事定制**：高尔夫是企业社交货币——企业 outing 活动 polo 定制（单款 100-500 件）；
- **尺码**：美国市场偏宽松（classic fit vs athletic fit 双版型策略）。

## 五、合规与着装规范

- **球场 dress code**：有领衫/禁牛仔/裤长要求——设计须满足规范（无领 mock 领是最低妥协）；
- **温网全白**：全白系列色牢度/透度控制（白色透底是客诉高发——面料克重/内衬）;
- **常规运动服合规**：阻燃豁免（运动服）、儿童高尔夫服走童装标准（见 `trade-compliance/cpsc-children-safety.md`）。

## 六、接单策略

- **打样能力**：polo 衫打样看门襟/领子工艺——领子（扁机领/罗纹领/原身布领）是品质分水岭；
- **小单快返**：DTC 品牌首单 300-500 件——接得住小单才有机会吃返单（见 `suppliers/production-capacity-scheduling.md`）；
- **配套品类**：帽/腰带/球童毛巾配件打包（客单价提升）；
- **季节性**：美国高尔夫旺季 4-9 月——订单前置 1-2 月下单，春季款 12 月-2 月集中下单。

## 七、产业带

- **广东**：东莞/中山（高端运动 polo——品牌代工集群）；
- **福建**：泉州/石狮（运动休闲 polo 性价比产能）；
- **浙江**：宁波/义乌（高尔夫配件+企业定制单）。
