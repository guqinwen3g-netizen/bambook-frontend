# 潮牌街头服饰生产专题（Streetwear Production）

潮牌的逻辑是"**面料克重即态度、工艺即身份**"：重磅面料、做旧水洗、限量联名——成本重心从版型转向面料与表面处理。

## 一、品类与面料门槛

| 品类 | 潮牌规格 | 普通款差异 |
|:---|:---|:---|
| 重磅 T 恤 | 230-320g 纯棉（普通 160-180g） | 克重翻倍+织法紧密（厚重挺括不激凸） |
| 重磅卫衣 | 400-500g 毛圈/抓绒（见 `fabric/fleece-terry-fabrics.md`） | 克重+oversize 版型 |
| 做旧牛仔 | 多重水洗/破坏（见 `garments/denim-jeans-production.md`） | 手工猫须/磨破/泼墨 |
| 工装裤 | 加厚珠帆/多袋 | 立体袋/织带配件 |

## 二、核心工艺

- **胶浆印花（plastisol）**：厚板胶浆（立体手感——潮牌 logo 标配）/发泡印花（puff——3D 效果）;
- **拔染/烂花**：做旧褪色效果;
- **炒洗/雪花洗**：酸性洗水做旧（每件效果微差——"独一无二的旧"）;
- **扎染（tie-dye）**：手工扎染复兴（小批量工坊化）;
- **直喷（DTG）**：照片级图案（小单灵活——见 `fabric/digital-printing-technology.md`）;
- **刺绣重磅化**：毛线绣/贴布绣（层次感——见 `garments/printing-embroidery.md`）。

## 三、版型与细节

- **Oversize 落肩**：潮牌版型基准（胸围+10-15cm——版师理解"垮而不塌"）;
- **小领口罗纹**：加厚高弹罗纹（久洗不泄——品质分水岭）;
- **后领压条/肩部双针**：耐穿加固;
- **辅料**：织标/皮标/硅胶章（品牌识别物——定制周期 2-3 周提前下单）。

## 四、商业模式（影响生产结构）

- **Drop 模式**：限量发售（supreme 范式——单款 500-3000 件，售罄即止）;
- **联名（collaboration）**：IP 授权款（生产需授权链文件——见 `trade-compliance/ip-brand-authorization.md`）;
- **预售模式**：先售后产（零库存——交期承诺 2-4 周需快反）;
- **转售溢价**：二级市场价格（StockX——品牌热度指标，对生产端=翻单谨慎）。

## 五、客户画像与订单特征

- **主理人品牌**：设计师/rapper/KOL 主理（订单小单价高——300 件起，毛利 30%+）;
- **品质敏感**：面料克重/做工是社群口碑点（次品在社媒被放大——全检比例高于常规）;
- **开发配合**：主理人有概念无技术（工厂提供面料+工艺方案——ODM 能力溢价）;
- **区域**：广州/杭州（国潮集群——RANDOMEVENT/ROARINGWILD 供应链）。

## 六、国潮出海

- **路径**：独立站+StockX/GOAT 入驻（先海外华人后本地圈层）;
- **合规**：IP 联名出海授权范围（区域授权条款——中国授权≠全球）;
- **包装**：潮牌开箱体验（雪梨纸/贴纸/防尘袋——包装成本 5-10 元/件常态）。

## 七、生产风险

- **水洗色差**：炒洗效果不均（首件封样+缸差管理）;
- **印花牢度**：厚板胶浆洗后开裂（固化温度工艺+洗水测试）;
- **小单成本**：500 件以下开机费摊薄（报价构成透明化——印花开机费/版费单列）;
- **知识产权**：图案原创性（抄袭大牌元素=法律风险，主理人需原创承诺）。
