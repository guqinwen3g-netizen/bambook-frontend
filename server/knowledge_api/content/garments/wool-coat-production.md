# 毛呢大衣生产（Wool Coat Production: 双面呢与手工工艺）

毛呢大衣是**面料驱动 + 手工含量**品类：面料占成本 60-70%，双面呢剖缝/手缝是高端分水岭（工时 3-5 倍于普通大衣），归拔定型决定版型档次。

## 一、面料基础

- **常用呢料**（详见 `fabric/wool-cashmere-fabrics.md`）：麦尔登（短顺毛挺括）/法兰绒/双面呢/阿尔巴卡（羊驼毛）/羊绒呢；
- **克重**：大衣呢 380-600g/m²（南方轻薄款 320-380g）；
- **面料检验**：呢面疵点（缺纱/呢粒/水印）+脱毛测试（兔毛/羊驼混纺掉毛痛点）+缩率（蒸呢预缩后复测——见 `suppliers/incoming-material-inspection.md`）。

## 二、结构工艺分级

| 工艺 | 结构 | 工时/定位 |
|:---|:---|:---|
| 双面呢手缝 | 无里布，剖缝后边缘手工藏针缝合 | 3-5 天/件——高端（¥2000+ 零售价） |
| 半里/全里机制 | 常规缝制+里布（宾霸/涤塔夫） | 主流（快时尚到中档） |
| 挂面粘合衬 | 挂面+粘合衬简化工艺 | 低端走量 |

### 双面呢工艺要点
1. **剖缝**：剖缝机（或手工）将双层织合处剖开（缝份 1-1.2cm——剖偏即报废）；
2. **手缝藏针**：边缘剖缝处手针缝合（熟练工日缝 3-5 米——人工是瓶颈）；
3. **免里布**：内面即面子（缝份全包光——做工即里子，检验标准内外一致）；
4. **珠边（拱针）**：门襟/领面装饰性珠边线迹（珠边机/手工）。

### 单面呢（常规）要点
- **衬**：挂面粘合衬（中档）/半麻衬（高档——工艺逻辑同西装，见 `garments/suits-tailoring-production.md`）；
- **里布**：袖里+身里（里布松量 0.5-1cm——活动量，绷紧=穿着撕裂）；
- **垫肩/胸衬**：薄型垫肩（廓形款免）。

## 三、版型与归拔

- **廓形**：H（直身）/A（伞摆）/X（收腰）/O（茧型）——廓形决定耗料（茧型 2.5-3m+）；
- **落肩/插肩/连袖**：袖型影响排料与穿着舒适度；
- **归拔定型**：胸/腰/摆纬向归拔（熨烫塑型——呢绒可塑性强是核心优势），领面归拔使驳领自然翻卷；
- **整烫**：蒸汽人像机+手工（呢面忌压光——垫布烫）。

## 四、生产管理

- **产区**：大连（呢大衣传统基地）/桐乡濮院/海宁（呢绒+皮革配套）；
- **排产**：手缝工序是产能瓶颈（双面呢需外包手缝队或自有手工组——见 `suppliers/production-capacity-scheduling.md`）；
- **季节**：4-7 月下单，8-10 月出货（冬装周期——见 `trade-process/annual-sourcing-calendar.md`）。

## 五、质量检验

| 检验点 | 标准 |
|:---|:---|
| 对称性 | 领/驳头/口袋/下摆左右对称（呢大衣第一观感） |
| 呢面疵点 | 主部位无呢粒/缺纱/水印（对光检验） |
| 色差 | 同件无色差（呢绒缸差——多件套特别注意，见 `suppliers/dyeing-mill-cooperation-management.md`） |
| 剖缝/手缝 | 无漏缝/断线/针迹外露（双面呢） |
| 脱毛 | 摩擦后掉毛量（兔毛混纺重点） |
| 蒸汽缩率 | 整烫后尺寸变化（成衣尺寸复核） |

- **包装**：挂装 GOH 为主（防皱——见 `garments/garment-packaging.md`）；防潮（呢绒虫蛀——樟脑/防虫剂注意客户国化学品限制，见 `trade-compliance/chemical-environmental-compliance.md`）。

## 六、成本与报价

- **面料**：羊毛呢 ¥80-200/m；羊绒呢 ¥200-600/m（占比 60-70%——面料锁价重要，见 `fabric/fabric-inventory-stock-strategy.md`）；
- **工时**：机制款 1.5-3 小时/件；双面呢手缝款 15-25 小时/件；
- **报价红线**：呢料损耗 +5-8%（呢面疵点剔除+排料方向性——顺毛面料单向排料耗料增加）。
