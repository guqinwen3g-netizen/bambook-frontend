# 旗帜与广告横幅生产（Flags & Banners Production: 数码印花促销品）

旗帜横幅是典型的"印花+缝纫"轻缝制品类：国旗、广告旗、沙滩旗（刀旗/羽毛旗）、横幅、桌旗。核心工艺是**热升华数码印花**（涤纶专用），设备投入小、起订量低、交期快——适合电商小单与促销品渠道（见 `customers-market/promotional-products-channel.md`）。产业带：浙江绍兴/江苏南通/广东东莞。

## 一、产品体系与材料

| 产品 | 常用面料 | 规格惯例 | 配件 |
|:---|:---|:---|:---|
| 国旗/手摇旗 | 75D/100D 涤丝纺（knitted polyester） | 3×5ft（90×150cm）为主力 | 铜鸡眼+旗腰 |
| 沙滩旗（刀旗/羽毛旗） | 110g 针织旗布 | 2.8-5.5m 杆高系列 | 玻纤杆+底座+水袋 |
| 横幅 banner | 经编旗布/PVC 刀刮布 | 按米定制 | 打扣眼/穿绳 |
| 桌旗/会议旗 | 色丁/贡缎 | 14×21cm 等 | 流苏边 |
| 车旗/花园旗 | 300D 牛津 | 12×18in | 旗杆夹 |

- **面料关键指标**：透风性（旗布要"透风不兜风"——针织孔洞结构，风大不断杆）、色牢度（户外日晒 3-6 个月不褪——分散染料热升华天然耐晒）；
- **单面印 vs 双面印**：单面印反面渗透 70-90%（旗帜惯例可接受）；**双面同色旗**需双层面料+中间遮光布缝合——价格 2.5 倍，政府/国企订单常要求。

## 二、生产工艺流程

1. **热升华印花**：转印纸打印→滚筒热转印机 200-220℃ 转印（或直接喷布旗帜机）——色彩管理与见 `fabric/digital-printing-technology.md`；
2. **裁剪**：旗帜尺寸公差 ±1cm（大货激光裁床或热切——**热切封边防毛边**）；
3. **缝制**：旗腰（canvas header）车合+双道锁边；鸡眼（grommet）冲压牢固度抽检（拉力 ≥50kg）；
4. **检验**：对稿核色（客户设计稿潘通色号对照，见 `fabric/color-management-pantone-measurement.md`）+透拍查渗透均匀度；
5. **包装**：单旗 PE 袋+配件分包——沙滩旗配件（杆/座/袋）齐套全检（缺件是客诉首位）。

## 三、订单特征与接单要点

- **典型买家**：促销品分销商（4imprint/Vistaprint 供应链）、体育赛事（球迷旗）、**选举物资**（美国中期/大选年旗帜爆发单）、国家机构（国庆日国旗）；
- **选举单风险**：政治敏感图案（候选人口号）注意出口申报品名中性化（"polyester flag"即可）；交期死亡线（选举日不可延）——只接产能 120% 把握的单；
- **国旗合规**：**各国国旗图案使用有法律约束**（如美国国旗法、部分国家禁止商业用途/错误比例）——接单核对客户提供的图案稿比例与色值（联合国会员国国旗有官方规范）；
- **IP 审核**：球队 logo/品牌商标旗必须有授权书（见 `trade-compliance/ip-brand-authorization.md`）——迪士尼/球队图案是海关查扣高发；
- **定价结构**：面料+印花（按面积）+配件+缝制——小单（<100 面）按版费+单价模式；**1 面起订的电商单靠数码印花零制版优势**。

## 四、品质与物流注意

- **色差控制**：热升华颜色受温度/速度影响——每单留产前样（print proof）给客户确认再量产；
- **克重虚标**：旗布克重（68g/75D vs 110g）影响飘扬感与耐久——合同注明克重公差 ±5g；
- **物流**：旗帜轻泡——真空压缩袋降体积；沙滩旗杆属超长件（>1.2m）走海运或铁路，空运附加费高（见 `trade-process/air-freight-express.md`）；
- **季节性**：北半球夏季赛事+节日（7/4 美国独立日、世界杯周期）——Q1 备产 Q2 发货（见 `trade-process/annual-sourcing-calendar.md`）。
