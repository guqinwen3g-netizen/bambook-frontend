# 纺织墙布与软包生产（无缝墙布/刺绣墙布/软包硬包/工程渠道）

纺织墙布是家纺与建材的跨界品类：以提花/印花织物为面、无纺布为底的复合结构，替代墙纸乳胶漆做墙面装饰。中国（绍兴/海宁产业带）占全球墙布产能 80%+。与窗帘同属家居软装但**渠道逻辑完全不同**（建材市场/家装公司 vs 窗帘店——见 `garments/curtains-window-treatments.md`）。核心壁垒=**阻燃工程资质+批次色差管理**。

## 一、产品矩阵

| 品类 | 结构 | 特征 | 价格带（出厂/㎡） |
|:---|:---|:---|:---|
| 无缝墙布 | 提花/印花布+无纺底复合 | 幅宽 2.8-3.2m 一面墙一整张（**无接缝**=核心卖点） | ¥15-45 |
| 刺绣墙布 | 底布+电脑绣花 | 高端定制（新中式花鸟） | ¥50-150 |
| 软包 | 面料+海绵+密度板/雪弗板 | 床头背景墙/影音室（吸音） | ¥80-300 |
| 硬包 | 面料+密度板（无海绵） | 酒店工程走量款 | ¥40-120 |
| 工程阻燃墙布 | 阻燃底布+阻燃整理 | B1 级检测报告随货（酒店/KTV 强制） | ¥25-60 |

- **无缝=幅宽逻辑**：层高 2.8m 内一张到顶——幅宽不足则拼缝（卖点尽失），故 3.0m+ 特宽幅提花机是产业门槛（与窗帘高精密面料同机台——见 `fabric/jacquard-fabrics.md`）；
- **复合工艺**：热熔网膜复合（环保无胶味）vs 胶水复合（低价但 TVOC 风险）——复合剥离强度 ≥3N/5cm 防起泡。

## 二、材料与工艺要害

- **面布**：高精密提花（经向密度 10000+ 针——仿刺绣效果）、色织、印花（数码印小单快反——见 `fabric/digital-printing-technology.md`）；亚麻质感款用涤麻混纺控成本；
- **底布**：水刺无纺布（平整）/针刺棉（厚软包感）——克重 60-120g/㎡ 决定上墙挺度；
- **防霉防潮**：无纺底+防霉整理（南方梅雨季上墙发霉是投诉重灾区）——地下室/卫生间相邻墙面**禁用纺织墙布**（销售端必须前置告知）；
- **软包工艺**：海绵密度 25-35D（手感与回弹平衡）；菱形拉扣款手工占比高（计件工价是平款 2-3 倍）；边角 45° 拼接收边（工艺细节决定工程验收）；
- **阻燃**：GB 8624 B1（氧指数/垂直燃烧/烟密度）——**工程投标必须检测报告原件**；出口对标 EN 13501-1 B-s2,d0 / ASTM E84 Class A（阻燃体系见 `fabric/flame-retardant-fabrics-deep-dive.md`）。

## 三、渠道与交付模式

- **内销渠道**：建材市场门店（样本册模式——版本费 200-500 元/本）、家装公司集采（返点 15-25%）、设计师渠道（高端刺绣定制）；
- **工程渠道**：酒店/精装房批量——投标制（资质+检测报告+样板墙），账期 3-6 个月（垫资压力见 `suppliers/garment-factory-cash-flow.md` 逻辑）；**KTV/影院强制 B1 阻燃+消防验收**；
- **出口市场**：东南亚（华人装修审美外溢）、中东（酒店工程——浮雕刺绣款契合）、俄罗斯（寒冷地区墙面保温叙事）——出口按墙布 HS 5905（纺织墙面覆盖物）归类（归类细节见 `trade-compliance/hs-classification-practice.md`）；
- **施工交付**：墙布是"三分产品七分施工"——基膜+糯米胶体系（环保糯米胶是营销点）；对花损耗 5-8% 计入报价；施工队管理是品牌方售后命门。

## 四、风控要点

- **批次色差**：同一房间必须同批次（提花色织缸差管理——见 `suppliers/dyeing-mill-cooperation-management.md`）——出货标注批号+留样 3 年；
- **起泡脱胶**：复合牢度+施工胶水双重因素——客诉界定难（产品问题还是施工问题），合同条款预设责任分配；
- **阻燃宣称**：B1 报告必须与**实际出货产品同配方**（送检特制样=刑事风险）；工程抽检不合格=整批返工+资质黑名单；
- **环保宣称**：E0/无醛宣称需检测报告支撑（反漂绿逻辑见 `trade-compliance/green-claims-anti-greenwashing.md`）；TVOC/气味差评集中在新装 7 天内。
