# 衬衫品类生产专题（Shirt Production）

衬衫（shirt）是男装第一大品类：工艺标准化程度高、版型精度要求严（领围±0.5cm 决定舒适合身）、商务衬衫是"西装之外最讲工艺的品类"。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 正装衬衫（dress shirt） | 高支色织/府绸、硬领、法式/意式工艺 |
| 商务休闲（business casual） | 牛津纺/免烫、领扣领（button-down） |
| 休闲衬衫 | 法兰绒/麻/印花、宽松版型 |
| 女式衬衫（blouse） | 雪纺/真丝/缎——设计款多 |
| 短袖衬衫 | 夏季/度假（夏威夷衫） |
| 工装衬衫 | 斜纹/牛仔布、双口袋（见 `garments/workwear-uniform-production.md`） |

## 二、核心工艺要点

### 领子（衬衫的灵魂）
- **领衬**：领衬硬度决定领型挺括（无纺衬/有纺衬——高端用领尖插片 collar stay 槽）；
- **领型**：标准领/温莎领（宽角——领带结大）/领扣领/立领/古巴领；
- **领座（collar stand）**：领座高度（2.5-3.5cm）影响穿着挺拔度。

### 关键工序
| 工序 | 品质点 |
|:---|:---|
| 上领 | 领面领座服帖（不起皱/不扭）——衬衫第一技术活 |
| 门襟 | 平服无波浪（衬+明线均匀） |
| 袖衩（placket） | 宝剑头袖衩（高端）vs 简易衩 |
| 扣眼/钉扣 | 锁眼密度、纽扣绕脚（shank——纽扣立起扣合顺畅） |
| 下摆 | 弧形下摆卷边均匀 |

### 免烫工艺
- **DP 免烫**（durable press）：成衣免烫整理（树脂——见 `fabric/shirting-fabrics.md`）；
- **液氨+潮态交联**：高端免烫（手感与免烫平衡）。

## 三、版型与规格

- **领围体系**：男正装衬衫按领围分码（38/39/40/41/42/43cm——欧码 15/15.5/16...英寸）；
- **版型分级**：Slim/Regular/Classic（胸腰差）——欧美体型版型库；
- **关键公差**：领围 ±0.5cm、胸围 ±1.5cm、袖长 ±1cm（衬衫公差严于 T 恤——贴身商务属性）。

## 四、面料配套

- **正装**：80-140 支色织府绸/斜纹（见 `fabric/shirting-fabrics.md`）；
- **牛津纺**：OCBD（牛津纺领扣衬衫——美式经典）；
- **休闲**：法兰绒/青年布/麻棉；
- **女式**：真丝/雪纺/天丝。

## 五、订单特征

- **商务衬衫**：品牌常年翻单（基础款生命周期长——白衬衫万年款）；
- **尺码配比**：男正装按领围 6-8 码配比（39-42 是主力码）；
- **包装**：正装衬衫折叠定型包装（领撑+衬板+胶夹——"礼盒级"折叠是正装衬衫的视觉标准）；
- **产业带**：广东佛山/浙江义乌诸暨/江苏（鲁泰体系高端色织衬衫）。

## 六、质量检验要点

| 项目 | 标准 |
|:---|:---|
| 领子 | 左右对称、领尖一致、不起皱 |
| 对格对条 | 口袋/门襟/袖衩对格（色织格条衬衫——见 `fabric/yarn-dyed-fabrics.md`） |
| 锁眼钉扣 | 扣眼无毛边、扣子牢固（拉力测试） |
| 免烫 | 水洗后外观平整度（AATCC 124 评级 3.5+） |
| 尺寸 | 领围/胸围/袖长公差表 |
