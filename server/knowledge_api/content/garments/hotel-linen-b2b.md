# 酒店布草生产与 B2B 供应（Hotel Linen: Bedding, Towels & Table Linen）

酒店布草是家纺的 B2B 细分（区别于零售家纺，见 `garments/home-textiles.md`）：床品四件套、毛巾浴巾、餐巾台布、浴袍。核心逻辑不是"好看"而是**耐工业洗涤+单位洗涤成本**。产业带：江苏南通（床品）、淮安（毛巾）、山东高密/河北高阳（毛巾）。

## 一、产品线与核心规格

| 品类 | 主流配置 | 关键指标 |
|:---|:---|:---|
| 床单被套 | 全棉 40s/60s/80s 贡缎或平纹，密度 200T-400T | **耐洗次数 ≥150-200 次**（三星）/≥300 次（五星） |
| 枕芯被芯 | 化纤棉/羽丝绒/羽绒（高端） | 蓬松度保持、可水洗 |
| 毛巾浴巾 | 全棉 16s/21s/32s 螺旋毛圈，500-700g/㎡ | 吸水性 ≤5 秒、脱毛率 ≤0.4% |
| 浴袍 | 华夫格/割绒/毛圈 | 克重 300-400g/㎡ |
| 餐巾台布 | 涤棉/全涤提花（耐氯漂） | 抗皱、耐污、耐高温熨烫 |

- **面料选型铁律**：五星酒店要"棉感"，但全涤/涤棉耐洗成本占优——中端连锁（汉庭/如家体系）大量用涤棉混纺平衡；
- **纱支与虚标**：市场惯用"60s 贡缎"宣传，实测常见 40s——出口订单以客户实测为准，合同注明纱支密度公差（见 `fabric/weaving-grammage-width.md`）。

## 二、B2B 渠道结构

- **酒店集团集采**：华住/锦江/万豪/IHG 供应商库——入库需验厂+样品测试+试用周期（3-6 个月），账期 60-90 天；
- **酒店用品批发市场**：广州南天、扬州杭集（一次性用品+布草）——现款现货、价格透明、利润薄；
- **布草租赁公司（欧美主流模式）**：ELIS/Alsco 租赁洗涤一体——采购量极大、要求极致耐洗与**RFID 芯片植入**（追踪洗涤次数与流转）；
- **海外酒店供应**：中东（新建酒店潮）、东南亚（旅游复苏）、非洲（中国援建酒店配套）——常随酒店管理公司打包出口；
- **OEM/ODM 差异**：布草多为买方图纸加工（绣酒店 logo、定制尺寸）——打样确认流程同服装（见 `trade-process/sample-development-and-confirmation.md`）。

## 三、生产与品控要点

- **耐洗测试**：接单前送第三方（或自测）模拟工业洗涤（80℃+碱性洗涤剂+高速脱水）50 次循环：缩水率 ≤3%、强力保留 ≥70%、不起球不发灰——这是布草单与普通家纺单的分水岭（见 `trade-compliance/testing-standards.md`）；
- **尺寸余量设计**：床品预留工业洗缩水余量（经向 +4-6%）——首次洗涤后达标尺寸才是真实交付尺寸；
- **绣字定位**：logo 刺绣位置/针数标准化（每件拍照留档）——见 `garments/printing-embroidery.md`；
- **毛巾要害**：螺旋毛圈均匀度、边部锁边强度（工业洗最先坏的是边）；
- **色差管理**：同一酒店分批补货必须同色——留足原批面料/染化料批次记录（见 `suppliers/dyeing-mill-cooperation-management.md`）。

## 四、报价与成本结构

- **单位成本锚点**：以"每间客房全套布草成本"报价（标准间约 2.5-3 套配比：1 用 1 洗 1 备）；
- **原料占比 60-70%**：棉纱价格联动条款（Cotlook A 指数或国内棉价，见 `fabric/fabric-procurement-quality-agreement.md`）；
- **洗涤寿命经济学**：帮客户算"单次洗涤成本=采购价÷耐洗次数"——耐洗 300 次的高价布草常比 150 次的低价货更便宜，这是销售话术核心。

## 五、出口实操注意

- **HS 归类**：床品 6302.2/6302.3、毛巾 6302.6——棉制与化纤制税率不同（见 `trade-compliance/hs-classification-practice.md`）；
- **阻燃要求**：英国/爱尔兰酒店床品需 BS 7175；美国部分州要求阻燃——接单确认（见 `trade-compliance/textile-flammability-regulations.md`）；
- **伊斯兰市场**：中东酒店要求全新未使用证明/清真洁净包装；
- **打托包装**：防潮+唛头按客房楼层/房型分箱（酒店工程部收货逻辑）——包装规范见 `garments/garment-packaging.md`。
