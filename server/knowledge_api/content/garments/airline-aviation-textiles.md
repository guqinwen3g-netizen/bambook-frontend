# 航空纺织品生产（Aviation Textiles: FAR 25.853 阻燃/座椅套/航司集采）

航空纺织品是**阻燃标准最苛刻**的民用纺织品：客舱火灾极端致命——材料必须自熄、低烟、低毒。产品=座椅面料/座套、毛毯枕头、窗帘隔帘、地毯、空乘制服。客户=航司（维修更换市场）+座椅制造商（Collins/Recaro/Safran 配套）+航空配餐服务公司。订单不大但**认证壁垒极高**，进入即长期绑定。

## 一、阻燃核心：FAR 25.853 体系

- **垂直燃烧（60 秒/12 秒）**：面料本体——自熄时间、烧焦长度、滴落物三项指标；
- **座椅组合测试（油燃烧器 Oil Burner）**：面料+泡棉**组合件**通过——单卖面料给座椅厂需与其泡棉匹配送测；
- **烟密度（NBS 烟箱）**：Ds ≤200（4 分钟）——客舱能见度；
- **热释放（OSU）**：最新机型座椅材料要求（65/65 kW·min/m²）；
- **毒性**：空客 ABD0031/波音 BSS 7239（CO/HCN/HCl 等气体限值）；
- **其他交通场景对照**：铁路 EN 45545（欧盟）/ NFPA 130（美）、船舶 IMO FTP Code、汽车 FMVSS 302（见 `garments/car-seat-covers-auto-accessories.md`）——**轨道交通纺织（高铁座椅/卧铺）是同一技术家族的近邻市场**。

## 二、产品线要点

| 产品 | 材料 | 要点 |
|:---|:---|:---|
| 座椅面料 | 阻燃羊毛/涤纶混纺梭织（羊毛 85%+ 天然阻燃叙事） | 耐磨 50,000+ 马丁代尔、抗静电、耐污易清洁 |
| 一次性头片（headrest） | 无纺布/短纤针织 | 每航班更换——航空公司集采耗材（量大利薄） |
| 航空毛毯 | 阻燃涤纶/腈纶（经济舱一次性 vs 两舱可洗） | 阻燃+手感平衡；两舱产品线=美利奴羊毛/羊绒高端叙事 |
| 客舱地毯 | 阻燃尼龙簇绒/威尔顿 | 抗静电+耐磨+烟毒全项 |
| 隔帘 | 阻燃涤纶 | 垂直燃烧+烟密度 |
| 空乘制服 | 阻燃整理或芳纶混纺 | 制服生产逻辑见 `garments/workwear-uniform-production.md` |

## 三、认证与准入

- **OEM 体系认证**：进入座椅厂供应链需 AS9100（航空质量管理体系）+ 客户审厂；材料测试报告由 **FAA 认可实验室**出具；
- **PMA/备件市场**：航司维修更换——座椅套复制件需 FAA PMA（零部件制造批准）或与座椅厂授权合作；**仿制座椅套（无 PMA）是法律雷区**；
- **批次一致性**：航空件"完全一致"纪律——换纱批/换染缸都要评估申报；留样 10 年+；
- **追溯文件**：每批材料的 COC（符合性证书）+测试报告+批次记录——航司审计追溯；
- **周期**：从送样到首单 18-36 个月（认证+试飞评估）——**用现金流耐心换超长生命周期合同**（机型服役 20-30 年的持续更换订单）。

## 四、市场机会评估

- **更换市场**：座椅套 2-4 年更换周期（航司客舱翻新）、毛毯持续消耗——耗材复购模型；
- **新机增量**：波音/空客交付 backlog 10 年+（疫情后产能爬坡）——座椅厂订单饱满；
- **中国商飞 C919 供应链**：国产大飞机材料国产化——纺织材料供应商进入窗口期（航空工业集团体系认证）；
- **邻近延伸**：高铁（中国中车供应链）、邮轮（IMO 标准）、高端巴士；
- **切入建议**：先供**非承力软性件**（毛毯/头片/隔帘——认证门槛相对低），积累航空体系业绩后再攻座椅面料；或给座椅厂做**面料后整理加工**（阻燃复合）切入体系。
