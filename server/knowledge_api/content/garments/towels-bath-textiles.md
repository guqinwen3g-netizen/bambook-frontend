# 毛巾浴巾生产深度（Towels: 毛圈/吸水率/酒店与礼品渠道）

毛巾是"**纱线原料+织造密度决定品质**"的重料家纺品：成本中棉纱占 60%+，品质看毛圈高度/密度/纱支。产业带：河北高阳（中低端集群）、山东孚日/洁丽雅（品牌+出口）、江苏淮安。出口主线=酒店集采+商超自有品牌+礼品定制三大渠道。基础规格见 `garments/home-textiles.md`，本文件做生产与贸易深度展开。

## 一、规格指标体系

| 指标 | 定义 | 常规水平 | 高端水平 |
|:---|:---|:---|:---|
| 克重（GSM） | 每平方米克重 | 350-450（面巾）/450-600（浴巾） | 700-900（酒店加厚） |
| 纱支 | 毛圈用纱细度 | 21S/32S 普梳 | 40S-80S 精梳（长绒棉） |
| 毛圈高度 | 绒圈长度 | 常规 | 高毛圈（蓬松手感） |
| 吸水率 | 沉降法秒数（GB/T 22799） | ≤10s 合格 | ≤3s（高密毛圈+无捻纱） |
| 脱毛率 | 洗涤掉毛量 | ≤0.4% 国标 | ≤0.2% |
| 尺寸 | 面巾 34×76/浴巾 70×140 | 按市场调整 | 美制 bath towel 27×52" / bath sheet 35×60" |

- **无捻纱/弱捻纱工艺**：纱线加极少捻度（PVA 水溶性纱混纺后溶解）——蓬松度与吸水性倍增，是高端毛巾的核心工艺（日本市场偏好）；
- **长绒棉叙事**：埃及棉（Giza）/匹马棉（Pima）/新疆长绒棉——Supima 商标需授权（见 `fabric/cotton-fabrics-deep-dive.md`）。

## 二、生产工艺要害

- **织造**：剑杆/喷气织机+毛圈装置——**毛圈密度（每英寸圈数）与毛经/地经张力比**决定蓬松度；
- **染整**：**前处理退浆煮练必须充分**（棉蜡残留=吸水性差的根因）；染色后皂洗牢度（毛巾高频洗涤——耐洗牢度 4 级+）；
- **柔软剂陷阱**：过量硅油柔软剂=手感好但**吸水性暴跌**——电商"新毛巾不吸水"差评多源于此；高端做法=无捻工艺天然蓬松，少用化学柔软剂；
- **断档/缎档（dobby border）**：小提花机织出的装饰边——酒店毛巾辨识度的来源；
- **绣花/提花 logo**：酒店/礼品单定制——绣花针数与衬纸处理（衬纸残留扎皮肤是客诉点）；
- **验针**：毛巾必过验针（见 `suppliers/needle-control-metal-management.md`）——断针藏在毛圈中极难发现。

## 三、渠道与订单模式

| 渠道 | 特征 | 关键要求 |
|:---|:---|:---|
| 酒店集采 | 白巾为主、按"par level"（床位×3 倍）配货、补货周期稳定 | 加厚耐洗（工业洗涤 200 次+）、可绣店标，见 `garments/hotel-linen-b2b.md` |
| 商超自有品牌 | 沃尔玛/Target 类——验厂+测试+低价 | 认证全套（OEKO-TEX/BSCI）、AQL 验货严格 |
| 礼品/促销定制 | 企业 logo 巾、婚庆回礼、运动赛事 | 小单快反、绣花/印花定制、交期敏感 |
| 运动/沙滩巾 | 超细纤维运动巾（速干轻量）、印花沙滩巾 | 数码印花（见 `fabric/digital-printing-technology.md`）、超细纤维吸水速干 |

## 四、合规与质量雷区

- **化学安全**：OEKO-TEX Standard 100（欧美准入标配）；婴幼儿毛巾按一类（最严）；
- **纤维成分虚标**："100% 棉"实际涤棉混纺是行业老问题——欧美抽检成分偏差>3% 即违规（见 `trade-compliance/textile-fiber-names-regulation.md`）；
- **掉色客诉**：深色毛巾首洗掉色——皂洗牢度不达标；建议订单约定"首洗浮色"验收方法；
- **异味**：仓储霉变（高阳部分小厂库存管理差）——出货前含水率控制+防霉剂慎用（化学残留）；
- **尺寸缩水**：棉毛巾洗后缩水 3-5% 正常——规格书标注"洗后尺寸"而非仅成品尺寸（美系客户强制要求）。
