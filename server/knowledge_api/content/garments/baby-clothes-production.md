# 婴幼装品类生产专题（Baby & Infant Wear Production）

婴幼装（0-24 月）是"**安全标准最高**"的品类：比童装更严（婴儿无自我保护能力）——小部件/绳带/化学品全面设防。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 爬服/连体衣（romper/bodysuit） | 裆部按扣开合（换尿布）——婴儿第一单品 |
| 包屁衣 | 短袖/长袖连体 |
| 婴儿套装 | 上衣+裤 |
| 睡袋（sleep sack） | 替代被子（防蒙头窒息——SIDS 预防推荐） |
| 婴儿外套 | 连体爬服外套 |
| 口水巾/围嘴 | 配件 |

## 二、安全红线（最高标准）

### 1. 小部件（窒息风险）
- **按扣**：拉力测试（90N 拉力不脱落——婴儿吞咽窒息）；
- **装饰**：无小零件（亮片/珠——禁止 3 岁以下）；
- **线头**：线头缠绕手指（缺血坏死——无长线头）。

### 2. 绳带（勒颈风险）
- **婴幼儿禁绳带**：帽绳/颈绳禁止（7 岁以下——比童装更严）；
- **腰带**：长度限制+固定。

### 3. 化学品（见 `trade-compliance/chemical-environmental-compliance.md`）
- **甲醛**：婴幼儿 A 类（GB 31701——甲醛 ≤20mg/kg，比成人 B 类 75 严）；
- **荧光剂**：婴儿面料禁荧光增白剂；
- **Azo/重金属**：严格限值。

### 4. 物理安全
- **无骨缝**：贴身缝份平缝/无骨（婴儿皮肤娇嫩）；
- **标签**：无感标签/外缝标签（颈部不刺激）。

## 三、面料（天然优先）

- **纯棉**：婴儿第一选择（A 类标准）；
- **有机棉**：GOTS 婴儿线（高端母婴——见 `trade-compliance/textile-certifications.md`）；
- **双层纱（double gauze）**：婴儿爆款面料（柔软透气）；
- **竹纤维**：柔软抗菌（母婴营销概念）；
- **避免**：化纤贴身（闷）/深色（染料）/荧光。

## 四、工艺要点

- **按扣（snap button）**：裆部/肩部按扣（换尿布/套头便利——树脂按扣/金属按扣拉力）；
- **信封领/肩开**：婴儿头大——领口开合设计（信封领/肩部按扣）；
- **裆部加深**：尿不湿空间（版型）；
- **无荧光印花**：印花环保（婴儿啃咬衣物——印花安全）。

## 五、睡袋（安全明星单品）

- **SIDS 预防**：睡袋替代被子（防蒙头——美国儿科学会推荐）；
- **TOG 保暖指数**：睡袋保暖分级（0.5 TOG 夏/2.5 TOG 冬——按室温选）;
- **设计**：无袖（防过热）/双向拉链（换尿布）/腿部空间（髋关节发育——"青蛙腿"空间）；
- **合规**：睡袋阻燃+安全（美国 CPSC 婴儿睡眠产品规则——2022 起严格）。

## 六、订单与合规

- **认证**：美国 CPC（儿童产品证书——见 `trade-compliance/cpsc-children-safety.md`）+ 婴幼专项；
- **测试**：小部件拉力/甲醛/阻燃（睡袋）——检测项目童装中最全；
- **品牌门槛**：母婴品牌（Carter's/Gap Baby）验厂+测试严格——高门槛高粘性；
- **市场**：母婴是刚需（出生率下降但单价升——"精养"消费升级）。

## 七、产业带

- **广东**：佛山/汕头（婴幼装集群）；
- **浙江**：湖州织里（童装之都——婴幼线）；
- **高端**：有机棉婴幼装（出口欧美母婴品牌）。
