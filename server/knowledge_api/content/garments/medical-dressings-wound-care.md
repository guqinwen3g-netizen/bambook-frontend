# 医用敷料生产（Medical Dressings: 纱布/水胶体/藻酸盐/银离子/ISO 13485）

医用敷料是纺织材料进入医疗体系的正门：传统纱布/脱脂棉是"**成本+灭菌**"逻辑的大宗耗材（湖北仙桃/河南长垣产业带承包全球中低端），先进敷料（水胶体/藻酸盐/泡沫/银离子）是"**材料配方+临床证据**"逻辑的高毛利区。法规门槛（CE MDR/FDA 510k/ISO 13485）构成真实护城河。本文件梳理产品分层、法规路径与外贸要点（组套贸易见 `garments/first-aid-kits-ifak-production.md`，医护服装见 `garments/medical-healthcare-textiles.md`）。

## 一、产品分层

| 层级 | 产品 | 技术要点 | 毛利 |
|:---|:---|:---|:---|
| 传统敷料 | 纱布片/脱脂棉/绷带/纱布卷 | 脱脂漂白（吸水量）+无菌屏障 | 10-20% |
| 功能敷料 | 凡士林纱布/碘伏纱布 | 含药均匀性 | 25-40% |
| 先进敷料 | 水胶体/藻酸盐/泡沫敷料/硅胶疤痕贴 | 湿性愈合理论+材料配方 | 50%+ |
| 抗菌敷料 | 银离子/PHMB/蜂蜜敷料 | 抗菌缓释+临床数据 | 60%+ |

- **纱布质量的四个指标**：经纬密度（21s/32s/40s 支数）+吸水量（沉降法 ≤10s）+白度+荧光物（不得检出）——**脱脂不净（吸水慢）是出口退货首因**；
- **先进敷料的护城河**：水胶体（CMC+弹性体配方）、藻酸盐（海藻酸钙——原料看挪威 FMC/国产青岛系）、银离子（载银量与缓释曲线）——**配方研发+临床验证周期 2-3 年**；
- **无纺布基材**：先进敷料大量用水刺/纺粘无纺布（见 `fabric/nonwoven-fabrics.md`）——基材克重均匀性影响含药量一致性。

## 二、法规路径（命门）

- **欧盟 MDR**：传统纱布一类（自声明+技术文档）；水胶体/藻酸盐多为 **IIa 类（公告机构审核）**；含银抗菌可上 IIb——**MDR 2017/745 实施后证书周期 12-18 个月**，没有证书不得宣称 CE；
- **美国 FDA**：多数敷料 510(k) 豁免一类；**含抗菌成分/先进敷料多需 510(k)**（比对器械路径，周期 6-12 个月、费用 2-5 万美元）；
- **ISO 13485 体系**：质量管理体系认证是 B 端招标硬门槛——从文件体系到内审管评 12-18 个月建成；
- **灭菌验证**：EO 灭菌（残留解析同 `garments/disposable-travel-underwear.md`）或伽马辐照（外包钴 60 站——剂量映射验证）；无菌屏障包装（透析纸+PE 复合膜封口验证）；
- **UDI 追溯**：欧美要求器械唯一标识（UDI-DI 注册+喷码）——批次追溯逻辑同 `trade-compliance/product-liability-recall.md`。

## 三、外贸接单要点

- **买家画像**：欧美医疗分销商（McKesson/Cardinal 类——验厂+年框）、中东政府医院招标（需当地注册代理）、非洲 NGO 采购（UNICEF 创可贴/纱布集采，见 `garments/emergency-relief-textiles.md` 机构逻辑）；
- **OEM 贴牌为主**：分销商自有品牌——工厂价值=**注册人资质（Legal Manufacturer）能力**；能做欧代/美代注册的工厂接单溢价 20%+；
- **报价构成**：基材+灭菌（占 15-20%）+检测+包装——**灭菌与检测是固定成本，小单摊不薄**（MOQ 通常 5 万片起）；
- **临床证据营销**：先进敷料竞标需临床对比报告——与医院合作发论文是长期资产；
- **汇率与账期**：医院渠道回款 90-180 天——信保覆盖（见 `trade-process/export-credit-insurance.md`）。
