# 童装品类生产专题（Childrenswear Production）

童装（childrenswear/kidswear）是安全法规密度最高的服装品类：绳带、小部件、阻燃、化学物质四重管控，且召回代价远超成人装。童装订单的核心竞争力是**安全合规的确定性**。

## 一、年龄段与尺码体系

| 阶段 | 尺码（美） | 身高参考 |
|:---|:---|:---|
| 婴儿（infant） | 0-24M（NB/3M/6M/12M/18M/24M） | 50-86cm |
| 幼儿（toddler） | 2T-5T | 86-110cm |
| 小童（kids） | 4-7 / XS-M | 104-124cm |
| 大童（youth） | 8-20 / S-XL | 128-170cm |

- 童装版型特点：头身比大、腹部突出、袖窿浅——**不能用成人版缩小**。
- 欧盟/日本按身高（cm）标识，美国按年龄/码。

## 二、安全红线（设计端即须规避）

### 绳带（drawstrings/cords）
- **美国 ASTM F1816**：头颈部禁拉绳（2T-12），腰部外露 ≤ 7.6cm，详见 `trade-compliance/cpsc-children-safety.md`。
- **欧盟 EN 14682**：更细致——7 岁以下头颈区完全禁止功能性绳带；背部、袖口、下摆各有分区规则。
- **设计替代方案**：松紧腰头、魔术贴、按扣替代抽绳；装饰性绳带改固定缝制。

### 小部件（small parts）
- 3 岁以下：纽扣/装饰件需通过 90N 拉力测试；禁止使用可脱落珠片/烫钻。
- 附件优先选择：包布扣、树脂按扣（YKK 婴儿专用按扣通过拉力认证）。

### 阻燃（美国）
- 儿童睡衣 16 CFR 1615/1616（见 CPSC 文档）；日常服装 16 CFR 1610。
- 起毛面料（抓绒/毛巾布/法兰绒）高风险，选料时预判。

### 化学物质
- 铅/邻苯/甲醛：童装限值严于成人装；涂层印花（烫画/胶浆）是高风险点。
- **欧盟 REACH + 日本《家居用品品质标签法》**：日本童装甲醛限值 16mg/kg（婴幼儿 A 类），严于多数市场。

## 三、面料与工艺选择

- **面料**：纯棉/有机棉为主流卖点；柔软度（纱支 32S+ 精梳）、透气性优先；色牢度（婴幼儿啃咬唾液——耐唾液色牢度 GB/T 18886 / DIN 53160）。
- **印花**：水浆/数码印优先（胶浆手感硬且邻苯风险）；反光印花需通过耐洗测试。
- **缝制**：
  - 贴肤接缝外翻或四针六线（防摩擦婴幼儿皮肤）；
  - 线头处理零容忍（缠绕手指风险）；
  - 领口防夹拉链挡布（zipper garage）；
  - **检针（needle detection）全检**——日本/欧美品牌强制，断针混入是致命事故。
- **洗标**：外置或烫印无感标签（防刮皮肤）。

## 五、报价与生产要点

- 童装单耗低但**工费不低**（小尺码缝制难度高、换线频繁）——CMT 约为成人同款 80-90%，但测试/认证成本摊入后单价反而更高。
- **认证成本**：CPC 全项测试 3,000-8,000 元/款/色，多色多码订单按组测试（representative testing）可降本。
- **尺码配比**：童装订单 SKU 多（6-10 个码），装箱配比表（assortment）必须与客户书面确认。
- **检针设备**：输送带式检针机（灵敏度 Fe Φ0.8mm），全件通过并留存检针记录。

## 六、常见客诉与召回案例教训

| 事故 | 教训 |
|:---|:---|
| 帽绳勒颈（游乐场勾挂） | 头颈绳带零妥协，设计阶段删除 |
| 纽扣脱落误吞 | 90N 拉力测试 + 备用扣外袋固定 |
| 烫钻脱落 | 3 岁以下禁用烫钻，改印花 |
| 睡衣燃烧事故 | 阻燃测试或紧身版型合规路径 |
| 断针刺伤 | 检针全检 + 断针管理程序（断针回收记录） |
