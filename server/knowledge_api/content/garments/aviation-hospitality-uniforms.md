# 航空与酒店制服生产（Aviation & Hospitality Uniforms: 空乘/高铁/酒店前台）

形象岗制服是制服品类的**塔尖市场**：航空空乘、高铁乘务、五星级酒店前台/门童/礼宾。与工装（见 `garments/workwear-uniform-production.md`）的功能逻辑相反——**形象优先、舒适与耐用让位视觉**，工艺对标西装高端定制（见 `garments/suits-tailoring-production.md`）。订单特征：**小批量多款式+高单价+严格样衣确认**（一套空乘制服单价=工装 5-10 倍）。

## 一、产品体系

| 岗位 | 款式构成 | 面料 | 工艺要求 |
|:---|:---|:---|:---|
| 空乘（女） | 西装套裙+丝巾+帽子+风衣 | 毛涤混纺/TR 哔叽 | 航空色系定染+全里衬 |
| 空乘（男） | 西装+衬衫+领带 | 毛涤 | 肩章袢/翼徽刺绣位 |
| 高铁乘务 | 连衣裙/套裙+马甲 | TR/仿毛 | 铁路色系+活动量设计 |
| 酒店前台 | 西装/连衣裙+丝巾 | TR/醋酸 | 品牌 VI 色 |
| 门童/礼宾 | 长礼服大衣+帽子+金绳饰 | 毛呢/制服呢 | 金属丝织带/盘扣 |
| 客房/餐饮 | 功能款（耐洗优先） | 涤棉 | 接近工装逻辑 |

## 二、生产要害

- **色系定染**：航空/酒店 VI 色（**藏青/酒红/墨绿体系**——色差 ΔE<1.0 要求）——小批量定染缸差风险（一批次备足 3 年补单量——**补单缸差是制服商头号难题**，见 `fabric/color-management-pantone-measurement.md`）；
- **版型**：形象岗**一人一版/套码量体**（空乘招聘身材筛选+量体定制）；批量制服**分体型套码**（Y/A/B/C 四体型——见 `garments/pattern-grading-sizing.md`）；
- **丝巾/配饰**：真丝/仿真丝印花丝巾（VI 图案——见 `fabric/digital-printing-technology.md`）；帽子（帽厂外协——贝雷帽/船形帽）；肩章/胸徽（织唛刺绣——见 `garments/embroidered-patches-woven-labels.md`）；
- **细节工艺**：里衬全夹（春亚纺/宾霸）、**丝巾扣/腰带等五金 VI 定制**（开模费计入报价）、门童金绳饰（金属丝编织带——印度手绣金线高端款）；
- **耐用性底线**：空乘制服每周穿 3 天+月洗 2 次——**耐干洗 30 次+耐磨 2 年**（面料马丁代尔 3 万转——形象岗也要过耐用关）。

## 三、商务模式与合规

- **招投标体系**：航空/高铁制服=**年度框架招标**（设计+打样+供货一体——投标需设计团队+样衣展示）；酒店集团=管理公司集采目录（品牌标准手册——按手册供款）；
- **设计能力绑定**：制服订单**设计打样前置**（免费设计提案是竞标成本——中标回收）；知识产权归属（设计版权归招标方条款常见）；
- **合同要点**：**补单条款**（3-5 年补单价格锁定+面料备库责任）；量体数据管理（人员流动——新员工补做周期承诺 15-30 天）；**次品率条款**（形象岗验收苛刻——全检交货）；
- **合规**：普通服装标准（GB 18401——见 `trade-compliance/china-domestic-standards.md`）；航空制服**阻燃非强制**（机组制服舱内防火逻辑由航空公司在招标文件中自定义——羊毛本征阻燃优势）；
- **标识**：航空公司 Logo 使用授权（商标许可条款——见 `trade-compliance/ip-brand-authorization.md`）。

## 四、市场与渠道

- **国内**：航司（三大航+地方航——5 年换装周期）；高铁（路局集采）；**酒店集团**（万豪/希尔顿/洲际标准手册——筹建酒店一次性大单 500-2000 套）；机场地服/安检（换装周期 3 年）；
- **出口**：中东航司（阿联酋/卡塔尔/阿提哈德——**高端面料+奢华设计溢价**）；东南亚酒店（度假村制服——热带面料）；非洲航司（价格敏感）；
- **延伸**：邮轮制服（海乘——耐湿耐盐）、高端物业（售楼处/豪宅礼宾）、企业高管服（金融机构形象款）、**演艺团体**（剧院引座员/乐队制服）；
- **竞争壁垒**：**案例背书**（航司/五星酒店合作案例是下一单门票）+量体数据库+补单响应速度；
- **差评/纠纷点**：补单色差（面料备库不足）、量体偏差（返修成本）、交期延误（开业/换装死线——违约金条款）。
