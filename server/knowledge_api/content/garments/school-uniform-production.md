# 校服生产专题（School Uniform Production）

校服（school uniform）是刚需、复购、计划性强的 B2B2C 品类：学生每年长高换装，订单以学校/教育局集采为主。中国有 GB/T 31888 专用标准；海外校服文化市场（英/日/澳）规则各异。

## 一、市场格局

| 市场 | 特征 |
|:---|:---|
| 中国 | 年规模千亿级；学校招标+家长自愿购买双轨；2021 年"校服新政"强调质量与美育 |
| 英国 | 校服文化发源地（blazer 西装/领带/格纹裙体系）；专业校服零售商（Trutex/Perry） |
| 日本 | 学生服（诘襟/水手服）文化深厚；全数检品品质要求 |
| 澳新 | 校服强制（公立校）；夏冬两季换装 |
| 美国 | 公立校多无校服（dress code 宽松）；私立/教会学校有校服——polo 衫+卡其裤基础款为主 |
| 中东 | 国际学校教育配套增长市场 |

## 二、中国校服标准与监管

- **GB/T 31888-2015《中小学生校服》**：专用国标——安全（GB 18401 全项）+ 耐用（耐穿/耐洗）+ 舒适（棉含量 ≥35% 贴身层）+ 反光（部分省份要求反光标识）；
- **双重质检**：出厂检验 + 学校/教育部门**二次送检**（双送检制度）——中标企业需预留检测预算；
- **监管**：市场监管总局+教育部联合抽查；质量黑名单公示（一次不合格丢区域市场）；
- **家委会参与**：校服选用组织（家长代表占比 ≥80%）——款式审美与价格接受度都要过家长关。

## 三、产品体系

| 品类 | 说明 |
|:---|:---|
| 夏装 | polo 衫/衬衫+短裤/裙（透气面料，棉涤混纺） |
| 春秋装 | 运动套装（空气层/健康布）、棒球服 |
| 冬装 | 冲锋衣/棉服（可脱卸内胆多功能款流行） |
| 制式装 | 西装/衬衫/裙裤正装（礼服场合，英伦风校服标配） |
| 配件 | 领带/领结/袜子/书包 |

- **版型特点**：宽松运动版型为主（活动量+生长余量）；制式装用西装工艺（见 `garments/suits-tailoring-production.md`）。

## 四、生产与供应链要点

1. **面料**：耐磨耐洗是第一指标（机洗 50 次+）；棉涤 60/40 平衡舒适与耐用；针织面料（汗布/空气层）主流；
2. **工艺**：加固缝（学生活动量大）——裤裆/袖窿受力点套结；橡筋腰头（适应生长）；
3. **logo**：校徽绣花（绣花版费按校收取）+ 反光烫画；
4. **尺码**：按身高制（120/130/.../180）——尺码分布按年龄段统计定制；
5. **检针**：童装逻辑——出口日本校服全检针（见 `garments/childrenswear-production.md`）。

## 五、商业模式

- **招投标**：教育局集采招标（资质+样品+价格评审）——资质：ISO9001+GB/T 31888 检测报告+无质量处罚记录；
- **价格管控**：中国校服限价（各地指导价，一套 100-300 元区间）——**成本控制能力=中标能力**；
- **换购补购**：开学季集中交付（8 月峰值）+ 全年零星补购——需备现货库存；
- **服务绑定**：量体/配送/调换服务是竞争差异点；线上商城（小程序复购）渐成标配。

## 六、出口机会

- **英国校服**： blazer 制式装+格纹裙——西装工艺要求高，单价高；
- **日本校服**：全检品要求（见 `customers-market/jp-market.md`）；
- **澳新**：夏冬两套体系+户外功能（防晒 UPF 校服）；
- **中东/非洲**：国际学校+本地校服普及化——新兴市场增量。
