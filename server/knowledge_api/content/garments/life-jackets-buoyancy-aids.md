# 救生衣与浮力装备生产（Life Jackets: 浮力背心/充气救生衣/EN ISO 12402）

救生装备是"**纺织结构+安全认证**"的强监管品类：浮力材料提供浮力、织带系统提供固定，**认证（CE/USCG）是准入门槛而非加分项**。市场三赛道：水上运动消费（桨板/皮划艇/钓鱼——增长最快）、船舶配备（SOLAS 强制）、儿童产品（合规雷区最多）。工艺门槛中等，**认证成本与责任风险**才是真正的门槛——产品责任险必备（见 `trade-compliance/product-liability-recall.md`）。

## 一、产品分类与浮力等级（EN ISO 12402 体系）

| 等级 | 类型 | 浮力 | 场景 |
|:---|:---|:---|:---|
| 50N | 浮力背心（buoyancy aid） | ≥50N | 会游泳者近岸/水上运动 |
| 100N | 救生衣（life jacket） | ≥100N | 平静水域（有翻转复位要求） |
| 150N | 救生衣 | ≥150N | 近海（穿着厚重衣物也能翻转） |
| 275N | 救生衣 | ≥275N | 远海/极端工况 |

- **关键区分**：50N 是"助浮"不是"救生"——listing 混用宣称是诉讼雷区；100N 以上必须**翻转测试**（失去意识者面部朝上复位）；
- **美国体系**：USCG Type I/II/III/V（Type III=运动款主流）——USCG 认证需**认可实验室测试+工厂检查**，周期长费用高（单款 $10k+）。

## 二、材料与结构

- **浮力芯**：EPE/PE 发泡片（分层裁片——肩部/胸背分块贴合体型）；NBR/PVC 闭孔泡棉（柔软款）；**浮力材料批次浮力值抽测**（吸水率<5%——浸水 24h 浮力损失超标=整批报废）；
- **面料**：210D/420D 尼龙/涤纶牛津（PU 涂层）——高强度+耐水解（见 `fabric/canvas-oxford-fabrics.md`）；儿童款鲜艳色+反光条；
- **受力系统**：38-50mm 高强度织带（断裂强力≥2kN）+插扣（ITW/多耐福品牌件）——**受力点打枣（bar-tack）42 针以上**；裆带（crotch strap——防救生衣冲脱头部，儿童款强制）；
- **充气式**：TPU 气密涂层布+**高周波焊接气室**（见 `garments/dry-bags-waterproof-pouches.md` 同工艺）；CO2 气瓶（16g/24g/33g）+自动触发器（水溶片）/手动拉绳——**气瓶属危险品运输**（空运受限，一般客户本地采购）；
- **配件**：口哨（ISO 12402 强制）+反光膜（SOLAS 级）+提拉带。

## 三、认证与合规

- **欧盟**：PPE 法规 (EU) 2016/425 **II 类**（浮力背心）/III 类（救生衣——淹溺致命风险）→CE 认证：模块 B 型式检验+III 类加模块 C2/D 工厂监督（见 `trade-compliance/ppe-protective-clothing-compliance.md` 的 PPE 路径）；
- **测试项目**：浮力值/浮力分布/强度（织带/衣身）/翻转性能/耐高低温/耐油——EN ISO 12402 各部分对应；
- **美国**：USCG 批准（UL 测试）——亚马逊美国站要求 USCG approval number；
- **儿童红线**：**游泳圈/浮袖是玩具（EN71）不是救生设备**——按救生衣宣称=虚假安全宣称（欧美召回高频）；儿童浮力泳衣（learn-to-swim vest）按 PPE+玩具双标准争议区；
- **国内**：GB/T 32227（船用工作救生衣）/GB 4303（船用救生衣——CCS 船检）。

## 四、生产与市场要点

- **版型**：浮力块分布（前胸>后背——翻转配平）；**多码体系**（按体重+胸围双维度——50N 背心通常 XS-XXL 6 码）；
- **品控红线**：织带打枣全检（漏打=致命）；浮力芯**不可遗漏一片**（充填工位计数管理+成品浮力抽检）；
- **市场节奏**：北半球 4-6 月旺季（2-3 月到仓）；水上运动渠道（迪卡侬 ODM——见 `customers-market/brand-retailer-supplier-systems.md` 的品牌供应商体系）；钓鱼救生背心（多口袋功能款——日本市场成熟）；
- **责任风险管理**：警示标签（"非救生设备"/体重适用范围/穿着图示）+多语言说明书+产品责任险保额核查；
- **差评高发点**：尺码偏小（浮力块让版型紧——listing 必须给体重胸围对照）、闷热（网眼透气设计）、插扣断裂（用品牌扣具规避）。
