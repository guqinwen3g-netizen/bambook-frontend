# 骑行服与专业运动装备生产专题（Cycling & Technical Sportswear）

骑行服是运动服中"**技术含量密度最高**"的品类：一件骑行裤涉及人体工学垫裆、气动剪裁、防滑收边——小众但客单价与复购率双高。

## 一、品类结构

| 品类 | 核心件 |
|:---|:---|
| 骑行服（jersey） | 短袖/长袖上衣（后三袋+全拉链+防滑下摆） |
| 骑行裤（bib shorts） | 背带短裤（垫裆 chamois 是灵魂——无背带款腰部下滑） |
| 铁三服（triathlon suit） | 连体（游泳/骑行/跑步三栖——薄垫裆） |
| 骑行外套/马甲 | 防风防泼水（轻量可收纳） |
| 周边 | 袖套/腿套/骑行袜/手套 |

## 二、核心部件：垫裆（chamois）

- **结构**：多层泡棉（密度分区——坐骨区高密度 120kg/m³，周边递减）+表层亲肤绒布;
- **男/女/铁三差异**：男女骨盆结构不同垫型不同（铁三垫薄——跑步不磨腿）;
- **等级**：入门级海绵/中高级多层密度/顶级凝胶+透气孔（长时间骑行 5 小时+ 区分度）;
- **品牌垫裆**：意大利 Elastic Interface（行业标杆——品牌款指定用垫，采购价 $3-15/副）;
- **固定工艺**：平锁缝（flatlock——防磨）+精准定位（偏差 5mm 就磨——车缝定位模板）。

## 三、面料体系

- **主体**：锦纶/涤纶+氨纶 15-25%（高弹压缩——锦纶手感好耐磨，涤纶印花好）;
- **压缩性**：梯度压缩（小腿>大腿——促进回血的功能宣称需测试）;
- **气动面料**：高尔夫凹坑纹/条纹导流（袖腿拼接区——wind tunnel 数据是高端卖点）;
- **网眼透气**：腋下/后背大网眼（散热区）;
- **UPF 防晒**：长袖款 UPF 50+（见 `garments/sun-protection-clothing.md`）。

## 四、工艺要点

- **平锁缝（flatlock）**：四针六线专用机（接缝平贴不磨皮——骑行服工艺标志）;
- **热压贴合**：无缝裤口/袋口（减少风阻+美观）;
- **防滑收边**：硅胶点胶/硅胶织带（裤腿/下摆——骑姿不滑移）;
- **反光**：反光转印标（夜骑安全——欧规 EN 17353 可视性服装）;
- **升华印花**：全车花（热升华涤纶——队服定制主力工艺，见 `garments/printing-embroidery.md`）;
- **立体剪裁**：骑行姿态版型（前短后长+弯腰袖——站立穿不合身是正常的）。

## 五、市场与订单

- **骑行热潮**：欧美成熟+中国爆发（2020 后国内骑行人口激增——中高端装备国产化替代）;
- **客户类型**：骑行品牌（Rapha/Castelli 梯队——意大利/英国设计）/车队队服（定制小单）/电商品牌;
- **订单特征**：队服定制 50-300 件（热升华数码化——快反小单）/品牌款 500-3000 件;
- **品质敏感**：垫裆投诉是生死线（磨裆=差评——垫裆供应商不可省）;
- **产业带**：广东（骑行服集群——东莞/广州）/福建（运动针织配套）。

## 六、延伸品类（同技术复用）

- **铁三/跑步**：压缩裤/竞速背心;
- **马术**：骑马裤（膝部硅胶防滑——工艺同源）;
- **摩托骑行**：防摔骑行服（CE 护具仓——EN 17092 认证）;
- **滑雪内层**：压缩保暖内衣（见 `garments/activewear-production.md`）。

## 七、开发注意

- **试穿测试**：必须真实骑行测试（办公室试穿无意义——长距离磨点才暴露）;
- **尺码表**：骑行服贴身（尺码偏差投诉高发——实测各码拉伸率）;
- **洗护**：冷水柔洗+禁柔顺剂（柔顺剂破坏吸湿排汗——洗标教育）;
- **认证**：常规 OEKO-TEX（见 `trade-compliance/textile-certifications.md`）——无特殊强制，但职业队服有 UCI 规则限制（赞助商标尺寸等）。
