# 宠物服装与用品生产专题（Pet Clothing & Accessories）

全球宠物经济 3000 亿美元级，宠物服装（pet apparel）是服装企业低门槛跨界的高增长品类：工艺与童装同源、起订量小、电商渠道为主、利润率高于成人装。

## 一、市场格局

- **规模**：宠物服装+配件全球年增 6-8%；北美占 45%（美国宠物渗透率 70% 家庭）、欧洲 30%、亚太增长最快。
- **渠道**：亚马逊（pet apparel 类目）、Chewy、Petco/Petsmart、独立站 DTC 品牌（如 Canada Pooch）。
- **价格带**：零售 $15-60 为主流；功能性（防水/保暖）可达 $80-120。

## 二、产品体系

| 品类 | 要点 |
|:---|:---|
| 宠物 T 恤/卫衣 | 基础款，棉/涤针织，印花是核心卖点 |
| 宠物外套/雨衣 | 防水面料+反光条（夜行安全） |
| 宠物毛衣 | 针织（小型犬秋冬刚需） |
| 节日服装 | 万圣节/圣诞——强季节波段 |
| 宠物鞋/袜 | 防滑底 |
| 配件 | 牵引绳/胸背带（harness）/项圈/口水巾/窝垫 |

## 三、设计与版型（核心技术点）

- **犬种体型差异是版型核心**：腊肠（长身）、法斗（胸宽颈粗）、吉娃娃（微小体）——同一款式需按犬种体型调整版型。
- **尺码体系**：背长（back length）+ 胸围（chest girth）+ 颈围（neck）三围制（XS-XXL）；**胸围是首要合身维度**。
- **结构特点**：腹部开口（便于排泄）、背部开合（魔术贴/四合扣穿脱）、牵引孔（harness hole）——这些是宠物装与童装的关键差异。
- **安全设计**：无小零件（防误食）、缝线牢固（耐撕咬）、无毒染料（啃咬场景）。

## 四、面料与工艺

- **面料**：与童装共享供应链（棉针织/摇粒绒/防水尼龙）；功能性需求增长（凉感面料夏装、发热面料冬装）。
- **工艺**：童装级缝制即可；弹性收口（袖口/腹围）用橡筋或罗纹。
- **印花**：数码印花/丝印（宠物 IP 图案是溢价点——授权 IP 见 `trade-compliance/ip-brand-authorization.md`）。
- **安全测试**：耐唾液色牢度（啃咬）、小部件拉力（同童装 16 CFR 1501 逻辑）。

## 五、订单与生产特征

- **MOQ 友好**：300-500 件/款（电商测款模式）；
- **SKU 爆炸**：款式 × 尺码（6-8 个）× 颜色——排产与物料管理复杂度高；
- **交期**：30-45 天；节日单（万圣节 8 月出货）季节性强；
- **检品**：电商退货率敏感（尺码不合是第一大退货原因——尺码表准确性是核心竞争力）。

## 六、客户开发与合规

- **目标客户**：亚马逊大卖、DTC 宠物品牌、宠物连锁自有品牌；
- **合规**：美国市场无专门宠物服装法规，但 CPSIA 类安全逻辑被平台参照执行（小部件/铅/邻苯）；欧盟 CE 不适用但 REACH 化学品适用；
- **知识产权**：宠物 IP 图案（迪士尼/史努比授权）是侵权重灾区——接印花单必查授权（见 `trade-compliance/ip-brand-authorization.md`）。

## 七、成本与利润

- **成本结构**：单件面料 0.1-0.3m（小体型），CMT 5-12 元——总成本 8-25 元，出厂价 $2-8，零售 $15-60（**渠道加价率 3-5 倍**，DTC 品牌毛利高）。
- **供应商利润**：毛利 25-40%（高于成人基础款），且库存风险低（无过季贬值——款式生命周期长）。
