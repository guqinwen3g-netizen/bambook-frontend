# 食品接触纺织品生产（Food-Contact Textiles: 茶包布/蒸笼布/过滤袋布）

食品接触纺织品是"**小品类高合规门槛**"的细分：茶包、咖啡过滤袋、蒸笼布、奶酪布、卤料袋、坚果奶过滤袋直接接触食品，**食品级法规（FDA/EU 食品接触材料）是入场券**。与厨房纺织品（围裙/隔热手套——不直接入口接触，见 `garments/kitchen-textiles-production.md`）的监管逻辑完全不同。

## 一、产品矩阵

| 品类 | 材质 | 关键要求 | 场景 |
|:---|:---|:---|:---|
| 一次性茶包布 | PLA 玉米纤维/木浆滤纸/PET 无纺布 | 热封/超声封合、透水性 | 袋泡茶工业化 |
| 可重复使用茶滤袋 | 全棉细布/麻布+抽绳 | 耐煮、无荧光 | 散茶/花草茶 |
| 咖啡过滤袋（cold brew） | 尼龙/涤纶细网（100-200 目） | 目数精度、缝线耐浸 | 冷萃咖啡包 |
| 奶酪布（cheesecloth） | 全棉稀纱布（Grade 10-90 目数分级） | **Grade 90（细密）溢价**、未漂白原棉 | 西餐厨房/奶酪制作 |
| 蒸笼布/屉布 | 全棉平纹/硅胶垫（替代） | 耐蒸煮、不粘、无浆料 | 中式面点 |
| 卤料袋/煲汤袋 | 全棉细布+抽绳 | 耐煮、纤维不脱落 | 中餐/药膳 |
| 坚果奶/果汁过滤袋（nut milk bag） | 尼龙 80-200 目细网+包边 | **U 型底无死角**、耐拧挤 | 植物奶风潮 |
| 豆腐布/压制布 | 全棉粗平布 | 透水、耐压 | 豆腐作坊 |
| 葡萄酒压榨袋 | 尼龙/涤纶网 | 耐酒石酸 | 家酿 |

## 二、食品级合规框架

- **美国 FDA**：食品接触纺织品按**间接食品添加剂**管理——21 CFR 相关章节（棉花/纤维素类相对宽松，合成纤维需符合 21 CFR 177 聚合物条款）；**染料/助剂迁移是监管核心**；
- **欧盟**：框架法规 (EC) 1935/2004+GMP (EC) 2023/2006——**纺织品类无统一专项措施**（活性和智能材料除外），按成员国产格执行（德国 LFGB 最严——**LFGB 测试是高端市场敲门砖**）；
- **中国**：GB 4806 系列（食品接触材料）——内销产品需符合；
- **关键检测项**：**总迁移量、特定迁移（甲醛/重金属/偶氮）、感官测试（气味/味道迁移）、荧光增白剂（食品接触禁用）**；
- **认证路径**：第三方实验室检测出报告（实验室选择见 `trade-compliance/testing-lab-selection.md`）——**无认证即上架亚马逊=下架风险**。

## 三、材料与生产要点

- **材质红线**：**未漂白/原色优先**（漂白剂残留争议）、禁荧光增白、禁用回收纤维（来源不明=迁移不可控）；尼龙网布需**食品级 PA66**（工业网布不可挪用——工业过滤布见 `fabric/industrial-filter-fabrics.md`，同机织技术但合规等级不同）；
- **缝制工艺**：**食品级缝纫线**（无硅油/低硅油——工业线硅油迁移风险）；包边缝线防纤维脱落（毛边入食品=异物投诉）；
- **PLA 茶包热封**：PLA 无纺布热封温度窗口窄（110-130℃）——与茶企灌装线参数匹配；
- **目数管理**：网布目数与孔径对照表随货（80 目≈180μm）——**目数虚标是品类纠纷点**；
- **清洁生产**：车间洁净度管理（头发/飞花异物管控——逻辑同验针管理见 `suppliers/needle-control-metal-management.md`）；成品**独立密封包装**。

## 四、市场与商业要点

- **需求驱动**：家庭咖啡/植物奶/精酿风潮（欧美厨房 DIY）、中式餐饮出海（蒸笼布/卤料袋）、袋泡茶工业（茶包布 B2B 大宗）；
- **渠道**：亚马逊厨房类目（cheesecloth/nut milk bag 为常青关键词）、餐厅供应链（WebstaurantStore 类）、茶企/咖啡厂 OEM；
- **价格与利润**：低值小件但**食品级溢价 30-50%**——合规检测成本摊入；
- **复购属性**：一次性茶包 B2B 复购稳定；可重复使用款靠**多件装+替换周期**；
- **延伸**：咖啡冷萃桶配套滤袋、酸奶过滤袋（希腊酸奶风潮）、香辛料袋。

## 五、风控要点

- **迁移测试随批留档**：染料批次变更=重新测试——**供应链变更管理**（面料换供应商必须重测）；
- **宣称边界**："BPA free/food grade"需检测支撑——泛化宣称触发 FTC/平台审查（反漂绿逻辑见 `trade-compliance/green-claims-anti-greenwashing.md`）；
- **异物责任**：纤维脱落混入食品=食品安全投诉——**产品责任险覆盖**（见 `trade-compliance/product-liability-recall.md`）；
- **化学合规交叉**：偶氮/甲醛/邻苯基础项见 `trade-compliance/chemical-environmental-compliance.md`——食品接触在基础项上**加严迁移限值**；
- **PLA 可降解宣称**：需工业堆肥条件说明（"可降解"裸宣称=漂绿）。
