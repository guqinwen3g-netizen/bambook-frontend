# 保温包与冷藏包生产（Insulated Bags: 冷链/午餐包/外卖箱/保温材料）

保温包是"**箱包工艺+隔热材料**"的交叉品类：午餐包、野餐冷藏包、外卖配送箱、医药冷链软包、母乳保鲜包。消费端=欧美户外野餐文化+午餐带饭习惯（刚需高频）；商用端=外卖/生鲜配送（中国外卖箱产业全球最大）。箱包基础见 `garments/bags-luggage-production.md`。

## 一、三层结构与材料

| 层 | 材料选项 | 功能 |
|:---|:---|:---|
| 外层 | 600D/900D 牛津布、帆布、Tyvek、PU 革 | 耐磨防水外观（见 `fabric/canvas-oxford-fabrics.md`） |
| 隔热层 | **EPE 珍珠棉（3-10mm）**、XPE、气凝胶毡（高端）、真空绝热板 VIP（医药级） | 导热系数决定保温时长 |
| 内层 | **铝箔/镀铝膜（PEVA）**、食品级 PEVA/TPU 膜 | 反射辐射热+防水易擦（**必须食品接触合规**） |

- **保温性能表述**："保冷 8 小时"类宣称的测试口径——配冰袋/冰板数量、环境温度、初始内容物温度都必须标注（无统一强制标准但虚假宣传是差评与投诉点）；
- **拉链命门**：保温包的拉链开口是漏冷点——**气密拉链/防水拉链**（见 `suppliers/zipper-fasteners-deep-dive.md`）或卷口设计（roll top）提升性能；内缝压胶防渗水。

## 二、产品线分级

| 产品 | 规格 | 价格带（零售） | 要点 |
|:---|:---|:---|:---|
| 午餐包（lunch bag） | 5-15L | $10-30 | 轻量+颜值（印花——见 `fabric/digital-printing-technology.md`） |
| 软冷藏包（soft cooler） | 10-40L | $25-150 | 保温时长竞赛（YETI 高端标杆——焊接无缝内胆） |
| 外卖配送箱 | 40-100L 双肩/车载 | ¥80-300 | 耐磨+分区+支架；美团/饿了么供应链 |
| 医药冷链包 | 2-8°C 疫苗/胰岛素 | $50-500 | **温度记录仪+验证报告（GDP 规范）**——准入壁垒 |
| 母乳/奶瓶包 | 2-6L | $15-40 | 母婴渠道（配合冰袋销售） |

## 三、生产工艺要害

- **高频焊接/热压**：内胆无缝（渗水+藏污纳垢是低端款差评首因）——高端软冷藏包全焊接内胆是分水岭工艺；
- **珍珠棉复合**：铝膜与 EPE 热复合——复合牢度（剥离不掉膜）；绗缝固定防位移；
- **结构细节**：排水口（融冰排水——冷藏包必备）、透气孔悖论（密封 vs 异味）、背带缓冲（满载 10kg+ 肩部压力）；
- **冰袋配件**：凝胶冰袋（PE+吸水树脂——防漏测试）配套销售提高客单；
- **验针与异物**：同纺织纪律（见 `suppliers/needle-control-metal-management.md`）。

## 四、合规与市场

- **食品接触材料**：内层膜——美国 FDA 21 CFR 177、欧盟 10/2011（迁移测试）；**邻苯与重金属**（见 `trade-compliance/chemical-environmental-compliance.md`）；
- **医药冷链**：WHO PQS（疫苗包认证）/欧盟 GDP——温度验证报告（多通道温度记录仪 48h 测试）是投标资质；疫情后疫苗包需求常态化；
- **渠道**：亚马逊（午餐包/软冷藏包常青品类）、户外渠道（REI 类——与露营协同，见 `garments/camping-gear-tents-sleeping-bags.md`）、商超季节性堆头（夏季）、企业促销品（logo 定制——见 `customers-market/promotional-products-channel.md`）；
- **季节节奏**：北半球 3-7 月旺季（野餐季+返校季 lunch box 8 月次峰）——订单前置；
- **客诉热点**：漏水（焊缝/拉链）、保温虚标、内衬异味（PEVA 膜 VOC——散味处理）、提手断裂（满载受力点打枣加固）；
- **竞争格局**：YETI 占据高端心智（品牌溢价 5 倍+）——中国工厂机会在中端性价比+外观差异化（印花/配色/联名）。
