# 防晒衣品类生产专题（Sun Protection Clothing）

防晒衣是"**功能宣称需检测背书**"的品类：UPF 值是核心卖点也是监管红线——虚标是电商投诉与抽检处罚高发区。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 防晒衣/皮肤衣 | 轻薄连帽外套（UPF 50+ 标配——夏季爆品） |
| 防晒衬衫/开衫 | 通勤化设计（女装主力） |
| 冰袖/面罩/防晒帽 | 配件类（骑行/户外场景） |
| 防晒裤/瑜伽防晒 | 运动场景延伸 |
| 儿童防晒衣 | 泳衣+防晒（海边场景——UPF 泳装） |

## 二、核心指标：UPF

- **UPF（Ultraviolet Protection Factor）**：紫外线防护系数——UPF 50+ 表示仅 1/50 紫外线透过（阻隔率 98%+）；
- **分级**：UPF 15-24（一般）/25-39（较好）/40-50+（优秀——**宣称"防紫外线产品"最低门槛 UPF 40+**）；
- **检测标准**：
  - 中国 GB/T 18830（防紫外线性能评定——UPF>40 且 UVA 透过率<5% 才可宣称）;
  - 美国 AATCC 183 / 澳洲 AS/NZS 4399（标准发源地——澳新防晒服最成熟）;
  - 欧盟 EN 13758;
- **宣称红线**：无检测报告宣称"防晒/UPF 50+"=虚假宣传（市场监管抽检+职业打假高发）。

## 三、防晒技术路线

- **原纱防晒（首选）**：纺丝添加二氧化钛/陶瓷微粒（永久性防晒——洗涤不衰减）;
- **织物结构**：高密度编织（物理遮蔽——克重/密度决定基础 UPF）;
- **染整助剂**：紫外线吸收剂后整理（成本低但洗后衰减——寿命 30-50 次洗涤）;
- **深色>浅色**：同色面料深色 UPF 更高（但深色吸热——凉感矛盾需平衡）。

## 四、面料选择（凉感+防晒双功能）

- **冰丝/锦纶**：锦纶+氨纶针织（凉感滑爽——夏季体感核心卖点）；
- **涤纶原纱防晒**：户外品牌路线（耐久+轻量）；
- **凉感助剂**：薄荷/木糖醇凉感整理（接触凉感系数 Q-max≥0.15 宣称凉感——GB/T 35263）;
- **透气矛盾**：高密度防晒 vs 透气闷热（激光冲孔/腋下透气网眼设计平衡）。

## 五、设计与工艺

- **连帽+面罩**：一体式面罩（骑行款——拉链护脸）；
- **指扣袖口**：手背防晒（拇指洞设计）；
- **版型**：宽松（贴身降低 UPF——拉伸使织物孔隙变大 UPF 下降）;
- **印花注意**：深色印花提升 UPF 但影响凉感（浅色+原纱防晒是主流方案）。

## 六、检测与合规

- **必检项目**：UPF+UVA 透过率（GB/T 18830 全项）;
- **洗后 UPF**：宣称"永久防晒"需洗 20-50 次后复测（原纱路线优势）;
- **吊牌规范**：标注 UPF 值+执行标准+洗涤说明（见 `trade-compliance/textile-labeling-regulations.md`）;
- **出口**：美国 FTC 功能宣称监管（无检测勿宣称）/澳新市场最认 AS/NZS 4399 报告。

## 七、市场与订单

- **国内爆发**：防晒服中国市场年销百亿级（蕉下/ohsunny 引领——6-8 月旺季提前 3 个月备货）;
- **出口场景**：东南亚（全年防晒）/中东（罩袍式防晒）/澳新（皮肤癌高发——刚需）;
- **订单特征**：季节性强（3-5 月下单集中——快反能力关键）;
- **产业带**：浙江义乌/泉州（电商快反）/江苏（品牌代工）。

## 八、风险提示

- **UPF 虚标**：职业打假重灾区（实测 UPF<40 即构成欺诈——留检测报告原件）;
- **凉感虚标**：Q-max 无检测勿宣称;
- **儿童款**：叠加童装安全标准（见 `trade-compliance/cpsc-children-safety.md`）。
