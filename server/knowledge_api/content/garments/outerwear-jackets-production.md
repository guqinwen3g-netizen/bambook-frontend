# 外套与羽绒服生产专题（Outerwear & Down Jacket Production）

外套（outerwear）是梭织成衣中工艺最复杂的品类：多层面料结构、填充物、功能性要求（防水/防风/保暖）叠加。羽绒服的**含绒量与防绒**是质量生死线。

## 一、填充物（Filling）

### 羽绒（Down）
| 指标 | 说明 | 标准 |
|:---|:---|:---|
| 含绒量（down content） | 绒朵占比：50%/70%/80%/90% | 90% 为高档（国标 90 绒） |
| 蓬松度（fill power, FP） | 每盎司立方英寸：500/600/700/800+ | 700+ 属高端户外 |
| 种类 | 白鹅绒 > 灰鹅绒 > 白鸭绒 > 灰鸭绒 | 鹅绒朵大蓬松 |
| 清洁度 | 浊度/耗氧量 | 国标 ≥ 450mm |
| 气味 | 微生物指标 | 无异味 |

- **新国标 GB/T 14272-2021**：绒子含量替代旧"含绒量"口径，标注更严格。
- **RDS 认证（Responsible Down Standard）**：欧美品牌强制（禁止活拔绒/强迫喂食），需 TC 交易证书链。
- 计价：羽绒按 kg 计（90 白鸭绒约 300-500 元/kg 随行情波动），单件充绒量 100-300g（按款式/尺码/FP 设计）。

### 棉服填充
- **仿羽绒棉（down-alternative）**：中空涤纶短纤，低价耐洗。
- **新雪丽（3M Thinsulate）**：高效保暖薄型棉，户外品牌常用。
- **杜邦 Sustans/索罗娜**：生物基环保棉。

## 二、面料与结构

- **面料**：尼丝纺/涤塔夫（20D-40D 轻薄防绒）、塔斯隆、春亚纺；户外款用防水透湿膜贴合面料（静水压 5000-10000mm+）。
- **防绒（down-proof）**：面料高密度+防绒涂层/轧光；**针孔钻绒**是最大客诉——需细针（7-9 号圆头针）、小针距（3cm/11-13 针）、缝线硅油润滑。
- **胆布（lining/down bag）**：双层防绒胆布包裹羽绒（400T 高密防绒布）。
- **结构**：立衬（baffle box，户外高档）vs 切穿绗缝（sewn-through，轻量）。

## 三、生产工艺要点

1. **充绒（filling）**：自动充绒机按格定量（误差 ±1g），充绒间防风（羽绒飘散）。
2. **绗缝（quilting）**：充绒后绗线固定；先充后绗 vs 先绗后充两种工艺路线。
3. **压胶（seam taping）**：冲锋衣全压胶防水（胶条宽度/温度/剥离强度是检验点）。
4. **专机**：模板机（绗线均匀）、充绒机、压胶机。
5. **配件**：防水拉链（YKK AquaGuard）、魔术贴、调节绳、风裙（powder skirt 滑雪服）。

## 四、质量检验要点

| 项目 | 标准 |
|:---|:---|
| 钻绒测试 | 摩擦/滚箱法，钻绒根数 ≤ 标准值 |
| 充绒量偏差 | 单件 ≥ 标称 -5% |
| 绒子含量/蓬松度 | 第三方检测（IDFL 为国际权威羽绒实验室） |
| 防泼水（spray rating） | 洗前 90 分/洗后 80 分（AATCC 22） |
| 静水压/透湿 | 按户外等级（如 10000mm/10000g） |
| 甲醛/pH/异味 | 常规安全项目 |

## 五、报价与采购

- **成本结构**：面料 25-35% + 羽绒 25-40%（90 绒占比最高）+ 工费 20-30% + 辅料。
- 羽绒服 CMT 30-60 元（结构复杂度差异大）；冲锋衣 40-80 元（压胶工序）。
- **羽绒价格锁价**：绒价季节波动大（冬季涨），大单提前备绒锁价。
- **产业带**：江苏常熟（羽绒服之都）、浙江平湖、广东虎门。

## 六、合规要点

- **RDS/Downpass**：羽绒人道采购认证，品牌强制。
- **标签**：含绒量/充绒量/蓬松度标注（FTC 与国标均有规定，虚标是打假重灾区）。
- **PFC-Free 防泼水**：欧盟 PFAS 禁令下，含氟防泼水剂（C8/C6）淘汰，改无氟（PFC-free）DWR——见 `trade-compliance/chemical-environmental-compliance.md`。
