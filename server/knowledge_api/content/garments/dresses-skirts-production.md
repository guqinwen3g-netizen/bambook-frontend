# 裙装品类生产专题（Dresses & Skirts Production）

裙装（dresses & skirts）是女装第一大品类：款式变化最多（连衣裙是每个季节的"主战场"）、工艺跨度大（梭织/针织/雪纺/礼服）。

## 一、品类结构

| 品类 | 特征 |
|:---|:---|
| 连衣裙（dress） | 连身款——夏季主力；按廓形分 A 字/H/X/鱼尾 |
| 半身裙（skirt） | 铅笔裙/A 字裙/百褶裙/伞裙/鱼尾裙 |
| 礼服裙 | 见 `garments/evening-wedding-dress.md` |
| 吊带裙/露肩裙 | 夏季度假风 |
| 衬衫裙/T恤裙 | 休闲风（面料决定风格） |
| 裹身裙（wrap dress） | DVF 经典——一片式裹身结构 |

## 二、版型核心

### 连衣裙版型要素
- **胸省/腰省**：省道处理（soustraction——收腰廓形的关键）；
- **裙长（length）**：mini/knee/midi/maxi——裙长是风格分水岭（季节趋势敏感）；
- **腰线位置**：高腰线（显腿长）/自然腰/低腰（H 廓形）；
- **裙摆量**：摆围（sweep——A 字摆量 180°/360°/720° 大摆）。

### 半身裙版型
- **腰臀差**：亚洲 vs 欧美体型（臀围放量）；
- **开衩（slit/vent）**：后开衩（行走量）——铅笔裙必须；
- **百褶（pleat）**：压褶工艺（定型褶——洗后褶保持度是质量点）。

## 三、面料与廓形匹配

| 廓形 | 面料 |
|:---|:---|
| 垂坠飘逸 | 雪纺/真丝/粘胶（垂感） |
| 挺括廓形 | 棉府绸/斜纹/复合面料 |
| 贴身包臀 | 弹力针织/罗马布 |
| 大摆蓬蓬 | 欧根纱/塔夫绸（支撑） |
| 鱼尾 | 有骨的缎面/厚缎 |

- **面料选错 = 廓形垮塌**（大摆裙用软塌面料 = 没有摆的效果）。

## 四、核心工艺

- **拉链**：连衣裙后中/侧缝隐形拉链（invisible zipper——工艺要求高：咬合隐形不起拱）；
- **里布**：连衣裙加里布（防透/滑爽——雪纺裙必须，见 `fabric/linings-interlinings.md`）；
- **裙摆处理**：卷边/贴边/密拷（雪纺细卷边是工艺点）；
- **省道**：省尖处理（圆润无尖角——熨烫归拔）。

## 五、订单特征

- **快时尚主力**：连衣裙是 Zara/Shein 的核心品类（周上新——快反订单）；
- **季节波段**：夏裙 12-3 月下单；秋裙 6-8 月；
- **印花裙**：连衣裙是印花最大应用（雪纺印花裙——见 `fabric/digital-printing-technology.md`）；
- **尺码**：裙装退货率电商居高（合身敏感——尺码表+模特参考）。

## 六、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 拉链 | 隐形拉链咬合/平服（拉合顺畅无波浪） |
| 左右对称 | 裙摆左右长短一致 |
| 里布 | 里布长度（不外露）/防静电 |
| 印花对位 | 侧缝/省位印花对花 |
| 裙摆卷边 | 均匀无波浪（雪纺卷边技术点） |
| 百褶 | 褶型均匀+洗后保持 |

## 七、产业带

- **广州**：快时尚连衣裙（十三行/沙河——快反）；
- **杭州**：真丝/雪纺连衣裙（丝绸之府）；
- **深圳**：中高端女装（品牌连衣裙）。
