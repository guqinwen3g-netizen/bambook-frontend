# 北美团队运动服定制（Team Uniforms: 棒球/橄榄球/篮球/啦啦队）

团队运动服是美国**校园+社区体育文化**支撑的定制市场：棒球/橄榄球/篮球/冰球/曲棍球/啦啦队，每个球队每季换装——**全幅热升华定制**（队名/号码/球员名）是主流工艺。订单特征=小单多款（一队 15-40 套）+交期刚性（赛季开赛日）+复购稳定。渠道=球队装备经销商（Alleson/Augusta 模式）+定制平台（线上自助设计下单）。

## 一、品类与面料

| 品类 | 面料 | 结构要点 |
|:---|:---|:---|
| 棒球服（jersey） | 涤纶网眼/双面布 | 全扣/半扣门襟+插肩袖 |
| 橄榄球服 | 高弹涤氨+加厚肩部 | 耐磨+肩垫兼容（大码宽松） |
| 篮球服 | 涤纶网眼/双面针织 | 背心+短裤套装 |
| 冰球服 | 重磅涤纶（300g+） | 超大码（护具外穿） |
| 啦啦队服 | 涤氨弹力+百褶裙 | 贝壳衫+短裙+金属丝饰条 |

- **面料**：100% 涤纶（热升华载体——涤纶含量决定印花鲜艳度）；**色牢度+不起球**（赛季高频洗涤）；
- **克重**：训练款 140-160g/比赛款 180-220g/冰球 280g+；
- **功能**：吸湿排汗整理（wicking——宣称需实测，见 `fabric/functional-fabrics.md`）。

## 二、热升华定制工艺（核心）

- **全幅升华（full sublimation）**：裁片印花后缝制——图案无限位（整件覆盖队徽/渐变/纹理，见 `fabric/digital-printing-technology.md`）；**对位精度**：袖子/门襟图案跨缝对齐是验货点；
- **排版软件**：按尺码混排（一套版含全尺码裁片——省料排版）；
- **号码/姓名**：升华一体印（主流）vs 贴布绣（tackle twill——高端线：斜纹布激光切+锁边绣，棒球职业风）；
- **色管控**：Pantone 队色对色（学校队色有官方 PMS——色差=整队退货，见 `fabric/color-management-pantone-measurement.md`）；
- **白底防透**：深色升华白底面料——防透光（深色图案印在白色基底+克重 180g+ 防透）。

## 三、订单运营要点

- **订单流程**：客户平台自助设计（3D 预览）→AI 核稿（logo 分辨率/版权元素）→拼版生产→**7-10 天交付**（赛季前爆单期产能瓶颈）；
- **尺码体系**：美式 YXS-3XL（青少年+成人同版——尺码表按胸围/衣长实测照片）；
- **起订量**：升华定制 1 件起（数码无版费）——但团队单均价 $15-35/件（球衣+裤套装 $40-70）；
- **IP 红线**：**职业球队 logo（NFL/MLB/NBA/NHL）与校徽属授权资产**——客户须提供学校/联盟授权书（无授权印 NCAA/NFL 元素=侵权重灾，见 `trade-compliance/ip-brand-authorization.md`）；
- **复购**：球队每年新球员补单+每 2-3 年换设计——**存档花型=锁定复购**；
- **季节**：棒球春季（1-2 月下单）/橄榄球秋季（6-7 月下单）/篮球冬季（9-10 月）——全年错峰排产。

## 四、合规要点

- **常规化学**：偶氮/甲醛/邻苯（青少年贴肤——CPSIA 适用儿童尺码，见 `trade-compliance/cpsc-children-safety.md`）；
- **阻燃**：无特殊要求（运动服豁免逻辑）；啦啦队金属丝饰条**镍释放**（欧盟单查）；
- **标签**：美国制造 vs 进口标注（"Made in USA"宣称红线——进口成衣不得标）；纤维成分标签（FTC——见 `trade-compliance/textile-labeling-regulations.md`）。

## 五、报价与接单

- **成本结构**：涤纶面料+印花（墨水量按覆盖率）+人工——升华款人工占比低（工序少）；贴布绣款人工翻倍；
- **报价单位**：按件/按套报价+分档（数量阶梯 15/30/50/100 套）；
- **利润点**：贴布绣高端款（毛利 40%+）>升华基础款；装备包打包（球衣+裤+袜+帽——客单价×3）；
- **风险**：赛季死线（延误=全额退款——产能留 buffer，见 `trade-process/order-delivery-kpi.md`）。
