# 正装衬衫与领型体系（Dress Shirt Production: 领型/袖口/面料/免烫工艺）

正装衬衫是西装的"**贴身内衣**"——外露 10% 但决定 50% 的第一印象。领型匹配脸型、袖口匹配袖扣、面料支数匹配季节、免烫等级匹配生活方式，构成高端衬衫的四维知识体系。泛衬衫生产见 `garments/shirts-production.md`，衬衫面料见 `fabric/shirting-fabrics.md`。

## 一、领型体系（Collar Taxonomy）

| 领型 | 特征 | 脸型适配 | 场合 |
|:---|:---|:---|:---|
| **尖领（point collar）** | 领尖长、角度小 | 圆脸拉长线条 | 保守商务/金融 |
| **温莎领（spread collar）** | 领尖短、角度大 | 长脸平衡宽度 | 时尚商务/领带大结 |
| **扣领（button-down）** | 领尖有扣 | 休闲正式之间 | 美式传统/无领带 |
| **针领（pin collar）** | 领针孔位 | 复古/仪式感 | 婚礼/老派绅士 |
| **帝国领（tab collar）** | 领下有扣带 | 挺括度极高 | 礼服/皇室风格 |
| **立领（mandarin/band）** | 无翻领 | 极简/设计师 | 非传统正装 |

- **领衬硬度**：粘合衬（标准）/半麻衬（高端）/全麻衬（定制）——**领子洗后起泡是粘合衬衬衫的第一死因**；
- **领尖长度**：7.5cm（标准）/8.5cm（长尖领）/6.5cm（短领）——**领尖必须恰好被西装驳领覆盖**（露 1-1.5cm 是经典）。

## 二、袖口体系（Cuff Taxonomy）

- **法式袖口（French cuff）**：反折+袖扣——**正装最高规格**，必须配袖扣（见 `garments/fashion-accessories-hats-scarves.md` 袖扣）；
- **桶形袖口（barrel cuff）**：单扣/双扣——商务标准；
- ** convertible cuff**：可反折可正常——"两用"是性价比话术；
- **袖口长度**：露出西装袖 1-1.5cm——**"衬衫袖长"是定制店量体的关键数据**。

## 三、面料与支数

- **支数体系**：
  - 80s/2：入门商务——厚度与耐穿的平衡；
  - 100s/2-120s/2：高端主线——**Theory/Reiss 衬衫主力区间**；
  - 140s/2+：奢侈级——"丝绸感"但易皱易破；
- **织法**：
  - 府绸（poplin）：平纹、光滑、正式度最高；
  - 牛津纺（oxford）： textured、扣领标配、休闲正式；
  - 斜纹（twill）： subtle 光泽、抗皱性优于府绸；
  - 人字纹（herringbone）： texture 深度、冬季首选；
- **成分创新**：
  - 棉 + 弹性纤维（2%）：舒适度——"弹力正装衬衫"是近年增长点；
  - 棉 + 亚麻：夏季——易皱管理是品控重点；
  - 棉 + 丝：光泽与手感——奢侈线。

## 四、免烫工艺（Non-Iron Technology）

| 等级 | 工艺 | 甲醛风险 | 手感 |
|:---|:---|:---|:---|
| 普通免烫 | 树脂浸渍+高温定型 | 中（需控制 <75ppm） | 微硬 |
| 高级免烫 | 液氨处理+树脂 | 低 | 接近未处理 |
| 成衣免烫 | 缝制后整体处理 | 最低 | 最自然 |
| 无免烫 | 仅预缩 | 无 | 最自然但必皱 |

- **环保红线**：欧盟 REACH 甲醛限值 75ppm（直接接触皮肤）——**免烫衬衫出口必须提供检测报告**（见 `trade-compliance/chemical-environmental-compliance.md`）；
- **耐久性**：高级免烫 50 次洗涤后保持 3.5 级（AATCC 128）——**"永久免烫"是虚假宣传**。

## 五、高端制造要点

- **针距**：18-22 针/英寸（高端）——针距过疏（<14）显廉价；
- **锁眼**：圆头锁眼（rounded buttonhole）——机器锁眼 vs 手工锁眼（米兰眼工艺见 `garments/couture-handwork-details.md`）；
- **衬布**：领/袖/门襟专用衬——**领衬必须耐洗 50 次以上**；
- **扣子**：贝母扣（mother of pearl）——厚度 2.5-3mm，激光 logo 是高端标识；
- **包装**：高端衬衫折叠+纸衬板——**"拆礼物"体验是奢侈衬衫的一部分**。
