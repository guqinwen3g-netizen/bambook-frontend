# 毛衫生产专题（Knitwear & Sweater Production）

毛衫（knitwear/sweater）用横机（flat knitting machine）成形编织，与圆机针织布（jersey）裁剪缝制是两套完全不同的生产体系。毛衫单价高、季节性强（秋冬主力），是针织品类的高价值分支。

## 一、设备与针型

- **横机（flat knitting）**：手工横机 → 电动横机 → 电脑横机（慈星/斯坦格 Stoll/岛精 Shima Seiki）。
- **针型（gauge, G）**：每英寸针数——3G/5G/7G（粗针，厚重外套感）、9G/12G（常规）、14G/16G（细针轻薄，羊绒衫主流）、18G（超细）。
- 针型决定风格与成本：同款式 3G 用纱粗、工时短；16G 用纱细、工时长，价格高 2-3 倍。
- **一体成形（whole garment / 3D knit）**：岛精全成形技术，无套口缝，高端无缝毛衫——设备投资大但省去套口人工。

## 二、纱线（Yarn）

| 纱线 | 支数参考 | 特点 |
|:---|:---|:---|
| 羊绒纱 | 2/26Nm、2/60Nm | 最柔软贵重，见 `fabric/wool-cashmere-fabrics.md` |
| 羊毛纱 | 2/48Nm 美利奴 | 精纺主流 |
| 棉纱 | 32S/2、40S/2 | 春秋毛衫 |
| 腈纶/膨体纱 | 2/28Nm | 仿羊绒低价替代 |
| 混纺纱 | 毛腈、棉毛、粘尼 | 性能与成本平衡 |
| 花式纱 | 圈圈纱/马海毛/珠片纱 | 时尚款 |

- **纱线成本占毛衫 50-65%**：报价核心是纱价 × 单件用纱量。
- 单件用纱量估算：常规成人套头衫 12G 约 300-400g（视尺码/组织）。

## 三、生产流程

```
纱线倒筒（winding）→ 织片（knitting panels）→ 套口/缝盘（linking）
→ 手缝修整 → 洗水缩绒（washing/milling）→ 烘干定型 → 整烫
→ 钉标钉扣 → 检针 → 包装
```

### 关键工序
- **织片**：前/后/袖片分别编织；**全成形（fully-fashioned）**沿边缘收针成形（高档、省料），vs **裁片（cut & sew）**织大片后裁剪（低档、费料）。
- **套口（linking）**：用缝盘将衣片线圈逐针对合缝合——毛衫最贵的人工工序（熟练工日产量有限），品质看"眼针"均匀度。
- **洗水缩绒**：控制毡缩到目标尺寸与绒面（羊绒衫手感关键）；水温/时间/助剂是工艺机密。
- **整烫定型**：按尺码表尺寸熨烫定型（under-press），尺寸控制的最后关口。

## 四、组织与花型

- 基本组织：平针（jersey/plain）、罗纹（rib 1×1/2×2）、双反面（purl）、四平（interlock）。
- 花型：绞花（cable）、提花（jacquard/intarsia 嵌花）、镂空（pointelle）、菠萝花、移圈。
- **提花 vs 嵌花**：提花（jacquard）双面带浮线可多彩图案；嵌花（intarsia）单面无浮线色块清晰（如卡通图案），工时更贵。

## 五、质量控制要点

1. **尺寸**：洗后成衣尺寸为准（毛衫洗缩显著）；每色每码抽 3 件量关键部位。
2. **手感（handfeel）**：洗水缩绒程度决定——与客户确认的"手感样"比对。
3. **起球**：羊毛/羊绒天然起球，订单注明抗起球等级（通常 ≥ 3 级）。
4. **色差**：纱线缸差（尤其天然纤维色纺纱），大货同缸。
5. **针洞/漏针/斜片**：织片疵点全数检验（毛衫 100% 验片是行业惯例）。
6. **检针**：断针全检（金属探测）。

## 六、报价与交期

- **报价公式**：纱线用量 × 纱价 + 织片费（按针时）+ 套口费 + 洗水整烫 + 辅料 + 包装。
- **CMT 参考**：常规套头衫 12G 工费 15-30 元；复杂提花/全成形更高。
- **交期**：45-75 天（纱线定纺 15-25 天 + 生产 30-40 天）；旺季（6-10 月秋冬单）产能紧张需提前 90 天下单。
- **产业带**：浙江桐乡濮院（全球最大毛衫集散）、广东大朗、内蒙古（羊绒）。

## 七、趋势

- **全成形增长**：岛精/斯坦格一体机降低套口依赖，品质稳定性提升。
- **春夏毛衫化**：细针棉麻毛衫（fine gauge）打破季节限制。
- **可追溯羊绒**：RWS/羊绒可追溯认证成为欧美品牌基本要求。
