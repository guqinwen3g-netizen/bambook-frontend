# 袜品生产专题（Socks & Hosiery Production）

袜品（hosiery）是标准化程度最高的纺织品类之一：专用袜机生产、工序少、走量大。中国大唐袜业（浙江诸暨）占全球袜产量 30%+。

## 一、品类结构

| 品类 | 说明 |
|:---|:---|
| 棉袜（crew/ankle socks） | 基础款主力——精梳棉+氨纶 |
| 运动袜 | 毛圈底（terry cushion）+ 足弓橡筋支撑 + 功能纱（Coolmax 吸湿） |
| 商务袜 | 薄款丝光棉/莫代尔 |
| 丝袜/连裤袜 | 锦纶包覆纱（15D-80D 纤度分级） |
| 功能袜 | 压力袜（compression——医疗/运动恢复）、五指袜、防滑袜（点胶） |
| 童袜 | 安全（无小配件）+ 防滑点胶 |

## 二、生产工艺

```
纱线准备 → 织袜（圆袜机）→ 缝头（rosso 对目缝/手工缝头）→ 定型（蒸汽定型板）→ 检配 → 包装
```

- **袜机针数（needle count）**：144N/168N/200N——针数越高越细腻（200N 用于商务薄袜）；粗针机做毛圈运动袜；
- **缝头（toe closing）**：机器对目缝（rosso，平整无骨——高端标志）vs 手工缝头（有棱）——"无骨缝头"是电商卖点；
- **定型**：蒸汽定型板定型（袜型平整）；
- **提花/绣花**：袜机提花（knitted-in pattern）vs 后道绣花/印花。

## 三、原料与规格

- **纱线**：精梳棉 21S/32S/40S（支数越高越细腻）；锦纶包覆纱（丝袜）；功能性纱线（Coolmax/竹炭/银离子抗菌）；
- **氨纶**：袜口橡筋（莱卡）——弹性与回复率决定袜口松垮问题；
- **尺码**：均码（女 35-39 / 男 39-44 弹力覆盖）或分码（S/M/L）——欧码美码对照表；
- **克重/密度**：针数 × 纱支决定厚薄（运动袜毛圈克重高）。

## 四、订单特征

- **起订量**：1000-3000 双/款（袜机高速量产，小单不经济——但也有 500 双快反机）；
- **单价低走量大**：棉袜出厂价 ¥2-8/双；运动功能袜 ¥8-20；压力袜 ¥20-60；
- **套装销售**：3 双/5 双装是电商主流 SKU 形态；
- **节日礼品**：圣诞袜礼盒（Q3 下单）；
- **客户群**：快时尚（H&M/优衣库袜品代工）、运动品牌（Nike/Adidas 袜类供应商体系）、电商大卖。

## 五、质量检验要点

| 项目 | 说明 |
|:---|:---|
| 缝头平整度 | 无骨缝头工艺判定 |
| 拉伸回复 | 袜口/袜筒弹性回复（松垮是袜品第一差评点） |
| 色牢度 | 耐洗/耐摩擦（深色袜掉色投诉高发） |
| 尺寸公差 | 袜长/筒高 ±0.5cm |
| 疵点 | 断纱/漏针/横条（灯检） |
| 配对 | 左右袜尺寸/颜色一致性（混双是低级错误） |

## 六、产业带与采购

- **诸暨大唐**：全球袜业中心（全品类+完整产业链）；**义乌**：低价走量+外贸集散；**吉林辽源**：棉袜产业集群；
- **采购要点**：确认袜机针数配置（决定能做的品类）；功能袜查检测报告（压力值/抗菌率）；
- **旺季**：9-12 月（秋冬袜品出货+圣诞订单）——提前 2 个月锁产能。

## 七、趋势

- **运动功能化**：跑步袜/瑜伽袜细分（防滑/压力/分区缓震）；
- **可持续**：再生棉/再生锦纶袜品（GRS 认证）；
- **定制袜**：数码印花袜（全袜印花）+ 小单定制（球队/企业礼品袜）——新增长点。
