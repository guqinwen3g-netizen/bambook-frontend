# 厨师服与餐饮工服生产（Chef Uniforms: 双排扣/耐氯漂/异物管控）

厨师服是工装制服中**传统结构+功能洗练**的经典品类：双排扣白大褂、棋盘格厨师裤、厨师帽/领巾/围裙整套。美国餐饮制服市场由 Cintas/Aramark 租赁模式主导（工服+洗涤捆绑），独立供应商切**餐饮集团集采+电商小 B**两块。生产=工装产线（见 `garments/workwear-uniform-production.md`），差异在**耐工业洗涤+食品场景异物管控**。

## 一、产品线与面料

| 产品 | 面料 | 结构要点 |
|:---|:---|:---|
| 厨师服（chef coat） | 涤棉 65/35 斜纹 200-240g（耐氯漂主力）；全棉厚府绸（高端行政主厨） | 双排扣/布包扣/长袖 |
| 厨师裤 | 同系列涤棉/涤纶 | 棋盘格/细条纹（遮污渍视觉）+松紧腰 |
| 厨师帽 | 涤棉/一次性无纺布 | toque 高帽/skull cap/发网 |
| 围裙/领巾 | 涤棉/帆布 | 见 `garments/kitchen-textiles-production.md` |
| 食品厂工服 | 涤棉细斜/防静电 | 无口袋/内袋/金属件禁令 |

- **涤棉 65/35 是灵魂**：耐工业洗涤（60-85°C 高温+含氯漂）+快干+免烫——全棉吸汗但洗 30 次发黄变形；高端线全棉只为行政主厨形象款；
- **耐工业洗涤标准**：ISO 15797 程序——洗 50 次尺寸变化 ≤3%、色牢度 4 级；接单合同写明洗涤次数承诺（见 `trade-process/trade-contract-terms.md`）。

## 二、结构工艺要点

- **双排扣的实用逻辑**：厨师服可**翻面穿**——一面污渍换面继续（后厨高强度）；左右片完全相同+双列扣位是裁剪要点；
- **纽扣系统**：传统**布包扣（knot button）**——可拆+耐煮+不导热；树脂扣注意耐温（热汤溅烫）；**金属按扣禁入食品场景**（异物风险）；
- **长袖防溅**：袖口内折无外露袢（勾挂风险）；法式袖高端线；
- **异物管控结构**：无胸袋或内嵌袋（笔/温度计掉落食品线=食品厂事故）；所有装饰件车缝牢固度拉力测试（与婴童装附件逻辑同源，见 `garments/baby-clothes-production.md`）；
- **透气细节**：腋下透气孔/后背育克网布（厨房 40°C+环境）——高端线差异点；
- **绣字**：姓名/餐厅 logo 绣（见 `garments/printing-embroidery.md`）——**绣线耐氯漂**（涤纶绣线，人造丝绣线氯漂褪色）。

## 三、合规要点

- **常规化学**：偶氮/甲醛（见 `trade-compliance/california-prop65.md`）；白色面料**荧光增白剂**管控（欧洲客户敏感）；
- **食品厂场景**：客户 HACCP 体系对工服的要求——无金属/每日更换/专用洗涤；这不是服装认证而是**客户审厂条款**（见 `customers-market/brand-retailer-supplier-systems.md` 的验厂逻辑）；
- **阻燃宣称纪律**：厨师服**不宣称阻燃**——防烫溅≠防火（阻燃是 FR 工装领域，见 `garments/fr-workwear-flame-resistant.md`）；
- **租赁洗涤标签**：Cintas 模式要求洗标含条码/芯片位——接单确认洗标规格。

## 四、渠道与运营

- **租赁公司代工**：Cintas/Aramark/UniFirst 体系——巨量长单但验厂+账期门槛；面料指定（耐洗测试数据准入）；
- **餐饮集团集采**：连锁餐厅年度框采（厨师服+服务员制服整套——服务员线见 `garments/workwear-uniform-production.md`）；
- **电商小 B**：亚马逊/ChefWorks 模式——单件零售+绣字定制（一件起绣的柔性线是利润点）；
- **酒店渠道**：与酒店布草同渠道销售（见 `garments/hotel-linen-b2b.md`——行政总厨制服随布草打包招标）。

## 五、报价与接单

- **报价拆项**：涤棉面料+纽扣（布包扣手工费）+绣花+人工——绣字定制款加工费上浮 30%；
- **MOQ**：现货面料 500 套；连锁集团框采 5000+；
- **返单逻辑**：餐饮高流动率→**工服按月补单**（尺码库存深度服务是粘客点）；新店开业集中单。
