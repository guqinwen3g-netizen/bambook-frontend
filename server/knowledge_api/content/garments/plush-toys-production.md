# 毛绒玩具生产（Plush Toys: EN71/ASTM F963/充棉工艺/IP 授权）

毛绒玩具是"**面料+充棉+儿童安全法规**"的劳动密集型品类：水晶超柔/短毛绒面料+PP 棉填充+刺绣/注塑五官。合规等级=**儿童产品最高级**（EN71/ASTM F963/GB 6675 三大体系），且 **IP 授权**是品类利润核心（迪士尼/三丽鸥/宝可梦——ILS 验厂先行）。产业带：**扬州（全球最大集群）、东莞、青岛**。与宠物玩具（见 `garments/pet-beds-mats-production.md`）共享面料工艺，法规体系完全不同。

## 一、材料与结构

- **面料**：水晶超柔（1-3mm 短毛——主流手感）、边纶布、长毛绒、珊瑚绒；印花/绣花定染——**色牢度+掉毛率**（婴童啃咬场景——毛高越短越安全）；
- **填充**：PP 棉（三维中空涤纶——见 `fabric/synthetic-insulation-fill.md` 的中空纤维体系）——**禁回收棉/黑心棉**（卫生+重金属）；填充均匀度（克重±3%+无硬块——充棉机风压参数）；
- **五官配件**：注塑眼鼻（**拉力 90N 不脱落**——3 岁以下禁用塑料件，必须刺绣）；刺绣线迹密度（防抽丝）；
- **配件**：铃铛/响纸（内置发音器——电池款另有电池仓螺丝锁定要求）；丝带/挂绳（**长度<220mm** 防缠绕勒颈）。

## 二、三大法规体系

| 体系 | 适用 | 核心测试 |
|:---|:---|:---|
| EN71-1/2/3（欧盟） | CE 标志强制 | 机械物理（小部件/拉力/缝线强度）、阻燃、19 项重金属迁移 |
| ASTM F963（美国） | CPSC 强制 | 机械物理+燃烧+化学（CPSIA 铅/邻苯——见 `trade-compliance/cpsc-children-safety.md`） |
| GB 6675（国内） | 内销强制 | 机械物理+燃烧+迁移+**标识（年龄警示）** |

- **年龄分级定生死**：3 岁以下全刺绣五官+无小部件+缝合强度加严——年龄标错=召回（CPSC 高频召回品类）；
- **追踪标签**：CPSIA 批次追溯标签（缝制永久标签——生产日期/批次/产地）；
- **测试成本**：单款 EN71+ASTM 全套 ¥8k-15k（多 SKU 系列款测试策略——同材料不同造型可部分减免）；
- **电动款加码**：发声/发光款叠加 EMC+电池安全（见 `garments/heated-blankets-electric-textiles.md` 的电器合规逻辑）。

## 三、IP 授权与验厂

- **IP 是利润分水岭**：白牌玩具出厂 ¥5-15；授权 IP 款（迪士尼/宝可梦/三丽鸥）¥20-80——**授权链条：IP 方→被授权商（licensee）→指定工厂**（无授权生产=商标侵权重罚，见 `trade-compliance/ip-brand-authorization.md`）；
- **迪士尼 ILS 验厂**：社会责任+反恐+品质三模块（接单前置——见 `suppliers/factory-security-ctpat-audit.md` 的反恐模块）；FAMA 授权书（生产授权书——无 FAMA 不出货）；
- **打样管控**：IP 形象**色稿偏差**（潘通色对色——角色色是 IP 方死穴）；样品三方确认（IP 方+被授权商+工厂）；
- **盗版红线**：来图生产必须索要授权链文件（客户自称"原创设计"也可能侵权——知名形象检索义务）。

## 四、生产管理与市场

- **工艺流**：激光裁片（毛绒倒向排版——**顺毛裁**否则成品色差）→刺绣→车缝（留充棉口）→充棉→**手工封口**（藏针法——外观命门）→整型（钢针挑毛）→检针（**玩具检针是强制环节**——见 `suppliers/needle-control-metal-management.md`）；
- **全检逻辑**：儿童产品=**外观全检+检针全检**（断针事故=召回+诉讼）；金属探测机灵敏度 Φ1.0mm（严于服装）；
- **旺季节奏**：圣诞季（8-9 月交货高峰）+情人节/复活节——反向占全年产能 60%（见 `suppliers/garment-factory-hr-labor-management.md` 的季节用工）；
- **渠道**：亚马逊（白牌+授权款）、礼品公司（定制吉祥物——企业 IP 小单快反）、扭蛋/抓娃娃机渠道（日本/国内——低价高周转）；
- **差评高发点**：掉毛（面料等级问题）、填充结块（充棉不均）、异味（面料定型剂残留——出货前通风）、尺寸虚标（毛绒类按"坐姿高"还是"全长"——listing 统一口径）。
