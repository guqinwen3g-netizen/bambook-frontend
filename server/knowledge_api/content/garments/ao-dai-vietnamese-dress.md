# 越南奥黛生产（Ao Dai: 国服长衫/校服/婚庆制服）

奥黛是"**越南国服+年度多脉冲**"的文化正装：女高中生白校服、Tet 春节新装、婚礼敬酒服、空乘/酒店制服——高频刚需+文化绑定。与中国旗袍（见 `garments/new-chinese-style-clothing.md`）有渊源但结构独立：立领长袖长衫+高开叉两片+阔腿长裤。市场背景见 `customers-market/vietnam-market.md`。

## 一、产品结构与面料

| 部件 | 要点 |
|:---|:---|
| 长衫 | 立领+长袖+前后两片（开叉至腰）——**合身剪裁**（胸腰省+侧缝收腰——合体度是奥黛灵魂） |
| 长裤 | 阔腿/直筒（传统白/黑——现代彩色同面料） |
| 面料（传统） | 真丝（高端婚庆——见 `fabric/silk-linen-fabrics.md`）/乔其纱/缎 |
| 面料（现代） | 弹力针织（四面弹——日常舒适化）/雪纺/蕾丝拼接 |
| 装饰 | 刺绣（胸花/下摆——手绘高端）/钉珠（婚庆） |

- **尺寸体系**：越南女装尺码偏小（平均体型差异）+**量体定制文化深厚**（裁缝店生态——会安 Hoi An 24 小时快定制是旅游名片）；
- **校服款**：白色奥黛（女高中生——部分学校周度着装要求）——**透度管控**（白面料克重/里衬——透光是投诉点）。

## 二、工艺要点

- **打版**：前后片独立裁剪（非连身）——开叉高度/摆围比例按场合（校服保守/婚庆高开叉）；省道处理（胸腰差大——合体关键）；
- **缝制**：薄料细针（乔其/雪纺——针洞抽丝管控）；滚边/嵌条（领口门襟）；隐形拉链（侧缝/后中）；
- **绣花**：定位花绣片（见 `garments/printing-embroidery.md`）——婚庆款金线绣；
- **整烫**：薄料定型（极光管控——见 `suppliers/finishing-ironing-packing-room.md`）；
- **裤装**：与长衫同面料或配白色——橡筋腰（舒适）vs 拉链腰（正装）。

## 三、市场节奏与渠道

- **年度脉冲**：**Tet 春节（1-2 月——新装刚需峰值）**+开学季（8-9 月——校服）+婚礼季（10-12 月）+三八节/教师节（献花+奥黛摄影文化）；
- **校服集采**：学校/教育局渠道（价格敏感+交期刚性——开学前交货死线）；
- **制服**：越航/酒店/银行（奥黛制服=企业形象——见 `garments/aviation-hospitality-uniforms.md` 制服逻辑）；
- **海外越裔**：美国（加州/德州越裔社区——Tet 与婚礼）+澳洲+欧洲——跨境电商小单；
- **中国角色**：**面料供应主通道**（绍兴/广州面料→越南成衣——越南本土裁缝生态强）+成衣 OEM（低价跑量线/校服集采）——RCEP 关税红利（见 `trade-compliance/rcep-fta-utilization.md`）。

## 四、风控与谈判

- **定制文化冲突**：越南消费者习惯量体——**成衣尺码表需详细平铺尺寸+弹力说明**（电商退货主因=不合身）；
- **白色校服品质**：透度/泛黄（荧光剂迁移）/缝线整洁——校服投诉零容忍；
- **交期**：Tet 前物流拥堵（越南 1 月工厂满负荷——倒排 10-11 月出货）；
- **竞争**：越南本土裁缝店（定制）+本土服装厂（校服）——中国厂优势=面料+批量成本；
- **付款**：越南买家 TT 为主+小单快反（电商卖家——MOQ 谈判空间）。
