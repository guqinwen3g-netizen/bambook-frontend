# 懒人沙发与豆袋椅生产（Bean Bag Chairs: EPS 填充软体家具）

懒人沙发是"**无骨架软体家具**"品类：外套+填充粒子的简单结构下，**面料耐用性、粒子品质与拉链安全**构成品质三角。无印良品带火的"舒适沙发"形态+美国大学宿舍刚需+儿童房场景，构成亚马逊稳定类目。与宠物窝垫（见 `garments/pet-beds-mats-production.md`）共享"外套+填充"逻辑，但人体使用标准全面更高。

## 一、产品矩阵

| 形态 | 填充 | 外套 | 场景 |
|:---|:---|:---|:---|
| 经典豆袋（round/teardrop） | EPS 粒子 3-5mm | 棉麻/灯芯绒/牛津布 | 客厅/宿舍 |
| 无印款（body fit cushion） | EPS 微粒子 0.5-1mm | 针织弹力布+内胆 | 日式简约——**微粒子贴合感** |
| 沙发款（lounger/sofa sack） | 碎海绵（shredded foam） | 法兰绒/雪尼尔 | 家庭影院——**碎海绵回弹** |
| 儿童豆袋 | EPS+**防误开拉链** | 卡通印花+防水底 | 儿童房 |
| 户外豆袋 | EPS | 牛津布 PU 涂层/船用级 | 泳池/庭院 |

| 收纳豆袋（stuffed animal storage） | **用户自填毛绒玩具** | 帆布+透明窗 | 儿童收纳爆品 |

## 二、材料与工艺要点

- **EPS 粒子分级**：全新料 vs 再生料——**再生粒子异味+易碎粉化**是差评源；粒径均匀性（3-5mm 偏差 ±1mm）；阻燃粒子（CAL TB117 软体家具场景）；
- **碎海绵**：高回弹海绵边角料粉碎——**密度混杂导致结块**是痛点；高端用整块海绵切削（shredded memory foam——记忆棉碎块溢价）；
- **内胆设计**：**外套+独立内胆=可拆洗**标配——无内胆款（粒子直装）换洗灾难性差评；
- **拉链安全**：**儿童安全法规强制**：美国 CPSC/加拿大要求豆袋拉链**锁定/隐藏设计**（防儿童钻入窒息——历史召回血泪）——拉链头需工具才能开启（见 `trade-compliance/cpsc-children-safety.md`）；
- **缝制**：双针链式+包边——**粒子泄漏投诉第一源=缝线针孔**；细针+高针距+防绒线（防钻绒逻辑见 `garments/comforters-pillows-bedding.md`）；
- **填充量标注**：按升/磅标注——**填充不足（"坐塌"）是品类第一差评**，标注"初次填充建议量+补充装"策略。

## 三、市场与商业要点

- **场景人群**：大学宿舍（8-9 月返校峰值）、儿童房、游戏/影音室、公寓小户型；
- **渠道**：亚马逊（bean bag chair 大词）、商超（Walmart/Target 季节端架）、家具电商（Wayfair）；
- **体积经济学**：**粒子蓬松=泡货之王**——对策：①粒子与外套分装（客户自填）②真空压缩（碎海绵可压缩 5:1，EPS 压缩比有限）③**海外仓本地填充**（运外套+当地购粒子——最优解，海外仓见 `trade-process/overseas-warehouse-operations.md`）；
- **填充补充装**：EPS refill 单独 SKU——**复购+解决塌陷投诉**；
- **价格带**：经典款 $30-60、碎海绵沙发款 $100-200、无印款 $60-120。

## 四、风控要点

- **阻燃合规**：加州 TB117-2013（软垫家具）——填充+外套组合测试；英国 BS 5852（更严——含填充物）——阻燃体系见 `fabric/flame-retardant-fabrics-deep-dive.md`；
- **儿童安全红线**：拉链锁定+警示标签（"窒息风险"）——**历史召回案例多，平台审核严格**；
- **粒子环保**：EPS 不可降解——部分市场（欧盟）叙事压力；替代填充（EPP/PLA 粒子/天然荞麦壳小众）；
- **异味投诉**：新粒子+新面料气味——出货前通风散味程序；
- **运输破损**：缝合处受力——跌落测试（ISTA 1A）写入 QC（包装测试逻辑见 `suppliers/finishing-ironing-packing-room.md`）。
