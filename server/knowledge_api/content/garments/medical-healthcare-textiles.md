# 医护纺织品生产（Medical & Healthcare Textiles: Scrubs, Gowns, Linens）

医护纺织品 = **功能 + 合规 + 租赁体系**三重门槛：耐工业洗涤是核心指标，美国医疗织物租赁公司（Cintas/Aramark）是集采大客户——量大、稳定、招标制。

## 一、品类矩阵

| 品类 | 面料 | 关键要求 |
|:---|:---|:---|
| 刷手服（scrubs） | 涤棉 65/35 / 四面弹涤纶 | 耐氯漂色牢度/抗静电/易洗快干 |
| 病号服/护理服 | 全棉/涤棉府绸 | 耐洗/开口设计（方便护理） |
| 白大褂 | 涤棉斜纹 | 挺括/耐漂/防污 |
| 手术衣/洞巾（重复使用） | 高密涤棉/三防整理 | 阻菌防渗透（EN 13795 / AAMI PB70 等级） |
| 手术衣（一次性） | SMS/SMMS 无纺布（见 `fabric/nonwoven-fabrics.md`） | 阻隔等级+无尘 |
| 病床织物 | 全棉贡缎/涤棉 | 耐工业洗涤 100 次+ |

## 二、核心指标：耐工业洗涤

- **洗涤条件**：工业洗 75-85°C + 氯漂/过氧化 + 高温烘干（家用洗完全两回事）；
- **寿命要求**：重复使用型 50-75 次工业洗涤（租赁模式按次计费——寿命即成本）；
- **测试**：色牢度（氯漂 AATCC 61/ISO 105 系列——见 `trade-compliance/testing-standards.md`）、强力保持率、尺寸稳定（缩水 ≤3%——见 `fabric/weaving-grammage-width.md`）；
- **面料开发**：涤棉 65/35 是寿命/舒适平衡点（全棉舒适但寿命短——涤含量高更耐洗但闷热）；导电丝抗静电（手术室要求）。

## 三、合规标准

| 标准 | 适用 | 要点 |
|:---|:---|:---|
| EN 13795 | 欧盟手术衣/洞巾 | 阻菌/防渗透性能分级 |
| AAMI PB70 | 美国 | 阻隔等级 1-4 级（Level 3-4 为手术级） |
| FDA 注册 | 美国 | 手术衣属 Class I 医疗器械（510(k) 豁免但需**企业注册+产品列名**） |
| YY/T 0506 | 中国 | 手术衣/洞巾行业标准 |

- **边界**：刷手服/病号服 = 普通服装（无医疗认证负担）；**手术衣/洞巾 = 医疗器械**（FDA/CE-MDR——合规见 `trade-compliance/ppe-protective-clothing-compliance.md` 与 `fabric/nonwoven-fabrics.md`）。

## 四、渠道与客户

1. **医疗织物租赁公司**：Cintas / Aramark / Vestis（租赁=集采大头——美国医院普遍外包织物洗涤租赁，见 `garments/workwear-uniform-production.md` 租赁模式）；
2. **医疗分销商**：Medline / Cardinal Health（自有品牌+分销——直接采购大单）；
3. **GPO 集团采购组织**：Vizient / Premier（医院集团招标——价格硬但量稳）；
4. **电商/DTC**：FIGS 模式（时尚化刷手服 DTC——溢价 2-3 倍，见 `customers-market/dtc-brand-clients.md`）。

## 五、订单与生产要点

- **订单特点**：招标制（年度框架）、量大稳定、交期刚性（医院不断供）、验厂（WRAP/社会责任——见 `suppliers/factory-audit-guide.md`）；
- **生产要点**：
  - 色牢度批次管理（氯漂测试每缸——见 `suppliers/dyeing-mill-cooperation-management.md`）；
  - 尺寸一致（租赁体系按箱收发——混码是客诉高发）；
  - 断针/金属管控（医院场景零容忍——见 `suppliers/needle-control-metal-management.md`）；
- **政策变量**：美国政府单部分受 BAA（Buy American）限制——民用市场为主攻；疫情后一次性防护用品库存出清完毕，回归常态采购。

## 六、机会评估

- **优势**：需求刚性（医疗不受经济周期）、复购稳定、时尚化升级（FIGS 证明溢价空间）；
- **门槛**：面料耐氯漂开发（与面料厂联合——见 `suppliers/fabric-mill-evaluation.md`）、FDA 注册成本、租赁公司验厂；
- **切入路径**：病号服/刷手服（普通服装门槛）→ 积累洗涤数据 → 手术衣（医疗器械门槛）。
