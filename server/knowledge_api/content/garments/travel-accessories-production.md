# 旅行配件生产（Travel Accessories: 眼罩/U型枕/收纳套装）

旅行配件是"低单价+高复购+礼品属性"品类：眼罩、U 型枕、收纳包套装、行李牌、护照包、压缩袋。三大订单来源：航空公司赠品（头等舱洗漱包）、品牌促销赠品、电商零售（亚马逊旅行类目长青）。产业带：浙江义乌/广东东莞/江苏南通。

## 一、主力产品工艺要点

| 产品 | 结构 | 材料 | 品质要点 |
|:---|:---|:---|:---|
| 眼罩 | 面料+填充+鼻梁条+松紧带 | 真丝/记忆棉/冰丝 | 遮光性（鼻梁贴合）、松紧带压迫感 |
| U 型枕 | 记忆棉/微珠（EPS）芯+外套 | 水晶超柔外套 | 回弹（记忆棉密度 40-50D）、外套可拆洗 |
| 收纳六件套 | 网布+牛津布+拉链 | 210D/420D 尼龙 | 拉链顺滑、网布抗勾丝 |
| 真空压缩袋 | PA+PE 复合膜+气阀 | 多层共挤膜 | **气阀密封性**（漏气=全差评）、厚度 7-9 丝 |
| 洗漱包 | 透明 TPU/网布 | TPU 抗黄变 | 车缝平整（透明料暴露工艺） |
| 行李牌/护照包 | PU/真皮+织带 | PU 革 | 油边工艺（见 `garments/bags-luggage-production.md`） |

- **真丝眼罩**：姆米数（16/19/22 momme）分级——虚标姆米是行业潜规则，客户抽检克重反推（见 `fabric/silk-linen-fabrics.md` 的真丝指标）；
- **记忆棉**：密度（40D/50D/60D）决定成本与回弹——低价竞争用粉料棉（掺碳酸钙增重），**泡水测试可识别**（粉料棉沉水掉渣）。

## 二、航空赠品单（洗漱包 amenity kit）

- **订单特征**：航空公司招标（阿联酋/卡塔尔/新航头等舱洗漱包是行业标杆）——设计稿由航司/代理提供，工厂按图生产；
- **内容物组合**：包体（工厂产）+眼罩+耳塞+袜子+护肤品（外采组装）——**组装与配套能力**是核心（多物料齐套管理）；
- **品质要求**：奢侈品级验货（全检外观——航司旅客投诉直接扣款）；交期配合航班换季（一年两次集中交货）；
- **认证**：航空食品安全无关，但接触皮肤的纺织品按目的国纺织品通标（见 `trade-compliance/testing-standards.md`）。

## 三、生产与品控

- **裁剪**：小件排版密集——激光切/刀模冲切效率高；
- **车缝**：小弧位多（眼罩/枕套）——用模板机车缝保证一致性；
- **填充工序**：记忆棉模压成型外发或自购；微珠填充用充填机（同毛绒玩具逻辑）——**填充量称重全检**（±3g）；
- **验针**：填充类产品必过验针（断针埋入填充物是重大事故，见 `suppliers/needle-control-metal-management.md`）；
- **气味**：记忆棉/微珠异味（VOC）——散味 48h+通风包装；欧盟客户要求 REACH 气味相关项。

## 四、接单与报价

- **报价拆项**：面料+填充+五金+组装分开——填充料（记忆棉粒/EPS 珠）价格波动单列；
- **MOQ**：现货面料 1000-3000 套；定织/定色 5000+；
- **礼品单陷阱**：促销赠品客户压价极致——**报"阶梯价+材料降档选项"**（如 210D→190T 降本）让客户自己选（见 `trade-process/inquiry-and-quotation.md`）；
- **电商零售**：旅行收纳类目竞争激烈——差异化点在设计（分区结构专利）与面料（RPET 环保叙事，见 `fabric/sustainable-fabrics.md`）；
- **套装组合报价**：眼罩+U型枕+收纳袋+耳塞组合 SKU 提客单价——包装彩盒成本别漏算。
