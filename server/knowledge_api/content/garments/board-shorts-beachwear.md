# 沙滩裤与沙滩装生产（Board Shorts & Beachwear: 快干/四面弹/冲浪）

沙滩裤（board shorts）是泳装之外的**海滩场景独立品类**：冲浪文化起源（及膝无内衬——区别于泳裤，见 `garments/swimwear-production.md`），现为美国夏季男装走量款（Q2 上架 Q3 清仓）。沙滩装延伸=罩衫（cover-up）、沙滩裙、度假衬衫。核心指标=**快干+耐氯耐盐+花色**。

## 一、产品线与面料

| 产品 | 面料 | 结构 |
|:---|:---|:---|
| 沙滩裤（board shorts） | 涤纶桃皮绒/四面弹 | 及膝/无内衬/抽绳魔术贴腰 |
| 泳裤（swim trunks） | 桃皮绒+网布内衬 | 内衬三角/及大腿 |
| 度假衬衫 | 人棉/棉麻夏威夷印花 | 古巴领（见 `garments/shirts-production.md`） |
| 罩衫（cover-up） | 雪纺/钩花/人棉 | 女款沙滩裙外罩 |

- **桃皮绒（peach skin）**：涤纶磨毛经典沙滩裤料（见 `fabric/woven-fabrics.md`）——快干基础款；
- **四面弹**：涤氨/锦氨（冲浪动作拉伸——高端线 4-way stretch，见 `fabric/nylon-spandex-stretch-fabrics.md`）；
- **功能整理**：防泼水（DWR——上岸速干）+耐氯耐盐（泳池海水——色牢度 4 级+，见 `trade-compliance/testing-standards.md`）；
- **环保线**：rPET 再生涤纶（塑料瓶叙事——Quiksilver 等品牌标配，见 `fabric/sustainable-fabrics.md` 的 GRS 逻辑）。

## 二、生产工艺要点

- **腰部结构**：**魔术贴+抽绳双保险**（冲浪大浪冲击——抽绳打结牢度测试）；松紧腰泳裤款（内抽绳）；
- **无内衬 vs 内衬**：board shorts 无内衬（穿泳裤内搭/速干内裤）vs swim trunks 网布内衬——美国市场两者并存，**页面标注混淆=退货**；
- **口袋**：后侧拉链袋（防水袋——钥匙卡包）/网布排水口袋（兜水排出）；口袋打枣加固（冲浪应力）；
- **平缝/包缝**：平缝贴肤（防磨 rash——长冲浪板摩擦）；裆部插片（活动量）；
- **印花**：全幅热升华/水印（夏威夷花/条纹/渐变色——见 `fabric/digital-printing-technology.md`）；定位花裁片对位；
- **长度体系**：outseam 英寸制（16"/18"/20"——及大腿/及膝/过膝），尺码表标注 outseam 是专业线。

## 三、合规与市场

- **化学常规**：偶氮/甲醛+耐海水/耐氯/耐光汗复合色牢度（海滩场景三耐——测试协议写进质量协议）；
- **绳带**：成人款无限制；**儿童沙滩裤**抽绳按童装规则（见 `garments/childrenswear-production.md`）；
- **UPF 宣称**：防晒沙滩装标 UPF 50+ 需实测（见 `garments/sun-protection-clothing.md`）；
- **市场节奏**：美国 Q4 下单→Q1 出货→**4-5 月零售上架**（Memorial Day 夏季启动——误季=清仓价，见 `trade-process/annual-sourcing-calendar.md`）；
- **品牌梯队**：Quiksilver/Billabong/Hurley（冲浪品牌授权代工）、亚马逊自营款（走量）、度假村/酒店定制（logo 刺绣款——礼品店渠道）。

## 四、报价与接单

- **成本结构**：面料（桃皮绒低价/四面弹加价 40%）+印花+五金（抽绳头/魔术贴）——走量款面料成本决定报价竞争力；
- **MOQ**：现货桃皮绒 1000 条/色；定印花 3000+；
- **利润点**：四面弹+rPET 环保款（溢价区）>基础桃皮绒（价格战区）；罩衫/度假衬衫组合单（度假系列打包）。
