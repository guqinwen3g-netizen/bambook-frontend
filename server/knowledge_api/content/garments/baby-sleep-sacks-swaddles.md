# 婴儿睡袋与襁褓生产（Baby Sleep Sacks & Swaddles: SIDS预防/TOG/安全合规）

婴儿睡袋（sleep sack）是美国儿科学会（AAP）SIDS 预防指南推荐的**被子替代品**——"bare is best"（婴儿床空无一物）理念下，睡袋成为欧美婴儿睡眠标配，复购率高（0-3 岁按月龄+季节多次购买）。品类=**安全合规最严**的婴童纺织分支：结构设计直接影响窒息风险。生产门槛低于童装成衣但合规门槛更高（婴童装总述见 `garments/baby-clothes-production.md`）。

## 一、产品线与 TOG 保暖体系

| 产品 | 结构 | 场景 |
|:---|:---|:---|
| 襁褓巾（swaddle blanket） | 大方巾 47×47 英寸（竹棉纱布主流） | 0-3 月防惊跳包裹 |
| 魔术贴襁褓（swaddle wrap） | 带魔术贴/拉链的成型襁褓 | 手残父母友好 |
| 背心睡袋（sleep sack） | 无袖马甲+下摆宽松 | 3 月+（会翻身后禁用襁褓） |
| 分腿睡袋 | 裤腿式（大月龄活动） | 18 月+学步期 |

- **TOG 保暖系数是选购第一参数**：0.5 TOG（夏季纱布）/1.0（春秋）/2.5（冬季夹棉）/3.5（严寒）——**每款必须标注 TOG 值+室温-穿着对照表**（穿多过热也是 SIDS 风险因素）；TOG 测试按 BS 8510 逻辑实测；
- **面料**：竹棉纱布（muslin——透气主打）、有机棉针织、美利奴羊毛（高端调温叙事）；冬季款夹棉（仿羽绒棉/有机棉絮片）；
- **结构红线**：**无绳带、无小部件、无帽**（睡眠产品严禁）——领口/袖窿尺寸防头部滑入（领口弹性卡尺测试）。

## 二、安全合规（品类生死线）

- **美国 CPSIA**：CPC 证书+第三方测试（铅/邻苯/阻燃——见 `trade-compliance/cpsc-children-safety.md`）；
- **阻燃**：婴儿睡袋属儿童睡衣范畴？——**关键判定**：sleep sack 在美国按"婴儿穿着用品"适用 16 CFR 1615/1616（儿童睡衣阻燃）的**紧身豁免或阻燃达标**二选一；宽松睡袋多走阻燃路线或标注"非睡衣外穿"（宣称纪律——与律师确认）；
- **英国/欧盟**：BS 8510（儿童睡袋安全——领口/袖窿/拉链/温升专项）、EN 16781（睡袋安全要求）；
- **拉链安全**：顶端挡片（zipper garage——防夹下巴）、双头拉链（夜间换尿布下摆开合）是主流设计；
- **髋关节健康**：襁褓需标注"hip healthy"（IHDI 认证——下肢宽松蛙式位，见 `garments/baby-carrier-production.md` 的髋关节逻辑）；
- **宣称纪律**："防惊跳反射/改善睡眠"属功能宣称边缘——**严禁"防 SIDS"宣称**（无产品可宣称预防 SIDS，FDA 警告信高发区）。

## 三、生产工艺要点

- **纱布织造**：双层/四层/六层纱布（muslin——经纬密度低、透气）；水洗预缩（纱布缩水率大——洗后尺寸是验货点）；
- **包边**：全件针织包边（贴肤无骨感）；按扣选树脂（金属凉感+过敏风险——镍释放见 `suppliers/buttons-metal-trims-deep-dive.md`）；
- **绗缝**：夹棉款绗缝固定（洗后棉不跑位——格子间距一致）；
- **印花**：活性印花（A 类婴幼儿——甲醛/偶氮/荧光剂管控见 `trade-compliance/chemical-environmental-compliance.md`）；纱布印花渗透均匀度；
- **验针**：全件过验针机（见 `suppliers/needle-control-metal-management.md`）；
- **包装**：纸质吊牌+无塑料钉（安全+环保叙事——有机品牌要求 FSC 包装）。

## 四、市场与运营

- **品牌梯队**：aden+anais（纱布襁褓开创者）/Halo（睡袋品类开创）/Kyte Baby（竹纤维高端 DTC）——**图案花色是核心差异化**（ins 风印花驱动复购）；
- **渠道**：亚马逊母婴（review 驱动）、buybuy BABY 等母婴连锁、DTC 订阅（按月龄推送下一 TOG/尺码）；
- **差评关键词**：zipper broke/shrinks/too hot（TOG 标注不准）——反向管控拉链品牌（YKK 树脂）与预缩；
- **礼品属性**：新生儿礼盒（baby shower）场景占 30%+——包装颜值投资回报率最高；
- **复购节奏**：0-6 月/6-18 月/18-36 月三尺码×两季 TOG=单客 6+ 件生命周期。

## 五、报价与接单

- **成本结构**：竹棉纱布价格高（竹纤维混纺比例决定——70% 竹+30% 棉主流）；印花+包边人工占比高（小件多工序）；
- **MOQ**：现货纱布 1000 条；定印花 3000+；
- **认证成本**：BS 8510/CPC 测试按款按色——首单分摊。
