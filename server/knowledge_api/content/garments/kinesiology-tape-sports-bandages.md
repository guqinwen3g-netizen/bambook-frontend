# 肌内效贴布与运动绷带（Kinesiology Tape & Sports Bandages: 压敏胶/低敏/贴扎耗材）

肌内效贴布（kinesiology tape）是"**纺织基材 + 医用压敏胶**"的跨界耗材：棉氨纶弹性布涂布水波纹胶面，借皮肤提拉促进淋巴回流的贴扎概念（实证强度有争议，但运动人群认知度已建立）。产品门槛不在织布而在**胶水配方与涂布工艺**——初粘/持粘/低敏/无残胶的四方平衡决定复购。本文件梳理材料、法规与渠道要点（硬质护具见 `garments/sports-protective-gear-production.md`）。

## 一、产品谱系

| 产品 | 基材 | 胶系 | 场景 |
|:---|:---|:---|:---|
| 肌内效贴布（卷装） | 棉 95%+氨纶 5%，拉伸率 130-140% | 医用亚克力水波纹 | 运动防护/理疗机构 |
| 预切肌贴 | 同上，模切成型（Y 型/X 型/I 型） | 同上 | 零售电商（傻瓜式使用） |
| 自粘弹性绷带（cohesive） | 无纺布/棉+氨纶 | 乳胶自粘（不粘皮肤只粘自身） | 固定敷料/兽用（大单品） |
| 运动胶布（athletic tape） | 棉布/人造丝（无弹） | 氧化锌胶 | 关节刚性固定 |
| 粘性绷带（EAB） | 弹性棉布 | 热熔胶边条 | 英式橄榄球/格斗 |

- **拉伸率是肌贴灵魂**：130-140% 对标 KT Tape——拉伸不足贴扎无效，过度则回缩力过大起泡；**每批基材拉伸率全检**（来料检验见 `suppliers/incoming-material-inspection.md`）；
- **胶水是 70% 的技术**：水波纹涂布（透气+排水）vs 满涂（粘力强但闷）——泳装场景（防水款）用满涂改性胶；**残胶投诉=胶配方内聚力不足**。

## 二、法规与检测

- **法规分层**：欧盟 CE 一类（MDR 自声明+技术文档）；美国 FDA 一类（工厂注册+列名，510k 豁免）；**宣称"治疗/止痛"升级为二类风险区**——详情页只写"support/recovery aid"（宣称边界同 `fabric/graphene-textile-applications.md`）；
- **生物相容性**：ISO 10993-5/10（细胞毒性+皮肤刺激+致敏）——**低敏报告是药房渠道入场券**；
- **物性检测**：初粘（滚球法）/持粘（1kg 砝码悬挂时间）/180° 剥离强度/防水性（浸水后粘性保持）——检测机构选择见 `trade-compliance/testing-lab-selection.md`；
- **乳胶警示**：自粘绷带含天然乳胶——**欧美订单需乳胶蛋白含量检测+包装乳胶警示**（过敏诉讼高发）。

## 三、外贸接单要点

- **买家画像**：运动品牌配件线（Nike 类代工门槛高）、理疗连锁自有品牌、亚马逊白牌（卷装+预切组合装）、兽用渠道（马用自粘绷带——马术市场见 `garments/equestrian-products.md`）；
- **价格锚点**：5cm×5m 卷装出厂 0.8-1.5 美元——**胶用量与胶品质是价差主因**（进口胶 vs 国产胶差 40%）；
- **彩印定制**：热转印迷彩/国旗/球队色——**印刷后胶面粘性会衰减**（温度影响），工艺验证不可省；
- **包装溢价**：彩盒+说明书（贴扎图示）比裸卷溢价 30%+——说明书多语言贴扎教程是差评防火墙；
- **效期管理**：压敏胶 2-3 年老化——**FIFO 出货+生产日期喷码**（效期逻辑同 `garments/first-aid-kits-ifak-production.md`）；
- **季节波段**：北半球 3-8 月运动季放量——2 月前备料的备货逻辑见 `fabric/fabric-inventory-stock-strategy.md`。
