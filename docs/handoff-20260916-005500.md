7. **不要动依赖**（含 `npm audit fix`）。14 个已知漏洞在用户手上，xlsx 那条要换源，属拍板项。

### ⚠️ 本轮新发现的第二个假修复陷阱：船样有两套互不相通的建模

**两个方案（⚠️ 这条要协调方拍，不要 Agent 自选）**

- **A（协调方倾向）**：只补写入口——建票时按批次传 `batchId` + `allocatedAmount`。
