## 9 条条款（逐条转录）

### 1. 装运期 Date of Shipment
```
Date of Shipment：
（允许溢短装 1 %）
Quantity more or less allowed
```

### 2. 装运口岸和目的地 Loading Port & Destination
```
2. 装运口岸和目的地由
   From  SHANGHAI
   至 TBC  BY SEA
Loading Port & Destination：
```
★ **From = SHANGHAI**、**至 = TBC**、**BY SEA** —— 这三个是**逐单数据**，应取订单字段。

### 3. 保险 Insurance
```
3. 保险：□ 由出卖人发票金额 110% 投保一切险及战争险，按 1981 年 1 月 1 日中国人民保险公司条款负责。
        □ 由买受人自理。
Insurance：（英文原文 OCR 噪声大，略 —— 见下方"边界"）
```
★ **两个勾选项**（出卖人投保 / 买受人自理）⇒ **是一个二选一字段**，不是固定文案。

### 4. 支付方式 Terms of payment
```
4. 支付方式：
   L/C AT SIGHT OR T/T
Terms of payment：Others
```

### 5. 品质数量异议、索赔
```
5. 品质数量异议，索赔：如果货到目的口岸买受人对品质/数量有异议时，
   可以凭出卖人同意的公证机构出具的检验报告，在货到目的口岸 30/15 天内向出卖人提出索赔，
   出卖人将根据实际情况考虑理赔或不理赔。
   对所装货物所提出任何异议属于保险公司、轮船公司其他有关运输机构或邮递机构负责者，出卖人不负任何责任。
```
★ **索赔期 30/15 天**、**凭公证机构检验报告** —— 这两条是**可判定的规则**。

### 6. 不可抗力 Force Majeure
```
6. 本合同所述全部或部分商品，如因战争或其他人力不可抗拒的原因，以至不能履约或延迟交货，出卖人不负责。
```

### 7. 签回要求
```
7. 买受人于收到本合同后请立即签回一份，如买受人对本合同有异议，应于收到后五天内提出，
   否则认为买受人已同意接受本合同所规定的各项条款。
```
★ **5 天异议期** —— 一条**可判定的时限**。

### 8. 争议的解决
```
8. 争议的解决：凡因执行本合同所发生的或与本合同有关的一切争议，应由双方通过友好协商解决。
   如协商不能解决，应提交 □ 中国国际经济贸易仲裁委员会，根据该会的仲裁规则进行仲裁，
   仲裁裁决是终局的，对双方都有约束力；或 □ 出卖人所在地人民法院，通过诉讼解决。
```
★ **两个勾选项**（仲裁 / 诉讼）⇒ **是二选一字段**。

### 9. 法律适用
```
9. 法律适用：本合同的签订、修改、补充、中止以及与本合同有关的争议的解决等，
   适用中华人民共和国有关法律规定。
   同时，本合同受 Incoterms 2010 的约束。
```
★ **Incoterms 2010** —— 一条**有版本号的**约束 ⇒ 模板里应**标注版本**。

## ★ 与软件生成合同的差距（对齐清单）

| # | 条款 | 是否可数据化 | 数据来源 |
|---|---|---|---|
| 1 | 装运期 | ✅ | 订单 `shippingDate` / 行级 `deliveryDate` |
| 2 | 装运口岸和目的地 | ✅ | 订单 `portOfLoading` / `portOfDischarge` / `shipmentMethod` |
| 3 | 保险（110% / 买方自理） | ✅ **二选一** | 需新增字段（当前无） |
| 4 | 支付方式 | ✅ | 订单 `paymentTerms`（**已有**） |
| 5 | 索赔期（30/15 天） | ✅ | 需新增字段 |
| 6 | 不可抗力 | ❌ 固定文本 | 模板常量 |
| 7 | 签回（5 天异议期） | ❌ 固定文本 | 模板常量 |
| 8 | 争议解决（仲裁/诉讼） | ✅ **二选一** | 需新增字段 |
| 9 | 法律适用（含 Incoterms 版本） | ❌ 固定文本 + **版本标注** | 模板常量 |

★ **可数据化的 5 条里，只有"支付方式"现在有字段** ⇒ 另 4 条**需要新增字段**（属 §2 的 ② 类：补字段）。
★ **固定文本 3 条** ⇒ 直接用模板常量，**但必须标注版本**。

## ★★ 边界（不许越界）

1. **英文正式文本**：OCR 对英文长句识别噪声大（如 `Inmrance` / `To be cflected` / `PLCC`），
   **不得据此重写英文条款** —— 需使用方提供或从原件重新抽取。
2. **法律文本改动**：仲裁机构、法律适用地、不可抗力范围**都是法律决定**，
   ★ **开发方只转录、不编写**。
3. **本文件不构成"设计稿"**：它只是"我方标准合同实际写了什么"的**转录**。
