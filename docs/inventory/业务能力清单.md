## 6. 对撞第二轮：**SHIPMENT REPORT（真实出运报表）× `OrderLine` 模型**

### 6.1 材料与方法

- 来源：`00-Entities/Peerless/面料/SHIPMENT REPORT/PANDA_2026*.xlsx.xls`（4 份）
- 抽取：`scripts/extract-businessdocu-office.py`（本程新增，纯标准库，不装依赖）
  ⇒ 4 份 SHIPMENT REPORT 抽出 1.8k–5.4k 字；**14 份发货通知是真·旧版 `.xls`，抽不出（0 字）**
- 对照：`server/prisma/schema.prisma` 的 `model OrderLine`

### 6.2 ★ SHIPMENT REPORT 的真实字段集

`PO Number` · `Item` · **`ZROH`** · `Mill Quality Number` · **`Original Quantity`** · **`Meters Needed`** ·
`Price` · **`Price Confirmed`** · `Ex-Mill` · `Deliv.dat` · **`Ship-To`** · `Mode of transp.` · **`Priority`**

### 6.3 逐字段对撞

| SHIPMENT REPORT 字段 | `OrderLine` 对应 | 结论 |
|---|---|---|
| PO Number | `Order.code` / `poNumber` | ✅ |
| Item | `itemNo` | ✅ |
| **ZROH**（客户料号） | 无同名字段；**疑似** `materialCode` | ⚠️ **待证**（若 `materialCode` 是"我方料号"，则客户料号**无位可放**） |
| Mill Quality Number | `millQuality` | ✅ |
| **Original Quantity** | `quantity` | ✅ |
| **Meters Needed**（需求米数） | **无** | ❌ **缺**（只有 `quantity` 一个量） |
| Price | `unitPrice` | ✅ |
| **Price Confirmed**（价格已确认） | **无** | ❌ **缺**（`fieldSources` 是 Json，可能间接表达，待证） |
| Ex-Mill | `exMillDate` | ✅ |
| Deliv.dat | `deliveryDate` | ✅ |
| **Ship-To**（**行级**收货地） | 无行级字段（`Order` 上有 `shipToName/Address…`，但**行级没有**） | ❌ **缺**（真实报表里**每行一个 Ship-To**） |
| Mode of transp. | `shippingMethod` | ✅ |

### 6.4 ★★ 两条重要发现

**① `Original Quantity` 与 `Meters Needed` 是两个量，而系统只有一个 `quantity`**
