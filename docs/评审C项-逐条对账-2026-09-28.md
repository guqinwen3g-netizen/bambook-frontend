**方法（以及一个必须写清的能力边界）**：
- 台账**不记 I 编号**，它按自己的 B 条 / §2 缺口名 / D 决议记账 ⇒ **"grep I-xx 查不到"绝不等于"没做"**。
  本次逐条**按语义**匹配（关键词、涉及文件、缺口名），不是按编号。
- 判据四档：`已闭`（要的东西今天确实在）/ `已闭·变形`（问题关掉了，但评审指定的**写法**没落）/ `仍开` / `在使用方侧`。
- 执行者是**只读子代理**，我自核了其中三句（见下"我自核的三句"）。其余按证据行号引用，使用方可逐条抽查。
