### 五·一 新观察：控制台里的噪声（**只记事实；两个数后来归因了一半，见五·三**）

- **现象**：reload 之后，驾驶舱控制台有 `Failed to load resource: 403`（9 次）、`404`（48 次），以及几十条
  `Unable to load glyph range 0, 0-255. Rendering codepoint U+XXXX locally instead. Error: Unimplemented type: 4`
  —— 回退发生在**ASCII** 码点上（U+0020 空格、U+0033 '3'、U+0041 'A' …）⇒ 说明它在给**地图的符号层**取字形。
- **我实测到的因果（这一截是测的，不是猜的）**：前端 dev（`:3002`）对 `/glyphs/Noto Sans Regular/0-255.pbf` 返回的**不是字体**，而是一段 **SPA 的 HTML**（`Content-Type: text/html`，3013 字节）；而 `/glyphs/Urbanist Regular/0-255.pbf` 返回的是**真二进制**（72,627 字节）⇒ maplibre 把 HTML 当 pbf 解析 ⇒ 报 `Unimplemented type: 4` ⇒ 回退本地渲染。**换句话说：请求打到了 `Noto Sans Regular` 这个包内并不存在的字体族。**
- **归属**：与今天四处改动**无关**（L/C 门禁 / 收费金额 / 账期解析 / 金额写法都不碰地图）；本件第一节那次代走**也看到过**同样的字形状告警（当时只当噪声没记，这次补记）。
- **⚠️ 不许读成"地图坏了"**：回退渲染对 ASCII 与 CJK（`localIdeographFontFamily`）通常仍能画出字，**肉眼效果要看一眼才知道**。⇒ 这条正好落在 §四 第 5 条那个缺口上：**请走查时看一眼地图（或驾驶舱背景那张图）上有没有字**；若没字，这就是一条**用户可感的缺陷**，再单独立账。
