## 四 历史清理的命令（**本清单只写不跑**）

```bash
# 0) 先备份（历史重写不可逆的体面做法：留一份 mirror 到别处）
git clone --mirror <repo-url> /tmp/bambook-backup-$(date +%Y%m%d).git

# 1) 重写：把这 8 个路径从**所有分支的所有提交**里摘掉（filter-repo 需要单独装）
git filter-repo --invert-paths --path-glob 'server/.env.local.bak.*'
#    备选：bfg --delete-files '.env.local.bak.*' <repo>

# 2) 验证（三条都要过）
git rev-list --objects --all | grep -c 'env.local.bak'        # 期望：0
for s in 319723dea82c7ec25fb64122202ff8d4f45b19a0 3453ceee… ; do git cat-file -e "$s" || echo "已消失 $s"; done
git log --all --diff-filter=A --name-only -- '*env.local.bak*' | wc -l   # 期望：0

# 3) 强推（⚠️ 这一步是"改共享历史"，会要求所有克隆重克隆）
git push --force-with-lease --all && git push --force-with-lease --tags
```
（`3453ceee…` 那几个省略号处要填全 sha，上面第一节给了完整值。）

★ **后果要一起说**：① 所有已有克隆必须**重新克隆**；② fork / 镜像 / 别人的本地副本**可能仍留**（GitHub 支持可协助清 fork）；③ CI/部署里若钉了旧提交号，会失效。
