### 11.2 三条值得记的工程结论
1. ★★ **量纲错了要当场改**：库里注释/实现/测试/界面文案原来都按「幅宽 cm」分档，
   而客户标准原文是「**偏差** ≤3%→扣10%」⇒ 按 cm 分档根本表达不了这条规则（每个客户基准幅宽不同）。
   现在 = 偏差 %，**界值归较低扣款档**（"≤3%"就是 ≤）。★ 改得安全的前提：两边面板当时**零数据**（实测过）。
2. ★★ **`gateToleranceOf` 的"未判定"给的是 `pct: 0`，不是 `pct: null`**（数量口径"按 0 卡"的语义）。
   我第一版按 `pct == null` 判 ⇒ 未判定会被当成"**扣 0%**"静默放过 —— 正好与"不拿默认假设冒充条款"相反。
   ⇒ 判据必须是 `unresolvedReason != null`；且那句 `gateNote`（"按不放溢装处理、上限=合同量"）是**数量**口径的，**不许**抄进幅宽语境。
3. **"读不到"与"没量过"必须分开**：`loadWidthMeasurements` 读失败**抛**，调用方标 `widthMeasurementUnavailable: true`；
   否则一次表故障会被渲染成"这行还没量"，静默漏掉一笔索赔。
