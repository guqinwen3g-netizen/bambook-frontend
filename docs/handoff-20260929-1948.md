## 三、★★★ 下个会话必须先知道的四件事

### 1. 「双轨制」是**全局原则**（使用方原话）
> 「**都是双轨制吧，就是全局都是这样**：首先，我们公司**内部有个标准**。然后，假如说客户那边有客户的标准，
> 那就是会有这个 **P0 级**的去处理客户的标准。然后通常这个**多做少做是双向的**嘛。」

⇒ **G1** 凡「标准/阈值」类 = **我方一套 + 客户一套（客户 P0 优先）**，**不是单一阈值**。
⇒ **G2** 容差类必须**双向**（短装 + 溢装）。
★ **检查话术**：以后凡遇到"只有一个数"的阈值，都要问两句 —— ① **客户那一轨在哪？** ② **反方向那一轨在哪？**

### 2. ★★ 短装也要拦（使用方已拍板）
> 「**短产也是属于业务上一个比较大的问题**，通常要跟客户去确认，所以**肯定是要先拦的**…
> 就是要**卡住**，卡住要等**业务员那边确认了**，**客人那边沟通下来同意了**，然后你这边**才能发货**。
> 肯定是**不能直接发的**。」

⇒ **溢装**：拦（已有）· **短装**：★ **也要拦，且不是提示、是卡住** → 业务员确认 → 客户同意 → 才能发。
★ **好消息**：`ShipmentOrderAllocation.status` 里**本来就有 `ShortShipped`**，还有 `exception` 列
—— 但实测**全仓没有任何代码会写它们**（声明了没人用的死状态，与 `customerAgreementMoq` 同类）。

### 3. ★ 拦的**时机**：我的解读，**待使用方确认**
★ **不能"每次分配都判下界"** —— 分批发货时**第一票必然少于合同量**，会误拦第一票。
使用方话里「**才能发货**」是关键 ⇒ 卡的是**发货/结案**这一步。
⇒ **我的解读**：短装判定发生在**该行出运完成 / 结案**时。★ **下一会话请先确认这一点再动手**。

### 4. ★★ 「未判定 ⇒ 按 0 卡」是**当前的实际行为**，且标准**尚未录入**
- 取数链：① 行级 override（**白名单**，只有 `toleranceSource='line_override'` 算）→ ② **客户标准(P0)**
  → ③ **内部标准(辅助)** → ④ **未判定**

- ★★ **实测：`SystemConfig` 里 `tolerance.internal_standard` 一条都没有** ⇒ **现在任何溢装都会被卡**。
  ⇒ **要么先录标准（界面已就绪），要么这就是你要的严格态** —— 这是使用方要拍的。

## 六、★ 环境与纪律要点（本会话新踩的）

1. ★★ **判"尺"的归类要用探针问它，不要读源码猜**
   `scripts/lib/writeRouteSurface.mjs` 的两条硬机制：
   - `shape` **只看实参位有没有中间件** ⇒ 门写在 handler 体内一律进 `nakedWriteRoutes`
   - `PERMISSION_BODY` 正则找的是**小写** `hasScope(` ⇒ 用 `hasScopeOnRequest`，
     **不要**用 `moqActorHasScope(`（大写 H 匹配不到）
   ★ 探针命令见 skill `bambook-add-write-route-past-guards`。
2. ★★ **`git stash -u` 不会移除"已提交"的文件** ⇒ 量基线时必须确认被测量的东西**真的不在树里**。
3. ★★ **`git commit` 的输出与退出码都不可信**（同一条命令可能被执行两次）⇒ 一律用
   **`git show --stat HEAD`** 复核。
4. ★ **"文件数"类基线在"搬代码"时会漂移，而"总数"不会** ⇒ 判据分开写，**别一看到红就改数字**。
5. ★ **`SystemConfig` 在 `valueType='json'` 时把值存成 JSON 字符串**（不是对象）⇒ 归一化要同时认两者。
6. ★ **Prisma schema 不支持 `/** */` 块注释**（只支持 `//`）。
7. ★ **前端字号守卫**：不许 `text-[11px]`~`text-[18px]` 任意值（用 `text-xs/sm/base/lg`；`text-[10px]` 可以）。
8. ★ **权限 scope 要登记在两份矩阵**（根 `lib/rolePermissionMatrix.ts` 真源 + `server/src/_shared/` 副本），
   只改一份会被「双文件逐字同步守卫」咬红。
