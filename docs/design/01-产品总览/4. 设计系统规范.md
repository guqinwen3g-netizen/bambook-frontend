## §2 BDS 三层治理结构

Bambook Design System（简称 **BDS v2.2**）采用 **宪法 → 契约 → 基线** 三层治理，确保 Bambook 与 BDS 设计宪法完全对齐：

### §2.1 第一层：宪法（Constitution）— BDS v2.2 ✅ 权威
- **BDS v2.2 本身是唯一真源**：所有颜色/圆角/字重/空间/动效/阴影 token 由 BDS v2.2 唯一声明
- Bambook 实现映射：`styles/os-vnext.css`（320 CSS 变量，完全对应 BDS v2.2）
- 不允许任何业务代码覆盖 BDS 变量值（theme 切换同样走 BDS 内的 [data-theme] 选择器）
- 新增 token：必须由 BDS v2.2 升级提供，Bambook 不自造

### §2.2 第二层：契约（Contract）— `styles/flat-experimental.css` ✅
- **实际渲染准源**：用 `!important` 覆盖旧 glass 材质遗留规则，确保 flat 设计（无阴影/无 rim/大圆角）
- BDS showcase 范例使用此文件的实际呈现效果作为视觉验收标准
- 所有 flat 特征在此落地，禁止在组件层单独写 `box-shadow: none` 或 `border: none` 覆盖

### §2.3 第三层：基线（Baseline）— `tailwind.config.js` + `check-design-tokens.sh` ✅
- Tailwind 语义类映射：必须完全镜像 BDS v2.2 token 成 `rounded-panel`、`bg-deep`、`text-link` 等业务友好类名
- `check-design-tokens.sh` 基线扫描：每次提交自动检查是否新增硬编码（颜色 hex / 圆角像素 / box-shadow），有则阻断
- **目标**：Bambook 与 BDS v2.2 showcase 视觉像素级一致

## §3 Luna flat 设计四大特征

**设计灵感融合**：Ron Design Lab（半透明磨砂塑料）+ Halo Lab（无边框大圆角现代极简），避免俗气暖灰拼凑，追求高级感高概念。

### §3.1 无阴影（Shadowless）
- 权威 token：`--bambook-flat-shadow: none`
- 所有静态面（卡片/面板/按钮/输入框）无任何 box-shadow
- 唯一允许发光（glow）的场景：徽章（badge）小元素、进度条活动段、焦点环极小范围 —— toast/tooltip 也不发光，只靠阴影区分浮层
- 禁止：`shadow-md`、`drop-shadow`、`glow`（除小元素外）

### §3.2 无 Rim（Rimless）
- 不做 1px 边框（`--bambook-rim: none`）作为默认风格
- 视觉层次靠「半透明雾化膜色（blur + saturate）」和「发丝分隔线（hairline separator）」构建，不是实色边框围出一个个盒子
- 控件填充采用「蚀刻进玻璃」分层：`--recessed-bg`（默认）/ `--recessed-bg-hover`（悬停）/ `--recessed-bg-strong`（激活），避免实色块拼接

### §3.3 大圆角（Generous Radius 8-34px）
- **BDS v2.2 权威 8 档**（与 tailwind.config.js 完全一致，禁止自造值）：
  - 面板 panel：`--bambook-rdl-radius-panel: 34px`（主面板最外层）
  - 大卡片 card-lg：`--bambook-rdl-radius-card-lg: 28px`（看板 KPI 大卡）
  - 卡片 card：`--bambook-rdl-radius-card: 24px`（普通列表卡片）
  - 内嵌 inset：`--bambook-rdl-radius-inset: 22px`（卡片内嵌套组）
  - 浮层 floating：`--bambook-rdl-radius-floating: 16px`（toast/tooltip/下拉浮层）
  - 控件 control：`--bambook-rdl-radius-control: 18px`（按钮/开关/Tag）
  - 输入字段 field：`--bambook-rdl-radius-field: 16px`（输入框/下拉/日期选择）
  - 紧凑 compact：`--bambook-rdl-radius-compact: 14px`（小徽章/小标签/状态点）
- **禁止**：tsx 中硬编码 `rounded-[Npx]`，一律用语义类 `rounded-panel/card-lg/card/inset/floating/control/field/compact`

### §3.4 半透明膜（Blurred Frosted Film）
- 颜色表达：主容器统一色（避免白色搜索栏+暖灰准交率栏+冷蓝青列表拼凑冲突）
- 雾化膜语法：`backdrop-filter: blur(24px) saturate(180%)` + `background: rgba(x,x,x,0.4~0.7)`
- 深浅模式明度：浅色模式高明度（更通透），深色模式保持现有明度（不要过黑）
- 暖黄底色严格禁止；主色调统一冷蓝青主题，暖灰列表列 hover 色全局排查并彻底杜绝

## §4 320 Token 分类清单（os-vnext.css 权威）

### §4.1 颜色 Token（核心组约 80+）

| 分类 | 示例变量 | 用途 |
|---|---|---|
| 表面 Surface | `--surface-deep`、`--surface-mid`、`--surface-shallow`、`--surface-floating` | 层次化的面板/卡片底色（深度越深越靠近用户） |
| 文字 Text | `--text-primary`、`--text-secondary`、`--text-tertiary`、`--text-link`、`--text-disabled` | 四档文字对比 + 链接色（禁止直接用 `text-black`） |
| 边框 Border | `--border-default`、`--border-subtle`、`--border-action`、`--border-danger` | 发丝分隔线 / 语义状态边框 |
| 品牌 Brand | `--brand-primary`、`--brand-primary-hover`、`--brand-primary-press`、`--brand-soft` | 主色三态（hover/press 明度 shift，非色相偏移） |
| 语义 Semantic | `--success`、`--warning`、`--danger`、`--info` | 状态四色（Success/Warning/Danger/Info） |
| 业务色 Business | `--fabric-blue`、`--garment-green`、`--finance-purple`、`--customer-orange`、`--supplier-teal` | 5 大业务域区分色（仅用于小面积视觉编码，避免大面积色块） |
| 蚀刻 Recessed | `--recessed-bg`、`--recessed-bg-hover`、`--recessed-bg-strong` | 控件「蚀刻进玻璃」填充（默认/悬停/激活） |
| Alpha 修饰 | 所有支持 `bg-deep/50`、`border-action/30` 类语义类自动带透明度 | 直接 hex + 透明度不允许 |

**禁止**：tsx 中任何 `#FFF`、`#0d1b2a`、`rgb(1,2,3)` 硬编码（唯一豁免：吉祥物 SVG/Canvas 美术色、3D 地图 WebGL、邮件/发票模板 CSS 变量在邮件客户端不可靠）

### §4.2 圆角 Token（核心 8 档，BDS v2.2 权威）

| Tailwind 语义类 | 映射 token | BDS v2.2 权威值 | 使用场景 |
|---|---|---|---|
| `rounded-panel` | `--bambook-rdl-radius-panel` | 34px | 主面板最外层（Sidebar / 主内容区外层） |
| `rounded-card-lg` | `--bambook-rdl-radius-card-lg` | 28px | 大卡片（看板 KPI 卡） |
| `rounded-card` | `--bambook-rdl-radius-card` | 24px | 普通列表卡片 |
| `rounded-inset` | `--bambook-rdl-radius-inset` | 22px | 卡片内嵌套组 |
| `rounded-floating` | `--bambook-rdl-radius-floating` | 16px | toast/tooltip/下拉浮层（项目规则：浮层不做深浅调转，用主题内表面，仅靠阴影区分） |
| `rounded-control` | `--bambook-rdl-radius-control` | 18px | 按钮/开关/Tag |
| `rounded-field` | `--bambook-rdl-radius-field` | 16px | 输入框/下拉/日期选择 |
| `rounded-compact` | `--bambook-rdl-radius-compact` | 14px | 徽章/状态点/小标签 |

### §4.3 字重 Token（全局 ≤300 铁律）

权威真源：`tailwind.config.js: theme.extend.fontWeight`

| Tailwind 类 | 映射值 | 使用场景 |
|---|---|---|
| `font-thin`（`font-title`） | 300 | 页面大标题（不是 100，避免过细在普通屏糊） |
| `font-light`（`font-body`） | 300 | 正文/列表（主打 thin 风格） |
| `font-normal`（`font-emphasis`） | 400 | 按钮文字 / 小标题 / 需要强调的行（**唯一一处超过 300**） |
| `font-medium` 及以上 | — | **禁止**（用户明确要求「全局字重≤300」，emasis 用 400 已是上限） |

字体栈：`-apple-system, BlinkMacSystemFont, 'SF Pro Text', 'PingFang SC', 'Helvetica Neue', sans-serif`（优先系统字体，不引入 Web Font 避免 FOIT）

### §4.4 空间 Token（8px 基准栅格）

| Tailwind 类 | 实际值 | 典型用途 |
|---|---|---|
| `space-1` / `p-1` | 4px（0.5 栅格） | 内部微间距（图标与文字之间） |
| `space-2` / `p-2` | 8px（1 栅格） | 紧凑元素间距 |
| `space-3` / `p-3` | 12px（1.5 栅格） | 卡片内边距 |
| `space-4` / `p-4` | 16px（2 栅格） | 列表项间距 |
| `space-5` / `p-5` | 20px（2.5 栅格） | 页面标题区上 padding（pt-5） |
| `space-7` / `px-7` | 28px（3.5 栅格） | 页面标题区左右 padding（px-7，全局统一） |
| `space-8` / `p-8` | 32px（4 栅格） | 主面板内部大间距 |

**标题间距铁律**（用户偏好）：所有页面标题区 `px-7 pt-5 pb-4`（左右 28px / 上 20px / 下 16px），禁止各页面自定义。

### §4.5 动效 Token（克制）

| Token | 默认值 | 场景 |
|---|---|---|
| `--dur-fast` | 120ms | hover/press 微交互 |
| `--dur-normal` | 240ms | 展开/折叠/页面切换 |
| `--dur-slow` | 400ms | 模态框进入、大卡片转场 |
| 缓动 `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 退出/完成优先（苹果风格） |
| 缓动 `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 对称动画 |

禁止：大于 500ms 的动画；弹性 spring 动画（与 Luna flat 极简调性不符）

  inset:      'var(--bambook-rdl-radius-inset, 22px)',
  floating:   'var(--bambook-rdl-radius-floating, 16px)',

  recessed:   'var(--recessed-bg)',
  'recessed-hover':   'var(--recessed-bg-hover)',

  // 文字（text-*）
  primary:    'var(--text-primary)',

  action:     'var(--border-action)',
  danger:     'var(--border-danger)',
  // 品牌（bg- / text- / border- 通用）
  brand: {
    DEFAULT:  'var(--brand-primary)',
    hover:    'var(--brand-primary-hover)',
    press:    'var(--brand-primary-press)',
    soft:     'var(--brand-soft)',
  },
  // 语义四色
  success:    'var(--success)',
  warning:    'var(--warning)',
  danger:     'var(--danger)',

  // 业务域编码色（仅小面积）

### §5.3 BDS 布局级类（.bds-filterbar / .bds-surface）
- 搜索筛选栏等布局组件**禁止手动拼接**基础组件（input + btn + select 一个一个放），必须用 `.bds-filterbar` 容器统一约束间距和材质
- 主容器必须用 `.bds-surface`（统一底色 + 圆角 + 雾化膜），避免多色拼凑（白搜索栏 + 暖灰准交率栏 + 其他色列表）
- 路径：`styles/components.css` 中定义

## §6 防回退机制（check-design-tokens.sh）

### §6.1 基线扫描规则
权威路径：`scripts/check-design-tokens.sh`

扫描 3 类硬编码违规：
1. **颜色硬编码**：`#xxx`、`rgb(...)`、`rgba(...)` 出现在 tsx/css 文件中（豁免清单：SVG 吉祥物 / Canvas / 邮件模板 / 发票模板）
2. **圆角硬编码**：`rounded-[0-9]` 模式出现在 tsx 中（必须用语义类）
3. **阴影硬编码**：`box-shadow:` + 非 `none` 且非 `var()` 的值（正则 `+[^nv]` 防止误判 `none` 和 CSS 变量引用）

### §6.2 CI 门禁
```bash
npm run check:tokens    # 基线模式：和上一次提交基线对比
```
有新增违规 → 阻断 commit。旧违规逐步消化，不允许新增。

## §7 新组件验收 Checklist

| # | 检查项 | 结果 |
|---|---|---|
| 1 | 无任何 `#xxx`/`rgb()` 颜色硬编码？（豁免：SVG 吉祥物 / Canvas / 邮件发票模板） | ▢ |

| 5 | 控件填充用 `--recessed-bg` 系列蚀刻色，不是实色块？ | ▢ |
| 6 | 全局字重 ≤300（强调最多 400），没有 `font-medium` 及以上？ | ▢ |
| 7 | 列表项 hover 不用暖灰色？ | ▢ |
| 8 | 页面标题区 `px-7 pt-5 pb-4`，没有自定义间距？ | ▢ |
| 9 | 标题栏左侧仅标题，右侧面包屑，不换行 + truncate ellipsis？ | ▢ |
| 10 | toast/tooltip 用主题内表面（不做深浅调转），区分仅靠阴影？ | ▢ |

## §8 主题切换机制

[data-theme="light"] / [data-theme="dark"] 切换时只改变 os-vnext.css 内的 CSS 变量值（颜色/透明度），不改变结构。
- 浅色模式：高明度半透明膜，背景更通透
- 深色模式：保持现有明度，不做纯黑（避免 OLED 过暗对比伤眼）

## §16 附录：合规豁免清单（唯一允许硬编码的场景）

| 场景 | 允许硬编码类型 | 原因 |
|---|---|---|
| 吉祥物 SVG / Canvas 插画 | hex 颜色 | 美术自由创作，不属于 UI 系统 |
| 3D 地图 WebGL 渲染 | 颜色 / 光照参数 | WebGL shader 底层需要 |
| 邮件模板（Commercial Invoice 等） | hex 颜色 / 圆角 px | 邮件客户端不支持 CSS 变量 |
| 发票打印模板（Print CSS） | 同上 | 打印机渲染不支持 CSS 变量 |
| 单元测试断言颜色 | hex 颜色 | 对比基线需要精确值 |
| Dashboard 冻结区 | 旧 token | 冻结期不在自动化开发范围，迁移时一并更新 |
