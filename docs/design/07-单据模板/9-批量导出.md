## §3 批量打印（PDF）

### 3.1 已实现：订单打包批量打印

`PackDialog`（`DocumentCenter.tsx` L824-L918）：

```
输入：orderId
  │
  ├─ apiService.packTradeDocumentsByOrder(orderId)
  │   → GET /api/v1/customs/trade-documents/pack?orderId=
  │   → 返回 TradeDocumentPackItem[]（含最新版本快照）
  │
  └─ for each item:
      ├─ TYPE_TO_EXPORT_KIND[item.type] → ExportDocKind
      ├─ extractDocumentSet(item.content) → DocumentSetData
      ├─ EXPORT_DOC_RENDERERS[kind].render(ds) → HTML body
      └─ printHtmlDocument({ title: item.documentNumber, htmlBody })
          → 独立打印窗口 → 浏览器打印 → PDF
```

### 3.2 批量打印限制

| 限制 | 说明 |
|------|------|
| 逐份打印 | 当前为逐份打开打印窗口（非合并 PDF） |
| 可渲染类型 | 仅 CI/PL/CO/BL/INS（TYPE_TO_EXPORT_KIND 映射） |
| 不可渲染降级 | 手工登记无 documentSet 快照 → 打印按钮禁用 |
| 浏览器弹窗 | 需允许弹窗（`window.open`） |

### 3.3 规划：批量合并 PDF

| 功能 | 说明 | 状态 |
|------|------|------|
| 合并 PDF | 多份单据合并为单个 PDF 文件 | 🔲 规划（需 jsPDF/pdf-lib） |
| 批量水印 | 打印水印（如"DRAFT"/"COPY"） | 🔲 规划 |
| 批量页码 | 连续页码编排 | 🔲 规划 |

## §4 订单打包（L/C 交单场景）

### 4.1 业务场景

L/C（信用证）交单要求提交全套装运单据：
- 商业发票（CI）
- 装箱单（PL）
- 原产地证（CO）/ 普惠证（Form A）
- 提单（BL）
- 保险单（INS）
- 受益人证明（BC）

`packTradeDocumentsByOrder` 一次性返回订单全部未删单据 + 最新版本快照，供逐份渲染打印。

### 4.2 打包服务

`packTradeDocumentsByOrder(prisma, orderId)`（`tradeDocumentLifecycleService.ts` L276-L308）：

```
1. 校验 orderId 非空
2. tradeDocument.findMany({ where: { orderId, deletedAt: null }, orderBy: { createdAt: 'asc' } })
3. for each doc:
   a. documentVersion.findFirst({ where: { documentId: doc.id }, orderBy: { version: 'desc' } })
   b. 组装 TradeDocumentPackItem（含 latestVersion + content 快照）
4. 返回 { items, total }
```

### 4.3 TradeDocumentPackItem 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 单据 ID |
| documentNumber | string | 单据编号 |
| type | string | 单据类型 |
| status | string | 单据状态 |
| issueDate | string \| null | 签发日期 |
| consignee | string \| null | 收货人 |
| consignor | string \| null | 发货人 |
| totalAmount | number \| null | 金额 |
| currency | string \| null | 币种 |
| fileName | string \| null | 附件名 |
| latestVersion | number \| null | 最新版本号（无版本=null） |
| content | Record \| null | 最新版本快照（含 documentSet，供前端渲染下载） |

## §5 权限门禁

### 5.1 模块守卫

| 操作 | 权限 | 守卫 |
|------|------|------|
| 订单打包查询（pack） | 读（JWT 或 API-Key） | `createModuleAuthGuard` |
| 批量打印 PDF | 前端纯渲染（无后端鉴权） | 无 |
| Excel 导出（规划） | 读（JWT） | `requireJwtForWrite`（导出含敏感数据） |
| 运单批量生成 | 写（JWT） | `requireJwtForWrite` |

### 5.2 数据权限

| 角色 | 可见范围 | 导出限制 |
|------|---------|---------|
| owner/admin/manager | 全部单据 | 无限制 |
| sales/merchandiser | 自己负责的单据（relationId 关联） | 仅自己的单据 |
| finance | 全部财务相关单据（CI/INS） | 仅 CI/INS |
| warehouse | PL/BL 相关 | 仅 PL/BL |

### 5.3 前端降级

未登录时：
- 打包查询只读降级（可查看不可导出）
- Excel 导出按钮禁用（需 JWT）
- 打印/PDF 可用（前端纯渲染）

### 6.2 Excel 导出端点（规划）

`GET /api/v1/customs/trade-documents/export?type=&status=&dateFrom=&dateTo=`：

**响应**：Excel 文件下载（`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`）

**实现参考**（`server/src/index.ts` L1225-L1233 Shipping Notice 导出）：
```typescript
const rows = [headers, ...dataRows];
const workbook = XLSX.utils.book_new();
const worksheet = XLSX.utils.aoa_to_sheet(rows);
XLSX.utils.book_append_sheet(workbook, worksheet, 'Trade Documents');
const buffer = XLSX.write(workbook, { type: 'buffer', bookType: 'xlsx' });
res.setHeader('Content-Type', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
res.setHeader('Content-Disposition', `attachment; filename="trade-documents-${Date.now()}.xlsx"`);
res.send(buffer);
```

### 8.1 订单打包数据流

```
用户输入 orderId
  ↓
前端: apiService.packTradeDocumentsByOrder(orderId)
  ↓
后端: GET /trade-documents/pack?orderId=
  ↓
packTradeDocumentsByOrder(prisma, orderId)
  ├─ tradeDocument.findMany({ orderId, deletedAt: null })
  └─ for each doc: documentVersion.findFirst({ documentId, orderBy: version desc })
  ↓
返回 TradeDocumentPackItem[]（含 content 快照）
  ↓
前端: for each item → EXPORT_DOC_RENDERERS[kind].render(ds) → printHtmlDocument
  ↓
浏览器打印窗口 → PDF
```

```

  ↓
后端: GET /trade-documents/export?type=...&status=...
  ↓
customsService.listTradeDocuments(filter) → TradeDocument[]
  ↓
XLSX.utils.aoa_to_sheet(rows) → workbook
  ↓

  ↓
res.setHeader('Content-Disposition', 'attachment; filename=...')
res.send(buffer)
  ↓
浏览器下载 Excel 文件
```

## §9 错误处理

| 场景 | 错误码 | 处理 |
|------|--------|------|
| orderId 为空 | 400 | `orderId 必填` |
| 打包查询失败 | 500 | `failed to pack trade-documents` |
| Excel 导出过滤条件非法 | 400 | `非法过滤条件` |
| Excel 生成失败 | 500 | `Excel 导出失败` |
| 打印弹窗被拦截 | 前端 | 提示"请允许浏览器弹窗" |
| 无可渲染快照 | 前端 | 打印按钮禁用 + tooltip 提示 |

## §14 安全约束

| 约束 | 说明 |
|------|------|
| Excel 导出需 JWT | 导出含敏感商业数据（金额/客户），必须 JWT 鉴权 |
| 数据权限分级 | 按角色限制导出范围（sales 仅自己/finance 仅财务单据） |
| 审计留痕 | Excel 导出记录审计日志（导出范围/行数/操作人） |
| 打印窗口隔离 | 打印窗口 `window.open` 独立上下文，不泄露应用 token |
| 文件名安全 | Excel 文件名不含用户输入（防路径注入），用时间戳生成 |
| SQL 注入防护 | 过滤条件经 Prisma 参数化查询，不拼接 SQL |
