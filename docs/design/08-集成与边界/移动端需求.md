## §3 QC 验货 PWA 需求（Phase 4 先行验证）

### 3.1 场景定义

QC 质检员在工厂现场执行验货，桌面端不可用，需要移动设备（手机/平板）完成：

| 场景 | 频率 | 核心操作 |
|------|------|---------|
| 接收验货任务 | 每日 2-3 次 | 查看 Assigned 任务列表，确认验货地点/订单/产品 |
| 执行中期验货 | 每周 5-10 次 | AQL 抽样 + 三级疵点计数（critical/major/minor）+ 拍照 + 结论 pass/conditional/fail |
| 执行终期验货 | 每周 2-5 次 | AQL 门禁（0 致命 + passRate≥90%）+ 业务批准流转 + 拍照 |
| 提交验货报告 | 每次验货后 | 表单提交 → 触发 qc_shipped 门禁校验 + 供应商评分 |

### 3.2 PWA 技术基线

源自 `public/manifest.webmanifest` 已有配置：

```json
{
  "name": "Bambook OS",
  "short_name": "Bambook",
  "scope": "/bambookos/",
  "start_url": "/bambookos/",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#F1F6FA",
  "theme_color": "#0A2746",
  "icons": [{ "src": "/bambookos/pwa-icon.svg", "sizes": "any", "purpose": "any maskable" }]
}
```

| 约束 | 说明 |
|------|------|
| **安装态** | standalone（无浏览器地址栏，类原生 App） |
| **方向** | portrait（竖屏优先，单手操作） |
| **入口** | `/bambookos/` scope 下，桌面图标启动 |
| **图标** | SVG maskable（自适应裁剪） |

### 3.3 页面规格

#### 3.3.1 验货任务列表页

| 元素 | 规格 |
|------|------|
| 顶部 | 任务筛选 Tab（待开始 Assigned / 进行中 InProgress / 已完成 Completed） |
| 列表项 | 订单号 + 产品缩略 + 验货类型（中期/终期）+ 驻地 + 截止日期 + 状态徽章 |
| 操作 | 点击进入验货表单；左滑显示"开始验货"（Assigned→InProgress） |
| 空态 | "暂无验货任务" + 联系 QC 主管提示 |

#### 3.3.2 验货表单页（中期/终期）

| 区块 | 字段 | 移动端交互 |
|------|------|-----------|
| 基本信息 | 订单号 / 产品 / 验货类型 / 驻地 / 验货日期 | 只读展示 |
| AQL 抽样 | 样本量 / 接收质量限 / 抽样方案 | 数字键盘输入 |
| 疵点计数 | critical / major / minor 三级计数 | 步进器（+/-）+ 数字输入 |
| 疵点照片 | 批量拍照上传 | 调用原生相机（`<input capture>`）+ 多图预览 + 删除 |
| 疵点描述 | defectSummary 文本 | 多行文本输入 |
| 验货结论 | pass / conditional / fail | 三选一卡片选择（颜色语义：绿/黄/红） |
| 提交 | 提交报告 | 二次确认（终期 fail 触发广播通知） |

#### 3.3.3 离线缓存策略

| 策略 | 说明 |
|------|------|
| 任务列表 | IndexedDB 缓存最近 50 条任务，离线可查看 |
| 验货表单 | 离线暂存草稿（IndexedDB），联网后自动同步 |
| 照片上传 | 离线存 Blob 到 IndexedDB，联网后分片上传（复用 IM 大文件分片模式） |
| 冲突处理 | 最后写入胜出（单租户单质检员场景，冲突概率低）+ 提交时校验任务状态未变 |

## §4 全员 Ship/Finance/HR 移动适配（🚫 不做）

### 4.1 不做声明

| 模块 | 移动端适配 | 原因 |
|------|-----------|------|
| **Shipments（出运）** | 🚫 不做 | 出运编辑器含装箱明细/物流节点/单据生成，桌面大屏 + 键鼠交互是刚需 |
| **Finance（财务）** | 🚫 不做 | 发票/凭证/核销/汇出汇款涉及金额精度 + 多页签表格，移动端操作风险高 |
| **HR（人事）** | 🚫 不做 | 薪酬/绩效/考勤涉及敏感字段 + 权限遮罩，移动端权限隔离成本高 |
| **Orders（订单）** | 🚫 不做 | 订单录入表单字段密集（客户+产品+BOM+条款），移动端录入效率低 |
| **Customs（报关）** | 🚫 不做 | 报关单明细行 + HS 编码 + 信用证交单，合规操作需桌面端 |
| **Dashboard（驾驶舱）** | 🚫 不做 | 完整 KPI 模型在 Phase 3，移动看板依赖 KPI 落地 |

### 4.2 替代方案

全员移动场景的替代路径（不在移动端适配，而是走通知 + 桌面端）：

```
移动场景需求
  │
  ├─ 查看业务状态 → 通知中心推送（SSE + 原生推送桥）→ 桌面端查看详情
  │                详见 [通知通道闭环.md](./通知通道闭环.md)
  │
  ├─ 审批操作 → 审批中心（桌面端）+ 通知提醒 → 桌面端处理
  │
  └─ 紧急响应 → 通知"转跟进"（convert-to-followup）→ 桌面端执行
```

## §5 QC PWA 与桌面端的关系

| 维度 | 桌面端（Electron） | QC PWA |
|------|-------------------|--------|
| 产品形态 | 唯一产品形态 | Phase 4 先行验证场景 |
| 数据真源 | Mac Mini PostgreSQL | 同（经 API 读写） |
| 验货能力 | 全量（验货任务 + 驻地 + 业务线 + 疵点趋势） | 子集（验货任务 + 中期/终期表单 + 拍照） |
| 离线 | 探活失败启动本地 Express 只读 | IndexedDB 草稿暂存 + 联网同步 |
| 权限 | 7 角色矩阵（移动端仅启用 QC/业务员/销售主管子集） | QC + 业务员/销售主管（子集） |
| 设计系统 | BDS v2.1 flat 全量 | BDS v2.1 移动端子集（竖屏 + 触控） |

## §6 API 端点复用

QC PWA 复用桌面端已有 API（无独立移动端 API），路由前缀 `/api/v1/qc`：

| 方法 | 路径 | PWA 用途 |
|------|------|---------|
| GET | `/qc/assignments` | 验货任务列表（status 过滤） |
| POST | `/qc/assignments/:id/transition` | 任务状态流转（Assigned→InProgress→Completed） |
| GET | `/qc/assignments/:id` | 任务详情 |
| POST | `/qc/inspection-reports` | 提交验货报告（中期/终期） |
| POST | `/qc/inspection-reports/:id/photos` | 疵点照片上传（复用 IM 分片上传） |
| GET | `/qc/locations` | 驻地列表（只读） |

## §7 权限矩阵

| 角色 | PWA 可见 | PWA 可操作 |
|------|---------|-----------|
| QC 质检员 | 本人 Assigned/InProgress 任务 | 执行验货 + 提交报告 + 拍照 |
| QC 主管 | 全部任务 + 驻地 + 业务线 | 分配任务 + 审核 + 驻地 CRUD |
| 业务员 | 关联自己的订单验货结果 | 只读 |
| 其他角色 | ❌ 不可见 | ❌ |

## §8 设计系统约束（移动端子集）

| 约束 | 说明 |
|------|------|
| **竖屏优先** | portrait orientation，单手操作可达 |
| **触控目标** | 最小 44×44pt（iOS HIG），按钮 `bds-btn` 加 `touch-target` |
| **字号** | 最小 14px 正文，标题 16-20px |
| **间距** | 卡片间距 12px，内边距 16px |
| **颜色** | 复用 BDS v2.1 语义 token（`--text-primary`/`--bg-panel` 等），支持 light/dark |
| **无阴影** | flat 设计延续，大圆角 `rounded-card` |
| **禁止** | 硬编码 hex / `rounded-[Npx]` / `box-shadow`（同桌面端铁律） |

## §9 离线与同步

```
在线态                          离线态
  │                               │
  ├─ GET 任务列表 ──写 IndexedDB   ├─ 读 IndexedDB 缓存任务
  ├─ POST 验货报告 ──直写 API     ├─ 验货表单存草稿到 IndexedDB
  ├─ POST 照片 ──分片上传          ├─ 照片存 Blob 到 IndexedDB
  │                               │
  └─ 联网正常                      └─ 联网恢复 → 自动同步草稿 + 照片
                                          │
                                          ├─ 任务状态校验（未变则提交）
                                          └─ 冲突 → 提示用户（最后写入胜出）
```
