## 三、工作区与 Git 纪律

1. **worktree 隔离**：S-FE / S-BE / S-QA 各在独立 git worktree 开工（历史教训：多 IDE 实例同文件并发回写曾造成修改丢失；worktree 从物理上杜绝）：
   - `git worktree add ../bambook-fe -b wave/fe-visual`
   - `git worktree add ../bambook-be -b wave/be-security`
   - `git worktree add ../bambook-qa -b wave/qa-docs`
2. **主 worktree（本目录）保持只读集成**：dev server 继续跑主目录；各分支由总控按波次合并，合并前在被合并 worktree 内完成三绿。
3. **提交粒度**：一个批次一个 commit（批 A/B/C…各自独立），commit message 前缀 `wave(fe|be|qa): 批X — …`；禁止跨批次混合提交。
4. **三绿门禁**（每次提交前在被修改的 worktree 内执行，缺一不可）：
   - `npx tsc --noEmit --skipLibCheck`（前端会话）/ `cd server && npx tsc --noEmit --skipLibCheck`（后端会话）
   - `npm run check:tokens`（S-FE 必跑；S-BE 不涉及样式可免）
   - 受影响测试套件：S-FE `npm test`；S-BE `cd server && npx vitest run`；S-QA 运行新增测试文件
5. **合并窗口**：总控在每个波次末统一 rebase + 合并 + 全量三绿 + 后端全量 vitest；波次中各会话不得自行合 main。

## 六、冲突仲裁与升级路径

1. **文件争用**：发现分工表未覆盖的文件需修改时，停止动手 → 报总控登记归属 → 更新本文档分工矩阵后再改。
2. **跨域依赖**：S-FE 需要后端改接口 / S-BE 需要前端配合时，在本文档「跨会话请求」节登记，由总控排入下一波次，禁止私自从对方目录下手。
3. **合并冲突**：总控合并时若两分支触同文件（说明分工表失效），以分工矩阵为裁决依据，越界方 rebase 重做。

5. **热修复例外**：生产环境 P0 可不按波次，但仍须遵守文件归属 + 三绿，事后补登记。

## 十、W-PG 页面规格化收编（CD-007，2026-08-17 增补）

> **根因**：违规点驱动（grep→替换）无法捕捉布局组合问题（按钮尺寸不一、filterbar 撑高 header 等），且同一页面被批 A/G/J 反复开膛却无终态责任人。
> **新范式**：规格 → 台账 → 逐页销号。台账 30 页全量驱动，结构性零遗漏。

### 10.1 页面骨架六区强制规格（S-FE 落 `docs/design-system/page-skeleton-spec.md`，总控审定后生效）

| 区 | 强制标准 |
|---|---|
| 标题区 | 统一 `PageHeader`（bds-pagehead）：`px-7 pt-5 pb-4`、中英双语标题、面包屑右置、标题不换行省略截断、通知按钮 Dashboard 大按钮规格 |
| 筛选区 | 统一 `bds-filterbar` 范式：input 用 `bds-input sm`（34px）、按钮 `bds-btn-ghost`（40px）、6px 高度差为官方设计；单行不换行；**禁止任何元素撑高筛选行导致页面上边距异常**；**选型规则**：纯单搜索页用简单搜索框（禁为用而用套组合 bar），仅当搜索+≥1 筛选共行时才用组合嵌套 bar；搜索 icon 必须在输入框内部（leading icon），禁止外挂框外；参考基准实现 = 开发管理 / 货运管理 / 财务管理的功能 bar（一搜索+两筛选，长度与尺寸比例） |
| 操作区 | 主操作一律 `bds-btn` 默认 40px；**`bds-btn-sm` 仅表格行内操作白名单**，其余禁用；主按钮 `bds-btn bds-btn-primary`；**toggle 组 active 态禁用 `bds-btn-dark` 实心黑填充**（浅色雾面环境中突兀），active 用冷墨洗 tint/inset 表达 |
| 表单控件 | **select/date/dropdown 一律 BDS 组件，禁原生默认渲染**：select → `bds-select`（已存在）；date → BDS 日期组件（`ui/CapsuleDateInput.tsx` 为基准实现）；原生 `<select>` / `type="date"` 存量 58 文件 321 处，逐页收编时清零 |
| 内容区 | `bds-surface` 家族 + 统一间距 token；嵌套层 `bds-inset`（--recessed-bg 冷墨洗） |
| 弹层区 | `bds-modal` / `bds-toast`（W4 alert 收敛后全站唯一入口） |
| 全局 | 字重 ≤300；rounded 仅 BDS 刻度；无阴影无 rim（豁免清单除外） |
