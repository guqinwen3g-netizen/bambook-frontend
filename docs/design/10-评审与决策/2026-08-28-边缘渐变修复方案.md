# UI 修复方案（边缘渐变 + 卡片 hover 颜色 + 侧边栏 button 过渡）

> 来源：用户人工审查发现 + 用户拍板（2026-08-28）
> 问题 1：ScrollEdgeFades 用 mask-image 动态遮罩，导致两个问题：
>   1. 边缘渐变会抖动（JS 动态计算）
>   2. mask 导致卡片的 backdrop-filter 失效（hover 颜色不一致）
> 方案：统一改成固定遮罩蒙版（独立渐变层，不动 backdrop-filter）
>
> 问题 2：卡片 hover 颜色不一致（大分类卡片淡蓝 vs 组织卡片冷灰）
> 根因：同问题 1 的根因 2（mask 导致 backdrop-filter 失效）
> 方案：修问题 1 后顺带解决，但需要额外验证两级页面 hover 颜色一致
>
> 问题 3：侧边栏收起/展开时，button 没有跟着过渡，直接出现/消失，视觉上"戳出来"
> 方案：button 透明度过渡与侧边栏宽度动画同步，并加位移动画

## 路线修正（2026-08-28 下午拍板，已落地）

**第一版 StaticEdgeFade（固定颜色渐变层）已否决并删除**。用户实测否决理由：
1. 那是"颜色遮盖渐变"（背景色带），不是"内容透明度渐隐"——正确效果是蒙版下方内容自身在边缘淡出；
2. 渐变层上下留白过多，位置不贴视口边缘。

**第二版（现行方案）：`useStaticEdgeMask`**（`components/ui/useStaticEdgeMask.ts`）——固定 mask-image（linear-gradient）直接挂在**滚动容器自身**的 style 上：
- 真透明度渐隐（内容淡出，非色带遮盖）；
- 一次设置、不监听滚动 → 不抖动（五档 scrollTop 实测 maskImage 取值不变）；
- 与其他 8 个 ScrollEdgeFades 单参页面同路径 → 不截断卡片 backdrop-filter（两级页面 hover 背景色/backdropFilter 实机逐字节一致：`rgba(15, 23, 42, 0.043)` + `blur(20px) saturate(1.8)`）；
- 渐隐区贴视口边缘（顶部渐隐终点 96px = 标题栏重叠 64 + 渐隐 32，底部 48px），无多余留白。

应用点：RelationsManager 大分类页/组织列表页（grid 模式）、ProductsManager 主分类页/产品网格页（grid 模式）；StaticEdgeFade.tsx 已删除。

**落地状态（2026-08-28）**：问题 1 边缘渐隐 `f7005b5` ✅｜问题 2 hover 颜色一致随问题 1 解决（实机逐字节一致）✅｜问题 3 侧边栏 button 过渡 `4c7d71c` ✅（rail/展开内容改 motion.div 与宽度 spring 锁步，展开块始终挂载 + inert/aria-hidden，实机交叉渐变无跳变）｜全站渐隐统一 `d8c1790` ✅（13 页面 16 处迁至 useStaticEdgeMask：BusinessTools 2/ProductionBoard/AdminPanel 2/Assistant 3/BomManager + null-ref 断链 6 页面恢复渐隐 Customs/Procurement/Quotation/Inventory/DocumentCenter/MesManager；hook 加固 ref 延迟挂载轮询绑定 + MutationObserver 内容增长重判，AdminPanel tab 往返渐隐失效与初始渐隐缺失两异常实机复验修复）。

## 问题根因

`ScrollEdgeFades` 组件在滚动容器溢出时，给外壳 div（maskRef）写内联 `mask-image`。这个 mask 在 Chromium 里会把卡片的 `backdrop-filter: blur() saturate()` 的采样范围截断为空，导致毛玻璃滤镜静默失效。

**实测证据**：
- 关系智库大分类页（6 卡不溢出）：无 mask → backdrop-filter 正常 → hover 淡蓝
- 关系智库组织列表页（7 卡溢出 48px）：有 mask → backdrop-filter 失效 → hover 冷灰

**影响范围**：
- `components/RelationsManager.tsx`（2 处 maskRef）
- `components/ProductsManager.tsx`（2 处 maskRef）

---

## 修复方案

### 1. 新建固定遮罩组件 `StaticEdgeFade.tsx`

位置：`components/ui/StaticEdgeFade.tsx`

**核心原理**：
- 不用 `mask-image` 遮罩内容
- 用绝对定位的渐变层（`pointer-events: none`），绘制渐变颜色
- 固定在顶部和底部，不随滚动动态计算
- z-index 在标题栏之下、主内容之上

**组件接口**：
```tsx
interface StaticEdgeFadeProps {
  topHeight?: number;        // 顶部渐变高度，默认 32
  bottomHeight?: number;     // 底部渐变高度，默认 48
  topOffset?: number;        // 顶部偏移（避开标题栏），默认 0
  zIndex?: number | string;  // z-index，默认 20（标题栏 z-30 之下）
  className?: string;        // 额外 className
}
```

**实现要点**：
- 顶部渐变层：`absolute top-{topOffset} left-0 right-0 h-{topHeight}`，渐变从背景色到透明
- 底部渐变层：`absolute bottom-0 left-0 right-0 h-{bottomHeight}`，渐变从透明到背景色
- 渐变颜色用 `var(--frosted-bg)` 或 `var(--os-bg-primary)`，与页面背景一致
- 下方左右角带弧度（`border-bottom-left-radius` / `border-bottom-right-radius` 与主容器一致）
- 不用 JS 监听滚动，纯 CSS 固定

## 问题 2：侧边栏 button 过渡

### 问题描述

侧边栏收起/展开时，button 没有跟着过渡，直接出现/消失，视觉上"戳出来"。

**根因**：
- 侧边栏本身用 `motion.aside` + spring 动画（`width: isCollapsed ? 64 : 232`），有平滑过渡
- 收起状态的 rail 用 `opacity` 过渡（`transition-all duration-700`），但 button 在里面是**直接显示/隐藏**（靠 `opacity-100` / `opacity-0 pointer-events-none`）
- button 的透明度过渡是 700ms，但侧边栏宽度动画是 spring（时长不固定），两者不同步

### 修复方案

**修改 `components/Sidebar.tsx`**：

1. **收起状态的 rail（L160-L163）**：
   - 把 `transition-all duration-700` 改成与侧边栏宽度动画同步的 spring 过渡
   - 或者：button 加位移动画（从左边滑入/滑出）

**具体做法**（推荐）：

把收起状态的 rail 也改成 `motion.div`，用 spring 动画控制 opacity 和 x 位移：

```tsx
<motion.div
  initial={false}
  animate={{
    opacity: isCollapsed ? 1 : 0,
    x: isCollapsed ? 0 : -20,
  }}
  transition={{ type: 'spring', damping: 25, stiffness: 150 }}
  className={`absolute left-0 top-0 bottom-0 w-16 z-10 flex flex-col items-center ${blueprint.collapsedRail.paddingClass}
    ${isCollapsed ? 'pointer-events-auto' : 'pointer-events-none'}`}
  data-sidebar-collapsed-rail
>
```

同时展开状态的内容（L210+）也要同步改：

```tsx
<motion.div
  initial={false}
  animate={{
    opacity: isCollapsed ? 0 : 1,
    x: isCollapsed ? 20 : 0,
  }}
  transition={{ type: 'spring', damping: 25, stiffness: 150 }}
  ...
>
```

这样 button 会跟着侧边栏宽度动画同步滑入/滑出，不会"戳出来"。

### 验收标准

- 侧边栏收起/展开时，button 平滑滑入/滑出，不突兀
- 过渡时长与侧边栏宽度动画一致
- 过渡期间 button 不会"戳出来"
