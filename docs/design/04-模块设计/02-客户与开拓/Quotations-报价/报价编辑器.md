## 一、编辑器定位与边界

报价编辑器是创建态的核心表单，将「报价信息录入」与「双轨成本定价」合二为一。业务员在录入报价行的同时，可在内嵌的双轨面板完成 Track A 估算与 Track B 退税定价，DeviationBadge 实时显示偏差等级，保存时双轨快照随报价单一并落库。

**在边界内**：表头信息录入、报价行增删改、面料档案搜索联动、历史价参考与偏离提示、双轨面板内联嵌入、偏差徽章实时显示、创建提交（含双轨快照）、表单校验。
**不在边界内**：双轨面板内部试算逻辑（见 [双轨成本面板.md](./双轨成本面板.md)）、已保存报价单的二次定价（见列表页「应用定价」modal）、转订单流程（见 [报价转订单流程.md](./报价转订单流程.md)）。

## 二、表单分区结构

编辑器纵向堆叠 3 个 bds-card 分区：

| # | 分区 | 说明 |
|---|------|------|
| 1 | 基本信息 | 表头 11 字段（编号/币种/日期/客户/业务员/询价参考/交货/付款条款） |
| 2 | 双轨成本面板 | 可折叠，内联 TrackAPanel + TrackBPanel + DeviationBadge（仅内部） |
| 3 | 报价明细 | 报价行增删改 + 面料档案联动 + 历史价参考 + 合计 |

底部为表单错误提示（bds-alert danger）+ 「创建报价单」主按钮。

## 三、表头字段定义

| 字段 | 控件 | 默认值 | 校验 | 说明 |
|------|------|--------|------|------|
| 报价编号 | text input | 空（自动生成 QT-YYYY-NNNN） | 传入时校验唯一 | 留空由服务端 nextBusinessNumber 分配 |
| 币种 | select | USD | — | USD / CNY / EUR |
| 报价日期 * | date | 今天 | 必填 | 变更时自动重算 validUntil（+30 天） |
| 有效期至 | date | 报价日 +30 天 | — | 外贸报价惯例 |
| 客户 | select | 空 | — | 从 Relation（Customer/Supplier）选择，选中带出 customerName |
| 业务员 | text input | 空 | — | salesperson |
| 询价参考 | text input | 空 | — | inquiryRef（开发案 prime 可预填） |
| 交货条款 | text input | FOB Shanghai | — | deliveryTerms |
| 付款条款 | text input | T/T 30% deposit, 70% before shipment | — | paymentTerms |

客户选项来源：`relations.filter(r => !r.deletedAt && (r.type === 'Customer' || r.type === 'Supplier'))`，label = englishName || chineseName || name。

## 四、报价行编辑

每行是一个 rounded-inset 卡片，含：

| 字段 | 控件 | 说明 |
|------|------|------|
| 面料编码 | text input + 搜索建议 | 输入≥2字符防抖300ms搜索 ProductAsset(Fabric)，选中带出 SKU+成分描述 |
| 品名描述 * | text input | description（必填）；选中档案时若为空自动填充「品名 + 成分」 |
| 数量 * | number input | quantity（必填） |
| 单位 | select | YD / M / KG / PC / SET |
| 单价 * | number input（step 0.01） | unitPrice（必填） |
| 历史价参考 | 自动展示 | 选中档案时显示工厂价/最近售价 + 偏离>15%黄标 |
| 行金额 | 自动计算 | calcLineAmount(qty, price) 4位小数 |

**行操作**：「添加行」按钮（Plus 图标）；行数>1时每行显示删除按钮（Trash2）。

**行金额计算**：`Math.round(qty × price × 10000) / 10000`（4 位小数）；合计 formTotal = Σ 行金额。

## 五、双轨面板内联嵌入

双轨成本面板作为第 2 分区，可折叠（showDualTrack 默认 true）：

```
┌─ 双轨成本面板（轨道 A 估算 + 轨道 B 退税定价 · 仅内部）[折叠] ─┐
│  grid-cols-1 xl:grid-cols-2                                       │
│  ┌──────────────────┐  ┌──────────────────────────────────────┐  │
│  │   TrackAPanel    │  │  TrackBPanel                          │  │
│  │  onMedianUsdChange│  │  onResultChange → trackBResult       │  │
│  │   → trackAMedian │  │  DeviationBadge { finalUsd, medianUsd│  │
│  │                  │  │   medianUnit }                        │  │
│  └──────────────────┘  └──────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

- TrackAPanel 通过 `onMedianUsdChange(usd, unit)` 回传中位估算
- TrackBPanel 通过 `onResultChange(result)` 回传终价试算结果
- DeviationBadge 实时显示偏差等级（ok/warn/block）
- 双轨数据在创建时随 `dualTrackSnapshot` 一并提交（trackAMedianUsd / trackAUnit / trackBFinalUsd）

详细集成规格见 [双轨成本面板.md](./双轨成本面板.md)。

## 六、保存/发送/审批流程

```
用户填写表头 + 报价行 + （可选）双轨试算
        │
        ▼
handleCreate() 校验：
  ① issueDate 必填
  ② 至少一行有效报价明细（description + quantity + unitPrice 齐备）
        │
        ▼
组装 QuotationInput（含 dualTrackSnapshot 若双轨齐备）
        │
        ▼
POST /v1/quotations
        │
        ▼
quotationService.createQuotation()：
  ① calcTotalAmount(lines)
  ② 双轨偏差：trackAOk && trackBOk → calculatePriceDeviation()
  ③ level=ok   → 正常落库
     level=warn → 同事务生成 ApprovalRequest(risk=medium)
     level=block→ 同事务生成 ApprovalRequest(risk=high)
  ④ 落 6 字段双轨快照 + 行明细 + 审计日志 + EntityLink
  ⑤ quotationNumber 自动生成（QT-YYYY-NNNN）
        │
        ▼
创建成功 → 关闭表单 + 重置 + 刷新列表
```

**发送门禁**：创建后状态为 Draft，需在列表页点「发送报价」转为 Sent。block 级偏差在发送时 fail-closed 拦截（服务端查 ApprovalRequest.status）。

**审批触发**：warn/block 在创建事务内自动生成 ApprovalRequest，无需用户手动发起。

## 七、面料档案联动（PRD §19.5）

```
用户在面料编码输入 → 防抖 300ms → ≥2 字符触发
        │
        ▼
apiService.listProductAssets(search, mainCategory='Fabric', limit=6)
        │
        ▼
下拉建议（bds-pop）：SKU + 品名
        │
        ▼
选中 → handleSelectFabric：
  ① fabricCode = product.sku
  ② description 若空 → 自动填充「品名 + 成分」
  ③ selectedFabrics[lineKey] = product
        │
        ▼
历史价参考条（latestPriceOf）：
  ① factory 类型最新价（工厂价）
  ② customer 类型最新价（最近售价）
  ③ 偏离最近售价 >15% → 黄标「将触发审批」
```

输入变化即视为偏离已选档案，清除旧参考避免陈旧价格误导。

## 十三、设计系统约束

- **BDS 组件族**：bds-card / bds-input / bds-select / bds-btn（primary/secondary/ghost）/ bds-alert / bds-overline / bds-pop / bds-mono / rounded-inset
- **主题透明**：编辑器无 isDarkMode 分支，所有色彩走 CSS 变量 token
- **标签类**：`labelCls = 'block text-xs mb-1 text-[var(--text-tertiary)]'`
- **禁止**：硬编码 rounded/hex/shadow
