## 一、页面定位与边界

报价列表页是报价管理模块的默认视图，承担「全局浏览—筛选定位—展开查看—执行操作」的售前调度职责。它与创建态（showCreateForm=true）通过 AnimatePresence 切换，共享同一 QuotationManager 组件实例。

**在边界内**：卡片列表渲染、状态分段过滤、关键词搜索、卡片展开/折叠、状态操作按钮（发送/接受/拒绝/删除/转单/生成 PI/应用定价/溯源/打印）、偏差徽标与超期提醒展示、转单成功横幅。
**不在边界内**：创建/编辑表单（见 [报价编辑器.md](./报价编辑器.md)）、双轨面板试算（见 [双轨成本面板.md](./双轨成本面板.md)）、转订单事务逻辑（见 [报价转订单流程.md](./报价转订单流程.md)）。

## 二、筛选维度

| 筛选维度 | 控件 | 值域 | 实现路径 |
|----------|------|------|----------|
| 状态 | `bds-segment` 分段控件 | 全部 / 草稿(Draft) / 已发送(Sent) / 已接受(Accepted) / 已拒绝(Rejected) / 已过期(Expired) | STATUS_TABS + statusFilter |
| 搜索 | 文本输入（带 Search 图标） | 报价号 / 客户名 / 询价参考号（OR contains） | searchQuery → listQuotations OR |
| 客户 | （服务端支持，UI 未暴露独立筛选） | customerRelationId | listQuotations params.customerRelationId |
| 日期范围 | （服务端支持，UI 未暴露） | dateFrom / dateTo（issueDate） | listQuotations params.dateFrom/dateTo |

**前端已暴露**：状态分段 + 搜索。**服务端已就绪待 UI**：客户筛选、日期范围筛选。

偏差级别（warn/block）不作为独立筛选项，而是以徽标形式叠加在卡片头部，便于在任意状态下识别需审批报价。

## 三、列定义与卡片结构

列表采用卡片式布局（非表格），每张报价单卡片含「头部（可点击展开）+ 展开详情」两层：

### 3.1 卡片头部（始终可见）

| 区域 | 内容 | 样式 |
|------|------|------|
| 展开按钮 | ChevronRight / ChevronDown 切换 | text-quaternary |
| 报价编号 | quotationNumber | bds-mono text-sm |
| 状态徽章 | STATUS_BADGE_VARIANT 映射 5 态语义色 | bds-badge sm + dot |
| 偏差徽标(warn) | AlertTriangle + 「偏差 ±N% · 已触发审批」 | bds-badge sm warning |
| 偏差徽标(block) | AlertCircle + 「偏差 ±N% · 需审批后发送」 | bds-badge sm danger |
| 超期提醒 | Sent ≥7 天 + 「已发送 N 天 · 待客户回复」 | bds-badge sm warning |
| 客户/日期 | customerName · issueDate · 有效期至 validUntil | text-tertiary |
| 金额 | totalAmount + currency | bds-tnum text-sm |
| 行数 | lines.length + 「行」 | text-quaternary |

### 3.2 展开详情（expandedId 匹配时）

| 区块 | 内容 |
|------|------|
| 条款信息 | 交货 / 付款 / 业务员 / 询价参考（4 列 grid） |
| 双轨定价快照 | trackAMedianUsd / trackBFinalUsd / 偏差百分比 + 级别（仅 priceDeviationLevel 存在时显示，标注「内部」） |
| 行明细表 | bds-table：序号 / 编码 / 品名 / 数量 / 单位 / 单价 / 金额 |
| 操作按钮 | 按状态动态渲染（见 §五） |
| 关联视图 | RelatedEntitiesPanel type="quotation" |

## 四、状态机与操作可用性

操作按钮按报价单状态动态渲染：

| 状态 | 可用操作 |
|------|----------|
| Draft | 应用定价 / 发送报价（block 时附门禁提示）/ 删除 |
| Sent | 接受 / 拒绝 |
| Accepted | 转为订单（未转时）/ 生成 PI / 溯源 / 打印；已转时显示「已转订单」+ 直达链接 |
| Rejected | 溯源 / 打印 + 终态标记 |
| Expired | 溯源 / 打印 + 终态标记 |
| 全状态 | 打印报价单 |

**block 门禁提示**：Draft 且 priceDeviationLevel='block' 时，「发送报价」按钮旁显示红色提示「偏差超 30%，需审批通过后发送」。服务端 sendQuotation 会 fail-closed 拦截。

**转单防重**：Accepted 且 convertedOrderId 已存在时，隐藏「转为订单」按钮，改为显示已转订单直达链接。

## 五、关键操作清单

| 操作 | 触发条件 | API | 行为 |
|------|----------|-----|------|
| 发送报价 | Draft | POST /:id/send | 状态→Sent + sentAt 写入 + QuotationIssued 事件 |
| 接受 | Sent | POST /:id/accept | 状态→Accepted + QuotationAccepted 事件 |
| 拒绝 | Sent | POST /:id/reject | 状态→Rejected |
| 删除 | Draft | DELETE /:id | 软删 + EntityLink 失效 |
| 转为订单 | Accepted 且未转 | POST /:id/convert-to-order | 创建 Order + 标记 convertedOrderId + 成功横幅 |
| 生成 PI | Accepted | financeV2Service.generatePi | 生成形式发票（成功横幅显示 PI 编号） |
| 应用定价 | Draft | financeV2Service.applyTrackPricing | 打开双轨定价 modal（见双轨成本面板.md） |
| 溯源 | 全状态 | TraceabilityPanel | Sheet 抽屉，报价到发货链溯源 |
| 打印 | 全状态 | printHtmlDocument | 中英文报价单 PDF |

操作期间按钮显示 Loader2 + disabled，actionLoading 按 `${id}_${action}` 锁定单行单操作。

## 六、数据流与刷新机制

```
statusFilter / searchQuery 变化
        │
        ▼
fetchQuotations(useCallback, 依赖 [statusFilter, searchQuery])
        │
        ▼
apiService.listQuotations({ status, search, limit: 100 })
        │
        ▼
setQuotations(result.items) + setLoading(false)
        │
        ▼
卡片列表渲染（quotations.map）
```

**刷新触发**：状态/搜索变化自动刷新；操作成功后（handleAction）调 fetchQuotations 刷新；导入向导关闭后刷新；应用定价成功后刷新。

**分页**：前端固定 limit=100，服务端最大 200。offset 分页服务端支持但 UI 未暴露翻页。

## 九、四态规范

| 状态 | 表现 | 实现路径 |
|------|------|----------|
| **空态** | bds-empty：「暂无报价单」+ 「点击新建报价单开始，或导入历史报价」 | quotations.length === 0 |
| **加载态** | Loader2 animate-spin 居中（首次加载）；按钮内 Loader2 + disabled（操作中） | loading / actionLoading |
| **错误态** | bds-alert danger 顶部提示 + 操作失败追加「操作失败：${message}」 | error state |
| **成功态** | 转单成功 bds-alert success 横幅 + 「查看订单」直达（onOpenOrder）；PI 生成成功横幅显示 PI 编号 | convertedOrderId state |

## 十、业务规则关联

| 规则 | 落地 |
|------|------|
| Sent 超 7 天未回复提醒 | sentDaysPending(qt) ≥7 天显示琥珀徽章 |
| 偏差 block 禁止发送 | 列表显示红色门禁提示 + 服务端 409 拦截 |
| 转单幂等 | convertedOrderId 已存在时隐藏转单按钮 |
| 终态不可操作 | Rejected/Expired 显示终态标记，无状态操作按钮 |

## 十一、可访问性 & 交互细节

- 卡片头部 cursor-pointer + hover 背景加深（hover-darken），点击切换展开
- 展开动画 AnimatePresence height:0→auto + opacity，duration 0.2s
- 列表项依次入场动画 delay = index × 0.03s
- 状态分段控件 active 态高亮
- 搜索输入带 Search 图标前缀，RefreshCw 按钮刷新（loading 时旋转）
- 金额格式化：toLocaleString en-US minimumFractionDigits:2
- 日期格式化：直接显示 YYYY-MM-DD，无值显示「—」

## 十二、设计系统约束

- **BDS 组件族**：bds-card（padding:0 + overflow:hidden）/ bds-badge（5 态语义变体 + dot）/ bds-segment / bds-btn / bds-table / bds-alert / bds-empty / bds-sheet / bds-mono / bds-tnum
- **主题透明**：列表态无 isDarkMode 分支，徽章/卡片/表格均走 token 语义类
- **偏差徽标语义**：warn→warning / block→danger，与 DeviationBadge 三态同源
- **状态徽章**：STATUS_BADGE_VARIANT 替代旧 statusSemanticClass 双三元拼装（BDS v2.1）
- **禁止**：硬编码 rounded/hex/shadow

## 十四、待补的设计缺口

| # | 缺口 | 影响 | 建议优先级 |
|---|------|------|-----------|
| 1 | 客户筛选 / 日期范围筛选 UI 未暴露 | 无法按客户或日期段快速定位 | P2 |
| 2 | 分页 UI 未暴露（固定 limit=100） | 超过 100 条报价需靠搜索缩小范围 | P2 |
| 3 | 偏差级别未作为独立筛选项 | 无法快速筛选所有需审批报价 | P3 |
| 4 | 列表无批量操作（批量发送/删除） | 大量 Draft 报价需逐条操作 | P3 |
