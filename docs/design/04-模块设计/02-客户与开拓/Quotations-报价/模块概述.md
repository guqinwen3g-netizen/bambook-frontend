## 一、模块定位与边界

Quotations 模块承担外贸出口企业「售前报价决策与转化」的真源——给客户报什么价、价格是否需要审批、客户接受后如何转为生产订单。它在客户关系管理与订单生产之间架起桥梁，并通过嵌入 Pricing 模块的双轨成本面板，让每一份报价都有成本依据可追溯。

**核心能力**：
- 报价单全生命周期：草稿（Draft）→ 已发送（Sent）→ 已接受（Accepted）/ 已拒绝（Rejected）/ 已过期（Expired），状态转换严格校验非法跳转
- 双轨成本快照：创建时由编辑器内联 Track A/B 面板写入中位估算 + 终价，服务端计算偏差分级（ok / warn / block）并持久化为历史快照
- 偏差审批门禁：偏差 >15% 同事务自动生成 ApprovalRequest（warn 提示审批），>30% fail-closed 禁止发送直至审批通过
- 转订单转化：Accepted 报价单一键转为生产订单（Order），字段自动映射 + 行明细迁移 + convertedOrderId 标记 + 幂等防重
- 下游联动：接受后可生成形式发票（PI）；全状态可打印中英文报价单；展开详情可调取报价到发货链溯源

**模块边界**：
- ✅ 在内：报价单 CRUD、状态流转、双轨快照写入与展示、偏差审批触发、转订单、PI 生成触发、历史报价导入、中英文打印
- ❌ 不在内：双轨纯函数计算逻辑（在 Pricing 模块 trackAEstimator，本模块只消费结果）、退税率表 / 佣金规则 / 价格历史维护（在 Pricing 模块）、审批审批人指派与流转 UI（在 Approval 模块）、订单后续生产管理（在 Orders 模块）、汇率维护（在 ExchangeRate 模块，本模块只读消费）

## 四、状态机与转换矩阵

报价单 5 态状态机，转换严格校验，非法跳转抛 409：

| 当前状态 | 允许目标 | 触发动作 | 服务端方法 |
|----------|----------|----------|------------|
| Draft（草稿） | Sent / Expired | 发送 / 标记过期 | sendQuotation / expireQuotation |
| Sent（已发客户） | Accepted / Rejected / Expired | 接受 / 拒绝 / 标记过期 | acceptQuotation / rejectQuotation / expireQuotation |
| Accepted（客户已接受） | —（终态） | 可转订单 / 生成 PI | convertToOrder / generatePi |
| Rejected（客户已拒绝） | —（终态） | 仅查看 / 溯源 / 打印 | — |
| Expired（已过期） | —（终态） | 仅查看 / 溯源 / 打印 | — |

**编辑/删除约束**：仅 Draft 状态可编辑（updateQuotation）与软删除（deleteQuotation）；非 Draft 抛 409。

**发送门禁（PRD §8.6）**：`priceDeviationLevel === 'block'` 时，sendQuotation 查 ApprovalRequest.status，未 approved 则抛错 → 路由层 409（门禁：price-deviation）。

**重发场景**：sentAt 保留首次发送时间（`existing.sentAt ?? now`），用于「Sent 超 7 天未回复」琥珀提醒与账龄分析。

## 六、数据模型与字段概览

Quotations 模块涉及 2 个核心模型（详细字段见 [报价与成本模型组.md](../../../02-数据模型/报价与成本模型组.md)）：

| 模型 | schema.prisma 位置 | 用途 | 关键字段 |
|------|-------------------|------|----------|
| `Quotation` | L2878 | 报价单主表 | quotationNumber @unique / status / totalAmount / 6 双轨快照字段 / convertedOrderId / sentAt |
| `QuotationLine` | L2941 | 报价行明细 | quotationId FK Cascade / lineNumber / fabricCode / quantity / unitPrice / amount |

**双轨快照 6 字段**（PRD §8.6，创建时写入，此后为历史快照不随编辑变更）：
- `trackAMedianUsd` Decimal?(18,4) — 轨道 A 中位估算美元单价
- `trackAUnit` String? — PC（件）/ M（米）
- `trackBFinalUsd` Decimal?(18,4) — 轨道 B 终价美元单价
- `priceDeviationPercent` Float? — 终价偏离估算中位百分比
- `priceDeviationLevel` String? — ok / warn（>15%）/ block（>30%）
- `priceApprovalId` String? — 偏差 >15% 时自动生成的 ApprovalRequest id

**行金额计算口径**：`amount = Math.round(quantity × unitPrice × 10000) / 10000`（4 位小数）；totalAmount = Σ 行金额。

## 十一、可访问性 & 交互细节

- **列表展开/折叠**：卡片头部点击切换 expandedId，AnimatePresence 高度动画
- **状态过滤分段控件**：`bds-segment` 全部/草稿/已发送/已接受/已拒绝/已过期 6 档
- **搜索**：报价号 / 客户名 / 询价参考号 OR 模糊匹配
- **Sent 超 7 天未回复提醒**：`sentDaysPending` 计算，≥7 天显示琥珀徽章「已发送 N 天 · 待客户回复」
- **偏差徽标**：列表卡片头部 warn（黄）/ block（红）双档徽章 + 偏差百分比
- **报价行面料搜索**：防抖 300ms，≥2 字符触发，下拉建议选中后带出 SKU + 成分描述 + 历史价参考
- **历史价偏离提示**：偏离最近售价 >15% 黄标「将触发审批」
- **创建表单有效期默认**：报价日 +30 天（外贸报价惯例），改报价日自动重算
- **开发案发起报价 prime**：sessionStorage 预填客户名/描述/询价参考，挂载时自动打开创建表单

- **状态徽章语义**：STATUS_BADGE_VARIANT 映射 Draft=neutral / Sent=info / Accepted=success / Rejected=danger / Expired=warning（BDS bds-badge 语义变体）
- **偏差徽章语义**：warn=warning（黄）/ block=danger（红），与 DeviationBadge 三态同源
- **打印版式**：复用共享 printHtmlDocument，中英文双栏（QUOTATION / 报价单），双轨快照属内部信息不打印
- **禁止**：tsx 中硬编码 `rounded-[Npx]`、hex 颜色、box-shadow 硬编码（遵循项目设计系统铁律）
