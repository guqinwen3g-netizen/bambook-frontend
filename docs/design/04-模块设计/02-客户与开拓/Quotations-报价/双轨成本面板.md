## 一、组件定位与共享契约

TrackAPanel / TrackBPanel / DeviationBadge 是 Pricing 模块导出的三大共享组件，设计目标是在「定价计算器（PricingManager）」与「报价编辑器（QuotationManager）」双处复用，保证双轨试算口径一致。组件本身不感知所处容器，通过回调契约与父级通信。

**组件职责边界**：
- **TrackAPanel**：轨道 A 成本分解估算，输出中位估算 USD（onMedianUsdChange）+ 完整输入（onInputsChange）
- **TrackBPanel**：轨道 B 退税美元定价，输出试算结果 TrackBResult（onResultChange）+ 有效输入 TrackBValidInputs（onInputsChange）
- **DeviationBadge**：纯展示组件，接收 finalUsd + medianUsd + medianUnit，前端 computePriceDeviation 计算偏差等级

**父级职责**：收集双轨回调数据 → 组装快照 → 提交后端 → 后端 calculatePriceDeviation 重算并落库。

## 二、两种集成模式

### 2.1 模式 A：创建表单内联嵌入

在报价编辑器创建表单第 2 分区，双轨面板与 DeviationBadge 内联渲染，试算结果随创建一并提交：

```tsx
<TrackAPanel onMedianUsdChange={(usd, unit) => setTrackAMedian(usd !== null && unit ? { usd, unit } : null)} />
<TrackBPanel onResultChange={setTrackBResult} />
<DeviationBadge finalUsd={trackBResult?.finalUnitPrice ?? null} medianUsd={trackAMedian?.usd ?? null} medianUnit={trackAMedian?.unit} isDarkMode={isDarkMode} />
```

**数据流**：用户在面板试算 → 回调更新 QuotationManager state → DeviationBadge 实时显示 → handleCreate 时组装 dualTrackSnapshot 提交。

### 2.2 模式 B：已保存报价单「应用定价」modal

对已保存的 Draft 报价单，通过列表「应用定价」按钮打开 modal，二次写入双轨快照：

```tsx
<TrackAPanel onInputsChange={setPricingTrackA} onMedianUsdChange={() => {}} />
<TrackBPanel onResultChange={() => {}} onInputsChange={setPricingTrackB} />
```

**数据流**：modal 收集 TrackAInput + TrackBValidInputs → handleApplyPricing 调 financeV2Service.applyTrackPricing(quoteId, input) → 后端重算 + 写入快照 + 偏差分级 → pricingResult 展示 → 刷新列表。

**查询校验**：handlePricingCheck 调 getPricingCheck(quoteId) 读取已保存快照 + 偏差分级（不写入）。

## 三、数据流：用户输入→实时计算→偏差徽章→审批触发

```
┌─────────────────────────────────────────────────────────────────┐
│ 创建表单内联模式                                                  │
│                                                                 │
│  TrackAPanel                       TrackBPanel                  │
│  ┌──────────────┐                  ┌──────────────┐            │
│  │ 用户输入成本  │                  │ 用户输入成本  │            │
│  │ → previewTrackA│                 │ → previewTrackB│           │
│  │ → TrackAResult │                 │ → TrackBResult │           │
│  └──────┬───────┘                  └──────┬───────┘            │
│         │ onMedianUsdChange(usd,unit)     │ onResultChange(result)│
│         ▼                                ▼                       │
│  setTrackAMedian({usd,unit})      setTrackBResult(result)       │
│         │                                │                       │
│         └────────────┬───────────────────┘                       │
│                      ▼                                           │
│              DeviationBadge                                      │
│              computePriceDeviation(finalUsd, medianUsd)          │
│              → { deviationPercent, level: ok|warn|block }        │
│              前端实时展示（不落库）                                │
└──────────────────────────────────┬──────────────────────────────┘
                                   │ handleCreate（保存报价）
                                   ▼
┌─────────────────────────────────────────────────────────────────┐
│ 服务端 quotationService.createQuotation()                       │
│  dualTrackSnapshot = { trackAMedianUsd, trackAUnit, trackBFinalUsd }│
│  ① trackAOk && trackBOk → calculatePriceDeviation(trackB, trackA)│
│  ② level=ok    → 正常落库                                        │
│     level=warn  → 同事务 ApprovalRequest(risk=medium, pending)    │
│     level=block → 同事务 ApprovalRequest(risk=high, pending)      │
│  ③ 落 6 字段快照：trackAMedianUsd/trackAUnit/trackBFinalUsd/     │
│     priceDeviationPercent/priceDeviationLevel/priceApprovalId    │
└──────────────────────────────────┬──────────────────────────────┘
                                   │ 发送报价（POST /:id/send）
                                   ▼
┌─────────────────────────────────────────────────────────────────┐
│ sendQuotation() 发送门禁                                         │
│  if priceDeviationLevel === 'block':                            │
│    查 ApprovalRequest.status                                    │
│    approved → 放行 / 其他 → throw → 409（门禁：price-deviation）  │
└─────────────────────────────────────────────────────────────────┘
```

## 四、回调契约详解

### 4.1 TrackAPanel Props

| Prop | 签名 | 触发时机 | 用途 |
|------|------|----------|------|
| onMedianUsdChange | (medianUsd: number \| null, unit?: 'PC' \| 'M') => void | result 变化时（useEffect 依赖 result） | 报价编辑器收集中位估算供 DeviationBadge + 快照 |
| onInputsChange | (input: TrackAInput \| null) => void | 任意输入变化时（useEffect 依赖全量输入） | modal 模式收集 TrackAInput 供 applyTrackPricing |

### 4.2 TrackBPanel Props

| Prop | 签名 | 触发时机 | 用途 |
|------|------|----------|------|
| onResultChange | (result: TrackBResult \| null) => void | preview 变化时（含输入变更导致的清空） | 报价编辑器收集终价供 DeviationBadge + 快照 |
| onInputsChange | (inputs: TrackBValidInputs \| null) => void | validInput 变化时（useEffect 依赖） | modal 模式收集 TrackBValidInputs 供 applyTrackPricing |
| title | string | — | 自定义标题（默认「轨道 B 试算（退税美元定价）」） |
| children | ReactNode | — | 额外输入字段（渲染于栅格末尾） |
| actions | ReactNode | — | 额外操作按钮（渲染于「试算预览」右侧） |

### 4.3 DeviationBadge Props

| Prop | 类型 | 说明 |
|------|------|------|
| finalUsd | number \| null | 轨道 B 终价美元单价 |
| medianUsd | number \| null | 轨道 A 中位估算美元单价 |
| medianUnit | string | 估算单位提示（PC/M） |
| isDarkMode | boolean | 主题（透传给 statusSemanticClass） |

DeviationBadge 内部 `computePriceDeviation` 与后端 `calculatePriceDeviation` 口径完全一致：`偏差 = (finalUsd − medianUsd) / medianUsd × 100`，Math.round 保留 2 位小数。

## 五、与 PricingManager 中使用的差异说明

| 维度 | PricingManager（定价计算器） | QuotationManager（报价编辑器） |
|------|------------------------------|-------------------------------|
| **使用模式** | 工作台主 tab，双轨面板常驻 | 创建表单内联分区 + 已保存报价 modal |
| **TrackAPanel 回调** | onMedianUsdChange（DeviationBadge 联动）+ onInputsChange（保存定价记录） | onMedianUsdChange（内联）+ onInputsChange（modal 模式） |
| **TrackBPanel 回调** | onResultChange（DeviationBadge 联动）+ onInputsChange（保存定价记录） | onResultChange（内联）+ onInputsChange（modal 模式） |
| **DeviationBadge** | 内联于双轨面板下方，实时联动 | 内联（创建表单）+ modal 结果区展示 pricingResult |
| **落库目标** | PricingCalculation 表（定价记录 CRUD） | Quotation 表 6 字段快照（历史快照，不随编辑变更） |
| **派生值重算** | calculateTrackB 服务端重算后落 PricingCalculation | calculatePriceDeviation 服务端重算后落 Quotation 快照 |
| **审批触发** | 不直接触发审批（定价记录独立） | warn/block 同事务自动生成 ApprovalRequest |
| **发送门禁** | 不涉及（定价记录无发送概念） | block 级 fail-closed 禁止发送 |
| **「保存定价记录」按钮** | TrackBPanel actions 槽位渲染 | 不渲染（报价无独立定价记录，快照随报价落库） |
| **标题** | TrackBPanel 默认标题 | 创建表单无自定义（用默认）；modal 无自定义 |
| **children 槽位** | 可选（数量/备注） | 未使用 |

**核心差异总结**：PricingManager 的双轨面板面向「定价记录管理」（CRUD + 状态流转 Draft→Confirmed→Archived），落 PricingCalculation 表；QuotationManager 的双轨面板面向「报价成本快照」（创建时一次性写入 + 偏差审批联动），落 Quotation 表 6 字段快照。前者是独立的定价工作台，后者是报价流程的内嵌成本依据。

## 六、偏差阈值与前后端同源

| 常量 | 值 | 前端导出 | 后端导出 |
|------|----|---------|---------|
| DEVIATION_WARN_PERCENT | 15 | DeviationBadge.tsx PRICE_DEVIATION_WARN_PERCENT | trackAEstimator.ts DEVIATION_WARN_PERCENT |
| DEVIATION_BLOCK_PERCENT | 30 | DeviationBadge.tsx PRICE_DEVIATION_BLOCK_PERCENT | trackAEstimator.ts DEVIATION_BLOCK_PERCENT |

**铁律**：阈值常量前后端同源，改动需双边同步。前端 `computePriceDeviation` 仅用于实时展示，不参与落库；后端 `calculatePriceDeviation` 是落库与门禁的唯一真源。

## 九、四态规范

| 状态 | 表现 | 实现路径 |
|------|------|----------|
| **空态** | DeviationBadge 返回 null（finalUsd 或 medianUsd 缺失/中位≤0） | computePriceDeviation 返回 null |
| **加载态** | 面板内 Loader2 animate-spin（previewing）+ 按钮 disabled | TrackAPanel/TrackBPanel previewing |
| **错误态** | alert 阻断式提示 + console.error | previewTrackA/B 失败 |
| **结果态** | DeviationBadge 三态展示：ok(绿✓)/warn(黄⚠)/block(红⛔) + 偏差百分比 + 阈值说明 | LEVEL_SEMANTIC 映射 |

## 十四、待补的设计缺口

| # | 缺口 | 影响 | 建议优先级 |
|---|------|------|-----------|
| 1 | 内联模式双轨快照仅创建时写入，编辑报价行不触发重算 | 改报价行后快照可能过时 | P2 |
| 2 | modal 模式 applyTrackPricing 后未自动关闭 modal | 用户需手动关闭 | P3 |
| 3 | TrackAPanel/TrackBPanel 在报价编辑器未与报价行面料联动 | 面料编码需在双轨面板重复输入 | P3 |
| 4 | DeviationBadge 前端计算与后端可能因浮点精度产生 ±0.01% 差异 | 边界值（恰好 15%/30%）前后端判定可能不一致 | P2（需统一精度处理） |
