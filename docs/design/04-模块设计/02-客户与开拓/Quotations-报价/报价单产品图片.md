# 报价单产品图片 (Quotation Product Images)

> **REQ2-12** · 痛度 28 · 来源 A4 缺口 · 批次三 B 级
> **甲方场景**：报价 PDF 含产品图是外贸报价单惯例（客户直观对色对款）；当前报价打印版式纯文字——这是报价链 L3 的唯一缺口。

## §1 元信息

| 项 | 值 |
|---|---|
| **模块名** | 报价行产品图片 |
| **定位** | 报价明细行挂面料照片/色卡图 → 打印版式嵌入缩略图列 |
| **核心实体** | QuotationLine.imageUrl（行级快照字段） |
| **需求编号** | REQ2-12（批次三 B 级） |
| **验收标准** | A4——报价 PDF 含产品图 |
| **关联代码** | schema.prisma QuotationLine / quotationService / quotationRoute（POST /line-image）/ QuotationManager（行图 UI + buildQuotationPrintHtml） |
| **依赖** | 数字档案图片体系既有（ProductImage/multer/uploads 静态服务）；printDocument 版式既有 |

---

## §2 关键设计决策（DR-053）

### DR-053-① 图片双通道：档案主图自动带出 + 行级手动上传

- **档案通道**：面料编码搜索选中数字档案面料时自动带出 `ProductAsset.imageUrl` 主图（零额外操作——有档案图的行开箱即有图）
- **手动通道**：行内上传（POST /v1/quotations/line-image，multer 落盘 `uploads/quotations/`，jpeg/png/webp/gif ≤10MB，返回 `/api/uploads/quotations/...` URL）——色卡扫描、临时实拍等无档案场景
- 手动上传优先于自动带出（已手动设图不被档案选中覆盖）

### DR-053-② 行级快照字段（报价历史不失真）

- `QuotationLine.imageUrl` 是**快照**而非活引用：数字档案后续换图/删图，已发报价单的图片不变（与 DunningRecord/colorCode 快照同哲学）
- 报价转订单不携带图片（订单行无图片域；转换链保持既有字段）

### DR-053-③ 打印版式向后兼容嵌入

- `buildQuotationPrintHtml`：任一行有图 → 表头插「Photo 图片」列（62px），有图行渲 54px 缩略图（object-fit:contain + 细边框），无图行渲染等宽占位保持对齐
- **整单无图 → 版式与既有完全一致**（不加空列）——存量报价单打印零变化

---

## §3 模块边界

| 包含 | 不包含 |
|------|--------|
| 行级图片（档案带出/手动上传/移除替换） | 图片裁剪/标注（增强） |
| 打印版式图片列（有图才启用） | 报价单邮件正文中内嵌图（邮件走链接，Outbox 域） |
| 上传落盘 + 静态服务复用 | 转订单图片携带（订单行无图域） |

---

## §4 数据模型

```prisma
// QuotationLine 增字段：
  // ─── REQ2-12 产品图片（DR-053-②：行级快照 URL） ───
  imageUrl String? // 面料照片/色卡图（/api/uploads/... 或外链）
```

---

## §5 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/v1/quotations/line-image` | multipart 单图上传（requireWrite JWT）→ `{ url }`；落盘 `uploads/quotations/` |
| POST/PUT | `/v1/quotations(/:id)` | lines[].imageUrl 随行提交（可选；创建与先删后建更新链路均落快照） |

---

## §6 前端（QuotationManager）

- **报价行表单**：面料编码旁图片格——空态「产品图」上传入口 / 有图缩略预览（hover 替换蒙层 + 角标移除）
- **档案联动**：选中档案面料自动填图（手动已设不覆盖）
- **打印**：有图单自动启用 Photo 列嵌入缩略图

---

## §7 验收标准

| 锚点 | 验证方式 |
|------|---------|
| A4 报价 PDF 含产品图 | API 验收：上传图 → 建报价行携 imageUrl → 落库 → 详情回读；打印 HTML 含 img 列（有图单）且无图单版式不变 |
