## §2 业务定位与目标

### 2.1 业务定位

外贸工具是 Bambook「**业务工具箱**」中已**收编至各主模块**的外贸专业计算/查询工具集合。原业务工具箱曾内嵌这些工具，阶段 IA-2 后改为**跳转卡**模式，由各主模块承载：

```
业务工具箱跳转卡 ──onNavigate(view, tab)──► Pricing / Customs / Risks 对应 tab
```

### 2.2 收编分工

| 工具 | 收编前 | 收编后落点 | 收编原因 |
| --- | --- | --- | --- |
| 报价计算器 | BusinessTools 内嵌 | Pricing/calculator | 与定价记录、利润表同属定价与利润域 |
| 退税核算汇率（退税率表） | BusinessTools 内嵌 | Pricing/taxRates | 退税率是定价 Track B 的核心输入 |
| 出运制单引擎 | BusinessTools 内嵌 | Customs/docGenerator | 依赖 Shipment 数据，属报关与退税域 |
| 单据模板管理 | BusinessTools 内嵌 | Customs/docTemplates | 模板服务于报关单据，属报关与退税域 |

汇率管理（FxPanel）则一直在 RisksManager 模块，因为汇率波动属于风险域。

### 2.3 核心目标

1. **专业聚合**：外贸专业工具按业务域归类，便于深度关联数据
2. **跳转深链**：业务工具箱仅保留跳转卡，避免数据/逻辑双写
3. **派生值单一真源**：定价/退税核算由后端单一计算，前端只展示
4. **状态机统一**：所有外贸单据/记录均走 Draft → Confirmed → Archived 等状态机
5. **外贸规则可配置**：HS Code 编码库、退税率表、汇率表、单据模板均可 CRUD 维护

### 4.2 跳转深链流程

```
用户点击跳转卡
  └─► handleToolClick(tool)
        └─► if (tool.targetView) onNavigate(tool.targetView, tool.targetTab)

父组件接收 onNavigate(view, tab)
  └─► setActiveView(view)
  └─► moduleTabOverrides.set(view, tab)  // 全局深链覆盖

目标模块挂载
  └─► const initialTab = moduleTabOverrides.get(View.Pricing) ?? 'calculator'
  └─► setActiveTab(initialTab)
  └─► moduleTabOverrides.delete(view)  // 消费一次即清除
```

### 4.3 深链机制设计

| 维度 | 说明 |
| --- | --- |
| 存储 | React 内存（moduleTabOverrides Map），不持久化 |
| 生命周期 | 设置后立即被目标模块消费一次并清除 |
| 失败回退 | 若目标模块不识别 tab id，回退到默认 tab |
| 多入口支持 | 报表下钻、业务工具跳转卡均使用同机制 |

## §5 报价计算器（Pricing/calculator）

### 5.1 双轨制架构

```
                    ┌─ Track A 系统推荐估算 ──► 估算售价区间
                    │   （按品类拆解成本，输出下限/中位/上限）
用户输入产品/成本/客户 ─┤
                    │                      ┌─ HS Code 查退税率
                    └─ Track B 退税美元定价 ─┤
                           （RMB → USD）    ├─ 最新汇率带入
                                            ├─ 实时派生值（后端重算）
                                            └─ 保存 PricingCalculation 记录
```

### 5.2 轨道 A 估算输入

| 字段 | 来源 | 用途 |
| --- | --- | --- |
| 品类（mainCategory） | 用户选择 | 决定成本拆解模板 |
| 原材料价格 | PriceHistory 表 | 自动带入最新价 + 用户可调 |
| 加工费 | 手填 | 工厂加工费 |
| 市场行情 | 手填 | 行业基准系数 |
| 来源标签 | 系统标注 | price-history / industry-benchmark / manual |

### 5.3 轨道 B 退税美元定价输入

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| hsCode | string | 10 位 HS Code，查 TaxRefundRate |
| fabricCost | number | RMB 面料成本 |
| processingCost | number | RMB 加工费 |
| quantity | number | 数量 |
| latestFxRate | number | 最新 USD→CNY 汇率（一键带入） |
| profitMargin | number | 期望利润率 % |
| commissionRate | number | 佣金率 % |

### 5.4 派生值（后端重算）

```typescript
// PricingCalculation 派生字段（前端只展示，不本地计算）
interface TrackBResult {
  refundRate: number;          // 退税率 %
  netRmbCost: number;          // 净 RMB 成本（扣除退税）
  netUsdCost: number;          // 净 USD 成本
  finalUnitPrice: number;      // 最终 USD 单价（含利润+佣金）
  totalAmount: number;         // 总金额
  // ...
}
```

派生值一律以后端返回为准，避免双端算法漂移。

### 5.5 PricingCalculation 状态机

```
Draft ──confirm──► Confirmed ──archive──► Archived
  │                    │
  └──edit (回退)──────┘
```

| 状态 | 中文 | 徽章变体 | 可执行操作 |
| --- | --- | --- | --- |
| Draft | 草稿 | neutral | 编辑 / 确认 / 删除 |
| Confirmed | 已确认 | success | 归档 / 回退到草稿 |
| Archived | 已归档 | neutral | 查看（不可编辑） |

### 5.6 关联 apiService 接口

| 接口 | 用途 |
| --- | --- |
| `apiService.calculateTrackB(inputs)` | 轨道 B 派生值实时预览（POST） |
| `apiService.savePricingCalculation(input)` | 保存定价记录 |
| `apiService.updatePricingCalculation(id, patch)` | 更新定价记录（含状态流转） |
| `apiService.listPricingCalculations(filters)` | 列表查询 |
| `apiService.listMaterialPriceHistory(filters)` | Track A 原材料价格历史 |

## §6 退税率表与 HS Code 查询（Pricing/taxRates）

### 6.1 TaxRefundRate 模型

```prisma
model TaxRefundRate {
  id          String   @id // 格式：TRR__${shortId}
  hsCode      String   @unique // 支持 2/4/6/8/10 位编码
  rate        Decimal  @db.Decimal(8, 4) // 退税率百分比（13 = 13%）
  description String?
  isActive    Boolean  @default(true)
  createdAt   BigInt
  updatedAt   BigInt
  deletedAt   BigInt?
  @@index([isActive])
}
```

### 6.2 最长前缀命中算法

```typescript
// 服务端 lookupTaxRefundRate(code) 伪代码
const prefixes = [10, 8, 6, 4, 2];  // 依次尝试
for (const len of prefixes) {
  const prefix = code.slice(0, len);
  const hit = await prisma.taxRefundRate.findFirst({
    where: { hsCode: prefix, isActive: true, deletedAt: null }
  });
  if (hit) return hit;
}
return null;  // 全部未命中
```

| HS Code 长度 | 用途 |
| --- | --- |
| 10 位 | 精确商品（如 5407520000 染色平纹布） |
| 8 位 | 子类 |
| 6 位 | 章/品目 |
| 4 位 | 章 |
| 2 位 | 大类 |

## §7 汇率管理（Risks/FxPanel）

### 7.1 ExchangeRate 模型

```prisma
model ExchangeRate {
  id            String  @id // 格式：FXR__${shortId}
  currency      String // USD | EUR | HKD ...（归一化大写）
  rate          Decimal @db.Decimal(18, 8) // 1 单位外币兑 CNY
  effectiveDate String // 生效日期 YYYY-MM-DD
  source        String  @default("manual") // manual | api
  note          String?
  createdAt     BigInt
  @@index([currency, effectiveDate])
}
```

### 7.2 FxPanel 数据流

```
挂载 useEffect
  ├─► loadLatest() → getLatestFxRates() → 各币种最新汇率
  ├─► loadRates()  → listExchangeRates({ currency, limit: 100 })
  └─► loadLocks()  → listFxLocks()

用户录入汇率
  └─► addExchangeRate({ currency, rate, effectiveDate, note })
        └─► 成功后 refreshAll() 刷新三处数据

用户创建订单汇率锁定
  └─► addFxLock({ orderId, currency, rate, note })
        └─► 锁定后订单定价/利润表使用锁定汇率，不受后续波动影响
```

### 7.3 三类数据展示

| 区块 | 数据源 | 用途 |
| --- | --- | --- |
| 最新汇率卡片 | `getLatestFxRates()` | 各币种当前最新汇率，供 Track B 一键带入 |
| 历史汇率列表 | `listExchangeRates({ currency, limit })` | 按币种过滤的历史汇率记录 |
| 订单汇率锁定列表 | `listFxLocks()` | 已锁定的订单汇率（订单维度） |

### 7.4 FxRateLock 锁定机制

```prisma
model FxRateLock {
  id         String  @id // 格式：FXL__${shortId}
  orderId    String // 关联订单（snapshot FK）
  currency   String // 锁定币种（归一化大写）
  rate       Decimal @db.Decimal(18, 8) // 锁定汇率
  lockedAt   BigInt
  lockedById String?
  note       String?
  createdAt  BigInt
  deletedAt  BigInt?  // 软删
  @@index([orderId])
}
```

锁定后，订单的定价/利润表使用锁定汇率，不受后续 ExchangeRate 波动影响。适用于大额订单长期生产周期场景。

## §8 HS Code 商品编码库（Customs/hsCodes）

### 8.1 数据模型

HS Code 商品编码库由 CustomsDeclaration 关联，维护完整的商品编码字典：

| 字段 | 说明 |
| --- | --- |
| hsCode | 10 位 HS Code |
| chineseName | 中文品名 |
| englishName | 英文品名 |
| unit | 法定计量单位 |
| refundRateId | 关联 TaxRefundRate（可选） |

### 8.2 关联 TaxRefundRate

HS Code 商品编码库与退税率表通过 hsCode 字段松散关联：
- HS Code 编码库记录商品信息（品名/单位/分类）
- TaxRefundRate 记录退税率（按 hsCode 唯一）
- 同一 hsCode 在两表中可同时存在，查询时分别返回

## §10 退税申报（Customs/taxRefunds）

### 10.1 TaxRefund 状态机

```
Draft ──submit──► Submitted ──approve──► Approved ──pay──► Paid
                       │
                       └──reject──► Rejected
```

| 状态 | 中文 | 说明 |
| --- | --- | --- |
| Draft | 草稿 | 录入未提交 |
| Submitted | 已申报 | 已提交税局 |
| Approved | 已审批 | 税局审批通过 |
| Rejected | 已驳回 | 税局驳回 |
| Paid | 已到账 | 退税款已到账 |

### 10.2 退税额核算公式

```
退税额 = FOB 金额 × 汇率 × HS 退税率（加权平均）

  FOB 金额 = 出口商品离岸价（USD）
  汇率 = 报关单申报日汇率
  HS 退税率 = 按商品 HS Code 查 TaxRefundRate（多商品时按金额加权）
```

由后端 customsService 核算，前端只展示结果。触发场景：
- 报关单状态变为「已放行」时，自动创建 Draft 退税申报（由 L10 自动化规则触发）
- 用户手动在 Customs/taxRefunds tab 创建 Draft

| PL | Packing List 装箱单 | ✅ | 常规出口必出 |
| CO | Certificate of Origin 原产地证 | ✅ | 常规出口必出 |
| BL | Bill of Lading Draft 提单补料 | ✅ | 常规出口必出 |
| FORMA | GSP Form A 普惠制产地证 | ❌ | 目的国享受 GSP 时 |
| INS | Insurance Policy 保险单 | ❌ | CIF/CIP 条款下 |
| BC | Beneficiary's Certificate 受益人证明 | ❌ | 信用证交单时 |

### 11.2 数据流

```
选择运单 Shipment
  └─► GET /v1/shipping/:id/document-set
        └─► 服务端多源装配 DocumentSetData
              ├─ shipment 基本信息
              ├─ order 关联订单
              ├─ customs declaration 报关信息
              ├─ items 装箱明细
              └─ extras
                  ├─ insurance（保额 → 智能预勾选 INS）
                  └─ letterOfCredit（存在 → 智能预勾选 BC）

勾选单据类型 → 点击生成
  └─► 遍历 selectedDocs
        └─► EXPORT_DOC_RENDERERS[kind].render(docSet)
              └─► 生成 HTML
                    └─► printHtmlDocument({ title, htmlBody })
                          └─► 多文档错开 500ms 打开（避免浏览器合并弹窗）
```

### 11.3 智能预勾选

```typescript
// 选中运单后自动调整勾选状态
setSelectedDocs(prev => ({
  ...prev,
  INS: data.extras.insurance.insuredAmount !== null,  // 有保额 → 勾选保险单
  BC: data.extras.letterOfCredit !== null,            // 有信用证 → 勾选受益人证明
}));
```

CI/PL/CO/BL 常规默认勾选；FORMA/INS/BC 按需智能预勾选。

## §13 已知限制与未来扩展

### 13.1 当前限制

- ❌ 汇率**无自动拉取**（source='api' 字段已预留，但无定时任务拉取）
- ❌ HS Code 商品编码库**无国标同步**（需手动维护）
- ❌ 退税申报**核算公式简化**（多商品加权算法未完整覆盖复杂场景）
- ❌ 单据模板**无版本管理**（覆盖式保存，无历史版本）
- ❌ 跳转卡**无快捷键**（只能点击跳转）
- ❌ 派生值**无缓存**（每次输入都触发后端重算，可能延迟）

### 13.2 未来扩展

- 接入央行/商业银行汇率 API 自动拉取（source='api'）
- HS Code 国标同步（海关编码库定期更新）
- 退税申报多商品加权算法完善
- 单据模板版本管理
- 派生值缓存 + 输入防抖优化
- 跳转卡快捷键（如 Alt+1 直接跳报价计算器）

## §14 实现备注

### 14.1 阶段 IA-2 收编原则

收编原则：「**有主模块的工具回归主模块，无主工具保留在业务工具箱**」。

| 工具 | 主模块 | 收编理由 |
| --- | --- | --- |
| 报价计算器 | Pricing | 与 PricingCalculation 数据强耦合 |
| 退税率表 | Pricing | 是 Track B 核心输入 |
| 出运制单 | Customs | 依赖 Shipment 数据 |
| 单据模板 | Customs | 服务于报关单据 |
| 汇率管理 | Risks | 汇率波动属风险域（一直在此模块） |
| HS Code 库 | Customs | 与报关单强关联 |
| 信用证 | Customs | 报关交单必备 |
| 退税申报 | Customs | 报关放行后触发 |

### 14.2 派生值单一真源原则

所有外贸计算派生值（退税额/USD 定价/利润等）**一律以后端返回为准**：

```typescript
// 前端只做输入与展示，不做本地派生计算
const handleInputChange = async (field, value) => {
  setInputs(prev => ({ ...prev, [field]: value }));
  // 防抖后调后端重算
  const result = await apiService.calculateTrackB(nextInputs);
  setDerivedResult(result);  // 直接展示后端返回值
};
```

避免双端算法漂移导致的数据不一致。

### 14.3 颜色与样式

所有外贸工具组件使用 BDS v2.1 token：

- `bds-card` / `bds-btn` / `bds-input` / `bds-badge` / `bds-tabs` / `bds-modal` 等
- 状态徽章用 `bds-badge` 语义变体（CALC_STATUS_BADGE_VARIANT）
- 主题透明无 `isDarkMode` 分支
