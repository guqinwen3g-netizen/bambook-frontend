## §2 业务定位与目标

### 2.1 业务定位

文档工具是 Bambook「**业务工具箱**」内的子分组——以**订单/客户/产品**为输入，按内置模板生成**外贸单据**，无需用户从零制单：

```
订单 / 客户 / 产品数据 ──► 文档生成器 ──► HTML / Excel / PDF
```

### 2.2 与出运制单引擎的分工

| 维度 | 文档工具（本页） | 出运制单引擎（Customs tab） |
| --- | --- | --- |
| 触发场景 | 业务员临时制单、未生成运单时 | 已有运单 Shipment 后批量成套制单 |
| 输入 | 手填或选订单/客户 | 已存在的 Shipment |
| 输出类型 | 单一文档（一份发票/一份合同/一份装箱单） | 成套单据（CI+PL+CO+BL+可选 FORMA/INS/BC） |
| 数据源 | props.orders/relations + 表单 | GET /v1/shipping/:id/document-set |
| 状态机 | 不入库（样品发票除外，存 BusinessProfile 历史） | DocumentRecord 入库 + 状态机 |

### 2.3 核心目标

1. **业务员友好**：从订单/客户预填，减少手输
2. **模板内置**：合同 7 条款、装箱单 11 列、发票字段均硬编码默认值，用户只需覆盖必要字段
3. **多输出格式**：HTML 预览 + PDF 打印 + Excel（发货通知由后端生成）
4. **不破坏数据真源**：文档工具只读业务数据，不写入业务表（仅 BusinessProfile 存模板/历史）
5. **可复用打印样式**：`BASE_PRINT_STYLES` 统一控制字体/边距/表格样式，确保跨文档视觉一致

### 5.5 发票号生成规则

```typescript
const generateInvoiceNumber = (date: Date): string => {
  const yy = String(date.getFullYear()).slice(-2);
  const mm = String(date.getMonth() + 1).padStart(2, '0');
  const dd = String(date.getDate()).padStart(2, '0');
  const seq = String(Math.floor(Math.random() * 90) + 10);  // 10-99
  return `PDAS${yy}${mm}${dd}${seq}`;  // 如 PDAS26081542
};
```

```

  └─► 卖方/买方从 relationOptions 选择（relations 过滤未删除）

  └─► 校验：至少卖方或买方 + 至少一行商品
        └─► 构造 htmlBody（含合同号/双方信息/明细表/合计大写/条款表/签字栏）
              └─► printHtmlDocument({ title, htmlBody }) 触发浏览器打印
```

### 7.2 合同类型差异

| 字段 | 销售合同 (sales) | 采购合同 (purchase) |
| --- | --- | --- |

| titleCn | 销售合同 | 采购合同 |

| 默认卖方 | getExporterProfile().nameEn | 用户从 relations 选择 |
| 默认买方 | 用户从 relations 选择 | 用户从 relations 选择 |

### 7.3 7 类标准条款默认值

| 条款 | 默认值 |
| --- | --- |
| Payment 付款方式 | T/T 30% deposit, 70% before shipment |
| Delivery 交货条款 | FOB Shanghai |
| Quality 品质条款 | 按买卖双方确认的样品品质为准，允许 ±5% 公差。 |
| Packing 包装条款 | 卷装出口，每卷 100 YD，外用编织袋包装，适合长途海运。 |
| Inspection 检验条款 | 买方须在货到后 15 天内提出品质/数量异议，逾期视为接受。 |
| Force Majeure 不可抗力 | 因战争、自然灾害等不可抗力导致无法履约，双方免除责任。 |
| Arbitration 仲裁 | 凡因本合同引起的争议，提交中国国际经济贸易仲裁委员会（CIETAC）按其规则仲裁。 |

### 9.2 printHtmlDocument 工作机制

```typescript
export function printHtmlDocument({ title, htmlBody, extraStyles = '' }): void {
  const win = window.open('', '_blank', 'width=900,height=700');
  if (!win) {
    alert('无法打开打印窗口，请检查浏览器弹窗拦截设置。');
    return;
  }
  win.document.write(`<!DOCTYPE html>...
    <title>${title}</title>
    <style>${BASE_PRINT_STYLES}${extraStyles}</style>
    <body>${htmlBody}
    <script>window.onload = function() { setTimeout(function() { window.print(); }, 300); };</script>
  `);
  win.document.close();
}
```

- 在 Electron 环境下，浏览器打印对话框可选择「保存为 PDF」
- 300ms 延迟确保 DOM 渲染完成后再触发打印

### 10.2 运行时合并

```typescript
export function getExporterProfile(): ExporterProfile {
  try {
    const raw = localStorage.getItem('panda_system_config');
    if (!raw) return EXPORTER_PROFILE;
    const parsed = JSON.parse(raw);
    const stored = parsed?.exporterProfile;
    if (!stored || typeof stored !== 'object') return EXPORTER_PROFILE;
    return { ...EXPORTER_PROFILE, ...stored };  // 浅合并，新增字段有默认回退
  } catch {
    return EXPORTER_PROFILE;
  }
}
```

## §13 已知限制与未来扩展

### 13.1 当前限制

- ❌ 文档工具**不入库**：除样品发票历史外，合同/装箱单/发货通知均不持久化到 BusinessProfile 或 DocumentRecord
- ❌ **无版本管理**：同一份合同多次生成不会保留历史版本
- ❌ **模板不可自定义**：合同 7 条款、装箱单 11 列均为硬编码默认值
- ❌ **发货通知依赖后端 Excel 服务**：若后端不可用，前端无法生成
- ❌ **样品发票 Logo/印章编辑需进入预览页**：表单页不可直接调整缩放位移
- ❌ **无多语言切换**：合同/装箱单默认中英双语，无法纯英文或纯中文输出
- ❌ **打印样式硬编码 hex**：BASE_PRINT_STYLES 使用 #1a202c 等颜色（豁免：打印 HTML 在系统窗口渲染，CSS 变量在打印窗口上下文不可靠）

### 13.2 未来扩展

- 文档生成后入库 DocumentRecord（与出运制单引擎统一状态机）
- 模板可配置（合同条款/装箱单列模板化）
- 多语言切换（纯英文/纯中文/中英双语）
- 样品发票编辑器与预览合并（所见即所得）
- 发货通知 Excel 模板可下载预填
- 合同/装箱单批量生成（一次选多订单生成多份）

### 14.2 样品发票 IPC 回退

```typescript
if (window.bambookInvoice?.savePdf) {
  await window.bambookInvoice.savePdf(html, filename);
} else {
  downloadFile(html, `${filename}.html`, 'text/html;charset=utf-8');
```

- Electron 主进程注册 `bambookInvoice.savePdf` IPC handler
- Web 环境无此 IPC，回退到下载 HTML 文件

### 14.3 乐观更新与防抖

样品发票模板字段编辑采用 500ms 防抖：

```typescript
const scheduleProfileSave = useCallback((nextTemplate) => {
  if (!selectedProfileId) return;
  if (profileSaveTimerRef.current) {
    window.clearTimeout(profileSaveTimerRef.current);
  }
  profileSaveTimerRef.current = window.setTimeout(() => {
    persistProfileTemplate(nextTemplate);
  }, 500);
}, [persistProfileTemplate, selectedProfileId]);
```

避免用户连续输入时频繁调用 saveBusinessProfile API。

### 14.4 颜色豁免范围

| 文件 | 豁免原因 |
| --- | --- |
| `printDocument.ts` BASE_PRINT_STYLES | 打印 HTML 在 window.open 新窗口渲染，CSS 变量在跨窗口上下文不可靠 |
| `FabricSampleInvoiceGenerator.tsx` 内 confirm/resizeHandle 内联 style | iframe 内动态创建的 overlay 元素，无法应用外层 CSS 变量 |

其余工具组件主体严格使用 BDS token，无硬编码 hex。
