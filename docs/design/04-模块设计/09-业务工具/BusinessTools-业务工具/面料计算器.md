## §2 关键设计决策（DR-062）

### DR-062-① 后端单一真源纯函数（非前端本地计算）

- 六类计算全部落在 `fabricCalculatorService.ts` 纯函数（无 DB 依赖、无状态）
- 前端 Panel 只做输入收集与结果展示，派生值一律以后端返回为准（对齐外贸工具 §14.2 派生值单一真源原则，避免双端算法漂移）
- 收益：单测可精确断言公式；后续 Agent 工具层可直接注册编排（面料计算是高频客服/跟单问答）

### DR-062-② 六类计算 kind 判别单端点

`POST /api/v1/tools/fabric-calculator/calculate`，body = `{ kind, ...input }`：

| kind | 计算名 | 输入 | 输出 |
|---|---|---|---|
| `weight-convert` | 克重换算 | gsm 或 ozyd + widthCm | 双向换算值 + 每米重量 g/m + 每公斤米数 + 每磅码数 |
| `yarn-convert` | 纱支换算 | value + from/to（Ne/D/Nm/tex） | 四制互转结果 |
| `theoretical-weight` | 理论克重 | 经密/纬密（根/in 或 根/10cm）+ 经/纬纱支（Ne 或 D）+ 织缩系数 | 理论克重 gsm + oz/yd² |
| `width-usage` | 门幅与用料 | 门幅 + 边损 + 克重 + 单件用料长 +（可选）净裁片面积 | 可裁门幅 + 每米重量 + 公斤米数 + 单件/千件用量 + 排料利用率 |
| `roll-length` | 卷装匹长 | 克重 + 门幅 + 卷重或匹长（二选一） | 匹长/卷重互推 + 码/磅换算 |
| `container-loading` | 装柜计算 | 柜型 + 卷径/卷宽/卷重（+克重/门幅推匹长）+ 装载率 | 按体积/按重量可装卷数 + 建议卷数 + 总米数/总重 + 约束维度 |

- 单端点理由：同一工具的六种子模式共享鉴权/校验/错误骨架；route 薄、service 厚
- 校验 fail-closed：非法 kind / 缺必填 / 负值 → 400 `VALIDATION_FAILED`（字段级 message）

### DR-062-③ 行业公式口径（固定常量，不做配置化）

| 常量 | 值 | 依据 |
|---|---|---|
| oz/yd² → g/m² | ×33.906 | 28.3495g ÷ 0.836127m² |
| Ne ↔ D（棉） | Ne = 590.5/D | 英支 840yd/lb × 0.9144 × 453.592 / 9000 |
| Nm ↔ D | Nm = 1000/D | 公制支数定义 |
| tex ↔ D | D = 9×tex | 旦尼尔/特克斯定义 |
| 理论克重 | gsm = (EPI/NeW + PPI/NeF) × 23.25 × 织缩系数 | 36×16/840×33.906（推导见 §3.3，40×40 133×72 府绸 ≈119 g/m² 实证） |
| 根/10cm → 根/in | ÷3.937 | 10cm = 3.937 in |
| 柜型（20GP/40GP/40HQ） | 内尺寸/容积/载重 | 行业通用规格（§3.6 表） |
| 卷体积 | π/4×D²×W（圆柱近似） | 卷装行业近似 |

- 公式常量属行业物理/贸易标准，不做 SystemConfig 配置化（与 REQ2-20 规则可配置形成对照：规则是公司策略可调，物理换算恒定）

## §3 公式明细

### §3.1 克重换算 weight-convert
```
ozyd = gsm / 33.906           gsm = ozyd × 33.906
每米重量 g/m = gsm × 门幅m     （门幅 cm ÷ 100）
每公斤米数 m/kg = 1000 / (gsm × 门幅m)
每磅码数 yd/lb = 453.592 / (g/m × 0.9144) = 496.06 / (gsm × 门幅m)
```

### §3.2 纱支换算 yarn-convert
```
D = 590.5 / Ne    Ne = 590.5 / D     （棉纱英支↔旦尼尔）
Nm = 1000 / D     tex = D / 9        （公支/特克斯）
Ne = 0.5905 × Nm                       （英支↔公支）
```

### §3.3 理论克重 theoretical-weight
```
oz/yd² = (EPI/NeW + PPI/NeF) × 24/35
gsm = oz/yd² × 33.906 × 织缩系数（默认 1.0；实际克重常比理论高 3-8%）
```
推导：1yd² 布 = 36in×36in；经纱共 36×EPI 根、每根 1yd → 经纱重 = 36×EPI/(NeW×840) lb；同纬。合计 lb/yd² = 36(EPI/NeW+PPI/NeF)/840。
实证：40×40/133×72 全棉府绸 → (3.325+1.8)×0.6857 = 3.51 oz/yd² ≈ 119 g/m²（行业公认 119-125）。
密度根/10cm 输入时先 ÷3.937；纱支 D 输入时先 590.5/D 转 Ne。

### §3.4 门幅与用料 width-usage
```
可裁门幅 = 门幅 − 边损（默认 3cm）
每米重量 g/m = gsm × 门幅m          （按全门幅计重——布边有重量）
每公斤米数 = 1000 / 每米重量
单件用量 kg = 每米重量 × 单件用料长 / 1000
千件用量 kg = 单件用量 × 1000；千件用料 m = 单件用料长 × 1000
排料利用率 = 净裁片面积 / (可裁门幅m × 单件用料长) × 100   （提供净面积时）
```

### §3.5 卷装匹长 roll-length
```
匹长 m = 卷重kg × 1000 / (gsm × 门幅m)      （by-weight）
卷重 kg = gsm × 门幅m × 匹长 / 1000          （by-length）
匹长 yd = 匹长 m / 0.9144；卷重 lb = 卷重 kg × 2.20462
```

### §3.6 装柜计算 container-loading
```
卷体积 m³ = π/4 × (卷径m)² × 卷宽m           （圆柱近似）
按体积可装 = floor(柜实用容积 × 装载率 / 卷体积)
按重量可装 = floor(柜载重 / 卷重)
建议卷数 = min(两者)；约束维度 = 体积或重量
总米数 = 建议卷数 × 匹长（提供克重/门幅时）；总重 = 建议卷数 × 卷重
```

| 柜型 | 内尺寸 m | 容积 m³ | 实用容积 m³ | 载重 kg |
|---|---|---|---|---|
| 20GP | 5.898×2.352×2.393 | 33.2 | 28 | 21,700 |
| 40GP | 12.032×2.352×2.393 | 67.7 | 58 | 26,700 |
| 40HQ | 12.032×2.352×2.698 | 76.4 | 68 | 26,580 |

## §4 API 合约

```
POST /api/v1/tools/fabric-calculator/calculate      （moduleAuthGuard：登录即可用——纯计算无敏感）
Request  { kind: 'weight-convert' | 'yarn-convert' | 'theoretical-weight'
         | 'width-usage' | 'roll-length' | 'container-loading', ...kind 专属字段 }
Response 200 { kind, ...计算结果 }（数值 round 2 位）
         400 { error: { code: 'VALIDATION_FAILED', message } }
```

## §5 前端结构

- BusinessTools.tsx 工具卡：`fabric-calculator`（icon: Ruler）→ 内嵌 FabricCalculatorPanel
- Panel 三 Tab（bds-segment）：
  - 克重与纱支：克重换算 / 纱支换算 / 理论克重 三卡
  - 门幅与用料：门幅与用料计算卡
  - 卷装与装柜：卷装匹长 / 装柜计算 两卡
- 输入即时计算（onBlur/onChange 防抖 300ms 调后端）；结果区只读展示后端返回值
- 表单控件一律 BDS：bds-input / bds-select（数值单位选择）
