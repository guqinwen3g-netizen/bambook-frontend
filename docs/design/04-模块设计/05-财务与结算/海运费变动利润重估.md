# 海运费变动利润重估 (Freight Re-estimation)

> **REQ2-14** · 痛度 24 · 来源 X-04 L0 · 批次三 B 级
> **甲方场景**（黑天鹅异常分支）：海运费暴涨 3 倍——出运成本重算 → 订单利润重估 → 已签合同是否可调价提示。当前 L0：运费重估/调价提示均无。
> **验收标准**：X-04——运费涨 3 倍录入后受影响订单利润变化一屏可见。

## §2 关键设计决策（DR-054）

### DR-054-① 重估即复用聚合真源（buildProfitOverview 抽取）

- 把 `generateOrderProfitSheet` 的聚合体（销售/采购/运费/杂费/内部交易 → 四维 CNY 汇总）抽成 `buildProfitOverview(orderId, freightMultiplier = 1)`
- **multiplier 仅作用于计算层**：运单四类费用金额 × multiplier 后再折 CNY，不改任何运单数据——重估是模拟（"如果运费涨 3 倍"），不是篡改
- 生成落库（multiplier=1）与重估（multiplier=N）走同一份聚合代码——杜绝两套口径漂移（P1-005 口径分裂的教训）

### DR-054-② 批量影响扫描（受影响 = 有活跃运费基数的活跃订单）

- 受影响范围：非终态订单（Cancelled/Delivered/Completed 排除）且存在活跃运单（非 Cancelled/软删）运费类费用 > 0——**有运费基数才谈重估**（未出运无运单的订单无基数，不在 X-04 场景内）
- 每单输出：baseline（已落库利润表优先——用户认过的口径；无则现场 ×1 计算）vs reestimated（×multiplier）
  - deltaProfit / deltaMargin / 新 grossProfit / 新 grossMargin
  - **renegotiate 建议**：利润转负（红·已签合同建议协商调价）/ margin 跌幅 > 10pt（黄·评估加价或成本转移）/ 其他（灰·可承受）
- summary：受影响单数 / 利润合计前后 / 变化额 / 转负单数

### DR-054-③ 重估是预览不是写（落库走既有真源）

- `GET /freight-impact?multiplier=3` 只读预览（读守卫）——重估结果不落任何表
- 真实运费到账后：运单费用更新（shipping 域既有）→ `POST /profit-sheets/generate/:orderId` 重生成（version+1）——链路既有，本模块零新增写路径
- 前端重估面板提供"按真实运费重生成"入口跳转语义（提示用户走既有生成）

## §3 模块边界

| 包含 | 不包含 |
|------|--------|
| 倍率模拟重估（×N 运费类费用：运费/保险/报关/其他） | 单运单运费编辑（shipping 域既有） |
| 批量受影响清单（前后对比 + 三级建议） | 自动批量重生成利润表（用户按单确认走既有生成） |
| 转负/margin 大跌预警 | 自动调价（调价走报价变更审批域） |

---

## §4 数据模型

无新表。复用：Shipment 四类费用字段（freightAmount/insuranceAmount/customsAmount/otherCharges + 币种）与 OrderProfitSheet（baseline 真源）。

---

## §5 API（挂 /api/v1/pricing，读守卫）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/freight-impact?multiplier=3` | 批量重估预览（不落库）：{ items: [{orderId, poNumber, customer, baseline, reestimated, deltaProfit, deltaMargin, advice}], summary } |
| GET | `/freight-impact?multiplier=3&orderId=X` | 单单重估（订单详情内嵌场景） |

multiplier ∈ (0, 100]；≤0 或非数 → 400。

---

## §6 前端（PricingManager 利润表 tab）

- **重估面板**：倍率 chips（1.5×/2×/3×/自定义输入）→ 受影响订单表
- 表列：PO / 客户 / 原利润（CNY）/ 新利润 / 变化额（红绿）/ 原毛利率 → 新毛利率 / 建议徽章（转负-红 renegotiate / 大跌-黄 / 可承受-灰）
- summary 头：受影响 N 单 · 利润合计 X → Y（Δ）/ 转负 N 单
- 一屏可见锚点：倍率一击 → 全量清单即时呈现

## §7 验收标准

| 锚点 | 验证方式 |
|------|---------|
| X-04 运费涨 3 倍录入后受影响订单利润变化一屏可见 | API 验收：构造带运费运单的订单 → multiplier=3 重估 → delta = −2×原运费CNY、转负单 renegotiate 建议、summary 聚合正确 |
| 重估口径与利润表同源 | multiplier=1 时重估结果 == generateOrderProfitSheet 落库值（同真源断言） |
