# 月末批量结转 (Monthly Close)

> **REQ2-17** · 痛度 22 · 来源 年度节奏 L0 · 批次四 C 级 · 成本 S-M
> **甲方场景**：月末财务一键结转——各报表（订单/发票/凭证/出运/增值税/付汇/退税）批量生成当月快照；下月看本月 vs 上月对比（行数/金额 Δ）。
> **验收标准**：报表快照批量生成 + 月度对比可视。

## §1 元信息

| 项 | 值 |
|---|---|
| **模块名** | 月末结转 Monthly Close |
| **定位** | 财务一键动作：monthly 报表定义批量快照（月末时点口径）+ 相邻期指标对比 |
| **核心实体** | 复用 ReportRun（快照真源）——零新表；幂等键 `mc:{definitionId}:{periodKey}` 前缀区隔 |
| **需求编号** | REQ2-17（批次四 C 级） |
| **关联代码** | server/src/reporting/monthlyCloseService.ts / route.ts /monthly-close* / FinanceReportsPanel 月末结转区块 |
| **依赖** | 报表引擎既有（runReportDefinition 幂等 + ReportRun rows 快照 + periodKeyFor monthly） |

## §2 关键设计决策（DR-058）

### DR-058-① 结转 = 月末时点存量快照（mc: 幂等键前缀区隔 A5 调度口径）

- A5 `scheduledReportRunner` 已每小时自动跑带 schedule 的定义——**monthly 在每月 1 日即跑当月周期键 `{id}:{YYYY-MM}`（月初口径）**
- 结转动作用 **`mc:{id}:{periodKey}`** 独立幂等键：财务在月末（或次月初）手动一键触发，periodKey 默认**上一个完整月**（8 月结转 2026-07）
- 快照 = 执行时点的存量报表状态（对账口径）；严格"当月发生额"需引擎时间窗注入，列增强（见 §4）
- 重复结转：同 periodKey 已有 mc: 快照 → skipped（幂等，不覆盖历史——append-only）

### DR-058-② 对比 = 相邻期 mc: 快照的 metric 汇总 diff

- GET /monthly-close/compare?periodKey=2026-07：对每个 monthly 定义取本期 `mc:{id}:2026-07` 与上期 `mc:{id}:2026-06` 的 Success run
- 每定义输出：metric 列（`agg(field)`）行值求和 → 本期/上期合计 + Δ + Δ%（上期为 0 时 Δ% = null 不除零）
- 缺期标注（上期无快照 → previous=null，提示先结转上月）

### DR-058-③ 零新表 + 审计留痕（复用不双轨）

- 快照真源 = ReportRun（既有）；结转汇总不落新表——结果可由 mc: 前缀幂等键即时派生
- 每次结转写审计（monthly_close_execute：periodKey/定义数/成功/跳过/失败）；单定义失败不阻断其余（与 A5 同语义）

## §3 API 合约（挂 /api/v1/reports，守卫 = requireJwtForWrite + requireRole('owner','admin','manager','finance')）

| 端点 | 方法 | 入参 | 出参 |
|---|---|---|---|
| `/monthly-close` | POST | `{ periodKey?: 'YYYY-MM' }`（默认上一个完整月） | `{ periodKey, total, ran, skipped, failed, results[{definitionId, name, datasetKey, runId, rowCount, skipped, error?}] }` |
| `/monthly-close/compare` | GET | `?periodKey=`（默认上一个完整月） | `{ periodKey, previousPeriodKey, items[{definitionId, name, datasetKey, current{runId, rowCount, totals}, previous{...}\|null, deltas[{metric, current, previous, delta, deltaPct}]}] }` |

错误码：`VALIDATION_FAILED`(400 periodKey 格式) / `NO_MONTHLY_DEFINITIONS`(404 无可结转定义)。

## §4 增强项（不阻塞验收）

- 当月发生额口径（时间窗注入引擎 filters，需 engine 扩展）
- 结转汇总单（打印版式）
- 对比图（柱状/趋势，BDS 图表组件）

## §5 验收锚点（scripts/acceptance-req2-17.mjs）

1. 无 monthly 定义 → 404 NO_MONTHLY_DEFINITIONS
2. 建 2 个 monthly 定义（orders/invoices）→ 结转 periodKey 当月 → 2 ran + ReportRun 快照落库（mc: 键）
3. 重复结转同 periodKey → skipped（幂等不覆盖）
4. 指定历史 periodKey 结转（补账）→ ran
5. 对比：本期 vs 上期（先结转两期）→ totals 精确（行数/金额 Σ）+ Δ/Δ% 正确；缺上期 → previous=null
6. periodKey 格式非法 → 400；权限：sales → 403
