## §2 只读工具四切片定位

只读工具遵循 P0-B 四切片语义的「never」切片——`approvalPolicy=never`、`risk=low`、无审批、无审计拦截，直接执行：

| 切片 | approvalPolicy | risk | 审批 | 审计 | 只读工具归属 |
|------|----------------|------|------|------|-------------|
| **never** | `never` | `low` | ❌ | ❌ | ✅ 本文档全部工具 |
| auto | `auto` | `medium` | ❌ | ✅ | knowledge.ingest |
| always | `always` | `high` | ✅ | ✅ | 写操作工具集 |
| flow | `always` + processSpec | `high` | ✅ | ✅ | 复合流程工具集 |

> **设计决策**：只读工具 `approvalPolicy=never` 意味着 LLM 可自主高频调用，不被审批阻塞。这是 Agent「先感知后决策」能力的基础——LLM 必须能自由查询业务数据才能规划下一步。

## §3 工具注册契约

每个只读工具在 `DEFAULT_AGENT_TOOLS` 中注册为 `DefaultToolDefinition`：

```typescript
{
  id: 'finance.get_aging',          // 全局唯一工具 ID
  name: 'Get AR/AP Aging Report',   // 人话名称
  scope: 'finance',                 // 权限域
  risk: 'low',                      // 风险等级
  allowedRoles: ['owner','admin','manager','finance','sales','merchandiser'],
}
```

同时在 `P0B_TOOL_DEFINITIONS` 中注册 `ToolDefinition`（含 JSON Schema）：

```typescript
{
  id: 'products.search',
  inputSchema: { type:'object', properties:{ query, mainCategory, filters, limit } },
  outputSchema: { type:'object', properties:{ candidates, total } },
  approvalPolicy: 'never',
}
```

`ensureDefaultAgentTools` 启动时 upsert 到 `AgentTool` + `AgentToolPermission` 表，`riskMode='direct'`（不走审批）。

## §4 产品域只读工具（products / dictionary / records）

### 4.1 工具清单

| toolId | 名称 | 入参 | 出参 | 说明 |
|--------|------|------|------|------|
| `products.count` | Count Product Assets | `{ query?, mainCategory?, filters? }` | `{ count, total }` | 按条件统计数字档案数量 |
| `products.search` | Search Product Assets | `{ query, mainCategory?, filters?, limit? }` | `{ candidates[], total }` | 短实体文本检索（SKU/品名） |
| `products.query` | Query Product Assets | `{ query?, mainCategory?, filters?, limit?, offset? }` | `{ items[], total, hasMore }` | 结构化条件查询（支持 40+ 字段过滤） |
| `products.get` | Get Product Asset | `{ id }` | `{ found, item, identifier }` | 按 ID 读取唯一数字档案 |
| `products.expand` | Expand Product Asset Context | `{ id, include[], limit? }` | `{ profile, pricing, certifications, composition, images, customerCodes, relations }` | 展开档案关联上下文 |
| `products.describe_schema` | Describe Product Asset Schema | `{}` | `{ fields[] }` | 返回 40+ 可过滤字段定义 |
| `dictionary.query` | Query Business Dictionary | `{ dictionary, query?, mainCategory? }` | `{ dictionary, items[], count }` | 查业务字典（productSubCategory 等） |
| `records.query` | Query Business Records | `{ entity, aggregate, query?, filters?, mainCategory? }` | `{ entity, aggregate, count, total }` | 按实体统计业务记录 |

### 4.2 可过滤字段（PRODUCT_FIELD_DEFINITIONS）

产品域支持 40+ 字段结构化过滤，覆盖面料/成衣/辅料三大子域：

| 子域 | 字段示例 | 操作符 |
|------|---------|--------|
| 基础 | sku, name, mainCategory, status, season | contains, equals |
| 面料 | fabric.articleNo, fabric.millQuality, fabric.construction, fabric.yarnCount, fabric.weightValue, fabric.widthValue, fabric.compositionTerm, fabric.priceAmount | contains, equals, gte, lte |
| 成衣 | garment.styleNo, garment.customer, garment.brand, garment.factory | contains, equals |
| 辅料 | trimming.trimmingCode, trimming.trimmingName, trimming.supplier | contains, equals |

### 4.3 expand 能力

`products.expand` 的 `include` 参数支持七维展开：
- `profile` — 基础档案
- `pricing` — 价格信息
- `certifications` — 认证许可
- `composition` — 成分构成
- `images` — 图片资源
- `customerCodes` — 客户编码映射
- `relations` — 关联实体（供应商/客户）

| `finance.query_outstanding` | Query Outstanding Balance | `{ relationId?, type? }` | `{ outstanding, byCurrency[] }` | 应收/应付敞口查询 |
| `finance.get_aging` | Get AR/AP Aging Report | `{ type?, asOf? }` | `{ buckets[], total }` | **账龄五桶分析** |
| `finance.get_statement` | Get Customer Statement | `{ customerRelationId, from?, to? }` | `{ statement, lines[] }` | 客户对账单快照 |

### 7.2 账龄分析（finance.get_aging）

`finance.get_aging` 对应 `reportService.getAgingReport`，返回五桶账龄分布：

| 桶 | 区间 | 预警 |
|----|------|------|
| 当前 | 0-30 天 | — |
| 31-60 天 | 31-60 天 | 关注 |
| 61-90 天 | 61-90 天 | 警告 |
| 91-180 天 | 91-180 天 | 逾期 |
| 180+ 天 | >180 天 | 坏账风险 |

> Agent 可基于账龄结果主动建议："客户 ABC 有 2 笔发票账龄超 90 天，建议催收或冻结门禁。"

### 7.3 客户对账单（finance.get_statement）

`finance.get_statement` 返回完整对账快照（发票 + 凭证 + 核销明细），是 `statement.send` 写操作工具 draftPhase 的数据源——"审批即所得"。

## §13 生产域只读工具（production）

### 13.1 工具清单

| toolId | 名称 | 入参 | 出参 | 业务对应 |
|--------|------|------|------|---------|
| `production.get_pipeline` | Get Production Pipeline | `{ orderId }` | `{ stages[], currentStage }` | 10 阶段生产管线状态 |
| `production.scan_alerts` | Scan Production Alerts | `{}` | `{ alerts[], count }` | **生产预警扫描** |

### 13.2 生产管线（production.get_pipeline）

返回订单的 10 阶段生产管线状态：
- 每阶段状态：`pending`/`done`/`skipped`
- 检查清单（裁剪前四项：放码/用量/样板/产前会）
- 验货报告（总数量/合格数量/合格率）
- 双签状态（产前样生产部+业务部）

### 13.3 生产预警扫描（production.scan_alerts）

扫描所有活跃订单的生产预警：
- 生产计划超期（当前阶段超出计划工期）
- 延期通知窗口临近（交期前 N 天未完成关键阶段）
