## §2 模块边界与职责

风险管理与合规模块是四维风险信号汇聚与处置中枢，其核心职责矩阵：

| 职责域 | 已实现 | 规划增强 | 上下游依赖 |
|--------|--------|----------|-----------|
| **统一预警中心** | ✅ RiskAlert raiseAlert 幂等入口（dedupKey @unique 先查兜底 P2002）+ 三段过滤（类型/等级/状态）+ 总览统计条（Open 按类型/级别分布）+ 状态机 Open→Acknowledged→Resolved | ⚠️ 预警指派/认领、SLA 时效 | 上游各 watchdog/手动触发；下游通知引擎 |
| **汇率管理 FX** | ✅ ExchangeRate 档案（append-only）+ 最新汇率卡片 + 波动预警（≥2% warning / ≥5% critical）+ FxRateLock 订单汇率锁定（同订单同币种唯一） | ⚠️ 汇率 API 自动拉取 | 上游手工录入；下游订单定价/结汇 |
| **信用管理 Credit** | ✅ CreditRating append-only 评级（A-D + 评分 0-100 + 因子快照）+ 按客户评估/历史查询 + runCreditRiskScan 批量冻结（逾期 >60 天冻结 Active 额度 + credit_frozen 预警）+ 坏账预警（逾期 >180 天 bad_debt） | ⚠️ 坏账计提台账、信用额度审批流 | 上游 Invoice 应收；下游 CreditLimit 冻结 |
| **合规管理 Compliance** | ✅ ComplianceCheck 三通道（HS Code 校验 / 出口管制禁运国 / 原产地规则人工登记）+ 检查记录列表 + fail 自动预警 | ⚠️ 认证预警（工厂资质到期）、HS Code 注册表自动同步 | 上游 CustomsDeclaration；下游出运门禁 |
| **质量风险管理 Quality** | ✅ DefectTrends 聚合（按工厂/季度分组 + 三级疵点 + 高频疵点词 Top5）+ runQualityRepeatScan 重复疵点扫描（近 90 天同工厂同疵点 ≥2 张报告 → quality_repeat 预警） | ⚠️ 疵点逐条录入、趋势图表可视化 | 上游 InspectionReport；下游工厂整改 |

## §4 核心数据模型速览

| 模型 | 主键格式 | 职责 | 软删 | 关键约束 |
|------|---------|------|------|---------|
| **RiskAlert** | `RSKA__${shortId}` | 统一风险预警（四维+扩展类型落地） | ❌ append-only | dedupKey @unique（幂等真源） |
| **ExchangeRate** | `FXR__${shortId}` | 汇率档案（外币→CNY） | ❌ append-only | @@index([currency, effectiveDate]) |
| **FxRateLock** | `FXL__${shortId}` | 订单汇率锁定 | ✅ deletedAt | 同订单同币种唯一未删除 |

## §5 四维风险体系

风险管理与合规围绕外贸企业经营的四类核心风险构建：

| 维度 | Tab | 风险本质 | 核心模型 | 处置手段 |
|------|-----|---------|---------|---------|
| **汇率风险 FX** | 汇率 FX | 外币波动侵蚀结汇利润 | ExchangeRate / FxRateLock | 录入汇率 → 波动预警 → 大额订单锁定汇率 |
| **信用风险 Credit** | 信用 Credit | 客户逾期/坏账导致应收损失 | CreditRating / CreditLimit | 实时评级 → 逾期扫描 → 自动冻结额度 + 坏账预警 |
| **合规风险 Compliance** | 合规 Compliance | HS 编码错误/出口管制违规/原产地不符 | ComplianceCheck / HsCode | 三通道检查 → fail 预警 → 出运前合规审批 |
| **质量风险 Quality** | 质量 Quality | 疵点重复出现/供应商质量下滑 | InspectionReport（聚合） | 趋势聚合 → 重复扫描 → 工厂整改预警 |

### 5.1 统一预警中心（四维汇聚）

四维风险产生的预警统一落地 RiskAlert，通过 `raiseAlert` 幂等入口写入：

```
raiseAlert({ type, level, title, content, relatedType, relatedId, dedupKey })
  │
  ├─ dedupKey @unique 先查 → 命中返回既有（created:false）
  ├─ DB 写入 → P2002 并发兜底再查 → 返回既有
  └─ 新建成功 → created:true（watchdog/通知引擎据此判断是否为新事件）
```

### 5.2 预警类型枚举（11 类）

| 类型 | 来源维度 | 触发方 |
|------|---------|--------|
| `fx_volatility` | 汇率 | addExchangeRate（波动 ≥2%） |
| `credit_frozen` | 信用 | runCreditRiskScan（逾期 >60 天冻结） |
| `bad_debt` | 信用 | runCreditRiskScan（逾期 >180 天） |
| `compliance_fail` | 合规 | runHsCodeCheck / runExportControlCheck |
| `quality_repeat` | 质量 | runQualityRepeatScan（90 天重复） |
| `sample_deadline` | 样品 | sampleDeadlineWatchdog |
| `hr_lifecycle` | 人事 | hrLifecycleWatchdog |
| `crm_follow_up_overdue` | 跟进 | crmFollowUpWatchdog |
| `lc_maturity` | 信用证 | lcMaturityWatchdog |
| `tax_refund_stall` | 退税 | taxRefundStallWatchdog |
| `factory_visit` | 验厂 | factoryVisitWatchdog |

## §6 预警状态机

```
Open ──(acknowledge)──▶ Acknowledged ──(resolve)──▶ Resolved
  │                                              ▲
  └──(resolve)──────────────────────────────────┘
```

| 状态 | bds-badge 变体 | 标签 | 可执行操作 |
|------|---------------|------|-----------|
| Open | warning | 未处理 | 确认 / 标记解决 |
| Acknowledged | info | 已确认 | 标记解决 |
| Resolved | success | 已解决 | — |

**状态流转校验**：
- acknowledge：Open → Acknowledged
- resolve：Open 或 Acknowledged → Resolved（写入 resolvedAt）
- Resolved 为终态，不可回退

**幂等语义**：dedupKey @unique 保证同一风险事件不会被重复告警；watchdog 日级触发时，已存在的 dedupKey 返回 `created:false`，不产生重复通知。

## §8 关键阈值常量

风险服务的风险判定阈值集中在 riskService.ts 顶部常量区，便于统一调参：

| 常量 | 值 | 含义 |
|------|---|------|

## §9 watchdog 日级巡检

信用风险与重复疵点由 scheduler 日级巡检自动触发，watchdog 本身只做日级触发去重，幂等由 RiskAlert.dedupKey 承担：

| watchdog | 触发时间 | 调用 | 幂等 dedupKey 模式 |
|---------|---------|------|-------------------|
| `credit_risk_watchdog` | 每日 10:00 后一次 | runCreditRiskScan | `credit_frozen:${limitId}:${dateKey}` / `bad_debt:${invoiceId}` |
| `quality_repeat_watchdog` | 每日 10:30 后一次 | runQualityRepeatScan | `quality_repeat:${mill}:${keyword}:${quarter}` |

## §10 与财务/订单/报关/QC 模块的联动

| 联动 | 方向 | 说明 |
|------|------|------|
| 汇率 → 订单定价 | FX → Pricing | 报价/订单结算可引用最新汇率或锁定汇率 |
| 信用评级 → 应收发票 | Invoice → Credit | CreditRating 因子（准时率/逾期/合作年限）实时取自 Receivable Invoice |
| 信用冻结 → 信用额度 | Credit → CreditLimit | runCreditRiskScan 将逾期 >60 天客户的 Active CreditLimit 批量置 Frozen |
| 合规检查 → 报关单 | CustomsDeclaration → Compliance | HS Code/出口管制检查以报关单为对象，读取 CustomsDeclarationLine |
| 质量趋势 → 验货报告 | InspectionReport → Quality | DefectTrends 聚合全量 InspectionReport，按 Order.millRelationId 分组到工厂 |
