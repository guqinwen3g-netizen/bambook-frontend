## §3 数据模型

### 3.1 ExchangeRate（汇率档案 — append-only）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id `FXR__${shortId}` | 主键 |
| currency | String | — | 币种（归一化大写 USD/EUR/HKD/GBP/JPY…） |
| rate | Decimal | @db.Decimal(18,8) | 1 单位外币兑 CNY |
| effectiveDate | String | YYYY-MM-DD | 生效日期 |
| source | String | @default("manual") | manual \| api |
| note | String? | — | 备注 |
| createdAt | BigInt | — | 录入时间戳 |

索引：`@@index([currency, effectiveDate])`。无软删（append-only 档案）。

### 3.2 FxRateLock（订单汇率锁定 — 软删）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id `FXL__${shortId}` | 主键 |
| orderId | String | — | 关联订单（snapshot FK） |
| currency | String | — | 锁定币种（归一化大写） |
| rate | Decimal | @db.Decimal(18,8) | 锁定汇率（外币→CNY） |
| lockedAt | BigInt | — | 锁定时间戳 |
| lockedById | String? | — | 锁定操作人 |
| note | String? | — | 备注 |
| createdAt | BigInt | — | 创建时间戳 |
| deletedAt | BigInt? | — | 软删时间戳（null=有效） |

索引：`@@index([orderId])`。软删（deletedAt 标记）。

## §4 录入汇率流程

```
用户填写（币种/汇率/生效日期/备注）
  │
  ├─ 校验：currency 非空 + rate > 0 + effectiveDate YYYY-MM-DD（缺省今日）
  │
  ▼
addExchangeRate(input, actorId)
  │
  ├─ 查同币种上一条（按 effectiveDate desc + createdAt desc）
  ├─ 写入 ExchangeRate（source 默认 manual）
  │
  ├─ prev 存在且 prevRate > 0 → 计算 deltaPct = (rate - prevRate) / prevRate * 100
  │   ├─ |deltaPct| >= 2 → raiseAlert
  │   │   ├─ level: |deltaPct| >= 5 ? critical : warning
  │   │   ├─ type: fx_volatility
  │   │   ├─ title: `${currency} 汇率波动 +X.XX%`
  │   │   ├─ content: 旧汇率→新汇率 + 幅度 + 结汇成本提示
  │   │   └─ dedupKey: `fx_volatility:${currency}:${effectiveDate}`
  │   └─ |deltaPct| < 2 → 不预警
  │
  └─ 返回汇率记录
```

**币种常量**：`FX_CURRENCIES = ['USD', 'EUR', 'HKD', 'GBP', 'JPY']`（前端下拉选项，后端不限制币种枚举，任意大写字母均可录入）。

## §5 波动预警双阈值

| 阈值常量 | 值 | 触发等级 | dedupKey |
|---------|---|---------|---------|
| `FX_WARN_PCT` | 2 | warning | `fx_volatility:${currency}:${effectiveDate}` |
| `FX_CRITICAL_PCT` | 5 | critical | 同上（level 由 absPct 决定） |

**幂等语义**：同一币种同一生效日期仅产生一条波动预警（dedupKey 去重）。若同日多次录入同币种汇率，第二次起 raiseAlert 返回 `created:false`，不重复告警。

**预警内容示例**：
> USD 汇率由 7.1234（2026-08-10）变动至 7.2850（2026-08-15），幅度 +2.27%，请关注在手订单结汇成本。

## §6 最新汇率聚合

`getLatestRates()` 取全部出现过的币种各一条最新汇率：

```
1. findMany 全量 ExchangeRate（按 effectiveDate desc + createdAt desc，take 1000）
2. 遍历去重：seen Set 记录已出现币种，首次出现即为该币种最新
3. 按 currency 字母序排序返回
```

前端以 4 列网格卡片展示：币种 + 来源 + 汇率（6 位小数）+ 生效日期。

## §7 订单汇率锁定流程

```
用户填写（订单号/币种/锁定汇率/备注）
  │
  ├─ 校验：orderId 非空 + currency 非空 + rate（可选，>0）
  │
  ▼
lockFxRate(input, actorId)
  │
  ├─ 查 Order（不存在/已软删 → 抛错）
  ├─ rate 缺省 → 查该币种最新 ExchangeRate（无可用 → 抛错）
  ├─ 查同订单同币种未删除锁定（已存在 → 抛错「该订单此币种已锁定汇率」）
  │
  └─ 写入 FxRateLock（lockedAt + lockedById）
```

**唯一性**：同订单同币种仅允许一个 `deletedAt: null` 的锁定。删除后可重新锁定。

**解除锁定**：`deleteFxLock(id)` 软删（deletedAt = now），不物理删除，保留审计痕迹。

## §9 API 端点

| 方法 | 路径 | 守卫 | 说明 |
|------|------|------|------|
| GET | `/api/v1/risk/fx-rates` | JWT/API-Key | 汇率列表（?currency&limit） |
| GET | `/api/v1/risk/fx-rates-latest` | JWT/API-Key | 各币种最新汇率（字面路由前置） |
| POST | `/api/v1/risk/fx-rates` | JWT（requireWrite） | 录入汇率（波动 ≥2% 自动预警） |
| GET | `/api/v1/risk/fx-locks` | JWT/API-Key | 汇率锁定列表（?orderId） |
| POST | `/api/v1/risk/fx-locks` | JWT（requireWrite） | 锁定汇率 |
| DELETE | `/api/v1/risk/fx-locks/:id` | JWT（requireWrite） | 解除锁定（软删） |

> 字面路由 `/fx-rates-latest` 须在参数化路由前注册（本路由无 `/fx-rates/:id`，仍保持字面前置约定）。

## §10 与订单/财务模块联动
