## §4 信用评级评分算法

### 4.1 因子计算（实时取自 Receivable Invoice）

```
evaluateCreditRating(relationId, actorId?)
  │
  ├─ 校验：relation 存在 + category=Customer
  ├─ 查全部 Receivable Invoice（type=Receivable, deletedAt=null）
  │
  ├─ 准时率 onTimeRate：
  │   ├─ settled = 已结清(Paid)且结算日可解析的发票
  │   ├─ onTime = settled 中结算日 ≤ 有效到期日的数量
  │   └─ onTimeRate = onTime / settled.length（settled 为空 → null）
  │
  ├─ 当前逾期 overdueCount / maxDaysOverdue：
  │   ├─ 遍历未结清（Issued/PartiallyPaid）发票
  │   ├─ effectiveDue = dueDate ?? issueDate + 30 天（Net 30 推定）
  │   ├─ days = (今日 - effectiveDue) / 天
  │   └─ days >= 1 → overdueCount++ + maxDaysOverdue = max(...)
  │
  ├─ 合作年限 cooperationYears：
  │   └─ (今日 - 最早开票日) / 365.25 天
  │
  ▼
评分（100 起扣）：
  score = 100
    - min(overdueCount * 10, 30)         // 当前逾期每张 -10，封顶 -30
    - (maxDaysOverdue > 60 ? 20 : 0)     // 逾期超 60 天 -20
    - (maxDaysOverdue > 180 ? 20 : 0)    // 逾期超 180 天 -20
    - (1 - onTimeRate) * 40              // 准时率不足扣分（null 不扣）
    - (cooperationYears < 1 ? 5 : 0)     // 合作不足 1 年 -5
  score = clamp(0, 100, round(score))
```

### 4.2 等级映射

| 评分区间 | 等级 grade | bds-badge 变体 | 含义 |
|---------|-----------|---------------|------|
| ≥85 | A | success | 优质客户 |
| 70-84 | B | info | 良好客户 |
| 55-69 | C | warning | 关注客户 |
| <55 | D | danger | 高风险客户 |

### 4.3 有效到期日推定（Net 30）

与 `receivableOverdueDetector` 同口径：

```
effectiveDueMs(dueDate, issueDate):
  ├─ dueDate 可解析 → 返回 dueDate
  ├─ dueDate 缺失 → issueDate + 30 天（NET30_DAYS）
  └─ 均无法解析 → null（无法判定逾期）
```

## §5 信用风险扫描

`runCreditRiskScan(today)` 由 watchdog（每日 10:00）与手动触发共用：

```
1. 查全部未结清 Receivable Invoice（Issued/PartiallyPaid）
2. 按客户分组计算最大逾期天数（无归属客户的发票无法冻结额度，但仍可记坏账）
3. 遍历客户：
   ├─ maxDays > 60 → 查其 Active CreditLimit
   │   ├─ 逐条 update status=Frozen
   │   ├─ frozenCount++
   │   └─ raiseAlert credit_frozen（critical）
   │       dedupKey = `credit_frozen:${limitId}:${todayKey}`（按日去重）
   └─ maxDays <= 60 → 跳过
4. 遍历单发票逾期 > 180 天：
   └─ raiseAlert bad_debt（critical）
       dedupKey = `bad_debt:${invoiceId}`（唯一，只报一次）
5. 返回 { frozenCount, badDebtCount }
```

**幂等语义**：
- credit_frozen：dedupKey 含 todayKey，同一额度同一天只报一次；次日若仍逾期会再次报警（提醒持续逾期）。
- bad_debt：dedupKey = `bad_debt:${invoiceId}`，永远只报一次（发票结清或核销后不再重复）。

## §6 信用额度状态机

```
            ┌───────── (扫描逾期>60天) ─────────┐
            ▼                                    │
Active ──(审批)──▶ Frozen ──(恢复)──▶ Active
  │                  │
  │(到期)            │(撤销)
  ▼                  ▼
Expired          Revoked
```

| 状态 | 含义 | 触发 |
|------|------|------|
| Active | 有效可用 | 审批通过 / 恢复 |
| Frozen | 冻结（不可新增授信） | runCreditRiskScan 逾期 >60 天 |
| Expired | 到期 | validTo 到期 |
| Revoked | 撤销 | 人工撤销 |
