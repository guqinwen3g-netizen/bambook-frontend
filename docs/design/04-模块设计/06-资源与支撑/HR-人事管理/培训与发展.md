## §2 模块边界与职责

| 职责域 | 已实现 | 规划增强 | 上下游依赖 |
|--------|--------|----------|-----------|
| **课程管理** | ✅ TrainingCourse CRUD（title + type Internal/External + instructor + startDate/endDate + capacity 名额上限 + status Planned/Ongoing/Completed/Cancelled + description + deletedAt 软删） | ⚠️ 在线课程、课程附件 | 上游人工创建；下游报名管理 |
| **课程状态流转** | ✅ updateTrainingCourse 状态校验（Planned→Ongoing→Completed / Planned/Ongoing→Cancelled） | ⚠️ 自动开课/结课提醒 | 上游 Planned；下游报名 |
| **报名管理** | ✅ enrollTraining（重复报名优先于容量检查 + capacity 名额校验 + P2002 幂等防重复 + 仅 Planned/Ongoing 可报名 + @@unique([courseId, userId])） | ⚠️ 批量报名、报名审批 | 上游 TrainingCourse/UserAccount；下游成绩录入 |
| **成绩录入** | ✅ updateEnrollment（status Enrolled/Completed/Absent/Cancelled + score 0-100 校验 + certificate 证书编号） | ⚠️ 在线考试、自动评分 | 上游 TrainingEnrollment；下游证书管理 |
| **课程查询** | ✅ listTrainingCourses（status 过滤 + deletedAt 软删过滤 + 聚合 enrolledCount/completedCount + listEnrollments 关联 displayName） | ⚠️ 培训报表导出 | 上游 TrainingCourse/Enrollment；下游管理报表 |
| **审计日志** | ✅ writeRouteAuditLog（所有写操作记录审计：create/update/delete course / enroll / update enrollment） | — | 上游路由操作；下游审计追溯 |

> **核心设计纪律**：报名校验采用"重复报名优先于容量检查"的语义优先级 — 先告知"已报名"而非"名额已满"，语义更准确。一人一课一报名（@@unique([courseId, userId])）防止重复报名，P2002 唯一约束异常捕获后转为 DUPLICATE_ENROLLMENT 业务错误。

## §3 数据模型

### 3.1 TrainingCourse（培训课程 — 软删）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id `course_${ts}_${rand}` | 主键 |
| title | String | — | 课程名称 |
| type | String | @default("Internal") | 类型：Internal（内部）/ External（外部） |
| instructor | String? | — | 讲师 |
| startDate | String? | YYYY-MM-DD | 开始日期 |
| endDate | String? | YYYY-MM-DD | 结束日期 |
| capacity | Int? | — | 名额上限（null=不限） |
| status | String | @default("Planned") | 状态：Planned / Ongoing / Completed / Cancelled |
| description | String? | — | 课程简介 |
| createdAt | DateTime | @default(now()) | 创建时间 |
| updatedAt | DateTime | @updatedAt | 更新时间 |
| deletedAt | BigInt? | — | 软删时间戳（null=未删除） |

关系：`enrollments TrainingEnrollment[]`（一对多，删除时级联 Cascade）。
索引：`@@index([status])`。软删：deletedAt 非空表示已删除，查询时 `where: { deletedAt: null }`。

### 3.2 TrainingEnrollment（培训报名/成绩记录 — 一人一课一报名）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id `enroll_${ts}_${rand}` | 主键 |
| courseId | String | — | 关联课程 |
| userId | String | — | 报名员工 |
| status | String | @default("Enrolled") | 状态：Enrolled / Completed / Absent / Cancelled |
| score | Float? | 0-100 | 成绩 |
| certificate | String? | — | 证书编号 |
| createdAt | DateTime | @default(now()) | 创建时间 |
| updatedAt | DateTime | @updatedAt | 更新时间 |

关系：`course TrainingCourse @relation(fields: [courseId], references: [id], onDelete: Cascade)`。
索引：`@@unique([courseId, userId])`（一人一课一报名）/ `@@index([userId])`。无软删（status Cancelled 替代删除）。

> **设计要点**：certificate 字段存储证书编号（非文件），支持外部培训证书编号登记。score 为 0-100 浮点数，支持小数评分（step=0.5）。

## §5 课程状态机

```
Planned ──(开课)──▶ Ongoing ──(结课)──▶ Completed
   │                   │
   │                   └──(取消)──▶ Cancelled
   │
   └──(取消)──▶ Cancelled
```

| 状态 | bds-badge 变体 | 可执行操作 | 可报名 | 说明 |
|------|---------------|-----------|--------|------|
| Planned | info（蓝） | 报名 / 开课 / 取消 | ✅ | 计划中，开放报名 |
| Ongoing | active（绿） | 报名 / 结课 / 取消 | ✅ | 进行中，仍可报名 |
| Completed | neutral（灰） | 录入成绩/证书 | ❌ | 已完成，终态 |
| Cancelled | danger（红） | — | ❌ | 已取消，终态 |

### 5.1 前端状态映射（TrainingTab.tsx）

```typescript
const courseSemantic = (status: string): StatusSemantic => {
  switch (status) {
    case 'Ongoing': return 'active';    // 绿
    case 'Planned': return 'info';      // 蓝
    case 'Completed': return 'neutral'; // 灰
    case 'Cancelled': return 'danger';  // 红
    default: return 'neutral';
  }
};
```

### 5.2 前端状态流转按钮

```typescript
// Planned → Ongoing（开课）
{selectedCourse.status === 'Planned' && (
  <button onClick={() => setCourseStatus(selectedCourse.id, 'Ongoing')}>开课</button>
)}
// Ongoing → Completed（结课）
{selectedCourse.status === 'Ongoing' && (
  <button onClick={() => setCourseStatus(selectedCourse.id, 'Completed')}>结课</button>
)}
// Planned/Ongoing → Cancelled（取消课程）
{(selectedCourse.status === 'Planned' || selectedCourse.status === 'Ongoing') && (
  <button onClick={() => setCourseStatus(selectedCourse.id, 'Cancelled')}>取消课程</button>
)}
```

## §7 报名校验流程

```
┌─────────────────────────────────────────────────────────────────┐
│  报名校验流程（enrollTraining）                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 课程存在性校验                                               │
│     ├─ 课程存在（COURSE_NOT_FOUND）                              │
│     └─ 未软删（deletedAt === null）                              │
│                                                                 │
│  2. 课程状态校验                                                 │
│     └─ status 须为 Planned 或 Ongoing（INVALID_TRANSITION）     │
│        （Completed/Cancelled 不可报名）                          │
│                                                                 │
│  3. 重复报名校验（优先于容量检查 — 语义更准确）                  │
│     ├─ course.enrollments.some(e => e.userId === userId)        │
│     └─ 命中 → DUPLICATE_ENROLLMENT（"该员工已报名此课程"）       │
│                                                                 │
│  4. 名额容量校验                                                 │
│     ├─ active = enrollments.filter(e => e.status === 'Enrolled' │
│        || e.status === 'Completed')                             │
│     ├─ capacity != null && active.length >= capacity            │
│     └─ 命中 → CAPACITY_FULL（"课程名额已满（N）"）               │
│                                                                 │
│  5. 创建报名记录                                                 │
│     ├─ db.trainingEnrollment.create                             │
│     ├─ P2002 唯一约束异常 → DUPLICATE_ENROLLMENT（兜底幂等）     │
│     └─ status 默认 Enrolled                                     │
│                                                                 │
│  6. 审计日志                                                     │
│     └─ writeRouteAuditLog（enroll_training）                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.1 容量统计口径

```typescript
// active 报名人数 = Enrolled + Completed（不含 Absent/Cancelled）
const active = course.enrollments.filter((e: any) => 
  e.status === 'Enrolled' || e.status === 'Completed'
);
if (course.capacity != null && active.length >= course.capacity) {
  throw new HrError('CAPACITY_FULL', `课程名额已满（${course.capacity}）`);
}
```

> **口径说明**：名额占用 = Enrolled（已报名待参训）+ Completed（已结业），Absent（缺席）和 Cancelled（取消）不占名额，允许补报。

### 7.2 聚合统计口径

```typescript
// listTrainingCourses 聚合
enrolledCount: c.enrollments.filter(e => e.status === 'Enrolled' || e.status === 'Completed').length,
completedCount: c.enrollments.filter(e => e.status === 'Completed').length,
```

> enrolledCount（报名人数）= Enrolled + Completed；completedCount（结业人数）= Completed。

### 8.1 未报名员工筛选

```typescript
// 未报名员工（picker）
const unenrolled = useMemo(() => {
  const enrolled = new Set(enrollments.map(e => e.userId));
  return personnel.filter(p => !enrolled.has(p.id));
}, [enrollments, personnel]);
```

> 筛选逻辑：从全体 personnel 中排除已有报名记录的 userId，确保一人一课一报名。注意：此处筛选包含所有已报名记录（含 Absent/Cancelled），与容量统计口径（仅 Enrolled+Completed）不同。

## §13 关键业务规则

| # | 规则 | 实现位置 |
|---|------|---------|
| 1 | **一人一课一报名** | `@@unique([courseId, userId])` + enrollTraining P2002 兜底 |
| 2 | **重复报名优先于容量检查** | enrollTraining 先查 `enrollments.some(e => e.userId === userId)` → DUPLICATE_ENROLLMENT，再查容量 |
| 3 | **仅 Planned/Ongoing 可报名** | enrollTraining 校验 `!['Planned', 'Ongoing'].includes(course.status)` → INVALID_TRANSITION |
| 4 | **名额占用 = Enrolled + Completed** | 容量校验 `active = enrollments.filter(e => e.status === 'Enrolled' \|\| e.status === 'Completed')` |
| 5 | **Absent/Cancelled 不占名额** | 容量统计排除 Absent/Cancelled，允许补报 |
| 6 | **课程软删** | deleteTrainingCourse 写入 `deletedAt = BigInt(Date.now())`，查询时 `where: { deletedAt: null }` |
| 7 | **已软删课程不可操作** | updateTrainingCourse 校验 `course.deletedAt` → COURSE_NOT_FOUND |
| 8 | **成绩范围 0-100** | updateEnrollment 校验 `score < 0 \|\| score > 100` → VALIDATION_FAILED |
| 9 | **课程状态限定四值** | updateTrainingCourse 校验 `!['Planned', 'Ongoing', 'Completed', 'Cancelled'].includes(status)` |
| 10 | **报名状态限定四值** | updateEnrollment 校验 `!['Enrolled', 'Completed', 'Absent', 'Cancelled'].includes(status)` |
| 11 | **课程类型限定两值** | createTrainingCourse 校验 `!['Internal', 'External'].includes(type)` |
| 12 | **课程删除级联** | `onDelete: Cascade`，删课程时报名记录级联删除 |
| 13 | **聚合统计** | listTrainingCourses 聚合 enrolledCount（Enrolled+Completed）/ completedCount（Completed） |

## §14 关键实现细节

### 14.1 enrollTraining（报名校验）

```typescript
async function enrollTraining(courseId: string, userId: string) {
  const course = await db.trainingCourse.findUnique({ 
    where: { id: courseId }, 
    include: { enrollments: true } 
  });
  if (!course || course.deletedAt) throw new HrError('COURSE_NOT_FOUND', `课程 ${courseId} 不存在`);
  if (!['Planned', 'Ongoing'].includes(course.status)) 
    throw new HrError('INVALID_TRANSITION', `课程已 ${course.status}，不可报名`);
  // 重复报名优先于容量检查（语义更准确：先告知"已报名"而非"名额已满"）
  if (course.enrollments.some((e: any) => e.userId === userId)) {
    throw new HrError('DUPLICATE_ENROLLMENT', '该员工已报名此课程');
  }
  const active = course.enrollments.filter((e: any) => 
    e.status === 'Enrolled' || e.status === 'Completed'
  );
  if (course.capacity != null && active.length >= course.capacity) {
    throw new HrError('CAPACITY_FULL', `课程名额已满（${course.capacity}）`);
  }
  try {
    const enrollment = await db.trainingEnrollment.create({
      data: { id: genId('enroll'), courseId, userId },
    });
    return { enrollment };
  } catch (e: any) {
    if (e?.code === 'P2002') throw new HrError('DUPLICATE_ENROLLMENT', '该员工已报名此课程');
    throw e;
  }
}
```

### 14.2 listTrainingCourses（聚合统计）

```typescript
async function listTrainingCourses(query: { status?: string } = {}) {
  const where: any = { deletedAt: null };  // 软删过滤
  if (query.status) where.status = query.status;
  const courses = await db.trainingCourse.findMany({
    where,
    include: { enrollments: true },  // 关联查询报名记录
    orderBy: { createdAt: 'desc' },
  });
  return courses.map((c: any) => ({
    ...c,
    enrolledCount: c.enrollments.filter((e: any) => 
      e.status === 'Enrolled' || e.status === 'Completed').length,  // 报名人数
    completedCount: c.enrollments.filter((e: any) => 
      e.status === 'Completed').length,  // 结业人数
    enrollments: undefined,  // 剥离明细，仅返回聚合
  }));
}
```

### 14.3 deleteTrainingCourse（软删）

```typescript
async function deleteTrainingCourse(id: string) {
  // 软删：写入 deletedAt 时间戳，非物理删除
  await db.trainingCourse.updateMany({ 
    where: { id, deletedAt: null }, 
    data: { deletedAt: BigInt(Date.now()) } 
  });
  return { deleted: true };
}
```

> **软删设计**：使用 `updateMany` 而非 `update`，确保即使记录已被软删（deletedAt 非空）也不会报错，保持幂等性。使用 BigInt 时间戳而非 DateTime，与项目其他软删字段口径一致。
