# 旺季舱位提醒 (Booking Lead Time Reminders)

> **REQ2-20** · 痛度 19 · 来源 X-09 L0 · 批次四 C 级 · 成本 S
> **甲方场景**：旺季（圣诞单集中出运）船公司舱位紧张，需提前 21 天订舱（平时 14 天）；订单交期临近才发现没订舱 → 误船期。
> **验收标准**：X-09——订舱提前期规则（旺季 21 天/平时 14 天）提醒。

## §2 关键设计决策（DR-061）

### DR-061-① 规则可配置 + fail-open 默认

- `SystemConfig` `global::shipping.bookingLeadTime`：`{ peakMonths: number[], peakDays: number, normalDays: number }`
- 默认：旺季 8/9/10 月 → 提前 **21** 天；平时 → **14** 天
- 配置缺失/非法（月超界/天数非正）/查询异常 → fail-open 回默认（提醒类能力不阻断出运域）

### DR-061-② 扫描口径（只读派生，零写路径）

- 候选订单：非 Cancelled/Closed 且有 dueDate
- **已安排出运跳过**：存在 ShipmentOrderAllocation（status ≠ Cancelled）即视为已安排（真源 DR-016，不看 shipment 单独状态）
- 需订舱日 = dueDate − leadDays（按 **dueDate 所在月**是否旺季取天数）；今天 ≥ 需订舱日 → 预警项
- 分级：`overdue`（已过交期）/ `urgent`（剩余 ≤3 天）/ `warning`；清单按剩余天数升序（最紧急在前）
- 建议文案区分旺季（舱位紧张立即订舱）/平时/过交期（加急或协商改期）

### DR-061-③ 挂出运页常显预警区块（S 级最小闭环）

- GET /api/v1/shipping/booking-reminders（登录即可读——预警属协同信息）
- ShipmentManager 列表顶部「舱位预警 BOOKING」区块：规则说明行（旺季月份/天数）+ 预警单列表（分级徽章/客户/PO/交期/旺季标/建议文案）；空态隐藏（零干扰）
- 调度通知（RiskAlert/Notification 日级幂等推送）与规则管理 UI 列增强

## §4 增强项

规则管理 UI（SystemConfig 设置页 logistics 组编辑）；调度推送（每日通知/风险台）；按船公司/航线差异化提前期。

## §5 验收锚点（scripts/acceptance-req2-20.mjs）

1. 默认规则（旺季 8/9/10 月 21 天/平时 14 天）回显
2. 旺月交期订单命中（leadDays=21 + 旺季建议文案）；平时订单 leadDays=14（剩余 3 天内 urgent）
3. 过交期 → overdue 分级；远期未到窗口不预警；清单按剩余天数升序
4. 建出运安排后从清单移除（软删恢复）
5. 未登录 401；登录即可读（QC 角色 200）
