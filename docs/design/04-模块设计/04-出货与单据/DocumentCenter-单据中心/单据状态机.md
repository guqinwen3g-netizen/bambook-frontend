## §4 6 态状态定义

| 状态 ID | 中文 | 语义 | 说明 |
|---------|------|------|------|
| Draft | 草稿 | neutral | 初始态，可编辑/可取消/可删除 |
| Issued | 已签发 | info | 正式签发，可提交/可取消 |
| Submitted | 已提交 | info | 已交单（L/C 场景），可接受/拒绝/取消 |
| Accepted | 已接受 | success | 终态，银行/对方接受 |
| Rejected | 已拒绝 | danger | 可退回 Draft 修改 |
| Cancelled | 已取消 | neutral | 终态，可删除 |

## §5 合法转换矩阵（DOC_TRANSITIONS）

```
                    ┌──────────┐
                    │  Draft   │ (草稿，可编辑)
                    └──┬───┬───┘
                       │   │
            签发        │   │ 取消
                       ▼   ▼
              ┌──────────┐  ┌──────────┐
              │  Issued  │  │ Cancelled│ (终态)
              │ (已签发) │  └──────────┘
              └──┬───┬───┘
                 │   │
        提交      │   │ 取消
                 ▼   ▼
        ┌──────────┐  ┌──────────┐
        │Submitted │  │ Cancelled│
        │(已提交)  │  └──────────┘
        └──┬─┬─┬───┘
           │ │ │
    接受    │ │ │ 拒绝
           │ │ ▼
           │ │ ┌──────────┐
           │ │ │ Rejected │ (可退回 Draft)
           │ │ │ (已拒绝) │
           │ │ └────┬─────┘
           │ │      │ 退回修改
           │ │      ▼
           │ │   Draft
           ▼ │
        ┌──────────┐
        │ Accepted │ (终态)
        │ (已接受) │
        └──────────┘
```

| from → to | 触发场景 | 业务含义 |
|-----------|---------|---------|
| Draft → Issued | 单证员签发 | 单据正式生效，不可再编辑 |
| Draft → Cancelled | 取消草稿 | 归档废弃 |
| Issued → Submitted | 交单（L/C 场景） | 提交银行/对方审核 |
| Issued → Cancelled | 取消签发 | 归档废弃 |
| Submitted → Accepted | 银行/对方接受 | 收汇/交单成功（终态） |
| Submitted → Rejected | 银行/对方拒绝 | 单证不符，需修改 |
| Submitted → Cancelled | 取消提交 | 归档废弃 |
| Rejected → Draft | 退回修改 | 回到草稿可编辑态 |

**终态**：Accepted / Cancelled（无下游转换）

## §6 前后端双校验机制

### 6.1 服务端 fail-closed（真源）

```typescript
// customsService.ts
const DOC_TRANSITIONS: Record<string, string[]> = {
  Draft: ['Issued', 'Cancelled'],
  Issued: ['Submitted', 'Cancelled'],
  Submitted: ['Accepted', 'Rejected', 'Cancelled'],
  Accepted: [],
  Rejected: ['Draft'],
  Cancelled: [],
};

function validateTransition(transitions, from, to, entityName): void {
  const allowed = transitions[from] || [];
  if (!allowed.includes(to)) {
    throw new Error(`非法${entityName}状态转换: ${from} → ${to}（允许: ${allowed.join(', ') || '无'}）`);
  }
}
```

服务端在 `transitionTradeDocumentStatus` 内调用 `validateTransition`，非法转换抛 409 错误。

### 6.2 前端镜像（放行合法流转）

```typescript
// DocumentCenter.tsx
const DOC_TRANSITIONS: Record<TradeDocumentStatus, TradeDocumentStatus[]> = {
  Draft: ['Issued', 'Cancelled'],
  Issued: ['Submitted', 'Cancelled'],
  Submitted: ['Accepted', 'Rejected', 'Cancelled'],
  Accepted: [],
  Rejected: ['Draft'],
  Cancelled: [],
};
```

前端仅渲染 `DOC_TRANSITIONS[currentStatus]` 中的目标状态按钮，fail-closed 不在前端放行非法流转。

### 6.3 双校验一致性保证

前后端 `DOC_TRANSITIONS` 必须保持一致。当前靠人工同步（非代码约束），已知风险：
- 后端新增合法转换时，前端需同步更新
- 若不一致，前端不放行的转换后端会拒绝（安全）；前端放行但后端拒绝的转换会返回 409（用户体验差但安全）

## §7 编辑/删除门禁

### 7.1 编辑门禁

```typescript
// customsService.ts updateTradeDocument
if (existing.status !== 'Draft') {
  throw new Error(`单据状态 ${existing.status} 不可编辑（仅 Draft 可编辑）`);
}
```

- 仅 Draft 可编辑字段
- Issued/Submitted/Accepted/Rejected/Cancelled 不可编辑
- Rejected 需先 `Rejected → Draft` 退回草稿才能编辑

### 7.2 删除门禁

```typescript
// customsService.ts deleteTradeDocument
if (existing.status !== 'Draft' && existing.status !== 'Cancelled') {
  throw new Error(`单据状态 ${existing.status} 不可删除（仅 Draft/Cancelled 可删除）`);
}
```

- 仅 Draft/Cancelled 可软删除
- 软删除设置 `deletedAt`，列表过滤 `deletedAt: null`
- 编号不回收（作废不回收原则）

## §8 版本留痕联动

状态机与版本留痕的联动关系：

| 状态转换 | 版本留痕 | 说明 |
|---------|---------|------|
| Draft（编辑） | ✅ 追加版本 | `updateTradeDocument` 同事务 `appendTradeDocumentVersion` |
| Draft → Issued | ❌ 不追加版本 | 状态转换不改字段内容，仅 status 变更 |
| Rejected → Draft | ❌ 不追加版本 | 退回草稿不改字段内容 |
| 任何 → Cancelled | ❌ 不追加版本 | 取消不改字段内容 |

> 版本留痕仅在**字段内容变更**时触发（创建/编辑），状态转换不触发版本留痕。状态变更的审计通过 AuditLog 记录（from/to）。

## §11 设计系统约束

- 状态徽章通过 `DOC_STATUSES` 映射 `statusSemanticClass` / `statusSemanticText`：
  - Draft/Cancelled → neutral
  - Issued/Submitted → info
  - Accepted → success
  - Rejected → danger
- 状态转换按钮用 `TRANSITION_LABELS` 文案（退回草稿/签发/提交/接受/拒绝/取消）
- 按钮仅渲染当前状态合法的下游态（`DOC_TRANSITIONS[doc.status]`）
- 操作中状态用 `actionLoading` 禁用按钮
- 禁止硬编码 hex/`rounded-[Npx]`/`box-shadow`
