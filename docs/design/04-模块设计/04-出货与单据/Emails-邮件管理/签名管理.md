## §3 多语言签名（zh/en/bilingual）

### 3.1 三语言定义

```ts
export type SignatureLanguage = 'zh' | 'en' | 'bilingual';

const LANGUAGE_LABELS: Record<SignatureLanguage, string> = {
  zh: '中文',
  en: '英文',
  bilingual: '中英双语',
};
const LANGUAGES: SignatureLanguage[] = ['zh', 'en', 'bilingual'];
```

### 3.2 语言校验

```ts
const VALID_LANGUAGES: SignatureLanguage[] = ['zh', 'en', 'bilingual'];

function validateLanguage(lang: string): asserts lang is SignatureLanguage {
  if (!VALID_LANGUAGES.includes(lang as SignatureLanguage)) {
    throw new Error(`非法签名语言: ${lang}`);
  }
}
```

非法语言抛错，路由层返回 400。

### 3.3 默认值

- 新建未指定 language → 默认 `'bilingual'`（中英双语，外贸通用）
- 新建未指定 isDefault → 默认 `false`
- 新建未指定 isActive → 默认 `true`

## §4 同语言默认签名唯一约束

### 4.1 事务内清除其他默认

```ts
async function applyDefaultUniqueness(tx: any, language: string, excludeId: string | null) {
  await tx.emailSignature.updateMany({
    where: {
      language,
      isDefault: true,
      deletedAt: null,
      ...(excludeId ? { id: { not: excludeId } } : {}),
    },
    data: { isDefault: false, updatedAt: now() },
  });
}
```

### 4.2 创建时应用

```ts
async function createSignature(input: EmailSignatureInput, actorId: string) {
  const item = await db.$transaction(async (tx: any) => {
    if (input.isDefault) await applyDefaultUniqueness(tx, language, null);  // 清除同语言其他默认
    const created = await tx.emailSignature.create({ data: { ... } });
    await tx.auditLog.create({ data: { action: 'EMAIL_SIGNATURE_CREATE', ... } });
    return created;
  });
  return item;
}
```

### 4.3 更新时应用

```ts
async function updateSignature(id, patch, actorId) {
  const nextLanguage = patch.language ?? existing.language;
  const item = await db.$transaction(async (tx: any) => {
    if (patch.isDefault === true) await applyDefaultUniqueness(tx, nextLanguage, id);  // excludeId=id 防自清
    const updated = await tx.emailSignature.update({ where: { id }, data: { ... } });
    await tx.auditLog.create({ data: { action: 'EMAIL_SIGNATURE_UPDATE', ... } });
    return updated;
  });
  return item;
}
```

**关键约束**：
- `excludeId` 防止更新自身时把自己也清除
- 同 language 下永远只有一个 isDefault=true
- 事务原子保证，并发安全

## §6 签名 CRUD

### 6.1 列表（listSignatures）

```ts
async function listSignatures(filter: { language?: string; includeInactive?: boolean } = {}) {
  const where: any = { deletedAt: null };
  if (filter.language) where.language = filter.language;
  if (!filter.includeInactive) where.isActive = true;
  const items = await db.emailSignature.findMany({
    where,
    orderBy: [{ isDefault: 'desc' }, { updatedAt: 'desc' }],  // 默认签名排前
  });
  return { items, total: items.length };
}
```

**排序规则**：`isDefault: 'desc'`（默认签名排第一）+ `updatedAt: 'desc'`（最近更新排前）。

### 6.2 详情（getSignature）

```ts
async function getSignature(id: string) {
  const item = await db.emailSignature.findFirst({ where: { id, deletedAt: null } });
  if (!item) throw new Error(`邮件签名 ${id} 不存在`);
  return item;
}
```

### 6.3 创建（createSignature）

校验链：
1. `validateLanguage(language)` 语言合法
2. `name` 非空 trim 后非空 → "签名名称必填"
3. `content` 非空 trim 后非空 → "签名内容必填"

事务内：
- 清除同语言其他默认（如 isDefault=true）
- 创建 EmailSignature + 写 AuditLog（EMAIL_SIGNATURE_CREATE）

### 6.4 更新（updateSignature）

校验链：
1. 签名存在且未软删
2. 如改 language，新 language 合法
3. 如改 name，非空
4. 如改 content，非空

事务内：
- 清除同语言其他默认（如 isDefault=true，excludeId=id）
- 更新 EmailSignature + 写 AuditLog（EMAIL_SIGNATURE_UPDATE）

### 6.5 软删除（deleteSignature）

事务内：
- 更新 `deletedAt: now()` + `updatedAt: now()`
- 写 AuditLog（EMAIL_SIGNATURE_DELETE）

## §7 校验规则

| 字段 | 规则 | 错误消息 |
|------|------|---------|
| `name` | 非空 trim 后非空 | "签名名称必填" / "签名名称不可为空" |
| `content` | 非空 trim 后非空 | "签名内容必填" / "签名内容不可为空" |
| `language` | 必须是 zh/en/bilingual | "非法签名语言: ${lang}" |
| `id` 存在性 | 详情/更新/删除时校验未软删 | "邮件签名 ${id} 不存在" |

## §14 数据模型

```prisma
model EmailSignature {
  id   String @id // 格式：ESIG__${shortId}
  name String // 签名名称（如 "默认英文签名"）

  language  String   @default("bilingual") // zh | en | bilingual
  content   String // 签名内容（HTML/文本，支持 {{variable}} 如 {{senderName}}）
  variables String[] // 自动从 content 解析（冗余存储供 UI 生成填写项）

  isDefault Boolean @default(false) // 同 language 下仅一个默认签名
  isActive  Boolean @default(true)

  notes     String?
  createdAt BigInt
  updatedAt BigInt
  deletedAt BigInt?

  @@index([language])
  @@index([isDefault])
  @@index([isActive])
}
```
