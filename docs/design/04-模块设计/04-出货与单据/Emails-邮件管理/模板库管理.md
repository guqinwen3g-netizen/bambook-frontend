## §3 5 场景标准模板定义

`STANDARD_EMAIL_TEMPLATES` 真源位于 [templateRoute.ts L91-L173](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/email/templateRoute.ts)：

| # | type | name | subject | 关键变量 |
|---|------|------|---------|---------|
| 1 | `quote` | 标准报价函 | `Quotation {{quotationNo}} — {{companyName}}` | `customerName`, `quotationNo`, `validUntil`, `senderName`, `companyName` |
| 2 | `payment_reminder` | 催款提醒函 | `Payment Reminder — Invoice {{invoiceNo}}` | `customerName`, `invoiceNo`, `amount`, `dueDate`, `senderName` |
| 3 | `delivery_notice` | 交期通知函 | `Delivery Schedule — Order {{orderNo}}` | `customerName`, `orderNo`, `deliveryDate`, `senderName` |
| 4 | `inspection_report` | 验货报告通知 | `Inspection Report — Order {{orderNo}}` | `customerName`, `orderNo`, `inspectionDate`, `result`, `senderName` |
| 5 | `greeting` | 节日问候函 | `{{festival}} Greetings from {{companyName}}` | `customerName`, `festival`, `senderName`, `companyName` |

**正文模板示例（标准报价函）**：
```
Dear {{customerName}},

Thank you for your inquiry. Please find our offer as follows:

Quotation No.: {{quotationNo}}
Valid Until: {{validUntil}}

Detailed pricing and terms are attached. Should you have any questions, please feel free to contact us.

Best regards,
{{senderName}}
{{companyName}}
```

**特征**：
- 全部英文模板（外贸对外主语言）
- 每个模板含 4-5 个变量，覆盖客户名/单号/日期/金额等核心字段
- `senderName` / `companyName` 在签名中也会出现，便于复用

## §4 模板 CRUD 与播种

### 4.1 幂等播种（seedStandardEmailTemplates）

```ts
export async function seedStandardEmailTemplates(prisma, actorId?) {
  for (const tpl of STANDARD_EMAIL_TEMPLATES) {
    const existing = await db.emailTemplate.findFirst({
      where: { type: tpl.type, name: tpl.name, deletedAt: null }
    });
    if (existing) { skipped += 1; continue; }
    await db.emailTemplate.create({
      data: {
        id: generateTemplateId(),  // EMTPL__${shortId}
        type: tpl.type, name: tpl.name, subject: tpl.subject, body: tpl.body,
        variables: extractTemplateVariables(tpl.subject, tpl.body),
        isActive: true, createdAt: BigInt(now), updatedAt: BigInt(now),
      }
    });
    created += 1;
  }
  return { created, skipped, total: STANDARD_EMAIL_TEMPLATES.length };
}
```

**幂等约束**：同 `type + name` 已存在则跳过（不覆盖），保证多次播种安全。
**触发点**：
1. 服务启动自动播种（保证模板库开箱有数，前端不成空壳）
2. `POST /api/v1/email-templates/seed` 手动触发

### 4.2 新建模板（POST /）

```ts
router.post('/', requireWrite, async (req, res) => {
  const { type, name, subject, body } = req.body;
  if (!name || !subject || !body) return 400 INVALID_INPUT;
  if (!TEMPLATE_TYPES.includes(type)) return 400 INVALID_TYPE;
  const item = await db.emailTemplate.create({
    data: {
      id: generateTemplateId(), type, name, subject, body,
      variables: extractTemplateVariables(subject, body),  // 自动解析
      isActive: true, ...
    }
  });
  res.status(201).json({ ok: true, item });
});
```

### 4.3 更新模板（PATCH /:id）

```ts
router.patch('/:id', requireWrite, async (req, res) => {
  const existing = await db.emailTemplate.findFirst({ where: { id, deletedAt: null } });
  if (!existing) return 404 NOT_FOUND;
  const nextSubject = body.subject !== undefined ? body.subject : existing.subject;
  const nextBody = body.body !== undefined ? body.body : existing.body;
  // 改文本时重解析 variables
  if (body.subject !== undefined || body.body !== undefined) {
    data.variables = extractTemplateVariables(nextSubject, nextBody);
  }
  const item = await db.emailTemplate.update({ where: { id }, data });
  res.json({ ok: true, item });
});
```

## §5 变量自动解析

### 5.1 共享库 extractTemplateVariables

真源 [lib/templateVariables.ts](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/lib/templateVariables.ts)，邮件模板与单据模板、签名模板**同口径**：

```ts
// 正则：匹配 {{variableName}} 占位符
const re = /\{\{\s*([a-zA-Z_][a-zA-Z0-9_]*)\s*\}\}/g;
```

### 5.2 前端同口径实现

```ts
// services/emailIntelligenceService.ts
export function extractTemplateVariables(...texts: string[]): string[] {
  const seen = new Set<string>();
  const out: string[] = [];
  for (const text of texts) {
    const re = /\{\{\s*([a-zA-Z_][a-zA-Z0-9_]*)\s*\}\}/g;
    let m: RegExpExecArray | null;
    while ((m = re.exec(text)) !== null) {
      if (!seen.has(m[1])) { seen.add(m[1]); out.push(m[1]); }
    }
  }
  return out;
}
```

**前后端口径一致**：前端解析展示用、后端解析落库用，正则相同，保证 UI 生成的填写项与 DB 冗余存储一致。

### 5.3 变量渲染 renderEmailTemplate

```ts
export function renderEmailTemplate(text: string, vars: Record<string, string>): string {
  return text.replace(/\{\{\s*([a-zA-Z_][a-zA-Z0-9_]*)\s*\}\}/g, (_, name) => vars[name] ?? `{{${name}}}`);
}
```

- 未填变量保留占位符（`{{name}}`），不静默清空
- 前端表单输入实时联动渲染（详见 [邮件编辑器 §4](./邮件编辑器.md)）

## §6 AI 生成模板草稿

### 6.1 端点契约

```ts
// POST /api/v1/email-templates/ai-generate
// 入参
interface AiTemplateInput {
  scenario: string;     // 业务场景描述
  type?: string;        // 模板类型（可选，默认 general）
  language?: 'zh' | 'en' | 'auto';
  tone?: string;        // 语气（formal/casual/...）
  hints?: string;       // 额外提示
}
// 出参（不落库，确认后走 POST / 保存）
interface AiTemplateDraft {
  name: string;
  type: string;
  subject: string;
  body: string;
  variables: string[];
}
```

### 6.2 前端调用

```ts
export async function generateEmailTemplateWithAI(
  input: AiTemplateInput, endpoint?: string
): Promise<AiTemplateDraft> {
  const res = await postWithJwt<{ ok: boolean; draft: AiTemplateDraft }>(
    '/v1/email-templates/ai-generate', input, endpoint
  );
  return res.draft;
}
```

**守卫**：必须 JWT（`postWithJwt`）；AI 调用走 ARK 网关（`createDefaultEmailLlm`），测试可注入 mock LlmCompleter。

### 6.3 不落库原则

AI 草稿**不直接落库**，返回给前端预览；用户确认后走既有 `POST /api/v1/email-templates` 保存，保证人审校对环节。

### 7.1 端点

```ts
// POST /api/v1/email-templates/:id/use
// 低风险计数端点，守卫口径同读（JWT 或 API-Key），不强制 JWT 写
router.post('/:id/use', async (req, res) => {
  const existing = await db.emailTemplate.findFirst({ where: { id, deletedAt: null } });
  if (!existing) return 404;
  const item = await db.emailTemplate.update({
    where: { id },
    data: { usageCount: (existing.usageCount || 0) + 1, lastUsedAt: BigInt(now), updatedAt: BigInt(now) },

  res.json({ ok: true, usageCount: item.usageCount, lastUsedAt: now });
});
```

## §8 校验规则

| 字段 | 规则 | 错误码 |
|------|------|--------|
| `type` | 必须是 `TEMPLATE_TYPES` 之一 | `INVALID_TYPE` |
| `name` | 非空 trim 后非空 | `INVALID_INPUT` |
| `subject` | 非空 trim 后非空 | `INVALID_INPUT` |
| `body` | 非空 trim 后非空 | `INVALID_INPUT` |
| `id` 存在性 | PATCH/DELETE 时校验未软删 | `NOT_FOUND` |

`TEMPLATE_TYPES = ['quote', 'payment_reminder', 'delivery_notice', 'inspection_report', 'greeting', 'general']`。
