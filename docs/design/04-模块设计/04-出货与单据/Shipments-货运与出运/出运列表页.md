## §3 筛选栏

### 3.1 模糊搜索

| 项 | 说明 |
|---|---|
| 输入框 | `bds-input sm` + Search 图标（左 padding 9） |
| 占位符 | "运单号 / 收货方" |
| 过滤字段 | shipmentNumber / customerName / carrierName / vesselOrFlight（前端 toLowerCase includes） |
| 触发 | 实时（useMemo 依赖 searchTerm） |

### 3.2 状态 Tab（bds-segment）

9 个段（全部 + 8 态），定义于 `SHIPMENT_STATUSES` 常量：

| id | label | 说明 |
|---|---|---|
| all | 全部状态 | 不筛选 |
| Draft | 草稿 | 未启动 |
| Booked | 已订舱 | 船期已定 |
| Loading | 装货中 | 装箱中 |
| Shipped | 已发运 | ATD 已回填 |
| Arrived | 已到港 | ATA 已回填 |
| Cleared | 已清关 | 清关完成 |
| Delivered | 已交付 | 终态 |
| Cancelled | 已取消 | 终态 |

**交互**：点击切换 `selectedStatus`，`filteredShipments` 重新计算；段可横向滚动（`overflow-x-auto`）。

### 3.3 后端筛选参数（GET /api/v1/shipping）

| 参数 | 类型 | 说明 |
|---|---|---|
| type | string | Export/Import/Domestic |
| status | string | 8 态枚举 |
| orderId | string | 关联订单 |
| customerRelationId | string | 客户 |
| carrierRelationId | string | 货代 |
| carrierName | string | 模糊匹配（insensitive） |
| shipmentNumber | string | 模糊匹配（insensitive） |
| search | string | OR 模糊搜索（shipmentNumber/customerName/carrierName） |
| limit | number | 默认 50，上限 200 |
| offset | number | 默认 0 |

## §4 准交率统计条

### 4.1 触发条件

`onTimeStats` 非空且（`order.total > 0 || shipment.total > 0`）时渲染。挂载时拉取一次，失败静默不阻断主流程。

### 4.2 口径定义（shipmentStatsService.getOnTimeStats）

| 指标 | 口径 |
|---|---|
| 运单准点率 | 已发运运单（ata 已回填）中 ata ≤ eta 的占比；分母 = 可判定样本（无 pending） |
| 订单准交率 | 交期（dueDate）在统计区间内的订单中，最后一票运单最大 ata ≤ dueDate 的占比；ata 未回填计入 pending |
| 多票 partial | 以该订单所有运单的最大 ata 作为"完成出运日" |
| 日期比较 | String YYYY-MM-DD 字典序比较（与全项目口径一致） |

### 4.3 展示格式

```
订单准交率  85.2%   准交 18 / 可判定 21 · 待出运 3
运单准点率  92.1%   准点 35 / 38
```

- 百分比：`(rate * 100).toFixed(1)%`，rate 为 null 时显示 `—`
- 明细：`准交 X / 可判定 Y` + `· 待出运 Z`（pending > 0 时追加）
- 统计区间参数：`from`/`to`（YYYY-MM-DD），默认全量

## §5 运输方式 chips（C4）

### 5.1 数据源

`getMethodStats` 按 `shippingMethod` 分组，内存过滤 etd/ata 区间。挂载时拉取，失败静默。

### 5.2 展示格式

每个 chip（`bds-badge sm neutral`）：

```
[Sea  45票  在途12  92%]
```

- method 名称 + 总票数
- 在途 > 0 时追加 `在途N`（Booked/Loading/Shipped/Arrived）
- onTimeRate 非 null 时追加百分比（`(onTimeRate * 100).toFixed(0)%`）
- 最多展示 6 个方式（`slice(0, 6)`），按总量降序
- title 属性含完整明细（总量/在途/已交付/准点率）

## §6 列表表格

### 6.1 列定义（tableColumns）

| 列 key | label | 宽度（grid） | 内容 |
|---|---|---|---|
| shipment | 货运单 | minmax(0,1.1fr) | shipmentNumber（truncate）+ shippingMethod · carrierName（10px 灰） |
| status | 状态 | minmax(0,0.78fr) | bds-badge（statusTone 映射变体） |
| partner | 收货方 | minmax(0,0.9fr) | customerName / 跟踪号 / 集装箱号 |
| schedule | 物流/日期 | minmax(0,1fr) | ETD/ETA + 船名航次 |

### 6.2 行渲染

- 使用 `CompiledMotionInteractiveCard`（as="button"），点击选中 `setSelectedId`
- 选中态：`background: var(--accent-tint)`
- 悬停态：`hover:bg-[var(--hover-darken)]`
- 底部分隔线：`bg-[var(--border-c-subtle)]` 1px
- 入场动画：`opacity 0→1`，`delay: index * 0.025`

### 6.3 状态徽章变体映射（statusTone）

| 状态 | 变体 | 语义 |
|---|---|---|
| Delivered | success | 成功 |
| Booked/Loading/Shipped/Arrived/Cleared | info | 进行中 |
| Draft | neutral | 未启动 |
| Cancelled | neutral | 终态 |

## §7 详情侧栏（320px）

### 7.1 inspector 字段卡

选中运单时渲染 21 个字段（`inspectorRows`），缺失值显示 `—`：

| 分组 | 字段 |
|---|---|
| 标识 | 运单号、客户、关联订单 |
| 物流 | 集装箱号、跟踪号、承运人、运输方式、航次号、船名/航班、装运港、卸货港 |
| 日期 | 预计离港、实际离港、预计到港、实际到港 |
| 报关 | 报关单号、清关日期 |
| 重量 | 总件数、毛重、净重、体积 |
| 其他 | 备注 |

### 7.2 操作按钮

| 按钮 | 条件 | 动作 |
|---|---|---|
| 编辑 | 始终显示 | openEditModal |
| 删除 | 始终显示 | handleDelete（confirm + soft delete） |
| 从订单带出 | orderId 存在 + packingEditable | handlePullLines |
| 编辑装箱 | packingEditable | setShowPackingEditor(true) |

### 7.3 联动刷新

选中运单变化（`selectedShipmentId`）或状态变化（`selectedShipmentStatus`）时：
- 重新拉取 `shipmentEvents`（时间轴）
- 重新拉取 `packingLines` + `packingCartons`（装箱明细）
- 装箱保存后手动 `setPackingRefreshKey(k => k + 1)` 触发刷新

## §8 空态与错误处理

| 场景 | 展示 |
|---|---|
| 列表为空 | 表格区域空白（无专门空态插画） |
| 搜索无结果 | filteredShipments 为空，表格空白 |
| 统计拉取失败 | 静默，统计条不渲染（不阻断主流程） |
| 时间轴拉取失败 | 静默，显示"暂无节点记录" |
| 装箱拉取失败 | 静默，显示"暂无装箱明细" |
| 操作错误 | 顶部 `bds-alert danger`，可关闭 |
