# 报关与退税模块概述 (Customs & Tax Refund Module Overview)

## §1 元信息

| 项 | 值 |
|---|---|
| **模块定位** | 出货与单据域的"合规主轴"——串联出运→报关→放行→退税→收汇全链路；报关单是退税申报的前置 FK，信用证是收汇与单据交单的契约源头 |
| **模块边界** | 报关单 CRUD + 状态机 + 明细行 / HS 编码参考库 / 信用证全生命周期 + 节点时间轴 / 出口退税申报 + 审核 + 进项专票勾稽；不含贸易单据台账（已收口至「单据中心」，本模块仅保留入口卡）、不含出运单据生成（归「制单引擎」）与单据模板编辑（归「单据模板编辑器」） |

## §4 子能力矩阵

本模块内嵌 4 个核心数据实体 + 3 个工具 Tab（入口卡），构成"报关→退税"合规闭环：

```
CustomsManager (7 Tab)
├── declarations   报关单 ────── CustomsDeclaration + CustomsDeclarationLine
├── hsCodes        HS 编码库 ── HsCode（参考数据，isActive 停用）
├── lettersOfCredit 信用证 ──── LetterOfCredit + LcEvent（节点时间轴）
├── taxRefunds     出口退税 ─── TaxRefund（+ VAT 专票勾稽只读消费）
├── tradeDocuments 贸易单据 ─── 入口卡 → 跳转「单据中心」（Wave A1 收口）
├── docGenerator   出运制单 ─── 嵌入 ShipmentDocumentGenerator（制单引擎）
└── docTemplates   单据模板 ─── 嵌入 DocumentTemplateManager（模板编辑器）
```

**数据实体依赖链**：

```
HsCode（参考库）
   │ hsCode 字段引用（无 FK 约束，仅文本匹配）
   ▼
CustomsDeclaration ──declarationId──▶ TaxRefund
   │ shipmentId                           │ declarationId 回引
   ▼                                      ▼
Shipment（运单）                    报关单（同一闭环）
   │                                      │
   └──── orderId ──▶ Order ◀── relationId ┘
                       │
                       └──▶ LetterOfCredit（独立收汇契约，orderId 关联）
```

## §5 核心业务流程图

```
┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  出运     │───▶│  报关单       │───▶│  放行         │───▶│  退税申报     │
│ Shipment │    │ CustomsDecl  │    │  Released    │    │  TaxRefund   │
│ (FK 源)  │    │ (Draft→...   │    │ (回填运单     │    │ (从报关单     │
│          │    │  →Released)  │    │  清关日期)    │    │  自动核算)   │
└──────────┘    └──────┬───────┘    └──────────────┘    └──────┬───────┘
                       │                                        │
                       │ HS 编码库（退税率/监管条件参考）          │ 进项专票勾稽
                       ▼                                        ▼
                  ┌──────────┐                          ┌──────────────┐
                  │  HsCode  │                          │ VAT 专票      │
                  │ (参考库) │                          │ (财务模块)    │
                  └──────────┘                          └──────────────┘
                                                                │
                                                                ▼
                                                        ┌──────────────┐
                                                        │ 退税到账      │
                                                        │  Refunded    │
                                                        └──────────────┘

信用证独立收汇链路（与报关并行，由订单触发）：
  Order ──▶ LetterOfCredit ──▶ LcEvent 节点时间轴
           (Issued→Presented    (开证→交单→承兑/不符点
            →Accepted→Settled)   →结清/过期/作废)
```

**闭环关键设计**：
1. **C4 关单回填**：报关单创建时回填运单 `customsDeclarationNumber`；放行（Released）时补写 `customsClearanceDate`（当日），免手工双录
2. **L10 退税自动核算**：`POST /tax-refunds/from-declaration/:declarationId` 从报关单读取 FOB/币种/HS 退税率，自动生成退税草稿
3. **C6 专票勾稽**：退税申报单展开时按 `taxRefundId` 拉取进项专票，有效专票（Declared）税额合计 vs 申报可退增值税勾稽核对

## §6 数据模型概要

本模块持久化真源由 6 个核心模型组成（全量字段见 `server/prisma/schema.prisma` L4288-L4520）：

| 模型 | 角色 | 关键约束 |
|------|------|---------|
| `CustomsDeclaration` | 报关单主表（22 业务字段 + 3 snapshot FK） | `declarationNumber @unique` / `deletedAt` 软删 / 5 索引（shipment/order/relation/status/type） |
| `CustomsDeclarationLine` | 报关明细行（商品/HS/数量/价格/重量/产地） | `declarationId` FK Cascade / `@@index([hsCode])` |
| `HsCode` | HS 编码参考库（税率/监管/检验检疫） | `code @unique` / `isActive` 停用（无软删）/ 3 索引 |
| `LetterOfCredit` | 信用证主表（银行/金额/期限/单据要求/不符点） | `lcNumber @unique` / `deletedAt` 软删 / 4 索引 |
| `LcEvent` | 信用证节点事件（append-only 时间轴） | `lcId` FK / `toNode` 取值同 LC 状态 / 无软删（业务可追溯） |
| `TaxRefund` | 退税申报单（出口信息/金额计算/审核） | `refundNumber @unique` / `deletedAt` 软删 / 4 索引 |

**Decimal 精度约定**：
- 金额类：`Decimal(18, 4)`（totalValue/amount/exportAmountFob/refundAmount）
- 税率类：`Decimal(6, 4)`（exportTaxRebateRate/importTariffRate/vatRate/refundableRate，百分比 4 位小数）
- 汇率：`Decimal(18, 8)`（fxRate，8 位小数保精度）

## §7 状态机总览

本模块包含 3 套独立状态机（HS 编码无状态机，仅 isActive 停用），均在服务端 `validateTransition` fail-closed 校验，前端镜像放行合法流转：

### 7.1 报关单状态机（DECLARATION_TRANSITIONS）

```
Draft ──▶ Submitted ──▶ Declared ──▶ Inspecting ──▶ Released
  │           │             │             │
  │           ▼             ▼             ▼
  │       Exception ◀───────┘        (终态)
  │           │
  ▼           ▼
Cancelled ◀───┘
```

| from → to | 触发场景 |
|-----------|---------|
| Draft → Submitted | 报关员提交申报 |
| Submitted → Declared | 海关确认报关 |
| Declared → Inspecting | 海关查验 |
| Inspecting → Released | 放行（回填运单清关日期） |
| * → Exception | 异常（可回到 Submitted 重报） |
| Draft/Submitted/Exception → Cancelled | 取消 |

### 7.2 信用证状态机（LC_TRANSITIONS）

```
Issued ──▶ Presented ──▶ Accepted ──▶ Settled
  │           │             │
  │           ▼             ▼
  │       Discrepant ──▶ Presented（不符点修正后重新交单）
  │           │
  ▼           ▼
Expired    Cancelled
```

详见 [`./信用证管理.md`](./信用证管理.md) §5。

### 7.3 退税状态机（TAX_REFUND_TRANSITIONS）

```
Draft ──▶ Submitted ──▶ Reviewing ──▶ Approved ──▶ Refunded
  │           │             │
  │           ▼             ▼
  │       Rejected ◀────────┘
  │           │
  │           ▼
  │         Draft（退回修改）
  ▼
Cancelled
```

审核分支：`Reviewing → Approved`（写入 reviewedBy/reviewedAt/reviewNotes）或 `Reviewing → Rejected`（可退回 Draft）。

## §10 设计系统约束

本模块遵循 BDS v2.1 中性契约：
- 状态徽章通过 `SEMANTIC_BADGE_VARIANT` 映射 `bds-badge` 语义变体（neutral/info/success/warning/danger），`active`/`rebate` 归并到 `info`
- 时间轴圆点/文字使用 `SEMANTIC_TEXT_COLOR` 取语义文本色 token（`--text-quaternary`/`--accent-text`/`--warning-text`/`--danger-text`/`--success-text`）
- Tab 导航采用 `bds-tabs` 下划线式，计数徽章用 `--bg-sunken` + `--text-tertiary`
- 卡片用 `bds-card`，明细行用 `rounded-inset` + `--bg-panel`
- 表格用 `bds-table`，数字列加 `bds-tnum` 等宽
- 禁止硬编码 hex/`rounded-[Npx]`/`box-shadow`，全部走 CSS 变量 + Tailwind 语义类
