## 二、模块边界与职责

### 2.1 模块做什么

采购管理覆盖"从需求到付款"的采购全链路：

1. **采购单创建**：手动录入 或 从订单/BOM 触发（prime 预填）
2. **审批流转**（待补）：金额分级审批 + 首单供应商加签
3. **发送确认**：Draft → Sent → Confirmed
4. **到货登记**：MaterialReceipt 收料记录
5. **质检入库**：合格/不合格数量 + 仓库归属（入库联动待补）
6. **对账闭环**：PO → 到货 → 发票 → 付款 全链路核对（待补独立页）

### 2.2 模块不做什么

| 不做的事 | 由谁负责 |
|---------|---------|
| 供应商档案 CRUD | Relations 模块（category=Supplier）+ FactoryProfile |
| BOM 物料清单 | BOM 模块（采购单可关联 bomId） |
| 库存账本 | InventoryTransaction 模块（待建，当前仅 MaterialReceipt 记录收料） |
| 应付发票 | 财务模块 Invoice（采购到货可触发 prime 跳转生成应付发票） |
| 供应商评分 | FactoryEvaluation（H1c 自动评分已接入，明细在供应商模块） |

## 三、采购单状态机（核心业务模型）

真源 [procurementService.ts TRANSITIONS](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/procurement/procurementService.ts#L92-L100)：

```
Draft ──▶ Sent ──▶ Confirmed ──▶ PartiallyReceived ──▶ Received ──▶ Closed
   │         │          │               │                  │
   │         │          └──▶ Received ──┘                  │
   │         │                (一次性全收)                   │
   │         │                                               │
   └─────────┴──▶ Cancelled ◀──────────────────────────────┘
```

| 状态 | 中文 | 可流转到 | 可编辑/删除 |
|------|------|---------|------------|
| Draft | 草稿 | Sent / Cancelled | ✅ 可编辑可软删 |
| Sent | 已发送 | Confirmed / Cancelled | ❌ |
| Confirmed | 已确认 | PartiallyReceived / Received / Cancelled | ❌ |
| PartiallyReceived | 部分到货 | Received / Closed | ❌ |
| Received | 全部到货 | Closed | ❌ |
| Closed | 已关闭 | — （终态） | ❌ |
| Cancelled | 已取消 | — （终态） | ❌ |

**状态转换校验**：`validateStatusTransition(from, to)` 查 TRANSITIONS 矩阵，非法转换抛 `非法状态转换：${from} → ${to}`。

## 七、业务事件

[procurementService.ts](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/procurement/procurementService.ts) 在状态流转时发布事件（fire-and-forget，失败不阻断业务）：

| 事件类型 | 触发时机 | payload 要点 |
|---------|---------|-------------|
| `PurchaseOrderSent` | Draft → Sent | poNumber / supplierName / totalAmount / lineCount |
| `PurchaseOrderConfirmed` | Sent → Confirmed | poNumber / lines 物料明细 |
| `MaterialReceived` | 创建来料记录 | receiptNumber / totalAccepted / totalRejected / newStatus |

**H1c 自动评分**（非阻塞）：
- 全部收齐（Received）→ 供应商交期评分（deliveryScoreForDaysLate）
- 验货结论 → 供应商质量评分（inspectionScoreForResult）

## 八、供应商拉黑拦截

```typescript
// procurementService.ts createPurchaseOrder
if (input.supplierRelationId) {
  const factory = await prisma.factoryProfile.findUnique({
    where: { relationId: input.supplierRelationId }
  });
  if (factory && factory.deletedAt === null && factory.blacklistedAt !== null) {
    throw new Error(`该供应商已被拉黑（原因：${factory.blacklistReason}），禁止新建采购单`);
  }
}
```

身份真源：Relation（category=Supplier）→ FactoryProfile 1:1。拉黑供应商禁止新建采购单（PRD 13.1）。
