## 二、对账全链路

### 2.1 四链路核对模型

```
┌───────────┐     ┌───────────┐     ┌───────────┐     ┌───────────┐
│  采购单   │ ──▶ │   到货    │ ──▶ │   发票    │ ──▶ │   付款    │
│ PurchaseOrder│ │MaterialReceipt│ │  Invoice  │ │PaymentVoucher│
├───────────┤     ├───────────┤     ├───────────┤     ├───────────┤
│ 订单数量  │     │ 收货数量  │     │ 发票数量  │     │ 付款金额  │
│ 订单金额  │     │ 合格数量  │     │ 发票金额  │     │ 付款日期  │
│ 单价      │     │ 拒收数量  │     │ 税额      │     │ 核销状态  │
└───────────┘     └───────────┘     └───────────┘     └───────────┘
      │                  │                 │                 │
      ▼                  ▼                 ▼                 ▼
   量差识别           质差识别          价差识别          付款差异
```

### 2.2 对账维度

| 维度 | 比对项 | 差异类型 | 容差 |
|------|--------|---------|------|
| 数量 | PO 订单数 vs 到货合格数 | 量差 | ±2%（行业惯例） |
| 质量 | 到货总数 vs 合格数 | 质差 | 拒收率 ≤5% |
| 价格 | PO 金额 vs 发票金额 | 价差 | ±0.5%（四舍五入容差） |
| 付款 | 发票金额 vs 付款金额 | 付差 | 0（应全额） |

## 四、差异类型与识别

### 4.1 量差（Quantity Variance）

**定义**：采购订单数量 vs 实际到货合格数量差异。

```
量差 = PurchaseLine.quantity - SUM(MaterialReceipt.totalAccepted)
量差率 = 量差 / PurchaseLine.quantity × 100%
```

| 量差率 | 等级 | 处理 |
|--------|------|------|
| |率| ≤ 2% | 正常 | 自动通过，记录备注 |
| 2% < |率| ≤ 5% | 轻微 | 经办业务员解释原因，财务确认 |
| |率| > 5% | 异常 | 供应商扣款/补货，管理层审批 |

**常见原因**：损耗超预期 / 短装 / 运输破损 / 计量误差。

### 4.2 质差（Quality Variance）

**定义**：到货总数 vs 合格数量差异（拒收部分）。

```
拒收率 = MaterialReceipt.totalRejected / MaterialReceipt.totalReceived × 100%
```

| 拒收率 | 等级 | 处理 |
|--------|------|------|
| 0% | 合格 | 无差异 |
| 0% < 率 ≤ 5% | 轻微 | 退货/折让，扣款 |
| 5% < 率 ≤ 10% | 严重 | 退货 + 供应商整改 |
| 率 > 10% | 批次拒收 | 整批退货 + 供应商评级降级 |

**关联**：MaterialReceipt.rejectionReason / qualityNotes 记录质差原因。

### 4.3 价差（Price Variance）

**定义**：采购单金额 vs 供应商发票金额差异。

```
价差 = Invoice.amount - PurchaseOrder.totalAmount
价差率 = 价差 / PurchaseOrder.totalAmount × 100%
```

| 价差率 | 等级 | 处理 |
|--------|------|------|
| |率| ≤ 0.5% | 正常 | 四舍五入容差，自动通过 |
| 0.5% < |率| ≤ 3% | 轻微 | 经办业务员核实单价，财务确认 |
| |率| > 3% | 异常 | 供应商对账，补开/红冲发票 |

**常见原因**：汇率波动 / 单价变更未更新 PO / 税率错误 / 运费分摊。

### 4.4 付差（Payment Variance）

**定义**：发票金额 vs 实际付款金额差异。

```
付差 = Invoice.amount - PaymentVoucher.amount
```

| 付差 | 处理 |
|------|------|
| = 0 | 全额付款，核销 |
| > 0 | 部分付款，剩余挂账 |
| < 0 | 超付，需追回或抵扣下期 |

## 六、差异处理流程

### 6.1 差异识别（自动）

```
对账单生成时自动跑四链路比对：
  for each PO in 周期:
    量差 = compareQuantity(PO.lines, receipts)
    质差 = compareQuality(receipts)
    价差 = comparePrice(PO.totalAmount, invoice.amount)
    付差 = comparePayment(invoice.amount, payment.amount)
  生成差异记录 → 按等级路由处理
```

### 6.2 处理路由

| 差异等级 | 处理人 | 动作 |
|---------|--------|------|
| 正常（容差内） | 系统 | 自动标记"正常差异"，对账单可直接核销 |
| 轻微 | 经办业务员 | 填写差异原因 → 财务确认 → 核销 |
| 异常 | 管理层 | 审批处理方案（扣款/补货/红冲）→ 执行 → 核销 |

### 6.3 差异处理动作

| 动作 | 适用差异 | 后端 | 说明 |
|------|---------|------|------|
| 折让扣款 | 量差/质差 | 创建 CreditNote（贷项通知单） | 下期 PO 抵扣或退款 |
| 补货 | 量差 | 新建 PO（补货数量） | 供应商补发短缺 |
| 退货 | 质差 | 创建退货单 | 拒收部分退回供应商 |
| 发票红冲 | 价差 | Invoice 红冲 + 重开 | 金额错误重开发票 |
| 供应商整改 | 质差严重 | FactoryEvaluation 降级 | 触发供应商评级调整 |

| actualValue | Decimal | 实际值（到货/付款） |
| varianceAmount | Decimal | 差异额 |

```

                        │                     │
```
