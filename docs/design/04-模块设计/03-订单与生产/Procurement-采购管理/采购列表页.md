> **2026-10-07 职责纠偏：** 采购、加工、库存与样品操作通常由对应业务组业务员办理，不设采购员、仓管员或样品管理员专岗。后勤主责为出运与单证；既有协作权限不代表仓储岗位。下文旧权限表、审批阈值和规划状态仅保留作历史线索，不据此新增岗位或扩充MVP。 当前规则见[角色与实际分工](../../../global/2026-10-06/05-roles-and-responsibilities.md)及[对话决策总账](../../../global/2026-10-06/08-2026-10-06-对话设计决策总账.md)。

## 三、状态 Tab 筛选

## 四、列定义

### 4.1 列表列

| # | 列名 | 数据字段 | 说明 |
|---|------|---------|------|
| 1 | PO 号 | `poNumber` | 业务单号（PO-YYYY-NNNN），主链接色可点击进详情 |
| 2 | 供应商 | `supplierName` | 冗余快照（无则显示 `—`） |
| 3 | 状态 | `status` | bds-badge 徽章（见 §五） |
| 4 | 总金额 | `totalAmount` + `currency` | `toLocaleString` + 币种前缀 |
| 5 | 下单日期 | `orderDate` | YYYY-MM-DD |
| 6 | 预计到货 | `expectedDeliveryDate` | YYYY-MM-DD（空显 `—`） |
| 7 | 经办业务员 | `buyer` | 可空 |
| 8 | 操作 | — | 展开按钮 + 状态流转快捷操作 |

### 4.2 行展开内容

点击展开按钮（ChevronDown/ChevronRight 切换）→ 展开两区块：

**A. 行明细（PurchaseLine）子表**：

| 列 | 字段 | 说明 |
|----|------|------|
| 行号 | `lineNumber` | 1,2,3... |
| 物料编码 | `materialCode` | 可空 |
| 品名描述 | `description` | 必填 |
| 分类 | `category` | Fabric/Trimmings/Accessories/Other |
| 数量 | `quantity` + `unit` | tabular-nums |
| 单价 | `unitPrice` | 4 位小数 |
| 行金额 | `amount` | = quantity × unitPrice |
| 已收 | `receivedQuantity` | 累计收料 |
| 不合格 | `rejectedQuantity` | 累计拒收 |

**B. 收料记录（MaterialReceipt）列表**：

| 列 | 字段 | 说明 |
|----|------|------|
| 收料单号 | `receiptNumber` | |
| 状态 | `status` | Accepted/Rejected/PartiallyAccepted 徽章 |
| 收货日 | `receivedDate` | |
| 总收货 | `totalReceived` | |
| 合格 | `totalAccepted` | |
| 拒收 | `totalRejected` | |
| 仓库 | `warehouseName` | |

## 五、状态徽章颜色编码

真源 [ProcurementManager.tsx STATUS_BADGE_VARIANT](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/components/ProcurementManager.tsx#L117-L125)（BDS v2.1 bds-badge 语义变体）：

| 状态 | badge 变体 | 语义 |
|------|-----------|------|
| Draft | neutral | 中性灰（草稿未提交） |
| Sent | info | 信息蓝（已发出待确认） |
| Confirmed | neutral | 中性（已确认待到货） |
| PartiallyReceived | warning | 警告橙（部分到货需跟进） |
| Received | success | 成功绿（全部到货） |
| Closed | neutral | 中性（终态已关闭） |
| Cancelled | danger | 危险红（已取消） |

**收料状态徽章**（RECEIPT_STATUS_BADGE_VARIANT）：

| 状态 | 变体 |
|------|------|
| Pending（待检） | neutral |
| Inspected（已检验） | neutral |
| Accepted（合格入库） | success |
| Rejected（不合格） | danger |
| PartiallyAccepted（部分合格） | warning |

## 六、筛选交互

### 6.1 已实现筛选

| 筛选器 | 类型 | 后端参数 | 前端实现 |
|--------|------|---------|---------|
| 状态 Tab | 单选 | `status` | ✅ |
| 搜索框 | 文本模糊 | `search` | ✅ 匹配 poNumber/supplierName/buyer |

### 6.2 后端已支持、前端待接入

| 筛选器 | 后端参数 | 设计 |
|--------|---------|------|
| 供应商下拉 | `supplierRelationId` | `RelationCombobox`（category=Supplier） |
| 日期范围 | `dateFrom` / `dateTo` | 双 datepicker，作用于 `orderDate` |

### 6.3 后端查询契约

```typescript
// procurementService.ts listPurchaseOrders
where: { deletedAt: null }
  + status? + supplierRelationId?
  + orderDate: { gte: dateFrom, lte: dateTo }
  + OR: [poNumber/supplierName/buyer contains search]
orderBy: { createdAt: 'desc' }
take: min(limit ?? 50, 200)  // 上限 200
skip: offset ?? 0
```

返回 `{ items: PurchaseOrder[], total: number }`。
