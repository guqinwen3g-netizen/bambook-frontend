## §3 AQL 抽样标准

### 3.1 AQL 字段说明

| 字段 | 含义 | 示例值 |
|------|------|--------|
| aqlLevel | AQL 接收质量限 + 检验水平 | "2.5/4.0 II"（major AQL 2.5 / minor AQL 4.0 / 检验水平 II） |
| lotSize | 批量（总生产数） | 5000 |
| sampleSize | 抽样数（按 AQL 表查得） | 200（批量 5000 / 检验水平 II / 一般检验） |
| totalUnits | 实际检验数（= sampleSize 或实际抽检数） | 200 |
| passedUnits | 合格数 | 185 |

### 3.2 AQL 抽样判定逻辑

| 疵点等级 | AQL 值 | 接收数 Ac | 拒收数 Re | 说明 |
|---------|--------|----------|----------|------|
| **致命 critical** | 0 | 0 | 1 | 零容忍，>0 即整批拒收 |
| **主要 major** | 2.5 | 查 AQL 表 | Ac+1 | 超过 Ac 即拒收 |
| **次要 minor** | 4.0 | 查 AQL 表 | Ac+1 | 超过 Ac 即拒收 |

> ⚠️ 当前系统仅记录 criticalDefects/majorDefects/minorDefects 计数与 result 结论，不自动按 AQL 表判定结论。结论由 QC 人员手动录入。

### 3.3 passRate / defectRate 计算

```typescript
function passRate(total: number, passed: number): number {
  if (total <= 0) return 0;
  return passed / total;
}

function defectRate(total: number, passed: number): number {
  if (total <= 0) return 0;
  return (total - passed) / total;
}
```

返回值范围 0-1，前端展示时 × 100 + toFixed(1) + `%`。

## §4 三级疵点体系

### 4.1 疵点等级定义

| 等级 | 字段 | 严重性 | AQL | 对结论影响 |
|------|------|--------|-----|-----------|
| **致命 critical** | criticalDefects | 最高 — 安全/功能/法律合规问题 | 0（零容忍） | >0 → 终期门禁直接拒绝（AQL 0 零容忍） |
| **主要 major** | majorDefects | 中 — 明显外观/尺寸偏差 | 2.5 | 影响 passRate/defectRate |
| **次要 minor** | minorDefects | 低 — 轻微外观瑕疵 | 4.0 | 影响 passRate/defectRate |

### 4.2 常见疵点分类

| 等级 | 常见疵点示例 |
|------|------------|
| 致命 critical | 锋利边缘/窒息风险/有害物质超标/商标错误/法律合规违规 |
| 主要 major | 色差超限/尺寸偏差超公差/破洞/断线/污渍>3cm/缝线开裂 |
| 次要 minor | 轻微色花/线头/轻微污渍<3cm/包装轻微破损 |

### 4.3 defectSummary 文本描述

当前疵点仅以计数 + 文本描述记录，示例：
- `criticalDefects=0, majorDefects=3, minorDefects=5`
- `defectSummary="跳线x3 污渍x2 色差x1 线头x2"`

> ⚠️ 规划增强：疵点逐条录入（DefectRecord 模型），记录每条疵点的类型/位置/照片/严重等级。

## §5 检验结论 result

| 结论 | 含义 | 中期验货影响 | 后续动作 |
|------|------|------------|---------|
| `pass` | 合格 | 生产可继续 | 进入终期验货 |
| `conditional` | 有条件合格 | 需整改指定问题后继续 | 整改 → 复验 |
| `fail` | 不合格 | 生产暂停，需整改 | 整改 → 复验（upsert 覆盖更新报告） |

**结论校验**：

```typescript
if (data.result !== undefined && data.result !== null
    && !['pass', 'conditional', 'fail'].includes(data.result)) {
  throw Object.assign(new Error(`非法验货结论: ${data.result}`), { code: 'INVALID_RESULT' });
}
```

> 中期验货 fail 不会触发终期 fail 广播通知（仅终期 fail 广播）。

## §8 供应商评分联动

中期验货结论保存后，自动追加供应商质量评分（fire-and-forget，无档案供应商静默跳过）：

```typescript
if (result.result && order.millRelationId) {
  const score = inspectionScoreForResult(result.result, critical);
  await factoryService.recordAutoEvaluation({
    relationId: order.millRelationId,
    kind: 'inspection',
    score,
    sourceType: 'inspectionReport',
    sourceId: result.id,
    evaluatedAt: result.inspectionDate || today,
    note: `验货报告 ${result.id}（订单 ${poNumber}）结论 ${result.result}...`,
    actorId: data.inspectedBy || 'system',
  });
}
```

| 结论 + critical | 评分影响 |
|----------------|---------|
| pass + 0 critical | 高分（供应商质量优秀） |
| conditional + 0 critical | 中分 |
| fail + 0 critical | 低分 |
| fail + N critical | 最低分 |
