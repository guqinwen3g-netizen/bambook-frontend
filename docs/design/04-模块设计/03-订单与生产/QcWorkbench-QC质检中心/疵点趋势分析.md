## §3 三级疵点率计算

### 3.1 疵点率定义

```
criticalRate = criticalDefects / totalUnits   // 致命疵点率
majorRate    = majorDefects / totalUnits       // 主要疵点率
minorRate    = minorDefects / totalUnits       // 次要疵点率
totalDefectRate = (critical + major + minor) / totalUnits  // 总疵点率
passRate      = passedUnits / totalUnits        // 合格率
defectRate    = (total - passed) / totalUnits   // 不合格率
```

### 3.2 现有计算函数

```typescript
// stageService.ts
function passRate(total: number, passed: number): number {
  if (total <= 0) return 0;
  return passed / total;
}

function defectRate(total: number, passed: number): number {
  if (total <= 0) return 0;
  return (total - passed) / total;
}
```

> ⚠️ 当前仅计算 passRate/defectRate，未计算三级疵点率。需新增 criticalRate/majorRate/minorRate 计算函数。

### 4.1 三大统计维度

| 维度 | 分组字段 | 来源 | 用途 |
|------|---------|------|------|
| **供应商维度** | Order.millRelationId | Order | 供应商质量对比、供应商评分 |
| **产品维度** | Order.product | Order | 产品质量问题定位 |

| 组合 | 分组 | 典型场景 |
|------|------|---------|
| 供应商 × 时间 | millRelationId + inspectionDate(月) | 供应商疵点率月度趋势 |

| 供应商 × 产品 | millRelationId + product | 某供应商某产品疵点率 |

| 业务线 × 时间 | businessLine + inspectionDate | 按业务线疵点率趋势 |

## §5 聚合查询设计（规划）

### 5.1 供应商疵点率聚合

```typescript
// 规划端点：GET /api/v1/qc/defect-trends/by-supplier?dateFrom=&dateTo=&inspectionType=

async function getDefectTrendsBySupplier(params: {
  dateFrom?: string;
  dateTo?: string;
  inspectionType?: string;
}) {
  const reports = await prisma.inspectionReport.findMany({
    where: {
      inspectionType: params.inspectionType ?? undefined,
      inspectionDate: {
        gte: params.dateFrom,
        lte: params.dateTo,
      },
    },
    include: {
      order: { select: { millRelationId: true, millRelationName: true } },
    },
  });

  // 按 millRelationId 聚合
  const bySupplier = new Map<string, {
    relationId: string;
    relationName: string;
    reportCount: number;
    totalUnits: number;
    passedUnits: number;
    criticalDefects: number;
    majorDefects: number;
    minorDefects: number;
  }>();

  for (const r of reports) {
    const key = r.order?.millRelationId;
    if (!key) continue;
    const agg = bySupplier.get(key) || { /* init */ };
    agg.reportCount++;
    agg.totalUnits += r.totalUnits;
    agg.passedUnits += r.passedUnits;
    agg.criticalDefects += r.criticalDefects;
    agg.majorDefects += r.majorDefects;
    agg.minorDefects += r.minorDefects;
    bySupplier.set(key, agg);
  }

  // 计算疵点率
  return [...bySupplier.values()].map(s => ({
    ...s,
    criticalRate: s.totalUnits > 0 ? s.criticalDefects / s.totalUnits : 0,
    majorRate: s.totalUnits > 0 ? s.majorDefects / s.totalUnits : 0,
    minorRate: s.totalUnits > 0 ? s.minorDefects / s.totalUnits : 0,
    passRate: s.totalUnits > 0 ? s.passedUnits / s.totalUnits : 0,
  }));
}
```

### 7.1 现有评分机制

```typescript
// factoryService.ts inspectionScoreForResult
function inspectionScoreForResult(result: string, critical: number): number {
  // 根据 result + critical 返回评分
  // pass + 0 critical → 高分
  // fail + N critical → 最低分
}
```

### 7.2 评分聚合（趋势分析）

| 聚合指标 | 计算 | 说明 |
|---------|------|------|
| 供应商平均评分 | AVG(score) WHERE relationId=X | 供应商整体质量水平 |
| 评分趋势 | AVG(score) GROUP BY month | 供应商评分月度变化 |
| 验货次数 | COUNT(InspectionReport) WHERE relationId=X | 验货频率 |
| fail 率 | COUNT(result=fail) / COUNT(all) | 不合格率 |
| 致命疵点率 | SUM(criticalDefects) / SUM(totalUnits) | 致命疵点率 |
