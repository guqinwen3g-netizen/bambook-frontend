## §2 模块定位与范围

### 2.1 在 ERP 全链路中的位置

```
报价单 → 开发案例 → 订单(Order) ──OrderConfirmed──▶ 【BOM 草稿(L6联动)】 → 采购 → 生产 → 出运
                        │                                │
                        └── 转订单 ──────────────────────┘
```

BOM 是"从订单到采购/生产"的成本真源：
- **上游**：订单确认（OrderConfirmed 事件）→ L6 联动自动生成 BOM 草稿（从模板复制或占位）
- **中游**：BOM 编辑（物料行 + 成本估算项）+ 成本汇总 + 利润分析
- **下游**：BOM 确认后 → 采购单生成（物料行驱动）+ 生产排产参考

### 2.2 模块边界

| 包含 | 不包含 |
|------|--------|
| BOM CRUD（含物料行 + 成本估算项） | 采购单本身（在 Procurement 模块） |
| 3 态状态机（Draft → Confirmed → Archived） | 生产排产（在 Production 模块） |
| 成本汇总自动计算（料/工/费） | 物料档案主数据（在 Products 模块） |
| 利润分析（sellingPrice → profitMargin） | 供应商档案（在 Relations 模块） |
| 版本管理（parentBomId 追溯链） | 报价单定价（在 Quotation 模块） |
| 插件化成本模型引擎（fabric/FOB/CM） | 订单状态推进（在 Order 模块） |
| L6 联动自动生成草稿 | 审计日志本身（在 Audit 模块） |
| EntityLink 关联图谱同步 | 业务事件总线本身（在 Events 模块） |

## §3 核心概念与术语

### 3.1 BOM（物料清单）

一个 BOM 代表"一个产品的物料清单 + 成本结构"。

| 概念 | 说明 | 代码真源 |
|------|------|---------|
| **bomNumber** | 业务编号（BOM-YYYY-NNNN），服务端自动生成或传入校验唯一 | `schema.prisma` L3921 `@unique` |
| **status** | 3 态：Draft(草稿) / Confirmed(已确认) / Archived(已归档) | `schema.prisma` L3924 |
| **version** | 版本号（修订递增，从 1 开始） | `schema.prisma` L3933 |
| **parentBomId** | 上一版本 BOM ID（版本追溯链） | `schema.prisma` L3934 |
| **totalCost** | 总成本 = 物料 + 人工 + 费用（自动汇总） | `schema.prisma` L3940 |
| **sellingPrice** | 销售单价（可选，用于利润分析） | `schema.prisma` L3944 |

### 3.2 BOMLine（物料行）

| 概念 | 说明 | 代码真源 |
|------|------|---------|
| **materialType** | 8 类：Main/Contrast/Lining/Pocketing/Trimmings/Thread/Packaging/Other | `schema.prisma` L3974 |
| **quantity** | 单件用量 | `schema.prisma` L3982 |
| **wastagePercent** | 损耗率（%） | `schema.prisma` L3984 |
| **effectiveQty** | 实际用量 = quantity × (1 + wastage%)（自动计算） | `schema.prisma` L3985 |
| **unitCost** | 单价 | `schema.prisma` L3986 |
| **amount** | 行金额 = effectiveQty × unitCost（自动计算） | `schema.prisma` L3987 |

### 3.3 CostEstimate（成本估算项）

| 概念 | 说明 |
|------|------|
| **costType** | 4 类：Material(物料) / Labor(人工) / Overhead(制造费用) / Other(其他) |
| **description** | 描述（如：裁剪人工 / 缝纫人工 / 厂房折旧 / 检验费） |
| **amount** | 金额 |

### 3.4 插件化成本模型

| 插件 id | 名称 | 适用场景 |
|---------|------|---------|
| `fabric` | 面料成本模型 | 面料报价单、单耗预算（仅算面料类行） |
| `apparel-fob` | 服装 FOB 报价模型 | 整单 FOB = 物料+人工+费用+利润；支持 Track B 退税公式 |
| `apparel-cm` | 服装 CM 代工模型 | 来料加工 = 人工+费用（不含面料） |

## §4 核心流程

### 4.1 主流程：订单确认 → BOM 草稿 → 确认 → 采购

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 订单确认  │───▶│ L6 联动  │───▶│ BOM 编辑 │───▶│ BOM 确认 │───▶│ 采购生成 │
│ OrderConfirmed│ 生成草稿  │    │ (Draft)  │    │(Confirmed)│    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                     │                                │
                     │  从模板复制 or 占位              │  发布 BOMConfirmed 事件
                     └────────────────────────────────┘
```

### 4.2 BOM 3 态状态机

```
Draft ──confirm──▶ Confirmed ──archive──▶ Archived (终态)
  │                    │
  └──archive──▶ Archived
  └──delete──▶ (软删除)
```

**合法转换矩阵**（`TRANSITIONS`）：

| 当前态 | 可推进到 |
|--------|---------|
| Draft | Confirmed, Archived |
| Confirmed | Archived |
| Archived | （终态） |

**操作限制**：
- 仅 Draft 状态可编辑（updateBOM）
- 仅 Draft 状态可重新计算成本（recalculateCost）
- 仅 Draft 状态可删除（deleteBOM）

### 4.3 成本汇总公式

代码真源：`bomService.ts` `aggregateCosts()` L142-L166

```
物料成本 = Σ(BOMLine.amount) + Σ(CostEstimate where costType=Material)
人工成本 = Σ(CostEstimate where costType=Labor)
制造费用 = Σ(CostEstimate where costType=Overhead or Other)
总成本 = 物料 + 人工 + 费用

实际用量 = quantity × (1 + wastage% / 100)
行金额 = 实际用量 × unitCost
```

### 4.4 利润分析公式

代码真源：`bomService.ts` `calcProfit()` L169-L174

```
利润额 = sellingPrice - totalCost
利润率 = (利润额 / sellingPrice) × 100   (sellingPrice > 0 时)
```

### 4.5 L6 联动 — 自动生成 BOM 草稿

代码真源：[L6CreateBOMDraft.ts](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/events/linkages/L6CreateBOMDraft.ts)

```
OrderConfirmed 事件
  → L6 联动触发
  → 幂等检查（orderId 是否已有 BOM）
  → 查找模板 BOM（Confirmed/Archived，description 包含订单产品名）
  → 有模板：复制物料行 + 成本估算项
  → 无模板：创建占位 BOM（单行占位物料）
  → 关联 orderId
  → 发布 BOM 草稿
```

**幂等性**：
- in-process: `auto:L6:${orderId}` 去重
- 业务层: 查询 orderId 关联的 BOM，有则跳过
