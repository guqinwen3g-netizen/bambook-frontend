## §4 三级样衣节点状态机

### 4.1 SampleNodesPanel 组件

代码真源：[SampleNodesPanel.tsx](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/components/development/SampleNodesPanel.tsx)

每个开发案例固定 3 个样衣节点，首次加载时 `ensureSampleNodes` 幂等创建。

### 4.2 三级节点定义

| 级别 level | 中文名 | 英文 | 业务含义 |
|-----------|--------|------|---------|
| `confirmation` | 确认样 | Approval | 客户确认款式/尺寸的初样 |
| `pp` | 产前样 | PP Sample | 大货开裁前的最终确认样 |
| `top` | 大货样 | TOP | 从大货首件抽取留档 |

### 4.3 节点状态机（5 态）

```
pending ──start──▶ making ──send──▶ sent ──approve──▶ approved (终态)
                       │               │
                       └──revise───────┴──▶ revising ──start──▶ making (round+1)
```

**状态中文标签**（`STATUS_LABEL`）：

| status | 中文 |
|--------|------|
| pending | 待打样 |
| making | 制作中 |
| sent | 已寄出 |
| approved | 已批准 |
| revising | 需修改 |

### 4.4 按状态渲染的操作按钮

| 当前状态 | 可用 action | 按钮文案 | 副作用 |
|---------|------------|---------|--------|
| pending | start | 开始打样（Scissors 图标） | → making |
| revising | start | 重新打样（RotateCcw 图标） | → making, round+1 |
| making | send | 寄出（Send 图标） | → sent，prompt 输入快递单号/公司 |
| making | revise | 需修改（RotateCcw 图标） | → revising，prompt 输入修改意见 |
| sent | approve | 批准（CheckCircle2 图标） | → approved，prompt 输入批准意见 |
| sent | revise | 需修改（RotateCcw 图标） | → revising |
| approved | — | PackageCheck 图标（终态展示） | — |

### 4.5 节点信息展示

每行节点卡片展示：
- 级级名称 + 英文 + 轮次（`R{round}` 当 round > 1）
- 当前状态中文 + 寄出日期 + 快递单号
- 反馈内容（`truncate` + title 悬停全文）

## §5 开发案例 6 态状态机

### 5.1 状态定义（DevelopmentStage）

| stage | 中文 | badge 语义色 |
|-------|------|-------------|
| developing | 开发中 | info |
| shipping | 待寄样 | warning |
| feedback | 待反馈 | info |
| revision | 需复样 | warning |
| approved | 已确认 | success |
| cancelled | 已取消 | neutral |

### 5.2 合法转换矩阵

代码真源：`developmentCaseMutationService.ts` `DEV_STAGE_TRANSITIONS`

| 当前态 | 可推进到 |
|--------|---------|
| developing | shipping, cancelled |
| shipping | feedback, cancelled |
| feedback | revision, approved, cancelled |
| revision | shipping, cancelled |
| approved | （终态） |
| cancelled | （终态） |

### 5.3 5A 评审门禁

`sampleCategory === '5a'` 的样衣，进入 `shipping` 阶段前必须 `reviewStatus === 'passed'`。

- 门禁字段：`STAGES_REQUIRING_REVIEW = new Set(['shipping'])`
- 未通过返回 `REVIEW_REQUIRED` 错误，提示当前评审状态

### 5.4 自动副作用

| 触发条件 | 自动行为 |
|---------|---------|
| stage → revision | `currentRound + 1` |
| stage → approved（无 completedDate） | 自动填充 `completedDate = today` |
| 转订单（convert） | stage → approved + linkedOrderId + convertedAt + completedDate |

## §6 转订单入口

### 6.1 显示条件

- `selectedCase.stage === 'approved'` 且 `!selectedCase.linkedOrderId` → 显示「一键转为大货订单」按钮
- `selectedCase.linkedOrderId` 存在 → 显示 `bds-alert success`："已转订单 · {linkedOrderPo}"

### 6.2 交互流程

```
点击「一键转为大货订单」
  → window.confirm("将 {code} 转为大货订单？")
  → developmentService.convertToOrder(id, { autoCreate: true })
  → handleRefresh()（刷新列表）
  → window.alert("已转为订单 {poNumber}")
```

详细转单流程见 [开发转订单流程.md](./开发转订单流程.md)。
