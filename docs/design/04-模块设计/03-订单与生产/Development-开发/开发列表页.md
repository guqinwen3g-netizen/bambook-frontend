## §3 筛选体系

### 3.1 三维筛选

| 维度 | 控件 | 选项 | 行为 |
|------|------|------|------|
| **搜索** | 文本输入框 | 模糊匹配 name/code/customerName/supplierName/productName | 客户端零延迟过滤（`useMemo`） |
| **类型** | CustomSelect | all / fabric(面料开发样) / garment(成衣开发样) / pp(产前样) / trim(辅料样) | 每项显示计数 `· N` |
| **阶段** | CustomSelect | all / developing / shipping / feedback / revision / approved / cancelled | 每项显示计数 `· N` |

### 3.2 客户端过滤逻辑

```typescript
// DevelopmentManager.tsx L178-L189
const filteredCases = useMemo(() => {
  const normalizedSearch = searchTerm.trim().toLowerCase();
  return cases.filter(item => {
    if (selectedType !== 'all' && item.type !== selectedType) return false;
    if (selectedStage !== 'all' && item.stage !== selectedStage) return false;
    if (normalizedSearch) {
      const haystack = `${item.name} ${item.code} ${item.customerName} ${item.supplierName} ${item.productName}`.toLowerCase();
      if (!haystack.includes(normalizedSearch)) return false;
    }
    return true;
  });
}, [cases, selectedType, selectedStage, searchTerm]);
```

**设计决策**：客户端过滤（非服务端），与 RelationsManager 模式一致 — 零延迟、不阻塞渲染。全量数据通过 `developmentService.listDevelopmentCases(undefined, { limit: 200 })` 一次性拉取。

### 3.3 服务端筛选（API 层）

虽然前端用客户端过滤，但后端 `GET /api/v1/development` 也支持服务端筛选（供 Agent / 外部 API 调用）：

| 参数 | 说明 |
|------|------|
| `type` | 按类型过滤 |
| `stage` | 按阶段过滤 |
| `customer` | 按 customerRelationId 过滤 |
| `supplier` | 按 supplierRelationId 过滤 |
| `owner` | 按负责人过滤 |
| `search` | 模糊搜索（name/code/customerName/supplierName/productName，insensitive） |
| `limit` | 最大 200 |
| `offset` | 分页偏移 |

## §7 状态机（列表层视角）

列表层不直接操作状态机，但通过 badge 展示当前 stage：

```
developing(info) → shipping(warning) → feedback(info) → revision(warning) → approved(success)
                                                                             ↘ cancelled(neutral)
```

状态推进操作在详情页或 API 层触发（见 [开发详情页.md](./开发详情页.md) §状态机）。

## §13 设计系统约束

| 约束 | 合规说明 |
|------|---------|
| 禁止硬编码 hex | 全部 CSS 变量（`var(--text-primary)` / `var(--accent-tint)` / `var(--hover-darken)` 等） |
| 圆角 | 表壳 `rounded-card`；badge `rounded-compact` |
| 无阴影 flat | CompiledTableShell / CompiledSurfacePanel 使用 backdrop-blur + hairline |
| badge 语义 | `bds-badge` + `stageTone()` 返回的 5 色变体 |
| 主题透明 | 组件无 `isDarkMode` 分支，暗色由 tokens 覆盖 |
| spotlight 统一 | `SPOTLIGHT_COLOR` / `SPOTLIGHT_SIZE` 常量统一，替代双值三元 |
