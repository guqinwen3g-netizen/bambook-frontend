## §4 物料卡片（收起态）

每张卡片对应一个 `InventoryItem`，点击头部展开/收起。

**卡片头部布局**（`flex items-center gap-3 p-4 cursor-pointer`）：

| 区域 | 内容 | 样式 |
|------|------|------|
| 展开图标 | ChevronRight（收起）/ ChevronDown（展开） | text-quaternary |
| 左主区 | materialCode（bds-mono）+ 低库存/锁定 badge + description · warehouse · 批次 · 库位 | text-primary / text-tertiary |
| 右数值区 | quantity + unit（bds-tnum）+ 最低库存（text-quaternary 10px） | 低库存时 danger-text |

**徽章规则**：

| 条件 | 徽章 | 变体 |
|------|------|------|
| `quantity ≤ minStock`（minStock != null） | `低库存` | bds-badge danger |
| `lockedQuantity > 0` | `锁定 {qty}` | bds-badge warning |

## §5 展开式详情

点击卡片头部 → `handleExpand(itemId)` → 拉取该物料最近 20 条变动流水 + AnimatePresence height auto 展开。

### 5.1 物料信息网格

`grid-cols-2 xl:grid-cols-4 gap-3 text-xs`，展示以下字段（仅非空显示）：

| 字段 | 标签 | 格式化 |
|------|------|--------|
| category | 品类 | 原值 |
| specification | 规格 | 原值 |
| unitCost + currency | 单位成本 | `toFixed(2) {currency}` |
| lastInDate | 最后入库 | formatDate（空值 `—`） |
| lastOutDate | 最后出库 | formatDate |
| maxStock | 最高库存 | formatQty |

### 5.2 可用库存摘要

`flex items-center gap-4 text-xs` 三值并列：

| 指标 | 计算方式 | 颜色 |
|------|---------|------|
| 当前 | `quantity` | text-primary |
| 锁定 | `lockedQuantity` | warning-text |
| 可用 | `availableQuantity = quantity - lockedQuantity` | success-text |

> availableQuantity 在前端拉取后计算：`Number(it.quantity) - Number(it.lockedQuantity)`，后端不存储此字段。

### 5.3 最近变动流水

`movements.slice(0, 8)` 展示最近 8 条 StockMovement：

每行结构（`p-2 rounded-inset flex items-center gap-3 text-xs`）：

```
[类型徽章(图标+标签)] [数量 unit] [日期] [余额Before→After] · [原因]
```

- 类型徽章：从 MOVEMENT_TYPES 查找 icon + semantic（success/warning/info/neutral）
- 余额箭头：`formatQty(balanceBefore) → formatQty(balanceAfter)`（bds-tnum 对齐）
- 原因：可选，text-quaternary

### 5.4 库存变动表单（内嵌展开）

点击「库存变动」按钮 → 表单内嵌展开（非弹窗），`grid-cols-2 xl:grid-cols-4 gap-2`：

| 字段 | 控件 | 条件显示 |
|------|------|---------|
| 类型 | bds-select（6 型可选） | 始终 |
| 数量 | bds-input number | 始终 |
| 日期 | bds-input date（默认今日） | 始终 |
| 原因 | bds-input text | 始终 |
| 目标仓库 | bds-select（仅非当前仓库） | **仅 type=Transfer** |
| 盘点备注 | bds-input text | **仅 type=Adjustment** |

提交 → `handleCreateMovement` → `apiService.createStockMovement` → 成功后刷新物料列表 + 预警列表。

## §13 可访问性 & 交互细节

| 项 | 规范 |
|----|------|
| **展开动画** | AnimatePresence + motion.div height 0→auto + opacity 0→1（duration 0.2s） |
| **列表 stagger** | 每张卡片 `transition={{ delay: index * 0.02 }}`（错峰入场） |
| **数量格式化** | `Number(n).toLocaleString('en-US', { maximumFractionDigits: 2 })`（千分位） |
| **日期格式化** | 空值显示 `—`，非空显示原值（YYYY-MM-DD 字符串） |
| **展开互斥** | 同一时刻仅展开一项（expandedId 单值，点击新项自动收起旧项） |
| **变动表单重置** | 提交成功后重置 movementForm 为默认值（type=Inbound, quantity=0） |
| **错误不丢稿** | 变动失败时 movementError 显示文案，不收起表单（保留用户输入） |

## §14 设计系统约束

| 约束 | 合规说明 |
|------|---------|
| 主题透明 | 无 isDarkMode 分支，暗色由 tokens.css 统一覆盖 |

| 圆角 | 卡片 rounded-card；字段胶囊 rounded-inset；按钮 rounded-control |
