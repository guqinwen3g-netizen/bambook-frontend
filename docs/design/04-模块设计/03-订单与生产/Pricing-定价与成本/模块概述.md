## 一、模块定位与边界

Pricing 模块承担外贸出口企业"定价决策"的真源——什么价格能报、什么价格能发、报出去后实际利润几何。它由两条独立但联动的"轨道"构成：

- **轨道 A（系统推荐估算器）**：基于成本分解（面料 / 辅料 / 工费 / 加工费 / 包装 / 纱线 / 织造 / 染整）+ 行业基准 + 价格历史命中，输出估算售价区间（下限 / 中位 / 上限）。**仅内部使用**（PRD §8.4），不对客户展示，作为轨道 B 终价的"标尺"。
- **轨道 B（退税美元定价）**：外贸口径的"对外报价真源"——采购成本 → 退税 → 净 USD 成本 → 利润 → 佣金 → 最终 USD 单价。派生值一律服务端重算，客户端不参与计算。

两条轨道通过 **偏差校验（Price Deviation）** 联动：轨道 B 终价偏离轨道 A 中位估算 >15% 触发审批，>30% 禁止直接发送。这一门禁在报价单创建时自动生成 `ApprovalRequest`，在发送时 fail-closed 校验。

**模块边界**：
- ✅ 在内：双轨试算、定价记录 CRUD、退税率表、原材料价格历史、佣金规则、订单利润表、偏差审批快照
- ❌ 不在内：报价单本身的 CRUD（在 Quotations 模块，但偏差快照由本模块的纯函数计算）、汇率维护（在 ExchangeRate 模块，本模块只读消费）、BOM 物料清单（在 BOM 模块，轨道 A 仅消费其成本分解口径的概念但不直接读 CostEstimate 表）

## 三、核心子模块逐块说明

### 3.1 双轨试算面板（Calculator tab）

PricingManager 的核心 tab，左栏自上而下：TrackAPanel（轨道 A 估算）→ TrackBPanel（轨道 B 退税定价）→ DeviationBadge（双轨偏差三态徽章）；右栏为定价记录列表（PricingCalculation CRUD + 状态流转 Draft → Confirmed → Archived）。

**双轨联动数据流**：
```
TrackAPanel.onMedianUsdChange(usd, unit) ──┐
                                          ├──→ DeviationBadge { finalUsd, medianUsd, medianUnit }
TrackBPanel.onResultChange(trackBResult) ─┘        ↓
                                          computePriceDeviation() → { deviationPercent, level: ok|warn|block }
```

- 轨道 A 中位 USD 通过 `onMedianUsdChange` 回传父组件
- 轨道 B 终价 USD 通过 `onResultChange` 回传父组件
- DeviationBadge 前端展示用 `computePriceDeviation`（与后端同源阈值 15% / 30%），不参与落库
- 保存定价记录时，派生值（netUsdCost / profitAmount / commissionAmount / finalUnitPrice）一律服务端 `calculateTrackB` 重算，不接受客户端传入

### 3.2 订单利润表 Profit Sheets（PRD §6.2 / §8.3）

`generateOrderProfitSheet(orderId)` 在服务端聚合订单全链路资金口径，归一化至 CNY：

| 维度 | 数据源 | 汇率口径 |
|------|--------|----------|
| 销售收入 | 应收发票（type=Receivable，非 Cancelled）amount | Invoice.exchangeRate 快照优先 → ExchangeRate 最新 → 未折算 |
| 采购成本 | 采购单（非 Cancelled）totalAmount | PurchaseOrder.exchangeRate 快照优先 → 最新 → 未折算 |
| 运费 | 运单（非 Cancelled）freight + insurance + customs + otherCharges | 运单无汇率快照字段，外币一律按最新汇率 |
| 杂费 | 付款凭证（type=Disbursement，orderId 匹配，未核销发票）amount + bankFee | PaymentVoucher.exchangeRate 快照优先 → 最新 → 未折算 |

**幂等真源**：`orderId @unique`，重生成 = 覆盖更新（version + 1），不产生重复行。`details.unconverted` 透明披露无可用汇率的外币行（不计入合计）。

### 3.3 原材料价格历史 Price History（PRD §8.5 P1）

MaterialPriceHistory 为轨道 A 估算提供校准数据源：
- 三类物料：yarn（纱线）/ fabric（面料）/ trimming（辅料）
- 字段：materialCode / name / specification / price / unit / currency / priceDate / source（manual | purchase-order | quotation）/ supplierRelationId + supplierName 快照
- 趋势查询：按 materialType（+ 可选 materialCode）+ 日期范围返回时间升序序列，前端渲染条形趋势图（高度 ∝ 价格）
- 最新价查询：`getLatestPrice(materialType, materialCode)` → 轨道 A 估算时按 fabricCode/yarnCode 命中注入

### 3.4 佣金规则 Commission Rules（PRD §8.5 P2）

CommissionRule 是佣金率的配置真源，仅允许 E5（5%）/ E10（10%）两档：
- 匹配口径：intermediaryRelationId 精确命中（且 isActive）优先 → 默认规则（intermediaryRelationId 为空）兜底 → 无命中返回 null（无佣金）
- 占位唯一：同一中间人（或默认）仅允许一条启用中规则
- 快照原则：PricingCalculation.commissionRate 落库为数值快照，规则后续调整不回溯历史定价记录；commissionRuleId 记录来源规则以便追溯
- 权限约束：佣金字段涉管理层 + 财务可见域（PRD §9.6），由前端 modulePermissions 在 finance:read 权限门控

## 四、双轨偏差与审批联动状态机

```
┌─────────────────────────────────────────────────────────────────┐
│ 报价编辑器（QuotationManager）                                   │
│   ① 用户在 TrackAPanel 估算 → 得 trackAMedianUsd                 │
│   ② 用户在 TrackBPanel 试算 → 得 trackBFinalUsd                  │
│   ③ DeviationBadge 实时显示偏差等级（ok / warn / block）          │
└─────────────────────────────────────────────────────────────────┘
                            ↓ 保存报价（POST /quotations）
┌─────────────────────────────────────────────────────────────────┐
│ quotationService.createQuotation()                              │
│   ① calculatePriceDeviation(trackBFinalUsd, trackAMedianUsd)     │
│   ② deviation.level:                                            │
│        ok    → 正常落库，无审批                                   │
│        warn  → 同事务生成 ApprovalRequest(risk=medium, pending)   │
│        block → 同事务生成 ApprovalRequest(risk=high, pending)     │
│   ③ Quotation 表落快照：                                        │
│        trackAMedianUsd / trackBFinalUsd / priceDeviationPercent  │
│        / priceDeviationLevel / priceApprovalId                   │
└─────────────────────────────────────────────────────────────────┘
                            ↓ 发送报价（POST /quotations/:id/send）
┌─────────────────────────────────────────────────────────────────┐
│ quotationService.sendQuotation()                                │
│   if priceDeviationLevel === 'block':                           │
│     查 ApprovalRequest.status                                   │
│       approved  → 放行                                           │
│       其他      → throw → 路由层 409（门禁：price-deviation）     │
└─────────────────────────────────────────────────────────────────┘
```

**阈值常量**（前后端同源，改动需双边同步）：
- `DEVIATION_WARN_PERCENT = 15`（>15% 黄标 warn，触发审批）
- `DEVIATION_BLOCK_PERCENT = 30`（>30% 红标 block，禁止直接发送）
- 后端：`server/src/pricing/trackAEstimator.ts` 导出
- 前端：`components/pricing/DeviationBadge.tsx` 导出 `PRICE_DEVIATION_WARN_PERCENT` / `PRICE_DEVIATION_BLOCK_PERCENT`

| §8.4 | 轨道 A 仅内部使用，不对客户展示 | TrackAPanel 标题「仅内部」+ 不出现在客户可见的报价单 PDF |
| §8.5 | 退税率 / 佣金规则 / 价格历史配置 | TaxRefundRate + CommissionRule + MaterialPriceHistory CRUD |
| §8.6 | 双轨联动校验（>15% 黄标审批 / >30% 红标禁止发送） | calculatePriceDeviation + DeviationBadge + ApprovalRequest + 409 门禁 |
| §9.2 | 报价低于成本价 → 管理层审批 | 偏差为负且 |dev| > 15% 同样触发 warn（亏损风险） |
| §9.6 | 行级权限（佣金可见性） | 前端 modulePermissions finance:read 门控 |

## 十一、可访问性 & 交互细节

- **逐项可调实时重算**（PRD §8.6）：轨道 A 成本拆解行失焦触发 `handleLineCommit`，手工改过的行标记 `adjusted + source=manual`，重算仅更新未调整项
- **最新汇率一键带入**：TrackAPanel / TrackBPanel 均有「最新」按钮，调 `apiService.getLatestFxRates()` 取 USD 汇率填入
- **HS Code 查税率**：TrackBPanel「查税率」按钮调 `lookupTaxRefundRate(hsCode)`，命中自动填退税率 + 显示命中提示
- **键盘可达**：所有 input / select / button 使用 BDS 语义类（bds-input / bds-select / bds-btn），原生 focus ring
- **数字输入**：`inputMode="decimal"` 移动端唤起数字键盘；`parseNum` 容错空串与非数字
- **金额格式化**：`formatMoney` 使用 `toLocaleString('zh-CN', { minimumFractionDigits: 2, maximumFractionDigits: 4 })`；USD 前缀 `$`，CNY 前缀 `¥`

## 十二、设计系统约束

- **BDS v2.1 组件族**：bds-card / bds-btn / bds-input / bds-badge / bds-tabs / bds-modal / bds-empty / bds-check / bds-overline
- **主题透明**：PricingManager 对 isDarkMode 透明——无 isDarkMode 分支，暗色由 tokens.css `[data-theme]` 统一覆盖
- **状态徽章**：CALC_STATUS_BADGE_VARIANT 映射 Draft=neutral / Confirmed=success / Archived=neutral；退税率 / 佣金规则启停状态用 success / neutral 徽章可点击切换
- **偏差三态语义**：DeviationBadge 通过 `statusSemanticClass` 映射 ok=success（绿）/ warn=warning（黄）/ block=danger（红），与 rdlBusinessStatusTokens 同源
- **轨道 A/B 共享面板**：TrackAPanel / TrackBPanel 在 PricingManager 与 QuotationManager 双处复用，使用 `bg-surface-elevated rounded-card` 表面 + `text-text-*` token 类
- **禁止**：tsx 中硬编码 `rounded-[Npx]`、hex 颜色、box-shadow 硬编码（遵循项目设计系统铁律）

## 十三、移动端适配

- PricingManager 桌面端为主（grid xl:grid-cols-2 / xl:grid-cols-5），移动端自动降级为单列堆叠
- TrackAPanel / TrackBPanel 输入栅格 `grid-cols-2` 在窄屏自适应为单列
- 利润表明细分组在小屏可水平滚动（`overflow-x-auto`）
- 移动端不单独提供 BottomSheet——定价计算器是工作台式操作，移动端仅做查阅
