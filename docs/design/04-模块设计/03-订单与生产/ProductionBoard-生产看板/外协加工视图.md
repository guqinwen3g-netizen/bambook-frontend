## 五、状态机

### 5.1 外协单状态流转

```
Draft ──▶ Sent ──▶ Confirmed ──▶ InProduction ──▶ Received
   │         │          │             │              
   └─────────┴──────────┴─────────────┴──▶ Cancelled
```

| 状态 | 中文 | 含义 |
|------|------|------|
| Draft | 草稿 | 新建未发送 |
| Sent | 已发送 | 已发外协厂 |
| Confirmed | 已确认 | 外协厂确认接单 |
| InProduction | 生产中 | 外协厂加工中 |
| Received | 已收货 | 验收完成入库 |
| Cancelled | 已取消 | 终态 |

### 5.2 与生产阶段的关系

⚠️ **当前未联动**。外协单状态变更不自动触发生产阶段（如 manufacturing）推进。设计建议：
- 外协全部 Received → 可推进 `manufacturing` 阶段（待补门禁）
- 外协逾期 → 看板阻塞红标（待补）

## 七、进度跟踪

### 7.1 进度字段

| 字段 | 含义 | 展示 |
|------|------|------|
| orderDate | 下单日期 | YYYY-MM-DD |
| plannedDeliveryDate | 计划交期 | YYYY-MM-DD |
| actualDeliveryDate | 实际交期 | YYYY-MM-DD（未交付空） |
| status | 当前状态 | 状态徽章 |

### 7.2 交期偏差计算

```
daysLate = actualDeliveryDate - plannedDeliveryDate （天）
```

- daysLate > 0 → 逾期，warning chip "逾期 N 天"
- daysLate = 0 / null → 未交付或按期

### 7.3 与订单详情页 Pipeline 集成

[stageService.ts getProductionPipeline L171-L193](file:///Users/qinwengu/WorkBuddy/Claw/apps/Bambook/server/src/production/stageService.ts#L171-L193)：

```typescript
const outsourcingRows = await prisma.outsourcingOrder.findMany({
  where: { orderId, deletedAt: null },
  select: { id, orderNumber, supplierId, processType, status, quantity, unit,
            plannedDeliveryDate, actualDeliveryDate,
            qualityAcceptedQty, qualityRejectedQty },
  orderBy: { createdAt: 'desc' },
});
// 批量查 Relation 取 supplierName
```

返回时 `quantity` / `qualityAcceptedQty` / `qualityRejectedQty` 从 Decimal 转 Number（前端不处理 BigInt/Decimal）。

## 八、质量验收

### 8.1 验收字段

| 字段 | 类型 | 说明 |
|------|------|------|
| qualityAcceptedQty | Decimal(18,4) | 合格数量 |
| qualityRejectedQty | Decimal(18,4) | 不合格数量 |

### 8.2 合格率计算

```
合格率 = qualityAcceptedQty / (qualityAcceptedQty + qualityRejectedQty) × 100%
```

展示规则：
- 合格率 ≥ 95% → success 语义
- 90% ≤ 合格率 < 95% → warning 语义
- 合格率 < 90% → danger 语义

### 8.3 验收与入库联动

⚠️ **当前未实现**。外协验收合格数量未自动写入库存（无 InventoryTransaction 模型）。设计建议：
- 外协 Received 时 qualityAcceptedQty → 触发库存入库（待补 InventoryTransaction）
