# 样品仓库与业务流转

## 已确定的产品规则

- 样品仓库管理真实实物；数字档案管理产品资料；开发与订单记录轮次、版本和评审。
- 收样从来源业务发起，自动带入来源、轮次、客户及已有产品档案。实际数量、收到日期和库位由员工确认。
- 已登记实物的业务寄样，一次提交保存业务记录、扣减实物和寄样流水。仓库无需重复出库。
- 未经过公司仓库的供应商直寄明确登记业务事实，不凭业务状态制造库存。
- 来源与库存属于后端共享记录；本地导航上下文仅用于打开正确记录。
- 收样与寄样分别防重；寄样失败必须整体回滚，未知结果保留原请求核对。
- 封样禁止寄出；旧轮次、未核实来源、可用量不足禁止扣库。
- 原收样数量和评审证据保留，不能以当前库存反推原收样事实。
- 原生业务记录、实物仓库和数字档案之间使用准确 ID 双向跳转。
- 独立或历史实物可手动登记，缺失的数字档案关联可补充；已有关联不能在描述编辑中随意替换。

## 实施范围

开发面料批次、原生成衣轮次和原生订单样品寄送共用事务内实物寄送函数。
开发收样加入仓库及结构化库位。订单准确收样带入来源摘要及物件类型。
旧船样寄送遇到原生来源或已登记实物，须从原生订单样品入口处理。

## 本轮检查边界

不运行测试套件。以静态编译、差异检查和本地界面读取检查本轮接入；真实寄样、权限及失败恢复完整流程仍需另行验收。
