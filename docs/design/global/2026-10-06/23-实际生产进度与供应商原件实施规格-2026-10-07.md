# 实际生产进度与供应商原件实施规格

生产跟单按准确订单条目、实际工厂分支和最终完工记录展示进度。采购单和加工合同由各自已批准的供应商承诺版本生成正式原件，历史文件保存原证据。业务依据为 [08 决策总账](./08-2026-10-06-对话设计决策总账.md)第三节、5.3、5.4.1、5.7、6.3 和第九节。本文的接口、布局与存储细节属于本轮受托实施设计，不补写为用户此前逐字段确认。

## 生产跟单页面

页面沿用全站标题栏、搜索栏和主题令牌。搜索内部订单号、实际客户 PO、客户、产品描述与工厂；筛选全部、逾期和质量暂停。主视图分为依据待核对、尚无产品条目、尚未建立生产分支、生产进行中和实际生产已完成五组，每组按当前真实订单显示卡片。

每张卡片显示内部订单号、客户、实际外部 PO、约定交期，并列显示全部可见条目。条目显示产品描述、约定数量和单位、累计实际完工数量、数量允差结论。各工厂分支显示准确工厂、当前修订、安排数量、实际完工数量、正式 QC 结论、业务确认状态、实际生产尺码覆盖和未解除问题。数量为十进制字符串；没有登记为未知，明确登记为零时显示零。

点击订单回到原主单；点击条目或工厂分支携带准确订单行和分支身份。目标页面重新读取服务端候选及当前修订，参数只表示选中意图。未来工作区是否可打开仍由原工作区门禁决定，不能靠导航参数解锁或默认选择首行。

最终生产数量齐备只说明物理生产事实完成。客户允差、QC、业务确认、出运和财务保持独立。没有生产条目、没有实际分支或缺少完工记录时，不能显示生产完成；旧十阶段全部标记完成也不构成新的完工依据。

## 当前生产事实和权限

`GET /api/v1/production/progress` 与 V2 对应入口使用相同聚合服务，逐行消费原生最终生产数量和准确分支 QC 来源。读取前后均重读真实账号、凭据权限上限及订单数据范围；越范围记录不参与页面、统计和提醒。没有 QC 读取权限时，质量详情不披露，显示依据待核实。

正式 Final 报告必须覆盖当前准确分支或允许适用的准确面料整单范围，且报告内容摘要仍与实际记录一致。面料没有逐码检查要求，不代表已有正式检验报告。QC NOK、复验通过等待业务恢复和当前报告通过分别呈现；后一次 OK 不自动消除原未恢复问题。正式报告的业务处理与需求方样品确认保持各自原生记录。

统计按实际订单状态、实际分支和实际完工记录计算；逾期提醒使用真实订单交期，不从固定七天、十阶段或固定合格率推断业务进度。当前读取失败时移除缓存事实，显示待读取，不能回退到健康零值。

历史整单阶段保留读取。旧 V1、V2 的推进、签署、阻塞解除、裁剪检查清单和验货覆盖写入口，在当前账号与原订单范围校验后返回明确冲突，提示使用准确条目及工厂分支的原生操作。Agent 旧整单写工具同样关闭；其生产查询和提醒消费当前真实来源。确认订单和报价转单不再自动创建十个未来阶段。

## 供应商正式原件

采购与加工分别使用准确合同批准修订。原生出单命令包含稳定请求键和所选批准修订，逐项核验该合同全部来源订单行及当前业务权限。批准依据在渲染期间发生变化时不发布文件，也不制造成功回执。

一个批准修订对应一份正式文档和一个版本。文档来源引用准确业务类型、合同和修订，冻结商业快照与服务端渲染内容。正式 PDF、文件字节摘要、大小、原版本身份、来源摘要、操作人及原请求键同事务登记；只修改合同后的新批准修订才生成新的原件身份。

同键同内容恢复原成功结果；后续合同修订不改变原回执和原件。其他请求键对同一批准修订重复出单时复用既有原件，不追加空版本或覆盖 PDF。下载核对当前全部来源权限、准确版本、生成审计与实际文件字节。通用文档创建、编辑、状态修改、删除、追加版本和重新生成入口都不能改变正式采购或加工原件。

单据中心在分页计数前按整份合同全部来源范围过滤。合并合同不假装只属于第一张订单；按订单查看资料包时通过批准快照保留所有准确来源回链。

## 历史采购加工文件

旧文件的表头和原有版本按当前实际来源订单范围读取，标记 `legacy_approval_unknown`。未分配且无法核实归属的历史文件，仅当前订单全范围读者可见。历史显示不从当前供应商表头重新制作承诺，不回填批准修订、数量或成功状态。

原生来源标记、冻结快照协议或受保护归档路径仍在时，不能删除其中一项后降为旧文件绕过校验。缺失批准依据的历史文件不开放正式重制；保留其原始数据及未知状态。

## 验收边界

源代码存在和纯 mock 检查不代表全站验收。独立 PostgreSQL 与真实 HTTP 连续验收必须证明：零读取补写、准确 L2 与撤权、旧写入口不可绕过、原件实际 PDF 字节及不可变版本、采购加工分别审批、未知回执精确恢复，以及升级后旧事实保留。生产页面还须在固定源码的浏览器中验证搜索、筛选、准确跳转、未知状态和当前角色可见性。证据逐项绑定 [决策覆盖矩阵](../../../../artifacts/acceptance-20261007/global-goal/decision-coverage.md)，未执行项保持未验收。
