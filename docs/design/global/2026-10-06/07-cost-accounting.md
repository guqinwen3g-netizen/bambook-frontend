# 成本核算体系设计（取代原"BOM 成本核算"）

日期：2026年10月6日。版本：**定稿 0.9**（结构已确认，具体公式与科目规则待定，见第九节）。

本文件定义公司成本核算的四层结构、各层计算人、依据与使用场景。原模块名"BOM 成本核算"**已改名为"成本核算"**。

---

## 一 为什么改名（背景与判断）

**原来的 BOM 是工厂语言。** 它回答"一件成衣用了哪些物料、各多少用量"——这是**工厂车间**关心的问题，不是贸易商公司该关心的主轴。

**贸易商公司关心的是钱，从细到大的每一层都要算清：**

- 一件衣服用了多少面料、值多少钱？
- 这一批实际花了多少（采购价可能和预算不一样）？
- 这笔订单从头到尾赚了多少？
- 这个季度公司整体赚了多少？

所以成本核算改为**由细到大的四级结构**：L1 单件 → L2 单批 → L3 单单 → L4 周期。

**注意**：原 BOM 数据**不废弃**。单件用料清单作为 L1 的**计算输入之一**保留，只是不再作为模块的主轴和名称。

---

## 二 四级结构总览

| 层级 | 核算对象 | 主要依据 | 计算人 | 主要用途 |
|---|---|---|---|---|
| **L1 单件** | 一件衣服的面料、辅料、加工成本 | 用料清单 × 面料金额 + 加工费 + 辅料费 | **业务员填报** | 报价参考、验算报价是否离谱 |
| **L2 单批** | 一次采购或一次生产的**实际**总成本 | 实际采购单价、实际用量、加工结算、加工损耗 | **财务核算** | 订单毛利真值 |
| **L3 单单** | 一笔订单从头到尾的利润 | L2 成本 + 运费 + 税费 + 佣金 − 收入 | **财务核算** | 订单结案、利润回读 |
| **L4 周期** | 一段时间的公司整体经营 | 全部订单汇总 + 期间费用 | **财务核算** | 经营报表、定价参考 |

---

## 三 L1 单件成本

### 3.1 构成

| 项 | 依据 | 谁提供 |
|---|---|---|
| 面料成本 | 用料量 × 面料金额 | 业务员（用料量来自工艺/BOM） |
| 辅料成本 | 辅料清单 × 单价 | 业务员 |
| 生产加工费 | 工厂报价或加工单价 | 业务员 |
| 其他 | 做工、烫工、包装等 | 业务员 |

### 3.2 关键约束

1. **L1 由业务员填报，但不自动成为定价依据。** 定价依据由财务与主管确认的版本决定。
2. **L1 是"预计"层**，可以随行就市调整，但**必须标注计算时点与依据来源**。
3. **L1 不得被当成 L2。** 报价时用的预计成本，不等于最后实际花的成本。

---

## 四 L2 单批实际成本

### 4.1 构成

| 项 | 依据 |
|---|---|
| 实际采购金额 | 实际采购单价 × 实际数量（含实际发生的加工费） |
| 实际用量与损耗 | 实际领用 vs 理论用量，损耗单独记录 |
| 加工结算 | 工厂实际结算金额 |

### 4.2 关键约束

1. **实际 ≠ 预计，不允许回落**。预计与实际**必须分开存储、分开展示**，不合并成一个字段。
2. **损耗必须单独记录**，不能摊进单价里消失。这是判断供应商是否可靠的关键数据。
3. **余料要记**。委外加工的发料、耗用、产出、余料形成闭环。

---

## 五 L3 单单利润

### 5.1 构成

```
订单利润 = 订单收入（合同/开票金额）
         − L2 实际成本
         − 运费 / 保险
         − 税费
         − 佣金
         ± 汇兑损益
         ± 索赔影响（客户索赔扣减 / 我方索赔收入）
```

### 5.2 关键约束

1. **利润计算时点必须明确**：是"订单结案时算一次"，还是"每次发货/收款后重算"。我建议**订单未结案时随业务进展实时重算并标注计算时点，订单结案时固化**。
2. **结案后被改动的订单必须重算并留痕**（见 [06-change-and-permission-rules.md](06-change-and-permission-rules.md) 4.2）。
3. **退款、索赔、核销冲回发生后必须重算**，不删除历史结果。
4. **预计利润与实际已结清利润必须分开表达**，不能用一个"利润"字段糊过去。

---

## 六 L4 周期经营

### 6.1 构成

L4 = 周期内所有订单 L3 的汇总 + 期间费用（房租、人员、管理费用等）。

### 6.2 关键约束

1. **必须标明系统内业务范围**：报表只覆盖系统内业务，不等于公司全部经营（可能有系统外业务）。
2. **L4 不能替代 L3**：公司整体赚多少不能掩盖某单亏了。
3. 报表需能下钻到 L3、再到 L2、L1。

---

## 七 分层之间的硬规则

| 规则 | 说明 |
|---|---|
| **上层不能由下层简单相加得出** | L4 ≠ L3 简单相加，因为期间费用只在 L4 体现 |
| **下层不能覆盖上层已确认值** | 已结案订单的 L3 不得被后续 L1 改动静默覆盖 |
| **每层必须标注计算时点与版本** | 看到数值要能知道"这是什么时候、按什么算的" |
| **未知不是零** | 成本项未取到数据显示空态/错误态，**不得回落 0 或硬编码** |
| **QC 不参与成本域** | 已确认（Kevin 10-06）：QC 不得写 BOM/成本数据 |

## 八 职责归属

| 层级 | 填报/计算人 | 复核人 | 说明 |
|---|---|---|---|
| L1 | 业务员 | 主管 | 报价参考，不自动生效 |
| L2 | **财务核算** | 主管 | 实际成本以财务为准 |
| L3 | **财务核算** | 主管 → 领导审批 | 订单结案依据 |
| L4 | **财务核算** | 领导 | 经营报表 |

**QC 已明确退出成本域**（2026-10-06 用户确认），QC 对 BOM/成本只有只读权。

## 九 尚未确定的部分（待定，将在成本核算模块开工方案中逐项定死）

以下项属公司制度，需 Kevin 拍板，coding agent 不得自行决定：

1. **具体计算公式**：L1 各项如何加总；L2 损耗如何进入成本；L3 汇兑如何处理。
2. **成本科目清单**：需要哪些科目（如面料、辅料、加工、运费、包装、佣金）。
3. **L3 计算时点规则**：实时重算的触发条件；结案固化的条件。
4. **L4 期间费用**：哪些费用进公司层面；报表是否含税。
5. **汇率来源与折算时点**：用哪个汇率、哪一天折算。
6. **退款/索赔/冲回后重算的触发规则**。
7. **已结案订单再改动的处理**：重算后是否需要重新审批。
