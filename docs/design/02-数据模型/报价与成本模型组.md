## §7 PricingCalculation 模型（轨道 B 定价记录）

### 7.1 输入项

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id | `PRC__${shortId}` |
| purchaseCostCny | Decimal | @db.Decimal(18,4) | 人民币成本单价（工厂采购价） |
| refundRate | Decimal | @db.Decimal(8,4) | 退税率百分比（0-16） |
| exchangeRate | Decimal | @db.Decimal(18,8) | CNY per USD（¥/$） |
| profitMargin | Decimal | @db.Decimal(8,4) | 利润率百分比 |
| commissionRate | Decimal | @default(0) @db.Decimal(8,4) | 佣金率（0=无 / 5=E5 / 10=E10） |

### 7.2 派生项（服务端重算，不接受客户端传入）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| netUsdCost | Decimal | @db.Decimal(18,4) | 退税后美元成本 = purchaseCostCny × (1 − refundRate%) ÷ exchangeRate |
| profitAmount | Decimal | @db.Decimal(18,4) | = netUsdCost × profitMargin% |
| commissionAmount | Decimal | @db.Decimal(18,4) | = netUsdCost × commissionRate% |
| finalUnitPrice | Decimal | @db.Decimal(18,4) | 终价 = netUsdCost + profit + commission |

### 7.3 关联与状态

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| orderId | String? | — | 关联订单 snapshot FK |

| productAssetId | String? | — | 关联产品资产 snapshot FK |
| hsCode | String? | — | 退税率来源 HS Code（追溯） |
| fxLockId | String? | — | 锁定汇率关联 FxRateLock |
| commissionRuleId | String? | — | 佣金率来源 CommissionRule（追溯；rate 已落快照） |
| quantity | Decimal? | @db.Decimal(18,4) | 数量（算总额用，不参与单价推导） |
| status | String | @default("Draft") | Draft / Confirmed / Archived |
| notes | String? | — | 备注 |
| createdBy | String? | — | 创建人 |
| createdAt | BigInt | — | epoch ms |
| updatedAt | BigInt | — | epoch ms |
| deletedAt | BigInt? | — | 软删 |

```
@@index([orderId]) @@index([quotationId]) @@index([status])
```

**快照原则**：commissionRate 落库为数值快照，规则后续调整不回溯；commissionRuleId 记录来源以便追溯。

## §8 OrderProfitSheet 模型（订单利润表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | @id | `OPS__${shortId}` |
| orderId | String | @unique | 一单一张，重生成=覆盖更新（幂等真源） |
| baseCurrency | String | @default("CNY") | 归一化币种 |
| salesRevenue | Decimal | @default(0) @db.Decimal(18,4) | 销售收入 |
| purchaseCost | Decimal | @default(0) @db.Decimal(18,4) | 采购成本 |
| freightCost | Decimal | @default(0) @db.Decimal(18,4) | 运费 |
| miscCost | Decimal | @default(0) @db.Decimal(18,4) | 杂费 |
| grossProfit | Decimal | @default(0) @db.Decimal(18,4) | 毛利润 |
| grossMargin | Decimal? | @db.Decimal(8,4) | 毛利率%（salesRevenue=0 时 null） |
| details | Json | — | `{ sales:[...], purchases:[...], freight:[...], misc:[...], unconverted:[...] }` |
| version | Int | @default(1) | 每次重生成 +1 |
| generatedAt | BigInt | — | 生成时间 |
| createdAt | BigInt | — | epoch ms |
| updatedAt | BigInt | — | epoch ms |

```
@@index([generatedAt])
```

**聚合口径**（归一化至 CNY）：
- 销售收入 = Σ 应收发票（type=Receivable，非 Cancelled）amount × 汇率快照
- 采购成本 = Σ 采购单（非 Cancelled）totalAmount × 汇率快照
- 运费 = Σ 运单（非 Cancelled）freight+insurance+customs+otherCharges（按最新汇率）
- 杂费 = Σ 付款凭证（type=Disbursement，orderId 匹配，未核销）amount × 汇率快照
- 无可用汇率的外币行不计入合计，列入 details.unconverted 透明披露

> **DR-005 利润口径约束**：
> - 服装部 OrderProfitSheet 的采购成本维度须包含 `internalTransferPrice × quantity`（内部面料采购成本）
> - 面料部 OrderProfitSheet 的销售收入维度须包含内部面料销售收入
> - 公司合并利润 = 服装部利润 + 面料部利润 − 抵销额（内部采购价）
> - 禁止将内部交易重复计入合并收入或合并成本

- Order 无直接反向引用 Quotation（Quotation 单向 convertedOrderId）
- Invoice（发票域）可关联 quotationId 生成 PI
- OrderInternalTransfer（订单与生产模型组）引用 OrderProfitSheet 做合并抵销计算（DR-005）

## §13 设计约定

| 约定 | 说明 |
|------|------|
| 主键 | String @id（带前缀的格式化 ID，如 `QT_`/`QTL_`/`TRR__`/`PRC__`/`OPS__`/`MPH__`/`CR__`） |
| 金额 | Decimal @db.Decimal(18,4)；汇率用 Decimal(18,8) 高精度；退税率/佣金率/利润率用 Decimal(8,4) |
| 时间戳 | BigInt epoch ms（createdAt/updatedAt/deletedAt/sentAt/generatedAt） |
| 业务日期 | String YYYY-MM-DD（issueDate/validUntil/priceDate） |
| 软删 | deletedAt BigInt?（null=未删；查询默认 `deletedAt: null` 过滤）；OrderProfitSheet 无软删（重生成覆盖） |
| snapshot FK | 跨模块关联用 snapshot FK 风格（不加 @relation），避免 Relation 归档时级联删除 |
| 强 FK（@relation） | 仅本组内 Quotation↔QuotationLine（Cascade）、CostEstimate↔BOM（Cascade） |
| 双轨快照 | Quotation 6 字段在创建时写入，此后为历史快照不随编辑变更 |
| 派生值服务端重算 | PricingCalculation 的 netUsdCost/profitAmount/commissionAmount/finalUnitPrice 一律服务端 calculateTrackB 重算 |
| 幂等真源 | OrderProfitSheet.orderId @unique，重生成=覆盖更新（version+1） |
