## §14 设计约定

| 约定 | 说明 |
|------|------|
| 主键 | String @id（UUID 或带前缀格式化 ID，如 `CTC_`/`CL_`/`FU_`/`OPP_`/`TIER_`） |
| 金额 | Decimal @db.Decimal(18,4)（creditLimit/totalLimit/amount）；折扣率 Decimal(5,2) |
| 时间戳 | BigInt epoch ms（createdAt/updatedAt/deletedAt/lastInteraction/approvedAt/closedAt） |
| 业务日期 | String YYYY-MM-DD（validFrom/validTo/followUpAt/nextFollowUpAt/expectedCloseDate/evaluatedAt/validUntil/birthday） |
| 软删 | deletedAt BigInt?（null=未删；查询默认 `deletedAt: null` 过滤） |
| 双态主档 | Relation 合并组织+联系人字段，isOrganization 区分；联系人专属字段在组织态可为空 |
| snapshot FK | 跨模块关联用 snapshot FK 风格（不加 @relation），避免级联删除 |
| 强 FK（@relation） | Relation↔Contact/CreditLimit/Opportunity/CustomerTier（Cascade）；Relation↔FollowUpRecord（Cascade）；Contact↔FollowUpRecord（SetNull 保留历史） |
| 实体图谱 | EntityReference/Alias/Link 三模型支持任意实体类型，跨域实体解析与溯源 |
| 行级权限 | Relation.ownerId/departmentId 支持 dataScope 隔离（Sales 仅看自己客户，同部门互相可见） |
