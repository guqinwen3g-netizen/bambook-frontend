# Bambook Enterprise OS v0.8 交付验收剧本

> **版本**：v0.8（不再是完整版）
> **定位**：以「业务主链闭环」替代「功能清单」作为本版本唯一交付验收真源。
> **交付时间目标**：2026-08-21 当周
> **范围口径**：19 个业务板块的「基础完整功能」围绕两条外贸主链闭环；Cockpit / 报表中心占位暂停；AI Agent 原生能力纯占位（9 月下一阶段）。

---

## §1 交付口径（先定「什么叫完成」）

v0.8 的「完成」不看某个模块有多少功能，只看三条铁律是否全部成立：

| 铁律 | 业务判据 | 失效表现 |
|---|---|---|
| **S1 主链闭环** | 一条面料单 + 一条成衣单，从「客户建档」走到「收款核销」，业务员（含协作角色）全程无死胡同，每步数据可见、且能传给下一步 | 某环节点不动 / 字段接不上 / 状态不流转 / 需要跳出系统手工完成 |
| **S2 数据可追溯** | 任意一张订单/发票/运单，3 击内能定位其单据、金额、状态、关联历史（快照不失真） | 同一数字在两处对不上 / 下游看不到上游引用 / 历史被后续改动覆盖 |
| **S3 角色权限正确** | 7 角色各只看到该看到的（行级隔离 + 范围 + 审批链），越权被 fail-closed 拦截 | 业务员能看到他人客户 / 越权改单 / 审批人可选可绕 |

**关键转变**：功能清单（API/单测/UI 断言）降级为「地基自检」，仅在三绿门禁里保留；**交付结论以 S1/S2/S3 的实际走查结果为准**。

## §2 环境军规（开发验收在 local+local，生产仅做交付前 UAT）

| 环境 | 用途 | 是否用于当前开发验收 |
|---|---|---|
| `localhost:3000`（本地 dev 网页）+ `local panda hub`（本地库） | **开发阶段 S1/S2/S3 走查主环境（本地后端即测试用）** | **是** |
| Electron（本地 dev 客户端） | 桌面形态冒烟（同一 local 后端） | 是（双形态抽检） |
| `bambook.jiangsupanda.com` + Mac Mini 后端 | 生产交付前的最终 UAT | 仅交付前，非常态 |

- **开发阶段一切走查都在 local + local**：无本地库即无真实验收对象。
- 每次走查必须声明「local 网页 / Electron 客户端 + 哪条演示数据」。
- 生产环境与本地库数据隔离；「登录本地、数据写生产」的割裂路由是历史踩过的坑，严禁再犯。

## §4 主链 A：面料出口单（Fabric）

| 步骤 | 角色 | 页面 | 操作 | 预期 / 完成标准 | 依赖数据 |
|---|---|---|---|---|---|
| A1 客户建档 | 业务员 | 关系智库 / CRM | 新建客户（含联系人、市场、币种、信用额度） | 客户出现在 CRM 列表，归属人=建档人，同部门他人不可见（S3） | Relation |
| A2 开发打样 | 业务员 | 开发管理 | 建开发案 → 打色/缸差登记 → 批色判定 | 打样流转留痕；封样基准生成；疵点入供应商质量分 | DevelopmentCase / SampleColorBatch |
| A3 报价 | 业务员 | 报价管理 | 生成报价单（含产品图/色卡图）+ 价格偏差门禁 | 报价成形；折扣>10%/低于成本价触发红标门禁（warn/block） | Quotation / PriceHistory |
| A4 订单 | 业务员 | 订单管理（面料） | 建面料订单 | MOQ 校验 + 信用冻结门禁：额度不足或冻结则阻断（S3） | Order |
| A5 采购 | 采购/业务员 | 采购管理 | 建采购单（坯布/染整）→ 付款申请 | 采购单关联订单；付款走「先申请后付款」审批链 | PurchaseOrder / PaymentRequest |
| A6 生产跟单 | 业务员/跟单 | 生产跟单 | 录入交期、登记延迟、工序链 | 延迟登记联动交期分下调；工序链损耗/完工锁留痕 | OrderProcessNode |
| A7 入库 | 后勤 | 库存管理 | 坯布/成品入库 | 库存余量变化，可追溯到采购单/订单 | Inventory |
| A8 QC | QC | QC 工作台 | 验货任务 + 测试委托 | fail 门禁：失败项 100% 整改闭环；报告归档 | InspectionReport / TestRequest |
| A9 货运 | 后勤 | 货运管理 | 订舱/运单/装箱 + 运费录入 | 运单关联订单；运费变动触发利润重估预览 | Shipment |
| A10 报关 | 后勤 | 外贸与报关 | 报关单 | 报关单关联运单/订单；单据齐套（S2） | Customs |
| A11 单据 | 后勤 | 单据中心 | 箱单/发票/产地证/TC 证书 | 各类单据一键生成，字段从订单/运单自动带出（S2） | Document |
| A12 财务 | 财务 | 财务管理 | 应收发票 → 收款核销 → 资金日历/信控 | 核销真源统一（InvoiceAllocation）；账龄/金额四处一致（S2） | Invoice / InvoiceAllocation / Voucher |
| A13 利润 | 财务/主管 | 定价与利润 | 生成利润表（Track A/B 双轨） | 利润表与成本/运费/报价同真源；重估不写库 | ProfitSheet |
| A14 成本 | 财务 | BOM 成本核算 | 原料+加工费+损耗成本 | 成本口径与订单/BOM 一致，可下钻（S2） | Bom |
