## §1 来源与方法论

第一轮能力评估结论：综合成熟度 ≈ 47%（30 项能力域，L3×4 / L2×7 / L1×7 / 缺陷×3 / L0×9）。L3 链的共同特征是**状态机纪律严格 + 每步留痕 + 拒绝路径明确**；全部缺陷项均为**数据链路中段断裂**。本需求池只解决"缺失"，缺陷修复单列批次 0。

**筛选口径**：以 L0 为主体（18 项），补充 4 项与 L0 强耦合的 L2 关键缺口（催款函深化 / 对账单导出 / 报价图片 / 展会 OCR），共 **22 项需求**。

## §2 痛度评分模型（甲方视角，透明可复算）

| 维度 | 权重 | 取值 |
|------|------|------|
| 频率 F：业务动作发生频率 | ×3 | 每日=5 / 每周=4 / 每月=3 / 每季=2 / 年度·罕见=1 |
| 损失 R：不做时的业务损失与风险 | ×3 | 资金损失·丢单·合规=5 / 客诉·效率显著=4 / 中等=3 / 轻=2 / 极轻=1 |
| 替代痛 P：现状手工替代的痛苦 | ×2 | 无替代·极痛=5 / 手工可忍=3 / 现有功能可绕=2 |
| 覆盖 C：受益角色数 | ×1 | 3+ 角色=2 / 1-2 角色=1 |

总分 = F×3 + R×3 + P×2 + C（满分 42）。**上线阻断类需求不受分数约束，一票进入批次二以内**。

## §5 批次一：S 级需求卡片（痛度 34+，每日业务命脉）

### REQ2-01 色差管理体系（痛度 42 —— 全池第一）

- **甲方场景**（剧本 A）：打色 3 缸寄客户 → 2 号缸 OK、1/3 号偏红要求重打 → 批色记录进供应商质量档案；大货阶段客户投诉缸差，须 3 分钟内调出该 PO 全部缸号/批次/批色证据。
- **功能范围**：
  - MVP：打色批次模型（缸号/色差评级 4-5 级制/左右色差/前后色差/照片附件）挂在样品轮次上，与既有封样链（已 L3）衔接——**批色通过即封样留档**，色差争议取证一键导出
  - 增强：疵点原因（偏红/偏蓝/色浅/色深）结构化入供应商质量分；大货匹差抽检记录（4% 抽检率联动）
- **验收标准**：A5 打色登记 ≤2min；客户投诉色差时 3 分钟内出具完整证据链（缸号×批次×批色记录×封样基准）；色差疵点自动计入供应商质量分趋势
- **数据模型**：新 SampleColorBatch（挂 DevelopmentCase 轮次 + Order 大货阶段两态）；供应商评分规则扩展色差权重
- **依赖**：封样链已就绪（L3）；疵点趋势分析已有基础

### REQ2-02 资金日历与 30 天现金流预测（痛度 40）

- **甲方场景**（剧本 C）：财务每天看"本周该收谁的钱、该付谁的钱"；老板看外汇敞口。当前"待收 $101,500"统计虚高（P1-004）证明地基必须先修。
- **功能范围**：
  - MVP：应收/应付日历视图（金额/币种/到期日/逾期天数）+ 今日动作清单 + 未来 30 天现金流净额预测（按账期推算）
  - 增强：外汇敞口汇总（未收/未付外币合计，E4）；预收款/保证金（voucherCategory 已有）单独泳道
- **验收标准**：C4 资金日历 30 天预测；数字与对账单/账龄交叉一致（跨模块一致性铁律 §4.4）
- **数据模型**：聚合现有 Invoice/PaymentVoucher/PaymentRequest，无新表；**强依赖批次 0 口径修复**
- **依赖**：P1-004/005/006 必须先行

### REQ2-03 溢短装与多单位计价（痛度 35）

- **甲方场景**：面料合同惯例 ±5% 溢短装条款；按米/码/公斤三种计价并存；开票数量与合同数量的溢短装差异须自动计算，超限预警。
- **功能范围**：
  - MVP：订单/合同录入溢短装条款（默认 ±5% 可改）；米↔码（1yd=0.9144m）换算；发货/开票数量按条款校验超限预警
  - 增强：按公斤计价（克重×门幅×长度换算）；结算金额按实际发货量自动重算
- **验收标准**：任一合同录入 ±5% 后，发货 5.2% 时系统预警并给出按条款的结算金额；米码换算双向精确
- **数据模型**：Order/OrderLine 增 tolerance 字段；单位换算工具函数库（供报价/订单/单据/报表共用——单一真源）
- **依赖**：报价明细行单位体系已有（YD/M/KG/PC/SET），扩展即可

## §6 批次二：A 级需求卡片（痛度 30-33，合规与上线刚需）

### REQ2-04 第三方测试管理（痛度 34）

- **甲方场景**（剧本 D）：客户测试要求（色牢度/缩水/强力/pH/甲醛）→ 委托 SGS/ITS/BV → 报告归档 → 失败项整改跟踪闭环。当前测试结果散落微信与邮件。
- **功能范围**：
  - MVP：TestRequest 模型（订单关联/测试项目/委托机构/送样日/报告 PDF 附件/结论 pass-fail）；失败项生成整改任务跟踪
  - 增强：客户测试要求模板化（下单时自动生成待测清单）；测试费用入订单成本
- **验收标准**：D4 测试报告挂订单归档；失败项 100% 有整改跟踪记录；任一订单 3 击查看全部测试报告
- **依赖**：与 QC 四指标（色牢度/缩水/克重/幅宽，已有）打通，避免双轨

### REQ2-05 面料工序级委外链（痛度 34）

- **甲方场景**：面料按单投产的真实链路 = 坯布厂→染厂→后整理（→涂层），各环节有独立损耗率与加工费；当前 MES 外协（L2）只有整体外协单，无工序拆分。
- **功能范围**：
  - MVP：订单工序链建模（工序节点/承接工厂/投入产出数量/损耗率/加工费单价）；各环节完工登记
  - 增强：工序级在制看板；委外加工费自动汇总入订单成本（Track A 估算联动）
- **验收标准**：任一面料订单可查看完整工序链进度与累计损耗；工序加工费计入 BOM/利润表
- **依赖**：MES 外协模块扩展而非新建；与采购（染费采购单）关系需设计评审

### REQ2-06 GRS TC 交易证书链（痛度 33）

- **甲方场景**：再生涤纶业务（演示库绍兴绿环即 GRS 供应商）出口欧盟必须 TC 链完整：原料 TC→工厂 TC→我方 TC，缺链=无法清关。
- **功能范围**：
  - MVP：TC 证书链建模（三段关联/证书编号/数量吨位/有效期）；GRS 订单缺链预警
  - 增强：TC 数量与订单数量勾稽校验（TC 吨位 < 订单用量即预警）
- **验收标准**：GRS 订单出货门禁前可一键校验 TC 链完整性；认证管理 Tab（已 L2）内可追溯整链
- **依赖**：认证管理台账已就绪，纯扩展

### REQ2-07 Excel/CSV 历史数据批量迁移（痛度 30 ⚑上线阻断）

- **甲方场景**：SEC-04/05——3 年历史客户/订单/报价/发票 Excel 导入 + 与 Excel 双轨并行 ≥1 个月。不迁移则系统空壳，验收无从谈起。
- **功能范围**：
  - MVP：四类模板（客户/供应商/订单/发票）下载→上传→逐行校验→错误行定位（行号+原因）→预览确认→批量落库；软删可回滚
  - 增强：报价历史导入（价格历史命中规则①的数据源）；导入批次报告
- **验收标准**：3 年数据（约千行级）迁移 ≤1 个工作日完成；错误行 100% 可定位可修正重导；导入后对账单/账龄数字与 Excel 原账一致
- **依赖**：复用 PO PDF 导入向导（L2）的预览-确认交互范式

### REQ2-08 催款函与对账单财务套件（痛度 30）

- **甲方场景**（剧本 C）：Peerless 逾期 $84,000 需一键生成中英催款函（含账龄明细）并登记催款记录；月度全客户对账单 ≤10min（KPI-05）。
- **功能范围**：
  - MVP：催款函中文化+账龄明细注入（逾期天数/分段/多发票汇总）+ 财务页一键发起；催款记录登记与历史
  - 增强：对账单批量生成（全客户循环）+ PDF 导出（复用 printDocument 版式）；催款提醒待办化
- **验收标准**：C 剧本全链——账龄页选中客户→生成中英双语催款函→发送→登记记录 ≤5min；KPI-05 月度对账 ≤10min
- **依赖**：P1-005 账龄口径修复为硬前置；打印版式（已 L3 范式）复用

## §9 推进建议

1. **顺序**：批次 0（缺陷地基）→ 批次一（3 项 S 级）→ 批次二（5 项 A 级，REQ2-07 迁移与批次 0 可并行启动模板设计）→ 批次三按管理层决策（REQ2-11/13 建议单独评审）→ 批次四远期池。
2. **口径决策先行**（批次 0 内）：应收余额口径、核销真源、汇率取值源（ExchangeRate 表 vs 快照）三项为设计决策，建议出 DR 决策记录后动工——否则 REQ2-02/08 建在错误地基上重蹈 P1 覆辙。
3. **协同纪律**：本需求池为甲方输入；具体模块设计文档（docs/design/04-模块设计/）与分工矩阵由总控按 [多会话协同推进纪律](../10-评审与决策/2026-08-17-多会话协同推进纪律.md) 安排，schema.prisma 单写者铁律不变。
4. **验收闭环**：每项需求落地后按 [验收计划](../../../.trae/documents/acceptance-plan.md) 对应量化标准（A/C/D/E/X/IND/KPI 编号已在各卡片标注）复测并更新能力地图——双层验证铁律持续生效。
