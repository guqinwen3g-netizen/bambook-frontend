## §5 债务修复生命周期状态机

```
   open → in-progress → resolved (验证通过)
     ↓         ↓             ↓
   (登记)   (修复中)      (收口)
     ↓         ↓
   blocked  wontfix
```

| 起点 → 终点 | 触发条件 | 门禁 |
|------------|----------|------|
| open → in-progress | Tech Lead 评审 + 分配负责人 | 评估修复路径 + 影响范围 |
| in-progress → resolved | 修复 commit 推送 + 全量测试通过 | tsc 零错误 + vitest 全绿 + check:tokens 通过 |
| open → blocked | 外部依赖未就绪 | 记录阻塞原因 + 阻塞源 |
| in-progress → wontfix | 评估后决定不修复 | Tech Lead 评审 + 替代方案 |
