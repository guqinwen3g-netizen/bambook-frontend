## §3 业务指标逐项说明

### 3.1 B1 — 订单周期（Order Cycle Time）

| 项 | 值 |
|---|---|
| **定义** | 从订单 Confirmed 状态到 Delivered 状态的平均天数 |
| **计算公式** | `AVG(DATEDIFF(days, Order.confirmedAt, Order.deliveredAt))` |
| **采集源** | `Order` 模型 + `OrderStatusTransition` 审计日志（schema.prisma L1490+） |
| **分维度** | 订单类型分层（面料 / 成衣 / Capsule）+ 客户分层（A/B/C）+ 季节 |
| **业务规则关联** | §10 业务十条（交期与生产规则）+ §9.7 订单变更规则 |
| **现状** | ⚠️ 数据底座已就绪（Order.confirmedAt / deliveredAt 字段 + 状态机 6 态 + Transition 审计），但**无聚合端点**；阶段 0-3 已修复 GAP-2 并发窗口，状态推进幂等 |
| **补建路径** | 新增 `/v1/metrics/order-cycle` 端点 + Prisma 聚合查询 + OPS Panel 卡片 |

### 3.2 B2 — 准交率（On-Time Delivery Rate）

| 项 | 值 |
|---|---|
| **定义** | 按 Order.deliveryDate 准时交付（Delivered 状态时间 ≤ deliveryDate）的订单占比 |
| **计算公式** | `COUNT(Delivered AND deliveredAt <= deliveryDate) / COUNT(Delivered) × 100%` |
| **采集源** | Order.deliveryDate + OrderStatusTransition（Delivered 时间戳） |
| **分维度** | 按客户 / 按工厂 / 按季节 / 按订单类型 |
| **业务规则关联** | §9.4 信用控制 ③ 60 天逾期冻结新单（已接 Wave C6）+ §10 业务十条交期锁死（未接） |
| **现状** | ⚠️ 字段齐全，但**无聚合端点**；Wave P0 已补"样品交期预警"（第 175 章） |
| **补建路径** | `/v1/metrics/on-time-delivery` 端点 + 周级 cron 聚合写入 MetricSnapshot 表 |

### 3.3 B3 — 质量合格率（Quality Pass Rate）

| 项 | 值 |
|---|---|
| **定义** | 终期验货（Final Inspection）通过率 + 平均疵点率 |
| **计算公式** | `passRate = COUNT(InspectionReport.result=PASS) / COUNT(InspectionReport) × 100%`；`defectRate = SUM(defectCount) / SUM(inspectedQty) × 100%` |
| **采集源** | `InspectionReport` + `PreCutChecklist`（生产管线 10 阶段 + 3 门禁） |
| **目标值依据** | 门禁 10：`passRate ≥ 90% + defectRate ≤ 3%`（PRD §9.3 ③ 终期 Final AQL） |
| **业务规则关联** | §9.3 质量门禁 ① PreCutChecklist 4 项 / ② 厂前样双签 / ③ 终期 AQL |
| **现状** | ✅ 数据底座完整：`InspectionReport` 模型 + `PreCutChecklist` + 生产管线门禁引擎（`server/src/production/stageService.ts`）；Wave P0 已补 QC 工作台深化（第 175 章） |
| **补建路径** | `/v1/metrics/quality-pass-rate` 端点 + 按工厂 / 季度疵点趋势 |

### 3.4 B4 — 资金周转（Cash Conversion Cycle）

| 项 | 值 |
|---|---|
| **定义** | 从采购付款到销售回款的资金占用天数 |
| **计算公式** | `CCC = DIO + DSO − DPO`（DIO=库存周转天数 / DSO=应收周转天数 / DPO=应付周转天数） |
| **采集源** | `Invoice` + `PaymentVoucher` + `InvoiceAllocation` + `InventoryBalance` + `FxSettlement`（已落地） |
| **分维度** | 按客户 / 按币种 / 按季度 |
| **业务规则关联** | §9.4 信用控制 ③ 60 天逾期冻结（已接 Wave C6）+ §10 业务十条 |
| **现状** | ⚠️ 数据底座完整（财务域模型组 9 个模型），Wave C6 已补"信用证三期预警 / 退税滞留分级预警"（第 180 章）；但**无聚合端点** |
| **补建路径** | `/v1/metrics/cash-cycle` 端点 + 月级 cron 聚合 |

## §4 系统指标逐项说明

### 4.1 S1 — 可用性（Availability）

| 项 | 值 |
|---|---|
| **定义** | 系统可服务时间占比（排除计划维护） |
| **目标值** | ≥ 99.5%（月级，~3.6 小时停机） |
| **采集源** | OPS Panel 健康检查 + Cloudflare 隧道状态 + Mac Mini uptime |
| **现状** | ✅ 基础健康检查端点存在（`/health`），但**不检查数据库 / LLM / TTS 等依赖可用性**（审计 §151 章）；Wave C 已补 env 模板 + 告警 webhook（commit `46503b8`） |
| **告警通道** | OPS Panel webhook → 飞书 / 邮件 |
| **依赖项** | PostgreSQL（必需）/ Mac Mini Express（必需）/ Cloudflare 隧道（push-based 部署通道）/ LLM 网关（降级可读）/ TTS（降级可读） |

### 4.2 S2 — 响应时间（Response Time）

| 项 | 值 |
|---|---|
| **定义** | API 请求 P95 响应时间 |
| **目标值** | 读 P95 ≤ 800ms / 写 P95 ≤ 1500ms |
| **采集源** | Winston 请求计时中间件（commit `e82ae6a`）+ Prisma 查询事件订阅（`BAMBOOK_SLOW_QUERY_MS` 阈值） |
| **现状** | ✅ 阶段 1 可观测性收口已落地：console→Winston 迁移完成 + 请求/查询计时接入；慢查询日志记录到 Winston daily rotate file |
| **关键路径** | `/v1/orders` 列表（含 EntityLink 图谱聚合）/ `/v1/reports/run` 报表运行 / `/v1/agent/loop` Agent 循环（≤ 90s 总预算） |
| **超时配置** | DuckDuckGo 搜索 15s / URL fetch 15s / IMAP 连接 15s / Agent `perToolTimeoutMs: 30_000` / `totalBudgetMs: 90_000` |

### 4.3 S3 — 并发（Concurrency）

| 项 | 值 |
|---|---|
| **定义** | 系统在不降级前提下可同时服务的会话数 |
| **目标值** | ≥ 50 并发会话（外贸团队典型规模） |
| **采集源** | realtime.ts SSE clients Set + 数据库连接池 + Agent 信号量三层 |
| **现状** | ⚠️ 三层信号量已建立：`runtime.ts` model(3) / search(6) / heavy(1)；同 session 新请求 abort 旧请求；但**零业务指标端点**；阶段 2 已修复 GAP-2 并发窗口（Serializable 隔离级别） |
| **限流策略** | Agent 层信号量 + 数据库连接池 + Express 单进程（Mac Mini 部署） |
| **风险** | `realtime.ts` 内存 Set，多进程部署时 SSE 事件无法跨进程广播（审计 §2525 P2） |

## §5 指标状态机

### 5.1 指标生命周期

```
   defined → instrumented → collected → alerted → reviewed → retired
       ↓           ↓             ↓          ↓          ↓
   (定义)     (采集埋点)     (端点暴露)  (告警阈值)  (周期复盘)
```

| 起点 → 终点 | 触发条件 | 门禁 |
|------------|----------|------|
| defined → instrumented | 指标定义纳入本文件 | Tech Lead 评审 |
| instrumented → collected | 埋点接入 + 端点暴露 | 端点可访问 + 数据可读 |
| collected → alerted | 告警阈值配置 + webhook 接入 | OPS Panel 触发验证 |
| alerted → reviewed | 月级业务复盘会议 | 管理层参与 |
| reviewed → retired | 业务下线或指标替换 | Tech Lead 评审 |

## §9 四态规范（空 / 加载 / 错误 / 无权限）

| 状态 | 指标呈现 | 处置 |
|------|----------|------|
| 空 | 指标未采集到数据（如新系统首日） | 显示"暂无数据"，附"开始采集"按钮 |
| 加载 | 指标聚合查询进行中（可能涉及大表 scan） | 骨架屏 + 进度提示；超时 5s 显示"加载较慢" |
| 错误 | 聚合查询失败 / 端点 500 | 显示"指标暂不可用" + 重试按钮；webhook 触发告警 |
| 无权限 | 角色无权查看该指标 | 隐藏指标卡片 / 显示"无权限"+ 申请权限入口 |
