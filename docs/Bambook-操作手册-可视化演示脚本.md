# Bambook 操作手册可视化演示脚本

> 用途：录制操作手册演示视频/GIF，用于培训业务员
> 工具：可用 Playwright/Puppeteer 自动化，或 OBS 手动录屏
> 时长：约 15-20 分钟

---

## 演示 1：快速上手（2 分钟）

### 场景 1.1：登录

**操作步骤**：
1. 打开软件（http://localhost:3000/ 或生产环境地址）
2. 展示登录页
3. 输入账号：boss@bambook.local
4. 输入密码：Bambook@2026
5. 点「登录」
6. 展示首页（工作台）

**解说词**：
"打开软件，输入你的账号和密码。首次登录后系统会要求你改密码。登录后你会看到首页，显示你今天要做的事。"

**画面重点**：
- 登录页完整展示
- 输入过程慢速展示
- 首页全貌展示

---

### 场景 1.2：左侧导航栏

**操作步骤**：
1. 鼠标移到左侧导航栏
2. 逐个展示导航分组（客户与市场/订单履约/财务/平台）
3. 点开「关系智库」
4. 展示关系智库首页（六大分类卡片）

**解说词**：
"左侧导航栏有所有功能模块，按业务分组。你只能看到你有权限的模块。比如点「关系智库」，这里有供应商、客户、代理商等六大分类。"

**画面重点**：
- 导航栏完整展示
- 鼠标 hover 效果
- 分类卡片展示

---

### 场景 1.3：找客户

**操作步骤**：
1. 在关系智库首页点「客户」分类卡片
2. 在搜索框输入「手册走查客户Alpha」
3. 点客户名进入详情页
4. 展示客户详情页（头部/联系方式/地址/财务/跟进管理/商机管线等）

**解说词**：
"找客户有三种方法：从关系智库找、从 CRM 找、从订单/报价跳转。比如在搜索框输入客户名，点进去就能看到客户的完整档案。"

**画面重点**：
- 搜索过程
- 客户详情页全貌
- 各个区块（跟进管理/商机管线/信用额度等）

## 演示 2：接新订单流程（8 分钟）

### 场景 2.1：客户建档

**操作步骤**：
1. 在关系智库首页点右上角「新增组织」
2. 填表单：
   - 基础信息：组织名称「演示客户ABC」
   - 联系方式：主联系人「张三」、主联系邮箱「zhangsan@abc.com」
   - 地址信息：注册地址「上海市浦东新区xxx路xxx号」
   - 财务信息：付款条款「T/T 30%+70%」、交易币种「美元」
3. 点「保存」
4. 展示保存成功后的客户详情页

**解说词**：
"新客户第一次联系你时，先建档。点「新增组织」，填五段式表单：基础信息、联系方式、地址信息、财务信息、备注。注意表单里的「信用额度」只是备注，真正的信用额度在详情页的「信用额度」区块设置。"

**画面重点**：
- 表单完整展示
- 每个字段填写过程
- 保存成功提示

---

### 场景 2.2：报价

**操作步骤**：
1. 点左侧「报价管理」
2. 点右上角「新建报价单」
3. 填表单：
   - 客户：下拉选「演示客户ABC」
   - 报价日期：默认今天
   - 有效期：默认 30 天
   - 币种：美元
4. 填报价明细：
   - 面料编码：输入「W001」，选中搜索结果
   - 品名描述：自动带出
   - 数量：3000
   - 单位：码
   - 单价：12.50
5. 展示双轨成本面板（可选）
6. 点「保存草稿」
7. 点「发送报价」
8. 展示发送成功提示

**解说词**：
"客户问你价格时，点「新建报价单」，填客户和明细行。面料编码打字搜索，选中后自动带成分和图片。双轨成本面板可以帮你算该卖多少钱。保存草稿后，点「发送报价」。系统会查 MOQ 和价格偏差，不合格会触发审批。"

**画面重点**：
- 表单填写过程
- 面料编码搜索效果
- 双轨成本面板展示
- 发送成功提示

---

### 场景 2.3：转订单

**操作步骤**：
1. 在报价单详情页
2. 点「接受」（客户电话/邮件说接受了）
3. 展示提示「已接受报价并自动转为订单草稿」
4. 点「转为订单」
5. 填 PO 号「PO-2026-ABC01」、工厂「演示工厂」、交期
6. 点「确认」
7. 展示转换成功提示
8. 点「查看订单」跳到订单详情页

**解说词**：
"客户接受报价后，点「接受」，系统会自动转为订单草稿。或者点「转为订单」手动转，填 PO 号、工厂、交期。转之前系统会再查一遍 MOQ。"

**画面重点**：
- 接受按钮点击
- 自动转单提示
- 转订单弹窗
- 订单详情页跳转

### 场景 2.4：采购

**操作步骤**：
1. 在订单详情页点「生成采购单」
2. 自动带订单明细
3. 填供应商：下拉选「演示供应商」
4. 点「保存草稿」
5. 点「发送」
6. 点「确认」（供应商确认后）
7. 点「收货」
8. 填收货数量：3000、合格数量：3000、仓库：主仓
9. 点「确认收货」
10. 展示收货成功提示

**解说词**：
"订单确认后，需要向工厂采购面料。点「生成采购单」，自动带订单明细。填供应商，保存草稿后发送。供应商确认后，货到了点「收货」，填收货数量和仓库。系统自动入库，库存增加。"

**画面重点**：
- 采购单生成过程
- 供应商下拉选择
- 收货表单填写
- 收货成功提示

### 场景 2.5：生产

**操作步骤**：
1. 点左侧「生产跟单」
2. 展示看板（10 列泳道）
3. 点订单卡片进入详情页
4. 在「生产管线」面板逐阶段点「完成推进」
5. 展示裁剪前检查（填 4 项检查）
6. 展示产前样确认（生产部和业务部双签）
7. 展示验货（QC 验货，合格率 ≥90%）

**解说词**：
"生产跟单是个看板，10 个阶段从业务下单到验货发货。点订单卡片进入详情页，在「生产管线」面板逐阶段点「完成推进」。关键节点：裁剪前检查要填 4 项，产前样确认要双签，验货要 QC 验货合格率 ≥90% 才能发货。"

**画面重点**：
- 看板全貌
- 订单卡片点击
- 生产管线面板
- 关键节点操作

---

### 场景 2.6：出运

**操作步骤**：
1. 在订单详情页点「创建出运」
2. 填运单：
   - 运输方式：海运
   - 装运港：上海
   - 卸货港：洛杉矶
   - 运费：5000
   - 保险费：500
3. 点「保存」
4. 点「从订单带出」生成装运行
5. 点「编辑装箱」
6. 填装箱明细：60 箱、毛重 1200kg、净重 1150kg、CBM 15
7. 点「保存」
8. 改状态推进：订舱 → 装货 → 发运
9. 展示发运成功提示

**解说词**：
"生产完成，验货合格后，点「创建出运」，填运单。装货前点「从订单带出」生成装运行，再点「编辑装箱」逐箱分配。一路改状态推进：订舱 → 装货 → 发运。系统会检查出运资格，QC 验货合格才能发。"

**画面重点**：
- 运单表单填写
- 装运行生成
- 装箱明细编辑
- 状态推进过程

### 场景 2.7：收款

**操作步骤**：
1. 点左侧「财务管理」→「发票」tab
2. 点「新建发票」
3. 填表单：
   - 类型：应收发票
   - 客户：演示客户ABC
   - 金额：37500
   - 币种：美元
   - 关联订单：选择刚创建的订单
4. 点「保存并开票」
5. 展示发票详情页
6. 点「收付款」tab
7. 点「新建收款凭证」
8. 填表单：
   - 收付类型：收款
   - 金额：37500
   - 币种：美元
   - 交易对象：演示客户ABC
9. 点「保存」
10. 在发票详情页点「添加核销」
11. 选中收款凭证
12. 填核销金额：37500、核销日期：今天
13. 点「确认核销」
14. 展示核销成功提示和发票状态变为「已结清」

**解说词**：
"货发出后，该给客户开发票了。点「新建发票」，填客户和金额，点「保存并开票」。客户付款后，点「新建收款凭证」，填金额和交易对象。最后在发票详情页点「添加核销」，选中收款凭证，填核销金额，确认核销。发票自动变「已结清」。"

**画面重点**：
- 发票表单填写
- 保存并开票按钮
- 收款凭证表单填写
- 核销勾对过程
- 发票状态变化

## 演示 3：日常跟进流程（3 分钟）

### 场景 3.1：客户跟进

**操作步骤**：
1. 在客户详情页
2. 找到「跟进管理」区块
3. 点「新建跟进」
4. 填表单：
   - 类型：电话
   - 日期：今天
   - 内容：电话沟通秋冬面料需求
   - 下次跟进日期：一周后
5. 点「保存」
6. 展示跟进记录列表

**解说词**：
"每天跟客户沟通后，在客户详情页找到「跟进管理」区块，点「新建跟进」，填类型、日期、内容。过了「下次跟进日期」没跟进的，会标红「已逾期」。注意日期输入框预填了当天日期，如果要改日期，先全选再输入。"

**画面重点**：
- 跟进管理区块
- 跟进表单填写
- 跟进记录列表

---

### 场景 3.2：商机推进

**操作步骤**：
1. 在客户详情页
2. 找到「商机管线」区块
3. 点「新建商机」
4. 填表单：
   - 标题：2026秋冬羊毛混纺面料采购
   - 预计金额：150000
   - 币种：CNY
   - 阶段：初步接触
5. 点「保存」
6. 点商机卡片的「推进 →」按钮
7. 展示阶段流转（初步接触 → 需求确认，概率 10% → 25%）

**解说词**：
"有潜在订单机会时，在客户详情页找到「商机管线」区块，点「新建商机」，填标题、预计金额、阶段。点商机卡片的「推进 →」按钮，进入下一阶段。阶段自动流转，概率自动联动。"

**画面重点**：
- 商机管线区块
- 商机表单填写
- 推进按钮点击
- 阶段流转效果

---

### 场景 3.3：订单状态更新

**操作步骤**：
1. 在订单详情页
2. 找到「生产进度时间线」
3. 点下一步按钮（如「已确认」→「生产中」）
4. 展示状态变化和时间线留痕

**解说词**：
"订单有进展时，在订单详情页找到「生产进度时间线」，点下一步按钮。系统自动记时间线（谁、什么时候、备注）。注意点状态按钮立即生效，无需二次确认。已交付是终态，所有按钮禁用。"

**画面重点**：
- 生产进度时间线
- 状态按钮点击
- 状态变化效果
- 时间线留痕

## 演示 4：财务对账流程（2 分钟）

### 场景 4.1：开发票

**操作步骤**：
1. 点左侧「财务管理」→「发票」tab
2. 点「新建发票」
3. 填表单（见场景 2.7）
4. 点「保存并开票」
5. 展示发票详情页

**解说词**：
"开发票在财务管理的「发票」tab，点「新建发票」，填客户和金额，点「保存并开票」。发票号可以留空，系统自动生成。草稿状态的发票可以编辑，开票后不能改只能作废。"

**画面重点**：
- 发票 tab
- 新建发票表单
- 保存并开票按钮
- 发票详情页

---

### 场景 4.2：收款核销

**操作步骤**：
1. 点「收付款」tab
2. 点「新建收款凭证」
3. 填表单（见场景 2.7）
4. 点「保存」
5. 在发票详情页点「添加核销」
6. 选中收款凭证
7. 填核销金额、核销日期
8. 点「确认核销」
9. 展示核销成功提示

**解说词**：
"客户付款后，点「新建收款凭证」，填金额和交易对象。在发票详情页点「添加核销」，选中收款凭证，填核销金额，确认核销。一张发票可以分多次核销，一张凭证可以核销多张发票。"

**画面重点**：
- 收付款 tab
- 新建收款凭证表单
- 添加核销弹窗
- 核销成功提示

---

### 场景 4.3：对账

**操作步骤**：
1. 点「对账」tab
2. 展示「四单对账」：订单 ↔ 出运 ↔ 开票 ↔ 收款
3. 展示差异分级（红/黄/蓝三级）
4. 点差异行下钻到单个订单逐字段对照
5. 展示「强制重算」按钮

**解说词**：
"月底或定期对账，点「对账」tab，看「四单对账」。差异按红/黄/蓝三级列出：红是严重（超发/超开/超收），黄是警示（未足量/未开票/未收款），蓝是提示（状态不一致/币种不一致）。点差异行下钻到单个订单逐字段对照。数据修复后点「强制重算」重新对账。"

**画面重点**：
- 对账 tab
- 四单对账展示
- 差异分级展示
- 下钻效果
- 强制重算按钮

## 演示 5：常见问题（1 分钟）

### 场景 5.1：信用门禁拦截

**操作步骤**：
1. 在订单详情页
2. 点「确认订单」
3. 展示拦截提示「客户信用门禁阻断，禁止新建订单」
4. 展示自动发起的信用例外审批单

**解说词**：
"如果客户信用有问题（冻结/逾期/吊销），订单确认时会被拦住。系统会自动发起信用例外审批，等审批通过后再点确认。"

**画面重点**：
- 拦截提示
- 审批单展示

---

### 场景 5.2：MOQ 校验拦截

**操作步骤**：
1. 在报价单详情页
2. 点「发送报价」
3. 展示拦截提示「低于起订量」
4. 展示自动发起的 MOQ 豁免审批单

**解说词**：
"如果报价低于起订量，发送报价时会被拦住。系统会自动发起 MOQ 豁免审批，等审批通过后再发送。"

**画面重点**：
- 拦截提示
- 审批单展示

---

### 场景 5.3：日期输入框问题

**操作步骤**：
1. 在跟进表单
2. 日期输入框预填当天日期
3. 直接打字（追加）
4. 展示格式错误提示
5. 全选再输入（正确）
6. 展示保存成功

**解说词**：
"日期输入框预填了当天日期，直接打字会追加，导致格式错误。先全选再输入，或用日期选择器。"

**画面重点**：
- 日期输入框
- 追加错误演示
- 全选正确演示

## 录制建议

**工具选择**：
- **Playwright/Puppeteer**：自动化录制，可批量生成 GIF
- **OBS Studio**：手动录屏，可加解说音轨
- **Loom**：在线录屏，可快速分享

**录制参数**：
- 分辨率：1920x1080
- 帧率：30fps
- 格式：MP4（视频）/ GIF（动图）
- 时长：每个场景 30 秒-2 分钟

**后期编辑**：
- 加字幕（关键操作步骤）
- 加高亮（鼠标点击位置）
- 加背景音乐（轻音乐）
- 加水印（公司 logo）

**适用对象**：业务员、销售主管、财务、QC、后勤、管理员、老板
**反馈渠道**：发现问题或建议，找管理员或技术支持
