## 面料线验收（= 实际跑的序列）

建米样（dev/yardage）→ 建账 20M → 分割 3M（父 17M + 子样 3M 继承来源/工厂/客户，父子流水互引）
→ 剪给客户 2M（15M）→ 剪 100M → 409 持有不足（账面不动）→ 重复建账 → 409 → 台账
[give, cut, set] 倒序含 balanceAfter → 父子样品软删回滚干净。

## 成衣线验收

米样是面料概念（subType=yardage 为面料样品子类型），成衣样品（fit/pp/size-set）无长度口径，
不适用；服务层对 type 不设限（字段可空），误用无副作用。

## 存量影响

- 存量样品 lengthQty 全为 null（不回填），界面显示"未建长度账"，零行为变化。
- 只有新建/已建账的米样才有长度账；样卡张数完全不受影响。
