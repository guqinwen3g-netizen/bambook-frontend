# 生产就绪贯通性审计（真装度 / 无卡点 / 非孤岛）— 2026-09-14

> 目标口径（业务方）：**生产库账号登进去就能真正干活**——从产品档案、关系智库、开发、报价、下单、订单跟踪，到财务开票、出运、回款，**全部功能真装、流程顺畅无卡点、跨模块数据正确加载与跳转、没有 prototype/临时/孤岛/糊弄**。
> 方法：4 路只读子代理并行全仓扫描 —— ①后端孤儿端点 ②前端死按钮/占位/假数据 ③导航断链与孤岛 ④主链逐跳贯通。全部结论带 `file:line` 证据。

## 一、总体结论

| 维度 | 结论 |
|---|---|
| 后端端点 | 79 router / ~1036 端点；**孤儿端点 72 个**（卡主链 0 / 能力缺失 15 / 纯冗余 57） |
| 前端页面 | **无空壳页、无空 onClick、无 MOCK/DEMO 假数据数组、无 ComingSoon 遮挡**；真没装仅 5 处 |
| 导航 | **死目标 0**；孤岛 6（真孤岛 4）；不带上下文跳转 4 处 |
| 主链 12 节点 | **4 个断点 + 2 个断头 + 6 处需手工重复录入** |

**一句话**：系统**不是空壳**——代码量与功能密度是真的；但**主链在「出运→报关」和「回款核销」两处确实断**，且大量下游单据**要手工重录上游已有的数据**。这正是不满足「顺畅无卡点」的地方。

## 三、卡点清单（按业务影响排序）

### P0 主链断裂（3 条）
1. **报关单脱离运单/订单**——断点 + 断头 + 重录三合一。运单页无入口；报关表单不采集 `shipmentId/orderId`（**后端已支持** `types.ts:4626`）；发货人/收货人/金额/件数/毛重全部手填（运单已有）；报关单仅能「生成退税草稿」，不回写运单/订单。
2. **回款凭证无订单/发票锚点**——`FinanceManager.tsx:486` 的 `voucherForm` 不带 `orderId/invoiceId` → **L5 自动核销形同虚设**（`L5AutoAllocate.ts:46`）→ 业务员必须手选发票与金额。
3. **订单详情 8 个下游阶段入口不带 orderId**——`OrderContextSection.tsx:215` 明明手握 `orderId`（`:2101`）却只切 view → 采购/出运/财务/报价/外协全部落地**列表**，业务员每次「跳过去再找回来」。

### P1 流程不顺 / 能力缺失（9 条）
4. **订单→采购仅带 1 行**（`ProcurementManager.tsx:300-306`），其余手录。
5. **出运装运行需手动「从订单带出」**（`ShipmentManager.tsx:1218`）。
6. **开发→报价不带 devCaseId/产品/价**（`QuotationManager.tsx:121-125,354-361`）——报价与开发案断链。
7. **`/api/v1/billing-items` 全族 7 端点零消费**（`finance/billingItemRoute.ts:48-88`）——DR-053「收费决定层」（免收/抵扣/承担方/确认/开票/取消）**无任何 UI 入口**，业务员只能绕道场景化开票。
8. **`CommandPalette` 的 `focusEntityId` 5 个模块不消费**（`RelationsManager.tsx:380`、`FinanceManager.tsx:444`、`ShipmentManager.tsx:429`、`DataCenter.tsx:23`、`EmailManager.tsx:90`）——全局搜索跳客户/发票/发货/知识/邮件**丢聚焦**（仅产品、订单可直达）。
9. **`CompletenessIndicators.tsx:237`** 的「去补齐」走 `/orders?id=X` → `App.tsx:1177` 把 `selectedOrder` 置空 → **把当前订单踢回列表**。
10. **MES / 营销 孤岛**——MES 排产行显示 `orderId`（`MesManager.tsx:805`）却点不进订单；营销线索 Converted 后无处可去（`MarketingManager.tsx:339` 无 nav）。QC 工作台 / 定价 只收 `onOpenOrder` 无 `onNavigate`；HR / 驾驶舱连 `onOpenOrder` 也无。
11. **`RelationCombobox` 键盘选择失效**——`handleKeyDown`（Arrow/Enter/Escape 全实现，`:118`）**从未挂到 input**（`:150-164`）→ 业务员**回车选不了客户**，只能鼠标点。
12. 日历点事件只到列表（`CalendarManager.tsx:156` 只传 view，`CalendarEvent` 无 targetId）。

### P2 冗余与清理（不卡主链）
