## 二、设计

**挂载点**：财务模块新增一个 tab「**核对**」（与「对账」并列）。
理由：这五个核对横跨 finance / customs 两域，但都属于「钱与单据的一致性复核」；
放财务模块改动最小（不用动 View 枚举 + 左侧导航 + 权限），且「对账」已在该模块。

**交互**：按**核对对象类型**（订单 / 运单 / 报关单）自动展示适用的核对项 ——
用户不需要记住"哪个核对要填哪种 ID"：

| 选的对象 | 展示的核对 |
|---|---|
| 订单 | 收汇 ↔ 报关 FOB（T7-③） |
| 运单 | 三单一致（T7-②） |
| 报关单 | 退税报缺（T7-④）+ 成交方式一致性（D2）—— **并行取数**（`Promise.all`） |

**渲染口径**：五个核对**全部只预警不阻断**（差异 severity 恒 `warning`），
故统一用 warning 色阶 + 提示图标，**不出现阻断性红**；差异卡片同时给出 `type / field / 期望 / 实际`，
便于人工判断。
