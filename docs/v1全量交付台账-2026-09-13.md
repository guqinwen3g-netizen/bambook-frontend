## 0. 口径与判定

### 0.1 v1 交付范围（§10.2 定案）
**必交付**：① 主线单据网 ② 财务四件全量（开票+核销+结案绿 / 付款申请审批流 / 订单利润表 / 退税·汇兑·费用归集）③ 主数据（关系/供应商/产品档案）④ 客户门户 ⑤ **全部周边模块零缺口**（HR/营销/风险/驾驶舱/库存/日历/数据中心——页面能开、数据能看、无死按钮/无占位）⑥ QC 全程 ⑦ 自制单据全套（PI/CI/装箱单/销售合同/报关全套等）⑧ 通知中心。
**v2**：AI Agent / 邮箱域 / Dashboard 工作台 / 知识库。**不做**：供应商门户、产地证。

### 0.2 状态定义（本台账用）
| 标记 | 含义 |
|---|---|
| ✅ 已交付 | 有实现 + 测试 + （关键路径）真实数据实跑 |
| 🟡 已实现待验收 | 代码/测试在，但未做 API 级真实数据实跑 |
| 🟠 有缺口 | 已知缺陷/死按钮/断链，见 §4 |
| ⬜ 未开工 | v1 范围内的未做项 |

### 0.3 验收方式（§10.5）
API 级真实实跑 + 契约测试 + 代码/数据走查；**不做** GUI 截图式。门禁：前后端 `tsc` 0 + 受影响域 vitest 全绿 + tokens + feature-inventory 三对齐销号。
