2. 延期：跟单员及时登记供应商新预计日期并提示受影响订单；对客户正式承诺交期由业务负责人取得客户确认后变更，保留原交期与依据。
3. 分批付款：按采购约定处理验收无争议部分；质量/数量争议部分单独暂缓结算并明确金额和负责人，定金及预付款按合同执行，不自动整单停付。
4. 客户临时改单：可先登记，通知相关岗位暂停受影响且尚未执行的动作，测算成本与交期；正式执行须变更获批，不受影响部分继续。
5. 复购确认：关键条件未变且客户接受沿用，可引用原确认依据；关键变化重新确认受影响项目，本次订单留存规格版本及依据。不要求每次复购重新打样，也不按同产品编号自动放行。
6. 出运准备期间质量异常：冻结受影响批次与数量，通知跟单/仓库/单证；其他货物重新核对齐套约定及单证后可继续，已生成CI/装箱单同步检查，不只修改库存状态。

## 追加确认与上线边界纠正（2026-09-30）

### 已确认的业务规则

- 余料：核实数量、归属、位置，由负责人决定退回、留厂备用、转其他订单或报废；来源及责任保留，报废审批，未处理余料不一概阻止原订单交货收尾。
- 供应商擅自换材料或加工厂：暂停受影响部分验收放行，评估规格、质量、客户要求及交期影响；涉及客户约定取得客户确认，经批准接受或返工/重做/索赔，其余部分可继续。
- 跨部门异常：每个事件有一名主负责人统筹，采购、QC、财务、销售按职责承担任务，处理结果齐备后关闭。

### 用户明确纠正：开发测试不得提前变成真实生产运行

此前“面料成衣少量代表性新业务受控试运行”和“阻断时经批准用应急记录继续办理”的提议，被用户本次明确纠正。不得据此前的B选择允许未验收软件承接真实业务。

1. 软件未达到完整上线验收要求前，只进行开发与测试。面料、成衣代表性案例及员工操作均在测试环境进行，不据此实际出货、付款或承担正式生产业务。
2. 完整业务、岗位交接、异常处理、权限、数量金额、部署与恢复须经验证；阻断性问题解决，未验证项不能算通过，不以正常路径或局部测试代替软件整体验收。
3. 由开发方汇总验收证据、未验证项及遗留问题，给出明确的能否上线判断；最终由用户明确批准启用。此决定方式已获用户“好的”确认。
4. 未达到门槛不能默认进入真实生产，也不能把先上线再修复作为交付策略。完成验收及批准后，才讨论和执行新业务正式接入。
5. 功能实施仍处于目标重审暂停状态；本次确认是上线决策原则，不是软件已达标、批准上线或批准恢复旧持续目标。

- 开发工作结束与整案费用核齐分开。开发可以结案，但快递费、测试费等尚未出账时，整案费用不能视为最终确定。
- 结案检查待到费用：明确项目、跟进负责人及凭据来源，金额标为待确定，不以0代替未知金额；已知费用正常登记。
- 仍有待到或未核对费用时，页面显示费用待齐；已登记金额只是当前小计，不作为最终整案总额，不进入默认综合收费确认及开票流程。
- 费用到齐并补录核对后，由负责人明确确认整案费用完整，再逐案决定综合收费或减免，然后交财务开票收款。

已确认默认流程更新为：开发期间登记已知费用 → 开发明确结案并检查待到费用 → 等待及补齐费用 → 确认整案费用完整 → 决定综合收费或减免 → 财务开票收款。

本条替代“结案即可直接确定综合收费”的可能理解。尚未确定金额的费用不是已确认金额为零；不得为了流程通过伪造零成本。费用齐备的字段/任务与权限实现待现状核对，当前仅记录规则、不恢复开发。

### 样品费用最小补齐方案草案（非已实施）

进一步核查发现：现CostRecord创建接口要求有效非负金额，不能直接以空金额登记；现有按案聚合函数可汇集开发案、批次、样品、封样的费用，可复用。所查开发及费用路径未找到整案费用齐备的明确确认机制，不据此断言全系统不存在。

拟定页面/操作：
- 开发详情内呈现费用区，分已登记明细、待到费用、整案核对结果、收费与财务进度，复用现有来源关系。
- 待到费用记录项目、来源、负责人、预计到账单时间和处理状态，不向现有实际费用表写0来占位；具体存储优先核查已有待办/业务事实能力后定。
- 账单到达后录入真实金额及凭据，与待到事项关联，完成事项；不复制为两笔成本。
- 开发结束且待到事项处理完并经明确核对后，才允许确认综合收费。没有待到记录不自动等于齐备，核对动作保留人、时间和范围。
- 对已知不再产生的待到项目可说明原因关闭，不伪造零金额费用。该操作为拟议专业设计，尚未实施。
- 费用齐备确认绑定当时明细；收费确认前如补记/更正费用，需重新核对。收费或发票已生效后保留原记录并进入调整处理，不自动改客户应收。
- 财务入口与开发入口执行同一齐备/收费检查，不只在前端禁用按钮。

代表性验证目标：两轮打样已登记+快递账单待到→开发结束但费用待齐→补账单后整案核对→决定收费或减免→生成财务草稿；未填金额、重复补录、增加新费用后的旧确认失效、失败重试等一并验证。尚未运行这些场景。
