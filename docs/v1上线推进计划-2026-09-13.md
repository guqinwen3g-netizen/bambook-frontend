- **先修会造成钱/货/质量事故的正确性缺陷**（金额、单位、数量、漏催）

**P0-6 评估结论（2026-09-13，先核准再动手，勿重复评估）**：
- 原兜底 `if (sample && release.sampleRound != null && round 不等)` —— 三个条件任一不成立就整体跳过。
- 关键事实：**「置 status=revising」与「round+1」是两个独立动作**。`sampleManageService.advanceSampleStage` 里
  `qc(failed)` 与 `confirm(needs_revision)` 只把 status 置 `revising`，**round 不变**（只有后续 `start` 才 +1）。
  `confirm(rejected)` 置 `rejected`，同样 round 不变。
- 空窗链路（已在单测中复现）：scope 处于 `paused` → `invalidateScopesBySample` 只处理 `state==='ready'` 故跳过
  → 期间样品返修（round 未变）→ `resume` 直接回 `ready` → 兜底比 round 相同 → **eligible=true，误放行**。
- 另两处同源：`release.sampleRound == null`（历史批准未锁轮次）时兜底整体失效；证据样品被软删后
  `sample=null` → 兜底也整体失效。

**P0-6 落地结论（2026-09-13）**：兜底改为**分层**，任一不成立即拒绝，且不再整体依赖 `sampleRound`：
1. 证据样品查不到（软删/不存在）→ 「无法核验」拒绝（fail-closed；联动本身是 fail-open，兜底就是它的安全网）；
2. 样品当前处于**证据失效态** `revising` / `rejected` → 无论 round 是否变化，拒绝（新增常量 `EVIDENCE_VOID_SAMPLE_STATUSES`）；
3. round 可比对（非空）且已变化 → 拒绝（原逻辑保留）。
- **不误伤**已验证：放行后封样 `sealed` / 继续 `confirmed` / 正常 `approved` 仍 eligible（round 未变也不拦）。
- 仅当 `Sample` 模型在当前 client 不可用时才整体跳过（旧 client 兼容，保持原 fail-open）。
- 新增回归 5 例（4 例修前红、修后绿；1 例不误伤恒绿）；production+samples 域 239/239 绿。
- 真库 API 级实跑（真实登录 token，非伪造）：建 PP 样 → 建范围 → 发起请求 → 领导单签 → `eligibility`
  由 `true` → 置 revising（round 仍 1）后 `false`（reasons=「样品证据已失效」）→ 置 rejected 同样 `false`。种子数据已全量回滚（5 张放行表归 0、验证样品删除、临时脚本删除）。

**P0-4 定案与落地结论（2026-09-13，业务方拍板「只用一种币种」）**：
- 机制：`markShipped` 门禁线 `required = max(0, orderAmt − batchAmt) × coverRatio`（订单币种），已收 `paidAll = totalPaidOfOrder(orderId)`。
- 原缺陷：`totalPaidOfOrder` 把该订单**全部发票**的 `InvoiceAllocation.appliedAmount` **直接相加，不做币种换算**；错误信息却统一标 `batch.currency`。注释自称「跨币种门禁由上层换算后覆盖 coverRatio」，但 `route.ts` 直接透传 body，**无换算层**。
- 关键事实：**`Order` 没有锁汇率字段**（只有 `currency`/`salesCurrency`/`purchaseCurrency` 字符串与各类金额），只有 `Invoice.exchangeRate`（→ baseCurrency 默认 CNY）→ 「按订单锁汇率换算」当前无字段可依。
- **业务定案（三选一取①）**：**订单收款恒为销售币种；凡出现混合币种或与门禁币种不符 → 报错拦截**（报错优于算错，与 P0-2/P0-3 同取向）。**不做任何隐式汇率折算**。
- 落地：`totalPaidOfOrder(orderId, expectedCurrency)` 改为返回 `{ok:true,total} | {ok:false,currencies}`；发票币种取 `distinct`，>1 种、或唯一币种 ≠ `batch.currency` → 返回 `{ok:false}`；调用方 fail-closed 返回 **409 `FINAL_PAYMENT_GATE_CURRENCY_MISMATCH`**（含实际币种清单，提示核对发票或走 `skipGate` 管理员豁免留痕）。
- 新增回归 2 例（混合币种拦截、单币种与门禁币种不符拦截）；shipping 域 12 文件 174 例全绿；server/root tsc 0、tokens 0。
