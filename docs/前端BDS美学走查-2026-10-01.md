## 三、具体缺陷清单（P0 → P2）

### P0-1 · 字号低于可读硬底（~1200 处）

**判据**：`tokens.css:334-340` 字号 token 最小为 `--text-xs: 12px`；`tokens.css:332` 与 `tailwind.config.js:75-77` 双双载明「**11px 中文低于可读硬底（CJK 笔画密度高，12px 以下发虚）**」。10px 比这份被否决的 11px 还小 1px。

> 可能的反驳：「但 `components.css` 里也有 30 处 `font-size: 10px`。」
> **不成立**：那 30 处是组件 CSS 内部的硬编码字面值（`.bds-badge.sm:332`、`.bds-table.compact th:1360`、`.bds-tl-time:1429`），它们自己也违反「值必须取 token」；且 **BDS 没有暴露任何 10px 工具类**（`.bds-text-*` 到 xs 为止）。正确用法是**调用**那些组件（写 `.bds-badge.sm`），不是去复刻它的一行 CSS。

**含 `text-[10px]` 最多的文件**：`ShipmentManager.tsx`(68) · `finance/FinanceReportsPanel.tsx`(57) · `development/SampleRoomPanel.tsx`(51) · `RelationsManager.tsx`(47) · `DevelopmentManager.tsx`(44) · `finance/FinanceCreditPanel.tsx`(41) · `FinanceManager.tsx`(37) · `AdminPanel.tsx`(34)

### P1-4 · `tracking-[0.14em]` 是「越狱的事实标准」，建议收编而非删除

**CustomSelect 测试适配的可复用范式**：

```tsx
const pickOption = async (label: string) => {
  await act(async()=>{ node.querySelector<HTMLButtonElement>('[data-select-trigger]')!.click(); });
  await act(async()=>{ [...document.body.querySelectorAll<HTMLButtonElement>('[role="option"]')]
    .find(b => b.textContent === label)!.click(); });
};
```

> 两个 `act` 分别承载「开菜单」「选值」两次状态更新；选项 portal 到 `document.body`，不在组件宿主容器里。
