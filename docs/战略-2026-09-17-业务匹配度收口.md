**产出：《业务口径真源》**（一份文档，后续所有开发的口径依据）。

**做法：按业务链走，不按文档章节走。** 8 个环节，每环节 3 问：

```
询价 → 订单 → 采购 → 生产 → 出运 → 报关 → 收汇 → 对账
```
