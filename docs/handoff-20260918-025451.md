### 6.2 技术坑

- **★ 走查脚本必须「每个用例前回到干净状态」**：`page.goto(BASE)` 重置。
  仅 `Escape` 关模态**关不干净** ⇒ 后续用例全假失败。**脚本不可信比没脚本更糟**（会持续产假信号）。
- **★ 不要用 localStorage 注入 token 绕过登录**：key 猜错 ⇒ 全站 401、侧栏空白，
  会让你误判「页面没渲染」。**走真实登录表单**（`input[type=text]` / `input[type=password]` / `button[type=submit]`）。
- **★ Edit 的 old_string 拼接会误删行**：本会话把 `const result = await db.$transaction(async (t) => {`
  整行删掉 ⇒ `catch/finally expected` 语法错。**跨行拼接时务必核对首行是否被完整包含**。
- **`UserAccount` 测试数据字段是 `displayName`**（无 `role`），照抄 `allocationService.test.ts:61-68`。
- **前端 dev server 不在 launchd 里**：`npm run dev`（vite，3000）；后端 8081 由 launchd 托管。
  本会话已起 3000（**后台任务 `ySyoF7`，仍在跑**），可直接用。
- `launchctl stop` 在沙箱 **Not privileged**（停不掉 8081，只能 `kickstart -k` 重启）。
