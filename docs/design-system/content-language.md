# Content And Language

Content is part of the UI system. Inconsistent words create inconsistent surfaces.

## Voice

Bambook OS voice is:

- Precise.
- Calm.
- Operational.
- Short.

It is not:

- Marketing.
- Tutorial-heavy.
- Decorative.
- Over-explanatory.

## Titles

Rules:

- Page title names the work area.
- Descriptive value props do not belong in titles.
- Breadcrumbs describe navigation depth.
- Avoid long sentence titles.

## Labels

Rules:

- Field labels are stable business terms.
- Section labels are short nouns.
- Labels do not end with punctuation.
- Do not use helper copy when a clear label is enough.

## Buttons

Rules:

- Use verb + object for important actions.
- Use icon-only only for familiar utilities and always include `aria-label` or `title`.
- Destructive buttons name the destructive action.
- Avoid vague verbs like "处理" unless the domain already defines the action.

## Missing Data

Standard missing values:

- Empty value: `未填`
- No records: `暂无数据`
- Loading: `正在读取...`
- Error: `读取失败`

Rule: absence must be visible and intentional. Blank space should not look like a rendering bug.

## Bilingual Text

Rules:

- Chinese owns interface structure.
- English remains for domain identifiers, product codes, model names, external fields, and source data.
- Do not translate codes, SKUs, order IDs, or source terms that users must match externally.

## Tooltips

Rules:

- Tooltips name unfamiliar icons.
- Tooltips do not repeat visible labels.
- Tooltips do not explain page philosophy.
