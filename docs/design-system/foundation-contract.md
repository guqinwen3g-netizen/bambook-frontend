## 页面组合

### 列表

使用 `ListWorkspace`，其页壳直接复用 `PageWorkspace`。查询在 `header.query`，同层视图在 `header.center`，页面级动作在 `header.actions`。表体单独滚动，底栏在其外。页码接口使用 `ListFooter`，offset 接口使用 `ListLoadMoreFooter`，不为接口伪造分页。

运行例：`/dev-ui-preview/showcase.html?recipe=list`。该例使用真实页壳、查询、状态标签和底栏，包含本地过滤、分页、打开对象及进入新建。

### 详情

`DetailWorkspace` 的 `identity` 仅接收对象名、编号、状态和必要事实；`task` 接收任务标题及主/次动作配置；正文通过 `children` 提供，支持信息通过 `supporting` 提供。`utility` 在主滚动区之外，传入当前对象的 `ObjectUtilityFooter`。

对象身份默认开放；存在真实当前任务时才传入 `task`，形成一个焦点容器，不把每个参数拆成卡片。只读档案可省略 `task`，正文保持开放，不为满足页型凭空添加任务或操作。阅读宽引用 `--w-workspace-reading`，分组间隔引用 `--gap-workspace-section`。原订单的特殊滚动与三维交接仍是独立扩展，不由这个基础页壳覆盖。

运行例：`?recipe=detail`，包含当前任务操作、修改入口、底部来源浮层和返回列表。

### 录入

`FormWorkspace` 将页面主按钮与 `formId` 绑定，`submitting` 同时禁用字段集和返回。`FormSection` 负责分组，`WorkspaceField` 的判别类型为 text / textarea / select / date；标签、错误和帮助文字有固定关联。选择和日期复用既有生产组件。

表单宽引用 `--w-workspace-form`；字段最小宽引用 `--w-workspace-field-min`，网格按实际容器自动收列。长字段显式 `fullWidth`。原生输入保留 required 语义；表单使用 `noValidate`，统一由 `onSubmit` 与领域校验负责，返回 `error` 后关联到控件，避免原生提示提前拦截共享错误反馈。选择与日期同样必须有领域校验，不能依赖显示星号代替业务校验。

运行例：`?recipe=form`，包含必填、禁用、校验错误、确认对话框及未保存返回确认。

### 弹层

确认弹窗使用生产 `BdsDialog`，保留焦点闭环、Escape、提交中关闭规则。复杂编辑抽屉仍是未完成契约，不用这个确认弹窗假冒统一抽屉。来源/历史使用 `ObjectUtilityFooter` 的 page/card 归属，不在业务正文中间常驻铺开。
