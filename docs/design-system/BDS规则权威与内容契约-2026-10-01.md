日期：2026-10-01。状态：W1 实施候选契约，可用于下一批页面的设计和实现准备；尚未经过用户视觉接受。初稿核对本地规范、token、组件和运行入口；后续局部实机证据另记，不等同全局视觉验收。源文件行号为本次核对位置，后续可能随代码变化。

## 1. 范围与执行边界

用户本轮要求是全局 UI/UX 学习、总结、收拢后持续优化，唯一界面豁免为 Dashboard。所有其他页面及其子视图、容器、按钮、卡片、文字、弹窗、抽屉、空错态均纳入。Claims 是待修对象，不是认可样板。

打印、邮件、SVG 等有输出介质约束，但不因此豁免其产品操作界面。不得为统一应用字号直接破坏对外文件版式；发现此类差异时登记介质规则并分别验收。Dashboard 不做改造，任何共享 token/组件变更必须检查是否间接影响它，必要时按已有作用域隔离。

本轮不改变业务字段含义、权限、状态转换和提交语义。默认展示与展开的调整必须保留信息可达性；删除字段、改变流程、引入新操作需单独说明，不得借视觉整改夹带。

## 3. 文字语义配方

数字刻度来源：`styles/bds/tokens.css:334-350`；语义起点来源：布局语言 `:111-137`，列表组件 `components.css:305-316`。以下补齐的是使用条件，不是新增全局 CSS，也不声明已完成组件化。

| 内容角色 | 默认表现 | 布局与内容约束 |
|---|---|---|
| 页面/抽屉标题 | 18px，300，primary | 使用 PageHeader/既有抽屉标题槽；标题说明不得与标题同权重 |
| 独立任务面板标题 | 16px，300，primary | 只用于真正独立任务区；不要每个字段组都升级16px |
| 分组标题、对象主名称 | 14px，300，primary | 对象列表一行只保留一个主要识别项；客户/时间/编号等附属信息降级 |
| 正文、字段值 | 14px，300，primary或secondary | 说明段落按 `--font-sm` 的1.5行高；长值换行或可访问的截断展开，禁止撑破卡片 |
| 字段标签 | 14px，300，secondary | 与值在位置和墨色上分层；密集键值摘要可12px，必须逐图确认可读 |
| 元信息、时间、辅助标签 | 12px，300，tertiary | 不用承载必须读懂才能完成操作的核心说明；不得堆多行元信息成为主要内容 |
| 状态 | 12px，语义徽章及文字 | 状态必须能由文字识别，不能只靠颜色；同一对象不重复多次展示相同状态 |
| 关键金额/数量 | 16px默认，20px仅任务关键摘要 | 数字与币种/单位分层；表格数字右对齐、等宽数字；不是每张卡都造KPI |
| 错误及恢复提示 | 字段12px，区块14px，danger文本 | 写清发生什么及下一步，错误靠近来源；不能用浅色辅助文本弱化阻塞原因 |

组合规则：一个容器先确定主内容，再安排辅助说明和操作。常规业务卡采用“14/16px主项 + 14px值 + 12px元信息”，不得所有子节点统一继承16px，也不得整卡全部压成12px。文本语义显式声明，HTML 标题级别为可访问性服务，不用 h 标签本身决定视觉大小。正文不施加 caps 字距。

## 4. 容器职责与组合配方

| 配方 ID | 适用与结构 | 已有承载 | 禁止或转型条件 |
|---|---|---|---|
| C01 页面画布 | 页头 → 顶层工具区 → 主内容；页内主滚动区明确 | PageHeader、PageShell；应用规范`:171-182` | 不重复包页级padding，不让工具条跟随内层列表意外滚走 |
| C02 对象列表行 | 主识别项/状态 → 一行关键摘要 → 次级元信息；操作独立尾槽 | `.bds-listrows/.bds-listrow`及lr-main/title/sub | 不把整行做button后再嵌button；重复同字段比较需求多时改表格 |
| C03 任务卡 | 标题/必要状态 → 一种任务的主体 → 必要操作 | `.bds-card`、现有标题/工具配方 | 卡片不能只作为每段文字的背景；多个无关任务必须拆任务区 |
| C04 键值详情 | 分组标题 → 标签/值网格；说明独占全宽 | 在现有卡内按token间距排布 | 默认无第二层玻璃；不得每个字段单独造卡；标签和值不能同字号同墨色挤成句子 |
| C05 数据比较表 | 统一表头、列对齐、数字右对齐、操作末列 | `.bds-table` + `TABLE_DENSITY` | 不为追求密度缩到12px以下；长描述放详情入口或允许换行，金额/状态不省略失义 |
| C06 表单组 | 分组标题 → label/control → hint/error；提交区固定逻辑位置 | `.bds-formfield`、CustomSelect、既有输入组件 | 多行输入不用pill；错误不可仅toast；label不可用placeholder替代 |
| C07 状态区 | 明确空/加载/失败/无权限 → 原因 → 有效下一步 | EmptyState、ErrorBanner、Skeleton | 零记录和加载失败不能共用“暂无数据”；不把技术解释塞进正常内容 |

容器判断顺序：是否独立任务 → 是否需要比较 → 是否需要持续可见 → 是否只是内容分组。仅内容分组优先留白/标题/分隔，非必需不加新表面。卡片内间距从既有 `--space-*` 取值：标签与值4/8，同行信息8/12，分组16/20；选择须匹配密度，不能跨页面机械替换。主表面复用 `.bds-card`，内嵌层先无背景，确需区分时才用既有recessed/flat配方，禁止膜叠膜。

摘要与完整信息分离只适用于确认不会隐藏关键决策条件的内容。阻塞原因、金额差异、不可逆操作后果不得折叠成“更多”。任何收起均提供明确可见入口并保留键盘可达。

## 5. 按钮与交互契约

沿用 `component-application-spec.md:67-80,198-203`，用任务区而非整页机械计数。

| 角色 | 配方 | 使用纪律 |
|---|---|---|
| 当前任务主要动作 | `.bds-btn` + primary | 每独立任务区最多一个；新建类在PageHeader，依赖面板输入的保存/提交留在面板；同一动作不在两处重复争夺主色 |
| 常规次操作 | secondary/outline | 与primary同行优先不超过两个；行内状态动作不用primary；数量过多先按频率分组，不能盲目藏必要操作 |
| 低频工具动作 | ghost | 刷新、更多等；动作名用业务动词，图标仅辅助 |
| 危险操作 | danger | 独立末位，与primary留出分隔；确认机制沿用业务要求，不因视觉整改删除 |
| 图标操作 | icon变体 | 仅清晰熟悉动作；具有可访问名称和键盘焦点，必要tooltip；陌生业务操作保留文字 |

尺寸：内容组合工具区40px；密集模态输入34px；卡片/行内次操作32px；独立表单44px输入。56px外壳大按钮只在现有PageHeader配方适用时保留，不复制到卡片。所有操作验证idle/hover/focus/pressed/disabled/loading；异步提交避免重复触发，禁用原因可被理解。点击卡片的导航与卡内操作事件必须分开，验证无意外冒泡导航。
