## 2026-10-14 · 报价条目专业核算首轮与冻结依据

- 从开发 `0978408` 接续，仍只推送 `feat/mist-fabric-commercial-units`；main 保持 `5a17794`，不部署、不交付压缩包、不接外部价格或模型服务。示例种子维持 v10，已有空间与附件不覆盖。
- 准确入口：报价详情每个条目的「条目核算」→ T9 成本来源 / 本次报价策略 / 核对冻结；按 quotationId + lineId 打开，失效行不猜配其他产品。返回准确报价；已发送、审批中、已转单或无报价写权限时只读，不能以新核算绕过报价版本。
- 两条人工路径：供应商成品报价＋明确未含的包装 / 运费 / 保险 / 银行 / 佣金 / 其他单位费用，或逐项专业拆解。前者拒绝再次叠加纱线 / 面料 / CMT 等成品基数成本，附加项逐项确认不包含；后者无成品报价基数，可记纱线 / 织造 / 染整 / 后整理或面料 / 辅料 / CMT 等。准确规格、成本计价单位、同币种、来源日期 / 有效期、交付与包含条件、用量 / 耗用单位 / 损耗 / 单价 / 依据及本次策略人工明确，不将旧行业常数或公司底线预填成事实。
- 模型 `quote-cost-v1`：输入普通十进制字符串，拒绝空值代零、指数、负数及超精度；单项用量 × (1＋损耗) × 单价用整数运算，末次统一舍入四位后汇总，不先舍入中间耗用量。成本加成＝成本×(1＋比例)，销售毛利目标＝成本÷(1－比例)，后者须小于100%；四位参考成本 / 建议价、两位报价与原门禁口径分别保留。没有外汇、米码公斤转换、退税或行业适配默认值。
- 快照与权限：新增 `market.quotation.costing.save`，沿 `quotations:write` 和既有独立业务审批。服务端重算，不接受客户端派生结果；冻结原始输入、公式版本、来源供应商身份、准确报价行及商业条款、附件元信息和操作者。每次追加，不覆盖历史；旧引用改名或改价不改已存依据。商业条件、其他条目、附件 / 备注或同时间再次提交变化时，乐观目标校验拒绝旧表单。原请求核对、失败保输入、同拍锁和跨目标 / 空间迟到隔离有回归覆盖。
