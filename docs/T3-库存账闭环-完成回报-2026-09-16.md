## 存量影响

- **从本批起出运会真扣库存**：历史上发过的运单不会补扣（无回溯逻辑），新发运单从 Shipped 起扣。已 Shipped/Arrived/Cleared/Delivered 的存量运单被取消时会查原 Outbound 流水做回冲——无流水（存量单）则回冲 0 行，不报错。

- 盘点界面从此可以清零（此前 400），错误提示文案更新。
- 部署顺序无要求（前后端可独立发；后端先发时前端旧界面提交盘点 0 会收到 400——与现状相同，不劣化）。
