# V1 新增事实关系与门禁登记

日期：2026-10-01。适用候选分支 `codex/v1-preacceptance`，不代表已加载至 localhost:3000，也不构成业务验收通过。

B120 的历史固定集合为 13 个 UserAccount 外键，其中 7 个必选且不级联。V1 新增的以下六个关系必须保留行为人的真实身份；缺失身份不能用虚构占位或省略审计修复：

| 新关系 | 新业务事实 | 删除政策 |
| --- | --- | --- |
| CreditNoteRefund.requesterId | 客户真实退款申请 | 必选，不级联 |
| CreditNoteRefundEvent.actorId | 退款原命令不可覆盖事件 | 必选，不级联 |
| CreditNoteRefundEvidence.uploadedBy | 私有银行凭据上传人 | 必选，不级联 |
| OrderCostReview.confirmedBy | 实际成本核对确认人 | 必选，Restrict |
| OrderCostReviewEvidence.createdBy | 原核对凭据上传人 | 必选，Restrict |
| CreditNoteRefundReturn.actorId | 已付退款后的真实返款事实 | 必选，Restrict |

因此当前源 schema 的精确集合为 19 个 FK / 13 个 blocking。更新测试的精确集合；仍保留源文本与固定源提交生成 DMMF 的独立对照、必选/可空/级联分类正反控制、删除面只降不升的预算，未新增删除或验收脚本跳过豁免。新增模型的上线依据由后续固定 SHA 独立 PostgreSQL、六个 migration 的升级差分及原业务用例回归提供；本表本身不是验证证据。
