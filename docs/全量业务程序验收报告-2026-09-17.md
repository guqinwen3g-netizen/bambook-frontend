## 三、★★★ 真缺陷（已修 + 已验证）：`clearError` 自己调自己 ⇒ 栈溢出

`components/ShipmentManager.tsx`：

```ts
const clearError = useCallback(() => {
  clearError();        // ← 自己调自己 ⇒ 无限递归
  setGateBlock(null);
}, []);
```

- **用户影响**：点「**新建运单**」/「**编辑运单**」⇒ `RangeError: Maximum call stack size exceeded` ⇒ **表单打不开** ✗
  （该函数在 **8 处**被调用 + 挂在错误横幅关闭按钮上 ⇒ 影响面大）
- **修法**：`setErrorMessage('')` ✓
- **真浏览器修前/修后对照**：修前各 **1 条栈溢出** ✗ / 修后 **0 条** ✓ + 表单正常打开 ✓
- **守卫**：`components/noSelfRecursiveCallback.test.ts`（判据三次收紧；**证伪**已咬红 ✓）
- ★ **为什么三层门禁全瞎**：`tsc` 不报 · 单测不渲染该交互 ·
  **连栈帧都骗人**（200 帧全指向一个无关组件的 `<input>` 行 ✗）
  ⇒ 靠 **`curl` 开发服务器拿「浏览器实际执行的转换后代码」**才定位 ✓
